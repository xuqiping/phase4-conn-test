## F1 后端：from-media 同项目判重 + 批量已入库查询

- `AssetMediaBridgeService`：
  - `importFromMediaTask` 在 requireWrite 后插判重：`findExistingBySource(projectId, taskId, imageIdx, category)`——按 `gen_meta` JSONB 文本匹配（`gen_meta->>'source'='MEDIA' AND ->>'taskId'=N [AND ->>'imageIdx'=I]`）+ mediaCategory 区分图/视频。命中 → 返回 `created=false, duplicate=true, assetId=既有`，不再触达媒体查询/insert。**不同项目仍可各自入库**（同一张图存多项目语义保留）；并发双击极小竞态由前端入库后置已入库态兜底（不做唯一索引，注释落字）。
  - `buildGenMeta(task, imageIdx)`：图片行 genMeta 新增 imageIdx（判重键）；**存量旧行无 imageIdx 键 → 判重不命中允许补入库（向前兼容）**。
  - `existsBySourceTaskIds(List<Long>)` → `Map<Long,Long>` taskId→首个资产 id（跨项目、source=MEDIA、按 id 升序取首；Long 校验拼 IN 无注入面）。
- `MediaImportVO` +`duplicate` 字段（@Builder.Default false），javadoc 更新判重语义。
- `AssetMediaBridgeController` +`GET /api/assets/exists-by-source?taskIds=`（@RequirePermission asset:write——与入库同权限族，产出 tab 已入库 tag 只对可入库者显；上限 50 静默返空）。
- 判重 SQL 语义注解：MP `apply` 参数占位 `{0}`（taskId/imageIdx 文本比较，PG `->>'k'` 返回 text）。
