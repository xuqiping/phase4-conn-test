# 人工测试问题 1—4 修复 PRD

> 类型：Phase 1 专项规格（需求真相源）
> 日期：2026-09-03
> 范围：文件管理、进程管理、公共桌面入口、剪贴板
> 来源：`workflow_output/人工测试问题/1x_文件管理.md` 至 `4x_剪切板.md`

## 1. 背景与目标

本轮解决四份人工测试文档中的六个未解决问题：收藏项独立快捷键、Windows 快捷方式托管、进程窗口标题默认展示、关闭后悬浮球、剪贴板置顶、剪贴板分组。

目标是让这些能力保持**本地优先**（数据与操作留在用户设备），不依赖登录、服务端或会员权益，并兼容现有收藏、进程设置和剪贴板历史。

## 3. 用户故事

- 作为办公用户，我希望给任意收藏项绑定全局快捷键，以便不打开主界面也能启动文件、文件夹或程序。
- 作为使用桌面快捷方式的用户，我希望删除桌面 `.lnk` 后，File Keeper 内的收藏仍然有效。
- 作为进程管理用户，我希望直接看到每个 Office 或资源管理器窗口的标题，以便区分同一进程的多个窗口。
- 作为频繁调用 File Keeper 的用户，我希望关闭主窗口后保留悬浮球入口。
- 作为剪贴板重度用户，我希望置顶重要内容并用分组组织历史记录。

## 4. 功能需求

### 4.1 收藏项独立全局快捷键

1. 文件夹、普通文件、Office 文档、EXE 和托管快捷方式均可设置一个可选全局快捷键。
2. 保存前检查收藏项之间，以及主窗口、剪贴板、截图快捷键之间的冲突。
3. 快捷键必须先试注册成功，再注销旧快捷键并保存；失败时保留旧配置。
4. 系统或其他应用占用但无法识别占用者时，显示明确提示。
5. 应用启动后异步恢复全部快捷键；单项失败不影响其他项，并提供失败清单。
6. 触发快捷键后复用现有打开逻辑，并更新打开次数和最近打开时间。

### 4.2 拖入路径与快捷方式托管

1. Windows `.lnk` 被拖入时，先解析目标，再复制到 File Keeper 的托管缓存目录；收藏项实际启动缓存副本。
2. 文件夹、PPT、Word、Excel、PDF、普通文件及非快捷方式 EXE 仅保存原始绝对路径，不复制内容。
3. 删除收藏项时只允许删除 File Keeper 创建的托管副本，绝不删除用户原文件或目录。
4. 原路径或 `.lnk` 最终目标失效时，收藏项显示“路径失效”，并支持重新定位。
5. 重新定位后保留分组、标签、独立快捷键、打开次数和创建时间。
6. `.lnk` 导入失败时不得创建收藏项或遗留半成品缓存。

### 4.3 进程窗口标题

1. `windowTitle` 列改为默认显示并支持排序。
2. 旧设置按列 key 与新默认值合并；缺失列自动补充。
3. 执行一次版本化迁移，使升级前默认隐藏的窗口标题首次升级后显示；迁移后尊重用户手动隐藏选择。
4. 标题读取失败时显示 `-`，不影响刷新、激活、关闭或强制结束。
5. 不改变现有基于窗口句柄的安全关闭逻辑。

### 4.4 关闭行为与悬浮球

1. “关闭主窗口后的行为”改为三个互斥选项：`floating_ball`、`tray`、`exit`，默认 `floating_ball`。
2. 悬浮球支持拖动、位置记忆、单击恢复主窗口。
3. 右键菜单提供“打开主窗口”“切换为托盘”“退出”。
4. 主窗口恢复后悬浮球自动隐藏。
5. 分辨率、缩放或显示器拓扑变化后，位置自动校正到可见工作区。
6. 悬浮球创建失败时降级为托盘并提示，不能让应用进入无可见入口状态。

### 4.5 剪贴板置顶

1. 单条记录右键菜单提供“置顶/取消置顶”。
2. 置顶项位于当前筛选结果顶部，多条置顶按最近置顶时间倒序排列。
3. 置顶项仍受关键词、类型、日期和分组筛选约束。
4. 再次采集相同内容时保留其分组和置顶状态。
5. 置顶记录继续受现有缓存保护策略保护。

### 4.6 剪贴板分组

1. 每条剪贴板记录最多属于一个自定义分组。
2. “全部”和“未分组”为固定查询入口，不写入可删除分组表。
3. 支持新建、重命名、删除分组，以及单条或批量移动记录。
4. 删除分组时，其中记录自动回到“未分组”，不删除记录内容。
5. 分组名去除首尾空白，长度为 1—40 个字符，拒绝控制字符；同名按忽略大小写判重。
6. 快捷面板默认搜索全部分组；主页面可记忆上次分组筛选。

## 5. 兼容性与范围边界

- 旧 `FileItem` 缺少新增字段时按默认值迁移，不要求用户重建收藏。
- 旧剪贴板记录默认归入“未分组”，默认不置顶。
- Windows `.lnk` 在本轮完整支持；macOS `.app`、Linux `.desktop` 保持直接路径方式。
- 本轮不做快捷键序列、多标签分组、嵌套分组、跨设备同步和云端备份。
- 所有能力未登录也可使用，不接入旧 `moduleCode` 门禁、Office Pro 或 AI 积分。

## 6. 完成标准

1. 六项功能的自动化测试及 Windows 人工测试通过。
2. 未登录和离线状态下功能完整可用。
3. 更新四份 Feature Map，创建对应 User-Ops。
4. 四份人工测试文档记录实际验证结果后，方可从“未解决”转为“已解决”。
5. 不删除或上传用户原文件、收藏路径、窗口标题和剪贴板数据。
