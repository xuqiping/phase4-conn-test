# 批量生图文档模板（规范化格式）

> 把你要批量生成的画面，按下面的格式写成一份文档，粘进网页「📂 批量」页签的输入框，
> 再上传对应的参考图，点「解析文档」即可。系统会用大模型自动拆分成多条任务并行生成。

---

## 一、格式规则（必读）

1. **每一段 = 一个生图 prompt**（给画图模型的画面描述），段落之间用**空行**隔开。
2. 在每段 prompt 的**正下方独立一行**，写出该 prompt 要用的**参考图文件名**，多个用**逗号**分隔。
   - 这一行建议以 `参考图:` 开头（也接受 `参考:` `图片:` `refs:` 或直接写文件名）。
3. **每个 prompt 最多 3 张参考图**，超过会被截断保留前 3 个。
4. **没有参考图**的 prompt，下方就**不写**这一行（直接空行接下一段）。
5. 文件名要和你在网页上**上传的参考图文件名一致**（系统按文件名匹配，**忽略大小写和扩展名**）。

---

## 二、完整示例（可直接复制试用）

```
一只穿着宇航服的猫，坐在月球表面弹吉他，背景是地球，赛博朋克霓虹光效，电影级质感
参考图: cat.jpg, guitar.jpg

海边悬崖上的孤独灯塔，暴风雨夜晚，闪电劈下，巨浪拍岸，冷色调，广角镜头
参考图: lighthouse.jpg

一杯冒着热气的手冲咖啡，木质桌面，清晨阳光从左侧斜射，浅景深，日系治愈风

古代宫殿大殿，金龙盘柱，红绸垂落，皇帝端坐龙椅，俯视构图，工笔重彩
参考图: palace.jpg, dragon.jpg, emperor.jpg
```

**上面这份文档会被拆成 4 条任务：**

| # | prompt | 参考图 | 说明 |
|---|---|---|---|
| 1 | 宇航服猫弹吉他… | cat.jpg, guitar.jpg | 2 张参考图 |
| 2 | 海边悬崖灯塔… | lighthouse.jpg | 1 张参考图 |
| 3 | 手冲咖啡… | （无） | 无参考图，纯文本生图 |
| 4 | 古代宫殿大殿… | palace.jpg, dragon.jpg, emperor.jpg | 3 张参考图（满额） |

---

## 三、参考图上传说明

- 在「② 参考图」处**多选上传**所有用到的图片。
- **文件名 = 文档里写的名字**。例如文档写 `cat.jpg`，上传的文件就叫 `cat.jpg`。
  - 匹配是**智能的**：`cat.jpg` / `CAT.JPG` / `cat.png` 都能对上（忽略大小写、忽略扩展名）。
- 同一张图可以被**多个 prompt 共用**（如多段都用 `cat.jpg`），系统整批只上传一次。
- 支持格式：jpg / png / webp 等常见图片格式；单张建议 ≤ 10MB。

---

## 四、解析后的核对（重要）

点「解析文档」后，系统会列出拆分结果，**请你逐条核对**再点「确认 · 开始并行生成」：

- 每条 prompt 的文字**可直接修改**；
- 参考图后面带 ✓ 表示已匹配到上传的图，✗ 表示**没找到对应文件**（该图会被跳过，按无该图生成）；
- 不需要的任务可以**删除**；
- 确认无误后才开始并行生成（避免误拆浪费额度）。

---

## 五、常见写法都支持（不必死守一种措辞）

以下写法都能被正确识别为「这段 prompt 用了这些参考图」：

```
参考图: a.jpg, b.jpg
参考: a.jpg,b.jpg
图片: a.jpg
refs: a.jpg, b.jpg, c.jpg
a.jpg, b.jpg            （直接写文件名也行）
```

> 只要保证「参考图文件名独占 prompt 正下方一行」即可，措辞不强求统一。

---

## 六、注意事项

- 生图较慢，并行默认 **3 条同时跑**，剩余排队。
- 失败的单条**不影响其他**，可在进度网格点「重试全部失败项」。
- 生成结果会按工作流返回的**类别**自动归档到 `downloads/<类别>/`（原图 + 水印低清图）。
