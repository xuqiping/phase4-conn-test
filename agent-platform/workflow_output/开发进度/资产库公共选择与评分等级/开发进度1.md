### Step 3 代码（2026-08-18，commit 893da2a）

- 新增 `asset/service/AssetGrade.java`：`fromScore(Integer)` 唯一真相源（null→null；≥95 A+ / ≥90 A / ≥80 B / ≥70 C / 其余 D）+ `rangeOf(grade)` 等级→[min,max] 区间表（A+=[95,100]…D=[0,69]，clone 防御拷贝；Map.of 不收 null key，先判空）+ `ALL` 下拉顺序常量

- 测试：新增 `AssetGradeTest` 5 例（边界 94/95/89/90/79/80/69/0/100/null + 区间表 + 区间自洽回映射 + 未知等级抛 + 拷贝防污染）；`AssetScoreServiceTest` +3 例（双轨各自派生 88→B/90→A、取整先行 90.33→90→A 与 90.5→91→A、**取整跨档 94+95→94.5→95→A+**、noScores 等级同 null）；`AssetServiceTest` 列表批装配断言 +2（88→B、均 90→A）
