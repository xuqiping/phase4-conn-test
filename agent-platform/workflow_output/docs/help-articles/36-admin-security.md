# 安全管理（管理员）

> 入口：侧栏「风险大盘 / 安全事件 / 封禁管理 / 安全规则」四页。钉钉群同步收告警（高危即时、中危 30 秒汇总、低危只入库）。

## 一、风险大盘

打开即看近 24 小时：危急/高危/中危/低危事件数大数字卡 + 事件类型 TOP10 + 待处置总数。点「进入事件中心处置」跳转。

## 二、安全事件中心

1. 顶部筛选：事件类型/严重度/状态 → 查询。
2. 点「详情」→ 中文键值完整信息：操作人、具体操作（如「计费积分 · 新建价表」）、操作对象、traceId。
3. **处置过程时间线**：①事件发生 → ②自动处置（系统已实际执行的动作）→ ③人工处置（你的「处置」= 确认标记，记录处置人和时间，不会重复封禁）。
4. 确认已知晓 → 点「处置」→ 状态变「已处置」。
5. **批量清理**：勾选 →「批量清理」→ 二次确认（物理删除不可恢复，单次上限 200 条，留审计）。
6. 参数级明细：按详情里的 traceId 去「审计日志」关联查。

## 三、封禁管理

- **封 IP**：输 IP + 原因（必填）→ 勾「永久」或用默认时长 → 封禁。该 IP 所有请求立即 403。解封：列表点「解封」。
- **封号**：点「前往用户管理」改状态（BANNED/DISABLED/LOCKED，立即踢下线；ACTIVE=解封）。不能封自己；最后一个用户管理管理员不可封。

## 四、安全规则配置（即时生效，无需重启）

- **总开关**：限流总闸 / 自动处置总闸（关掉 = 只告警不封不锁，误伤一键关停）/ 自动封 IP / 自动锁号 / 钉钉告警。
- **钉钉告警**：填机器人 Webhook；加签密钥只写不读（留空=不修改）。
- **限流阈值**：全局次/分钟/IP（默认 600）、对话 20/分钟、媒体 10/分钟。
- **检测阈值**：越权 10 次/5 分钟、外带 500 条/10 分钟、积分 10000 分/10 分钟等。

## 五、哪些行为会被自动封号/封 IP

| 触发行为 | 检测条件 | 自动动作 | 恢复 |
|---|---|---|---|
| 登录暴破 | 同账号 15 分钟 5 次密码错 | 锁账号 15 分钟 | 自动 |
| 撞库攻击 | 同 IP 5 分钟试 ≥20 个账号 | 封 IP 60 分钟 | 自动 |
| SQL 注入累犯 | 同 IP 1 小时 ≥3 次 | 封 IP 60 分钟 | 自动 |

**要点**：没有任何行为会自动永久封号/封 IP；永久封只能人工在「封禁管理」操作。其余事件（越权/异地登录/Token 盗号/凌晨敏感操作等）只记录 + 推告警。

## 常见异常

| 现象 | 原因 | 处理 |
|---|---|---|
| 钉钉没推送 | webhook 未配/总闸关 | 安全规则页查配置 |
| 处置提示 409 | 已被别的管理员处置 | 正常（幂等），刷新列表 |
| 用户被自动锁定 | 触发滥用规则 | 15 分钟自动解锁，或用户管理页手动解 |
| 异地登录告警 | 账号可能泄露 | 看详情，必要时锁号并通知用户改密 |
