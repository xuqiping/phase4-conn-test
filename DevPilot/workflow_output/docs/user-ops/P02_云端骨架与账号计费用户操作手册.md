# P02 云端骨架与账号计费 · 用户操作手册

> 受众：DevPilot 桌面端用户（B 类）。细化到 功能→步骤→界面变化→预期结果。

## 1. 查看余额（顶栏余额环）

| 步骤 | 界面变化 | 预期结果 |
|---|---|---|
| 打开 DevPilot，看顶栏右侧 | 环形图标 + `¥xx.xx`，含体验金则带灰色「含体验金 ¥x.xx」 | 云端可达：显示真实余额；未加载/断网：显示「— 元」，不影响其他功能 |
| 点击余额环 | 无弹窗 | 立即刷新一次余额（平时每 60 秒自动刷新） |

## 2. 余额不足（环变红 + 充值）

| 步骤 | 界面变化 | 预期结果 |
|---|---|---|
| 余额为 0 或调用返回 402 | 环变红，旁边出现红色「去充值」按钮 | 后续云端调用会被拦截并提示「余额不足，请充值后再试」 |
| 点「去充值」 | 浏览器新开充值页 | 在页面上完成支付（MVP 为 mock 渠道） |
| 充值到账后回桌面 | 点余额环刷新，环恢复常色 | **不会自动续跑被暂停的任务，需手动重试**（边界） |

## 3. 对账告警（黄色条）

| 步骤 | 界面变化 | 预期结果 |
|---|---|---|
| 本地用量镜像与云端账本对不上 | 余额环旁出现黄色「⚠ 对账不平：本地 x 分 vs 云端 y 分」 | 仅提示不阻塞使用；可反馈给客服排查 |
| 点击黄色条 | 黄条消失 | 本次会话不再显示，下次刷新若仍不平会再出现 |

## 4. 登录态过期（静默续期）

| 步骤 | 界面变化 | 预期结果 |
|---|---|---|
| access token 过期（15 分钟） | 无任何提示 | 自动用保存在系统凭据管理器的 refresh token 静默换新，重试原请求 |
| refresh token 也过期（7 天） | 提示「登录已过期，请重新登录」 | 需重新登录；凭据管理器中的旧 token 已自动清除 |

## 5. 消耗明细（云端网页，MVP 暂无独立入口）

余额环数据来自 `GET /api/v1/balance` 与 `/balance/transactions`（分页）；每笔 chat 扣费、联网搜索（10 分/次）、深度阅读（20 分/次）、充值（kind=2）各占一行。搜索缓存命中**不产生条目**。

## 常见问题

- **环一直显示「— 元」**：云端未启动或网络断开，检查网络后点环刷新。
- **为什么扣的钱和明统能对上**：云端账本只增不改，余额是账本加总，可随时对账重建。
