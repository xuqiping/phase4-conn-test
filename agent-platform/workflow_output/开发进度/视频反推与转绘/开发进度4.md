## 关键决策

1. **Tab 用 `display-directive="show"`**：切 Tab 不卸载生成表单——轮询中任务/已填参数/附件槽全保留（v-if 会丢状态）。
2. **面板独立组件**：VideoReversePanel 自包含（不读 VideoGenView 任何状态），emits 单事件 `use-script`——后续别的页面要复用反推零成本。
3. **历史任务源直传 taskId**：面板存 `taskById` 映射（taskId→VO），选中即拿 `resultFileId` 供「用剧本生成」参考视频槽预填；列表懒加载（切到该来源才拉，一次）。
4. **帧预览鉴权 blob**：关键帧 fileId → `fetchFilePreview` 拉 token blob 转 objectURL；onUnmounted 统一 revoke 防泄漏（同资产预览范式）。
5. **转绘后默认本土化版**：`genScriptFrom` radio 切原/本土化；「用剧本生成」按钮文案随动 `(原剧本/本土化)`。
6. **冲突三选**（plan L4）：表单提示词与视频槽全空→直接替换不弹窗；非空→`dialog.create` 自定义 action（取消/追加/替换），替换先清视频槽逐个 revokeObjectURL；取消=表单原样。
7. **首尾帧模式互斥**：带入参考视频前 `modeAllows('video')` 预检——首尾帧已占则只预填提示词+警告（不清用户帧）。
