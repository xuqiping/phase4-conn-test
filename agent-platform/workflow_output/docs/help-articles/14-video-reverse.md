# 视频反推与本土化转绘

> 把一条现成视频「拆」成关键帧 + 分镜表 + 剧本，还能改写成其他国家/地区版本，最后一键拿去再生成。
> 入口：**视频生成页 → 顶部「视频反推」页签**（推荐）；或无限画布的视频节点。
> 前置：视频 ≤10 分钟；勾分镜/剧本才花多模态积分（只勾关键帧零模型成本）。

## 一、五步走完（视频生成页）

1. **① 选择视频来源**：「上传本地视频」传文件，或「从历史任务选」下拉挑自己生成过的视频。
2. **② 反推产物**：勾选 关键帧（默认）/ 分镜表 / 剧本；可展开调帧数(4-24)/阈值；「大模型」下拉可换反推用的模型（默认平台配置）。
   - 页面会提示大概花多少积分，确认后点「**开始反推**」（长任务可取消）。
3. **③ 看结果**：
   - 关键帧时间轴：每帧带时间戳，悬浮放大、点击全屏。
   - 分镜表：序号/起止/景别/运镜/画面描述/台词。
   - 剧本：格式化文本，右上「复制」可带走。
4. **④（可选）本土化转绘**：填目标地区（如「美国」）+ 保留要求（如「保留春节团圆情节」）→「开始转绘」→ 得到改写剧本 + **替换清单**（筷子→刀叉逐条可核对）。
5. **⑤ 用剧本生成**：点「用剧本生成 → 填入生成表单」→ 自动切回「视频生成」页签，提示词和参考视频已预填 → 检查后「提交生成」。

## 二、无限画布里的反推

1. 选中画布上的视频节点 → 右侧属性面板「反推」区 → 勾产物 →「开始反推」。
2. 自动在旁边生成：每帧一个图片节点 + 分镜节点 + 剧本节点（全部自动连线）。
3. 选中剧本/分镜节点 →「本土化转绘」→ 生成带「本土化(地区)」标签的新剧本节点（**原稿不动**）。

## 常见异常

| 现象 | 原因 | 恢复 |
|---|---|---|
| 「已取消反推」 | 只断了等待，已抽的帧保留 | 直接重试 |
| 「模型未返回合法 JSON」 | 模型偶发 | 重试一次（已内置 1 次自动重试） |
| 转绘有黄色警示条 | 场景数不一致等 | 结果仍可用，人工核对替换清单再用 |
| 历史任务下拉为空 | 只列本人成功且有产物的任务 | 先去生成一条视频 |
