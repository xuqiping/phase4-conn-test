# ADR 索引（架构决策记录）

> 记录本项目「为什么选 A 不选 B」的关键决策，防止「AI 新会话好心改回去」。
> 每条 ADR 一个文件，编号递增（ADR-001、ADR-002…），按时间倒序排在下面。
> **last_updated: 2026-08-04**

## 何时写 ADR

- 推翻了常规做法 / 业界默认选择（如：不用 Whisper 而用 sherpa-onnx）。
- 决策代价高、回退成本大（如：技术栈选型、打包格式选择）。
- 多个备选方案各有取舍，最终选定其一的理由需要留痕。

## 模板

新建 ADR 时拷贝 [_模板.ADR.md](_模板.ADR.md)。
