# 企业级精准知识库 RAG 开发进度 4

## P1 Step 2：权威等级、生效期、密级和元数据治理

- 新增 V107，为 Canonical Document 增加 `owner/source/sourceUpdatedAt/authority/confidentiality/tags/expiredAt`，并从旧 `deadline` 回填失效时间。
- 权威等级限制为 `OFFICIAL/APPROVED/REFERENCE/UNVERIFIED`；密级限制为 `PUBLIC/INTERNAL/CONFIDENTIAL/RESTRICTED`。
- 新增治理更新 API，校验生效区间、标签数量/长度、来源字段长度；非管理员禁止改变密级。
- 治理更新使用显式 SQL 写 JSONB，允许清空可选字段；操作写审计并发布 `VisibilityInvalidationEvent`，主动失效可见集与答案缓存。
- 默认检索 SQL 在 L0、L1、可见集、类型枚举和 L1 元数据读取处统一过滤：有当前版本、已生效、尚未过期。
- L1 元数据返回权威等级、密级与有效区间，为后续冲突解释和重排输入保留接口。
- 前端文档列表增加“治理”入口，支持责任人、来源、权威等级、密级、标签和生效区间配置；非管理员密级下拉禁用。
