## 一、受众审美

| 用户角色 | 占比 | 审美取向 | 对中国风的预期反应 |
|---|---|---|---|
| 开发者（全栈/个人） | 65% | 效率优先，欣赏"有品位但不碍事"的工具；对过度装饰敏感 | 接受度高，前提是加载快、不拖慢操作 |
| 团队负责人 | 25% | 专业、可信、可度量 | 中国风传递"匠心/沉淀"，利于团队推广时的认同 |
| 企业管理员（CTO） | 10% | 稳重、合规、安全 | 深色沉稳基调比跳脱实验风更能建立信任 |

**结论**：B 端工具的情感目标是「效率感 + 掌控感 + 专业认同」（D-21.04），中国风必须服务这三点——本能层（水墨美感）与反思层（东方雅致的专业认同）可以拉满，但行为层（效率）是不可牺牲的底线。

## 二、文化依据

- **核心意象**：高山流水·知音（伯牙绝弦）——天然契合"多 Agent 协作"隐喻：Agent 是知音，平台是山水，编排是流水。这是竞品（Dify/n8n/Coze 均为科技蓝/中性 SaaS 风）无人占据的文化位。
- **辅助意象**：行到水穷处，坐看云起时（禅意山水）；空山新雨后；独钓寒江雪。
- **名画参照**：《富春山居图》（淡墨、隐逸、留白 → 主基调）；《千里江山图》（石青/石绿矿物点色 → 图表与点缀色来源）。
- **东方法则**（内置维度 07 红线）：东方氛围 = 少即是多 + 时间感；主导氛围词每屏 ≤2 个（本项目固定为「禅寂 + 空灵仙气」）；忌满、忌堆叠——用了泼墨就不再叠飞白。

| 竞品 | 视觉语言 | 本项目差异化机会 |
|---|---|---|
| Dify | 浅色 SaaS、蓝紫主色、圆角卡片 | 无文化叙事；我们以水墨意境建立记忆点 |

## 四、品牌

- 现品牌：SuperCoder Agent Hub，无成熟 VI，3 套暗色科技主题（deep-space/dark-pro/cyber-glow）无文化锚点。
- 重定位：**「东方雅致的 AI 工作台」**——技术上是最现代的 Agent 编排，气质上是高山流水的知音文化。
- 品牌签名元素（候选）：朱红印章 Logo 落款、行书大标题、水墨空状态插画、"静候知音"文案体系。

## 五、渠道

- 主渠道：桌面 Web（≥1200px 为主战场，B 端桌面优先，`max-width` 优雅降级，断点 lg992/xl1200/2xl1400 三档足够）。
- 次渠道：登录/分享页可能有移动端曝光——响应式是布局重组不是缩放。
- 无 APP/小程序计划，但 Token 层预留多平台编译扩展位（D-05.07）。

## 六、禁忌与反例（禁区清单）

1. **禁止为风格牺牲语义**：error/warning/success/info 状态色保持可辨识，不得改成灰墨色。
2. **禁止低对比水墨灰**：正文对比度 ≥4.5:1（WCAG 2.1 AA），背景墨晕压在文字层之下（opacity ≤12%）。
3. **禁止书法体泛滥**：书法/行书每屏 ≤1 处且仅限大字号标题；草书禁用（识别度低）；正文永远是中性黑体。
4. **禁止破坏性动效**：弹跳、强视差、粒子轰炸；微交互不得拖慢核心流程 0.5s 以上；必须响应 `prefers-reduced-motion`。
5. **禁止 AI 味模板**：蓝紫渐变 + 玻璃拟态 + 圆角卡片堆砌（即现主题 deep-space 的通用 SaaS 感）是本次要淘汰的东西。
6. **禁止水印式中国风**：龙凤、祥云、大红灯笼、金光描边等旅游纪念品符号一律不用；我们取的是宋代山水的"淡、远、空"。
7. **禁止改信息架构**：侧栏+主区卡片骨架、导航层级、交互流程不变——只换皮肤与气质。

## 八、工程约束红线（来自 D-05.04/05.07/21.04/19.04，门禁必查）

1. 三层 Token 架构：本次只改原始层 + 语义层映射，组件层不动。
2. Naive UI 必须补齐 `themeOverrides`（现状缺失，组件永远是默认暗色）。
3. 交互状态五件齐全：悬停/聚焦环/加载骨架/Toast/禁用态，水墨纹理不得干扰。
4. 明暗双主题：深色=夜墨（黛蓝底），浅色=宣纸（月白底），全部走 CSS 变量一处定义。
5. AI 等待设计：阶段化提示 + 流式首字 <1s + 可取消；高风险操作二次确认/可撤销。
6. 微交互 ≤0.5s 不阻塞核心流程；`prefers-reduced-motion` 整体降级。
