# 资产库公众池 API

所有端点均要求登录且具备 `asset:write`。服务层继续校验项目 OWNER/管理员身份，不能仅依赖前端按钮隐藏。

## 公共摘要列表

`GET /api/assets/public-pool`

返回当前仍在公众池中的项目摘要。每项仅包含 `id`、`name`、`description`、`coverFileId`、`publicAccessMode`、`publishedBy`、`publisherUsername`、`publishedAt`、`publishedByAdmin`、`assetCount`、`myRequestStatus`、`usable`，不返回资产列表、版本正文或文件内容。

## 发布

`POST /api/assets/public-pool/{projectId}/publish`

普通 OWNER 请求体：

```json
{
  "accessMode": "OPEN"
}
```

`accessMode` 可为 `OPEN` 或 `APPROVAL_REQUIRED`。管理员发布任意项目时服务端强制使用 `OPEN`，并将本次发布快照记为官方发布；请求体可以省略。

重复发布返回冲突错误，不会改写原发布者、发布时间或官方标记。

## 移出公众池

`DELETE /api/assets/public-pool/{projectId}/publish`

OWNER 或管理员可操作。移出会清空项目发布快照，并把该项目全部 `PENDING`、`APPROVED` 公共访问申请改为 `REVOKED`；成员授权不受影响。

## 审批型公共访问

- `POST /api/assets/public-pool/{projectId}/requests`：申请访问；重复申请返回当前状态，`REJECTED/REVOKED` 会原记录重置为 `PENDING`。
- `GET /api/assets/public-pool/{projectId}/requests/mine`：仅查询当前用户自己的申请状态。
- `GET /api/assets/public-pool/{projectId}/requests`：仅现任 OWNER 或管理员查看该项目申请列表。
- `PUT /api/assets/public-pool/{projectId}/requests/{requestId}/decision`：请求体 `{"decision":"APPROVED"}` 或 `{"decision":"REJECTED"}`；仅 `PENDING` 可被处理。
- `DELETE /api/assets/public-pool/{projectId}/requests/{requestId}/approval`：仅 OWNER 或管理员撤销当前 `APPROVED` 访问。

申请创建使用 `INSERT ... ON CONFLICT DO NOTHING` 保证并发幂等；审批、拒绝、撤销和重新申请均使用带旧状态条件的更新。OPEN 或 APPROVED 用户在项目 ACL 中只获得 `VIEWER`，所有写入口仍返回 403。
