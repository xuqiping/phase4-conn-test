# 11 - 工作流执行与编排引擎

## 功能简介
Java 侧编排引擎：根据对话模式（默认对话/Agent 路由/工作流）选择执行策略，构建执行上下文、变量存储，调用 LLM/Skill 执行器，并对接 Runtime Sidecar 完成实际工作流图执行。

## 后端 (backend) — `engine` 包
- 上下文：`engine/context/`
  - [ExecutionContext.java](../../backend/src/main/java/com/superprogrammer/engine/context/ExecutionContext.java) — sessionId/mode/agentId/workflowId/ragEnabled
  - [VariableStore.java](../../backend/src/main/java/com/superprogrammer/engine/context/VariableStore.java) — 变量存取
- 路由：`engine/router/` AgentRouter、RoutingResult
- 策略：`engine/strategy/`
  - [ExecutionStrategy.java](../../backend/src/main/java/com/superprogrammer/engine/strategy/ExecutionStrategy.java) — 策略接口
  - DefaultChatStrategy（默认对话）
  - [AgentRoutingStrategy.java](../../backend/src/main/java/com/superprogrammer/engine/strategy/AgentRoutingStrategy.java)（Agent 路由）
  - WorkflowStrategy（工作流）
- 执行器：`engine/executor/`
  - [OrchestrationEngine.java](../../backend/src/main/java/com/superprogrammer/engine/executor/OrchestrationEngine.java) — 编排入口
  - LlmCallHandler、SkillExecutor、StepActionHandler、StepResult
- 编排由 `chat/service/ChatSessionService` 与 `workflow/service/WorkflowService` 触发。

## 前端 (frontend)
无独立 UI（执行结果通过对话流式 / 执行监控页展示，见 [13-执行监控](13-执行监控.md)）。

## Sidecar 联动
- Java 引擎通过 `runtime` 包网关下发执行请求，见 [12-Runtime-Sidecar执行](12-Runtime-Sidecar执行.md)。

## 数据表
