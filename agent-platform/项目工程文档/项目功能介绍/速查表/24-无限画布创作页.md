# 24 - 无限画布创作页

## 功能简介
基于 Vue Flow 的 LibTV 式无限创作画布：拖 5 类节点（文本/图片/视频/音频/脚本）、自由连线、属性面板、一键拓扑重跑、焦点编辑、故事板剪辑；内置视频抽帧（首/尾/指定秒）、视频截取、多段拼接成片。与工作流编辑器并存——**工作流编辑器=编排引擎 DAG（驱动 sidecar 执行），画布=创作面（多模态产出）**，互不干涉。

## 后端 (backend)
`canvas/` 包（`com.superprogrammer.canvas`，独立于 llm/chat/knowledge/media/workflow，零回归）。
- 控制器：[CanvasController.java](../../../backend/src/main/java/com/superprogrammer/canvas/controller/CanvasController.java)
  - 快照 CRUD：`POST /api/canvas` · `GET /api/canvas` · `GET/PUT/DELETE /{id}` · `POST /{id}/save` · `POST /{id}/rename`
  - 节点产出：`POST /{id}/nodes/run`（按 type 分发）· `POST /{id}/upload`（图/音频上传，落 SOURCE_CANVAS）
  - 媒体工具：`POST /{id}/nodes/{nodeId}/frames`（抽帧）· `POST /{id}/nodes/{nodeId}/clip`（截取）
  - 故事板：`POST /{id}/storyboard/concat`（多段拼接成片）
  - **全端点 `@RequirePermission("canvas:write")`**（切面 403 兜底）
- 服务：[canvas/service/](../../../backend/src/main/java/com/superprogrammer/canvas/service/)
  - `CanvasService` — 快照 CRUD + **ownership 硬过滤**（普通用户只能操作自己的画布，admin 旁路看全量）+ `loadOwned`（写侧端点复用归属咽喉点）
  - `CanvasNodeRunnerService` — 按 `CanvasNodeDTO.type` 分发生成：文本/脚本→`LlmGateway.chat`；视频→重定向前端调 media API；图片 MVP 抛 provider 未配话术
  - `VideoFrameService` — javacv 抽帧（FIRST/LAST/AT N 秒）+ 截取（时间段）+ 拼接（concat），产物写临时文件非 byte[]
- 实体：[Canvas.java](../../../backend/src/main/java/com/superprogrammer/canvas/entity/Canvas.java)（继承 BaseEntity，`snapshot` JSONB + `JsonbStringTypeHandler`）
- Mapper：[CanvasMapper.java](../../../backend/src/main/java/com/superprogrammer/canvas/mapper/CanvasMapper.java)（纯 `BaseMapper`，ownership 在 service 层）
- DTO：`CanvasVO`/`CanvasCreateRequest`/`CanvasSaveRequest`（snapshot ≤5MB）· `CanvasNodeDTO`/`NodeOutputRef`/`NodeRunResult`（无状态回包，零 JSONB 竞态）· `FrameExtractRequest`/`VO` · `VideoClipRequest`/`VO` · `StoryboardConcatRequest`/`VO`
- 测试：[CanvasServiceTest](../../../backend/src/test/java/com/superprogrammer/canvas/service/CanvasServiceTest.java)(7) + [CanvasNodeRunnerServiceTest](../../../backend/src/test/java/com/superprogrammer/canvas/service/CanvasNodeRunnerServiceTest.java)(10) + [VideoFrameServiceTest](../../../backend/src/test/java/com/superprogrammer/canvas/service/VideoFrameServiceTest.java)(18) = **canvas 包 35 绿**

## 前端 (frontend)
- 视图：[CanvasView.vue](../../../frontend/src/views/CanvasView.vue)（列表模式卡片网格 ↔ 编辑模式，路由 `/canvas/:id` 驱动；`canEdit=hasPermission('canvas:write')` 无权限三重兜底：菜单隐藏+页内 403 卡片+API 403）
- 画布组件：[components/canvas/](../../../frontend/src/components/canvas/)
  - `CanvasBoard.vue` — Vue Flow 画布 + Background 网格 + smoothstep 边 + snap-to-grid + 拖拽增节点 + 手选删除 + 缩放/适应工具条 + `getSnapshot`/`loadSnapshot`
  - `PropertyPanel.vue` — 选中节点按 type 显隐字段 + 运行/上传/抽帧/截取按钮（5 类全覆盖）
  - `StoryboardPanel.vue` — 故事板右抽屉：上下调序 + 顺序预览（`<video>` auto-advance on ended）+ 合计时长 + 拼接成片
  - `FocusEditOverlay.vue` — 焦点编辑沉浸模式框选（产新图节点 + 自动连边）
  - 节点：`CanvasNodeBase`（共用外壳：accent 条 + 运行态徽标 + Handle）+ `Text`/`Image`/`Video`/`Audio`/`ScriptNode`（`markRaw` 注册，规避响应式包裹组件对象）
- 类型：[types/canvas.ts](../../../frontend/src/types/canvas.ts)（`CanvasNode`/`CanvasEdge`/`CanvasSnapshot` 扁平接口——**规避 vue-flow `Node` 默认泛型深递归 TS2589**，范式同 `types/workflow.ts`）
- API：[api/canvas.ts](../../../frontend/src/api/canvas.ts)
- 路由：`/canvas`（列表）· `/canvas/:id`（编辑），见 [router/index.ts](../../../frontend/src/router/index.ts)
- Sidebar：`canEditCanvas` 入口（[Sidebar.vue](../../../frontend/src/components/Sidebar.vue)，`hasPermission('canvas:write')` 显隐，同 video-gen 范式）
- 移动端（≤768px）显示「请在电脑端使用」占位（节点画布不适合触屏，同工作流编辑器，见 [23-前端布局与移动端适配](23-前端布局与移动端适配.md)）

## 复用（只读，零回归）
- **视频生成**：`media/` 包 `MediaGenTaskService.submit` + 轮询（seedance 已通；可灵/海螺/happy horse 待 R-4 各家 API 开通）。视频节点 = media 的另一个 submit 调用方，不改 media 任何类
- **文本/脚本**：`LlmGateway.chat`（脚本拆分镜 + `parseScenes` 容错剥 ```json 围栏）
- **节点模型自选**（FR-006）：文本/脚本节点属性面板挂 ModelSelector（optional 模式），选值落 `node.data.model` 随画布保存，运行时覆盖 `canvas.text-model` 默认；清空=回退默认
- **文件落地**：`FileStorageService.storeStream(SOURCE_CANVAS)` + `loadPath`（javacv 需 seekable 文件，load 咽喉点拆出返 Path）+ V40 `stored_files`（新 `SOURCE_CANVAS` 常量）
- **抽帧/截取/拼接**：javacv（bytedeco）纯 Java 自包含，无系统依赖；sidecar 禁 subprocess 故走后端 Java
