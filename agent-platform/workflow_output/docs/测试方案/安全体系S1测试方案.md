# 安全体系 S1 止血与基线 · 测试方案

> Phase 3 人工/渗透测试基准。自动化能断言的走单测/IT，本方案只收「要人点 / 走真实环境 / 部署后确认」的用例。
> 对应 plan：[安全体系_S1止血与基线.plan.md](../plans/安全体系_S1止血与基线.plan.md)

## 前置条件

- 后端已含 S1 全部 commit，V80 迁移已在测试库执行（`SELECT count(*) FROM user_points_balance WHERE balance<0` 预检 = 0）。
- Redis 正常；另备「停 Redis」降级验证窗口。
- 测试账号：普通用户 A、admin；测试文件：evil.html、evil.svg（内嵌 `<script>alert(1)</script>`）、正常 png/mp4/docx。

## 一、渗透自查用例（自动化覆盖不了的浏览器/部署层确认）

| # | 用例 | 步骤 | 预期 |
|---|---|---|---|
| P1 | 存储型 XSS 根治（SEC-FR-030a/b/c） | 上传 evil.html → 复制文件链接浏览器直接打开 | 触发**下载**而非渲染；响应头含 `Content-Disposition: attachment` + `X-Content-Type-Options: nosniff`；evil.svg 同 |
| P2 | 预览回归 | 上传 png/mp4 → 画布/资产库/聊天内预览 | 仍 inline 正常预览/播放（nosniff 不影响） |
| P3 | 上传白名单 | 上传 evil.html / .svg / .exe | 400 固定话术「文件类型不允许」，不透内部细节 |
| P4 | SSE 回归 | 发起一轮流式对话 | 逐 token 输出正常（nosniff/CSP 不杀 text/event-stream） |
| P5 | 登录锁定（SEC-FR-001） | 同账号故意错密码 5 次 | 第 6 次起固定话术拒绝（不区分「密码错」与「已锁定」）；15min 后自动解锁可登录 |
| P6 | IP 封禁 | 同 IP 1 小时内失败 >20 次（换账号） | 该 IP 临时封禁；audit_logs 有 login_locked/ip_banned 行 |
| P7 | Redis 降级 | 停 Redis → 登录 | 登录仍可用（降级放行），日志 WARN |
| P8 | 安全头（SEC-FR-002） | F12 查看任意 API 响应头 | 含 CSP / X-Frame-Options: DENY / nosniff / Referrer-Policy |
| P9 | CORS 白名单（SEC-FR-003） | 非白名单 Origin 发预检 OPTIONS | 被拒；白名单前端页面功能正常 |

## 二、功能联动用例（plan 联动点清单逐条对应）

| # | 触发动作 | 联动对象预期 |
|---|---|---|
| L1 | 危险类型强制 attachment | 画布/资产库/聊天的 image/video/audio/pdf 预览**不受影响**（正向）；用户既有 .html 素材变下载不可在线预览（预期边界） |
| L2 | 合法用户被锁 | 15min 自动解锁可登录（正向）；admin 删 `login:fail:u:{username}` Redis 键立即解锁（runbook 路径） |
| L3 | 同用户并发 20 个扣积分 | 余额不为负；成功笔数 × 单价 + 余额 = 初值；流水 balance_after 与余额恒一致 |
| L4 | 同幂等键重复提交积分变动 | 只生效一次，两次返回**相同结果**（非报错）；同键不同金额 → 写安全审计 |
| L5 | 扣减失败后同幂等键重试 | 可成功（占位随事务回滚不留死键） |
| L6 | CSP 上线后 | Naive UI 页面渲染正常（style-src 'unsafe-inline' 放行）；SSE 正常 |
| L7 | CORS 收紧后 | 白名单前端/钉钉 H5 回调正常；漏配域名跨域报错（上线前预发核对清单） |

## 三、边界/异常场景

| # | 场景 | 预期 |
|---|---|---|
| E1 | 传负数/零/超大金额充值或调账 | 400 校验错误（SEC-FR-122） |
| E2 | 请求体塞 `balance=99999` 试图直改余额 | 不生效（服务端重算，字段被忽略） |
| E3 | 手工 SQL 改一行 points_ledger | 次日对账任务 diff → ERROR 日志 + audit_logs 行（SEC-FR-123）；应用账号直接 UPDATE/DELETE 流水被 DB REVOKE 拒绝 |
| E4 | Mapper 写 `${}` / 提交假密钥 | 本地 `scripts/security/*.sh` 与 CI security-gate 红（SEC-FR-020/071） |
| E5 | 锁定风暴（大量账号同时被锁） | 日志 ERROR 计数（告警接运维 P1，本阶段仅日志） |

## 四、人工阻断项（无人工无法闭合）

| # | 项 | 说明 |
|---|---|---|
| H1 | **G1 密钥轮换**（SEC-FR-070） | DB 密码 + JWT_SECRET + RUNTIME_CALLBACK_TOKEN + 钉钉/ctaigw key 全量轮换；低峰执行（JWT 轮换=全员强制重登）；按 runbook 改环境变量→滚动重启→验证登录/刷新/回调/DB 连通→作废旧值 |
