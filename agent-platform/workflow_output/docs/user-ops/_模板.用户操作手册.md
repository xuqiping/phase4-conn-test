## 常见异常与恢复

| 异常 | 触发条件 | 界面表现 | 用户该怎么恢复 |
|---|---|---|---|
| 网络超时 | 提交时断网 | 提示「网络异常，请重试」 | 检查网络后点击「重试」 |
| 表单校验失败 | 必填项为空 | 对应字段标红，提示具体错误 | 补全字段后再次提交 |
| 权限不足 | 未登录/无权限 | 跳转登录页或提示「无权限」 | 登录或联系管理员 |
| 数据为空 | 列表无数据 | 展示空状态插图 + 「去创建」按钮 | 点击按钮创建第一条数据 |
