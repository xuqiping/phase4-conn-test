# 已解决（2026-08-26 勾销，修复设计III §9，Chunk C/D，commit `0770434c`/`5453e59b`）
1. **节点拉伸** ✅（C1 复验+补链）—— 节点四角/四边拖拽改尺寸，resize 结果随画布自动保存落库（落库链此前缺失已补）。
2. **图片节点选管理员默认图模型** ✅（C2）—— 图片节点模型下拉默认选中管理端标记的默认图模型（默认标记读媒体模型列表接口，无标记回落第一个）。
3. **视频比例选择太窄** ✅（C3）—— 视频比例选择器在属性面板**独占整行**（原与时长同挤一行被截断），各比例完整可见可选。
4. **节点创建副本** ✅（C4）—— 节点卡片菜单「创建副本」，复制节点及配置为新节点。
5. **各节点默认大小一致** ✅（C5）—— 16:9 与 9:16 产物定型后节点尺寸统一（定型收口 updateNodeData），生成结果不撑爆布局。
6. **点击图片/视频节点放大** ✅（C6+D1 Lightbox）—— 点击产物缩略图弹 Lightbox 大图/播放，滚轮缩放图片。
7. **任何变动自动保存** ✅（C7）—— 防抖自动保存+右上「保存中/已保存/失败重试」状态徽标+未保存离开确认弹窗。
8. **上游节点面板+悬浮放大+双击@引用** ✅（D2/D3）—— 选中媒体节点侧栏「上游」面板分层展示全部上游（缩略图/视频/提示词，带节点名，不挤在一起）；悬浮预览放大；点击开 Lightbox 全窗（滚轮缩放）；**双击图片/视频=以 @引用 插入输入框末尾**并聚焦（生成中禁插）。
9. **@选项跟光标** ✅（D3）—— @候选弹层改为**光标锚定**：定位在 @ 字符处（上方优先、越界翻转下方），不再固定输入框底部；宽度 240px 最多 8 行滚动，键盘↑↓回车 Esc 可用。
