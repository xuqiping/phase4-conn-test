# 推送渠道配置傻瓜式指南

> 本指南面向最终用户，说明如何在飞书、钉钉、企业微信、Slack 中创建群机器人，并把机器人凭证配置到「工作汇报」模块中，用于接收报告和提醒消息。

---

## 一、飞书（Lark）

### 官方文档

- [飞书开放平台 - 自定义机器人使用指南](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)
- [飞书帮助中心 - 如何在群组中使用机器人](https://www.feishu.cn/hc/zh-CN/articles/360024984973)

### 操作步骤

1. **打开目标飞书群**
   在电脑端或手机端飞书里，进入你希望接收消息的群聊。

2. **进入群设置**
   点击群聊右上角的 **设置（齿轮图标）**。

3. **进入「群机器人」**
   在设置菜单中找到 **群机器人** 选项并点击。

4. **添加自定义机器人**
   点击 **添加机器人** → 选择 **自定义机器人**。

5. **配置机器人**
   - 填写机器人 **名称**（例如：工作汇报助手）
   - 上传一个 **头像**（可选）
   - 点击 **添加**

6. **复制 Webhook 地址**
   创建成功后，页面会显示一个地址，格式类似：
   ```
   https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```
   点击 **复制**，这就是你需要填到 File Keeper 里的 **目标 ID / Webhook 地址**。

7. **完成**
   点击完成，机器人就已经进群。

### 在本模块中如何填写

| 配置项 | 填什么 |
|---|---|
| 推送平台 | 选择 **飞书** |
| 目标 ID 或 Webhook 地址 | 粘贴第 6 步复制的完整 Webhook 地址 |
| 凭据或密钥 | 如果开启了「签名校验」，填写 `secret`；否则留空 |

### 安全建议

- Webhook 地址相当于机器人的钥匙，不要发到公开群或上传到代码仓库。
- 如需更高安全性，可在机器人设置中开启 **签名校验** 或 **IP 白名单**。

## 二、钉钉

### 官方文档

- [钉钉开放平台 - Webhook 机器人](https://open.dingtalk.com/document/orgapp/webhook-robot)
- [阿里云 - 获取钉钉机器人 Webhook 地址](https://www.alibabacloud.com/help/zh/doc-detail/2726332.html)

### 操作步骤

1. **打开目标钉钉群**
   建议在 **电脑版钉钉** 中操作。

2. **进入群设置**
   点击群聊右上角的 **群设置** 图标。

3. **进入智能群助手**
   找到 **智能群助手** → 点击 **添加机器人**。

4. **选择自定义机器人**
   在机器人类型中选择 **自定义**（通过 Webhook 接入自定义服务）。

5. **配置机器人**
   - 设置 **头像** 和 **名称**
   - 点击 **添加**

6. **设置安全方式（推荐「加签」）**
   三选一：
   - **自定义关键词**：消息里必须包含这个关键词
   - **加签**：获得一个 `SEC` 开头的密钥，调用时需要签名（更安全，推荐）
   - **IP 地址（段）**：只允许指定 IP 调用

7. **复制 Webhook 地址**
   创建成功后，会显示一个地址，格式类似：
   ```
   https://oapi.dingtalk.com/robot/send?access_token=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
   点击 **复制**。

### 在本模块中如何填写

| 配置项 | 填什么 |
|---|---|
| 推送平台 | 选择 **钉钉** |
| 目标 ID 或 Webhook 地址 | 粘贴第 7 步复制的完整 Webhook 地址 |
| 凭据或密钥 | 如果安全方式选了 **加签**，把 `SEC` 开头的密钥填到这里；否则留空 |

### 常见问题

- **报错 `sign not match`**：说明选了加签但没有正确生成签名。请确认凭据框里填的是完整的 `SEC` 密钥。
- **报错 `keywords not in content`**：说明设置了自定义关键词，但发送的消息里没有包含该关键词。
- **频率限制**：每个机器人每分钟最多 20 条，超限会被限流 10 分钟。

## 三、企业微信

### 官方文档

- [企业微信 API 文档 - 群机器人配置说明](https://work.weixin.qq.com/api/doc/90000/90136/91770)
- [企业微信开发者中心](https://developer.work.weixin.qq.com)

### 操作步骤

1. **打开目标企业微信群**
   必须是 **内部群**，外部群暂不支持添加机器人。

2. **进入群设置**
   点击群聊右上角的 **···（更多）**。

3. **添加群机器人**
   选择 **添加群机器人** → **新创建一个机器人**。

4. **配置机器人**
   - 设置 **头像** 和 **名称**
   - 点击 **添加**

5. **复制 Webhook 地址**
   创建成功后会显示一个地址，格式类似：
   ```
   https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```
   点击 **复制**。

### 在本模块中如何填写

| 配置项 | 填什么 |
|---|---|
| 推送平台 | 选择 **企业微信** |
| 目标 ID 或 Webhook 地址 | 粘贴第 5 步复制的完整 Webhook 地址 |
| 凭据或密钥 | 企业微信机器人一般不需要额外密钥，留空即可 |

### 注意事项

- 每个机器人每分钟最多发送 **20 条** 消息。
- Webhook 地址仅机器人创建者可查看。
- key 泄露后他人可向群内发消息，请妥善保管。

## 四、Slack

### 官方文档

- [Slack API - Your Apps](https://api.slack.com/apps)
- [Slack API - Create New App](https://api.slack.com/apps/new)

### 操作步骤

1. **登录 Slack API 控制台**
   打开 [https://api.slack.com/apps](https://api.slack.com/apps) 并用你的 Slack 账号登录。

2. **创建新 App**
   点击 **Create New App** → 选择 **From scratch**。

3. **填写 App 信息**
   - **App Name**：例如 `File Keeper Report`
   - **Workspace**：选择要安装的工作区
   - 点击 **Create App**

4. **启用 Incoming Webhooks**
   - 在左侧菜单找到 **Features → Incoming Webhooks**
   - 把开关 **Activate Incoming Webhooks** 打开
   - 页面会刷新

5. **添加 Webhook 到工作区**
   滚动到 **Webhook URLs for Your Workspace** → 点击 **Add New Webhook to Workspace**。

6. **选择频道并授权**
   选择要接收消息的频道（Channel），点击 **Allow / Authorize**。

7. **复制 Webhook URL**
   页面会生成一个地址，格式类似：
   ```
   https://hooks.slack.com/services/T00000000/B00000000/XXXXXXXXXXXXXXXXXXXXXXXX
   ```
   点击 **Copy**。

### 在本模块中如何填写

| 配置项 | 填什么 |
|---|---|
| 推送平台 | 选择 **Slack** |
| 目标 ID 或 Webhook 地址 | 粘贴第 7 步复制的完整 Webhook URL |
| 凭据或密钥 | Slack Incoming Webhook 不需要额外密钥，留空即可 |

### 注意事项

- Webhook URL 具有发送消息权限，请妥善保管。
- 每个 Webhook URL 只能发送到一个频道。
- 如果泄露，可在 Slack App 管理后台删除该 Webhook 并重新创建。

## 五、在 File Keeper 中配置推送

1. 打开 **工作汇报** 模块。
2. 进入 **报告配置** 或固定工作/未来计划的提醒设置。
3. 在「推送配置」区域：
   - **推送平台**：选择你已创建的机器人平台。
   - **目标 ID 或 Webhook 地址**：粘贴从平台复制的完整 Webhook 地址。
   - **凭据或密钥**：仅飞书签名校验、钉钉加签时需要填写；其他情况留空。
4. 点击保存。
5. 可以手动触发一次报告生成或等待定时提醒，验证是否能收到消息。

## 六、各平台凭证对照表

| 平台 | 需要填写的目标 ID / Webhook 地址示例 | 是否需要凭据 |
|---|---|---|
| 飞书 | `https://open.feishu.cn/open-apis/bot/v2/hook/xxxx` | 开启签名校验时填写 `secret` |
| 钉钉 | `https://oapi.dingtalk.com/robot/send?access_token=xxxx` | 选择加签时填写 `SEC` 密钥 |
| 企业微信 | `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxx` | 一般不需要 |
| Slack | `https://hooks.slack.com/services/T00/B00/XXXX` | 不需要 |

---

## 七、安全提示

1. **不要把 Webhook 地址提交到 Git 仓库。**
2. **不要把 Webhook 地址发到公开群或论坛。**
3. **如怀疑泄露**，立即到对应平台删除旧机器人/旧 Webhook，并重新创建。
4. **生产环境建议开启加签或 IP 白名单**。
