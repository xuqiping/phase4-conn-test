# 项目组与积分划拨

> 入口：侧栏「**项目组**」。组长建组、划拨积分、管成员；成员选组干活、花组池积分。

## 一、选组干活（所有角色，最重要）

**每页顶部右侧「参与项目」下拉**——全局唯一控制点，旁边常显「组池 N / 个人 N」两个积分徽标。

1. 下拉选组（默认「个人」）。
2. 之后发起的对话/问答/生图/生视频/画布消耗都扣**组池**，个人钱包不动。
3. 切回「个人」→ 恢复扣个人钱包。

**注意**：组池不足 → 提示「项目组积分不足」，找组长划拨；被移出组后提交会报 403，切回个人即可。

## 二、组长：建组与划拨

1. 项目组页右上「**新建项目组**」→ 填组名 → 建组。
2. 点卡片进详情 →「**划拨**」→ 输积分（从你个人钱包扣）→ 组池增加；「**回收**」= 组池退回你钱包。
3. 「组池流水」页签看每一笔记账（划入/回收/消耗/退款/调整），带变动后余额可对账。

**限制**：组池非 0 不能删组（先回收清零）；回收额不能超过「组池 − 在途占用」（在途 = 已提交未结算的任务，等结算完再收）。

## 三、组长：成员管理（邀请制）

1. 详情 →「成员」→「**邀请成员**」→ 搜用户名选人 + 可设限额 → 发送邀请。
2. **对方同意后才真正入组**（对方在项目组页顶部「我的邀请」条点「同意加入」）。
3. 成员表每行可以：
   - **调限额**：每人消耗上限（空=不限）。调低不追溯已耗。
   - **重置已用**：已用清零（如按月重置额度）。
   - **功能开关**：限制该成员在组内可用哪些模块（对话/图片/视频等）。全不勾=全禁。
   - **可见性**：单独定某成员产出的可见范围（跟随组默认/仅自己/全员可见）。
   - **移除**：移出组；历史流水保留。再次被邀入组时从零开始。

## 四、组长：任免「管理」

成员表「角色」列下拉：成员 ↔ 管理。
- **管理能**：邀请成员、审批入组、调限额、配开关/可见性、看流水（只读）、看全组产出。
- **管理不能**：划拨/回收、改组设置、任免角色——这些是组长专属。

## 五、组长：产出可见性与公共池招募（详情 →「设置」）

- **成员产出可见性**：默认「各自只见自己」；可改「成员互见全组」，也可只勾个别模块互见。
- **公共池招募**：点「推入公共池」→ 全平台用户可申请加入；申请出现在「入组审批」页签，逐条通过/拒绝。人够了点「撤出公共池」。

## 六、成员：受邀/申请入组、看自己的消耗

- **被邀请**：项目组页顶部「我的邀请」条 →「同意加入」。
- **主动加入**：「公共池」→ 招募中的组点「申请加入」（可附留言）→ 等组长审批。
- **看消耗**：点组卡片进「产出」页签，默认只显示自己的行（组长开了互见可看全组）。
- 普通成员看不到成员表和组池流水。

## 常见异常

| 现象 | 原因 | 恢复 |
|---|---|---|
| 侧栏没有「项目组」 | 账号无权限码 | 找管理员授权 |
| 提交报「超出成员限额」 | 已用+本次预估 > 限额 | 找组长调额或重置已用 |
| 提示「组长已限制你在本组使用该类模型」 | 组长给你配了功能白名单 | 找组长调整 |
| 管理看不到「划拨/回收」 | 设计如此：管理管人不管钱 | 找组长 |
