## 场景2：Context Rot 治理（长任务推理质量下降）

**何时进入**：Agent 长任务（20+ 步工具调用/30+ 分钟）后推理质量下降、忘记原始目标、重复编辑同一文件、绕圈——典型的 Context Rot。

**查什么**：
- 3_AI精炼版 → 3.2 上下文工程与 Context Rot 对抗（Context Rot 机理 + Lost in the Middle + Compaction + 缓存 + Goldilocks Zone + 渐进式披露）
- 4_可落地流程 → 4.2 SOP：上下文管理设计流程 + Compaction 策略表模板 + 渐进式披露清单模板

**PM 要回答的问题**：

- 工具数怎么控制？Vercel 15→2 的减工具逻辑能不能复用？
- 渐进式披露怎么实现（按需加载工具元信息/记忆条目）？
