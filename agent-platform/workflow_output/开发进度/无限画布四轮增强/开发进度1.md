## Step 2：节点宽高拖拽（✅ commit 1bb9591a / plan 勾验 87819451）

**spike 结论**：`@vue-flow/node-resizer@1.5.1` peer=`@vue-flow/core ^1.23`（core 1.41.5 满足）/`vue ^3.3`（3.4 满足），**采用库**。源码验证三点：组件内自动注入 NodeIdInjection（免传 id）；拖柄带 noDragClassName（不触发节点拖动）；min/max 有挂载校正 watch。用 `NodeResizeControl` 直组四角柄而非 `NodeResizer` 包装——包装额外渲染四边 line 控件，会压住上/下连线 Handle 的热区。npm audit 端点镜像源未实现（NOT_IMPLEMENTED），包为 @vue-flow 官方+依赖仅 d3-drag/d3-selection，记录豁免。

**涉及文件与关键位置**：

| 文件 | 改动 |
|---|---|
| `frontend/package.json` | +`@vue-flow/node-resizer ^1.5.1` |
| `types/canvas.ts` | `CanvasNodeData` +`width?/height?`（持久化真源注释）；`CanvasNode` +`style?`（会话态注释） |
| `nodes/CanvasNodeBase.vue` | selected 时 4×`NodeResizeControl`（160×64 下限）；`onResizeEnd` 取整写 `node.data.width/height`（`useNode` 注入，裸挂守卫）；根节点改 flex 列 + `width/height:100%` 跟随 wrapper、min 160×64；`--resized` 类（data.height 存在时）；头部 flex-wrap；body flex:1+overflow-y:auto |
