## 案例1：微信红包春节战役——场景绑定的巅峰(颠覆战)

| 要素 | 内容 |
|---|---|
| 名称 | 微信红包春节战役：用场景绑定击退来往 |
| 时间 | 2014年春节 |
| 主角 | 微信(张小龙团队) vs 来往(阿里巴巴) |
| 背景 | 阿里强推来往，马云亲自拉人，投入10亿+，目标是3个月1亿用户；微信需要守住社交霸主+切入支付 |
| 技术手法 | 不直接对战社交功能→做红包(场景绑定)：800万用户在春节绑定银行卡→支付场景绑定→社交+支付双壁垒；公众号+朋友圈形成内容+社交闭环 |
| 影响后果 | 来欢1亿注册但DAU<5%，2015年转型钉钉；微信支付从0到20%份额，社交份额>90% |
| 教训启示 | 场景绑定>功能对标——不是"做得比你好"而是"做你做不了的场景"；社交防守=做生态，不是做功能 |
| 反例 | Google+用"功能比Facebook好"策略→功能赢了但用户不走→2019关闭 |
| 来源标注 | [来源:QuestMobile 2015+微信公开课 | 置信度:🔍高] |

## 案例2：抖音算法飞轮碾压快手——效率>忠诚(颠覆战)

| 要素 | 内容 |
|---|---|
| 名称 | 抖音算法驱动增长碾压快手社区模式 |
| 时间 | 2018-2020 |
| 主角 | 抖音(字节跳动) vs 快手 |
| 背景 | 2018年快手DAU 1.2亿(社区)，抖音0.6亿(算法)，短视频格局未定 |
| 技术手法 | 3板斧：①全屏沉浸式(完播率↑→推荐更准)②算法冷启动(新创作者也能爆)③重运营(挑战赛+明星入驻)；算法匹配→完播率↑→推荐更准→更多内容→飞轮 |
| 影响后果 | 2020年抖音DAU 6亿>快手4亿；2025年抖音DAU 7亿+电商GMV 3万亿 |
| 教训启示 | 增长期效率>忠诚度；但社区模式更抗周期(快手2025年仍4亿DAU)；两种模式各有适用场景 |
| 反例 | 微博用算法驱动替代社区→短期DAU涨但创作者出走→长期萎缩 |
| 来源标注 | [来源:极光数据+字节跳动/快手财报 | 置信度:🔍高] |

|---|---|

| 主角 | 拼多多 |
| 背景 | 2019年拼多多被标签"假货/低端"，一二线用户渗透率低 |
