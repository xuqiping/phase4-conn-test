# 复制粘贴强化功能当前进度

更新时间：2026-05-31

## 已完成

- 完成本地复制粘贴强化功能的一稿设计，不包含云端同步能力。
- 完成实施计划文档：`docs/superpowers/plans/2026-05-29-local-clipboard-enhancement.md`。
- 已实现剪贴板历史的本地文本采集、列表展示、详情预览、复制回剪贴板和删除能力。
- 已实现剪贴板页面与快捷面板的基础入口。
- 已实现复制后界面实时刷新：后端采集成功后发送 `clipboard://changed` 事件，前端监听后刷新列表。
- 已修复同一文本复制产生多条重复记录的问题：文本入库前会按相同文本查重。
- 已新增列表多选能力：单条勾选、全选、反选、取消选择、删除选中。
- 已将批量工具栏改为常驻显示，未选中时显示当前列表记录数。
- 已新增右键菜单：复制、删除；文件类型记录额外显示“打开文件目录”。
- 已修复复制链路失效问题：单条复制、右键复制、双击复制、批量复制、Ctrl+C 快捷键和预览区复制都统一走同一套复制逻辑。
- 已增强后端可复制内容解析：不再只支持纯文本记录，链接、颜色、富文本、文件路径、图片 OCR/路径等记录也能复制。
- 已新增复制结果提示：复制成功显示“已复制到剪贴板 / 已复制 N 条记录到剪贴板”，复制失败显示具体原因。
- 已将剪贴板列表顶部批量操作工具栏置顶，滚动历史记录时保持可见。
- 已修复取消勾选后绿色选中框不立即消失的问题：绿色高亮现在只跟随勾选状态。
- 已调整右键删除和“删除选中”样式，改为贴近进程管理模块的柔和危险色风格。
- 已接入打开文件目录能力，复用现有 `showInFolder` 文件接口。
- 已实现剪贴板设置页、存储用量展示、非文本缓存清理入口。
- 已实现安全内容检测方向：敏感文本保存为安全事件，不保存原文。
- 已完成 URL 预览默认关闭、开启后才联网的设计和基础实现。
- 已完成 OCR 可替换接口、文件/图片/HTML/URL/颜色等类型的基础记录能力。
- 已实现日期筛选：支持全部时间、今天、昨天、近 7 天、近 30 天、自定义起止日期。
- 已实现备注功能：详情区可编辑备注，右键可进入备注编辑，备注内容参与搜索。
- 已修复右键编辑备注无反应、切换记录后备注残留、取消选择后详情仍停留在取消项等问题。
- 已修复非最新剪贴板记录详情读取异常问题，避免旧记录因只查最新 1 条而打不开详情。
- 已支持链接记录右键直接打开访问。
- 已支持文件记录右键打开文件、打开文件所在目录、复制文件路径。
- 已修复复制文件无反应问题，Windows 文件复制现在能读取 `CF_HDROP` 并进入剪贴板历史。
- 已修复从资源管理器复制单张图片时被归类为普通文件的问题，现在会作为图片记录保存。
- 已实现图片记录右键打开图片文件和打开图片所在目录。
- 已修复本地图片预览失败问题，前端图片缩略图和详情预览会通过 Tauri 资源地址加载本地路径。
- 已接入 Windows 系统 OCR，复制图片文件后会尝试识别文字，并把 OCR 结果写入图片备注。
- 已实现文件和图片真实备份到本地缓存目录的能力。
- 已新增“文件和图片保存方式”设置：用户可选择“备份副本到本地缓存目录”或“仅记录原始文件/图片地址”，切换后只影响新记录。
- 已修复切换到剪贴板页面卡顿的首屏问题：列表先加载，设置异步加载，存储用量延后刷新。
- 已修复剪贴板页面和文件管理模块布局混杂问题：文件管理搜索/排序/添加按钮、批量浮条、右键菜单和底部“共 X 个项目”状态栏只在文件管理页显示。
- 已将“剪贴板设置”入口移动到剪贴板顶部工具栏右侧，用户不需要再到左侧栏底部寻找。
- 已启用 Tauri 本地资源协议，支持自选备份目录中的本地图片通过前端预览加载。
- 已优化图片列表缩略图和详情预览显示方式，改为完整显示图片，避免长图或宽图被裁切。
- 已新增自选备份目录设置：用户可手动选择文件/图片备份位置，后续新复制的文件进入自选目录 `files` 子目录，新复制的图片进入自选目录 `images` 子目录。
- 已实现备份目录后端校验：保存设置时会要求绝对路径，并尝试创建目录；无效路径会返回错误。
- 已调整文件和图片文件备份命名规则：备份副本保留原文件名，并在扩展名前追加“备份”，同名时追加编号，例如 `报告-备份.docx`、`报告-备份2.docx`。
- 已补齐截图和浏览器直接复制图片的采集能力：Windows 剪贴板会读取 PNG、DIB、DIBV5 图片格式，统一保存为 PNG 图片记录。
- 已明确并实现保存模式规则：仅记录地址模式下，文件和图片文件只记录原始路径不备份；截图或浏览器直接复制的无路径图片仍会保存到图片缓存目录并进入历史。
- 已完成开源 OCR 方案初步调研：首选参考 RapidOCR + ONNX Runtime 作为 File Keeper 后续本地增强 OCR 引擎；PaddleOCR 作为中文 OCR 能力和模型来源参考；Umi-OCR 作为桌面端 OCR 产品形态和引擎调用方式参考；Tesseract 可作为经典稳定备选，Surya 更适合后续复杂文档/PDF/表格识别方向。

- 同一文本是否不再出现三条重复记录。
- 右键删除是否符合视觉风格和交互预期。
- 文件类型记录的“打开文件目录”是否能打开并定位到正确路径。
- 全选、反选、删除选中、取消选择在大量记录和筛选状态下是否符合预期。
- 复制成功 / 复制失败提示在桌面端实际使用中是否足够明显。
- 置顶批量操作工具栏在大量记录滚动时是否遮挡内容或影响观感。
- 日期筛选在真实历史数据下是否按本地时间正确过滤。
- 备注保存、清空、搜索备注关键词、右键编辑备注在桌面端是否稳定。
- 从资源管理器复制文件和图片后，历史记录是否实时出现，图片是否稳定显示缩略图和详情预览。
- 使用 `Win + Shift + S` 截图后，截图是否自动进入剪贴板历史并显示为图片记录。
- 浏览器右键复制图片后，若浏览器提供 PNG/DIB/DIBV5 格式，是否能进入剪贴板历史并正常预览。

- 自选备份目录是否能保存、重启后回显，并让新文件进入 `files` 子目录、新图片进入 `images` 子目录。
- 文件和图片文件备份名是否符合 `原名-备份.扩展名` / `原名-备份2.扩展名` 规则。
- 剪贴板页面是否不再显示文件管理模块的搜索/排序/路径/底部项目统计。
- 顶部“剪贴板设置”入口是否足够明显。
