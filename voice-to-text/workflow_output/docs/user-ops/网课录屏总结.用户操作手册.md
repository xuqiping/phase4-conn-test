# 网课录屏总结 · 用户操作手册

> Phase 3 产物（C 类受众）。细化到 功能 → 步骤 → 界面变化 → 预期结果。
> 技术原理看 [../feature-map/网课录屏总结.feature-map.md](../feature-map/网课录屏总结.feature-map.md)；异常用例对照 [../测试方案/网课录屏总结测试方案.md](../测试方案/网课录屏总结测试方案.md)。

## 0. 首次使用前：配置云端总结（一次性）

1. 打开应用 → 顶部点「**网课总结**」Tab。
2. 展开底部「**总结设置**」面板。
3. 填 **Base URL**（如 `https://api.moonshot.cn/v1`）和**模型名**（如 `kimi-k3`）。「**超时时长（秒）**」默认 600，一般不用动；只有网络极慢或超长课程汇总定稿频繁超时才需要调大。
4. （可选）在「**总结侧重点**」下拉选择预设；如内置选项不合用，可在下方「**侧重点预设维护**」表格里新增/编辑：填名称和提示词，保存后下次生成/重生成即按该提示词提炼要点。
5. 点「**保存 API Key**」输入框粘贴 Key 并保存。
   - 预期：Key 只进 Windows 凭据管理器，界面永远不回显 Key 本体，只显示「已设置」。
6. 点「**测试连接**」。
   - 预期：显示「连接成功（模型名）」。失败时按提示检查 Base URL / 模型名 / Key。
   - 不配 Key 也能用：录制、抽帧、OCR、对齐都正常，只有「云端总结」阶段会失败，之后补 Key 点重试即可。

## 1. 录制网课

1. 打开网课播放器窗口（网页或客户端均可），**不要最小化**（最小化后录到的是黑屏）。
   - 录制中若顶部出现红色告警「⚠️ 画面丢失超过 3 秒」：先还原/置顶被录窗口；**若窗口明明没最小化、只是被别的程序最大化盖住仍黑屏**（部分 Windows 显卡驱动会停止绘制被完全遮挡的窗口，属系统限制），请停止后改用「区域框选」模式录制屏幕区域——区域模式录的是屏幕合成画面，被遮挡不影响。
2. 在「录制区」下拉框**选择要录的窗口**。
   - 界面变化：下拉框列出当前所有窗口标题。
3. （可选）设置「**定时停止**」：录制控制行右侧，模式三选——
   - **关**（默认）：不定时；
   - **倒计时**：填分钟数（支持小数，如 1.5 = 90 秒），到点自动停止；
   - **定点**：填 `HH:MM`（24 小时制），到点自动停止；填的时间已过则顺延到明天同一时刻。
   - 录制前设置或录制中随时修改都行，修改立即按新参数生效；录制中计时器旁会显示「mm:ss 后停」倒减（最后 1 分钟带 ⚠）。到点自动停止与手动点「停止录制」完全一样，录后处理正常进行。
4. 点「**开始录制**」。
   - 界面变化：进入录制态——计时器走动、实时字幕区滚动显示识别文字。
   - **实时录制画面面板**：录制中顶部出现「实时录制画面」面板（红点闪烁 + 黑屏占比徽标），预览图约每 0.5~1 秒刷新，所见即所录——窗口被最小化/投黑帧时预览会变黑、占比上升（>10% 徽标变红），可实时发现录没录上。注意：被录画面完全静止时预览刷新会略慢（Windows 只在画面变化时投帧）。
   - 预期结果：屏幕画面、系统/麦克风声音、实时转写三路同时在录，共用同一时间轴。
5. 课上完点「**停止录制**」（或等定时停止到点自动停）。
   - 界面变化：自动切到「处理中」视图。
   - 预期结果：`sessions/<时间戳>/` 下已落盘 video 切片、audio.wav、transcript.jsonl。

> ⚠️ 联动注意：录制中不能开第二个录制（按钮态互斥）；切换 Tab 到「实时转写」不影响录制。

## 2. 录后自动处理（四阶段）

停止后自动开始：**精细抽帧 → 课件 OCR → 音字帧对齐 → 云端总结**，每阶段显示 ⏳/✓/✗。

- **正常**：四阶段全 ✓ → 自动进入学习区。
- **想看进度**：每阶段下方有一行结果摘要（如「抽出 86 页课件帧」「OCR 成功 80 帧（失败 6）」「对齐 142 个单元」）。
- **取消**：点「取消」→ 当前阶段跑完后停下，已完成阶段结果保留。
- **断点续跑 / 重试**：点「继续/重试」→ 只跑未完成阶段，已完成的不会重跑。
- **总结阶段失败**（常见于没配 Key）：前三阶段成果都在，配好 Key 后点「重试」只重跑总结。
- **部分帧 OCR 失败**：不阻塞，这些页没有 OCR 原文，总结仍会用转写文字。

## 3. 学习区（复习）

处理完成后出现左右两区：

- **左：章节时间轴**。章节严格按**课件翻页（关键帧变化）**划分——老师翻一页就是一章。点章节 → 右侧定位到该章要点。
- **右：视频点播 + 章节总结 + 要点列表**。
  - **章节总结**（绿色卡片，位于要点列表上方）：本章的自由文本总结，**完全按照你在总结设置里选中的侧重点来写**（比如选了考试复习就提炼考点、易错点、考题摘录），篇幅不限。某章没有该卡片 = 该章章节总结生成失败（已降级，不影响要点）。
  - 点任意**要点或课件帧缩略图** → 视频自动跳到该要点对应的讲课时刻（跨切片会等加载再 seek）。
  - 要点旁的**课件帧缩略图**点击可放大看原图。
  - 展开「OCR 原文」→ 逐字核对课件上原本写的是什么（懒加载，点开才读文件）。

### 3.1 汇总定稿（去重兜底汇总）

抽帧偶有不准时不同章节可能讲了重复内容。「**汇总定稿**」按钮（导出按钮旁）做最后的兜底汇总：

1. 总结完成后点「**汇总定稿**」（已汇总过显示「重新汇总定稿」，可覆盖重做）。
2. 预期结果：学习区顶部出现「**汇总定稿（去重后最终章节）**」卡片——
   - 内容重复/连贯的章节已**合并去重**（卡片底部标注「合并自原章节：N、M」）；
   - 每个最终章节有**重新拟定的真实标题**（不再是「章节 N」占位）；
   - 每章带合并去重后的最终总结和时间区间。
3. **定稿即产 Markdown 文件**：点「汇总定稿」成功后自动生成 `sessions/<id>/exports/<全课总标题>.md`——文件名就是 LLM 拟定的全课总标题；文档结构：`# 总标题` → 每章 `## 章节标题（起-止时间）` + 本章总结 + 带时间戳要点，**重复引用的课件帧图全课只贴一次**。界面「已导出：…」显示文件完整路径。
4. 之后点「导出 Markdown」仍可导出逐章原始版（文件开头含「汇总定稿」一节）。
5. 注意：**重生成/重新分析视频会清掉旧汇总定稿**（总结内容已变），需要重新点一次；汇总失败会直接报错，可重试。
6. **汇总定稿也遵循「总结侧重点」**（2026-08-22 起）：若在总结设置里选了/自定义了侧重点，定稿的合并取舍、总标题与各章总结都会按该侧重来写。改了侧重点想生效到定稿 → 点「重新汇总定稿」即可，无需重跑整课总结。

## 4. 总结草稿的修改与重生成（SummaryPanel）

- **看版本**：草稿徽标显示 版本号 + 所用模型；本地兜底草稿会显示 ⚠️ 提示。
- **改单条要点**：点要点的编辑框直接改 → 保存。
  - 预期：只改这条，不产生新版本（历史版本靠重生成保留）。
- **重生成某一段**：点该段「重生成」→ 只重跑这一段（费一次 API 调用）。
- **全量重生成**：点「全量重生成」→ 所有段重跑，版本号 +1，旧版本保留在草稿历史里。
  - ⚠️ 注意：它**只重新调用云端总结**，不会重新抽帧或 OCR。如果你怀疑抽帧/OCR 结果有问题（比如解码 bug 修复后旧会话的帧还是斜的、OCR 全空），请用学习区的「**重新分析视频**」按钮。
- **重新分析视频**：点后会弹出确认，删除当前 `frames.json`、`frames/`、`aligned.json`、`summary_draft.json`（旧 `summary_draft.json` 会先备份），然后切回处理视图重新跑完整流水线（抽帧 → OCR → 对齐 → 总结）。
- **多模态精修开关（默认关）**：打开时弹二次确认「将上传课件图到 {base_url}」。
  - 确认后重生成的总结会附带课件截图给云端模型，图文对照更准，但**课件图会离开本机**——确认前请知悉。

## 5. 导出 Markdown

1. 学习区点「**导出 Markdown**」。
2. 预期结果：生成 `sessions/<id>/exports/summary.md`，界面显示完整文件路径。
3. 用 Typora / Obsidian 打开：汇总定稿（若已点过「汇总定稿」）+ 章节 + 章节总结 + 要点（带 `[mm:ss]` 时间戳前缀）+ 课件帧图片（相对路径直接显示）。
4. 「思维导图 / Anki」按钮为占位（Should 级未实现），当前置灰。

## 6. 运维：临时关停本功能（管理员）

功能出线上问题时，不必回滚版本，二选一：

- **环境变量**：设 `VTT_COURSE_SUMMARY=off` 后重启应用；
- **配置文件**：在应用配置目录新建 `feature_flags.json`，内容 `{"course_summary": false}`，重启应用。

预期结果：顶部「网课总结」Tab 消失；即使绕过前端，后端也会拒绝新的录制请求。恢复：删掉该设置重启即可。

## 7. 隐私与数据说明

- **上传云端的只有文字**（转写文字 + 课件 OCR 文本）；开了多模态开关才会附课件帧图。
- **视频、音频原文件永不离开本机**。
- 一节课的全部数据在 `sessions/<时间戳>/` 一个目录里，**删除该目录 = 彻底删除这节课**。
- API Key 存 Windows 凭据管理器，卸载应用不会自动删，可在「总结设置」里点清除。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 「尚未设置 API Key」 | 总结设置里填 Key 并测试连接，然后对失败阶段点重试 |
| 录制状态显示 stalled / 「画面丢失」红色告警 | 被录窗口最小化了（录到黑屏），还原窗口即可；若窗口没最小化、只是被别的程序最大化盖住仍黑屏，是显卡驱动停止绘制被遮挡窗口的系统限制——改用「区域框选」模式录制。黑屏时段的讲解仍会正常转写，抽帧时会自动跳过黑屏不产生假章节 |
| 汇总定稿/总结阶段超时失败 | 总结设置里把「超时时长（秒）」调大（默认 600；长课程汇总定稿建议保持默认或更大），保存后重试 |
| 总结内容像原文堆砌且有 ⚠️ | API 失败走了本地兜底；检查网络/额度后重生成 |
| 点开始录制提示功能已关闭 | 运维开关被关停（见第 6 节），联系管理员 |
