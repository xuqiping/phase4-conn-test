## 搜索引擎链路（com.superprogrammer.search）

| 功能 | 文件 | 大白话原理 |
|---|---|---|
| 统一入口/路由/降级 | [WebSearchService.java](../../../backend/src/main/java/com/superprogrammer/search/service/WebSearchService.java) | 像 110 接线员：先问"主引擎"通不通，不通转备用，备用也不通就告诉上面"没查到"，绝不挂电话（不抛异常） |
| 默认值装配 | [SearchConfig.java](../../../backend/src/main/java/com/superprogrammer/search/config/SearchConfig.java) | 从系统设置读默认值（查几条/超时多久），打包给上面那个接线员 |
| 外部-Tavily | [TavilyProvider.java](../../../backend/src/main/java/com/superprogrammer/search/provider/TavilyProvider.java) | 调 Tavily 公司的搜索 API，带我们申请的 key |
| 外部-Serper | [SerperProvider.java](../../../backend/src/main/java/com/superprogrammer/search/provider/SerperProvider.java) | 调 Serper（背后是 Google 结果）|
| 外部-Bing | [BingProvider.java](../../../backend/src/main/java/com/superprogrammer/search/provider/BingProvider.java) | 调微软 Bing API |
| 自建引擎 | [BuiltInSearchProvider.java](../../../backend/src/main/java/com/superprogrammer/search/provider/BuiltInSearchProvider.java) | 调自己部署的 SearXNG 拿网址列表 → 并发抓 5 个网页正文 → 组装结果。没外部 key 时兜底 |
| SearXNG 客户端 | [SearxngClient.java](../../../backend/src/main/java/com/superprogrammer/search/client/SearxngClient.java) | 调 SearXNG 的 JSON 接口拿网址；再单独抓网页正文 |
| 正文抽取 | [ContentExtractor.java](../../../backend/src/main/java/com/superprogrammer/search/util/ContentExtractor.java) | 自实现 Readability：从乱糟糟网页 HTML 里只抠正文文字，丢导航广告（像榨汁机去皮留果肉） |
| 安全清洗 | [SanitizeUtil.java](../../../backend/src/main/java/com/superprogrammer/search/util/SanitizeUtil.java) | `sanitizeText` 去垃圾字符防注入；`assertPublicUrl` 抓网页前先看 IP 是不是内网（防 SSRF 被骗抓内网） |

## 注入 CHAT 链路

| 功能 | 文件 | 大白话原理 |
|---|---|---|
| 开关门控+检索+注入 | [ChatSessionService.java](../../../backend/src/main/java/com/superprogrammer/chat/service/ChatSessionService.java)（`resolveWebSearch` / `resolveWebSearchOn`） | 开关开→查网→把网页内容当"参考资料"塞给 LLM 提示词；查不到也给句"没查到"继续答 |
| web 引用回传 | 同上（`WebSearchInjection` record + tail CITATION 事件） | 查到的网址打包成引用，单独发一个 CITATION 事件给前端 |
| 引用 VO | [RagRetrieveVO.java](../../../backend/src/main/java/com/superprogrammer/knowledge/dto/RagRetrieveVO.java)（`CitationVO.url`+`snippet`） | 引用对象加了 url 字段，区分"网页外链" vs "知识库文档" |
| 前端引用合并 | [chat.ts](../../../frontend/src/stores/chat.ts)（CITATION 帧累积合并） | 知识库引用和网页引用分两批发，前端拼一起不互盖 |
| 引用渲染 | [MessageBubble.vue](../../../frontend/src/components/chat/MessageBubble.vue)（`c.url` → 外链） | 有 url 的是网页→渲染蓝链可点；没 url 的是知识库→原样 |
