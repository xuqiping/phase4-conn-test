# 4.2 路径发现模板

## 模板一：起止式路径发现

### 配置表

| 配置项 | 值 | 说明 |
|---|---|---|
| 起点事件 | `app_open` | 用户打开App |
| 终点事件 | `pay_success` | 支付成功 |
| 粒度 | 页面级 | 电商场景页面够用 |
| 路径深度 | 7步 | 覆盖浏览→支付全链路 |
| 最小流量 | 1% | 过滤长尾路径 |
| 时间范围 | 近30天 | 排除短期波动 |
| 分群 | 新/老用户 | 比较路径差异 |

### 输出解读框架

```
路径结果解读按以下框架：
1. 主路径是什么？占比多少？
2. 主路径是否=预期的漏斗路径？
3. 有多少用户走了非预期路径？
4. 非预期路径的共性是什么？
5. 是否存在环路/死胡同？
```

## 模板二：开放式路径发现

### 配置表

| 配置项 | 值 | 说明 |
|---|---|---|
| 起点事件 | `feature_X_used` | 用户使用了新功能X |
| 终点事件 | — | 不设终点，追踪后续行为 |
| 追踪深度 | 5步 | 了解功能使用后的去向 |
| 时间窗口 | 同一会话 | 关注即时行为 |

### 典型发现

| 发现 | 含义 | 优化方向 |
|---|---|---|
| 使用功能X后又用了Y | X和Y是功能组合 | 引导X→Y的关联使用 |
| 使用功能X后跳出 | 功能X未能留存用户 | 检查X的体验完整性 |
| 使用功能X后返回首页 | 用户没有下一步目标 | 功能X后推荐下一步 |

## 模板三：逆向式路径发现

### 配置表

| 配置项 | 值 | 说明 |
|---|---|---|
| 起点事件 | — | 不设起点，从终点回溯 |
| 终点事件 | `churned`(流失) | 用户标记为流失 |
| 回溯深度 | 10步 | 覆盖流失前的完整行为链 |
| 时间范围 | 流失前30天 | 寻找流失前兆 |

### 典型发现

| 流失前路径模式 | 含义 | 干预点 |
|---|---|---|
| ...→帮助中心→帮助中心→跳出 | 遇到问题未解决 | 帮助中心满意度提升 |
| ...→价格页→竞品关键词搜索→跳出 | 价格敏感流失 | 优惠/价值强化 |
| ...→功能使用下降→沉默→流失 | 价值衰减 | 早期功能引导 |
