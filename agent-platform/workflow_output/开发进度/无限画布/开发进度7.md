## 本轮做了什么

### C13 故事板（IC-11，基础剪辑成片）

- **VideoFrameService.concat** [canvas/service/VideoFrameService.java](../../../backend/src/main/java/com/superprogrammer/canvas/service/VideoFrameService.java)：以**首段** width/height/fps/bitrate 初始化一个 `FFmpegFrameRecorder`，逐段 `FFmpegFrameGrabber.grabImage()` 把帧重编码进**同一 recorder** → 单个 mp4 临时文件。
  - **要求各段同源/同尺寸**（典型 = 同一视频的若干 clip 截取产物）；尺寸不一致 javacv 按原始像素塞入可能变形 —— MVP 不做缩放对齐（plan 边界：深度剪辑/转场是独立 plan）。
  - 同 extract/clip：流式按帧不整片 load；**产物写临时文件非 byte[]**（调用方 try-finally 删，复用 [[../../../../../C/Documents and Settings/Administrator/.claude/projects/e--workspace/memory/]] 无，复用 C12 沉淀的临时文件规范）；仅视频轨（无音频轨拼接）；失败固定话术。
  - 返 `ConcatResult(tempFile, mime, size, totalDurationMs, segmentCount)`；`totalDurationMs` = 各段 `getLengthInTime()` 之和。
  - 校验：parts 非空 / 段数 ≤ `MAX_CONCAT_PARTS`(20) / 首段尺寸可读。

### 端点（C13 chunk2）

- **CanvasController** `POST /{id}/storyboard/concat` [CanvasController.java](../../../backend/src/main/java/com/superprogrammer/canvas/controller/CanvasController.java)：body `{fileIds}` → ①`loadOwned`（画布归属）②**LinkedHashSet 去重保序**（同 fileId 重复入列会让成片重复同段）③逐 fileId `loadPath`（**每段 ownership 复检**，防借他人 fileId 拼接）④`concat`⑤`storeStream(SOURCE_CANVAS)`。
  - try-finally 删临时 mp4（storeStream 成败都删）。
  - 返 `StoryboardConcatVO { fileId, url, mime, size, segmentCount, totalDurationSec, sourceNodeIds }`。

### 前端故事板面板（C13 chunk3）

- **StoryboardPanel.vue** [StoryboardPanel.vue](../../../frontend/src/components/canvas/StoryboardPanel.vue)：右抽屉。投影画布视频节点（type=video 且有 fileId）为段列表。
  - **上下调序**（↑↓ 按钮，内部 `order` ref 保序，segments 变化时同步新增段、保留旧段序）。
  - **顺序预览**：`<video>` 绑当前段 `previewUrl`，`@ended` 自动进下一段（末段停）；点击列表项跳段。
  - 每段显示 label + durationSec（未知则「时长未知」）；合计 ≈ 总时长。
  - 「拼接成片（N 段）」按钮，`disabled` 当 <2 段；emit `concat fileIds[]`。
- **CanvasView.onStoryboardConcat** [CanvasView.vue](../../../frontend/src/views/CanvasView.vue)：调 `canvasApi.concatStoryboard` → `fetchVideoBlob(f.url)` → `addNode(video)`（label=`成片(N段/Ts)`，带 fileId+previewUrl+mediaStatus=SUCCEEDED+duration）→ `scheduleSave`。**不批量连源边**（成片是综合产物，连所有源会杂乱；保留用户手动连）。
- **storyboardSegments computed**：依赖 `showStoryboard` 触发重算（抽屉打开时从 `boardRef.getNodes()` 取最新视频节点），避免无效计算。
- `StoryboardSegment` 类型入 `types/canvas.ts`（script setup 禁 export，跨组件共享类型走 types）。

## 踩坑批注

| 坑 | 解 |
|---|---|
| 多段尺寸不一致 recorder 按首段尺寸塞入变形 | MVP 不缩放对齐，文档要求各段同源（同视频的 clip）；深度剪辑独立 plan |
| 同 fileId 重复入列致成片重复同段 | controller `LinkedHashSet` 去重保序 |
| concat 每段都须 ownership 校验（不能只校验画布） | 逐 fileId `loadPath` 复检，防借他人 fileId 拼接 |
| `<script setup>` 禁 `export`（StoryboardSegment 跨组件用） | 类型移 `types/canvas.ts`，组件 import type |
| storyboardSegments 取 `boardRef.getNodes()` 非响应式 | computed 依赖 `showStoryboard`，抽屉打开时重算取最新节点 |
