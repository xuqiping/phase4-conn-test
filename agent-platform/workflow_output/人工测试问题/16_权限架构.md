## 用户管理看不到 id 1-100 的老用户（2026-08-25 解决）
- **根因**：前端 `UserManageView.vue` 的 `n-data-table` 缺 `remote` 属性——Naive UI 把后端已分页的一页数据再按客户端切片，第 2 页起永远为空；列表按 created_at 倒序，最老用户（id 1-100）够不到。
- **修复**：加 `remote` 走纯服务端分页。实测 `page=2` 正常返回 id [175,174,173,172,8,4,3,2,1]。
