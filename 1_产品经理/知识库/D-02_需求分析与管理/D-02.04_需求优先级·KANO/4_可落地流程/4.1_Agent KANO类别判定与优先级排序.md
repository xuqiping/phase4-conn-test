# 4.1 Agent KANO类别判定与优先级排序

> 📅 2026-07-11 ｜ 🔴红线：KANO类别判定不可仅凭AI推断，必须基于真实用户问卷数据；Agent仅辅助分析，PM必须审核判定结果 ｜ 角色：KANO优先级分析Agent

## 背景

KANO模型的分析流程（问卷回收→类别判定→Better-Worse计算→优先级排序）重复性高、计算繁琐，但规则明确，适合Agent辅助。本Agent自动完成从原始问卷数据到优先级推荐的完整链路。

## 目标

输入KANO问卷原始数据（正反向作答记录），输出需求KANO分类表 + Better-Worse系数 + 优先级排序建议。

## 关键结果

1. 每个需求的KANO类别标签 + 判定方法说明
2. Better-Worse系数（SI/DSI）+ 四象限归属
3. 同类别内排序 + 跨类别优先级推荐

## 执行步骤

### Step 1：数据清洗与校验

```
输入：问卷原始数据（CSV/Excel）
  每行=1个受访者对1个需求的正反向作答

清洗规则：
  1. 剔除Q类（可疑回答：正反都"喜欢"或都"讨厌"）
  2. 剔除缺答项（正反向任一未作答）
  3. 标记R类（反向回答）供PM确认是否为真实反向需求

输出：有效数据集（含有效回收率报告）
```

### Step 2：类别判定（PM选择判定方法）

```
判定方法选择（由PM指定，非Agent自选）：
  A. Max频率法 → 适合快速分类、样本量>50
  B. 优势类别法 → 适合产品规划、需区分M/O/A
  C. 阈值判定法 → 适合高决策成本场景

Agent自动执行选定方法：
  - 统计每个需求各类别频率
  - 按选定方法输出类别
  - 标注判定信心度（Max频率法：Max占比；阈值法：是否达到强/弱阈值）
```

### Step 3：Better-Worse计算

```
对每个需求计算：
  SI = (A + O) / (A + O + M + I)
  DSI = -1 × (O + M) / (A + O + M + I)

四象限归属：
  均值法阈值 → SI_mean, DSI_mean
  → 高于SI_mean = 高改善，低于DSI_mean = 高损失
  → 四象限定位
```

### Step 4：优先级排序推荐

```
排序逻辑：
  1. 跨类别排序：M > O > A > I
  2. M类内部：按DSI绝对值降序
  3. O类内部：按SI×|DSI|降序
  4. A类内部：按SI降序
  5. I类：标注"建议暂缓"

输出排序表：
  | 优先级 | 需求ID | KANO类别 | SI | DSI | 象限 | 排序依据 |
```

### Step 5：漂移检测（可选）

```
如Agent检测到历史KANO数据：
  - 对比当前类别与上次类别
  - 标注漂移方向（A→O, O→M等）
  - 预警：6个月内从A→O的需求（建议调整策略）
```

## 输出格式

```markdown
# KANO分析报告

## 数据概况
- 回收问卷：X份 ｜ 有效问卷：Y份 ｜ 有效率：Z%
- 分析需求数：N个 ｜ 判定方法：[Max频率法/优势类别法/阈值判定法]

## KANO分类结果
| 需求 | M% | O% | A% | I% | R% | 类别 | 信心度 |
|---|---|---|---|---|---|---|---|

## Better-Worse分析
| 需求 | SI | DSI | 象限 | 类别内排序 |
|---|---|---|---|---|

## 优先级推荐
| 排序 | 需求 | 类别 | 排序依据 | 建议 |
|---|---|---|---|---|

## 漂移预警（如有历史数据）
| 需求 | 上次类别 | 本次类别 | 漂移方向 | 行动建议 |
```
