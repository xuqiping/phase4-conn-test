### 2026-05-16 — 功能 13 拖拽虚影修复 + 快捷键冲突修复 ✅

**修复内容：**

#### ✅ 功能 13 - 拖拽虚影跟随鼠标
- **问题**：拖拽文件卡片时，虚影不跟随鼠标移动，钉死在原位置
- **根因**：`.sortable-fallback` CSS 用 `!important` 覆盖了 sortablejs 的内联定位属性
- **修复**：移除所有定位相关的 `!important`，只保留视觉效果样式
- **结果**：✅ 拖拽虚影正常跟随鼠标，类似 Windows 资源管理器体验

#### ✅ 快捷键冲突连环报错
- **问题**：频繁弹框报错 `快捷键更新失败：Failed to unregister hotkey`
- **根因**：注册失败后仍写入 store，下次 unregister 一个从未注册的快捷键导致报错
- **修复**：新增 `registeredShortcut` 追踪变量，解耦 OS 状态与 store，unregister 失败降级为警告
- **结果**：✅ 快捷键冲突时只提示一次，不再连环报错

**修改文件：**
- `src/App.vue` — 重写 sortable CSS + 重构快捷键注册逻辑

**技术验证：**
- 构建通过 ✅
- 单元测试 38/38 通过 ✅
