# 联网搜索 · 用户操作手册

> 普通用户 + 管理员两套操作。细化到「功能→步骤→界面变化→预期结果」。

## A. 普通用户：聊天里开联网

### A1. 开启联网搜索
| 步骤 | 操作 | 界面变化 | 预期结果 |
|---|---|---|---|
| 1 | 进入对话页（CHAT 模式，非 Agent/工作流） | 输入框下方工具栏 | 看到 `🌐 联网：关` 下拉 |
| 2 | 点 `🌐 联网：关` 下拉 → 选「🌐 联网：开」 | 下拉变「🌐 联网：开」 | 开关状态存浏览器，刷新/换会话仍保持 |
| 3 | 输入时效问题，如「今天什么日期？」发送 | 正常发消息 | AI 回答带真实日期（不再是训练截止日），回答里出现 `[1][2]` 编号 |

### A2. 查看引用来源
| 步骤 | 操作 | 界面变化 | 预期结果 |
|---|---|---|---|
| 1 | 等 AI 回答完 | 回答气泡下方 | 出现 `📎 引用来源` 区 |
| 2 | 看联网来源 | 蓝色 `🌐 标题` 链接 | 联网来源标 🌐 + 是可点外链 |
| 3 | 点击 `🌐 标题` | 新标签页打开 | 跳到原网页（rel=noopener 安全打开） |

### A3. 关闭联网
| 步骤 | 操作 | 界面变化 | 预期结果 |
|---|---|---|---|
| 1 | 点 `🌐 联网：开` 下拉 → 选「关」 | 下拉变「🌐 联网：关」 | 之后消息走纯模型作答，无引用、无 🌐 外链 |

### A4. 反向/边界场景
| 场景 | 行为 |
|---|---|
| 开关关 → 发消息 | 零变化，原 CHAT 流程 |
| 开关开 + 网没查到 | AI 仍照常作答，不报错不卡住（无引用区） |
| 开关开 + 记忆模式同时开 | 两套引用都在（知识库 [n] + 联网 🌐[n]，编号不串） |
| Agent / 工作流模式 | 联网开关无效（本期仅 CHAT；UI 仍显示但不生效） |

## B. 管理员：后台运维配置

入口：侧边栏 → **设置** → **联网搜索** tab（仅 admin 可见）。

### B1. 开启总开关
| 步骤 | 操作 | 界面变化 | 预期结果 |
|---|---|---|---|
| 1 | 「联网搜索（全局）」开关 → 点开 | 开关亮，下方表单解锁 | 用户侧 🌐 开关才生效；关则用户开了也不查 |

### B2. 选默认引擎
| 步骤 | 操作 | 界面变化 | 预期结果 |
|---|---|---|---|
| 1 | 「默认 Provider」下拉选一个 | 下拉更新 | 下次请求按此 provider 查 |
| 2 | 看「Provider 可用性」标签 | 标签绿=可用 / 灰=不可用 | 外部标"不可用"=没配 key；自建标"不可用"=SearXNG 没部署 |

### B3. 配外部 key（Tavily/Serper/Bing 任选）
| 步骤 | 操作 | 界面变化 | 预期结果 |
|---|---|---|---|
| 1 | 「Tavily Key」密码框输入申请到的 key | 框内有值，旁「已配置/未配置」标 | - |
| 2 | 点「保存 Key」 | 提示"已保存"，key 框清空，标签变绿「已配置」 | key AES 加密入库，**不回显明文** |
| 3 | （反向）清除 key：密码框填空格 → 保存 | 标签变灰「未配置」 | 该 provider 走降级 |

> Serper / Bing 操作同上。

### B4. 调结果数 / 超时
| 字段 | 范围 | 说明 |
|---|---|---|
| 默认结果数 (top-N) | 1~10 | 越大越慢（每页抓全文）|
| 单次超时 (ms) | ≥1000 | 整体超时，外部超时还会重试 1 次 |

### B5. 测试连通
| 步骤 | 操作 | 界面变化 | 预期结果 |
|---|---|---|---|
| 1 | 点「测试连通」 | loading | 后端实时搜一次 "test" |
| 2 | 看蓝色提示框 | 显示「命中 N 条 / active provider / 各可用性」 | N>0=通；N=0=零结果或全降级失败（看可用性定位） |

### B6. 部署自建引擎（一次性，运维）
| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | Docker 部署 SearXNG，`settings.yml` 配 `formats: [json]` | `curl '<searxng>/?q=test&format=json'` 返 JSON |
| 2 | 后端 `application.properties` 设 `search.searxng.base-url=http://<host>:<port>` | 重启后「Provider 可用性」builtin 标绿 |
| 3 | （可选）admin 页默认 provider 留「自建 SearXNG」| 无任何外部 key 也能用 |

> SearXNG base-url 是部署期配置（写配置文件），**不在 admin 页改**——它是 Docker 地址非运行时项。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 开关开了但没引用 | 没查到内容（AI 仍作答）；或后台总开关关 / 自建没部署且无外部 key |
| 测试连通命中 0 | 看「各可用性」：active provider 标灰=没配 key 或 SearXNG 没起 |
| 用户点了 🌐 链接打不开 | 原网页已下线/被墙；换 provider 或换 query |
| 想临时全局停用 | admin 页「联网搜索（全局）」关 → 不发版即生效 |
