## 板块 B · 学谁 — 业内顶尖人士对标图谱

### 1. Robert G. Cooper（罗伯特·库珀）

| 维度 | 内容 |
|---|---|
| 身份 | Stage-Gate国际创始人/产品创新管理学者/麦克马斯特大学荣休教授 |
| 国籍 | 加拿大 |
| 核心成就 | 创立Stage-Gate®产品开发流程——将NPD分为"阶段+门"结构化决策；全球70%+顶尖制造企业采用；著《Winning at New Products》畅销30年；PDMA终身成就奖 |
| 思维模型 | **门即投资决策**：每个Gate不是"流程关卡"而是Go/Kill/Hold投资决策点——评审的本质是"是否继续投资这个方向"；门的标准必须事前量化、不可临时降低 |
| 行动范式 | 学术+实证双轮驱动：基于2000+企业调研数据建模；迭代修正——Stage-Gate从1.0演进到3.0，每次基于新数据；坚持"可操作性"——理论必须能落地为评分表和检查清单 |
| 可学习点 | 评审门的核心是"事前定义好的通过标准"而非"评委的感觉"；Kill不是失败，错误的Go比Kill代价大得多；评审裁剪必须按项目类型调整——不能一刀切 |
| 代表作 | 《Winning at New Products》《Portfolio Management for New Products》/Stage-Gate®官方指南 |
| 来源 | 🔍高 |

### 2. Jeff Bezos（杰夫·贝索斯）

| 维度 | 内容 |
|---|---|
| 身份 | Amazon创始人/Blue Origin创始人 |
| 国籍 | 美国 |
| 核心成就 | 创立Amazon"六页纸"叙事评审制度——用结构化文档替代PPT做评审决策；建立"单向门/双向门"决策框架，区分不可逆决策与可逆决策的评审严格度 |
| 思维模型 | **单向门vs双向门**：不可逆决策(单向门)需要严谨评审+集体决策；可逆决策(双向门)可快速试错、随时回退——90%的产品决策是双向门，不需要重度评审 |
| 行动范式 | 叙事驱动：六页纸叙事备忘录替代PPT，强制写作者深度思考而非堆砌要点；"反对但承诺"(Disagree and Commit)：评审分歧时，被否决方仍全力执行而非消极抵抗 |
| 可学习点 | 评审的形式(六页纸>PPT)决定了思考的深度；不是所有决策都需要重度评审——先区分单向门/双向门再配评审；"反对但承诺"是评审分歧的终极解法 |
| 代表作 | Amazon年度股东信(1997-2021)/《Invent and Wander》 |
| 来源 | 🔍高 |

### 3. Tom Graves（汤姆·格雷夫斯）

| 维度 | 内容 |
|---|---|
| 身份 | 企业架构师/Tetradian咨询创始人/DACI决策框架推广者 |
| 国籍 | 英国(现居澳大利亚) |
| 核心成就 | 在企业架构领域将DACI决策框架系统化推广——DACI(Decision/Driver/Approver/Contributor/Informed)为评审门提供明确的角色分工模型；著《Mapping the Enterprise》 |
| 思维模型 | **角色即责任**：评审门如果角色不清，就会变成"全员负责=无人负责"；DACI明确谁做决策(A)、谁推进(D)、谁提供建议(C)、谁被告知(I)——评审不只是"开会"，是需要角色预设的结构化决策 |
| 行动范式 | 架构思维+可视化：用映射图(Mapping)呈现组织中的决策流；关注"元级别"——评审门本身也需要被设计，而非默认继承 |
| 可学习点 | 评审门效率低下的根因往往是"谁拍板"不明确——DACI必须前置定义；每个门都需要一个Approver(决策者)，否则评审就沦为讨论会 |
| 代表作 | 《Mapping the Enterprise》/Tetradian博客/DACI框架推广文章 |
| 来源 | 📚中 |

### 4. 邱昭良

| 维度 | 内容 |
|---|---|
| 身份 | 组织学习与复盘专家/中国复盘方法论推广第一人 |
| 国籍 | 中国 |
| 核心成就 | 系统化引入并本土化"复盘"方法论，著《复盘》成为中文复盘实践标准；将军事复盘→商业复盘→产品复盘做了三级落地改造；培训数千家企业建立复盘机制 |
| 思维模型 | **结构化复盘四步法**：回顾目标→评估结果→分析原因→总结规律——复盘门(第四门)不是"总结会"而是"决策改进会"；复盘的核心产出是"可复用的规律"而非"记流水账" |
| 行动范式 | 从解放军"战后复盘"传统吸取精华，结合PDCA循环；强调"复盘的敌人是自我辩护"——必须区分"事实"与"解释"；工具化输出：复盘画布、复盘模板 |
| 可学习点 | 复盘门是评审门体系中最容易被"走过场"的门——需要结构化四步法而非随意聊；复盘门的价值在于"规律复用"，没有规律输出就是浪费时间 |
| 代表作 | 《复盘》《复盘+：把经验转化为能力》 |
| 来源 | 🔍高 |

### 5. Marty Cagan（马蒂·卡根）

| 维度 | 内容 |
|---|---|
| 身份 | SVPG创始人/产品管理顾问 |
| 国籍 | 美国 |
| 核心成就 | 著《Inspired》《Empowered》，定义"产品发现+产品交付"双轨模型；提出"产品评审的本质是判断而非审批"——评审门应该检验"做对的事"而非"流程走完" |
| 思维模型 | **双轨评审观**：发现轨道的评审关注"这个方向值不值得做"(验证假设)；交付轨道的评审关注"这个方案能不能用"(验证质量)——两扇门的评价标准完全不同，不能混用 |
| 行动范式 | 基于HP/eBay/AOL等大厂实战经验提炼；强调"产品团队"而非"项目团队"——团队对结果负责而非对流程负责；反对"以PRD为核心的评审"，主张以原型和用户反馈为核心 |
| 可学习点 | 评审门最大的变异是"从质量门槛退化为流程章"；PM在评审中的角色是"捍卫用户价值"而非"催流程过门"；PRD不是评审门的核心交付物——原型+用户测试结果才是 |
| 代表作 | 《Inspired》《Empowered》/SVPG博客 |
| 来源 | 🔍高 |
