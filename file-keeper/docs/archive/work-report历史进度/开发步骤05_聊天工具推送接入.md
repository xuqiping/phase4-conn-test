## 4. 详细任务

### 4.1 推送服务接口

创建 `PushService` 接口和 `PushResult`：

```java
public interface PushService {
    boolean supports(Platform platform);
    PushResult push(WorkReport report, ReportPushTarget target);
}

public record PushResult(boolean success, String message, String response) {}

public enum Platform {
    FEISHU, DINGTALK, WECHAT_WORK, SLACK
}
```

### 4.2 飞书推送实现

创建 `FeishuPusher`：

```java
@Component
@RequiredArgsConstructor
@Slf4j
public class FeishuPusher implements PushService {

    private final RestTemplate restTemplate;
    private final CredentialEncryptor credentialEncryptor;

    @Value("${work-report.feishu.api-base:https://open.feishu.cn/open-apis}")
    private String feishuApiBase;

    @Override
    public boolean supports(Platform platform) {
        return platform == Platform.FEISHU;
    }

    @Override
    public PushResult push(WorkReport report, ReportPushTarget target) {
        try {
            FeishuCredential credential = parseCredential(target.getCredential());
            String tenantAccessToken = getTenantAccessToken(credential);

            String url;
            Object requestBody;

            if ("GROUP".equals(target.getTargetType())) {
                url = feishuApiBase + "/message/v4/send/";
                requestBody = Map.of(
                    "chat_id", target.getTargetId(),
                    "msg_type", "text",
                    "content", Map.of("text", buildMessage(report))
                );
            } else {
                url = feishuApiBase + "/message/v4/send/";
                requestBody = Map.of(
                    "open_id", target.getTargetId(),
                    "msg_type", "text",
                    "content", Map.of("text", buildMessage(report))
                );
            }

            HttpHeaders headers = new HttpHeaders();
            headers.setBearerAuth(tenantAccessToken);
            headers.setContentType(MediaType.APPLICATION_JSON);

            ResponseEntity<String> response = restTemplate.postForEntity(
                url,
                new HttpEntity<>(requestBody, headers),
                String.class
            );

            if (response.getStatusCode().is2xxSuccessful()) {
                return new PushResult(true, "推送成功", response.getBody());
            } else {
                return new PushResult(false, "推送失败: " + response.getStatusCode(), response.getBody());
            }
        } catch (Exception e) {
            log.error("飞书推送异常", e);
            return new PushResult(false, "推送异常: " + e.getMessage(), null);
        }
    }

    private String getTenantAccessToken(FeishuCredential credential) {
        String url = feishuApiBase + "/auth/v3/tenant_access_token/internal/";
        Map<String, String> body = Map.of(
            "app_id", credential.getAppId(),
            "app_secret", credential.getAppSecret()
        );
        ResponseEntity<Map> response = restTemplate.postForEntity(url, body, Map.class);
        return (String) response.getBody().get("tenant_access_token");
    }

    private String buildMessage(WorkReport report) {
        return report.getTitle() + "\n\n" + report.getContent();
    }

    private FeishuCredential parseCredential(String encryptedCredential) {
        String json = credentialEncryptor.decrypt(encryptedCredential);
        return JsonUtils.parse(json, FeishuCredential.class);
    }
}

@Data
public class FeishuCredential {
    private String appId;
    private String appSecret;
}
```

### 4.4 推送统一入口

创建 `ReportPushService`：

```java
@Service
@RequiredArgsConstructor
public class ReportPushService {

    private final WorkReportService workReportService;
    private final ReportConfigService reportConfigService;
    private final PushDeliveryService pushDeliveryService;
    private final List<PushService> pushServices;

    @Async
    public void pushReport(Long reportId) {
        WorkReport report = workReportService.getEntityById(reportId);
        List<ReportPushTarget> targets = reportConfigService.getPushTargets(report.getConfigId());

        report.setStatus("PUSHING");
        workReportService.updateStatus(report);

        boolean allSuccess = true;
        for (ReportPushTarget target : targets) {
            PushService pusher = pushServices.stream()
                .filter(s -> s.supports(Platform.valueOf(target.getPlatform())))
                .findFirst()
                .orElse(null);

            if (pusher == null) {
                pushDeliveryService.record(reportId, target.getId(), false, "不支持的推送平台", 1);
                allSuccess = false;
                continue;
            }

            PushResult result = pusher.push(report, target);
            pushDeliveryService.record(reportId, target.getId(), result.success(), result.response(), 1);
            if (!result.success()) {
                allSuccess = false;
            }
        }

        report.setStatus(allSuccess ? "PUSHED" : "FAILED");
        workReportService.updateStatus(report);
    }
}
```

### 4.5 推送记录服务

创建 `PushDeliveryService`：

```java
@Service
@RequiredArgsConstructor
public class PushDeliveryService {

    private final PushDeliveryMapper pushDeliveryMapper;

    @Transactional
    public void record(Long reportId, Long targetId, boolean success, String response, int triedCount) {
        PushDelivery delivery = new PushDelivery();
        delivery.setReportId(reportId);
        delivery.setTargetId(targetId);
        delivery.setStatus(success ? "SUCCESS" : "FAILED");
        delivery.setResponse(response);
        delivery.setTriedCount(triedCount);
        pushDeliveryMapper.insert(delivery);
    }
}
```

### 4.6 重试机制

创建 `PushRetryService`：

```java
@Service
@RequiredArgsConstructor
public class PushRetryService {

    private final PushDeliveryMapper pushDeliveryMapper;
    private final ReportPushService reportPushService;

    @Scheduled(fixedDelay = 5 * 60 * 1000) // 每 5 分钟
    public void retryFailedDeliveries() {
        List<PushDelivery> failed = pushDeliveryMapper.selectFailedWithin(
            LocalDateTime.now().minusHours(24)
        );

        for (PushDelivery delivery : failed) {
            if (delivery.getTriedCount() >= 3) continue;
            // 重新推送单个 target
            reportPushService.pushDelivery(delivery);
        }
    }
}
```

### 4.7 手动推送接口

在 `WorkReportClientController` 中增加：

```java
@PostMapping("/reports/{id}/push")
public R<Void> pushReport(
        Authentication auth,
        @RequestParam String deviceId,
        @PathVariable Long id) {
    if (!checkModuleAuth(auth, deviceId)) {
        return R.fail(ErrorCode.FORBIDDEN, "未授权访问工作汇报模块");
    }
    AuthPrincipal principal = (AuthPrincipal) auth.getPrincipal();
    WorkReport report = workReportService.getEntityByUserAndId(principal.userId(), id);
    reportPushService.pushReport(report.getId());
    return R.ok();
}
```

## 8. 风险与注意事项

| 风险 | 说明 |
|---|---|
| 飞书应用申请/审核延迟 | 提前申请飞书企业自建应用，MVP 可用 webhook 方式过渡 |
| tenant_access_token 过期 | token 有效期 2 小时，需要缓存并自动刷新 |
| 消息内容过长被截断 | 飞书文本消息有长度限制，超长时考虑分段或转卡片消息 |
| 凭据密钥泄漏 | `WORK_REPORT_CREDENTIAL_KEY` 必须放在环境变量，禁止硬编码 |
| 重试风暴 | 限制重试次数和窗口期，避免频繁调用平台 API |
