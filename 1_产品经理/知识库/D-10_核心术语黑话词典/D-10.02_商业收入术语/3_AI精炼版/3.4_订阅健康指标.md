# 3.4 订阅健康指标

## ARR/MRR：SaaS的北极星

### 口径拆解

```
ARR = MRR × 12

MRR = 当月所有活跃订阅的月费之和
    = 新增MRR + 增购MRR - 降级MRR - 流失MRR
```

### MRR构成四要素

| 要素 | 英文 | 口径 | 何时为正/负 |
|---|---|---|---|
| 新增MRR | New MRR | 新客户首月订阅费 | 始终为正 |
| 增购MRR | Expansion MRR | 现有客户升级/加购 | 始终为正 |
| 降级MRR | Contraction MRR | 现有客户降级 | 始终为负 |
| 流失MRR | Churn MRR | 客户完全取消 | 始终为负 |

**MRR变化公式**：
`期末MRR = 期初MRR + 新增MRR + 增购MRR - 降级MRR - 流失MRR`

> [来源:SaaS行业通用 | 置信度:🔍高]

### ARR/MRR常见口径陷阱

| 陷阱 | 具体表现 | 修正方案 |
|---|---|---|
| 非经常性收入计入MRR | 一次性实施费/咨询费计入MRR | MRR只含经常性订阅，一次性收入单独列 |
| 试用转正未区分 | 试用期间的MRR虚低 | 用"Committed MRR"（含试用期预计转正） |
| 折扣/促销冲减不清晰 | 年费9折但MRR按原价报 | MRR按实际收款口径 |
| 汇率影响未剔除 | 海外业务MRR因汇率波动 | 报Constant Currency MRR |

> [来源:作者总结+SaaS最佳实践 | 置信度:📚中]

## NRR：SaaS融资最重要的单一指标

### 什么是NRR？

```
NRR = (期初客户群在期末的收入) / (期初客户群在期初的收入) × 100%

分子 = 期初客户群的期末收入（含增购-降级-流失）
分母 = 期初客户群的期初收入
```

**NRR的核心含义**：就算你一个新客户都不签，现有客户群明年值多少钱？

### NRR的行业基准

| NRR值 | 含义 | 常见于 |
|---|---|---|
| < 80% | 产品有根本性问题（流失远超增购） | 不成熟的SaaS |
| 80-100% | 流失被增购部分抵消 | 中等SaaS |
| 100-110% | 增购超过流失，客户群自然增长 | 优秀SaaS |
| 110-130% | 严重依赖增购，产品粘性极强 | 顶级SaaS（Snowflake/Datadog） |
| > 130% | 极罕见，通常伴随初期定价过低 | 少数早期高速增长SaaS |

> [来源:SaaS Capital研究报告+公开财报 | 置信度:🔍高]

### NRR vs GRR

| 维度 | NRR | GRR |
|---|---|---|
| 含增购 | 是 | 否 |
| 含降级 | 是 | 是 |
| 含流失 | 是 | 是 |
| 数值 | 高（增购拉高） | 低（无增购对冲） |
| 衡量 | 总体收入健康度 | 产品留存力（底线健康） |
| 融资关注 | 更被看重 | 作为安全底线补充 |

**关键洞察**：NRR>100%只说明增购>流失，不代表没有流失问题。GRR才是底线的真实反映。
