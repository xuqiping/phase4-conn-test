# 认证系统增强 · 用户操作手册

> Phase 3 产物。终端用户傻瓜式操作步骤——每步点哪、输什么、界面怎么变。
> Phase 4 按本手册逐项验证。功能入口：浏览器打开平台地址 → `/login`。

## 功能入口

| 功能 | 入口 |
|---|---|
| 登录/注册/找回密码 | 登录页 `/login`（三 Tab：账号密码 / 手机验证码 / 扫码登录） |
| 邮箱激活 | 点激活邮件里的链接（跳 `/verify-email?token=xxx`） |
| 重置密码 | 点重置邮件链接（跳 `/reset-password?token=xxx`）或输短信码 |
| 安全设置 | 登录后 → 右上角头像 → 设置 → 「安全」标签页 |

---

## 一、账号密码登录（默认通道）

1. 打开 `/login`，默认在「账号密码」Tab。
2. 输入用户名 + 密码 → 点「登录」。
3. **界面变化**：登录成功跳转首页（默认 `/chat`）；密码错提示「用户名或密码错误」。
4. **连续输错 3 次**：第 4 次弹出滑块验证，拖动滑块对准缺口后才能继续登录。

## 二、注册（账密通道）

1. 登录页点「注册账号」链接 → 弹出注册弹窗。
2. 填用户名 + 邮箱 + 密码 + 确认密码。
   - 密码规则：6-100 位，须同时含大写/小写字母、数字、特殊字符；常见弱密码（如 `123456`、`admin123`）会被拒。
3. **勾选**「我已阅读并同意《用户协议》」（必勾，否则注册按钮禁用）。
4. 点「注册」。
5. **界面变化**：提示「注册成功，请去邮箱验证」→ 弹窗关闭。**此时已可用账号密码登录**（邮箱验证非登录前提）。
6. 收到激活邮件 → 点「验证邮箱」按钮。
7. **界面变化**：跳转激活页显示「邮箱验证成功」。此后该邮箱方可用于找回密码。

## 三、手机验证码登录（新号自动注册）

1. 登录页切到「手机验证码」Tab。
2. 输入手机号（国内 11 位，1[3-9] 开头）。
3. 点「获取验证码」→ **弹出滑块**，拖动对准缺口。
4. 滑块通过后 → **界面变化**：按钮变 60s 倒计时；手机收到 6 位验证码。
5. 输验证码 → 点「登录」。
6. **界面变化**：新号自动注册并登录进首页；老号直接登录。

> **注意**：国际号（如 +852）被拒；60s 内不可重发；验证码错误 5 次作废需重新获取。

## 四、微信扫码登录（需管理员开启）

1. 登录页切到「扫码登录」Tab。
2. 点「微信登录」按钮 → **跳转微信授权页**。
3. 微信扫码 → 手机点确认。
4. **界面变化**：自动回调跳转回平台首页，已登录（新号自动注册）。

> 若 Tab 无微信按钮 = 管理员未开启微信通道。

## 五、找回密码

### 邮件找回
1. 登录页点「忘记密码」→ 弹出找回弹窗。
2. 选「邮箱」渠道 → 输账号（用户名/邮箱/手机号均可）→ 点「发送」。
3. **界面变化**：提示「若账号存在，重置链接已发送」（**无论账号是否存在都这句**，防探测）。
4. 收重置邮件 → 点「重置密码」按钮 → 跳转 `/reset-password`。
5. 输新密码 + 确认 → 点「重置」。
6. **界面变化**：提示成功 → 用新密码登录。**所有旧设备已被踢下线**。

### 短信找回（需绑手机）
1. 找回弹窗选「短信」→ 输已绑手机的账号 → 发送。
2. 收 6 位码 → 在重置页输码 + 新密码 → 重置。

> **未验证邮箱不可找回**：注册填了邮箱没激活的，选邮件找回不会收到邮件（仍提示统一话术）。

## 六、安全设置（登录后）

入口：右上角头像 → 「设置」→ 第一个标签「安全」。

### 6.1 查看我的登录方式
- **界面**：卡片列出当前所有凭证（账号密码 / 邮箱 / 手机 / 微信），每条显示脱敏标识（如 `138****8000`、`a***@x.com`）+ 验证状态标签（已验证/未验证）。

### 6.2 绑定邮箱
1. 点「+ 绑定邮箱」→ 弹窗输邮箱 → 点「确认绑定」。
2. **界面变化**：提示「绑定成功，请查收激活邮件」→ 列表多一条 EMAIL（未验证）。
3. 收激活邮件点链接 → 列表该条变「已验证」。
4. **冲突**：邮箱已被其他账号绑 → 提示「该邮箱已被其他账号绑定」。

### 6.3 解绑
1. 在要解绑的凭证行点「解绑」→ 弹确认框。
2. 点「确认解绑」。
3. **界面变化**：列表该条消失（解绑走软删，后台留审计痕）。
4. **限制（Phase 4 实测确认）**：
   - 密码凭证不可解绑（提示「密码凭证不可解绑，请使用修改密码功能」）
   - 非密码凭证（邮箱/手机/微信）仅剩 1 种时，解绑按钮置灰「不可解绑」+ 下方提示「仅剩一种登录方式时不可解绑」
   - 强行调接口解绑最后一种 → 服务端拒（42204「至少保留一种登录方式」）

### 6.4 修改密码
1. 「修改密码」卡片：输当前密码 + 新密码 + 确认新密码。
2. 点「修改密码」。
3. **界面变化**：提示「密码修改成功，请重新登录」→ **自动退出跳转登录页**（所有设备被踢下线，旧设备再调接口提示「账号已在别处登录」）。
4. 用新密码登录。
5. **校验（Phase 4 实测确认）**：
   - 旧密码错 → 提示「当前密码不正确」
   - 新旧相同 → 拒
   - **弱密码拒收**：新密码在常见弱密码字典内（如 `admin123`、`password123`、`12345678`）→ 提示「密码过于常见，容易被猜到」
   - 强度不足 → 提示「须同时包含大写字母、小写字母、数字和特殊字符」

## 常见异常与恢复

| 现象 | 原因 | 恢复 |
|---|---|---|
| 激活链接点开提示「无效或已过期」 | token 超 24h 或已用过 | 登录页点「重发激活邮件」 |
| 短信收不到 | 60s 限频 / 阿里云故障 / 号码错 | 等 60s 重试；检查号码 |
| 改密后被踢下线 | 正常（踢所有会话） | 用新密码重新登录 |
| 解绑按钮灰色 | 仅剩一种登录方式 | 先绑定其他方式再解绑 |
| 邮箱找回收不到邮件 | 邮箱未验证 / 账号不存在 | 先登录去设置页验证邮箱 |

## 7. 注册（12x B1 起：邮箱验证码必填）

> **2026-08-23 开关回退**：本节流程仅在管理员打开「邮箱验证总开关」（设置 → 认证通道 → 邮件通道）后生效。
> 开关**关（默认）**时：注册页无验证码行，邮箱**可选填**（填了可在安全设置里后验），直接注册即可。

1. 登录页点「立即注册」→ 弹注册窗。
2. 填用户名 → 填邮箱 → 点「**获取验证码**」（按钮变 60s 倒计时）。
3. 去邮箱收信（主题「注册验证码」），把 **6 位数字码**填进「邮箱验证码」（10 分钟内有效，错 5 次作废需重发）。
4. 填密码 + 确认密码 → 勾协议 → 点「注册」。
5. **界面变化**：提示「注册成功，请登录」→ 弹窗关闭，用户名自动带入登录框。
6. **完成标志**：邮箱注册即已验证，可直接用于找回密码（不再有注册后点激活链接的步骤）。
7. **常见异常**：
   - 「邮件通道未开启，暂无法注册」→ 平台邮件服务未配置，联系管理员（注册整体暂停是刻意保护）。
   - 「该邮箱已被注册」→ 直接登录或用「忘记密码」找回。
   - 「验证码已过期/错误次数过多」→ 重新点「获取验证码」。

## 8. 渐进式滑块（12x B2）

- **触发**：登录（同账号）/注册、发码、找回密码（同 IP）连续失败 **2 次**后，页面自动出现滑块拼图。
- **操作**：拖动滑块拼合缺口 → 再点原按钮（登录/注册/发送）。
- **界面变化**：滑块区在按钮上方出现，带提示「失败次数过多，请完成滑块验证后再试」；未过滑块按钮置灰。
- **解除**：任意一次成功（登录成功/发码成功）即清零回归无验证态；或等 30 分钟自然解除。
- **注意**：滑块结果单次有效——每次提交后需重新滑一次（防重放设计）。

## 9. 充值前必须验证邮箱（12x B5）

> **2026-08-23 开关回退**：本门仅在「邮箱验证总开关」打开时生效；开关关（默认）时充值不校验邮箱。

1. 未绑定/未验证邮箱的账号在「我的钱包 → 充值」下单时，会被拒并提示「充值前请先绑定并验证邮箱」。
2. 点错误框里的「**去「设置 → 安全设置」绑定邮箱 →**」链接直达绑定页。
3. 绑定并完成验证后，回来重新下单即可。
4. **原因**：积分=钱，丢号=丢钱；已验证邮箱是找回账号（和余额）的最后通道。

## 10. 管理员：接入腾讯邮箱发信（12x A，设置 → 认证通道 → 邮件通道）

1. 通道类型选「**SMTP**」。
2. 填四要素（QQ 邮箱：`smtp.qq.com` / 端口 `465` / SSL 开 / 用户名=完整 QQ 邮箱地址 / 授权码=QQ 邮箱设置→账户→开启 SMTP 后给的 16 位码；企业邮：`smtp.exmail.qq.com` / 同 465 / 用户名=完整企业邮地址 / 客户端专用密码）。
3. 先点「**测试发信**」填自己邮箱收一封——收到再打开「启用」开关（先测通再上线）。
4. **密钥安全**：授权码只在该页面填，AES 加密落库，回显只显尾巴；别进群、别截图发第三方、别提交进 git。
5. **日封顶**：默认全平台 500 封/天（`auth.channel.mail.daily-cap` 可调）——防被盗后轰炸导致发信账号被服务商封禁。
6. **邮箱验证总开关**（同页，2026-08-23 新增）：测试发信确认收到后再翻开。开 = 注册强制邮箱验证码（§7）+ 充值需已验证邮箱（§9）整体生效；关（默认）= 注册邮箱可选填不验码、充值不卡邮箱——人工测试期保持关。

## 11. 邮箱也能登录了 + 忘记密码怎么用（2026-08-25）

**邮箱登录**：密码登录框现在支持「用户名或邮箱」——注册时填过的邮箱 + 同一个密码即可登录，不用背用户名（大小写不敏感）。

**忘记密码（重置密码）**：
1. 登录页点「忘记密码」，输入**用户名或邮箱**（绑定了手机的账号也可用手机号）。
2. 系统把重置链接发到你的邮箱（没有配置邮件通道的环境请联系管理员重置）。
3. 打开邮件里的链接进入重置页（地址形如 `{前端域名}/reset-password?token=...`，如 `http://localhost:5173/reset-password`），填新密码提交。
4. 重置成功后用新密码登录；旧密码立即失效。
- 注意：邮件里的链接有时效，过期重新走「忘记密码」再收一封即可。

## 2026-08-26 增补
- **重置邮件里链接可直接复制**：部分邮箱客户端里长链接显示不全点不动——邮件底部新增灰底纯文本链接块，点击无效时选中复制到浏览器打开即可。
- **直接打开重置页不再死白屏**：不点邮件链接、自己导航到 `/reset-password` 时，页面按当前环境给出引导：开了短信通道→直接出手机号重置表单；开了邮件通道→提示「请从重置邮件里的链接进入」，附「去登录页重新发送」按钮；邮件通道关闭→提示「请联系管理员重置密码」。持有有效链接 token 进入的不受影响，直接出密码表单。
- **用户备注（备注信息）**：注册页「备注」、登录后「设置 → 个人信息 → 备注」、管理员「用户管理 → 编辑」三处都能填/改备注（本人只能改自己的；管理员可改任何人的）。管理员用户列表新增「有备注」筛选开关，可快速筛出填过备注的账号。备注仅用于运营标记，不影响任何功能权限。

## 2026-08-26 增补（修复III：锁定解锁/姓名）
- **账号被锁能看到解封时间**：密码错太多次锁 15 分钟——登录报错直接写「账号已锁定，将于 MM-dd HH:mm 自动解锁，可联系管理员提前解锁」，不用干等猜。
- **管理员提前解锁**：用户管理 → 状态=锁定的行 →「解锁」→ 确认弹窗显示锁定到期时间 → 确认后该用户**立即可登录**，审计记「提前解锁账号」。注意：封禁/禁用的行没有解锁按钮（那是另一种状态，走「启用」）。
- **管理员改姓名**：用户管理行「姓名」按钮（≤64 字，留空=清除）；本人也可在 设置→个人信息 改（同样 64 字上限）。改名后项目组成员表、组产出等处显示「姓名（账号）」，留空回落账号名。
