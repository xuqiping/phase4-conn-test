## 四、坑/沉淀（待入通用约束）

- **缺路由返 500 非 404**：Spring Boot 3.2 NoResourceFoundException 被全局 `@RestControllerAdvice` `@ExceptionHandler(Exception.class)` 兜底返 500。404 契约测不能 `isNotFound()`，改断言「≥400 = 旧 2xx 业务通路已断」。沉淀：**删端点后失效断言用 isError 非 isNotFound**。
- **Edit 工具与 CRLF 不匹配**：Windows 工作树 CRLF，大块 Edit old_string 匹配失败 → 改用 Write 整文件重写（chat.ts/MemoryManagerPanel）。沉淀：**Windows CRLF 下大段替换优先 Write 整文件**。
- **store 轮询改 no-op 保签名**：删 API 方法后，引用其返回值的 store ref 不能直接删（模板依赖）→ 保留 ref 恒默认值 + 函数体 no-op，零网络请求零 404。沉淀：**死 API 调用拆「删调用体/保签名」两步，避免波及模板**。
