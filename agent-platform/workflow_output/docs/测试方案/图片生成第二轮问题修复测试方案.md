# 图片生成第二轮问题修复 · 测试方案

> 谁测：人工（UI 交互 + 真实生图链路）。前置：后端含 kind 过滤（a120ad1）、前端含历史区四能力（8d04518b）；IMAGE provider + 两模型价表已配（见 user-ops 前置节）；账号有 media:gen 且积分充足。
> 自动化已覆盖（免人工）：kind 白名单 400（后端 4 用例）、parseImageRestore 9 边界、缩略组件懒加载/revoke 4 用例、vue-tsc。

## 联动用例（对齐 plan L1-L7，含反向）

| # | 步骤 | 预期 | 对应联动 |
|---|---|---|---|
| C1 | 图片生成页生成 1 张图 → 切到**视频生成页**看历史 | 图片任务**不出现**在视频历史（反向：旧前端/第三方不传 kind 仍返回全量，向后兼容） | L5 |
| C2 | 回图片页，历史区输提示词子串（如「猫」） | 300ms 后列表收窄，只显命中行；**清空**→恢复全量（反向） | L4 |
| C3 | 时间范围选昨天~今天 / 上周~上月 | 列表按区间收窄/变空（显「无匹配」占位）；清空恢复 | L4 |
| C4 | 快速连输「猫」→「猫咪」 | 最终只显「猫咪」结果（竞态守卫，旧响应被丢弃） | L4 |
| C5 | 历史区滚动浏览 | 成功行右侧出 56px 首图缩略（滚入视野才加载）；FAILED/PENDING 行显「—」占位；组图任务只取首图 | L7 |
| C6 | 点缩略图 | 弹灯箱放大；**不触发**行点击（结果区不切换） | L7 |
| C7 | 生成一条 pro+参考图+自定义尺寸+guidance 7+fast 的任务 → 完成后点该行 | ①结果区出图（L1）②左侧表单全还原：模型/prompt/尺寸 `__custom__`+原文/guidance 7/fast/水印/参考图缩略回来（L2 正向）③**不自动提交** | L1/L2/L3 |
| C8 | 点一条 lite 组图（sequential=auto，4 张）历史行 | sequential 选「自动组图」且**张数输入框显示**为 4；组图/联网控件按 lite 显 | L2 |
| C9 | C7 还原后点「生成图片」 | 正常提交新任务，参数与还原一致（历史多一条） | L3 |
| C10 | 结果区点「请求参数」→ 两个页签 | 「平台收到的提交参数」页签 JSON 含 prompt/size/refFileIds；「实际发给模型」页签显「未记录发送快照」（图片路径无快照，不冒充）；复制 JSON 按钮可用 | L6 |
| C11 | 还原含参考图的任务后，去资产库删掉其中一张参考图 → 再点该行 | 失效张跳过，toast「N 张参考图已失效」；其余正常回填（L2 反向） | L2 |
| C12 | （可选，admin 配合）下线历史用过的模型 → 点该历史行 | 显「模型已下线」警告条；表单控件隐藏无法提交；「请求参数」弹窗仍可核对（L2 反向） | L2 |
| C13 | 筛选出结果后切换页面再回来 / 关页面 | 无报错；DevTools Memory 无 blob: URL 泄漏（卸载 revoke） | L4/L7 |

## 异常与边界

| 现象 | 预期 |
|---|---|
| 手改 URL `?kind=AUDIO` 调 /api/media/tasks | 400「kind 仅支持 IMAGE/VIDEO」（已自动化，抽查即可） |
| 非本人任务 id 手调 getTask | 403（既有门控，抽查） |
| 缩略图文件被删 | 该槽显「无预览」，不影响行点击 |

C1-C13 全过；无控制台报错；历史区交互流畅（防抖无闪烁）。
