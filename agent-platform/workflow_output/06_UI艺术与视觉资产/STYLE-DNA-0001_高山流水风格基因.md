# STYLE-DNA-0001 高山流水 · 风格基因

> 产物编号：STYLE-DNA-0001 ｜ 状态：定稿 ｜ 上游：ART-DIR-0001
> 用途：AI 生成与人工实现的**同一份真值源**——任何页面/组件/资产产出前逐条对照。

## 一、风格公式（修订 2026-08-28：去水墨，转现代东方）

```
高山流水 = 留白构图(≥35%) + 低饱和传统色(黛蓝/宣纸/天青/朱砂) 
         + 现代雾感语言(柔和渐变/雾感模糊层/极简山形剪影) 
         + 思源黑体正文×霞鹜文楷标题
         + 云雾缓动(150/300/400ms) + 诗意文案(仅品牌位)
```

**已移除**：泼墨、枯笔飞白、宣纸/绢纹理、水墨晕染颗粒——意境保留，传统绘画肌理不用。

## 二、七条可执行基因

1. **淡**：同色系低饱和；任何颜色饱和度感知高于天青即违规（状态色除外）。
2. **远**：纵深靠"远山叠影"——多层低透明度山形剪影/柔影，不用透视、不用 3D、不用水墨笔触。
3. **空**：留白是主角；新增一个装饰元素前必须先问"去掉它页面是否依然成立"，成立则不加。
4. **逸**：书法只在标题与空状态；装饰元素仅限极简山形、云雾渐变、印章——无笔触感。
5. **稳**：信息架构、交互流程、组件状态优先级永远高于风格表达；风格绝不改动行为层。
6. **明**：正文对比度 ≥4.5:1；纹理永远在文字之下；任何"好看但看不清"的方案直接判负。
7. **时**：时间感——晨昏、云雾缓动；禁止急促、闪烁、弹跳。

## 三、正面示例（Do）

- 登录页：极简山形 + 云雾柔光大背景 + 印章 Logo + 行书 Slogan「高山流水，静候知音」+ 柔光登录卡片。
- 空状态：现代极简山水插画（渐变雾感，非水墨）+ 行书短句 + 直白引导按钮（例：「空山无人，水流花开」+「创建你的第一个 Agent」）。
- 工作台首屏：晨昏云雾背景层 + 问候语随时间变化（晨「晨光熹微」/暮「暮色四合」）。
- 卡片 hover：微光提亮（+3%）+ 2px 抬升，300ms 云雾缓出。

## 四、反面示例（Don't，含已否决方案）

- ❌ 现 deep-space 主题（蓝紫渐变玻璃拟态）——通用 SaaS 模板感，本次淘汰对象。
- ❌ 水墨画质感（泼墨背景、宣纸颗粒纹理、枯笔分隔线）——用户裁定不现代，已全部移除。
- ❌ 把侧边栏做成卷轴展开动画——拖慢核心流程，违反基因 5。
- ❌ 表格行用宣纸黄底 + 墨绿字——对比度 3.1:1，违反基因 6。
- ❌ 每页页脚放山水画横幅——装饰堆砌，违反基因 3。
- ❌ 成功 Toast 用朱砂红——与错误色混淆，状态语义不可侵占。

## 五、冲突仲裁顺序

信息可读 > 操作效率 > 状态可辨 > 文化意境 > 装饰表达。任何两层冲突，排前者胜。
