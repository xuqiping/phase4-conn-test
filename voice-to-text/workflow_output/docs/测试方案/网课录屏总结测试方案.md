# 网课录屏总结 · 人工测试方案

> Phase3-A 判定：本功能涉及**录屏交互 / 实时字幕体感 / 真实云端 API / 2h 端到端** → 需人工测试。开发时照此自验，Phase 4 照此验收。
> 能自动化且可断言的（session 目录、对齐算法、pHash 去重等）走单元测试，不在本方案。

## 前置条件

- Windows 10/11；有独显（NVENC 硬编）或可触发软编兜底的机器
- 网课窗口素材：① PPT 翻页课 ② 白板书写课 ③ ≥2h 长课
- 云端 LLM：用户自有 OpenAI 兼容 **API Key + Base URL + 文本模型名**（多模态精修另需视觉模型名）
- sherpa-onnx 流式模型、RapidOCR 引擎已就位
- feature flag「网课录屏总结」已开启

## 功能联动用例（v1.9 硬要求 · 横切清单 L1-L8 逐条）

> 每条必须覆盖 **正向 / 反向 / 边界**。联动 = 触发动作 → 联动对象变化。

| 联动 | 步骤 | 预期（正向） | 反向 / 边界（必测） |
|---|---|---|---|
| **L1 停止录制** | 录制中点「停止」 | 状态 `Recording→Processing`；自动开始 抽帧→OCR→对齐→总结 | ①录制中关闭/最小化目标窗口（中断）→保留已录片段+提示，仍可部分处理；②录制至磁盘满→停止+提示，不进处理 |
| **L2 多模态精修开关** | 总结面板切「多模态精修」ON | 弹二次确认「将上传课件图到 {provider}」；确认后分段附图给 VLM | ①OFF→仅传文字；②确认弹窗点取消→保持 OFF；③已有总结**不自动重算**（需手动重新生成） |
| **L3 重新生成** | 点「重新生成」全局/单段 | 覆盖草稿，旧版进版本历史 | ①生成中再点→忽略/排队；②失败→保留旧草稿不覆盖；③单段→只换该段，其余不动 |
| **L4 选中时间轴章节** | 学习区点某章节 | 右侧切该章节要点+课件帧；视频跳章节起点 | ①无选中→空态提示；②章节无要点→「本段无总结」 |
| **L5 点时间戳/课件帧** | 点要点时间戳或课件帧 | 视频跳该时刻+高亮对应帧 | ①原视频已删→「原视频已删除，仅可查看帧」 |
| **L6 feature flag 关闭** | 关闭「网课录屏总结」flag | 入口隐藏，回到纯录音转文字 | ①再开启→入口恢复；②已有会话数据保留，可再访问 |
| **L7 切换会话** | 会话列表切到另一会话 | 时间轴/总结/课件帧重新加载 | ①有未保存编辑→提示保存（草稿态确认） |
| **L8 导出** | 点「导出」选 Markdown | 生成 MD 到 `exports/` | ①磁盘不足→提示；②同名覆盖→确认 |

## 端到端关键场景（Phase 4 必测）

1. **2h 网课全流程**：选窗口录制 → 实时字幕 → 停止 → 自动抽帧/OCR/对齐 → 云端总结 → 学习区 → 导出 MD。验收：音画同步、抽帧合理（PPT 翻页召回 >90%、白板 <200 帧/h）、对齐正确、总结无丢段（map-reduce）、导出可用。
2. **降级矩阵**：①无变化帧→5min 固定窗分段 ②OCR 失败→`ocr_text=null` 不阻塞 ③转写某段缺失→标「无讲解文字」 ④云端 API 断网/限流/Key 无效→友好降级+文本保留。
3. **容错四件套**（FR-109）：可解释（要点带时间戳+帧回链）/ 可纠错（regenerate 单段+全局）/ 可撤销（草稿态确认才落库）/ 可降级（API 失败兜底）。

## 运维埋点核对（横切 O1-O7，开发期对照 · 写码当下就埋）

- [ ] **O1 可观测**：capture/ocr/align/summary 各阶段耗时+状态日志；traceId=会话目录名；前端关键事件埋点（采纳/重写/完成/各阶段进入）
- [ ] **O2 配置开关**：feature flag 控入口显隐；抽帧阈值（直方图/汉明距离）、API 并发度可配
- [ ] **O4 限流熔断降级**：云端 API 超时/限流→重试+降级（文本兜底）+友好报错；本地阶段失败→阶段化重试
- [ ] **O5 运维入口**：学习区「重新总结」=手动重试；会话管理可清理脏目录/补处理
- [ ] **O7 容量性能**：sessions/ 累积→「导出后删原视频」+清理；2h 切 15min 片；OCR/抽帧结果缓存避免重算
- （O3 数据层天然可逆；O6 桌面单机不做服务端告警——已在横切清单判定「不做」）

## 通过标准

- 联动用例 **L1-L8 全绿**（含每条反向/边界）
- 端到端 2h 场景通过；降级矩阵 4 条 + 容错四件套 4 条路径全验证
- 性能：2h 录后处理 P95 < 8min；总结单段 API P95 < 15s；录制中转写延迟仍 < 2s
- 安全：默认仅传文字、多模态二次确认、Key 不泄漏、录屏前提示
- **回归**：现有「纯录音转文字」功能不受影响
- 与 spec **AC-101~109** 逐条对齐（见 spec 第七章，plan 主表索引）
