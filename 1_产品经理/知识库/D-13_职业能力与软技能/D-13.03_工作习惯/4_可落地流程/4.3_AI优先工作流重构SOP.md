# AI优先工作流重构 SOP

## 适用场景
传统PM希望用AI工具提升日常效率，但不清楚从哪里开始或如何系统化。

## 前置条件
- 有1个可用的AI对话工具（ChatGPT/Claude/豆包等）
- 愿意尝试新工作方式

## 步骤（7步，2周完成）

### Step 1 审计现有工作（Day 1-2）

列出你日常所有工作项，标记每项的"重复性"和"AI可替代性"：

| 工作项 | 频率 | 耗时 | 重复性 | AI可替代性 |
|---|---|---|---|---|
| 写PRD | 每周2次 | 3h/次 | 高 | 高（初稿） |
| 竞品分析 | 每月1次 | 4h | 中 | 中（数据收集） |
| 会议纪要 | 每天1次 | 30min | 高 | 高 |
| 需求评审 | 每周3次 | 1h | 低 | 低 |
| 数据报表 | 每周1次 | 2h | 高 | 高 |
| ... | | | | |

### Step 2 选Top3最高ROI项（Day 3）

从"高重复+高AI可替代"中选3个作为AI化起点：
- ROI = 每周节省时间 ÷ 学习成本

### Step 3 学AI用法（Day 4-5）

对选出的3项，学习AI最佳用法：
- **PRD**：给AI口述需求→AI出初稿→你精修
- **会议纪要**：用AI转录+要点提取
- **数据报表**：AI生成SQL/图表→你判断

### Step 4 实践+记录效率差（Week 1）

每项工作做了后记录：
- 传统方式耗时 vs AI辅助耗时
- 质量差异（AI版是否需要大量修改）
- 体验感受（顺畅/卡点）

### Step 5 迭代提示词（Week 1-2）

对效果不好的任务，优化提示词：
- 更具体的背景信息
- 更清晰的输出格式要求
- 多轮对话逐步完善

### Step 6 固化新习惯（Week 2）

- 把"AI优先"加入每天第一个动作：碰到重复任务→先想"AI能不能做"
- 在知识库中沉淀有效的提示词模板
- 分享给团队→放大效率收益

### Step 7 持续扩展（Week 2+）

- 每2周审视一次：哪些新任务可以AI化
- 关注AI工具更新：新工具新能力可能覆盖更多场景
- 警惕AI依赖：核心判断力不能外包给AI

## AI辅助典型场景提示词模板

### PRD初稿

```
我需要写一个{{功能名}}的PRD。背景是{{业务背景}}。目标用户是{{用户}}。
核心需求是{{一句话描述需求}}。
请按以下结构输出PRD：
1. 需求背景与目标
2. 用户场景与用户故事
3. 功能描述与交互逻辑
4. 数据埋点要求
5. 非功能需求

注意：不确定的信息请标注[待确认]，不要编造。
```

### 会议纪要

```
请根据以下会议内容，提取：
1. 决策事项（谁决定什么）
2. 行动项（谁+做什么+截止时间）
3. 待定事项（需要下次讨论的）
4. 关键分歧点

会议内容：{{粘贴会议转写内容}}
```

## 红线
- AI输出必须人工审核后再发出——不能把AI生成的PRD/分析直接发出去
- 核心判断（需求优先级/产品方向）不能外包给AI
- AI是效率工具不是思维替代——你的价值在判断力不在写文档速度
