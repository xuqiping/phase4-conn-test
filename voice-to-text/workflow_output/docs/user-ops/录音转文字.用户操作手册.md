## 一、安装（首次使用）

### 方式一：MSI 安装包（推荐）

1. 下载 `voice-to-text_0.1.0_x64_en-US.msi`
2. 双击运行，按提示完成安装
3. **下载语音模型**（约 100MB），4 个文件：
   - `encoder-epoch-99-avg-1.onnx`
   - `decoder-epoch-99-avg-1.onnx`
   - `joiner-epoch-99-avg-1.onnx`
   - `tokens.txt`
   - 下载地址：https://huggingface.co/csukuangfj/sherpa-onnx-streaming-zipformer-bilingual-zh-en-2023-02-20/tree/main
4. 放入安装目录 `models/`：
   ```
   C:\Program Files\voice-to-text\models\
   └── sherpa-onnx-streaming-zipformer-small-bilingual-zh-en-2023-02-16/
       ├── encoder-epoch-99-avg-1.onnx
       ├── decoder-epoch-99-avg-1.onnx
       ├── joiner-epoch-99-avg-1.onnx
       └── tokens.txt
   ```

### 方式二：绿色版（免安装）

1. 下载绿色版压缩包并解压
2. 直接运行 `voice-to-text.exe`
3. 确保 `models/` 目录与可执行文件在同一文件夹

> 详细打包/分发见 [部署手册](../deploy/部署手册.md)。

## 二、界面介绍

1. **设备选择** — 下拉选择音频输入源
   - 麦克风设备（如 `Microphone (Realtek Audio)`）
   - 系统音频（如 `[系统音频] 扬声器 (Realtek Audio)`）
2. **开始录音 / 停止录音** — 控制识别开关
3. **同时保存录音** — 勾选后，停止录音时自动保存 WAV 到程序同级目录
4. **转写结果区** — 实时显示识别文字
   - 灰色斜体字 = 临时识别结果（可能变化）
   - 白色正体字 = 已确认结果

## 三、基础用法：麦克风输入

1. 打开应用，确认设备选择为你的麦克风
2. 点击 **「开始录音」**
3. 对着麦克风说话，文字实时出现在上方
4. 点击 **「停止录音」** 结束

## 四、进阶用法：系统音频内录（实时字幕）

1. 在设备选择下拉框中，选择带 `[系统音频]` 前缀的设备
2. 点击 **「开始录音」**
3. 播放任意视频或音频（B 站、YouTube、本地播放器）
4. 应用自动识别电脑播放的声音并转写
5. 点击 **「停止录音」** 结束

> **提示**：系统音频内录仅限 Windows，且需电脑有活跃音频输出设备。

## 五、保存录音

勾选 **「同时保存录音」** 后，停止录音时自动生成时间命名的 WAV（如 `recording_20260507_143022.wav`），保存在程序同级目录。

## 六、常见问题

| 问题 | 原因 / 解决 |
|---|---|
| 打开程序提示缺少 DLL | 用了 NSIS 的 `.exe`，改用 **MSI** 或绿色版 |
| 点击开始录音后闪退 | 检查 `models/` 是否存在、4 个模型文件齐全；看日志 `%APPDATA%\com.ap.voicetotext\logs\` |
| 识别结果一直显示 `[mock] 你好` | 模型加载失败回退演示模式，检查模型路径/完整性后重启 |
| 系统音频设备列表为空 | Windows 音频服务未启动或无活跃输出设备；播放一段音频后再打开应用 |
| 识别准确率不够 | 麦克风音质清晰、避免噪音、正常语速；当前 small 级模型，更高精度待后续更新 |
