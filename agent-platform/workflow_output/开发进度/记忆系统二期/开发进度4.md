## Step3：召回 + 深读（FR-203）

- **`MemoryAssetRecallService`**（新）：`collectFileCards(selectedTagIds, userId)` —— READY 文件记忆按 `tag_ids && #{tagIds}`（LongArrayTypeHandler 真 PG ARRAY，直接 `&&` 无需 cast）命中，上限 10；chunk 计数 GROUP BY 一次查防 N+1；stored_files meta 缺失/非 ACTIVE → `fileCleaned=true, downloadable=false`（「原文件已删除」语义前置到卡片）。
- **pipeline ⑥.5**：`MemoryRecallPipeline` 在 ⑥ patch 后插文件召回块，仅 `scope.personalOn() && 选签非空` 时跑；独立 try/catch 全降级；trace 恒记 `file-recall`/`file-deepread` 两步。装配新增两块：
  - `【文件记忆】`：`- 《名》（类型·共N块·可下载|原文件已删除·file:{fileId}）：{l1}`
  - `【文件深读】`：`- 《文件名》[pageRef]：{chunkText}`（注入话术要求回答引用带页码锚点，D-19.12 幻觉对冲）
- **深读裁决（偏离 plan，见下）**：复用 ③ 选签 LLM 相关性判定 + query 向量在命中记忆 chunks 内 cosine top-5、距离 ≤0.5 过滤噪声（halfvec `<=>` 注解 SQL 裸写）；embed 失败/维度不符 → 降级空深读不崩召回。

## Step4：路由进项目 + ACL 放行（FR-204）

- **READY 钩子**：ingestion 完成 → `routingService.routeAsync(RoutingInput.ofFile(userId, fileId, l1, l2, tagIds))`，复用 P1 收录全链（粗筛→蒸馏→三档分流）；**弱记忆不路由**（无内容蒸馏是噪声）。
- **幂等去重**：同项目同 file_id 已有条目（`countFileEntry`）→ 跳过不重复收录（重试重 ingest 安全）。
- **条目落库**：`content_type=FILE + file_id`，无 sourceTurnId。
- **下载 ACL 放行（咽喉点方案）**：`FileSharedAccessGrantor` 接口（fail-closed 契约）注入 `FileStorageService.loadPath` 归属校验——非 owner 非 admin 时咨询 grantor 链，任一放行即许；**grantor 异常 fail-closed 绝不开门**。实现 `MemoryFileEntryAccessGrantor`：「ACTIVE FILE 条目引用 + 请求者是该条目项目 ACTIVE 成员」单 SQL 裁决。
- **删除闭环**：`DELETE /api/chat/attachments/{memoryId}`（owner 咽喉）→ 分块软删 → 记忆行删 → **项目 FILE 条目全软删标失效** → 原文件硬删。成员随后下载自然回落 403。

## 关键决策 / 偏离 plan

1. **深读不新增 reflect LLM**（plan 写「reflect 判需深读」）：③ 选签已是 LLM 相关性判定，再加一次 reflect 会破「单轮召回最多 2 次 LLM」预算（embed 不计）。改为 ③ 命中 + 向量距离 ≤0.5 双闸门；已在 `MemoryAssetRecallService` javadoc 记为 plan 偏离。
2. **ACL 放行走 loadPath 咽喉点内钩子列表**（非调用方各自判）：/api/files/{id} 下载只有一个咽喉，grantor 列表 Spring 无 bean 注空列表=纯 owner 校验，行为零回归；grantor 抛异常 fail-closed。
3. **卡片「展开第 N 页」落地为「展开分块」**：页码锚点已在 chunk 级（page_ref），前端按锚点列块即等价语义；新增 `GET /attachments/{memoryId}/chunks`（owner 校验）。
4. **附件 chips 状态一次性延迟刷新而非轮询**：ingestion 异步通常秒级，5s 后拉一次列表对齐 READY/FAILED；发送不阻塞等待解析。
5. **FILE_CARDS 同时走流帧 + 消息 metadata 落库**：流帧管即时渲染，metadata 管历史回显（与 citations 同模式）。
