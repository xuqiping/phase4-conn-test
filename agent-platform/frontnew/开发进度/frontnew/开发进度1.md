## 关键决策/偏离记录（对照 plan）

1. **vitest 4 → 3.2.4**（偏离 plan 依赖表）：vitest 4 需 vite 6+（`./module-runner` 导出），本项目锁 vite 5。前端 frontend 用 npm 能侥幸跑，pnpm 严格 peer 下必崩。
2. **n-config-provider 断高度链**：其多渲染一层无 id div，画布塌成 82px。修复：`global.scss` 补 `#app > div { height: 100% }`。
3. **选中跟踪用 getSelectedNodes watch**：vue-flow 1.41 无 `onSelectionChange`（plan 伪码用了），`Node.selected` 联合类型不可达（frontend 同款坑批注）。
4. **Edge filter 触发 TS2589**：改 `removeEdges` API。
5. **状态枚举/连接桩方向对齐 frontend**（spec 三处已修订，原因见 plan 迭代记录）。

## Bug 修复（用户反馈：冷静极简白屏）

- **根因**：NodeCardBase.vue 的 SCSS `:global([data-theme='calm-slate']) &--selected` 写法被编译成**裸选择器** `[data-theme="calm-slate"] { display: none }` 等，直接命中 `<html>` 根节点 → 整页 display:none / 0 尺寸 → 白屏。T2 全塌；T4 部分规则也中招（cineon 因后续 display:block 覆盖侥幸存活）。
- **修复**：去除全部 `:global([data-theme])` 写法，主题差异改走 token 开关（`--stream-display` / `--timeline-display` / `--selected-border-w` / `--timeline-*-w`），4 主题 css 补对应变量。
- **回归防线**：tokens.spec.ts 新增「禁止 :global([data-theme]) 裸选择器」源码断言；浏览器复验 T2 897 高度 + T1 流光 block/T4 时间轴 block 互斥正确。
