### 关键设计落地
- **全走新栈命名空间 `/api/chat/memory/*`**：4 个新 controller（通知/gen-matrix/summaries 挂 summaries 路径/turns 加 list 方法），零 import legacy MemoryController/MemoryService。承 C/D/E/I2 隔离裁决。
- **通知 ACK 权边界**：`user_id`=接收者本人，他人 ACK → 403（向量：通知属个人隐私）；ACK 幂等（where resolved_at IS NULL 命中 0 行不报错）。
- **gen 矩阵双开关模型**：owner 项目级 + 会员覆写 AND；null/无行=默认开（未显式关=开）；effective=AND。一键关 = 前端循环 PUT member（无专用端点，避免冗余）。DEPARTED 不列矩阵。
- **总结/流水账仅本人**：总结恒只读自己（findByUserAndScope user_id=self）；流水账 user_id=self（向量 7/13）。两者 batch 回填 tag/项目名防 N+1。
- **gen 矩阵 mapper 复用 roster 源**：`findMyGenMatrix` 走 memory_project_members join projects + 双 settings 表，单查询出全矩阵。

### 坑修复
- **PG `NOW()` = 事务时间（同事务内同值）**（B-FE-1 IT 顺序断言挂）：通知 IT seed 改 `clock_timestamp()`（语句级）。
- **`queryForObject` 0 行抛 EmptyResultDataAccessException**（B-FE-2 IT assertNull 断言挂）：helper 改 `queryForList` 取首行。
- **PG JDBC 拒 String→bigint[] 隐式转换**（B-FE-4 IT seed）：测试 seed SQL 加 `?::bigint[]` cast（同 E 迭代 IT `::timestamptz` 套路，沉淀已入通用约束）。

## 沉淀（入通用约束）
1. **PG `NOW()` = 事务时间，同事务内多次调用返同值**——测试 seed 需语句级时间基准用 `clock_timestamp()`（事务回滚测尤其）。
2. **MyBatis-Plus 单查询 join 多设置表出矩阵**：gen 矩阵单 SQL 三 LEFT JOIN（members+projects+owner setting+member setting）出全行，null→默认值由 service 解析，避免 N+1 与多次往返。
