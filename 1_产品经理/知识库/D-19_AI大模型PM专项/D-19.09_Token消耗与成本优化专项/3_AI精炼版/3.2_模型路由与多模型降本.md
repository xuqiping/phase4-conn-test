## 六、路由决策树（PM可直接用）

```
请求进入
├─ 任务复杂度判断（意图分类/置信度评分）
│   ├─ 高复杂度/低置信度 → 旗舰模型
│   ├─ 中复杂度 → 中档模型
│   └─ 低复杂度/高置信度 → 轻量模型
├─ 延迟要求
│   ├️ 实时(<500ms) → 本地小模型/缓存命中
│   └️ 可等待 → 远程大模型
├─ 成本预算检查
│   ├️ 超限 → 降级（贵→便宜→模板兜底）
│   └️ 未超限 → 放行
└─ 故障检测
    └️ 主模型不可用 → 自动切换备用模型
```

## 七、成本测算模型

**单次请求成本** = (输入token × 输入单价 + 输出token × 输出单价) × (1 - 缓存命中率 × 缓存折扣)

**输出token单价通常是输入2-4倍** [来源:新浪2026定价全景 | 🔍高 | 2026-07]

**月度成本测算**：
- 日均10万次调用，不做优化月费可从2万飙至8万 [来源:51CTO《从月费8万到1.6万》 | 🔍高 | 2026-06]
- 优化路径：缓存(降80-95%) + 路由(降50-70%) + 压缩(降20倍) → 月费8万可降至1.6万
