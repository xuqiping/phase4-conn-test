## 三、归因与ROI分析

### 3.1 归因框架

| 归因类型 | 说明 | 2026现状 |
|---|---|---|
| 确定性归因(IDFA/GAID) | 基于设备ID精准匹配 | iOS ATT后~20%用户授权→大幅衰减 |
| 概率归因 | 基于IP/UA/时间窗口推测 | 2025-2026被Apple限制→可靠性下降 |
| SKAdNetwork(iOS) | Apple官方归因框架——聚合+延迟+隐私 | 主流iOS归因方案但粒度粗 |
| 自归因网络(SDN) | Meta/Google/TikTok自报归因 | 常见"重复归因"→需去重校验 |

### 3.2 核心指标

| 指标 | 计算公式 | PM决策阈值 |
|---|---|---|
| CPI(每安装成本) | 广告费/安装数 | <LTV/3 → 健康 |
| CAC(每获客成本) | 总营销费/付费用户数 | <LTV → 健康 |
| LTV(生命周期价值) | ARPU×留存月数 | LTV/CAC > 3 → 健康 |
| ROAS(广告回报率) | 归因收入/广告费 | D7 ROAS>15% → 可规模化 |
| D1/D7/D30留存 | 次日/7日/30日留存率 | D1>40%/D7>20%/D30>10% → 健康 |

## 四、KOL与本地社媒运营

| 策略 | 说明 | 适用场景 |
|---|---|---|
| 头部KOL(100万+粉丝) | 品牌曝光+信任背书——贵但广 | 新市场冷启动/品牌定位 |

### 4.2 本地社媒运营框架

```
确定目标市场Top3社媒 → 建立官方账号 → 内容日历(周3-5更) → 互动运营(评论/DM) → 数据复盘(月度) → 迭代
```
