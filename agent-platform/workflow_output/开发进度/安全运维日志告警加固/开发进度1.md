### C2 — 通用 RateLimiter（Redis 限流基建）
- 新建 4 文件（`common/ratelimit/`+`common/security/`+`common/config/`）：
  - `RateLimit.java` 注解：action/max/windowSeconds/algo(FIXED|SLIDING)/scope(USER|IP)
  - `RateLimiter.java`：checkFixed（INCR+首次EXPIRE）/checkSliding（ZSET，member=now+"-"+UUID 防同毫秒覆盖）；**全 catch 降级放行 true**（可用性>强制力）
  - `ClientIpResolver.java`：XFF 仅 trusted-proxies 白名单命中才采信，否则 remoteAddr
  - `RateLimitInterceptor.java`：无注解放行；总闸 `security.rate.enabled`；阈值热更 `security.rate.{action}.max`；key=`rl:u:{uid}:{action}`/`rl:ip:{ip}:{action}`；超限打 `bizMetrics.apiRateLimited(action)` + 抛 RATE_LIMIT(429)
  - `WebMvcConfig.java` 注册 `/api/**`
- 改动：`BizMetrics.java` +4 指标方法（apiRateLimited/securityEventRaised/ipBlocked/accountLocked，tag 全有界枚举防高基数）
- 测试：`RateLimiterTest` 9 例 + `RateLimitInterceptorTest` 9 例 = **18 绿**

### C3 — 封号即时生效（堵真实洞：JwtFilter 原不查 status）
- 新建 `common/security/BanService.java`：双保险 = 删 `session:user:{uid}`（sid 比对失败→401）+ 设 `ban:user:{uid}` 标记（TTL=access 有效期，单点登录关时兜底）；restore 删标记；isBanned Redis 故障降级放行（DB status 阻新登录/refresh 兜底）
- 改 `JwtAuthenticationFilter.java`：isCurrent 之后加 ban 标记校验 → 401 SESSION_KICKED 固定话术（不透传「被封」防探测）；抽 writeSessionKicked() 复用
- 改 `AuthService.refreshToken`：refresh 兜底查 DB status ≠ACTIVE → SESSION_KICKED（单点登录关/Redis 故障时封号用户不得换发新 access）
- 改 `UserController.updateUserStatus`：枚举白名单 {ACTIVE,DISABLED,LOCKED,BANNED}（堵裸写）+ reason ≤128 + 防自封 403 + 防最后超管 403（countActiveByPermission('user:manage')≤1）+ ban_reason 落列 + revoke/restore 接线
- `UserMapper` +countActiveByPermission（@Select 三表 join 统计）
- `User` 实体 +banReason +lockedUntil；`UserVO` 同步 +2 字段
- 前端：`admin.ts` updateUserStatus +reason 参数 + UserVO 类型 +2 字段；`UserManageView.vue` 状态变更弹窗（radio DISABLED/LOCKED/BANNED + 原因必填 ≤128 + 即时踢下线警示）+ 状态列加 BANNED tag + 原因列
- 测试：`BanServiceTest` 7 例 + `UserControllerStatusTest` 8 例 = **15 绿**

### C4 — logback 合规（网安法第21条 ≥6 个月）
- 改 `logback-spring.xml`：APP 30→180天/2GB→12GB、ERROR 90→180天/1GB→2GB、SQL 7→180天/500MB→3GB
- 新增 SECURITY_FILE 通道（security.log，JSON+MaskingAppender 脱敏，50MB×180天×3GB 上限），logger `com.superprogrammer.common.security` additivity=false（BanService 已落此通道）
- XML 校验通过（10 appenders）；磁盘预算 ≈20GB，部署须确认 D 盘 ≥25GB
