# 影响评估 · 认证通道管理员配置

## 变更概要

- **变更类型**：修改、增加
- **目标**：管理员在设置页维护阿里云邮件/短信通道；数据库配置优先，原环境变量作为首次部署和故障恢复兜底。
- **原因**：现有邮件、短信参数只能在启动环境中修改，无法由管理员即时调整。
- **规模**：中（认证服务、系统设置 API、设置页、部署配置与测试）。

## 引用点排查

| 对象 | 当前引用 | 处理 |
|---|---|---|
| `AliyunMailConfig` | `EmailService` | 保留为环境变量兜底，主读取改为动态快照 |
| `AliyunSmsConfig` | `SmsService`、测试 | 保留为环境变量兜底，主读取改为动态快照 |
| `SystemSettingService` | 多个管理员设置页 | 复用 AES-GCM 加密存储范式，不改变既有键 |
| `/api/system/settings/*` | `frontend/src/api/system.ts` | 新增独立 `auth-channels` 契约，不破坏已有 `/auth` |

## 受影响清单

| 受影响项 | 动作 | 回归重点 |
|---|---|---|
| 邮件验证/找回 | 动态读取配置 | token、限流和降级行为不变 |
| 短信登录/找回 | 动态读取配置 | 验证码 TTL、手机号/IP 限流即时生效 |
| 管理员设置页 | 新增认证通道页签 | Secret 不回显；留空不改；清除后回退环境变量 |
| 审计/日志 | 保存及测试端点加审计 | 不记录 Secret、验证码和完整 token |

## 数据库影响

- 不新增表或字段；沿用 `system_settings` 键值表。

## 回滚预案

- 关闭或清除数据库中的认证通道键后，运行时恢复读取原环境变量。
- 代码回滚使用本变更前部署包；数据库无结构迁移，无需回滚 Flyway。

## 安全与运维

- Secret 使用现有 `AesEncryptService` 加密，API 仅返回 `secretConfigured`。
- 配置每次调用解析，无进程内长期明文缓存，保存后即时生效。
- 阿里云 SDK 仍由 Maven 编译依赖提供，页面只管理运行参数。
