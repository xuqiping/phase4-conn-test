# File Keeper 项目 README

## 1. 项目简介

File Keeper 是一款面向 Windows 桌面工作流的轻量级效率工具。它将“常用文件快速访问”和“运行中应用管理”放在同一个工作台中，帮助用户减少在资源管理器、任务管理器、浏览器、终端、办公软件和各类资料窗口之间反复切换的成本。

File Keeper 不只是一个文件收藏工具，也不是传统任务管理器的替代品。它更适合作为个人桌面工作台：工作开始时快速打开常用资料，工作过程中快速定位文件和应用，工作结束时快速整理窗口和关闭不需要的程序。

---

## 2. 核心定位

File Keeper 当前围绕两条主线建设：

1. **文件管理入口**
   - 收藏常用文件和文件夹
   - 通过分组、标签、搜索、排序快速定位资料
   - 支持网格/列表双视图和批量操作

2. **Windows 应用管理入口**
   - 查看当前运行中的桌面应用
   - 按类别筛选、按列排序、批量选择和关闭
   - 支持列自定义、右键快捷操作和重要应用确认保护

这两个能力组合后，File Keeper 更适合服务真实桌面工作流：用户不只是需要“找到一个文件”，也经常需要“整理当前打开的一堆窗口”。

## 3. 适用人群

### 3.1 开发者

开发者通常需要频繁打开 README、接口文档、配置文件、脚本、日志和测试资料，同时还会打开多个浏览器、终端、编辑器和本地服务窗口。

File Keeper 可以帮助开发者：

- 快速访问项目资料和常用脚本
- 按项目或模块管理文档
- 切换到进程管理页查看浏览器、终端、编辑器等应用
- 收尾时批量关闭测试窗口和临时工具

### 3.2 学生与自学者

学生、自学者和培训参与者经常需要同时处理课程资料、PDF、笔记、浏览器、作业文件和会议软件。

File Keeper 可以帮助他们：

- 按课程或学习阶段管理资料
- 用标签区分重点、待复习、作业和参考资料
- 清理学习期间打开的 PDF 阅读器、浏览器和会议软件

### 3.3 设计师与内容创作者

设计师和内容创作者需要快速访问设计稿、素材、参考图、交付文档，同时管理图片工具、媒体软件、浏览器和通讯工具。

File Keeper 可以帮助他们：

- 将素材和交付文件集中管理
- 快速打开高频设计资源
- 按图像、媒体、通讯等类别整理正在运行的软件

### 3.4 办公人员

办公人员经常在文档、表格、演示稿、浏览器、会议软件和即时通讯工具之间切换。

File Keeper 可以帮助他们：

- 快速回到高频工作文档
- 通过搜索定位合同、模板、报表等文件
- 会后批量关闭浏览器、会议工具和临时窗口

### 3.5 运维、技术支持与高级 Windows 用户

这类用户需要快速判断某个程序是否运行、属于哪类应用、是否可以关闭，以及在沟通中复制进程信息。

File Keeper 可以帮助他们：

- 查看应用名称、PID、窗口标题、内存和 CPU 信息
- 按类别缩小排查范围
- 复制进程信息用于记录或沟通
- 遇到权限不足时得到更清晰的提示

## 4. 主要功能

## 4.1 文件管理

### 快速收藏与打开

用户可以将常用文件和文件夹添加到 File Keeper 中，之后直接在应用内一键打开，不需要反复进入多层文件夹查找。

### 分组管理

支持按项目、课程、客户、用途创建分组。默认分组包括：

- 全部
- 最近打开

用户也可以创建自定义分组，用于管理长期使用的文件集合。

### 标签系统

每个文件可以添加多个标签，例如：

- 重要
- 待处理
- 作业
- 合同
- 素材
- 配置

标签可以辅助搜索和分类，让文件不只依赖文件夹层级管理。

### 搜索能力

搜索支持匹配：

- 文件名
- 文件路径
- 标签

搜索输入带防抖处理，减少大量文件列表下的重复计算。

### 排序能力

文件列表支持多种排序方式：

- 自定义排序
- 打开次数
- 文件名
- 最近打开
- 添加时间

这让高频文件可以自然靠前，也支持用户手动维护重要文件顺序。

### 双视图模式

File Keeper 支持：

- 网格视图：适合浏览和展示
- 列表视图：适合快速扫描和查找

### 批量操作

用户可以多选文件后执行批量操作，例如批量打开、批量移动、批量删除等。

---

## 4.2 Windows 应用管理

### 运行中应用总览

进程管理页可以展示当前运行中的 Windows 应用窗口，并显示：

- 应用名称
- PID
- 窗口标题
- 内存占用
- CPU 使用率
- 应用类别

### 智能分类

File Keeper 内置常见 Windows 应用映射，支持 13+ 类别：

- 浏览器
- 办公
- 文件管理器
- 终端
- 压缩
- 文档
- 媒体
- 图像
- 通讯
- 下载
- 游戏
- 系统
- 其他

分类的目的不是做底层系统诊断，而是让用户按日常工作场景理解和整理窗口。

### 类别筛选

用户可以通过类别下拉框或快捷筛选快速缩小范围。例如只查看浏览器、终端、办公软件或文件管理器。

### 列排序

进程列表支持按以下字段排序：

- 名称
- 类别
- PID
- 内存
- CPU
- 窗口标题

内存和 CPU 默认按更适合排查的方向排序，方便发现资源占用较高的应用。

### 列显示与顺序自定义

用户可以在列设置弹窗中：

- 显示或隐藏列
- 拖拽调整列顺序
- 保存后同步影响表头和每一行内容

### 选择与批量关闭

进程管理支持：

- 单选
- 多选
- 全选
- 反选
- 取消选择
- 关闭单个应用
- 批量关闭选中应用

关闭方式优先向目标窗口发送正常关闭信号，适合日常桌面整理。

### 右键快捷操作

进程行支持右键菜单：

- 显示到前台
- 复制进程信息
- 关闭进程

### 重要应用确认保护

对于资源管理器、任务管理器、系统服务等重要应用，File Keeper 支持确认保护，降低误关关键窗口的风险。

### 权限不足提示

当目标应用以更高权限运行或属于受保护窗口时，Windows 可能返回 `拒绝访问` / `0x80070005`。File Keeper 会将这类错误转换成更清楚的人话提示，引导用户尝试以管理员身份启动应用后重试。

## 5. 产品优势

### 5.1 文件入口和应用整理合一

传统工作流中，用户需要在资源管理器中找文件，再到任务栏或任务管理器中整理窗口。File Keeper 把这两件事放在同一个界面体系里，减少上下文切换。

### 5.2 更贴近日常桌面工作流

很多桌面效率问题不是单纯“文件难找”，而是资料、浏览器、终端、办公软件和会议窗口同时堆在一起。File Keeper 同时处理资料入口和窗口整理，更接近真实使用场景。

### 5.3 分类比进程名更容易理解

传统任务管理器强调进程视角，普通用户可能很难判断某个 exe 属于什么软件。File Keeper 通过应用类别降低理解成本，让用户更容易按“浏览器”“办公”“终端”等日常概念操作。

### 5.4 本地化与低打扰

File Keeper 当前数据保存在本地，不依赖联网。进程管理页采用按需刷新策略，不打开该页面时不会持续扫描进程，减少后台占用。

### 5.5 轻量但有保护机制

File Keeper 提供批量关闭能力，但也保留重要应用确认和权限错误提示，避免把“快捷”变成“高风险”。

## 9. 数据存储

File Keeper 的数据主要保存在本地，包含：

- 收藏文件列表
- 分组信息
- 标签信息
- 文件打开次数
- 最近打开时间
- 应用偏好设置
- 进程管理列设置
- 自动刷新设置
- 关闭确认模式
- 重要应用白名单
- 当前语言设置

文件管理相关数据主要通过应用本地持久化保存；进程管理设置和语言设置使用当前应用环境的本地存储保存。

## 10. 使用建议

### 10.1 开始工作前

1. 打开 File Keeper
2. 通过分组找到当前项目或任务资料
3. 一键打开常用文档、配置文件、脚本或素材

### 10.2 工作过程中

1. 使用搜索快速定位临时需要的资料
2. 通过标签区分重点、待处理、参考资料
3. 根据打开次数和最近打开排序找到高频文件

### 10.3 工作结束后

1. 切换到进程管理页
2. 按类别筛选浏览器、终端、会议软件等
3. 多选不再需要的窗口
4. 批量关闭并保留关键应用确认

---

## 11. 当前限制

1. 进程管理能力主要面向 Windows，跨平台支持有限。
2. 关闭应用采用窗口关闭信号，不保证所有程序都会立即退出。
3. 权限更高的应用可能无法被普通权限的 File Keeper 关闭。
4. 当前应用更偏个人本地使用，不包含云同步和团队协作能力。
5. 性能指标仍需要在大量真实文件和进程场景下继续测试。

## 13. 总结

File Keeper 的核心价值是把“常用文件入口”和“Windows 应用整理”整合成一个轻量本地工作台。它适合多任务、频繁切换资料和窗口的用户，尤其适合开发者、学生、设计师、办公人员和高级 Windows 用户。

当前版本已经具备文件收藏、分组、标签、搜索、排序、批量操作、运行中应用查看、分类筛选、列自定义、批量关闭和右键快捷操作等能力，已经形成了较完整的个人桌面效率工具雏形。
