## 数据与排序

- `clipboard_groups`：一行代表一个用户自定义组；名称 trim 后 1—40 字符，拒绝控制字符，忽略大小写判重。
- `clipboard_items.group_id`：可空；空值就是“未分组”。删除组时先批量置空再删组，不删除正文。
- `is_pinned/pinned_at`：置顶状态和最近置顶时间。
- 稳定顺序：`is_pinned DESC → pinned_at DESC → created_at DESC → id DESC`。

## 调用链

```text
用户单条/批量置顶或移动
  → Store 立即修改当前可见列表
  → 一次 Tauri API 提交全部 IDs
  → SQLite 事务整体成功或整体回滚
  → 成功发送 clipboard://changed("mutation")
  → 失败按条目操作版本恢复；旧失败不能覆盖较新的成功

快捷面板打开 → quickPanelItems + 独立 query → 查询不携带 groupId
主页面 → items + 持久化 groupFilter → 两套结果互不覆盖
```

## 技术原理（大白话）

- **SQLite 事务**：一批记录要么全改、要么全不改。像银行批量转账，中途有一笔账户不存在就整批撤销。
- **乐观更新**：点击后界面先变化，后台失败再恢复。像先把便签挪到顶部，系统没保存成功再放回原处。
- **操作版本**：每个条目记住最后一次操作编号。像快递只认最新改址单，较早失败通知不能把新地址改回去。
- **参数绑定**：分组名和 ID 不拼进 SQL。像把内容放入封好的参数盒，数据库只把它当数据，不当命令。
