# 02 - 用户与部门管理

## 功能简介
管理员对用户列表/启停、分配角色；部门树 CRUD、部门成员管理。

## 后端 (backend)
- 用户：
  - [UserController.java](../../backend/src/main/java/com/superprogrammer/auth/controller/UserController.java) — `GET /api/users` `PUT /{id}/status` `PUT /{id}/roles`
- 部门：
  - [DepartmentController.java](../../backend/src/main/java/com/superprogrammer/auth/controller/DepartmentController.java) — `GET POST /api/departments` `PUT/DELETE /{id}` 成员 `POST/DELETE /members`
- 服务：`auth/service/`（UserService 隐于 AuthService、DepartmentService）
- 实体：`auth/entity/` User、Department、UserDepartment、UserRole
- Mapper：`auth/mapper/`（含 xml）

## 前端 (frontend)
- 视图：[UserManageView.vue](../../frontend/src/views/admin/UserManageView.vue)
- API：[admin.ts](../../frontend/src/api/admin.ts)
- 路由：`/admin/users`

## 数据表
`users`、`departments`、`user_departments`、`user_roles`
