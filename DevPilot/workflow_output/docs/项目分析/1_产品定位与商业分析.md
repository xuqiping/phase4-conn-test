# 1 · 产品定位与商业分析

> Phase 0 产物：需求 → 竞品 → 受众 → 差异化 → 商业模式 → 定价
> 数据来源：2026-08 联网调研（来源 URL 见文末）

## 1. 需求分析：解决什么问题

**核心矛盾**：AI 编程工具的能力已过剩，但「不会代码的人做出可靠产品」这件事仍然失败率极高。

- **学术佐证**（arXiv:2510.00328）：非开发者两大死穴——①无法把意图准确写进 prompt；②无法验证 AI 产出是否正确，遇 bug 陷入「改 prompt→粘贴→再报错」死循环。仅 32.5% 的 CS1 学生能读懂 LLM 生成的代码。
- **事故佐证**：vibe coding 产物频发数据库公网裸奔、硬编码密钥、无鉴权上线（Tea 泄露、Base44 越权事件）；Stack Overflow 2025 调查显示 84% 采用率但 ~46% 不信任 AI 代码。
- **体验佐证**：METR 实测资深开发者用 AI 反而慢 19%（自以为快 20%）——虚假信心是全行业问题，对零代码用户是致命的。

**结论**：市场不缺「会写代码的 Agent」，缺的是**把软件工程方法论内置进去、替用户守住质量与安全底线的 Agent**。这正是 `2_编程类可迭代workflow`（Phase 0~6 + SDD + 人在环路）的产品化机会。

**最小可用范围（MVP 边界）**：Windows+macOS 桌面客户端单表面 + 内置工作流五阶段（想法→需求→计划→建造→验收）+ 本地沙箱执行 + diff 大白话审阅 + 一键回滚 + Skills 生成 + MCP 客户端。并行任务、移动端、MCP Server/指令开放、IDE 插件放二期。

## 2. 竞品对比（2025–2026 全景）

| 产品 | 强项 | 弱项（=我们的机会） |
|---|---|---|
| **OpenAI Codex** | 功能最全：云沙箱并行任务、Best-of-N、AGENTS.md、CLI/IDE/移动/Slack 多表面、容器缓存提速 90%、GA 后企业工具链 | 假设用户是开发者：无需求引导、无验收引导、diff/日志裸呈、无商业分析层；UI 为工单列表式，信息密度高、对新手不友好 |
| **Claude Code** | Checkpoints + /rewind 回滚体验标杆；Plan Mode 计划先行； Skills/Subagent 生态 | 纯 CLI/IDE 形态，零代码用户无法上手 |
| **Cursor** | 编辑器体验之王；Background Agents 并行 + 「一键在 Cursor 打开」双向切换 | 仍服务开发者；无方法论、无验收闭环 |
| **Devin 2.0** | Interactive Planning（可编辑计划审批后执行）是「先对齐再执行」UX 代表作 | 面向企业工程团队，$20/月起但学习成本仍在 |
| **Copilot Coding Agent** | Issue→PR 流水线 + Session Logs 全透明 + 四眼安全原则 | 深度绑定 GitHub 生态，非开发者无入口 |
| **Windsurf** | Cascade 开箱自动索引、Auto-Linter、Suggested Actions 保持心流 | 编辑器形态，被收购后方向转向企业 |
| **Lovable / Bolt / v0** | 门槛最低：prompt 框开场 + 分屏实时预览 + 元素点选编辑 | 锁定技术栈、只做前端/原型、无后端工程严谨性、产物难维护 |
| **Replit Agent** | 引导最佳：checkpoint 一体回退（代码+配置+DB+对话）、主动反问澄清 | IDE 优先、checkpoint 计费失控、环境/部署仍卡非技术用户 |

**空白地带**：左上是「工程能力强 + 方法论内置 + 零代码可用」象限——目前无产品占据。Codex 证明了工程能力的上限，Lovable/Replit 证明了低门槛的市场规模，中间地带就是本产品。

## 3. 受众群体

| 分层 | 画像 | 痛点 | 付费意愿 |
|---|---|---|---|
| **P0 一人公司/独立创造者**（主） | 有商业想法、零代码或半吊子、正在用 ChatGPT+Cursor 硬撑 | 做出原型后维护不动；不懂规格导致 AI 越改越乱；不会验收 | 高：愿意为「做出能卖的产品」付 $20–50/月 |
| **P1 小微创业者/业务人员** | 需要内部工具、MVP 验证 | 外包贵且沟通成本高；低代码平台灵活度不够 | 中高：按项目付费心智 |
| **P2 产品经理/设计师** | 想独立验证想法 | 懂需求不懂实现，现有工具要么太玩具要么太硬核 | 中：工具预算敏感 |
| **P3 初级开发者**（溢出人群） | 想要规范流程加持 | 缺方法论训练，想要「有人带」的感觉 | 低：白嫖为主，但贡献口碑 |

**获客渠道**：中文圈（B 站/小红书/即刻 vibe coding 话题）、Product Hunt、独立开发者社群（IndieHackers/电鸭）、「一人公司」内容营销。

## 4. 差异化定位（宣扬口径）

> **对外一句话**：「Codex 是给程序员的外包团队，DevPilot 是给创业者的技术合伙人——它不只写代码，还替你把需求想清楚、把质量守住。」

三个支撑点：
1. **方法论内置**（独家）：Phase 0 商业分析 → Phase 1 规格 → Phase 2 计划 → Phase 3 建造 → Phase 4 验收 → Phase 5 上线 → Phase 6 变更，全程引导，用户永远知道「现在到哪一步、下一步是什么、为什么要做」。
2. **大白话双层呈现**（体验分水岭）：所有技术产物都有翻译层；验收不是看 diff 而是「点一点」清单。
3. **安全与成本兜底**：安全清单强制卡点 + 预算仪表盘，直击 vibe coding 两大口碑雷区。

## 5. 商业模式与定价

**模式：Token 充值转售（余额制，非订阅）**。平台接入多家模型 API（旗舰模型 + 国产模型组合），用户充值 Token 余额，按实际消耗扣费，**收入 = 官方 API 成本 × 加价率 − 渠道成本**。客户端本地执行意味着我们几乎不背算力成本——毛利结构天然健康。

| 档位 | 内容 |
|---|---|
| **新人体验金** | 注册送 ¥10 等值 Token，可完整走通一个 L0/L1 项目——目标：onboarding 转化与口碑 |
| **充值包** | ¥50 / ¥200 / ¥500 三档，大额档赠 5%~15% 加赠额度（充值即锁客，无月费压力） |
| **加价率** | 建议 1.5~2× 官方价，按模型分档：旗舰模型低加价（走量），国产模型高加价（性价比心智）；客户端内明示「本次任务消耗 X Token ≈ ¥Y」 |
| **BYOK（自带 Key）** | 用户可填自己的 API Key 绕过平台计费——不设限，作为口碑与转化漏斗（用惯工作流后自然转充值） |

**定价依据**：①Token 转售是 Cursor/各类套壳站已验证的模式，用户心智成熟；②对标感知价——Codex 含在 ChatGPT Plus $20/月，我们「用多少花多少、不订阅」对轻度用户显著便宜，对重度用户靠充值包锁客；③本地执行无算力成本，加价率即毛利，定价弹性大。

**计费体验的护城河**：余额/消耗仪表盘做成第一公民（顶栏常驻余额环 + 每任务消耗明细 + 月度报表）——卖 Token 的产品，计费透明度就是复购率（Replit 计费失控是反面教材）。

**变现扩展**（二期后）：行业技能包/模板市场分成、企业私有部署 License、团队共享额度池。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 大厂（OpenAI/Anthropic）下Methodology引导，差异化被抹平 | 深耕中文市场 + 工作流/技能可自定义（用户与行业模板沉淀）形成数据网络效应 |
| 模型渠道与合规风险（转售海外模型 API 的资质、稳定性、封号） | 多供应商冗余 + 国产模型兜底路由 + 合规评估前置（Phase 1 安全规格专题）；BYOK 作为极端情况逃生通道 |
| 恶意/超额消耗（充值用户跑失控任务烧余额引发客诉） | 每任务消耗预估前置 + 余额不足自动暂停 + 单任务 Token 上限可配 |
| 零代码用户期望管理（「说一句话就出淘宝」） | onboarding 明确边界 + 项目规模预检（超复杂度建议拆分或转人工） |
| 安全事故连坐口碑 | 安全清单强制卡点不可跳过（见文档 4 §5） |
