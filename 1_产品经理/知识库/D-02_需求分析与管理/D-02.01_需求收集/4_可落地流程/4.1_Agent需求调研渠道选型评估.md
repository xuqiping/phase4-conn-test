# 4.1 Agent 需求调研渠道选型评估

> 📅 2026-07-11 ｜ 🔴红线：渠道选型不可仅凭AI推荐，PM必须基于资源约束与战略方向做最终决策 ｜ 角色：需求收集决策Agent

## 背景

需求收集的第一步是**选择正确的渠道组合**。选错渠道意味着：用问卷发现不了隐含需求、用访谈覆盖不了统计显著性、用行为数据解释不了动机。本Agent根据产品阶段、用户类型、资源约束，自动推荐渠道组合方案。

## 目标

输入产品阶段+用户类型+资源约束，输出渠道组合策略报告（含优先级排序、预算分配、时间规划）。

## 关键结果

1. 渠道组合方案（含各渠道权重）
2. 各渠道执行预算与时间估算
3. 风险点与备选方案

## 执行步骤

### Step 1：输入产品阶段与用户类型

```
输入变量：
- product_stage: "探索期" | "成长期" | "成熟期"
- user_type: "C端消费者" | "B端企业" | "内部员工"
- resource_constraint: "低(<2人周)" | "中(2-5人周)" | "高(>5人周)"
- existing_data: "有行为埋点" | "无行为埋点" | "部分埋点"
```

### Step 2：渠道匹配规则

| 条件 | 推荐主渠道 | 推荐辅渠道 | 不推荐 |
|---|---|---|---|
| 探索期+C端+低资源 | 深度访谈(5-8人) | 行业报告+竞品 | 大规模问卷 |
| 探索期+B端+高资源 | 现场观察+深度访谈 | 销售反馈+AI挖掘 | 问卷（B端回收率极低） |
| 成长期+C端+中资源 | 行为数据+问卷 | 访谈+AI挖掘 | 现场观察（成本过高） |
| 成长期+B端+中资源 | 深度访谈+销售反馈 | 行为数据+竞品 | 大规模问卷 |
| 成熟期+C端+低资源 | 行为数据+AI挖掘 | 问卷+NPS | 深度访谈（边际收益递减） |
| 成熟期+B端+高资源 | 客户成功反馈+行为数据 | AI挖掘+现场观察 | 竞品（成熟期竞品信号弱） |

### Step 3：生成渠道策略报告

```markdown
## 需求收集渠道策略

### 产品背景
- 阶段：{product_stage}
- 用户类型：{user_type}
- 可用资源：{resource_constraint}

### 渠道组合（按优先级）
| 优先级 | 渠道 | 权重 | 预算 | 周期 | 产出 |
|---|---|---|---|---|---|
| P0 | ... | ...% | ...人天 | ...天 | ... |
| P1 | ... | ...% | ...人天 | ...天 | ... |

### 风险与备选
- 风险1：... → 备选：...
- 风险2：... → 备选：...

### AI辅助选项
- [ ] 是否启用AI反馈挖掘作为补充渠道？
- [ ] 是否使用AI初步聚类已有反馈？
```

## 输出格式

Markdown格式的渠道策略报告，PM审核后决定是否执行。Agent仅推荐，PM决策。
