## 关键决策
1. 图片同步 API → ArkImageProvider 独立 @Component（不实现 MediaGenProvider），worker 按 task_type 分流，视频零回归。
2. provider/价表**不 seed**——admin 自填 key（用户明确「设置里全局模型供应商我自己去填 key」）。
3. 生图入库**无重复三态**——无画布节点绑定，同图可多次入库独立资产（偏离 plan 联动 5）。
