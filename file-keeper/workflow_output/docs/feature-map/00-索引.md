## 使用建议

- **新成员上手**：先看 01-公共基础设施 了解整体架构与约定，再按需阅读业务模块。
- **排查问题**：按功能定位模块速查表，再按「核心数据流 / 调用链路」逐层定位文件。
- **迭代规划**：各表末尾的「已知缺口 / TODO」是后续需求 / 技术债输入。
