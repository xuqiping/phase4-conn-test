## 根因证据

- `VideoGenView.vue` 用 `capability.maxVideos > 0 && capability.referenceVideoEnabled` 控制整个参考视频表单项；本地未配置公网 HTTPS 回拉通道时能力值为 false，导致整块 DOM 被移除。
- 数据库最近视频任务的 `request_config ->> 'prompt'` 有真实值；运行中的 `GET /api/media/tasks?kind=VIDEO` 也返回 `prompt`。历史数据链路未丢字段，问题在右侧窄栏表格呈现。

## Phase 3 实现

- 参考视频表单项只按模型 `maxVideos > 0` 决定是否显示。
- 部署通道未配置时显示警告，视频可用槽位归零，上传与资产库按钮保持禁用；后端 fail-closed 规则不变。
- 历史表开启横向滚动，并把 ID/提示词固定在左侧；提示词列固定宽度 260px，每条记录继续直接使用 API 返回的 `prompt`。
- 新增 `VideoGenView.test.ts` 两条回归：未配置时区域可见禁用；历史提示词列固定且记录值存在。
- 同步 User-Ops 和 Feature Map。
