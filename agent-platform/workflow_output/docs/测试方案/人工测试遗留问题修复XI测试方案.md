## 准备

- 账号：admin/admin123（管理员，官方库数据用）；普通成员账号一个（对照官方口径）。
- 后端本地起（V169+），前端 dev；建议先在资产库后台/DB 准备 1 个管理员发布的官方资产包（多类型资产）+1 个普通成员分享的公众池包（对照「官方≠公众」）。

## A 右键菜单（S1-S5）

### S1 空白右键开菜单+落点建节点
1. 进无限画布，鼠标移到画布空白处点右键。
2. **预期**：弹两栏菜单（添加节点 7 类+粘贴/撤销/重做/一键整理）；点「图片」→ 图片节点落在**右键点的那里**。
3. 反向：再右键别处空白 → 菜单**挪位**不叠两层；点空白左键/Esc → 菜单关。

### S2 不该弹的地方
1. 分别在节点上、连线上、顶部工具条上、组彩框上、弹窗（如设置）开着时点右键。
2. **预期**：节点右键走节点自带菜单（存资产库等）；其余**不弹**新菜单；弹窗层挡住=不触发。

### S3 Esc 只关菜单
1. 框选 2+ 节点（保持选中）→ 空白右键开菜单 → 按 Esc。
2. **预期**：只菜单关，框选高亮**仍在**；再按一次 Esc 才走画布清多选链；开着 n-modal 弹窗时 Esc 关弹窗不关菜单后的画布态（不串层）。

### S4 禁用态实时
1. 刚进画布（无复制/无撤销）右键 → 「粘贴/撤销/重做」灰。
2. 复制一个节点后再右键 → 「粘贴」亮；撤销一步后「重做」亮。
3. **预期**：灰项点击零动作。

### S5 菜单「粘贴」落点=右键点
1. Ctrl+C 复制子图 → 空白右键点某处 → 菜单「粘贴」。
2. **预期**：粘贴体包围盒**中心**对齐右键点（连贴 +32 错开照旧）；与 Ctrl+V 键盘链（鼠标处）互不干扰。

## B 官方库（S6-S9）

### S6 官方口径=仅管理员发布
1. 调色板底部点「官方库」。
2. **预期**：左列只出现**管理员发布**的资产包（官方徽标）；普通成员分享的公众池包**不出现**（网络面板 `/public-pool?official=true`）。

### S7 大卡片结构与分组
1. 点选一个官方包 → 右侧列资产。
2. **预期**：按包自定义 mediaTypes **词汇序**分组；词汇外类型归尾组「其他」；空组不显示；行内悬浮预览/灯箱与「从库选择」同款（点「选择」才是唯一入口）。

### S8 插入链成功
1. 选一个图片资产点「选择」。
2. **预期**：卡片关、toast、**视口中心**出现资产节点且预览/正文/@引用即用；可正常连线下游生成。

### S9 失败静默回滚（反向）
1. 构造失败（如后端停掉/资产文件失效）后选择资产。
2. **预期**：toast 报错；画布**无残壳节点**（不留空节点/半节点）；Ctrl+Z 栈无空步（撤一步回到点开前的状态）；卡片**留在原地**可重试换选。

## C 两级词汇（S10-S14）

### S10 编辑分类两级保存
1. 项目设置→编辑分类→叙事角色：给「人物」加子类「老人」「孩童」→ 保存 → 重进。
2. **预期**：两级结构回显一致；行内错误分两种：加**子类**撞任意一级/他父子类名 → 输入清空+红字；改**一级名**撞名或留空 → 字保留+红字+「保存」置灰（P4 review 中④ 口径，AC-XI3-5 已自动化），改名不撞后可存。

### S11 删子类资产归父
1. 先给若干资产挂「老人」→ 编辑分类删「老人」。
2. **预期**：确认弹窗只提子类自身计数；删后这些资产筛选「人物」**能搜到**（归父级），资产一个不丢。

### S12 删一级归通用（反向）
1. 「人物」挂直接资产+「老人」下也有资产 → 删「人物」。
2. **预期**：确认文案「N 个资产将归入『通用』（子类随删）」N=两者合计；删后这些资产在「通用」下；「孩童」等同级其余子类一并消失。

### S13 矩阵两级筛选
1. 矩阵视图：点一级「人物」→ 再点子类「老人」→ 再点「全部角色」。
2. **预期**：点一级=含全部子类的大类结果（一级徽标=自己+Σ子类）；点子类=精确；子类选中时一级行点亮；清空回全量。

### S14 一键分镜含子类
1. 画布选几个节点（含挂子类的资产节点）→ 一键生成分镜。
2. **预期**：目录包含人物/道具/场景**及其子类**的资产；提交/存入库的角色下拉为分组（父/子 key 都能挂）。

## D 组=大节点（S15-S19）

### S15 点选分层+Delete 无动作
1. 建组（≥2 节点）→ 点组框空白 → 点成员节点 → Esc → 框选。
2. **预期**：组选高亮/成员单选/多选互斥切换；选组时按 Delete/Backspace **零动作**（成员不删、无保存闪动）；组选退出=点别处/Esc。

### S16 整组拖动跟手
1. 点组框空白选中 → 按住组框空白拖 → 松手。
2. **预期**：全组成员**同步跟手移动**（包围盒跟随），松手才见「已保存」（拖动中不刷）；缩放非 100% 下位移距离正确；未选中第一次按住拖=只选中不移动，再按住才拖；组头端口拖线照常（不被拖动抢）。

### S17 完全包含整组复制（真实生成联动）
1. 组 g1（2 节点）+外部节点 b 与 g1 双向连线；框选**全部组员**（漏一个都不行）→ Ctrl+C → Ctrl+V。
2. **预期**：粘出新组（名去重/成员全新/色保留）+ toast「已粘贴 1 个组（N 个节点）」；b 与**新组**两向连线在（⛓ 开）；对下游跑一次真实生成 → 广播/聚合取到**新组成员**产物；Ctrl+Z 一步撤（组+节点+线全消）。

### S18 半含不带组（反向）
1. 只框选组内 1 个成员 → Ctrl+C → Ctrl+V。
2. **预期**：平节点不建组、新节点**不进任何组员**；其组边按修复X 连**原组**；无组 toast。

### S19 ⛓ 关壳留边零+解散重现
1. 关 ⛓ 开关 → 完全包含复制粘贴 → 新组壳在、**零组级/跨集连线**（诱导边照旧）。
2. 粘贴出的新组点 ✕ 解散 → 成员变平节点、组线级联消失；刷新页面 → 组/边/节点全部重现一致（V169 快照含组）。
