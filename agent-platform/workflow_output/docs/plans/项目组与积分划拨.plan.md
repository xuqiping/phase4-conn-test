# Implementation Plan for 项目组与积分划拨

> Phase 2 产出。Phase 3 逐步勾选执行。只含伪代码，不含真代码。
> 来源规格：[../specs/项目组与积分划拨设计.md](../specs/项目组与积分划拨设计.md)
> 拍板：独立实体 + 组池/按成员记账 + 组长配置成员累计限额。

## 背景与目标

- 7x#3：组长建组拉成员→个人积分划入组池→成员五入口（智能对话/知识库/图片/视频/画布）选「参与项目」→组池扣费+成员记账+限额拦截；新模块「项目推进」看全部产出。
- 7x#4：账单调用明细加「项目」列。

## 技术实现坑点预判与规避措施

| 技术点/功能块 | 可能的坑 | 规避措施 | 验证方式 |
|---|---|---|---|
| **双钱包死锁** | allocate 同时锁个人+组钱包，两请求反向加锁互等 | 固定加锁顺序（先个人后组，按 id 升序）；组池内操作只锁组侧 | 并发单测：50 组长同时 allocate 无死锁（超时即失败） |
| 并发扣组池丢失更新 | 两成员同时扣最后一百分都成功 → 透支 | 镜像 `PointsWalletService` 的 `UPDATE ... SET balance=balance-:x WHERE balance>=:x RETURNING`（条件更新天然防透支） | 并发单测 20 线程扣同一池 |
| used_points 与 ledger 漂移 | 扣费成功但 used 更新失败（非同事务）→ 限额失真 | 钱包/成员行/ledger 三写同一事务；对账单测：Σ(CONSUME-REFUND actor)=used 逐成员 | 事务单测+对账断言 |
| 估价缺失/为零 | 媒体提交无估价快照 → 回收在途校验失效 | Step 5 落 `estimated_cost`（无价模型记 0 并打 WARN）；回收上限公式容忍 0（保守提示） | 单测：无价模型回收提示 |
| BACKSTOP 扣组长 | 组长余额也不足 → 记负（欠款语义）与既有可负余额一致，但用户困惑 | 流水 remark 明示「组池不足兜底」；项目推进页高亮 BACKSTOP 行 | 单测兜底路径+remark |
| 五入口漏带 gid | 某入口（画布 LLM 节点/检索内部 embed）漏透传 → 走个人扣费用户无感 | Step 4 列「网关计费调用点清单」逐一过；e2e 五入口各断言 usage_log.project_group_id 非空 | 五入口集成测试 |
| 会话级选择器持久化歧义 | 对话会话存 kbIds 模式照抄 gid，但旧会话无字段 | nullable 追加，旧会话=null=个人；切换即存 | 旧会话回归 |
| outputs JOIN 分页 | usage_log JOIN media_tasks 一对一假设破（同 taskId 多行扣费/退款） | JOIN 取该 taskId 最新一行（或聚合 points），分页在 usage_log 侧 | 单测：退款任务两行显示为一行净额 |
| 删除组残留 | balance>0 删除 → 组池积分蒸发 | 删除前置校验 balance=0；成员 used 保留只读归档 | 单测拒绝删除 |
| 画布快照带 gid | 老快照无字段 | snapshot 顶层 `projectGroupId?` 可缺省 | 老画布回归 |

## 安全检查清单

- [ ] **鉴权/授权**：组操作=组长或 admin（服务端校验，防直调）；成员只能读自己组列表；allocate 不能替他人
- [ ] **输入校验**：points>0 且 ≤余额、两位小数；quota≥0 或 null；name≤64；成员上限/组（建议 50）
- [ ] **审计**：allocate/reclaim/成员增删/限额调整/重置 @AuditLog（谁动了钱一眼可查）
- [ ] **幂等**：媒体扣/退复用 taskId 幂等键；allocate 防重复提交（前端 disable+后端金额+余额双重约束）
- [ ] **错误处理**：`GROUP_INSUFFICIENT`/`GROUP_QUOTA_EXCEEDED` 文案不含他人余额明细
- [x] **加密/CORS**：无新面；**依赖**：无新增包

## 性能考虑与验证计划

- [ ] 组池行锁热点：单组并发 20 扣费（窗口=媒体并发闸 video2/image3，实际压力小）；单测断言无死锁<3s
- [ ] outputs 分页查询走 `llm_usage_logs(project_group_id)` 索引；JOIN 单层
- [ ] 账单两接口 JOIN project_groups 走主键
- [ ] Phase 4：项目推进页 500 条产出翻页 <1s

| # | 触发动作 | 联动对象 | 预期变化 | 必测边界 |
|---|---|---|---|---|
| L1 | 选择器切组 | 该入口后续请求/余额徽标 | 带 gid+徽标显示组池余额 | 切回个人立即停带；对话切旧会话=各自记住；画布刷新保持 |
| L2 | 组长划拨 | 组池余额/徽标/流水 | 实时增（组长+成员侧刷新） | 超个人余额拒；划0拒；重复点击防双扣 |
| L3 | 组长回收 | 余额/流水 | 减少并回个人 | 在途任务占额→拒并提示；回收后任务结算 BACKSTOP 高亮 |
| L4 | 成员消耗触发限额 | 该成员后续请求 | 4xx「超出成员限额」 | 退款恢复余量可再用；组长调高限额立即解禁；调低不追偿 |
| L5 | 组长移除成员 | 选择器/在途任务 | 列表消失；在途结算仍入组账（历史保留） | 被移除者已打开页面残留 gid 提交→403+自动回落提示 |
| L6 | 删除组 | 全入口选择器/项目推进页 | 不可达+兜底提示 | balance>0 拒删；删后旧画布快照 gid 失效→提交按个人+提示 |
| L7 | 限额重置 | used/流水 | used=0 可再消耗 | ADMIN_ADJUST delta=0 留痕；进行中请求不受影响 |
