坑：Mockito strict stubs 下 `when()` 重挂 thenThrow 桩会真抛——重挂必须用 `doThrow/doReturn().when()`；空列表场景注意 UnnecessaryStubbing。

## 对计划的偏差（已回写 plan.md）

伪代码「超限 return false」→ 实际**超限抛 `BusinessException(42904)`**（沿 InflightGateService 语义）；返回 false 统一=「未闸」（系统调用/上限 0/降级），消除 false 二义性。
