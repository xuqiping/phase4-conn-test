# Public Cloud Ecosystem Workflow Checklist

在完成 `workflow/public_cloud_ecosystem_workflow.md` 的每一步后，使用此检查清单进行交叉验证。每个项目必须回答**是**才算完成。如果有任何项目回答**否**，修复输出并重新验证。

## Step 1: 识别公有云需求场景

- [ ] 已明确场景类型（云厂商选型/云架构设计/产品矩阵组合/成本优化/迁移上云/Landing Zone治理）
- [ ] 已识别业务属性（电商/音视频/政企/AI/金融/工业互联网）
- [ ] 已提取目标市场（中国国内/出海/全球化/混合）
- [ ] 已提取合规要求（等保等级/信创要求/数据主权/国密/行业监管）
- [ ] 已提取预算模式（按需付费/预留实例/混合）
- [ ] 已识别现有基础设施（IDC/私有云/其他公有云/无）
- [ ] 已对照知识库厂商定位完成初步判断（阿里云/腾讯云/华为云/百度智能云/运营商云）
- [ ] 如有信息缺失，已向用户追问不超过2个澄清问题

## Step 2: 输出公有云方案

- [ ] 如为云厂商选型，五大厂商对比已覆盖（核心优势场景/产品矩阵/生态与集成/价格竞争力/合规与信创/全球覆盖）
- [ ] 如为云厂商选型，最终推荐附决策矩阵和关键趋势标注
- [ ] 如为云厂商选型，多云/混合云策略已给出（如适用）
- [ ] 如为云架构设计，Landing Zone治理框架已覆盖（账号体系/网络架构/身份权限/安全基线/成本管控）
- [ ] 如为云架构设计，Well-Architected Framework五支柱评估已输出
- [ ] 如为云架构设计，典型架构模板已给出（高可用Web/容器化微服务/AI训练推理/大数据平台）
- [ ] 如为成本优化，FinOps可视化方案已说明（Kubecost/云厂商成本管家/OpenCost）
- [ ] 如为成本优化，资源优化策略已覆盖（VPA/KEDA/Karpenter/Spot实例）
- [ ] 如为成本优化，预留实例策略已给出（1年/3年/全预付/部分预付/可转换预留）
- [ ] 如为成本优化，成本告警与预算管控已设计（月度预算/异常波动/闲置识别/团队责任制）
- [ ] 如为迁移上云，迁移评估框架已输出（6R分析/数据评估/网络评估/合规评估）
- [ ] 如为迁移上云，迁移路径已给出（试点→批量→切换）
- [ ] 如为迁移上云，数据迁移方案已覆盖（数据库/对象存储/大数据）
- [ ] 如为迁移上云，回滚预案已给出（DNS切回/反向同步/版本回退）
- [ ] 所有核心论断均能在知识库中找到支撑来源

## Step 3: 验证与交付

- [ ] 已读取对应 checklist 并逐项核对
- [ ] 输出内容无知识性错误
- [ ] 已向用户交付最终答案

- [ ] 每一步都已与其检查清单部分进行交叉验证
- [ ] 没有在任何检查清单部分通过前提前进入下一步
