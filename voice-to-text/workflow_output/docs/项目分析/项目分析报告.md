# 项目分析报告 · Voice to Text 实时语音转文字

> Phase 0 产物：商业前置 + 技术选型决策记录（唯一出处）。
> 本文由原根目录「系统音频转文字-开发计划.md」的选型/方案对比/风险章节迁移整合而来。
> **last_updated: 2026-08-04**

## 一、项目定位

开发一款**跨平台桌面实时语音转文字工具**。用户对着麦克风说话（或播放系统音频），文字实时显示在屏幕上；支持录音保存、离线运行。

**核心目标：**

- 离线运行，无需网络（隐私优先）
- 实时流式识别，延迟 < 2 秒
- 安装包体积尽可能小
- 跨 Windows / macOS / Linux

## 二、语音识别引擎选型

### 2.1 方案对比

| 特性 | sherpa-onnx | faster-whisper | whisper.cpp | Vosk |
|------|------------|----------------|-------------|------|
| 实时流式识别 | ✅ 原生支持 | ❌ 需 VAD 分段 | ⚠️ 实验性 | ✅ |
| 中文效果 | 优秀 | 优秀 | 优秀 | 一般 |
| 最小模型 | ~30MB | ~75MB (tiny) | ~40MB (量化) | ~50MB |
| 跨平台 | ✅ | ✅ | ✅ | ✅ |
| 说话人分离 | ✅ (pyannote) | ❌ | ❌ | ❌ |
| Rust API | ✅ (sherpa-rs) | ❌ | ✅ (whisper-rs) | ❌ |
| 授权 | Apache 2.0 | MIT | MIT | Apache 2.0 |

### 2.2 决定：sherpa-onnx（详见 [ADR-001 待补](../adr/README.md)）

**理由：**

1. 唯一同时满足「流式识别 + 轻量模型 + 中文优秀 + 跨平台 + 多语言 API」的方案。
2. 内置 VAD（语音活动检测）。
3. 支持说话人分离。
4. 活跃维护（最新 v1.13.0，2026-04-28）。

**选定模型：**

| 模型 | 语言 | 大小 | 说明 |
|------|------|------|------|
| zipformer-transducer-bilingual（当前使用） | 中英双语 | ~150MB | 流式双语，实际项目采用 small 级别 |
| paraformer-zh-streaming (int8) | 中文 | ~120MB | 流式中文备选 |
| 量化小模型 | 中文 | ~30-50MB | 体积最小，精度略降 |

## 三、GUI 框架选型

### 3.1 三种方案对比

| | 方案 A：Tauri + Rust | 方案 B：Python + PySide6 | 方案 C：Tauri 壳 + Python 核心 |
|---|---|---|---|
| **安装包（不含模型）** | **~3-10MB** | ~80MB | ~35MB |
| **开发效率** | 中（需学 Rust） | **高** | 中 |
| **UI 美观度** | 高（Web 技术） | 高（Qt6） | 高（Web 技术） |
| **性能** | **最好** | 好 | 好 |
| **预计开发周期** | 6-8 周 | **3-4 周** | 4-5 周 |

### 3.2 决定：方案 A（Tauri 2 + Rust + sherpa-rs）

体积最小、性能最好、支持自动更新和系统托盘；代价是需学 Rust。详见 [ADR-002 待补](../adr/README.md)。

**体积明细：**

| 组件 | 体积 |
|------|------|
| Tauri Runtime | < 1MB |
| WebView（系统自带） | 0 |
| sherpa-onnx + ONNX Runtime | ~15-20MB |
| cpal + 音频处理 | ~1MB |
| 前端资源 | ~2MB |
| **安装包总计（不含模型）** | **~20-25MB** |

## 四、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| sherpa-rs 绑定不完善 | 高 | 通过 C FFI 直接调用 sherpa-onnx C API；或改用方案 B/C |
| Rust 学习曲线 | 中 | 选择方案 B（Python）或方案 C（仅前端用 Tauri） |
| 模型体积过大 | 中 | 量化模型 + 首次下载策略 + 提供多档位模型 |
| 中文识别不准 | 中 | 提供多个模型选项，用户可切换 |
| macOS 麦克风权限 | 低 | 引导用户在系统设置中授权 |

## 术语表
