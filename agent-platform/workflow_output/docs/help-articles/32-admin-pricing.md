# 价表配置与阶梯比例（管理员）

> 入口：「计费管理 → 价表配置」。给每个模型定单价；价表改了只影响之后的调用，历史账不变。
> ⚠️ 新模型上线前**先配价**，否则调用会因找不到价表报错。

## 一、新增价表

1. 点「新增」→ 可搜索下拉选「供应商 · 模型」（已有价的同名模型不再出现）。
2. 按类型填价：
   - **对话模型**：输入每百万 token 价 + 输出每百万 token 价（¥）。
   - **视频模型**：选计费方式（按 token / 按秒）+ 填价。
   - **图片模型**：每张价（¥）。
   - **重排模型**：选「知识库重排」，按输入价/百万 token。
3. 设生效时间 → 保存。

## 二、视频模型「有参考/无参考」双价

带参考视频与不带成本不同，可配两行：

1. 第一行：该模型「是否含参考视频」开关**关** → 填无参考价。
2. 再「新增」选同一模型（候选仍在，选项带提示）→ 开关**开** → 填有参考价。
3. 命中规则：任务带参考视频附件 → 有参考价；否则无参考价。只配了一行时另一面兜底用该行（建议两行都配）。
4. 注意：首尾帧参考图**不算**参考视频，只有视频附件才触发「有参考」价。

## 三、导出 / 导入 / 模板（批量配价）

- **导出**：下载当前全部价表 JSON（备份/迁移）。
- **下载模板**：自动把未配过价的模型预填成空白行（已带类型和模型名），填价后导入。
- **导入**：弹预览「新增 N / 更新 M」→ 确认。**同名行价格会被覆盖**、立即生效；单次上限 200 行。

## 四、阶梯比例（¥ → 积分换算）

「阶梯比例」页签定「1 元换多少积分」，可按金额区间设档（充得多换得多）：
- 例：0–100 元 1 元=10 积分；100 元以上 1 元=12 积分。
- 充值和消耗都按命中区间的比例换算。

## 五、删错配的价表行

列表「操作」列「删除」→ 二次确认（显示模型名+有无参考）。⚠️ 删掉某模型唯一价行后，调用它会报「价表缺失」；历史账单不受影响。
