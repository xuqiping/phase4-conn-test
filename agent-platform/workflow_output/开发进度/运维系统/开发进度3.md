## 本轮关键决策与变更

- **webhook "界面" 的落地形态**：Alertmanager 无配置 UI，Grafana 对外部 Alertmanager 联络点只读——等价入口=中文引导 bat（双击填地址即用）。这是用户"界面上留个设置我自己填"诉求的最优实现。
- **up==0 拆两级**：sidecar 未服务化前日常不在跑，一刀切 critical 会告警疲劳（plan 偏离①）。
- **爆破规则改全局速率**：IP 是高基数红线不进 metric tag，单 IP 判定归安全体系限流/审计（plan 偏离②）。
- **Flyway 门禁实现形态**：服务器无 Maven，门禁=启动期迁移失败→健康超时→自动回滚；repair 纪律前置到开发机（写进 deploy.bat 头注释）。
- **备份脚本部署到英文路径**：`D:\IT\ops\backup\`（中文路径+计划任务=乱码炸点红线）；仓库里的脚本仍是版本化真相源。

## 踩坑与排雷

- **git-bash sed 毁 GBK bat**：sed 改写 GBK+CRLF bat 会丢 \r → REM 保护失效 → 中文碎片被当命令执行（实测满屏 'xxx' 不是内部或外部命令）。**改 GBK bat 只能用 PowerShell 字节级读写**。已沉淀 AGENTS.md。
- **kill 后端测试须杀进程树**：mvn spring-boot:run 的父 java 会复活 fork 的子 JVM；查真正监听进程用 `Get-NetTCPConnection -OwningProcess`。
- **cmd 在本环境不解析相对名 bat**：`cmd /c xxx.bat` 报"不是内部或外部命令"，全路径才行（环境怪癖，非脚本问题）。
- **提权进程产物用户态读不了**：C:\Windows\Temp 里 admin 创建的文件非提权读 Permission denied；提权日志要写到用户临时目录。
- **ghproxy.net 镜像支持 Range 可续传**：GitHub 直连/多数镜像极慢（~10KB/s），9.3MB 下了约 20 分钟；大文件还是开代理 7892 靠谱。
