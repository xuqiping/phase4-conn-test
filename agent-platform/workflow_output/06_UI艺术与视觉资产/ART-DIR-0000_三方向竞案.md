# ART-DIR-0000 三方向竞案 · 中国风 UI 重做

> 产物编号：ART-DIR-0000（竞案，待用户批准）｜ 阶段：07 UI 艺术设计
> 依据：AESTH-0001 ｜ 批准后：指定方向转为 ART-DIR-0001 + STYLE-DNA-0001，其余归档
> 三方向均遵守 AESTH-0001 第六节禁忌与第八节红线；差异在**意境浓度与实现成本**。

---

## 方向 A：夜墨（稳健可用）

**一句话**：保留现有深色骨架，把"科技蓝紫"换成"黛蓝墨夜 + 天青点缀"，最小成本完成气质切换。

**视觉语言**
- 色彩：黛蓝底（`#1a2230` 级）、鸦青侧栏、月白正文、天青主色、朱砂仅用于 Logo 印章角标。
- 质感：卡片背景叠 5–8% 透明度的水墨纹理（SVG 噪点），无其他装饰。
- 字体：全站思源黑体；仅登录页品牌语用楷体。
- 动效：维持现状（路由淡入淡出），仅统一缓动曲线。
- 实施面：新增 `styles/themes/ink-wash.scss` 一套 `[data-theme]` + 补齐 Naive `themeOverrides` + 文字/间距 token 主题化。不新增 ART-ASSET（纹理用程序化 SVG）。

**价值**：2–3 天落地，零功能风险，立即摆脱"通用 SaaS 模板感"。
**风险**：意境浓度低，"中国风"感知弱，可能被认为只是换了套深色皮肤。
**成本**：低（纯 token + 一套主题文件）；**适用场景**：想先快速去同质化、后续再迭代的保守路线。

---

## 方向 B：高山流水（品牌签名）★ 推荐

**一句话**：以「宣纸月白（明）/ 黛蓝夜墨（暗）」双主题为载体，完整落地水墨语言——留白栅格、行书标题、朱红印章、水墨空状态——让"高山流水遇知音"成为平台可识别的品牌签名。

**视觉语言**
- 色彩：明=宣纸底 + 墨色正文 + 天青主色；暗=黛蓝底 + 月白正文 + 天水碧选中态；石青/石绿用于图表；朱砂唯一暖色做印章与关键强调；状态色独立不风格化。
- 构图：大留白 + 疏密对比；卡片=宣纸质感微纹理；分隔线用飞白枯笔 SVG 笔触；侧栏与主区间以"远山剪影"渐变过渡。
- 字体：正文思源黑体；页面级标题用行书（开源可商用的「钟齐流江毛笔草体」或「站酷高端黑以外的行书/楷体 WebFont」，子集化后 ≈200–400KB）；空状态短句用行书大字（"高山流水，静候知音"）。
- 意境浓度最高点：登录页（泼墨大背景 + 印章 Logo + 行书 Slogan）、空状态（水墨插画 + 诗意文案）、工作台首屏（晨昏云雾缓动背景层）。
- 动效：云雾级缓动（300–400ms 贝塞尔缓入缓出）、关键操作水墨晕染反馈（按钮按压墨滴扩散 150ms）、骨架屏扫光；全部可经 `prefers-reduced-motion` 关闭。
- 实施面：token 三层重构（原始层换传统色板）+ Naive themeOverrides 全量 + 双主题 + 字体子集化 + 5–8 个 ART-ASSET（登录背景、空状态插画×3、Logo 印章、纹理×2）+ 组件状态核对。

**价值**：形成竞品无人占据的文化记忆点；空状态/登录页成为传播素材；明暗双主题顺带补齐体验短板。
**风险**：① 行书 WebFont 加载性能（需子集化 + `font-display: swap`）；② 水墨纹理与文字对比度需逐页过 WCAG；③ 浅色主题是新工作量（现状纯深色）。
**成本**：中（预估 1.5–2.5 周，含资产生成与回填验收）；**适用场景**：确立长期品牌语言，本次重做就一步到位。

## 方向 C：知音·山水卷轴（突破实验）

**一句话**：把"工作台"做成一幅可漫游的山水长卷——Canvas 生成式水墨背景、Agent 编排画布化作青绿山水图、鼠标行过留墨痕、可配置古琴环境音。

**视觉语言**：在方向 B 基础上叠加：① 生成式水墨背景（Canvas/WebGL shader，晨昏随时间变化）；② 画布模块（vue-flow）节点=山峦、连线=溪流、执行状态=云雾聚散；③ 墨痕光标轨迹；④ 环境音（默认关闭）。
**价值**：demo 即传播，发布会级别的"哇塞"时刻；Agent 编排的视觉隐喻前无古人。
**风险**：B 端效率场景动效过载风险高；WebGL 背景有性能与兼容性成本；生成式水墨质量不稳定；可访问性需额外专项。
**成本**：高（4 周+，且需性能专项）；**适用场景**：仅建议作为登录页/营销页/工作台首屏的**局部实验**，或在方向 B 稳定后作为二期探索。

## 对比总览

| 维度 | A 夜墨 | B 高山流水 ★ | C 山水卷轴 |
|---|---|---|---|
| 意境浓度 | ★☆☆ | ★★☆ | ★★★ |
| 落地周期 | 2–3 天 | 1.5–2.5 周 | 4 周+ |
| 功能风险 | 无 | 低（纯皮肤层） | 中（性能/干扰） |
| 品牌差异化 | 弱 | 强 | 极强 |
| 资产需求 | 0（程序化纹理） | 5–8 个 ART-ASSET | 10+ 含生成式 |
| 明暗双主题 | 仅暗 | 明+暗 | 明+暗+动态 |
| 推荐定位 | 过渡方案 | **本次目标** | 二期局部实验 |

## 建议

**选 B（高山流水）为主方向**，吸收 C 的一个低风险元素——工作台的"晨昏云雾"静态背景层（图片而非 WebGL）作为品牌签名时刻；C 的生成式画布留作二期。A 的全部工程产出（token 三层化 + themeOverrides 层）天然包含在 B 内，不浪费。
