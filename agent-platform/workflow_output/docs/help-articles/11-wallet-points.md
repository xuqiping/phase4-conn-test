# 我的钱包：余额、扣费、自助充值

> 平台用「积分」计量你调用 AI 的消耗。入口：左侧菜单「**我的钱包**」。

## 一、看余额和流水

1. 打开「我的钱包」，顶部**余额卡片**显示当前积分。
2. 下方**流水列表**每行一笔变动：时间、类型（充值/消耗/退款/管理员发放）、变动量、变动后余额、来源说明。
3. 点「**我的用量**」看每次调用的消耗明细。

> 你只看见积分，看不见 token 和人民币金额（那是管理员视图）——不是算错，是分权设计。

## 二、什么动作扣积分（全自动，无需操作）

- 聊天对话：按模型 × 实际 token 扣。
- 知识库问答：检索 + 回答都计。
- 视频生成：按 token 或按秒；图片生成：按张。
- **失败的调用自动全额退款**（流水里有一条「退款」）。

## 三、余额不足怎么办

余额 ≤0 时发起 AI 调用会被拦截，提示积分不足。两个办法：

1. **自助充值**（推荐，见下）。
2. 找管理员人工充值。

> 余额低（默认低于 100）时还能用，但**同时只能跑一个任务**——等当前任务跑完再发下一条。

## 四、自助充值

1. 「我的钱包」右上角点「**充值**」（看不到按钮 = 平台暂未开通支付渠道，找管理员代充）。
2. 输入**金额**（¥0.01 ~ ¥99999.99）→ 选支付渠道 → 点「去支付」。
3. 收银台页面完成支付；页面每 2 秒自动查结果，不用手动刷新。
4. 提示「支付成功，积分已入账」→ 余额立即增加；「充值记录」出现一行明细。
5. 中途不想付了：点「取消订单」；不取消 30 分钟后订单自动关闭，**不扣钱**。

**常见异常**：
- 提示「重复提交金额不一致」：关掉弹窗重开即可（原订单仍有效）。
- 支付后长时间显示「待支付」：在充值记录里核对；实际已扣款但订单显示已关闭 → 联系管理员人工补单。
- **双击/网络重试不会双扣**：同一笔提交只到账一次。

## 五、计入项目组

页顶「参与项目」下拉选了某个项目组后，消耗改扣**组池积分**（个人钱包不动），页顶显示「组池 / 个人」两个余额；切回「个人」即恢复。详见「项目组与积分划拨」篇。

## 常见问题

**Q：刚发了消息余额没变？**
A：流式回答要等整条结束才扣。久久不变就查流水有没有对应「消耗」行。

**Q：管理员改价会影响我之前的账吗？**
A：不会。改价只影响之后的调用，历史账固定。

**Q：流水能被后台改掉吗？**
A：不能。流水只增不改，系统每天自动对账抓异常。
