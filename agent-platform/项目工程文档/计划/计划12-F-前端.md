## 动作（伪代码）
1. **MemoryManagerPanel 三页签**：
   - 流水账：列表 + raw 查看/批量删除（仅本人无导出）+ 挂载项目 + 撤回（12h 规则提示）。
   - 总结：列表 + provenance 展示（逐条 scope 校验）+ 状态徽标（CLEAN/PENDING_CONFLICT/STALE）。
   - 标签库：subject:topic + label + usage_count；owner 可改 label/补 aliases（不露 anchor）。
2. **MemoryConflictJudgeDialog 四选项**：KEEP_BOTH（提示自动排序）/ KEEP_NEW / KEEP_OLD / DISCARD（**二次确认：将连带删除相关流水账**）；DISCARD 失败 403 时提示「他人已引用超 12h，建议 KEEP_OLD」。
3. **RagMemorySettingsTab**：gen 开关矩阵（owner 项目级 + 会员覆写）+ 统一「开始总结」按钮 + raw 管理 + 顶端说明条（M3 文案）+ 一键关。
4. **ChatView 底栏**：召回 scope 多选（持久化）+ 写入目标多选（默认勾个人）+ 离职开关 + 时间窗/方向。
5. **MemoryLifecyclePanel**：已删除项目折叠板（badge 高亮 + 通知 3s 轮询 + restore 新项目拉 turn）；已离开项目折叠板（copy-to 自建新项目）；波及通知 badge。
6. **MemoryAlertBadge**：未总结 >100 → 记忆面板/总结页签高亮，点开详情 + 「立即总结/加入每日自动」入口。
7. **移动端适配**：汉堡/抽屉导航 + 弹窗/表格/筛选机械扫荡；390px 实测。
