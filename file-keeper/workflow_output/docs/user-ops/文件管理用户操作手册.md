# 文件管理用户操作手册

> 本手册覆盖收藏独立快捷键和 Windows `.lnk` 托管。已进入 Phase 4；自动化通过，M1—M6、L1/L2、E1/E2 真实系统交互待用户确认。

## 拖入收藏

1. 将文件夹、PPT/PPTX、普通文件、EXE 或 `.lnk` 拖到文件管理区。
2. 等待收藏卡片出现。

界面变化与结果：

- 只有 Windows `.lnk` 会复制到应用托管目录；源快捷方式删掉后收藏仍可用。
- 文件夹、PPT、普通文件和非快捷方式 EXE 只保存原路径，应用不会复制或删除原件。
- 导入失败时不新增收藏，也不留下半成品托管文件。

## 设置独立快捷键

1. 打开某个收藏的编辑窗口。
2. 在快捷键输入框按下组合键并保存。
3. 在其他窗口中按该组合键。

预期结果：对应收藏被打开并更新使用统计。若与主窗口、剪贴板、截图或其他收藏冲突，保存被拒绝并指出冲突用途；系统注册失败时旧快捷键仍可用。清空输入并保存会注销该收藏快捷键。

## 重新定位失效收藏

1. 收藏显示失效后打开编辑窗口。
2. 点击重新定位并选择新的目标或快捷方式。
3. 保存。

预期结果：收藏名称、分组、标签、快捷键和统计保留，仅打开目标更新。

## 删除收藏

- 删除普通文件、文件夹、PPT 或 EXE 收藏：只删收藏记录，原件不变。
- 删除托管 `.lnk` 收藏：先删收藏记录，再只清理应用能证明归属的托管副本。
- 取消删除：不发生任何写入。

> 真实带参数、中文、UNC、失效 `.lnk` 与系统占键按 Phase 4 M1—M6、L1/L2、E1/E2 执行。
