# 画布与视频生成 · 测试问题修复2 · 开发进度7

> 承 [开发进度6.md](./开发进度6.md)。本篇记 **脚本拆分镜→分镜节点自动生成（第 6 类节点）**（2026-08-09）。

## 背景

人工测试反馈：画布脚本节点点「拆分镜」后，画布上什么都不显示。

**根因**（playwright + 代码深挖确认）：当前拆分镜把 `scenes[]` 原地塞回**脚本节点自己的 data**（后端 dataPatch），前端 `onRunNode` 只 `updateNodeData` 合并进同一节点——零子节点、零连线。面板仅回显「已拆 N 分镜」计数，分镜内容埋在 data 里看不见。

用户需求：
1. 拆出的每个分镜 **自动生成独立分镜节点**挂画布、与脚本**扇出**连线（脚本→各分镜独立分支）。
2. 新增第 6 类节点「分镜」（原仅文本/图片/视频/音频/脚本 5 类）。
3. 分镜节点可存入资产库「分镜」分类。
4. 脚本节点加**拆分段数** + **拆分规范**两参数（规范空则 LLM 自由发挥）。
5. 重拆时**替换**旧分镜子节点。

资产库**已有** `MEDIA_STORYBOARD="分镜"` 分类，但画布 node→asset 映射无 storyboard 行。注意命名：「故事板」抽屉（视频拼接 concat）≠ 本次新增「分镜节点」。

### F2 拆分后扇出生成分镜节点（核心，commit `11f36c71`）

**CanvasBoard.vue 命令式 API 改造**：
- `addNode`：① 返回新节点 id（原不返回，批量连线靠取数组末尾不可靠）；② id 加 `seqCounter` 序号后缀防批量撞（脚本拆分镜同毫秒连调 N 次，`Date.now()` 相同会撞 id → vue-flow 重复告警 + 渲染错乱）。
- `defineExpose` 加暴露 `removeNodes`（重拆替换旧分镜用）。

**CanvasView.vue 新 `onSplitStoryboard(node)`**（替代脚本走通用 `onRunNode`）：
1. `interpolateForRun` 插值 @占位符 → `canvasApi.runNode`（type=script，data 带 segmentCount/storyboardSpec）。
2. 成功取 `result.dataPatch.scenes`：
   - **替换旧分镜**：`getNodes().filter(sourceScriptId===node.id && autoGenerated)` → `removeNodes(ids)`（连相关 edge 一并清）。
   - **扇出生成**：遍历 scenes，`addNode({type:'storyboard', position:{x:sx+320, y:sy+i*175}, data:{label:分镜N, index, description, sourceScriptId, autoGenerated:true, status:'success'}})` → 拿返回 id → `addEdge(node.id, id)`（扇出：脚本→各分镜）。
   - 仍合并 dataPatch.scenes 进脚本节点 data（保「已拆 N 分镜」计数 + 记录）。

**PropertyPanel.vue**：脚本节点「拆分镜」按钮 `@click` 由 `emit('run')` 改 `emit('split-storyboard')`（新事件），CanvasView `@split-storyboard="onSplitStoryboard"` 接线。
