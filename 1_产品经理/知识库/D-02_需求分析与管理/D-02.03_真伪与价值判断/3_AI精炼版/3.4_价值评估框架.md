# 3.4 价值评估框架

## 三维价值评估模型

```
需求价值 = 用户价值 × 商业价值 ÷ 实现成本
```

### 维度1：用户价值

| 指标 | 计算方法 | C端示例 | B端示例 |
|---|---|---|---|
| **影响面** | 受影响用户/总用户 | 30%活跃用户 | 5个大客户(占收入40%) |
| **频次** | 周/月使用频次 | 3次/周 | 每日必用 |
| **痛点强度** | 1-5分（访谈/数据） | 4分(流失率12%) | 5分(客户投诉3次/月) |
| **替代方案质量** | 有/有但差/无 | 有但差(手动导出) | 无(只能发邮件) |

### 维度2：商业价值

| 来源 | C端 | B端 |
|---|---|---|
| **直接收入** | 付费转化/ARPU提升 | 客单价提升/新签 |
| **留存价值** | 降低流失率×LTV | 降低客户流失率×续约金额 |
| **增长价值** | 推荐/传播/新用户获取 | 客户口碑/案例背书 |
| **降本价值** | 减少客服/运营成本 | 减少实施成本/培训成本 |
| **战略价值** | 生态扩展/竞品壁垒 | 平台化/行业标准化 |

### 维度3：实现成本

| 成本项 | 计算方法 | 说明 |
|---|---|---|
| **开发成本** | 人天×日均成本 | 前端+后端+测试 |
| **设计成本** | 人天×日均成本 | UX+UI+原型 |
| **维护成本** | 年维护人天×持续年数 | Bug修复+适配+迭代 |
| **机会成本** | 不做其他需求的机会损失 | 同等资源做哪个需求回报更高 |
| **风险成本** | 失败概率×失败损失 | 做出来没人用的概率 |

## B端 vs C端价值评估差异

| 维度 | C端评估特点 | B端评估特点 |
|---|---|---|
| **价值单位** | 单用户价值×用户量 | 单客户价值×客户数(差异极大) |
| **付费模式** | 小额×大量 | 大额×少量 |
| **决策者** | 用户≈决策者 | 使用者≠采购者≠决策者 |
| **价值感知** | 即时体验(秒/分钟级) | 长期效率(周/月级) |
| **替换成本** | 低(秒级卸载) | 高(数据/流程/培训迁移) |
| **评估重点** | 留存/传播/ARPU | 续约率/客单价/实施成本 |

## 价值评估的反模式

| 反模式 | 表现 | 正解 |
|---|---|---|
| **只看用户价值不看成本** | "用户很需要！"(但开发3个月) | 用户价值÷成本=净价值 |
| **只看商业价值不看用户价值** | "这个能赚钱！"(但伤害用户体验) | 短期变现≠长期价值 |
| **低估维护成本** | "开发2周就完事"(维护2年) | 维护成本≈开发成本的3-5倍/年 |
| **高估影响面** | "所有用户都会用"(实际5%) | 用数据而非假设估算影响面 |
| **忽略机会成本** | "反正也要做"(同等资源做另一个需求价值更高) | 对比多个需求的ROI |
