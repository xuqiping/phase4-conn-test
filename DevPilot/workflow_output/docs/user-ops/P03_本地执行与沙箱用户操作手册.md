# P03 本地执行与沙箱 · 用户操作手册

> 面向使用 DevPilot 桌面端的开发者：如何在本地安全地跑任务、管理环境、审批危险操作、配置 Secrets。

## 1. 环境一键安装（FR-005/AC-006）

### 入口
打开项目 → 侧边栏「环境安装」或项目卡片进入详情页后显示 `InstallWizard`。

### 操作步骤
1. DevPilot 自动扫描项目根目录，识别 `package.json` / `requirements.txt` / `Cargo.toml` 等技术栈。
2. 若缺少 Node / Python / Rust 等运行时，面板列出缺失项和对应安装命令。
3. 点击「一键安装」，逐个执行命令。
4. 每步显示 ✅ 成功或 ❌ 失败；失败时 stderr 直接展开，可手动复制命令排查。

### 预期结果
- 全部安装成功：显示「已识别运行时/依赖齐备」。
- 某一步失败：后续步骤停止；可修复网络/权限后再次点击安装。

### 边界
- MVP 支持 Node、Python、Rust；Go/Ruby/Php 会识别但安装命令可能不够完整。
- Windows 推荐已配置 winget/scoop；macOS 需 brew；Linux 需 apt。

## 2. 配置 Secrets（FR-012/AC-014）

### 入口
项目详情页 → 「Secrets 管理」面板。

### 操作步骤
1. 在「名称」输入框填 `api_key`（大小写不敏感，注入时会自动转大写）。
2. 在「值」输入框填 secret（密码框，界面上不可见）。
3. 点击「添加」。
4. 后续 runner 执行任务时，进程内会多一个环境变量 `DEVPILOT_SECRET_API_KEY`。
5. 如需修改：点击列表右侧「编辑」，输入新值后点「更新」。
6. 如需删除：点击「删除」并确认。

### 预期结果
- 列表只显示名称，不显示值。
- 任务输出中若出现 secret 原文，会自动替换为 `***`。
- 值优先存 OS 凭据管理器；不可用则 AES-256-GCM 加密落本地库。

### 边界
- Secret 名称只支持字母、数字、下划线；前端未强校验，请勿带空格或特殊符号。
- 注入的变量名统一为 `DEVPILOT_SECRET_<NAME>`。

## 3. 执行构建任务（FR-003 + 状态机联动）

### 入口
项目进入「建造」阶段后，页面顶部/操作区出现「🚀 执行构建并推进到验收」按钮。

### 操作步骤
1. 确保项目当前阶段为「建造」（如不在，先通过状态机推进到 build）。
2. 点击「执行构建并推进到验收」。
3. DevPilot 自动：
   - 复用/新建一轮次；
   - 探测技术栈并执行 `npm test` / `cargo test` / `pytest` / `go test`；
   - 成功后 `git commit` 一个 `devpilot: 自动构建` 存档点；
   - 自动把项目推进到「验收」阶段。
4. 若测试失败：项目留在「建造」阶段，页面显示失败提示和 exit code。

### 预期结果
- 成功：阶段条从「建造」变为「验收」，可继续后续流程。
- 失败：阶段不变，可查看 stderr、修复代码后再次执行。

### 边界
- MVP 不自动修复测试失败；需用户手动改代码或后续接入 LLM 修复策略。
- 若项目没有可识别的测试命令，runner 会直接成功并推进阶段。

## 4. 审批危险操作（FR-009）

### 入口
当某次操作命中危险命令清单（如删除、curl \| sh、改系统目录）时，前端弹出审批窗口；或在「待审批」面板查看。

### 操作步骤
1. 审批弹窗显示操作标题、详情、风险等级（Normal / Dangerous / Critical）。
2. 点击「允许」或「拒绝」。
3. 允许后操作继续执行；拒绝后操作终止。

### 预期结果
- 自动策略下：普通命令直接放行，危险命令弹窗。
- 手动策略下：任何命令都弹窗。
- 审批记录持久化，未解决的审批可在列表中查看。

### 边界
- MVP 审批通过 Tauri 命令 `create_approval` / `submit_approval` 管理；runner 自动审批集成预留到后续迭代。

## 5. 查看文件读写（FR-001）

DevPilot 所有文件操作默认只能在项目目录内进行；越界读写会被沙箱拒绝并返回大白话错误（如「路径试图逃逸出项目目录」）。

### 常见提示
- 「路径不在项目白名单内」：你或 AI 试图访问项目外文件。
- 「命中敏感目录黑名单」：试图读写 `~/.ssh`、系统目录等。

## 6. 故障排查速查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 安装命令无法启动 | 缺少包管理器或不在 PATH | 手动安装 winget/scoop/brew/apt 后重试 |
| runner 测试 exit=None | 测试命令不存在（如未装 npm） | 先跑「一键安装」 |
| Secret 注入后程序读不到 | 变量名大小写或名称含特殊字符 | 检查环境变量名 `DEVPILOT_SECRET_XXX` |
| 构建成功但阶段未推进 | 状态机并发被其他操作修改 | 刷新状态后重试 |
| cargo audit 本地失败 | 网络受限 | CI 环境会兜底硬拦截，本地不影响提交 |
