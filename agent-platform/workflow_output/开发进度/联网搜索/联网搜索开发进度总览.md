# 联网搜索 开发进度总览

> 功能入口。SDD 视角全貌。
> 实现计划：[../../docs/plans/联网搜索.plan.md](../../docs/plans/联网搜索.plan.md)

## 目标

CHAT 模式下用户开 `🌐联网` 开关 → 后端按 query 联网检索 → 结果注入 system context → LLM 带引用[n]作答 → 复用 CITATION 事件回显。解决 LLM 训练截止导致时效问题答错（如"今天日期"）。

双引擎：**外部可插拔供应商**（Tavily/Serper/Bing）+ **自建引擎**（SearXNG + Jsoup+Readability，对标 Tavily）。无 key 时自建兜底。

## 架构决策（brainstorming 锁定）

| 决策点 | 选择 | 理由 |
|---|---|---|
| 触发方式 | 用户开关手动触发 | 不建 tool-calling 基建，1 周可上线 |
| 外部供应商 | 可插拔多供应商 | 学现有 LlmProvider 范式 |
| 自建数据源 | 自部署 SearXNG 元搜索 | 抗封 + 质量近 Tavily |
| 正文抽取 | Jsoup + 自实现 Readability | 对标 Tavily extract |
| 模式范围 | 仅 CHAT | Agent/Workflow 留扩展点 |

## 关键基建复用

- `StreamEvent.CITATION` + `MessageBubble` 引用回显（KB 已用）
- ChatView 3 态下拉开关模式（记忆模式已用）
- `SystemSettingService` + `AesEncryptService`（provider key 存储已用）
