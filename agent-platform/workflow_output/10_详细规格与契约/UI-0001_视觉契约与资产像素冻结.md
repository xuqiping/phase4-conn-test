## 一、UI-0001 视觉契约要点

### 1. 组件状态覆盖（每个改动组件必须七态齐全）

`default / hover / focus(焦点环) / pressed / disabled / empty / error / loading` ——水墨风最易漏 disabled 与 empty，验收时逐组件核对（D-14.02）。权限不足态独立于 disabled（锁定图标+申请路径文案）。

### 2. 主题行为

- 主题名：`ye-mo`（夜墨·暗）、`xuan-zhi`（宣纸·明）；旧三主题保留可切换。
- 切换即时生效、无闪白；选择持久化（localStorage）；Naive `themeOverrides` 与 `[data-theme]` 同源同切。
- 字体加载失败 → 回退系统字体栈且布局不抖动（`font-display: swap` + 尺寸近似兜底 `size-adjust`）。

### 3. 可判定 AC（摘）

- AC-01：当切换 `ye-mo`/`xuan-zhi` 时，全站（含 Naive 组件）无旧科技蓝紫色残留，否则判 FAIL。
- AC-02：正文/控件文字对比度自动检测 100% ≥4.5:1（亮/暗各跑一次），否则 FAIL。
- AC-03：开启 `prefers-reduced-motion` 时，云雾层、墨滴扩散、扫光全部静止，否则 FAIL。
- AC-04：3G 弱网节流下首屏不白屏、字体 swap 后无布局偏移（CLS 增量 <0.02），否则 FAIL。
- AC-05：书法体仅出现在页面标题/空状态/登录品牌位，任意页面出现第二处即 FAIL。
- AC-06：状态色（成功/警告/错误/信息）与品牌朱砂在任意页面不同框混淆，否则 FAIL。
