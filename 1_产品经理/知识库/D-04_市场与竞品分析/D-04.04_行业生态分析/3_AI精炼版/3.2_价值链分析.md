# 价值链分析

## 一、价值链分析是什么

价值链分析（Value Chain Analysis）是理解"价值在产业链各环节中如何创造、传递和分配"的方法论。它回答3个核心问题：

1. **谁创造了价值？** —— 产业链中哪个环节是价值的主要创造者
2. **谁获取了价值？** —— 利润最终流向了哪里
3. **价值在怎样转移？** —— 利润池正在从哪个环节向哪个环节迁移

## 二、三大理论工具

### 工具1：Porter企业内价值链

```
 ┌────────────────────────────────────────────────┐
 │              利  润  =  差值                      │
 │                                                  │
 │  基本活动：内部物流→生产运营→外部物流→营销销售→服务  │
 │                                                  │
 │  支持活动：企业基础设施/人力/技术开发/采购            │
 └────────────────────────────────────────────────┘
```

**PM适用版**：将企业内9个活动简化为PM可操作的5个价值创造点

| 价值创造点 | 对应PM动作 | 价值衡量 |
|---|---|---|
| 需求洞察 | 用户研究、市场分析 | 需求命中率 |
| 产品设计 | 功能定义、交互设计 | 功能使用率 |
| 技术实现 | 技术选型、架构决策 | 研发效率 |
| 传播分发 | 渠道策略、增长手段 | CAC/LTV |
| 用户运营 | 留存、续费、口碑 | NPS/续费率 |

### 工具2：微笑曲线（产业级）

```
利润率
  ↑
高│  ○ 研发/设计                    ○ 品牌/营销
  │      \                          /
  │        \                        /
低│          ○———○———○———○———○———○
  │         制造  组装  代工  分销
  └──────────────────────────────────→ 产业链位置
```

**核心洞察**：
- 产业链两端（研发+品牌）利润最高
- 中间环节（制造+组装）利润最低
- **PM的战略含义**：向微笑曲线两端移动，或帮助产业链中间环节"升级"

### 工具3：价值迁移（Slywotzky）

价值迁移7阶段模型：

| 阶段 | 价值流入 | 价值稳定 | 价值流出 |
|---|---|---|---|
| 信号 | 用户需求向新模式转移 | 当前模式仍有吸引力 | 获客成本上升/利润率下降 |
| 典型 | AI搜索→传统搜索（2025-） | App Store生态（2015-2022） | PC软件零售→SaaS（2010-2015） |

**PM关键动作**：识别你所在行业处于价值迁移的哪个阶段，提前布局下一个价值流入方向。

## 三、价值链分析实战步骤

### Step 1：拆分产业链环节

列出行业从原材料到终端用户的全部环节，每环节标注：
- 参与者数量（多/少/寡头）
- 平均利润率
- 增长速度
- 进入门槛

### Step 2：标注价值流向

- 用箭头标注价值（利润）的流向方向
- 粗箭头 = 大量价值流向，细箭头 = 少量
- 标注"定价权"归属（谁说了算）

### Step 3：识别价值迁移信号

| 信号 | 含义 |
|---|---|
| 头部玩家纵向整合 | 试图控制更多价值链环节 |
| 新技术从下游向上游渗透 | 价值向上游转移 |
| 中间商被平台化替代 | 价值向平台聚集 |
| 消费者直接参与创造 | 价值向用户端转移 |

### Step 4：评估你的生态位

在价值链中的位置决定了你的战略选项：

| 你的位置 | 战略选项 | 风险 |
|---|---|---|
| 高利润区 | 防守+扩展 | 被新技术替代 |
| 低利润区 | 向上/下游延伸 | 投入大+不确定 |
| 枢纽位置 | 平台化 | 多方博弈复杂 |
| 边缘位置 | 差异化/细分聚焦 | 天花板有限 |
