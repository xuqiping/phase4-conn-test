# 反馈处理台（管理员）

> 入口：侧栏「反馈处理」。两个页签：建议审核 / 提问回答。

## 一、建议审核

1. 默认「建议审核」页签，可按状态筛（待审核/已采纳/未采纳/已关闭）。
2. 点「审核」→ 详情弹窗（用户、正文、附件缩略图可点放大）。
3. 填回复（可选）→ 点 **采纳 / 不采纳 / 关闭** → 用户收到铃铛通知。
4. 已采纳的要改判不采纳 → 会弹**二次确认**，确认后改判并重新通知用户。
5. 「已关闭」是终态，不可再改。

## 二、提问回答

1. 切「提问回答」页签 → 点「回答」。
2. 回答弹窗：写答案（markdown，可预览）+ 「**公开到 FAQ**」开关。
3. 提交 → 用户收到通知；勾了公开则全平台用户 FAQ 可检索到（提问人已脱敏）。
4. 已答的问题点「改答案」→ 回填旧答案修改 → 保存**不重复通知**用户。

## 注意

- 两名管理员同时处理一条 → 后提交者看到「已被其他管理员处理」，列表自动刷新，属正常（防抢态）。
- FAQ 公开视图天然不含提问人身份，无需额外打码。
