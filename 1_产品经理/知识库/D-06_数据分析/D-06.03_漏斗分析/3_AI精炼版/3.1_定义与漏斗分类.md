# 3.1 定义与漏斗分类

## A.01 核心定义

**漏斗分析（Funnel Analysis）** 是一种追踪多步骤流程中用户逐层转化与流失的数据分析方法，通过量化每一步的转化率，直观呈现用户从进入到完成的递减趋势。概念可追溯至1898年St. Elmo Lewis提出的AIDA(注意→兴趣→欲望→行动)模型。[来源: 百度百科/营销学史 | 置信度:🔍高]

**一句话定位**：漏斗分析是产品的"X光片"——看清楚用户在哪一步健康地走过、在哪一步"骨折"流失。

## A.04 边界与不含什么

**漏斗分析包含**：漏斗构建、转化率解读、流失定位、漏斗对比、微转化分析、漏斗优化。

**漏斗分析不含**：指标体系设计（→D-06.01）、数据采集技术（→D-06.02）、留存分析（→D-06.04）、路径发现（→D-06.05）、因果推断（→D-06.06）。

## I.01 核心术语

| 术语 | 定义 |
|---|---|
| 漏斗步骤(Funnel Step) | 用户流程中的一个关键节点（如"查看商品""加入购物车"） |
| 转化率(Conversion Rate) | 从步骤N到步骤N+1的用户比例 |
| 整体转化率(Overall CR) | 从漏斗第一步到最后一步的累计转化率 |
| 步骤转化率(Step CR) | 相邻两步之间的转化率 |
| 流失率(Drop-off Rate) | 1-步骤转化率，从步骤N流失到不去步骤N+1的比例 |
| 时间窗口(Time Window) | 允许用户完成下一步的最大时间间隔 |
| 严格顺序(Strict Order) | 步骤必须按指定顺序依次发生 |
| 闭合漏斗(Closed Funnel) | 同一用户必须在同一会话/时间内按序完成所有步骤 |
| 开放漏斗(Open Funnel) | 步骤之间无严格时间和顺序限制 |

## I.03 四大漏斗类型

### 1. 主路径漏斗（Core Funnel）

产品核心转化路径的完整漏斗。

```
注册 → 首次使用 → 核心动作 → 付费 → 续费
```

- **用途**：度量产品整体健康度、识别最大瓶颈
- **步骤数**：通常4~7步

### 2. 微转化漏斗（Micro-Conversion Funnel）

主路径中某一关键步骤的深度拆解。

```
首页 → 搜索 → 结果浏览 → 筛选 → 详情页
```

- **用途**：精确定位某一步骤内的微观流失点
- **步骤数**：通常3~5步，粒度更细

### 3. 逆向漏斗（Reverse Funnel）

从终点回溯，看成功用户经历了什么。

```
付费用户 ← 完成新手引导 ← 首日完成3个核心动作 ← 注册来自XX渠道
```

- **用途**：发现成功用户的共性行为路径
- **与正向漏斗区别**：正向看"哪些人流失了"，逆向看"成功者做了什么"

### 4. 时间漏斗（Time-Based Funnel）

按时间维度分析转化速度。

```
注册后0-1h激活 → 1h-24h首次付费 → 1天-7天复购
```

- **用途**：评估转化效率、确定最佳干预时机
- **关键指标**：每步中位时间、P90时间
