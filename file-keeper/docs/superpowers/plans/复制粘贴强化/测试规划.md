# 复制粘贴强化功能测试规划

更新时间：2026-05-31

## 目标

验证 File Keeper 本地复制粘贴强化功能在 Windows 桌面端可稳定完成采集、展示、搜索、选择、复制、删除、文件定位、安全防护和设置管理。

本规划只覆盖本地功能，不覆盖云同步、账号体系、跨设备同步等后期能力。

## 测试分层

1. 自动化单元测试
   - 前端 API 封装测试。
   - 前端 Pinia 状态测试。
   - 前端 Vue 组件交互测试。
   - Rust 剪贴板服务、存储、搜索、安全、缓存策略测试。

2. 构建和编译验证
   - 前端 TypeScript 类型检查和 Vite 构建。
   - Rust cargo test。
   - Rust cargo check。
   - Tauri 桌面启动验证。

3. 桌面端实机回归
   - 真实系统剪贴板读写。
   - Tauri 窗口内列表刷新。
   - Windows 文件目录打开。
   - 快捷键与鼠标交互。

## 核心功能测试用例

### 1. 文本采集与实时刷新

步骤：
1. 打开 File Keeper 剪贴板页面。
2. 在系统任意位置复制一段普通文本，例如 `hello clipboard`。
3. 观察剪贴板列表。

预期：
- 列表自动刷新，不需要手动切换页面或重启应用。
- 新记录出现在列表顶部。
- 记录类型显示为“文本”。
- 详情区能看到对应文本内容。

### 2. 重复文本策略

步骤：
1. 复制文本 `repeat text`。
2. 复制另一段文本 `another text`。
3. 再次复制 `repeat text`。

预期：
- `repeat text` 不新增第二条重复记录。
- 原有 `repeat text` 记录刷新到列表顶部。
- 列表中只存在一条 `repeat text`。

### 3. 单条复制

步骤：
1. 在剪贴板列表中选择一条文本记录。
2. 点击详情区“复制”。
3. 到记事本或任意输入框粘贴。

预期：
- 页面顶部显示“已复制到剪贴板”。
- 粘贴内容与选中记录一致。

### 4. 双击复制

步骤：
1. 在列表中双击一条记录。
2. 到输入框粘贴。

预期：
- 页面顶部显示复制成功提示。
- 系统剪贴板内容更新为该记录内容。

### 5. 右键复制

步骤：
1. 在列表中右键一条记录。
2. 点击“复制”。
3. 到输入框粘贴。

预期：
- 页面顶部显示复制成功提示。
- 系统剪贴板内容与右键记录一致。

### 6. 多选批量复制

步骤：
1. 勾选多条文本记录。
2. 点击顶部工具栏“批量复制”。
3. 到输入框粘贴。

预期：
- 页面顶部显示“已复制 N 条记录到剪贴板”。
- 粘贴内容按列表可见顺序排列。
- 多条内容之间使用换行分隔。

### 7. Ctrl+C 快捷复制

步骤：
1. 勾选多条记录。
2. 确保焦点不在搜索框、输入框、下拉框或可编辑区域中。
3. 按 Ctrl+C。
4. 到输入框粘贴。

预期：
- 页面顶部显示“已复制 N 条记录到剪贴板”。
- 粘贴内容为已勾选记录的批量内容。
- 当焦点在搜索框中时，Ctrl+C 不应被页面拦截。

### 8. 选中与取消选中样式

步骤：
1. 点击一条记录。
2. 观察复选框和绿色选中框。
3. 再次点击同一条记录。

预期：
- 第一次点击后记录被勾选，并显示绿色选中框。
- 第二次点击后复选框取消勾选，绿色选中框立即消失。
- 详情区可继续显示最近查看的记录，但不应造成绿色勾选样式残留。

### 9. 全选、反选、取消选择

步骤：
1. 点击“全选”。
2. 点击“反选”。
3. 点击“取消选择”。

预期：
- 全选只选择当前可见列表中的记录。
- 反选只反转当前可见列表中的记录。
- 取消选择后所有勾选框清空，绿色选中样式消失。

### 10. 顶部工具栏置顶

步骤：
1. 准备较多剪贴板历史记录。
2. 在剪贴板列表中向下滚动。

预期：
- 顶部批量操作工具栏固定在列表顶部。
- 工具栏不随记录列表滚走。
- 工具栏不遮挡第一条可见记录的主要内容。

### 11. 删除单条记录

步骤：
1. 右键一条记录。
2. 点击“删除”。

预期：
- 该记录从列表中消失。
- 如果删除的是当前详情记录，详情区切换到下一条或清空。
- 删除按钮样式为柔和危险色，不应过艳。

### 12. 批量删除

步骤：
1. 勾选多条记录。
2. 点击“删除选中”。

预期：
- 选中的记录全部从列表中消失。
- 未选中的记录保留。
- 选中状态同步清空或移除已删除项。

### 13. 搜索防抖

步骤：
1. 在搜索框输入一个字符。
2. 不按回车，等待短暂时间。

预期：
- 列表自动按输入内容搜索。
- 搜索不需要手动点击按钮。
- 快速连续输入时不应频繁卡顿。

### 14. 类型筛选

步骤：
1. 分别点击“文本、富文本、图片、文件、链接、颜色、安全事件”等筛选项。

预期：
- 列表只显示对应类型记录。
- 全选、反选、批量复制、删除选中只作用于当前可见结果。

### 15. 多类型记录复制

步骤：
1. 准备链接记录，例如 `https://example.com/path`。
2. 准备颜色记录，例如 `#22c55e`。
3. 准备富文本、文件、图片 OCR 记录。
4. 分别执行右键复制或详情复制。

预期：
- 链接记录复制 URL。
- 颜色记录复制十六进制颜色值。
- 富文本记录复制可读文本或 Markdown 形式内容。
- 文件记录复制文件路径。
- 图片记录优先复制 OCR 文本，没有 OCR 时复制图片路径。
- 无可复制内容时显示明确失败提示。

### 16. 打开文件目录

步骤：
1. 准备文件类型记录。
2. 右键文件记录。
3. 点击“打开文件目录”。

预期：
- 系统文件管理器打开对应文件位置。
- 非文件类型记录不显示该菜单项。
- 路径不可用时后续应显示失败提示。

### 17. 安全内容拦截

步骤：
1. 复制银行卡号、疑似 Token、私钥片段或密码管理器来源内容。
2. 查看剪贴板列表。

预期：
- 敏感内容不以普通文本保存。
- 列表显示安全事件。
- 详情不泄露原始敏感内容。

### 18. 设置页

步骤：
1. 打开“剪贴板设置”。
2. 修改自动粘贴、OCR、URL 预览、空间上限、后缀规则等设置。
3. 选择自定义备份目录并保存。
4. 保存后重新打开设置页。

预期：
- 设置能保存并回显。
- URL 预览默认关闭。
- 未配置文件后缀规则时默认允许所有后缀。
- 自动粘贴关闭时只复制回剪贴板。
- 自定义备份目录保存后能回显；点击“使用默认目录”后恢复默认应用数据目录。
- OCR 说明应明确使用 Windows 本机识别能力，Windows 10/11 可用性取决于系统语言包。

### 19. 文件和图片备份目录

步骤：
1. 在“剪贴板设置”中选择一个自定义备份目录。
2. 复制一个普通文件。
3. 复制一个资源管理器中的图片文件。
4. 打开自定义备份目录。

预期：
- 普通文件副本保存到 `自定义目录/files`。
- 图片文件副本保存到 `自定义目录/images`。
- 备份文件名保留原名并追加“备份”，例如 `report-备份.txt`。
- 如果同名备份已存在，应生成带编号的文件名，例如 `report-备份2.txt`。
- 旧历史记录不迁移、不重命名。

### 20. 仅记录地址模式

步骤：
1. 在“剪贴板设置”中选择“仅记录原始文件地址”。
2. 复制一个普通文件。
3. 复制一个资源管理器中的图片文件。
4. 检查默认缓存目录或自定义备份目录。

预期：
- 文件和图片文件仍进入剪贴板历史。
- 文件和图片文件记录使用原始路径。
- 不生成新的文件副本或图片文件副本。
- 打开文件、打开文件所在目录、复制文件路径仍基于原始路径工作。

### 21. 截图图片采集

步骤：
1. 确认剪贴板监听已开启。
2. 使用 `Win + Shift + S` 截取一块屏幕区域。
3. 查看剪贴板历史。
4. 切换到“仅记录原始文件地址”模式后再次截图。

预期：
- 截图会进入剪贴板历史并显示为图片记录。
- 列表缩略图和详情预览能显示完整图片。
- 截图没有原始文件路径，因此会保存为 PNG 文件。
- 即使处于“仅记录原始文件地址”模式，截图仍保存到图片缓存目录并进入历史。
- 如果 OCR 开启且系统支持，截图文字识别结果写入备注；OCR 无结果不应阻塞图片保存。

### 22. 浏览器复制图片

步骤：
1. 在浏览器中右键一张图片并选择复制图片。
2. 查看剪贴板历史。
3. 尝试不同浏览器或不同网页图片来源。

预期：
- 如果浏览器向系统剪贴板提供 PNG、DIB 或 DIBV5 图片格式，File Keeper 应保存为图片记录。
- 图片预览正常显示。
- OCR 开启时尝试写入备注。
- 如果某浏览器只提供 HTML 或私有格式，允许暂不采集，记录为后续兼容问题。

## 回归重点

每次修改剪贴板模块后，至少回归以下路径：

1. 复制新文本后列表实时刷新。
2. 重复文本刷新到顶部但不新增重复记录。
3. 单条复制、右键复制、双击复制、批量复制、Ctrl+C 复制均可用。
4. 复制成功和失败都有提示。
5. 勾选和取消勾选样式立即同步。
6. 删除单条和批量删除不误删未选中记录。
7. 搜索和类型筛选后，多选操作只影响当前可见记录。
8. 备份模式、自选备份目录、仅记录地址模式三种保存路径都符合预期。
9. `Win + Shift + S` 截图在备份模式和仅记录地址模式下都能进入历史。
10. 前端测试、前端构建、Rust 剪贴板测试、Rust 编译检查全部通过。
