# AI Fundamentals Workflow Checklist

在完成 `workflow/ai_fundamentals_workflow.md` 的每一步后，使用此检查清单进行交叉验证。每个项目必须回答**是**才算完成。如果有任何项目回答**否**，修复输出并重新验证。

## Step 1: 识别基础AI理论需求场景

- [ ] 已明确场景类型（理论学习/面试辅导/模型选型指导/算法优化/数学基础补课）
- [ ] 已识别理论方向（机器学习/深度学习/神经网络基础/概率统计）
- [ ] 已提取应用场景（数据建模/模型设计/训练优化/不确定性量化/生成模型/风险评估）
- [ ] 已确定当前水平（入门/中级/高级）
- [ ] 已对照知识库关键洞察完成初步判断（训练相关→ML+DL/架构相关→神经网络+DL/不确定性→概率统计）
- [ ] 如有信息缺失，已向用户追问不超过2个澄清问题

## Step 2: 输出基础AI理论方案

- [ ] 如为机器学习基础，监督/无监督/强化学习核心概念已覆盖
- [ ] 如为机器学习基础，经典面试题已输出（偏差-方差/过拟合/正则化/交叉验证策略）
- [ ] 如为深度学习架构，CNN已覆盖（卷积/池化/经典架构演进/感受野计算）
- [ ] 如为深度学习架构，RNN已覆盖（LSTM/GRU/双向RNN/Seq2Seq+Attention/梯度消失爆炸）
- [ ] 如为深度学习架构，Transformer已覆盖（自注意力/QKV/多头/位置编码/复杂度分析）
- [ ] 如为深度学习架构，Diffusion已覆盖（前向扩散/反向去噪/DDPM/DDIM/Stable Diffusion架构）
- [ ] 如为深度学习架构，训练优化技巧已输出（学习率调度/优化器/梯度裁剪/混合精度/分布式训练）
- [ ] 如为神经网络基础，感知机→MLP→深度网络演进已说明
- [ ] 如为神经网络基础，激活函数选型已覆盖（ReLU/Leaky ReLU/GELU/Swish/Mish）
- [ ] 如为神经网络基础，GNN已覆盖（GCN/GAT/消息传递/图分类节点分类链接预测）
- [ ] 如为概率统计，贝叶斯推断已覆盖（先验/似然/后验/MCMC/变分推断/贝叶斯优化）
- [ ] 如为概率统计，生成模型数学基础已说明（VAE/GAN/Normalizing Flow/优缺点对比）
- [ ] 如为概率统计，A/B测试框架已输出（实验设计/样本量计算/指标选择/结果分析/常见陷阱）
- [ ] 如为概率统计，概率校准已覆盖（Platt Scaling/Isotonic Regression/Temperature Scaling/Brier Score/ECE）
- [ ] 如为概率统计，交叉验证金标准已说明（K-Fold/Stratified/Time Series Split/Group K-Fold）
- [ ] 所有核心论断均能在知识库中找到支撑来源
