# 人工测试遗留问题修复IX · 用户操作手册

> 两件新能力：智能对话**思考强度**、无限画布**连线保留开关**；外加联网搜索部署验证（管理员）。
> 技术细节见 feature-map，逐项验证见测试方案。

## 1. 🧠 思考强度（智能对话，全体用户）

**入口**：智能对话 → 输入框下方工具栏，「🌐 联网」旁的「🧠 思考」下拉。

| 操作 | 界面变化 | 预期 |
|---|---|---|
| 当前模型支持思考 | 显示「🧠 思考」下拉（默认**标准**） | 三选一：关 / 标准 / 深度 |
| 当前模型不支持 | **下拉不显示** | 请求不带思考参数=模型默认行为 |
| 选「深度」发消息 | 💭 思考过程明显变长、回答更慢 | 消耗明细积分比标准档高（预扣按档位放大，答完多退少补） |
| 选「关」 | 无 💭 或极短 | 最快最省 |
| 切换模型 | 档位选项集跟着变 | 上次选的档不在新模型集合 → 自动落到该模型第一档（如深度→关） |
| 刷新页面 | 档位保持上次选择 | localStorage 记忆 |
| 只有两档的模型 | 下拉只有「关/标准」 | 协议无深度态，诚实不显示 |

**注意**：深度档开局积分预扣是标准档的数倍——余额不足会直接提示充值，属预期拦截不是 bug。

## 2. ⛓ 连线保留开关（无限画布，全体用户）

**入口**：画布右下工具条 **⛓**（🔗「只看关联」旁）。**一个开关管两处**：Ctrl+V 粘贴 + 节点右键「创建副本」。

| 操作 | 界面变化 | 预期 |
|---|---|---|
| ⛓ 开（默认）框选 Ctrl+C → Ctrl+V | 粘贴体出现在鼠标处，内部连线保留，**外部连线连回原节点** | 副本接入原上下文 |
| ⛓ 开连按 Ctrl+V | 每次整体 +32 错开；对外部节点产生**平行重复线** | 属预期，可逐条点选删 |
| ⛓ 关 Ctrl+V | 粘贴体全新独立，零原节点连线 | 干净副本 |
| ⛓ 关节点「创建副本」 | 副本零连线（原=克隆全部入/出边） | 只有节点 |
| 复制后切开关再粘贴 | —— | 按**粘贴当下**开关态生效 |
| 粘贴前删掉外部节点 | 那条外部连线自动消失 | 不产断线 |
| Ctrl+Z | 该次粘贴的节点+线一步全消 | 含跨集边 |
| 刷新页面 | ⛓ 态保持 | localStorage 记忆 |

**注意**：⛓ 关做副本/粘贴后，提示词里 `@节点名` 仍指原节点——上游面板可能显「断链」灰显，重新连线即恢复。

## 3. 联网搜索上线验证（管理员）

**入口**：系统设置 → 联网搜索配置（运维配置页）。

1. **快路（Tavily）**：申请 Tavily key → 配置页粘贴 → 总开关开、provider 选 tavily → 点「测试连通」→ results>0。
2. **自建路（SearXNG）**：Docker 起 SearXNG（**必须 `formats:[json]`**，否则被 JS 挑战挡）→ 后端 env `SEARCH_SEARXNG_BASE_URL` 指向它 → provider 选 builtin → 测试连通。
3. **用户侧验证**：智能对话开「🌐 联网：开」问时效问题（「今天什么日期」）→ 回答带 `[n]` 引用 + 📎 来源外链；切「关」→ 纯模型作答。
4. **降级**：全失败不报错，AI 正常作答只是没引用；测试按钮返回 results=0 + providerAvailability 全 false = key/地址无效。

## 常见异常

| 现象 | 原因 | 恢复 |
|---|---|---|
| 🧠 下拉不显示 | 当前模型无思考声明（OpenAI 系未配 thinking 节） | 正常；管理员按运维手册声明后出现 |
| 深度档被拒「积分不足」 | 预扣按档位放大 | 充值或降档/调小 max_tokens |
| 粘贴后平行线多条 | ⛓ 开连按属预期 | 逐条删或关 ⛓ |
| 联网开了没引用 | 没搜到/未配 key/总开关关 | 找管理员看配置页测试按钮 |
