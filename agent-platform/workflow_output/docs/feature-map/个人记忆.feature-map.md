# 个人记忆(计划12 重设计)· Feature Map

> 功能-代码速查表。真相源 [总体设计](../../../项目工程文档/设计/个人记忆重设计-总体设计.md)。当前态 API/端点见 [速查表 09 主表](../../../项目工程文档/项目功能介绍/速查表/09-个人记忆与冲突解决.md)。

## 一句话
每轮对话全程留账(INPUT/OUTPUT 各一条)→ 开生成后一次 LLM 出三层(L0 标签/L1 概要/L2 详述)→ 写时标签归一 → 召回聚合标签+优先读自己总结+拼未覆盖流水账 → 周期总结压缩 → 时序冲突 pending → 流水账多挂项目按成员 ACL 只读共享。

## 技术原理(大白话)
- **流水账 = 账本**:[memory_turns](#1-memory_tags-标签库) 每行 = 你说的一句或 AI 回的一段,像记账。挂哪个项目,哪个项目成员能翻到(只读);不挂 = 私人账本。
- **标签 = 贴在账本上的便签**:[memory_tags](#1-memory_tags-标签库) 独立成表,`主体:主题`(如 `我:居住`)。写时系统自动查同义标签复用(「兴趣」归并到已有「爱好」),你只能改名/补别名,不能手动合并(合错了不可逆)。
- **总结 = 月度结账**:800 条爱好对话灌 AI 太贵。[memory_summaries](#3-memory_summaries-总结提炼层) 把它们压成 1 条精华,带溯源(来自哪些账本行)。AI 先看总结标题(reflect),感兴趣的才翻原文,省 token。
- **覆盖表 = 打钩记录**:[memory_summary_coverage](#4-memory_summary_coverage-覆盖表) 记「这条账本行的这个便签已被我的总结吃进去了」。召回时全打钩的行走总结压缩态、没全打钩的才翻原文,避重复。
- **ACL = 项目花名册授权**:[memory_recall_acl](#11-memory_recall_acl-项目读取授权) 记「A 能读 B 的项目流水账」。owner 默认全读,其他要 owner/recall_admin 显式配。
- **召回 = 翻账本前先查目录**:不是全灌,先聚合 scope 内便签→AI 选相关便签→优先读自己的结账→没被结账覆盖的才翻原文→按主体打包塞进提示词。

## 表注解(建表用 Flyway V47-V53)

### 1. memory_tags — 标签库
**用途**:写时归一主体,`subject:topic` + `label` + `aliases` + anchor 三列。禁手动归并/拆分。
- `subject`(默认「我」)/ `topic`(居住/爱好…) = L0 主体:主题;`label` 对外展示名;`aliases[]` 同义别名(归一滚进,对外不露)。
- `anchor_embedding halfvec(2048)` 语义粗筛 + `anchor_tokens_tsv tsvector` BM25 词法(召回选标签用)。
- `usage_count` 归一命中自增。`UNIQUE NULLS NOT DISTINCT(user_id,subject,topic)` 写时归一兜底。
- **关联**:`user_id→users`;被 `memory_turns.tag_ids`/`memory_summaries.tag_id`/`memory_conflicts.tag_id` 引用。

### 2. memory_turns — 流水账(主体表)
**用途**:一轮对话 INPUT/OUTPUT 各一条,记忆主体。可多挂项目按成员 ACL 只读共享。
- `direction`(INPUT/OUTPUT);`tag_ids[]`=L0;`l1_summary`/`l2_detail`=L1/L2;`raw_content` 原文(gen 关态写,90 天 TTL);`gen_done` 是否跑过生成 LLM(false=仅 raw 不参与召回)。
- `project_ids[]` 多挂共享(空=个人私有);`born_personal` 出身定死(挂/卸不改,卸空转 true);`departed_project_ids[]`/`deleted_project_ids[]` 保交接不删数据。
- **关联**:`user_id→users`(作者);`tag_ids→memory_tags`;`project_ids→projects`(数组无 FK,app 管)。

### 3. memory_summaries — 总结提炼层
**用途**:周期/手动压缩流水账得精华条。`project_id` 单值,**不可挂数组/不可分享**。
- `l1_summary`/`l2_detail`;`source_summary_id` 链式(防膨胀再压缩溯源);`source_turn_ids[]` flat provenance(`@> [T]` 查受影响 summary);`status` CLEAN/PENDING_CONFLICT/STALE;`summarized_at` 12h 规则基准。
- **关联**:`user_id→users`(作者,只读自己);`project_id→projects`(单值,NULL=个人);`tag_id→memory_tags`。项目删 `ON DELETE CASCADE` 清项目总结,个人(NULL)不清。

### 4. memory_summary_coverage — 覆盖表(allCovered 判定依据)
**用途**:记某作者某 turn 某 tag 某 scope 被其总结吃进。**召回只认 `user_id=召回者自己` 的行**。
- `UNIQUE NULLS NOT DISTINCT(turn_id,tag_id,project_id,user_id)`(PG 默认 NULL≠NULL,个人 scope project_id=NULL 约束会失效,须 NULLS NOT DISTINCT)。
- 无 `deleted` 列,随 summary/turn CASCADE 清。**关联**:`turn_id→memory_turns`/`tag_id→memory_tags`/`summary_id→memory_summaries`/`user_id→users`。

### 5. memory_project_members — 记忆专属成员
**用途**:角色 + ACTIVE/DEPARTED。**独立于 Agent 模块 `project_members`(旧表不动)**。
- `role` OWNER/ADMIN/MEMBER;`recall_admin` ACL 配置权(owner 兜底,admin 须此 flag);`status` ACTIVE/DEPARTED;`departed_at` 离职时间(带「已离开人员·名·时间」标注)。
- 无 `deleted`,离职置 DEPARTED 不删行保交接。`UNIQUE(project_id,user_id)`(re-add 软删复活)。

### 6/7. memory_project_settings / memory_project_user_settings — gen 开关
**用途**:owner 项目级 gen / 会员个人覆写 gen。**二者 AND 方可生成**(默认开)。无 `deleted`,项目删 CASCADE 清。

### 8. memory_consolidation_scopes — 自动总结 scope 勾选
**用途**:用户勾哪些 scope 自动总结。默认插 PERSONAL(新用户 trigger)。`UNIQUE NULLS NOT DISTINCT(user_id,scope_kind,project_id)`。V51 加 `locked_until`/`last_run_at`(worker SKIP LOCKED 任务锁)。

### 9. memory_notifications — 跨用户波及通知
**用途**:`SUMMARY_AFFECTED_BY_RECALL`(他人撤回 turn 波及我的 summary)/ `PROJECT_DELETED_AFFECTED`(项目删除)。`resolved_at` worker 重生后回填(不追加新行避 badge 抖动)。

### 10. memory_conflicts(扩列 V48)
**用途**:新模型冲突**只来自总结层时序互斥**(非跨用户编辑),无 type 列。V47 加 `tag_id`+`summary_id`;V48 放宽 `new_memory` 老列 NOT NULL(新模型 insert 卡)。旧列(block_label/new_memory 等)随旧表语义废弃。

### 11. memory_recall_acl(V49)— 项目读取授权
**用途**:reader→target 授权读项目流水账。`UNIQUE(project_id,reader_user_id,target_user_id)`;owner 兜底全读无需 ACL 行;可逆 DROP(无 deleted)。

### 旧表(V53 DROP)
`user_memories` / `user_memory_projects` 直接 DROP,老数据不迁移(项目未上线全测试数据)。旧 `projects`/`project_members` Agent 模块在用不动。
