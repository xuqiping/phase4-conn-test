## 关键调用链路

### 菜单显隐（10x-4/5）
```
Sidebar.navItems() → 每项标 module → 末尾 filter(canSeeModule)
  └─ canSeeModule(key) = isModuleEnabled(key) && (!perm || hasPermission(perm))
       └─ 数据源：config/modules.ts ENABLED_MODULES / MODULE_PERMISSION_MAP
```

### 路由守卫（10x-3/4/5）
```
router.beforeEach → resolveRouteAccess({module, requireAdmin, user, ...})
  ├─ 未登录受保护 → /login
  ├─ 已登录访问 /login → defaultLanding()
  ├─ module 关闭 → defaultLanding()   （10x-5，含 admin）
  ├─ requireAdmin 非 admin → defaultLanding()   （10x-3）
  ├─ 模块权限码未持有 → defaultLanding()   （10x-4，admin 豁免）
  └─ allow
```

### 供应商导出/导入（10x-2）
```
前端「导出」→ 二次确认 → GET /providers/export (blob) → 浏览器下载
  └─ 后端：exportAll → 解密 apiKeyEnc → JSON（明文 key）
前端「导入」→ 选 .json → 解析 → 预览 → POST /providers/import
  └─ 后端：importAll → size≤200 校验 → 逐条 upsert by name → reload
```

### 对话路由（10x-1）
```
chat 发消息 → LlmGateway.chat(req, userId) → findProvider(model, userId)
  └─ 10x-1 起：跳过原 Step1 用户级 override，直接全局 CHAT 注册表
  └─ userId 仅用于计费归户，不触发 user_llm_providers 查询
```

## 技术清单与原理注解

| 技术 | 一句话原理 | 大白话 | 案例 |
|---|---|---|---|
| 项目级模块开关 | 单一布尔表控制模块全链路显隐 | 像总电闸，一拉全楼某层灯灭 | Agent大厅设 false → 菜单/路由/入口同步消失 |
| RBAC 权限兜底 | 模块映射权限码，用户持码才可见 | 像门禁卡，有卡才能进 | 普通用户无 media:gen → 看不到视频生成 |
| 路由守卫纯函数 | 把访问判定逻辑从守卫抽成无副作用函数 | 像把裁判规则写成手册，单独考试 | resolveRouteAccess 可直接单测，不跑真实导航 |
| 导出明文 key | AES 对称加密，解密后明文返回给 admin | 像保险箱管理员取出现金给你 | admin 点导出 → JSON 里 apiKey 是明文 sk-... |
| upsert by name | 按唯一标识存在则更新、不存在则新建 | 像通讯录按名字存人，重名覆盖 | 导入同名 provider → 更新字段而非报错 |

> 踩坑批注：
> - 默认落地页不能硬编码 `/agents`——10x-5 关掉 /agents 后登录会白屏，故改 `defaultLanding()` 动态选首个启用模块。
> - 导入 apiKey 空**不能**清空原值——用户可能只想改 endpoint，误删 key 会断服务。
> - 守卫逻辑抽纯函数前，测试用真实 router.push 触发懒加载，jsdom 下卡死超时——纯函数避坑。
