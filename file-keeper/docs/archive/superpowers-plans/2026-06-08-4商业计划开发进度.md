## Task 2：桌面端登录用户授权接入 ✅

- 目标：登录用户绑定设备并查询授权快照。
- 已新增生产代码：
  - `src/api/commercialAuth.ts`：新增 `CommercialAuthApiError` 结构化错误类、`isCommercialAuthApiError` 类型守卫、`ClientDevice`/`ClientDeviceBinding`/`ClientAuthorizationSnapshot` 类型、`registerClientDevice()` 和 `getClientAuthorization()` API 函数。`postJson`/`getJson` 支持额外 headers 传递 Bearer token。

- 已修改生产代码：
  - `src/App.vue`：主内容区 `files/processes/clipboard` 加 `canUseTab()` 二次门禁；`handleClipboardShortcut`、`handleScreenshotShortcut`、`handleScreenshotCapture` 检查 `canUseTab('clipboard')`；文件右键菜单"关闭进程"加 `v-if="canUseTab('processes')"`；新增 `syncClipboardMonitor()` 按授权动态启停剪贴板监控；新增 `ensureAuthorizedTab()` 授权变化时切换可用 tab；新增 watcher 监听三模块授权状态变化；启动时不再无条件 `clipboardStore.startMonitor()`。
- 已新增/修改测试：
  - `src/api/__tests__/commercialAuth.test.ts`：新增 `registerClientDevice` 和 `getClientAuthorization` 登录 API 测试、`CommercialAuthApiError` 结构化错误测试（含 HTTP 状态、网络失败不包装），共 9 个测试。
  - `src/stores/__tests__/commercialAuthStore.test.ts`：新增登录授权初始化测试、后端省略 `offlineUsableUntil` 测试、网络失败保留离线缓存测试、服务端明确拒绝清空缓存并回退匿名授权测试、过期离线快照不参与模块合并测试，共 7 个测试。
  - `src/components/__tests__/appScreenshot.test.ts`：新增 `@tauri-apps/plugin-store`、`commercialAuth`、`clipboard` API mock 以适配授权门禁。
- 已完成功能：
  - 登录后调用 `POST /api/client/devices/register` 注册/心跳设备。
  - 调用 `GET /api/client/authorization?deviceId=xxx` 获取模块授权。
  - 根据 files/processes/clipboard 模块授权控制桌面端功能入口（含所有绕过入口修复）。
  - 支持 offlineCacheMinutes 对离线可用时间的影响（离线缓存区分网络失败与服务端拒绝）。
  - 按模块合并登录授权与匿名授权（登录优先、匿名兜底）。
  - `initializeAuthenticated(baseUrl, accessToken)` 提供显式接入入口，待登录 UI 集成。
