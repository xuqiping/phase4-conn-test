# 人工测试遗留问题修复II · 用户操作手册

> 面向使用者/管理员的界面变化操作册。技术细节见 feature-map，逐项验证见测试方案。

## 1. 组内生成的积分账（成员+组长）

**场景**：组池不够付结算差额时，账去哪了。

1. 成员在组内提交视频/图片任务 → 组页「已使用」按**预估**先占。
2. 任务结算（实际消耗 > 预估且组池不够）→ **界面变化**：组流水多一条差额腿；成员「已使用」= **实际消耗**（不再少记）；组长个人钱包多一条扣款（余额不足则挂「未偿还欠款」）。
3. **完成标志**：组流水两笔加起来 = 账单该条实耗金额；组长余额/欠款对得上。

## 2. 项目组对账按组查（管理员）

**入口**：账单管理 →「项目组对账」tab。

| 操作 | 界面变化 | 预期 |
|---|---|---|
| 组下拉选某组 | 表格只剩该组行，顶卡合计变该组数值 | 账平组显「平」 |
| 清空筛选 | 回默认「仅异常组」 | 只列不平组 |
| 开「显示全部组」 | 全部组行出现，异常行标红 | 选了具体组时此开关无效 |

## 3. 审计日志（管理员）

**入口**：系统/日志 → 审计日志。

1. 模块下拉 → **18 项全中文**（如「安全」「项目组」「反馈中心」），表格模块列同样显中文。
2. 注册/找回密码页发一次验证码 → 回审计页刷新 → 出现「认证-发送注册验证码」，详情含**完整邮箱 + IP**、结果 SUCCESS/FAIL。
3. 找回密码完整走一遍（发码+重置）→ **两条**日志。
4. 改 Provider 配置、审批流、MFA 绑定等操作 → 均有日志（操作失败也有 FAIL 行）。

**常见异常**：某操作没日志 → 记下操作路径反馈（P0-P3 清单外即新漏网）。

## 4. 邮箱验证码倒计时（注册/找回/短信登录）

| 操作 | 界面变化 | 预期 |
|---|---|---|
| 点「发送验证码」 | 按钮变灰进 60s 倒计时 | 收到邮件 |
| **刷新页面** | 按钮仍是灰的，秒数=真实剩余 | 不再「刷新就能重发」 |
| 间隔内再点 | 提示「请 N 秒后再试」（N=真实剩余），按钮进倒计时 | 不发第二封、不耗每日额度 |
| 连点 3 次 | 不弹强制滑块 | 间隔拒绝不算失败次数 |
| 改邮箱输入框 | 倒计时按新邮箱重新算 | 旧邮箱倒计时不串台 |

## 5. 价表配置三改（管理员）

**入口**：价表配置。

1. **新增视频价**：选 Cdance2.0 → 只有「有视频参考/无视频参考」两组输入，**无 480P/720P 下拉**。
2. **LLM 闲时价**：每行价表多「闲时输入/闲时输出/闲时缓存/缓存价」四个输入——**留空=沿用忙时/输入价**（不配就当没这功能）。
3. **闲时段**：系统设置 → 计费设置 → 「闲时时段」卡：开关 + 工作日/周末各最多 4 段（HH:mm）。起止须成对、25:00 之类非法值**拒绝保存**。
4. **est 偏差提示**：视频 TOKEN 预估价输入旁若显「近7天实耗偏高 N%」tag → 按提示调高预估（样本<3 不显示）。
5. **旧导出文件**：含分辨率字段的旧导出再导入 → 分辨率被忽略，不报错。

## 6. 积分实时刷新（全体）

1. 登录后顶栏个人积分徽标、组徽标 → 任何变动（消费/充值/管理员发放/组内划拨/结算）**秒级跳动**，无需刷新。
2. 钱包页/项目组页开着时 → 流水/卡片约 1 秒后自动跟上。
3. **断网恢复**：联网恢复后几秒内自动补齐最新数值（退避最长 30s）。
4. **多端登录**：手机和电脑同时在线 → 两端都实时收。

**常见异常**：徽标不动 → 看 DevTools Network/WS `ws://…/ws/events` 是否连接；推送挂了不影响账（刷新页面即校正）。

## 7. 聊天缓存命中（智能对话用户）

同会话连续追问 → 第二条回答的消耗明细含「**缓存命中 N**」字样，总积分比首条低（命中部分按缓存价，未配缓存价则价格不变）。
