## 一、方向声明

**「东方雅致的 AI 工作台」**——技术上是最现代的 Agent 编排平台，气质上是高山流水的知音文化。明=宣纸月白，暗=黛蓝夜墨；吸收方向 C 的「工作台晨昏云雾背景层」（静态美术资产，非 WebGL），其余 C 元素（生成式背景、墨痕光标、环境音）留作二期。

> **修订（2026-08-28 用户裁定）**：放弃「水墨画」传统绘画质感（泼墨、枯笔、宣纸纹理、晕染肌理），转为**现代化的东方高山流水**——缥缈空灵的意境用现代数字视觉语言表达：柔和渐变、雾感层次、极简山形剪影、光影氛围。传统绘画肌理全部移除；文化锚点（山水、云雾、知音、印章）保留但现代化转译。

## 二、文化依据

- 核心叙事：高山流水遇知音 → Agent 是知音，平台是山水，编排是流水。
- 基调：「淡、远、空」的意境参考《富春山居图》，点色参考《千里江山图》石青石绿——**只取意境与色彩，不取其水墨画法**（用户裁定 2026-08-28：去水墨、转现代化表达）。
- 文案气质：诗意但克制——仅空状态、登录页、品牌位用诗性短句；业务操作文案保持直白准确。

## 三、构图

1. **大留白 + 疏密对比**：页面留白率 ≥35%；信息区密集、周边空寂（呼吸感）。
2. **骨架不变**：侧栏（240/64px）+ 顶栏（56px）+ 卡片主区，12 列栅格；中国风只改皮肤不改信息架构。
3. **远山过渡**：侧栏→主区以低对比极简山形剪影渐变衔接（现代扁平渐变，非水墨画法，opacity ≤10%）。
4. **分隔**：极细浅色线或纯留白分隔；~~飞白枯笔笔触~~ 已移除（传统绘画肌理弃用）。
5. **安全区**：所有背景渐变/山形/云雾资产，内容区（文字、控件）上方净空，装饰元素禁止进入控件命中区。

## 四、字体

| 角色 | 字体 | 说明 |
|---|---|---|
| 正文/控件/数字 | 思源黑体（Noto Sans SC）+ 系统栈兜底 | 屏幕可读性红线，不换 |
| 页面标题/品牌语/空状态短句 | **霞鹜文楷（LXGW WenKai，SIL OFL 开源可商用）** | 行楷气质、自然飘逸且屏幕可读；子集化（按用字裁剪 ≈200–400KB）+ `font-display: swap` |
| 装饰印章 | 篆刻风 SVG（Logo 资产） | 不用篆刻 WebFont |
| 禁用 | 草书、每屏 >1 处书法体、正文用书法体 | 识别度与可读性红线 |

## 五、色彩（语义先行，色值见 DESIGN-TOKEN-0001）

- **暗色「夜墨」**：黛蓝底、鸦青侧栏、月白正文、天青主色、天水碧选中态。
- **亮色「宣纸」**：宣纸底、墨色正文、深天青主色（保证对比度）。
- **点缀**：朱砂唯一暖色（印章 Logo、关键强调，非状态色）；石青/石绿/暮山紫为图表序列色。
- **状态色独立**：成功（竹绿系）、警告（赭黄系）、错误（朱砂红系但与品牌朱砂拉开明度差）、信息（靛蓝系）——可辨识性优先，禁止灰墨化。
- 全站同色系低饱和；禁止高饱和渐变、霓虹、玻璃拟态。

## 六、材质与光影（修订：现代数字材质，弃传统绘画肌理）

- ~~宣纸微纹理、绢本微光、泼墨、枯笔~~ → 全部移除。
- 现代材质语言：**柔和渐变 + 雾感模糊层 + 极简山形剪影**；卡片用极淡的色层与柔影做纵深（"远山叠影"的现代版），无颗粒纹理。
- 光影=蓝调时刻：柔和冷光、无硬阴影。
- 工作台首屏：晨昏云雾静态背景层（现代渐变雾感美术资产，按本地时间切换晨/暮两版，opacity ≤15%，可被 reduced-motion/性能模式关闭）。

## 七、动效

- 统一缓动 `cubic-bezier(0.22, 0.61, 0.36, 1)`（云雾缓出）；时长 150/300/400ms 三档。
- 路由过渡：交叉淡入淡出（呼应云雾）；按钮按压：~~墨滴~~**涟漪**扩散 150ms（流水意象的现代化表达）；加载：骨架屏扫光。
- 禁止：弹跳、强视差、粒子轰炸；全部动效响应 `prefers-reduced-motion`，总开关进设置页。

## 八、声音

不做。方向 C 的环境音提案已排除（B 端工具红线：默认静音即唯一正确态）。

## 九、反例与禁止用法（门禁必查）

| 禁止 | 正确 |
|---|---|
| 蓝紫渐变 + 玻璃拟态卡片（现 deep-space 风） | 同色系低饱和 + 现代渐变柔光 |
| 祥云/龙凤/金描边/大红灯笼 | 极简山形、云雾、渐变雾层、印章 |
| 传统水墨肌理进任何区域（泼墨/枯笔/宣纸纹/晕染颗粒） | 现代化渐变与雾感层次表达山水 |
| 正文用行书/草书 | 正文永远思源黑体 |
| 错误红改成灰墨色 | 状态色独立可辨识 |
| 背景装饰盖住文字（对比度 <4.5:1） | 装饰层 opacity ≤12% 且压在文字层下 |
| 每屏堆 3+ 意境元素 | 主导氛围词每屏 ≤2 个（禅寂+空灵） |
