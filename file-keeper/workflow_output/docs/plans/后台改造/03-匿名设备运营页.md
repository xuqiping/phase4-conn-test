# 03 - 匿名设备运营页

> 状态:**⏳ 待做**(四项中工作量最大)
> 依赖:需要后端新建匿名设备管理 repository/service/controller,前端新建运营页

## 一、目标

让管理员/客服在后台管理匿名试用设备:
- 查看所有匿名设备列表(含试用状态、所选免费模块、试用到期时间)
- 重置试用(让某设备重新获得 7 天全功能试用)
- 禁用匿名设备(防滥用)

## 二、现状调研(关键发现)

- **`anonymous_device_trials` 表已存在**,字段完整(device_id/fingerprint_hash/device_name/trial_started_at/trial_expires_at/free_module_code/free_module_selected_at/last_free_module_changed_at/status)。status CHECK 约束:`active`/`disabled`。当前 **0 条数据**(联调期没产生匿名设备,都走的登录链路)。
- **客户端侧 repository/service 已存在**:`AnonymousTrialRepository`(findByDeviceId/insert/updateFreeModule)、`AnonymousTrialService`(start/status/selectFreeModule/changeFreeModule)。
- **但完全没有管理端** —— 没有 list/reset/disable 的方法,没有 controller。
- ⚠️ **隐患(同 04 记录的 bug)**:`anonymous_device_trials.device_name` 也是 `VARCHAR(120)`,匿名设备注册时若传超长 UA 同样会 500。本项实现时应一并放宽或截断。

## 三、设计要点

### 后端新建文件
1. **`server/.../device/dto/AnonymousDeviceDto.java`** — record,展示用(id/deviceId/deviceName/status/trialExpiresAt/freeModuleCode/trialStartedAt/lastSeenAt 等)
2. **`server/.../device/repository/AnonymousDeviceAdminRepository.java`** — 管理端专用(不复用客户端 repository,职责分离):
   - `findAll(status?, page, size)` → PageResult<AnonymousDeviceDto>
   - `resetTrial(deviceId, newExpiresAt, adminUserId)` — 重置 trial_expires_at = now + 配置天数
   - `updateStatus(deviceId, status, adminUserId)` — active/disabled
3. **`server/.../admin/service/AdminAnonymousDeviceService.java`** — 重置试用读配置天数(依赖 02 系统设置,或临时硬编码 7)
4. **`server/.../admin/controller/AdminAnonymousDeviceController.java`**:
   - `GET /api/admin/anonymous-devices?status=&page=&size=`
   - `POST /api/admin/anonymous-devices/{deviceId}/reset-trial`
   - `POST /api/admin/anonymous-devices/{deviceId}/disable`
   - `POST /api/admin/anonymous-devices/{deviceId}/enable`(可选)

### 前端新建/改动
- **新建** `admin-web/src/api/anonymousDevices.ts`
- **新建** `admin-web/src/views/AnonymousDevicesView.vue` — n-data-table 列表(设备ID/名/状态/试用到期/免费模块) + 重置/禁用按钮 + 状态筛选 + 分页
- **改动** `admin-web/src/types/index.ts` — 加 `AnonymousDevice` interface
- **改动** `admin-web/src/router/index.ts` — 加 `{ path: 'anonymous-devices', name: 'anonymous-devices' }`
- **改动** `admin-web/src/views/Layout.vue` — menuOptions 加"匿名设备"项

## 四、验证
1. 先用客户端匿名流程(或 API)造几条匿名设备数据(目前表是空的)。
2. `GET /api/admin/anonymous-devices` 返回列表 + 分页。
3. reset-trial 后 trial_expires_at 更新;disable 后 status=disabled。
4. 禁用后再调匿名接口 `/api/anonymous/**` 应被拒。
5. `npm run build` 通过。

## 五、风险/边界
- 工作量最大(全新 controller/service/repository/前端页)。
- reset-trial 的天数来源:优先读 02 的系统设置 `anonymous_trial_days`;若 02 未做,临时硬编码 7 并留 TODO。
- 建议顺手放宽 `device_name` 列(同 04 修复思路)。
- 本期不做:匿名设备数据导出、批量操作。
