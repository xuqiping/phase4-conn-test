# 3.2 北极星指标与指标树

## I.03 核心框架：NSM选型五准则

来源：Amplitude × Reforge 联合方法论 [来源: Amplitude North Star Playbook, 2023 | 置信度:🔍高]

### NSM必须同时满足的五个条件

| 准则 | 含义 | 反例 |
|---|---|---|
| 1.反映核心价值 | 指标必须直接度量产品为用户交付的核心价值 | "页面浏览量"不反映内容消费深度 |
| 2.可行动驱动 | 团队的工作能直接影响该指标 | "市场总量"团队无法直接影响 |
| 3.先行预测性 | 该指标变化能预测业务结果 | "月收入"是滞后指标，不适合作NSM |
| 4.可理解可沟通 | 全员（含非数据角色）都能理解其含义 | "LTV/CAC比"过于复杂 |
| 5.唯一性 | 全公司只选一个NSM，避免目标分裂 | 多个"平等重要"指标=无方向 |

### 不同产品类型的NSM参考

| 产品类型 | 推荐NSM | 为什么 |
|---|---|---|
| 社交/社区 | 日活跃用户的消息/互动次数 | 互动是社交核心价值的直接度量 |
| 内容平台 | 用户消费内容时长/篇数 | 内容消费深度=核心价值 |
| 电商 | 月活跃买家数×购买频次 | GMV虽大但含价格干扰，买家行为更本质 |
| SaaS | 日活跃付费用户的核心功能使用率 | 使用深度预测续费 |
| 工具/效率 | 周活跃用户完成核心任务数 | 任务完成=价值交付 |
| 双边平台 | 匹配成功数（如预订完成/交易达成） | 匹配效率是平台核心 |

## I.06 方法论：指标树（Input/Output Tree）

### 三层拆解模型

```
层1: NSM（北极星指标）
  └── 层2: Output指标（3~5个业务结果指标）
        └── 层3: Input指标（每个Output拆2~4个团队可执行指标）
```

**拆解原则**：
- **MECE**：同级指标互斥且穷尽（不重叠、不遗漏）
- **因果链**：Input→Output→NSM有明确因果关系
- **可归属**：每个Input指标有明确的责任团队
- **可行动**：Input指标的变化能追溯至具体产品动作

### 指标树示例：电商产品

```
NSM: 月度活跃买家购买次数
├── Output1: 购买转化率
│   ├── Input1.1: 商品详情页→加购转化率
│   ├── Input1.2: 加购→下单转化率
│   └── Input1.3: 下单→支付转化率
├── Output2: 月活跃买家数
│   ├── Input2.1: 新客首单转化率
│   └── Input2.2: 老客月复购率
└── Output3: 购买频次
    ├── Input3.1: Push触达→下单转化率
    └── Input3.2: 个性化推荐点击率
```

### 护栏指标（Guardrail Metrics）

与NSM并列的"安全网"——确保优化NSM时不牺牲其他关键价值：

| 护栏类型 | 作用 | 典型指标 |
|---|---|---|
| 质量护栏 | 防止数量牺牲质量 | 退订率/差评率/客诉率 |
| 公平护栏 | 防止短期损害长期 | 节奏/通知打扰率/数据隐私合规率 |
| 收入护栏 | 防止增长损害变现 | ARPU/毛利率/付费转化率 |
| 技术护栏 | 防止增长压垮系统 | 崩溃率/加载时长/API错误率 |
