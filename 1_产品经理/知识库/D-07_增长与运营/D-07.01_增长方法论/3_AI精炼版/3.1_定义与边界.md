# 3.1 定义与边界

## A.01 核心定义

**增长方法论（Growth Methodology）** 是一套以数据为驱动、实验为手段、系统化为原则的产品增长框架。它不是"拉新技巧"的堆砌，而是从获客→激活→留存→变现→推荐的全链路价值最大化，核心是"用最小成本验证最大增长假设，再将有效路径规模化"。[来源: Sean Ellis, "Hacking Growth" | 置信度:🔍高]

**一句话定位**：增长方法论是产品增长的"科学方法论"——不是拍脑袋，而是假设→实验→验证→规模化的循环。

## A.04 边界与不含什么

**增长方法论包含**：增长模型/框架、增长实验方法论、增长组织设计、增长心理与行为、增长指标体系、增长策略制定。

**增长方法论不含**：具体运营执行（→D-07.02~07）、A/B实验技术实现（→D-06.07）、数据分析方法（→D-06）、商业模式设计（→D-18）、用户研究方法（→D-03）。

## B.01 优先级框架

增长问题天然有优先级——资源有限，不可能同时做所有事。

| 框架 | 维度 | 适用场景 |
|---|---|---|
| ICE(Impact/Confidence/Ease) | 影响/信心/难度 | 快速排列实验优先级 |
| RICE(Reach/Impact/Confidence/Effort) | 触达/影响/信心/工作量 | 更精确的优先级量化 |
| 北极星→增长树 | 一致性/可拆解/可执行 | 确定增长核心方向后逐层拆解 |
| 增长杠杆矩阵 | 影响/成本 | 2×2矩阵快速筛选高价值低成本的杠杆 |

## B.03 核心清单

增长方法论的5个核心要素（缺一不可）：
1. **北极星指标**：全员对齐的核心方向（→D-06.01）
2. **增长模型**：量化从输入到输出的因果链
3. **实验文化**：假设→实验→验证→迭代的循环
4. **数据基座**：可信数据驱动决策（→D-06）
5. **跨职能协作**：增长不是单一团队的事

## C.01 场景分类

| 场景 | 增长类型 | 核心矛盾 | 关键模型 |
|---|---|---|---|
| 0→1冷启动 | 获客驱动 | 没人知道你 | PLG+病毒循环+内容增长 |
| 1→10成长期 | 多维增长 | 找到PMF后如何规模化 | AARRR全链路+实验加速 |
| 10→100成熟期 | 留存驱动 | 流量成本上升/留存不足 | RARRA(留存优先)+精细化运营 |
| 100→衰退 | 挽留与第二曲线 | 增长停滞/用户流失 | 流失预警+新场景拓展 |

## D.01 定义域

| 维度 | 说明 |
|---|---|
| 核心问题 | "怎么让产品持续增长并留住用户？" |
| 适用对象 | 产品经理、增长PM、运营、CEO |
| 典型使用 | 增长策略制定、实验优先级、增长团队搭建、北极星对齐 |
| 不适用 | 纯品牌营销(Awareness不等于Growth)、短期流量采买 |

## F.01 核心触发器

增长启动的3个信号：
1. **PMF验证通过**：产品有留存（次留>25%，7留>10%）→可启动增长
2. **北极星确认**：全员对齐一个核心指标 → 方向明确
3. **数据基建就绪**：核心指标可量化、可归因 → 可实验

## F.03 增长闭环

```
设定增长目标 → 拆解增长杠杆 → 生成假设 → 排列优先级 → 设计实验 → 执行与数据收集 → 分析结果 → 规模化/放弃 → 设定新目标
```

## I.01 核心术语

| 术语 | 定义 |
|---|---|
| PMF(Product-Market Fit) | 产品与市场契合——产品满足了一个真实且有规模的市场需求 |
| 北极星指标(NSM) | 最能反映产品核心价值交付的单一指标 |
| 增长杠杆(Growth Lever) | 对核心指标影响最大的可控行动维度 |
| 增长实验(Growth Experiment) | 用最小成本验证增长假设的可控测试 |
| 增长飞轮(Flywheel) | 自我强化的增长循环——A推动B→B反过来推A |
| PLG(Product-Led Growth) | 产品本身是增长引擎——用户体验驱动获客/留存/变现 |
| 病毒系数(K-factor) | 每个用户平均带来多少新用户(>1则自增长) |
| 增长劫持(Growth Hijacking) | 增长手段伤害用户体验/品牌/合规 |

## I.10 常见问题清单

1. PMF没验证就开始做增长 → 浪费资源
2. 北极星选错 → 全员跑偏
3. 只看虚荣指标 → 增长不健康
4. 实验样本量不足 → 结论不可信
5. 忽视留存只做拉新 → 漏桶效应

## I.12 常见误区

| 误区 | 实际 |
|---|---|
| 增长=拉新 | 增长是全链路(AARRR)，拉新只是第一环 |
| 增长=黑客手段 | 增长是科学方法论，不是"取巧/欺骗" |
| 增长=营销 | 增长覆盖产品内体验+数据+实验，不只是外部推广 |
| 增长可以没有PMF | 没有PMF的增长=花钱请人来然后看他们走 |
| 增长能解决所有问题 | 增长解决不了产品本身的根本问题 |
