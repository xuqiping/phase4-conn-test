# M3 RAG 记忆设置动态化 · 用户操作手册

> 面向管理员/运维。后台「系统设置 → RAG/记忆」tab 的两件新能力。

## 能力一:设置项按检索模式自动显隐

### 场景
原设置页所有旋钮全摊着,选了「向量检索」却还看到「全量阈值」「LLM_KEY 粗筛」等无关项,易混淆。

### 操作
1. 后台 → 系统设置 → RAG/记忆 tab。
2. 「记忆检索模式」下拉切到目标模式。
3. 界面变化(预期):
   - **全量(LLM_FULL_CONTEXT)**:显「记忆标签语言」+「全量记忆阈值」。
   - **向量检索(EMBEDDING_VECTOR)**:模式专属组全隐(只剩总开关/处理模式/检索模式 3 项)。
   - **混合(VECTOR_KEYWORD)**:显「关键词召回块阈值」+「关键词通道上限」+「entities 词袋计数」卡片。
   - **LLM_KEY**:显「LLM_KEY 粗筛候选数」+「LLM_KEY 精排开关」+「entities 词袋计数」卡片。
4. 改完任一项自动保存(失焦/拨动即触发),右上角弹成功提示。

### 反向(切回)
- 切回「全量」或「向量」→ entities 卡片隐藏,但**已填的数值不丢**(切回 LLM_KEY/混合再显原值)。
- 切回非召回模式时**不会**清空 entities 配置(后端只在 LLM_KEY/VECTOR_KEYWORD 模式才提交 entitiesConfig)。

## 能力二:entities 词袋计数可配

### 场景
LLM 给每条记忆抽「召回关键词」(如「女儿叫小红」→ 抽 女儿/孩子/小孩/家人/啊闪 等)。原来抽多少个写死(总数≤20、上位词 5~10),想调细一点或粗一点改不了。现在可配。

### 操作(仅 LLM_KEY / 混合 模式可见)
1. 检索模式切到 **LLM_KEY** 或 **混合**。
2. 滚到「entities 词袋计数」卡片(绿色左边框分组)。
3. 调 7 个旋钮:
   - **总数上限**:entities 总词数硬上限。调小=召回词更精(省 token);调大=召回更全。默认 20。
   - **同义变体 min~max**:近义说法数量区间(女儿→孩子/小孩)。默认 1~3。
   - **专名数量 min~max**:value 里专有名词数量区间(人名/地名/品牌)。默认 1~5。
   - **上位词数量 min~max**:类别词数量区间(家人/工作/居住,决定泛问召回)。默认 5~10。
4. min/max 旋钮有联动约束(min 不能超 max),改完自动保存。

### 让老记忆吃新配置(重要)
- 改完 entities 配置**只对新入库的记忆生效**,老记忆的 entities 不变。
- 要让老记忆也按新配置重抽:点页面下方「**老记忆关键词重抽**」按钮 → 异步跑(进度看后端日志 `memoryReextract`)。幂等可重跑。

## 边界与兜底
| 情况 | 行为 |
|---|---|
| min 填得比 max 大 | 前端旋钮阻止;绕过则后端自动互换 |
| totalMax 填 0 或超大 | 前端约束 [1,50];绕过则后端 clamp |
| 配置被改成非法 JSON(直接改库) | 后端读失败 → 走默认值(20/1-3/1-5/5-10)不崩,日志告警 `memoryEntitiesConfig` |
| 不改配置 | 默认值 = 旧行为(零变更) |
