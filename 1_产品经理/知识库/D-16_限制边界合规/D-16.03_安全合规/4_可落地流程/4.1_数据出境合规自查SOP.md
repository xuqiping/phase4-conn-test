# 4.1 数据出境合规自查SOP

## 适用场景

产品涉及用户数据跨境传输（海外服务器、跨国API调用、出海运营）时的合规自查与路径选择。

## SOP 步骤

### Step 1：数据资产盘点

输出：**数据出境清单**

| 数据类型 | 是否个人信息 | 是否敏感个人信息 | 数据量级 | 是否重要数据 | 接收方所在国 |
|---|---|---|---|---|---|
| 用户注册信息 | 是 | 部分（手机号） | 填写 | 否 | 填写 |
| 用户行为日志 | 是 | 否 | 填写 | 待判定 | 填写 |
| 业务运营数据 | 否 | 否 | 填写 | 待判定 | 填写 |

**关键判断**：
- "重要数据"判定：参照《网络安全标准实践指南——数据分类分级指引》和行业主管部门的目录
- "敏感个人信息"判定：身份证/护照/生物识别/医疗健康/金融账户/行踪轨迹等

### Step 2：出境路径判定决策树

```
是否在自贸区负面清单范围？
├─ 是 → 清单内数据？走安全评估/SCC/认证；清单外数据→自由出境
└─ 否 → 以下任一满足？
    ├─ CIIO出境个人信息 → 【安全评估】（必须）
    ├─ 出境"重要数据" → 【安全评估】（必须）
    ├─ 出境100万人以上个人信息 → 【安全评估】（必须）
    ├─ 累计出境10万人以上个人信息或1万人以上敏感个人信息 → 【安全评估】（必须）
    └─ 以上均不满足 → 
        ├─ 跨国集团内部传输？ → 【认证】
        └─ 其他 → 【标准合同(SCC)】
```

### Step 3：合规文件准备

#### 安全评估路径
1. 《数据出境安全评估申报书》
2. 《数据处理者与境外接收方拟订的数据出境合同》
3. 《数据出境风险自评估报告》
4. 数据处理者及接收方主体信息

#### 标准合同(SCC)路径
1. 《个人信息出境标准合同》（网信办2023版模板）
2. 《个人信息保护影响评估(PIA)报告》
3. 《标准合同备案表》

#### 认证路径
1. 认证申请书
2. 跨国企业集团内数据出境管理制度说明
3. 数据出境场景与安全保障措施说明

### Step 4：个人信息保护影响评估(PIA)核心要素

PIA报告须覆盖以下维度：

| 评估维度 | 核心内容 |
|---|---|
| 合法性基础 | 数据出境的法律依据（用户同意/合同履行/法定义务等） |
| 必要性分析 | 是否必须出境，能否境内替代 |
| 风险评估 | 数据泄露/滥用/篡改风险，接收国法律环境风险 |
| 安全保障措施 | 加密传输/访问控制/审计日志/数据脱敏 |
| 数据主体权益保障 | 查询/更正/删除/投诉渠道 |
| 接收方安全能力评估 | 技术能力/管理制度/历史合规记录 |

### Step 5：提交与跟踪

| 路径 | 提交部门 | 审批时限 | 结果跟踪 |
|---|---|---|---|
| 安全评估 | 省级网信部门→国家网信办 | 自接收之日起7个工作日内书面反馈受理，45个工作日内完成评估 | 评估结果有效期2年，到期重新申报 |
| SCC备案 | 省级网信部门 | 备案后10个工作日内反馈是否通过 | 合同变更需重新备案 |
| 认证 | 认证机构 | 按认证机构流程 | 证书有效期3年 |

### Step 6：持续合规

- 建立数据出境台账，每季度更新
- 数据量/接收方/数据类型变更时重新评估路径
- 关注自贸区负面清单更新动态
- 定期（至少年度）复核出境路径是否仍然适用
