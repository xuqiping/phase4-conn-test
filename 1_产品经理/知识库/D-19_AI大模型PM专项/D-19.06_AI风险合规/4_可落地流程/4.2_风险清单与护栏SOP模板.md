# 4.2 风险清单与护栏SOP模板

## 一、AI风险清单8步SOP

| 步骤 | 输入 | 动作 | 输出 |
|---|---|---|---|
| 1.产品场景定边界 | 产品形态/场景/用户/数据 | 判定是否Agent/是否出海/是否高风险垂类 | 场景卡 |
| 2.六风险域扫描 | 场景卡 | 逐域（幻觉/越狱/隐私/偏见/版权套壳/法规）列风险点 | 风险初表 |
| 3.风险评分 | 初表 | 按"可能性×影响"评分定级（高/中/低） | 风险评分表 |
| 4.幻觉分级 | 场景 | 按场景定幻觉率红线+主控+兜底 | 幻觉控制表 |
| 5.四层护栏设计 | 风险表 | 输入/模型/输出/运营四层护栏 | 护栏设计文档 |
| 6.Agent专项护栏 | 是否Agent | 对齐OWASP ASI 2026设计 | Agent护栏文档 |
| 7.多法域合规自查 | 是否出海 | 中国/欧盟/美国合规自查 | 合规自查表 |

| **高（经常发生）** | 极高 | 高 | 中 |

## 四、四层护栏设计模板

### 4.1 输入侧护栏

```yaml
input_guardrails:
  - intent_detection: 分类器判断意图合规性
  - pii_filter: 命名实体识别去身份证/手机/邮箱
  - jailbreak_detection: 模板匹配 + 模型识别越狱
  - sensitive_word: 关键词 + 语义过滤
  - rate_limit: 防滥用扫描速率限制
  - multimodal_scan: 多模态输入做隐写/对抗检测
```

### 4.2 模型侧护栏

```yaml
model_guardrails:
  - alignment: RLHF/宪法AI/DPO训练
  - system_prompt: 强约束系统提示词
  - structure_constraint: 限制输出格式/白名单行为
  - temperature: 降低温度提稳定性
  - model_routing: 高风险转强对齐模型
```

### 4.3 输出侧护栏

```yaml
output_guardrails:
  - content_review: 有害/违法/涉黄检测
  - citation: 关键事实带引用溯源
  - confidence: 低置信度标记
  - copyright_filter: 相似度过滤防复制版权内容
  - regenerate: 不合规自动重新生成
  - aigc_watermark: AIGC水印标注
```

### 4.4 运营侧护栏

```yaml
operation_guardrails:
  - real_time_monitor: 指标监控 + 异常告警
  - audit_log: 全链路可追溯/不可篡改/法定留存
  - human_in_loop: 高风险转人工
  - circuit_breaker: 风险事件触发熔断
  - feedback_loop: 举报 → 分析 → 护栏更新
```

## 五、Agent专项护栏设计（OWASP ASI 2026对齐）

| ASI攻击面 | 护栏 | 实现 |
|---|---|---|
| 目标劫持 | 目标锁定 | 关键决策不可被Prompt改 |
| 工具滥用 | 工具白名单 | 只允许调用白名单工具 |
| 权限越权 | 权限边界 | 最小权限原则 |
| 记忆污染 | 记忆隔离+审查 | 记忆写入前审查 |
| 级联故障 | 步骤校验+回退 | 每步校验+可回退 |
| 供应链攻击 | 工具/MCP签名验证 | 来源验证 |
| 高风险动作 | HITL确认点 | 删除/转账/下单二次确认 |
| 沙箱 | 沙箱执行 | 代码/操作沙箱 |

## 六、多法域合规自查清单

### 6.1 中国合规自查

- [ ] 生成式AI服务是否完成备案？
- [ ] 拟人化互动是否符合2026-07-15办法？
- [ ] 是否有AIGC水印标注？
- [ ] 训练数据是否合法来源？
- [ ] 算法推荐是否备案？
- [ ] 深度合成是否合规？

### 6.2 欧盟合规自查

- [ ] AI Act风险分级判定（不可接受/高/有限/最小）？
- [ ] 若高风险：训练数据质量/偏见检测/人工监督/技术文档？
- [ ] GDPR：数据最小化/用户权利（访问/删除/移植）？
- [ ] 是否做DPIA？
- [ ] 数据跨境是否合规？

### 6.3 美国合规自查

- [ ] FTC：算法公平/反欺诈？
- [ ] 是否受出口管制（若前沿模型）？
- [ ] 州法（加州等）是否合规？
- [ ] 版权（训练数据/生成物）是否合规？
