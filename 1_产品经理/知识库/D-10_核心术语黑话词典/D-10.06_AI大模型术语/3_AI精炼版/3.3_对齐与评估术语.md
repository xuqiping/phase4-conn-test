## 1. 人类反馈强化学习 / RLHF

| 字段 | 内容 |
|---|---|
| 英文全称 | Reinforcement Learning from Human Feedback |
| 缩写 | RLHF |
| 定义 | 通过人类对模型输出的偏好标注训练奖励模型，再用奖励模型指导强化学习，使LLM输出更符合人类偏好 |
| PM解读 | RLHF是"给模型装方向盘"——预训练+SFT让模型能说话，RLHF让它往"人想要的方向"说 |
| 常见误解 | 以为RLHF=SFT（SFT教"怎么回答"，RLHF教"哪种回答更好"） |
| 来源 | Ouyang et al., 2022 (InstructGPT) [📚训练知识]

## 2. 直接偏好优化 / DPO

| 字段 | 内容 |
|---|---|
| 英文全称 | Direct Preference Optimization |
| 缩写 | DPO |
| 定义 | RLHF的简化替代方案：跳过奖励模型，直接用人类偏好数据优化策略模型，训练更稳定 |
| PM解读 | DPO是RLHF的"去中介化"——不需要先训奖励模型再训策略模型，一步到位。2024年起成为越来越多模型的对齐首选 |
| 对比RLHF | DPO训练更稳定、工程更简单，但RLHF在大规模对齐中仍有优势（奖励模型可复用） |
| 来源 | Rafailov et al., 2023 [📚训练知识]

## 3. 可验证奖励强化学习 / RLVR

| 字段 | 内容 |
|---|---|
| 英文全称 | Reinforcement Learning from Verifiable Rewards |
| 缩写 | RLVR |
| 定义 | 用可自动验证的奖励信号（如数学题对错、代码能否通过测试）做强化学习，无需人工标注偏好 |
| PM解读 | RLVR是2025年训练范式的"新主流程阶段"。它让推理模型的训练不再依赖昂贵的人工标注——答案对不对可以程序验证 |
| 趋势 | [来源:36Kr/腾讯云 | 📚中 | 2026-01] 2025年起，训练配方从"Pretraining→SFT→RLHF"演变为"Pretraining→SFT→RLVR→RLHF" |
| 来源 | [来源:Karpathy 2025年终总结 | 📚中 | 2025-12]

## 4. 对齐 / Alignment

| 字段 | 内容 |
|---|---|
| 英文全称 | Alignment |
| 定义 | 使AI系统的行为与人类意图、价值观和安全标准保持一致的技术与流程 |
| PM解读 | 对齐是"让模型听话且不惹事"的总称。SFT/RLHF/DPO/RLVR都是对齐手段。注意：对齐≠完美安全，是妥协与权衡 |
| 常见误解 | 以为对齐后模型就不会出错（对齐降低风险概率，不消除风险；过度对齐会损害模型能力→"对齐税"） |
