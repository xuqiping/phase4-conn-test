# 进程管理用户操作手册

> 本手册覆盖窗口标题默认列、列设置和排序。已进入 Phase 4；自动化通过，真实窗口对应关系 M7 待用户确认。

## 查看窗口标题

1. 打开“进程管理”。
2. 刷新进程列表。
3. 查看“窗口标题”列。

预期结果：全新安装和从旧版本首次升级时默认显示该列；没有标题的进程显示 `-`。

## 排序与列设置

1. 点击窗口标题列头进行排序。
2. 打开列设置，可调整支持列的顺序或隐藏窗口标题。
3. 重启应用再次进入进程管理。

预期结果：排序状态可理解；用户手动隐藏后保持隐藏，不会因再次启动被迁移逻辑强制打开。旧配置中缺少的新列按 key 补齐，原有列顺序和选择不被整包覆盖。

## 安全说明

- 标题按普通文本显示，不执行其中的 HTML 或脚本。
- 标题只用于当前界面展示和排序，不上传、不写持久化日志。
- 同时打开多个 Excel、PowerPoint、资源管理器窗口后，按 Phase 4 M7 核对标题对应关系。
