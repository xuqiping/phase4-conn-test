# Compiler & Fundamentals Workflow

## Purpose

基于编译原理与底层基础知识体系，为用户提供数据结构/算法、计算机组成原理、操作系统内核、编译原理、设计模式等计算机基础知识的深度解答、学习路径规划、面试辅导或工程优化建议。

## Prerequisites

- 用户已明确底层知识领域或问题
- 知识库文件 `01_编程语言与核心技能.md` 及子目录文件可访问

## Steps

### Step 1: 识别底层知识需求

**Goal**: 确定用户需要的具体底层知识方向和应用场景
**Completion criterion**: 已锁定具体知识模块和应用场景

1. 读取用户消息，提取以下信息：
   - 知识模块：数据结构/算法 / 计算机组成原理 / 操作系统内核 / 编译原理 / 设计模式与工程规范
   - 应用场景：面试准备 / 系统学习 / 工程优化 / 架构设计 / 工具链开发
   - 当前水平：初级（概念理解）/ 中级（能应用）/ 高级（能优化/设计）
   - 具体目标：如"准备大厂算法面试"、"优化系统缓存命中率"、"设计一门DSL"等

2. 对照知识库中的全景地图定位模块：
   - 数据结构与算法 → 哈希表/B+树/DP/图论/排序 → LeetCode + 算法导论
   - 计算机组成原理 → CPU流水线/缓存层次/SIMD/异构计算 → perf + PMU + Roofline
   - 操作系统内核 → 进程调度/虚拟内存/io_uring/eBPF/容器 → eBPF + perf + ftrace
   - 编译原理 → 三段式架构/SSA/LLVM/MLIR → ANTLR4 + LLVM + Tree-sitter
   - 设计模式 → SOLID/GoF 23/DDD/重构/TDD → SonarQube + Pre-commit

3. 如有信息缺失，向用户追问不超过2个澄清问题。

**Knowledge Base Reference**:
- [参考: Agents知识库/0_超级编程行业知识库/01_编程语言与核心技能.md > 三、编译原理与底层基础 > 全景地图]

### Step 2: 输出底层知识方案

**Goal**: 产出针对性的知识内容或学习路径
**Completion criterion**: 输出包含核心概念解释、实践建议、学习资源、与具体场景的结合点

根据Step 1确定的场景，按以下分支处理：

**分支A — 面试辅导**：
1. 输出高频考点清单（与该模块相关的经典面试题）。
2. 对每类考点给出：核心概念速览、常见变种、答题模板、易错点提醒。
3. 附推荐刷题清单（LeetCode题号/类别）和推荐书籍章节。

**分支B — 学习路径**：
1. 输出阶段性学习计划（概念理解→代码实现→工程应用→深度优化）。
2. 每个阶段附：
   - 核心知识点（与知识库L3模块对齐）
   - 推荐资源（书籍/课程/论文/工具）
   - 实践项目（如手写LRU缓存、实现简单编译器前端、用eBPF追踪系统调用等）
   - 验证标准
3. 标注核心定律/原则的应用（Amdahl定律、CAP定理、SOLID、DRY/KISS/YAGNI、Three Strikes Rule等）。

**分支C — 工程优化**：
1. 定位具体优化目标（如"降低缓存未命中率"、"减少系统调用开销"、"优化编译产物体积"）。
2. 输出优化方案：
   - 根因分析（用底层知识解释当前瓶颈）
   - 优化策略（具体技术手段）
   - 预期收益（量化指标）
   - 验证方法（benchmark设计、监控指标）
3. 附工具使用示例（perf/eBPF/Roofline/编译器优化选项等）。

**分支D — 架构设计/工具链开发**：
1. 输出设计方法论（如编译器三段式架构、DSL设计流程、高性能数据结构选型）。
2. 给出关键决策点和技术选型建议。
3. 附参考实现或开源项目案例。

将结果保存到 `output/fundamentals_advice.md` 或直接在对话中呈现。

**Knowledge Base Reference**:
- [参考: Agents知识库/0_超级编程行业知识库/01_编程语言与核心技能.md > 三、编译原理与底层基础 > 核心原理速览]
- [参考: Agents知识库/0_超级编程行业知识库/01_编程语言与核心技能.md > 知识体系总览 > 核心定律/原则速查]

### Step 3: 验证与交付

**Goal**: 确保底层知识解释准确无误
**Completion criterion**: 已通过 checklist 逐项核对

1. 读取 `checklist/compiler_fundamentals_workflow_checklist.md`。
2. 逐项核对知识准确性（特别是算法复杂度、硬件参数、内核机制等精确数据）。
3. 确认所有核心定律/原则引用正确。
4. 如有遗漏或偏差，补充修正。
5. 向用户交付最终答案。

## Post-Workflow

1. 记录完成状态到 `task/current_task.md`。
2. 如需深入某一具体知识点（如"B+树实现细节"、"eBPF程序编写"），在当前 Agent 内继续追问并输出。
