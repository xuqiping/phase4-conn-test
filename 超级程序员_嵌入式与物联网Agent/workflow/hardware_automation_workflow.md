# 硬件自动化与智能控制 Workflow

## Purpose

为工业自动化、机器人控制、视觉质检和硬件测试项目提供从机械臂控制开发、PLC编程、硬件视觉识别到手机自动化硬件测试的完整执行路径。覆盖智能制造、工业质检、协作机器人、产线自动化测试四大方向。

## Prerequisites

- 用户已明确自动化场景（精密装配/焊接/打磨/质检/分拣/测试）
- 用户已明确精度与速度要求（重复定位精度、节拍时间、负载重量）
- 用户已明确安全等级（人机协作/围栏隔离/安全门）
- 用户已明确预算范围（机械臂+视觉+控制系统的总投入）

## Steps

### Step 1: 机械臂控制开发与运动规划

**Goal**: 完成机械臂选型、ROS2+MoveIt2运动规划环境搭建，实现基础运动控制与视觉伺服。
**Completion criterion**: 机械臂在仿真环境中完成轨迹规划并通过Sim2Real迁移，在真实硬件上执行规划轨迹，重复定位精度达标。

**A. 机械臂选型决策**
- 评估维度：负载能力（kg）、工作半径（mm）、重复定位精度（±mm）、自由度（4/6/7轴）、速度（关节最大速度/线速度）、协作安全认证、价格
- 选型矩阵：
  - 轻负载精密装配（<5kg，精度±0.02mm）→ 协作机器人（UR5e/遨博i5/节卡Zu5）
  - 中负载搬运分拣（5-20kg，精度±0.05mm）→ 工业臂（ABB IRB 1200/发那科 LR Mate）
  - 重负载焊接/码垛（>20kg）→ 重载工业臂（KUKA KR QUANTEC/安川 GP系列）
  - 高精度（±0.01mm）精密操作 → 力控专用臂（非夕科技/Rethink Robotics）

**B. ROS2环境搭建**
- ROS2版本选择：Humble Hawksbill（LTS，2022-2027）或 Jazzy Jalisco（LTS，2024-2029）
- 中间件选型：Zenoh（微秒级调度，替代DDS，2026推荐）或 CycloneDDS（默认）
- 工作空间结构：`colcon build`构建，`src/`下放功能包（`robot_description`、`moveit_config`、`control_node`）
- URDF建模：使用SolidWorks/Onshape导出URDF，或手动编写（link+joint+mesh+inertial）

**C. MoveIt2运动规划配置**
- Setup Assistant：加载URDF → 配置自碰撞矩阵 → 定义规划组（Planning Group）→ 配置末端执行器 → 定义姿态（Named Poses）→ 生成MoveIt配置包
- 规划算法选择：
  - 通用场景：OMPL（RRT-Connect/RRT*/PRM*，采样型，鲁棒性强）
  - 平滑优先：CHOMP（优化型，适合重复轨迹）
  - 噪声环境：STOMP（随机优化，适合动态障碍物）
  - 高频实时：MoveIt Servo（>1kHz闭环，基于雅可比的速度控制）
- MPC轨迹规划（MoveIt2原生支持2025+）：模型预测控制，适合动力学约束严格的场景

**D. 底层运动控制**
- 正/逆运动学：DH参数建模（标准DH/改进DH），使用KDL或trac_ik求解逆解
- 动力学建模：牛顿-欧拉法/拉格朗日法，用于力控和碰撞检测
- 伺服三环控制：位置环→速度环→电流环（FOC磁场定向控制）
- 实时性要求：控制周期1ms（1kHz）典型，Cortex-M7/M85通过Helium加速使电流环缩短至10μs

**E. 力控与柔顺控制**
- 阻抗控制（Impedance Control）：设定刚度/阻尼参数，机械臂与环境柔顺交互，适用于精密装配和打磨抛光
- 导纳控制（Admittance Control）：基于外力反馈调整轨迹，适用于重载推压场景
- 六维力/力矩传感器集成：ATI Nano系列/SRI系列，校准后接入ROS2 Topic
- 案例参考：某空调管口装配，力控+视觉引导实现0.02mm啮合精度

**F. 视觉伺服**
- 手眼标定：
  - Eye-in-hand（相机装在末端）：标定相机与末端法兰的变换矩阵
  - Eye-to-hand（相机固定在工作区）：标定相机与机器人基座的变换矩阵
  - 使用OpenCV `calibrateHandEye` + 标定板（ArUco/ChArUco）
- PBVS（基于位置的视觉伺服）：图像→3D位姿估计→笛卡尔空间伺服
- IBVS（基于图像的视觉伺服）：图像特征误差→关节速度直接控制，响应更快
- 2D视觉：OpenCV轮廓匹配、模板匹配、霍夫变换（平面定位）
- 3D视觉：结构光/ToF/双目深度相机（Intel RealSense/Orbbec），点云配准（ICP）

**G. 具身智能集成（前沿可选）**
- VLA模型部署：RT-2 / OpenVLA 自然语言→动作指令端到端推理
- LeRobot框架（Hugging Face）：从训练到部署的完整管道，适配ROS2
- Sim2Real验证：NVIDIA Isaac Sim仿真训练→迁移至真实机械臂，目标一次通过率>95%

**H. 安全合规**
- 标准：ISO 10218-1/2（工业机器人安全）+ ISO/TS 15066（协作机器人安全）
- 碰撞检测：基于力矩传感器/电流检测/速度监控，触停时间<500ms
- 功率/力限制：协作模式下关节力矩限制在安全阈值内
- 安全功能：紧急停止（双回路）、安全门监控、双手操作、安全速度/位置监控

### Step 2: PLC编程与工业控制系统

**Goal**: 完成PLC选型、IEC 61131-3程序开发、工业通信配置，实现逻辑/运动/过程控制，通过现场调试。
**Completion criterion**: PLC程序下载运行，I/O信号与现场设备正确联动，扫描周期稳定在规定范围内，安全功能验证通过。

**A. PLC平台选型**
- 国际品牌：西门子（TIA Portal，生态最完善）、三菱（GX Works，亚洲市场强）、欧姆龙（Sysmac，运动控制强）、倍福（TwinCAT/CODESYS，EtherCAT原生支持）
- 国产品牌：汇川（InoProShop/CODESYS平台）、信捷（XCP Pro）、联诚（LCSYS）、蓝普锋（RAMP）
- 选型维度：
  - 逻辑控制为主（产线启停/联锁/报警）→ 紧凑型PLC（西门子S7-1200/汇川H3U）
  - 运动控制为主（多轴联动/电子凸轮/飞剪追剪）→ 运动控制型PLC（西门子S7-1500T/汇川AM600）
  - 过程控制为主（PID调节/模拟量闭环）→ 过程控制型PLC（西门子S7-1500/信捷XG2）
  - 安全功能（急停/安全门/SIL3）→ 安全PLC（西门子ET 200SP HA/皮尔兹PSS）

**B. IEC 61131-3编程**
- 编程语言选择：
  - LD梯形图（Ladder Diagram）：逻辑控制，电气工程师最友好，适合继电器替代场景
  - ST结构化文本（Structured Text）：算法实现（排序/查找/数学运算），类Pascal语法，2026年主流趋势
  - FBD功能块图（Function Block Diagram）：过程控制，图形化连线，适合PID和模拟量运算
  - SFC顺序功能图（Sequential Function Chart）：流程控制，步骤+转换条件，适合批次生产
  - 注意：第四版（2025）已弃用IL（指令表），OOP特性大幅增强（继承/多态/封装）
- 程序结构：组织块（OB，循环/中断/启动）→ 功能块（FB，带状态）→ 功能（FC，无状态）→ 数据块（DB，变量存储）

**C. 通信协议配置**
- PROFINET（西门子生态）：实时以太网，IRT同步周期<1ms，适合运动控制
- EtherCAT（倍福主导）：性能最优，抖动<1μs，菊花链拓扑，国产PLC+伺服首选
- Modbus TCP/RTU：最广泛工业协议，简单可靠，跨品牌兼容性强
- OPC UA：IT/OT融合标准，信息模型化，MES/SCADA系统对接首选
- TSN（时间敏感网络）：下一代工业通信基础，IEEE 802.1AS时间同步

**D. 运动控制编程**
- PLCopen运动控制功能块：
  - `MC_Power`：伺服上电使能
  - `MC_MoveAbsolute`：绝对位置定位
  - `MC_MoveRelative`：相对位移
  - `MC_MoveVelocity`：速度模式运行
  - `MC_Stop` / `MC_Halt`：平滑/快速停止
- 多轴联动：电子齿轮（跟随主轴）、电子凸轮（非线性跟随）、飞剪/追剪（剪切运动中的材料）
- 伺服参数整定：惯量比匹配、增益调整（Kp/Ki/Kd）、滤波器设置
- 案例参考：宁德时代锂电池产线，PLC+EtherCAT实现100+轴同步控制

**E. 过程控制编程**
- PID调节：单回路PID（温度/压力/流量）、串级PID（内环快速+外环稳定）、前馈PID（抑制已知扰动）
- 模拟量处理：4-20mA（工业标准，抗干扰强）/ 0-10V（简单场景），A/D转换分辨率选择（12/14/16位）
- 模型预测控制（MPC）：化工流程优化，基于过程模型预测未来输出，滚动优化控制量
- 案例参考：中石化DCS+PLC联合控制反应釜温度压力

**F. 国产PLC替代评估**
- 替代可行性：中小型项目（<50轴，非SIL3）已实现国产化替代
- CODESYS平台：作为"工控界的Android"，国产PLC主流开发平台，降低工程师迁移成本
- 风险评估：大型项目（>100轴/SIL3/高振动环境）仍需评估国产PLC长期可靠性数据
- 供应链：国产PLC交货周期通常4-8周，进口PLC6-12个月（ geopolitical风险）

**G. 数字化工厂集成**
- MES/SCADA对接：PLC通过OPC UA Server暴露数据点，MES读取生产数据（产量/节拍/质量）
- OEE计算：可用率×性能率×质量率，PLC实时采集停机/速度/废品信号
- 远程诊断：PLC程序在线监控（Force/Modify变量）、远程下载程序（VPN安全通道）
- 数字孪生：PLC程序在TIA Portal/WinMOD中仿真验证，虚拟调试减少现场调试时间50%+

### Step 3: 硬件视觉识别与工业质检

**Goal**: 完成YOLO系列模型选型训练、边缘AI芯片部署、产线集成，实现实时视觉质检或机器人视觉引导。
**Completion criterion**: 视觉系统在产线运行，检测精度/速度满足指标，误检率/漏检率在可接受范围，全流程延迟<100ms。

**A. 视觉任务定义**
- 缺陷检测：划痕/凹坑/色差/缺件/裂纹/毛刺（分类+定位+分割）
- OCR识别：产品序列号/日期码/二维码/条形码（文本检测+文本识别）
- 尺寸测量：关键尺寸（长度/直径/孔距）亚像素精度测量
- 机器人引导：目标定位（2D/3D位姿）→ 抓取点计算 → 机械臂执行
- 行为分析：人/车/非识别、打架/摔倒/越界（安防场景）

**B. YOLO模型选型**
- 模型演进链：YOLOv8（Anchor-Free，工程成熟）→ YOLOv11（C3k2模块，精度提升）→ YOLO26（2026，无NMS端到端，CPU提速43%）
- 选型决策：
  - 若追求部署速度/资源受限 → YOLOv8n/s（Nano/Small）
  - 若追求精度/算力充裕 → YOLOv8m/l/x 或 YOLO26
  - 若需开放词汇/零样本检测 → YOLOE-26
- 训练框架：Ultralytics（YOLOv8/v11）、官方YOLO26仓库

**C. 数据集与训练**
- 数据采集：产线相机采集真实样本，覆盖不同光照/角度/批次/缺陷类型
- 标注规范：LabelImg/LabelStudio/CVAT标注，边界框紧贴缺陷边缘，分类标签统一命名
- 数据增强：随机翻转、旋转、亮度调整、Mosaic/MixUp（提升小目标检测）
- 训练策略：迁移学习（COCO预训练→领域微调）、学习率调度（Cosine Annealing）、早停机制
- 验证指标：mAP@0.5、mAP@0.5:0.95、Precision、Recall、F1-score

**D. 边缘AI芯片选型与部署**
- 选型矩阵：
  - NVIDIA Jetson Orin（200+ TOPS INT8）：高端场景，CUDA生态成熟，功耗15-60W
  - 瑞芯微RK3588（6 TOPS INT8）：中端国产首选，功耗5-8W，RKNN工具链
  - 海思Hi3519（安防专用）：低功耗，集成ISP，适合摄像头一体机
  - 地平线征程6（车规级）：自动驾驶/车路协同，功能安全ASIL-B
- 部署流水线：
  1. 训练（PyTorch/Ultralytics）→ 导出ONNX
  2. 优化：TensorRT（NVIDIA）/ RKNN（瑞芯微）/ OpenVINO（Intel）/ ONNX Runtime（通用）
  3. INT8量化：精度损失<1%，推理速度提升2-4倍
  4. 部署：C++/Python推理程序，集成至产线PLC/机械臂控制系统
- 性能基准：YOLOv8-INT8在RK3588上实现30fps实时检测

**E. 产线集成**
- 触发机制：光电传感器/编码器信号→相机触发→图像采集
- 推理流程：图像采集→ISP处理（曝光/白平衡/降噪）→AI推理→结果输出→PLC联动
- I/O输出：OK/NG信号→PLC→分选机构/报警灯/停机
- 全流程延迟预算：相机触发→采集（10ms）→ISP（5ms）→推理（20ms）→结果输出（5ms）→PLC响应（10ms）= 50ms，目标<100ms
- MLOps工程化：
  - 数据闭环：产线NG样本自动回流至标注池，持续迭代模型
  - OTA模型更新：边缘设备远程更新模型版本，AB测试新模型
  - 版本管理：模型版本号+训练日期+数据集版本+性能指标，可追溯可回滚

**F. 嵌入式视觉集成**
- 摄像头驱动：V4L2（Linux）、MIPI CSI（高速）、USB UVC（通用）
- ISP调优：曝光时间/增益/白平衡/降噪/锐化，确保图像质量稳定
- 多路视频：MIPI CSI多路复用或USB Hub扩展，单芯片处理8-16路（Jetson Orin/RK3588）
- 隐私合规：端侧推理只输出结构化数据（坐标/类别/置信度），不上传原始图像

**输出物**: `视觉质检系统文档_项目名称.md`（含模型训练报告、芯片选型矩阵、部署配置、产线集成架构、MLOps流程）。

### Step 4: 手机自动化硬件测试系统（如适用）

**Goal**: 设计并实现机械臂+视觉+控制协同的UEE自动化测试系统，覆盖功能/生物识别/射频/产线测试。
**Completion criterion**: 测试系统可自动执行测试用例集，单台测试节拍<60秒，测试结果准确率>99%，产线并行工位≥8个。

**A. UEE测试范式设计**
- 核心思想：真机 + 物理交互 + 黑盒验证（不在被测设备安装任何软件）
- 三层架构：
  - 感知层：工业相机（高分辨率，捕捉屏幕细节）+ 力传感器（触控力度反馈）+ 环境传感器（温湿度/光照）
  - 决策层：AI视觉识别（OCR/UI元素检测/状态判断）+ 测试逻辑引擎（用例编排/异常处理/结果判定）
  - 执行层：协作机械臂（多自由度）+ 末端执行器（仿人手/气动夹爪/触控笔）

**B. 机械臂执行系统**
- 协作臂选型：UR5/遨博i5/节卡Zu5（负载3-10kg，重复定位精度±0.02mm，安全协作认证）
- 末端执行器设计：
  - 触控执行：电容触控笔（模拟手指，导电橡胶头）
  - 夹持执行：气动夹爪（快速换型，适配不同尺寸手机）
  - 精密执行：力控传感器（10g-500g触控力度控制，防压碎屏幕）
- 标定：机械臂基座→治具坐标系→手机坐标系→屏幕坐标系，统一变换矩阵

**C. 视觉识别与UI定位**
- 屏幕内容识别：
  - OCR：PaddleOCR/Tesseract识别屏幕文字（菜单/按钮/提示/数值）
  - UI元素检测：OpenCV 5.0 DNN模块检测图标/按钮/状态栏/弹窗
  - 屏幕状态判断：亮屏/息屏/锁屏/弹窗/加载中/异常画面
- 定位精度：屏幕坐标映射误差<0.5mm（对应1080p屏幕约2像素）
- 混合方案：模板匹配（固定UI，快速）+ 深度学习（动态UI，鲁棒）结合

**D. 触屏交互模拟**
- 单点触控：点击/长按/拖动，坐标偏差<0.5mm，时序精度<5ms
- 多点触控：双指缩放/旋转，同步精度<10ms
- 压力测试：3D Touch/压感屏压力梯度测试（50g-500g分10级）
- 滑动测试：边缘滑动（返回手势）、快速滑动（列表滚动）、慢速滑动（精准定位）

**E. 生物识别测试**
- 指纹测试：假指纹模具攻击检测、解锁成功率、湿手/干手/油污场景
- 人脸测试：2D/3D假头模攻击检测、不同光照/角度/遮挡场景
- 虹膜测试：假虹膜检测
- 呈现攻击检测（PAD）：符合ISO 30107标准，iBeta Level 1/2认证
- 案例参考：蚂蚁天玑实验室生物识别检测方案

**F. 传感器与射频测试**
- 运动传感器：加速度计/陀螺仪/指南针校准（六面翻转法），验证各轴灵敏度
- 环境传感器：光线传感器（明暗变化响应）、距离传感器（遮挡响应）
- 射频测试：WiFi吞吐量/漫游、蓝牙配对/传输距离、NFC读写、5G射频性能
- 测试环境：屏蔽房（隔绝外部信号干扰）+ 综测仪（R&S/Keysight）

**G. 产线批量测试架构**
- 并行多工位：8-16工位并行，每工位独立机械臂+相机+治具+被测设备
- 测试节拍优化：
  - 并行化：非依赖测试项同时执行（如射频测试与传感器测试并行）
  - 预加载：上一位测试时预加载下一位测试程序
  - 目标：单台全流程测试<60秒
- Burn-in老化测试：72小时连续运行（高温高湿环境），筛选早期失效
- SPC统计过程控制：Cpk计算（目标>1.33），控制图监控良率趋势
- 案例参考：百佳泰ART方案支持多品类设备自动化测试

**H. 数字孪生测试（前沿可选）**
- 虚拟测试环境：NVIDIA Isaac Sim构建虚拟手机+机械臂+相机环境
- 强化学习：自主探索测试路径，发现边界场景（如异常手势组合）
- 虚实融合：仿真验证用例→迁移至真实产线，覆盖率互补提升
