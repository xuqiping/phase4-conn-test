# 3.3 Sankey图与可视化

## I.07 核心技法

**Sankey图（桑基图）** 是路径分析最常用的可视化工具，用带宽度表示流量大小，直观展示路径分流与汇聚。

## Sankey图构建要素

| 要素 | 说明 | 设计原则 |
|---|---|---|
| 节点(Node) | 路径中的每个步骤 | 节点名称简短、统一粒度 |
| 边(Edge/Link) | 两节点间的流量 | 宽度与流量成比例 |
| 层级(Layer) | 从左到右的时间顺序 | 通常3~7层，过多难读 |
| 颜色(Color) | 区分分组或标记异常 | 同一分支用同色系 |

## Sankey图解读方法

### 1. 看主流量

```
首页 ━━━━━━━━━━━━━━━━━━━━→ 搜索 ━━━━━━━━━→ 详情 ━━━━→ 支付
     ╠═══════════            ╠═══════       ╠══
     ╚→ 推荐 ━━━━━━→ 详情 ━━╣              ╚→ 返回
                              ╚→ 搜索 ←━━━━╯(回退)
```

最宽的流=主路径。关注主路径是否是你预期的（漏斗）路径。

### 2. 看分流

从一个节点分出多条较细的流=用户在选择/分散。分流越早，说明产品引导越弱。

### 3. 看回退/环路

如果流量从右往左流动=回退。大量回退=用户迷路或对当前页面不满意。

### 4. 看跳出

某节点的流量突然消失=跳出。跳出点=流失点。

## 其他可视化方式

| 可视化方式 | 适用场景 | 工具 |
|---|---|---|
| Sankey图 | 全景路径流量 | Amplitude/Mixpanel/神策 |
| 路径树(Tree Map) | Top-N路径结构化展示 | D3.js/ECharts |
| 转移矩阵热力图 | 节点间转移概率 | Python seaborn |
| 用户轨迹(Timeline) | 单个用户的完整行为序列 | Mixpanel/Heap |
| 流程图(Flowchart) | 对比预设路径vs实际路径 | 手动/Miro |

## Sankey图常见问题与调优

| 问题 | 原因 | 解决方案 |
|---|---|---|
| 节点太多太碎 | 粒度太细（事件级） | 合并为模块级或页面级 |
| 层级太深 | 追踪步数过多 | 限制路径深度（5~7步） |
| 长尾太分散 | 众多次要路径 | 设置最小流量阈值（如>1%） |
| 颜色混乱 | 缺乏分组逻辑 | 按功能模块/页面对应颜色 |
| 环路导致循环显示 | 回退行为 | 单独统计回退率，不放入Sankey |
