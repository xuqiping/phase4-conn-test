## E1 账号锁定可见 + 管理员解锁（12x#2）

- `AuthService.java`：①登录前置闸（Redis 计数满）命中改查 DB——`lockedException(usernameKey)` 按 LOWER(username) 查，LOCKED+locked_until 非空 → 报错带「将于 MM-dd HH:mm 自动解锁」+`data.lockedUntil`；未落库（计数锁/用户不存在）维持 SEC-FR-001 固定话术（无账号存在性 oracle）。②status 检查点同分支（auditAuth user_locked +同话术）。BANNED/DISABLED/MFA/钉钉路径维持统一话术。前置闸也查 DB 的原因：Redis 计数与 locked_until 同 15min 窗，只改 status 点则真实用户永远只见固定话术；泄露权衡 spec §10.1 已接受（需 5 次错密码才获 oracle 且账号已锁不可再爆破）。
- `unlockUser(userId)` @Transactional：404「用户不存在」；BANNED/DISABLED→400「请用启用动作」；手动锁（无 locked_until）→400；条件 UPDATE `eq status=LOCKED` rows=0→409（并发护栏）；三清=DB 行（ACTIVE+locked_until/ban_reason 清空）+Redis `login:fail:u:{username小写}`+banService.restore。
- `UserController`：`PUT /api/users/{id}/unlock`（`@PreAuthorize user:manage` 与全控制器一致 + `@AuditLog(user:unlock)`）。
- 前端 `UserManageView.vue`：操作列 `status==='LOCKED' && lockedUntil` 显「解锁」（否则维持启用/变更状态），dialog.warning 确认弹窗显 `new Date(lockedUntil).toLocaleString('zh-CN')`；`admin.ts` +unlockUser。登录页无需改——后端 message 经 axios 拦截器 toast 直出（含解锁时间）。
