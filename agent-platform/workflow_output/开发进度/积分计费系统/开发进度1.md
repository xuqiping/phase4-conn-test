## 计费链（已就绪，待出口接线）

```
token/secs/count → PricingService.computeCost → ¥
                → PointsRatioService.toPoints(阶梯) → points
                → PointsWalletService.charge(UPDATE...RETURNING 行锁) → balance  [同步,不可丢]
                → UsageCollector.record(llm_usage_logs)                            [异步,可丢]
```
- `LlmBillingService.onSuccess/onFailure` 封装整链，**铁律：全链 try/catch 吞，绝不回归 LLM 出口**。
- userId=null（系统调用，RAG 内部 embed）→ charge 自然短路（仅采不扣）。
- billing.enabled=false → charge/refund/precheck/record 全短路；grant 不看 enabled（恒开）。

## 并发安全（spec §4 坑点②）

扣/退/充走 `UserPointsBalanceMapper.adjustBalanceReturn`：
```sql
UPDATE user_points_balance SET balance_points = balance_points + #{delta}, updated_at=NOW()
WHERE user_id=#{userId} RETURNING balance_points
```
单语句行锁串行化同用户并发扣减，杜绝「先查后扣」超支窗口。余额行+流水同 `@Transactional`。
