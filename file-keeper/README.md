## 📖 简介

File Keeper 是一个面向 Windows 桌面工作流的轻量级效率工具，既能帮助您快速访问常用文件，也能帮助您查看、筛选和关闭当前运行中的应用程序。通过统一的可视化界面，您可以同时管理“工作资料”和“当前工作窗口”，减少在文件管理器、任务管理器和多个应用之间来回切换的成本。

### 适用场景

- 📚 **开发者** - 快速访问项目文档、配置文件、脚本，并整理浏览器、终端和测试窗口
- 🎓 **学生 / 自学者** - 管理课程资料、笔记、作业文档，并清理学习期间打开的 PDF、浏览器和会议软件
- 🎨 **设计师 / 内容创作者** - 快速打开设计文件和素材，同时整理图片、媒体和通讯类应用
- 💼 **办公人员** - 管理工作文档、报告、表格，并高效关闭会议和协作带来的大量窗口
- 🛠️ **运维 / 技术支持 / 高级 Windows 用户** - 快速识别、筛选和处理运行中的应用程序

详细使用场景请参考 [使用场景+使用人群+产品优势.md](docs/使用场景+使用人群+产品优势.md)

## ✨ 功能特性

### 文件管理能力

- ⚡ **快速访问** - 一键打开收藏的文件，无需在文件夹中查找
- 🪶 **轻量高效** - 虚拟滚动技术支持管理 1000+ 文件而不卡顿
- 📁 **分组管理** - 按项目、主题或用途创建分组
- 🏷️ **标签系统** - 为文件添加多个标签，支持标签筛选
- 🔍 **智能搜索** - 实时搜索文件名、路径、分组和标签（300ms 防抖优化）
- 🔢 **多种排序** - 自定义排序、打开次数、文件名、最近打开、创建时间
- 🎴 **双视图模式** - 网格视图（卡片式）和列表视图（紧凑式）
- 🎯 **批量操作** - 多选文件进行批量打开、移动、删除
- 🖱️ **拖拽添加** - 直接拖拽文件到应用窗口添加收藏
- 📊 **使用统计** - 自动记录文件打开次数和最近打开时间

### Windows 应用管理能力

- 🔄 **运行中应用总览** - 查看当前运行中的 Windows 应用程序，并显示应用名称、PID、窗口标题、内存、CPU 等信息
- 🏷️ **智能分类识别** - 支持 13+ 应用类别、400+ 常见应用映射，便于按场景而不是按陌生进程名查找
- 🔍 **类别筛选与列排序** - 支持按类别筛选，并按名称、类别、PID、内存、CPU、窗口标题排序
- 📐 **列自定义** - 支持显示/隐藏列，并在列设置弹窗中拖拽调整列顺序
- ✅ **单选 / 多选 / 全选 / 反选** - 快速选中要处理的应用窗口
- ⚡ **单个关闭与批量关闭** - 支持关闭单个应用或批量关闭多个应用
- 🛡️ **重要应用确认保护** - 对关键应用保留确认机制，降低误关风险
- 🖱️ **右键快捷操作** - 支持显示到前台、复制信息、关闭进程
- 💬 **明确错误反馈** - 遇到权限不足时，会提示目标应用可能以更高权限运行

### 体验与性能优化

- 🚀 **文件虚拟滚动** - 只渲染可见区域的文件卡片，支持大量文件
- 🖼️ **图标懒加载** - 按需加载文件图标，加快启动速度
- ⏱️ **搜索防抖** - 输入停止 300ms 后执行搜索，避免卡顿
- 🔋 **标签页感知的应用刷新** - 仅在进程管理页激活时刷新，离开页面后停止监控以减少资源占用
- 💾 **本地存储** - 所有数据和设置都保存在本地，无需联网
- 🎨 **深色模式** - 支持亮色/深色主题切换
- ⌨️ **全局快捷键** - 自定义快捷键快速唤起应用（计划中）

## 📖 使用指南

### 添加文件

**方法 1：拖拽添加（推荐）**
- 直接拖拽文件或文件夹到应用窗口
- 支持同时拖拽多个文件

**方法 2：按钮添加**
- 点击顶部工具栏的"添加文件"或"添加文件夹"按钮
- 在弹出的对话框中选择文件

### 打开文件

- **单击卡片** - 使用系统默认程序打开文件
- **右键菜单** - 查看更多操作选项
- **批量打开** - 选中多个文件后点击"批量打开"

### 搜索文件

- 在顶部搜索框输入关键词
- 支持搜索：文件名、文件路径、分组名、标签名
- 搜索结果实时更新（300ms 防抖）

### 排序文件

点击顶部工具栏的"排序"下拉框，选择排序方式：

- **自定义排序** - 手动调整顺序（点击卡片底部的序号徽章编辑位置）
- **打开次数** - 最常用的文件排在前面
- **文件名** - 按字母顺序排列
- **最近打开** - 最近使用的文件排在前面
- **创建时间** - 按添加时间排序

### 分组管理

**创建分组：**
1. 点击顶部工具栏的"新建分组"按钮
2. 输入分组名称
3. 点击确定

**移动文件到分组：**
- 右键文件卡片 > 移动到分组 > 选择目标分组
- 或在编辑文件时修改分组

**切换分组：**
- 点击顶部的分组下拉框选择要查看的分组
- 选择"全部"查看所有文件

### 标签管理

**添加标签：**
1. 右键文件卡片 > 编辑
2. 在标签输入框中输入标签名
3. 按回车添加标签
4. 可以添加多个标签

**筛选标签：**
- 点击文件卡片上的标签，自动筛选相同标签的文件
- 在搜索框中输入标签名进行搜索

### 批量操作

**多选文件：**
- **Ctrl + 点击** - 选中/取消选中单个文件
- **Shift + 点击** - 选中范围内的所有文件
- **Ctrl + A** - 全选当前视图的所有文件

**批量操作：**
- 选中文件后，底部工具栏会显示批量操作按钮
- 支持：批量打开、批量移动、批量删除

### 视图切换

- 点击顶部工具栏的视图切换按钮
- **网格视图** - 卡片式布局，适合浏览和管理
- **列表视图** - 紧凑布局，适合快速查找

### 应用管理（Windows 独家）

File Keeper 内置了一个面向日常桌面工作流的应用管理页，让你在同一套界面里完成“找文件”和“整理当前工作窗口”两件事。

**当前已实现的能力：**
- 📊 **运行中应用总览** - 查看当前运行中的应用窗口，并显示应用名称、PID、窗口标题、内存、CPU 和类别
- 🏷️ **智能分类识别** - 支持 13+ 类别与 400+ 应用映射，包括浏览器、办公、终端、压缩、文档、媒体、图像、通讯、下载、游戏、系统等
- 🔍 **类别筛选** - 通过下拉筛选和常用快捷筛选快速定位目标应用
- ↕️ **按列排序** - 支持按名称、类别、PID、内存、CPU、窗口标题排序
- 📐 **列显示与顺序自定义** - 可显示/隐藏列，并在列设置弹窗中拖拽调整顺序
- ✅ **单选 / 多选 / 全选 / 反选** - 快速框定要处理的应用
- ⚡ **单个关闭与批量关闭** - 支持关闭单个应用，也支持一次性关闭多个选中应用
- 🛡️ **重要应用确认** - 对关键应用保留确认流程，减少误操作
- 🖱️ **右键快捷操作** - 支持显示到前台、复制信息、关闭进程
- 💬 **更清楚的错误提示** - 遇到权限不足时，会提示目标应用可能以更高权限运行

**使用方法：**
1. 切换到“应用管理”标签页
2. 浏览当前运行中的应用列表
3. 用类别筛选、列排序和列设置快速定位目标应用
4. 通过单选、多选、全选/反选选择要处理的应用
5. 使用“关闭选中”按钮或右键菜单完成关闭、前台显示或复制信息

**支持的应用类别：**
- 🌐 浏览器
- 📄 办公软件
- 📁 文件管理器
- 💻 终端
- 📦 压缩工具
- 📝 文档工具
- 🎬 媒体播放器
- 🖼️ 图像工具
- 💬 通讯软件
- 📥 下载工具
- 🎮 游戏平台
- ⚙️ 系统工具
- 📦 其他应用

**应用管理的性能策略：**
- 进入进程管理页时才启动刷新
- 切回文件管理页时停止监控并清空列表
- 页面不可见时暂停自动刷新，减少后台资源占用

### 文件进程管理

除了应用管理功能，File Keeper 还提供了针对单个文件的进程管理：

- 右键文件卡片 > 关闭已打开的进程
- 查看哪些程序正在使用该文件
- 一键关闭相关进程（需要管理员权限）

### 数据存储位置

File Keeper 的所有数据（文件列表、分组、标签、设置等）都存储在本地，无需联网。

**Windows 数据文件位置：**
```
%APPDATA%\com.filekeeper.app\file-keeper-data.json
```

完整路径通常为：
```
C:\Users\<你的用户名>\AppData\Roaming\com.filekeeper.app\file-keeper-data.json
```

**本地数据包含：**
- `file-keeper-data.json`: 所有添加的文件信息（路径、名称、标签、分组、打开次数等）、自定义分组配置、应用设置
- 应用管理相关设置：列配置、自动刷新状态、确认逻辑和白名单等会保存在当前应用的本地设置中

**备份数据：**
- 直接复制 `file-keeper-data.json` 可备份主要文件管理数据
- 应用管理相关设置会随当前本地应用环境保留

**注意：** 卸载应用不会自动删除数据文件，需要手动删除上述目录。

## 🔧 从源码构建

### 环境要求

- **Node.js**: 18+ (推荐 20+)
- **npm**: 9+ 或 pnpm 8+
- **Rust**: 1.70+ (推荐 1.80+)
- **操作系统**: Windows 10/11 (64-bit)

### 安装依赖

```bash
# 克隆仓库
git clone https://github.com/yourusername/file-keeper.git
cd file-keeper

# 安装前端依赖
npm install

# Rust 依赖会在构建时自动安装
```

### 开发模式

```bash
# 启动开发服务器（热重载）
npm run tauri:dev
```

### 构建生产版本

```bash
# 构建 MSI 安装包
npm run tauri:build

# 输出位置：src-tauri/target/release/bundle/msi/
```

### 运行测试

```bash
# 运行单元测试
npm run test

# 运行测试（监听模式）
npm run test:watch
```
