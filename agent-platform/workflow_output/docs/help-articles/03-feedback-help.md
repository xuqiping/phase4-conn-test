# 反馈与帮助

> 入口：左侧菜单「**反馈与帮助**」。你有想法、遇到问题、想找答案，都来这里。

## 一、提建议（产品改进想法）

1. 打开「反馈与帮助」，默认就在「提建议」页签。
2. 填**标题**（≤120 字）和**正文**（≤4000 字），都有字后「提交建议」才可点。
3. （可选）点「添加截图」传图说明，最多 3 张。
4. 点「**提交建议**」→ 下方「我的建议」列表出现新条目，状态「待审核」。
5. 管理员处理后，顶栏 💬 铃铛会有红点通知 → 点开自动跳过来。
6. 点列表「查看」→ 看处理结果（已采纳/未采纳/已关闭）和官方回复。

## 二、提问题（使用中遇到困难）

1. 切到「**提问题**」页签。
2. 填标题 + 问题描述 → 点「提交问题」→ 列表出现，状态「待回答」。
3. 管理员回答后铃铛通知你 → 点「查看」看官方回答。

## 三、查 FAQ（先看有没有人问过）

1. 「提问题」页签下方的 **FAQ 区**。
2. 输入关键词，停手片刻自动检索。
3. 命中的是平台公开的问答（**看不到提问人是谁**，已脱敏）。

## 四、看使用说明（本帮助中心）

1. 切到「**使用说明**」页签。
2. 左侧按**模块分类**选文章，右侧看正文。
3. **你只能看到自己有权使用的模块的说明**——看不到某模块说明 = 没有该模块权限，需要的话找管理员开通。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 提交按钮是灰的 | 标题或正文没填 | 补全即可 |
| 「附件最多 3 个」 | 截图超限 | 移除一张再加 |
| 提示提交太频繁 | 1 分钟内提交超 5 次 | 等 1 分钟 |
| 文章打不开 | 文章已被管理员下架 | 回目录选其他文章 |
