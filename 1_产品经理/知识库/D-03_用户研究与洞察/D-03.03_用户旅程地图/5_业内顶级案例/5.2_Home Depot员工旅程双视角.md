## Home Depot员工旅程双视角：当顾客和员工旅程叠加

### 案例档案

| 字段 | 内容 |
|---|---|
| **公司** | The Home Depot（美国家装零售） |
| **时间** | 2018 |
| **主角** | 体验设计团队 |
| **核心方法** | 双视角旅程地图（顾客+员工同步绘制） |
| **关键成果** | 发现双方痛点叠加的"高压区"才是真机会，驱动门店体验重构 [来源:CX行业会议分享 | 置信度:📚中] |

### 双旅程发现

Home Depot创新在：**不是只画顾客旅程，而是同时画员工旅程**。

**顾客旅程**（周末DIY爱好者）：

| 阶段 | 顾客痛点 | 情绪 |
|---|---|---|
| 列清单 | 不知道需要什么材料和工具 | 0 |
| 找货 | 仓库大、找不到区域，橙色围裙员工少 | -2 |
| 询问 | 员工忙着理货/结账，等5min+ | -3 ← MOT |
| 比价 | 同类商品太多不知选哪个 | -1 |
| 结账 | 排队长 | -2 |
| 返工 | 买错了需要退换 | -3 |

**员工旅程**（同一天的同一员工）：

| 阶段 | 员工痛点 | 情绪 |
|---|---|---|
| 开店准备 | 理货任务重、时间紧 | -1 |
| 被顾客拦住问路 | 自己也不熟悉所有区域 | -2 |
| 帮顾客选商品 | 缺乏专业家装知识培训 | -2 |
| 手持设备查库存 | 设备老旧、查询慢 | -2 |
| 结账台支援 | 排队长、POS系统卡顿 | -3 ← MOT |
| 收工复盘 | 感觉一整天在"救火" | -1 |

### 关键洞察：痛点叠加区

```
顾客痛点              员工痛点              叠加区=真机会
───────────────────────────────────────────────
找不到区域      ←→    不熟悉所有区域      →  门店导航+AR寻货
员工太少等5min  ←→    忙着理货没空服务    →  自助查询终端
不知道选哪个    ←→    缺乏专业培训        →  AI选品助手
POS排队长       ←→    POS系统卡顿         →  自助结账+移动POS
```

**发现**：顾客最大的抱怨"找不到人问" × 员工最大的抱怨"被到处拉去救火" = 同一个系统问题的两面。

### 关键决策时刻

**决策**：不以"顾客满意度"或"员工满意度"孤立优化，而是优化双方痛点叠加的4个高压区——

1. **AR门店导航**：顾客手机直接导航到货架，不需要找员工
2. **员工iPad+AI助手**：员工遇到专业问题一键查询，不再需要背所有SKU
3. **自助结账**：减少POS排队，释放员工去专业咨询
4. **任务调度优化**：AI排班优先保证高峰期有足够咨询岗员工

### 旅程方法论启示

| 启示 | 说明 |
|---|---|
| **双视角>单视角** | 只看顾客=盲区，只看员工=偏颇，叠加看=真相 |
| **痛点叠加=杠杆最大** | 解决1个叠加痛点=同时提升两端体验 |
| **员工不是成本而是触点** | 员工旅程决定了顾客旅程的上限 |
| **B2C同样适用** | 虽然Home Depot是零售，但"双视角旅程"在SaaS、B2B同样适用（客户旅程+CSM旅程） |
