# 影响评估：开发环境启停脚本

> 日期：2026-08-30
>
> 回滚锚点：`b52538d8`

## 变更范围

- 新增项目根目录启动、关闭、重启 PowerShell 脚本。
- 同步运行指南和 Git 忽略规则。
- 管理对象仅为 Memurai/Redis、PostgreSQL、Java 后端和 Tauri 桌面端。
- 管理后台不纳入脚本，每次执行结束都显式提醒。

## 联动与风险

- 启动顺序固定为 Redis → PostgreSQL → 后端 → Tauri，依赖未就绪时不继续。
- 关闭顺序反向执行。
- 端口已监听时视为组件已运行，不重复启动。
- 后端和 Tauri 的关闭依赖启动脚本记录的 PID，避免误杀其他 Java、Node 或 PowerShell 程序。
- PostgreSQL 和 Redis 仅操作明确识别的 Windows 服务或官方启停命令。

## 不受影响项

- 不改动业务代码、数据库结构、Tauri API 或 Office Worker 协议。
- 不改动已存在的端口和环境变量名称。
