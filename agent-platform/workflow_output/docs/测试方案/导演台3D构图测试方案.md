# 导演台3D构图 · 测试方案

> 覆盖 [plan](../plans/导演台3D构图.plan.md) Step 1-8。联动用例对齐 plan「功能联动点清单」L1-L9，每条含正向/反向/半途/批量边界。
> 纯逻辑层（sceneModel 校验/letterbox/分辨率/undo 栈）已由单测覆盖（656 全绿中 55 例），本方案仅人工交互部分。

## 一、前置环境

- 后端 + 前端 dev 栈已起；已登录账号建有任一画布
- 浏览器 Chrome/Edge（WebGL 可用）；另备一台可禁 WebGL 的环境（chrome://flags 关 WebGL 或 about:config webgl.disabled=true）用于 L9
- DevTools Performance/Memory 面板可用（性能口径用）

## 二、功能联动用例（L1-L9）

### L1 添加元素 → 视口 + 清单联动
| # | 操作 | 预期 |
|---|---|---|
| L1-1 正向 | 左栏点「人物」再点「桌子」 | 视口原点附近 5×5 网格位依次落件；清单各增一行 |
| L1-2 反向（undo） | 加 2 个元素后 Ctrl+Z 两次 | 视口与清单同步减少；再 Ctrl+Shift+Z 恢复 |
| L1-3 上限 | 加到 200 个（或复制至满） | 添加按钮禁用+红字提示；再 Ctrl+Z 可退 |
| L1-4 批量 | 群众阵列 12×12 一次加 144 人 | 一次成型、帧率不掉（InstancedMesh）；清单 1 行 |

### L2 清单点选 ↔ 视口 gizmo 双向
| # | 操作 | 预期 |
|---|---|---|
| L2-1 正向 | 清单点某行 | 视口该元素 attach gizmo 高亮，清单滚动定位 |
| L2-2 反向 | 视口点元素 | 清单对应行高亮并滚动到可见 |
| L2-3 清空 | 视口点空白处 | 双侧选中同时清空，gizmo detach |
| L2-4 互斥 | 视点点机位视锥 | 元素选中清空、机位面板行选中 |

### L3 隐藏开关 → 视口/截图
| # | 操作 | 预期 |
|---|---|---|
| L3-1 正向 | 清单行点眼睛 | 视口即时消失；清单行划线保留；数据保留 |
| L3-2 截图口径 | 隐藏 1 个元素后机位截图 | 截图不含该元素 |
| L3-3 反向 | 再点眼睛 | 视口恢复显示 |

### L4 新增机位 → 列表 + 视锥
| # | 操作 | 预期 |
|---|---|---|
| L4-1 正向 | 转好导演视角 →「从当前视角新增机位」 | 视锥落在当前视角位姿；列表增行 |
| L4-2 上限 | 加到 16 个 | 按钮禁用+提示 |
| L4-3 反向（删所在机位） | 进入机位 3 视角后删除机位 3 | 自动回导演视角，不黑屏不悬挂 |
| L4-4 点选 | 导演视角点机位视锥 | 机位面板对应行选中 |

### L5 切机位视角 → 主视口 + 遮幅
| # | 操作 | 预期 |
|---|---|---|
| L5-1 正向 | 机位行「看」 | 该相机渲染 + 黑边遮幅框 + 左上画幅/FOV 标签 |
| L5-2 联动 | 机位视角下改画幅 16:9→9:16 | 遮幅框实时变（横→竖） |
| L5-3 半途切走再回 | 机位 2 → 导演视角 → 再看机位 2 | FOV/画幅/名称保持不重置 |
| L5-4 只读 | 机位视角拖视口/点元素 | 无 orbit、无 gizmo、无点选；提示条在 |

### L6 截图 → 画布回流
| # | 操作 | 预期 |
|---|---|---|
| L6-1 正向 | 机位视角「截图回流画布」 | 画布新增图片节点（导演台右侧）+ 连边 + 卡片封面刷新 |
| L6-2 批量（连截） | 不关 modal 连截 3 张 | 3 个图片节点纵向依次偏移不叠位 |
| L6-3 反向（失败） | DevTools 断网再截 | toast 报错、无新节点、按钮恢复可点 |
| L6-4 WYSIWYG | 16:9 与 9:16 各截一张 | 两图长宽比与遮幅一致（长边 2048） |

### L7 关 modal → 场景暂存
| # | 操作 | 预期 |
|---|---|---|
| L7-1 正向 | 摆好场景 →「完成并关闭」→ 保存画布 | 卡片摘要变「N 元素 · M 机位」；刷新后场景还原 |
| L7-2 半途（不保存刷新） | 关 modal 后不保存直接刷新 | 回上次保存版（画布现状口径，不丢已保存数据） |
| L7-3 重开 | 关闭后重开 modal | 场景/机位/封面还原；undo 栈已清（Ctrl+Z 一步回不动） |

### L8 undo/redo → 全编辑器
| # | 操作 | 预期 |
|---|---|---|
| L8-1 正向 | 增删改/拖 gizmo/换姿势各做一次后连 Ctrl+Z | 每步整场景恢复（含机位变化） |
| L8-2 拖中不推栈 | 拖一次 gizmo松手 | 只推 1 条（Ctrl+Z 一次回到拖前） |
| L8-3 文本防抖 | 名称连续输入 | 500ms 合并一条（快速 Ctrl+Z 一次回改名前） |
| L8-4 上限 | 连做 50+ 步后 Ctrl+Z 到底 | 最早状态被丢（50 深），编辑器不卡 |

### L9 WebGL 失败 → 降级
| # | 操作 | 预期 |
|---|---|---|
| L9-1 降级 | 禁 WebGL 环境点「打开导演台」 | NAlert 明确提示可换浏览器；画布其他功能不受影响 |
| L9-2 卡片可用性 | 同环境建导演台节点 | 卡片正常建/显示引导（探测在打开时才做） |

## 三、性能口径（P4 实测记录处）

- three chunk gz 142.85KB（≤200KB ✅ 已实测）；主入口无 director 模块 ✅
- modal 打开→可交互 <1.5s / 100 元素+4 机位 ≥60fps / 开关 modal×3 内存增量 <10MB → P4 填数
