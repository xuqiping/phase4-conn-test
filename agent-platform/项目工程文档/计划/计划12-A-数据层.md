## 动作（伪代码）
1. **V47 建表**（按总体设计 §2 表清单）：
   - `memory_tags`：`UNIQUE(user_id, subject, topic)`；anchor_embedding halfvec + anchor_tokens tsv。
   - `memory_turns`：`project_ids BIGINT[]` 建 GIN；`born_personal bool`；`departed_project_ids[]` / `deleted_project_ids[]`；`gen_done bool`；`raw_content`（gen 关态用）；L0/L1/L2 列。
   - `memory_summaries`：`project_id BIGINT` 单值（个人=NULL）；`status` ENUM(CLEAN/PENDING_CONFLICT/STALE)；`source_summary_id` 链式；`source_turn_ids[]` flat provenance。
   - `memory_summary_coverage`：`UNIQUE(turn_id, tag_id, project_id, user_id) NULLS NOT DISTINCT`。
   - `memory_project_members`：role(OWNER/ADMIN/MEMBER) + recall_admin bool + status(ACTIVE/DEPARTED) + departed_at；`UNIQUE(project_id, user_id)`。
   - `memory_project_settings` / `memory_project_user_settings`：gen_enabled bool，默认 true。
   - `memory_consolidation_scopes`：`UNIQUE(user_id, scope_kind, project_id) NULLS NOT DISTINCT`。
   - `memory_notifications`：type(SUMMARY_AFFECTED_BY_RECALL/PROJECT_DELETED_AFFECTED) + resolved_at。
   - 扩 `memory_conflicts`：加 `tag_id` + `summary_id`（无 type 列）。
2. **实体**：继承 BaseEntity。**注意**：coverage/members/settings/consolidation_scopes/notifications 无 `deleted` 软删列（业务上硬约束或级联清），不强行加；turns/summaries/tags/conflicts 走软删。
3. **Mapper XML**：流水账/总结/覆盖/冲突四表所有读方法内联 `<include refid="SCOPE_FILTER"/>`；halfvec 算子转义 `&lt;=&gt;`；BIGINT[] 写入显式 `typeHandler=LongArrayTypeHandler`。
4. **SqlScopeFilter**：抽 `<sql id="SCOPE_FILTER">` 公共片段（按 user_id + project_ids 交集），供四表 include。
5. **新用户注册钩子**：AOP 或注册成功回调，默认插 `memory_consolidation_scopes (user_id, PERSONAL, NULL, auto_enabled=true)`。
