# 画像质量检查模板

## 一、定性画像（Persona）质量检查

### 检查清单（5维度×5项=25分制）

| 维度 | 检查项 | 标准 | 得分(0~5) |
|---|---|---|---|
| **可识别性** | 团队能叫出Persona的名字吗？ | ≥80%团队成员能叫出→5分 | |
| | Persona有照片/视觉化呈现吗？ | 有真实感照片→5分；无→0分 | |
| **可区分性** | 任意2个Persona≥3个行为变量不同？ | 全满足→5分；有1对不满足→2分 | |
| | Persona不是简单的年龄/收入切分？ | 行为变量为主而非人口统计→5分 | |
| **可共情性** | 引用语是用户原话而非PM编造？ | 100%原话→5分；有编造→0分 | |
| | 痛点描述能引发"我也遇到过"共鸣？ | ≥3位同事共鸣→5分 | |
| **可操作性** | 每个Persona关联≥2个设计决策？ | 全满足→5分 | |
| | 画像素材以场景驱动而非属性列表？ | 场景优先→5分；属性罗列→2分 | |
| **可溯源** | 每条属性标注数据来源？ | 100%溯源→5分；有遗漏→2分 | |
| | 无数据支撑的标"⚠️假设待验证"？ | 全标→5分；有遗漏→0分 | |

**合格线**：≥18分；**优秀线**：≥22分

### Persona自查三问

1. **删除测试**：删掉这个Persona，会影响什么设计决策？→ 无影响则该Persona冗余
2. **合并测试**：两个Persona能合并吗？→ 能合并则区分度不足
3. **反例测试**：团队里有同事说"我不是任何一个Persona"吗？→ 有则说明覆盖不全

### 标签健康度仪表盘

| 指标 | 定义 | 健康标准 | 告警阈值 |
|---|---|---|---|
| **覆盖率** | 有标签用户/总活跃用户 | ≥85% | <60% |
| **准确率** | 抽样校验正确率 | ≥90% | <75% |

| **冗余度** | 与其他标签相关系数>0.9的占比 | <10% | >25% |
