## 0. 两个关键决策（已与人确认）

1. **渲染引擎 = ffmpeg ProcessBuilder（源码原样移植，不改写 javacv）**。
   源码 `FfmpegEditProvider` 已用 ffmpeg `filter_complex` **完整实现**多轨合成（VIDEO 黑帧 concat + AUDIO volume/adelay/amix + TEXT drawtext），音频混音（原声 + 多 BGM）天然由 `amix` 支持、已验证可用。
   本机已装系统 ffmpeg（`/d/ImageMagick-7.1.1-Q16-HDRI/ffmpeg`，且 `ffmpeg` 在 PATH），源码可直接跑。
   javacv Frame API 不暴露 `filter_complex`，纯 Java 重写多轨音频混音 = 共享 PCM 缓冲 + 样本对齐求和，风险高（本项目 `VideoFrameService` 当初因此坑跳过音频）——故放弃重写，直接移植源 ffmpeg 实现。
   **代价（已知情接受）**：偏离 canvas 模块「禁 sidecar 子进程」软约定。该约定是 `VideoFrameService` javadoc 记的**单服务口径**（frame 抽帧是 javacv 的简单场景），非 CLAUDE.md 全局铁律；多轨剪辑是 ffmpeg CLI 的强项，两服务口径不同合理。**部署要求**：Linux 生产机须装系统 ffmpeg（Windows 开发机已具备）。
2. **不计费**（不扣积分）。剪辑渲染 = 确定性像素/编码合成，**无任何大模型调用**；草稿导出 = 本地 zip 打包，也无 LLM。按用户规则「不涉及大模型不扣积分」，源码本就无计费（grep `charge|billing|points` 零命中），无需删。

> **合并因此变成「近乎逐字移植已验证模块」**：9 个跨包 seam 全部在目标 1:1 存在，provider 不再需要重写，C2 风险从「最大」降为「机械移植」。整体风险与工期大幅下降。

## 3. 技术坑点预判

- **坑 #1（必踩，项目史高频）：MyBatis 构造器位置映射 OOB。** `MediaEditTaskVO`/`MediaAssetVO` 用 `@Data @Builder` → Lombok 全参构造器 → MyBatis 按 SELECT 列序位置映射，列错位 OOB（本项目 P4/links 等多次中招）。
  **规避**：两 VO 必加 `@NoArgsConstructor`，移植第一件事核对。
- **坑 #2（部署，ffmpeg 可用性）：生产机须装系统 ffmpeg。** 源码 `ProcessBuilder` 拉 PATH 上的 `ffmpeg`。Linux 生产机若无 ffmpeg，render 全 FAILED。
  **规避**：部署清单写明「装 ffmpeg（含 libx264/aac）」；`media.edit.enabled=false` 可临时关提交；`media.edit.ffmpeg-path` 可指绝对路径；启动健康检查可探 `ffmpeg -version`（后续再说，§6）。
- **坑 #3（命令注入，安全核心）：ffmpeg 子进程参数。** ProcessBuilder 走参数数组（不经 shell）已防 shell 注入；但 drawtext 文本、fontfile、文件路径仍是潜在面。
  **规避（源码已实现，照搬）**：字幕走 `textfile=<temp>` 临时文件，**不**用 `text=<用户串>`；文件一律用 worker 生成的内部 temp 路径（按 fileId 命名），用户文件名永不入命令；fontfile 是 admin 配置路径（非用户输入）；所有滤镜数值（trim/scale/fps/volume/adelay/start-end）来自已校验 double，非字符串拼接。见 §4。
- **坑 #4（资源）：worker 多实例 + 线程池 AbortPolicy。** 队列满 submit 抛 `RejectedExecutionException` → 该轮 claim 的任务卡 RUNNING 至锁过期 → 下次 poll 重认领。
  **规避**：claim BATCH ≤ 线程池（max4）容量，或捕获 Rejected 回退；照源 BATCH 默认，核对 BATCH vs pool 比。
- **坑 #5（CJK 字体）：ffmpeg 4.4 不收 `.ttc`，须 `.ttf/.otf`。** Windows `msyh.ttc` 给 ffmpeg drawtext 会失败。
  **规避**：`resolveFontFile()` 候选列表优先 `.ttf/.otf`；Windows 找 `arial.ttf`/转 `msyh` 的 `.ttf`；macOS/Linux 候选照源；有字幕但无可用字体 → fail-fast，不静默丢字幕。
- **坑 #6（probe 边界）：`ffmpeg -i` 退出码非 0 属预期。** 未指定输出时 ffmpeg 报 "At least one output file must be specified" 退出非 0，但 stderr 已含 Duration/Video/Audio 信息。
  **规避**：probe 路径不断言退出码，按 stderr 文本解析（照源 `parseFfmpegInfo`）。
- **坑 #7（并发/锁）：SKIP-LOCKED 复用须与目标同口径。** 目标 `MediaGenTaskTxService.claimBatch` 已成熟，源 `MediaEditTaskTxService` 同构。
  **规避**：照搬源 claimBatch SQL；renewLock 时机照源；勿自创锁逻辑。
- **坑 #8（迁移）：V87 必须空位。** 目标 V68/69/70 已跳过，最高 V86。
  **规避**：建迁移前 `ls db/migration/V8*` 复核 V87 未占。

## 4. 安全检查清单（对照 P1 安全策略）

- [ ] **鉴权**：Controller 所有端点 `@RequirePermission("media:edit")`（C6）；权限 admin-only 种子（C0）；前端 triple-fallback（菜单隐 + canEdit + 403，C7）。
- [ ] **输入校验**：`MediaAssetService.validate` 提交期校验归属（`FileStorageService.load` 咽喉点）+ 格式（probe）+ 时长/段数上限（properties）（C3）。

## 5. 功能联动点清单（正向 + 反向 + 边界）

- **L1 视频轨片段增删/移动 → timelineEnd 重算 → 黑帧间隙变化**
  边界：空 VIDEO 轨 → 提交拒（至少 1 段）；段间无间隙 → 不插黑帧；末段 targetEnd < timelineEnd → 补尾黑帧；段重叠 → 校验拒（同轨禁重叠）。
- **L2 AUDIO 轨/段音量 → amix 成片音量**
  边界：段级 volume 覆盖轨级；volume clamp [0,1]；0=静音不剔流；无任何音频源 → 产出无音轨 mp4（audioOut=false 分支，不 map [aout]）。
- **L3 字幕时段/内容 → drawtext 叠加窗口**
  边界：字幕 targetEnd 超 timelineEnd → enable=between 自然截断；空 content → 跳过；有字幕但无可用字体 → fail-fast；position 缺省 BOTTOM。
- **L4 提交 → worker → 前端轮询状态机 PENDING→RUNNING→SUCCEEDED/FAILED**
  边界：FAILED 后 attempt < 上限 → 锁过期自动重认领；attempt 超限 → 终态 FAILED 不再跑；worker 崩溃 → 重启下次 poll 续跑（SKIP-LOCKED 崩溃恢复）；DOWNLOAD_FAILED 常量 edit 不用（本地渲染无下载步，仅 SUCCEEDED/FAILED）。
- **L5 资产面板（生成视频列表）← 新生成视频落 media_gen_tasks SUCCEEDED**
  边界：仅 SUCCEEDED + result_file_id 非空才列；非 owner 不可见（admin 全见）；FAILED/PENDING 不列；与 asset 库模块概念相邻但**不合并**（edit 面板独立查 media_gen_tasks）。
- **L6 渲染产物落 stored_files(source=EDIT) → 详情 videoUrl 出现**
  边界：仅 SUCCEEDED + owner 出 videoUrl；非 SUCCEEDED/非 owner → videoUrl=null（前端不渲染播放器）。
- **L7 Sidebar 菜单 ← authStore.hasPermission('media:edit')**
  边界：无权限 → 菜单项不显；路由仍可达（无 per-route guard）→ 页内 canEdit=false + API 403（平台 triple-fallback 一致）。
- **L8 导出草稿 ← 同一 EditSpec（不渲染，纯 zip）**（C5 后置）
  边界：素材归属校验同 submit；总素材超 draftMaxTotalMb → 拒；export 与 render 互不影响（失败任务仍可导出草稿到剪映手剪）。

## 6. 运维考量清单（7 类，逐条 做/不做/后续再说）

1. **可观测性** — **做**。worker log taskId/阶段/costMs；render log vsegs/audios/texts/WxH/fps/timelineEnd/用时（照源已有）；失败固定话术。`ffmpeg.log` 落 workDir 供排障。traceId 全链 —— **后续再说**（接入平台现有 trace 时补）。
2. **配置开关** — **做**。`media.edit.enabled` 出问题可关提交入口（worker 仍跑完已提交任务）；`ffmpeg-path` 可指绝对路径或关；`media.edit.max*`/`*TimeoutSeconds` 全可调。
3. **可回滚** — **做**。V87 迁移带注释 rollback 段（drop table + del permission/role_perm）；Flyway `baseline-on-migrate=true`。`media_edit_tasks` 新表无数据迁移，回滚=删表（任务丢，MVP 可接受）。`SOURCE_EDIT` 常量删之即可（无引用则安全）。
4. **限流/熔断/降级** — **做**。`mediaEditExecutor` core2/max4/q20 AbortPolicy = 自然并发限流；`renderTimeoutSeconds` 540s 超时 destroyForcibly；无外部 LLM 依赖故无外部熔断需求。**部署机 ffmpeg 缺失** = 全局降级（render 全 FAILED）→ 靠 `enabled=false` 关提交 + 装 ffmpeg 恢复。
5. **运维入口** — **部分做**。重试：FAILED attempt<上限 → 锁过期自动重认领（免运维）；查日志：worker 日志 + `media_edit_tasks` 表 + `ffmpeg.log`；修脏数据：admin SQL 改 status 重置 attempt。手动运维脚本（批量重跑/清孤儿 temp）—— **后续再说**。
6. **告警阈值** — **后续再说**（MVP 无监控接入）。接入平台监控时补：render 失败率 > X%、worker 认领异常连续 N 轮、线程池 reject 累计、**ffmpeg 不可用**（probe 启动失败率）。
7. **容量/性能预案** — **做（索引/清理）/后续再说（分区）**。`media_edit_tasks` 索引 `(user_id,created_at)` + `(status,created_at)`（照源）；临时文件 `cleanupStaleTemp` PT2H 扫；渲染产物复用平台 `stored_files` 清理策略；ffmpeg 渲染是 CPU 密集，靠线程池 max4 自然限并发。大表分区/归档 —— **后续再说**。**部署清单必写**：Linux 生产机装 ffmpeg（libx264 + aac）。

## 7. 术语表

- **EditSpec**：剪辑意图，`edit_spec` JSONB 的 Java 投影，贯穿提交/校验/渲染/导出。
- **schemaVersion V1/V2**：V1=旧单轨（顶层 clips/texts/audio）；V2=多轨（tracks 权威）。Normalizer 统一抬到 V2。
- **TrackSpec（VIDEO/AUDIO/TEXT）**：VIDEO 全局唯一；AUDIO 可多条混音；TEXT 持字幕列表。
- **SegmentSpec**：视频/音频片段。`trimStart/trimEnd`=素材内裁剪秒；`targetStart/targetEnd`=成片时间轴秒。
- **timelineEnd**：成片总长 = 所有段/字幕 targetEnd 的最大值。
- **filter_complex**：ffmpeg 单遍滤镜图，本模块把多轨合成（concat/amix/drawtext）编进一条。
- **amix / adelay / drawtext / concat**：ffmpeg 滤镜——混音 / 时间轴延迟对齐 / 文字叠加 / 流拼接。
- **SKIP-LOCKED**：Postgres 行锁子句，多 worker 抢任务互不阻塞。
- **stored_files.source=EDIT**：剪辑渲染产物在文件表的来源标记（区别 MEDIA/CANVAS/ASSET）。
- **剪映 draft_content.json**：剪映 draft 工程文件，`DraftExportService` 把 EditSpec 转成此格式 + 媒体打包 zip。
- **triple-fallback**：前端权限三重兜底——菜单隐 + 页内 canEdit=false + API 403（本项目无 per-route 权限守卫的约定）。
