### Provider role 路由（核心）

```java
// IMAGE2VIDEO + refImageUrl 通道
if ("last".equalsIgnoreCase(request.getFrameRole())) {
    content.add(Map.of("type","image_url", "image_url",Map.of("url",url), "role","last_frame")); // 尾帧
} else {
    content.add(Map.of("type","image_url", "image_url",Map.of("url",url))); // 首帧/默认，裸无 role（向后兼容）
}
```

**关键决策**：首帧保持**裸 image_url 不带 role**（旧路径已 E2E 通过，不动）；仅尾帧加 `role:last_frame`。最小改动面 + 零回归风险。对外 DTO 只暴露通用 `first`/`last`，Ark 专属 role 字符串封在 provider。
