## Step 12：移除管理后台商业运营入口

- [x] **目标**：后台只保留账号与设备安全管理，不展示商业权益、试用和额度。
- **动作**：
  - UserDetail 删除设备上限/离线缓存表单、权益列表和授权操作；保留用户信息、禁用/启用和设备列表。
  - UserList 删除待审核筛选、审核按钮和设备上限列；状态映射保留 active/disabled 等真实状态。
  - Dashboard 删除待审核和权益到期卡片/跳转。
  - Settings 页面当前只有商业设置，因此删除页面、导航和路由。
  - 移除匿名设备侧栏和路由；直接访问旧路径应进入现有 404/安全首页，不白屏。
  - Router 增加认证区 catch-all 重定向到 Dashboard，覆盖旧 settings/anonymous-devices 收藏链接。
  - 删除不再被管理后台引用的 `entitlements`、`anonymousDevices`、`settings` API 文件；服务端兼容接口仍暂留。
- **文件**（≤20）：
  - `admin-web/src/views/UserDetailView.vue`、`UserListView.vue`、`DashboardView.vue`、`SettingsView.vue`、`AnonymousDevicesView.vue`。
  - `admin-web/src/views/Layout.vue`、`admin-web/src/router/index.ts`。
  - `admin-web/src/api/users.ts`、`entitlements.ts`、`anonymousDevices.ts`。
  - `admin-web/src/api/settings.ts`。
  - `admin-web/src/types/index.ts`。
- **依赖**：子计划 2 Step 10。
- **无障碍**：保留禁用/启用按钮明确文本与确认弹窗；移除导航后键盘焦点顺序连续。
- **验证**：`npm --prefix admin-web run build`；浏览器人工验证侧栏、用户列表、详情、禁用/启用、设备禁用和旧路由。

## Step 16：人工联动回归与兼容观察

- [ ] **目标**：覆盖自动测试难以证明的桌面、后台和旧客户端行为。
- **动作**：
  - 未登录：文件/进程/剪贴板/截图全可用；工作汇报/AI 显示登录引导。
  - 登录：注册即 active；工作汇报、AI、收件箱、灵感、推送可用且数据隔离。
  - 退出/refresh 失败：服务端内容清空，本地功能继续运行。
  - 多设备：超过旧上限可注册；禁用其中一台只阻断该设备服务端访问。
  - 管理后台：无商业入口；用户/设备禁用正常；旧路由不白屏。
  - 兼容接口：匿名/登录授权接口返回计划语义，无 500；记录调用日志以备后续清理。
- **文件**：
  - `workflow_output/docs/测试方案/取消商业化与开放模块.测试方案.md`（新建）。
  - `workflow_output/开发进度/取消商业化与开放模块/开发进度1.md`。
