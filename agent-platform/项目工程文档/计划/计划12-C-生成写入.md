## 动作（伪代码）
1. **MemoryPrefilter**（不调 LLM，按侧独立判）：
   - INPUT 侧：过短/纯标点语气词/纯确认/致谢/系统提示 → 仅跳 INPUT。
   - OUTPUT 侧：纯套话/免责/重复致歉/无信息客套 → 仅跳 OUTPUT。
   - 敏感黑名单（密码/支付/验证码/身份证/银行卡/token，**预置默认开，用户只能加项不能清空核心项**）→ 命中即跳该侧。
   - 两侧都跳 → 不调 LLM 不写 raw；一侧跳 → 调一次 LLM 出未跳侧；双侧未跳 → 一次出双方三层。
2. **MemoryGenerator**：双侧三层同生，单 `gen_done` 标记；结构化输出 schema 校验 + applyClean 兜底 + 重试。
3. **MemoryGenToggleService**：项目对话 = `memory_project_settings.gen_enabled`(owner) AND `memory_project_user_settings.gen_enabled`(会员覆写)；任一关 → 跑过滤后过过滤侧写 raw（`gen_done=false`，tag/L1/L2 空）；非项目读 `rag.memory.gen.personal.enabled` 兜底。
4. **MemoryService 写入链**：流式回复后 `memoryTaskExecutor` 异步 fire-and-forget 落两条 turn；写入目标多选（默认勾个人，与召回解耦）；`born_personal` 定死，`project_ids` 叠加；卸空转 born_personal=true。
5. **raw 透明化**：gen 关态首条写 raw 前**非阻塞强提示**（不阻塞非模态）；raw 在线查看/批量删除端点（**仅本人，无导出/下载**）。
6. **顶端说明条（M3）**：明示「开启会记录提炼对话、每条调生成 LLM 加 token、关闭后新对话不生成、原文 90 天后清除、已生成摘要保留」，一键关。
