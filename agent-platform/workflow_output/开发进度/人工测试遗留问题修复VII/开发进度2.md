## Chunk 4 · Ctrl+C/V 接入（commit `1095e04a`）

- `CanvasBoard.vue`：
  - `clipboard = ref<CanvasClipboard|null>` 组件级内部剪贴板（不碰系统剪贴板）。
  - `onWindowKeydown` 扩展：Ctrl/Cmd（无 Alt）+ `c`/`v` 分支，置于 Delete 分支之前。
  - `onCopyKeydown(e)`：**无选中 → clipboard=null 且不 preventDefault**（系统复制/图片通道恢复，K1）；有选中 → buildCopySet + preventDefault + `emit('nodes-copied', n)`。
  - `onPasteKeydown(e)`：clipboard 为空 → 直接 return 不拦截（外部图片走修复VI paste 链，K2 三级优先）；非空 → preventDefault + pasteSubgraph()。
  - `isTypingTarget(t)`：`t instanceof HTMLElement` 守卫（e.target 可能是 window）+ isEditableTarget + `.n-input/.n-base-selection,.mention-ta` closest——焦点在输入框三级全让位。
  - `pasteSubgraph()`：落点 = 有指针轨迹用最后鼠标位置、否则视口中心；`project()` 转画布坐标；**一次** pushHistory('paste') 后 nodes/edges **直批 push**（绝不走 addNode/appendEdges——那会拆成 'add'+'edge' 两历史步，plan 坑 1）；一次 structure-changed；`clip.pasteCount++`。
  - defineExpose 增 pasteSubgraph/clipboard；新 emit `nodes-copied`。
- `CanvasView.vue`：`@nodes-copied` → toast「已复制 N 个节点，Ctrl+V 在鼠标处粘贴」。
- 测试：describe「节点复制粘贴」7 例（key() 派发真实 KeyboardEvent）：复制计数 emit/粘贴重映射+诱导边/连按 +32/一步撤回/输入框放行/无选中复制后图片通道恢复/脱钩直查 data.taskId。
