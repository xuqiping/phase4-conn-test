# D-19.05 AI产品指标

## 是什么

**AI产品指标（AI Product Metrics）**：用于量化AI产品健康度、用户价值、运营效率、系统性能的指标体系，与传统互联网指标（DAU/MAU/留存/转化）互补但本质不同——AI产品额外需度量"输出质量（用户拿到的是否有用/正确）+ 运营成本（Token消耗/单次成本）+ 系统性能（延迟/吞吐）"三组维度。2026年AI PM的最大共识是："没有AI指标的AI产品都是赌博"——不度量采纳率/任务完成率/幻觉率，根本不知道产品做得好不好 [来源:知乎AI产品指标 | 🔍高 | 2026-04/05]。

**三大类指标体系**（PM视角）：
1. **质量指标**——AI输出有没有用、对不对、用户满不满意（采纳率/任务完成率/幻觉率/引用准确率等）
2. **成本指标**——AI产品烧不烧钱、能不能持续运营（Token消耗/单次成本/缓存命中率/单位任务成本）
3. **性能指标**——AI响应快不快、稳不稳（延迟TTFT/TPS/吞吐/错误率/并发）

**三个核心问题**（PM视角）：
1. **质量怎么度量**——AI输出是概率生成，"正确率"不像传统软件二元化；要从采纳率/重写率/任务完成率/人评/LLM-as-Judge多角度组合度量
2. **成本怎么平衡**——Token调用是真金白银，Cache命中率/模型路由/上下文工程直接影响毛利率；2026年AI产品成本优化已是PM核心KPI
3. **性能怎么感知**——TTFT（首字时延）/TPS（每秒Token数）直接决定用户体验；推理模型o1/R1引入新维度：推理时延与质量如何权衡

**2026 AI指标范式**（基于知乎30个AI核心指标/斯坦福AI指数2026/Day35三指标方法论）[来源:知乎/斯坦福 | 🔍高 | 2026]:
- **三指标速判**（面试直接拿来说）：①意图命中率（用户问什么AI答什么）②任务完成率（AI能独立完成比例）③幻觉率（一本正经胡说的比例）[来源:知乎Day35 | 🔍高 | 2026-05]
- **质量指标体系从"准确率"转向"采纳率"**——AI输出最终是否被用户采纳/编辑/抛弃，是最直接的用户价值信号
- **成本指标成为商业可持续性关键**——Token成本、缓存命中率、模型路由降本是2026 AI PM的硬仗
- **推理模型带来新指标维度**——推理时延/思考Token数/思考深度，是质量-成本-性能三维权衡的新变量

## 核心要素

| 要素 | 说明 | 典例 |
|---|---|---|
| **意图命中率** | AI理解用户意图正确的比例 | 搜索/客服类指标 |
| **采纳率** | AI输出被用户采纳的比例 | Copilot"Tab采纳率"是核心 |
| **任务完成率** | AI独立完成任务不需人工介入的比例 | Agent核心指标，目标>90% |
| **幻觉率** | AI编造事实的比例 | 高风险场景核心指标 |
| **重写率** | 用户重写AI输出的比例 | 衡量输出质量 |
| **引用准确率** | 引用溯源的链接正确性 | Perplexity类指标 |
| **工具调用成功率** | Agent调用工具成功的比例 | Agent专项 |
| **用户满意度** | 点赞/点踩/星级 | 通用体验指标 |
| **Token消耗** | 接口消耗的Token数 | 成本核心 |
| **单次调用成本** | 单次API调用费用 | 成本测算 |
| **缓存命中率** | 命中缓存省Token的比例 | 降本关键 |
| **单位任务成本** | 完成一次任务平均成本 | 商业可持续性 |
| **TTFT** | 首字时延（Time To First Token） | 流式体验核心 |
| **TPS** | 每秒生成Token数 | 流式速度 |
| **总时延** | 端到端响应时间 | 体验核心 |
| **吞吐量** | QPS/并发数 | 系统容量 |
| **错误率** | 接口/解析错误比例 | 稳定性 |
| **SLA达成率** | P95/P99时延达成率 | 企业级指标 |

## 为什么AI PM必须懂AI产品指标

1. **传统指标不够用**——DAU/MAU/留存衡量"用户来不来"，但AI产品要回答"输出对不对/贵不贵/快不快"，传统指标完全不覆盖这三个核心维度 [来源:知乎AI产品指标 | 🔍高 | 2026-04]
2. **不度量=赌博**——AI输出是概率生成，没有指标就分不清"AI真的解决了用户问题"还是"用户只是好奇来了一下"，产品迭代会失方向 [来源:知乎Day35 | 🔍高 | 2026-05]
3. **成本决定商业可行性**——AI产品Token是真金白银，PM不做缓存/路由/上下文工程优化，毛利会被吃光；2026 AI产品成本优化是PM核心KPI
4. **本能力有`I.09必选`标记**——AI指标维度是评估核心；不会度量就无法做AB、无法量化改进、无法做成本优化
5. **2026推理模型新挑战**——o1/R1推理时延长、思考Token贵，质量提升 vs 成本/性能下降是新PM必答的三维权衡题
6. **AI采用率已88%**——2026斯坦福AI指数显示全球生成式AI采用率88%、80%大学生使用生成式AI工具 [来源:斯坦福HAI | 🔍高 | 2026-06]；量这么大，没有指标就是裸奔

## 常见误区

- **误区1：只看DAU/MAU**——AI产品的用户行为比传统互联网复杂得多，DAU高不代表AI输出有价值；要叠加采纳率/任务完成率
- **误区2：只看准确率**——AI输出不是二元化"对/错"，准确率难定义；要组合采纳率/重写率/人评/LLM-as-Judge
- **误区3：忽视幻觉率**——AI幻觉是核心风险，不度量=不知情；高风险场景（医疗/金融/法律）幻觉率必须核心跟踪
- **误区4：成本不PM事**——很多PM把Token成本当后端问题；2026年AI PM要直接背成本KPI
- **误区5：缓存命中率不管**——Cache能省30-80%成本，不优化等于烧钱
- **误区6：只看平均值不看分布**——平均时延2秒但P99可能10秒，长尾用户体验崩塌
- **误区7：忽视学习曲线**——AI产品指标初期变化大（用户不熟悉），过早判定易误判
- **误区8：指标不分级**——质量/成本/性能指标要分级管理（北极星/主指标/辅助指标），不能并列堆
- **误区9：自动指标代替人评**——自动指标（BLEU/ROUGE）与人类偏好相关性弱，必须配人评/LLM-as-Judge
- **误区10：指标不回流模型**——指标数据未回流训练/Reward Model，产品永远停在初始水平
