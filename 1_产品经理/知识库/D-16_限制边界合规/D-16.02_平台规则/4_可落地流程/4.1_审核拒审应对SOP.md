## 一、拒审分析决策树

> 收到拒审通知后，PM按此决策树定位问题类型和整改方向。

```
收到拒审通知
│
├─ Apple App Store
│   ├─ 有条款编号(如4.3/5.1.1/3.1.1)?
│   │   ├─ 是 → 进入"条款定位"(见1.1)
│   │   └─ 否 → 仅有文字描述 → 进入"通用分析"(见1.2)
│   │
│   └─ Resolution Center有审核员补充信息?
│       ├─ 有 → 仔细阅读补充说明，针对性回复
│       └─ 无 → 自查可能违规点后回复提问
│
├─ Google Play
│   ├─ 有政策名称(如"Personal and Sensitive Information")?
│   │   ├─ 是 → 对照Play Policy定位具体条款
│   │   └─ 否 → 检查Play Console警告/日志
│   │
│   └─ 是否收到"App Suspension"通知?
│       ├─ 是 → 紧急处理(见1.3)，30天内整改否则永久封号
│       └─ 否 → 常规拒审处理
│
└─ 微信小程序/国内安卓商店
    ├─ 查看审核详情中的"驳回原因"
    └─ 多为类目不匹配/内容不合规/资质缺失 → 定向修复
```

### 1.1 Apple常见拒审条款定位表

| 拒审条款 | 含义 | 根因分析 | 整改方向 |
|---|---|---|---|
| 2.1 App Completeness | App不完整 | ①未提供测试账号 ②功能崩溃 ③审核期间服务器宕机 | 配置测试账号+确认服务可用+提供演示数据 |
| 2.3 Metadata | 元数据不符 | 截图/描述与实际功能不同 | 重新制作截图，描述如实说明功能 |
| 3.1.1 In-App Purchase | 未使用IAP | 虚拟商品用了第三方支付 | 移除第三方支付，接入Apple IAP |
| 4.2 Minimum Functionality | 功能不足 | ①纯WebView封装 ②功能过于简单 ③信息展示型App | 增加原生功能/推送/离线能力 |
| 4.3 Spam | 垃圾App | ①同类App套壳 ②功能与已上架App雷同 ③模板生成器 | 突出差异化功能，提供独特品牌内容 |
| 5.1.1 Privacy | 隐私合规问题 | ①无隐私政策 ②权限说明不充分 ③过度收集 | 补充隐私政策+完善Info.plist权限说明 |
| 5.1.5 Location | 位置使用不当 | 位置采集无明确功能用途 | 增加位置功能说明，证明必要性 |

### 1.2 Google Play常见拒审定位表

| 政策名称 | 含义 | 整改方向 |
|---|---|---|
| Personal and Sensitive Information | 隐私信息安全问题 | 检查Data Safety表与实际行为一致性；补充隐私政策 |
| Target API Level | API版本过低 | 升级target API至最新要求并做兼容性测试 |
| Payments Policy | 计费政策违规 | 数字商品须用Play Billing；检查替代计费合规性 |
| Impersonation | 冒充他人 | 修改App名称/图标/描述，避免与知名App混淆 |
| Malicious Behavior | 恶意行为 | 移除可疑SDK/代码；提交安全分析报告申诉 |
| Multiple Violations | 多次违规 | 优先解决最严重问题；整改完毕后一次性提交 |

### 1.3 紧急下架/封号应急预案

```
Step 1: 确认下架原因（24小时内）
  └─ 登录开发者后台/查阅邮件 → 定位具体违反条款
  └─ Apple: Resolution Center查看
  └─ Google: Play Console > Policy status
  └─ 微信: 站内信+邮件通知

Step 2: 评估影响范围（24小时内）
  └─ 影响用户数 → 是否需要公告/客服预案
  └─ 是否影响正在付费的用户 → 订阅退款预案
  └─ 是否涉及竞品/合规部门 → 通知法务/合规

Step 3: 整改并重新提交（3-5个工作日内）
  └─ 修复违规点
  └─ 准备申诉说明（见下方模板）
  └─ 提交审核 + 在说明中解释整改措施

Step 4: 如果申诉被拒（升级路径）
  └─ Apple: 申请App Review Board复审
  └─ Google: 提交Play Console申诉表单
  └─ 微信: 通过"申诉专区"提交
```

## 四、上架前自查清单（20项）
