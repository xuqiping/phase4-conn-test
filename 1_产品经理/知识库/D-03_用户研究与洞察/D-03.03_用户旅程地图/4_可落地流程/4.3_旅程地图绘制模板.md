╚══════════════════════════════════════════════════════════════╝
```

**填写规则**：
- **阶段名**：用户语言，3~7个
- **行为**：动词开头，每阶段2~5个
- **触点**：标注类型（线上/线下/人际/情感），按主次排列
- **情绪**：-3~+3整数，每点必须标数据来源
- **MOT**：情绪转折>1.5的地方标记YES
- **摩擦类型**：建=建设性摩擦（可保留优化），破=破坏性摩擦（必须消除）

**情绪曲线绘制checklist**：

| 检查项 | ✓/✗ |
|---|---|
| 每个数据点都有数据来源标注 | ☐ |
| 识别了所有情绪低谷（≤-1） | ☐ |
| 识别了所有MOT（转折点） | ☐ |
| 低谷区分了建设性vs破坏性摩擦 | ☐ |
| 有对应的痛点-机会配对 | ☐ |
| 曲线走势与用户原话一致 | ☐ |

触点遗漏检查：
□ 是否包含"竞品触点"（用户在你家搜索、竞品比价、回你家下单）？
□ 是否包含"非数字触点"（线下门店、快递、客服电话）？

```
