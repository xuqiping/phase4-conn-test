# Implementation Plan for 记忆系统二期 · P1 收录路由

> 主索引：[记忆系统二期.plan.md](记忆系统二期.plan.md) ｜ 规格 FR-001~008
> 内部步骤串行为主（主干链路，环环相扣）。

## 本模块坑点预判

| 坑 | 规避 | 验证 |
|---|---|---|
| 路由在写链路上拖慢落库 | 路由整个挂在 processTurnAsync 之后独立 fire-and-forget（memoryTaskExecutor），异常吞掉只记日志 | 路由抛异常，turns 仍正常落库 |
| 粗筛 anchor 未生成时规则不生效 | rule 保存时同步算 anchor；embed 失败→规则存但 enabled 强制 false + 提示 | embed 故障注入断言规则不生效且告警 |
| 精判 LLM JSON 不规范 | applyClean 兜底 + schema 校验 + 1 次重试，仍败=不收录 | mock 脏 JSON 断言降级 |
| turns 删列后老代码编译炸 | 分三迁移：V65 建新表 → 代码双读写切换 → V67 才删列 | 每个迁移后全量编译 |
| 规则 anchor 阈值太松误收 | 粗筛阈值独立 KV（默认严于标签归一的 0.25，建议 0.35 起步） | 无关对话断言零候选 |
