## 用户地图

| 谁 | 场景 | 效益 |
|---|---|---|
| 所有用户 | 日常聊天 | 全程自动留痕（流水账），下次相关提问 AI 自动召回，无需重复自我介绍 |
| 所有用户 | 上传文件提问 | 文件蒸馏成记忆，后续相关问答附带文件卡片 |
| 所有用户 | 隐私自控 | 流水账恒个人域仅本人可见；raw 可批量删；gen 可关（关=仅留 raw 不提炼） |
| 项目 owner | 沉淀团队知识 | 配收录规则（主题锚词+文件名硬规则），项目对话自动蒸馏成条目，审核后成员共享 |
| 项目 owner | 跨团队共享 | 授权链（项目↔项目）/ 只读授权（项目↔个人）/ 公共池，审批制、可撤销 |
| 成员 | 离职交接 | 条目属项目资产留项目；离职即失读权，原文永不出个人域 |

## 功能清单（当前态）

1. **流水账**：一轮 INPUT/OUTPUT 各一条；L0 标签/L1 概要/L2 详述三层；被收录轮 INPUT+OUTPUT 都显「收录于：项目X」（V100 建链+V125 存量回填）。
2. **召回**：scope 多选（个人+项目，持久化）+方向+时间窗；pipeline 七步+①.5 项目条目合流；文件记忆第三路 UNION。
3. **标签库**：写时归一四路径+主动建标签；禁手动并拆（防误并不可逆）。
4. **总结**：立即/重新/自动总结，方向（INPUT/OUTPUT/BOTH）个人+项目双通道；项目总结按条目方向过滤取数（V126）；条目级 coverage 幂等。
5. **冲突裁决**：时序互斥 pending，四选项，DISCARD 级联+12h 规则。
6. **收录管线**：规则粗筛→LLM 精判（零护栏+三档分流+黑名单）→蒸馏→owner 审核；**文件名硬规则用户级唯一**（撞重 409）+**路由多命中先建规则赢**（第三轮 #8）。
7. **收录确认式回复**：附件命中硬规则→秒回模板确认+「需要回答/不用了」点选，确认后才全量回答（V127 开关热关）。
8. **授权**：项目↔项目链（非对称撤销）、项目↔个人只读 grant、公共池；删除项目双向清链。
9. **gen 矩阵**：owner 项目级 AND 会员覆写；关=仅 raw。

## 技术说明（一段）

Spring Boot `chat` 包内实现（无独立 sidecar）。写入 fire-and-forget 走 `memoryTaskExecutor`；召回 `MemoryRecallPipeline` 串编+逐步降级（目标 <2s）；确认式回复前置确定性快检（规则 TTL 15s 缓存，异常 fail-open）；表 15+ 张走 Flyway V47–V127（二期 V71 起撞号改号）；LLM 兜底 model 走 `memory.judge.model`（请求域透传对话 model 优先）。
