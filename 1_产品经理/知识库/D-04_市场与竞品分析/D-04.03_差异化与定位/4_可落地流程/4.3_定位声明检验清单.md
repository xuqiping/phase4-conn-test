# 定位声明检验清单

## 概述

一份好的定位声明需要同时满足"外部一致性"（用户能理解）和"内部一致性"（组织能执行）。本清单提供11项逐条检验，确保定位声明不是口号而是可落地的战略指令。

[来源:定位理论+Play Bigger品类设计+品牌金字塔实践 | 置信度:📚中]

---

## 前置条件：定位声明已按标准公式填写

```
对于 [目标用户群体]，
他们 [核心需求/痛点]，
我们的 [产品名] 是一个 [品类名]，
它 [核心差异化价值]，
不同于 [主要竞品] 的 [竞品特征]，
我们 [独特优势]。
```

如未填写，先完成后再进入以下检验。

---

## 一、外部一致性检验（用户端）

### 检验1：可识别性 — "用户知道你在说什么吗？"

| 检验项 | 通过标准 | 实际情况 | ✅/❌ |
|---|---|---|---|
| 品类名是否用户可理解？ | 非行业人士听1遍能复述 | | |
| 核心差异化是否用用户语言？ | 不含行业术语黑话 | | |
| 目标用户是否可自识别？ | 用户听后能判断"这是给我用的" | | |

**快速测试**：把定位声明读给5位非业内人士听，3位以上能复述核心信息→通过。

### 检验2：真实性 — "你说的是真的吗？"

| 检验项 | 通过标准 | 实际情况 | ✅/❌ |
|---|---|---|---|
| 核心差异化价值是否有数据/证据支撑？ | 至少1个可量化证据 | | |
| 独特优势是否被现有用户验证？ | 至少5个用户证言或案例 | | |
| 竞品对比是否客观？ | 不含贬低性措辞，对比维度可验证 | | |

### 检验3：排他性 — "别人能说同样的话吗？"

| 检验项 | 通过标准 | 实际情况 | ✅/❌ |
|---|---|---|---|
| 竞品能否替换产品名后同样成立？ | 替换后至少1处逻辑矛盾 | | |
| 差异化是否依赖可复制资源？ | 不可复制的至少占1项 | | |
| 品类名是否独占？ | 是品类开创者或该品类有强关联 | | |

### 检验4：渴求性 — "用户在乎吗？"

| 检验项 | 通过标准 | 实际情况 | ✅/❌ |
|---|---|---|---|
| 核心需求是否为前3痛点？ | 用户调研中排名前三 | | |
| 差异化价值是否解决真实痛点？ | 不是"更好"而是"不同"的解决方式 | | |
| 目标用户群是否足够大？ | TAM估算>合理下限 | | |

---

## 二、内部一致性检验（组织端）

### 检验5：产品可交付 — "我们真的能做出来吗？"

| 检验项 | 通过标准 | 实际情况 | ✅/❌ |
|---|---|---|---|
| 核心差异化功能是否在6个月路线图中？ | 有明确的里程碑 | | |
| 技术栈是否能支撑？ | 无关键技术瓶颈 | | |
| 凹陷项（有意不做的）是否得到团队共识？ | 团队签字认可不做 | | |

### 检验6：营销可传播 — "能讲出一个好故事吗？"

| 检验项 | 通过标准 | 实际情况 | ✅/❌ |
|---|---|---|---|
| 定位声明能否转化为1句广告语？ | 广告语<15字且不含"更" | | |
| 是否有可视觉化的核心概念？ | 能画1张图表达 | | |
| 传播素材是否自然围绕差异化展开？ | 不需要额外"编故事" | | |

### 检验7：销售可转化 — "销售能拿这个卖吗？"

| 检验项 | 通过标准 | 实际情况 | ✅/❌ |
|---|---|---|---|
| 目标客户画像是否足够明确？ | 销售可直接筛选线索 | | |
| 竞品对比话术是否可用？ | 有1页纸竞品对照卡 | | |
| 定价是否与差异化定位匹配？ | 高端定位↔溢价/性价比定位↔低价 | | |

### 检验8：组织可承诺 — "全公司能朝这方向走吗？"

| 检验项 | 通过标准 | 实际情况 | ✅/❌ |
|---|---|---|---|
| CEO/创始人是定位的第一代言人？ | CEO能用1句话说清定位 | | |
| 各部门OKR是否与定位对齐？ | 产品/营销/销售OKR反映定位 | | |
| 定位是否写入了公司级文档？ | 在品牌手册或战略文档中有记录 | | |

## 三、可持续性检验（时间端）

### 检验9：护城河验证 — "能守多久？"

| 护城河类型 | 是否具备 | 竞品复制难度(1-5) | 说明 |
|---|---|---|---|
| 网络效应 | □是 □否 | | |
| 转换成本 | □是 □否 | | |
| 成本优势 | □是 □否 | | |
| 品牌无形资产 | □是 □否 | | |

**通过标准**：至少1项"是"+复制难度≥4

### 检验10：趋势适应性 — "方向会不会变？"

| 检验项 | 通过标准 | 实际情况 | ✅/❌ |
|---|---|---|---|
| 定位是否依赖正在消退的趋势？ | 不依赖即将过时的用户行为 | | |
| AI/自动化是否可能取代差异化？ | 核心差异化不因AI同质化而消失 | | |
| 品类定义是否足够稳定？ | 3年内品类含义不会剧变 | | |

### 检验11：迭代预留 — "能进化吗？"

| 检验项 | 通过标准 | 实际情况 | ✅/❌ |
|---|---|---|---|
| 定位声明是否预留了扩展空间？ | 品类边界可自然延伸 | | |
| 是否有明确的定位刷新触发条件？ | 定义了"何时需要重新定位" | | |
| 护城河构建是否有路线图？ | 6-12月护城河加强计划 | | |
