## ✅ Step8 云端总结 map-reduce（`d14781e`，FR-107/109）

**前置闸门**：AGENTS.md「例外·网课总结功能」红线增补 2026-08-05 已 review；API 凭据 2026-08-07 用户提供 → 闸门解锁。

**API 凭据**（用户自带）：Base URL `https://api.kimi.com/coding/`，模型 `k3-256k`；Key 用户自己在 App 里填。

**后端 `summary/` 模块**
- `mod.rs`：SummaryConfig（默认 Kimi 端点/模型，非密）存 `%APPDATA%/<app>/summary_config.json`；**API Key 只走 keyring（Windows 凭据管理器）**，`has_summary_api_key` 永不回显本体；`summary_draft.json` = 当前草稿 + 历史版本（cap 20，可撤销）。
- `cloud_api.rs`：OpenAI 兼容 `/v1/chat/completions`，reqwest **blocking + rustls**（不引 tokio，spawn_blocking 调用，与 process_ocr 同模式）；429/5xx 退避重试×2、4xx 不重试；`sanitize` 强制抹 Key；content String/分块数组双兼容；base_url 尾斜杠归一。
- `prompt.rs`：分段 prompt（段区间约束 ts_ms 必落区间——防长文本中段迷失）+ 合并 prompt（时间去重）；`extract_json_object` 花括号配对提取，容忍 markdown 围栏。
- `map_reduce.rs`：≤2000 字切段（单页超限独占一段并截断）；**map 串行 + 300ms 礼貌间隔**（最保守限流姿态，concurrency 字段预留）；解析失败重试 1 次 → 本地抽取兜底（local_fallback）；LLM 失败整段兜底、reduce 失败 outline 空不阻塞（可降级）；要点带 ts_ms + frame_ref 回链（可解释）；`regenerate` 单段/全局（可纠错）；多模态精修 vlm_on 默认关，开启才附帧图（≤3 张/段，≤1024px JPEG q80 base64）。

**lib.rs 命令**：`get/set_summary_config`、`set/has/clear_summary_api_key`、`test_summary_connection`、`summarize(session_id, vlm_on)`、`regenerate_summary(session_id, segment_id?, vlm_on)`。

**前端 `SummarySettings.vue`**（挂网课总结 Tab）：Base URL/文本模型/视觉模型输入 + Key 密码框（保存即清空不回显）+ 保存/清除/测试连接；Recorder.vue 布局微调（字幕区固定 260px，页面改纵向滚动）。

**测试**：58 单测绿（新增 15：URL 拼接/脱敏/content 解析/配置容错/草稿历史 cap/切段预算/超限截断/兜底抽取/ts 截断+帧回链/JSON 提取/prompt 内容）；vue-tsc 零错误；check_all 全绿。

**坑**：本轮 cargo 拉新依赖时 USTC 镜像走了代理（HTTPS_PROXY 残留在环境）→ `via 127.0.0.1` 连接失败；NO_PROXY 必须带 USTC 三主机（memory 已记，上次也踩过同类）。
