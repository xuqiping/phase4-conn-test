# Office 效率增强开发进度 12

> 记录日期：2026-08-26。范围是统一安全底座 Chunk 5：输出事务与恢复。自动化测试与故障注入按用户要求留到 Phase 4。

## 1. 输出事务

- `output.rs`：创建输出目录内的独立任务临时目录，确保临时文件和最终文件位于同一文件系统；预计输出与临时空间按 1.5 倍预算检查。
- 输出 ID、最终文件名和 Windows 保留名受限；临时根若是符号链接或越界目录则拒绝。
- 发布前重新打开文件，校验非空、扩展对应 OOXML/OLE/PDF/CSV 基础签名，并调用具体功能提供的业务不变量校验器。
- 发布前后分别计算 SHA-256；使用硬链接 create-if-absent 语义原子创建最终文件，目标同名时不覆盖，任何后续复核失败都移除本次创建的最终链接。
- 单输出只允许 expected=1；多输出逐项记成功/失败，只有全部输出均已计入后才能完成事务。

## 2. 发布凭证与状态机

- `PublicationReceipt` 只能由完成的 `OutputTransaction` 构造，不支持反序列化、复制或公开字段构造。
- 凭证绑定 taskId 并被状态机按值消费，普通调用方不能再直接提交 `OutputSummary` 把任务标为成功。
- taskId 不匹配返回 `OFFICE_PUBLICATION_RECEIPT_TASK_MISMATCH`；单输出和多输出状态推导继续复用原有严格计数规则。

## 3. 恢复与替换原件

- `recovery.rs`：枚举任务临时目录，失败/取消产物默认保留 7 天，清理前重新约束目录根且不跟随符号链接。
- 替换原件必须显式确认，只接受已发布且校验和一致的 `PublishedOutput`。
- 源文件在复制替换件前、交换前各核对一次大小、修改时间和 SHA-256；读取期间变化也会阻止。
- 替换件先复制到源文件同目录并落盘，原文件先移动到本地备份目录；交换或交换后哈希复核失败时恢复备份。
- 路径只通过访问器提供给后续本地命令，所有 `Debug/Display` 均隐藏真实路径。
