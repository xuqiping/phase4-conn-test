# 资产库公共选择与评分等级 · 测试方案

> Phase 3 预处理产物。对应问题 2x#4（选择器无公共池）/#5（分享搜索空关键词不展示）/#7（评分改等级制）+ 待决策项（公共池复制管控，OWNER 自选）。
> 计划：[plan](../plans/资产库公共选择与评分等级.plan.md) · 规格：[spec](../specs/资产库公共选择与评分等级设计.md)
> 自动化（后端单测+前端单测+可脚本化 playwright）之外需人工确认项，标注【人工】。

## 前置数据

| 角色/数据 | 准备 |
|---|---|
| 账号 A（发布者） | OWNER 项目 P1：publicPool=true、allowPublicCopy=true，含图片资产≥2、视频资产≥1，owner 评分 96（A+）；项目 P2：publicPool=true、allowPublicCopy=false，含图片≥1；项目 P3：APPROVAL_REQUIRED 未给 A 审批（usable=false） |
| 账号 B（公共用户） | 无任何项目关系（纯 VIEWER 视角） |
| 账号 C/D（成员） | P1 成员，各打分 90、89（均分 89.5→取整 90→A 边界样本） |
| 用户池 | ACTIVE 用户 ≥3 个可作分享候选；含 1 个已禁用 |

## 一、公共池选择（P，2x#4）

| # | 步骤 | 预期 |
|---|---|---|
| P1 | 图片页「+从资产库选取」→ 项目下拉 | 出现「公共池」分组，含 P1/P2，**不含** P3（usable=false 不展示）【人工】 |
| P2 | 选 P1 → 类型切「图片」 | 列表只出图片资产（mediaTypes/类型过滤生效） |
| P3 | 选中 P1 一张图 → 确认 | resolve 成功，参考图 chip 出现在表单；提交生成不报权错 |
| P4 | 视频页首帧/参考图选取 → 选公共池视频 | 同 P3，视频资产可入表单 |
| P5 | 画布侧 AssetPicker 同操作 | 与 AssetFilePicker 行为一致（两组件分别改，口径相同）【人工】 |
| P6 | 反向：P1 被 OWNER 移出公共池后（另一会话操作），B 会话内再选 | 载列表报错 → 有兜底提示（非白屏/静默失败） |

## 二、分享搜索默认展示（S，2x#5）

| # | 步骤 | 预期 |
|---|---|---|
| S1 | A 打开 P1 分享弹窗 | **不输入任何词**即展示候选 ≤50 人（开箱即载）【人工】 |
| S2 | 输入「C」再清空 | 恢复全量候选而非空白列表 |
| S3 | 检查候选内容 | 不含 OWNER（A）、现有成员（C/D）、操作人自己；不含禁用用户 |
| S4 | 候选>50 时 | 有提示文案「输入用户名筛选，最多展示 50 人」 |

## 三、评分等级（G，2x#7）

| # | 步骤 | 预期 |
|---|---|---|
| G1 | 看 P1 资产卡片/详情 | 数值旁徽章：owner 96→★A+；成员均分 89.5→取整 90→A（展示口径「取整」可考） |
| G2 | 打分滑杆拖到 94→95→89→90 | 实时等级 A→A+→B→A 跨档即变（94/95 边界来回拖）【人工】 |
| G3 | 未评资产 | 无等级徽章（空态不显示「D」） |
| G4 | 筛选条选等级 A+ | 等价分数区间 [95,100]；与手动输入 95-100 结果一致 |
| G5 | 等级与手动区间冲突 | 等级覆盖手动区间；清除等级后手动区间保留与否按拍板（等级是快捷方式，清除不清手动）【人工】 |

## 四、复制管控（C，待决策项）

| # | 步骤 | 预期 |
|---|---|---|
| C1 | A 重新发布 P2（allowPublicCopy=false） | 开关回显「关」；可改开 |
| C2 | B 浏览 P2 公共池项目页 | **无**「复制到我的项目」按钮（不渲染，非置灰）【人工】 |
| C3 | B 直调 `POST /assets/assets/{id}/copy`（P2 资产，需接口工具） | 403 ASSET_COPY_FORBIDDEN，文案不泄漏源项目信息 |
| C4 | B 浏览 P1（allow=true） | 复制按钮在，复制成功且副本为 B 的 PERSONAL、与源解耦 |
| C5 | P1 项目内成员复制（成员路径） | 不受开关限制（开关只管公共 VIEWER） |
| C6 | admin 代发布 | 同样可设开关；admin 代发的项目按开关管控 |

## 五、功能联动用例（L1-L6，对齐 plan 联动清单）

| # | 触发 | 正向 | 反向/边界 |
|---|---|---|---|
| L1 | 选择器选公共池项目 | 载入该项目资产+类型过滤联动 | 切回「我的项目」列表正确切换；项目被移出公共池→兜底提示（=P6） |
| L2 | 发布关「允许复制」 | 公共 VIEWER 按钮隐藏（重拉摘要后） | 已开着项目页的用户刷新后按钮消失；直调 API 仍 403（=C2/C3） |
| L3 | 打分拖动 | 等级实时标签跨档即变 | 94↔95 来回拖；未评→首评出现等级（=G2） |
| L4 | 等级筛选选中 | scoreMin/scoreMax 联动填入 | 与手动区间冲突以等级覆盖；清除等级不清手动区间（=G5） |
| L5 | 分享弹窗打开 | 空关键词即出 ≤50 人 | 输入后清空→恢复全量；已选成员不重复出现（=S2/S3） |
| L6 | 成员改分 | 均分等级徽章重算 | 两成员 90+89→均分 89.5→取整 90→A（非 B），跨档取整正确 |

## 六、回归红线

- 「我的项目/共享给我」选择与 resolve 原路径不回归；评分存分与双轨算法不变（只加展示层）；非公共项目 copy 不受新校验影响；发布/取消发布既有流程与审计不变；既有分页/类型过滤行为不变。

## 术语表

| 术语 | 大白话 | 案例 |
|---|---|---|
| usable | 接口算出的「当前用户能不能用」 | 需审批未获批→false，选择器不展示 |
| 派生等级 | 不存库现场算 | 88 分→B，库里只有 88 |
| 快捷筛选 | 选等级自动换算分数区间 | 选 A+ = 95~100 |
| 回显 | 重开表单显示上次存的值 | 再发布时开关显示上次选择 |
