### 坑沉淀

- **桩的时序语义**：ServiceTest 透传桩必须 thenAnswer（运行时委托）不能 thenReturn（settle 期定值）——否则 per-test 对 queryPlanner.plan 的覆写被吞。
- **测试数据自证**：断言「>20 字子意图被丢」的用例，字符串先数字符数——首版 17 字 ≤20 没被丢，断言会假红。
- **orTimeout 孤儿线程**：超时后 supplyAsync 线程仍睡在 gateway 桩里——commonPool daemon 线程不阻 JVM 退出，但真实代码 gateway 有 provider 侧 timeoutMs 中止，双保险闭环。
