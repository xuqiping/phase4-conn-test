# D-18.02 定价方法

## 是什么

**定价方法（Pricing Methodology）**：决定产品价格"凭什么定这个价"的方法论体系——回答"用什么逻辑锚定价格"。它是商业化与定价策略（D-18）的方法论层，连接商业模式（D-18.01，怎么收钱）和价格策略（D-18.03，怎么包装卖）。本叶子聚焦三大主流定价方法——成本定价、价值定价、竞争定价，以及衍生的动态定价、心理定价、用量定价等方法，并提供定价测算工具（Van Westendorp PSM价格敏感度测试、Conjoint联合分析、价格弹性测算）与定价博弈话术（N.04）。定价方法的核心命题是"价格锚定在什么基础上"——锚在成本上收不到价值、锚在竞品上失去主动权、锚在价值上才是定价的最高境界。 [来源:定价方法论/Stripe定价指南 | 置信度:📚中]

**三大主流定价方法**：
- **成本定价（Cost-based）**：以成本+加成为定价基础，逻辑简单但把价格锚定在成本而非客户价值，被批"最危险的定价方式"
- **价值定价（Value-based）**：以客户感知价值为定价基础，定价锚定在"客户获得的价值"上，是SaaS/数字化产品的主流方向
- **竞争定价（Competition-based）**：以竞品价格为锚定，跟随或差异化定价，逻辑直接但失去定价主动权

[来源:新浪/Stripe定价策略指南 | 🔍高 | 2026]

## 核心要素

| 要素 | 说明 | 示例 |
|---|---|---|
| **价格锚定原理** | 价格定在什么基础上——成本/竞品/客户价值，决定定价主动权和天花板 | 成本锚定→收不到价值；价值锚定→获最大利润 |
| **三大定价方法** | 成本/价值/竞争三条主线，各有适用场景与缺陷 | 价值定价是SaaS主流；成本定价适合 commodities；竞争定价适合同质化市场 |
| **价值量化方法** | 如何把"客户感知价值"量化成价格——ROI测算/TCO对标/愿付价测试 | Van Westendorp PSM四问、Conjoint联合分析、ROI=省了多少/赚了多少 |
| **价格敏感度测试PSM** | Van Westendorp 1976提出的四问(太便宜/便宜/贵/太贵)推导可接受区间与最优价 | 新产品定价、无竞品场景的标准化价格测试 |
| **定价心理学** | 锚定效应/损失厌恶/价格敏感度/诱饵效应等心理定价原理 | 三档定价中间最畅销(诱饵)、年付比月付划算(锚定) |
| **价格弹性** | 价格变化对需求量的敏感度——弹性大降价增收、弹性小涨价增收 | 必需品弹性小可涨价；可选弹性大需谨慎 |
| **定价博弈话术N.04** | 定价谈判中的话术与逼单博弈——价值证明/锚定/让步/紧迫 | "年付省20%"锚定、"本月特惠"紧迫 |
| **差异化与定价耦合** | 定价与差异化定位（D-04.03）强耦合——差异化是价值定价的前提 | 无差异化只能成本/竞争定价；有差异化才能价值定价 |

## 为什么产品经理必须懂定价方法

1. **定价是企业最被低估的增长杠杆**——Patrick Campbell/ProfitWell研究显示定价是PM最易忽视但ROI最高的杠杆，价格提升1%对利润的杠杆远超获客1%。PM懂定价才能把产品价值转化为收入 [来源:ProfitWell定价研究 | 📚中]
2. **成本加成是最危险的定价方式**——成本加成法把价格锚定在成本而非客户价值，有三大致命缺陷：①收不到真正的价值；②惩罚效率(越熟练越快反而收不到高价值)；③与产品差异化脱钩。一人企业/独立开发者最易踩此坑 [来源:网易/一人企业定价 | 📚中 | 2026]
3. **价值定价是SaaS/数字化产品的活路**——2025-2026 SaaS增速放缓，客户不再为功能买单而为"省了多少/增了多少"付费，价值定价是唯一让客户愿付高价的逻辑 [来源:雪球/IDC | 🔍高 | 2025]
4. **AI产品重新激活成本定价讨论**——AI产品推理成本可观，按Token用量计费本质是"成本加成+用量透明"，与价值定价形成张力。AI产品定价需在成本覆盖与价值锚定间平衡 [来源:知乎/AI PM商业化 | 🔍高 | 2026]
5. **定价方法决定定价博弈能力**——选错方法(纯成本/纯竞争)在B端谈判中无价值支撑易被压价；价值定价提供ROI/TCO的价值证明，是B端定价博弈话术(N.04)的弹药库

## 常见误区

- **误区1：定价=成本+利润率**——成本加成是最省事也最危险的定价，让你永远收不到客户真正愿付的价值。除非是commodities/无差异化产品，否则应避免纯成本定价
- **误区2：定价=对标竞品**——竞品定价是参考不是锚定。竞品的价格反映其成本结构与客户价值，你未必有同样前提；纯竞争定价让你失去定价主动权，陷入价格战
- **误区3：价值定价=拍脑袋报高价**——价值定价需要量化客户价值(ROI/TCO/愿付价测试)，不是凭感觉报高价。无价值证明的"价值定价"在B端谈判中站不住
- **误区4：定价是财务/销售的事**——PM最懂产品价值与差异化，定价的价值锚定PM必须参与。定价脱离PM会导致价格与产品价值脱节
- **误区5：一次定价终身不变**——定价需随产品演进/客户分层/竞争格局动态调整。一次性定价会错过价值增长的红利
- **误区6：降价=增长**——降价提升量但不一定提升收入(取决于弹性)，更会损害品牌定位。盲目降价是最常见的定价错误
