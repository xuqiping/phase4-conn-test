### Task 6-3：系统设置页

**Priority:** 可选。

**Current fact:** 服务端目前没有独立 `AdminSettingsController`，只有用户级 `PUT /api/admin/users/{id}/settings`。

**Adjusted decision:** 不把 `SettingsView.vue` 作为当前阶段四缺口。只有当要支持全局默认设备数、默认离线缓存时长、匿名试用天数、免费模块更换间隔后台配置时，再新增服务端 API 和前端页面。

### Task 6-4：匿名设备运营页

**Priority:** 可选。

**Current fact:** 服务端目前有匿名试用用户端 API，没有管理端匿名设备列表、重置试用、禁用匿名设备 API。

**Adjusted decision:** 不把 `AnonymousDevicesView.vue` 作为当前必须补齐项。若后续需要客服处理匿名试用滥用，再新增：

- Admin anonymous device repository/service/controller。
- `GET /api/admin/anonymous-devices`
- `GET /api/admin/anonymous-devices/{deviceId}`
- `POST /api/admin/anonymous-devices/{deviceId}/disable`
- `POST /api/admin/anonymous-devices/{deviceId}/reset-trial`
- `file-keeper/admin-web/src/views/AnonymousDevicesView.vue`
