## 本轮 2：WP6 Step2 SPI 与三连接器（后端全量 2894/2894，commit 见 git log）

- **SPI 简化**：`KnowledgeConnectorSpi`（type/list/fetch/close+`ExternalDoc(externalId,etag,displayName)` record）——list() 返**全量条目**非 cursor 流（增量差分交 Step3 worker 对账本；URL 站点/PROPFIND 本无游标语义，S3 continuation 只是分页细节）。
- **SafeHttpFetch**（URL_SITE/WebDAV 共用底层）：`followRedirects(NEVER)` 手动跟 ≤3 跳且**每跳 Location 重过 urlGuard**（自动跟随=校验过首跳 302 直进内网——坑点表头号变体，测试 mock 302→169.254.169.254 锁死）；非 2xx 异常只带状态号不带响应体（防内网信息回显）。
- **三连接器**：`UrlSiteConnector`（BFS 同域 scheme+authority 全等、深度 ≤2 但**到顶页仍提链接为条目**只不下钻、成环去重、≤50 页、白名单七后缀、etag=ETag 或 `LM:`Last-Modified）；`WebDavConnector`（PROPFIND Depth:1 逐目录递归 ≤5/≤500 条、Basic 认证、**jsoup xmlParser+按本地名递归**——CSS select 不匹配 `d:response` 命名空间前缀标签，getetag 嵌 propstat/prop 三层须无条件递归）；`S3Connector`（**AWS SDK v2 2.54.11**+url-connection 传输 pom 排除 apache/netty 控树；**必须显式 `.httpClient(UrlConnectionHttpClient.create())`** 否则 service-load 到残缺 apache5 报 NoClassDefFoundError；endpointOverride+forcePathStyle 兼容 MinIO/OSS/COS；分页闸 50 页）。
- **FetchLimiter**：1 req/s+200MB 总字节闸，同步阻塞式（worker 单线程顺序拉取）。SsrfGuard 生产装配留 Step3 工厂（urlGuard 策略注入：测试 mock 源站绑 127.0.0.1 须放行 guard 才能测爬取；SSRF 语义另用真 SsrfGuard 直测五渗透字面量）。
- 测试 +9（计划 ×3）：SafeHttpFetch 2（五渗透字面量/302 跳内网）+UrlSite 3（成环去重+白名单+深度语义/页数闸/fetch 字节）+WebDav 2（递归+etag/Basic 下载）+S3 2（**AWS SDK 只发不验响应签名→HttpServer 应答裸 XML 即可 mock**：prefix 过滤+etag 透传+目录占位跳过/下载）。真实 S3 桶/WebDAV 源验证留 Phase4 手测。
- 坑：SsrfGuard.validate 返 void 不能方法引用作 Predicate 须包 lambda；jsoup HTML 解析器小写化/重排树必须 xmlParser。
