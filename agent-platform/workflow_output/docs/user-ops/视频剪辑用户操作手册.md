# 视频剪辑 · 用户操作手册

> 面向持有 `media:edit` 权限的用户。入口：侧边栏「视频剪辑」菜单（`/video-edit`，无权限不显示，联系 admin 授权）。

## 前置条件

- 账号已被授予 `media:edit` 权限（默认仅 admin 有；普通用户须 admin 在「角色权限」页授予）。
- 系统已装好 ffmpeg ≥4.4（Windows 上通常需运维额外指 modern ffmpeg 路径，见 `快速启动速查表.md → 视频剪辑`）。
- 字幕渲染需要 CJK 字体（Windows 默认探测 `simhei.ttf`，无字体且有字幕时会失败）。

---

## 功能一：提交一段视频渲染

**操作步骤**：

| 步骤 | 用户操作 | 界面变化 | 预期结果 |
|---|---|---|---|
| 1 | 点侧边栏「视频剪辑」进入页面 | 左侧「剪辑台」、右侧「当前任务/历史任务」 | 进入剪辑页 |
| 2 | 点「上传视频片段」选本地视频文件 | 上传完成后，素材自动加入「视频轨」末尾 | 视频轨出现一段素材 |
| 3 | 点「添加字幕」按钮 | 字幕轨新增一条空字幕段，并自动选中 | 字幕轨出现「字幕」块 |
| 4 | 在属性面板「字幕」输入框里填文字，选位置（底部/居中）、调字号 | 字幕块实时显示文本；字号为空则后端按画面高度默认 | 字幕内容生效 |
| 5 | 在时间线或属性面板调整各段起止时间 | 段块长度/位置变化；属性面板数值同步 | 时间线符合预期 |
| 6 | 「输出」区选分辨率（480p/720p/1080p）和 fps（默认 24） | 下拉值更新 | 输出规格确定 |
| 7 | 点「提交渲染」 | 右侧「当前任务」出现「排队中」→「渲染中」 | 任务提交成功 |
| 8 | 等待后端 FFmpeg 渲染 | 状态变「已完成」，出现 `<video>` 播放器和「下载成片」按钮 | 成片可播放/下载 |

**完成标志**：「当前任务」状态为「已完成」，可直接播放并下载 mp4。

**预期耗时**：短视频（几十秒）通常数秒到 1 分钟；长视频或多音轨混音会更久，超配置超时时间自动判失败。

## 功能二：多轨混剪（多视频段 + 多音轨 + 字幕）

**说明**：视频轨只有 1 条；音轨最多 4 条；字幕轨 1 条。

**操作步骤**：
1. 按功能一上传/添加多个视频段到「视频轨」，调整每段在时间轴上的前后位置和起止时间；段之间留空会自动补黑帧。
2. 点「上传音频」选本地音频文件 → 自动加入最后一条音轨；没有音轨会自动新建一条。
3. 重复上传音频可在同一条音轨内前后排列，或点时间线「添加音轨」新建音轨（最多 4 条）。
4. 在属性面板调整音频段音量（0~1）。
5. 添加字幕并调整出现时间和位置。
6. 点「提交渲染」。

**完成标志**：同功能一。

## 功能三：导出剪映草稿

**说明**：不渲染，直接把当前剪辑意图生成剪映（CapCut）可导入的 `draft_content.json + draft_meta_info.json + 素材 zip`。

**操作步骤**：
1. 在时间线排好视频段/音频/字幕。
2. 点「导出剪映草稿」。
3. 浏览器下载 zip。
4. 解压后把素材目录拖入剪映。

**完成标志**：浏览器下载 `futurex-draft-YYYY-MM-DD.zip`。

---

## 功能四：查看历史任务与回看

- 右侧「历史任务」表格列出自己（admin 看全量）的任务：ID / 片段数 / 状态 / 创建时间。
- 当前提交的任务同时出现在「当前任务」中自动轮询。
- 已完成的任务可在「当前任务」直接播放/下载；也可从历史任务刷新后查看（当前列表只加载最近 50 条）。

## 常见异常与恢复

| 现象 | 原因 | 恢复 |
|---|---|---|
| 看不到「视频剪辑」菜单 | 无 `media:edit` 权限 | 联系 admin 在「角色权限」页授权 |
| 直接访问 `/video-edit` 显示「无 media:edit 权限」 | 同上 | 同上 |
| 「提交渲染」按钮灰显 | 视频轨为空 | 至少上传/添加一个视频段 |
| 提交后状态「失败」，错误含 `adelay` / `all=` | 系统 ffmpeg 版本过低（如 ImageMagick 自带 4.2.3） | 联系运维升级 ffmpeg 或设 `MEDIA_EDIT_FFMPEG_PATH` 指现代版（≥4.4） |
| 提交后状态「失败」，错误含 `No option name near '/Windows/...'` | Windows 盘符冒号破坏 filter_complex（如回退到旧版代码） | 用当前已修复版本；勿把 fontfile/textfile 改成绝对路径 |
| 状态「失败」且含「字幕渲染失败：未配字体」 | 系统无可用 CJK 字体 | 联系运维配置 `MEDIA_EDIT_FONT_FILE` 为 ttf/otf 字体 |
| 状态「失败」且含「素材未 copy 到 temp」 | 引用的 fileId 无效或已被删 | 重新上传素材并加入时间线 |
| 状态「失败」含 `ffmpeg` 日志尾 | 滤镜参数或素材格式不兼容 | 简化时间线（先去音轨/字幕/多段）重试；持续失败联系开发 |
| 状态「下载失败」 | 成片生成成功但写入存储失败 | 后端管理员手动重试或重新提交 |
| 成片播放只有画面没有声音 | 原视频无音频轨且未加音频 | 属正常；加音轨即可 |
| 轮询卡住不更新 | 前端网络断开 | 刷新页面，任务仍在历史列表 |

## 边界场景

- [ ] 在渲染过程中刷新页面，是否能在「历史任务」恢复查看？
- [ ] 视频段 targetEnd 早于 targetStart 时后端会校验失败。
- [ ] 连续快速点「提交渲染」会提交多个任务（当前无防抖）。
- [ ] 上传非 video/audio MIME 文件会被后端校验拒绝。

---

## 移动端

- ≤768px 自动单列堆叠（剪辑台在上，结果/历史在下），操作流程同桌面端。
- 上传文件仍调用系统文件选择器；长段时间线可能需横向滚动。
