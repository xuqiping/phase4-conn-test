# B端PRD检查清单

## 六层复杂度逐项检查

### 第1层：角色权限

- [ ] 是否列出所有角色（系统管理员/业务管理员/普通用户/只读用户/外部用户等）
- [ ] 是否有角色×操作权限矩阵（CRUD：创建/读取/更新/删除）
- [ ] 是否有字段级权限（如：销售看金额，普通员工看不到）
- [ ] 是否有数据行级权限（如：只看自己部门的数据）
- [ ] 是否考虑了越权场景的处理

### 第2层：组织架构

- [ ] 是否支持多级组织树（集团→公司→事业部→部门→团队）
- [ ] 是否定义了组织间数据隔离策略（完全隔离/向下可见/交叉授权）
- [ ] 是否有跨组织协作的数据共享机制
- [ ] 是否支持组织变动（合并/拆分/人员调动）的数据迁移

### 第3层：审批流程

- [ ] 是否列出所有审批流（每流含：发起人/审批人/条件/超时/回退）
- [ ] 是否有审批节点条件判断（金额>X需总监审批）
- [ ] 是否有审批超时自动处理（自动通过/自动升级）
- [ ] 是否有审批回退机制（回退到哪一步/回退后修改规则）
- [ ] 是否有会签/或签/依次签场景

### 第4层：数据权限

- [ ] 是否有数据权限矩阵（角色×数据范围）
- [ ] 是否有数据脱敏规则（如：手机号中间4位*）
- [ ] 是否有数据导出权限控制
- [ ] 是否有审计日志（谁在什么时候查了什么数据）

### 第5层：集成对接

- [ ] 是否列出所有对接系统（ERP/CRM/OA/HR/Payment等）
- [ ] 每个接口是否含：方式/字段映射/同步策略（实时/定时）/异常处理
- [ ] 是否有数据一致性保障（对账/补偿机制）
- [ ] 是否有对接测试/沙箱环境说明

### 第6层：配置化

- [ ] 是否列出功能开关清单（含默认值/可配范围）
- [ ] 是否有客户差异化配置矩阵（租户级/实例级）
- [ ] 是否有配置变更的审批/回滚机制
- [ ] 是否考虑了配置冲突（开关A开时开关B不可用）
