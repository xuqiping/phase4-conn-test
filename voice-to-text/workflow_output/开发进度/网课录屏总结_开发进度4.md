## ✅ Step9 多形态渲染 + Markdown 导出（`451d766`，FR-108）

**后端 `summary/render.rs`**（新）
- `Timeline`：章节 → 要点[ts_ms + ts_label] + frame_ref + local_fallback 打标，供 Study.vue；`version`/`model` 字段供 SummaryPanel 草稿态提示。

- `lib.rs` 命令：`get_timeline` / `export_markdown`（纯本地读写，无网络、无 spawn_blocking）。
- 测试：7 单测（时间格式化/章节映射/无草稿报错/大纲错位退化/MD 结构/fallback 标记/导出落盘）。

## ✅ Step11 Processing + Study + SummaryPanel（`a20d814`，FR-107/108/109）

**后端新增命令**（lib.rs）
- `get_video_slices` → `{ slice_ms, files[] }`（video/*.mp4 排序清单，供点播跳转）。
- `get_ocr_text(session_id, frame_ref)` → 按 frames.json 查 OCR 原文；frame_ref 路径穿越校验（拒 `..`/绝对路径）；找不到返回 None 不算错。
- `update_summary_point(session_id, segment_id, point_index, text)` → `summary::update_point_text` 原地改草稿文本，**不压历史版本**（撤销靠 regenerate 历史）；空文本/段不存在/越界均校验。
- `setup()` 动态 `asset_protocol_scope().allow_directory(sessions根目录, 递归)` + tauri.conf `assetProtocol.enable=true` —— 帧图/视频走 `asset://`（convertFileSrc），不走 base64 IPC，避开「帧走 IPC 撑爆 webview」坑。

**前端**
- `stores/session.ts`：处理编排 pipeline（抽帧→OCR→对齐→总结串行；**段间取消**——当前阶段后端跑完才停、结果保留；**断点续跑**——已完成阶段跳过不重跑，OCR 靠 already 幂等）+ 学习区状态（timeline/slices/sessionPath/vlmOn/lastExportPath）+ `regenerate`/`updatePoint`/`exportMarkdown`。
- `Processing.vue`：阶段列表（⏳/✓/✗）+ aria-current + 取消/继续/重试 + 放弃会话；phase=processing 时自动开跑。
- `Study.vue`：左章节时间轴（联动选中）+ 右视频切片点播 + **要点/帧点击跳回视频时刻**（ts → 切片序号 + 片内偏移，换片等 loadedmetadata 再 seek）+ 课件帧缩略图 + OCR 原文 `<details>` 懒加载核对 + MD 导出（导图/Anki 占位禁用）。
- `SummaryPanel.vue`：草稿徽标（版本+模型）+ 全量/单段重生成 + 当前章节要点行内编辑（textarea 保存）+ **多模态精修开关**（默认关，开启弹二次确认「将上传课件图到 {base_url}」）。
- `App.vue` 三区串联：Recorder →（processing）Processing →（done）Study + SummaryPanel；`selectedChapter` 由 App 持有供 Study/SummaryPanel 联动。
- `Recorder.vue`：processing banner 精简（进度由 Processing.vue 承担）。

**偏离 plan 处**（已回填 04 子 plan 备注）：① 流式打字机未做（summarize 整段返回，无逐段事件）；② 取消为段间协作取消（后端无强制中断）；③ 要点编辑挂 SummaryPanel 当前章节（避免双份列表）。

**测试**：66 单测绿（+8：render 7 + update_point_text 1）；vue-tsc 零错误；check_all 全绿。

**坑**：`app.asset_protocol_scope()` 需要 `use tauri::Manager` trait 在作用域（E0599，一次修掉）。
