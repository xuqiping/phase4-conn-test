# 行业生态分析

> **是什么**：行业生态分析是PM从"看对手"升级到"看整条食物链"的分析能力——不只是知道竞品在做什么，而是理解上游供应商、下游渠道、互补品、替代品、政策环境如何共同构成一个动态博弈的生态系统，以及自己在这个系统中的生态位。

> **为什么重要**：2025-2026年，单一产品的竞争让位于生态系统的竞争（AI+Agent生态、车+能源生态、SaaS+平台生态）。PM不看生态，就无法理解"为什么一个好产品会输给一个普通但生态强的产品"。

> **何时进入**：完成市场分析(D-04.01)和竞品分析(D-04.02)后，需要理解"为什么市场格局是这样"以及"未来格局会怎么变"时。

> **关键词**：产业地图 / 生态位 / 价值链分析 / 平台策略 / 互补品与替代品 / 生态飞轮 / 上下游博弈 / 政策法规环境
