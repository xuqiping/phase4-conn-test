# 用户操作手册 · 安全体系

> Phase 3 产物。安全加固大多是「看不见的护栏」，本手册只收**你作为用户/管理员可能真实撞到的行为变化**（2026-08 S1 上线后；S2 追加单点登录/低余额限行）。
> 关联 Feature Map：[../feature-map/安全体系.feature-map.md](../feature-map/安全体系.feature-map.md)
> 本功能 PRD 编号：SEC-FR-001/003/008/010/040~044/120~123/126

## 一句话描述
平台加了一层安全护栏：登录有防爆破锁定、危险文件传不上也打不开、积分充值不怕重复点——你基本无感，撞到规则时照本手册处理即可。

## 适用场景

- **谁用**：全体用户（登录锁定、文件上传）+ 管理员（充值防重、对账）
- **什么时候用**：登录提示被锁 / 上传文件被拒 / 担心充值重复到账
- **用完得到什么**：知道发生了什么、多久恢复、找谁处理

---

## 一、登录提示「登录失败次数过多」（普通用户）

**发生了什么**：你的账号连续输错密码 **5 次**，系统把它锁了 **15 分钟**——这是防别人暴力猜你密码的护栏，锁定期内**连正确密码也进不去**。

**怎么办**：
1. 等 15 分钟自动解锁，再用正确密码登录。
2. 着急用：联系管理员在 Redis 里删 `login:fail:u:你的用户名` 键立即解锁（运维手册有 runbook）。
3. 如果**不是你本人试的**：解锁后立刻改密码，并告知管理员查审计日志（每次锁定都有记录）。

**另一条规则**：同一个 IP 一小时失败超 20 次会被封 1 小时（公司共用出口网络时，别人试错可能误伤你，同样等自动解或找管理员）。

---

## 二、上传文件提示「文件类型不允许上传」（普通用户）

**发生了什么**：你传的文件扩展名在危险名单里（如 `.html`、`.svg`、`.exe`、`.js`）——这类文件能被用来在平台里塞恶意脚本，上传入口统一拒收（HTTP 400，错误码 40010）。

**怎么办**：
1. 文档/图片/音视频/pdf 都能正常传；被拦的基本是可执行或网页类文件。
2. 确需传代码/网页：打包成 `.zip` 再传（zip 不在危险名单）。
3. 既有老的 html/svg 文件**还能下载**，但只会强制下载到本地、不会在浏览器里直接打开——这是故意的，不是坏了。

## 五、提示「账号已在别处登录」（普通用户，S2 新增）

**发生了什么**：你的账号在另一台设备/浏览器**新登录了一次**，系统实行单点登录——同账号只允许一处在线，新登录会把旧会话踢下线（HTTP 401，错误码 40104）。

**怎么办**：
1. 是你自己换设备登录的 → 正常现象，原设备重新登录即可（会把另一边踢掉）。
2. **不是你本人登录的** → 立刻改密码，并告知管理员查审计日志（每次踢人都留有 `session_kicked` 记录）。
3. 登出（点退出）会同时失效两侧 token，不用担心残留。

**例外**：平台 Redis 故障期间单点登录会临时失效（双端都能用），恢复后自动回到「一处在线」——这是有意的可用性设计，不是bug。

---

## 六、提示「余额不足，请等待当前任务完成」（普通用户，S2 新增）

**发生了什么**：你的积分余额低于平台阈值（默认 100，管理员可调），系统限制你**同时只跑一个任务**（对话/视频生成）。你前一个任务还在跑，第二个就被拦了（HTTP 429，错误码 42902）。

**怎么办**：
1. 等当前任务跑完再发下一条——余额低不影响使用，只是不能并行。
2. 充值到阈值以上立即恢复并行能力。
3. 不影响：知识库索引、文件上传、历史记录查看等不扣费功能照常。

**管理员**：阈值和在途上限在「设置 → 计费设置」页面实时可调（保存即生效，无需重启）。

## 常见问题

**Q: 我什么都没做，为什么登录被锁？**
A: 两种可能：有人（或某个存了你旧密码的客户端）在反复试你的账号；或你所在的共用出口 IP 被别人试错连累。等自动解锁或找管理员，解锁后建议改密码。

**Q: 安全响应头/CORS 白名单会影响我用平台吗？**
A: 正常用完全无感。只有自己写脚本/第三方页面跨域调平台 API 时才受白名单限制——生产环境仅放行官方前端域名，发现跨域报错联系管理员核对白名单。

**Q: 我存的积分流水能被后台改掉吗？**
A: 不能。流水表只增不改（数据库层禁止应用账号 UPDATE/DELETE），且有每日对账抓异常。

**Q: 审计日志会不会被偷偷改掉？**（S2 新增）
A: 改不了不留痕。每条审计记录都带着「链上一条」的防伪指纹（HMAC 哈希链），改或删任意一条，后面全对不上——系统每天凌晨自动全量校验并把末行指纹写入独立锚点文件，断链会告警且留 `chain_broken` 记录。只会告警不会自动改回（防篡改系统自己覆盖证据）。

**Q: 单点登录能关掉吗？**（管理员）
A: 能。「设置 → 认证设置 → 单点登录」开关关掉即恢复同账号多端同时在线，立即生效。
