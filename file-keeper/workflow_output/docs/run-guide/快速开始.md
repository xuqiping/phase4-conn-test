# 🚀 快速开始指南

## ⚠️ 当前状态

检测到系统中**未安装 Node.js**，需要先安装 Node.js 才能运行前端项目。

---

## 📦 步骤 1: 安装 Node.js

### 方式 1: 官方安装包 (推荐)

1. 访问 Node.js 官网: https://nodejs.org/
2. 下载 **LTS 版本** (长期支持版，当前推荐 v20.x)
3. 运行安装程序，按默认选项安装
4. 安装完成后，**重启命令行窗口**

### 方式 2: 使用 Chocolatey (Windows 包管理器)

如果已安装 Chocolatey:
```powershell
choco install nodejs-lts
```

### 验证安装

打开新的命令行窗口，运行：
```bash
node --version
npm --version
```

应该看到版本号输出，例如：
```
v20.11.0
10.2.4
```

---

## 📦 步骤 2: 安装项目依赖

在项目目录下运行：

```bash
cd "C:\AI Projects\file-keeper"

# 使用 npm (Node.js 自带)
npm install
```

**预计安装时间**: 2-5 分钟 (取决于网络速度)

### 可选: 安装 pnpm (更快的包管理器)

```bash
npm install -g pnpm
pnpm install
```

---

## 🎨 步骤 3: 运行前端开发服务器

### 仅运行前端 (推荐先测试)

```bash
npm run dev
```

或使用 pnpm:
```bash
pnpm dev
```

**运行成功后**:
- 浏览器会自动打开 `http://localhost:1420`
- 或手动访问该地址

### 运行完整 Tauri 应用 (需要 Rust)

```bash
npm run tauri:dev
```

**注意**: 首次运行 Tauri 需要：
1. 安装 Rust: https://www.rust-lang.org/tools/install
2. 等待 Rust 依赖编译 (首次约 5-10 分钟)

## 🐛 常见问题

### 1. 命令找不到 (node/npm/pnpm)

**原因**: Node.js 未安装或未添加到 PATH  
**解决**: 
- 重新安装 Node.js，确保勾选"Add to PATH"
- 重启命令行窗口
- 重启电脑

### 2. 端口 1420 被占用

**错误信息**: `Port 1420 is in use`  
**解决**: 
- 关闭占用端口的程序
- 或修改 `vite.config.ts` 中的端口号

### 3. 依赖安装失败

**错误信息**: `npm ERR!` 或网络超时  
**解决**:
```bash
# 清除缓存
npm cache clean --force

# 使用国内镜像
npm config set registry https://registry.npmmirror.com

# 重新安装
npm install
```

### 4. TypeScript 类型错误

**原因**: 依赖未完全安装  
**解决**:
```bash
# 删除 node_modules 和 lock 文件
rm -rf node_modules package-lock.json

# 重新安装
npm install
```

### 5. Naive UI 样式不显示

**原因**: Naive UI 按需导入配置问题  
**解决**: 已在代码中正确配置，确保依赖安装完整
