# 剪贴板用户操作手册

> 覆盖分组、置顶、批量动作和快捷面板。已进入 Phase 4；自动化通过，M10—M13、L4—L6、E3/E5/E6 待用户确认。

## 浏览和切换分组

1. 打开“剪贴板”。
2. 在左侧选择“全部记录”“未分组”或自定义组。
3. 列表按所选分组刷新，当前入口有选中状态；重启后恢复主页面分组筛选。

联动：仍在新结果中的选中项保留；不可见项被移出选择，不参与批量操作。快捷面板始终搜索全部分组，不会覆盖主页面结果。

## 管理分组

1. 点击“管理分组”。
2. 输入 1—40 字符名称并新建，或修改现有名称后重命名。
3. 删除时先阅读确认说明，再点击确认删除。

预期结果：空名、超长、控制字符或忽略大小写同名会被拒绝。删除分组只把记录移到“未分组”，不删除正文；删除当前组后主页面切到“未分组”。取消确认不发生变化。

## 单条置顶和移动

1. 右键记录，或聚焦记录后按 `Shift+F10`/菜单键。
2. 选择“置顶/取消置顶”或目标分组。
3. 界面立即重排或移出当前筛选；后台失败时恢复，并显示通用错误提示。

按 `Esc` 可关闭菜单，焦点返回原记录。置顶记录显示“已置顶”。

## 批量操作

1. 勾选多条记录，可使用全选或反选。
2. 点击批量置顶、取消置顶，或从“移动选中项”选择目标组。
3. 所有 ID 通过一次请求提交；任一记录无效时整批失败并回滚，不会部分成功。

## 快捷面板

1. 使用剪贴板快捷键打开面板。
2. 输入关键词；结果来自全部分组。
3. 上下键选择，`Enter` 原格式粘贴，`Shift+Enter` 纯文本粘贴，`Esc` 关闭。

## 异常与隐私

- 失败提示不显示剪贴板正文、来源窗口标题或文件路径。
- 本功能不新增服务端请求或云同步。
- 右键体感、完整键盘路径、1 万条/100 组性能按 Phase 4 M10—M13、L4—L6、E3/E6 验收。
