## Step 5 · 模型网关 chat（commit `87116a6`）
- **链路**：`POST /gateway/chat`（受登录保护）→ 余额预估 precheck（空钱包 402，流都不开）→ 供应商 `chatStream` SSE 逐块透传 → 末帧权威 usage `meter.settle` 实扣（幂等键 `chat:{nonce}`）→ `done` 帧回报 cost/任务累计/capped。
- **SSE 防缓冲**（坑点①落实）：`@Res()` 手写 + `cache-control: no-cache, no-transform` + `x-accel-buffering: no` + flushHeaders；e2e 断言逐字 delta（>3 块，不是憋一屏）。
- **计量口径**：usage 只认上游末帧（客户端报的不算）；上游没给按输入 token 兜底。**幂等键语义拆两层**：`nonce`（请求级，重试不重扣）与 `task_id`（任务级，熔断按它累计，缺省视同 nonce）。
- **熔断**：`CHAT_TASK_CAP_CENTS`（默认 500 元），超限 done 帧 `capped=true` + ERROR 日志（联动点 1：客户端收到后停跑）。
- **供应商适配层**：`ProviderRegistry`（env `GATEWAY_PROVIDER`，dev/test 默认 mock 不烧钱）+ `MockProvider`（固定 usage 1M in/0.5M out=315 分可精确断言；消息以 `[dead]` 开头模拟上游挂）+ `AnthropicProvider`（api_identities 取 key AES-GCM 解密、SSE 解析；真上游联调待运营配 key）。
- 错误映射：上游挂 → SSE `error` 事件 502 语义大白话，绝不透传上游原文。
- e2e 5 用例：正常流入账 315 / 同 nonce 重放不重扣 / 402 / 502 / 熔断（同 task 两轮 630≥500）。

## Step 7 · 充值（commit `002d5ea`）
- **下单**：`POST /payments/recharge {pack_code}` 三档 P50/P200/P500（配置文件不进库，P200/P500 带赠送）；回 mock `pay_url`。
- **回调**：`POST /payments/webhook` `@Public`（渠道无 JWT）+ HMAC-SHA256 验签（`X-Signature`，规范化 JSON 拼串，密钥 `PAYMENT_HMAC_SECRET`）。
- **防重放双保险**：订单 `status 0→1` CAS（`WHERE status=0`，输家直接幂等返回 first=false）+ 账本幂等键 `recharge-{orderId}`。
- **金额一致性**：回调 `paid_cents` 必须等于订单金额，改小金额的自签回调也拦（400 大白话）。
- 入账走 `BillingService.credit`（kind=2，本金+赠送一起，model 字段存档位码）——不破坏对账不变量。
- e2e 5 用例：下单→回调余额+20500 / 重放不加钱 / 伪造签名 400 / 金额篡改双路 400 / 非法档位+401。

## Step 6 · 搜索网关（commit `3951bc2`）
- **接口**：`POST /gateway/search {intent: web|deep_read, query, nonce}`（受登录保护）。
- **降级链**：`SearchService` 按序试启用的供应商——mock 主（dev/test 默认）→ 博查（env `BOCHA_API_KEY`）→ SearXNG（env `SEARXNG_URL`）→ mock 备；首家失败自动下家，响应带 `provider` + `degraded`（非首家命中=true）；空结果按失败处理；全挂 502 大白话且**失败不计费**。
- **deep_read**：URL 转 Markdown，链 Jina（env key）→ mock；同样走缓存与计费。
- **计次计费**：web 10 分/次、deep_read 20 分/次（env 可调），kind=1 `model='web_search'`——明细单列「联网搜索」（联动点 3）；幂等键 `search:{nonce}`。
- **缓存防重复扣费**：query 归一化（trim+lowercase+sha1）KV 缓存 10 分钟，命中 `cached=true` 且**不扣钱不记账**（半选态联动）。
- e2e 6 用例全过：正常计费 / 降级标记 / 缓存命中不扣费（含归一化验证）/ 全挂 502 / deep_read / 402+401。
