# 3.3 多模态评测体系与5大避坑

> 本碎片覆盖 D-19 基线维度：I.09/I.12/I.16/I.20

## 一、为什么传统文本评测不适用多模态

### 1.1 传统文本评测失效的3个原因

| 原因 | 表现 | 多模态特殊问题 |
|---|---|---|
| BLEU/ROUGE指标纯文本 | 不能评估图像/视频质量 | 多模态必须考虑"跨模态一致性" |
| 单模态幻觉率指标 | 不评估跨模态对齐 | 多模态幻觉率40%+，必须专项测 |
| 静态基准（如MMLU） | 不评估动态时序一致性 | 视频生成必须测"时序一致性"，传统基准无能为力 |

### 1.2 多模态评测的"协同与时序对齐"本质

> 多模态测试的本质难点不在"多"，而在"协同"与"时序对齐"

## 二、多模态评测三层框架

### 第一层：模态内评测（Same-Modality）

每个模态独立做评测，确保单模态质量不退化。

| 模态 | 评测指标 | 主流基准 |
|---|---|---|
| 文本 | BLEU/ROUGE/Perplexity/GPT-4 as judge | MMLU/HumanEval |
| 图像（理解） | VQA准确率/物体识别准召率 | VQAv2/GQA/TextVQA |
| 图像（生成） | FID/CLIP Score/人工偏好 | PartiBench/DrawBench |
| 音频（ASR） | WER（词错率）| LibriSpeech/Common Voice |
| 音频（生成） | MOS（平均主观意见分）/客观指标PESQ | VoiceMOS Challenge |
| 视频（理解） | VideoQA准确率/动作识别准召率 | MVBench/Video-MME |
| 视频（生成） | 时序一致性/物理一致性/画面质量/Audio-Visual对齐 | VBench/VideoScore |

### 第二层：跨模态评测（Cross-Modality）

评估模态间的对齐质量与一致性，是大多数产品最容易失守的层。

| 评测维度 | 评测指标 | 典型基准 |
|---|---|---|
| 图文对齐度 | CLIP Score / Fine-Grained Alignment Score | FLICKR-30K/COCO Retrieval |
| 视觉幻觉率 | POPE Hallucination率 / HallusionBench | POPE/HallusionBench |
| 多模态推理 | 跨模态CoQ准确率 | MMMU/MathVista |
| 多模态RAG幻觉率 | 答非所问率/语义锚点命中率 | 自建回归集 |
| 跨模态生成一致性 | 文生视频中"红色"是否真实出现 | 自建对照测试集 |

### 第三层：任务级评测（Task-Level）

把多模态产品放到实际业务任务中评测。

| 任务类型 | 评测指标 |
|---|---|
| 多模态客服 | 任务完成率/满意度/转人工率（参D-19.05） |
| 多模态RAG问答 | 答案准确率/幻觉率/拒答率 |
| 多模态内容创作 | 用户采纳率/修改次数/分享率 |
| 具身智能任务 | 任务成功率/物理一致性/安全事件率 |
| 跨模态搜索 | Top-K召回率/NDCG/查询时延 |

## 三、8个核心多模态评测指标（PM必知）

| 指标 | 含义 | 评测方法 | 适合场景 |
|---|---|---|---|
| **VQA准确率** | 模型对图像问题的回答准确率 | 在VQAv2/GQA等基准测 | 多模态理解产品 |
| **视觉幻觉率** | 模型"看到"图中不存在的事物的比例 | POPE基准（Yes/No问答，识别是否脑补） | 任何多模态理解产品 |
| **CLIP Score** | 图文对齐度（生成图与描述文本的相似度） | 用CLIP模型对图-文对打分 | 文生图产品 |
| **FID** | 生成图像质量（与真实图像分布距离） | 与参考图像数据集对比 | 图像生成产品 |
| **时序对齐误差** | 多模态事件时间偏差 | 不同模态事件时间戳偏差统计 | 多模态RAG/具身智能 |
| **模态缺失鲁棒性** | 缺模态下任务完成率 | 主动剔除某模态测试 | 任何多模态产品 |
| **Audio-Visual对齐度** | 视频画面与音轨同步度 | 唇音同步算法检测 | 视频生成产品 |
| **多模态RAG幻觉率** | 多模态RAG答错或脑补率 | 自建回归集+GPT-4 as judge | 多模态RAG产品 |

## 四、5大多模态评测避坑

### 避坑1：数据污染虚增分数
- **现象**：评测基准被泄露到训练数据，导致基准分数虚高
- **典型**：MMBench部分题目被发现在训练数据中
- **对冲**：用动态基准/未公开基准/自建回归集
*参 D-19.10 评估掩盖三机制*

### 避坑2：CLIP词袋效应污染评测
- **现象**：基于CLIP Score评测文生图时，"红苹果"和"苹果红"都打高分
- **对冲**：用Fine-Grained CLIP Score替代基础CLIP Score

### 避坑3：评估者偏差（GPT-4 as Judge的问题）
- **现象**：用GPT-4.7做评测时，GPT-4.7对自己系列的模型打分偏高（同类偏好）
- **对冲**：用多个不同模型交叉评测+人工抽样校验

### 避坑4：基准覆盖盲区
- **现象**：MMMU等学术基准覆盖不了自家业务场景（如医疗影像+病历+主诉）
- **对冲**：必须自建领域回归集，不能依赖学术基准

### 避坑5：时序对齐不纳入评测
- **现象**：只评单模态效果，忽视模态时序对齐误差
- **对冲**：必须把时序对齐误差作为单独指标

## 六、PM多模态评测落地清单

### MVP期评测（轻量）
1. 视觉幻觉率（POPE基准）
2. VQA准确率（VQAv2）
3. 用户日志人工抽样（每周100条）

### 成长期评测（标准）
4. 跨模态对齐（CLIP Score / Fine-Grained Alignment）
5. 多模态RAG幻觉率（自建回归集，每周500条）
6. 模态缺失鲁棒性测试

### 旗舰期评测（深度）
7. 时序对齐误差
8. Audio-Visual对齐度（视频产品）
9. 多源交叉验证准确率
10. 用户任务成功率（业务指标联动，参D-19.05）

## 七、PM核心理念提炼

1. **多模态评测是三层（模态内/跨模态/任务级）不能简化**
2. **视觉幻觉率永远要测，POPE基准是底线**
3. **时序对齐误差是大多数团队忽视的指标**
4. **自建回归集比学术基准更重要**（业务场景覆盖）
5. **评测者偏差必须用多模型交叉消除**
6. **多模态RAG幻觉率40%+是2026-07的现实，必须专项测**
7. **2026评测体系升级方向**：从静态基准→动态基准→真实业务任务
