## 本轮实现

### C5 — SecurityGateFilter 热路径拦截器
- `common/security/SecurityGateFilter.java`（新建）：顺序 ①IP 黑名单（Redis hasKey）→ 403 固定话术 + IP_BLOCKED_HIT 事件 ②全局 per-IP 固定窗口限流（默认 600/min，`security.rate.global_ip.max` 热调）→ 429 + RATE_BURST MEDIUM 事件 ③注入特征（只扫 URL query + 表单参数键值，**不扫 JSON 正文**——chat 内容走 P3 Prompt 冷规则）→ 403 + HIGH 事件 + 累犯 3 次/1h 自动封 IP 1h
- **依赖全 ObjectProvider 延迟取**（@WebMvcTest 切片自动包含 Filter/HandlerInterceptor Bean 但不加载普通 @Component——P1 实证崩 6 个切片类的坑，新组件一律 ObjectProvider）
- `common/security/InjectionDetector.java`（新建，纯函数）：SQLi 10 组合模式（union select/恒真式/注释截断/sleep/xp_ 等）+ XSS 7 模式 + PATH 5 模式；URL decode 最多 2 次（防 %2527 双重编码绕过）；命中片段 ≤80 字符 + 去控制字符（防 ANSI 逃逸污染日志）
- `common/security/SecurityEventTypes.java`（新建）：15 检测码 + 5 动作码 + 来源码常量，防散写
- `common/security/entity/SecurityEvent.java` + `mapper/SecurityEventMapper.java`（新建）：不继承 BaseEntity（本表可物理删，与 audit 隔离）；detailJson 走 JsonbStringTypeHandler；+ackIfUnhandled 条件更新（并发 ACK 幂等）
- `common/security/SecurityEventService.java`（新建轻量版，P3-C8 扩异步总线）：落库 + 指标 + security 日志通道；**Redis SET NX 去重窗口 5min**（同 type+user/ip 只落 1 行防告警风暴）；全程 catch 吞绝不阻业务主链
- `SecurityConfig.java`：SecurityGateFilter 经 ObjectProvider 注册在 MdcUserFilter 之后（事件日志含 traceId/userId）

### C6 — IP 黑名单（自动+手动，Redis 镜像）
- `IpBlacklistService.java`（新建）：@PostConstruct 启动加载未过期行灌 Redis（漂移自愈）；isBlocked 热路径 hasKey 降级放行；autoBlock（upsert 续期 + Redis TTL=剩余封禁期）；manualBlock（永久=DB null + Redis 30 天兜底 TTL）；unblock 双删；@Scheduled 每小时清 DB 过期行；**IPv6 归一化 InetAddress**（防多写法绕过）
- `entity/IpBlacklist.java` + `mapper/IpBlacklistMapper.java`（新建：upsert ON CONFLICT/selectActive/deleteByIp/deleteExpired）
- `controller/IpBlacklistController.java`（新建）：POST /api/security/ip/block|unblock + GET /list，@RequirePermission("security:ban:manage") + @AuditLog

### C7 — login_attempts + 4 热规则
- `LoginAttemptsService.java`（新建）：异步写（专用小池 core1/max2/queue500/CallerRuns 背压，命名线程 login-attempt-*）；geo 异步线程查；每日 04:30 清 30 天前行；记录绝不阻登录主链
- `GeoIpService.java`（新建）：ip2region 3.3.7 + Searcher.newWithBuffer 整库内存模式；**xdb 缺失/内网 IP/异常 → 降级返回 ""**（异地检测数据不足不误报）；内网段判定含 10/172.16-31/192.168/127/169.254/::1/fc/fd
- `AuthService.login` 接线：成功/无此用户/密码错三分支 recordAsync（identifier 小写归一，failReason no_such_user/bad_password）
- `AuthService.recordLoginFailure` 扩两热规则（阈值跃迁瞬间触发，防刷屏）：
  - **暴破**：账号 5 次/15min → DB LOCKED + locked_until=+15min + banReason=LOGIN_BRUTE_FORCE + BanService.revoke 踢下线 + LOGIN_BRUTE_FORCE HIGH 事件（auto_action=ACCOUNT_LOCKED）——原来只 Redis 计数（Redis 故障即归零），升级后 DB 持久+即时踢
  - **撞库**：同 IP 5min ≥20 个不同账号（Redis SET login:ids:{ip}）→ autoBlock IP 60min + CREDENTIAL_STUFFING HIGH 事件（撞库封 IP 而非锁每个号——防账号枚举 DoS）
- RATE_BURST 升级链接入 `RateLimitInterceptor` 429 路径：rlburst:{u:42|ip:x} INCR TTL 1h；≥3 → MEDIUM 事件；≥10 且 IP 维度 → autoBlock 30min
- 高频端点挂注解：chat `/messages` + `/messages/stream`（chat_send 20/min SLIDING）、media `/video` + `/image`（media_submit 10/min SLIDING）
