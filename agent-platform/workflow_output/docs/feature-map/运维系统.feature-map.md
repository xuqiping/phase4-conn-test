## 调用链路（关键路径）

**指标**：业务代码 → BizMetrics 埋点（O(1) 内存计数）→ /actuator/prometheus → Prometheus 15s 拉取入仓 → Grafana 看板 PromQL 展示
**告警**：Prometheus 评估 alert-rules（15s）→ firing → Alertmanager 分组（30s 凑批）→ webhook → 钉钉适配器转译 → 钉钉群
**备份**：计划任务 02:00/02:30 → backup-pg/backup-files.bat → D:\backup\agent-platform\ + 状态文件（巡检标记）
**发布**：deploy.bat 新包 → 备份 versions\时间戳 → 停服→拷包→起服 → /actuator/health 轮询 5min → 超时回滚旧版

## 技术清单与原理注解（大白话版）

### Prometheus（指标仓库）
- **一句话**：定时来抄指标的仓库，15 秒拉一次。
- **大白话**：像抄表员——各组件把指标摆在自己窗口（/metrics），抄表员按名单挨家抄，存进自家账本，想看历史趋势随时翻。
- **为什么用它**：拉模式不阻塞应用；生态标准。
> 踩坑：micrometer 计数器**懒注册**——没调用过的指标查不到，面板空非故障；指标名点号自动转下划线（llm.calls→llm_calls_total）。

### Micrometer 埋点（应用侧度量）
- **一句话**：在代码咽喉处放计数器/秒表。
- **大白话**：高速公路收费站——每过一辆车抬杆记一次，不占车道（O(1) 内存操作，主链路零 IO）。
> 踩坑：**高基数红线**——userId/IP 这类几千万种取值的绝不许当 tag（会把时序库撑爆），只许有界枚举（provider/result/status）；流式调用用 doOnComplete/Error/Cancel 三终态互斥保证「正好一次」。

### Grafana 看板 + provisioning
- **一句话**：把指标画成图；配置即代码，重启自动装板。
- **大白话**：provisioning 像「菜谱入库」——看板 JSON 是菜谱，Grafana 开机照着摆盘，换机器重摆一模一样。
> 踩坑：看板 JSON 不手改，改 `gen_dashboards.py` 重新生成（防大 JSON 漂移）；数据源 uid 固定 `prometheus`，看板按 uid 引用才找得到。

### Alertmanager + 钉钉适配器
- **一句话**：告警的分拣派送员 + 翻译官。
- **大白话**：分拣员把相同告警凑一堆（30s 一批防刷屏）、重复的隔 4 小时再提醒；翻译官把英文电报转成钉钉机器人认的格式——**没有翻译官钉钉直接拒收**。
> 踩坑：占位配置 receiver 要写字符串 `"null"`（YAML 裸 null 会报错）；Alertmanager 无配置 UI，填 webhook 走「配置钉钉告警.bat」。

### WinSW（服务化）
- **一句话**：把 exe/jar 包成 Windows 服务，开机自启+崩溃自动重启。
- **大白话**：给进程请了个 24 小时保姆——倒了 10 秒内扶起来，开机自动上岗。
> 踩坑：`status` 对未安装服务也返回 0，判存必须 `sc query`；exe 必须与 xml 同名配对；改 xml 参数要重启服务才生效。

### pg_dump / robocopy（备份）
- **一句话**：数据库导出 + 文件镜像。
- **大白话**：pg_dump=给数据库拍快照（压缩存档）；robocopy /MIR=照镜子——源删了镜子也删（保持完全一致，不是无限堆积）。
> 踩坑：robocopy 退出码 0~7 都是成功，≥8 才是失败；中文 bat 必须 GBK+CRLF+无 BOM+不 chcp 65001；**改 GBK bat 禁用 git-bash sed**（丢 \r 全炸），用 PowerShell 字节级读写。

### deploy.bat（健康门禁发布）
- **一句话**：新包上岗前先体检，体检不过自动请回旧人。
- **大白话**：像换人值班——先让旧人别走远（备份到 versions\时间戳），新人上岗观察 5 分钟（/actuator/health 每 5s 问一次），不行立刻换回旧人，还发钉钉汇报。
> 踩坑：Flyway 门禁=启动期迁移失败→健康超时→自动回滚（服务器无 Maven，repair 须在开发机先做）；回滚安全靠 DB「只增不删、向后兼容」纪律。

## 维护提示
- 加新指标：BizMetrics 加方法（tag 只用枚举）→ 埋点处调用 → 看板生成器加面板 → 需要告警再进 alert-rules.yml。
- 改看板：只改 `gen_dashboards.py` 重跑生成，别手改 JSON。
- 改告警文案：alert-rules.yml annotations（中文+处置入口），改完重启 agent-prometheus。

## 增补（2026-08-12，11x 安全加固联动）

- 新增安全域指标（BizMetrics）：api_rate_limited_total{action} / security_events_raised_total{type,severity} / security_ip_blocked_total{source} / security_account_locked_total{action} / security_event_dropped_total。详见 [安全加固.feature-map.md](安全加固.feature-map.md)。
