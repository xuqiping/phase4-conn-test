# SeedDance 视频生成 · 用户操作手册

> 面向持有 `media:gen` 权限的用户。功能入口：侧边栏「视频生成」菜单（`/video-gen`，无权限不显示，联系 admin 授权）。

## 前置条件

- 账号已被授予 `media:gen` 权限（默认仅 admin 有；普通用户须 admin 在「角色权限」页授予）。
- 系统已配置 doubao provider（Ark key + endpoint + seedance 模型）——由运维保证，用户无需关心。

---

## 功能一：文生视频

**操作步骤**：
1. 点侧边栏「视频生成」进入页面。
2. 「生成方式」选 **文生视频**。
3. 「提示词」填描述（≤2000 字，越具体越好，如「一只橘猫在窗台上晒太阳，阳光柔和，慢镜头」）。
4. 「画面比例」选 16:9 横屏（默认）/9:16 竖屏/1:1/4:3/3:4/21:9/adaptive（图生视频沿用参考图比例）。
5. 「时长」选 4-15 秒；「分辨率」选 480p/720p/1080p/4K（720p 推荐，平衡质量与额度；4K 仅 2.0 全版，H.265 部分播放器不兼容）。
6. 「水印」开关（默认关）；「生成音频」开关（默认关，2.0 特色，同步生成原生音频）。
7. 点 **提交生成**。

**界面变化**：右侧「当前任务」出现状态标签「排队中」→「生成中」（旋转加载图标）。

**完成标志**：状态变「已完成」，内联 `<video>` 播放器出现 + 「下载视频」按钮；下方历史列表新增一行。

**预期耗时**：通常 1-3 分钟（超 10 分钟自动判 FAILED）。

---

## 功能二：图生视频（参考图作首帧）

**操作步骤**：
1. 「生成方式」切 **图生视频**。
2. 「参考图（首帧）」点上传，选本地图片（≤8MB，image/*）。
3. 填提示词描述如何「动起来」。
4. 画面比例可填 adaptive（沿用参考图比例）；选时长/分辨率/水印/音频 → **提交生成**。

**完成标志**：同文生视频。

> 注：图生视频需参考图，未上传时「提交生成」按钮旁提示「图生视频需上传参考图」且按钮禁用。

---

## 功能三：查看历史与回看

- 下方「历史任务」表格列出自己（admin 看全量）的任务：ID/提示词/状态/时长/分辨率/创建时间。
- 点某行「查看」→ 该任务加载到上方「当前任务」：已完成则播放视频，进行中则继续轮询，失败则显示原因。

## 下载视频

- 「当前任务」已完成时点「下载视频」→ 浏览器下载 mp4（Content-Disposition 附件，不在线执行）。
- 下载需 `media:gen` 权限 + 任务归属（非自己任务，普通用户下载被拒）。

## 常见异常与恢复

| 现象 | 原因 | 恢复 |
|---|---|---|
| 看不到「视频生成」菜单 | 无 `media:gen` 权限 | 联系 admin 在「角色权限」页授权 |
| 直接访问 `/video-gen` 显示「无 media:gen 权限」 | 同上（4 层权限第②层兜底） | 同上 |
| 提交后页面提示 403 | 权限被收回 | 联系 admin |
| 状态「失败」+「Ark 429 限流」 | Ark 配额超限 | 稍后重试（重新提交） |
| 状态「失败」+「任务超时（>600s）」 | Ark 生成超 10 分钟 | 重新提交；持续超时联系运维查 Ark |
| 状态「下载失败」 | Ark 出视频但下载落盘失败 | 历史保留 arkTaskId 可重试（MVP 暂无重试入口，重新提交） |
| 「参考图过大（>8MB）」 | 参考图超限 | 压缩后重新上传 |
| 轮询中页面提示「网络异常」 | 服务暂不可达 | 连续 5 次自动跳登录；恢复后重新进入页面回看历史 |
