## 动作（伪代码）
1. **① 过滤**：`scopes(用户多选) × timeWindow × direction`。
2. **② 聚合标签**：scope 内 `memory_summaries(status≠STALE)` + `memory_turns.tag_ids` join `memory_tags` → 取 `(subject, topic)` 跨 user 去重 DISTINCT；scope 外 turn/summary 关联不到的 tag 不进聚合（防标签名泄敏）。
3. **③ LLM 选标签**：标签 <30 全灌；>30 anchor 向量+BM25 RRF 粗筛 top-30 → LLM 精选 T。复用 `RrfFusion` / `QueryExpansionService` / `JiebaTokenizer`。
4. **④ 优先读自己总结**：`findSummariesByTagAndScope(T, scope, timeWindow)`，只 user_id=召回者自己（他人总结不召回）。
5. **⑤ 读层分支**：>5 条 → 读全部 L1 → reflect 批量 1 次 LLM 选深读子集 → 展开那些 L2；≤5 条 → 直接读全部 L2（跳 L1 省 reflect）；0 条 → 跳过走 turns。
6. **⑥ 拼增量流水账（allCovered 严格策略，统一按 coverage(user_id=self) 判）**：批量 `WHERE turn_id IN (...)` 一次取 coverage；该 turn 在此 scope 所有 tag_id 均有 coverage 行 → 跳原文走自己总结；否则拼该 turn 原文；他人 turn 同样按自己 coverage 判；**召回恒只认 gen_done=true 的 turn**；gen_done=false 的 raw 不进聚合也不兜底。
7. **⑦ 装配**：按 subject 聚合打前缀带 owner；subject='我' 且 owner≠当前用户 → 省略主体【张三·爱好】。
8. **scope 多选持久化**：保留上次选择，新会话沿用；首次无历史默认 {个人}。复用 `MemoryQueryCache`（prefix `mem:` TTL 60s）。
9. **降级**：选标签失败→null；reflect 失败→只读 L1。最多 2 次 LLM。
