# P01 客户端骨架与状态机引擎 · 人工测试方案

> Phase 3 功能级预处理产出。关联规格：FR-018/029/039/048，覆盖 AC-020、AC-021（仅唤起骨架部分）、AC-043、AC-052。
> 关联计划：[../plans/P01_客户端骨架与状态机引擎.plan.md](../plans/P01_客户端骨架与状态机引擎.plan.md)

## 1. 为什么需要人工测试（判定依据）

- [x] 涉及 UI 交互 / 视觉效果（暗色主题、辉光、管道条动效需人眼确认）
- [x] 主观体验（冷启动体感、密度切换舒适度）
- [x] 桌面端安装/启动/卸载流程（自动化在 CI 只到出包，真机安装需人）
- [x] 跨进程生命周期（杀进程重开恢复）

**自动化覆盖不了的点**：安装包在干净系统的真实安装体验；动效观感；Mac 公证后 Gatekeeper 提示是否符合预期。

## 2. 前置条件

- **环境**：本机 Win10（开发机）+ 任一 macOS 13+ 机器（或虚拟机）；干净 Win10 虚拟机（无 WebView2，验证引导安装）
- **数据准备**：无（全新安装）
- **依赖服务**：无（P01 纯本地，无云端）

## 3. 桌面端专属

| 维度 | 要求 |
|---|---|
| 操作系统版本 | Windows 10 22H2 / macOS 13+（Apple Silicon 优先） |
| 屏幕分辨率/缩放 | 1920×1080 / 100% 与 125% 缩放各一遍 |
| 安装包类型 | .msi（或 .exe）/ .dmg |
| 测试范围 | 安装 → 首次启动 → 创建项目 → 视图切换 → 杀进程重开 → 退出 → 卸载 |
| 控件定位方式 | 人工目检（P01 不上桌面自动化，E2E 在 P05 后补） |
| 离线/弱网 | 需验证：全程断网客户端功能不受影响（P01 无网络依赖） |
