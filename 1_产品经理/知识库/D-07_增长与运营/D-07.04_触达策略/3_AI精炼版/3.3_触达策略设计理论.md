# 3.3 触达策略设计理论

## 五大策略维度

触达策略设计 = 时机 × 频次 × 个性化 × 内容 × 渠道编排，五维联动而非各自为政。

---

### 3.3.1 时机策略（When）

**核心原则**：在用户最可能响应的时间窗口触达。

| 方法 | 说明 | 适用场景 |
|---|---|---|
| 行业黄金时段 | 按行业经验（如电商午间12-13点/晚间20-22点） | 无个性化数据时的基线 |
| 用户活跃时段 | 基于用户历史活跃时间推送（"每位用户有自己的黄金时间"） | 有行为数据的成熟产品 |
| 行为触发时机 | 关键行为后N分钟/小时自动触发 | 加购未付/注册未激活/流失预警 |
| 事件驱动时机 | 基于外部事件触发（天气/节日/赛事/降价） | 外卖/出行/旅游/电商 |
| AI预测最佳时机 | 模型预测每位用户最可能打开的时间点 | L5智能触达（见3.6） |

**时机策略关键指标**：发送时段的打开率分布图（热力图），每季度刷新。

### 3.3.2 频次策略（How Often）

**核心原则**：触达频次 = 用户承受力上限以下 × 业务目标所需最低频次。

| 框架 | 说明 |
|---|---|
| 疲劳阈值法 | 设定全局上限（如每周≤5次Push），超限自动熔断 |
| 分层频次法 | 不同人群不同上限（新用户≤2次/周，活跃用户≤5次/周，沉默用户≤3次/周） |
| 渐进式增强 | 从低频开始，根据用户互动反馈逐步提升（打开了→可以多发，忽略了→降频） |
| 响应式调频 | 连续3条未打开→自动降频/换渠道；每条打开→维持当前频次 |

**频次控制铁律**：
- 退订率/关闭授权率是频次策略的"红线指标"，一旦上升立即降频
- 不同渠道频次独立计算但合并感知（用户不区分"这是Push不是短信"，只感知"又在打扰我"）
- 紧急通知（交易/安全）不受营销频次限制，但必须控制占比

### 3.3.3 个性化策略（Who + What变体）

**层级**：

| 层级 | 名称 | 方法 | 示例 |
|---|---|---|---|
| P0 | 全量 | 统一内容，全量发送 | 全渠道公告 |
| P1 | 分群 | 按标签/分群发不同内容 | 男/女不同商品推荐 |
| P2 | 参数化 | 模板+用户参数填充 | "张三，你的订单已发货" |
| P3 | 行为触发 | 基于实时行为触发+动态内容 | 浏览过A商品→A降价推送 |
| P4 | AI生成 | AI实时生成个性化文案/图片/时机 | 千人千面Push文案 |

**过度个性化风险**：
- 隐私感知（"它怎么知道我想要这个？"）→ 适度"模糊化"展示
- 内容质量下降（AI生成文案千篇一律/机械感）→ 人审+AB测试
- 维护成本飙升（N个变体×M个渠道）→ 模板化+动态参数

> [来源:📚训练知识 | 置信度:🔍高]

### 3.3.4 内容策略（What）

**Push文案4要素**：标题（抓注意）+ 副标题（说价值）+ 参数（个性化锚点）+ 行动指引（点击做什么）

| 文案类型 | 结构 | 示例 |
|---|---|---|
| 利益驱动 | 优惠/折扣/限时 | "你的专属券仅剩2小时！" |
| 稀缺/紧迫 | 库存/时间/名额 | "仅剩3件，你的购物车在等" |
| 社交证明 | 他人行为/评价 | "2.3万人已领取" |
| 好奇/悬念 | 信息缺口 | "你猜今天有什么新功能？" |
| 服务提醒 | 订单/物流/安全 | "你的包裹已到达驿站" |

**内容策略避坑**：标题党长期伤害信任；emoji滥用导致专业感下降；过长标题截断信息不全。

### 3.3.5 全渠道编排（Omnichannel Orchestration）

**编排四原则**：

1. **去重**：同一消息同一用户只触达一次（跨渠道去重）
2. **递进**：先低成本渠道，未响应再升级（邮件→Push→短信→外呼）
3. **协同**：不同渠道传递不同信息层面（邮件=详情，Push=提醒，短信=紧迫）
4. **频控**：无论多少渠道参与，总触达频次有全局上限

**编排画布模式**：

```
[触发条件] → [等待N分钟] → [渠道A]
                         ↓ 无响应
                    [等待N分钟] → [渠道B]
                                  ↓ 无响应
                             [等待N分钟] → [渠道C]
```

**工具支撑**：神策/Convertlab/瓴羊Quick Audience/AppsFlyer等营销自动化平台，2025-2026主流平台均已支持全渠道编排+AI智能触达。
