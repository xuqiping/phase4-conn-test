## 关键设计

1. **编号 V133 非计划的 V130**——仓库迁移已到 V132，占位号作废（偏差已记 plan）。
2. **钱包/流水不继承 BaseEntity**：单行 update 表没有软删/乐观锁语义；append-only 流水同理。沿用 V65 points 钱包先例。
3. **防透支下沉数据库**：`deduct` 条件 UPDATE 靠行锁原子性，两成员并发扣最后一百分不会双成功（IT 验证第二次返 0 行、余额停在 4）。另有 `ck_pgw_nonneg` CHECK 双保险。
4. **组流水 FK 不带 CASCADE**：组可删，钱的历史不可随组消失（回滚块里也警告 ledger 须先导出）。members/wallets 才 CASCADE。
5. **points_ledger type 是 CHECK 不是注释**：PG 不能 ALTER CONSTRAINT 加值，走 DROP `chk_ledger_type` + re-ADD 六枚举（+GROUP_ALLOCATE/GROUP_RECLAIM）。
6. **对账模板内嵌迁移尾部**：ledger-vs-wallet 逐组对账 + 成员 used 对账两条 SQL，运维不用现想。
