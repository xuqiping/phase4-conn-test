# 快速原型Prompt模板

## 模板1：v0.dev Web产品原型生成

```
Create a [产品类型] web application with the following pages and features:

**Target Users**: [用户描述]
**Core Flow**: [核心流程描述]

Pages:
1. [页面1名称] - [功能描述，包含哪些组件]
2. [页面2名称] - [功能描述，包含哪些组件]
3. [页面3名称] - [功能描述，包含哪些组件]

Design Requirements:
- Style: [Modern/Minimal/Enterprise/Dashboard]
- Color scheme: [主色调描述]
- Component library: shadcn/ui
- Responsive: Mobile-first with desktop layout

Interactions:
- [交互描述1：如"点击卡片跳转详情页"]
- [交互描述2：如"表单实时校验"]
- [交互描述3：如"列表支持筛选和排序"]

Data:
- Use realistic mock data in [语言/地区]
- [数据特征描述]

Accessibility:
- All interactive elements keyboard accessible
- Proper form labels and ARIA attributes
- Color contrast ratio ≥ 4.5:1
```

## 模板2：Figma Make 设计稿生成

```
Generate a [产品类型] design for [目标平台] with these specifications:

**Screen**: [Mobile 375×812 / Desktop 1440×900 / Tablet 768×1024]

**Pages/Frames**:
1. [页面名] - [详细布局描述]
2. [页面名] - [详细布局描述]

**Visual Style**:
- Reference: [Apple/Google Material/SaaS Dashboard/电商风格]
- Primary color: [色值或描述]
- Typography: [字体风格]
- Spacing: 8px grid system
- Border radius: [8px/12px/rounded]

**Components needed**:
- [导航栏: 含logo+搜索+用户头像]
- [卡片: 含图片+标题+描述+操作按钮]
- [表单: 含输入框+选择器+提交按钮]
- [列表: 含筛选+排序+分页]

**States to include**:
- Default / Hover / Active for all interactive elements
- Empty state / Loading state / Error state for data sections

**Content**: Use realistic [中文/英文] copy, no placeholder text.
```

## 模板3：低保真线框图生成

```
我需要为[产品名称]制作一张低保真线框图，要求如下：

**页面**：[页面名称]
**目标用户**：[用户描述]
**核心任务**：[用户在这个页面要完成什么]

布局要求：
- 页面结构：[从上到下描述分区，如"顶部导航→搜索区→内容列表→底部操作"]
- 信息优先级：[最重要的信息放哪，次要放哪]
- 操作入口：[主要操作和次要操作分别放哪]

不要：
- 不要颜色（灰度即可）
- 不要真实图片（用占位框）
- 不要装饰元素
- 不要具体文案（用[x文字]占位）

只要：
- 清晰的信息层级
- 合理的空间分配
- 明确的操作区域
```

## 模板4：交互规格说明生成

```
为以下原型生成完整的交互规格说明：

**组件/页面**：[名称]
**设计稿链接**：[Figma链接或截图描述]

请按以下结构输出：

1. 触发条件（Trigger）
   - 什么操作触发（点击/滑动/输入/系统事件）
   - 触发区域精确位置

2. 响应行为（Response）
   - 视觉变化：状态转换（default→active→...）
   - 动效参数：时长(ms)+缓动函数
   - 数据变化：变量赋值/API调用

3. 状态转换矩阵
   | 当前状态 | 触发条件 | 目标状态 |
   |---------|---------|---------|
   |         |         |         |

4. 异常处理
   - 网络错误：[处理方式]
   - 数据为空：[处理方式]
   - 无权限：[处理方式]

5. 无障碍
   - 键盘操作路径
   - aria-label
   - focus管理
```

## 模板5：AI原型快速迭代

```
基于当前原型，我需要做以下修改：

**当前问题**：[描述发现的可用性问题或反馈]
**修改方向**：[具体要改什么]

请保留：
- [保留项1：如现有信息架构不做调整]
- [保留项2：如组件库和设计令牌不变]

请修改：
- [修改项1：如"将列表页的筛选从侧边栏改为顶部筛选条"]
- [修改项2：如"增加空状态和数据加载态"]

请验证：
- 修改后核心流程是否仍可走通
- 修改后状态覆盖是否完整
- 修改后是否引入新的一致性问题
```

## 模板6：跨端原型适配

```
我有一个[平台1]的原型，需要适配到[平台2]。

**原始原型**：[描述或链接]
**目标平台**：[iOS/Android/Web/iPad/智能手表/TV]
**目标分辨率**：[如 375×812]

适配原则：
- 保留核心功能不变
- 遵循目标平台规范（[iOS HIG / Material Design / Web标准]）
- 交互方式适配（[如鼠标→触摸/触摸→遥控器]）

请输出：
1. 需要调整的布局变化
2. 需要替换的平台特有交互方式
3. 需要新增/删除的功能（因平台差异）
4. 适配后的组件规格差异（间距/字号/触控区域）
```
