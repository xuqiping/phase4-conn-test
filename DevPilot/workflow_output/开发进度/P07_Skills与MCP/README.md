# P07 Skills 与 MCP 功能 README

> 受众 B/C（用户 + 两头都要看）。四块能力：技能（存/斜杠调用/导入导出）、MCP 市场点选安装、MCP 生命周期管理、多模态输入（贴图；语音二期）。

## 用户地图（我能干什么）

| 我想… | 去哪 | 一句话 |
|---|---|---|
| 把这次任务流程存成可复用命令 | 建造阶段 → 存技能 | 存完即可 `/名字` 调用 |
| 用现成技能续跑 | 追加指令框打 `/` | 候选→Enter→写要求→续跑 |
| 把技能带到别的机器 | 技能导出/导入 | 就是复制文件夹 |
| 给模型装外挂工具 | 侧边栏「MCP 管理」→ 市场 | 点「安装」即用，不改配置文件 |
| 救活崩了的 server | MCP 管理页 | 「一键重启」或看日志 |
| 拿截图当需求 | 拖/粘贴进追加指令框 | 自动压缩 ≤1MB |

详细步骤见 `docs/user-ops/P07_Skills与MCP用户操作手册.md`。

## 技术说明（开发看）

- **新 crate**：`core-skills`（SKILL.md 解析/注册表/生成器，16 单测）、`core-mcp`（进程管理+市场，含真进程集成测试）。
- **新表（L11）**：skills_local / mcp_servers / input_attachments，详见 feature-map 表注解。
- **新命令**：技能 4 条 + MCP 8 条 + 多模态 4 条，均在 `commands.rs` 分区注释。
- **前端**：TaskInputBox（斜杠候选+附件+语音占位）、Mcp.tsx 视图（管理+市场），67 例 vitest。
- **语音**：voice_probe 恒 false，按钮隐藏——诚实降级，不放假功能。
