# AI Application Workflow Checklist

在完成 `workflow/ai_application_workflow.md` 的每一步后，使用此检查清单进行交叉验证。每个项目必须回答**是**才算完成。如果有任何项目回答**否**，修复输出并重新验证。

## Step 1: 识别AI应用落地需求场景

- [ ] 已明确场景类型（企业知识库搭建/办公自动化提效/行业大模型定制/AI创业产品/商业化模式设计/出海策略）
- [ ] 已识别目标用户（企业内部员工B2E/企业客户B2B/个人消费者B2C/开发者API）
- [ ] 已提取商业化阶段（概念验证PoC/MVP开发/PMF/规模化增长/成熟运营）
- [ ] 已提取资源约束（团队规模/预算范围/技术栈/数据资产）
- [ ] 已提取关键痛点（知识分散/重复性工作多/行业专业度不够/获客成本高/变现路径不清）
- [ ] 已对照知识库关键洞察完成初步判断（知识分散→企业知识库/重复工作→办公自动化/垂直行业→行业大模型/创业→商业化六大模式）
- [ ] 如有信息缺失，已向用户追问不超过2个澄清问题

## Step 2: 输出AI应用落地方案

- [ ] 如为企业知识库，架构设计已覆盖（数据源接入/RAG Pipeline/对话界面）
- [ ] 如为企业知识库，运营策略已输出（知识更新机制/权限管理/质量监控）
- [ ] 如为企业知识库，部署模式已说明（纯本地/混合/云端SaaS）
- [ ] 如为企业知识库，效果度量指标已给出（检索准确率/答案满意度/响应时间P99/知识覆盖率）
- [ ] 如为办公自动化，自动化层级演进已覆盖（Copilot→Agent→Autopilot）
- [ ] 如为办公自动化，典型场景方案已输出（代码开发Cursor/Copilot/文档处理/会议沟通/数据分析）
- [ ] 如为办公自动化，Computer Use Agent架构已说明（感知层/决策层/执行层/验证层）
- [ ] 如为行业大模型定制，五步法已覆盖（选型→继续预训练PT→监督微调SFT→对齐→部署）
- [ ] 如为行业大模型定制，典型行业案例已给出（法律/医疗/金融/教育）
- [ ] 如为行业大模型定制，合规要点已说明（数据隐私/知识产权/行业监管）
- [ ] 如为AI创业商业化，六大商业模式已覆盖（SaaS订阅/API计费/私有化部署/结果付费/交易抽成/增值服务）
- [ ] 如为AI创业商业化，出海策略已输出（国内验证→海外放大/市场选择/本地化/渠道）
- [ ] 如为AI创业商业化，关键成功因素已说明（AI Native vs AI Enhanced/PLG vs SLG/留存策略/竞争壁垒）
- [ ] 如为AI创业商业化，风险与缓解已覆盖（模型依赖风险/数据飞轮/成本结构控制）
- [ ] 所有核心论断均能在知识库中找到支撑来源

## Step 3: 验证与交付

- [ ] 已读取对应 checklist 并逐项核对
- [ ] 商业化数据（Cursor ARR $5亿等）来源准确
- [ ] 已向用户交付最终答案

## Overall

- [ ] 工作流中的所有步骤已按顺序执行，没有跳过
- [ ] 每一步都已与其检查清单部分进行交叉验证
- [ ] 没有在任何检查清单部分通过前提前进入下一步
- [ ] `task/current_task.md` 已更新完成记录
