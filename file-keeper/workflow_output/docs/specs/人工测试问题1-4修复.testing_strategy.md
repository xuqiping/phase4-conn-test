# 人工测试问题 1—4 修复测试策略

> Phase 1 测试规格。Phase 3 应据此生成四个模块的详细人工测试方案和 User-Ops。

## 1. 测试层次

### 1.1 前端 Vitest

- 快捷键标准化、应用内冲突、试注册失败保留旧配置。
- 文件夹、普通文件、Office 文档、EXE、托管快捷方式均可绑定快捷键。
- 启动恢复部分失败不阻断其他项，失败清单准确。
- 进程旧列配置迁移后 `windowTitle` 默认可见，用户后续可手动隐藏。
- `floating_ball/tray/exit` 三种关闭分支及悬浮球恢复事件。
- 剪贴板置顶、取消置顶、分组筛选、批量移动、失败回滚和国际化文案。

### 1.2 Rust 单元测试

- 托管缓存随机路径、临时文件发布、失败清理。
- 删除只允许托管根下的普通 `.lnk` 文件；覆盖路径越界、根目录、目录、符号链接和连接点。
- 非 `.lnk` 路径只返回描述，不发生复制。
- `.lnk` 目标解析与失效检测使用固定样本。
- 悬浮球位置在单屏、多屏、负坐标、缩放变化时校正到可见区。
- SQLite 版本迁移、索引、分组 CRUD、分组删除事务、孤立归属修复和置顶排序。

### 1.3 组件集成测试

- 编辑收藏项设置/清空快捷键及冲突提示。
- 无效路径标记、重新定位后元数据保持。
- 进程标题列渲染、空标题占位和排序。
- 悬浮球单击、拖动、右键菜单。
- 剪贴板右键置顶、分组管理、单条/批量移动。

## 2. Windows 人工交互测试

| 编号 | 场景 | 通过标准 |
|---|---|---|
| M1 | 分别拖入 `.lnk`、EXE、文件夹、PPT | 类型识别正确；只有 `.lnk` 产生托管副本 |
| M2 | 删除桌面原 `.lnk` 后打开收藏 | 仍由缓存副本正常启动 |
| M3 | 移动或删除真实目标 | 显示失效；重新定位后原元数据保留 |
| M4 | 两收藏项设置相同快捷键 | 保存被拒绝并指出冲突项 |
| M5 | 设置系统已占用快捷键 | 新配置失败，旧快捷键仍有效 |
| M6 | 应用重启恢复多项快捷键 | 成功项可用，失败项有清单 |
| M7 | 同时打开多个 Excel/PPT/资源管理器窗口 | 每行显示对应窗口标题，可排序 |
| M8 | 三种关闭行为分别测试 | 悬浮球、托盘、退出与设置一致 |
| M9 | 拖动悬浮球后重启和切换显示器 | 位置保持且始终可见 |
| M10 | 置顶、取消置顶、搜索和日期筛选 | 排序与筛选规则一致 |
| M11 | 新建、重命名、删除分组 | 记录归属正确，删除组不删内容 |
| M12 | 重启应用 | 分组、置顶和关闭行为保持 |
| M13 | 未登录并断网 | 六项能力均可使用 |

## 3. 回归范围

- 文件收藏新增、删除、编辑、拖拽排序、批量打开和最近打开统计。
- 主窗口、剪贴板、截图原有全局快捷键。
- 托盘显示/隐藏/退出。
- 进程刷新、筛选、激活、关闭和强制结束。
- 剪贴板监控、搜索、复制、粘贴、删除、OCR、缓存清理及敏感内容拦截。
- Pinia 和 SQLite 旧数据升级。

## 4. 测试数据

- `.lnk`：带参数、带工作目录、中文路径、目标不存在、UNC 目标。
- 路径：中文、空格、超长名称、只读目录、无权限目录。
- 进程：Excel、PowerPoint、资源管理器同进程多窗口及空标题窗口。
- 剪贴板：至少 1 万条混合记录、100 个置顶项、100 个分组、同名和非法分组名。

## 5. 退出条件

- 自动化测试全通过，无新增高危安全问题。
- M1—M13 全部通过并保留人工验证记录。
- 性能指标达到 [性能目标](人工测试问题1-4修复.performance_goals.md)。
- Feature Map、User-Ops 和四份人工测试文档同步完成。

## 6. 术语表

| 术语 | 大白话 | 简单案例 |
|---|---|---|
| 回归测试 | 确认新修改没弄坏旧功能 | 新增置顶后复制粘贴仍正常 |
| 固定样本 | 专门保存下来反复测试的文件 | 一个带启动参数的 `.lnk` |
| 组件集成测试 | 同时验证组件与状态交互 | 右键置顶后列表立即重排 |
