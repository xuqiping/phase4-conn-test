# 5.3 O2O与SaaS路径案例

## 案例一：美团「下单→送达」跨端路径

### 背景

美团外卖的完整路径跨越App和小程序，甚至涉及线下场景。

### 跨端路径发现

```
路径1(App)：首页→搜索→餐厅→选菜→支付→等待→送达 (70%)
路径2(小程序)：微信→分享链接→餐厅→选菜→支付→收到通知→打开App查看 (15%)
路径3(历史复购)：首页→再来一单→确认→支付 (10%)
路径4(营销)：短信/推送→打开→领券→下单→支付 (5%)
```

### 优化

| 路径 | 优化 | 效果 |
|---|---|---|
| 路径1过长 | 智能推荐上次餐厅"再来一单" | 复购路径从6步→3步 |
| 路径2断裂 | 小程序内嵌状态追踪 | 跨端体验连续 |
| 路径3效率高 | 首页突出"再来一单"入口 | 复购占比提升 |

### 产品经理启示

1. **跨端路径是O2O产品的特殊挑战**——路径不能断在小程序/App边界
2. **"再来一单"是O2O最短路径**——复购不需要重新搜索

## 案例二：Uber「叫车→到达」极简路径

### 背景

Uber将路径优化做到了极致——从打开App到叫车只需1~2步。

### 路径设计哲学

| 原则 | 实现 |
|---|---|
| 零操作启动 | 打开即显示当前位置+推荐目的地 |
| 智能预测 | 基于历史+时间预测你要去哪 |
| 一键叫车 | 确认目的地后一键下单 |
| 上下文感知 | 机场自动推荐"回家"，公司推荐"常去餐厅" |

### 对比传统叫车路径

```
传统路径：打开→输入目的地→搜索→选择→确认→叫车 (6步)
Uber路径：打开→确认推荐目的地→叫车 (2步)
```

### 产品经理启示

1. **最好的路径是不需要用户走的路径**——预测+自动填充
2. **上下文感知是路径缩短的关键**——知道你在哪里、什么时间，就能预测你去哪
3. **O2O产品的路径优化目标是"2步以内"**

## 案例三：Notion「新手→使用」路径引导

### 背景

Notion面临"空白页恐惧"——用户不知道从哪开始，路径极度分散。

### 路径问题

```
新手实际路径（高度分散）：
注册 → 左侧栏浏览 → 随机点击 → 困惑 → 关闭
注册 → 尝试创建Page → 空白页 → 不知道填什么 → 关闭
注册 → 帮助中心 → 太多内容 → 关闭
```

### 优化

| 策略 | 做法 | 路径变化 |
|---|---|---|
| 渐进式引导 | 注册后3步引导：选模板→填内容→分享 | 散漫→聚焦 |
| 模板推荐 | 选用途后推荐行业模板 | 空白页→有内容页 |
| 示例数据 | 模板内预填示例数据 | 零→有参考 |
| 侧边提示 | 页面右侧显示操作提示 | 不知道做什么→有指引 |

### 产品经理启示

1. **SaaS新手的最大问题是"路径太多"**——没有明确路径=每条路径都走不通
2. **渐进式引导=强制聚焦路径**——减少选择=减少迷失
3. **模板+示例数据=new user onboarding的标配**
