# 6.2 学谁 — 业内顶尖人士对标图谱

## 1. Geert Hofstede

| 字段 | 内容 |
|---|---|
| 身份/头衔 | 荷兰社会心理学家、文化维度理论创始人 |
| 国籍/归属 | 荷兰/荷兰马斯特里赫特大学 |
| 核心成就 | 提出6维度文化差异模型（权力距离/个人主义/男性化/不确定性规避/长期导向/放纵度）——全球跨文化研究基石 |
| 思维模型 | **文化维度量化思维**——把"模糊的文化差异"变成"可量化的维度分数"，每个国家一个6维向量，文化差异=向量距离 |
| 行动范式 | 大规模实证调查→维度提取→模型验证→持续迭代（从4维到6维，跨50年） |
| 可学习点 | 如何把直觉性的"文化差异"变成可度量、可比较、可操作的框架——PM做文化适配时也应用此方法：先量化差异再适配 |
| 代表作 | *Cultures and Organizations: Software of the Mind* |
| 来源 | 📚训练知识 |

## 2. Erin Meyer

| 字段 | 内容 |
|---|---|
| 身份/头衔 | INSEAD教授、跨文化沟通专家 |
| 国籍/归属 | 美国/法国INSEAD商学院 |
| 核心成就 | 提出8维度文化映射模型（沟通方式/评价方式/说服方式/领导方式/决策方式/信任方式/分歧方式/时间安排）——比Hofstede更贴近商务实战 |

| 可学习点 | PM做本地化时不要泛谈"文化差异"，而是按具体场景（注册/支付/投诉/社交）逐一映射——Meyer的方法是最佳框架 |
| 代表作 | *The Culture Map* / TEDx演讲 |
| 来源 | 📚训练知识 |
