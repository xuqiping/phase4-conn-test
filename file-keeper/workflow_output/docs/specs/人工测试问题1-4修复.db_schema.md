# 人工测试问题 1—4 本地数据模型

> 本轮不涉及服务端数据库；以下均为桌面端本地数据。

## 1. 收藏项模型扩展

`FileItem` 增加可选字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `shortcut` | `string?` | 标准化后的独立全局快捷键 |
| `sourcePath` | `string?` | 用户最初拖入的路径 |
| `managedArtifact` | `ManagedArtifact?` | 托管缓存信息 |
| `shortcutTargetPath` | `string?` | Windows `.lnk` 最终目标，用于失效检测 |

`ManagedArtifact`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `kind` | `'windows-shortcut-copy'` | 托管类型 |
| `cachePath` | `string` | 应用数据目录内的随机名副本 |
| `originalPath` | `string` | 原 `.lnk` 路径，仅用于说明和重新定位 |

兼容规则：旧数据的 `path` 继续作为实际启动路径；缺失新增字段视为普通直接路径收藏项。

## 2. 设置模型扩展

将 `minimizeToTray: boolean` 迁移为：

```ts
closeBehavior: 'floating_ball' | 'tray' | 'exit'
floatingBallPosition?: { x: number; y: number; monitorId?: string }
processSettingsVersion: number
```

旧值迁移：`minimizeToTray=true → tray`；否则迁移为 `floating_ball`。迁移完成后只写新字段。

## 3. 剪贴板 SQLite

### 3.1 新表 `clipboard_groups`

```sql
CREATE TABLE clipboard_groups (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  normalized_name TEXT NOT NULL UNIQUE,
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);
```

### 3.2 `clipboard_items` 新增字段

```sql
ALTER TABLE clipboard_items ADD COLUMN group_id TEXT NULL;
ALTER TABLE clipboard_items ADD COLUMN pinned_at INTEGER NULL;
```

保留现有 `is_pinned INTEGER NOT NULL DEFAULT 0`，以兼容现有类型和缓存保护逻辑。

### 3.3 索引

```sql
CREATE INDEX idx_clipboard_items_group_created
  ON clipboard_items(group_id, created_at DESC);
CREATE INDEX idx_clipboard_items_pinned
  ON clipboard_items(is_pinned DESC, pinned_at DESC, created_at DESC);
CREATE INDEX idx_clipboard_groups_sort
  ON clipboard_groups(sort_order, created_at);
```

## 4. 数据约束

- `group_id=NULL` 表示“未分组”。
- “全部”和“未分组”不写入 `clipboard_groups`。
- `is_pinned=0` 时 `pinned_at` 必须清空；置顶时两者在同一事务更新。
- 删除分组时先将所属记录 `group_id=NULL`，再删除分组，并在同一事务提交。
- 启动迁移发现孤立 `group_id` 时自动置空，不删除记录。

## 5. 迁移策略

使用 SQLite `PRAGMA user_version` 管理本地剪贴板数据库版本：

1. 读取当前版本。
2. 在事务中按版本顺序创建表、补列和索引。
3. 迁移成功后更新 `user_version`。
4. 失败则回滚并保留旧数据库可读状态，应用显示修复提示。

## 6. 术语表

| 术语 | 大白话 | 简单案例 |
|---|---|---|
| 可空字段 | 允许没有值的字段 | `group_id=NULL` 表示未分组 |
| 索引 | 帮数据库加速查找的目录 | 快速列出某分组的记录 |
| `user_version` | SQLite 内置的数据库版本号 | 判断是否需要执行本次升级 |
