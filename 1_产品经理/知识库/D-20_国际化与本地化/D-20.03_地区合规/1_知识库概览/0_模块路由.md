## 是什么

地区合规是产品出海时必须遵守的各国/地区法律合规体系——涵盖数据本地化存储/跨境传输、隐私法规（GDPR/PIPL/LGPD/DPDPA等）、内容审核/言论法规、行业准入许可（金融/医疗/教育/游戏）、本地化税务与消费者保护法。合规不是"可选"——不合规=罚款+下架+业务关停。

核心知识域（3层）：
- **数据合规层**：数据本地化要求 / 跨境数据传输机制（SCC/BCR/ adequacy决定）/ 数据保护影响评估(DPIA) / 数据主体权利 / 数据泄露通知
- **内容合规层**：各国内容审核标准 / 言论自由边界 / AI内容标识 / 未成年人保护 / 禁忌内容（政治/宗教/成人）
- **行业合规层**：金融牌照/支付合规 / 医疗数据合规(HIPAA) / 教育合规(COPPA/FERPA) / 游戏分级与未成年人防沉迷 / 消费者保护法/退换货法规

本叶子不含：多语言架构/翻译流程（→D-20.01）、文化适配/格式本地化（→D-20.02）、海外发行运营/渠道（→D-20.04）、数据隐私通用知识（→D-16.01）、AI合规通用知识（→D-16.04）、落地流程与模板（→4_可落地流程）、案例详解（→5_业内顶级案例）
