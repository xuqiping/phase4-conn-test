## 设计（完全复制生图默认范式，零新概念）

设置键 `media.default.video-model`（`SystemSettingService.MEDIA_DEFAULT_VIDEO_MODEL`）。
读宽容：未配置/已失效（不在任何 ACTIVE VIDEO provider）→ null，消费方自然回落列表第一个/默认 provider 首模型。
入口：设置 → 全局模型供应商 →「默认模型」卡片新增**默认视频模型**下拉（与对话/向量/生图并列）。

## 后端改动

- `SystemSettingService`：+`MEDIA_DEFAULT_VIDEO_MODEL` 常量 + `getDefaultVideoModel()`；
  `updateDefaultModels` 3→4 参（+videoModel）。
- `SystemSettingController`：PUT `llm-model-defaults` +`validateDefaultModel(videoModel, VIDEO, "视频")`
  （不属于启用 VIDEO provider 的模型拒 400）；GET 回显 +videoModel。
- DTO：`LlmModelDefaultsUpdateRequest`/`LlmModelDefaultsVO` 各 +videoModel。
- `MediaModelVO` +`defaultModel` 布尔；`MediaModelService.listModels()` 按设置标记命中项
  （与 `listImageModels` 同款，附属档也可被标记——独立页支持其表单形态）。
- `MediaGenTaskService`：
  - `doSubmit` 空 model 分支：**优先**设置默认（`resolveProviderByModel` 反查命中即用，跨 provider）；
    未配置/失效 → 回落旧路径（`media.provider-name` 默认 provider + 首模型），失效时 WARN 记运维线索。
  - `estimatePreview` 空 model 同口径（预览与提交同模型，防预估/实扣不一致）。

## 前端改动

- `api/system.ts` `LlmModelDefaults` +videoModel；`api/media.ts` `MediaModelVO` +`defaultModel?`。
- `ProviderManageTab.vue`：默认模型卡片 +「默认视频模型」下拉（候选=启用 VIDEO provider 模型全集含附属档），
  hint 文案补视频口径。
- `VideoGenView.vue` `loadModels`：初始选中 = `defaultModel` 标记项 ?? 列表第一个（原固定第一个）。
- `PropertyPanel.vue`：+`applyDefaultVideoModel()`（仿图片 C2 范式）：视频节点未显式选模型时补默认——
  候选先滤附属档（context-ir/regeneration 画布形态不匹配，标记落附属档时跳过标记取生成档第一个），
  **走 `onVideoModelChange`** 顺带把 ratio/分辨率/时长收敛进该模型能力区间（画布对不支持字段传值直接被后端拒）；
  挂载期目录加载完 + 节点切换两时机各补一次。占位符改「默认（管理员默认视频模型）」。
- `CanvasView.submitVideoOnly` 不改：节点 model 已在面板层补默认；真漏空时后端空 model 路径也按设置回落（双保险）。

## 坑

1. 画布补默认必须走 `onVideoModelChange` 不能裸赋 `node.data.model`——裸赋不收敛参数，
   minimax-h3（仅 768p/2k）配旧节点残留 720p 会被后端拒（生图默认没这问题因生图无残留参数档位收敛需求）。
2. 设置页候选含附属档是有意为之：独立视频页支持附属档表单；画布侧自行过滤（两处消费口径不同）。
