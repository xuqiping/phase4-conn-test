## 本轮做了什么（迭代 I1 落地，单测 10/10 全绿）

项目记忆读取 ACL 前置：建授权表 + `readableAuthors(projectId, reader)` resolver。**前置**——D 召回 / E 总结取数强依赖，须在 D/E 前。本迭代只建 resolver，**接入（召回/总结取数加过滤）在 I3**。

### I1-1 Flyway V49 建表
- [V49__create_memory_recall_acl.sql](../../../backend/src/main/resources/db/migration/V49__create_memory_recall_acl.sql)
- 表 `memory_recall_acl`：`project_id` + `reader_user_id` + `target_user_id` + `created_by`(审计) + `created_at`；`UNIQUE(project_id, reader_user_id, target_user_id)`；索引 `(project_id, reader_user_id)` 覆盖 resolver 主查。
- **无 deleted 列**——ACL 行 = 显式授权事实，撤销 = DELETE 行（append-only + 删，同 members/coverage 风格）。
- **版本偏移落地**：原 plan 写 V48，V48 已被迭代 A 补丁（memory_conflicts 放宽）占用 → 本迭代走 **V49**（H DROP 顺延 V50）。子 plan 文内旧数字已订正。
- **可逆**（运维考量）：建表无数据，逆操作 `DROP TABLE memory_recall_acl;`（注释附）。

### I1-2 实体 + Mapper
- [MemoryRecallAcl](../../../backend/src/main/java/com/superprogrammer/chat/entity/MemoryRecallAcl.java)：plain `@TableName`（同 MemoryProjectMember 风格，无 BaseEntity 软删）。
- [MemoryRecallAclMapper](../../../backend/src/main/java/com/superprogrammer/chat/mapper/MemoryRecallAclMapper.java)：`BaseMapper` + `@Select findGrantedTargetIds(projectId, readerUserId)`（强制 project+reader scope，向量 14）。写侧（配/撤销）属 I2，BaseMapper.insert/delete 足够。
- **MemoryProjectMemberMapper 不动**（A 注释明示"查询走 MP wrapper"）——resolver 用 `LambdaQueryWrapper` 查成员表，保持 I1 改动最小。

### I1-3 resolver 主逻辑
- [MemoryRecallAclResolver.readableAuthors](../../../backend/src/main/java/com/superprogrammer/chat/service/internal/MemoryRecallAclResolver.java) 五路径：
  ① **owner** → 项目全部成员 user_id（含 DEPARTED，保交接；owner 无需 ACL 行兜底全读）
  ② **admin（recall_admin=false）** → ACL 授权集 ∪ {自己}
  ③ **member** → ACL 授权集 ∪ {自己}
  ④ **recall_admin=true admin** → 仍 ACL 集 ∪ {自己}（**契约：recall_admin 只多配权，不扩读**；配权边界 I2 判）
  ⑤ **非成员** → 空集（无项目读权；自己流水账走个人 scope 召回）
- **DEPARTED 保留**：曾授权 target / 曾在册成员离职后仍在结果集（保交接）；是否纳入召回由 L10 开关在 I3 过滤，本 resolver 不滤。
- **summary 不受 ACL 影响**（恒只读自己）——本 resolver 只管流水账读取范围。

### I1-4 运维埋点（随 chunk 当下埋）
- **可观测性**：`readableAuthors` 三分支各打 `log.debug`（含 projectId/reader/角色/recallAdmin/集大小/DEPARTED 标注），召回链 traceId 在 D 接入时串。
- **可回滚**：V49 建表无数据，DROP 即逆（注释附）。
- **配置开关（recall_admin）**：**非新 system_setting**——是 V47 已建的 `memory_project_members.recall_admin` 列，I1 只**读**它；"后台改" = I2 花名册端点暴露（本迭代不建端点）。运维清单「recall_admin 标记可后台改」由列 + I2 端点满足。
