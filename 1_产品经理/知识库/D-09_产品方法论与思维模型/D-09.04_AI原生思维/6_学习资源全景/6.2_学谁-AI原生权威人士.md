# 6.2 学谁 — AI原生权威人士对标图谱

## 1. Sam Altman

- **身份/头衔**：OpenAI CEO
- **国籍/归属**：美国 / OpenAI
- **核心成就**：领导ChatGPT从Wrapper到Agent的演进；推动AI产品从"聊天"到"做事"的范式转换
- **思维模型**："渐进部署"——先让AI上线、在真实使用中发现问题迭代，而非等完美再发布；"能力优先"——相信AI能力边界会持续扩展，PM应提前设计可扩展架构
- **行动范式**：极简公开沟通（博客+X）；产品先行、规范后置；用户真实场景验证优先于内部测试
- **可学习点**：如何在AI不确定性下做产品决策；如何用渐进式部署管理AI产品风险
- **代表作/演讲**：OpenAI DevDay 2023-2025演讲、个人博客samaltman.com
- **来源**：[📚训练知识]

## 2. Bret Taylor

- **身份/头衔**：Sierra AI联合CEO / 前Salesforce联合CEO / 前Facebook CTO
- **国籍/归属**：美国 / Sierra AI
- **核心成就**：创立Sierra——将AI Agent作为企业基础设施而非对话插件；系统化驾驭工程的商业落地
- **思维模型**："企业级AI=确定性基础设施"——AI产品不是卖聪明，是卖可靠；"护栏即产品"——护栏不是限制AI，而是产品本身的核心价值
- **行动范式**：从企业客户真实痛点出发设计Agent；SLA先行、功能后置；销售驱动产品定义
- **可学习点**：如何把概率性AI包装为企业愿意买单的SLA承诺；B端AI Native产品的商业化路径
- **代表作/演讲**：Sierra官网案例 / 多次a16z播客访谈
- **来源**：[📚训练知识]

## 3. Andrej Karpathy

- **身份/头衔**：前OpenAI创始成员/前Tesla AI总监 / Eureka Labs创始人
- **国籍/归属**：美国/斯洛伐克裔 / Eureka Labs
- **核心成就**：推动AI教育民主化；提出"Software 2.0"概念——软件从人写代码变为AI学数据
- **思维模型**："Software 2.0"——未来软件不是程序员写if-else，而是AI从数据中学习规则；"AI原生教育"——假设AI存在，教育应该长什么样
- **行动范式**：深度技术博客+YouTube长视频教学；从第一性原理出发解释AI；开源精神
- **可学习点**：理解AI Native的底层技术逻辑（Software 2.0）；用第一性原理思考AI原生
- **代表作/演讲**：YouTube "Let's build GPT"系列、博客karpathy.github.io、X @karpathy
- **来源**：[📚训练知识]

## 4. Aravind Srinivas

- **身份/头衔**：Perplexity AI CEO
- **国籍/归属**：美国/印度裔 / Perplexity AI
- **核心成就**：创立Perplexity——意图驱动的AI Native搜索；证明AI原生产品可以挑战Google搜索
- **思维模型**："答案即产品"——用户要的不是搜索结果，是答案；"引用是信任基础设施"——每个陈述必须可溯源
- **行动范式**：产品驱动增长（PLG）；用AI重构搜索这个品类而非做加法；快速迭代+社区反馈
- **可学习点**：如何用AI Native思维颠覆一个成熟品类；意图驱动产品的设计方法
- **代表作/演讲**：Perplexity产品迭代 / X @AravSrinivas
- **来源**：[📚训练知识]

## 5. Andrew Ng

- **身份/头衔**：DeepLearning.AI创始人 / 前百度首席科学家 / 前Google Brain负责人
- **国籍/归属**：美国/华裔 / DeepLearning.AI
- **核心成就**：AI教育民主化先驱；提出"AI是新电力"；推动AI应用从实验室走向产业
- **思维模型**："AI是新电力"——AI将像电力一样渗透所有行业；"数据>算法"——产品和业务理解比算法细节更重要
- **行动范式**：系统化课程+简明邮件通讯；将复杂AI概念翻译为商业语言；持续关注AI落地ROI
- **可学习点**：理解AI能力边界；将AI技术与产品语言桥接
- **代表作/演讲**：DeepLearning.AI课程 / The Batch邮件通讯 / X @AndrewYNg
- **来源**：[📚训练知识]
