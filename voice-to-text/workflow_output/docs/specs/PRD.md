## 一、产品概述

基于本地 AI 模型的实时语音转文字**桌面应用**，支持**麦克风输入**和**系统音频内录**，无需联网即可进行中英文语音识别。

## 二、功能特性

| 功能 | 说明 |
|------|------|
| **实时语音识别** | 边说边转，延迟低，支持中文和英文 |
| **麦克风输入** | 直接使用电脑麦克风进行语音输入 |
| **系统音频内录** | 识别电脑播放的音频（看视频、听播客时实时生成字幕） |
| **本地运行** | 语音模型完全在本地运行，**无需联网**，保护隐私 |
| **录音保存** | 可选同时保存为 WAV 音频文件 |
| **离线可用** | 首次下载模型后，无需网络即可使用 |

## 四、系统要求

- **操作系统**：Windows 10 / 11（64 位）；系统音频内录仅限 Windows
- **内存**：建议 4GB 以上（运行时约占用 300-600MB）
- **磁盘空间**：约 150MB（程序 25MB + 模型 100MB）
- **CPU**：支持 x64 的主流处理器即可，**不需要独立显卡**

## 五、验收标准（FR / AC）

> 追溯编号：FR = 功能需求，AC = 验收标准。开发时 plan Step 标对应 FR；测试用例名带 AC 号。

| 编号 | 需求 | 验收标准 |
|---|---|---|
| FR-001 | 麦克风实时识别 | AC-001：选麦克风设备 → 点开始 → 说话，文字 2 秒内出现 |
| FR-002 | 系统音频内录 | AC-002：选「[系统音频]」设备 → 播放音视频，实时生成字幕 |
| FR-003 | 离线运行 | AC-003：断网后首次以外启动可正常识别 |
| FR-004 | 录音保存 WAV | AC-004：勾选保存 → 停止后程序目录生成时间戳命名的 WAV |
| FR-005 | 模型加载容错 | AC-005：模型缺失时回退 mock 模式并提示，不崩溃 |

## 六、非功能需求

- **隐私**：所有语音数据仅在本地处理，不上传任何服务器，不收集用户数据。
- **性能**：流式识别延迟 < 2 秒；CPU 运行流畅，无需 GPU。
- **安装包体积**：不含模型 < 25MB。
