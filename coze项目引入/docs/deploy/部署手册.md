# 部署手册 · Coze 批量生图网页

> 项目：`coze项目引入`（Flask 单机应用：LLM 拆分批量文档 → 并行 Coze 工作流生图 → 按类别归档）
> 部署形态：**Windows 服务器 + 小圈子 IP 直连公网**（无域名 / 无 HTTPS / 无 Nginx）
> 版本：v1（2026-08-04）
> 对应流程：[Phase5_发布迭代.md](../../2_编程类可迭代workflow/Phase5_发布迭代.md)

---

## 0. 部署架构一览

```
小圈子用户浏览器
      │  http://<服务器公网IP>:5000
      ▼
┌─────────────────────────────────────┐
│  Windows 云服务器                    │
│  ┌───────────────────────────────┐  │
│  │ NSSM → Windows 服务            │  │  开机自启 + 崩溃自动重启
│  │   └─ python 2_对话网页.py      │  │
│  │       监听 0.0.0.0:5000        │  │
│  └───────────────────────────────┘  │
│  防火墙入站规则：放行 TCP 5000      │
└─────────────────────────────────────┘
      │  HTTPS 出站
      ▼
   智谱 GLM（/api/anthropic）  +  Coze 工作流 API
```

- **应用本身不存数据**：无数据库、无 Redis。状态在内存（重启即丢，结果图已落盘 `downloads/`）。
- **计算在云端 API**：服务器只做中转 + 图片处理，所以配置要求很低。

## 1. 服务器环境要求

| 项 | 最低 | 推荐 | 说明 |
|---|---|---|---|
| 操作系统 | Windows Server 2016 / Win 10 | Windows Server 2019+ | 需常驻运行，Server 版更适合；中文系统（字体 `msyh.ttc` 自带） |
| CPU | 1 核 | 2 核 | LLM/生图都在远端 API，本地 CPU 负载低 |
| 内存 | 2 GB | 4 GB | Pillow 处理大图 + 批量并发会吃内存；2GB 跑小批量够 |
| 磁盘 | 20 GB | 40 GB+ | 主要是 `downloads/` 归档图会持续增长，磁盘要留余量 |
| 网络 | 公网 IP | — | 必须有公网 IP 才能小圈子访问；带宽 1~5Mbps 够（图不大） |
| Python | 3.8.x | 3.8.x | **务必 3.8**，与本机开发环境一致（依赖已在此版本验证） |

> 选型参考：阿里云/腾讯云/华为云的**轻量应用服务器**（Windows 版）最划算，2C2G 约 60~100 元/月。

## 3. 傻瓜式部署步骤（Step 0 ~ 6，照着勾）

> 全程在**服务器**上操作。假设项目装在 `C:\app\coze`（下文以此为例，实际路径按你定的填）。

### Step 0 · 装 Python + NSSM

- [ ] **0.1 装 Python 3.8**：双击安装包，**勾选 "Add Python to PATH"**，装完打开 `cmd` 验证：
  ```
  python --version
  :: 应输出 Python 3.8.x
  ```
- [ ] **0.2 装 NSSM**：下载 nssm-2.24.zip，解压到 `C:\nssm\`（里面有 `win64\nssm.exe`）。把 `C:\nssm\win64` 加到系统 PATH，或后面用全路径调用。验证：
  ```
  nssm version
  ```

### Step 1 · 放代码 + 配置

- [ ] **1.1 拷代码**：把本机 `coze项目引入/` 整个传到服务器 `C:\app\coze\`。需要传的核心文件：
  - `2_对话网页.py`、`coze_token.py`、`llm_parser.py`、`chat.html`、`requirements.txt`
  - `docs/`（可选）
  - **不要传** `downloads/`（归档图，本地测试产生的）、`__pycache__/`、`application.yaml`、`private_key.pem`（这俩下一步单独放）
- [ ] **1.2 放敏感配置**（**不随代码公开传**）：
  - `application.yaml` → `C:\app\coze\application.yaml`，填智谱 API Key：
    ```yaml
    api_key: <你的智谱GLM-API-Key>
    ```
  - `private_key.pem` → `C:\app\coze\private_key.pem`（Coze OAuth 私钥，从 Coze 平台下载的那个）
- [ ] **1.3 核对 `coze_token.py` 里的常量**与你的 Coze 应用一致：
  - `CLIENT_ID = "<你的应用ID>"`
  - `KID = "<你的公钥指纹>"`
  - （这两个在代码里，部署时确认无误）

### Step 2 · 装依赖

- [ ] **2.1** 在 `C:\app\coze\` 打开 `cmd`，执行：
  ```
  cd /d C:\app\coze
  pip install -r requirements.txt
  ```
- [ ] **2.2 验证关键包**：
  ```
  python -c "import flask, requests, jwt, cryptography, PIL, yaml; print('依赖OK')"
  ```

### Step 3 · 本机试跑（先不公网，验证应用本身能起）

- [ ] **3.1** 启动（默认只监听 127.0.0.1）：
  ```
  python 2_对话网页.py
  ```
- [ ] **3.2** 服务器本机浏览器开 `http://127.0.0.1:5000`，能看到网页、页签正常。
- [ ] **3.3** 跑一条单图 + 一个小批量，确认 LLM 解析、生图、归档都通（这步会消耗 Coze/智谱额度）。
- [ ] **3.4** Ctrl+C 停掉，进入下一步。

### Step 4 · 开放公网端口

> 代码已改为支持环境变量 `HOST`。设 `HOST=0.0.0.0` 才会监听公网，否则只本机能访问。

- [ ] **4.1 Windows 防火墙入站规则**（放行 5000）：
  ```
  netsh advfirewall firewall add rule name="Coze生图-5000" dir=in action=allow protocol=TCP localport=5000
  ```
- [ ] **4.2 云控制台安全组**：在云厂商后台，给这台服务器加一条**入方向规则**：协议 TCP、端口 5000、来源（见下方安全建议）。

### Step 5 · 注册 Windows 服务（开机自启 + 崩溃重启）

- [ ] **5.1 建日志目录**：`C:\app\coze\logs\`
- [ ] **5.2 用 NSSM 注册服务**（在 `cmd` 管理员身份运行）：
  ```
  nssm install Coze生图 "C:\Python38\python.exe" "C:\app\coze\2_对话网页.py"
  nssm set Coze生图 AppDirectory "C:\app\coze"
  nssm set Coze生图 AppEnvironmentExtra HOST=0.0.0.0 PORT=5000 PYTHONUTF8=1
  nssm set Coze生图 AppStdout "C:\app\coze\logs\stdout.log"
  nssm set Coze生图 AppStderr "C:\app\coze\logs\stderr.log"
  nssm set Coze生图 AppRotateFiles 1
  nssm set Coze生图 AppRotateBytes 10485760
  ```
  > `python.exe` 的全路径以你实际安装位置为准（如 `C:\Users\<用户>\AppData\Local\Programs\Python\Python38\python.exe`）。
- [ ] **5.3 启动服务**：
  ```
  nssm start Coze生图
  ```
- [ ] **5.4** 设为自动启动（NSSM 注册的服务默认开机自启，可在 `services.msc` 里确认 `Coze生图` 启动类型为"自动"）。

### Step 6 · 公网验证

- [ ] **6.1** 用**你本机/手机**（非服务器）浏览器访问 `http://<服务器公网IP>:5000`，能打开网页。
- [ ] **6.2** 跑一个批量，确认从公网进来也能正常生图、归档。
- [ ] **6.3 重启服务器一次**，验证服务能自动起来（重启后等 1~2 分钟，再访问）。

## 4. 配置项说明

| 配置 | 位置 | 说明 | 默认 / 示例 |
|---|---|---|---|
| `HOST` | 环境变量（NSSM 里设） | 监听地址。本地 `127.0.0.1`；**公网必须 `0.0.0.0`** | `0.0.0.0` |
| `PORT` | 环境变量 | 端口 | `5000` |
| `BATCH_CONCURRENCY` | 环境变量 | 批量并行工作流数（Coze ≈5 QPS） | `3` |
| `PYTHONUTF8` | 环境变量 | 强制 UTF-8，避免中文乱码 | `1` |
| 智谱 API Key | `application.yaml` 的 `api_key` | 智谱 GLM Key（也支持 `LLM_API_KEY` 环境变量覆盖） | `<填>` |
| `LLM_BASE_URL` / `LLM_MODEL` | 环境变量（可选） | 覆盖 LLM 端点/模型，默认智谱 anthropic + glm-5 | — |
| `CLIENT_ID` / `KID` | `coze_token.py` | Coze OAuth 应用 ID + 公钥指纹 | `<填>` |
| `private_key.pem` | 同目录文件 | Coze OAuth 私钥 | 从 Coze 下载 |
| 水印文字 | `2_对话网页.py` 的 `WATERMARK_TEXT` | 归档低清图的水印 | `绘雅图研阁为您精心定制您` |
| 字体路径 | `2_对话网页.py` 的 `FONT_PATH` | 水印用字体，Windows 自带 | `C:\Windows\Fonts\msyh.ttc` |

> 敏感项（API Key / 私钥 / CLIENT_ID）**不要写明文进本手册**，上表用 `<填>` 占位，实际值单独安全存储。

## 6. 回滚方案

| 场景 | 操作 |
|---|---|
| 新版本有 bug，要回到上一版 | 1. `nssm stop Coze生图`<br>2. 把 `C:\app\coze\` 备份的旧代码覆盖回去（部署前务必备份整个目录）<br>3. `nssm start Coze生图` |
| 服务起不来 | `nssm start Coze生图`，看 `logs\stderr.log` 排错；常见：Python 路径错、依赖没装全、`application.yaml`/`private_key.pem` 没放 |
| 彻底下线 | `nssm stop Coze生图` → `nssm remove Coze生图 confirm` → 关闭安全组/防火墙 5000 端口 |

> **每次发新版本前**，先 `Copy-Item C:\app\coze C:\app\coze_backup_YYYYMMDD -Recurse` 备份。

## 7. ⚠️ 安全提醒（小圈子公网部署必读）

1. **本应用没有任何用户认证**：谁拿到 `http://IP:5000` 就能用，**会消耗你的 Coze 生图额度 + 智谱 LLM 额度**。小圈子用必须做下面之一：
   - **不公开地址**：IP:端口只告诉自己人（最简单）
   - **IP 白名单**：云安全组的 5000 入方向，来源限定为小圈子的固定 IP（推荐）
   - **加认证**：后续在代码里加 Basic Auth / token 校验（进 Phase 1/2 迭代）
2. **敏感文件单独放**：`application.yaml`（智谱 Key）、`private_key.pem`（Coze 私钥）**绝不随代码上传到公开仓库**——已写入 `.gitignore`，部署时手工放到服务器，不要进 git。
3. **Flask 开发服务器**：`app.run()` 是开发服务器，小流量够用；如果后续并发高或要求更稳，换 **Waitress**（Windows 友好的生产 WSGI）：`pip install waitress`，启动改 `waitress-serve --host=0.0.0.0 --port=5000 2_对话网页:app`。
4. **额度监控**：定期看 Coze / 智谱控制台的用量，避免泄露后被刷爆。

## 8. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 公网访问不了、本机能 | `HOST` 没设 `0.0.0.0`；或防火墙 / 安全组 5000 没开 |
| `启动工作流失败: authentication is invalid (code=4100)` | Coze token 失效，已做自愈（见 [开发进度_批量生图_01.md](../开发进度_批量生图_01.md)）；若仍持续，检查 `private_key.pem` / `CLIENT_ID` / `KID` 是否匹配 |
| LLM 解析报 401 | 智谱端点临时限流，已加退避重试；检查 `application.yaml` 的 `api_key` 是否正确/未过期 |
| 中文乱码 | 确认环境变量 `PYTHONUTF8=1`（NSSM 里已设） |
| 批量任务全失败 | 查 `logs\stderr.log`；多为额度耗尽或网络问题 |
