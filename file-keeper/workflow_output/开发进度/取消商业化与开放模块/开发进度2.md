## Step 12：移除管理后台商业运营入口

- Dashboard 只展示总用户、正常用户、禁用用户和活跃设备，不再展示待审核或权益到期指标。
- 用户列表删除待审核筛选、审批按钮、设备额度和离线缓存列；账号禁用/启用及确认弹窗保留。
- 用户详情删除额度设置、权益列表和授权弹窗；用户基本信息、设备列表和设备禁用保留。
- 删除匿名设备、权益、商业设置的页面与前端 API；服务端兼容接口不受影响。
- 侧栏只保留 Dashboard 与用户管理；认证区 catch-all 将旧收藏路由重定向到 Dashboard。
- 新增零依赖静态契约测试，防止商业页面、路由、字段或 API 被重新引入。
