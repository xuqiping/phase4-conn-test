# 资产库与画布第三轮问题修复 · 测试方案

> 覆盖 [plan](../plans/资产库与画布_第三轮问题修复.plan.md) C1-C7。联动用例对齐 plan「功能联动点清单」L1-L7，每条含正向/反向/批量边界。
> 自动化可断言部分走单测（见各 chunk 验证清单），本方案仅人工交互部分。

## 一、前置环境

- 后端 + 前端 dev 栈已起；`system_settings` 可访问（管理员）
- 双账号：admin（管理员/项目 OWNER）、user2（被授权 EDITOR）
- 演示画布：文本节点「主角1设定」→ 分镜节点（含「主角1拿起了剑」「主角10出场」）→ 图片/视频节点若干

## 二、功能联动用例（L1-L7）

### L1 框选集 → 工具条/属性面板联动（C1）
| # | 操作 | 预期 |
|---|---|---|
| L1-1 正向 | Shift+拖框套住 3 节点松开 | 3 节点高亮；顶部批量工具条出现；属性面板关闭 |
| L1-2 反向 | 框选后单击空白处 | 选集清空、工具条消失 |
| L1-3 半选 | 框选 3 个后再单击其中 1 个 | 回单选模式：面板打开、工具条消失 |
| L1-4 批量 | 框选 3 节点 → 工具条「批量删除」 | 二次确认列 3 节点名 → 确认后全删（含边），自动保存 |
| L1-5 回归 | 框选后直接按 Backspace（不经工具条） | 只走应用层删除流程一次，无双删/不静默删 |
| L1-6 输入守卫 | 聚焦提示词输入框按 Shift 拖动/Backspace | 不触发框选误删 |

### L2 一键关联写入 → @链路联动（C2）
| # | 操作 | 预期 |
|---|---|---|
| L2-1 正向 | 框选分镜节点 →「一键关联」 | 预览弹窗列「主角1→上游节点」替换明细；确认后文本中「主角1」变蓝 chip |
| L2-2 断链 | 关联后删除上游「主角1设定」节点 | 目标节点属性面板黄色断链 warn；运行降级注入【断链】 |
| L2-3 运行 | 点目标节点「生成」 | 插值注入上游产出，与手动 @ 效果一致 |
| L2-4 重复包装 | 文本已含 @{{node:x}} 的「主角1」再点一键关联 | 该区间不被二次包装 |
| L2-5 批量 | 同时框选分镜+文本+图片节点 | 仅文本类进提案；图片节点被列出「跳过」 |
| L2-6 无匹配 | 框选无上游/名字未出现的节点 | 不弹窗，message.info 说明原因 |
| L2-7 编辑中 | 目标节点面板打开改过文本未失焦 → 一键关联 | 按面板最新值计算，不丢未保存输入 |

### L3 批量生成 → 节点状态联动（C4）
| # | 操作 | 预期 |
|---|---|---|
| L3-1 正向 | 框选 3 图片节点 →「批量生成」 | 2 并发第 3 排队；进度条 n/m；全部完成回填预览+名字 |
| L3-2 失败隔离 | 其中 1 节点提示词非法/模型失效 | 仅该节点红标 errorMsg，其余照常完成 |
| L3-3 拓扑 | 选中含上下游依赖对（A→B，B @A） | A 先提交，B 后提交 |
| L3-4 反向·恢复 | 批量提交后立刻刷新页面 | resumePendingTasks 恢复全部节点轮询至终态 |
| L3-5 批量+单跑 | 批量进行中手动单跑另一节点 | 允许，共享并发闸，超限走退避/报 429 |
| L3-6 删除竞态 | 批量轮询中删除某节点 | stale-guard 不误写、不报错 |

### L4 并发闸 429 → 前端退避联动（C3/C4）
| # | 操作 | 预期 |
|---|---|---|
| L4-1 正向 | 上限 video=2，第 3 个视频提交 | 429 MEDIA_CONCURRENT_LIMIT；前端 1s/2s/4s 退避重试 |
| L4-2 补位 | 1 个完成 → 排队任务自动补上 | 无需人工干预 |
| L4-3 反向·关闭开关 | 完成终态重复回调 | 计数不二次扣减（不超卖） |
| L4-4 配置热更 | 管理员把 video 改 1 | 不重启，下一提交即生效 |

### L5 评分提交 → 双轨聚合联动（C6/C7）
| # | 操作 | 预期 |
|---|---|---|
| L5-1 正向 | OWNER 评 88、成员甲乙丙评 80/90/100 | 卡片显「拥有者 ★88｜成员均分 90 · 3人」，两轨互不混入 |
| L5-2 覆盖 | 成员甲改评 60 | 均分变 83.3（100→60），不新增计数 |
| L5-3 反向·开关关 | OWNER 关「成员打分」 | EDITOR 评分区消失；已有均分仍显示；OWNER 仍可评 |
| L5-4 权限 | VIEWER/公共池用户尝试评分 | 无入口；直接调 API 403 |
| L5-5 D4 保留 | 移除成员甲后看均分 | 其 60 分仍计入（保留参与均分） |

### L6 content_mode 切换 → 按钮显隐联动（C6/C7）
| # | 操作 | 预期 |
|---|---|---|
| L6-1 正向 | OWNER 切 PERSONAL | 二次确认；EDITOR 视图里他人内容的编辑/删除/定稿按钮立即消失，自己的保留 |
| L6-2 反向·可逆 | 切回 SHARED | 全员 EDITOR 恢复全编辑，数据无损 |
| L6-3 OWNER 豁免 | PERSONAL 下 OWNER 操作任意资产 | 全权不受影响 |
| L6-4 半选边界 | PERSONAL 下 EDITOR 对他人资产直接调 API | 403「仅能管理自己上传的内容」 |

### L7 created_by 回填 → 上传者徽标联动（C5/C7）
| # | 操作 | 预期 |
|---|---|---|
| L7-1 正向 | 迁移后打开任意项目 | 全部资产卡片有「上传者」徽标；文件类=真实上传者 |
| L7-2 存量近似 | 旧文本类资产 | 显示 owner（历史无创建者，近似值），文档已注明 |
| L7-3 新建路径 | PERSONAL 下成员上传/入库/复制新资产 | created_by=操作者，徽标即时正确 |
