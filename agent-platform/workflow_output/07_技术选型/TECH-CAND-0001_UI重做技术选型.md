## 一、候选评估（六个决策点）

### D1 书法字体方案

| 候选 | 评估 | 结论 |
|---|---|---|
| 霞鹜文楷 LXGW WenKai（SIL OFL）+ fonttools 子集化自托管 | 行楷气质、屏幕可读、许可干净、子集可控 | **采用** |
| 商用书法字体（汉仪/方正） | 授权费+Web 授权限制 | 否决（成本/合规） |
| 系统字体栈（楷体 KaiTi） | 零加载但 Windows/macOS 渲染差异大、无飘逸感 | 否决（品质不可控） |
| 全量 WebFont 不子集 | LXGW 全量 woff2 ≈ 8–15MB，不可接受 | 否决 |

### D2 图片资产格式与管线

| 候选 | 评估 | 结论 |
|---|---|---|
| AVIF 主 + WebP 回退（`<picture>`） | 体积最优；Vite 静态导入即可，无新依赖 | **采用** |
| 仅 WebP | 兼容性已无忧但体积略大 | 回退层保留 |
| PNG/JPG | 体积超标（基线 ≤200KB） | 否决 |

### D3 动效方案

| 候选 | 评估 | 结论 |
|---|---|---|
| 纯 CSS transition/animation + Vue `<Transition>`（现状延续） | 零新依赖、天然响应 reduced-motion、transform/opacity 不触发重排 | **采用** |
| GSAP | 功能过剩，包体 +30KB | 否决 |
| WebGL 生成式水墨 | 方向 C 元素，已明确留二期 | 否决（本期） |

### D4 Naive UI 接管方式

| 候选 | 评估 | 结论 |
|---|---|---|
| `n-config-provider :theme-overrides` 按 `[data-theme]` 计算值（GlobalThemeOverrides） | 官方机制，覆盖全部组件语义色 | **采用**（补齐现状缺失层） |
| CSS 变量硬覆盖 Naive 内部类 | 脆弱、升级即碎 | 否决 |
| 换组件库 | 成本巨大无收益 | 否决 |

### D5 纹理实现

| 候选 | 评估 | 结论 |
|---|---|---|
| 程序化 SVG `feTurbulence` 噪点（宣纸/墨晕纹理） | 零资产体积、分辨率无关、可调参 | **采用**（ART-ASSET-0007 改程序化） |
| AI 生成纹理图 | 平铺接缝风险、体积 | 备选 |

### D6 图标

| 候选 | 评估 | 结论 |
|---|---|---|
| 沿用 @vicons/ionicons5 | 已全站使用，风格中性不冲突 | **采用** |
| 自绘水墨 SVG 图标集 | 一致性差、工作量大 | 否决（仅 Logo 印章走 ART-ASSET-0006） |

## 三、选型结论（TECH-0001）

技术栈零变更：Vue 3.4 + Vite 5 + Naive UI 2.38 + SCSS。新增构建期工具仅 `fonttools`（子集化脚本，不进运行时）；新增运行时依赖为零。退出方案（EXIT-0001）：双主题为纯增量 `[data-theme]`，回滚=切回旧主题名，无数据迁移、无 API 变更。

## 四、成本与许可

- 许可证：LXGW WenKai SIL OFL 1.1（可商用，随包附许可副本）；思源黑体系沿用系统栈/Noto，OFL。
- 开发成本：主题层 3–4 天 + themeOverrides 2 天 + 字体管线 1 天 + 组件状态核对 2–3 天 + 资产接入 1–2 天 ≈ **1.5–2.5 周**（与竞案一致）。
- 运行成本：字体 +200–400KB（一次性，可缓存）；背景图 +400KB 内；无新增常驻 JS。
