## 关键实现口径（排障速查）

- **取价链**：resolveRule 命中行不变 → 行内 `token_price_per_resolution[normalize(res)]`，未配/null/脏 → `price_input_per_million`（通用价），全空 → 0 元交付（口径钉死）；fallback 命中无参考行时槽取**该行**的，不跨行。
- **三态防坑**：前端 TOKEN 行**恒发** `tokenPricePerResolution` 对象（全空档=`{}`）——省略字段会被后端「null=不动」吞掉清空操作；实体 `FieldStrategy.ALWAYS` 防 MyBatis-Plus 跳过 NULL 更新。
- **归一双侧同函数**：存储侧 canonicalizeTokenSlots 与结算侧 `PricingService.normalizeResolution`（4K→4k）。
- **est ≠ 槽位**：`est_per_resolution`（¥/秒，预检）与 `token_price_per_resolution`（¥/百万，扣费）同表同形态不同义。
