# 支付渠道配置（管理员）

> 入口：侧栏「支付渠道」。配好后用户才能在「我的钱包」自助充值。

## 操作

1. 进入支付渠道页，新增/编辑渠道（如支付宝、微信、模拟支付）。
2. 填渠道密钥等参数——**密钥只写不读**（保存后不回显明文，留空 = 不修改）。
3. 启用渠道 → 用户「我的钱包」右上角出现「充值」按钮。

## 安全须知

- 密钥只在本页填，别发群、别截图、别提交进 git。
- 测试环境可开「模拟支付」渠道：用户端走完整入账链路但无真实扣款，适合验收流程。
- 未开通任何渠道时，用户端不显示充值按钮（走管理员人工代充）。

## 异常排查

- 用户支付后订单长时间「待支付」：查渠道回调配置；对账区「支付渠道异常」有线索。
- 用户已扣款但订单已关闭：核实单号后走「积分充值」人工补等额积分并备注订单号。
