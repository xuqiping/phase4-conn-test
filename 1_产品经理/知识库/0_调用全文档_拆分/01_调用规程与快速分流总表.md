# 拆分01 · 调用规程与快速分流总表

> 来源：0_知识库调用全文档.md（一、二章）｜ 路由：0_路由.md

## 一、调用规程（怎么用这份文档）

**知识库结构**：每个维度（D-XX）下有若干子项（D-XX.YY），每个子项标准含 6 个模块：

| 模块 | 内容 | 何时调用 |
|---|---|---|
| `1_知识库概览/` | 是什么、核心能力清单、边界 | 需要先理解该领域全貌时 |
| `2_知识库引用场景/` | 触发词、典型问题、不适用分流、相邻维度 | **精确定位场景时先读它** |
| `3_AI精炼版/` | **核心知识正文**（3.1~3.x 碎片文件） | **每次调用必读**，先读其中 `0_模块路由.md` 再按场景跳 3.x |
| `4_可落地流程/` | SOP、Agent 提示词、模板、检查清单 | 用户要"怎么做/给我流程/给我模板"时追加 |
| `5_业内顶级案例/` | 真实案例拆解 | 用户要"案例/谁做过/对标"时追加 |
| `6_学习资源全景/` | 书单/课程/社区 | 用户要"怎么学/推荐资源"时追加 |

**调用四步**：
1. 用「二、快速分流总表」按用户输入的关键词锁定 1~3 个候选维度；
2. 用「三、分维度调用明细」锁定子项（D-XX.YY），并注意"分流提示"排除易混淆子项；
3. 加载文件：先读 `D-XX_维度名/D-XX.YY_子项名/3_AI精炼版/0_模块路由.md`，再按需加载 3.x 正文文件（本文档已列出每个子项的全部正文文件名）；
4. 需要 SOP/模板/案例/资源时，追加同子项的 `4_` `5_` `6_` 模块。

**结构差异备忘**：
- D-06.06 归因分析、D-06.07 实验与A/B、D-06.08 AI辅助数据分析 的 `3_AI精炼版/` 只有单一"理论全景"文件；
- D-19.11 的 `3_AI精炼版/` 有两个 3.2 文件并存（AIGC标识 / 越狱攻击），调用时两个都要加载；
- D-04.04、D-04.05 的场景路由文件名为 `2_知识库引用场景/0_引用场景.md`（非 0_模块路由.md）；
- D-02 各子项场景路由为"场景速查表+引用链"格式，无显式触发词段，以场景表述为触发依据。
