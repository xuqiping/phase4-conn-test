# 4.2 定价SOP与模板（含博弈话术库）

## SOP-1：定价方法选型SOP

### 适用场景
新品从零定价、产品重新定价、商业模式迁移需重新选定价方法

### 步骤

| 步骤 | 动作 | 产出 | 负责人 |
|---|---|---|---|
| 1 | **差异化评估**：列出产品独有功能/体验/服务/品牌差异化点 | 差异化评估表 | PM + 市场 |
| 2 | **市场同质化评估**：调研竞品功能矩阵，客户是否感知差异 | 竞品对比矩阵 | PM |
| 3 | **走选型决策树**：差异化→价值定价 / 同质化→竞争定价 / commodity→成本定价 | 方法选型结论 | PM + 商业化 |
| 4 | **AI成本评估**（如适用）：评估推理成本量级，确定成本底线 | AI成本底线测算 | PM + 技术 |
| 5 | **混合策略判断**：是否需要成本底线+价值锚定混合 | 混合策略说明 | PM |
| 6 | **方法可演进路径**：从当前方法→目标方法的迁移路径 | 演进路径图 | PM + 商业化 |

### 关键决策点
- 步骤3是核心决策点：差异化评估不充分时不得走价值定价——"我能在别处更便宜拿到"是价值定价失败的头号信号
- 步骤4 AI产品必须做：AI推理成本不做的产品会在重度用户上亏钱

## SOP-2：价值量化SOP

### 适用场景
B端定价谈判准备、价格页价值传递、续费ROI证明

### 步骤

| 步骤 | 动作 | 产出 | 负责人 |
|---|---|---|---|
| 1 | **确定价值锚点**：省了多少(成本节省)/赚了多少(增量收入)/替代了什么(TCO对标) | 价值锚点选择 | PM |
| 2 | **收集客户基线数据**：向客户获取人力成本/效率基线/转化率基线 | 客户数据清单 | 销售 + PM |
| 3 | **选择量化方法**：ROI测算(效率型)/TCO对标(替代型)/愿付价测试(新品) | 方法选择 | PM |
| 4 | **套用量化模板**：填写ROI计算表或TCO对比表 | 量化结果表 | PM |
| 5 | **保守原则校验**：增量收入取行业下限，成本节省只算可验证部分 | 校验记录 | PM |
| 6 | **产出销售弹药包**：量化表+一页价值证明话术 | 销售弹药包 | PM + 销售 |

### 关键原则
- **只算客户认可的数字**——用客户自己的基线数字，不编造行业平均
- **保守原则**——宁可低估不可高估，让客户觉得"实际可能更好"
- **时间维度明确**——标清年化/月化/项目周期

## SOP-3：价格敏感度测试SOP（PSM）

### 适用场景
新品定价探索、价格调整前验证市场接受度

### 步骤

| 步骤 | 动作 | 产出 | 负责人 |
|---|---|---|---|
| 1 | **准备展示物**：产品Demo/功能清单/ROI说明，确保客户了解价值后再答 | 展示物 | PM |
| 2 | **设计PSM问卷**：4个标准问题(太便宜/便宜/贵/太贵) | 问卷 | PM + 用研 |
| 3 | **确定样本**：100-200名目标客户，覆盖不同分层 | 样本计划 | 用研 |
| 4 | **执行调研**：在线问卷/深度访谈/客户拜访 | 调研数据 | 用研 |
| 5 | **绘制四线交叉图**：计算OMC/上下限/IDP四个交叉点 | PSM交叉分析图 | PM + 数据 |
| 6 | **解读价格区间**：OMC为定价中心参考，上下限定义可探索区间 | 价格区间建议 | PM |
| 7 | **A/B验证**（如可能）：在OMC和上限间做A/B测试验证真实转化 | A/B测试报告 | PM + 增长 |

### 关键原则
- **先展示价值再问价格**——不展示价值的PSM结果系统性偏低
- **分层分析**——不同客户分层可能给出不同价格区间，需分别解读

## SOP-4：定价谈判博弈SOP

### 适用场景
B端大客户定价谈判、续费涨价谈判、竞品对标谈判

### 步骤

| 步骤 | 动作 | 产出 | 负责人 |
|---|---|---|---|
| 1 | **准备弹药包**：ROI表+TCO对比表+差异化拆解+竞品公开价格 | 谈判弹药包 | PM + 销售 |
| 2 | **预测异议类型**：预判客户可能异议(太贵/竞品便宜/预算/要请示) | 异议预测清单 | 销售 |
| 3 | **匹配话术策略**：为每类异议匹配话术模板 | 话术方案 | PM + 销售 |
| 4 | **设计让步条件**：预设让步阶梯+对应条件(年付/多年/案例/增购/预付) | 让步条件矩阵 | PM + 销售 |
| 5 | **谈判执行**：先立价值锚→报价→回应异议→有条件让步→逼单 | 谈判记录 | 销售 |
| 6 | **复盘**：记录实际异议vs预判、让步幅度vs预设、最终成交价vs目标 | 谈判复盘表 | PM + 销售 |

### 关键原则
- **先立价值再谈价格**——不先展示价值就报价=让客户在"不了解价值"时判断价格
- **不无条件降价**——每次让步必须换条件，否则价格锚崩塌
- **不把价格当唯一筹码**——用实施/培训/SLA/案例等非价格价值替代降价

## 模板-1：ROI计算表

```
| 维度 | 当前状态(无产品) | 使用产品后 | 年化价值 |
|---|---|---|---|
| 人力成本 | [X人×Y万/年] | [减少到Z人] | 省[W万] |
| 效率损失 | [月均N工时浪费] | [降至M工时] | 省[Q万] |
| 错误返工 | [年损失R万] | [降至S万] | 省[T万] |
| 增量转化 | [基线] | [+P%转化] | 增收[U万] |
| **总收益** | - | - | **[V万]** |
| 产品年费 | 0 | [A万/年] | -[A万] |
| 实施分摊 | 0 | [B万/年] | -[B万] |
| **总投入** | - | - | **[C万]** |
| **ROI** | - | - | **[V/C×100%]** |
| 回本周期 | - | - | **[约N个月]** |

填写说明：
- [X人×Y万] 须用客户真实人力成本，不编造
- [+P%转化] 须标来源(行业基准/同类客户案例)，取保守下限
- 实施分摊按一次性费用/预期使用年限折算
```

## 模板-2：TCO对比表（3年）

```
| 成本项 | 方案A(如:自建)3年 | 方案B(如:SaaS)3年 | 差额 |
|---|---|---|---|
| 采购/订阅 | [X万] | [Y万(Z万/年)] | [差额] |
| 服务器/云资源 | [X万] | [Y万] | [差额] |
| 开发团队 | [X人×Y万×3] | [0或少量] | [差额] |
| 运维 | [X万] | [Y万] | [差额] |
| 实施/集成 | [X万] | [Y万] | [差额] |
| 升级/技术债 | [X万] | [0或少量] | [差额] |
| 停机/效率损失 | [X万] | [Y万] | [差额] |
| **3年TCO** | **总计** | **总计** | **总差额** |

填写说明：
- 隐性成本(技术债/停机/效率损失)不可省略——这是TCO对标的核心价值
- SaaS方案不能假设零间接成本——集成/培训/运维仍存在
```

## 模板-3：PSM测试问卷

```
在了解产品功能与价值后，请回答以下4个问题：

Q1. 太便宜：什么价格让你觉得产品质量可能有问题，不会购买？
  □ ¥____ /月

Q2. 便宜：什么价格让你觉得划算、性价比高，愿意购买？
  □ ¥____ /月

Q3. 贵：什么价格让你觉得贵，但仍然会考虑购买？
  □ ¥____ /月

Q4. 太贵：什么价格让你觉得太贵，绝对不会购买？
  □ ¥____ /月

附加信息：
- 您所在的团队规模：□ 1-10 □ 11-50 □ 51-200 □ 200+
- 您的岗位层级：□ 执行层 □ 管理层 □ 决策层
- 您目前是否在使用类似产品？□ 是(产品名:___) □ 否

执行说明：
- 展示物：先展示产品Demo+功能清单+ROI说明(5-10分钟)，再让客户答题
- 样本量：至少100-200份有效问卷，覆盖不同团队规模与岗位层级
- 分析：将4个答案做累积分布曲线，绘制4条曲线的交叉点
```

## 模板-4：价格页设计模板（三档）

```
┌─────────────────┬─────────────────┬─────────────────┐
│   基础版        │   专业版        │   企业版        │
│   ¥99/月        │   ¥299/月       │   ¥999/月       │
│   (年付¥990)    │   (年付¥2990)   │   (年付¥9990)   │
├─────────────────┼─────────────────┼─────────────────┤
│ ✓ 功能A         │ ✓ 基础版全部    │ ✓ 专业版全部    │
│ ✓ 功能B         │ ✓ 功能C         │ ✓ 功能E         │
│ ✓ 5GB存储       │ ✓ 功能D         │ ✓ 功能F         │
│ ✓ 社区支持      │ ✓ 50GB存储      │ ✓ 无限存储      │
│                 │ ✓ 邮件支持      │ ✓ 专属客户成功  │
│                 │                 │ ✓ SLA保障       │
│                 │                 │ ✓ 私有部署      │
├─────────────────┼─────────────────┼─────────────────┤
│   [免费试用]    │  [最受欢迎 ★]   │   [联系销售]    │
└─────────────────┴─────────────────┴─────────────────┘

设计原则：
- 锚定效应：先展示高价企业版→专业版显得划算
- 诱饵效应：基础版功能少到"不够用"→推专业版；企业版贵到"不需要"→留专业版
- 尾数定价：¥99/¥299/¥999而非¥100/¥300/¥1000
- 默认年付：年付价格高亮，月付需主动切换
- "最受欢迎"标记：利用社会认同引导选择中间档
```

## 模板-5：博弈话术库（N.04专项）

### 5-1. 客户说"太贵了"——价值证明话术库

| 客户表达 | 话术模板 | 关键变量 |
|---|---|---|
| **真贵（预算不够）** | "理解您的感受。当前每月因[效率损失]的成本约[X万]，产品年费[Y万]，[Z个月]回本后全年净省[W万]。这不是花钱，是赚钱。" | [X万]客户月损失 [Y万]年费 [Z]回本月数 |
| **谈判策略（不给理由）** | "价格背后是价值。让我们看看——[功能A]解决[痛点1]，[功能B]解决[痛点2]，ROI约[N%]。这个投入和回报的比例，您觉得合理吗？" | [N%]ROI数字 |
| **竞品更便宜** | "竞品确实有不同的定价。关键区别在于——[竞品没有的独有功能/服务/SLA]。如果您只用[基础功能]，竞品可能够用；但您提到需要[高级需求]，这正是我们的差异化所在。" | 独有功能列表 |
| **要回去请示** | "理解。我准备了一份一页的ROI摘要和TCO对比表，方便您向上汇报。如果领导有疑问，我可以安排线上答疑。" | 一页ROI摘要 |

### 5-2. 让步话术库（有条件降价）

| 让步条件 | 话术模板 | 权限 |
|---|---|---|
| **换年付** | "如果改为年付，可以给到8折，相当于免费多用2.4个月。" | 销售自主 |
| **换多年合约** | "签2年7折，3年6折。锁定长期合作我们才好给这个力度。" | 需审批 |
| **换案例授权** | "如果愿意做标杆客户案例（含logo+数据），可申请特别折扣+免费实施支持。" | 需审批 |
| **换增购** | "如果加购[模块B]，整体方案可享[X折]组合优惠。" | 销售自主 |
| **换预付** | "预付6个月可享9折，预付12个月8.5折。" | 销售自主 |

> **铁律**：让步必须换条件。客户不同意任何条件→不降价。宁可失去订单也不无条件降价——一次无条件降价会让客户认为你还有空间，且会在行业内传播你的底价。

### 5-3. 紧迫话术库（基于真实信息）

| 紧迫类型 | 话术模板 | 真实性要求 |
|---|---|---|
| **促销到期** | "早鸟价到[具体日期]截止，之后恢复原价¥[X]。" | 必须有真实促销计划 |
| **涨价预告** | "下季度产品将调价，现在锁定可按当前价格续费[1年]。" | 必须有真实涨价计划 |
| **名额限制** | "标杆客户计划名额仅剩[N]个，含1对1实施支持和[额外权益]。" | 必须有真实名额限制 |
| **财年节点** | "我们财年[月]底前签约有额外[X%]折扣，这是内部考核节点。" | 必须有真实内部政策 |

> ⚠️ **红线**：紧迫话术必须基于真实信息。虚构"明天涨价""仅剩1个名额"被客户发现后，信任永久受损，且涉嫌欺诈。

### 5-4. 逼单话术库（临门一脚）

| 场景 | 话术模板 |
|---|---|
| **客户已认可价值但拖延** | "王总，方案已匹配您的需求——[功能A]解决[痛点1]，ROI约[N%]。如果今天确定，实施团队下周启动，[X周]内上线。年付还是月付？我帮您优先排期。" |
| **客户在两个方案间犹豫** | "基于您的需求[核心需求]，我建议[方案A]，因为[理由]。方案B是[区别]。我们先按方案A推进，后续可根据实际使用灵活调整。" |
| **客户说"再考虑考虑"** | "理解。为了帮您更好地考虑，我梳理了三个关键点：①[价值点] ②[差异化点] ③[紧迫理由]。您看还有什么顾虑我可以现在解答？" |

### 5-5. 博弈红线速查

| 红线 | 说明 | 违反后果 |
|---|---|---|
| 不撒谎 | 不编造竞品价格/虚构促销/谎称最低价 | 信任永久受损，涉嫌欺诈 |
| 不无条件降价 | 每次让步换条件 | 价格锚崩塌，客户继续压 |
| 不贬损竞品 | 说"竞品做不到X"而非"竞品很差" | 显得不专业，引发客户反感 |
| 不第一轮报底价 | 留让步空间但第一口价合理 | 报太高客户跑了/报太低没空间 |
| 不只靠价格 | 用实施/培训/SLA/案例替代降价 | 陷入价格战，利润蒸发 |
