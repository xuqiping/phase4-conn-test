> 1. **设置入口仅 admin**：非 admin 不显示「设置」菜单，路由守卫 `requireAdmin` 重定向（详见下方「设置入口权限」）。
> 2. **「我的模型」Tab 已下线**：SettingsView 移除 `my-models` Tab；后端 `LlmGateway.findProvider` 停用用户级 override（chat 一律走全局）。`UserProviderTab.vue` / `UserLlmController` / `user_llm_providers` 表保留不删（备用）。

> 4. **项目级模块开关**：`frontend/src/config/modules.ts` 的 `ENABLED_MODULES` 控制各模块是否展示；Agent大厅/工作流/执行监控本项目关闭（含 admin 隐藏）。

## 设置入口权限（10x-3）
- 菜单层：`Sidebar` 仅当 `isModuleEnabled('settings') && authStore.isAdmin` 才显示「设置」入口。
- 路由层：`/settings` 路由 `meta.requireAdmin=true`，`accessGuard.resolveRouteAccess` 非 admin 重定向默认落地页。
- 默认落地页：`defaultLanding()` 选首个启用模块（原硬编码 `/agents`，10x-5 后 /agents 已关闭会白屏，故改为 `/chat`）。

## 项目级模块开关（10x-4/10x-5）
- 真相源：[`frontend/src/config/modules.ts`](../../frontend/src/config/modules.ts)
  - `ENABLED_MODULES`：模块布尔开关；Agent大厅/工作流/执行监控本项目 `false`（对所有人隐藏含 admin）。
  - `MODULE_PERMISSION_MAP`：模块→权限码（agent:read/workflow:read/media:gen 等），无权限码模块仅受开关控制。
- 消费方：`Sidebar.canSeeModule`（菜单显隐）、`accessGuard.resolveRouteAccess`（路由守卫）。
- 恢复某模块：把对应布尔改 `true`，菜单 + 路由 + 入口同步生效，不改代码逻辑。

## rag-memory 设置字段（VO `RagMemorySettingsVO`）
- `enabled`：记忆总开关（false=opt-in）。
- `processMode`：`ASYNC`（默认，全异步）/ `HYBRID`（同步即时冲突追问）。
- `retrievalMode`：`LLM_FULL_CONTEXT`（全量灌入 LLM）/ `EMBEDDING_VECTOR`（query embed → pgvector top-K，仅注入相关，无命中不注入）/ `VECTOR_KEYWORD`（向量+关键词 hybrid + LLM 兜底）/ `LLM_KEY`（**V38**，anchor 锚点语义两阶段，百万 key 推荐）。详见 [09-个人记忆·检索模式](09-个人记忆与冲突解决.md)。
- `keyLanguage`：注入上下文 key 展示语言 `EN`（默认）/ `ZH`（key_zh，空回退英文）/ `BOTH`（中英并列 `key_zh(key)`）。
- `fullContextThreshold`：仅 `LLM_FULL_CONTEXT` 生效，记忆 > 阈值改三维合并筛（key × key_zh × block，一次 LLM；默认 20，0=禁用）。
- `keywordPerBlockThreshold`：仅 `VECTOR_KEYWORD` 生效，关键词召回 per-block_label 阈值（默认 10，0=禁用）。
- `llmKeyCoarseTopN`（**V38**）：仅 `LLM_KEY` 生效，向量+BM25 RRF 融合后保留粗筛候选数（默认 40）。
- `llmKeyRerank`（**V38**）：仅 `LLM_KEY` 生效，粗筛 top-N → LLM 三维精排（key × key_zh × block，一次调用）开关（默认 true，false 直接注 top-N）。
- `keywordMax`（**V38**）：关键词通道单次最大召回块数（默认 8，0=不限），替后端 `KEYWORD_MAX` 硬编码。
- 设置走 `system_settings` KV 表 upsert，**无 Flyway 迁移**（检索模式变更见 V38 新增 anchor 列）。

## knowledge.excel.* 解析阈值（Excel 多Sheet导入，V39/V40，无 Flyway）
> 走同款 `system_settings` KV upsert。仅影响 `.xlsx/.xls` 解析（[14-知识库RAG-基础](14-知识库RAG-基础.md)）。非法/缺失回退默认。

- `knowledge.excel.col-threshold`（默认 10）：列数 > 此值 → 宽表行流兜底（markdown 表保不住列对齐）。
- `knowledge.excel.row-chunk-size`（默认 200）：每 Section 最大行数（防超大 section）。
- `knowledge.excel.cell-max-chars`（默认 200）：单 cell 文本截断长度（尾部加 `…`）。
- `knowledge.excel.max-rows-per-sheet`（默认 5000）：单 sheet 行数硬上限（截断防 OOM，写 `parse_warning`）。
- `knowledge.excel.preview-max-sheets`（默认 50）：预读端点 `POST /sheets/preview` 返回 sheet 名上限（防恶意巨多 sheet 文件）。
