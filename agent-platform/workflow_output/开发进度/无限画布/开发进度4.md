## 本轮做了什么

### C4 文本节点 + 图片节点上传（IC-2/IC-3 起步）

- **CanvasNodeRunnerService** [canvas/service/CanvasNodeRunnerService.java](../../../backend/src/main/java/com/superprogrammer/canvas/service/CanvasNodeRunnerService.java)：按 `CanvasNodeDTO.type` 分发生成。`runText`→`LlmGateway.chat`，产出 `outputText` 内联进 dataPatch（文本小不落 stored_files）。`runImage` MVP 抛 provider 未配话术（R-3 待生图 provider）。
- **NodeRunResult** [canvas/dto/NodeRunResult.java](../../../backend/src/main/java/com/superprogrammer/canvas/dto/NodeRunResult.java)：无状态回包（`dataPatch` 前端合并，不碰 snapshot 读写，零 JSONB 竞态）。
- **CanvasController** +`POST /{id}/nodes/run` +`POST /{id}/upload`（落 `SOURCE_CANVAS`，走 `loadOwned` 归属咽喉点）。
- **CanvasService.loadOwned** 提 public（写侧端点复用同一归属校验）。
- 前端 `CanvasView.onRunNode` → 置 running → 调 runNode → 合并 dataPatch → scheduleSave（800ms 节流）。`onUploadFile` → 上传 → `fetchCanvasPreview` 拉 blob 转 objectURL 预览。

### C5 视频节点（IC-4，复用 media API）

- `onRunVideo` 直连既有 `mediaApi.submitVideo`（`media:gen` gated，无权 submit→403→节点 FAILED，plan 安全清单「各自权限」）。
- 5s 轮询至终态（`isTerminal`）→ SUCCEEDED 时 `fetchVideoBlob`（带 auth 拉 blob→objectURL）预览。
- `taskId`/`mediaStatus` 入快照（加载时 `hydrateVideoPreviews` 按 taskId 重取预览）；`previewUrl` 会话级，`onSave` 剥离（blob: URL 跨会话失效）。

### C6 音频节点（IC-5 MVP）

- 上传复用 `/canvas/{id}/upload`（accept audio/*）+ `<audio>` 播放器。
- TTS/音乐生成 provider 待接入（doubao TTS / 音乐模型），属性面板占位禁用按钮。

### C7 脚本节点批量分镜（IC-6）

- `CanvasNodeRunnerService.runScript` → `LlmGateway.chat` 拆分镜。
- `parseScenes` 容错：剥 ```json 围栏 → 取首个 `[..]` 子串 → Jackson 解析 `[{index,description}]`；全失败兜底单条原始剧本（不阻断）。
- 批量分镜图生成（R-7 限流）待生图 provider（R-3），本步只拆文本分镜。

### C8 连线数据流 + edges 持久化（IC-7）

- `CanvasBoard` 暴露 `getEdges`/`getNodes`/`getNode`/`updateNodeData`。
- `resolveUpstreamImageFileId`：`onRunVideo` 沿入边找上游 image 节点 `fileId` 作 `refFileId`（图生视频自动联动；手动 refFileId 优先）。
- edges 随快照整存整取（`getSnapshot` 含 edges），C2 起已通；本轮补数据传递语义。

### C9 一键重跑（IC-9，拓扑 + 环检测）

- `topoSort`（Kahn 入度 + 邻接表）：入度 0 入队 → 出队减邻居入度。`order.length < nodes.length` ⇒ 存在环 → 报错（plan R-6）。
- `onRerunAll`：按拓扑序串行跑可生成节点（text/script/video；image/audio 上传型跳过）。
- 编辑器头加「重跑全链」按钮（`RefreshOutline`）。

## 踩坑批注

| 坑 | 解 |
|---|---|
| `/api/files/{id}` 需 auth header，`<img>/<audio>/<video src>` 无法带 → C4 图片直链预览坏 | `fetchCanvasPreview`/`fetchVideoBlob` 走 axios 拉 blob→`URL.createObjectURL`（会话级，保存剥离、加载重取） |
| 视频 `previewUrl` 是 blob: objectURL，入快照跨会话失效 | `onSave` 剥 `previewUrl`；`taskId`/`mediaStatus` 入快照，`loadCanvas` 按 taskId `hydrateVideoPreviews` 重取 |
| LLM 分镜输出带 ```json 围栏或解释文字 | `parseScenes` 剥围栏 + 取首个 `[..]` 子串 + 兜底单分镜 |
| 节点运行改 snapshot 会竞态 | Runner 无状态回 `dataPatch`，前端合并 + 节流整存（不改 JSONB 读写） |
