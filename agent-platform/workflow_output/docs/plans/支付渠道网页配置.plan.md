# 支付渠道网页配置 实现计划（7x 追加，2026-08-21）

> 来源：用户拍板「支付密钥由 admin 在网页自填，不再只走环境变量」。
> 范围切割：**只做配置管理**（加密落库/脱敏回显/审计/双端页面）；支付宝/微信 SDK 真实下单验签实现不在本计划（商户号到位后另起，渠道类 available() 维持 false，填了配置也不会把未实现的渠道暴露给用户）。

## 拍板决策

1. 密钥**整体 AES 加密**落库（复用 `AesEncryptService`，与 LLM 供应商 Key 同管线）；**不明文存任何字段**。
2. 脱敏回显列 `config_tails`（每字段 `****尾4位`），读取永不解密明文出端点。
3. 填表**留空=保持原值**（后端 merge 既有配置再校验全集），避免「改一个字段要重填全部」。
4. 每渠道必填键白名单：ALIPAY=appId/privateKey/alipayPublicKey；WECHAT=mchId/appId/apiV3Key；其余键 400。
5. 新权限码 `payment:config`（V144 授 admin）；写操作 @AuditLog。
6. env 变量保留：SDK 实现落地时解析顺序 = DB 优先、env 兜底（本次只落 DB 读写，解析桥 `getDecrypted()` 一并写好+单测）。

- `billing/controller/PaymentChannelAdminController.java`：GET `/api/billing/admin/payment-channels`（脱敏列表）、PUT `/{channel}`（保存，channel 白名单 ALIPAY/WECHAT）。
