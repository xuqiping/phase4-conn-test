## 四、遗留风险与验点提示

- M2/M3 落点手感：判定用**不吸附坐标**，组边缘 12px pad 内落点归属组——若实测手感有争议（想 quick-add 却成组边），记录落点截图反馈。
- Chrome 下 WS close code 4401 在 onclose 可见——若某浏览器代理吞 code 导致回退登录路径不走，按 N4 记录浏览器型号。
- M5/M6 积分消耗：聚合/广播会放大输入量，预估/余额闸门兜底，但请人工确认预估数字符合预期（组 2 成员≈双份输入）。
