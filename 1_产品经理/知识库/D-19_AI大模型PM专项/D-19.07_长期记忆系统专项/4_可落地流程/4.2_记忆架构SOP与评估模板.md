# 4.2 记忆架构设计 SOP + 评估看板模板 + 参数调优清单

## 一、记忆架构设计 7 步 SOP

| 步 | 动作 | 输出 | 红线 |
|---|---|---|---|
| **1. 场景画像** | 明确产品类型/场景/用户规模/是否多 Agent/是否高合规垂类/是否出海 | 场景画像卡 | 缺项必追问，不臆测 |
| **2. 分层架构定** | 4 级分层（工作/短期/长期/外部）+ 反射层；定每层装什么、生命周期 | 分层架构图 | 长期记忆不可省略 |
| **3. 编码与 CRUD-M 选型** | 向量/KG/原文/混合 + add/update/merge/delete/ignore 五操作设计 | 选型决策表 | CRUD-M 缺一不可 |
| **4. 检索与遗忘策略** | 检索(召回+重排+衰减+置信)+遗忘(分级+保护关键事实)+污染防护 | 策略清单 | 关键事实(身份/法律)不衰减 |
| **5. I.20 参数初值** | top-k/相似度/衰减/置信度权重/写入触发/容量上限初值+调参依据 | 参数表 | 每参数必须给推理依据 |
| **6. I.09 红线+黄金集** | 准确率/召回/时延/增长率/误删率/一致性红线 + 黄金集构建思路 | 红线表 + 黄金集 | 误删率<0.5%红线硬约束 |
| **7. 隐私合规通过** | 数据最小化+用户可控+被遗忘权+跨境自查（联动 D-19.06） | 合规自查表 | 高合规垂类必法务复核 |

## 三、I.20 参数调优清单

| 参数 | 起点 | 调优方向 | 监控指标 |
|---|---|---|---|
| top-k 召回数 | 10 | 召回率不足→上调；token 成本高→下调 | Recall@k / token/次 |
| 相似度阈值 | 0.75 | 精度不足→上调；漏召多→下调 | 准确率 / 召回率 |
| 衰减系数 λ | 0.05 | 偏好近期→上调；历史平等→下调 | 一致性 / 用户感知 |
| 置信度权重 α | 0.3 | 验证记忆优先→上调；纯相似度→下调 | 准确率 |
| 写入触发 | 半严格 | 库膨胀→收紧；漏信息→放松 | 增长率 / 召回率 |
| 容量上限 N | 500/用户 | 不易遗忘→上调；强制淘汰→下调 | 增长率 / 误删率 |
| 重排 top-N | 5 | 不够准→下调；漏召→上调 | 准确率 / 时延 |
| 重排模型 | bge-reranker | 精度优先→Cohere；成本优先→bge | 准确率 / 成本 |
| 遗忘周期 | 周扫 | 清理不及时→缩短；省资源→延长 | 误删率 / 增长率 |
| 冲突合并策略 | 时间优先 | 强一致→置信度优先；用户控制→用户裁决 | 冲突率 / 一致性 |
| 检索时机 | 每轮固定 | 省 token→按需；质量优先→固定 | token 成本 / 召回率 |
| 隔离粒度 | 用户级 | 多 Agent→Agent 级；调试→会话级 | 串扰数 |

> 调参铁律：**每次只调 1-2 个参数**，用黄金集回归（参考 D-19.05）；改动记录留痕可回滚。
