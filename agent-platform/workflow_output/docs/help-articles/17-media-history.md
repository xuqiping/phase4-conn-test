# 生成历史翻页、参考图放大预览、图片缓存

> 适用于：视频生成页 / 图片生成页的「历史」区和参考图区。

## 一、历史记录翻页

1. 历史区底部有页码条（如「共 3 页 23 条」）。
2. 点页码翻页；点「10/页」可改每页条数（10/20/50）。
3. 在筛选框输提示词或选时间范围 → **自动回第 1 页**按条件查。
4. 点「清空」恢复全量。

**小细节**：
- 改每页条数导致原页码越界 → 自动回第 1 页（正常）。
- 点历史行回填参数后，页码不跳走；再翻页表单内容也不清空。
- 筛选无结果显示「无匹配的历史任务」，清空筛选即恢复。

## 二、参考图放大预览

| 操作 | 效果 |
|---|---|
| 悬停小图约 0.3 秒 | 右侧弹出大图浮层（快速划过不触发，防误触） |
| 鼠标移开 | 浮层消失 |
| 单击小图 | 全屏黑底灯箱看大图 |
| 点空白 / 按 Esc / 点 ✕ | 关闭灯箱 |

**视频页专属**：参考视频悬停可静音预览；单击弹独立播放弹窗（带播放条）。弹窗只看不改表单，关掉表单原样。

## 三、图片缓存（自动生效，无需操作）

- 同一张图第二次出现（历史回填、翻页回来）**秒出**，不重复下载。
- 图片被更新过会自动拉新图，不会看到旧图。
- 缓存有上限（约 80 张），满了自动淘汰最久没看的——图片偶尔变慢属正常。

## 常见异常

| 现象 | 原因 | 恢复 |
|---|---|---|
| 参考图裂开/不显示 | 文件被删或无权 | 重新从资产库选或重传 |
| 悬停不出浮层 | 停留太短或预览加载失败 | 稍停留；显示「预览未加载」= 该图拉取失败 |
| 历史列表空白 | 筛选太严 | 点「清空」 |
