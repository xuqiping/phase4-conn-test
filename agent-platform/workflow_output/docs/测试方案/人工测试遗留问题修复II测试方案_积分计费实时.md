> 来源：plans/人工测试遗留问题修复II_{A,D,E}*.plan.md 联动点清单逐条对齐 + 规格 §1.6/§2.6/§4.5/§5.5/§6.5/§3.5。
> 自动化可断言部分已走单测（收口 250/250），不在本文。本文=必须人介入的钱路径门槛 + UI 联动用例。
> 环境：本地（admin/admin123，DB psql agent_platform；两浏览器/双无痕窗模拟 A/B 端）。

## 一、钱路径门槛用例（不过不许验收）

### T1 组池不足补差复演（A，7x-2 原话）
1. 组长建组拉成员，组池充 4000；成员提交 15s 1080P **有参考**视频（预估 3750，HOLD 占用）。
2. 结算前把组池耗到 **< 550**（组长再提交任务或调低组池）。
3. 结算到账（实际 4300+）后核对四处：**组流水两条**（HOLD 转 + 差额腿）、成员「已使用」=**实耗**（非 3750）、账单该条 = 实耗、组长个人余额/欠款含差额腿（组长扣 550 或挂 DEBT）。
4. **反向**：组池富余时结算 → 无差额腿，成员 used 仍 = 实耗（回归 A 前行为）。

### T2 闲时价全链（D，§5.5）
1. 管理员配闲时窗 22:00–08:00（周末同段），闲时输出价 < 忙时。
2. 闲时窗内聊天一轮 → **预期**：消耗按闲时价（对照钱包流水金额）。
3. **边界①**：闲时缓存价/闲时输入留空 → 用输入价/缓存价回落（行为=改前）。
4. **边界②**：跨 22:00 在途回答 → 按结算时刻价（多退少补）。
5. 改闲时配置保存 → 下一轮对话即时生效（无需重启）。

### T3 缓存 token 计价（D，§6.5）
1. 同会话连问两轮（第二轮命中 Provider 缓存）→ **预期**：第二轮总积分明显更低；消息 DONE 文案含「缓存命中 N」。
2. **反向**：价表不配缓存价（留空）→ 计费与 V159 前完全一致（缓存腿消失）。
3. 检查 llm_usage_logs.cached_tokens > 0 且钱包/账单金额三腿（输入/输出/缓存）对得上。

### T4 价表去分辨率（D，§4.5）
1. 价表配置新增 Cdance2.0 → **预期**：只有「有参考/无参考」两行，无 480P/720P 下拉。
2. 存量（V160 迁移后）→ 每模型至多两行最新价；提交视频估价/结算正常。
3. 导入含 resolution 的旧导出文件 → 字段被忽略不报错。

### T5 实时推送（E，§3.5）
1. A 页面挂着（任意登录页），B 端/admin 给 A 充值 → A 顶栏个人徽标**秒跳**（无刷新）。
2. 组内成员提交任务 HOLD → 组长与成员两侧组池徽标、组页 used **即时变**。
3. 断网 10s（DevTools offline）期间 B 端扣分 → 恢复 → 退避重连后余额**自动补齐**正确。
4. **反向**：未登录/过期 token 连 `ws://…/ws/events` → 握手拒绝（无广播）。
5. **压测（人工）**：真浏览器 50 连接 × 100 事件/秒级别连发 → 无掉线、徽标不卡（单测级 5000 帧已过，此为真 WS 栈验证）。

## 二、对账下钻（A，§2.6）

1. 账单「项目组对账」tab 选一个**账平组** → 该组完整行可见、状态「平」、顶卡合计=该组数值。
2. 清空筛选 → 回默认「仅异常组」视图。
3. 开「显示全部组」→ 全组行可见、异常行标红；**边界**：选了具体组时开关无效（单组优先）。

## 三、功能联动用例（对齐联动清单，含反向/边界）

### A 计划（5 条）
- L-A1 补差组腿失败 → 差额扣组长（或挂 DEBT）；组长侧失败**不影响**成员 used 计入（反向）。
- L-A2 成员 used +差额=实耗，quota 耗尽不卡（无条件加）。
- L-A3 对账 tab 组筛选 → 顶卡合计=该组；清筛选回全平台。
- L-A4 includeAll 开关 → 全组行含正常组；带 groupId 时开关无效（边界）。
- L-A5 存量回填后对账 crossDiff 不变（回填只动 used，人工抽查一行仍平）。

### D 计划（6 条）
- L-D1 闲时开关切换 → 全部文本计费即时换价；跨边界在途按结算时刻（反向）。
- L-D2 缓存价留空 → =输入价；cachedTokens=null 缓存腿整体消失。
- L-D3 带分辨率存量在途任务结算 → 命中通用行兜底（迁移回归）。
- L-D4 去分辨率后新增价表 → 每模型至多 2 槽位（有/无参考）；TOKEN est 输入仍在。
- L-D5 cachedTokens 进 DONE → 聊天显示「含缓存命中 M」；null 省略（半选边界）。
- L-D6 est 偏差 tag → 近 7 天样本 ≥3 才显（|偏差|≥5%），无历史隐藏。

### E 计划（6 条）
- L-E1 个人余额任何变动 → 个人徽标秒级（纯 store 无请求）；推送失败下次变动/刷新校正（反向兜底）。
- L-E2 组池变动 → 组徽标+组页卡片秒级；MEMBER 事件只驱动组页、徽标读 GROUP（边界）。
- L-E3 断线重连 → loadWallet+loadGroups 全量补拉；退避封顶 30s；登出即停（反向）。
- L-E4 token 刷新 → 不主动重连（偏差口径）；下次断连携新 token 重连。
- L-E5 页面不可见 → 列表重查跳过；徽标仍更新（store 内存操作，边界）。
- L-E6 支付回调到账 → 徽标秒级；**多端登录全部收到**（双浏览器同账号验证，批量边界）。
