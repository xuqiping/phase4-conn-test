## A2 画布空白右键菜单（commit 9d9140fc）

- **实现**（[CanvasBoard.vue](../../../frontend/src/components/canvas/CanvasBoard.vue)）：
  - 根 `@contextmenu.prevent` 升级为 `onRootContextMenu`：closest 判定 `.vue-flow__node`/`.vue-flow__edge`/`.canvas-board__toolbar`/`.canvas-board__groupbox` → 只拦默认不开菜单（节点右键=现状「存资产库」emit 链不叠加；**组框分支=plan 细化1 先立**，D1 组框点选落地后接组级操作）；空白 → 记 clientX/Y + project 换算 flow 落点后开菜单。
  - 菜单两组项：**添加节点** 7 类（`PALETTE_ITEMS` 单源，icon+label）＋**画布操作**（粘贴/撤销/重做/一键整理=工具条同 handler 纯入口，零新逻辑）。范式照 FlowCanvas overlay：全屏透明层左键他处关；右键他处=冒泡根 handler **挪位置不叠两层**（spec ⑦）。
  - **落点**：添加节点=`addNode({type, position: 右键点 flow 坐标})`（节点落在右键处非随机）；粘贴=`pasteSubgraph` **落点参数化** `atClient?`（菜单传右键点；键盘 Ctrl+V 不传，维持修复VI「鼠标位置>视口中心」口径）。
  - **Esc 逐层退**（Lightbox R7 口径）：window 捕获监听+stopPropagation——菜单开着 Esc 只关菜单，不清画布多选/不关 n-modal；关闭即摘监听 + onUnmounted 兜底摘（修复X P4 教训：路由切走不残留）。
  - 无障碍：role=menu/menuitem、aria-disabled、disabled 态实时跟随（canUndo/canRedo/clipboard/nodes.length）。
- **测试**（[CanvasBoard.test.ts](../../../frontend/src/components/canvas/CanvasBoard.test.ts) 新增 describe 8 用例）：①开菜单结构（11 项/role/空态全禁用）②添加落点=右键坐标 ③四类 closest 分支不开菜单 ④粘贴落点=bbox 中心锚同式断言（planPastePositions 同式计算，锁「落点=右键点」契约）⑤撤销/整理接线 disabled 实时 ⑥Esc 双向（开着拦截外层 document 收不到/关后放行）⑦右键挪位+左键关 ⑧卸载摘监听不吞 Esc。
- **踩坑沉淀**：vitest 原生 dispatchEvent 后 v-if 卸载是异步渲染——DOM 断言前须 `await nextTick()`（trigger 自带，原生派发不带）。
