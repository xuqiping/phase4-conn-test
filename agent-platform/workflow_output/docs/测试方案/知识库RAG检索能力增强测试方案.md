# 知识库RAG检索能力增强 测试方案

> Phase 3 功能级预处理产出。来源：[plan 联动点清单](../plans/知识库RAG检索能力增强.plan.md) L1-L8 + 各 WP 子计划手测剧本。
> 原则：单测/集成可断言项不进本表（见各 WP plan 验证汇总）；本表只列**必须人工介入**项：UI 交互、真实 LLM/VLM 效果、检索体感。

## 用例编号规则

- S 系列对应 WP 手测剧本；L 系列对应主计划联动点（含反向/半选/批量边界，逐条对齐）。

## 一、L 联动用例（全量对齐主计划 L1-L8）

| # | 操作步骤 | 预期 | 边界（反向/半选/批量必测） |
|---|---|---|---|
| L1 | 库内 A《差旅制度》B《术语表》建边 MUST_CITE(A→B)→问差旅问题 | 回答同时引用 B，证据带「🔗 关联带出」徽标 | ①删边后再问：B 不再出现；②给无 B 读权的成员问：B 静默不出现且**无报错**；③A、B 都被独立命中：B 只出现一次 |
| L2 | 建边 MUST_BE_CITED(A→B)后只问命中 B 的问题 | A 强制出现 | ①已有 MUST_CITE(B→A) 时再建此边：被拒并提示「等价关联已存在」；②删掉新边后原 MUST_CITE(B→A) 不受影响 |
| L3 | 附件模式传图片（AUTO 描述）→问图中内容→**再上传新版本换图**→重问 | 首答含图中信息+📎；换图后回答基于新图 | 旧版本视觉缓存不串（回答不再含旧图细节） |
| L4 | 保密库开 ON：成员问带附件/关联命中问题 | 回答正常含注入内容；引用无下载钮 | owner 同问题全程不受限；成员直调 asset 403 |
| L5 | 库换 embedding 模型→重建索引 | 附件描述向量/图片向量一并重生成 | 重建过程检索可用（旧索引）；取消重建中途停止可再续 |
| L6 | 连接器同步的文档在源端删除 | 本地文档转 ISOLATED 不召回 | ①源端恢复→下轮同步自动复活；②「源删同步删」开→走治理删除；③连接器本身删除→本地文档保留变普通文档 |
| L7 | 问「总结一下这个库」 | 走全局分支：概览段+要点段+文档级引用《标题》 | ①混合问题「总结库并说明 X 细节」：三段结构齐全；②多库同选：提示已取首库 |
| L8 | 关闭 rag.contextual.llm.enabled 后传新文档→检索调试看 embed 文本 | 无 LLM 定位语（纯规则前缀） | 存量 LLM 版文档检索照常；重开开关→新文档恢复定位语 |

## 二、S 系列人工验证（按 WP）

### WP1 关联与附件
- S1：术语表 MUST_CITE 差旅制度全链（=L1 正向）。
- S2：附件模式传架构图+描述「系统部署图」→问「网关部署在哪」→回答引用图中信息+📎 原件可下载（owner）；首次慢（VLM 实时）二次快（缓存）。
- S3：文本附件（长 txt 20k 字）→命中注入显示「已截断，原件可下载」标注。
- S4：关联建议页出现共召回 ≥3 次的文档对→采纳→边列表出现。

### WP2 多轮检索
- S5：列表题故意只召回部分章（构造短上下文预算）→trace/调试面板显示 round1 补检索→三章齐。
- S6：拒答类问题两轮仍缺→INSUFFICIENT 文案与基线一致（无行为漂移）。
- S7：常规单点问题 trace rounds=0（调试面板无轮次记录）——零回归体感确认。

### WP3 上下文嵌入
- S8：新文档索引→检索调试 embed 文本含「定位语+原文」结构。
- S9：小库「应用 LLM 上下文增强」重建→确认框成本预估数字合理→完成后检索质量体感对比。
- S10：影子对比报告（选库）人工确认 Recall/MRR 增益后默认开关裁决。

### WP4 全局问答
- S11：=L7。
- S12：50+ 文档库全局问题延迟 <30s，超时降级提示出现（可构造大库验证）。

### WP5 多模态
- S13：传产品截图（AUTO 识图）→问「这个界面哪里改配置」→图被召回且引用带缩略图。
- S14：库配不支持图输入的 embedding 模型→图片照常入库仅文本路（无报错，配置提示可见）。

### WP6 连接器
- S15：建 URL 连接器指向静态测试站点→立即同步→文档出现「🔌」→可被检索。
- S16：二轮同步：改 1 增 1 删 1→本地对应更新/新增/ISOLATED（=L6 正向）。
- S17：坏地址连接器→ERROR 红标+脱敏错误摘要→修好→恢复 ENABLED。
- S18：内网地址（http://192.168.x.x / http://localhost）保存或同步被拒，错误提示不含内网明文（脱敏 ***）。

## 三、前置条件

- 模型：embedding（qwen3-vl-embedding）、VLM 识图、rerank 均已配置启用。
