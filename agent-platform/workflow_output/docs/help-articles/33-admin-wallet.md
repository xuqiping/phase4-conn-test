# 人工充值（管理员）

> 入口：侧栏「积分充值」。手动给用户加积分（内测/补偿/赠送/补单）。

## 操作步骤

1. 按用户名/ID 搜到目标用户 → 点「充值」。
2. 填积分数量（或金额，按当前比例折算）。单次上限 1 亿积分。
3. 填**备注**（可空，如「8月内测补偿」）——落在流水「来源说明」里方便查账。
4. 确认 → 用户余额立即增加，流水记一条「管理员发放」。

## 防重复到账（放心重试）

- 充值表单每次打开自动生成一把幂等键：**双击、网络重试、刷新重发，同一笔只到账一次**。
- 不确定有没有充成功？**直接重试是安全的**——余额不会翻倍。
- 看到「幂等键冲突」提示：刷新页面重发即可（极罕见）。

## 充错了怎么办

目前没有「撤销充值」按钮：给对方做一笔反向调整（或联系更高权限管理员处理），并记好流水备注。
