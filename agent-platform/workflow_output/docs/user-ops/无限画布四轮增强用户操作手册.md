# 无限画布四轮增强 · 用户操作手册

> 2026-08-18。8 项增强：断网韧性/节点宽高/批量依赖调度/图片翻转与标注/@参考预览/关联高亮/连线左右/节点组。
> 技术侧见 [Feature Map](../feature-map/无限画布四轮增强.feature-map.md)。

## 1. 长任务/断网不再误报「服务不可达」

**入口**：任意画布生成任务进行中（图片/视频节点「生成中」态）。

**行为**：
1. 生成中把网络断了或服务慢——**不会**再弹红色「服务不可达」，也不会被踢出登录；最多看到「后台任务网络波动，恢复后自动重试」。
2. 网络恢复后任务自动续跑，状态最终回填到节点。
3. 生成中切到别的标签页再切回来——立即查一次任务进度，不用等下一个轮询周期。

**注意**：你自己主动点的操作（保存/提交/上传）连续失败仍会正常报错断路——豁免只给后台自动轮询。

## 2. 拖拽改节点宽高

**入口**：画布 → 单击任意节点（出现选中框）→ 节点四角出现拖柄。

**步骤**：按住任一角柄拖动 → 宽高实时变 → 松手完成。点画布空白处取消选中（柄消失）。

**界面变化**：图片节点图 100% 自适应不裁切；文本类内容超高出内部滚动条；最小 160×64（拖到极限卡住）。

**完成标志**：点「保存」→ 刷新页面 → 宽高还原。

## 3. 批量生成按上下游顺序跑

**入口**：框选 ≥2 个节点 → 顶部批量工具条 → 「批量生成」。

**步骤与预期**：
1. 有连线关系的节点：**上游成功后下游才提交**；进度浮条显示「等待上游 N」。
2. 上游失败 → 下游自动标灰「上游失败，已跳过」，不报错弹窗；级联下游同样跳过。
3. 选中的下游但其上游不在框选里 → 标灰「上游不在本次批量选集中」。
4. 互不依赖的分支并行跑（同时 2 个）。
5. 浮条「停止调度」= 未启动的不再提交，已提交的照跑。

## 4. 图片翻转/旋转

**入口**：点选有源图的图片节点 → 属性面板操作区五个按钮：↔ 水平翻转 / ↕ 垂直翻转 / ⟳ 旋转 90°/180°/270°。

**步骤**：点按钮 → 稍候 → 画布上原图右侧出现新图节点（名字如「图片·水平翻转」），自动连线回原图。

**完成标志**：新节点带预览图；原图不变（源图不可变，翻转变换都产新图）。手机竖拍图会先自动转正再翻转。

## 5. 彩色框选标注 + AI 修改

**入口**：点选图片节点 → 属性面板「彩色标注」。

**步骤**：
1. 在弹层图上按住拖出一个框；松手后右侧色板选色（8 色），框下输入框写指令（如「这里加一个杯子」，≤200 字）。
2. 可画多个框（≤8）；可改色、删框；拖很小的框自动丢弃。
3. 预览实时显示合成效果（半透明色块+序号徽标）。
4. 两个出口：
   - **生成标注图** → 产「源名·标注」图节点+连线，无 AI。
   - **AI 修改** → 先产标注图节点，再自动建下游 AI 图节点（提示词已写好=参考图1原图+参考图2标注图+逐框指令清单）。若源节点已选模型则自动提交生成；没选模型会提示你选好再点运行。

**完成标志**：标注图/AI 出图节点出现在画布并连线。

## 6. @引用的参考图/视频预览

**入口**：图片/视频节点的属性面板 → 提示词里 @ 上游图/视频节点（或已设首/尾帧）→ 面板出现「参考」区。

**步骤**：直接看「参考」区——每条引用一张缩略：徽标=首帧/尾帧/图1/图2/视频1（与提交时发给模型的序号一致）；鼠标悬浮放大；点击图片进全屏（点空白关闭），点击视频进播放弹窗。

**界面变化**：在提示词里增删 @，参考区列表实时跟着增减。

## 7. 关联高亮 + 只看关联

**入口**：点选任一节点。

**步骤**：
1. 选中即高亮：该节点全部上下游连线变主色加粗带辉光；无关节点半透明。
2. 右下工具条点 🔗（「只看关联」）→ 无关节点直接隐藏（布局不动）；再点恢复。
3. 框选多个节点 = 以整组求关联并集。

**完成标志**：点空白处全部还原。

## 8. 连线左进右出

无操作——新连线自动横向（左侧输入、右侧输出）。存量老画布打开也自动变横向，中点「×」删除按钮、选中红色高亮照常可用。

## 9. 节点组

**入口**：框选 ≥2 个节点 → 批量工具条「设为组」。

**步骤**：
1. 输入组名（如「角色设定组」，≤30 字）→「建组」→ 画布出现彩色虚线包围盒（组名+人数），成员节点带同色描边。
2. 拖动成员 → 包围盒实时跟随。
3. 点包围盒上的组名 → 改名；点 ✕ → 解散（节点不删）。
4. 成员再选进新组 → 自动移出旧组；旧组被掏空自动解散；删除成员节点组自动减员。
5. **下游 @ 组员**：下游节点提示词输 @ → 候选列表按组分节（彩色点+组名）——组内任一成员是你的上游，整组成员都能 @（含非直连的组员）；没有成员连到你的组不出现在候选。

**完成标志**：建组 → 保存 → 刷新 → 组还原；老画布打开零报错。

## 常见异常与恢复

| 现象 | 原因 | 处理 |
|---|---|---|
| 批量后部分节点灰标 | 上游失败或上游不在选集 | 看节点悬停提示原因；重跑上游后再批量，或把上游一起框选 |
| AI 修改没自动出图 | 源节点未选图片模型 | 点 AI 节点 → 属性面板选模型 → 点「AI 生图」 |
| 建组按钮点了没反应 | 框选少于 2 个有效节点 | 重新框选 ≥2 个节点（工具条出现即够） |
| 建组提示「组成员上限 50」 | 一次框太多 | 分批建组 |
| 参考区视频缩略一直「…」 | 后台拉取失败（网络/文件） | 稍候重进属性面板；任务本身不受影响 |
| 拖柄拖不动 | 节点未选中或正在缩到最小值以下 | 先单击选中节点；最小 160×64 是下限 |

## 六轮增补（2026-08-25）
- **@标注图的具体框**：标注图生成后，在下游节点提示词里敲 @，候选里会出现「标注图:序号1-红色」这类子项——选它就是在引用标注图的具体某一框，直接接着写「改为 xxx」即可（旧标注图没有颜色明细，显示为「序号N框」）
- **AI 修改即时可见**：彩色标注→AI 修改后，标注图节点和「·AI修改」节点会立刻一起出现并自动开始生成（修复了之前要删掉标注图才能看到生成节点的问题）
- **生成图更干净**：AI 修改现在会明确告诉模型不要把标注框和序号画进结果图
