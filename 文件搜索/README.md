# 文件搜索工具 Pro

一个功能强大的Python图形界面工具，支持多种搜索模式。

## 功能特性

- 现代化图形用户界面
- **三种搜索模式**：
  - 搜索文件内容
  - 搜索文件名/目录名
  - 混合模式（同时搜索内容和名称）
- 多线程并发搜索，效率大幅提升
- 支持 Excel (.xlsx) 文件搜索
- 递归搜索子目录
- 支持按文件扩展名过滤
- 快捷文件类型选择按钮
- 实时显示搜索进度和百分比
- 显示匹配内容位置（行号/单元格）
- 支持停止搜索
- 结果导出功能
- 结果高亮显示

## 安装依赖

```bash
pip install -r requirements.txt
```

或者单独安装：

```bash
pip install openpyxl
```

## 使用方法

1. 运行程序：
   ```bash
   python file_searcher.py
   ```

2. 选择要搜索的目录

3. 输入要搜索的内容

4. 选择搜索模式：
   - **搜索文件内容**：仅在文件内容中查找
   - **搜索文件名/目录名**：仅匹配文件或目录名称
   - **混合模式**：同时搜索文件内容和名称

5. （可选）选择文件类型：
   - 使用快捷按钮（全部/文本/Office/代码）
   - 或手动输入扩展名，如：`py,txt,md,xlsx`

6. 点击"开始搜索"

7. 搜索完成后可点击"导出结果"保存结果

## 依赖

- Python 3.x
- tkinter（通常随 Python 一起安装）
- openpyxl >= 3.1.0（用于 Excel 文件支持）
