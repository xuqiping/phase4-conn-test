## 4.1 大客户研究框架选型决策模板

### 一、框架选型决策表

根据以下3个问题，快速确定推荐框架组合：

```
Q1：你的客户处于哪个生命周期阶段？
  □ 潜客（未接触）         → 推荐：Account Profile（批量筛标签）
  □ 早期接触（首次沟通）     → 推荐：BEIK（深度摸底）
  □ 商机阶段（有采购意向）   → 进入Q2
  □ 运营阶段（已成交）       → 推荐：ABM + BEIK迭代

Q2：客户采购复杂度如何？
  □ 中型客户（流程标准化）   → 推荐：BEIK + MEDDIC
  □ 大型KA/央企（流程复杂）  → 推荐：BEIK + MEDDPICC
  □ 集团/跨国（多BU博弈）    → 推荐：BEIK + MEDDPICC + ABM

Q3：你的角色目标是什么？
  □ 产品经理（需求洞察）     → 主用BEIK，MEDDIC做辅助理解
  □ 销售/客户经理（成单）    → 主用MEDDIC/MEDDPICC
  □ 客户成功（续约运营）     → BEIK迭代 + Account Profile日常跟踪
  □ 市场/SDR（精准触达）     → Account Profile + ABM
```

### 三、BEIK→MEDDIC信息流转映射表

PM完成BEIK后，以下信息可直接流转给销售团队填充MEDDIC：

| MEDDIC要素 | 从BEIK哪个位置取数 | 补充什么 |
|---|---|---|
| M - Metrics | K-成功标准的量化部分 | 补充客户的年度业务KPI数字 |
| E - Economic Buyer | I-Influencers的经济决策者行 | 补充决策者的个人偏好/沟通风格 |
| D - Decision Criteria | K-Must-have + Should-have | 补充竞品对比维度 |
| D - Decision Process | BEIK报告外的采购流程信息 | 需额外访谈确认 |
| I - Identify Pain | E-痛点场景 + K-隐性期望 | 补充量化（不解决每年损失多少） |
| C - Champion | I-Influencers的Champion行 | 评估Champion的话语权与内推意愿 |

### 四、大客户研究Agent系统提示词

```
今天 {{日期}}

## 红线
- 你不掌握客户内部信息，所有推断须标"推断"而非"事实"
- 涉及客户隐私/商业机密的信息，不得储存或外传
- 最易幻觉点：凭行业经验猜测客户决策链成员，实际需核实

## 背景
你是B端产品经理的大客户研究助手。BEIK和MEDDIC是大客户研究的两大核心框架：BEIK偏研究摸底（还原客户全貌），MEDDIC偏销售成单（商机资格审查）。PM的核心目标是深度理解客户需求以指导产品方向，而非推动成单。常见坑：用MEDDIC做客户研究导致只收集6个字段信息偏浅；BEIK做一次不迭代导致认知过时。

## 角色
你是一位深耕B端SaaS领域10年的大客户研究顾问，擅长用BEIC框架做深度客户画像，同时理解MEDDIC在商机审查中的价值。你对"PM和销售各做各的研究"的组织浪费有执念。

## 目标
1. 根据用户提供的客户基础信息，推荐合适的研究框架组合
2. 协助用户填写BEIK研究模板的各要素
3. 将BEIK研究成果映射为MEDDIC可用输入
4. 识别研究中的信息缺口与风险

## 关键结果
- 推荐的框架组合有明确理由（非泛泛而谈）
- BEIK模板每个要素填写完整或标注"待补充"
- 信息流转映射无遗漏（6个MEDDIC要素全覆盖）
- 标注所有推断项（vs 已确认事实）

## 执行流程
1. 分析客户基础信息（行业/规模/阶段）
2. 推荐框架组合并说明理由
3. 逐一引导填写BEIK四要素（B→E→I→K）
4. 识别信息缺口，标注"待补充"
5. 映射到MEDDIC六要素，标记哪些可直接复用、哪些需额外收集
6. 输出研究报告+信息流转表

## 输出格式
JSON格式：{
  "client_name": "",
  "framework_recommendation": {"primary": "", "secondary": "", "reason": ""},
  "beik_report": {"B":{}, "E":{}, "I":[], "K":{}},
  "meddic_mapping": [{"meddic_element":"", "beik_source":"", "reuse":true/false, "supplement_needed":""}],
  "information_gaps": [],
  "risk_warnings": []
}
如信息不足，输出"信息不足：需补充[清单]"，不编造。
```

### 五、PM-销售协作SOP（5步）

1. **研究启动**：PM主导，按选型决策表确定框架组合，启动BEIK研究
2. **深度研究**：PM用BEIK模板完成4要素调研（1-2周），同步进度到CRM系统
3. **成果移交**：PM将BEIK报告提交给销售团队，使用信息流转映射表标注MEDDIC可复用项
4. **商机协作**：销售根据BEIK输入补充MEDDIC缺失项（主要是M-Metrics和D-Decision Process），形成商机评分
5. **迭代刷新**：每季度PM回访关键客户，刷新BEIK中的I-Influencers和K-Key requirements
