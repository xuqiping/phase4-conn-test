# 3.3 生命周期与运营体系

> 叶子：D-07.06 社群运营 ｜ 模块：3_AI精炼版 ｜ 碎片：3.3

## 一、社群五阶段生命周期

| 阶段 | 时间参考 | 核心指标 | PM角色 | 关键动作 |
|---|---|---|---|---|
| 创建期 | 0-1月 | 种子用户数/首周发言率 | 创始人 | 定位+种子招募+规则制定+冷启动内容 |
| 成长期 | 1-3月 | DAU/MAU/新成员增长率 | 运营者 | 裂变机制+内容日历+KOL识别+子群孵化 |
| 成熟期 | 3-12月 | 留存率/贡献度/NPS | 守夜人 | 分层运营+治理机制+价值升级+UGC激励 |
| 衰退期 | 12月+ | 活跃度周降/核心流失率 | 医生 | 诊断归因+内容革新/社群重组 |
| Renewal/归档 | 适时 | 是否能焕新/是否该结束 | 决策者 | 版本2.0定位/归档传承/合并迁移 |

### 创建期详解

**冷启动三件套**：
1. 价值主张卡片（一句话说明群价值+入群门槛）
2. 种子内容包（至少20条高质量预填充内容）
3. 运营公约（发什么/不发什么/违规处理/入群自我介绍模板）

**种子用户获取**：
- 从现有用户池筛选（Top 10%活跃用户）
- 从KOL人脉引入（行业专家/意见领袖）
- 从竞品社群吸引（差异化价值主张）
- 种子用户规模建议：小群10-20人 / 中群30-50人 / 大群100人

种子用户筛选标准：高意愿 + 高表达能力 + 高行业影响力（至少满足2项）

### 成长期详解

**裂变公式**：
```
裂变系数K = 邀请率 × 人均邀请数 × 转化率
K > 1 → 自然增长；K < 1 → 需持续拉新投放
```

增长杠杆排序（ROI从高到低）：
1. KOL自带流量入群
2. 优质内容社交传播
3. 老带新权益激励
4. 跨社群联合活动
5. 付费投放拉新

### 成熟期详解

**健康度三大指标**：
- 活跃度 > 30%（日活/总成员）
- 月留存率 > 70%
- 核心贡献者占比 > 5%（产生80%内容的成员比）

**价值升级路径**：
- 免费社群 → 付费会员 → 高级合伙人 → 共创生态
- 每升级一次，释放更多独家权益和治理参与权

### 衰退期详解

**预警信号**：
- 日消息量连续2周下降 > 20%
- 核心KOL连续4周未发言
- 新成员7日留存率 < 30%
- 负面情绪帖占比 > 15%

**衰退归因框架**：
| 归因类型 | 诊断方法 | 典型解法 |
|---|---|---|
| 价值衰减 | 内容打开率/完成率下降 | 内容升级/引入新话题 |
| 关系固化 | 互动网络密度下降 | 新成员注入/跨群联动 |
| 治理失效 | 违规率/投诉率上升 | 规则 tighten/管理员增补 |
| 外部竞争 | 成员流失到竞品 | 差异化价值提升/独家权益 |

## 二、四引擎运营体系

| 引擎 | 职责 | 核心动作 | 频率 |
|---|---|---|---|
| 内容运营 | 供给信息价值 | 选题规划/内容日历/UGC激发/知识沉淀 | 日级 |
| 活动运营 | 创造互动机会 | 线上AMA/线下聚会/挑战赛/打卡/直播 | 周级 |
| 用户运营 | 维系关系价值 | 分层运营/KOL维护/新成员Onboarding/流失挽留 | 日级 |
| 数据运营 | 驱动科学决策 | 活跃分析/留存诊断/AB测试/预警监控 | 周级 |

**四引擎协同关系**：
```
数据运营 ──→ 发现问题 → 指导其他三引擎调整
内容运营 ──→ 吸引+留存 → 为活动引流
活动运营 ──→ 促活+裂变 → 为内容贡献UGC
用户运营 ──→ 分层+激励 → 为内容和活动提供KOL和种子
```

## 三、运营节奏设计

**日运营**（每天）：
- 早安话题/每日一问（信息价值供给）
- 新成员欢迎+Onboarding引导
- 热帖/精华推荐

**周运营**（每周）：
- 周主题讨论/周报摘要
- 1次线上活动（AMA/分享/辩论）
- 数据周报+下周规划

**月运营**（每月）：
- 月度活动（大赛/大课/线下聚会）
- 成员月报+KOL表彰
- 内容/规则迭代Review

**季运营**（每季度）：
- 社群大事件（周年/里程碑/版本升级）
- 价值模型Review+战略校准
- 核心成员深度访谈
