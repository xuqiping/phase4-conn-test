## 实现内容

选中 ≥2 节点 → 批量工具条「批量生成」→ 资格预检 → 选中节点**诱导子图**拓扑序（未选上游按已物化产出插值，不补跑）→ 滑动窗口 2 并发「仅提交」→ 429 指数退避 1s/2s/4s×3 → 独立轮询 + 进度浮条。依赖 C1（工具条）+ C3（后端并发闸 2/3）。

## 关键决策

- **text 节点在窗口内同步跑完**（无 taskId），按节点终态计数；image/video 拆「仅提交」+ 独立 `void poll`，窗口只约束提交速率，真正的并发上限由 C3 后端闸门兜底（退避即应对它的 429）。
- 批量中删除节点：窗口 worker `getNode` 为 null 静默跳过 + 既有 poll stale-guard（isCurrentNodeTask）双保险。
- 每节点独立 try/catch：单节点提交失败（含退避 3 次仍 429）标红该节点，不阻断其余。
