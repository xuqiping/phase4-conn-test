### 关键设计落地
- **日期铁律**（§3.4 line134）：Compressor 喂 turn 真实 `created_at` + `assertYearIronRule` 断言总结年份 ∈ 源年份集，源外年份→违则重试至 null 丢弃（不写带错年份 summary）。
- **12h 规则**（§3.8 line171）：DISCARD 前查 source turns 的他人引用，引用方 `summarized_at > 12h` → FORBIDDEN 拒（基准=他人引用方 summary.summarized_at，非 turn.created_at）。
- **死循环防护**（§3.8 line173）：DISCARD 连带软删 source turns → turns 不进 `findPersonalTurnsForConsolidation` 取数 → worker 不会再生成同冲突。
- **双节点互斥**（plan E）：claimAutoScopes `FOR UPDATE SKIP LOCKED` + `markClaimed` 置 `locked_until` 同 tx；`last_run_at >= periodStart` 跳过=幂等。
- **gen 关态空跳过**（§3.4 line125）：auto(manual=false) 不 backfill raw；未覆盖空→不调压缩 LLM。

## 沉淀（入通用约束）
1. **@Transactional 自调绕代理** → 抽独立 TxService bean 跨 bean 调（同 IndexJobTxService 先例），LLM 调用须事务外（秒级阻塞+计费不持 DB 连接）。
2. **PG 拒 varchar→timestamptz 隐式转换** → JdbcTemplate 传时间字符串须 `?::timestamptz` cast。
3. **FOR UPDATE SKIP LOCKED 锁生命周期** → claim（@Transactional 短事务 select+markClaimed）→ process（事务外 LLM）→ release（单行 UPDATE），locked_until 时间戳持久化挡他节点（非靠行锁）。
4. **flat provenance 级联查** → `source_turn_ids @> [T]` 包含算子查受影响 summary（@> 在 XML 无需转义，异于 `&&` 重叠算子）。
