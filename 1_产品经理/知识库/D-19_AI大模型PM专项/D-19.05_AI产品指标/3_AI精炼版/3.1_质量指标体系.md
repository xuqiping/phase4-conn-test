# 3.1 质量指标体系

## 一、三指标速判（面试直接拿来说）

PM要在30秒内说清AI产品好坏：①意图命中率 ②任务完成率 ③幻觉率 [来源:知乎Day35 | 🔍高 | 2026-05]：

| 指标 | 定义 | 目标 | 不达标说明 |
|---|---|---|---|
| **意图命中率** | AI理解用户意图正确的比例 | >80% | AI答非所问，意图理解差 |
| **任务完成率** | 用户发起的任务，AI能独立完成（不需人工介入/重试）比例 | >90% | AI一次性交付能力不足 |
| **幻觉率** | AI一本正经胡说的比例 | <5%（高风险场景<1%） | AI输出不可信 |

> 三指标必须组合看：意图没命中→答非所问；任务完成率低→用户要反复追问；幻觉率高→输出不可信

## 二、AI产品核心质量指标全集

### 2.1 输出质量直接指标

| 指标 | 定义 | 计算公式 | 目标 |
|---|---|---|---|
| **意图命中率** | AI理解意图正确比例 | 正确意图响应/总请求 | >80% |
| **采纳率** | AI输出被用户采纳比例（直接复制/应用/未修改）| 采纳数/AI建议总数 | >60%（Copilot类）|
| **重写率** | 用户重写AI输出的比例 | 重写数/采纳数 | <30% |
| **任务完成率** | AI独立完成任务比例 | 独立完成/总任务 | >90% |
| **首次成功率** | 首轮即完成比例（不重试）| 首轮成功/总任务 | >70% |
| **平均会话轮数** | 完成任务所需对话轮数 | 总轮数/总任务 | 行业基线对比 |
| **幻觉率** | 编造事实比例 | 幻觉数/总断言 | <5%（高风险<1%）|
| **引用准确率** | 引用溯源链接正确率 | 正确引用/总引用 | >95% |
| **工具调用成功率** | Agent调用工具成功比例 | 成功调用/总调用 | >85% |
| **格式合规率** | 输出符合JSON/Markdown等格式 | 合规数/总数 | >98% |
| **安全合规率** | 输出符合内容审核 | 合规数/总数 | >99.9% |

## 三、人评（Human Evaluation）

人评是质量度量的"金标准"，但有成本与一致性问题：

| 人评方法 | 说明 | 优势 | 劣势 |
|---|---|---|---|
| **盲评对比** | A/B两个模型盲评选优 | 简单直接 | 不能给绝对分 |
| **5星评分** | 单输出打1-5分 | 可量化 | 主观差异大 |
| **多维度评分** | 准确性/相关性/连贯性/有用性多维度 | 信息丰富 | 标注成本高 |
| **李克特量表** | 1-7同意度 | 区分度好 | 标注复杂 |
| **Chatbot Arena（Elo）** | 大规模盲评对战 | 公认最贴近真实体验 | 需大规模用户参与 |

**Chatbot Arena**（lmarena.ai）：2026公认的"民间Leaderboard"，靠Elo评分排名模型；优势是大规模真实用户盲评，最接近真实体验 [来源:LMSYS | 🔍高 | 2026]

## 四、LLM-as-Judge

用GPT-4/Claude等强模型当裁判评其他模型，是规模化的中间方案：

| 维度 | 说明 |
|---|---|
| **适用** | 大规模自动评估，比纯人评便宜得多 |
| **方法** | 给裁判模型"评分标准+对比项"，让其打分或选优 |
| **优势** | 成本低/可大规模/可重复 |
| **风险** | 裁判模型偏好（同源偏好、长输出偏好、位置偏好）|
| **2026最佳实践** | 多裁判混合 + 偏好校正 + 关键case人评对照 |

### 4.1 LLM-as-Judge常用模式

| 模式 | 说明 |
|---|---|
| **单点打分** | 给输出1-N分 |
| **成对比较** | A vs B选优 |
| **参考答案对比** | 与黄金答案对比打分 |
| **多维评分** | 准确性/相关性/流畅性多维 |
| **思维链评分** | 裁判先推理再给分，质量更高 |

## 五、Agent专项指标

Agent产品有不同于对话/Copilot的专项指标：

| 指标 | 定义 | 目标 |
|---|---|---|
| **端到端完成率** | 整个任务链完整完成 | >70% |
| **平均步骤数** | 完成任务所需步骤 | 与基线对比 |
| **工具调用正确率** | 选对工具且参数正确 | >85% |
| **规划正确率** | 任务分解合理 | 人评 |
| **中断率** | 用户中途打断比例 | <30% |
| **错误恢复率** | 失败后恢复成功 | >60% |
| **检查点回退率** | 触发checkpoint回退比例 | <20% |
| **平均成本/任务** | 完成一个任务平均花费 | 商业可行边界 |
| **平均时延/任务** | 完成一个任务平均耗时 | 体验边界 |

## 六、幻觉率专项度量

幻觉是AI产品最大风险，必须专项度量：

| 度量方法 | 说明 | 适用 |
|---|---|---|
| **黄金集比对** | 与已验证黄金答案对比 | 高频问答 |
| **关键事实核查** | 抽样关键事实联网核验 | 通用 |
| **引用回溯核查** | 验证引用是否真实存在 | 引用类产品 |
| **数字/日期/人名专项** | 易错字段专项 | 数据类产品 |
| **领域专家抽查** | 医疗/法律/金融专家抽检 | 高风险垂类 |
| **LLM-as-Judge幻觉识别** | 用强模型识别幻觉 | 规模化方案 |

> 2026幻觉度量难点：①"幻觉"边界模糊（推测 vs 编造）②规模化成本高 ③领域差异大。详见 [D-19.06 AI风险合规](../../D-19.06_AI风险合规/1_知识库概览/0_模块路由.md)
