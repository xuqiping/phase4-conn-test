# 安全管理 · 用户操作手册

> 适用角色：系统管理员（admin，持 security:* 权限）。入口：左侧栏「风险大盘 / 安全事件 / 封禁管理 / 安全规则」。
> 配套：钉钉群收告警卡片（高危即时、中危 30 秒汇总）。

## 1. 风险大盘（/admin/security/dashboard）
**看什么**：近 24 小时 4 级事件数（危急/高危/中危/低危大数字卡）+ 事件类型 TOP10 + 待处置总数。
**操作**：打开即自动加载；点「刷新」更新；点「进入事件中心处置」跳转。
**完成标志**：各卡片数字与事件中心实际一致。

## 2. 安全事件中心（/admin/security/events）
**场景**：有人攻击/滥用 → 查事件 → 处置。
1. 顶部筛选：事件类型（中文下拉）/ 严重度 / 状态（未处置/已处置）→ 点「查询」。
2. 表格每行：时间、类型、严重度（颜色标签）、用户、IP、自动处置、状态。
3. 点「详情」→ 弹窗看完整信息（含 traceId，可去日志系统追全链）。
4. 确认已知晓/已处理 → 点「处置」（行内或弹窗内）→ 状态变「已处置」，侧栏 badge 数减 1。
   - 已被别人处置过 → 提示 409「事件不存在或已被处置」（幂等，正常）。
5. **批量清理**（物理删除，不可恢复！）：勾选行 → 点「批量清理(N)」→ 弹窗二次确认 → 删除。
   - 单次上限 200 条；操作留审计（security:event_batch_delete）。

## 3. 封禁管理（/admin/security/ban）
### 封 IP
1. 输入 IP 地址 + 封禁原因（必填）→ 勾选「永久」（不勾=默认时长）→ 点「封禁 IP」。
2. 效果：该 IP 所有 /api/** 请求立即 403。
### 解 IP
列表点「解封」→ 二次确认 → 恢复访问。
### 用户封号
点「前往用户管理」→ 用户列表改状态：
- **BANNED**（封号）/ **DISABLED**（禁用）/ **LOCKED**（锁定）：填原因（≤128 字）→ 该用户**立即被踢下线**（会话删除 + ban 标记），无法再登录/刷新 token。
- 改回 ACTIVE = 解封（清原因/锁定到期时间）。
- 保护：不能封自己；最后一个持「用户管理」权限的 admin 不可封（防自锁死）。

## 4. 安全规则配置（/admin/security/rules）
**即时生效**（改完下一次检测即用新值，无需重启）。
- **总开关**：限流总闸 / 自动处置总闸（关=全部只告警不封不锁，误伤一键关停）/ 自动封 IP / 自动锁号 / 钉钉告警。
- **钉钉告警**：填机器人 Webhook URL（空=不推）；加签密钥只写不读（留空=不修改）。
- **限流阈值**：全局次/分钟/IP（默认 600）、对话发送 20/分钟、媒体提交 10/分钟。
- **检测阈值**：越权 10 次/5 分钟、外带 500 条/10 分钟、积分 10000 分/10 分钟、媒体 ¥100/30 分钟、Prompt 屡犯 3 次/小时、Token 3 个 IP/10 分钟。

## 5. 钉钉告警长什么样
- **高危/危急**：即时单条卡片（类型中文/严重度/用户/IP/详情/自动处置/traceId/「进入安全事件中心处置」链接）。
- **中危**：30 秒汇总一条（各事件一行，超 10 条折叠提示去事件中心看）。
- **低危**：不推送，只在事件中心可查。

## 常见异常与恢复
| 现象 | 原因 | 处理 |
|---|---|---|
| 钉钉没推送 | webhook 未配 / 总闸关 / 机器人故障 | 安全规则页查配置；失败计数看 Prometheus security_alert_send_failed_total |
| 事件中心无权限 403 | 账号无 security:event:read | 角色权限页授权 |
| 用户被自动锁定 | 触发积分/媒体滥用规则 | 15 分钟自动解锁；或用户管理页手动改 ACTIVE |
| IP 被自动封 | 注入探测≥3 次/小时 或 限流突发≥10 次/小时 | 封禁管理页查原因；确认误伤后「解封」 |
| 异地登录告警 | 账号可能泄露 | 事件中心看详情（新旧地区+时间差），必要时封禁管理锁号 |

### 变更记录（2026-08-14 · 13x）
- 事件详情改为大白话中文键值展示；「自动处置」列显示中文（锁定账号/封禁来源IP/仅记录告警）。
- 详情弹窗新增「处置过程」时间线：告知事件发生时系统已自动执行的动作（含时长），以及人工「处置」按钮的实际语义（记录处置人与时间，不重复封禁）。


## 安全事件详情怎么看「谁在何时对谁做了什么」（13x 第二轮，2026-08-14）

点「详情」后：

- **操作人**：直接显示账号名（如 `admin（用户#1）`），列表「用户」列同样显示 `admin #1`。
- **事件详情（键值区）**：
  - 「具体操作」= 大白话动作，如 `计费积分 · 新建价表`、`用户管理 · 修改账号状态`、`安全管理 · 处置安全事件`（凌晨敏感操作同样能看到具体动作+发生时刻）。
  - 「操作对象类型 / 目标ID」= 动的是谁（价表规则、用户账号、安全事件等）。
- **参数级明细**（改了什么值）：事件详情不落参数明文，按弹窗提示的 traceId 去「审计日志」关联查询（审计日志有脱敏参数摘要）。
- **处置过程时间线**：①事件发生 → ②自动处置（发生瞬间已实际执行的动作）→ ③人工处置（「处置」按钮=确认标记，记录处置人/时间，不会重复执行封禁）。

## 哪些行为会被自动封号/锁定（13x 回答，2026-08-14）

| 触发行为 | 检测条件 | 自动动作 | 恢复方式 |
|---|---|---|---|
| 登录暴破 | 同账号 15 分钟内 5 次密码错误 | 锁定该账号 15 分钟 | 到期自动恢复 |
| 撞库攻击 | 同 IP 5 分钟内尝试 ≥20 个不同账号 | 封禁来源 IP 60 分钟 | 到期自动解封 |
| SQL 注入累犯 | 同 IP 1 小时内注入特征命中 ≥3 次 | 封禁来源 IP 60 分钟 | 到期自动解封 |
| 危急级事件（预留档，当前无检测器触发） | — | 锁号 15 分钟 + 封 IP 24 小时 | 到期自动恢复 |

其余事件（特权变更/凌晨敏感操作/积分滥用/媒体滥用/Prompt注入/越权探测/异地登录/Token盗号/频率突发/单次注入探测等）**只记录 + 推告警，不自动封禁**。

要点：
- **没有任何行为会自动永久封号**。自动锁定最长 15 分钟、自动封 IP 最长 24 小时，均自动恢复。
- 永久封禁账号 / 永久封 IP 只能管理员在「封禁管理」手动操作。
- 管理员可在「安全规则」页关闭自动处置开关（auto_enabled 总闸 / auto_ip_block / auto_account_lock 分闸），关闭后全部降级为仅告警。
