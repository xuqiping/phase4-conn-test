# File Keeper 前端运行说明

## 前置要求

在运行项目之前，请确保已安装：

1. **Node.js** (v18 或更高版本)
   - 下载地址: https://nodejs.org/
   - 推荐安装 LTS 版本

2. **包管理器** (选择其一)
   - npm (Node.js 自带)
   - pnpm (推荐): `npm install -g pnpm`
   - yarn: `npm install -g yarn`

## 安装依赖

在项目根目录 `C:\AI Projects\file-keeper` 下运行：

```bash
# 使用 pnpm (推荐)
pnpm install

# 或使用 npm
npm install

# 或使用 yarn
yarn install
```

## 运行前端开发服务器

### 方式 1: 仅运行前端 (推荐先测试 UI)

```bash
# 使用 pnpm
pnpm dev

# 或使用 npm
npm run dev

# 或使用 yarn
yarn dev
```

运行后，浏览器会自动打开 `http://localhost:1420`

### 方式 2: 运行完整 Tauri 应用

```bash
# 使用 pnpm
pnpm tauri:dev

# 或使用 npm
npm run tauri:dev

# 或使用 yarn
yarn tauri:dev
```

**注意**: 运行 Tauri 需要先安装 Rust 和 Tauri CLI:
- Rust: https://www.rust-lang.org/tools/install
- Tauri CLI: 已在 devDependencies 中，会自动安装

## 常见问题

### 1. 端口被占用
如果 1420 端口被占用，可以修改 `vite.config.ts` 中的端口号。

### 2. 依赖安装失败
尝试清除缓存后重新安装：
```bash
# pnpm
pnpm store prune
pnpm install

# npm
npm cache clean --force
npm install

# yarn
yarn cache clean
yarn install
```

### 3. TypeScript 报错
确保安装了所有依赖，特别是 `lucide-vue-next`。

### 4. Naive UI 样式问题
Naive UI 使用按需导入，样式会自动注入，无需额外配置。
