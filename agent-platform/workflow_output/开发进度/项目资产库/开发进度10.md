## S19 剧本拆解模板 + 一键分镜（核心）

- `AssetScriptService.breakdownStoryboard`（@Transactional）：剧本→LLM 拆镜→每镜建分镜资产（字段 1/2 自动填 + 实体首轮匹配）。
  - 循环外 `requireWrite` 一次；`assetProjectService.ensureMediaType` vocab 缺分镜自动补（L13）。
  - `assetService.getImageCatalog(projectId,50)`：IMAGE 类 ∩ {人物,道具,场景} ≤50 updated_at 倒序注入 LLM（防 token 爆）。
  - `buildShotContent`：5 字段 schema（1/2/4 全功能，3/5 占位 `status:none`）。
  - 非法/越项目 assetId 逐条校验置 null（L16）；name/mediaType 取自目录富化非模型。
  - LLM 失败/解析失败返固定话术「分镜失败，请稍后重试」不透传 `e.getMessage()`（安全清单）。
  - `parseShots` 复用 `parseScenes` 容错（剥围栏/取 `[..]`/兜底单镜）。
  - 剧本 content 记 `storyboardModel/storyboardAt/shotCount` meta 产新版本（不存 shots）。
- `AssetService.internalCreateText`：抽建库核心（剥离 ACL，create + breakdown 循环复用 DRY）。
- `AssetProjectService.ensureMediaType`：vocab 缺 key 自动 append（幂等，复用 normalizeMediaTypes）。
- `AssetController POST /assets/{id}/breakdown-storyboard`（@RequirePermission + 委派）。
- 前端 `scriptApi.breakdownStoryboard`；抽屉剧本分支加「拆解规范」可折叠 textarea（写 content.template）+「一键分镜」按钮（dirty 检查 + loading + 显「已生成 N 个分镜资产」+ reload，L13）。
