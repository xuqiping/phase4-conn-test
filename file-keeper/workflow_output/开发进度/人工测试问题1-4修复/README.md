# 人工测试问题 1—4 修复

## 用户地图

面向经常打开本地文件、管理多个 Office 窗口、依赖剪贴板历史并希望应用随时可恢复的 Windows 用户。本轮解决六类高频摩擦：收藏快捷键冲突、桌面快捷方式被删后失效、进程标题难区分、关闭后找不到应用、剪贴板重要记录难固定、历史记录难分类。

用户收益：常用入口更快、删除边界更安全、多窗口更容易识别、关闭行为可预测、剪贴板批量整理效率更高。全部是本地模块，不需要登录或联网。

## 技术说明

- 收藏快捷键统一标准化和冲突协调，新键成功后才释放旧键。
- Windows `.lnk` 使用应用目录托管、随机名和原子发布；普通路径绝不托管删除。
- 进程列设置按 key 合并并使用一次性版本迁移。
- 关闭行为为悬浮球/托盘/退出三态，失败按悬浮球→托盘→主窗降级。
- 剪贴板分组与置顶存入本地 SQLite；批量写入单事务；前端乐观更新用条目操作版本防止旧失败覆盖新成功。
