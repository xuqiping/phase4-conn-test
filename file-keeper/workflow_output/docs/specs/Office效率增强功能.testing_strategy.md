# Office 效率增强功能测试策略

## 1. 测试金字塔

- Vue/Vitest：向导状态、额度提示、字段映射、宏/链接冲突、范围说明、键盘和无障碍属性。
- Rust 单测：路径校验、任务状态机、SQLite、输出事务、Worker 协议、取消和清理。
- Worker 契约测试：固定 JSON Lines 请求/响应、错误码、心跳和超时。
- Spring/JUnit：Office Pro 实时校验、管理员授予、AI 预扣/结算/释放、幂等、限流和审计。
- 集成测试：桌面创建任务 → Worker 模拟执行 → 校验 → 发布 → 历史报告。

## 2. 兼容样本矩阵

必须建立可版本化测试样本：

- Excel：公式、跨 Sheet/外链、样式、条件格式、合并单元格、表格、图表、命名区域、隐藏 Sheet、`.xls/.xlsm`、签名/密码宏。
- Word：跨 Run 文本、表格、页眉页脚、脚注尾注、文本框、批注、修订、旧 `.doc`、密码文件。
- PPT：多母版、字体缺失、图表、Excel 外链、嵌入对象、`.ppt/.pptm`、签名/密码宏。
- 通用：中文/Emoji/超长路径、只读文件、网络盘、文件被占用、磁盘不足、Worker 崩溃。

## 3. 核心断言

- 源文件哈希在任务前后不变。
- 成功输出能由对应 Office/解析器重新打开；单输出失败时目标文件不存在。
- `.xlsm/.pptm` 宏部件在支持场景下保留；冲突未解决时任务不能开始。
- Word 批注和修订内容不变，界面与报告显示排除范围。
- AI Key/密码/正文不出现在日志、数据库、前端包和错误响应。
- 同 requestId 重试不重复扣积分。

## 4. 性能与稳定性

- 免费边界：100 文件、1GB 总量、100MB 单文件分别测试等于和超过边界。
- Pro 压测使用 2,000 文件/20GB 作为工程基准，不作为产品硬上限。
- 运行 8 小时混合任务，监测内存增长、句柄泄漏、Office 残留进程和临时目录清理。
- Worker 强制崩溃、服务端断网、模型超时、余额竞争均需故障注入。

## 5. 人工交互测试（Phase 3 必须产测试方案）

- 宏 Trust Center、数字签名失效、密码凭据保存和删除。
- Word 各 Story Range（文档不同区域）替换范围的肉眼确认。
- PPT 母版/主题/字体与外链刷新后的 Office 实际显示。
- 大任务进度、取消、部分成功、失败恢复和二次替换确认。
- 屏幕阅读器、全键盘流程、高对比度和中英双语。

## 6. 发布门槛

- 自动测试全绿；真实 Office 版本兼容矩阵通过。
- 源文件损坏事故为 0；关键安全扫描无高危项。
- 任何已知保真限制均在 UI 支持等级和用户手册中明确说明。

## 7. 术语表

| 术语 | 大白话 | 示例 |
|---|---|---|
| 故障注入 | 故意让依赖失败验证恢复 | 执行中杀掉 Worker |
| 契约测试 | 检查两个模块说话格式一致 | JSON Lines 字段必须匹配 |
