# 3.3 战役方法论提炼

> 从10大战役提炼5要素方法论+跨战役对比矩阵——"学战役不是学故事，是学方法论"。

## 一、方法论5要素框架

| 要素 | 定义 | 提炼方法 |
|---|---|---|
| 核心洞察 | 战役背后的"人/需求/场景"洞察 | 战役中什么洞察驱动了关键决策？→从结果反推洞察 |
| 关键决策 | 战役中改变走向的1-3个决策 | 哪个决策让战局逆转/加速？→决策树回溯 |
| 执行节奏 | 战役的时间线+节奏把控 | 哪些时机把握是胜负手？→时间轴标注关键节点 |
| 资源分配 | 人/钱/技术的分配策略 | 有限资源怎么分配？→资源投入vs产出的ROI分析 |
| 可迁移模型 | 从战役抽象出的可复用模型 | 能否用1句话概括→能否迁移到其他场景？ |
