# 资产库公众池与价表模型选择

## 用户地图

- 项目 OWNER：把资产项目公开给所有用户，或要求申请后使用；管理审批并继续控制成员授权。
- 管理员：可发布任意项目，发布内容带“官方发布”标记并直接开放。
- 普通用户：在公共池查看摘要，直接使用 OPEN 项目或申请审批；获权后只读引用，也可复制到自己可写的项目继续创作。
- 计费管理员：新增价表时从全局供应商的未配置模型中选择，避免手填错 provider/model/kind。

## 技术说明

- 公共发布复用原项目、资产和版本，不复制数据；访问申请独立于成员表。
- `AssetAclService` 为内容访问咽喉：OPEN/APPROVED 只授予 VIEWER，写入口仍拒绝。
- 复制在事务内锁定源当前版本，在目标项目新建独立资产和版本 1，物理文件仅复用 `fileId`。
- 分享弹窗使用资产域最小候选接口，仅返回 `id/username`，不再依赖管理员用户列表。
- 前端公共池、审批、复制和 AssetPicker 均采用请求会话/防重保护，避免关闭重开或切项目后旧响应污染新界面。
