# 无限画布创作页 · 用户操作手册

> 面向持有 `canvas:write` 权限的用户（创作型终端用户）。功能入口：侧边栏「无限画布」菜单（`/canvas`，无权限不显示，联系 admin 授权）。
> 关联 Feature Map：[../feature-map/无限画布创作页.feature-map.md](../feature-map/无限画布创作页.feature-map.md) · 功能 README：[../../开发进度/无限画布/README.md](../../开发进度/无限画布/README.md)

## 前置条件

- 账号已被授予 `canvas:write` 权限（默认仅 admin 有；普通用户须 admin 在「角色权限」页授予）。
- 想在画布上**生成视频**还需 `media:gen` 权限（视频节点复用视频生成能力；无权则视频节点生成 FAILED）。
- 系统已配置 doubao provider（Ark key + endpoint + seedance 模型）——由运维保证，用户无需关心。
- 桌面端使用（移动端 ≤768px 显示「请在电脑端使用」占位，节点画布不适合触屏）。

## 功能一：新建画布与拖节点

**操作步骤**：
1. 点侧边栏「无限画布」进入 `/canvas`，看到「我的画布」卡片网格。
2. 点右上「新建画布」→ 自动进入编辑模式（路由变为 `/canvas/{id}`），画布名为「未命名画布」。
3. 左侧调色板拖节点到画布：**文本 / 图片 / 视频 / 音频 / 脚本 / 分镜** 6 类。
4. 鼠标滚轮缩放，按住空白拖动平移；点节点选中（高亮辉光），再点空白取消。
5. 选中节点后右侧「属性面板」编辑该节点字段。
6. 顶部工具条：放大/缩小/适应视口；「重跑全链」按钮（见功能五）。
7. 改动后自动节流保存（停手 800ms 后落库）；也可手动 Ctrl+S 风格点击标题栏保存。右上「重命名」改名。

**完成标志**：画布列表多一张卡片（显示节点数 + 更新时间）；再次进入复原全部节点/连线/位置。

---

## 功能二：文本节点生成（提示词扩写）

1. 拖入「文本」节点，属性面板「提示词」填一段描述（如「赛博朋克街景，霓虹雨夜」）。
2. 点「运行」→ 节点徽标转 **running**（旋转）→ 完成变 **success**，节点内显示 LLM 扩写结果（4 行预览）。
3. 失败则徽标 **failed** 标红，鼠标悬停看原因。

**用途**：把简短提示词扩成完整描述，作为下游图片/视频节点的输入素材。

---

## 功能二·五：脚本节点拆分镜 → 分镜节点自动生成

> 把一段剧本交给大模型拆成多个分镜，每个分镜自动生成独立「分镜节点」挂在脚本节点右侧并连线（扇出）。

**操作步骤**：
1. 拖入「脚本」节点 → 选中 → 右侧属性面板填「剧本」（可 `@` 引用上游节点产出）。
2. （可选）设**拆分段数**：填数字（如 6）→ 大模型严格拆成 N 个分镜；留空则大模型自定（默认 3-10）。
3. （可选）填**拆分规范**：如「每镜含景别+运镜」；留空则大模型自由发挥。
4. （可选）选「模型」（默认后端回落）。
5. 点「拆分镜」→ 等待数秒，脚本节点右侧**扇出生成 N 个分镜节点**，每个自动连脚本节点（脚本→各分镜独立边），节点头显「分镜1/2/…」，正文是画面描述。
6. 点任一分镜节点 → 属性面板可**编辑画面描述**（微调后再下游生图/视频）。
7. **重拆**：改剧本/段数/规范后再点「拆分镜」→ 旧的自动生成的分镜子节点会被删除并按新参数重建（手动改过的分镜描述会丢，重拆前请确认）。

**下游用法**：在图/视频节点的提示词里 `@分镜N` → 该分镜的画面描述会注入提示词（生图/视频参考其画面）。

**存入资产库**：右键分镜节点 → 「存入资产库」→ 进**分镜**分类（正文=画面描述）。

**完成标志**：脚本节点右侧出现一列分镜节点，各连脚本，描述正确。

## 功能三：图片节点（上传 / 衍生）

> MVP 仅支持上传 + 衍生 + 焦点编辑。AI 生图待后续接入生图 provider。

1. 拖入「图片」节点。
2. 点属性面板「上传图片」→ 选本地图片 → 上传完成后节点显示缩略图。
3. **衍生**（不覆盖原图）：在原图基础上调整产新图（保留原图，新图自动连边到原图旁）。
4. **焦点编辑**：点节点进入沉浸模式 → 在图上框选要提取的元素 → 提交产新图节点（提取质量依赖模型能力，弱保底）。

---

## 功能四：视频节点（文生 / 图生）

1. 拖入「视频」节点，属性面板填提示词 + 选比例/时长/分辨率。
2. **图生视频**：先在该视频节点上游连一张图片节点（文本→图片→视频，或直接图片→视频连线）——画布会自动把上游图作为参考图（首帧）。
3. 点「生成」→ 徽标 running → 后台异步生成（通常 1-3 分钟）。
4. 生成中节点 5 秒轮询一次状态；**SUCCEEDED** 后节点内出现 `<video>` 预览。
5. 失败（如限流 429 / 超时）→ 徽标 failed 标红。

> 无 `media:gen` 权限：点生成直接 403，节点标 FAILED「无 media:gen 权限」。

---

## 功能五：连线 + 一键重跑

1. **连线**：鼠标悬停节点边缘出现连接锚点，从上游节点拖到下游节点松开即连（smoothstep 曲线）。图片→视频连线后，视频生成自动取上游图作参考图。**删连线**：单击连线选中（变红色加粗）→ 按 Delete 或 Backspace 删除。
2. **一键重跑**：顶部「重跑全链」→ 按**拓扑顺序**串行重跑所有可生成节点（文本/脚本/视频；上传型图片/音频跳过）。
3. 若画布**有环**（A→B→A）→ 重跑前报错提示「画布存在环，无法拓扑排序」，需先解开环。

---

## 功能六：视频抽帧（首/尾/指定秒）

> 需视频节点已生成（有 fileId）。

1. 选中视频节点 → 属性面板「抽帧」区。
2. 三选一：**首帧** / **尾帧** / **第 N 秒**（AT 模式填秒数输入框）。
3. 点对应按钮 → 后台用 javacv 取该帧 → 产一张新**图片节点**自动连到该视频节点旁，命名如「抽帧(AT 3s)」。
4. 秒数越界（超过视频时长）→ 提示错误，不产空节点。

---

## 功能七：视频截取（时间段裁剪）

1. 选中视频节点 → 属性面板「截取」区。
2. 填起止秒（两个数字输入框），点「截取片段」。
3. 后台裁剪 `[start, end)` → 产一段新**视频节点**自动连边，命名如「截取(2-5)」，徽标直接 success（可预览）。
4. 校验：起≥0 / 止>起 / 时长 ≤600 秒 / 不超原视频时长；违规提示具体错误。

> MVP 仅视频轨（截取片段静音，浏览器播放/下载正常）。

---

## 功能八：故事板（多段拼接成片）

1. 画布上有 ≥2 个已生成的视频节点后，点顶部「故事板」打开右侧抽屉。
2. 抽屉列出画布上所有视频段（带 label + 时长）。
3. **调序**：点段右侧 ↑↓ 调整播放顺序。
4. **顺序预览**：点「预览」→ 按当前顺序逐段播放，一段结束自动进下一段；点列表项可跳段。
5. **拼接成片**：点「拼接成片（N 段）」→ 后台逐段重编码进同一 mp4 → 产一个新**视频节点**（成片），命名如「成片(3段/12s)」。
6. 失败（如段尺寸不一致）→ 提示错误。

> **要求各段同源/同尺寸**（典型场景：同一视频的若干截取片段）。深度剪辑/转场/多轨是后续独立功能。

## 常见异常与恢复

| 现象 | 原因 | 恢复 |
|---|---|---|
| 看不到「无限画布」菜单 | 无 `canvas:write` 权限 | 联系 admin 在「角色权限」页授权 |
| 直接访问 `/canvas` 显示「无 canvas:write 权限」 | 同上（三重兜底第②层） | 同上 |
| 视频节点生成 FAILED「无 media:gen 权限」 | 有画布权限但无视频生成权限 | 联系 admin 授 `media:gen` |
| 视频节点 FAILED「Ark 429 限流」 | Ark 配额超限 | 稍后重试（重新点生成） |
| 视频节点 FAILED「任务超时」 | Ark 生成超 10 分钟 | 重新生成；持续超时联系运维 |
| 抽帧/截取提示「秒数越界」 | N 秒超过视频时长 | 改小秒数后重试 |
| 截取提示「时长超 600s」 | 单片段超上限 | 拆成多段分别截取 |
| 拼接失败「段尺寸不一致」 | 各段非同源/分辨率不同 | 用同一视频的截取片段拼接 |
| 重跑报错「画布存在环」 | 节点连线成环 | 解开环（删一条边）后重跑 |
| 图片预览刷新后失效 | blob 预览 URL 跨会话失效（正常） | 重新进入画布会自动按 fileId 重取预览 |
| 节点标红「上游缺失」 | 上游图/视频被删或失败 | 重跑或重连上游 |

## 边界场景

- [ ] 编辑中刷新页面：本地未落库的改动会丢（停手 800ms 后才落库；刷新前最好手动保存）。
- [ ] 删画布：画布软删，**产出物（图/视频）保留**在文件存储（不级联清，供历史复用）。
- [ ] 删节点：连带删该节点的连线；下游节点参考图失效会**标红**（不自动删下游，保留调整权）。
- [ ] 大画布（节点多）：Vue Flow 内置节点虚拟化，100 节点级加载/编辑流畅（Phase4 验证基线）。

## 无限画布第三轮操作指引（2x，2026-08-16）

### 框选多节点 + 批量删除

1. **按住 Shift + 鼠标在空白处拖框**，框住的节点全部高亮选中；选 2 个及以上时画布顶部浮出**批量工具条**（一键关联 / 批量生成 / 批量删除）。
2. **批量删除**：点「批量删除」→ 二次确认（列明将删 N 个节点）→ 确认后节点连同其连线一起删除，改动自动保存。
3. 松开 Shift 单击任意节点 → 回到单选（右侧属性面板照常）；点空白或按 **Esc** → 清空选择、工具条消失。
4. **改进**：此前框选后按 Backspace 会触发库内置删除、应用界面无感知——现已接管，删除只走带确认的应用层入口，不会静默双删。

### 一键关联（按名字自动插 @）

> 选中多个**文本类**节点（文本/脚本/分镜）后，系统在其连线可达的上游节点里，找**名字（节点名或资产名）出现在该文本中**的，自动把该词替换成 `@引用`——效果与手动输入 @ 完全一致。

1. Shift 框选或 Ctrl 选中多个文本类节点 → 工具条点「**一键关联**」。
2. 弹出**提案预览表**：目标节点｜匹配到的上游（类型+名字）｜替换位置前后文（命中的词高亮）。默认全勾选，不想要的逐行取消勾选。
3. 点「应用」→ 文本里的名字变成蓝色 @引用块；点「取消」则原样不动。
4. **替换规则**（防误伤）：名字至少 2 个字；「主角1」「主角10」并存时**长名优先**互不误吞；已是 @引用的部分不会二次包装。
5. **无匹配**：不弹窗，仅提示（区分「没有可达上游」和「名字未在文本中出现」两种情况）。
6. 关联后运行节点、断链黄色警告、上游改名不断链——与手动 @ 的行为完全相同。

### 批量生成（多节点受控并发）

1. 框选多个可生成节点（文本/图片/视频）→ 点「**批量生成**」。
2. 系统按**连线先后顺序**（上游先提交）提交，同时最多 2 个在途（与平台每用户并发上限一致），完成一个自动补一个。
3. 画布上方浮出**进度条**：「已提交 n/m · 已完成 k · 失败 j」，可点关闭（关闭只隐藏浮条，任务继续跑）。
4. **撞并发上限（429）自动排队**：指数退避 1s/2s/4s 重试最多 3 次，仍失败才把该节点标红（其余节点不受影响，一个失败不阻断整批）。
5. **不可跑的节点会跳过并列出原因**（如图片节点没选模型、缺提示词）。
6. **中途刷新/离开**：每个节点提交瞬间已保存，回来打开画布自动恢复轮询（与单跑一致）；批量期间也可手动单独运行其他节点。

> 并发上限由管理员在系统设置调整（默认视频 2 / 图片 3），与你无关时按默认即可。
