# 21 - 系统设置

## 功能简介
平台全局开关与参数：认证设置(auth)、RAG 记忆设置(rag-memory，控制个人记忆开关 + 处理模式 + 检索模式)。

## rag-memory 设置字段（VO `RagMemorySettingsVO`）
- `enabled`：记忆总开关（false=opt-in）。
- `processMode`：`ASYNC`（默认，全异步）/ `HYBRID`（同步即时冲突追问）。
- `retrievalMode`（V28 新增）：`LLM_FULL_CONTEXT`（默认，全量灌入 LLM）/ `EMBEDDING_VECTOR`（query embed → pgvector top-K 真检索，仅注入相关，无命中不注入）。详见 [09-个人记忆·检索模式](09-个人记忆与冲突解决.md)。
