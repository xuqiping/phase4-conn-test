# 影响评估：取消商业化与开放模块

> 日期：2026-08-24
>
> 状态：设计批准，待实施
>
> 回滚锚点：`2834ea87`

## 1. 变更目标与原因

取消按模块、设备数量和时间售卖的商业授权。登录保留为服务端身份和数据隔离机制；本地模块免登录，服务端模块登录后全部开放。

## 2. 已确认边界

- 保留注册、登录、退出、Token 刷新。
- 注册后直接激活。
- 保留账号禁用、设备记录和设备禁用。
- 取消模块权益、匿名试用、免费模块、设备上限和离线授权。
- 本轮保留旧表与旧接口作为废弃兼容层。

## 3. 直接受影响范围

### 桌面端

- `src/App.vue`：Tab 门禁、授权状态、登录引导、剪贴板监听生命周期。
- `src/stores/commercialAuthStore.ts`、`src/api/commercialAuth.ts`：退出运行链路并进入废弃清理范围。
- `src/components/EntitlementStatus.vue`、`FreeModuleSelector.vue`：删除 UI 引用。
- `src/stores/workReportStore.ts`、`aiConfigStore.ts`：移除商业授权依赖，保留登录校验。
- 认证、商业授权、工作汇报和 AI 相关测试。

### Rust/Tauri

- `src-tauri/src/commands/auth.rs`：signed entitlement 命令进入废弃范围。
- 进程、剪贴板、截图、工作汇报等命令：移除 `require_module()`。
- `src-tauri/src/main.rs`：授权状态和 invoke handler 注册调整。

### 服务端

- 用户注册与状态流转：注册后直接 `active`。
- 工作汇报、互动收件箱、灵感、AI 配置 Controller：删除模块权益检查，保留认证与用户隔离。
- 设备注册：取消数量限制，保留禁用检查。
- 授权、权益、匿名试用相关 Controller/Service：标记废弃。
- 新增 Flyway 迁移，将 `pending_review` 转为 `active`。

### 管理后台

- 用户详情的模块权益与设备额度区域。
- 匿名设备运营页和相关导航。
- 商业授权相关系统设置。
- 保留用户及设备禁用操作。

## 4. 逻辑联动点

- 登录/退出会触发工作汇报和 AI 数据装载或清空。
- Token 刷新失败必须回到未登录引导，不能影响本地模块。
- 剪贴板监听由授权驱动改为应用生命周期驱动。
- 截图成功仍需写入剪贴板历史并切换剪贴板 Tab。
- 工作汇报、AI、互动收件箱和推送配置继续按 `userId` 隔离。
- 设备禁用仍需在登录或服务端访问时生效。

## 5. 外部兼容与废弃策略

- 旧桌面客户端仍可能调用授权、匿名试用和免费模块接口。
- 本轮不直接删除公开接口；接口进入废弃期并返回稳定兼容响应。
- 数据库商业化表和字段本轮不删除。
- 兼容期结束后的物理清理由下一次独立变更处理。

## 6. 运维影响

- 服务端不再要求离线授权签名私钥作为桌面功能启动前提。
- 应清理模块授权、匿名试用和权益到期相关告警或看板。
- 保留登录失败、Token 刷新、账号禁用、设备禁用、AI 调用和推送失败日志。
- 部署文档需要移除商业授权密钥和试用参数的必配说明。

## 7. 数据风险与回滚

- `pending_review → active` 是本轮唯一用户状态迁移；`disabled` 不变。
- 不删表、不删字段，降低不可逆风险。
- 代码可按 chunk 提交逐步回滚。
- 若需回退注册审核机制，可恢复旧代码；已转为 `active` 的用户不会自动恢复为待审核，回退前需根据迁移前备份决定是否重置。

## 8. 回归清单

- 本地四模块与截图的未登录访问。
- 工作汇报/AI 未登录引导和登录后访问。
- 注册、登录、退出、Token 刷新。
- 多设备登录、设备禁用、账号禁用。
- 工作汇报 CRUD、定时生成、推送和 AI 总结。
- 剪贴板监听、截图联动、进程操作。
- 管理后台用户和设备管理。
- 旧授权接口兼容响应。
