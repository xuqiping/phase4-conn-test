# 个人记忆 · 用户操作手册

> 面向普通用户。功能→步骤→界面变化→预期结果。技术细节见 [Feature Map](../feature-map/个人记忆.feature-map.md),界面入口 [速查表 09](../../../项目工程文档/项目功能介绍/速查表/09-个人记忆与冲突解决.md)。
> 记忆抽屉入口:聊天页右上角「记忆」按钮 → [MemoryManagerPanel](../../../frontend/src/components/chat/MemoryManagerPanel.vue) 7 页签。

## 基础概念(先读)
- **流水账**:你说的一句 + AI 回的一段,系统自动各记一行。
- **个人 vs 项目**:不挂项目 = 只有你能看;挂项目 = 项目成员能看(只读,改不了你的)。
- **召回范围(读哪段记忆)** vs **写入目标(新记忆落哪)**:两件事独立设置,互不影响。

---

## 1. 对话自动留痕(无需操作)
- **步骤**:正常聊天。
- **界面变化**:流式回复结束后,无可见变化(异步后台落账)。
- **预期**:开生成时 → 落 L0/L1/L2 三层;关生成时 → 落 raw 原文(90 天后自动清)。「流水账」页签能看到新行。

## 2. 设召回范围(这次聊天让 AI 参考哪些记忆)
- **入口**:聊天输入框下方「召回范围」气泡([MemoryRecallScopePopover](../../../frontend/src/components/memory/MemoryRecallScopePopover.vue))。
- **步骤**:点气泡 → 勾选 个人 / 一个或多个项目 →(可选)设方向(仅我问的/仅 AI 答的/全部)、时间窗、离职人员开关。
- **界面变化**:勾选后 400ms 自动保存,新会话沿用上次选择。
- **预期**:下次提问,AI 带勾选范围内的相关记忆回答。
- **边界**:① 取消全部 → 空召回(不报错,AI 无记忆辅助);② 首次无历史默认勾{个人};③ 勾了离职人员但「同步已离开人员」开关关 → 仍不召回(**开关优先级高于多选**);④ 多选 = 并集(个人+项目记忆都参考)。

## 3. 设写入目标(新记忆落哪里)
- **入口**:聊天底栏写入目标选择器(非项目会话无此项,恒个人)。
- **步骤**:勾 个人 / 项目。默认勾{个人}。
- **预期**:勾个人 → 新记忆个人私有;勾个人+项目 → 个人出身+叠加共享给该项目成员;显式取消个人仅勾项目 → 纯项目出身(个人记忆页看不到)。
- **边界**:① 卸空所有项目 → 自动转个人出身(防无归属);② 首次勾项目弹确认(含 12h 规则提示:被他人引用超 12h 的记忆删不了);③ 首次取消{个人}弹确认;④ **默认不跟随召回范围**(避免读项目记忆时自己的新隐私被共享)。

## 4. 手动总结(把流水账压成精华)
- **入口**:记忆抽屉「总结」页签 →「开始总结」。
- **步骤**:弹框列出 {个人} ∪ {你参与的 ACTIVE 项目} → 每 scope 标可选(有变化)/灰选(无变化)→ 勾选 →(项目)选取数范围 [MemoryConsolidationPeoplePicker](../../../frontend/src/components/memory/MemoryConsolidationPeoplePicker.vue)(人员:仅自己/某几人/全员;方向)→ 确认。
- **界面变化**:跑完后总结页出精华条,带溯源(来自哪些流水账)+状态徽标。
- **预期**:精华条 `user_id=你`、只你能读;被选人员的流水账喂进你的总结。
- **边界**:① 无变化 scope = 灰选不可点;② 独立于 gen/总结开关;③ 项目总结取数离职人员开关关时离职人员既不召回也不进总结。

## 5. 加自动总结(每天定时跑)
- **入口**:同「开始总结」弹框 → 勾「加入每日自动总结」。
- **预期**:勾上的 scope 每天定时跑;默认勾{个人}(项目主动加);**该 scope 该周期无新增未总结流水账时空跳过不耗 token**。

## 6. 裁决冲突(住萧山 vs 住拱墅)
- **入口**:记忆抽屉「冲突裁决」页签([MemoryConflictSection](../../../frontend/src/components/memory/MemoryConflictSection.vue))。时序矛盾时出 pending 行。
- **步骤**:点待裁决行 → 弹框 [MemoryConflictJudgeDialog](../../../frontend/src/components/memory/MemoryConflictJudgeDialog.vue) → 选 都留 / 新的 / 旧的 / 丢弃 →(丢弃二次确认)。
- **预期**:都留 → 两条按时间排序都留;新的/旧的 → 留一条另一条软删;**丢弃 → 连带软删该总结及其全部源流水账**(防死循环)。
- **边界**:① 非作者不可裁决(只作者改自己的);② 丢弃时源流水账被他人引用且引用方总结超 12h → 拒 403,提示改「都留/旧的」;③ 项目内不产生跨用户冲突(别人改不了你的)。

## 7. 管理标签库
- **入口**:「标签库」页签([MemoryTagLibrary](../../../frontend/src/components/memory/MemoryTagLibrary.vue))。
- **步骤**:改标签展示名(label)/ 补别名(aliases)。
- **预期**:tag_id 不变,只影响展示;补的别名参与后续写时归一同义命中。
- **边界**:**禁手动合并/拆分/重抽**(误并不可逆,会让已生成总结的 tag_id 漂移)。

## 8. 设生成开关(开/关 L0/L1/L2 生成)
- **入口**:「生成矩阵」页签([MemoryGenMatrixPanel](../../../frontend/src/components/memory/MemoryGenMatrixPanel.vue))。
- **步骤**:owner 改项目级开关 / 会员改个人覆写开关。
- **预期**:两层都开才生成;关后新对话不调生成 LLM(仍留 raw)。
- **边界**:① owner 关 → 会员覆写无效(项目侧不生成);② 会员关+owner 开 → 仍留 raw 不生成;③ 非项目会话读全局兜底;④ 三层同开同关。

## 9. 配项目 ACL(谁能读谁的流水账)
- **入口**:「项目 ACL」页签([MemoryProjectAclPanel](../../../frontend/src/components/memory/MemoryProjectAclPanel.vue))。仅 owner 或 recall_admin 可配。
- **步骤**:花名册(含已离开)→ reader×target 矩阵勾授权 → 即时保存(全量替换)。
- **预期**:owner 默认全读无需配;其他成员按授权集+自己可读;**单套 ACL 同时管召回读取与总结取数**。
- **边界**:已离开人员留 target 列、剔 reader 行(保交接)。

## 10. 生命周期(离职/被删项目后拉回自己的记忆)
- **入口**:「生命周期」页签([MemoryLifecyclePanel](../../../frontend/src/components/memory/MemoryLifecyclePanel.vue))。已离开项目 / 已删除项目两个折叠板。
- **步骤(已删除)**:有未处理记忆时折叠板 badge 高亮 → 展开 → 新建项目 →「拉取」(restore)。
- **步骤(已离开)**:展开 →「复制到自建新项目」(copy-to)。
- **预期**:restore/copy-to = 把你的流水账挂到新项目;**原项目零改动、别的成员照常**(copy 非 move)。
- **边界**:① 仅拉流水账,不拉总结;② 离职后不可再选原项目作召回 scope;③ 个人出身记忆不受影响仍经个人 scope 召回。

## 11. 查看波及通知
- **入口**:聊天页右上角 badge([MemoryNotificationBadge](../../../frontend/src/components/memory/MemoryNotificationBadge.vue))。
- **触发**:别人撤回记忆波及你的总结 / 你参与的项目被删。
- **预期**:badge 计数 + 下拉列表 +「全部已读」;worker 重生完成后通知自动标已处理。

## 12. 查看/删除原文(raw)
- **入口**:「流水账」页签 → 切「raw」视图。
- **步骤**:查看本人原文 / 单删 / 批量删(勾选行)。
- **预期**:仅本人;无导出;删后级联受影响总结标 STALE 待重生。
- **边界**:被他人引用且引用方总结超 12h 的 → 拒删 403;无他人引用 → 随时删。
