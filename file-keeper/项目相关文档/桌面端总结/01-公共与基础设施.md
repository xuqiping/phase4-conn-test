## 2. 前端入口与全局挂载

### 2.1 `file-keeper/src/main.ts`
- 使用 `createApp` 创建 Vue 3 应用实例。
- 根据 URL 参数 `screenshotOverlay` 判断当前窗口类型：若为截图遮罩窗口则挂载 `ScreenshotOverlayHost`，否则挂载根组件 `App.vue`。
- 注册 Pinia（`createPinia()`）并应用持久化插件 `createPersistPlugin()`。
- 导入全局样式 `./styles/global.css`。
- **开发环境约定**：在 `DEV` 模式下将 `pinia` 暴露到 `window.__PINIA__`，便于调试。

### 2.2 `file-keeper/src/App.vue`
- **单一根组件**，承载整个应用 UI 布局：
  - 顶部自定义标题栏（`data-tauri-drag-region` 支持拖拽，含最小化/最大化/关闭按钮）。
  - 主标签栏：`files`（文件管理）、`processes`（进程管理）、`clipboard`（剪贴板）。
  - 批量操作悬浮条（基于 `selectionStore` 的选中状态）。
  - 文件管理区：支持网格/列表双视图、虚拟滚动、图标懒加载、拖拽添加、右键菜单、分组标签栏。
  - 进程管理区：`<ProcessManagement />`。
  - 剪贴板管理区：`<ClipboardManagement />` + `<ClipboardQuickPanel />`。
  - 各类对话框：认证、设置、分组管理、编辑文件、进程关闭确认等。
- **全局快捷键管理**：在 `onMounted` 中注册三组 Tauri 全局快捷键（主窗口显隐、剪贴板快捷面板、截图遮罩），并在 `onUnmounted` 中清理。
- **Tauri 事件监听**：
  - `screenshot://capture` — 接收截图区域并完成截图保存。
  - `screenshot://cancel` — 取消截图并关闭遮罩窗口。
  - `onDragDropEvent` — 接收系统拖拽文件路径并批量导入。
  - `onCloseRequested` — 拦截关闭事件，若开启“最小化到托盘”则改为隐藏窗口。
- **商业授权集成**：通过 `commercialAuthStore` 控制各标签页的可用性；未授权时显示 `FreeModuleSelector`。

## 3. 全局状态与插件

### 3.1 Pinia 持久化插件 `file-keeper/src/plugins/persistPlugin.ts`
- 基于 Tauri `tauri-plugin-store` 实现 Pinia 状态的磁盘持久化。
- 通过 `StorePersistOptions` 为每个 Store 配置：
  - `key`：存储键名。
  - `path`：持久化文件路径（默认 `file-keeper-data.json`）。
  - `paths`：限定需要持久化的状态字段（白名单）。
  - `importantActions`：指定需要立即 `flush` 的关键 action。
  - `debounceMs`：自动保存防抖间隔（默认 500ms）。
- 扩展 Pinia 类型声明，注入 `$persistReady: Promise<void>`，供组件在挂载时等待数据恢复完成。
- 使用 `apiCache` 缓存同路径的 `PersistAPI` 实例，避免重复创建。

### 3.2 `settingsStore.ts` — 全局设置
- 状态：`theme`（`light`/`dark`/`auto`）、`defaultView`（`grid`/`list`）、`globalShortcut`、`clipboardShortcut`、`screenshotShortcut`、`minimizeToTray`、`autoStart`、`language`、`itemsPerPage`、`iconMode`（`real`/`generic`）。
- 计算属性：`effectiveTheme` — 当 `theme === 'auto'` 时根据系统暗色偏好自动切换。
- 持久化配置：`paths: ['settings']`，关键 action 立即 flush。
- **被依赖**：`App.vue`（主题切换、快捷键注册、视图模式）、`SettingsDialog.vue`。

### 3.3 `selectionStore.ts` — 文件多选状态
- 状态：`selectedIds: Set<string>`。
- 计算属性：`selectedCount`、`hasSelection`。
- 方法：`toggleSelection`、`selectAll`、`clearSelection`、`isSelected`。
- **被依赖**：`App.vue`（批量操作条、网格/列表视图的复选框）、文件卡片点击（Ctrl/Cmd 多选）。
- **注意**：该 Store **不配置持久化**，页面刷新后选中状态自动清空。

## 8. 平台抽象层（`platform/`）说明

平台模块通过条件编译（`#[cfg(target_os = ...)]`）为不同操作系统提供统一的原生能力接口。

### 8.1 模块结构

```
file-keeper/src-tauri/src/platform/
├── mod.rs                      # 公共类型 ProcessInfo + ProcessMatcher trait
├── linux.rs                    # Linux 进程匹配（/proc/[pid]/fd 扫描）
├── macos.rs                    # macOS 进程匹配（lsof + sysinfo）
├── windows/
│   ├── mod.rs                  # Windows 子模块声明
│   ├── clipboard.rs            # Windows 原生剪贴板读写（CF_UNICODETEXT/CF_HDROP/CF_DIB/PNG）
│   ├── foreground.rs           # 获取前台窗口 + 模拟 Ctrl+V 自动粘贴
│   ├── process_mappings.rs     # 进程分类映射（推断）
│   ├── process_monitor.rs      # Windows 进程枚举与监控（推断）
│   └── screenshot.rs           # Windows 截图/OCR（推断）
└── windows_file_matcher.rs     # Windows 专用：通过窗口标题匹配打开某文件的进程
```

### 8.2 关键平台实现

| 文件 | 平台 | 职责 |
|------|------|------|
| `platform/mod.rs` | 全平台 | 定义 `ProcessInfo`（pid, name, path, window_title, associated_file）和 `ProcessMatcher` trait（`find_processes_for_file`、`kill_process`） |
| `platform/linux.rs` | Linux | 通过 `/proc/[pid]/fd` 读取符号链接，匹配文件绝对路径；使用 `sysinfo` 获取进程信息 |
| `platform/macos.rs` | macOS | 通过 `lsof` 命令查找持有目标文件的进程；使用 `sysinfo` 获取进程信息 |
| `platform/windows_file_matcher.rs` | Windows | 通过 `EnumWindows` 枚举所有窗口，获取窗口标题并与文件名/路径匹配；使用 `sysinfo` 终止进程 |
| `platform/windows/clipboard.rs` | Windows | 直接调用 Win32 API（`OpenClipboard`、`GetClipboardData`、`SetClipboardData`）读写文本、文件列表（HDROP）、图片（DIB/DIBV5/PNG）。包含 `dib_to_png_bytes` 转换函数，支持 24/32 位 DIB 转 PNG |
| `platform/windows/foreground.rs` | Windows | `current_foreground_window()` 获取当前前台窗口句柄；`restore_and_paste()` 恢复最小化窗口并发送 `Ctrl+V`（用于剪贴板“自动粘贴到原窗口”功能） |

### 8.3 测试
- `platform/windows/clipboard.rs` 底部包含 `#[cfg(test)]` 模块，测试 `dib_to_png_bytes` 对 24 位 DIB 的转换正确性。

## 11. 已知约定与注意点

### 11.1 前端约定
- **Vue 3 + Composition API + `<script setup>`**：`App.vue` 完全使用组合式 API。
- **Tailwind CSS v4**：使用 `@import "tailwindcss"` 和 `@theme` 自定义变量，而非传统的 `tailwind.config.js`。
- **图标库**：`lucide-vue-next`，所有图标按需导入使用。
- **路径别名**：`@/` 映射到 `src/`（由 `vite.config.ts` 配置）。
- **截图遮罩窗口**：通过 URL 参数 `?screenshotOverlay` 区分，独立渲染 `ScreenshotOverlayHost`，与主窗口共享同一份构建产物。
- **图标懒加载**：使用单个全局 `IntersectionObserver` + 队列（最大并发 3）+ `requestIdleCallback` 降级，避免阻塞主线程；图标模式切换时会清空缓存并触发重新加载。
- **虚拟滚动**：`useVirtualScroll` 分别用于网格（每行 5 个，itemHeight 220）和列表（每行 1 个，itemHeight 60），提升大列表性能。

### 11.2 后端约定
- **Rust 版本**：`edition = "2021"`，`rust-version = "1.70"`。
- **Tauri v2**：使用插件化架构（`tauri-plugin-*`），所有前端能力通过权限（capability）显式授予。
- **剪贴板服务**：`ClipboardService` 在 `main.rs` 的 `setup` 中创建并 `manage` 到 Tauri 状态，后续命令通过 `app.state::<ClipboardService>()` 获取。
- **离线授权**：`OfflineTokenState` 同样通过 `manage` 注入，供 `set_offline_token` / `check_offline_access` 等命令使用。
- **Windows 专属依赖**：`windows = "0.58"` 开启大量 Win32 API feature（窗口管理、线程、剪贴板、GDI、文件系统、OCR 等）。
- **macOS 专属依赖**：`cocoa`、`objc`、`core-foundation`。
- **进程匹配策略**：
  - Windows：通过窗口标题字符串匹配（`EnumWindows` + `GetWindowTextW`）。
  - macOS：通过 `lsof` 查找文件句柄。
  - Linux：通过 `/proc/[pid]/fd` 符号链接匹配。

### 11.3 安全与权限注意
- `csp: null` 当前未启用内容安全策略，生产环境建议补充。
- `assetProtocol.scope: ["**"]` 范围较宽，允许 WebView 访问任意本地文件路径；若需收紧可改为特定目录。
- `fs:allow-home-read-recursive` / `fs:allow-home-write-recursive` 权限较宽，允许递归读写用户主目录。
- 全局快捷键注册失败时（与系统冲突），前端会弹出 `alert` 提示用户更换组合键。

### 11.4 性能与体验注意
- **启动性能**：`App.vue` 在 `onMounted` 中记录 `performance.now()` 计算并打印启动耗时和加载文件数。
- **关闭行为**：若开启 `minimizeToTray`，点击关闭按钮或拦截 `onCloseRequested` 都会隐藏窗口而非退出进程；托盘菜单提供“退出”选项彻底结束应用。
- **剪贴板监控生命周期**：`App.vue` 根据 `clipboard` 模块授权状态动态启停剪贴板监控（`clipboardStore.startMonitor()` / `stopMonitor()`），避免无授权时浪费资源。
