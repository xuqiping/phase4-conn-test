# 3.1 交互设计基础

## A.01 核心定义

**交互设计（Interaction Design, IxD）** 是定义交互式数字产品行为的设计领域——关注"用户做什么→系统如何响应→下一个状态是什么"的行为闭环。由Bill Moggridge和Bill Verplank于1980年代提出。[来源: Moggridge, 2007 "Designing Interactions" | 置信度:🔍高]

**一句话定位**：交互设计 = 定义"用户与产品之间的对话方式"——每一次点击、滑动、输入、语音指令，都是用户在"说话"；每一个反馈、动效、状态变化，都是产品在"回应"。

## A.02 设计对象的复杂度谱系

| 复杂度 | 交互层级 | 典型场景 |
|---|---|---|
| 微交互级 | 单一动作+即时反馈 | 点赞/开关/收藏 |
| 流程级 | 多步骤线性流程 | 注册/下单/支付 |
| 状态级 | 多状态间的切换与转换 | 编辑/预览/空/加载/错误 |
| 系统级 | 复杂交互系统与生态 | 多端协作/权限体系/工作流 |
| AI交互级 | 人机协同的开放式对话 | AI助手/对话式产品/Skills调用 |

## A.04 边界与不含什么

**交互设计包含**：交互行为定义、状态机设计、反馈机制、输入方式设计、异常处理逻辑、微交互与动效逻辑。

**交互设计不含**：信息结构（→D-05.01）、视觉表现（→D-05.04）、原型制作技术（→D-05.03）、前端实现方案、内容创作。

## B.02 交互设计的六维度

Gillian Crampton Smith 提出的交互设计四维度 + 后续扩展的2维度：[来源: Crampton Smith, 1995; Silver, 2006 | 置信度:🔍高]

| 维度 | 关注 | 设计决策 |
|---|---|---|
| 1D-文字 | 语言与文案 | 按钮文案/提示语/空状态文案/错误信息 |
| 2D-视觉表现 | 图形/排版/图示 | 视觉层级/图标风格/色彩编码 |
| 3D-物理实体与空间 | 硬件/空间/触摸 | 设备尺寸/触控区域/手势感应范围 |
| 4D-时间 | 时序/变化/节奏 | 动效时长/加载等待/响应时序 |
| 5D-行为 | 交互行为与响应 | 触发条件→响应动作→状态转换 |
| 6D-情感 | 情感化设计元素 | 惊喜微交互/幽默文案/愉悦动效 |

## I.01 核心术语

| 术语 | 定义 |
|---|---|
| 交互(Interaction) | 用户行为与系统响应的双向信息交换 |
| 微交互(Micro-interaction) | 完成单一任务的小型交互单元（如开关/点赞） |
| 状态机(State Machine) | 系统在不同状态间的转换逻辑 |
| 反馈(Feedback) | 系统对用户行为的即时响应信号 |
| 亲和力(Affordance) | 界面元素暗示其使用方式的设计属性 |
| 约束(Constraint) | 限制用户可能操作的规则，防止错误 |
| 映射(Mapping) | 控制元素与受控对象之间的对应关系 |
| 交互范式(Interaction Paradigm) | 人机交互的主导模式（CLI→GUI→NUI→AI） |
| 渐进式披露(Progressive Disclosure) | 按需逐步展现复杂信息/选项 |
| 静谧界面(Calm Interface) | 低认知负荷、克制动效、仅在必要时打扰用户的设计 |
