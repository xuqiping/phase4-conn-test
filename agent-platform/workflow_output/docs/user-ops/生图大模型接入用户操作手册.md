# 图片生成 · 用户操作手册

> 谁用：需生图的创作者（须有 `media:gen` 权限）。场景：文生图、参考图生图、组图批量、资产库参考图复用、生成图入库。效益：两个 Seedream 模型按官网参数生图，一键入库复用。

## 功能入口

左侧菜单「图片生成」（需 `media:gen` 权限，无权限不显示）。直访 `/image-gen` 无权限显示提示。

## 前置（admin 一次性）

1. 「设置→全局模型供应商」建一条 **IMAGE 类 provider**：name=`ctaigw-image`、category=IMAGE、apiEndpoint=`https://ai.ctaigw.cn/v1/images/generations`、apiKeyEnc=填真实 ctaigw key、models 两模型。
2. 「积分计费→价表」配两模型 `price_per_image`（按张）。
3. 给需用角色授 `media:gen`。

## 历史区

右侧底部「历史」：仅图片任务（视频任务不会混入，反向亦然）。

**筛选**：顶部筛选条——提示词子串 + 时间范围，输完 0.3 秒自动查询；「清空」恢复全部。时间范围点完起止两天即生效（含结束日全天）。

**缩略图**：成功的记录右侧直接显示首张小图（滚到才加载）；点缩略图放大看，不会切换结果区。失败/进行中的记录显示「—」占位。

**点记录还原参数**：点某行 → ①结果区加载该任务图网格（未完成的继续轮询）；②左侧表单自动填回当时的全部参数：模型/提示词/尺寸（自定义尺寸回填原文）/输出格式/提示词优化/引导尺度/组图张数/联网/水印/**参考图**（逐张从库里拉回缩略）。不会自动提交——改完参数可再点「生成图片」复用。

**核对发送参数**：结果区「请求参数」按钮 → 弹窗看当时提交的完整 JSON（含参考图 refFileIds，可核对参考图是否正确发送）。「实际发给模型」页签对图片任务显示「未记录发送快照」——以提交参数页签为准。

**异常提示**：
- 参考图已被删除/无权 → 弹「N 张参考图已失效」，其余参数正常还原。
- 参考图张数超当前模型上限 → 截断并提示。
- 模型已被管理员下线 → 顶部显「模型已下线」警告条，表单隐藏不可提交，但「请求参数」仍可核对。

## 常见异常与恢复

| 现象 | 原因 | 恢复 |
|---|---|---|
| 提交报「余额不足」 | 余额 0 或预检失败 | 充值后再提交 |
| 任务 FAILED「key 相关」 | ctaigw key 失效/未填 | admin 在 provider 设置填有效 key |
| 任务 FAILED 不计费 | 价表未配 price_per_image | admin 配两模型价表 |
| 看不到菜单 | 无 media:gen 权限 | 找 admin 授权 |
| 入库 403 | 目标项目仅 viewer | 换可写项目或找 owner 升权 |
| 网格某张占位失败 | 该张 data[].error | 其余正常；计费按实际成功张数 |
| 还原后参考图缺几张 | 原参考图已删/无权 | 重选参考图后再生成 |
| 历史行显「模型已下线」 | admin 删了该模型 | 换在架模型重新配参数；参数可从「请求参数」弹窗抄 |
| 筛选无结果 | 提示词/时间条件过严 | 「清空」恢复全量 |
