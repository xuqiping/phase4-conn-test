# 一、4 套 SOP

## SOP 1：场景适配判断（先决策该不该拆）—— 30 分钟

**目标**：80% MAS 翻车源于本该不拆却硬拆。本 SOP 保证 30 分钟内决策"该不该拆"。

**步骤**：

1. **任务盘点**（5 分钟）：写清任务类型 / 子任务数 / 上下文规模 / 实时性 / 模型能力等级
2. **三条件检查**（10 分钟）：填模板 T1《场景适配检查表》——关注点分离 ✅/❌ + 并行探索 ✅/❌ + 上下文隔离 ✅/❌。三者必须同时 ✅
3. **红线触发判定**（5 分钟）：检查 6 条不拆红线（串行推理 / 上下文够 / 任务简单 / 阈值未到 / 无客观验证 / Real-time）
4. **路线推荐**（5 分钟）：三条件全 ✅ + 无红线 → Anthropic MAS 路线；任一不满足 → Cognition 单 Agent + 长上下文压缩 或 D-24.04 工作流
5. **收益成本预估**（5 分钟）：MAS 收益估算 - 15x token 成本 - 协调失败风险溢价（基于 Gartner 65% 失败率）

**关键判定标准**：智能阈值未到 → 不拆；任务强串行 → 不拆；上下文可压缩 → Cognition 路线；上下文隔离成立 + 并行探索成立 → MAS。

## SOP 2：拓扑与通信选型 —— 1-2 小时

**目标**：在判定为 MAS 后，1-2 小时内确定拓扑 + 通信协议。

**步骤**：

1. **拓扑匹配**（30 分钟）：用模板 T2《拓扑选型决策矩阵》让 8 种拓扑 × 任务特征打分，得分最高的为推荐拓扑
2. **Anthropic 工作流模式匹配**（15 分钟）：5 种工作流模式（提示链/路由/并行化/编排者-执行者/评估器-优化器）哪个最贴近
3. **三基因轴分析**（15 分钟）：控制拓扑 + 通信模式 + 状态管理 三轴组合确认
4. **通信原语选型**（15 分钟）：填模板 T3《通信协议对照表》—— Blackboard / MessageBus / SharedMemory 三选一或组合
5. **协议栈选型**（15 分钟）：MCP（工具调用必选）+ A2A（跨 Agent 必选）+ ACP（边缘可选）+ Skill（无状态能力）
6. **同步异步策略**（15 分钟）：同步请求-响应 / 异步事件驱动 / SSE 流式 三选一或组合

**关键约束**：Hierarchical ≤3 层 + P2P/Mesh Agent ≤5 + 辩论用不同模型 + Generator/Validator 不共享同源 prompt。

## SOP 3：失败恢复设计 —— 2-3 小时

**目标**：65% 企业 MAS 因协作失控失败，本 SOP 系统化设计失败恢复。

**步骤**：

1. **Berkeley 14 失败模式自查**（30 分钟）：用模板 T5《失败模式自查清单》逐项检查
2. **MAST 分类归因**（30 分钟）：把可能触发的失败按 Specification / Coordination / Interdependence / Execution 四类归因
3. **L1-L5 恢复配置**（30 分钟）：每级触发条件 + 动作。L3 绕路与 L4 重规划是多 Agent 独有
4. **三层超时熔断**（30 分钟）：调用级（30秒/分钟）+ Agent 级（连续 N 次失败熔断）+ 流程级（兜底）
5. **死锁预防**（30 分钟）：禁循环依赖 + 最大调用深度 + wait-die/wound-wait 算法
6. **高风险步骤标 L5 人工接管**（30 分钟）：识别所有"出错代价高"步骤，配人工接管触发

**关键产出**：失败恢复设计文档 + 三层熔断配置 + 死锁预防方案 + 高风险步骤清单。

## SOP 4：安全边界设计 —— 2 小时

**目标**：A2A 让攻击面扩大 N 倍，本 SOP 系统化设计安全边界。

**步骤**：

1. **OWASP MCP Top 10 自查**（30 分钟）：逐项检查 [来源:OWASP / 腾讯云 | 🔍高 | 2026-05]
2. **最小权限矩阵**（30 分钟）：每个 Agent → 工具集 → 数据访问范围 → 操作权限。Executor 不能给全部工具
3. **沙箱隔离配置**（20 分钟）：高风险 Agent 必须沙箱。Manus 每任务一台云虚拟机是最佳实践
4. **跨 Agent 注入防护**（20 分钟）：A2A AgentCard 签名验证 + 输入过滤 + 输出验证
5. **影子 Agent 防御**（10 分钟）：监控所有运行 Agent + 未授权 Agent 立即告警
6. **跨组织权限矩阵**（10 分钟）：跨组织互联必须有权矩阵 + 数据脱敏

**关键产出**：OWASP 自查表 + 权限矩阵 + 沙箱方案 + AgentCard 签名验证方案 + 影子 Agent 监控方案。
