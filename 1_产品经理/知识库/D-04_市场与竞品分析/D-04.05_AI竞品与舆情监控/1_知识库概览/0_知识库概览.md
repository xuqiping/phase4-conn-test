# AI竞品与舆情监控

> **是什么**：利用AI技术自动化、持续化地监控竞品动态（产品更新、定价变化、营销动作）和品牌舆情（用户评价、舆论走向、危机信号），将"手工情报收集"升级为"智能情报系统"。

> **为什么重要**：2025-2026年，竞品动态感知延迟从"周级"压缩到"分钟级"——海外竞品新功能上线平均比本土感知早4.2周。不做AI竞品监控 = 系统性信息劣势。舆情危机的黄金响应窗口也从"24小时"缩短至"2小时"，AI监控是唯一能做到实时的方式。

> **何时进入**：完成竞品分析(D-04.02)后，当竞品数量>5或舆情关注点>3时，从"手工分析"升级为"AI监控"。

> **关键词**：竞品情报自动化 / 舆情实时监控 / 社交聆听 / 情感分析 / 预警系统 / AI竞对追踪 / 品牌健康度 / 危机信号检测
