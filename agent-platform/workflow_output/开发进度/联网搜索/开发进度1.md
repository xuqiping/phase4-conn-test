## 2026-07-19 · Step2：自建引擎 BuiltIn（SearXNG + 抽取）

**plan 编号**：Step 2（路径 B：代码+单测先，SearXNG 真连通冒烟待人工部署后补）
**commit**：`12c6de0d`

### 做了什么
实现对标 Tavily 的自建引擎：SearXNG 拿 URL → Jsoup+自实现 Readability 抽正文 → SSRF 防护 + sanitize。

### 涉及文件（全新建）
| 文件 | 用途 |
|---|---|
| [search/util/SanitizeUtil.java](../../../backend/src/main/java/com/superprogrammer/search/util/SanitizeUtil.java) | sanitizeText(去控制/零宽/折叠空白/截断) + assertPublicUrl(SSRF 拒私有/环回/链路本地/组播) |
| [search/util/ContentExtractor.java](../../../backend/src/main/java/com/superprogrammer/search/util/ContentExtractor.java) | Jsoup 抽正文：article→p 密度最大块→全 p 聚合→body 兜底；script/style/nav 清场 |
| [search/client/SearxngClient.java](../../../backend/src/main/java/com/superprogrammer/search/client/SearxngClient.java) | SearXNG JSON API(WebClient) + fetchContent(Jsoup 直抓,含 SSRF 校验)；@Setter base-url 供 mock |
| [search/provider/BuiltInSearchProvider.java](../../../backend/src/main/java/com/superprogrammer/search/provider/BuiltInSearchProvider.java) | 编排：SearXNG top N → 并发(线程池≤5)抽正文 → 组装 SearchResult(score 按序递减) |
| [pom.xml](../../../backend/pom.xml) | 加 jsoup 1.18.3 |
| test/.../SanitizeUtilTest.java | 8 例：sanitize 截断/控制字符 + SSRF 拒 127/10/192.168/172.16/localhost/file scheme + 放行 example.com |
| test/.../ContentExtractorTest.java | 6 例：article 优先/密度块/fallback p 聚合/空 HTML/截断/script 剔除 |
| test/.../SearxngClientTest.java | 5 例：未配置返空/JSON 解析/maxResults 截断/5xx+非 JSON 返空/SSRF 拒内网 |
| test/.../BuiltInSearchProviderTest.java | 5 例：available/带正文抽取/snippet-only/零结果/未配置 |

### 关键设计点 / 与 plan 偏差
- **Readability 自实现精简版**（非引第三方库）：article → p 密度最大块(≥3 p) → 全 p 聚合 → body 兜底；plan 允许。
- **并发抽正文用固定线程池(5)** 而非 plan 写的 `Flux.merge`：接口是同步 List，线程池+CompletableFuture 更直观可测；功能等价。
- **SSRF 校验**：解析所有 A/AAAA 记录，任一落私有段即拒；防 IPv4 公网+IPv6 内网绕过。DNS rebinding 不防（注明局限，SearXNG 作出口代理已收口）。
- **失败一律返空/不抛**：SearXNG 5xx/非 JSON、抓取超时、SSRF 命中 → 返空，service 层据此降级。
- 修坑：Jsoup.parse(html, null baseUri) 抛 NPE → ContentExtractor 内 null→""。

### 安全检查（plan 清单，本 chunk 涉及）
- ✅ SSRF 防护：assertPublicUrl（单测覆盖 127/10/192.168/172.16/localhost/file scheme）
- ✅ sanitize：去控制字符 + 折叠空白 + 截断（防 prompt 注入）
- ✅ 抓取超时：单页 8s + maxBodySize 512KB
- ✅ UA 伪装 + 依赖安全 jsoup 1.18.3（pom 注释标注升级时复核 CVE）

### 运维埋点（plan 清单，本 chunk 涉及）
- ✅ 可观测：slf4j 日志（query 脱敏截断 80 字符防日志注入）

## 2026-07-19 · Step4：WebSearchService 路由 + 降级链

**plan 编号**：Step 4
**commit**：`310eb7fb`

### 做了什么
统一入口：按 `search.active_provider` 路由 → 不可用降级 builtin → 外部空降 builtin → 全空返空。query sanitize + 外部重试 1 + 审计日志（traceId/脱敏 query/耗时）。

### 涉及文件（全新建）
| 文件 | 用途 |
|---|---|
| [search/config/SearchConfig.java](../../../backend/src/main/java/com/superprogrammer/search/config/SearchConfig.java) | 读 system_settings 默认值(enabled/active/maxResults/timeoutMs)→ 组装 SearchOptions |
| [search/service/WebSearchService.java](../../../backend/src/main/java/com/superprogrammer/search/service/WebSearchService.java) | 路由+降级链主逻辑；注入 List<WebSearchProvider> 按 name 建 map |
| test/.../WebSearchServiceTest.java | 10 例：总开关关/空 query/外部不可用降 builtin/外部空降 builtin/全空返空/builtin 直走/builtin 不可用不崩/外部重试命中/builtin 不重试/provider 抛异常吞掉 |

### 关键设计点 / 与 plan 偏差
- **provider 注入用 `List<WebSearchProvider>`**：Spring 自动收集所有 bean，service 按 `getName()` 建 map 找 active；新增 provider 只需加 `@Component` 不改 service。
- **"空结果"=可能失败**：provider 契约失败返空不抛，service 把外部空结果当"可能失败"触发一次 builtin 兜底（真零结果极罕见，可接受多一次 builtin 调用）。builtin 空不二次兜底（避免无限递归）。
- **外部重试 1**：`callWithRetry` 对非 builtin provider 重试 1 次（plan「重试1」）；builtin 不重试。
- **try-catch 兜底吞异常**：provider 契约不应抛，但若真抛了也吞掉当空走降级链，不阻塞调用方（plan「错误处理：不泄漏内部异常栈」）。
- **审计日志字段**：traceId(UUID 去横线) + query(脱敏截断 80) + provider(含 `builtin(fallback)` 标记) + 结果数 + 耗时 ms。
- **query 校验落 service**：sanitize 去控制字符 + 截断 ≤500（plan 安全项「输入校验」），provider 不重复校验。

### 安全检查（plan 清单，本 chunk 涉及）
- ✅ 输入校验：query 去 control char + 截断 500（sanitizeQuery）
- ✅ 审计日志：query/provider/结果数/耗时/traceId（脱敏 query）
- ✅ 错误处理：失败降级链一路返空不抛，不泄漏内部异常栈（try-catch 兜底）
- ✅ 总开关 `search.enabled`（config.isEnabled，false 直接返空）

### 运维埋点（plan 清单，本 chunk 涉及）
- ✅ 可观测：每次搜索一条 INFO 审计日志 + 降级 WARN + 重试 DEBUG
- ✅ 配置开关：search.enabled / search.active-provider / max-results / timeout-ms 全读 setting
- ✅ 限流/熔断/降级：外部重试 1 + 不可用/空结果降 builtin + 全空返空触发零结果分支
