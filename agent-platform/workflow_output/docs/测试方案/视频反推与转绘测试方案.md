# 视频反推与转绘 · 人工测试方案

> 对应 plan：`docs/plans/视频反推与转绘.plan.md`（Step1-4 已落地，后端 2197 / 前端 599 自动化绿）。
> 本功能涉及多模态 LLM 真实调用（产物质量/计费体感）、FFmpeg 真机行为、跨页面联动——机器测不了，需人工介入。
> 联动用例覆盖 plan 联动点清单 L1-L6（含正向/反向/半选/批量边界）。

## 前置准备

- 账号 `tester`：持 `media:gen` 权限 + 钱包余额 ≥500 分；另备 `other` 账号（造他人任务，验 403）。
- 系统装 ffmpeg ≥4.2 且 `media.reverse.ffmpeg-path` 配置正确（速查表→视频剪辑同款）；管理员模型供应商配好多模态对话模型。
- 测试素材：①10s 干净硬切视频（≥3 场景）；②含渐变转场视频（验兜底）；③>10 分钟视频（验拒）；④一段中国元素明显带台词的短剧（验转绘）。
- 后端起服务、浏览器开 Network 面板（看请求/耗时/取消）。

## 一、来源与产物（两入口通用）

| # | 操作 | 预期 |
|---|---|---|
| A1 | 生成页反推 Tab：默认渲染 | 来源两模式、产物默认仅勾「关键帧」、无来源时「开始反推」禁用 |
| A2 | 上传本地视频（素材①）只勾关键帧 → 开始反推 | 成功；账单**零新增 LLM 消耗**（不调大模型）；时间轴条帧数=命中场景数 |
| A3 | 勾三产物 → 开始反推 | 一次调用出三产物（分镜表/剧本/帧齐）；meta 显示模型名与场景检测命中数 |
| A4 | 素材②（渐变转场）三产物 | 场景命中偏少→自动**均匀采样兜底**，meta 显示「均匀采样兜底」，帧数仍≥4 |
| A5 | 素材③（>10min） | 明确拒绝话术（超时长），不发 LLM |
| A6 | 历史任务下拉 | 仅本人 SUCCEEDED 且有产物的视频任务；other 的任务不可见 |
| A7 | other 账号抓包直接 POST analyze 带 tester 的 taskId | 403（loadForDownload 归属咽喉） |
| A8 | 连续发起 4 次 analyze | 第 4 次 429 限流（3/min） |
| A9 | 传超时坏 JSON 双败场景（难造可跳过，单测已覆盖） | 报「模型未返回合法 JSON，请重试」 |

## 二、画布入口（Step3）

| # | 操作 | 预期 |
|---|---|---|
| B1 | 画布视频节点 → 反推三产物 | 源节点右侧帧列（纵向）+分镜节点+剧本节点，全部自动连边；帧图悬浮放大 |
| B2 | 只勾关键帧 | 只建帧列节点，不建分镜/剧本（账单零 LLM） |
| B3 | 反推失败（临时改坏 ffmpeg 路径） | 源节点标红错误话术，**零半成品节点**；改回后重试成功 |
| B4 | script 节点 →「本土化转绘」弹窗 | 目标地区+保留要求表单；确认后新 script 节点连自原节点，原节点内容不动 |
| B5 | storyboard 节点转绘 | 输入=分镜描述，同样产出新 script 节点 |

## 三、本土化转绘核对（Step2/4）

| # | 操作 | 预期 |
|---|---|---|
| C1 | 素材④剧本 → 转绘目标「美国」，保留要求「保留团圆结局」 | 剧情骨架不变；筷子→刀叉类替换出现在**替换清单**（from/to/位置），逐条可核 |
| C2 | 转绘结果与原稿对比场景数 | 一致；若不一致→黄色警示「场景数不一致：原N现M…请人工核对」但结果仍可用 |
| C3 | 生成页 Tab 转绘后 | 「用剧本生成」按钮文案变「（本土化）」默认取改写版，radio 可切回原剧本 |
| C4 | 目标地区空提交 | 「开始转绘」禁用；地区>32 字/剧本>8000/备注>500 被后端拒（400） |

## 四、联动专项（L1-L6 边界）

| # | 联动点 | 操作 | 预期（反向/半选/取消/批量） |
|---|---|---|---|
| D1 | L1 半选 | 逐个勾/退勾产物组合（仅帧/仅剧本/帧+分镜/全不勾） | 勾啥出啥；全不勾「开始反推」禁用；仅帧零 LLM 计费 |
| D2 | L2 取消 | 三产物反推进行中点「取消」 | toast「已取消」；请求 aborted（Network 可见）；画布/面板**零节点零结果**；重跑同源正常 |
| D3 | L3 转绘不改原稿 | 转绘后查原 script 节点/面板原剧本区 | 原文逐字未动；新产物带 changeLog |
| D4 | L4 冲突三选 | 生成表单已有提示词+参考视频时点「用剧本生成」 | 弹窗三选：取消=表单原样；追加=提示词换行拼接；替换=提示词覆盖+视频槽清空重填源视频。预填后手改内容**不再回弹** |
| D5 | L4 反向 | 表单为空时直接点「用剧本生成」 | 不弹窗直接替换预填，自动切回生成 Tab |
| D6 | L4 首尾帧互斥 | 表单已设首帧时带入 | 参考视频不带入，警告「请先清空首尾帧」；提示词照常预填 |
| D7 | L5 预览边界 | 时间轴帧悬浮/移出/点击灯箱 | 移出即关；灯箱可关；分镜表与帧**无联动**（首版明确不做，别报 bug） |
| D8 | L6 组池 | 选了项目组后 analyze（后端透传 gid 场景：画布入口暂无组选择，生成页 Tab 走个人） | 走 LLM chat 既有计费链路；组池不足同步 402 拒（无在途） |
| D9 | 批量帧 | maxFrames 拉 24 + 长视频（≤10min） | 抽帧耗时可控（<60s 超时杀）；帧图缩略加载齐；计费与提示帧数一致 |
