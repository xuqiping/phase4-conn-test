## 1. 项目概述

- **一句话定位**：DevPilot 是一款 Windows/macOS 桌面端 AI 编程智能体——全覆盖 Codex 级开发能力（本地执行、并行任务、Skills、MCP 双向、CLI/深链开放），并内置 Spec→Plan→Implement→Run 引导式工作流，让零代码用户也能从一句话想法做出可靠产品。
- **背景与动机**：见 [项目分析/0_设计总路由.md](../项目分析/0_设计总路由.md)（设计文档导航）与 [1_产品定位与商业分析.md](../项目分析/1_产品定位与商业分析.md)。核心矛盾：AI 编程能力过剩，但非程序员「无法表达意图、无法验证产出」，安全事故频发；方法论内置是市场空位。
- **商业模式**：Token 充值转售（余额制 + 分模型加价率 + BYOK 逃生通道），本地执行使云端零算力成本。
- **成功指标**（MVP 验收）：①一名零代码测试用户在 Win 或 Mac 上从一句话想法到本机跑起真实小产品，全程无开发者协助；②全程 Token 消耗明细可查；③安全卡点实际拦截过至少一类问题（测试注入）。

## 2. 用户故事

- 作为**一人公司创业者**，我希望用大白话描述想法后被引导着把需求想清楚，以便不用学编程也能开工。
- 作为**零代码用户**，我希望看不懂的 diff/日志/报错都有大白话翻译，以便我知道 AI 到底改了什么。
- 作为**零代码用户**，我希望验收时按清单「点一点」、哪里不对圈出来，以便我能真正验收而不是盲信。
- 作为**独立开发者**，我希望每步自动存档、任意回滚、关掉客户端隔天续跑，以便项目长期可维护。
- 作为**进阶用户**，我希望把常用流程存成技能、用 MCP 接外部工具，以便能力随用随长。
- 作为**第三方应用/脚本作者**，我希望用 CLI/深链/MCP 把任务委派给 DevPilot，以便把它当工作流引擎集成。
- 作为**充值用户**，我希望每次任务花多少 Token 一目了然、回滚不收费，以便放心充值。

- **性能目标** → [performance_goals.md](performance_goals.md)：客户端冷启动 ≤3s、主界面操作响应 ≤100ms、任务流推送延迟 ≤1s、翻译层 P95 ≤3s 等。

## 8. 边界与不做

| 不做 | 说明 |
|---|---|
| 不做自有 IDE | 用 IDE 插件借位（三期） |
| 不做模型自研 | 模型路由接多家供应商 |
| 不做通用 Chat | 垂直开发场景外不服务，对话入口始终挂在项目/任务上下文上 |
| 不做云端沙箱 | 本地执行为主；云端沙箱为远期可选项，MVP 不投入 |
| 不做移动端代码编辑 | 移动端（二期）只做监督面：审批/监控/语音派单 |
| 不做 Web 端开发操作 | Web 仅账号/充值/明细/技能市场门户 |
| 不做团队协作 | Team 能力（共享额度池/审计）三期再议 |
| 不替用户做决定 | 需求歧义必须反问（AC-044）；卡点不可自动跳过 |

## 10. 术语表

| 术语 | 大白话 | 简单案例 |
|---|---|---|
| SDD（规格驱动开发） | 先写清楚「做什么」的文档，再写代码；文档跨会话不丢 | 先确认 8 张需求卡，AI 才开工 |
| Tauri | 用系统自带网页引擎做桌面应用的框架，安装包小、内存省 | DevPilot 客户端本体 |
| MCP | AI 工具的通用插座协议，各家工具即插即用 | 点选安装「数据库查询」工具 |
| Skills | 把一套提示词+流程打包成可复用技能 | 「发版检查」技能一键调用 |
| EARS | 写验收标准的句式模板（WHEN/IF/THEN…），保证每条可测 | 「WHEN 连续输错 5 次，系统应锁定 15 分钟」 |
| BYOK | 用户填自己的模型 API Key，不走平台计费 | 自带 Key 的高级用户零加价 |
| worktree | git 的并行工作区，同一仓库开多个互不干扰的副本 | 并行跑 3 个任务互不打架 |
| 状态机 | 用代码严格定义「当前阶段能做什么」，防止流程走乱 | 需求没确认完，开工按钮锁死 |
| WebView2 | Windows 自带的网页引擎组件，Tauri 在 Win 上依赖它 | 安装客户端时自动检测引导 |
