# 画布与视频生成 · 测试问题修复2 · 开发进度8

> 承 [开发进度7.md](./开发进度7.md)。本篇记 **分镜节点存/取资产库 + 连线可删**（2026-08-09，commit `f210427f`）。

## 背景

人工测试两问题：
1. **分镜节点存入资产库和从库选择不可用**——「我的测试短句里明明有分镜分类的，就算没有也需要可存并创建该分类」。
2. **所有节点之间的连线应该可以被删除**。

## 根因（playwright + 代码深挖）

### 问题1：前端类型字典漏 storyboard（后端已就位）

后端 B1（`dc741bc4`）早已配齐分镜资产映射（`AssetCanvasBridgeService.mapNodeType` storyboard→MEDIA_STORYBOARD + `extractTextContent` 取 description），但**前端两处门控字典只认原 5 类**，storyboard 被拦在前端：

| 文件 | 拦截点 | 现象 |
|---|---|---|
| [SaveToAssetDialog.vue](../../../frontend/src/components/canvas/SaveToAssetDialog.vue) `KIND_LABEL`/`hasOutput` | switch 无 storyboard case → default 返 false | 弹窗显「该节点暂无可入库的产出」，入库按钮 disabled |
| [AssetPicker.vue](../../../frontend/src/components/canvas/AssetPicker.vue) `NODE_TO_MEDIA`/`KIND_LABEL` | storyboard→undefined | `loadAssets` 守卫 `!mediaType` 提前 return，列表恒空 |

### 问题2：连线删除已接线但零视觉反馈

`CanvasBoard` 删除链路**本就完整**：`onEdgeClick`（设 `selectedEdgeId`+focus boardRoot）→ `@keydown.delete/backspace` → `deleteSelected` → `removeEdges`。但 `selectedEdgeId` 是内部状态，**未回灌边渲染**——点边后画面无任何变化，用户以为不可删。

## 落地（commit `f210427f`，5 文件）

| 文件 | 改动 |

| `SaveToAssetDialog.vue` | `KIND_LABEL` + `hasOutput` switch 加 `storyboard`（description 非空即可入库） |
