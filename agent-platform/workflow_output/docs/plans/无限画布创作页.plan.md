## 背景与目标

客户要做 LibTV 式**无限画布**：一张画布上拖 5 类节点（文本/图片/视频/音频/脚本）、自由连线、打组保存、一键重跑、焦点编辑（图上提元素）、故事板剪辑；并内置**视频抽帧**（首/尾/指定秒）与**视频截取**。Agent 自动建流放最后。

- **解决什么**：平台现只有单镜头独立生成页（[VideoGenView.vue](../../../frontend/src/views/VideoGenView.vue)），无画布编排、无节点复用、无抽帧/截取。多镜头叙事/分镜→成片流程缺编排面。
- **复用既有**：视频生成走已落地的 `media/` 包（[MediaGenTaskService](../../../backend/src/main/java/com/superprogrammer/media/service/MediaGenTaskService.java) + `MediaGenProvider` + `mediaTaskExecutor` + `MediaStorageService`）；文本/脚本/音频走 [LlmGateway](../../../backend/src/main/java/com/superprogrammer/llm/LlmGateway.java)；文件落地走 [FileStorageService](../../../backend/src/main/java/com/superprogrammer/file/service/FileStorageService.java) + V40 `stored_files`（新 `SOURCE_CANVAS` 常量）。
- **成功指标**：用户新建画布→拖节点→连线→文本生图→图生视频→抽帧→故事板排列，全链在画布上闭环；零主链路回归（画布走独立包/独立路由/独立执行池，不扰 chat/RAG/memory/工作流编辑器）。

## 架构总览

```
前端 CanvasView (Vue Flow)
  ├─ 5 类节点 shape：Text/Image/Video/Audio/Script
  ├─ 连线 / 打组 / 重跑 / 焦点编辑 / 故事板 / 抽帧截取面板
  │   HTTP (R<T>, JWT)
  ▼
CanvasController (/api/canvas) ── CanvasService（快照 CRUD + 拓扑重跑编排）
  │
  ├─ 节点产出触发（按节点类型分发）：
  │   ├─ 文本/脚本/音频 → LlmGateway.chat / chatStream / embed
  │   ├─ 图片 AI 生图 → MediaGenProvider 新 impl（Seedream，见 R-3）
  │   ├─ 视频 → MediaGenTaskService.submit（多 model 路由 seedance/可灵/海螺）
  │   └─ 抽帧/截取 → VideoFrameService（javacv，见 R-2）
  │
  ├─ 产出物落地 → FileStorageService.storeStream → stored_files(SOURCE_CANVAS)
  └─ 画布快照 → canvases.snapshot JSONB（只存 fileId 引用，不嵌 base64）
```

**关键技术决策**：
1. **画布只读复用 media 包**：不改 `ArkSeedanceProvider`/`MediaGenTaskWorker`；画布的视频节点调 `MediaGenTaskService.submit` + 轮询 `MediaGenQueryService`，与独立页同路径。
2. **快照与产出物分离**：画布结构（节点/连线/位置）存 `canvases.snapshot` JSONB；图/视频/音频**产出物**存 `stored_files`，快照里只放 `fileId` 引用——避免 JSONB 撑爆、支持增量。
3. **执行隔离**：画布重跑走**新建 `canvasTaskExecutor`**（core2/max4/queue100/AbortPolicy，照 [MediaTaskExecutorConfig](../../../backend/src/main/java/com/superprogrammer/media/config/MediaTaskExecutorConfig.java)），不复用 media/chat 池，互不饿。
4. **拓扑重跑**：一键重跑先对选中子图做**拓扑排序 + 环检测**（有环报错），按序提交各节点任务，并发上限可控。
5. **抽帧后端化**：sidecar 禁 subprocess（AGENTS），故抽帧走后端 javacv（纯 Java，无系统依赖），不进 sidecar。

## ⚠️ 对原有功能影响分析（零回归）

| 点 | 影响? | 规避 |
|---|---|---|
| 新增 `canvas/` 包（独立于 llm/chat/knowledge/media/workflow） | 否 | 全新模块，无交叉 |
| 复用 media 包 | 低 | **只读调用** `MediaGenTaskService`/`MediaGenQueryService`，不改 media 任何类；视频节点 = 另一个 `submit` 调用方 |
| 复用 FileStorageService | 低 | 新 `SOURCE_CANVAS` 常量 + 子目录 `canvas/`，不动现有上传 |
| 复用 LlmGateway | 否 | 文本/脚本节点等同多一个调用方 |
| 新增 javacv 依赖 | 低 | 仅 `VideoFrameService` 用，jar 重（~200MB）但不扰运行时；按 R-2 评估 ffmpeg-via-ProcessBuilder 替代 |
| 前端新增路由/导航 | 否 | 独立 `/canvas` 路由 + Sidebar 条目，不改现有页 |
| 现有 Vue Flow 工作流编辑器 | 否 | 画布与工作流编辑器**并存**（工作流=编排引擎 DAG，画布=创作面），互不干涉 |

**结论**：全功能在新包/新表/新池/新路由内闭环，零回归。

## 技术实现坑点预判与规避措施

| 坑 | 规避 | 验证 |
|---|---|---|
| ~~R-1 tldraw 是 React 仅，集成需双运行时~~ **已解决（2026-08-04 改 Vue Flow）** | LibTV 画布=节点图+连线非自由涂鸦；`@vue-flow/core ^1.41.5` 已装、Vue 原生、团队在用 → 改用 **Vue Flow**，弃 tldraw 省 React 运行时成本 | C2 走 Vue Flow，无需引 react/veaury |
| **R-2 平台零视频抽帧/处理能力**（0 ffmpeg/javacv） | 引入 **javacv（bytedeco）** 纯 Java 自包含（jar 重但无系统依赖），或**系统 ffmpeg via ProcessBuilder**（部署须装 ffmpeg 二进制）。推荐 javacv 避部署依赖；若嫌 jar 大走 ffmpeg+部署文档 | 抽 1 帧 <2s；指定秒定位准确；大视频内存可控（流式帧不全部 load） |
| **R-3 无生图 provider**（只有视频 ArkSeedance），图片节点 AI 生图缺后端 | 复用 `MediaGenProvider` 抽象 + 新 impl（Seedream / Nano-Banana / 可灵图）。生图 provider 是**平行子 plan**（承 SeedDance SD-11）。**MVP 图片节点先只支持【上传 + 衍生 + 焦点编辑】**，AI 生图待生图 provider 落地 | 上传→展示→衍生不覆盖；生图 provider 落地后接通 |
| **R-4 可灵/海螺/happy horse 视频模型未接**（只 seedance） | `MediaGenProvider` 抽象已支持多 provider，加 `KlingVideoProvider`/`HailuoVideoProvider`/`HappyHorseVideoProvider` impl。每家协议不同（任务型/同步），逐家摸协议 | 各 provider 单测 create/query 各 status |
| **R-5 画布快照大**（JSONB 含全图）+ 节点产出物多 | 快照存 `canvases.snapshot` JSONB；**产出物复用 stored_files，不嵌 base64**（只存 fileId 引用）；快照保存节流（编辑期本地暂存，手动/定时落库） | 加载 100 节点画布 <2s |
| **R-6 一键重跑拓扑 + 并发触发 provider** | 拓扑排序定序 + 环检测（有环报错）；并发上限；失败部分重试非全量 | 10 节点链重跑；环检测报错；单节点失败不阻塞兄弟 |
| **R-7 脚本批量分镜一次生多个任务**（配额/成本） | 分镜批量任务限流（每批 N 个，可配）；分镜图并行生但有上限 | 1 剧本→10 分镜批量跑通；超限降级 |
| **R-8 焦点编辑元素提取**（图上扣元素）靠 LLM/分割模型，能力不确定 | MVP 焦点编辑先做**交互骨架**（沉浸模式选区→提交 LLM/分割→新图节点）；提取质量依赖生图模型能力，弱保底 | 选区→新图节点链路通；质量 Phase4 评 |

## 安全检查清单

- [ ] **鉴权/授权**：画布端点 `@RequirePermission("canvas:write")` 新权限（照 [V54](../../../backend/src/main/resources/db/migration/V54__media_gen_tasks.sql) `media:gen` gated 模式 seed，仅 admin 默认有）；ownership 硬过滤（用户只能编/删自己的画布）；节点触发的 media/llm 调用**各自权限**（复用 `media:gen`，无权则节点生成 FAILED 而非绕过）。
- [ ] **输入校验**：快照大小上限（防撑爆 JSONB）；节点 prompt 长度上限；上传图/视频大小+类型白名单；抽帧秒数 ∈ 视频时长范围；截取时间段合法。
- [ ] **数据最小化**：快照不存 base64/ provider 临时 URL，只存 fileId + request_config；不存 LLM 原始响应。
- [ ] **密钥安全**：复用 AES（media provider / llm key，[AesEncryptService](../../../backend/src/main/java/com/superprogrammer/...)），不明文落日志；抽帧无密钥。
- [ ] **错误处理**：provider/抽帧失败固定话术，不透传 `e.getMessage()`；节点失败标红 + error_msg 截断。
- [ ] **文件安全**：抽帧/截取产出走 `FileStorageService.load` 咽喉点 ownership 校验；下载端点 Content-Disposition。
- [ ] **CORS/SSRF**：无新增抓取（节点用已存 file 或 provider 出站），无 SSRF 新面。
- [ ] **依赖安全**：新增 javacv（bytedeco）走 Maven Central，关注 CVE；（若 tldraw）新增 react/react-dom/veaury 走官方。

## 性能考虑与验证计划

- [ ] **查询效率**：`canvases` 索引 `(user_id,updated_at)`；快照 JSONB 不建特殊索引（整存整取）；节点产出列表查 `stored_files` 复用 V40 索引。
- [ ] **并发处理**：重跑走独立 `canvasTaskExecutor`（不挤 media/chat 池）；拓扑排序保证无环；批量分镜并发上限可配。
- [ ] **资源使用**：抽帧 javacv 流式（不全部 load 视频进内存）；大产出物流式落盘；快照节流保存。
- [ ] **大画布性能**：Vue Flow 节点虚拟化（内置）；tldraw 内置视口剔除。
- [ ] **Phase4 验证**：100 节点画布加载/编辑流畅；10 节点链一键重跑；抽 1 帧 <2s；零回归（chat/RAG/memory/工作流延迟对比）。

## 功能联动点清单（只列正向必漏 bug）

- [ ] **节点产出完成 ↔ 下游可用**：上游图节点生成完 → 下游视频节点的"参考图"下拉自动出现该图；**边界**：上游 FAILED → 下游参考图选项不出现 + 下游标红"上游缺失"。
- [ ] **重跑上游 ↔ 下游级联**：重跑文本节点 → 提示"是否级联重跑下游图/视频"；**边界**：半选重跑只跑选中子图；环检测报错；单节点失败不阻塞兄弟节点。
- [ ] **打组保存 ↔ 拖入复用**：模板拖入画布 → 展开为子节点；**边界**：模板内节点 id 重新生成（不与现有 id 冲突）；模板内 fileId 引用复制（产出物共享）。
- [ ] **删节点 ↔ 级联标红**：删图节点 → 下游视频节点参考图失效 → 标红；**边界**：只标红不自动删下游（保留用户调整权）；删带连线的节点一并删连线。
- [ ] **删画布 ↔ 产出物**：删画布 → `canvases` 软删；产出物 `stored_files` **保留**（历史/复用，ownership 自然过滤）；**边界**：不级联清产出物（后续清理脚本）。
- [ ] **抽帧/截取 ↔ 新节点**：视频节点抽帧 → 产出新图节点自动连到该视频节点旁；**边界**：抽帧失败不产空节点。
- [ ] **provider 失效 ↔ 节点**：key 失效 → 节点生成直接 FAILED（复用 media worker 的"建任务即失败"路径），不卡 PENDING。

## 术语表

| 术语 | 大白话 | 案例 |
|---|---|---|
| 无限画布 | 可无限缩放平移的创作面，上面摆节点 | LibTV/tldraw/Vue Flow 画布 |
| 节点 shape | 画布上一种节点类型的渲染+数据定义 | 文本/图片/视频/音频/脚本节点 |
| 快照（snapshot） | 整张画布的结构 JSON（节点/连线/位置），存 JSONB | canvases.snapshot |
| 拓扑排序 | 按依赖关系排出执行先后，并检测环 | 重跑时文本→图→视频的顺序 |
| 打组保存 | 选几个节点存成可复用模板 | 一组"剧本→3 分镜"存模板拖入 |
| 焦点编辑 | 进沉浸模式在图上框选元素，提出来变新图 | 角色图抠出一束花 |
| 抽帧 | 从视频取某一帧变图片 | 取第 3 秒画面做视频节点封面 |
| Vue Flow | Vue 3 节点图画布库（已装），支持节点/连线/缩放平移 | 本项目工作流编辑器 + 无限画布都用它 |
