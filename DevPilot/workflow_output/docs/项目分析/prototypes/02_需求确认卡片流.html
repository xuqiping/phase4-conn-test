📄 需求说明书 · 大白话摘要

做一个网页版投票工具：公司/小团队发起投票、大家手机点开链接就能投。核心是「发起 → 分享 → 投 → 看结果」四步走完不超过 1 分钟。

明确不做：小程序版、结果导出（先放需求池，以后想要了走「改需求」）。

🧭 项目分析结论（想法阶段）

  • 技术建议：网页版先行，验证后再考虑小程序
