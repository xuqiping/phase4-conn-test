## 本轮：WP3 Step4 影子对比（补挂起项，真实语料实测）

### 试验设置

- **语料**：用户提供产品经理知识库（3019 md）；每模块抽 2 篇（2-16KB 优先）共 48 篇 0.43MB → 590 个 L2 chunk。
- **试验库**：`影子对比-产品经理`（KB 13，PRIVATE，qwen3-vl-embedding + qwen3-rerank）。
- **方法**（V117 影子并行套不上——C4 定位语烤进 embedding，检索期无法逐查询切换）：
  1. **A 基线**：后端 `RAG_CONTEXTUAL_LLM_ENABLED=false` 入库（contextual_text 全 NULL=纯规则前缀=旧行为）；
  2. **B 增强**：默认 flag 重启 → `POST /api/knowledge/admin/indexes/13/contextual-rebuild`（dryRun 预估 48 docs/590 chunks/48 次 LLM——按文档批）→ REINDEX 590 job 全 DONE（ctx 547/590，43 条超短列表残片被合理跳过）；
  3. 同一黄金集跑评测中心 run（`mode=PRECISION, generateAnswer=true`）。
- **黄金集 36 例**：28 DETAIL（按 chunk 原文直问）+8 HARD（换说法去词面重合）；每例期望 chunk=对应 L2 nodeId。弃 5 条链接图谱类（出不了唯一问题）+3 条人物志（事实提炼 LLM 吐非法 JSON）。

**逐例对账（关键）**：35 个可比例 A/B 检索结果逐一相同；唯一差异例=A 侧评测 LLM 偶发非法输出记 ERROR（B 同例 PASS）。**Δ 全为评测侧噪声，检索层真实变化=0（0 回归 0 增益）**。共同未中 1 例：L1/L2/L3 换说法难例（node172，两版同 miss——词法+向量召回共性短板，非 C4 范畴）。

### 裁决

- **默认开关维持 true**：回退线本意「增益不达标→关」；本集实测无伤害（0 回归），35/36 rank-1 全中=集已近天花板（DETAIL 词面重合高 BM25 已够，HARD 换说法 C4 也救不动）。**C4 增益证明移 Phase4 真实库全量黄金集**。

### 顺手修的真 Bug（影子跑批炸出来的）

1. **V177 连接器两表缺 version 乐观锁列**（commit a0084cc0）：BaseEntity `@Version` 进 SELECT，V175/V176 建表漏列 → 真库连接器轮询每轮 BadSqlGrammar「字段 version 不存在」；单测 mock 数据层不暴露。补 `INTEGER NOT NULL DEFAULT 0`（惯例同 V102/V103），重启后轮询干净。
2. **评测中心单用例容错**（commit c7d3f49e）：原 fail-fast——一例 LLM 非法输出/网关抖动整 run FAILED（36 例两轮各炸一次）；改单例记 ERROR 结果+summary 增 errorCount 继续跑批。EvaluationRunServiceTest +1（2/2 绿）。

### 环境坑复盘（复用价值）

- admin **单会话**：并行 curl 登录踢掉跑批脚本 token（401）→ 跑批期间禁手动登录 admin；脚本改断点续传按 title 多重集去重。
- **reactor-netty 连接池闲置后首呼被 LLM 网关 RST**（curl 同端点正常）：闲置>15min 后首个评测 run 必炸「query embedding 失败」，重启后端换新池即愈。
- 上传限速 10/60s：6.5s 步进+429 退避 30s×5。
- 重启杀在途索引 job → 文档卡 EMBEDDING 孤儿态（嵌入实际已齐）：核 `emb=l2` 后数据修复标 INDEXED（本地库 3 例）。
