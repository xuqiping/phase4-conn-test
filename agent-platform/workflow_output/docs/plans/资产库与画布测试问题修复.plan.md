### D1 两层设计（关键架构）

> 媒体类型当前绑死处理行为（PROMPT/SCRIPT 走 LLM 文本、IMAGE/VIDEO/AUDIO 走文件），直接放开自定义会击穿 `isTextType`/`isFileType`/`validateFileMime`/`mapMediaType` 全部分类链。解法=拆两层：

| 层 | 语义 | 取值 | 决定什么 |
|---|---|---|---|
| **media_category**（处理类别） | 系统级，固定 | `TEXT`/`IMAGE`/`VIDEO`/`AUDIO` 四类 | 编辑器形态(文本框/上传)、预览方式、mime 校验、gen_meta 提取、画布节点映射 |
| **media_type**（媒体类型标签） | 项目级受控词汇，可扩展 | 默认 `PROMPT`/`SCRIPT`/`IMAGE`/`VIDEO`/`AUDIO` 五项 + 用户加项(如 `MAP`) | 矩阵筛选、卡片标签、统计聚合 |

- 每个自定义 media_type **必须绑定一个 category**（加「地图」时选 category=IMAGE → 走图片上传+预览链路）。
- 现状映射：PROMPT/SCRIPT→TEXT，IMAGE→IMAGE，VIDEO→VIDEO，AUDIO→AUDIO。迁移时按此 backfill。
- 此设计与叙事角色桶（纯标签，无处理绑定）对称：角色桶=单层标签；媒体类型=category+type 双层。

## 技术坑点预判

| 坑 | 场景 | 规避 |
|---|---|---|
| **缩略图 N+1 / blob 泄漏**（C2） | 列表 N 张卡每张拉 blob，滚走不释放 → 内存爆 | IntersectionObserver 视口内才拉；模块级 Map 缓存 objectURL 复用；unmount/滚出 revoke |
| **overlay 像素错位**（C4） | mirror 与 textarea 字体/padding/wrap 不一 → 蓝底偏移 | 抽公共 CSS 变量同源；box-sizing/border 一致；中文换行 wrap=soft 同步测 |
| **视频首帧抽帧成本**（C2） | 服务端逐视频 javacv 抽首帧 → 慢 | 前端 `<video #t=0.1 preload=metadata>` 浏览器自带抽首帧，零后端成本 |
| **视频模型列表缺失**（C5） | `models/available` 过滤 MEDIA → 视频节点无选项 | D2 新端点返 CATEGORY_MEDIA；或硬编码 Seedance 系列保底 |
| **媒体类型自定义击穿分类链**（C1b） | 用户加 media_type → isTextType/isFileType/mime/mapMediaType 全失效 | D1 两层设计：media_category(系统固定4类) 决定处理，media_type(受控词汇) 仅分类；mapMediaType 改返 category+type |
| **migration backfill 漏数据**（C1b） | V60 加 media_category 列 backfill 错 → 旧资产 category 错 | CASE WHEN 覆盖全 5 类 + DEFAULT 'TEXT' 兜底；删旧 CHECK 前确认 backfill 完；回滚=drop V60 |
| **删 media_type 资产悬挂**（C1b） | 删 type 下有资产 → 资产 media_type 指向不存在的值 | reassignOnRemovedMediaTypes 归同 category 首项；前端二次确认显迁移数（仿 L10 reassign） |
| **mime↔category 校验缺口**（C1b） | 自定义 type 的 category 与上传文件 mime 不符 | 上传时按文件 mime 推断 category，前端只列同 category 可选 type；后端 validateFileMime 按 category 兜底 |
| **删桶数据迁移**（C1a） | 桶下资产未归通用 → 资产悬挂 | 后端 reassignOnRemovedRoles L185 已处理；前端二次确认显迁移数 |
| **双击与拖拽/单击冲突**（C6） | dblclick 与 pane-click/drag 事件叠加 → 误触 | dblclick 判定 e.target===boardRoot（点节点不触发）；拖拽不受影响 |
| **大画布双击坐标漂移**（C6） | 缩放/平移后 project 坐标偏 | 复用 useVueFlow().project（onDrop L95-106 已验证范式） |
