# 3.1 定义与核心机制

## 1. 定义

**大客户/账户研究方法** 是B端产品经理系统性理解战略客户（Key Account / Strategic Account）的结构化方法体系——通过账户地图、决策链分析、需求洞察、客户情报等方法，将"客户黑箱"转化为"可决策的洞察"，支撑产品策略、售前赢单与客户成功。

> 关键客户管理（Key Account Management, KAM）被定义为过去20年销售领域最重要的变革之一 [来源:McDonald & Woodburn, 2006 | 置信度:📚中]

**与C端用户研究的本质差异**：

| 维度 | C端用户研究 | B端大客户研究 |
|---|---|---|
| 研究对象 | 个体用户 | 组织（多角色决策体） |
| 决策模式 | 个人决策 | 委员会决策（6-10人采购委员会） |
| 研究深度 | 广而浅（大量样本统计） | 窄而深（单客户全链路） |
| 需求特征 | 个人体验偏好 | 业务成果导向（ROI/效率/合规） |
| 研究周期 | 快迭代（周级） | 慢周期（季度/年度） |
| 核心产出 | Persona/用户旅程 | Account Map/决策链/业务痛点 |

## 2. 核心机制

### 2.1 账户地图（Account Map）

账户地图是B端客户研究的核心产出物——可视化展示客户的组织架构、决策链、影响者关系和关键触点。

**5层账户地图结构**：
1. **组织架构层**：部门/团队/汇报线 → 理解权力结构
2. **决策链层**：采购委员会角色 → 定位Economic Buyer
3. **关系层**：影响者·Champion·阻挠者 → 理解政治生态
4. **触点层**：过往交互·产品使用·服务记录 → 理解客户成熟度
5. **动态层**：人事变动·战略调整·预算周期 → 预判窗口期

### 2.2 大客户的界定标准

不是所有B端客户都是"大客户"。典型界定维度：

| 维度 | 说明 | 权重 |
|---|---|---|
| 收入贡献 | 当前+潜在ARR占比 | 高 |
| 战略价值 | 行业标杆/生态卡位/品牌背书 | 高 |
| 增购空间 | 交叉销售/向上销售潜力 | 中 |
| 影响力 | 对其他客户的辐射效应 | 中 |
| 合作深度 | 多产品线/多部门/长期绑定 | 低 |

> 实操中常用ABC分类：A类=Top 20%贡献80%收入、B类=中间层、C类=长尾 [来源:📚训练知识 | 置信度:🔍高]

### 2.3 大客户研究的5大维度

| 维度 | 研究什么 | 核心方法 |
|---|---|---|
| 组织与权力 | 架构·汇报线·政治生态 | Account Map·组织调研 |
| 决策与采购 | 采购委员会·决策流程·审批链 | MEDDIC·Buying Center分析 |
| 需求与痛点 | 业务目标·现状差距·优先级 | SPIN·JTBD(B端版)·深度访谈 |
| 技术与运营 | 技术栈·数据流·集成点 | 技术调研·产品使用分析 |
| 竞争与替代 | 竞品使用·替代成本·合同周期 | 竞品分析·客户情报 |

### 2.4 大客户研究的生命周期

```
识别(Who) → 深挖(Deep Dive) → 监控(Monitor) → 更新(Refresh)
   ↓              ↓                ↓               ↓
  分层定位     账户地图+决策链    信号捕获       季度刷新
  战略匹配     痛点挖掘          异常预警       人事变更新
```

**关键信号**（需持续监控）：
- 客户高管变动 → 决策链可能重构
- 客户融资/上市 → 预算扩张窗口
- 客户并购 → 技术栈整合需求
- 客户负面新闻 → 预算收紧风险
- 竞品合同到期 → 替换窗口
