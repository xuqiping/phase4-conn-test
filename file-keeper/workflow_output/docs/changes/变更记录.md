## [Unreleased]

### 2026-08-30 · 开发环境启停脚本

- 新增根目录 `启动.ps1`、`关闭.ps1`、`重启.ps1`，管理 Redis/Memurai、PostgreSQL、Java 后端和 Tauri 桌面端。
- 启动前检查 `6379/5432/8088/1420` 端口，已运行组件直接跳过；后端和 Tauri 使用独立可见日志窗口。
- 三个脚本均提醒管理后台未纳入自动管理。
- 修正 Windows PowerShell 5.1 将 UTF-8 无 BOM 中文脚本按 ANSI/GBK 解析导致的乱码与语法错误；三个入口脚本统一保留 UTF-8 BOM。

### 2026-08-27 · 运行指南

- 将 Tauri 桌面端开发启动命令更新为 `npm run tauri:dev -- -- --bin file-keeper`，解决新增 Office Worker 后 Cargo 无法在两个 Rust 二进制之间自动选择的问题。
- 同步更正快速启动速查表的桌面端端口说明：Vite dev server 使用 `1420`，Tauri 主程序无独立网络端口。
- 影响范围仅限 `workflow_output/docs/run-guide/` 及变更记录，不改动业务代码、Office Worker 或数据库。

## [0.1.0] - 2026-05-23

### 🎉 首个公开版本

File Keeper v0.1.0 是首个公开发布的版本，提供了完整的文件快速访问和管理功能。

### ✨ Added - 新增功能

#### 核心功能
- **文件管理**
  - 添加文件和文件夹到收藏列表
  - 一键打开文件（使用系统默认程序）
  - 编辑文件信息（名称、分组、标签）
  - 删除文件（仅删除引用，不删除原文件）
  - 拖拽文件到应用窗口添加收藏

- **分组系统**
  - 创建、编辑、删除分组
  - 为文件指定分组
  - 按分组筛选文件
  - 分组下拉框快速切换

- **标签系统**
  - 为文件添加多个标签
  - 标签自动生成颜色
  - 点击标签筛选相同标签的文件
  - 搜索支持标签匹配

- **搜索功能**
  - 实时搜索文件名、路径、分组、标签
  - 300ms 防抖优化，避免输入卡顿
  - 搜索结果高亮显示

- **排序功能**
  - 自定义排序 - 手动调整文件顺序
  - 打开次数排序 - 最常用的文件排在前面
  - 文件名排序 - 按字母顺序排列
  - 最近打开排序 - 最近使用的文件排在前面
  - 创建时间排序 - 按添加时间排序
  - 所有排序模式都使用文件名作为次序 tiebreaker

- **视图模式**
  - 网格视图 - 卡片式布局，适合浏览
  - 列表视图 - 紧凑布局，适合快速查找
  - 视图状态持久化

- **使用统计**
  - 自动记录文件打开次数
  - 记录最近打开时间
  - 统计信息显示在卡片底部

#### 高级功能
- **批量操作**
  - Ctrl + 点击多选文件
  - Shift + 点击范围选择
  - Ctrl + A 全选
  - 批量打开文件
  - 批量移动到分组
  - 批量删除

- **进程管理**（Windows 独家）
  - 查看文件关联的运行进程
  - 一键关闭已打开文件的进程
  - 显示进程 PID 和名称

- **主题系统**
  - 亮色主题
  - 深色主题
  - 主题切换按钮
  - 主题状态持久化

- **自定义排序**
  - 可编辑序号徽章（替代拖拽排序）
  - 点击序号徽章弹出输入框
  - 输入目标位置快速移动
  - 回车保存，Esc 取消

#### UI/UX 优化
- 自定义窗口标题栏（无边框窗口）
- 窗口拖拽、最小化、最大化、关闭按钮
- 文件图标自动提取和显示
- 卡片悬停效果
- 右键菜单
- 响应式布局
- 状态栏显示文件统计信息

### ⚡ Performance - 性能优化

- **虚拟滚动**
  - 网格视图和列表视图都支持虚拟滚动
  - 只渲染可见区域的文件卡片
  - 支持管理 1000+ 文件而不卡顿
  - 滚动帧率 ≥ 55fps（目标）

- **图标懒加载**
  - 使用 Intersection Observer 监听卡片进入视口
  - 全局队列控制并发（最多 5 个并发）
  - 按需提取文件图标，降低启动时间
  - 避免启动时大量并发请求

- **搜索防抖**
  - 输入停止 300ms 后才执行搜索
  - 避免频繁搜索导致的卡顿
  - 提升输入流畅度

- **性能监控**
  - 启动时间测量
  - 搜索性能日志
  - 性能测试框架和脚本

### 🐛 Fixed - 问题修复

- 修复 Vue 生命周期警告（使用 watch 代替 onMounted）
- 修复窗口操作卡顿（使用 requestIdleCallback 优化图标加载）
- 修复状态栏显示问题（调整网格视图高度计算）
- 修复切换分组时图标加载卡顿（降低并发数，优化调度）
- 修复卡片布局溢出问题（标签和底部文字溢出）
- 修复虚拟滚动导致的拖拽排序失效（改用可编辑序号徽章）
- 修复排序效果不明显的问题（添加名称次序作为 tiebreaker）
- 修复图标懒加载的 TypeScript 类型错误

### 🚧 Limitations - 功能限制

- 仅支持 Windows 10/11 (64-bit)
- 不支持云同步
- 不支持文件预览
- 不支持全局快捷键
- 不支持文件夹批量导入
- 不支持导出/导入配置
- 不支持主题自定义
- 不支持插件系统

### 🔐 Security - 安全性

- 所有数据存储在本地 (fileStore.json)
- 不收集用户数据
- 不联网（除了安装 WebView2）
- 文件路径仅存储引用，不复制文件
- 进程管理需要管理员权限

### 📦 Installation - 安装说明

**系统要求：**
- Windows 10/11 (64-bit)
- WebView2 运行时（安装程序会自动安装）

**安装步骤：**
1. 下载 `File-Keeper_0.1.0_x64_zh-CN.msi`
2. 双击安装包
3. 按照安装向导完成安装
4. 从开始菜单启动 File Keeper

**卸载：**
- 通过 Windows 设置 > 应用 > 已安装的应用 卸载
- 或通过控制面板 > 程序和功能 卸载

### 🔐 Security - 安全加固（离线授权与门禁）

#### 2026-07-17

- **P0-1 修复**：离线/授权 token 由 HMAC-SHA256 对称签名升级为 **Ed25519 非对称签名**。服务端持有私钥签发，客户端仅内嵌公钥验签，客户端二进制中不再驻留任何对称 secret。
- **P0-2 修复**：生产环境缺失 `FILE_KEEPER_ENTITLEMENT_PRIVATE_KEY` 时，服务端**拒绝启动**（不再静默兜底）。
- **P1-1 修复**：token payload 内增加绝对 `notAfter` 字段，Rust 侧通过 `SystemTime::now()` 强校验，签名覆盖有效期，移除任何外部 duration 续期路径。
- **P1-2 修复**：结束进程、截图/OCR、剪贴板监听 start/stop 等所有特权 Tauri 命令入口统一调用 `require_module` 进行二次校验；无凭据、签名无效、过期、未授权模块均拒绝。
- **兼容性处理**：升级后若本地残留旧版 HMAC 格式 token（无 `.` 分隔符），前端检测后清空 Rust 凭据并提示联网刷新一次。
- **测试覆盖**：
  - Rust `commands::auth` 内联测试由 9 个扩展至 **14 个**，新增跨语言一致性固定向量（Java 签发 → Rust 验签）及篡改一字节拒绝用例。
  - 前端 `commercialAuthStore` 单测覆盖旧 HMAC token 检测与强制刷新场景。
  - 新增《安全加固端到端测试方案》，覆盖断网过期、改系统时钟、直接 invoke 特权命令、旧 token 兼容四个场景。
