# Network Security Workflow Checklist

在完成 `workflow/network_security_workflow.md` 的每一步后，使用此检查清单进行交叉验证。每个项目必须回答**是**才算完成。如果有任何项目回答**否**，修复输出并重新验证。

## Step 1: 识别网络基础安全需求场景

- [ ] 已明确场景类型（边界防护/Web应用防护/渗透测试/DDoS防护/协议安全/网络架构安全/云原生网络安全）
- [ ] 已识别防护边界（互联网边界/内网分区/多云互联/混合云）
- [ ] 已提取攻击面规模（公网IP/暴露端口/域名/第三方接入点数量）
- [ ] 已提取合规要求（等保级别/关保/行业监管）
- [ ] 已识别现有工具（防火墙/WAF/IDS IPS/DDoS防护服务商）
- [ ] 已提取关键痛点（规则误报率/告警噪音/防护盲区/0day响应慢/DDoS频繁/内网横向移动）
- [ ] 已对照知识库典型架构完成初步判断（Web应用→WAF六层/渗透测试→PTES+ATT&CK/DDoS→分层防御/云原生→eBPF XDP）
- [ ] 如有信息缺失，已向用户追问不超过2个澄清问题

## Step 2: 输出网络基础安全方案

- [ ] 如为协议安全，TCP/IP分层防御已覆盖（物理链路层/网络层/传输层/应用层）
- [ ] 如为协议安全，云原生网络增强已说明（eBPF XDP/Service Mesh安全/微分段）
- [ ] 如为协议安全，协议安全新趋势已输出（Rust内存安全/AI协议模糊测试/QUIC HTTP3适配）
- [ ] 如为防火墙WAF，防火墙选型演进已对比（包过滤→状态检测→UTM→NGFW→SASE）
- [ ] 如为防火墙WAF，WAF六层规则体系已覆盖（签名/语义/AI模型/业务/频率/Bot管理）
- [ ] 如为防火墙WAF，开源WAF已说明（雷池SafeLine/ModSecurity/Coraza）
- [ ] 如为防火墙WAF，纵深防御架构模板已给出（互联网边界/内网分区/城商行四层案例）
- [ ] 如为防火墙WAF，OWASP 2025变化已说明（权限失效首位/SSRF新类别）
- [ ] 如为渗透测试，PTES七阶段已覆盖（前期交互→情报收集→威胁建模→漏洞分析→渗透攻击→后渗透→报告）
- [ ] 如为渗透测试，MITRE ATT&CK映射已说明
- [ ] 如为渗透测试，AI驱动渗透和全自动框架已输出（效率提升3-5倍/RapidPen）
- [ ] 如为渗透测试，漏洞管理闭环已覆盖（发现→评分CVSS+EPSS+CISA KEV→修复→验证）
- [ ] 如为渗透测试，红蓝对抗和护网行动已说明
- [ ] 如为DDoS防护，威胁演进已覆盖（容量型/协议型/应用型/新型AI智能体攻击/IoT僵尸网络）
- [ ] 如为DDoS防护，分层防御架构已输出（边缘层CDN/网络层清洗/主机层内核/应用层限流）
- [ ] 如为DDoS防护，AI智能清洗已说明（132维特征/3秒识别/动态策略/人机验证）
- [ ] 如为DDoS防护，应急响应流程已给出（告警→切换高防→清洗→恢复→溯源→复盘）
- [ ] 所有核心论断均能在知识库中找到支撑来源
