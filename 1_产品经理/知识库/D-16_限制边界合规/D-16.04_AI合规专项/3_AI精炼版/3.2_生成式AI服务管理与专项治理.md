# 3.2 生成式AI服务管理与专项治理

## 一、《生成式人工智能服务管理暂行办法》核心要求

2023年8月15日施行的《暂行办法》是中国生成式AI领域的核心部门规章，对服务提供者提出以下法定义务：

| 义务类别 | 具体要求 |
|---|---|
| 算法备案 | 具有舆论属性或社会动员能力的生成式AI服务，上线前须算法备案 |
| 安全评估 | 须开展安全评估，包括训练数据安全、模型安全、输出安全 |
| 内容标识 | 生成内容须按《标识办法》要求进行显式+隐式标识 |
| 训练数据合规 | 训练数据来源合法、不侵害他人知识产权、个人信息须脱敏 |
| 用户管理 | 实名认证、使用记录留存（不少于6个月）、未成年人保护 |
| 内容审核 | 建立内容审核机制，发现违法内容须立即处置并报告 |
| 投诉举报 | 提供便捷投诉举报渠道，及时处置用户投诉 |

[来源:《生成式人工智能服务管理暂行办法》第4-17条 | 置信度:🔍高 | 2026-07]

## 二、API调用登记制度

2026年起，网信办明确了"API调用已备案模型"的登记制度：

| 维度 | 要求 |
|---|---|
| 适用情形 | 通过API接口调用已通过大模型备案的模型能力，构建自己的AI应用/功能 |
| 登记主体 | AI应用运营方（非模型提供方） |
| 登记机关 | 地方网信办（省级） |
| 核心材料 | 应用场景说明+调用模型备案号+内容安全措施+用户保护措施 |
| 与备案区别 | 登记是轻量审核，不要求重新评估模型本体安全 |

**2026年5-6月数据**：68款API调用应用完成地方网信办登记。

[来源:网信办公告(2026.7.10) | 置信度:🔍高 | 2026-07]

## 三、清朗·整治AI应用乱象专项行动

2026年5月起，中央网信办在全国范围内开展为期4个月的"清朗·整治AI应用乱象"专项行动：

### 专项行动重点

| 治理方向 | 具体内容 |
|---|---|
| AI生成虚假信息 | 利用AI批量生成谣言、虚假新闻 |
| AI诈骗 | 换脸冒充亲友/领导、AI语音诈骗 |
| AI擦边内容 | AI生成色情擦边/低俗内容 |
| 深度合成未标识 | 未按规定标识AI生成/合成内容 |
| 未成年人保护 | AI产品未设置未成年人保护模式 |
| 算法备案违规 | 提供生成式AI服务但未完成备案 |

## 四、《人工智能拟人化互动服务管理暂行办法》

2026年7月15日正式施行的《暂行办法》是国内首部针对AI拟人化互动服务的专门立法：

| 核心要求 | 内容 |
|---|---|
| 适用范围 | 提供具有人类外观/声音/情感表达能力的AI互动服务 |
| 身份标识 | 拟人化AI须明确标识非人类身份 |
| 禁止诱导情感依赖 | 不得设计使未成年人产生情感依赖的拟人化互动 |
| 未成年人保护 | 对未成年人使用设置时间限制和内容过滤 |
| 数据安全 | 互动数据不得用于未经授权的画像分析 |
| 备案要求 | 纳入算法备案体系，新增"拟人化互动"场景 |

[来源:新浪财经(2026.7.15) | 置信度:🔍高 | 2026-07]

> **PM要点**：做AI陪伴/AI角色扮演类产品的PM须重点关注此办法——产品设计须加入身份标识、防沉迷、未成年人保护等合规能力。

## 五、应用商店备案前置审查

2026年起，各应用商店已将算法备案证明作为AI类应用上架的前置条件：

| 应用商店 | 要求 |
|---|---|
| 华为应用市场 | AI类应用须提供算法备案号 |
| 小米应用商店 | 同上 |
| OPPO/vivo | 同上 |
| Apple App Store(中国区) | 参照中国法规要求 |

**真实案例**：某AI写作助手因"未提供有效算法备案证明"被华为应用市场驳回上架，上线计划推迟2个月。

[来源:知乎(2026.7.15)1000+企业备案经验 | 置信度:🔍高 | 2026-07]

## 六、常见坑

1. **"先上线再备案"**：应用商店已将备案作为前置条件，未备案=无法上架。备案周期2-4个月，须提前规划。
2. **"API调用=不用管合规"**：API调用仍需登记+内容审核+用户管理，只是免去了模型层备案。
3. **"清朗行动只查大平台"**：专项行动覆盖全量AI服务，中小AI产品同样被查。
4. **"拟人化AI是新赛道不用管"**：2026.7.15新规已施行，做AI陪伴/角色扮演产品须立即合规。
5. **"备案了就万事大吉"**：备案后有持续合规义务——内容审核、用户投诉、定期报告、算法变更重新备案。
