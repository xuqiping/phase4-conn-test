# 20 - 文件存储

## 功能简介
通用文件上传与读取（Agent 头像、知识库文档附件等依赖此基础能力）。
核心是**归属咽喉点 + 生命周期登记**（V40 `stored_files`）：上传记 owner，读取强校验归属，根治 `GET /api/files/{id}` 既有 authenticated IDOR；文档 INDEXED 后清原件字节（D5）。

## 后端 (backend) — `file` 包
- 控制器：[FileController.java](../../backend/src/main/java/com/superprogrammer/file/controller/FileController.java)
  - `POST /api/files/upload` — 落盘 + 记 owner（`store(file, userId, source)`）
  - `GET /api/files/{fileId}` — 经 `load(fileId, currentUserId, isAdmin)` **强校验归属**（V40 修既有 IDOR）
- 服务：[FileStorageService.java](../../backend/src/main/java/com/superprogrammer/file/service/FileStorageService.java)
  - `store(file, ownerUserId, source[, kbId, expiresAt])` — 落盘 + 写 `stored_files(ACTIVE)`；`expiresAt` 仅 PREVIEW 用
  - `load(fileId, userId, admin)` — **单一归属咽喉点**：owner 不匹配且非 admin → `FORBIDDEN(403)`；登记行缺失/文件不存在 → `NOT_FOUND(404)`
  - `cleanAfterIndex(fileId)` — **D5**：删磁盘字节 + 置 `status=CLEANED`（**保留登记行**，区别于 `delete` 的硬删行）；文档 INDEXED 后由 `IndexJobWorker` 事务外调用
  - `delete(fileId)` — 删字节 + 硬删登记行（文档删除清 orphan 用）
- 实体：[StoredFileEntity.java](../../backend/src/main/java/com/superprogrammer/file/entity/StoredFileEntity.java)（`stored_files`，自然主键 `file_id`=UUID+ext，不继承 BaseEntity）；`StoredFile` 为 store 返回的只读 record（fileId/url/name/mime/size）

## 文件生命周期（D5 / 设计 §10.5）
| 事件 | 动作 |
|---|---|
| store（upload/preview） | 落盘 + `stored_files(ACTIVE)`；PREVIEW 带 `expires_at` |
| 文档 INDEXED（embed 全完成） | `cleanAfterIndex` 删字节 + `status=CLEANED`（开关 `app.files.retain-after-index=false`，调试可设 true 保留原件） |
| 文档删除 | `delete` 删字节 + 硬删 `stored_files` 行（清 orphan） |
| 知识完整性 | 删原件后 `knowledge_nodes` + 向量仍在，检索/重嵌读 nodes，**不依赖原件** |

> `cleanAfterIndex` vs `delete`：前者删字节留行（生命周期审计），后者字节+行全删。清字节后 `load` → NOT_FOUND（预期）。

## 前端 (frontend)
- 上传组件分散于各表单（Agent 头像、知识库文档 DocumentManager）
- 知识库上传走独立接口 `/api/knowledge/documents/upload`（见 [14-知识库RAG-基础](14-知识库RAG-基础.md)）

## Sidecar
无。

## 数据表
`stored_files`（V40）— `file_id`(PK)、`owner_user_id`、`kb_id`、`source`(KB/WORKFLOW/CHAT/PREVIEW/**MEDIA/CANVAS/ASSET**，后三个为媒体生成/画布/资产库改造新增)、`status`(ACTIVE/CLEANED/EXPIRED)、`original_name`、`mime`、`size`、`expires_at`、`created_at`。索引：`owner_user_id`、`expires_at`(部分)。
