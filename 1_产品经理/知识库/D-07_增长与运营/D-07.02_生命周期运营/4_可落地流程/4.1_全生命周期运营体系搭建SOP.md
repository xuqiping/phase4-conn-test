# 4.1 全生命周期运营体系搭建SOP

## 适用场景
从0到1搭建生命周期运营体系，或对现有体系进行重构。

## 前置条件
- 已有基础数据分析能力（可跑出留存、活跃等核心指标）
- 产品已有明确的北极星指标

## 8步流程

### Step 1：定义生命周期阶段
- [ ] 参考AARRR/RARRA模型，结合产品特性定义4-6个生命周期阶段
- [ ] 为每个阶段命名并给出定义（如"新手期=注册后7天内且完成≤3次核心动作"）
- [ ] 跨团队对齐定义（产品、运营、数据三方一致）

### Step 2：建立阶段判定规则
- [ ] 基于用户行为数据，为每个阶段设定定量判定条件
- [ ] 典型判定维度：时间窗口+行为频次+功能深度
- [ ] 编写SQL/查询语句，验证规则合理性（检查各阶段用户量分布是否合理）
- [ ] 输出：《生命周期阶段判定规则表》

### Step 3：梳理阶段迁移路径
- [ ] 绘制生命周期状态机图（含正向迁移+逆向回流）
- [ ] 标注每条迁移路径的关键触发条件
- [ ] 识别"关键节点"（如新手→成长的迁移条件是什么？）
- [ ] 输出：《生命周期状态机图》

### Step 4：制定各阶段北极星指标
| 阶段 | 北极星指标示例 | 衡量周期 |
|---|---|---|
| 新手期 | 首日激活率 | 日 |
| 成长期 | 周使用天数≥3的占比 | 周 |
| 成熟期 | 月付费率/月活跃天数 | 月 |
| 衰退期 | 活跃度环比变化 | 周 |
| 流失期 | 召回成功率 | 月 |

- [ ] 结合产品实际调整指标
- [ ] 确定各指标的基准值与目标值

### Step 5：设计各阶段运营策略
- [ ] 为每个阶段设计3-5条核心策略
- [ ] 每条策略包含：目标→触达对象→触达方式→内容/权益→触发条件→效果指标
- [ ] 优先设计"关键节点"的策略（影响后续阶段的转化率）
- [ ] 输出：《各阶段运营策略矩阵》

### Step 6：搭建自动化触发机制
- [ ] 将策略转化为可自动执行的规则（事件触发+时间触发）
- [ ] 接入消息推送系统（Push/短信/邮件/站内信）
- [ ] 设置A/B测试分流（每条策略至少保留对照组）
- [ ] 输出：《自动化触发规则配置表》

### Step 7：上线与监控
- [ ] 灰度上线（先选5-10%用户验证策略不产生负面效果）
- [ ] 核心监控：各阶段迁移率、留存曲线、Push打开率、策略ROI
- [ ] 每日check：自动化规则是否正常触发，有无异常
- [ ] 输出：《生命周期运营日报模板》

### Step 8：迭代优化
- [ ] 每两周review一次策略效果数据
- [ ] 淘汰负向策略（效果显著低于对照组的）
- [ ] 放大正向策略（扩大流量占比+优化文案/时机）
- [ ] 每季度更新生命周期阶段定义（伴随产品演进而调整）
