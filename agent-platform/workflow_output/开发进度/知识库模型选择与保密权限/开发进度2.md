## Step 4（3752bb16）· 保密开关后端（14x#3，spec §5.3）

**收紧矩阵（服务端强制，前端仅 UX）**：
- `KnowledgeConfidentialGuard.java`（新增，纯静态无 Spring 依赖）：
  - `isRestricted(kb, userId, admin)` = confidential && !(admin ‖ createdBy==userId)
  - `assertCanViewContent(...)` 抛 `KNOWLEDGE_CONFIDENTIAL_DENIED(40303)`「内容仅可通过 RAG 问答召回」
- `ErrorCode.java`：+40303（排在 ASSET_COPY_FORBIDDEN 40302 后）
- 四处接入：
  - 文档 list/get：`stripFileRef`——保密成员剔除 fileRef，**元数据保留**（目录索引语义）；owner 不剔
  - `/documents/{id}/asset`（streamAsset）：assertCanViewContent → 403（文件流不走）
  - `/{docId}/nodes`（listByDocument）：403（切片原文不走）
  - `POST /retrieve` 检索调试：403 **早退**（verifyNoInteractions 证明零检索消耗）；/ask 与 chat kbIds 走 retrieveGroundedAnswer→retrieveEvidence **无 Guard = 唯一内容出口**（设计使然）
- PUBLIC 互斥：`assertConfidentialCompatible`——create 与 update（toggle 时）都校验；update `confidential=null` = 不动既有开关（旧客户端兼容）
- `KnowledgeBaseController.update` 补 `@AuditLog(kb_update)`（保密切换=安全敏感操作留痕）
- 测试：`KnowledgeConfidentialGuardTest` 8 例（矩阵/剥离/asset 403+owner 越门后 NOT_FOUND 证明/nodes/PUBLIC 互斥/可逆/null 保持）+ `RagRetrieveConfidentialTest` 2 例（member 403 早退 / owner 越门后 NO_VISIBLE_DOCS abstain）
**验证**：10 用例绿

**测试技巧沉淀**：owner 越过守卫的证明——不 stub 完整 happy path，而是让下游自然报错（fileRef 置空→NOT_FOUND「文档无原件」；可见集空→NO_VISIBLE_DOCS），错误码区分「403 挡住」vs「过了门但没货」。

## Step 5（3bce17f3）· 前端保密 UI

**后端标志（chat CITATION 帧）**：
- `RagRetrieveVO.CitationVO` + `boolean confidential`；`CachedPayload.CitationRef` 同步 +（缓存命中回放保留标志；**旧缓存条目缺字段反序列化=false**——隐藏是 UX，强制在 /asset 403）
- `RagRetrievalService.retrieveEvidenceInternal`：
  - scope 循环记 `Map<Long,Boolean> kbRestricted`（Guard.isRestricted 请求者视角）
  - gather 循环 `confidentialNodes`（Set<Long>）登记受限 KB 全部候选 nodeId——**topK ⊆ allPool，标志不漏**
  - citation 构建处 `.confidential(confidentialNodes.contains(e.nodeId()))`
  - `buildVo`（retrieve 调试路径）不加：该接口保密成员已 403，owner/admin 恒 false
- `Evidence`/`L2Candidate` 不带 kbId——不改 record，per-KB 循环侧集合法避免 8 处签名改动

**前端五处**：
- `knowledge.ts`：KnowledgeBase +confidential；Request +confidential?；RagCitation +confidential?
- `MessageBubble.vue`：IMAGE 缩略图与 FILE 下载 chip 条件 +`!c.confidential`（引用标题仍显示）
- `RetrievalDebugPanel.vue`：kbOptions 受限库 `{disabled:true, label:'…（保密库，仅问答）'}`（=admin‖owner 判定与后端对齐；引用 authStore.userInfo?.id/isAdmin）
- `DocumentManager.vue`：`assetRestricted` computed（store.bases 找当前库）→ renderAsset 渲染「🔒 保密库：原件仅可经问答召回…」替代缩略图/下载
- `KnowledgeView.vue`：可见性列 +「🔒 保密」n-tag（title tooltip 说明语义）
- `KbFormModal.vue`：保密开关 n-switch + 说明文案；PUBLIC 时禁用+提示互斥；payload 透传 confidential（编辑回显）
- 测试：KbFormModal +2（回显透传/PUBLIC 互斥禁用）、DocumentManager +2（成员隐藏/owner 直通）、MessageBubble.test.ts 新建 3 例（保密 FILE/IMAGE 隐藏、非保密照常）
**验证**：前端 17/17 绿（knowledge+chat）；后端知识套件 309 全绿
