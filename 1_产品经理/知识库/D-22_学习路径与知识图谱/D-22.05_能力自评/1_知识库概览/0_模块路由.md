# D-22.05 能力自评 — 知识库概览

> 本叶子是产品经理全能力地图的"导航层"第五站——回答"我能力到哪了、差什么、怎么补"。前置依赖(D-22.01)解决"先学什么"，学习路线图(D-22.02)解决"学什么路径"，知识关联(D-22.03)解决"知识怎么关联"，学习方法(D-22.04)解决"怎么学更高效"，能力自评解决"我在哪里、差距多大、提升计划是什么"——是学习路径的"反馈闭环"。

## 一、本叶子核心命题

| 命题 | 一句话 |
|---|---|
| 什么是能力自评 | PM能力水平的系统化评估——154个L3逐一自评+对标框架+差距分析+提升计划+定期追踪 |
| 为什么重要 | 无自评=无方向=盲目学习；自评是学习路径的"GPS定位"——知道在哪，才能规划到哪 |
| 与D-22.02区别 | 学习路线图是"规划路径"，能力自评是"定位当前位置"——自评结果决定路线图的起点 |
| 与D-22.04区别 | 学习方法是"怎么学"，能力自评是"学得怎么样"——自评是学习方法效果的检验 |
| 三子维度 | ①自评维度与评分体系（154个L3的5分制评分+雷达图维度映射+评分校准）②对标框架与差距分析（大厂能力模型对标/同行对标/目标岗位对标/差距诊断）③提升计划与追踪（基于差距的提升计划/优先级排序/里程碑/定期自评/能力演进记录） |
