# 开发环境启停脚本 Feature Map

| 入口 | 作用 | 关键边界 |
|---|---|---|
| `启动.ps1` | 监听端口并按 Redis → PostgreSQL → 后端 → Tauri 启动 | 已监听即跳过；密钥不写文件 |
| `关闭.ps1` | 反向关闭并等待端口释放 | 项目进程只结束记录的 PID 树 |
| `重启.ps1` | 顺序调用关闭和启动 | 关闭失败时不继续启动 |
| `.file-keeper-dev-processes.json` | 记录后端、Tauri 和非服务 Redis 的启动 PID | 临时文件，Git 忽略 |

## 调用链

```text
启动.ps1
  → TCP 端口检查
  → Windows Service / pg_ctl
  → 可见 PowerShell 窗口执行 Maven
  → 可见 PowerShell 窗口执行 Tauri
  → 记录启动窗口 PID

关闭.ps1
  → taskkill /T 关闭记录的进程树
  → Windows Service / pg_ctl 关闭依赖
  → 等待端口释放
```

> TCP 端口检查就像先敲门：端口有回应就不再重复开一套服务。

> 三个中文 `.ps1` 必须保留 UTF-8 BOM。Windows PowerShell 5.1 不会把 UTF-8 无 BOM 脚本稳定识别为 UTF-8，否则中文字节可能被当作 ANSI/GBK，最终从乱码演变成 ParserError。
