## 调用链

```text
用户关闭主窗口
  → App.vue 读取 closeBehavior
  → floating_ball: showFloatingBall()
  → tray: 隐藏主窗并保留托盘
  → exit: 正常退出并释放监听

悬浮球单击/托盘打开/全局快捷键
  → restore_main_window
  → 显示并聚焦主窗
  → 隐藏悬浮球，避免两个入口同时占屏
```

## 技术原理（大白话）

- **Tauri 多 Webview 窗口**：同一应用开一个轻量独立页面。像主店旁边放一个小服务铃，主窗口藏起来时仍能叫回来。
- **Pinia 版本迁移**：读取旧设置后先补默认值，再只写新结构。像把旧表格按列名升级，不覆盖用户已经手动选择的值。
- **工作区坐标校正**：把保存位置限制在任一显示器可见范围。像搬桌子时保证至少仍在房间内，副屏位于负坐标也不会丢失。
- **逐级降级**：悬浮球创建失败就转托盘，托盘不可用则恢复主窗。目标是任何故障都不能让用户找不到应用。

> 悬浮球只加载打包内的本地资源，不加载远程 URL。窗口标题、路径和剪贴板正文不进入日志或服务端。
