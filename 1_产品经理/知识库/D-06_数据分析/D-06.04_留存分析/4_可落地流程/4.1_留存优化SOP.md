# 4.1 留存优化SOP

## SOP 6步闭环

### Step 1：测量基线

| 输入 | 动作 | 输出 |
|---|---|---|
| 产品核心事件定义 | ①跑出近3个月的整体留存曲线 ②按渠道/设备/版本拉分群留存 | 留存基线报告 |

**关键动作**：
1. 确定留存类型（N-Day/Unbounded/Bracket），与行业对标一致
2. 记录D1/D7/D30三个核心节点
3. 判断曲线形态（健康型/持续下降型/微笑型/阶梯型）

### Step 2：识别优化杠杆

用两组对比找优化杠杆：

| 对比方式 | 做法 | 发现什么 |
|---|---|---|
| 留存 vs 流失群组 | 高留存用户做了什么、低留存用户没做什么 | 关键行为差异 |
| 同期群纵向对比 | 本月 vs 上月 vs 去年同期的留存变化 | 趋势向好还是变差 |
| 行为群组对比 | 完成A行为 vs 未完成的留存 | A行为是否为关键行为 |

### Step 3：生成留存假设

**假设模板**：

```
如果用户在[时间窗口]内完成[关键行为X]≥[N次]，
则D7/D30留存率将提升[Y个百分点]
```

**假设来源**：
1. Behavior-Cohort分析：高留存群组的共性行为
2. 用户调研：流失用户反馈的原因
3. 竞品对标：竞品在同期做了什么
4. 产品直觉：新功能/改版预期效果

### Step 4：设计干预方案

| 干预类型 | 触发条件 | 干预手段 | 适用阶段 |
|---|---|---|---|
| 引导型 | D0未完成核心行为 | 新手引导强化/功能提示 | 新用户 |
| 触达型 | D1~D3活跃下降 | Push/邮件/短信召回 | 短期流失预警 |
| 激励型 | D7未回访 | 优惠券/积分/限时权益 | 中期留存 |
| 社交型 | 无社交关系 | 好友推荐/社交功能引导 | 长期粘性 |
| 内容型 | 内容消费深度不足 | 个性化推荐/Dailydigest | 内容产品 |

### Step 5：A/B实验验证

| 要素 | 说明 |
|---|---|
| 实验假设 | "如果[干预X]，则D7留存将提升[Y%]" |
| 核心指标 | D7/D30留存率 |
| 护栏指标 | DAU、卸载率、负反馈率 |
| 分流方式 | 新用户随机50/50分流 |
| 实验时长 | 至少4周（覆盖2个完整留存周期） |

### Step 6：复盘与迭代

```
1. 实验结果：[胜/负/不确定] 留存变化：[+X% / -X%]
2. 假设验证：关键行为驱动留存的假设是否成立？
3. 异常发现：_________________________________
4. 下一步：
   - 胜出 → 全量 + 更新留存基线
   - 负面 → 回滚 + 修正假设
   - 不确定 → 延长实验 / 细分分析
5. 沉淀：将有效的干预策略固化为产品功能/运营SOP
```
