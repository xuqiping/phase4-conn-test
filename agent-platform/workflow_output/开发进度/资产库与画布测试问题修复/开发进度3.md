## C2 关键决策与落点

### 后端：list 列表态批补 fileId（防 N+1）
- `AssetService.assembleRoles` 增 `currentFileIdsOf(assets, ids)`：单次 `versionMapper.selectList(IN assetId)` 拉全部版本，内存按 `asset.currentVersion` 过滤取当前版本 `fileId`（镜像 `rolesOf` 单 IN 范式）。
- `AssetVO.fileId` 字段早已存在（详情态 `get()` 单取设值）；本轮在 list 态批量补——仅文件类版本有值，文本类为 null，前端按 `mediaCategory` 分流。
- content 仍按列表态不返（省流量）；fileId 单独返供卡片缩略。
- **null 防御**：`selectList` 结果 null-safe（Mockito 默认返 null，生产不触发，纯防御）。

### 前端：抽 `api/file.ts` + `useLazyFilePreview` 组合式 + AssetCard
- **`api/file.ts.fetchFilePreview(fileId)`**：带鉴权拉 `/api/files/{fileId}` blob → objectURL（归属咽喉点 FileStorageService.load 已校验防 IDOR）。`canvas.ts` 原 `fetchCanvasPreview` 改 re-export 别名，CanvasView/AssetDetailDrawer 既有调用零改。
- **`composables/useLazyFilePreview.ts`**（核心）：
  - 模块级缓存 `Map<fileId, {url, promise, refs, idleTimer}>`：
    - **去重**：同 fileId in-flight 共享 promise，已完成直接返 url（多卡同 fileId 单次请求）。
    - **refcount + 30s idle 回收**：refs 归零后 30s 仍无人复用才 revoke（滚动来回 30s 内命中缓存，真实离开才释放——平衡「不重复拉」与「objectURL 释放」）。
    - **LRU 上限 80**：缓存满时驱逐最旧 refs=0 条目（blob URL 浏览器配额约数百，留余量）。
    - **失败清条目**：下次进入视口可重试（非永久失败）。
  - IntersectionObserver 门控：视口外不拉，进入视口（rootMargin 120px 预拉）才 acquire。`typeof IntersectionObserver==='undefined'` 静默跳过（jsdom 无 IO 不崩，测试按需 polyfill）。
  - `onMounted` 建观察（模板 ref 挂载后）+ `watch(target)` 兜底晚绑定；卸载 `disconnect` + `release`。
- **`AssetCard.vue`**：
  - `coverRef` + `useLazyFilePreview(coverRef, () => asset.fileId, previewEnabled)`；`previewEnabled` = effectiveCategory ∈ {image, video}（AUDIO 走图标，MVP 不做波形）。
  - IMAGE → `<img object-fit:cover>`；VIDEO → `<video preload=metadata muted @loadedmetadata seek 0.1>` 显首帧（blob URL 不一定支持 `#t` 片段，故用 seek）；失败/无 fileId → 回退原色块 emoji。
  - `@error` → 置 failed 显式回退（objectURL 拉成功但解码失败兜底）。
