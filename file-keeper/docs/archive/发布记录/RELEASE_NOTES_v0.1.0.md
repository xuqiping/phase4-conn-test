# File Keeper v0.1.0 发布说明

## 🎉 首个公开版本
File Keeper v0.1.0 是第一个公开发布的版本，提供了完整的文件收藏管理功能。

## ✨ 主要特性

### 核心功能
- **快速访问** - 一键打开收藏的文件和文件夹
- **分组管理** - 按项目/类型组织文件
- **智能搜索** - 实时搜索文件名、路径和标签
- **批量操作** - 多选、批量打开、批量移动、批量删除
- **进程管理** - 查看和关闭已打开文件的进程（独家功能）

### 用户体验
- **深色模式** - 支持亮色/深色主题切换
- **拖拽添加** - 直接拖拽文件到应用添加收藏
- **双视图模式** - 网格视图和列表视图切换
- **全局快捷键** - 自定义快捷键快速唤起应用

### 性能优化
- **虚拟滚动** - 流畅处理数千个文件
- **图标懒加载** - 按需加载，降低内存占用
- **搜索防抖** - 300ms 延迟提升输入体验
- **启动时间** - < 500ms（1000 个文件）

## 📦 安装

### Windows 用户

1. 下载 `File-Keeper_0.1.0_x64_zh-CN.msi`
2. 双击安装文件
3. 按照安装向导完成安装
4. 从开始菜单启动 File Keeper

### 系统要求

- Windows 10 或更高版本
- 64 位操作系统
- 约 50MB 磁盘空间

## 🚀 快速开始

### 第一次使用

1. **添加文件**
   - 点击"添加文件"按钮选择文件
   - 或直接拖拽文件到应用窗口

2. **创建分组**
   - 点击"新建分组"创建项目分组
   - 右键文件 > 移动到分组

3. **快速访问**
   - 单击卡片打开文件
   - 使用搜索框快速查找

### 高级功能

- **批量操作** - Ctrl+点击多选文件，使用底部工具栏
- **进程管理** - 右键文件 > 关闭已打开的进程
- **全局快捷键** - 设置 > 配置快捷键（如 Ctrl+Alt+F）
- **自定义排序** - 顶部排序下拉框选择排序方式

## ⚠️ 已知问题

1. **图标提取** - 某些文件类型的图标提取可能失败，会显示默认图标
2. **快捷键冲突** - 全局快捷键可能与其他应用冲突，请选择不常用的组合键
3. **进程管理** - 仅支持 Windows 平台
