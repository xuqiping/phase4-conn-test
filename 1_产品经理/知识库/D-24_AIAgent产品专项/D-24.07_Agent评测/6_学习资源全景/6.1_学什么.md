## 学习路径建议

**入门（1-2周）**：
1. 读 CSDN《Agent vs LLM 评测三大根本差异》+ 51CTO/腾讯云四维框架 12 指标（第1类）
2. 读 Gartner 88% 项目失败报告 + 腾讯云 Token 燃烧炉事故（第1类，建立警示基线）
3. 跑 DeepLearning.AI Evaluating AI Agents 课程 + Promptfoo 官方教程（第4类+第3类）

**进阶（2-4周）**：
4. 精读 Anthropic Claude Code 工程博客（100% vs 14%）+ CSDN/新浪 Harness Engineering 范式跃迁（第1类，掌握 2026 核心命题）
5. 拆解 SWE-bench / TAU-bench / Tool Decathlon / MAST 基准仓库（第2类）
6. 读 KRAFTON 30% 偏差研究 + BabelJudge / MM-JudgeBias / WebDevJudge 系列（第5类）
7. 跟腾讯云 / 51CTO / 即刻 Agent 评测话题（第7类）

**实战（4-8周）**：
8. 用 4.1 评测设计 Agent 设计一个 Agent 评测体系
9. 跑 4.2 SOP 落地四维 12 指标 + 基准选型 + LLM-as-Judge 四层 + 红队 + 可观测三件套
10. 跟字节 JD 评测闭环到 RL 五步法实战（如团队有 RL 能力）
11. 持续跟踪 Anthropic / 字节 / 微软 Azure 工程博客（第1类+第7类）

**前沿（持续）**：
12. 跟 ICLR 2026 / NeurIPS 2026 Agent Eval Track（第5类）
13. 跟 SWE-bench / TAU-bench / Tool Decathlon / MAST Live Leaderboard（第2类）
14. 跟斯坦福/MIT/CMU 记忆安全研究持续产出（联动 D-24.06）
15. 持续跟踪 Agent 评测工程师招聘市场（字节 JD 是风向标，PM 转型信号）
