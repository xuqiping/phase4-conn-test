## 2026-08-21 二轮：成员复活 + 成员权限三维（已解决 1-2，Flyway V139 + 前后端，自动化全绿）

1. **移除后再邀请同意报 409** ✅
   根因：`uk_pgm_group_user UNIQUE(group_id,user_id)` 无 deleted 谓词，removeMember 软删后接受邀请走 INSERT 撞唯一索引。
   - 方案：**复活（revive）两阶段**——`UPDATE ... SET deleted=0, used_points=0, role='MEMBER', allowed_kinds=NULL, member_visibility_overrides=NULL WHERE deleted=1` 先行；0 行才走探测+插入。复活记 ADMIN_ADJUST 流水「成员回归复活」。并发双接受：条件 UPDATE 互斥，输家见活行 → 友好 409「该用户已在项目组中」。
   - 验证：`ProjectGroupMemberReviveIT`（真 PG：复活重置断言+并发回归）；全量回归 2275 绿。
2. **每成员权限设置** ✅（三维）
   - **角色**：`role` 列 + `ck_pgm_role` CHECK + 部分唯一索引 `uk_pgm_owner`（每组一活 OWNER）。MANAGER 管人不管钱（邀请/审批/调限额/重置/移除/看流水可读；划拨/回收/组设置/任免仅 OWNER）。`requireRole` 统一闸（admin/OWNER 直通，否则成员行角色 ∈ 白名单）。
   - **功能开关**：`allowed_kinds` JSONB 白名单（null=不限，[]=全禁），入口预检 + `chargeGroup` 事务内硬卡双保险；被禁 400「组长已限制你在本组使用该类模型（kind）」，前端 toast 自动翻中文模块名。
   - **成员级可见性覆盖**：`member_visibility_overrides` JSONB 稀疏 map，三层判定 成员覆盖>组模块覆盖>组默认；MANAGER/本人/组长/admin 恒可见。outputs SQL 预过滤放宽 + 内存精判（分页 total 为预过滤口径，已注记）。
   - 前端：成员表角色列（OWNER 下拉任免）+「功能开关」弹窗（不限制开关+5 模块白名单+全禁警告）+「可见性」弹窗（5 模块三态）；MANAGER 视角见成员/流水（只读）/审批 tab，不见设置与资金按钮。
   - 验证：后端 52 个 projectgroup 测试绿；前端 vitest 678 绿（新增 groupPerms 6 例+端点 3 例）。


## 2026-08-21 四连修复（已解决 3-6，Flyway V138 + 前后端，实测全过）

3. **组产出可见真实图片/视频** ✅
   根因三层：产出 VO 无文件字段 / FileStorageService 仅文件属主可读 / 产出表无预览列。
   - VO：`ProjectGroupOutputVO` + `resultFileId`/`imageFileIds`（从 media_gen_tasks 反查，按可见性逐行置空）。
   - 闸门：新 `FileSharedAccessGrantor` 挂点（FileStorageService 属主校验失败→授权器链，fail-closed）+ `ProjectGroupFileAccessGrantor` 实现（组成员+可见性放行）。
   - 前端：产出表新「预览」列——图片懒加载缩略图（点开大图）、视频弹窗播放（打开才拉 blob 防整页流量）。
   实测：OWN 时成员看他人行被过滤+取文件 403；ALL 时行带图、取文件 200、页面真缩略图 ✅
4. **组长可见性设置** ✅
   `member_output_visibility`(OWN/ALL) + `module_visibility_overrides`(jsonb 稀疏覆盖，5 模块 CHAT/EMBED/RERANK/IMAGE/VIDEO)。判定=覆盖优先落 base；admin/组长/本人恒可见。设置 tab：单选默认+例外模块勾选，保存即生效。实测：覆盖持久化、非法模块 400、非组长 403、UI 回显勾选正确 ✅
5. **邀请需被邀请人同意** ✅
   新 `project_group_invites` 状态机（PENDING→ACCEPTED/DECLINED/CANCELED，PENDING 部分唯一索引防重，条件 UPDATE 抢态 0 行=409）。`POST /{id}/members` 改为发邀请（不再直接落成员）；接受才落成员行。通知三路：邀请→被邀请人、结果→邀请人（页顶铃铛+项目组页「我的邀请」条可同意/拒绝）。实测：全链路+通知文案 ✅
6. **公共池招募** ✅
   `public_pool` 开关 + `project_group_join_requests`（PENDING/APPROVED/REJECTED/REVOKED）。发布→全员「项目组→公共池」可见并申请（200 字留言）；组长「入组审批」tab 通过/拒绝（通过落成员行 quota 不限）；被拒 30 天防刷窗；撤出级联未审批申请→REVOKED 并逐个通知。实测：发布/列表/申请/审批/重复申请 409/撤出/级联失效+通知 ✅
