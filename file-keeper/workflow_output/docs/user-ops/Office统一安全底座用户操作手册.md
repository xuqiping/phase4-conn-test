# Office 统一安全底座用户操作手册

## 1. 新建并预检任务

1. 打开 File Keeper，点击顶部“Office 工作台”。界面显示“新建任务”和“任务历史”。
2. 选择任务类型与输出策略。单输出合并应选择“单输出全有或全无”；拆分通常选择“多输出逐文件发布”。
3. 点击“选择文件”，多选 Office 文件。列表显示文件名，不上传文件。
4. 点击“选择目录”，选择独立输出目录。输出目录不能与输入文件目录重叠。
5. 点击“开始安全预检”。按钮显示扫描状态，完成后进入问题确认页。

预期：页面显示处理引擎、文件数、额度、风险清单和源文件只读说明。旧格式、宏、签名、密码或复杂外链可能出现阻断项。

## 2. 查看问题并确认

1. 使用“全部/警告/阻断”筛选问题。无论选择哪项，阻断问题始终显示。
2. 阅读每个稳定错误码和说明。阻断项未解决时，“确认并加入队列”不可用。
3. 没有阻断项时点击“确认并加入队列”。

预期：任务状态变为“已排队”，并写入本机任务历史。当前具体 Office 处理器未接入时不会生成文件，也不会显示伪成功。

## 3. 取消与恢复

1. 已排队任务可点击“取消任务”，状态变为“已取消”。
2. 应用重启后再次进入 Office 工作台；右侧会显示预检、待确认、排队或运行中的本地任务。
3. 对不再需要的恢复任务点击“取消任务”。

预期：取消只影响选中的 taskId，不关闭用户自行打开的 Office。后续处理器接入后，恢复前仍会重新核对文件与风险。

## 4. 查看历史

1. 点击“任务历史”。
2. 查看任务类型、状态、文件数、体积和创建时间；点击“刷新”重新读取本机数据库。

常见异常：

- `OFFICE_OUTPUT_OVERLAPS_INPUT`：换一个不在源文件目录下的输出目录。
- `OFFICE_FILE_LOCKED`：关闭占用文件的 Excel/Word/PowerPoint 后重新预检。
- `OFFICE_HIGH_FIDELITY_BLOCKED`：当前兼容矩阵未批准，不能强行执行。
- `OFFICE_EXECUTION_ENGINE_NOT_READY`：对应业务处理器尚未接入，不会产生输出。
