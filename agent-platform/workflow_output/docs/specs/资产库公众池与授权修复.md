# 规格 · 资产库公众池、成员授权与价表模型选择

> Phase 6 变更规格。实现必须与本文一致；来源为 2026-08-10 人工测试问题与用户确认。
> 关联：[项目资产库 Feature Map](../feature-map/项目资产库.feature-map.md)｜[积分计费系统规格](积分计费系统.md)。

## 1. 目标

1. 修复普通资产项目 OWNER 无法搜索并授权其他用户的问题。
2. 允许资产项目发布到公众池；普通用户可选择直接开放或申请审批，管理员发布带“官方发布”标记且直接开放。
3. 新增价表时从全局供应商的未配置模型中选择，不再手填模型名和 providerId。

## 2. 资产公众池

### 2.1 发布规则

- 拥有 `asset:write` 的项目 OWNER 可发布自己的项目。
- 管理员可发布任意未删除项目；管理员发布固定为 `OPEN`，并显示“官方发布”徽章。
- 普通 OWNER 发布时选择访问模式：
  - `OPEN`：所有已登录且拥有资产库入口权限的用户可直接使用。
  - `APPROVAL_REQUIRED`：所有用户可看到项目摘要，申请获批后才能使用。
- 发布记录保存发布人、发布时间及发布时是否为管理员。项目转让不改变既有官方标记；移出后重新发布按本次发布者重算。

### 2.2 可见与可用边界

- 未获批用户只可看到项目名称、封面、简介、发布者、官方标记和资产数量，不可读取资产列表、版本正文或文件预览。
- 可使用者在 ACL 中获得只读 VIEWER 能力：浏览、预览、引用版本快照、复制资产到自己有写权的项目。
- 公共用户不能修改源项目、成员、分类、资产、版本或状态。
- 原项目更新后，公共池立即展示最新内容；不复制项目、资产、版本或文件数据。
- 已进入画布的引用仍锁定原版本；重新引用或复制时取当前版本。
- 移出公众池后，新访问、待审批和已批准的公共访问立即失效；既有画布快照及已复制资产保留。

### 2.3 申请与审批

- 申请状态为 `PENDING / APPROVED / REJECTED / REVOKED`，同一项目与申请人只保留一条当前记录。
- 重复申请返回当前状态；被拒绝或撤销后允许重新发起并回到 `PENDING`。
- 仅项目 OWNER 或管理员可审批、拒绝或撤销公共访问。
- 审批采用条件更新，只有 `PENDING` 可转为 `APPROVED/REJECTED`，防止并发重复处理。
- 公共访问申请独立于 `asset_project_members`；获批项目不进入“共享给我”，统一在“公共池”查看。

### 2.4 数据模型

通过新的 Flyway 迁移扩展 `asset_projects`：

- `public_pool BOOLEAN NOT NULL DEFAULT FALSE`
- `public_access_mode VARCHAR(24)`，取值 `OPEN/APPROVAL_REQUIRED`
- `published_by BIGINT`
- `published_at TIMESTAMPTZ`
- `published_by_admin BOOLEAN NOT NULL DEFAULT FALSE`

新增 `asset_public_access_requests`，保存 `project_id`、`applicant_id`、`status`、`decided_by`、`decided_at`、审计时间，并对 `(project_id, applicant_id)` 建唯一约束。

## 3. 成员授权修复

### 3.1 根因

`ShareDialog.vue` 调用需要 `user:manage` 的 `/api/users`。普通项目 OWNER 只有 `asset:write` 时收到 403，导致分享弹窗整体加载失败。

### 3.2 修复契约

- 资产域新增成员候选搜索接口，仅项目 OWNER/管理员可调用。
- 参数为关键词，最多返回 20 个启用用户；排除项目 OWNER、已有成员和当前操作人。
- 响应只包含 `id`、`username`，不暴露邮箱、角色和权限。
- `MemberVO` 增加用户名，成员列表不再依赖管理员用户接口。
- 前端使用远程搜索；成员加载与候选搜索分别处理错误，任一失败不拖垮整个弹窗。
- 既有邀请、改角色、移除、退出及转让接口与角色规则保持不变。

## 4. 价表模型选择

- 新增 `GET /api/billing/pricing/available-models`，要求 `pricing:manage`。
- 只读取状态为 ACTIVE、未删除的全局供应商及其模型列表。
- 类别映射：`CHAT→CHAT`、`EMBEDDING→EMBED`、`IMAGE→IMAGE`、`VIDEO→VIDEO`。
- 以 `(providerId, model)` 为配置身份，排除已有价表的组合。
- 候选项返回 providerId、供应商显示名、model、kind；前端选中后自动填写并锁定三项。
- 编辑价表时供应商、模型和类型不可修改，只调整价格、计费模式及生效时间。
- 后端创建时校验模型归属、类型映射和重复配置，不能靠直接调用 API 绕过下拉约束。
- 供应商停用不删除历史价表，只从新增候选中移除。

## 5. 接口与页面

- 资产项目：发布、移出公众池、公共池摘要列表。
- 公共访问：申请、查看本人状态、OWNER 查看申请、审批/拒绝/撤销。
- 资产复制：同时校验源项目读权和目标项目写权；复制当前版本内容与文件引用，生成目标项目内独立资产和初始版本。
- 资产库增加“公共池”页签、发布配置弹窗、申请状态按钮和 OWNER 审批管理入口。
- 价表弹窗模型字段改为可搜索下拉，没有候选时显示“所有全局模型均已配置价表”。

## 6. 错误处理与安全

- 未批准读取资产内容、非 OWNER 发布/审批、公共用户修改源项目均返回 403。
- 项目已移出公众池时，申请和审批返回明确业务错误。
- 复制目标无写权、源版本不存在或并发变更时不产生半成品；复制在事务中完成。
- 发布、移出、申请、审批、拒绝、撤销和复制均记录 projectId/userId/action 日志。
- 不放宽 `/api/users` 管理接口权限，不向普通用户暴露全量用户资料。

## 7. 测试与验收

- 后端：ACL 各分支、发布权限、申请状态机、并发审批、撤回失权、成员候选搜索、复制事务、价表候选过滤与防重复。
- 前端：三个资产页签、官方徽章、两种发布模式、申请/审批状态、远程用户搜索、价表下拉及编辑锁定。
- 回归：普通成员授权、共享列表、资产预览、画布版本引用、资产复制、项目删除/转让、历史价表询价。
- 构建门禁：后端相关单测及全量 `mvn test`，前端相关 Vitest 及 `npm run build`。

## 8. 回滚

- 代码通过独立 commit 回滚。
- 数据库只新增列和表，不修改旧迁移；回滚部署时旧代码忽略新结构。
- 若必须清理结构，确认没有发布/申请生产数据后另写新 Flyway 迁移，不回改已执行脚本。
