# 记忆的存与读

> 一句话：**「落库于」= 新事实存哪；「读取范围」= AI 回答时参考哪些记忆。两件事互不影响。**
> 设置位置：聊天页输入框下方的一排下拉框。

## 一、底栏下拉框都是什么（从左到右）

| 下拉框 | 作用 | 选项 |
|---|---|---|
| 目标 / 模型 | 对话对象 + AI 模型 | 略 |
| **记忆模式** | 记忆系统开/关 | 跟随全局（默认）/ 本会话开 / 本会话关 |
| **记忆落库于**（写） | 新说的事实存到哪里 | 总记忆 / 某个项目 |
| **总记忆**（读） | 要不要参考全局记忆 | 总记忆：开 / 总记忆：关 |
| **项目记忆**（读，多选） | 额外参考哪些项目的记忆 | 勾选项目 |

末尾两个图标按钮：**📂** = 管理项目；**🔖** = 打开「我的记忆」抽屉（带红点 = 有冲突待处理）。

## 二、场景：新说的事实存哪？

用「**记忆落库于**」下拉：
- 选「总记忆」→ 存全局，所有场景都能用。
- 选某项目 → 只挂这个项目。

## 三、场景：AI 回答时读哪些记忆？

用「**总记忆**」下拉 + 「**项目记忆**」多选组合：
- 只读某项目、不掺私人记忆：「总记忆」选「关」+ 只勾该项目。
- 全都参考：「总记忆」选「开」+ 项目全勾。

> 改了读范围但事实没存进去？去看「落库于」——写和读是两个开关。

## 四、场景：临时关掉记忆

「记忆模式」下拉选「本会话关」→ 只对当前对话生效；选「跟随全局」= 跟系统设置走（默认）。

## 五、调试：这条记忆为啥没被用上？

1. 点 🔖 打开「我的记忆」抽屉 → 顶部「**记忆注入预览**」。
2. 输入你的问题 → 预览范围选「指定项目」→ 开/关「包含总记忆」→ 点预览。
3. 能看到 AI 这次实际会带上哪些记忆，逐条核对。

## 常见疑问

| 现象 | 原因 / 处理 |
|---|---|
| 找不到「跟随」按钮 | 已并进「记忆模式」下拉的「跟随全局」 |
| 图标按钮不认识 | 悬停看提示：📂=项目管理，🔖=记忆抽屉 |
| 授权来的项目只能看不能总结 | 正常：被授权项目只读召回，总结只能 owner 发起 |
