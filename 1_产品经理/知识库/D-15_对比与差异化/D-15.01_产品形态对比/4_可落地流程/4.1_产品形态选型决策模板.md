## 概述

本模板覆盖产品形态选型的3个核心决策：**B/C端定位**、**跨端（App/Web/小程序）选型**、**品类（工具/内容/社交）定位**。适用于新产品立项、赛道选择、产品转型等场景。

## Part A：B/C端定位决策表

### 使用方法

逐行打分（1-5分），右侧权重乘以得分得到加权分。最终B端总分 vs C端总分，差距>15分则方向明确，<15分则需进一步调研。

| 决策维度 | 权重 | B端得分(1-5) | C端得分(1-5) | B端加权 | C端加权 |
|---|---|---|---|---|---|
| 目标用户是组织还是个人 | 20% | | | | |
| 付费意愿来自预算还是个人收入 | 15% | | | | |
| 决策链路长短偏好 | 10% | | | | |
| 是否需要角色/权限体系 | 10% | | | | |
| 商业模式偏好（订阅vs广告/增值） | 15% | | | | |
| 增长方式偏好（销售vs增长） | 10% | | | | |
| 迭代节奏偏好（慢而稳vs快而试） | 10% | | | | |
| 数据敏感度（高→B端/低→C端） | 10% | | | | |
| **合计** | 100% | — | — | | |

### 评分指引

| 维度 | B端=5分的典型表现 | C端=5分的典型表现 |
|---|---|---|
| 目标用户 | 用户是HR/财务/管理者等组织角色 | 用户是个人消费者 |
| 付费意愿 | 企业有明确IT预算，ROI可量化 | 个人为体验/娱乐/便利付费 |
| 决策链路 | 需要选型→审批→采购，理性决策 | 用户自己决定，冲动+理性混合 |

## Part B：跨端选型决策矩阵

### 使用方法

对每个端的能力按产品需求打分（1=不满足/3=部分满足/5=完全满足），综合"开发成本"和"战略价值"做最终决策。

| 能力需求 | App | Web | 小程序 | 本产品需要？(Y/N) |
|---|---|---|---|---|
| 离线使用 | 5 | 2 | 1 | |
| 蓝牙/NFC/传感器 | 5 | 1 | 2 | |
| 系统级推送 | 5 | 2 | 3 | |
| 社交裂变传播 | 2 | 3 | 5 | |
| SEO获客 | 1 | 5 | 3 | |
| 快速迭代部署 | 2 | 5 | 4 | |
| 低获客成本 | 1 | 4 | 5 | |
| 跨平台覆盖 | 2 | 5 | 3 | |
| 完整支付闭环 | 5 | 4 | 4 | |
| PC端办公场景 | 1 | 5 | 1 | |

### 决策规则

- **必须Y的能力中有3项以上App=5而其他端≤2** → 必须做App
- **必须Y的能力集中在社交裂变+低获客成本** → 小程序优先
- **必须Y的能力集中在SEO+PC办公+跨平台** → Web优先
- **多端均需要** → 按优先级分阶段：先做低成本端验证MVP，再做高投入端深度体验

### 品类选择自检清单

- [ ] 用户来这个产品的第一动机是"完成任务"还是"消费内容"还是"与人互动"？
- [ ] 如果砍掉所有内容/社交功能，产品还有价值吗？（是→工具型）
- [ ] 如果砍掉所有工具/社交功能，产品还有价值吗？（是→内容型）
- [ ] 如果砍掉所有工具/内容功能，产品还有价值吗？（是→社交型）
- [ ] 未来是否计划从主品类向其他品类演化？（如工具→内容→社交）
- [ ] AI能力将如何改变产品的品类属性？（如工具型→Agent型）

## 使用案例（示例填充）

**产品**：某企业知识管理工具

**Part A 结果**：B端加权75分 vs C端加权35分 → 明确B端定位

**Part B 结果**：必须Y的能力为"跨平台覆盖+PC端办公+完整支付闭环"，App=2/Web=5/小程序=3 → Web优先

**Part C 结果**：
- 核心价值：帮企业员工高效管理和检索知识
- 主品类：工具型
- 留存驱动力：功能粘性
- 冷启动策略：单点功能极致→口碑
- 未来演化：工具→内容（知识社区）→社交（团队协作）
