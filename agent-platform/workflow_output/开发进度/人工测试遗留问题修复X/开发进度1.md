## A1 视频区上传按钮 + 统一预检

- **实现**：PropertyPanel.vue 视频区顶部（提示词字段前）新增 `n-upload`（accept=video/*、:show-file-list=false、按钮「上传视频」带 CloudUploadOutline 图标 + running loading 态）+ 上限提示行（引 `KIND_LIMIT_LABEL.video` 常量，单源 mediaLimits 防文案漂移）。
- **预检**：`onPickFile` 内统一三 kind 大小预检——`kindFromMime(file.type)` 判 kind，非空则 `sizeLimitError(kind, size, name)` 超限 `message.warning` 拒（不发 upload 事件）；kind 为 null（MIME 空串/未知）跳过预检直接 emit 交后端闸（plan 细化2）。图片/音频既有上传口同函数收口，预检口径与拖入链同源。
- **语义**（Q1 拍板·产物口径）：上传即节点产物——fileId+预览落节点，可 @引用/抽帧/截取，重传覆盖；非生成参考视频通道。上传链（CanvasView.onUploadFile→canvasApi.upload→后端）零改动。
- **涉及文件**：
  - [PropertyPanel.vue](../../../frontend/src/components/canvas/PropertyPanel.vue)（视频区模板 + onPickFile + useMessage try-catch 降级）
