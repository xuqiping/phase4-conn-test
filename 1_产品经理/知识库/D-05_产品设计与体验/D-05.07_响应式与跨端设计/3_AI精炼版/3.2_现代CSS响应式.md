## 现代CSS响应式 — 从视口级到组件级

> 2025-2026现代CSS已实现质变：Flexbox+Grid+Container Queries+Subgrid+:has()+Cascade Layers让纯CSS实现复杂响应式布局成为现实 [来源:CSDN | 🔍高 | 2026-01]

### Container Queries — 组件级响应式

**定义**：样式不再根据视口宽度变化，而是根据**父容器尺寸**变化——实现真正的组件自治 [来源:MDN | 🔍高]。

```css
.card-container {
  container-type: inline-size;
  container-name: card;
}
@container card (min-width: 400px) {
  .card { flex-direction: row; }  /* 宽容器：横排 */
}
@container card (max-width: 399px) {
  .card { flex-direction: column; }  /* 窄容器：竖排 */
}
```

| 对比 | Media Queries | Container Queries |
|---|---|---|
| 响应依据 | 视口宽度 | 父容器宽度 |
| 组件可移植性 | 低（放到侧边栏还是异常） | 高（组件自适应所处空间） |
| 2026适用场景 | 全局布局（header/footer） | 局部组件（card/modal/aside） |

> **PM要点**：Container Queries让设计系统从"页面级响应式"进化到"组件级响应式"，这是2026最大的响应式范式迁移 [来源:CSDN | 🔍高 | 2026-01]。

### Subgrid — 跨组件对齐

**定义**：子网格继承父网格的行列定义，实现跨组件的视觉对齐 [来源:MDN | 🔍高]。

| 场景 | 无Subgrid | 有Subgrid |
|---|---|---|
| 卡片列表对齐 | 每张卡片高度不齐，需JS/Flex hack | 跨卡片标题/价格/按钮严格对齐 |
| 表单组对齐 | label/input手工设grid | 子网格自动继承父grid行 |

```css
.card-grid {
  display: grid;
  grid-template-rows: auto 1fr auto; /* 标题/内容/按钮 */
}
.card {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid; /* 继承父级3行 */
}
```

### :has() 选择器 — 父元素响应式

**定义**：根据子元素的存在/状态选择父元素——CSS首次拥有"父选择器"能力 [来源:CSDN | 🔍高 | 2026-01]。

| 实际应用 | 实现 |
|---|---|
| 有图片的卡片加边框 | `figure:has(img) { border: 2px solid; }` |
| 空状态切换 | `.form:has(:invalid) { outline: red; }` |
| 侧边栏有无内容 | `.layout:has(.sidebar) { grid-template-columns: 1fr 300px; }` |

### Cascade Layers — 样式优先级分层

**定义**：用`@layer`显式声明样式层优先级，解决第三方库/设计系统/业务样式权重冲突 [来源:MDN | 🔍高]。

```css
@layer base, design-system, components, utilities;
@layer base { /* reset */ }
@layer design-system { /* 设计系统 */ }
@layer components { /* 业务组件 */ }
@layer utilities { /* 工具类 */ }
```

> **PM要点**：当设计系统跨端部署时，Cascade Layers是控制"哪套样式优先"的声明式方案，减少`!important`泛滥。

### 2026 CSS响应式决策矩阵

| 需求 | 传统方案 | 2026最优方案 |
|---|---|---|
| 全局布局切换 | Media Queries | Media Queries（仍然适用） |
| 组件内自适应 | JS/复杂的MQ | Container Queries |
| 跨组件视觉对齐 | Flex hack / JS | Subgrid |
| 父元素条件样式 | JS / 无解 | :has() |
| 样式优先级冲突 | !important / 权重战争 | Cascade Layers |
