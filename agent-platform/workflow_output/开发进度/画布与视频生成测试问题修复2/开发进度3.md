## Chunk A1 · @chip 显节点名 + 点击跳转聚焦节点 ✅ commit `5d77a931`

**根因**（prior 轮已诊断，本轮解决）：原生 textarea 死规矩——存什么只能显什么。存 token `@{{node:n1}}`，就只能显 `@{{node:n1}}` 丑码，**无法「存 token、显人话节点名」**。prior 轮因此 defer 为「contenteditable 重设计（独立大 chunk）」。本轮落地。

### 实现：contenteditable 重写（契约不变）

[MentionTextarea.vue](../../../frontend/src/components/canvas/MentionTextarea.vue) 从 `textarea + mirror 镜像层` 改为**单一 contenteditable div**（命令式管 innerHTML，不用 Vue v-for 渲染 segments 以免与手动 DOM 冲突）：

- **chip = 原子块**：`<span contenteditable="false" data-mention="@{{node:n1}}" data-kind data-id>人物设定</span>`。光标不可入，退格整块删；底层存 token，眼睛看人话 label。
- **文本节点 = 字面量**，`<br> = 换行`。序列化（serializeNode）：chip→`data-mention`、`<br>`→`\n`、文本→字面量，**还原回 v-model 字符串，对外契约完全不变**（消费方 PropertyPanel/VideoGenView 零感知）。
- **label 映射**：`labelMap`（kind:id→label）由 candidates 派生，**响应式**——改上游节点名 chip 同步；断链/候选已无 → 回退显 raw token（黄底断链可见）。

### 纯逻辑抽离（可纯测，与 DOM 解耦）

新建 [mentionLogic.ts](../../../frontend/src/components/canvas/mentionLogic.ts)：
- `MENTION_RE` / `parseSegments(text)` — 占位符切分（text/mention，带 kind/id）。
- `detectAnchor(text, caret)` — @唤起定位（@ 前非 alnum 拦邮箱、@ 后空白关闭；**保旧语义**）。
- `insertMention(text, at, caret, kind, id)` — @ 锚点插 token + 尾随空格。
- `escapeHtml(s)` — innerHTML 渲染防 XSS（节点名/label 均用户内容）。

### 难点解法

| 难点 | 解法 |
|---|---|
| **caret 回声丢光标**（用户输入 emit → 父回写 modelValue → watch 触发 → render 重建 → 光标丢） | `lastEmitted` 守卫：自身 emit 回写 `=== lastEmitted` 跳过 render（DOM 已对、光标不丢）；仅外部变更（切节点/加载）才 render 重建 |
| **选中候选后 chip 要显示** | `selectCandidate` emit 后显式 `render(text)`（lastEmitted 已更新故 watch 回声跳过重复 render）+ `setCaretCharOffset(pos)` 定位 |
| **Enter 产生 `<div>` 非 `\n`** | keydown 拦截 Enter → `execCommand('insertLineBreak')` 插 `<br>`，保 serialize→`\n` 1:1 可逆 |
| **paste 富文本污染** | `@paste` preventDefault + `getData('text/plain')` + `execCommand('insertText')` 纯文本 |
| **IME 合成误触** | `composing` 标志，compositionstart/end 间不序列化/不唤起 |
| **maxlength 无原生硬截断** | onInput 超 maxlength 软裁尾部 + 计数器 |

### A1 增强：chip 点击跳转聚焦节点（用户追加需求）

- chip `cursor: pointer`（hover 手型），断链 chip `cursor: not-allowed` + 不响应点击（上游已删，跳转无目标）。
- chip 点击 → 事件委托（editRef @click → `closest('.mention-ta__chip')`）→ emit `mention-click {kind,id,raw}`。
- **画布**：PropertyPanel `@mention-click` → emit `mention-focus` → CanvasView `onMentionFocus` → `CanvasBoard.focusNodeById(id)`（选中 `selectedNodeId` + emit `node-selected` 切属性面板 + `vfFitView({nodes:[id],padding:0.4,maxZoom:1.2,duration:300})` 居中）。
- **视频页**：VideoGenView `@mention-click` → `attachAreaRef.scrollIntoView`（同页锚点，无画布实体可跳）。
