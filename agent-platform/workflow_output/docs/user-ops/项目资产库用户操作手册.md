# 项目资产库 · 用户操作手册

> B 类功能。面向创作者/团队成员的「功能→操作步骤→界面变化→预期结果」操作指南。
> 配套：[FeatureMap](../docs/feature-map/项目资产库.feature-map.md)｜[README](../开发进度/项目资产库/README.md)｜[速查表25](../../项目工程文档/项目功能介绍/速查表/25-项目资产库.md)

## 入口

左侧边栏「**资产库**」（需 `asset:write` 权限，无权不显菜单；直访 `/assets` 显 403 卡片）。权限由管理员授予。

## 一、项目管理

### 1.1 新建项目
1. `/assets` 页右上「**新建画布/项目**」按钮（注：资产库入口按钮文案「新建项目」）→ 弹窗
2. 输入项目名（必填）+ 描述（可选）→ 「确定」
3. **界面变化**：「我的项目」Tab 出现新卡片（首字母色块封面 + 5 叙事角色计数）
4. **预期**：叙事角色桶默认五桶（人物/道具/场景/风格/通用），无需手填

### 1.2 分享给团队成员（授权）
1. 在“我的项目”卡片操作区点「**分享**」→ 弹窗
2. 成员表显 owner（自己，角色锁 OWNER，不可移除）
3. 邀请栏输入用户名远程搜索（只显示最小身份信息）+ 多选 + 角色下拉（EDITOR 可改资产 / VIEWER 只读引用）→ 「邀请」
4. **界面变化**：被邀请人下次进 `/assets` → 「共享给我」Tab 出现该项目
5. **改角色/移除/转让**：成员行 NSelect 改角色 / 「移除」按钮 / 「设为 owner」（转让=自己降 EDITOR）

> **L1 失权即时**：被移除/降权的成员，其「共享给我」列表立即少该项目；但其画布里**已引用的版本快照不受影响**（引用存版本号，属引用方）。

### 1.3 删除项目
1. 项目卡片右上垃圾桶 → 二次确认弹窗（列明影响：级联软删资产/成员/绑定，文件保留）
2. 仅 OWNER 可删；有成员时确认弹窗会列明影响
3. **预期**：卡片消失；`stored_files` 文件保留；画布引用快照不受影响（L4）

### 1.4 发布到公共池
1. “我的项目”卡片点「发布到公共池」。普通 OWNER 选择“直接开放”或“需要审批”；管理员固定直接开放并显示“官方发布”。
2. 发布后“公共池”页签出现摘要卡；发布不复制项目/资产/版本，源项目更新会立即反映。
3. OWNER 可点“移出公共池”；移出后公共访问立即失效，但成员授权、既有画布快照和已复制副本保留。

### 1.5 申请、审批与撤销
1. 在“公共池”查看卡片：OPEN 项目点“使用”；审批型项目点“申请使用”。
2. PENDING 显“等待审批”；REJECTED/REVOKED 显“重新申请”。未获批卡片不能进入项目内容。
3. 项目 OWNER 在自己的卡片点“审批管理”，列表按用户名识别申请人；对 PENDING 申请批准/拒绝，对 APPROVED 访问撤销。
4. 获批后进入详情只获得 VIEWER：可浏览、预览、引用、复制，不能编辑分类/资产/版本或成员。

### 1.6 复制公共资产
1. 进入可用公共项目，资产卡旁点“复制到我的项目”。
2. 选择自己拥有 OWNER/EDITOR 写权的目标项目并确认。
3. 成功后目标项目生成独立资产和版本 1；正文/文件引用取复制时源当前版本，之后源更新不会反向改变副本。
4. 公共项目及复制副本中的图片/视频/音频应可正常预览；文件仍复用存储记录，但读取权限跟随可读资产项目，不要求复制者成为原文件 owner。

## 二、资产管理（项目详情页 `/assets/:id`）

### 2.1 双轴矩阵筛选
- **顶栏**：类型分段（全部/提示词/剧本/图片/视频/音频），徽标显该类型资产数
- **左栏**：叙事角色分段（全部/人物/道具/场景/风格/通用），徽标显该角色资产数
- **下钻交集算法**：选「图片」→ 左栏角色徽标变成「图片下各角色数」；选「人物」→ 顶栏类型徽标变成「人物下各类型数」
- **搜索框**：关键词（≤50 字符），与筛选交集

### 2.2 上传图片/视频/音频
1. 「上传」按钮 → 选文件
2. **校验**：按 mime 推断类型（mp4→视频/图片→图片），类型↔资产类型须匹配（mp4 不可入图片资产）
3. **预期**：上传后自动提取技术元数据（图片宽高 / 视频时长分辨率，javacv 懒提取），新卡片出现在矩阵对应格

### 2.3 新建提示词/剧本资产
1. 「新建提示词」/「新建剧本」按钮 → 弹窗
2. 选 mediaType + 勾选叙事角色（受控词汇多选）→ 命名 → 确定
3. 进入资产详情编辑正文

### 2.4 资产详情抽屉（点卡片打开）
- **预览**：文本类 JSON 美化；图片/视频/音频自动转预览流（带鉴权 fetch → 临时 objectURL，关抽屉即释放）
- **元数据**：描述 / 叙事角色 / 标签 / 创建时间
- **状态机动作**（EDITOR+）：
  - DRAFT →「定稿」(LOCK) / 「归档」
  - LOCKED →「解锁」(回 DRAFT) / 「归档」
  - ARCHIVED →「取消归档」
  - 文件类 →「下载」（`/files/{id}` blob）
- **版本时间线**：倒序列表，点选只读查看历史版本（快照不可变，仅回滚查看）
- **一致性包**（仅 人物/道具/场景 类额显）：主参考图 + 图集 + 标准描述 + 参数基线 → 保存产新版本
- **使用记录**：该资产被哪些画布节点产出/引用（双向追溯，viewer 可读）

> **L2 定稿锁版本**：定稿后画布引用锁定当前版；**L3 归档隐藏**：归档后默认列表隐藏（搜索加状态过滤可及）。

## 三、画布打通

### 3.1 节点产出入库（L5）
1. 在无限画布生成满意产出（如一张图）
2. **节点右键** → 「存入资产库」弹窗（或属性面板「存入资产库」按钮）
3. 选项目（仅 OWNER/EDITOR 项目可选；VIEWER 不可入库）→ 叙事角色 → 命名 → 确定
4. **重复三态**：若该节点已有 PRODUCED 绑定（重复入库）→ 显「存为新版本(NEW_VERSION) / 另存为新资产(NEW_ASSET)」二选一
5. **空产出拦截**：节点无产出（图无 fileId / 文本无 outputText）时前端预检拦截
6. **预期**：资产库对应矩阵格计数+1；资产详情「使用记录」显该节点为 PRODUCED

### 3.2 从库引用资产到节点（L6）
1. 选中画布节点 → 属性面板「**从库选择**」按钮 → AssetPicker 弹窗
2. 来源可切“我的/共享项目”或“公共池”；未获批公共项目显示原因并禁用。选择可用项目后按节点类型过滤并支持关键词搜索。
3. 选定资产 → 自动 resolve 当前版本快照写回节点
4. **界面变化**：节点头部显「来自资产·name vN」徽标
5. **「有新版」**：点「检查更新」→ asset.get 比对 currentVersion > 绑定版 → 徽标变黄「有新版」（不自动变）；点「更新到最新版」→ re-resolve 写回

> 版本快照语义：引用锁某版，资产升版后**旧引用不变**，仅徽标提示，手动更新。

## 四、节点 @引用（S13）

### 4.1 插入 @引用
1. 文本/脚本/视频节点的提示词/剧本输入框，输入 **`@`**（须独立 @，前面是空白或行首——防邮箱 foo@bar 误判）
2. 弹候选列表（**仅当前节点经连线可达的祖先节点**——直接上游 + 上游的上游）
3. 键盘 ↑↓ 选中 + Enter，或鼠标点选 → 插入占位符 `@{{node:节点名}}`（实际存 node id）
4. **查询过滤**：@ 后接文字按候选 label 过滤

### 4.2 运行时插值
1. 点「生成文本」/「提交视频生成」/「拆分镜」
2. **运行前**：前端把 `@{{node:xxx}}` 替换为该上游节点的产出（文本→outputText / 脚本→分镜序列化 / 文件类→prompt+元信息）
3. **不递归**：注入串里的 @不再二次展开（防死循环）
4. **占位符原文保留**：node.data 里存的是占位符（持久化），仅运行 payload 走插值

### 4.3 断链处理（L7/L8）
- 删连线 / 删上游节点后，下游节点属性面板提示词下显**黄色「断链引用：@{{node:xxx}}（上游被删/断连，运行前请重连或移除）」**
- 运行时：断链处降级注入「【断链】」+ 顶部 message.warning（不级联失败）
- 重连/恢复后自动消除

### 4.4 重命名查重（L9）
- 同画布节点 label 不许重复
- 新建/粘贴节点：撞名自动加序号（「图片」→「图片 2」）
- 重命名：名称框失焦时若撞名自动加序号
- @占位符存 **node id**，节点重命名后 @引用**不断链**（chip 不受影响）

## 五、分镜（S15-S19）

### 5.1 剧本一键拆分镜
1. 项目详情页打开**剧本**资产（media_type=剧本）详情抽屉
2. 剧本正文里可按模板写拆解规范（`content.template`）
3. 点「一键拆分镜」→ 选段数/规范 → 确认
4. LLM 自动把剧本拆成 N 个**分镜**资产，列表出现 N 张分镜卡
5. 打开任一分镜卡：提示词（prompt）与实体引用（entityRefs）已自动填好
6. **重新拆**：再次点拆分镜 → 旧分镜产物整批被替换（不是追加）

### 5.2 分镜 5 字段编辑
分镜详情抽屉内 5 字段流水线编辑（`StoryboardFields.vue`）：
| 字段 | 说明 |
|---|---|
| 1 场景描述 | 镜头画面内容 |
| 2 提示词 | 生图/生视频用 prompt（可手改） |
| 3 生图 | **占位待接入图模型**（R-3），当前不可点 |
| 4 实体引用 | 关联的角色/场景资产（`StoryboardRefList` 展示） |
| 5 生视频 | **占位待接入**，当前不可点 |

### 5.3 画布分镜节点
1. 画布上脚本节点 → 点「拆分镜」（可设段数/规范参数）
2. 自动扇出：脚本节点 → 各分镜节点各连一条边
3. 分镜节点产物可「存到资产库」（分类=分镜）；库里选分镜也可引用回节点

## 常见异常与恢复

| 现象 | 原因 | 恢复 |
|---|---|---|
| 看不到「资产库」菜单 | 无 `asset:write` 权限 | 联系管理员授权 |
| 上传被拒「类型不匹配」 | 文件 mime 与资产类型不符（mp4 入图片资产） | 选对资产类型再传 |
| 入库弹窗项目下拉为空 | 非 OWNER/EDITOR（仅 VIEWER） | 让 owner 把你升为 EDITOR，或 owner 入库 |
| @候选列表空 | 无连线可达祖先 / 画布成环 | 拉线连上游；成环则按重跑提示解环 |
| @显「断链」 | 上游节点被删或连线被删 | 重连，或移除该 @引用 |
| 版本提交冲突 CONFLICT | 两人同时改同一资产版本 | 重新打开（拉最新版）再提交 |
| 「检查更新」无反应 | 未绑定资产 / 已是最新 | 先从库选择绑定；已是最新会提示 |

## 无限画布第二轮修复操作指引（2x，2026-08-14）

### 视频生成页：把生成好的视频入库资产库
- 视频生成完成后，「入库到资产库」按钮始终可用（此前视频预览加载失败时按钮会消失）。点它 → 命名 → 选目标项目 → 「前往资产库」确认入库。

### 画布：生成任务做到一半离开，回来还在
- 提交视频/图片生成后可以随意离开画布甚至关页面：任务关联已即时保存。
- 重新打开画布：生成中的节点会显示「生成中」并自动继续跟踪；任务已完成则自动回填结果预览、节点状态「完成」，视频节点还会带「有/无参考视频」审查标志。
- 顺手改动（拖动节点/改提示词）在离开画布时也会自动保存，不再丢失。

### 画布：图片节点选参数
1. 选中图片节点 → 属性面板「图片模型」选模型（如 Seedream lite / pro）。
2. 选完模型自动出现该模型支持的参数：尺寸（预设或自定义宽x高）、输出格式、优化模式、水印开关；lite 还有组图（自动组图+数量）和联网搜索，pro 支持引导尺度（以实际模型能力为准，不支持的不显示）。
3. 切换模型时参数自动重置为新模型的默认值。
4. 填提示词 → 「AI 生图」。

### 画布：@引用上游视频节点当参考视频
- 视频节点的提示词里 `@上游视频节点`，系统会把它作为**参考视频附件**（提示词里显示「视频1」）发给模型，而不是当成一段文字。
- 注意：参考视频/参考图与「首帧/尾帧」互斥，同时用会提示二选一。

### 画布：从资产库拉图片/视频到节点
- 选中对应类型节点 → 属性面板「从库选择」→ 选项目/公共池 → 找到资产点「选择」。
- 节点会立即显示媒体预览 + 「已引用资产 名称 v版本」徽标（此前预览不显示的问题已修复）。

### 画布：拉线快速建下一节点 + 节点自动命名
- 从一个节点右侧输出圆点**按住拉线到空白处松手** → 弹出「添加下一节点（自动连线）」搜索框 → 输入或上下键选类型 → 回车：新节点建在松手位置并自动连上线。
- 双击画布空白处的「快速添加节点」弹窗仍可用。
- 视频/图片生成完成后，节点名会自动改成提示词前 12 个字（如「一只橘猫趴在窗台上晒太阳」）；你手动改过的节点名不会被覆盖。

## 资产库第三轮操作指引（2x，2026-08-16）

### 项目设置（仅 OWNER）：成员打分开关 + 内容模式

1. 进入项目详情页，顶部点「**项目设置**」（仅项目拥有者可见）。
2. **成员打分开关**：开启后成员（EDITOR）可对资产打分并参与均分；关闭后成员不可新增/修改评分，**历史评分与均分保留**。拥有者始终可评分。
3. **内容模式**：
   - **共享（默认）**：所有编辑者可管理全部内容（原有协作方式不变）。
   - **个人**：编辑者**仅能编辑/删除/定稿/归档自己上传的内容**；拥有者不受限制；成员之间互相只能看、不能改。
   - 首次从共享切到「个人」需二次确认；切换即时生效、可随时切回、**不删除任何数据**（回切共享即恢复全部编辑权）。
4. 「个人」模式下被限制的成员，详情抽屉里的编辑/删除/定稿/归档按钮对**他人内容不显示**（下载等只读操作不受限）。

### 资产评分（百分制，双轨分开记）

1. 打开资产详情抽屉，滚动到「**评分**」区。
2. 拖动滑杆（0-100）或直接填数字 → 「**提交评分**」；再次提交会**覆盖**自己上次的分。
3. **双轨展示**：拥有者的分单列「拥有者 ★88」；成员的分自动算**均分**「成员均分 90 · 3人」——两轨互不混算（像豆瓣评委分与观众分分开记）。
4. **谁可以打分**：拥有者恒可；成员需拥有者开启「成员打分」；访客（VIEWER/公共池用户）不可。
5. 成员被移除项目后，其历史评分**保留并继续参与均分**。
6. 卡片上也会直接显示双轨分（任一轨有分才显示该行）；点「我的评分」旁可看到自己已打的分。

### 上传者标识与筛选

1. 每张资产卡和详情抽屉都显示**上传者**用户名（卡片右上角 ↑ 徽标，悬停看全名）。
2. 筛选工具条新增三项（与类型×角色×关键词叠加交集）：
   - **上传者**：输入用户名远程搜索候选，也可直接回车按任意用户名过滤；
   - **分数来源**：拥有者评分 / 成员均分；
   - **分数区间**：最低分 ~ 最高分（0-100）。
3. **历史数据说明**：修复前上传的资产，文件类（图/视频/音频）已回填**真实上传者**；文本类（提示词/剧本等）历史无法溯源，统一显示**项目拥有者**（近似值），此后新建的资产均记录真实创建者。
