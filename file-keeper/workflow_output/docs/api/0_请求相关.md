# File Keeper 后台接口请求文档

> 本文档汇总 `server` 模块的管理后台 API，方便使用 Postman 等工具调试。
> 基础地址默认：`http://localhost:8088`

---

## 1. Postman 环境变量建议

| 变量名 | 初始值 | 说明 |
|---|---|---|
| `base_url` | `http://localhost:8088` | 后端服务地址 |
| `access_token` | 空 | 登录后自动填入 |
| `refresh_token` | 空 | 登录后自动填入 |

---

## 2. 认证接口

### 2.1 管理员登录

```http
POST {{base_url}}/api/admin/auth/login
Content-Type: application/json
```

Body (raw JSON):

```json
{
  "identifier": "admin@example.com",
  "password": "Password123!"
}
```

Response 示例：

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "accessToken": "eyJhbG...",
    "refreshToken": "dGhpcyB...",
    "expiresIn": 900,
    "user": {
      "id": 1,
      "email": "admin@example.com",
      "role": "super_admin",
      "status": "active"
    }
  }
}
```

> 登录成功后，把 `accessToken` 和 `refreshToken` 保存到环境变量，后续请求使用。

---

### 2.2 刷新 Token

```http
POST {{base_url}}/api/admin/auth/refresh
Content-Type: application/json
```

Body:

```json
{
  "refreshToken": "{{refresh_token}}"
}
```

---

### 2.3 退出登录

```http
POST {{base_url}}/api/admin/auth/logout
Content-Type: application/json
```

Body:

```json
{
  "refreshToken": "{{refresh_token}}"
}
```

---

## 3. 通用请求头

所有需要登录的接口都要带以下 Header：

```http
Authorization: Bearer {{access_token}}
Content-Type: application/json
```

---

## 4. 用户管理接口

### 4.1 用户列表

```http
GET {{base_url}}/api/admin/users?status=&page=1&size=20
Authorization: Bearer {{access_token}}
```

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `status` | string | 否 | 状态：`pending_verification` / `pending_review` / `active` / `disabled` |
| `page` | int | 否 | 页码，默认 1 |
| `size` | int | 否 | 每页条数，默认 20 |

---

### 4.2 用户详情

## 5. 用户模块权益接口

### 5.1 查询用户权益

```http
GET {{base_url}}/api/admin/users/1/entitlements
Authorization: Bearer {{access_token}}
```

---

### 5.2 授予权益

```http
POST {{base_url}}/api/admin/users/1/entitlements
Authorization: Bearer {{access_token}}
Content-Type: application/json
```

Body:

```json
{
  "moduleCode": "work-report",
  "expiresAt": "2026-12-31T23:59:59+08:00"
}
```

> `moduleCode` 可选：`files` / `processes` / `clipboard` / `work-report`  
> `expiresAt` 不传表示永不过期。

---

### 5.3 启用/禁用权益

```http
PUT {{base_url}}/api/admin/users/1/entitlements/5
Authorization: Bearer {{access_token}}
Content-Type: application/json
```

Body:

```json
{
  "enabled": false,
  "expiresAt": "2026-12-31T23:59:59+08:00"
}
```

> `expiresAt` 可选。

---

### 5.4 撤销权益

```http
DELETE {{base_url}}/api/admin/users/1/entitlements/5
Authorization: Bearer {{access_token}}
```

## 10. Postman 使用技巧

### 10.1 自动保存 Token

在 **Login 请求的 Tests 标签页** 写入：

```javascript
const jsonData = pm.response.json();
pm.environment.set("access_token", jsonData.data.accessToken);
pm.environment.set("refresh_token", jsonData.data.refreshToken);
```

### 10.2 统一授权

在 Collection 级别设置 `Authorization` 为 `Bearer Token`，Token 值填 `{{access_token}}`，所有子请求会自动继承。

### 10.3 角色限制

目前只有 `role = super_admin` 的用户能调用 `/api/admin/**` 接口，普通 `user` 角色会收到 403。
