# 多Agent智能体平台 — 数据库设计文档

> 数据库：PostgreSQL 16 | 共 13 张表，4 个模块
> 主键策略：`GENERATED ALWAYS AS IDENTITY`（自增）
> 软删除：所有业务表含 `deleted` 字段（0=正常，1=已删除）
> 乐观锁：所有业务表含 `version` 字段
> 审计字段：`created_by / created_at / updated_by / updated_at`（MyBatis-Plus 自动填充）

---

## 一、表关系总览

```
                          ┌─────────────┐
                          │   users     │ 用户表
                          └──────┬──────┘
                    ┌────────────┼────────────┐
                    │            │            │
              ┌─────┴─────┐  ┌──┴───┐  ┌─────┴──────┐
              │ user_roles│  │roles │  │permissions │
              └─────┬─────┘  └──┬───┘  └─────┬──────┘
                    │           │             │
                    └────┬──────┘             │
                         │    ┌──────────────┘
                   ┌─────┴────┴──────┐
                   │role_permissions │
                   └────────────────┘

  users ──1:N──> agents ──1:N──> skills ──1:N──> skill_steps
    │                │
    │           agent_groups
    │                │
    │           (agents.group_id → agent_groups.id)
    │
    ├──1:N──> workflows ──1:N──> workflow_nodes
    │                      │
    │                      └──1:N──> workflow_edges
    │
    └──1:N──> execution_logs
```

## 二、模块一：认证（auth）— 5张表

### 2.1 users — 用户表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT | PK | 自增 | 主键 |
| username | VARCHAR(50) | 是 | — | 用户名，唯一 |
| password | VARCHAR(100) | 是 | — | BCrypt加密密码 |
| email | VARCHAR(100) | 否 | — | 邮箱，唯一 |
| avatar | VARCHAR(500) | 否 | — | 头像URL |
| status | VARCHAR(20) | 是 | 'ACTIVE' | 状态：ACTIVE / DISABLED / LOCKED |
| last_login_at | TIMESTAMP | 否 | — | 最后登录时间 |
| created_by | BIGINT | 否 | — | 创建人ID |
| created_at | TIMESTAMP | 是 | NOW() | 创建时间 |
| updated_by | BIGINT | 否 | — | 更新人ID |
| updated_at | TIMESTAMP | 是 | NOW() | 更新时间 |
| deleted | INT | 是 | 0 | 逻辑删除：0=正常，1=已删除 |
| version | INT | 是 | 0 | 乐观锁版本号 |

**唯一约束**：username、email

### 2.2 roles — 角色表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT | PK | 自增 | 主键 |
| name | VARCHAR(50) | 是 | — | 角色名称（如"普通用户"） |
| code | VARCHAR(50) | 是 | — | 角色编码（如"user"），唯一 |
| description | VARCHAR(200) | 否 | — | 角色描述 |
| created_by ~ version | — | — | — | 公共审计字段（同上） |

**初始数据**：user（普通用户）、agent_admin（Agent管理员）、admin（系统管理员）

### 2.3 permissions — 权限表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT | PK | 自增 | 主键 |
| name | VARCHAR(100) | 是 | — | 权限名称（如"查看Agent"） |
| code | VARCHAR(100) | 是 | — | 权限编码（如"agent:read"），唯一 |
| resource | VARCHAR(50) | 是 | — | 资源：agent / workflow / user / role / execution / skill |
| action | VARCHAR(50) | 是 | — | 操作：create / read / update / delete / publish / run / manage |
| created_by ~ version | — | — | — | 公共审计字段 |

**初始数据**：15条权限（agent:5 + skill:1 + workflow:5 + execution:2 + user:1 + role:1）

### 2.4 user_roles — 用户-角色关联表

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| user_id | BIGINT | PK | → users.id，级联删除 |
| role_id | BIGINT | PK | → roles.id，级联删除 |

**关系**：用户 N:N 角色（多对多）

### 2.5 role_permissions — 角色-权限关联表

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| role_id | BIGINT | PK | → roles.id，级联删除 |
| permission_id | BIGINT | PK | → permissions.id，级联删除 |

**关系**：角色 N:N 权限（多对多）

**初始分配**：
- user → 8个权限（查看Agent、工作流CRUD+发布、执行相关）
- agent_admin → 13个权限（Agent全权限 + 技能管理 + 工作流 + 执行）
- admin → 全部15个权限

## 三、模块二：Agent管理（agent）— 4张表

### 3.1 agent_groups — Agent分组表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT | PK | 自增 | 主键 |
| name | VARCHAR(100) | 是 | — | 分组名称（如"通用助手"） |
| icon | VARCHAR(50) | 否 | — | 图标标识（robot / chart / edit / code） |
| description | VARCHAR(500) | 否 | — | 分组描述 |
| sort_order | INT | 是 | 0 | 排序序号，小的在前 |
| created_by ~ version | — | — | — | 公共审计字段 |

**初始数据**：通用助手(1)、数据分析(2)、内容创作(3)、开发工具(4)

### 3.2 agents — Agent表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT | PK | 自增 | 主键 |
| name | VARCHAR(100) | 是 | — | Agent名称 |
| description | VARCHAR(500) | 否 | — | Agent描述 |
| avatar | VARCHAR(500) | 否 | — | 头像URL |
| group_id | BIGINT | 是 | — | → agent_groups.id，所属分组 |
| status | VARCHAR(20) | 是 | 'DRAFT' | 状态：DRAFT / PUBLISHED / OFFLINE |
| config | JSONB | 否 | — | 配置：{model, temperature, maxTokens, systemPrompt} |
| created_by | BIGINT | 是 | — | → users.id，创建者 |
| created_at ~ version | — | — | — | 公共审计字段 |

**索引**：group_id、status（WHERE deleted=0）、created_by

### 3.3 skills — 技能表

| 字段 | 类型 | 必填 | 默认值 | 说明 |

| id | BIGINT | PK | 自增 | 主键 |

| name | VARCHAR(100) | 是 | — | 技能名称 |
| description | VARCHAR(500) | 否 | — | 技能描述 |
| type | VARCHAR(30) | 是 | 'SEQUENCE' | 执行类型：SEQUENCE(顺序) / CONDITION(条件) / PARALLEL(并行) |
| config | JSONB | 否 | — | 技能配置 |
| sort_order | INT | 是 | 0 | 排序序号 |
| created_by ~ version | — | — | — | 公共审计字段 |

**索引**：agent_id（WHERE deleted=0）

### 3.4 skill_steps — 技能步骤表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT | PK | 自增 | 主键 |
| skill_id | BIGINT | 是 | — | → skills.id，所属技能 |
| step_order | INT | 是 | — | 步骤顺序号 |
| name | VARCHAR(100) | 是 | — | 步骤名称（如"理解需求"） |

| config | JSONB | 否 | — | 步骤配置（提示词、URL等） |
| created_by ~ version | — | — | — | 公共审计字段 |

## 四、模块三：工作流编排（workflow）— 3张表

### 4.1 workflows — 工作流表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT | PK | 自增 | 主键 |
| name | VARCHAR(100) | 是 | — | 工作流名称 |
| description | VARCHAR(500) | 否 | — | 工作流描述 |
| status | VARCHAR(20) | 是 | 'DRAFT' | 状态：DRAFT / PUBLISHED / ARCHIVED |
| owner_id | BIGINT | 是 | — | → users.id，所有者 |
| created_by ~ version | — | — | — | 公共审计字段 |

**索引**：owner_id（WHERE deleted=0）、status（WHERE deleted=0）

### 4.2 workflow_nodes — 工作流节点表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT | PK | 自增 | 主键 |
| workflow_id | BIGINT | 是 | — | → workflows.id，级联删除 |
| node_id | VARCHAR(50) | 是 | — | 画布节点UUID（如"node-abc123"） |
| type | VARCHAR(30) | 是 | — | 节点类型：START / END / AGENT / CONDITION / PARALLEL / LOOP |
| position_x | DOUBLE | 是 | 0 | 画布X坐标 |
| position_y | DOUBLE | 是 | 0 | 画布Y坐标 |
| label | VARCHAR(100) | 否 | — | 节点显示名称 |
| config | JSONB | 否 | — | 节点配置（AGENT类型含agentId，CONDITION含expression等） |
| created_by ~ version | — | — | — | 公共审计字段 |

**唯一约束**：(workflow_id, node_id)

**索引**：workflow_id

### 4.3 workflow_edges — 工作流边表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT | PK | 自增 | 主键 |
| workflow_id | BIGINT | 是 | — | → workflows.id，级联删除 |

| target_node_id | VARCHAR(50) | 是 | — | → workflow_nodes.node_id，目标节点 |
| source_handle | VARCHAR(50) | 否 | — | 起始连接点（用于条件分支的"是/否"端口） |
| target_handle | VARCHAR(50) | 否 | — | 目标连接点 |
| label | VARCHAR(100) | 否 | — | 边标签 |
| condition | TEXT | 否 | — | 条件表达式（JavaScript） |
| created_by ~ version | — | — | — | 公共审计字段 |

**索引**：workflow_id

## 五、模块四：执行日志（execution）— 1张表

### 5.1 execution_logs — 执行日志表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT | PK | 自增 | 主键 |
| workflow_id | BIGINT | 是 | — | → workflows.id，被执行的工作流 |
| workflow_name | VARCHAR(100) | 否 | — | 工作流名称（快照，避免删改后丢失） |
| triggered_by | BIGINT | 是 | — | → users.id，触发人 |
| status | VARCHAR(20) | 是 | 'RUNNING' | 状态：RUNNING / SUCCESS / FAILED / CANCELLED |
| variables | JSONB | 否 | — | 执行时的全局变量 |
| node_logs | JSONB | 否 | — | 节点执行日志数组：[{nodeId, type, status, input, output, error, startedAt, completedAt}] |
| started_at | TIMESTAMP | 是 | NOW() | 开始时间 |
| completed_at | TIMESTAMP | 否 | — | 完成时间 |
| duration | BIGINT | 否 | — | 执行耗时（毫秒） |
| error_message | TEXT | 否 | — | 错误信息 |
| created_by ~ version | — | — | — | 公共审计字段 |

**索引**：workflow_id、triggered_by、status、started_at DESC

## 六、完整关联关系

| 关系 | 类型 | 外键 | 说明 |
|------|------|------|------|
| users → user_roles → roles | N:N | user_roles.user_id → users.id | 一个用户可有多个角色 |
| roles → role_permissions → permissions | N:N | role_permissions.role_id → roles.id | 一个角色可有多个权限 |
| agent_groups → agents | 1:N | agents.group_id → agent_groups.id | 一个分组下多个Agent |
| users → agents | 1:N | agents.created_by → users.id | 用户创建的Agent |
| agents → skills | 1:N | skills.agent_id → agents.id | 一个Agent有多个技能 |
| skills → skill_steps | 1:N | skill_steps.skill_id → skills.id | 一个技能有多个步骤 |
| users → workflows | 1:N | workflows.owner_id → users.id | 用户拥有的工作流 |
| workflows → workflow_nodes | 1:N | workflow_nodes.workflow_id → workflows.id | 一个工作流多个节点 |
| workflows → workflow_edges | 1:N | workflow_edges.workflow_id → workflows.id | 一个工作流多条边 |
| workflows → execution_logs | 1:N | execution_logs.workflow_id → workflows.id | 一个工作流多次执行 |
| users → execution_logs | 1:N | execution_logs.triggered_by → users.id | 用户触发的执行 |
