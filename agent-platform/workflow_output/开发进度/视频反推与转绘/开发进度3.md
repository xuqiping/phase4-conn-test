## 关键决策

1. **默认仅勾关键帧**：零 LLM 成本先看帧；勾分镜/剧本才产生多模态 token（提示文案随帧数联动预估）。
2. **reversing 与 running 分离**：反推是长任务（秒~分钟），独立 `reversingNodeId`，取消按钮只依 reversing——不与生成 running 抢状态。
3. **取消语义（plan L2）**：AbortController 只断前端等待；服务端 in-flight 抽帧/LLM 自然完成并计费，已落库帧文件保留；画布零节点，重跑重新抽帧（幂等不保证，toast 说明）。
4. **节点布局**：帧列纵向（×120px）紧邻视频节点右侧；分镜表→storyboard 节点（表格化文本 `#1 0.0-5.2s 远景/推 描述 台词：…`）；剧本→script 节点（synopsis=缩进 JSON，可直接再拆分镜/转绘）。
5. **转绘产物可追溯**：新 script 节点 data 存 `changeLog` + `localizeWarning`（节点详情可查）；warning 非空 toast「结果仍可用请人工核对」不阻断（plan L3）。
6. **失败不建节点**：反推/转绘失败只标红源节点 errorMsg，不产半成品节点（同 C11/C12 口径）。
