# 访谈提纲与问卷设计模板

## 一、深度访谈提纲模板（5段式）

### 段1：暖场（5min）

```
"感谢你来聊，今天没有对错，我想了解你的真实体验。"
"先简单聊聊——你现在做什么工作？平时用什么[品类]？"
```

### 段2：任务回溯（10min）

```
"能讲讲你上次[做X任务]是什么时候？从头到尾怎么做的？"
→ 追问：每一步具体怎么操作的？中间有没有卡住？
```

### 段3：痛点深挖（15min）

```
"做这个任务时，最麻烦/最不爽的是哪一步？"
→ 5WHY追问到根因
→ 场景追问："给我讲一个最近的例子？"
```

### 段4：方案验证（10min）

```
"如果你有一个魔法棒，你最想改什么？"
→ 追问：为什么这个最重要？改了之后你会怎么做？
```

### 段5：总结确认（5min）

```
"我总结一下你说的核心需求是X、最大痛点是Y，对吗？"
"还有什么想补充的？"
```

**访谈提纲设计Checklist**：

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 每个问题都是开放式的 | 不含"是不是好不好"式问题 |
| 2 | 有追问策略 | 核心问题后标注追问方向 |
| 3 | 含场景追问 | 至少3题要求"给我讲个具体例子" |
| 4 | 不含引导语 | 没有暗示PM偏好的措辞 |
| 5 | 总时长≤60min | 含暖场和收束不超过1小时 |

## 二、问卷设计Checklist

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 每题只问一个概念 | 无"X且Y"式复合问题 |
| 2 | 选项MECE | 同维度选项互斥+有"其他"兜底 |
| 3 | 无引导措辞 | 无"很多人喜欢X"类引导语 |
| 4 | 先封闭后开放 | 开放题在问卷后1/3 |
| 5 | 逻辑跳转正确 | 未使用X功能的跳过X题 |
| 6 | 含筛选题 | 前3题筛除非目标用户 |
| 7 | 含NPS/满意度 | 至少1个标准化量表便于横向对比 |
| 8 | 时长≤10min | 预估填答时间<10分钟 |
| 9 | 有预测试 | 找5人试填并修正歧义题 |
| 10 | 有激励方案 | 答完有奖品/红包/积分 |

## 三、可用性测试任务模板

```
【任务1】[用户目标描述，非操作指令]
例如：❌"点击我的订单" ✅"查看你最近一次购物并尝试退货"
预期路径：首页→我的→订单→选择订单→退货
记录要点：是否迷路/在哪停顿/是否求助/完成时间/情绪
```

**严重度评级标准**：

| 级别 | 定义 | 处理优先级 |
|---|---|---|
| **致命** | 用户完全无法完成任务 | P0 本迭代必修 |
| **严重** | 用户绕了很久才完成 | P1 尽快修 |
| **轻微** | 用户轻微困惑但很快恢复 | P2 有空再修 |
