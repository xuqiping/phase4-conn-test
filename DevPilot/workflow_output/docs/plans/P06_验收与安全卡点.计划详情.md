## S4 · 安全扫描引擎

- **对应需求**：FR-040 / AC-044
- **目标**：实现本地静态安全扫描，输出分级 findings。
- **动作**：
  1. `core-orchestrator/src/security_scanner.rs`：`SecurityScanner::new(project_path, scale)`。
  2. 内置规则：
     - 密钥硬编码：匹配 `sk-...`、`AK...`、`-----BEGIN PRIVATE KEY-----`，白名单 `.test`/`.example`/注释。
     - 鉴权缺失：扫描后端路由文件中无保护且路径含 `admin|user|auth|delete` 的 handler。
     - DB/端口暴露：扫描配置中的 `0.0.0.0`、`5432`、`3306`、数据库连接串含密码。
  3. 依赖漏洞：本地有 `npm` 时运行 `npm audit --json`；有 `cargo audit` 时运行并解析；失败记 `partial`。
  4. 返回 `ScanReport { status, findings }`。
- **涉及文件**：
  - `core-orchestrator/src/security_scanner.rs`
  - `core-orchestrator/src/lib.rs`
- **依赖**：S0。
- **并行**：`[P]` 与 S5 同批（S5 依赖 S4 接口）。
- **安全检查**：扫描子进程只读；超时 kill； findings 中密钥值脱敏。
- **验证**：注入含高危密钥、缺失鉴权、DB URL 的样本，断言 fail 且分级正确。
