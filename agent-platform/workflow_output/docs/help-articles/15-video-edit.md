# 视频剪辑

> 入口：侧栏「**视频剪辑**」。看不到菜单 = 没有权限，找管理员开通。

## 一、剪一段视频（最快上手）

1. 进入页面：左边「剪辑台」，右边「当前任务/历史任务」。
2. 点「**上传视频片段**」选本地视频 → 自动加入视频轨末尾。
3. 点「**添加字幕**」→ 字幕轨出现一条字幕 → 右侧填文字、选位置（底部/居中）、调字号。
4. 拖时间线上的段块，或在属性面板改起止时间。
5. 「输出」区选分辨率（480p/720p/1080p）和帧率。
6. 点「**提交渲染**」→ 右侧「当前任务」：排队中 → 渲染中 → **已完成**。
7. 直接播放，或点「**下载成片**」拿 mp4。

**耗时**：短视频通常几秒到 1 分钟；长视频/多音轨更久。

## 二、多轨混剪

- **视频轨**：1 条，可排多段（段之间留空自动补黑帧）。
- **音轨**：最多 4 条，「上传音频」加入；属性面板调音量（0~1）。
- **字幕轨**：1 条，可加多段字幕。

## 三、导出剪映草稿（不渲染）

1. 排好视频段/音频/字幕。
2. 点「**导出剪映草稿**」→ 浏览器下载 zip。
3. 解压后把素材目录拖入剪映（CapCut）继续精剪。

## 四、历史任务

右侧「历史任务」列出自己的任务（最近 50 条）；已完成的可回看播放/下载。

## 常见异常

| 现象 | 原因 | 恢复 |
|---|---|---|
| 「提交渲染」按钮灰 | 视频轨是空的 | 至少加一个视频段 |
| 失败，错误含 `adelay`/`all=` | 服务器 ffmpeg 版本太旧 | 找运维升级 ffmpeg |
| 失败，含「字幕渲染失败：未配字体」 | 服务器缺中文字体 | 找运维配置字体 |
| 失败，含「素材未 copy 到 temp」 | 素材文件已失效 | 重新上传素材 |
| 成片有画面没声音 | 原视频无音轨且没加音频 | 加一条音轨 |
| 轮询卡住 | 网络断了 | 刷新页面，任务在历史里 |
