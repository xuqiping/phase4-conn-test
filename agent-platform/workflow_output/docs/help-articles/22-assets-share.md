# 资产库协作：分享、公共池、评分

## 一、把项目分享给同事

1. 「我的项目」卡片点「**分享**」。
2. 弹窗打开**直接显示候选用户**（最多 50 人，已排除现有成员）；输用户名可精确筛选。
3. 选人 + 选角色（编辑者可改资产 / 只读者仅引用）→「邀请」。
4. 对方在「共享给我」页签看到该项目。
5. 之后可改角色/移除成员/「设为 owner」转让项目。

> 被移除的成员立即看不到项目；但他画布里**已引用的版本快照不受影响**。

## 二、项目设置（仅项目主）

项目详情页顶部「**项目设置**」：

- **成员打分开关**：开了成员才能评分；关掉后历史评分保留但不能再打。项目主始终可评。
- **内容模式**：
  - **共享**（默认）：所有编辑者都能改全部内容。
  - **个人**：编辑者只能改/删**自己上传的**内容（互相只能看）。首次切换需二次确认，随时可切回，不删任何数据。

## 三、发布到公共池（全平台可用你的资产）

1. 项目卡片点「**发布到公共池**」。
2. 选开放方式：**直接开放** 或 **需要审批**（管理员发布显示「官方发布」）。
3. 可设「**允许公共用户复制资产**」开关：关掉后别人只能引用、不能把资产复制成副本（你的项目成员不受影响）。
4. 发布后「公共池」页签出现摘要卡；源项目更新立即反映（发布不是复制）。
5. 「移出公共池」→ 公共访问立即失效（已复制的副本保留）。

**使用公共池资产**（图片/视频生成页选资产时）：
1. 资产选择弹窗顶部切到「**公共池**」→ 下拉选项目（只列你能用且类型匹配的）。
2. 需要审批的项目点「申请使用」→ 等发布者审批。
3. 若看不到「复制到我的项目」按钮 = 发布者关了复制权限（引用照常用）。

## 四、评分等级（A+/A/B/C/D）

**双轨记分**：项目主的分单列；成员的分算均分——两轨不混（像评委分和观众分）。

1. 打开资产详情抽屉 →「评分」区 → 拖滑杆（0-100）→「提交评分」。再交覆盖自己上次的分。
2. **等级表**：A+ =95-100，A =90-94，B =80-89，C =70-79，D =0-69。没评分不显示等级。
3. 拖滑杆时实时显示「当前 xx 分 · x档」（94↔95 会看到 A↔A+ 跳档）。
4. **快捷筛选**：筛选条「等级」下拉选档 = 自动填好分数区间（选 A+ 即 95-100）；清除等级不会清掉你手填的区间。

**注意**：成员被移出项目后，他的历史评分**保留并继续参与均分**；文本类老资产的上传者统一显示项目主（历史无法溯源，近似值）。

## 常见异常

| 现象 | 原因 | 处理 |
|---|---|---|
| 公共池下拉是空的 | 没有对你开放且类型匹配的项目 | 找项目主开放或申请审批 |
| 分享下拉找不到某人 | 对方已是成员/是项目主/是你自己 | 正常排除 |
| 卡片只有分没有等级徽章 | 还没人评分 | 评过即出现 |
| 滑杆一打开是 50 分 · D | 未评分默认 50 | 拖到想要的分再提交 |
