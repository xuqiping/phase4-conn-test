
# 已解决
1. 项目组模块（个人可创建项目组 + 从个人积分划拨指定积分数到组池）✅（2026-08-18 计划5 Step1-8 全落地，详见 [7x_积分系统.md](7x_积分系统.md) 已解决 #7）—— V133 四表 + 组长个人↔组池划拨/回收（条件 UPDATE 防负）+ 成员按人限额 + 组池幂等记账 + 异步媒体三重预检估价/结算/失败退款 + 「项目推进」模块。
2. 参与项目统一入口 + 全模型调用消耗组池 + 账单/日志记录项目组 ✅（2026-08-20 完成，`7c4d630f`）——
   - **统一入口**：原五处分散选择器（智能对话/知识库问答/图片/视频/画布顶栏）收拢为**页顶 AppHeader 唯一「参与项目」选择器**；Pinia store + 单键 `project_group_id` 全局唯一真相；旧五入口遗留选择（4 个 localStorage 键 + 画布快照 projectGroupId）打开对应页面时一次性收养（全局已设则不覆盖，旧键留作回滚）；各页面原位置改为小标签只显当前计费去向。
   - **积分展示**：页顶选择器旁实时显示「组池 xxx」+「个人 xxx」积分徽标（挂载加载、路由切换轻刷新；多项目组的余额在选择器下拉里逐项带余额标签可对比后切换）。
   - **消耗与账单**：选中组后所有模型调用（对话/问答/生图/生视频/画布）随请求携带组 id 消耗组池（账单项目组列此前已于 2026-08-18 落地，见 7x 已解决 #8）；切组后正在编辑的画布自动调度保存，快照计费去向跟上当前选择。
   - **权限补授（V137，冒烟实测发现）**：V134 建权限码时 `project-group:manage` 只授 admin → 普通用户 `/api/project-groups/mine` 403、页顶选择器恒空；V137 补授 `user` 角色后建组/划拨/组池计费对普通成员可用（越权防线不动：service 层 `requireOwner` 只许操作自己是组长的组）。
