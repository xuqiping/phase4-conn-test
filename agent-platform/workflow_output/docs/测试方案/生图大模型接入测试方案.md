# 生图大模型接入 · 测试方案

> 功能需人工交互测试（UI 体验 + 真第三方 ctaigw 调用 + 生图主观视觉），故产出本方案。自动化能覆盖的（请求体构建/响应解析/参数校验/能力默认/ownership/入库桥）已落单测（见下），此处聚焦**人工 E2E + 功能联动用例**。
>
> 覆盖两个模型：**Seedream 5.0 lite**（≤14 参考图、组图 max15、联网、stream、2K/3K/4K+WxH、optimize 仅 standard、无 guidance）与 **Seedream 5.0 pro**（≤10 参考图、无组图/联网/流式、2K/3K+WxH、guidance[1,10]、standard+fast）。

## 二、人工 E2E（需真 ctaigw key + 浏览器）

**前置**：admin 在「设置→全局模型供应商」建一条 **IMAGE 类 provider**（name=`ctaigw-image`、category=IMAGE、apiEndpoint=`https://ai.ctaigw.cn/v1/images/generations`、apiKeyEnc=填真实 ctaigw key、models=两模型）；admin 在「积分计费→价表」配两模型 `price_per_image`（V66 表就绪，**无 seed**）；一个普通 user 账号。

| # | 场景 | 步骤 | 预期 |
|---|---|---|---|
| E1 | lite 文生图端到端 | 选 Seedream 5.0 lite → 提示词「赛博朋克猫咪」→ 4K → 生成 | 同步返回，网格渲染 1 张图，可下载；历史新增一行；扣 1 张图积分 |
| E2 | lite 组图批量 | lite → sequential=auto → max_images=4 → 提示词 | 生成 4 张组图，网格 4 格，扣 4 张图积分 |
| E3 | lite 参考图生图 | lite → 从资产库选 3 张参考图 → 提示词 → 生成 | 图反映参考图风格；task_type=IMAGE2IMAGE |
| E4 | lite 联网搜索 | lite → 打开联网搜索 → 提时事提示词 | 联网检索后生图（请求体带 tools[web_search]） |
| E5 | pro 文生图 | 选 Seedream 5.0 pro → guidance=7 → fast → 2K → 生成 | 生成 1 张；表单无 sequential/web_search/stream 控件 |
| E6 | pro 参考图上限 | pro → 尝试选第 11 张参考图 | 第 11 张被拦（cap=10） |
| E7 | 自定义宽高 | 任模型 → size 选「自定义宽x高」→ 输 `1536x1024` → 生成 | 按指定尺寸生图 |

| E9 | ownership 隔离 | user A 生成 → user B 查 A 任务 | 普通用户只看自己；admin 全量 |
| E10 | 一键入库 | 任意图生成后 → 点「入库」→ 选可写项目 → 命名 → 入库 | 资产库出现该 IMAGE 资产 v1，预览图即生成图 |

| E13 | 余额不足 | user 余额清零 → 提交 | 前端拦截/后端 requireAffordable 拒绝，不建任务行 |

## 三、功能联动用例（对齐 plan 联动点清单，含正向/反向/半选/批量）

### 联动 1：模型切换 ↔ 表单重渲染

| 用例 | 操作 | 预期联动 |
|---|---|---|
| 正向 | lite ↔ pro 互切 | 控件按各自 manifest 重渲染：lite 显 sequential/web_search、pro 显 guidance、optimize 候选变（lite=standard/pro=standard+fast） |
| **反向** | lite 已传 12 张参考图 → 切 pro（cap=10） | 已传参考图被**清空**（避免超新模型上限）；size 若原 4K→pro 无 4K 回退默认 2K |
| 半选 | 切模型时提示词保留 | 仅重置 size/sequential/参考图，提示词/水印不丢 |

### 联动 2：sequential=auto ↔ max_images 显隐 + 上限

| 用例 | 操作 | 预期联动 |
|---|---|---|
| 正向 | lite sequential=auto | 显 max_images 输入，范围 [1,15] |
| **反向** | sequential=disabled | 隐 max_images；提交不带 sequential |
| 半选 | 已选 12 参考图 + sequential=auto + max_images=4（12+4>15） | 后端校验 ref+max≤15 拒（400「参考图+组图超 15」） |
| 批量 | max_images=15 无参考图 | 生成 15 张组图，扣 15 张积分 |

### 联动 3：size 模式互斥 ↔ 控件切换

| 用例 | 操作 | 预期联动 |
|---|---|---|
| 正向 | 选 preset「3K」 | 自定义 WxH 输入隐藏；提交 size=3K |
| **反向** | 选「自定义宽x高」 | preset 值清空；提交 size=`<custom>` |
| 半选 | 切 lite→pro 时 size 原 4K | pro 无 4K 候选→回退默认 |

### 联动 4：任务 SUCCEEDED ↔ 多图下载落地 + 网格渲染

| 用例 | 操作 | 预期联动 |
|---|---|---|
| 正向 | lite 组图 4 张 SUCCEEDED | worker 逐张下载存 fileId（source=MEDIA）→result_meta.imageFileIds[4]→前端网格 4 格 |
| **反向** | mock 部分 data[].error | 该张标失败占位，其余正常渲染；计费按 usage.generated_images（非 data 长度） |
| 批量 | 15 张组图全 SUCCEEDED | 网格 15 格，逐张可下载/入库 |

### 联动 5：一键入资产库 ↔ 复用 fileId（**实现偏离 plan：无三态**）

> **偏离说明**：plan 联动 5 原写「三态重复（NEW_VERSION/NEW_ASSET）」。实现决定**生图入库无重复检测**——同一张图可多次入库为独立资产（用户可能想存进不同项目）。理由：生图产物无画布节点绑定，无 PRODUCED 关系，无「该产出已入库」语义。`MediaImportVO.created` 恒 true，无 duplicate 分支。

| 用例 | 操作 | 预期联动 |
|---|---|---|
| 正向 | 生成图 → 入库到项目 A | 资产库新增 IMAGE 资产 v1，fileId 复用（不拷贝），genMeta.source=MEDIA |
| **批量** | 同一张图 → 入库到项目 A、再入库到项目 B | 两个独立资产，各自 v1，共享同一 stored_files 行 |
| 反向 | viewer 项目入库 | 项目下拉不列；POST → 403 |
| 半选 | 未选项目点入库 | 入库按钮禁用 |

### 联动 6：参考图从资产库选取 ↔ 附件槽

| 用例 | 操作 | 预期联动 |
|---|---|---|
| 正向 | 资产库选 3 图填参考图槽 | 缩略图渲染，计数 3/cap |
| **反向** | 已达 cap 再选 | AssetFilePicker 按剩余槽位禁选；绕前端 POST → 400「参考图超限」 |
| 半选 | 取消已选某图 | 槽位回退，计数-1 |
| 批量 | 一次选满 cap（lite 14 / pro 10） | 全部入槽，达上限后「+」按钮消失 |

### 联动 7：余额不足 ↔ 提交拦截

| 用例 | 操作 | 预期联动 |
|---|---|---|
| 正向 | 余额>0 提交 | 建任务行；生成完按张扣（后扣，允许瞬时欠款） |
| **反向** | 余额=0 提交 | requireAffordable 预检失败→不建任务行；前端提示余额不足 |
| 半选 | 余额仅够 1 张但提交组图 4 张 | 预检只看 balance>0（不预扣 4 张）→建行→生成完按实际张扣→瞬时欠款→下次提交拦截 |

> **三处对齐**：plan 联动点清单（7 条）↔ 本方案联动用例（逐条 + 正向/反向/半选/批量）↔ UserOps 界面变化（选模型→渲染控件→提交→网格→下载/入库）。

## 四、运维能力验证（随 chunk 已埋）

- **可观测性**：worker 任务态变更打日志（taskId/userId/model/status/generatedImages/cost）；失败 WARN；入库桥 `media import as new asset: assetId/taskId/idx/fileId/projectId/userId`。
- **配置开关**：单模型 manifest enabled 标志可禁；provider 行可删（删后提交 FAILED「供应商已停用或删除」）。
- **可回滚**：V84 仅 `ADD COLUMN result_meta`（附 drop）；provider 行可删；task_type 新值无 CHECK 约束破坏。
- **限流/降级**：同步调用 response 超时 90s；imageDownloadClient 64MB 缓冲；网关 5xx 友好报错；余额预检兜底。

## 五、部署必做（人工）

1. **IMAGE provider 密钥**：admin 填 ctaigw IMAGE provider 的 apiKeyEnc（与 chat/视频同 ctaigw key）。
2. **价表**：admin 在 pricing_rule 配两模型 `price_per_image`（V66 表就绪，**无 Flyway seed**）。缺行→PRICING_NOT_FOUND 被 MediaBillingService 吞→usage 记 FAILED、不阻生成但**不计费**。
3. **菜单权限**：复用 `media:gen`（V54 已 seed），给需用图片生成的角色授权。
