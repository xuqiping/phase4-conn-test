# D-19.03 模型选型与评估

## 是什么

**模型选型与评估（Model Selection & Evaluation）**：为AI产品在通用大模型/垂类模型/边缘小模型、闭源/开源之间做选型决策，并用基准测试（Benchmark）+ 人评 + LLM-as-Judge + 业务场景评测四套方法评估模型能力、性价比与合规性的系统化方法。2026年已从"看MMLU分数选模型"进化为"六维能力评估 + 业务场景实测 + 成本-质量权衡 + 合规评估"的工程化体系。 [来源:腾讯云/SegmentFault | 🔍高 | 2026]

**三个核心问题**（PM视角）：
1. **选什么模型**——通用大模型（GPT-5.5/Claude Opus/Gemini 3）vs 垂类模型（医疗/法律/代码专精）vs 边缘小模型（端侧/私有化）；闭源（API）vs 开源（Llama 4/Qwen 3/DeepSeek可自部署）
2. **怎么评估**——基准测试（MMLU/GPQA/SWE-bench/OSWorld）+ 人评（Chatbot Arena）+ LLM-as-Judge + 自建业务场景评测集
3. **怎么对比**——能力维度×成本×延迟×合规×可定制性的多目标决策

**2026模型格局**（基于SuperCLUE/SWE-bench Pro/GPQA Diamond权威测评）[来源:OSCHINA/51CTO/CSDN | 🔍高 | 2026-06/07]：
- **第一梯队（海外闭源）**：GPT-5.5（全能均衡六边形战士）、Claude Opus 4.8（推理封王+编程强）、Gemini 3 Pro（多模态碾压+超长上下文）
- **国产追平梯队**：DeepSeek V4/R2（极致性价比）、Qwen 3.7、GLM 5.2、Kimi 2.6、豆包2.1 Pro（字节，Benchmark对标国际旗舰）
- **开源阵营**：Llama 4（MoE 1.2万亿参数，MMLU/HumanEval/GSM8K均89.7%）、DeepSeek开源、Qwen开源
- **编程专精**：MiniMax M3（SWE-Bench Pro 59%登顶）

**2026评测范式转移**：[来源:CSDN评测范式革命 | 🔍高 | 2026-07]
- MMLU从"能力标尺"退化为"准入门槛"（顶级模型86-90%，差距缩小）
- GSM8K成新模型"开机自检"
- 真正决定落地的是Agent能力基准（OSWorld：连续多步操作办公软件的能力）——靠规划/容错/状态管理而非记忆
- 评测从"刷分"转向"工程落地六维能力评估"

## 核心要素

| 要素 | 说明 | 典例 |
|---|---|---|
| **模型分类选型** | 按场景选通用/垂类/边缘、闭源/开源 | 通用GPT-5.5；垂类代码Claude；边缘Phi；开源Llama 4 |
| **基准测试（Benchmark）** | 标准化能力测试集 | MMLU(知识)/GPQA Diamond(推理)/SWE-bench(代码)/OSWorld(Agent)/HumanEval(代码) |
| **人评（Human Eval）** | 人类盲评模型输出质量 | Chatbot Arena（Elo评分，公认最贴近真实体验） |
| **LLM-as-Judge** | 用强模型当裁判评其他模型 | GPT-4/Claude评生成质量，低成本大规模 |
| **自建业务评测集** | 针对自身业务场景建黄金集 | 抽取/分类/对话/Agent任务的业务case集 |
| **评估指标体系** | 多维度量化模型能力 | 准确率/采纳率/格式合规/延迟/成本/幻觉率 |
| **性价比评估** | 质量÷成本的单位成本质量 | DeepSeek性价比无敌；按Token/按请求计费对比 |
| **合规评估** | 数据隐私/内容合规/地域可用性 | 数据出境/内容审核/备案/本地化部署 |
| **成本-质量权衡** | 质量达标下选成本最低 | 简单任务用便宜模型+复杂任务用强模型的路由策略 |
| **模型路由（Routing）** | 按任务难度动态路由到不同模型 | 简单问题→小模型；复杂→大模型 [详见 D-19.09 Token成本] |

## 为什么AI PM必须懂模型选型与评估

1. **模型选错=产品失败**——选了贵模型成本爆炸、选了弱模型质量崩、选了不合规模型上线被拦；2026年AI产品在核心业务渗透率破60%，模型选型直接影响产品体验与商业可行性 [来源:腾讯云 | 🔍高 | 2026]
2. **"看MMLU分数选模型"是严重误区**——2026年MMLU已成"准入门槛"，模型间差距缩小，真正决定落地的是业务场景实测+Agent能力+成本-质量权衡，而非榜单分数 [来源:CSDN/SegmentFault | 🔍高 | 2026]
3. **国产模型追平+开源崛起改变选型逻辑**——DeepSeek/Qwen/GLM性价比逼近甚至超越海外闭源，Llama 4开源可私有化部署；2026选型不再是"无脑选GPT"，而是按场景+成本+合规多目标决策 [来源:什么值得买/CSDN | 🔍高 | 2026-06]
4. **评测是AI PM的I.09核心硬技能**——本能力有`I.09必选`标记，量化评估指标是核心维度；不会评测就无法做AB、无法量化产品改进、无法做成本优化
5. **推理模型（o1/R1类）颠覆评测与选型**——推理模型内化CoT，传统提示词技巧失效，评估方法也需调整（推理时延/成本与准确率的权衡是新评估维度）[详见 D-19.02 提示词工程]

## 常见误区

- **误区1：只看MMLU/榜单分数选模型**——MMLU已退化为准入门槛，榜单分数≠业务场景表现，必须自建业务评测集
- **误区2：无脑选最强模型**——强模型成本高/延迟长，简单任务用强模型是浪费；应按任务难度路由
- **误区3：忽视性价比**——DeepSeek等国产模型性价比远超GPT，质量接近但成本1/10，不评估性价比是商业失职
- **误区4：不做合规评估**——数据出境/备案/内容审核/地域可用性不评估，上线即被拦
- **误区5：只做自动评测不做人评**——自动指标（BLEU/ROUGE）与人类偏好相关性弱，必须配人评或LLM-as-Judge
- **误区6：评测集不迭代**——业务场景变化后评测集不更新，评测结果失真
- **误区7：忽视模型敏感性**——换模型/升级模型后提示词可能失效，不做回归测试就上线翻车
- **误区8：开源=免费**——开源模型自部署有GPU成本+运维成本+安全成本，不一定比API便宜
