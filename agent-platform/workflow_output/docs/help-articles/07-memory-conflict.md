# 记忆冲突与时间线

> 你先说「住萧山」，后说「住拱墅」——系统发现矛盾，会请你裁决。这篇教你怎么处理。

## 一、冲突卡片出现了怎么办

1. 发了和旧记忆矛盾的话后，记忆面板顶部出现「**待解决的记忆冲突**」卡（🔖 图标也会带红点）。
2. 卡片列出**新值和旧值**供你对比。
3. 三种处理方式：
   - **合并保留**：两条都留（适合时间线类，见下）。
   - **自定义**：手动改成你想要的最终值（如把「住萧山」改成「住萧山区市心路」）→ 确认。
   - 在「冲突裁决」页签里还有四选项：**都留 / 留新的 / 留旧的 / 丢弃**（丢弃会二次确认）。

## 二、时间线标记（住址/工作这类会变迁的信息）

1. 冲突卡上有「**时间线：是/否**」选择（首次处理该信息时显示「未设」）。
2. 住址、工作、状态这类**会随时间变化**的信息 → 选「**是**」。
3. 选「是」后合并保留，记忆值显示为时间线：`2026-06-25 住萧山；2027-01-01 住拱墅`——AI 能分清「以前住哪、现在住哪」。
4. 选「否」→ 值直接拼接（如 `小美,小芳`），适合孩子名字这类并列信息。
5. 同一信息的标记**设一次全局生效**，下次冲突不再问；想改就在下次冲突卡上重选。

## 三、查看时间线记忆

- 「我的记忆」列表里，时序信息的「值」列显示多段「日期 + 内容」，一目了然。
- 老数据（没日期的）按单值显示，不受影响。

## 注意

- 日记类信息自动按时间线处理，不用手设。
- AI 的回答不会进记忆（只记你说的话）。
- 只有你自己能裁决自己的记忆冲突，别人动不了。
