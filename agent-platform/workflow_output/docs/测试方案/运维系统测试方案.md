> Phase 3 功能级预处理产出。关联规格：[../../0_推进计划/4_运维系统.md](../../0_推进计划/4_运维系统.md)，覆盖 OPS-FR-01~22。

## 1. 为什么需要人工测试（判定依据）
- [x] 走真实第三方依赖（Prometheus/Grafana/钉钉 webhook/pg_dump/robocopy，真实进程与服务器环境）
- [x] 需人工确认的流程（kill 进程看告警、备份还原抽查、模拟坏包发布回滚、恢复演练）

**自动化覆盖不了的具体点**：P0 埋点正确性由单测覆盖；但「端点真实可达」「kill 进程 5 分钟内钉钉到信」「pg_dump 备份能还原出真数据」「deploy.bat 坏包自动回滚」必须真人起真实环境验证。看板视觉效果需人眼确认。

## 2. 前置条件
- **环境**：本机 dev（P0 验证用）+ Windows Server 生产机（P1/P2/P3 验证用）
- **数据准备**：dev 库正常 Flyway 到最新；测试账号 admin；一个可对话的 LLM provider 配置
- **依赖服务**：PG、Redis、sidecar（P0）；Prometheus/Grafana/Alertmanager/windows_exporter（P1，服务器窗口安装）；异地副本目标（P2）
