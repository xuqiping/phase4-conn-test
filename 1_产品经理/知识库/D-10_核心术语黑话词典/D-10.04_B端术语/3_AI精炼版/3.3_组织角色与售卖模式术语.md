## 核心口径详解

### B端销售角色分工

**从获客到续约的完整链路**：

```
拓客(AE/SDR) → 售前(SE) → POC → 签约(AE) → 交付(PM/实施) → 日常(CSM) → 续约(AM/CSM) → 增购(AE/AM)
```

**角色对齐速查**：

| 角色 | 核心职责 | KPI | 与PM的协作界面 |
|---|---|---|---|
| SDR/BDR | 线索挖掘与初步筛选 | 合格漏斗数 | 提供产品卖点材料 |
| AE | 新客签约与关单 | 新签ARR | 需求收敛与优先级 |
| SE | 技术方案+POC | POC通过率 | 技术可行性评估 |
| CSM | 客户健康度+续约+增购 | NRR/续约率 | 产品使用深度+需求反馈 |
| AM | 关系维护+续约 | 续约率 | 续约风控+竞品动态 |

**⚠️ PM常见混淆**：
- CSM=客服→错，CSM是主动型的（推动客户成功），客服是被动型的（响应问题）
- AM=AE→不同，AM管存量续约，AE管新客签约
- 小公司这些角色可能合并→PM需理解角色职责而非角色名称

### 按-seat计费 vs 阶梯定价

**按-seat（按席/按用户数）**：
- 核心逻辑：用户数=价值量→多用多付
- 优势：与客户增长天然绑定→用得越多收入越高
- 劣势：大客户谈判空间大→"我们1000个seat能不能打折"

**阶梯定价**：
- 核心逻辑：分档对应不同功能/服务级别
- 典型结构：免费版/专业版/企业版
- 优势：客户自主选择→降低销售阻力
- 劣势：功能边界划分需要精细化→PM需定义每档的Feature差异

**⚠️ 注意**：
- 按-seat + 阶梯不冲突→通常是"每档有对应seat价格"
- 按-seat的"seat"口径要注意→活跃seat? 注册seat? 并发seat? →口径不同，ARR差异大

### 目录价 vs 成交价

**核心逻辑**：目录价是"锚"，成交价是"实际"。

| 维度 | 目录价 | 成交价 |
|---|---|---|
| 作用 | 价格锚点/品牌定位 | 实际收入 |
| 可见性 | 公开（官网/报价单） | 不公开（合同保密） |
| 折扣 | 0% | 通常20%-60% |

**B端定价的"冰山模型"**：
```
        目录价（公开，冰山一角）
━━━━━━━━━━━━━━━━━━━━━━━
        ┌──────────────┐
        │   成交价     │
        │  ┌────────┐  │
        │  │底线价  │  │
        │  │(成本+) │  │
        │  └────────┘  │
        └──────────────┘
     实际定价空间（水下）
```

**⚠️ PM注意**：
- 目录价不是随意定的→直接影响客户的价格感知和谈判空间
- 成交价折扣率如果>60%→说明目录价虚高，品牌价值被稀释
