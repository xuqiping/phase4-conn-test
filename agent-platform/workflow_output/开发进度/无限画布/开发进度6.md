## 本轮做了什么

### C12 视频截取（IC-13，R-2 javacv，复用 C11 javacv 栈）

- **VideoFrameService.clip** [canvas/service/VideoFrameService.java](../../../backend/src/main/java/com/superprogrammer/canvas/service/VideoFrameService.java)：`FFmpegFrameGrabber` seek 到 startSec → 逐帧 `grabImage()` 重编码到 `FFmpegFrameRecorder`（H.264/mp4，浏览器 `<video>` 可直接播）→ 时间戳 ≥ endSec 停。
  - **产物写临时文件非 byte[]**（大片段不撑爆堆）：返 `ClipResult(tempFile, mime, size)`，调用方落 stored_files 后**必须删**临时文件。
  - **流式按帧**处理不整片 load（同 extract 的 R-2 内存口径）；finally 必 `grabber.release()` + `recorder.stop/release()`。
  - **校验**（plan 安全清单「输入校验」）：start≥0 / end>start / 时长 ≤ `MAX_CLIP_SECONDS`(600s) / start·end 不超视频时长（duration 不可读时跳过越界校验，靠 600s 兜底）。
  - 失败固定话术「视频截取失败，请稍后重试」不透传 `e.getMessage()`。
  - **MVP 范围**：仅视频轨重编码（不含音频轨）。截取片段静音——浏览器播放/下载正常；音频轨裁剪需 grabSamples+AAC+A/V 同步，留后续。
  - recorder 参数对齐源：`setVideoCodec(AV_CODEC_ID_H264)` / `setFrameRate(grabber.getFrameRate()||25)` / `setVideoBitrate(grabber.getVideoBitrate()||2Mbps)` / width·height 取 grabber。

### 端点（C12 chunk2）

- **CanvasController** `POST /{id}/nodes/{nodeId}/clip` [CanvasController.java](../../../backend/src/main/java/com/superprogrammer/canvas/controller/CanvasController.java)：body `{startSec,endSec}` → ①`loadOwned`（画布归属）②`resolveVideoFileId`（**复用 C11 同款**解析快照定位视频节点 + 校验 type=video + 读 data.fileId）③`loadPath`（视频源文件 ownership 复检，防借他人 fileId 截取）④`clip`⑤`storeStream(SOURCE_CANVAS)` 产新视频 fileId。
  - **临时文件兜底删**：try-finally `Files.deleteIfExists(clipPath)`，storeStream 成败都删，防磁盘泄漏。
  - 失败不产空文件（plan 边界）：service 抛 → 端点直接返错。
  - `Files.newInputStream` IOException 包成 UNPROCESSABLE「截取文件落盘失败」。

### 前端截取面板（C12 chunk3）

- **PropertyPanel.vue** [PropertyPanel.vue](../../../frontend/src/components/canvas/PropertyPanel.vue)：视频节点块抽帧下方加「截取（C12，时间段裁剪）」面板 —— 起/止两个 `n-input-number` + 「截取片段」按钮。`disabled` 当 `fileId` 空 / end≤start。emit `clip-video {node, startSec, endSec}`。
- **CanvasView.onClipVideo** [CanvasView.vue](../../../frontend/src/views/CanvasView.vue)：调 `canvasApi.clipVideo` → `fetchVideoBlob(f.url)`（/api/files/{id} 需 auth header → axios 拉 blob 转 objectURL）→ `addNode(video)`（label=`截取(start-ends)`，带 fileId+previewUrl+mediaStatus=SUCCEEDED+parentFileId+sourceNodeId+空 prompt）→ `addEdge(video→video)` 自动连边。失败标红源视频节点不建空节点。
- 新视频节点 `mediaStatus:'SUCCEEDED'` 直接走 VideoNode 预览分支（无需轮询）。

## 踩坑批注

| 坑 | 解 |
|---|---|
| clip 产物塞 byte[] 大片段撑爆堆 | 写临时文件（`Files.createTempFile`），返 Path；controller storeStream 后 try-finally 删 |
| H.264 浏览器可播但源是 MPEG4（测试片） | recorder 显式 `setVideoCodec(AV_CODEC_ID_H264)` 重编码，非流拷贝；测试片 MPEG4→clip 后变 H.264 round-trip 抽帧验证可播 |
| seek 精度误差致末帧多/少一帧 | 时间窗判定用 `grabber.getTimestamp() >= endUs` break（≥ 非 ==），容错 seek 误差 |
| `Files.newInputStream` 抛 IOException 不在 service | controller 层 try-catch 包 UNPROCESSABLE，service 只抛 BusinessException/UNPROCESSABLE 固定话术 |
| 截取产物视频节点无 taskId（非 media 任务） | 不走 pollVideoTask；前端直接 `mediaStatus:'SUCCEEDED'` + previewUrl 走 VideoNode 预览分支 |
