# 通用约束 · 跨所有模块

> 所有模块共用的编码/命名/响应/异常/安全规范。模块特有约束另建 `<模块>约束.md` 并在 AGENTS.md 索引。

## 后端
- 包名：`com.superprogrammer`，模块包：auth/agent/workflow/engine/execution/runtime/chat/knowledge/llm/project/file/system/common。
- 分层：controller → service → mapper（MyBatis-Plus BaseMapper）；跨模块用 Facade 接口 + DTO，**禁止循环依赖**。
- 响应：统一 `R<T>`（`{code,msg,data}`），分页 `PageResult<T>`。
- 异常：业务异常抛 `BusinessException(ErrorCode)`，全局异常处理器转 `R`；错误信息不泄漏内部实现。
- 实体继承 `BaseEntity`（id/created_by/created_at/updated_by/updated_at/version/deleted）。
- 权限：方法级 `@RequirePermission("resource:action")`，切面 `RequirePermissionAspect` 拦截。
- API 前缀 `/api/`；认证 Header `Authorization: Bearer {token}`。

## 数据库（PostgreSQL 16 + pgvector）
- 主键 `GENERATED ALWAYS AS IDENTITY`。
- 逻辑删除 `deleted` + `@TableLogic`；乐观锁 `version`；自动填充审计字段。
- 向量 `halfvec(2048)` + HNSW `halfvec_cosine_ops`，不用 `vector(2048)`。
- 配置类灵活字段用 JSONB。建表走 Flyway 新版本脚本，旧脚本不可改。

## 安全
- JWT 双 Token：access 15min + refresh 7d；登出入 Redis 黑名单。
- 密码 BCrypt（cost=10）；连续 5 次失败锁定 15 分钟。
- 用户 LLM API Key 用 AES 加密存储（`AesEncryptService`）。
- 加密配置通用读写走 `SystemSettingService.getDecryptedValue(key)` / `upsertEncrypted(key,plaintext,desc)`（AES 存 `system_settings`，不回显明文）；新供应商 key 复用此范式（如联网搜索 `search.*.api-key`）。
- 敏感配置（JWT_SECRET / DB_PASSWORD / RUNTIME_CALLBACK_TOKEN）走环境变量，**fail-closed 未注入拒启动**。
- sidecar 回调校验 `X-Runtime-Token`；`callback_client` 用 `trust_env=False` 避免系统代理拦截。
- **外部服务降级链范式**（联网搜索沉淀）：可插拔 provider 学 `LlmProviderInterface`（`getName`/`available`/`search`），`search()` 失败**返空不抛**避免异常类型打架；service 层把"空结果"当"可能失败"触发兜底（外部→自建→空），外部重试 1 自建不重试；审计日志含 traceId + query 脱敏 + provider + 结果数 + 耗时。
- **多源 CITATION 帧前端累积合并**：同一条消息可能收多个 CITATION 事件（KB 引用 + 联网 web 引用），前端须累积拼接，不可后者覆盖前者；引用编号空间隔离（web 顺延 KB max index 避免 `[n]` 撞号）。
- **抓取类 SSRF + sanitize 必备**：服务端抓网页须 `assertPublicUrl`（解析所有 A/AAAA 防公网 IPv4+内网 IPv6 绕过，拒私有/环回/链路本地/组播段）+ 正文 sanitize 去 control char/零宽/折叠空白/截断防 prompt 注入。

## 前端
- Vue 3 Composition API + `<script setup lang="ts">`；状态 Pinia；API 走 `src/api/request.ts`（自动 JWT 注入 + 401 刷新）。
- UI Naive UI 暗色；样式 Sass + BEM + CSS 变量引用主题色。
- 移动端适配：`useBreakpoints` + 汉堡抽屉导航 + 会话抽屉（≥390px 可用）。
- 路由守卫检查认证。

## Sidecar（runtime-sidecar）
- FastAPI + LangGraph；无沙箱，禁 `eval/exec/subprocess`，条件求值手写解析。
- 回调 Java 带 `X-Runtime-Token`；`httpx.AsyncClient(trust_env=False)`。
- 检查点目录 `RUNTIME_CHECKPOINT_DIR`，默认 `.runtime-checkpoints/`。
