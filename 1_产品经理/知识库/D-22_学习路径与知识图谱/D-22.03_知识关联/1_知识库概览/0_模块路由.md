## 四、关键术语速查

| 术语 | 定义 |
|---|---|
| 知识关联 | 两个知识节点间的语义关系（依赖/交叉/互补/互证/互斥/共现） |
| 强依赖 | 必须先学A才能理解B（A→B，D-22.01的核心） |
| 弱关联 | A与B有交叉但不强制先后（A↔B，本叶子的核心增量） |
| 交叉引用 | A的知识可被B引用（单向引用关系） |
| 互补关联 | A+B组合产生新认知（1+1>2效应） |
| 互证关联 | A的知识可验证B的假设（双向验证关系） |
| 互斥关联 | 学了A的思维方式可能阻碍B的思维方式（负迁移风险） |
| 关联密度 | 某知识节点的关联边数/总可能边数，密度越高→学习越深 |
| 知识图谱 | 以图结构（节点+边+属性）组织知识的表示方法 [来源:Knowledge Graph学术界共识 | 置信度:🔍高] |
| 技能图谱(SkillNet) | 面向Agent/人的技能级知识图谱，将分散经验沉淀为可检索可组合的技能网络 [来源:OpenKG SkillNet 2026-03 | 置信度:📚中 | 日期:2026-03] |
