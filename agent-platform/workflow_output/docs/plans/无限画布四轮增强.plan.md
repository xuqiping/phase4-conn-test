# Implementation Plan for 无限画布四轮增强

> Phase 2 产出。Phase 3 逐步勾选执行。只含伪代码，不含真代码。
> 来源规格：[../specs/无限画布四轮增强设计.md](../specs/无限画布四轮增强设计.md)
> 前置依赖：Step 8 复用 [图片视频模块计划](图片视频模块历史分页与预览缓存.plan.md) Step 3 的 `MediaLightbox`/`HoverPreviewImage`，先完成该计划。

## 背景与目标

规格 §3-§10 八项：前端断路误伤修复（「服务不可达」真根因）、节点宽高拖拽、批量生成依赖调度（上游 SUCCEEDED 释放下游）、图片翻转+8色框选标注、@参考预览区、关联高亮+只看关联、连线左右、节点组+@组内全员。

## 技术实现坑点预判与规避措施

| 技术点/功能块 | 可能的坑 | 规避措施 | 验证方式 |
|---|---|---|---|
| @vue-flow/node-resizer 版本兼容 | 包版本与 core 1.41.5 不匹配（resize 句柄不渲染/拖拽冲突） | Step 2 先做 30 分钟 spike：锁兼容版本装不上则自绘右下角手柄（契约不变）；**安装前先跑既有画布回归** | spike 结论记录；手测六类节点拖拽 |
| resize 与框选/平移手势冲突 | 拖手柄被画布 pan 吃掉 | 手柄 mousedown stopPropagation；仅节点 selected 时渲染手柄 | 手测 ✋/▭ 两模式下拖手柄 |
| 依赖调度内存泄漏 | 上游永不终态（网络断）→ 下游 Promise 悬挂、进度条卡死 | 调度器带全局超时上限（60min/节点）+ 取消令牌（进度浮条关闭即停调度，在途任务不撤仅停释放） | 断网手测：进度条可关、恢复后不双跑 |
| 429 退避与依赖调度叠加 | 下游释放瞬间又撞并发闸 → backoff 重试期间占窗口位 | 重试期间不占窗口槽（释放槽再排） | 单测：窗口2+3节点全429场景 |
| transform-image EXIF 方向 | 手机图翻转后横竖颠倒 | ImageIO 读入时应用 EXIF 或统一 BufferedImage 后再变换 | 后端单测带 EXIF 样图 |
| 标注图与原图尺寸漂移 | 前端显示尺寸 vs 原图像素，矩形归一化错位 | 全程归一化坐标（0-1，FocusEditOverlay 既有模式）；合成按原图尺寸还原 | 单测：1920 图上 0.25 宽矩形落位 480px |
| 高亮集合频繁重算 | 每次拖节点/选变化 BFS 全图，大画布卡顿 | 仅 selectedNode 变化时重算（拖动不触发）；BFS 结果 memo | 100 节点画布手测选切流畅 |
| 组包围盒随拖拽重算 | 每帧算 bounds 并集 → 拖拽掉帧 | 用 vue-flow 节点位置响应式更新节流（requestAnimationFrame 合帧）；组成员 ≤50 上限提示 | 20 节点组拖拽手测 |
| @候选并集误放大 | 未连通组也进候选=越权引用（规格 §10.3 禁） | 并集条件严格=「组内任一成员 ∈ ancestors(N)」，单测菱形/孤立组用例 | 单测：孤立组不可 @ |
| background 标记漏标 | 只标了轮询没标 blob 拉取 → 断网仍弹错误 toast | Step 1 列出全部后台型请求清单逐一标记（getTask/fetchMediaBlob/fetchVideoBlob/帧提取） | 断网 30s 手测零误导 toast |

## 安全检查清单

- [ ] **鉴权**：transform-image/ANNOTATE 复用 `canvas:write` + fileId 访问授权（与 crop-image 同口径）；无新开放面
- [ ] **输入校验**：transform op 白名单枚举；ANNOTATE 矩形坐标 0-1 clamp、颜色 8 色枚举、指令文本 ≤200 字/框、框数 ≤8
- [ ] **错误处理**：调度器跳过节点在节点上标明原因（不静默）；FFmpeg 失败返回明确错误
- [x] **加密/CORS/依赖**：新增 npm 包（node-resizer 或零依赖）需 npm audit 过

## 性能考虑与验证计划

- [ ] 高亮/组 bounds：rAF 合帧（上表）；100 节点画布切换选中 <100ms
- [ ] 依赖调度：单测 20 节点混合图调度无死锁（cycle 守卫复用）
- [x] 后台请求退避：连续失败不锤接口（请求间隔单测断言 5→10→30s）✅ Step1 落 `mediaTaskPolling.test.ts`
- [ ] Phase 4：30 分钟长任务全程无「服务不可达」无踢会话

## 功能联动点清单（含反向/边界）

| # | 触发动作 | 联动对象 | 预期变化 | 必测边界 |
|---|---|---|---|---|
| L1 | 上游任务 SUCCEEDED | 下游待命节点 | 自动提交 | 上游 FAILED→下游灰标不提交；上游被手动删除→下游标「上游缺失」；进度条关闭→停释放不停在途 |
| L2 | 节点选中 | 边/节点高亮 | 关联路径高亮+无关淡化 | 清除选中全还原；「只看关联」开时再选另一节点=重算隐藏集；开关关=全恢复 |
| L3 | 拖宽高 | 内容区/图片缩略/快照 | 实时自适应+落快照 | 刷新还原；缩到 min 后内容滚动不溢出；与左右连线叠加视觉正常 |
| L4 | 画框标注 | 确认按钮可用性 | ≥1 框才可确认 | 全删框→禁用；改最后一框颜色→预览即时变；取消弹层→不产任何节点 |
| L5 | 建组 | 成员描边/包围盒/@候选 | 组视觉+下游可@全员 | 解组全还原；成员再入新组→旧组自动减员；删除成员节点→组引用清；组内节点全部删除→组自解散 |
| L6 | 断网恢复 | 轮询/断路 | 退避恢复5s、不踢会话 | 用户主动操作连续失败仍正常断路（安全语义不降级） |
| L7 | @文本新增/删除引用 | 属性面板参考区 | 列表随 prompt 变化增减 | 断链 @（节点已删）→该项显示「断链」不崩；首尾帧与参考互斥报错时参考区仍渲染 |

## 运维考量清单

| 类别 | 结论 | 说明 |
|---|---|---|
| 可观测性 | **做** | 调度器跳过/看门狗触发打 WARN（canvasId+nodeId）；后台请求豁免后网络错误仍计数入 console 便于诊断 |
| 配置开关 | **做（轻）** | 依赖调度器常量（窗口数/看门狗时长）走前端配置对象，出问题可热调参；断路豁免无开关（正确性修复） |
| 可回滚 | **做** | transform-image 无 DB 变更可独立回滚；snapshot groups/width 字段向后兼容（老版本读新快照=忽略未知字段），回滚不破数据 |
| 限流/熔断 | **做** | transform/ANNOTATE 复用 canvas @RateLimit 模式；FFmpeg 变换超时上限（30s/图）防积压 |
| 运维入口 | **不做** | 无补单需求（变换失败用户重试即可） |
| 告警阈值 | **不做** | 前端日志暂无接入点 |
| 容量/性能 | **做** | 组成员≤50、标注框≤8、帧数上限既有；快照 ≤5MB 既有约束不破（组数据量小） |
