# 3.3 性价比合规与2026前沿

## 一、性价比评估

### 1.1 性价比 = 质量 ÷ 成本

| 模型阵营 | 质量档 | 成本档 | 性价比 | 典型 |
|---|---|---|---|---|
| 海外闭源旗舰 | 顶级 | 高 | 中 | GPT-5.5/Claude Opus |
| 国产闭源旗舰 | 接近顶级 | 低 | 极高 | DeepSeek/Qwen（性价比无敌） |
| 开源自部署 | 逼近旗舰 | 固定GPU（量大便宜） | 量大时高 | Llama 4/DeepSeek开源 |
| 闭源小模型 | 中 | 极低 | 高（简单任务） | GPT-4o-mini/Gemini Flash |

**DeepSeek性价比案例**：2026 DeepSeek以接近旗舰的质量+约1/10的成本搅动市场，成为高性价比首选 [来源:51CTO/什么值得买 | 🔍高 | 2026-06]

### 1.2 成本计算

| 计费方式 | 说明 | 适用 |
|---|---|---|
| 按Token | 输入Token+输出Token分别计价 | 标准API |
| 按请求 | 每次请求固定价 | 简单任务 |
| 按席位 | 月/年订阅 | 对话式产品(Plus) |
| 按GPU时长 | 自部署 | 开源模型 |
| 混合 | 订阅+超额按量 | Claude/GPT |

**单位成本质量(QPC, Quality Per Cost)** = 业务集准确率 ÷ 单请求成本。QPC越高性价比越好。

### 1.3 模型路由策略（降本核心）

按任务难度动态路由到不同模型，质量不降成本大降 [详见 D-19.09 Token成本]：

```
用户输入 → 路由器(分类任务难度) 
  → 简单任务 → 小模型(GPT-4o-mini/DeepSeek低配/边缘) [便宜]
  → 中等任务 → 中档模型(DeepSeek/Qwen) [性价比]
  → 复杂任务 → 旗舰(GPT-5.5/Claude Opus) [质量]
```

**路由实现**：
- 规则路由：按输入长度/关键词/类型规则分发
- 模型路由：用小模型先分类难度再分发
- 级联：先用便宜模型，失败/低置信再升级贵模型

**收益**：典型可降本40-70%而质量损失<2% [来源:成本优化实践 | 📚中]

## 三、2026前沿

### 3.1 推理模型（o系列/R1）对选型评估的影响

| 维度 | 标准模型 | 推理模型 |
|---|---|---|
| 推理方式 | 靠CoT提示词 | 内化CoT，先推理再答 |
| 适用任务 | 通用 | 数学/科学/多步推理强 |
| 时延 | 快 | 慢（推理过程耗Token） |
| 成本 | 低 | 高 |
| 提示词 | 需CoT | 传统CoT反而冗余（详见D-19.02） |
| 评估 | 标准基准 | 需加推理时延/成本维度 |

**选型启示**：推理模型在复杂数学/科学推理上准确率显著提升，但时延和成本高；不是所有任务都需要推理模型，简单任务用推理模型反浪费 [来源:推理模型实践 | 📚中]

### 3.2 Agent基准崛起（2026评测范式转移）

[来源:CSDN评测范式革命 | 🔍高 | 2026-07]

**核心转变**：
- MMLU从"能力标尺"退化为"准入门槛"
- GSM8K成"开机自检"
- 真正决定落地的是Agent能力（OSWorld：连续多步操作办公软件）
- 评测从"刷分"转向"工程落地六维能力评估"

**OSWorld示例**：能否连续3次正确打开Excel→定位Sheet2→筛选2025年Q3营收超500万的客户→生成可视化→存PNG——靠规划/容错/状态管理而非记忆

### 3.3 Multi-Agent评估

多Agent协作系统的评估是新难题——单Agent基准不适用，需评估协作效率/通信开销/涌现行为 [详见 D-24.07 Agent评测]

### 3.4 评测工具进化

DeepEval/RAGAS等开源评测框架成熟，LLM-as-Judge规模化，评测从"手工跑case"走向"自动化CI"

## 四、常见坑

| 坑 | 表现 | 规避 |
|---|---|---|
| 只看榜单选模型 | 榜单高分业务翻车 | 必须自建业务集 |
| 无脑选最强 | 简单任务用旗舰浪费成本 | 按难度路由 |
| 不评估性价比 | 贵模型成本爆炸 | QPC性价比评估 |
| 自动评测不人评校准 | LLM-Judge有偏见不自知 | 人评校准一致率>80% |
| 评测集不迭代 | 业务变了评测失真 | 评测集随业务迭代 |
| 忽视模型敏感性 | 换模型Prompt失效 | 回归测试 |
| 忽视合规 | 上线被拦 | 合规评估前置 |
| 开源=免费 | 自部署成本被忽视 | 算GPU+运维+安全总成本 |
| 推理模型误用 | 简单任务用推理模型反慢反贵 | 按任务复杂度选 |
| 基准污染 | 训练含基准分数虚高 | 查污染+用新基准/私有基准 |
