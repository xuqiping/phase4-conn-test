# 文件整理工具

基于 PyQt5 的可视化文件分类整理与磁盘清理工具。

## 功能

### 扫描与整理
- 按文件类型自动分类（Office文档、图片、视频、音频、压缩包、代码、程序、快捷方式等）
- 支持自定义内容规则（关键词/正则）将匹配文件归入指定目录
- 支持移动或复制两种执行方式
- 分类预览：扫描后以树形结构展示归类结果，确认后再执行
- 支持递归/非递归扫描

### 文件删除
- 以文件夹树形结构浏览磁盘目录
- 懒加载展开子目录，后台并行计算文件夹大小
- 支持勾选文件或整个文件夹进行删除
- 按大小排序（升序/降序）和按名称排序
- 实时显示扫描路径、文件数、运行时间

### 分类设置
- 自定义各分类的归档目录名
- 添加自定义分类（指定扩展名归属到新类别）
- 添加内容匹配规则（关键词 → 目标目录）
- 所有设置自动保存，重启后保留

## 安装依赖

```bash
pip install PyQt5
```

## 使用

```bash
python file_organizer.py
```

## 配置

设置自动保存到脚本同目录下的 `organizer_config.json`，包括自定义分类、目录名映射、内容规则等。
