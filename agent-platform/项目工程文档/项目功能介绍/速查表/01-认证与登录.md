# 01 - 认证与登录

## 功能简介
用户注册、登录签发 JWT（access 15 分钟 + refresh 7 天）、token 刷新、登出（Redis 黑名单）、`/me` 当前用户。

## 后端 (backend)
- 控制器：[AuthController.java](../../backend/src/main/java/com/superprogrammer/auth/controller/AuthController.java)
  - `POST /api/auth/register` `POST /api/auth/login` `POST /api/auth/refresh` `POST /api/auth/logout` `GET /api/auth/me`
- 服务：[AuthService.java](../../backend/src/main/java/com/superprogrammer/auth/service/AuthService.java)
- 安全：
  - [SecurityConfig.java](../../backend/src/main/java/com/superprogrammer/auth/security/SecurityConfig.java) — Spring Security 配置
  - [JwtUtil.java](../../backend/src/main/java/com/superprogrammer/auth/security/JwtUtil.java) — JWT 生成/校验
  - [JwtAuthenticationFilter.java](../../backend/src/main/java/com/superprogrammer/auth/security/JwtAuthenticationFilter.java) — 请求拦截
  - [PasswordEncoderConfig.java](../../backend/src/main/java/com/superprogrammer/auth/config/PasswordEncoderConfig.java) — BCrypt
- DTO：`auth/dto/` LoginRequest、RegisterRequest、RefreshTokenRequest、LogoutRequest、TokenResponse、UserVO

## 前端 (frontend)
- 视图：[LoginView.vue](../../frontend/src/views/LoginView.vue)
- API：[auth.ts](../../frontend/src/api/auth.ts)
- 状态：[auth.ts (store)](../../frontend/src/stores/auth.ts) — token/用户信息
- 请求层：[request.ts](../../frontend/src/api/request.ts) — Axios 实例，自动注入 Bearer + 401 触发刷新
- 工具：`frontend/src/utils/storage.ts` — token 持久化

## Sidecar
无（仅由后端签发的 JWT 鉴权）。

## 钉钉 H5 微应用免登（可选）
- 流程：钉钉容器内打开 H5 → 重定向钉钉授权页拿 `authCode` → 回调页 `/dingtalk/callback` → POST `/api/auth/login/dingtalk` → 后端用 `authCode` 换用户 `unionId` → 按 `unionId` 查/建本地用户 → 签发标准 JWT（与账密登录同）。
- 后端：
  - 控制器：[DingTalkAuthController.java](../../backend/src/main/java/com/superprogrammer/auth/dingtalk/controller/DingTalkAuthController.java) — `POST /api/auth/login/dingtalk`
  - 服务：[DingTalkService.java](../../backend/src/main/java/com/superprogrammer/auth/dingtalk/service/DingTalkService.java) — 换 userAccessToken + 拉用户信息
  - 配置：[DingTalkProperties.java](../../backend/src/main/java/com/superprogrammer/auth/dingtalk/config/DingTalkProperties.java)（`dingtalk.enabled/app-key/app-secret/agent-id`）
  - 业务：`AuthService.loginByDingTalk()` — unionId 查找/自动建号、签 JWT
  - 白名单：`SecurityConfig` 放行 `/api/auth/login/dingtalk`
- 前端：
  - 工具：[dingtalk.ts](../../frontend/src/utils/dingtalk.ts) — `isDingTalkClient()` / `redirectToDingTalkAuth()`
  - 回调页：[DingTalkCallbackView.vue](../../frontend/src/views/DingTalkCallbackView.vue)（路由 `/dingtalk/callback`，免登录）
  - 登录页：[LoginView.vue](../../frontend/src/views/LoginView.vue) 钉钉登录入口
  - API：[auth.ts](../../frontend/src/api/auth.ts) `dingTalkLogin(authCode)` / store `loginByDingTalk(authCode)`
- 数据表：`users` 加 `bind_type / dingtalk_union_id（唯一部分索引）/ dingtalk_open_id`（V41）。
- 钉钉平台配置清单（管理员）：
  1. 钉钉开放平台创建「H5 微应用」（企业内部应用）。
  2. 「开发配置 > 安全设置」：把 `VITE_DINGTALK_REDIRECT_URI`（如 `https://your-domain/dingtalk/callback`）加入**重定向 URL** 白名单。
  3. 拿 `AppKey/AppSecret/AgentId`，填后端 `dingtalk.app-key/app-secret/agent-id`（生产走环境变量 `DINGTALK_APP_KEY` 等），`dingtalk.enabled=true`。
  4. 前端 `.env` 填 `VITE_DINGTALK_APP_KEY`、`VITE_DINGTALK_REDIRECT_URI`。
  5. 微应用「应用首页地址」指向前端首页（或 `/login`）。
  6. 在钉钉手机端/PC 端打开微应用，验证免登进入。
