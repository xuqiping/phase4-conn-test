## 本轮关键决策与变更

- **Boot 3 无 `web.server.request.autotime`**：直方图等价物是 `management.metrics.distribution.percentiles-histogram.http.server.requests=true`（yml 注释留痕）。
- **DiskSpace 百分比阈值走自定义 bean 顶掉 Boot 默认版**：yml threshold 是绝对字节数表达不了 <15%；反编译确认 Boot 3.2.5 `DiskSpaceHealthContributorAutoConfiguration` 为 `@ConditionalOnMissingBean(name="diskSpaceHealthIndicator")` 让步，同名 bean 安全替换。装配验证用 ApplicationContextRunner 无 DB 方案（dev 库 flyway 漂移见下）。
- **instrumentator 锁 6.0.0**：7.x 强拉 starlette≥0.38 与 fastapi 0.111.0（starlette<0.38）硬冲突。
- **备份机密零入库**：脚本全部从 `backup-env.bat`（gitignore，只存在服务器）读密码/webhook；仓库只存 example 模板。已验证 backup-env.bat 未被 git 追踪。
- **plan 原文落点过期（Step 5 偏离）**：`chat/service/MemoryService.java` 系计划12 重设计前旧架构，实际埋点 MemoryConsolidationWorker + MemoryAssetIngestWorker。

## 踩坑与排雷（已沉淀总览规范表）

- **指标埋点五红线**：高基数禁入 tag / 埋点绝不阻断主链路 / 流式三终态互斥正好一次 / Gauge 只注册一次且 builder 持强引用 / null tag→unknown。
- **中文注释 .bat 编码红线（实证）**：zh-CN Windows 必须 **GBK + CRLF + 无 BOM + 不 chcp 65001**——UTF-8+chcp 时 REM 行多字节错位漏出执行；BOM 直接炸 `@echo off`；LF 行尾 REM 保护整体失效。webhook JSON 内容一律 ASCII。
- **sse-starlette 2.x 全局 `AppStatus.should_exit_event` 跨 event loop 炸弹**：套件出现第二个流式测试必炸 "bound to a different event loop"——共享单 TestClient + autouse fixture 用后重置 None。
- **prometheus_client 全局 registry 测试断言用前后差值**，不依赖绝对值。
