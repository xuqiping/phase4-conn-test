# 项目功能速查总览

> 一功能一文档。每篇列出该功能在 **后端(backend) / 前端(frontend) / Sidecar(runtime-sidecar)** 的代码位置、关键 API、数据表。
> 路径相对仓库根 `agent-platform/`。

## 模块全景

| 层 | 目录 | 说明 |
|---|---|---|
| 后端 | `backend/src/main/java/com/superprogrammer/<模块>/` | Spring Boot 3.2.5 + Java 17，模块化单体 |
| 前端 | `frontend/src/` | Vue 3 + TS + Vite + Naive UI(暗色) |
| Sidecar | `runtime-sidecar/app/` | Python FastAPI + LangGraph，工作流图执行引擎 |

## 后端模块速查

| 模块包 | 职责 |
|---|---|
| `auth` | 登录/JWT/RBAC/用户/角色/部门（含钉钉免登） |
| `agent` | Agent/技能Skill/Agent权限/KB绑定/分组 |
| `chat` | 对话会话/流式/个人记忆/记忆冲突 |
| `project` | 项目（记忆 scope 容器）/成员共享（仅服务记忆，见 [09](09-个人记忆与冲突解决.md)） |
| `engine` | 编排引擎/路由策略/执行上下文 |
| `execution` | 执行日志/人工审批/断点恢复 |
| `workflow` | 工作流定义/边节点/KB绑定 |
| `canvas` | 无限画布创作页（Vue Flow 节点图+抽帧截取拼接，见 [24](24-无限画布创作页.md)） |
| `runtime` | Runtime 网关/Sidecar 通信/节点回调 |
| `knowledge` | RAG 知识库/文档/节点/权限/检索/问答/缓存/对账 |
| `llm` | LLM 供应商/网关/用户级配置/Embedding |
| `file` | 文件上传存储 |
| `system` | 系统设置(认证/RAG记忆) |
| `common` | R/PageResult/异常/MyBatis配置/CORS/类型处理器 |
