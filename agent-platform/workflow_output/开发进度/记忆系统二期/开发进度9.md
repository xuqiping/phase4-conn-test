## C8 关键决策记档

- **summaries 不动**：`memory_summaries.tag_id` 单值，增补=替换=删旧语义 → 只改 turns；总结生效走既有「重新总结」force 重压——正是拍板⑤「手动重新总结」的技术根基。
- **非本人标签统一 NOT_FOUND**（不泄露存在性，与 edit() 的 NOT_FOUND+FORBIDDEN 分裂不同——有意为之，匹配 plan 测试名「非本人 404」）。
- **PG NULL 数组坑**：`NOT (tag_ids @> ARRAY[x])` 遇 NULL tag_ids 返 NULL → WHERE 视 false → 行被静默排除；SQL 全程 `COALESCE(tag_ids,'{}'::bigint[])`。
- **幂等原子增补**：`UPDATE ... SET tag_ids=array_append(COALESCE(tag_ids,'{}'),#{tagId}) WHERE ... AND NOT (COALESCE(tag_ids,'{}') @> ARRAY[#{tagId}])`。
