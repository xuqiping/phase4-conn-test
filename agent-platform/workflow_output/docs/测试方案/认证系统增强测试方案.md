## 二、测试用例（TC）

### TC-A 邮箱验证注册（通道 A）

- **TC-A1 注册成功**：填用户名+邮箱+密码+勾协议 → 注册 → 提示"请去邮箱验证"。预期：建号 ACTIVE 可立即登录；查库 PASSWORD 凭证 verified=TRUE、EMAIL verified=FALSE。
- **TC-A2 未勾协议**：不勾协议 → 注册按钮禁用。预期：无法提交。
- **TC-A3 邮箱激活**：收邮件点激活链接 → 落地页显示激活成功。预期：查库 EMAIL verified=TRUE。
- **TC-A4 激活链接过期**：用 24h 前的 token（或伪造）→ 提示"链接无效或已过期"。
- **TC-A5 重发激活邮件**：60s 内连续点重发 → 第二次被拒（限流提示）。

### TC-B 手机验证码登录（通道 B）

- **TC-B1 新号登录即注册**：未注册手机号 → 过滑块 → 获取验证码 → 输码登录 → 直接进首页。预期：自动建号 username=手机号，分配 user 角色。
- **TC-B2 老号登录**：已注册手机号 → 验证码登录。预期：直接登录不建号。
- **TC-B3 国际号拒绝**：输 +852 开头 → 提示手机号格式错误。
- **TC-B4 滑块前置闸门**：不过滑块直接点获取 → 无反应/被拒。
- **TC-B5 限频**：同号 60s 内连续获取 → 第二次被拒。
- **TC-B6 验证码错误**：输错 5 次 → 码作废，提示重新获取。
- **TC-B7 验证码重放**：同码输第二次 → 拒（用完即删）。

### TC-C 微信扫码登录（通道 C，需开放平台已配置）

- **TC-C1 扫码登录（新号）**：点微信登录 → 扫码确认 → 回调自动建号 + 登录进首页。预期：username=wx_xxx，avatar/nickName 同步。
- **TC-C2 扫码登录（老号）**：同微信再扫 → 直接登录不建号。
- **TC-C3 未配置开关**：`app.auth.wechat.enabled=false` → 前端不显示微信 Tab；直接访问接口返"未开启"。

### TC-D 找回密码（通道 D）

- **TC-D1 邮件找回**：输已验证邮箱的账号 → 选邮件 → 收重置邮件点链接 → 输新密码 → 重置成功。预期：旧会话全部失效（旧 token 调接口 401），新密码可登录。
- **TC-D2 短信找回**：输已绑手机号 → 选短信 → 收 6 位码 → 输码+新密码 → 重置成功。
- **TC-D3 统一话术防枚举**：输不存在的账号 → 提示"若账号存在，重置链接已发送"（与存在时话术一致）。
- **TC-D4 未验证邮箱不可找回**：用未验证邮箱的账号选邮件找回 → 提示"请先验证邮箱"（或统一话术+不发）。
- **TC-D5 找回限流**：同账号 1h 内发 4 次 → 第 4 次被拒。

### TC-E 账密登录优化（通道 E）

- **TC-E1 条件滑块**：同账号连续输错密码 3 次 → 第 4 次登录页强制弹滑块。预期：过滑块才允许继续登录。
- **TC-E2 异地提醒**：账号 A 在上海 IP 登录 → 换省份（模拟）再登录 → 收"您的账号刚在 X 省登录"邮件。预期：同省不提醒，首次登录不提醒。
- **TC-E3 既有防爆破保持**：输错 5 次 → 账号锁 15min（现有能力，回归）。

### TC-F 设置页（Chunk G）

- **TC-F1 绑定邮箱**：设置页点「+ 绑定邮箱」→ 输邮箱 → 提示「绑定成功请查收激活邮件」→ 收激活邮件点链接 → 凭证列表 EMAIL verified=TRUE。已被他人绑 → 提示「该邮箱已被其他账号绑定」。
- **TC-F2 绑定手机/微信**：⏸ Phase 2（需独立验证码/OAuth 回路，本期按钮置灰「即将上线」），Phase 4 跳过。
- **TC-F3 解绑保留最后一种**：账号非密码凭证仅剩 1 种 → 解绑按钮禁用 + 列表下方提示「至少保留一种登录方式」。剩多种时解绑 → 软删成功 + 列表刷新。PASSWORD 解绑接口侧已拒（DTO 正则约束）。
- **TC-F4 改密**：输旧密码+新密码 → 改密成功 → 当前 token 即刻失效（调任何接口 401），前端自动 logout 跳登录页，新密码可登录。旧密码错 → 提示「当前密码不正确」。新旧相同/弱密码 → PasswordPolicy 拒。

## 三、功能联动用例（对应 plan.md L1-L12）

> 每条联动点至少一用例，覆盖正向/反向/半选/批量边界。

| 联动 | 用例 | 预期 |
|---|---|---|
| L1 注册→发邮件 | TC-A1 | 建号+PASSWORD verified+EMAIL unverified+邮件入队；邮件失败不阻断注册 |
| L2 激活→verified | TC-A3/A4 | FALSE→TRUE；过期拒 |

| L6 改密→踢会话 | TC-F4 | 同 L5 + 旧密码必验 |
| L7 绑定→verified | TC-F1/F2 | 按验证流程；已被他人绑 CONFLICT 拒 |
| L8 解绑→保留最后 | TC-F3 | 解绑最后一种被拒 |
| L9 失败≥3→滑块 | TC-E1 | 弹滑块；登录成功后计数清零不再要求 |
| L10 异地→邮件 | TC-E2 | 跨省提醒；同省/首次不提醒 |
| L11 禁用→全通道拒 | TC-通用 | DISABLED 用户账密/手机/微信/钉钉登录全拒（回归） |
| L12 开关→前端显隐 | TC-C3 | enabled=false 时前端不显示对应 Tab |

## 四、边界/异常场景

- **阿里云不可用**：模拟 SDK 超时/报错 → 发短信/邮件接口降级返"发送失败请重试"，不阻塞登录主流程
- **Redis 故障**：限流计数/验证码存储降级放行 + WARN（复用现有降级范式）
- **并发注册**：同邮箱并发注册 10 次 → 唯一约束兜底只有 1 次成功
- **微信回调伪造**：state 不匹配 → 拒（防 CSRF）
