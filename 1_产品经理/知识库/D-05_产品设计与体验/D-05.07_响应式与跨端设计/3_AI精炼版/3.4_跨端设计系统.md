## 跨端设计系统 — Design Token与平台映射

### Design Token — 多端设计参数的标准化桥梁

**定义**：Design Token是设计决策的**平台无关**抽象表示——颜色/间距/字号/圆角/阴影等设计参数以key-value对存储，编译后输出各平台格式(CSS/Android XML/iOS Swift/Flutter Dart) [来源:Token Studio | 🔍高 | 2025-2026]。

### Token层级架构

```
Global Tokens（全局原值）
  ↓ 引用
Alias Tokens（语义别名）
  ↓ 引用
Component Tokens（组件级）
  ↓ 编译输出
各平台实现(CSS/Android/iOS/Flutter)
```

| 层级 | 示例 | 含义 |
|---|---|---|
| Global | `blue-500: #3B82F6` | 原始颜色值，不具备语义 |
| Alias | `color-primary: {blue-500}` | 语义化——"主色是什么" |
| Component | `button-bg: {color-primary}` | 组件级——"按钮背景是什么" |

**跨端输出示例**：

| 平台 | 格式 | 示例 |
|---|---|---|
| Web(CSS) | `--color-primary: #3B82F6` | CSS自定义属性 |
| Android | `<color name="color_primary">#3B82F6</color>` | XML资源 |
| iOS | `static let primary = UIColor(hex: "3B82F6")` | Swift常量 |
| Flutter | `static const primary = Color(0xFF3B82F6)` | Dart常量 |

### 平台规范映射 — 三大设计体系

| 维度 | Material Design 3 | Apple HIG | HarmonyOS Design |
|---|---|---|---|
| 导航模式 | BottomNav + NavDrawer | TabBar + SideBar | 底部Tab + 侧滑 |
| 触控目标 | 48dp最小 | 44pt最小 | 44vp最小 |
| 字号系统 | Type Scale(15级) | SF Symbols+Dynamic Type | HarmonyOS Sans+无障碍字号 |
| 暗色模式 | 动态色调(tonal palette) | 语义色+系统自动 | 双色主题 |
| 手势 | 返回=系统手势 | 边缘右滑返回 | 左滑返回 |
| 动效 | Motion(缓动/时长) | Spring动画 | 物理动效 |

> **PM要点**：跨端≠同端。差异不是Bug而是Feature——移动端底部Tab vs 桌面侧边栏是平台习惯差异，强行统一反而降体验。

### 组件映射策略

| 设计系统组件 | Web | Android | iOS | 鸿蒙 |
|---|---|---|---|---|
| Button | `<button>` | `MaterialButton` | `UIButton` | `Button` |
| Navigation | `<nav>` | `BottomNavigationView` | `UITabBarController` | `Tabs` |
| Dialog | `dialog`/`modal` | `AlertDialog` | `UIAlertController` | `AlertDialog` |
| List Item | `<li>` | `RecyclerView Item` | `UITableViewCell` | `ListItem` |
| Switch | `<input type="checkbox">` | `SwitchMaterial` | `UISwitch` | `Toggle` |

### 跨端一致性检查清单

| 维度 | 一致性要求 | 允许差异 |
|---|---|---|
| 品牌色 | 必须90%+一致 | 各平台色域差异微调 |
| 字号层级 | 比例关系一致 | 基准值按平台规范 |
| 间距节奏 | 比例关系一致 | 基础单位4pt/8pt/1rem |
| 导航结构 | 信息架构一致 | 导航实现按平台规范 |
| 组件行为 | 交互逻辑一致 | 手势/动画按平台习惯 |
