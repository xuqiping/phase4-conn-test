## 实测发现的 bug（均已修）

### bug1：EDITOR 上传者筛选候选 403

- 现象：EDITOR 在上传者下拉输关键词 → `GET /assets/projects/10/members/candidates` 403。
- 根因：该端点 `requireManage`（OWNER 邀请专用），前端筛选误复用。
- 修复：新增读门端点 `GET /assets/projects/{id}/creator-candidates`（loadAccessible，任何可访问项目者；只返回本项目出现过 的上传者去重，不泄露全局用户目录）。
- 文件：AssetMapper(+selectCreatorUserIds)、AssetService(+searchCreatorCandidates)、AssetProjectController(+端点)、api/assets.ts(+creatorCandidates)、AssetMatrixFilter.vue(改调用)、AssetServiceTest(+单测)、AssetProjectView.test.ts(mock)。
- 验证：后端单测 40/40；curl EDITOR 200 候选 [p4_editor,p4_owner]、旧端点仍 403；浏览器 EDITOR 筛选生效。

### bug2：一致性包 PERSONAL 门控漏网

- 现象：PERSONAL 下 EDITOR 打开他人资产抽屉，一致性包输入可编辑+「保存一致性包」按钮可见（后端 403 兜底，前端应隐藏）。
- 根因：AssetDetailDrawer.vue:249 给 ConsistencyPack 传 `canEdit`（角色写权），应传 `canModify`（写权×PERSONAL 本人内容；同文件 115 行分镜字段即正确用法）。
- 修复：改传 canModify；新增单测 C7-8（PERSONAL 非本人 → ConsistencyPack can-edit=false）。
- 验证：drawer 单测 26/26；浏览器实测他人资产输入禁用+按钮消失、本人资产保留。

## 环境备忘（非 bug）

- **单会话令牌**：同账号每次新登录使旧 access+refresh 失效（curl 登录会踢掉浏览器会话）→ 联调时 API 探测与浏览器会话用不同账号，或走浏览器内 fetch。
