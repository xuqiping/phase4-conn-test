# 3.2 六层架构与商业模式映射

## 一、AI产品形态的六层核心架构

任何AI产品形态都可拆解为六层架构，每层的设计选择累积定义了产品形态：[来源:AI产品设计架构 | 📚中]

### 层1：模型层（Model Layer）
- **通用大模型**：GPT-4o/Claude/Qwen——能力广但深度浅
- **行业垂类**：医疗/法律/金融模型——精度高但泛化弱
- **小模型/边缘模型**：本地推理/隐私优先——成本低但能力弱
- **多模态模型**：图/音/视频/3D生成与理解
- **选型原则**：能力够用即可、成本可控、隐私合规、延迟容忍 [详见 D-19.03 模型选型与评估]

### 层2：能力层（Capability Layer）
- **理解能力**：意图识别、语义抽取、多轮上下文
- **生成能力**：文本/图/音/视频/代码生成
- **推理能力**：多步逻辑、思维链CoT、规划
- **工具调用能力**：Function Call、MCP、外部API集成
- **记忆能力**：短期上下文/长期记忆/RAG/记忆分层 [详见 D-19.07 长期记忆系统]
- **检索能力**：RAG/EOL/混合检索 [详见 D-19.08 RAG检索增强]

### 层3：交互层（Interaction）
| 交互范式 | 形态 | 典型 | 设计要点 |
|---|---|---|---|
| 对话框 | 主交互是文字对话 | ChatGPT | 多轮上下文管理、清晰开场 |
| Copilot侧栏 | AI在工作区侧栏建议 | GitHub Copilot | 不打断主流程、即时反馈 |
| 内联生成 | 在原内容上直接生成/修改 | Cursor/Notion AI | diff展示、原内容保留 |
| Agent后台 | AI在后台执行+结果通知 | Devin/Agent平台 | 进度可视、可中断、日志可追溯 |
| 语音对话 | 全语音交互 | Ray-Ban Meta/ChatGPT语音 | 低延迟、打断响应、隐私感知 |
| 多模态原生 | 看图/手势/语音混合界面 | Apple Intelligence/Rabbit | 模态切换自然、识别稳定 |
| 主动推送 | AI主动洞察/建议 | 数据洞察Agent | 低打扰、可关闭、价值密度高 |

### 层4：自主性谱系（Autonomy）
**这是从Copilot到Agent的核心变量**。自主性不是产品级开关，而是任务级滑动：

```
人主导 ←───────────────────────────→ AI自主
 ├ 每步确认（典型Copilot）
 ├ 单任务批量确认（半Agent）
 ├ 单任务全自主+人Review（典型Agent）
 ├ 多任务链全自主+里程碑Review（高阶Agent）
 └ 完全自治（L5前沿探索）
```

**自主性分配原则**：高频低风险→高自主；低频高风险→低自主+人监督。
**护栏设计**：工具白名单/敏感操作二次确认/自动回滚/操作日志/限制token消耗等。

### 层5：数据与反馈层
- **私有知识**：RAG知识库、企业文档、用户上传
- **上下文管理**：token预算、上下文压缩、摘要历史
- **长期记忆**：用户偏好/项目记忆/会话记忆 [详见 D-19.07]
- **反馈飞轮**：
  - 显式反馈：点赞/点踩/纠错/评分
  - 隐式反馈：复制/编辑/采纳/重试/停留时长
  - RLHF/DPO/SFT数据采集与回流

### 层6：业务流程融合度
- **外围工具**：AI在业务流程外做辅助（如独立问答窗口）
- **流程节点**：AI作为流程中某个节点（如审核环节AI打分）
- **流程重构**：按AI能力重构业务流程（如Agent Native客服流程）
- **流程替代**：AI直接替代原流程（如AI Coding替代传统编码流程）

## 二、形态×商业模式映射矩阵

形态决定商业模式可行性，强行错配会越卖越亏：[来源:AI产品商业化实践 | 📚中]

| 产品形态 | 适配商业模式 | 不适配商业模式 | 典型组合 |
|---|---|---|---|
| 对话式AI Chatbot | API按量/免费增值+订阅 | 高客单买断/抽佣 | ChatGPT API Tokens/Plus订阅 |
| Copilot嵌入式 | 席位订阅 | 纯按量/纯买断 | Copilot $10/月/席位 |
| 生成式工具 | 订阅+按量超额 | 席位订阅 | Midjourney订阅/按图加购 |
| 智能体Agent | 按量/按成果 | 纯席位订阅 | Devin按成果/Cursor按量 |
| AI搜索 | 订阅+API/广告 | 按量对C端 | Perplexity Pro订阅 |
| 情感陪伴AI | 订阅/打赏/角色付费 | B端席位 | Character.AI订阅+星野打赏 |
| 数据洞察AI | 订阅+用量 | 买断 | ThoughtSpot订阅+用量 |
| AI硬件 | 硬件买断+服务订阅 | 纯订阅 | Ray-Ban Meta硬件+Meta AI |
| AI原生工作流 | 订阅+用量+定制 | 纯买断 | 企业Agent平台订阅+定制 |

**关键洞察**：2026年Agent形态+按成果计费是最强趋势，因Agent能直接交付"任务结果"而非"使用时长"，与"按结果付费"天然契合。[来源:百家号2026 AI算账本 | 🔍高 | 2026-07]

## 三、形态×指标体系映射

不同形态需不同指标体系衡量产品健康度：[详见 D-19.05 AI产品指标]

| 形态 | 北极星指标 | 核心辅助指标 | 反指标（避坑） |
|---|---|---|---|
| 对话式AI | 周活会话数 | 单会话轮数/重试率/满意度 | 单纯token消耗（与价值无关） |
| Copilot | 周活采纳率 | 采纳次数/编辑率/采纳后保留率 | 展示次数（≠采纳） |
| Agent | 任务完成率 | 端到端成功率/平均步数/中断率/回滚率 | 任务发起数（≠完成） |
| AI搜索 | 查询满意度 | 无点击率（直接答完）/二次搜索率/引用采纳 | 查询数（≠答得好） |
| 生成式工具 | 生成采纳率 | 满意率/付费转化率/复购率 | 生成数（≠质量） |
| 情感陪伴 | 周留存 | 平均会话时长/主动发起率 | 单次时长（≠粘性） |
| AI硬件 | DAU/MAU | 语音唤醒率/使用场景覆盖 | 硬件销量（≠活跃） |

## 四、形态×团队能力映射

不同形态对团队能力的要求差异极大：[来源:AI团队组织实践 | 📚中]

| 形态 | 关键团队能力 | 缺失会怎样 |
|---|---|---|
| 对话式AI | 模型评估/Prompt工程/对话设计 | 体验割裂、意图识别差 |
| Copilot | IDE插件/上下文集成/内联渲染 | 集成卡顿、采纳率低 |
| Agent | 工具调用/规划引擎/护栏/任务编排 | Agent乱跑、回滚不可控 |
| 生成式工具 | 内容审核/版权合规/创意模板 | 合规风险、内容同质化 |
| AI硬件 | 硬件工程/嵌入式AI/续航优化 | 续航短、价值不足翻车 |
| AI原生工作流 | B端业务流抽象/Agent编排 | 工作流跑不通、客户不续费 |
