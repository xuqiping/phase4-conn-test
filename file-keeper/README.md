# File Keeper

> 轻量级跨平台文件收藏管理器 - v0.1.0

基于 Tauri 2 + Vue 3 + TypeScript 技术栈的跨平台文件管理工具。

## ✨ 特性

- ⚡ **快速访问** - 一键打开收藏的文件和文件夹
- 🪶 **轻量高效** - 虚拟滚动支持数千文件流畅运行
- 📁 **分组管理** - 按项目/类型组织文件
- 🔍 **智能搜索** - 实时搜索文件名、路径和标签（300ms 防抖）
- 🎯 **批量操作** - 多选、批量打开、批量移动、批量删除
- 🔄 **进程管理** - 查看和关闭已打开文件的进程（独家功能）
- 🎨 **深色模式** - 支持亮色/深色主题切换
- 🖱️ **拖拽添加** - 直接拖拽文件到应用添加收藏
- 📊 **使用统计** - 记录文件打开次数和最近打开时间
- ⌨️ **全局快捷键** - 自定义快捷键快速唤起应用

## 🚀 快速开始

### 下载安装

**Windows 用户：**
1. 下载 `File-Keeper_0.1.0_x64_zh-CN.msi`
2. 双击安装
3. 启动应用

### 从源码构建

**环境要求：**
- Node.js 18+
- npm 或 pnpm
- Rust 1.80+

**安装依赖：**
```bash
npm install
```

**开发模式：**
```bash
npm run tauri:dev
```

**构建应用：**
```bash
npm run tauri:build
```

## 📖 使用指南

### 添加文件

1. **拖拽添加** - 直接拖拽文件/文件夹到应用窗口
2. **按钮添加** - 点击"添加文件"或"添加文件夹"按钮
3. **批量添加** - 可同时拖拽多个文件

### 管理文件

- **打开文件** - 单击卡片打开文件
- **多选** - Ctrl+点击 或 拖拽选择多个文件
- **批量操作** - 选中后使用底部工具栏进行批量操作
- **右键菜单** - 右键卡片查看更多操作
- **搜索** - 顶部搜索框支持文件名、路径、标签搜索

### 分组管理

- **创建分组** - 点击"新建分组"按钮
- **移动文件** - 右键菜单 > 移动到分组
- **切换分组** - 点击顶部分组标签切换

### 进程管理

- 右键文件 > 关闭已打开的进程
- 查看哪些程序正在使用该文件
- 一键关闭相关进程

## 🎯 性能

- **启动时间** - < 500ms（1000 个文件）
- **滚动性能** - 60fps 流畅滚动（虚拟滚动技术）
- **搜索响应** - < 100ms（含 300ms 防抖）
- **内存占用** - < 100MB（1000 个文件）
