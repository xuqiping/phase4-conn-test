## 冒烟揪出 1 个真 bug（已修）

- **Esc 一次连关灯箱+选择弹窗**：Lightbox `onKeydown` 只 emit close 不拦事件——window 监听与 n-modal 的 document Esc 监听依序都收到。修复：`window.addEventListener('keydown', onKeydown, true)` 捕获阶段 + `stopPropagation/preventDefault`（Esc 逐层退，符合 user-ops「Esc 关灯箱弹窗仍在」承诺）。回归用例 +1（document 外层监听不应收到）。全量 vitest **1019/1019**、vue-tsc 0 错。

## 工装坑沉淀

- 资产上传 API 的 multipart **filename 必须带扩展名**——后端类型↔资产类型校验认扩展名，裸中文名静默拒（data null）。
- picker 行等待时序：modal 开≠有行（项目未选显「请先选择项目」）——先等 `.picker__bar` 再选项目再等行。
- hover popover 的 follower 层会拦截后续点击——测行空白点击前先 `mouse.move` 挪离缩略。
- 面板 fileId 不全类型显 readonly——fileId 断言改走上传响应体 listener（CanvasStoredFile.fileId）。
