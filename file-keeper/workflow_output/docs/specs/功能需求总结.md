# File Keeper 功能需求总结文档

> 用于 UI 设计参考的完整功能清单

---

## 📱 应用概述

**应用名称：** File Keeper  
**应用类型：** 桌面应用（跨平台）  
**核心定位：** 轻量级文件收藏管理器  
**目标平台：** Windows / macOS / Linux

---

## 🎯 核心功能列表

### 1. 文件收藏管理

#### 1.1 添加文件/文件夹
- **功能描述：** 用户可以将常用的文件或文件夹添加到收藏列表
- **交互方式：**
  - 点击"添加"按钮，打开文件选择对话框
  - 拖拽文件/文件夹到应用窗口
  - 支持批量添加多个文件
- **显示信息：**
  - 文件/文件夹图标（系统原生图标）
  - 文件名称
  - 文件路径（鼠标悬停显示完整路径）
  - 所属分组
  - 标签（可选）
  - 打开次数统计
  - 最后打开时间

#### 1.2 文件卡片展示
- **网格视图：** 以卡片形式展示，每个卡片包含图标和名称
- **列表视图：** 以列表形式展示，显示更多详细信息
- **卡片操作：**
  - 单击：打开文件/文件夹
  - 右键：显示上下文菜单（编辑、删除、移动分组、添加标签）
  - 拖拽：移动到其他分组或调整排序

#### 1.3 编辑收藏项
- 修改显示名称
- 添加/删除标签
- 添加备注说明
- 更换图标（可选）

#### 1.4 删除收藏项
- 单个删除
- 批量删除
- 删除前确认提示

---

### 2. 分组管理

#### 2.1 分组功能
- **默认分组：**
  - "全部" - 显示所有收藏的文件
  - "最近打开" - 按打开时间排序的最近10个文件
- **自定义分组：**
  - 创建新分组（输入分组名称）
  - 重命名分组
  - 删除分组（删除前确认，文件移至"全部"）
  - 设置分组颜色标识（可选）
  - 设置分组图标（可选）

#### 2.2 分组切换
- **标签页形式：** 顶部显示所有分组标签
- **点击切换：** 点击标签页切换到对应分组
- **拖拽移动：** 拖拽文件卡片到标签页可移动分组

---

### 3. 搜索与过滤

#### 3.1 搜索功能
- **搜索框位置：** 顶部工具栏
- **搜索范围：**
  - 文件名称
  - 文件路径
  - 标签
  - 备注
- **实时搜索：** 输入时即时显示结果
- **搜索高亮：** 匹配的关键词高亮显示

#### 3.2 过滤功能
- 按分组过滤
- 按标签过滤
- 按文件类型过滤（文件/文件夹）
- 按打开频率排序

---

### 4. 批量操作

#### 4.1 多选功能
- **选择方式：**
  - Ctrl/Cmd + 点击：多选
  - Shift + 点击：范围选择
  - 全选按钮
- **选中状态：** 卡片显示选中高亮

#### 4.2 批量操作
- 批量打开（一次性打开所有选中的文件）
- 批量移动到其他分组
- 批量添加标签
- 批量删除

---

### 5. 进程管理（核心特色功能）

#### 5.1 查看已打开的进程
- **触发方式：** 右键文件卡片 → "查看已打开的进程"
- **显示内容：**
  - 进程名称
  - 进程ID (PID)
  - 窗口标题
  - 进程图标
- **支持场景：**
  - 单个文件被多个程序打开（如Word文档被多个Word实例打开）
  - 文件夹被多个资源管理器窗口打开

#### 5.2 关闭进程
- **单个关闭：** 点击进程列表中的"关闭"按钮
- **批量关闭：** 一键关闭该文件的所有相关进程
- **确认提示：** 关闭前弹出确认对话框，避免误操作
- **错误处理：** 关闭失败时显示友好提示（如权限不足）

---

### 6. 全局快捷键

#### 6.1 快捷键功能
- **默认快捷键：** Ctrl+Shift+F (Windows/Linux) / Cmd+Shift+F (macOS)
- **功能：** 显示/隐藏主窗口
- **自定义：** 用户可在设置中自定义快捷键
- **冲突检测：** 检测并提示快捷键冲突

---

### 7. 系统托盘

#### 7.1 托盘图标
- 应用最小化时显示在系统托盘
- 托盘图标显示应用 Logo

#### 7.2 托盘菜单
- **显示主窗口** - 点击恢复窗口
- **退出应用** - 完全退出程序
- **最近打开** - 快速访问最近打开的文件（可选）

#### 7.3 托盘行为
- 点击托盘图标：显示/隐藏主窗口
- 右键托盘图标：显示托盘菜单
- 关闭窗口时最小化到托盘（可在设置中配置）

---

### 8. 设置页面

#### 8.1 外观设置
- **主题选择：**
  - 浅色主题
  - 深色主题
  - 跟随系统
- **视图模式：**
  - 网格视图（默认）
  - 列表视图
- **每页显示数量：** 可调整（12/24/48/全部）

#### 8.2 行为设置
- **开机自启动：** 开关
- **最小化到托盘：** 开关
- **全局快捷键：** 自定义输入框
- **语言选择：** 中文/英文

#### 8.3 数据管理
- **导出配置：** 导出收藏列表和设置
- **导入配置：** 从文件导入
- **清空数据：** 清空所有收藏（需确认）

## 🎨 UI 设计要求

### 设计风格
- **现代简约：** 扁平化设计，避免过度装饰
- **轻量感：** 界面清爽，留白适当
- **专业感：** 配色稳重，适合办公场景
- **易用性：** 交互直观，符合用户习惯

### 配色方案

#### 浅色主题
- **主色调：** #42b883 (绿色，代表活力和效率)
- **背景色：** #ffffff (纯白)
- **次级背景：** #f5f5f5 (浅灰)
- **文字主色：** #333333 (深灰)
- **文字次色：** #666666 (中灰)
- **边框色：** #e0e0e0 (浅灰)
- **悬停色：** #f0f0f0 (浅灰)
- **选中色：** #e8f5e9 (浅绿)

#### 深色主题
- **主色调：** #42b883 (绿色)
- **背景色：** #1e1e1e (深灰)
- **次级背景：** #2d2d2d (中灰)
- **文字主色：** #e0e0e0 (浅灰)
- **文字次色：** #a0a0a0 (中灰)
- **边框色：** #3d3d3d (深灰)
- **悬停色：** #383838 (中灰)
- **选中色：** #2d4a3e (深绿)

### 字体
- **中文：** 微软雅黑 / PingFang SC / Noto Sans CJK SC
- **英文/数字：** -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto
- **代码/路径：** Consolas, Monaco, 'Courier New'

### 图标
- **风格：** 线性图标（Outline）
- **大小：** 16px / 20px / 24px
- **来源：** Material Icons / Feather Icons / Heroicons

### 间距
- **小间距：** 8px
- **中间距：** 16px
- **大间距：** 24px
- **卡片内边距：** 16px
- **卡片间距：** 16px

### 圆角
- **按钮：** 4px

## 🔄 交互动画

### 动画时长
- **快速：** 150ms (按钮点击、悬停)
- **标准：** 300ms (页面切换、对话框)
- **慢速：** 500ms (大型内容加载)

### 动画效果
- **淡入淡出：** opacity 过渡
- **滑动：** transform translateY/X
- **缩放：** transform scale
- **弹性：** cubic-bezier(0.68, -0.55, 0.265, 1.55)

## 🎯 核心交互流程

### 1. 添加文件流程
```
用户点击"添加文件"按钮
  ↓
打开系统文件选择对话框
  ↓
用户选择文件/文件夹
  ↓
提取文件信息（名称、路径、图标）
  ↓
显示在当前分组的文件网格中
  ↓
保存到本地存储
```

### 2. 打开文件流程
```
用户点击文件卡片
  ↓
验证文件路径是否存在
  ↓
调用系统默认程序打开文件
  ↓
记录打开时间和次数
  ↓
更新"最近打开"列表
```

### 3. 关闭进程流程
```
用户右键文件卡片 → "查看已打开的进程"
  ↓
扫描系统进程，匹配文件路径
  ↓
显示进程列表对话框
  ↓
用户点击"关闭进程"
  ↓
弹出确认对话框
  ↓
用户确认
  ↓
关闭进程
  ↓
刷新进程列表
```

### 4. 搜索流程
```
用户在搜索框输入关键词
  ↓
实时过滤文件列表（防抖 300ms）
  ↓
高亮匹配的关键词
  ↓
显示匹配结果数量
  ↓
用户清空搜索框
  ↓
恢复显示所有文件
```

## 📱 特殊状态处理

### 空状态
- **无收藏文件：** 显示引导图和"添加文件"按钮
- **搜索无结果：** 显示"未找到匹配的文件"提示
- **分组为空：** 显示"该分组暂无文件"提示

### 加载状态
- **应用启动：** 显示 Logo 和加载动画
- **数据加载：** 显示骨架屏或加载指示器
- **图标加载：** 显示默认图标，加载完成后替换
### 错误状态
- **文件不存在：** 卡片显示"文件已移动或删除"，提供"移除"选项
- **打开失败：** 弹出提示"无法打开文件，请检查文件是否存在"
- **权限不足：** 提示"权限不足，无法执行操作"
