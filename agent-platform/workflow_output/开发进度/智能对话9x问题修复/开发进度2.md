## Playwright 实测补充（2026-08-11）

- 首次复现空白助手消息：显式选择 `doubao-seed-2.1-code`，实际却被模型列表为空的 `newok` Provider 抢占。
- 根因：Provider 的 `supports()` 把空模型列表当成“支持所有模型”；Claude Provider 还会按模型名前缀隐式认领。
- 修复：所有 CHAT Provider 只能认领其明确配置在 `models` 列表中的模型；空列表不再作为通配符。
- 回归测试：OpenAI compatible、Claude、Gateway 路由共 39 项通过。
- 修复后实测确认路由为 `provider=doubao`，页面不再留下无内容的助手气泡，而会显示失败提示。
- 当前剩余外部配置问题：Coding 端点与标准 Ark `/api/v3/chat/completions` 均返回 HTTP 404。标准端点试验后已恢复原配置；需使用火山实际开通套餐对应的 endpoint、API Key 和可调用模型 ID。
