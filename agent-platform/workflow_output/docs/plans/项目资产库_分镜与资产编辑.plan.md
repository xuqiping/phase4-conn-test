# Implementation Plan for 项目资产库·分镜与资产编辑（增量）

> Phase 2 产出。Phase 3 逐步勾选执行。只含伪代码，不含真代码。
> 续 [项目资产库.plan.md](项目资产库.plan.md) S1-S14（资产库主体已落地），本 plan 编号 S15 起。
> 来源：用户报障 4 项 + [1_8.6计划.md 第 11 点](../../0_推进计划/1_8.6计划.md)（分镜 5 字段流水线）。
> 设计稿见同目录 `项目资产库_分镜与资产编辑.设计稿.md`（P1 即规格；本 plan 自定义 FR 编号回链）。

## 背景与目标

四个问题，三类工作：

| 报障 | 根因（已核实） | 本 plan |
|---|---|---|
| ① 剧本和提示词不能修改 | 抽屉 `v-else` 把 PROMPT/非剧本 TEXT 渲染成只读 `<pre>`，无编辑器（剧本 SCRIPT 已有编辑器，运行正常） | S15 |
| ② 所有资产无法删除 | 后端 `DELETE` + `assetApi.remove` 已在，**缺 UI 删除按钮** | S15 |
| ③ 分镜拆解（模板+一键分镜+分镜类型） | 现仅分场，无分镜；需新媒体类型「分镜」+ 拆解模板 + LLM 拆镜产分镜资产 | S17-S19 |
| ④ 文本类资产显示默认图片 | 卡片 TEXT 类只显 emoji 色块；列表态 content=null 拿不到正文 | S16 |

**分镜 = 5 字段流水线**（1_8.6计划 第 11 点）：①提示词描述 ②实体→@资产键值对（LLM 拆镜首轮自动匹配）③批量生图+入库 ④生视频键值对（音频/图片参考）⑤据前 4 字段生视频。

**本轮范围（用户已选「地基+拆解」）**：字段 1/2 全功能；字段 3 生图/5 生视频**占位 UI**（阻塞于图模型接入，1_8.6计划 第 1 点，代码确认 `MediaGenProvider` 仅视频、`runImage` 是 stub）；字段 4 数据可编辑但生视频占位。

## 非目标（本轮不做）

- 字段 3 批量生图（需图模型 provider，R-3）、字段 5 生视频（待字段 3 图就绪）。
- 分镜卡缩略图（无生成图）、canvas 分镜节点。
- 手动「新建分镜」入口（分镜仅由一键分镜产出）。
- canvas 内 @资产 选择器/解析器接线（S13 asset 路径是 stub，且分镜字段用结构化 kv+NSelect，不走 MentionTextarea）。

## 技术实现坑点预判与规避措施

| 技术点/功能块 | 可能的坑 | 规避措施 | 验证方式 |
|---|---|---|---|
| LLM 拆镜·资产目录注入 | 大项目资产目录撑爆 prompt token | 仅注入 人物/道具/场景 图片资产，≤50 条（updated_at 倒序），紧凑 JSON `[{id,name,role}]` 不带 content | 构造 100+ 资产项目，日志看注入条数=50 |
| LLM 拆镜·assetId 幻觉 | 模型编造不存在的 assetId 或跨项目 id | 输出逐条校验 `assetId ∈ 目录 set`，非法置 null（用户后填）；富化 name/mediaType 取自目录非模型 | 单测造非法 id，断言被置 null |
| LLM 拆镜·JSON 解析 | 模型返围栏/多余文本/非数组 | 复用 `parseScenes` 容错（剥 ``` fence → 取首 `[..]` → 解析；全失败兜底单条） | 复用 AssetScriptService 现有解析单测范式 |

| 分镜 media type 不在 vocab | 项目自定义 vocab 删了「分镜」→ resolveCategory 400 | breakdown 前确保 vocab 含 分镜（缺失则自动追加 `{key:分镜,category:TEXT}` 再建）；V62 seed 存量 + default 覆盖新建 | 删分镜 type 后再一键分镜，验自动补回 |
| textPreview 抽取 | content 旧态非 JSON（裸文本）/ 嵌套对象 / 分镜无 body | parse 防御：JSON.parse 失败用原文本；按键优先级 `body`/`synopsis`/`prompt` 取值，再回退首层字符串值；截断 ≤120 字去换行 | 造 4 种 content 形态（body/synopsis/prompt/裸文本）单测 |
| 分镜 entityRefs 悬挂 | 被引用资产后删/失权 → 分镜 entityRefs 指向空 | 抽屉渲染时 assetId 取不到 → 降级显「资产已删」红标，不崩；保存不校验存在（宽松，保留引用痕迹） | 删被引资产后开分镜抽屉，验降级提示 |
| 抽屉多分支同文件 | S15/S18/S19 都改 AssetDetailDrawer.vue | 严格串行（S15→S18→S19），每步带测试防回归；分镜 UI 抽 StoryboardFields.vue 子组件减重 | 每步 vitest 全绿 |
| 并发改正文/模板 | 两人同时编同资产版本撞车 | 复用现有 `current_version` 乐观锁（versionApi.create 路径） | 复用现有并发版本单测范式 |

## Step S15 — Bug①②：提示词编辑器 + 资产删除按钮（前端）

**目标**：提示词(PROMPT)/非剧本 TEXT 类资产可编辑正文；抽屉提供删除入口。

**动作（伪代码）**：
- 抽屉抽出统一「正文编辑器」逻辑（现仅剧本有）：
  - helper `readTextBody(content, type)`：剧本→`content.synopsis`；其他 TEXT→`content.body`；兜底纯文本
  - helper `writeTextBody(content, type, body)`：按类型写回对应键，保留其他键（scenes/template 不丢）
  - PROMPT/自定义 TEXT 分支：复用 `n-input textarea`（rows 6, readonly=!canEdit）+ 「保存正文」按钮 → `versionApi.create({content, changeNote})`
  - 剧本分支：保持现有 synopsis 编辑器（顺手验证运行时无回归）
- 删除：actions 区加「删除」按钮（canEdit gated，`n-popconfirm`「确认删除？画布引用快照不受影响」）→ `assetApi.remove(id)` → message + emit('changed') + 关抽屉
- emit 增加 `deleted(assetId)`（或复用 changed，父 reload 即可）；抽屉 delete 后置 show=false

**涉及文件（≤20）**：
- `frontend/src/components/asset/AssetDetailDrawer.vue`
- `frontend/src/components/asset/AssetDetailDrawer.test.ts`

**依赖**：无（bug 独立）

**验证步骤**：
- vitest：PROMPT 编辑→存版本→content 刷新；删除 confirm→调 remove→关抽屉；剧本编辑无回归

## Step S16 — Bug④：文本类资产显示正文片段（后端 + 前端卡片）

**目标**：卡片 TEXT 类资产封面显示正文片段，不再只是 emoji 色块。

**动作（伪代码）**：
- 后端 `AssetVO` 加字段 `textPreview`（String，列表态用）
- `AssetService.toVO(a, withContent)`：TEXT 类（category=TEXT）时调私有 `extractTextPreview(content)`：
  - JSON.parse → 按键优先级取 `body`/`synopsis`/`prompt`（prompt 供分镜卡）→ 剥为纯文本 → 截断 ≤120 字 → 去换行/多空格；parse 失败用原文本截断；非 TEXT 类 null
  - 列表态（withContent=false）也填 textPreview（独立于 content 懒加载）
  - 与 `AssetScriptService.readScriptBody` 各司其职不合并（后者为 LLM 读正文，含 fallback 语义不同）
- 前端 `asset.ts` AssetVO 加 `textPreview?: string`
- `AssetCard.vue`：effectiveCategory==='text' 且 textPreview 非空 → 封面渲染 `<div class="cover-text">`（引文卡：clamp 2 行，等宽/次色字）；空则回退现 emoji 色块。非 TEXT 不变

- `backend/.../asset/dto/AssetVO.java`
- `backend/.../asset/service/AssetService.java`（私有 `extractTextPreview`）
- `backend/.../asset/service/AssetServiceTest.java`（textPreview 抽取单测）
- `frontend/src/types/asset.ts`
- `frontend/src/components/asset/AssetCard.vue`
- `frontend/src/components/asset/AssetCard.test.ts`

**依赖**：无

**验证步骤**：
- 后端单测：3 种 content 形态（`{body}`/`{synopsis}`/裸文本）→ textPreview 正确截断；非 TEXT→null

## 术语表

- **分镜（storyboard）**：把剧本拆成镜头级别，每镜头一资产，含提示词+实体映射+（占位）生图/生视频。
- **分场（scene split）**：现已有，剧本→3-10 场（粗粒度）；分镜更细（场→镜）。
- **拆解模板（template）**：剧本内自由文本，指导 LLM 拆镜风格（景别/节奏/台词密度）。
- **entityRefs（实体→@资产）**：分镜字段 2，键值对，值=项目内人物/道具/场景图片资产；LLM 拆镜首轮自动匹配，用户可改。
- **资产目录（catalog）**：一键分镜时注入 LLM 的项目图片资产清单（≤50），供实体匹配。
- **占位字段**：分镜字段 3（生图）/5（生视频）本轮只显 disabled 按钮，等图模型 provider（R-3）接入。
- **R-3**：1_8.6计划 第 1 点「接入图片模型」，当前 `MediaGenProvider` 仅视频、`runImage` stub。
