# 3.1 核心依赖链

> 核心依赖链是PM知识体系的"骨架"——10条骨干依赖链，覆盖从方法论→需求→设计→数据的纵向依赖。PM必须按链序学，跳链 = 知识悬空。

## 一、10条骨干依赖链

### 链1：方法论基石链（D-09 → D-02 → D-05）

```
D-09.01产品思维 → D-09.02经典框架(KANO/RICE/MoSCoW) → D-02.01需求收集 → D-02.03优先级 → D-05.01信息架构 → D-05.02交互设计
```

**依赖逻辑**：产品思维是所有PM的元认知，经典框架是方法论工具箱，需求收集用框架判断真伪，优先级用KANO/RICE排序，信息架构基于优先级组织内容，交互设计基于架构设计交互。跳过D-09直接学D-05 = 无方法论的设计 = 画图工。

**关键节点**：D-09.02经典框架是整条链的"枢纽"——KANO教需求分类，RICE教优先级量化，MoSCoW教版本裁剪，三个方法递进而非并行。

---

### 链2：指标→数据→增长链（D-06 → D-07）

```
D-06.01指标体系 → D-06.02采集方案 → D-06.03分析方法 → D-07.01增长方法论 → D-07.02生命周期运营
```

**依赖逻辑**：没有指标体系就无法度量增长，没有采集方案就没有数据来源，没有分析方法就无法从数据中提炼洞察。跳D-06直接做D-07 = 无数据的增长 = 瞎增长。

**关键节点**：D-06.01指标体系是增长的"地基"——OSM/UJM/AARRR三层指标体系是增长所有决策的数据基座。

---

### 链3：用户→市场→产品链（D-03 → D-04 → D-05）

```
D-03.01用户画像 → D-04.01市场分析 → D-04.02竞品分析 → D-05.01信息架构 → D-05.03原型设计
```

**依赖逻辑**：先懂用户（D-03画像），再懂市场（D-04分析），才能设计产品（D-05架构→原型）。跳用户直接做产品 = 不懂用户的产品 = 自嗨产品。

---

### 链4：流程→项目→质量链（D-01 → D-08）

```
D-01.01产品规划 → D-01.02需求评审 → D-08.01研发模式 → D-08.02项目管理 → D-08.05测试质量
```

**依赖逻辑**：产品规划定义做什么，需求评审定义怎么做，研发模式定义用哪种方式做，项目管理管过程，测试质量保结果。跳D-01直接做项目管理 = 不懂产品逻辑的项目管理 = 流程工。

---

### 链5：文档工具链（D-11 → D-12）

```
D-11.01需求文档 → D-11.03分析报告 → D-12.01原型设计工具 → D-12.02协作工具
```

**依赖逻辑**：先会写文档（内容），再会选工具（效率）。工具是手段，文档是目的。跳文档直接学工具 = 只会用工具但不知道写什么。

---

### 链6：合规风控链（D-16 → D-19.06 → D-24.09）

```
D-16.01数据隐私 → D-16.03安全合规 → D-19.06 AI风险合规 → D-24.09 Agent安全与对齐
```

**依赖逻辑**：数据隐私是合规底线，安全合规定义边界，AI风险合规是AI场景的合规深化，Agent安全是Agent场景的合规再深化。跳D-16直接学D-24.09 = 不懂通用合规的专项合规 = 只见树木不见森林。

---

### 链7：AI基础→AI专项→Agent专项链（D-19 → D-24）

```
D-19.01 AI产品形态 → D-19.02提示词工程 → D-19.03模型选型 → D-24.01 Agent产品形态 → D-24.02 Agent通信协议 → D-24.04工作流设计
```

**依赖逻辑**：先理解AI产品形态（D-19.01），再掌握提示词工程（D-19.02，与模型交互的底层能力），再学模型选型（D-19.03），然后进Agent专项（D-24）。跳D-19直接做D-24 = 不懂大模型的Agent设计 = 空壳Agent。

---

### 链8：B端基础→B端专项链（D-17 → D-18）

```
D-17.01大客户研究 → D-17.02客户分层 → D-17.03客户成功 → D-18.01商业模式 → D-18.02定价方法
```

**依赖逻辑**：先懂客户（D-17），才能设计商业（D-18）。定价基于客户价值认知，商业模式基于客户需求结构。

---

### 链9：行为心理→增长链（D-21 → D-07）

```
D-21.01行为模型 → D-21.02行为经济学 → D-07.01增长方法论 → D-07.03触达策略
```

**依赖逻辑**：增长的本质是改变用户行为，不理解行为模型就无法设计有效增长策略。Hooked模型→增长触发，损失厌恶→限时优惠，锚定效应→定价锚点。

---

### 链10：职业→避坑链（D-13 → D-14）

```
D-13.01能力模型 → D-13.02发展路径 → D-14.01需求坑 → D-14.02设计坑
```

**依赖逻辑**：先知道自己该发展什么能力（D-13），再学怎么避坑（D-14）。不知道正确的路，就不知道哪些坑是偏离正确路的表现。
