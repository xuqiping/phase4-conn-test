## 本轮做了什么（C3：5 类节点 shape + 产出物契约，IC-2..IC-6 前端骨架 + DTO）

### 前端节点体系

- **CanvasNodeBase** [nodes/CanvasNodeBase.vue](../../../frontend/src/components/canvas/nodes/CanvasNodeBase.vue)：可复用节点外壳——accent 条 + 图标槽 + kind 标签 + 运行态徽标（idle/running/success/failed）+ 顶/底 Handle + 选中态辉光。5 类节点共用。
- **5 类节点 shape**（各用 base + slot，紧凑）：
  - [TextNode](../../../frontend/src/components/canvas/nodes/TextNode.vue)：提示词预览（4 行截断）。
  - [ImageNode](../../../frontend/src/components/canvas/nodes/ImageNode.vue)：thumbnail（previewUrl）或上传占位。
  - [VideoNode](../../../frontend/src/components/canvas/nodes/VideoNode.vue)：prompt + 比例/时长/分辨率 meta。
  - [AudioNode](../../../frontend/src/components/canvas/nodes/AudioNode.vue)：来源模式占位。
  - [ScriptNode](../../../frontend/src/components/canvas/nodes/ScriptNode.vue)：剧本概要 + 分镜数。
- **node-types 注册** [CanvasBoard.vue](../../../frontend/src/components/canvas/CanvasBoard.vue)：`markRaw` 注册 5 类（同 FlowCanvas 范式，规避响应式包裹组件对象）；调色板文本类型 `default→text` 对齐。
- **PropertyPanel** [PropertyPanel.vue](../../../frontend/src/components/canvas/PropertyPanel.vue)：选中节点按 type 显隐字段——文本(prompt)/视频(prompt+比例+时长+分辨率)/音频(模式)/脚本(剧本)/图片(占位)。直编 `node.data`（数组真实引用，reactive 即时反映画布）。
- **选中态联动**：CanvasBoard `@node-selected` emit 数组中的真实 CanvasNode 引用 → CanvasView `selectedNode` → PropertyPanel。

### 后端产出物契约 DTO

- [CanvasNodeDTO](../../../backend/src/main/java/com/superprogrammer/canvas/dto/CanvasNodeDTO.java)：快照内节点后端契约（id/type/position/data Map），5 类常量，C4+ 按 type 分发生成。
- [NodeOutputRef](../../../backend/src/main/java/com/superprogrammer/canvas/dto/NodeOutputRef.java)：产出物引用（nodeId/fileId/outputKind）——快照只存 fileId 不嵌 base64（plan R-5），下游节点引用上游产出（plan 联动清单）。

### 类型扩展

- [types/canvas.ts](../../../frontend/src/types/canvas.ts)：加 `CanvasNodeStatus`（运行态）+ `CanvasNodeData.status`。

## 验证

- 后端 `mvn compile` 绿（canvas DTO 加入零回归）。
- 节点拖入→属性面板编辑→快照保存全链路通（5 节点 shape 渲染正确）。

## 踩坑批注

| 坑 | 解 |
|---|---|
| `<script setup>` 内 `export type` 有 vue-tsc 风险 | `CanvasNodeStatus` 放 types/canvas.ts，节点 import `@/types/canvas`（不依赖 SFC 导出） |
| Vue Flow 自定义节点须 `markRaw` 注册 | 同 FlowCanvas，否则响应式包裹组件对象告警 |
| 属性面板直编 prop 嵌套属性 | 传数组真实引用（非副本），nested mutation 合法且即时反映画布 |
