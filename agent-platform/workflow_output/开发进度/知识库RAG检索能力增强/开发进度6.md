### Step1 代码（commit 06ed7cbb，LlmContextualizerTest 5/5）

- **`config/RagContextualProperties.java`**（新）：`rag.contextual.llm.*`——enabled 默认 **true**（与规划器默认 false 相反：索引进线增益明确、可降级，规划器在查询热路径保守起步）/maxTokens 2000/maxChunks 60（超限截断取前 60，log warn）/model null=网关默认。
- **`service/LlmContextualizer.java`**（新）：
  - `generateLocators(doc, l1Summary, chunks, docOwner)` → `Map<path, locator>`；开关关/ATTACHMENT/空清单→`Map.of()`（降级纯规则）；每文档**1 次** LLM 调用（temperature 0.3=L1 口径、stream false），输入=L1 摘要+chunk 清单（path/标题/首行 ≤200 字截断），输出 JSON 数组 `{path, locator ≤50字}`；计费归户 `doc.createdBy`。
  - **key=chunk path 非 nodeId**：LLM 调用必须在 writeNodes 事务前（定位语要进同一事务的 contextHash），节点 id 尚未生成——path（`/L0-i/L2-ordinal`）写库前确定，绕开鸡生蛋。
  - **解析容错三级**：readTree 成功走数组 → 失败/异常走 `salvageObjects`（花括号配对+inString/escaped 状态机扫描，逐对象独立解析，烂尾处前的完整对象全捞回）→ 单对象失败忽略；**逐 chunk 独立降级**（缺失项该 chunk 纯规则前缀，非整文档失败）。
  - **权限治理词过滤**：GOVERNANCE_WORDS 12 词命中→**整条丢弃**（词级替换有泄漏风险：改写后的定位语仍可能暗示权限结构）；>50 字截断。
- 偏离 plan：独立类非 Contextualizer 加方法（职责分离）、配置独立 RagContextualProperties 非塞 RagConfig——已记 plan 实现注。
