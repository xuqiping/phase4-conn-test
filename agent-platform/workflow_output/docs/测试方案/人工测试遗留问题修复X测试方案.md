## R 系列① · 视频节点上传（X-1）

**前置**：打开任一画布，新建视频节点（拖入或双击空白选「视频」）。

| # | 用例 | 步骤 | 预期 |
|---|---|---|---|
| R1 | L1 正向上传 | 视频节点属性面板顶部点「上传视频」→ 选一个 mp4（<50MB） | 上传中按钮 loading；完成后节点显视频预览可播；面板提示「本地视频 ≤50MB」常显 |
| R2 | L1 产物联动 | R1 后看节点工具条与下游 | C11 抽帧/C12 截取按钮出现可用；下游节点 @候选含本节点（可引用该视频）；重传另一 mp4 覆盖旧预览 |
| R3 | L2 预检三线 | 分别传 60MB 视频 / 31MB 图（图片节点）/ 16MB 音（音频节点） | 各自 toast 超限拒（视 50MB/图 30MB/音 15MB 单源），不发请求节点不变；恰卡上限值（=50MB）放行 |
| R4 | L1 反向·失败 | 断网上传 mp4 | 节点标红 errorMsg 不落 fileId；恢复网络重传成功 |

## R 系列② · 从库选择全类型预览（X-2）

**前置**：项目资产库备四类资产各一（图/视/音/提示词——提示词有正文）；画布建对应类型节点（列表只显同类）。

| # | 用例 | 步骤 | 预期 |
|---|---|---|---|
| R5 | L3 图正向 | 图片节点「从库选择」→ 鼠标悬浮行缩略图 300ms | 侧边浮层放大图+底部尺寸行（如 1920×1080）；快速划过不弹 |
| R6 | L3 点击大图 | R5 后点缩略图 | Lightbox 大图开于**弹窗之上**；滚轮缩放/拖拽/双击复位/工具条 ± 复位可用 |
| R7 | L3 关闭恢复 | R6 后按 Esc（或点遮罩/×） | 灯箱关、选择弹窗仍在且完好；再点缩略可重开 |
| R8 | 视/音/文四态 | 视频/音频/提示词节点各开「从库选择」 | 视=首帧缩略+▶+悬浮首帧放大+点击弹播放；音=「音」字标+行内播放条可播；文=正文片段（无片段显「提」字标） |
| R9 | L4 选择+误选 | ① 点「选择」按钮；② 点行空白处；③ 音频行点播放条 | ① resolve 后节点数据写入+弹窗关；② 零动作（不选不关）；③ 只播不选 |
| R10 | 反向·加载失败 | 传一个会 404 的资产（或断网）开列表 | 缩略回落类型字标（图/视），不白屏不转圈死；「选择」仍可用 |

## R 系列③ · 组边随 ⛓ 保留（X-3）

**前置**：画布建组 g（2 成员 m1,m2）；组外节点 b 与 g 两向连：b→group:g（聚合）、group:g→b（广播）。⛓ 开关默认开。

| # | 用例 | 步骤 | 预期 |
|---|---|---|---|
| R11 | L5 正向两向 | 框选 b → Ctrl+C → 空处 Ctrl+V | 副本 b' 带**两条组边**：b'→g 与 g→b'（SVG 覆盖层连线跟随）；b' **不入组员**（组计数不变）；v-model 无伪 id（图面无异常边） |
| R12 | L5 反向·开关 | ⛓ 关 → 同样复制粘贴；再开再贴 | 关=零组边（原 IX 行为）；开=两向组边回来 |
| R13 | L5 反向·解散 | ⛓ 开复制 b → 解散组 g → Ctrl+V | 粘贴节点照常，组边被悬挂防护丢弃，无断线残留无报错 |
| R14 | L6 批量+撤回 | ⛓ 开连按 Ctrl+V 三次 → Ctrl+Z 一次 | 三份副本各带两条组边（与原组边平行并存）；一次撤回该批节点+组边齐消 |
| R15 | 消费+落库 | ① 点组内 m1 生成（广播上游含 b'）；② b' 生成（聚合上游含组成员）；③ 等自动保存刷新页面 | ① ② 输入面板/数据流含对端产物；③ 组边随快照重现（连线保持） |

## 出口

R1-R15 全过 → 问题单 2x 三项销项。
