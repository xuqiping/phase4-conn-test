## 发现缺陷与修复（commit `07d63ae2`）

**症状**（K5 判别实验抓出）：单选节点按 Esc——DOM 选中类被 vue-flow 清掉、视觉无选中，但应用层 `selectedNodeId` 残留 → 属性面板仍挂旧节点 + ✨ 一键整理被「隐形选中」拉进子图模式（拖走的孤立点不回槽）。多选 Esc 正常（window keydown 有清多选分支）。

**根因**：`syncSelectionFromLibrary`（S5 引入）对「库选中=0」**故意不处理**（注释：pane/edge 点击由各自 handler 清）——但 vue-flow 自发清空（Esc）不经过那两个 handler，状态失同步。修复VII 之前症状只是面板挂旧节点（轻微）；✨ 子图模式把它放大成行为错乱。

**修法**：`syncSelectionFromLibrary` 补 `ids.length === 0` 分支——有任一选中态（单选/边选/多选）才清+emit，幂等，通用收口所有 vue-flow 自清路径，非只堵 Esc。

**修后复测**：Esc → 面板回占位文案；拖走孤立1→Esc→✨ → 全图模式回槽（链 -528→-128→304→720 LR 递增，锚点随粘贴批整体左移属预期）；点节点面板正常开、点空白正常关；vitest 901/901 绿 + vue-tsc 0 错。
