## 决策与坑点批注
- **ModelSelector 不清空语义用空串 '' 而非 null**：emit 签名 `[model: string]` 不动，ChatView（`@change`）/DocumentOptionsModal（`v-model`）/VideoGenView 三处旧调用方零适配；调用方自行 `'' → undefined/delete`。
- **optional 模式 mounted 不自动选中**：旧行为「无值自动选 preferred」在覆盖场景是 bug（会把「跟随默认」悄悄变成「锁死 preferred」）；用 prop 开关而非改默认，旧页面行为冻结。
- **模型选择走 `data-changed` emit 落库，提示词不跟**：画布保存靠手动保存按钮 + 动作后 scheduleSave，提示词等连续输入沿用该既有行为；模型是离散点选，用户预期「选了就存」，单独 emit。
- **Node 版本坑（环境批注）**：vitest 4.1.7 → rolldown 要求 `node ^20.19||>=22.12`，本机默认 PATH 是 nvm 的 v18.19.0 起不来（`styleText` 缺导出）；须 `PATH="/d/IT/nvm/v24.11.1:$PATH"` 跑前端测试。rolldown win32-x64-msvc binding 曾被旧 node 的 npm 装丢（optional dep 按 engine 跳过），`npm i @rolldown/binding-win32-x64-msvc@1.0.2 --no-save` 补回。**凡前端测试/构建照此**。
- **NDrawer/NModal teleport 测试**：`wrapper.findAll('button')` 找不到抽屉/弹窗内按钮（内容 teleport 到 body）——DOM 断言须 `attachTo: document.body` + `document.body.querySelectorAll`；组件实例断言 `findComponent` 不受 teleport 影响（走 vnode 树）。
