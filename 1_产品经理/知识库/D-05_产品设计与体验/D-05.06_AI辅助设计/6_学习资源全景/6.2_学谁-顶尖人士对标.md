## B. 学谁 — 业内顶尖人士对标图谱

### 1. David Holz

| 维度 | 内容 |
|---|---|
| 身份 | Midjourney创始人，前NASA/Leap Motion |
| 核心成就 | 创建全球最具影响力的AI图像生成平台；定义了"AI作为想象力放大器"范式 |
| **思维模型** | "AI不是替代创造力，而是扩展想象力的边界"——工具应降低创作门槛而非取代创作者 |
| **行动范式** | 产品驱动——把最前沿的Diffusion模型包裹成最简洁的Discord交互；持续迭代而非完美再发布 |
| 可学习点 | 如何在技术爆炸期用极简产品定义品类 |
| 来源 | [🔍高 \| 2025-2026] |

### 2. Mike Krieger

| 维度 | 内容 |
|---|---|
| 身份 | Anthropic首席产品官，Instagram联合创始人 |
| 核心成就 | 将Instagram从0做到10亿用户；2026年主导Claude产品设计，定义"反AI平庸设计"框架 |
| **思维模型** | "好产品=约束×品味"——AI时代更需要设计约束与审美判断力 |
| **行动范式** | 反AI平庸——不是AI能生成就该生成，每个输出都需要人类审美把关 |
| 可学习点 | 如何在AI能力泛滥时建立设计约束和品质标准 |
| 来源 | [🔍高 \| 2025-2026] |

### 3. Guillermo Rauch

| 维度 | 内容 |
|---|---|
| 身份 | Vercel CEO，v0.dev创造者 |
| 核心成就 | 创建Next.js生态；2024-2026推出v0.dev定义"Prompt→React组件"品类 |
| **思维模型** | "生成即部署"——从想法到生产级代码的最短路径，消灭设计→开发的鸿沟 |
| **行动范式** | 开发者体验优先——每个AI生成结果都要可运行、可编辑、可直接部署 |
| 可学习点 | 如何让AI设计工具真正融入工程流程而非停留在"好看的图" |
| 来源 | [🔍高 \| 2025-2026] |

### 4. Ranjan Sinha

| 维度 | 内容 |
|---|---|
| 身份 | Galileo AI创始人，前Meta设计工程师 |
| 核心成就 | 创建2026最成熟的text-to-UI设计生成工具；首创"AI理解设计系统"方法 |
| **思维模型** | "AI应该读懂设计系统而非从零生成"——基于组件库+设计规范的约束生成比自由生成更可靠 |
| **行动范式** | 约束式生成——用设计系统做语义锚点，用AI做排列组合，兼顾效率与一致性 |
| 可学习点 | 如何让AI生成结果符合企业级设计规范 |
| 来源 | [📚中 \| 2025-2026] |

### 5. Jasper Hauser

| 维度 | 内容 |
|---|---|
