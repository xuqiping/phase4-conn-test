# D-06.07 实验与A/B — 可落地流程

## 4.1 A/B实验全流程 SOP

### 流程图

```
需求确认 → 假设形成 → 实验设计 → AA测试 → AB运行 → 结果分析 → 决策 → 复盘
```

### 详细步骤

| 阶段 | 步骤 | 动作 | 输出 | 红线检查 |
|---|---|---|---|---|
| 设计 | 1.确认需求 | 定义要验证的产品假设 | 假设陈述 | 假设必须可证伪 |
| 设计 | 2.选指标 | 1个OEC + N个护栏指标 | 指标清单 | OEC只能有1个 |
| 设计 | 3.算样本量 | 确定MDE、基线率、α、β | 所需样本量/运行天数 | MDE需业务方确认 |
| 设计 | 4.定分组 | 确定分组比例和分流方式 | 实验配置 | 需AA测试验证 |
| 执行 | 5.AA测试 | 验证分流均匀性 | AA结果报告 | AA不显著才可开始AB |
| 执行 | 6.AB运行 | 上线实验，按预设时间运行 | 实验数据 | 禁止提前偷看 |
| 执行 | 7.监控 | 日常监控护栏指标 | 监控日报 | 护栏指标触发即暂停 |
| 分析 | 8.结果分析 | 显著性检验+效应估计+分层分析 | 分析报告 | 需做辛普森检查 |
| 决策 | 9.决策 | 上线/不上线/继续实验 | 决策记录 | 需多角色签字 |
| 复盘 | 10.复盘 | 记录学到的经验 | 复盘文档 | 入知识库 |

## 4.2 实验设计模板

### 模板字段

```markdown
## 实验设计文档
- 实验名称：[简洁命名]
- 实验编号：[EXP-YYYY-NNN]
- 业务背景：[为什么要做这个实验？]
- 假设：[如果做X，则Y会变化Z%，因为...]
- OEC（总体评估标准）：[1个核心指标]
- 护栏指标：[2-3个不可恶化的指标]
- 目标人群：[全量/新用户/某地区...]
- 分组设计：[对照组A] vs [实验组B]，比例 [X:Y]
- 样本量：[计算过程+结论]
- 运行时长：[N天，覆盖N个完整周期]
- 停止规则：[预设运行完成/护栏触发]
- 分析计划：[主分析+分层分析+异质性分析]
- 负责人：[PM/数据/开发]
```

### MDE设定指南

| 场景 | MDE参考值 | 理由 |
|---|---|---|
| 大流量+小改动 | 0.5-1%相对提升 | 流量充裕，可检测小效应 |
| 中流量+中度改动 | 2-5%相对提升 | 需平衡检测能力与运行时长 |
| 小流量+大改动 | 5-10%相对提升 | 流量有限，只检测大效应 |
| 基线率极低(<1%) | 10-20%相对提升 | 低基线需要更大绝对变化才显著 |

## 4.3 结果分析清单

### 分析步骤

| 步骤 | 动作 | 方法 | 通过标准 |
|---|---|---|---|
| 1.AA验证 | 分流是否均匀 | AA测试组间差异 | p>0.3 |
| 2.主效应 | OEC是否显著变化 | t/z检验+CI | p<0.05且方向一致 |
| 3.护栏检查 | 护栏指标未恶化 | 逐项检验 | 所有护栏p>0.05 |
| 4.效应量 | 变化了多少 | 均值差+95%CI | CI不含0 |
| 5.分层分析 | 效应在子群中是否一致 | 按平台/地域/新老分 | 无辛普森反转 |
| 6.趋势分析 | 效应是否随时间稳定 | 逐日变化趋势 | 无明显衰减/增长趋势 |
| 7.新奇效应 | 是否存在短期效应 | 前3天vs后7天对比 | 趋势稳定 |
| 8.溢出检查 | 是否存在组间污染 | 检查社交数据 | 无显著溢出 |

### 决策矩阵

| 主指标 | 护栏指标 | 决策 |
|---|---|---|
| 显著正向 | 无恶化 | ✅上线 |
| 显著正向 | 有恶化 | ⚠️权衡：评估正向收益vs负向风险 |
| 不显著 | 无恶化 | 🔄继续实验或放弃（看MDE是否达标） |
| 不显著 | 有恶化 | ❌不上线 |
| 显著负向 | — | ❌不上线 |

## 4.4 实验与A/B Agent 提示词

### 提示词：A/B实验设计助手

```
# Role
你是一位资深实验设计专家，擅长帮助产品经理从0到1设计高质量的A/B实验，确保统计严谨性和业务可操作性。

# Background
产品经理经常需要验证新功能/策略的效果，但实验设计涉及统计假设、样本量计算、指标选择、常见陷阱等多个维度，设计不当会导致结论不可信甚至误导决策。

# Objective
帮助产品经理系统化地设计A/B实验，输出完整的实验设计文档，确保统计严谨、业务可行、陷阱可控。

# Key Results
1. 明确可证伪的实验假设
2. 预注册1个OEC+N个护栏指标
3. 合理的样本量和运行时长
4. 完整的分析计划和决策规则

# Steps
1. 梳理业务背景，形成可证伪的假设（"如果做X，则Y变化Z%"）
2. 选择OEC（只能1个）和护栏指标（2-3个）
3. 确定MDE——与业务方确认"最小值得关注的变化"
4. 计算样本量——基于基线率、MDE、α=0.05、β=0.2
5. 确定运行时长——覆盖至少1个完整业务周期
6. 设计分组方案——AA测试+AB实验
7. 制定停止规则和护栏触发条件
8. 规划分析方案——主分析+分层+趋势+新奇效应检查
9. 设定决策矩阵——基于主指标×护栏指标的组合决策

# 红线
- 禁止OEC超过1个（多指标需指定优先级）
- 禁止没有护栏指标就上线实验
- 禁止偷看结果后提前停止（除非用序贯分析）
- 禁止在AA测试不通过时直接开始AB
- 如果样本量不足，必须标注"当前流量不足以检测该MDE，建议提高MDE或扩大人群"

# 输出格式
```markdown
## 实验设计文档
- 实验名称：[简洁命名]
- 实验编号：[EXP-YYYY-NNN]
- 假设：[如果做X，则Y变化Z%，因为...]
- OEC：[1个核心指标]
- 护栏指标：[2-3个]
- MDE：[X%相对提升]
- 样本量：[计算结果+所需运行天数]
- 分组：[对照组] vs [实验组]，[比例]
- 分析计划：[步骤清单]
- 决策矩阵：[主指标×护栏的决策表]
- 负责人：[PM/数据/开发]
```

# 固定结尾
以上实验设计基于当前业务理解和统计假设。实验过程中如发现假设违反（如溢出效应、新奇效应），需及时调整分析策略。建议每次实验后进行复盘，沉淀团队实验知识库。
```
