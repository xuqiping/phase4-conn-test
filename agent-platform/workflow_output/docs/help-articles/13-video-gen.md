# 视频生成（SeedDance）

> 入口：侧栏「**视频生成**」。看不到菜单 = 没有权限，找管理员开通。

## 一、文生视频（最简单）

1. 「视频模型」下拉选模型（不同模型的比例/分辨率/时长选项会自动变化）。
2. **不传任何附件** = 文生视频。
3. 填提示词（≤2000 字，越具体越好，如「一只橘猫在窗台上晒太阳，阳光柔和，慢镜头」）。
4. 选画面比例（16:9 横屏 / 9:16 竖屏等）、时长（4-15 秒）、分辨率（720p 推荐；fast/mini 模型最高 1080p）。
5. 水印、生成音频开关按需（仅支持的模型显示）。
6. 点「**提交生成**」→ 右侧「当前任务」：排队中 → 生成中。
7. 状态变「**已完成**」→ 直接在页面播放，或点「下载视频」。

**耗时**：通常 1-3 分钟。可以离开页面，之后从「历史」回看。

## 二、参考生视频（图 + 视频 + 音频混搭）

上传任意参考附件即自动进入该模式（不用手动切换）。

- **参考图**（≤8MB/张）：产品图、人物图、风格图。
- **参考视频**（≤50MB/个）：运镜、动作参考。
- **参考音频**（≤15MB/个）：音色、背景音乐。

以上限以所选模型上传区标题为准（如 SeedDance 2.0：图≤9 + 视频≤3 + 音频≤3，合计≤12）。

提示词里**按上传顺序引用素材**：「以图1为产品细节参考，视频1为运镜参考，音频1作背景音乐，生成一支水果茶广告」。

## 三、首尾帧模式（与参考媒体互斥）

- 传「首帧」和/或「尾帧」图片 → 视频从首帧开始、到尾帧结束。
- ⚠️ 首尾帧和参考图/视频/音频**不能同时用**——想切换先清空当前附件。

## 四、生成完入库 / 看历史

- 「下载视频」旁的「**入库到资产库**」：把成品存进资产库复用。
- 历史列表可按提示词/时间筛选；点「查看」回填当时全部参数（模型已下线的只读展示）。
- 「请求参数」按钮可看当时实际发给模型的参数（附件已脱敏为摘要）。

## 常见异常

| 现象 | 原因 | 恢复 |
|---|---|---|
| 看不到菜单 / 进页面提示无权限 | 无 `media:gen` 权限 | 找管理员授权 |
| 「视频模型」下拉为空 | 没配视频类供应商 | 找运维配置 |
| 提示「模型不可用」 | 模型已下线 | 换下拉里其他模型 |
| 提示附件超限/类型不符 | 超模型上限或传错了上传区 | 删减/传对位置 |
| 参考视频区按钮禁用 | 公网签名通道未配置 | 找运维配置 |
| 状态「失败」+ Ark 429 | 模型方限流 | 稍后重新提交 |
| 一直「生成中」 | 模型方还在处理 | 离开页面，稍后从历史回看 |
| 提交报「余额不足」 | 积分不够 | 充值后再提交 |
