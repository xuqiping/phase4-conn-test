# 多Agent智能体平台 — 完整运行案例

> 以「代码助手」Agent为例，从登录到查看能力、编排工作流，完整走一遍系统流程

---

## 案例背景

用户 **张三** 是一名开发者，他想：
1. 看看平台里有什么 Agent
2. 了解「代码助手」有哪些技能，每个技能的具体步骤是什么
3. 用「代码助手」的技能编排一个工作流，把"代码生成"和"代码调试"串起来
4. 运行这个工作流，得到结果

## 第三步：导入Agent数据（Markdown同步）

假设管理员通过API触发同步，项目知识库目录下有如下Markdown文件：

**skills-router.md（顶层路由）：**
```markdown
# Agent 路由

## 开发工具

| Agent | 描述 |
|-------|------|
| 代码助手 | 帮助编写和调试代码 |
```

**代码助手/skills-router.md（子路由）：**
```markdown
# 代码助手 技能路由

## 代码生成

**类型:** SEQUENCE

**描述:** 根据自然语言需求生成代码

### 步骤

| 序号 | 名称 | 动作 |
|------|------|------|
| 1 | 理解需求 | LLM_CALL |
| 2 | 生成代码 | LLM_CALL |
| 3 | 代码审查 | LLM_CALL |

## 代码调试

**类型:** SEQUENCE

**描述:** 分析和修复代码错误

### 步骤

| 序号 | 名称 | 动作 |

| 1 | 分析错误信息 | LLM_CALL |
| 2 | 定位问题 | LLM_CALL |
| 3 | 生成修复方案 | LLM_CALL |
```
