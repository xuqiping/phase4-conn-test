## Task 5：授权查询 API ✅

- 已按 TDD 完成：先新增 `ClientAuthorizationTest`（3 个用例）和 `AnonymousAuthorizationTest`（5 个用例），确认红灯，再实现生产代码，再验证绿灯。

- 已新增生产代码：
  - `authorization/dto/ModuleAccess.java`：模块授权结果 DTO，包含 moduleCode、allowed、reason、expiresAt。
  - `authorization/dto/AuthorizationSnapshot.java`：登录用户授权快照 DTO，包含账号状态、设备绑定、离线缓存和模块授权。
  - `authorization/dto/AnonymousAuthorizationSnapshot.java`：匿名设备授权快照 DTO。
  - `authorization/service/AuthorizationService.java`：统一授权查询逻辑，聚合用户、权益、设备绑定和匿名试用状态。
  - `authorization/controller/ClientAuthorizationController.java`：登录用户授权查询 API。
  - `authorization/controller/AnonymousAuthorizationController.java`：匿名设备授权查询 API。
- 已新增测试：
  - `ClientAuthorizationTest.java`（3 个用例）。
  - `AnonymousAuthorizationTest.java`（5 个用例）。
- Task 5 能力：
  - `GET /api/client/authorization?deviceId=xxx`：返回登录用户授权快照。
  - `GET /api/anonymous/authorization?deviceId=xxx&fingerprintHash=xxx`：返回匿名设备授权快照。
  - 登录用户授权会检查账号状态、设备是否绑定且 active、模块权益是否 enabled 且未过期。
  - `offlineCacheMinutes = 0` 时 onlineRequired=true；大于 0 时返回 offlineUsableUntil。
  - 匿名授权支持无试用记录、全功能试用期内、过期已选免费模块、过期未选、指纹不匹配、设备禁用等场景。
