# 3.2 经典增长模型

## AARRR海盗模型（Acquisition/Activation/Retention/Referral/Revenue）

| 环节 | 核心问题 | 关键指标 | 增长杠杆 |
|---|---|---|---|
| 获客(Acquisition) | 用户从哪来？ | CAC/渠道贡献/安装量 | 渠道优化/SEO/内容/PLG |
| 激活(Activation) | 用户"Aha Moment"了吗？ | 激活率/首日关键完成率 | 新手引导/Aha缩短/价值前置 |
| 留存(Retention) | 用户还会来吗？ | 次留/7留/30留/留存曲线 | 核心循环/推送/个性化 |
| 推荐(Referral) | 用户会推荐吗？ | K-factor/NPS/分享率 | 邀请机制/社交裂变/口碑 |
| 变现(Revenue) | 能赚钱吗？ | ARPU/转化率/LTV | 定价/增值/分层 |

**局限**：AARRR是线性漏斗思维，忽略了环节间的循环反馈。[来源: Dave McClure, 2007 | 置信度:🔍高]

## RARRA（Retention-First翻转模型）

2020年后增长共识从"先拉新"翻转为"先留存"：

```
Retention(留存) → Activation(激活) → Referral(推荐) → Revenue(变现) → Acquisition(获客)
```

**为什么翻转？**
- 存量竞争时代获客成本飙升（2025年C端CAC同比+35%）[来源:QuestMobile | 置信度:📚中 | 2025]
- 没有留存的拉新=漏桶注水
- 留存好的产品，获客效率天然高（口碑+裂变）

**适用判断**：
- 0→1阶段：仍用AARRR（先获客验证PMF）
- 1→10阶段：过渡到RARRA（先验证留存）
- 10→100阶段：全面RARRA（留存优先精细化）

[来源: Gabor Papp/Reforge | 置信度:📚中]

## 增长飞轮（Flywheel Model）

**亚马逊飞轮**（Jeff Bezos, 2001）：

```
更低价格 → 更多顾客访问 → 更多卖家 → 更多选择 → 更低成本 → 更低价格（循环）
```

**飞轮 vs 漏斗**：
- 漏斗：线性，一个环节失败后续全部中断
- 飞轮：循环，每个环节强化其他环节，越转越快

**PM可用的3种飞轮**：

| 飞轮类型 | 核心循环 | 典型产品 |
|---|---|---|
| 供给侧飞轮 | 更多供给→更好体验→更多需求→更多供给 | 淘宝/滴滴/美团 |
| 社交飞轮 | 更多用户→更多内容/连接→更多互动→更多用户 | 微信/抖音/小红书 |
| PLG飞轮 | 好体验→更多使用→更多邀请→更多用户→更好体验 | Slack/Notion/Figma |

## PLG（Product-Led Growth 产品驱动增长）

**定义**：产品本身是增长引擎——用户通过试用产品获得价值，自发付费/推荐/留存，无需人工销售推动。[来源: OpenView Partners, 2018 | 置信度:🔍高]

**PLG四要素**：

| 要素 | 说明 |
|---|---|
| 免费试用/免费增值 | 让用户体验核心价值，不设付费门槛 |
| 产品内自传播 | 使用中自然触发邀请/分享（非强推） |
| 用户自助转化 | 从免费→付费的用户旅程在产品内完成 |
| 数据驱动迭代 | 基于使用数据持续优化增长路径 |

**PLG 2.0（2025-2026 AI+PLG）**：

AI正在重塑PLG范式——AI+PLG = 产品通过AI个性化体验驱动增长：
- AI自动识别用户"Aha Moment"并加速到达
- AI驱动的个性化新手引导（而非千人一面）
- AI Agent自动推荐下一步最优行动
- 使用数据+AI预测→主动触发转化 [来源:woshipm.com | 置信度:📚中 | 2026-03]

[来源:OpenView Partners "Product-Led Growth" 报告系列 | 置信度:📚中 | 2020-2024]

## 北极星+增长树

**增长树**是北极星指标的可视化拆解——从1个NSM→3-5个Input指标→每个Input再拆解到团队可执行的实验：

```
NSM(北极星) = Input1 + Input2 + Input3
                ↓        ↓        ↓
            实验A/B   实验C/D   实验E/F
```

**增长树价值**：让每个团队成员知道"我的实验在推动哪个Input、对NSM的贡献路径是什么"。

## G.02 模型对比与选型

| 模型 | 最佳阶段 | 核心优势 | 核心局限 |
|---|---|---|---|
| AARRR | 0→1冷启动 | 全链路框架清晰 | 线性思维，忽略循环 |
| RARRA | 1→10留存优先 | 存量时代最实用 | 不适合0→1 |
| 飞轮 | 10→100生态 | 自我强化可持续 | 建立飞轮需要时间和规模 |
| PLG | SaaS/工具/平台 | 低CAC高LTV | 不适合客单价高的B端 |
| 北极星+增长树 | 全阶段 | 方向对齐+可执行 | 依赖指标体系成熟度 |
