## 查端口占用 & 关闭端口（命令速查）

### Windows（本机 Win10）

- **查谁占了某端口**：`netstat -ano | findstr :8080`（最后一列数字是 PID）
- **按 PID 强杀进程**：`taskkill /PID <PID> /F`
- **看所有端口占用**：`netstat -ano`

### Linux / Mac（服务器常用）

- **查谁占了端口**：`lsof -i:8080` 或 `netstat -tunlp | grep 8080`
- **按 PID 杀**：`kill -9 <PID>`

> 📌 端口被占最常见原因：上次启动没关干净。**先查 PID 再 kill**，别瞎杀进程。
