# 变更记录（Changelog）· <项目名>

> Phase 6 产物。项目级变更日志，每次**改 / 增 / 删已有功能**追加一条。
> 让"这个功能什么时候、为什么被改成现在这样"有据可查。
> **新功能开发不记这里**（那走主链）；本表只记**对存量功能的变更**。
> **文档规模**：本文件不得超过 5000 tokens。记录过多时，按年份/季度拆分（如 `变更记录.2026.md`），本文件保留最近记录和索引。

## 记录格式

每条：日期 \| 变更类型(改/增/删) \| 变更内容 \| 原因 \| 影响范围 \| 涉及文件/文档 \| **变更规格 delta** \| 回滚 commit

> **变更规格 delta**（OpenSpec 格式）：每次变更在 `_模板.变更规格delta.md` 产出一份 delta，按 **ADDED / MODIFIED / REMOVED** 列出动了哪些需求（FR/AC）；实施完成后 delta 回写 PRD 正文（sync），delta 归档。本表「delta」列链接到那份 delta，需要需求级细节翻 delta，需要一句概括看本表。
