## 方向一「景窗扉页」——每页一扇山水窗（L2，稳健可用型）

**做法**：每个模块内容区顶部加一条 **景窗带**（高约 140px、通栏、8px 圆角绢本卡内嵌）：现代渐变山水场景（该模块专属色调的远山中景雾+一道光），文楷模块名 + 竖排/宽字距诗签落在景窗上；景窗之下内容区保持干净平板。

```
┌──────────────────────────────────────────┐
│ ╭──────────────────────────────────────╮ │
│ │  ~~远山渐变·雾·光（模块专属色）~~     │ │
│ │  知识库                    源头活水   │ │
│ │  问渠那得清如许          （竖排小字）  │ │
│ ╰──────────────────────────────────────╯ │
│ ┌─────────────┐ ┌─────────────┐          │
│ │  绢本卡内容  │ │  绢本卡内容  │          │
│ └─────────────┘ └─────────────┘          │
└──────────────────────────────────────────┘
```

- **价值**：意境一眼可见；内容区零风险（场景不碰文字区）；实现纯 CSS 渐变即可，也可后期回填 AI 生成景窗图
- **风险**：景窗带重复出现 12 次，若每页构图雷同会审美疲劳 → 要求每模块色相/山形走向不同
- **成本**：低（CSS 渐变版 1 天；AI 图版另加资产一轮）
- **适用**：求稳、求快、内容密度高的页面（admin 13 页同用此方案）

## 方向二「雾中浮岛」——整页即景，内容浮于雾上（L3，品牌签名型）★推荐

**做法**：每模块**整页背景**是一幅极简现代山水场景：天际渐变（模块专属色）+ 底部远山剪影 + 晨昏雾层缓漂；所有绢本卡像浮在雾上的岛，卡片带 8px 柔影与 90% 实底（保对比度）；页头诗签以竖排小字落在页面右缘（如画卷题跋）；滚动时场景固定（background-attachment: fixed 等效），内容从雾上滑过。

```
┌──────── 天际渐变（模块色，极淡） ────────┐
│                    ┊ 竖排诗签             │
│  ╭─────────╮  ╭─────────╮                │
│  │ 浮岛卡1  │  │ 浮岛卡2  │   ← 90%实底   │
│  ╰─────────╯  ╰─────────╯                │
│ ～～～ 雾层缓漂 ～～～                     │
│ ▓▓ 远山剪影（底部，opacity 8%）▓▓          │
└──────────────────────────────────────────┘
```

- **价值**：真正「缥缈空灵」——每页就是一幅现代山水；浮岛卡天然解决内容可读性；滚动时景不动人动，有「人在画中游」的纵深
- **风险**：① 12 个场景要管一致性（用同一套「天际-远山-雾」参数化生成，只变色相与山形种子）；② 对比度要逐页脚本核验（卡片 90% 实底是红线）；③ 旧三主题必须完全不受影响（全部挂 ink 主题门控）
- **成本**：中（场景纯 CSS 渐变参数化；雾层复用现有资产；预计 2 天含逐页调校）
- **适用**：用户侧 11 模块全量；admin 13 页用淡版（场景 opacity 减半，保信息密度优先）

## 方向三「一色一境」——抽象色彩场 + 印章诗签（L1.5，实验先锋型）

**做法**：不画山水，每模块把专属传统色做成**大面积色场渐变**（从页顶 40% 高度晕染到无），配宽字距文楷诗签 + 该模块小印章（朱砂方戳，内刻模块意象单字：溪/书/影/画/剪/白/藏/泉/集/音/亭/星）；内容平板。最接近高端时尚杂志的「留白+一个色」语言。

- **价值**：最高级、最现代、最克制；实现最简单；性能最好
- **风险**：**没有山水画面**——用户已明确要「高山流水缥缈」的画面感，抽象色场可能再次被判「感觉不到」；单字印章需要 12 个篆刻小资产
- **成本**：低-中（印章资产一轮 + CSS）
- **适用**：作为方向二的降级预案（性能模式/reduced-motion 下退到色场）
