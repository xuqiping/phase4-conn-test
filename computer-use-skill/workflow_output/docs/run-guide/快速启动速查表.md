## 启动步骤
```bash
cd "d:/AI Projects/AI-Projects/computer-use-skill"
npm install
npm run build          # tsc + 拷贝 uia.ps1（自动带 UTF-8 BOM）
node dist/index.js     # 即 MCP Server（宿主 Agent 以 stdio 启动它）
```
接入 Claude Code（.mcp.json 片段）：
```json
{ "mcpServers": { "computer-use": { "command": "node", "args": ["d:/AI Projects/AI-Projects/computer-use-skill/dist/index.js"] } } }
```
技能：复制 skill/SKILL.md → .claude/skills/computer-use/SKILL.md

## 端口占用速查
**无端口**（stdio）。PowerShell 子进程随 Server 生命周期自动启停。

## 查进程 & 关闭
```powershell
# 查 Server / PS 工作进程
Get-Process node,powershell | Where-Object {$_.StartTime -gt (Get-Date).AddHours(-1)}
taskkill /IM node.exe /F   # 慎用（会杀所有 node）；建议按 PID
```

## 常见启动报错速查
| 报错 | 原因 | 处置 |
|---|---|---|
| uia.ps1 中文乱码/解析错误 | dist 里 uia.ps1 丢了 BOM | 重新 `npm run build`（build 内置拷贝）|
| 输入无效/截图空白 | **屏幕锁定** 或目标最小化 | 解锁屏幕；工具会自动还原最小化窗口 |
| CONFIRMATION_REQUIRED | 白名单未放行 | 属正常安全流，confirm_app 放行 |
| TARGET_BLOCKED | 目标是终端/宿主自身 | 安全设计，不可绕过 |
| APP_NOT_FOUND | 应用没开 / 标题不含关键词 | 先启动应用，用窗口标题关键词 |
