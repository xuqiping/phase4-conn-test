## 功能清单

### ✅ 功能 1: 共享工具函数
**文件位置**: `src/utils/file.ts`

**功能说明**:
- `deriveIconFromExt(filename)` — 根据文件扩展名自动推断图标类型
  - `.doc/.docx` → word 图标
  - `.xls/.xlsx` → excel 图标
  - `.png/.jpg/.jpeg/.gif` → image 图标
  - `.js/.ts/.py/.java` → code 图标
  - 其他 → file 图标
- `resolveGroupId(currentGroupId, customGroupId)` — 智能解析分组 ID
  - 当前在"全部"或"最近"时自动切换到自定义分组
  - 其他情况保持当前分组

**单元测试**: ✅ 10 个测试全部通过 (`src/utils/__tests__/file.test.ts`)

**测试方法**: 
这是底层工具函数，其他功能会自动使用。可以通过添加不同类型的文件来观察图标是否正确显示。

**测试结果**:
- [ ] 图标自动匹配正确
- [ ] 分组 ID 解析逻辑正确

### ✅ 功能 4: EditFileDialog 编辑对话框
**文件位置**: `src/components/EditFileDialog.vue`

**功能说明**: 
完整的文件元数据编辑对话框，支持修改图标、名称、标签、分组
**测试步骤**:
1. 右键点击任意文件
2. 选择 **"编辑信息"**
3. 在弹出的对话框中测试：
   - **图标选择器**: 点击不同图标类型（文件、文件夹、图片、代码、文档、设计）
   - **名称**: 修改文件显示名称（最多 255 字符）
   - **路径**: 只读，带锁图标，无法修改
   - **标签**: 
     - 点击 "+ 添加" 按钮
     - 输入标签名（最多 20 字符）
     - 按回车或失焦确认
     - 点击标签上的 × 删除
     - 最多添加 10 个标签
   - **所属分组**: 下拉选择目标分组
4. 点击 **"保存"** 或 **"取消"**

**预期结果**:
- 所有修改立即生效并显示在列表中
- 路径字段灰色不可编辑，带锁图标
- 标签输入支持回车/失焦/ESC 键
- 标签数量限制为 10 个
- 关闭对话框后数据持久化到 localStorage

**测试结果**:
- [ ] 图标选择器工作正常
- [ ] 名称修改生效
- [ ] 路径字段只读
- [ ] 标签添加功能正常
- [ ] 标签删除功能正常

### ✅ 功能 6: 搜索关键词高亮
**文件位置**: 
- `src/utils/highlight.ts` (高亮工具函数)
- `src/App.vue` (应用高亮到视图)

**功能说明**: 
在搜索框输入关键词时，匹配的文本会用黄色背景高亮显示

**测试步骤**:
1. 在顶部搜索框输入关键词（例如 "test"）
2. 观察网格视图和列表视图中的高亮效果：
   - **网格视图**: 文件名中的匹配部分
   - **列表视图**: 文件名和路径中的匹配部分
3. 测试特殊字符（例如 `(test)` 或 `<script>`）
4. 测试大小写不敏感（输入 "TEST" 也能匹配 "test"）
5. 清空搜索框，检查高亮是否消失

**预期结果**:
- 匹配的文本用黄色背景高亮（浅色模式：`bg-yellow-200`，深色模式：`bg-yellow-800`）
- HTML 特殊字符被正确转义，不会导致 XSS 漏洞
- 正则表达式特殊字符被正确转义
- 大小写不敏感匹配
- 空搜索词时不显示高亮

**单元测试**: ✅ 6 个测试全部通过 (`src/utils/__tests__/highlight.test.ts`)

**测试结果**:
- [ ] 网格视图高亮正常
- [ ] 列表视图高亮正常
- [ ] 大小写不敏感匹配
- [ ] 特殊字符正确转义
