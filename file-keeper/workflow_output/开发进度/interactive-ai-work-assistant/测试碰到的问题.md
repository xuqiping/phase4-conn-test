- 3.2 [已解决] 我今天给他勾上了，也就是今天完成了，第二天会自动取消勾选吗？另外这个勾选，我可以通过跟聊天软件LLM的交互，来实现的吗（比如我说完成了，会自动勾选上吗）
  - 结论：
    - 第二天会自动取消勾选。后端 `fixed_work_completions` 表按 `(item_id, completion_date)` 记录每日完成状态，新的一天没有记录即视为未完成。
    - 已增强聊天 NLP，支持通过飞书/钉钉/企业微信/Slack 说出以下语句自动完成固定任务：完成xxx、做完了xxx、搞定了xxx、标记完成xxx、标记xxx为完成、把xxx标记为完成、将xxx标记完成、xxx标记为完成、xxx完成了、done with xxx、finish/finished/completed xxx。
    - 仅说“我完成了”等没有任务名的消息会保持 unknown 待确认，避免误操作。
  - 改动文件：`server/src/main/java/com/superprogrammer/workreport/service/NlpIntentService.java`、`server/src/test/java/com/superprogrammer/workreport/service/NlpIntentServiceTest.java`
  - 验证：`mvn test -Dtest=NlpIntentServiceTest,InboundMessageServiceTest` 通过。
