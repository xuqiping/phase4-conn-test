
# 居民审核搜索脚本

## 项目说明
本项目包含使用 Playwright 自动化操作天翼智慧社区系统的 Python 脚本。

## 文件说明
- `居民审核搜索.py` - 基础版本的自动化脚本
- `居民审核搜索_完善版.py` - 增强版本的自动化脚本（推荐使用）
- `居民审核自动审核.py` - **自动循环审核脚本（新增！）**
- `requirements.txt` - Python 依赖包列表
- `README.md` - 本说明文件

## 重要提示 - 连接到9333端口浏览器

所有脚本现在都使用连接到9333端口的浏览器模式！

### 如何启动浏览器并监听9333端口

#### Windows - Chrome/Edge
```cmd
# Chrome
chrome.exe --remote-debugging-port=9333

# 或 Edge
msedge.exe --remote-debugging-port=9333
```

#### Windows - 带用户配置目录（推荐）
```cmd
# Chrome
chrome.exe --remote-debugging-port=9333 --user-data-dir="C:\temp\chrome-profile"

# 或 Edge
msedge.exe --remote-debugging-port=9333 --user-data-dir="C:\temp\edge-profile"
```

#### 提示
- 启动浏览器后，**先手动登录**天翼智慧社区系统
- 然后再运行Python脚本
- 脚本会自动连接到已打开的浏览器

## 安装步骤

### 1. 安装 Python 依赖
```bash
pip install -r requirements.txt
```

### 2. 启动浏览器（重要！）
按照上面的"重要提示"部分启动浏览器并登录系统

### 3. 运行脚本

## 使用方法

### 运行基础版本
```bash
python 居民审核搜索.py
```

### 运行完善版本
```bash
python 居民审核搜索_完善版.py
```

### 运行自动循环审核版本（新增！）
```bash
python 居民审核自动审核.py
```
- 每隔5秒自动检查是否有未审核记录
- 如果有记录，自动全选并批量审核
- 如果没有记录，继续等待下次检查
- 按 Ctrl+C 可退出程序

## 脚本功能

### 基础版本功能
1. 连接到9333端口的浏览器
2. 访问目标网址（如已登录会自动使用现有登录状态）
3. 点击状态下拉框
4. 选择"未审核"选项
5. 点击搜索按钮
6. 显示搜索结果

### 完善版本功能
1. 连接到9333端口的浏览器
2. 访问目标网址（如已登录会自动使用现有登录状态）
3. 点击状态下拉框
4. 选择"未审核"选项
5. 点击搜索按钮
6. 显示搜索结果
7. 点击全选复选框（选中所有未审核记录）
8. 点击批量审核按钮
9. 在弹窗中确认批量审核操作
10. 完成批量审核

### 自动循环审核版本功能（新增！）
1. 连接到9333端口的浏览器
2. 访问目标网址（如已登录会自动使用现有登录状态）
3. **每隔5秒自动检查一次未审核记录**
4. 如果有未审核记录：
   - 点击全选复选框
   - 点击批量审核按钮
   - 在弹窗中确认批量审核操作
   - 完成批量审核并记录审核数量
5. 如果没有未审核记录：
   - 跳过审核，继续等待
6. **持续循环运行，直到手动停止（Ctrl+C）**
7. 显示累计审核数量和运行统计

## 注意事项
- **必须先启动浏览器监听9333端口并手动登录系统**
- 脚本不会关闭浏览器，只会断开连接
- 如遇到问题，请检查网络连接
- 按 Ctrl+C 可退出程序
- 批量审核操作会将选中的记录审核通过
- 自动审核版本会持续运行，建议在需要时启动

## 故障排除

### 连接9333端口失败
如果看到"连接失败"错误，请确保：
1. 浏览器已使用 `--remote-debugging-port=9333` 参数启动
2. 没有其他程序占用9333端口
3. 防火墙没有阻止连接

### 页面加载超时
1. 检查网络连接
2. 确认网址正确
3. 检查浏览器是否已登录系统

### 其他问题
1. 确认已正确安装 Playwright
2. 检查 Python 版本是否为 3.7 或更高
3. 查看错误提示信息进行排查
