# 4.3 流失预警清单

## 流失预警规则配置表

### 按产品类型的默认预警规则

| 产品类型 | 低活跃预警 | 沉默预警 | 流失判断 | 续费风险预警 |
|---|---|---|---|---|
| 日活型(社交) | 连续3天未登录 | 连续7天未登录 | 连续14天 | — |
| 中频型(电商) | 连续10天未访问 | 连续21天未访问 | 连续30天 | — |
| 低频型(SaaS) | 月活跃<2次 | 连续30天未使用 | 连续60天 | 到期前14天使用<2次 |
| 订阅型(视频) | 月观看<3次 | 连续14天未打开 | 到期未续 | 到期前7天使用<1次 |

### 行为维度预警

| 指标 | 预警阈值 | 预警等级 | 干预方式 |
|---|---|---|---|
| 登录频率 < 历史50% | 近7天vs近30天均值 | 🟡中 | Push/邮件 |
| 核心功能 < 历史40% | 近7天vs近30天均值 | 🔴高 | 个性化功能引导 |
| 会话时长 < 历史50% | 近7天vs近30天均值 | 🟢低 | 内容推荐 |
| 负面行为 ≥ 2次 | 投诉/退款/差评 | 🔴高 | 客服主动联系 |
| 功能使用种类减少 | 从5种→2种 | 🟡中 | 新功能推送 |

## 干预策略矩阵

```
流失风险 ─────────────────────────────
  高       │ 1对1客服  │ 专属优惠  │ 大力召回
  中       │ 邮件/内信 │ 限时权益  │ Push触达
  低       │ 产品内引导 │ 内容推荐  │ 社交触发
           ─────────────────────────────
             D0~D3       D7~D14     D30+
                    用户生命周期
```

### 具体干预模板

| 干预类型 | 触发条件 | 模板 | 预期效果 |
|---|---|---|---|
| Push | D1未回访 | "你错过了今日推荐！" | 回访率提升10~15% |
| 邮件 | D7未回访 | "你的X还在等你，今天回来领XX" | 回访率5~8% |
| 短信 | D14未回访 | "[品牌名] 你有一份专属优惠即将过期" | 回访率3~5% |
| 客服 | 付费用户流失风险 | 1对1电话/微信联系 | 挽回率20~30% |
| 优惠 | 流失边缘 | 7折优惠/积分翻倍 | 促活15~20% |
| 社交 | 好友召回 | "你的好友XX邀请你回来" | 回访率8~12% |

## 留存监控看板设计

### 必看指标（首页级）

| 指标 | 说明 | 告警阈值 |
|---|---|---|
| D1留存率 | 新用户次日回访率 | < 历史均值-5pp |
| D7留存率 | 新用户7日回访率 | < 历史均值-3pp |
| D30留存率 | 新用户30日回访率 | < 历史均值-2pp |
| DAU/MAU比 | 日活/月活的比值 | < 30%（低粘性信号） |
| 周留存趋势 | 最近4周D7留存走势 | 连续2周下降 |

### 分群监控（二级页面）

| 看板 | 说明 | 检查频率 |
|---|---|---|
| 渠道留存看板 | 按渠道的D1/D7/D30 | 每周 |
| 版本留存看板 | 按App版本的留存对比 | 每个版本发布后 |
| 功能留存看板 | 核心功能的D1/D7留存 | 每月 |
| 流失漏斗看板 | 活跃→低活跃→沉默→流失 | 每日 |

### 告警机制

```
指标异常(低于阈值)
  → Slack/飞书群通知
  → 自动生成异常报告(哪个指标+哪个群组+变化幅度)
  → 指定负责人跟进
```
