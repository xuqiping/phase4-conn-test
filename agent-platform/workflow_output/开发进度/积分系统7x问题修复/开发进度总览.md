## 关键技术坑（已规避）
- PG `deleted` INTEGER 列不能用 `= false`（全仓 grep 只有 LlmProviderMapper 一处）
- taskType 不可靠（IMAGE2VIDEO 被重载），hasReference 必须从 attachments kind 判
- 首尾帧参考图（kind=image）不算参考视频
- fallback 只回退 false 行，不无限兜底（只配 true 没配 false → 无参考报错）
- Canvas 审计字段 hydrate 后必须保留（pollVideoTask + hydrateVideoPreviews 两处）
- 推送参数已脱敏落库，无需新 DB 列
