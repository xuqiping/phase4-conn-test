# D-18.01 商业模式

## 是什么

**商业模式（Business Model）**：描述企业如何创造价值、传递价值并捕获价值的整体逻辑框架——回答"产品靠什么赚钱、赚谁的钱、赚多少、可持续吗"。对产品经理而言，商业模式是产品战略的商业化落地，决定产品形态、用户路径、增长引擎与盈利可持续性。本叶子聚焦数字化产品（尤其SaaS/B端/AI原生产品）的主流商业模式选型与设计，涵盖订阅制、免费增值、交易抽佣、广告变现、买断授权五大经典模型，以及用量计费、成果计费、AI原生混合模式等前沿变体。 [来源:商业模式画布理论/数字化产品实践 | 置信度:📚中]

**五种经典商业模式**：
- **订阅SaaS（Subscription）**：按周期（月/年）付费使用，经常性收入（MRR/ARR），适合持续服务、高复用价值的产品
- **免费增值（Freemium）**：基础功能免费+高级功能付费，靠免费流量漏斗筛选付费用户，适合边际成本低、网络效应/PLG型产品
- **交易抽佣（Marketplace/Take Rate）**：平台撮合交易，按成交额抽成，适合双边市场、平台型产品
- **广告变现（Advertising）**：产品免费/低价，靠流量卖广告，适合C端高频、注意力密集型产品
- **买断授权（License/Perpetual）**：一次性付费买断使用权（含私有化部署），适合工具型/重数据安全的产品

[来源:数字化商业模式分类 | 置信度:📚中]

## 核心要素

| 要素 | 说明 | 兺例 |
|---|---|---|
| **价值主张与收费点对应** | 用户为什么付费 = 用户获得的核心价值。收费点必须锚定在"不可替代的核心价值"上 | Notion按协作席位收费=协作价值；Snowflake按存储计算用量收费=数据计算价值 |
| **收入模型（怎么收）** | 收费方式：订阅/按量/抽佣/买断/混合；计费单位：席位/用量/功能/成果 | Figma按席位订阅；Twilio按API调用次数；App Store按交易抽佣30% |
| **客户与付费方** | 谁是用户、谁是付费方（C端用户付费/B端企业付费/三方 advertiser付费/平台双边） | 抖音用户免费→广告主付费；钉钉企业付费；淘宝买家免费→卖家付费 |
| **单位经济（Unit Economics）** | LTV（用户生命周期价值）vs CAC（获客成本），LTV/CAC≥3为健康，回收期<12个月为优 | SaaS订阅LTV/CAC基准3-5；交易抽佣看GMV与take rate |
| **增长引擎匹配** | 商业模式与增长引擎必须匹配：PLG/SLG/MLG/CLG不同打法对应不同收费模式 | Freemium+PLG；订阅+SLG（销售驱动）；交易+MLG（市场驱动） |
| **可防御与可扩展** | 商业模式的护城河（转换成本/网络效应/规模经济）与边际成本结构决定能否做大 | 订阅靠转换成本防御；平台靠网络效应；买断边际成本高难规模化 |
| **商业模式画布9要素** | 客户细分/价值主张/渠道/客户关系/收入流/关键资源/关键活动/关键合作/成本结构——全局自检工具 | 用画布诊断商业模式完整性 |
| **商业模式与产品形态耦合** | 收费模式反过来约束产品形态设计：按席位→多做协作；按用量→多埋计量；按成果→多埋结果度量 | 按用量计费的产品必须内生计量能力 |

## 为什么产品经理必须懂商业模式

1. **商业模式决定产品形态设计**——按席位收费的产品必须设计协作、席位管理、权限隔离；按用量收费的产品必须内生计量、配额、计费引擎。收费模式不是"商业化最后加的层"，而是从Day 1就该锁定的产品基因 [来源:数字化产品设计实践 | 📚中]
2. **2025-2026 AI智能体正在重写SaaS按席位订阅**——AI智能体能替代多名员工重复性工作，企业付费规模与员工数挂钩的"按人头收费"逻辑面临崩塌；Klarna 2024年已考虑停用Salesforce转向AI方案，Salesforce/SAP股价因Anthropic发布AI插件能力出现明显下跌。商业模式正从"按席位订阅"向"按Agent/按成果/按用量"迁移 [来源:腾讯网/G+教育科技大会 | 🔍高 | 2026]
3. **SaaS增速放缓，客户只为"省了多少/增了多少"付费**——2025年中国企业级SaaS市场规模1860亿元，同比增长22.3%，但增速较2024年29.7%明显放缓。客户不再为"能聊天"的花哨功能买单，价值定价（Value-based）成为唯一活路 [来源:雪球/IDC数据 | 🔍高 | 2025]
4. **AI原生产品需要重新设计单位经济**——AI推理成本（Token消耗）使传统SaaS"边际成本趋零"假设失效，AI应用商业化面临效果/成本/速度不可能三角，商业模式必须把推理成本计入单位经济否则越卖越亏 [来源:知乎/AI PM商业化 | 🔍高 | 2026]
5. **商业模式选型决定生死路径**——选错商业模式的代价远高于选错功能：Freemium选错导致免费用户占满服务器却无付费转化；买断选错导致无经常性收入难以融资；交易抽佣进入时机不对导致双边冷启动失败

## 常见误区

- **误区1：商业模式=定价**——商业模式是"靠什么赚钱的整体逻辑"，定价只是其中一个收入模型的参数。混淆两者会导致只调价不调模式而治标不治本
- **误区2：照搬竞品商业模式**——竞品能跑通的商业模式依赖其产品形态/客户/规模/护城河，你未必具备同样前提；如照搬PLG但产品需要重度实施就无法自助转化
- **误区3：免费增值=免费试用**——Freemium是永久免费的基础版+付费高级版（漏斗逻辑），Free Trial是限时全功能试用（体验逻辑），两者获客与转化机制完全不同
- **误区4：订阅一定优于买断**——订阅适合持续迭代/高复用价值产品；工具型/数据安全敏感/低频使用产品买断更合理；强推订阅可能导致"订阅疲劳"用户流失
- **误区5：AI产品直接套用SaaS订阅**——AI推理成本使纯订阅难以覆盖用量差异（重度用户亏损），需采用订阅+用量混合或纯按量计费
- **误区6：先做产品再想商业模式**——商业模式决定产品形态与计量能力，事后加计费/计量/席位体系成本极高且体验割裂
