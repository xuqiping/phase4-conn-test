# 已解决（2026-08-14）
- 视频加载缓存 ✅ 两层：
  - 后端 `/api/media/tasks/{id}/download` 加 `Cache-Control: no-cache, private` + `ETag`（fileId+size）——浏览器可存 body 但每次 If-None-Match 回源再验证，未变化返 304 零 body（实测 2.9MB 视频二次请求 304）；请求仍进控制器，@AuditLog 下载审计不打折。变化场景安全：任务结果文件不可变（重新生成=新任务新 id 新 URL），文件内容/大小变化则 ETag 变、缓存自动失效
  - 前端 `fetchVideoBlob/fetchMediaBlob` 增加会话内 LRU blob 缓存（6 条/256MB 上限）——切任务/翻页不重复下载；缓存 Blob 而非 objectURL，调用方 revoke 语义不变
- 入库资产库按钮 ✅ 成功播放区新增「入库到资产库」按钮、历史行成功任务新增「入库」按钮 → `SaveVideoToAssetDialog`（选项目/名称/描述）→ 后端 `POST /assets/from-media` 扩展 `mediaKind=VIDEO`（按 result_file_id 建 VIDEO 资产 v1，复用 loadForDownload 归属/终态咽喉）→ 入库成功弹「前往资产库」一键跳转。图片入库老路径不带 mediaKind 完全兼容（回归通过）
