# 开发进度1 · 无限画布创作页（LibTV 式）· Phase 2 计划

> 受众：A 技术类。本轮 = Phase 2 出总计划 + 调研 + 决策落锁。未进 Phase 3（卡许可闸门）。
> 主 plan：[../../docs/plans/无限画布创作页.plan.md](../../docs/plans/无限画布创作页.plan.md)
> 需求来源：客户本轮需求第 11 项（[1_客户本轮需求.md](../../客户需求文档迭代/1_客户本轮需求.md)）

## 本轮做了什么

1. **读需求**：客户本轮需求 15 项，第 11 项「无限画布」（视频截取 + 抽帧首尾/指定秒）为本次目标。第 8（剧本/资产库）/9（剪辑）/10（图片模型）相关但另立 plan。
2. **联网调研 LibTV + 开源**：
   - LibTV = 无限画布 + 节点式工作流 + 双入口（人类/Agent）；5 类基础节点（文本/图片/视频/音频/脚本）；自由连线/打组保存/一键重跑；焦点编辑（图上提元素）；故事板剪辑；内置抽帧/截取/补帧；20+ AI 能力（角色三视图/多机位 9 宫格/剧情推演四宫格）。
   - 开源对照：NodeTool（画布+时间线+草图，多模态，github `nodetool-ai/nodetool`）/ Franklin Canvas（画布+Agent，`BlockRunAI/franklin-canvas`）/ tldraw workflow starter kit / ComfyUI（节点图非自由画布）/ Krea、Higgsfield（商业）。
   - 画布底座候选：React Flow / tldraw（tldraw 是白板，React Flow 是节点图）。
3. **摸本项目代码结构**（Explore agent）：media 包 16 文件齐全（MediaGenProvider/MediaGenTaskService/Worker/StorageService/Controller 全在）；@vue-flow/core ^1.41.5 已装（工作流编辑器在用）；tldraw 未装且 React 仅；零抽帧能力（无 ffmpeg/javacv）；无生图 provider（只视频）；migration 最高 V54；FileStorageService/LlmGateway 可复用。
4. **写主 plan**：[无限画布创作页.plan.md](../../docs/plans/无限画布创作页.plan.md)。FR IC-1..IC-16 全覆盖；6 阶段 14 chunk；跨切（坑/安全/性能/联动/运维）全过；零回归（新 canvas 包/新表/新池/新路由，只读复用 media/FileStorage/LlmGateway）。
5. **3 决策落锁**（调研后偏离初选，已写进 plan 决策记录 + 与用户确认）：
   - 画布底座：~~tldraw~~ → **Vue Flow**（LibTV=节点图+连线非涂鸦；tldraw=React 仅进 Vue 双运行时；Vue Flow 已装团队在用）。用户确认要「LibTV 式节点创作流（A）」非「自由白板（B）」。
   - 抽帧库：**javacv/bytedeco**（纯 Java 无系统依赖；sidecar 禁 subprocess 故走后端）。
   - 图片节点：**MVP 先上传/衍生/焦点编辑，AI 生图后接**（平台无生图 provider，平行子 plan，不阻塞主线）。

## 决策依据速查

| 决策 | 选 | 为什么不选另一个 |
|---|---|---|
| 画布库 | Vue Flow | tldraw 是自由涂鸦白板+React 仅；LibTV 要的是节点图，Vue Flow 已装原生 Vue |
| 抽帧库 | javacv | 系统 ffmpeg 多部署依赖；javacv 自 contained |
| 生图 MVP | 上传/衍生先行 | 平台无生图 provider；先跑通画布主线，生图 provider 平行做 |
