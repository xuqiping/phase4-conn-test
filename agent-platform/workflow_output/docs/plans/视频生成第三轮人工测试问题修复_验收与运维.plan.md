## 技术坑点与性能

| 坑点 | 规避 | 验证 |
|---|---|---|
| 50 个历史视频同时下载 | 可视区懒加载、`preload=metadata`、及时 revoke | 请求数只覆盖可见行 |
| 无限等待造成线程饥饿 | 一次查询即归还线程，`locked_until` 表示下次查询时间 | 永久 RUNNING 时新任务仍处理 |
| 瞬时查询失败误终态 | 传输异常退避重试，仅 Provider 明确终态才失败 | 断网恢复后任务成功 |
| 附件列表 N+1 | 只解析任务 JSONB；预览由前端按需取 | 列表 SQL 数固定 |
| 提示词特殊字符 | 参数绑定的字面子串匹配 | `%_引号` 正常筛选 |
| 旧任务字段不全 | VO/前端逐字段默认、名称按类型序号兜底 | 旧记录可打开 |

## 功能联动点

| 触发 | 联动对象 | 预期 | 边界 |
|---|---|---|---|
| 改筛选 | 历史/预览 | 重查并释放旧 URL | 清空恢复；无结果空态 |
| 点击历史 | 当前任务/表单/附件/轮询 | 参数恢复，运行中继续轮询 | 模型下线只读；失权占位 |
| 插入首个 chip | 光标/候选 | 第二次 @ 仍可用 | 多行、中文、删除 chip |
| Provider RUNNING | DB 锁/线程 | 延后再查并归还线程 | 网络异常同样重试，不释放 inflight |
| Provider SUCCEEDED | 下载/计费/历史 | 落盘扣费并显示视频 | 下载失败保留 DOWNLOAD_FAILED |
| Provider 准备发送 | 请求快照/详情面板 | POST 前保存脱敏快照，页面可查看复制 | POST 失败也保留本次实际尝试参数；旧任务明确无快照 |
| 页面/节点销毁 | 本地轮询/objectURL | 停轮询并释放 URL | 后端任务继续运行 |

## 运维考量

| 类目 | 做/不做/后续 | 说明 |
|---|---|---|
| 可观测性 | 做 | 记录查询状态、下一次查询时间、连续传输错误；metric 不带 taskId/userId |
| 配置开关 | 做 | 保留退避起始/封顶和传输超时；删除业务任务超时开关 |
| 可回滚 | 做 | 不改表；按 chunk commit，可独立回滚 |
| 限流/降级 | 做 | 退避封顶控 Provider QPS；预览失败降级文字 |
| 运维入口 | 后续 | 手动重查/重下 DOWNLOAD_FAILED 另立项 |
| 告警阈值 | 做 | 超长 RUNNING 只告警不失败；查询错误率/下载失败率告警 |
| 容量/性能 | 做 | limit≤100、懒加载、JSONB 解析不查附件表，无新索引 |
