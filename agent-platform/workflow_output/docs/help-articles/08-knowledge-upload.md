# 知识库：传文件前怎么准备

> 一句话：**系统能"读懂结构"的文件，回答时能告诉你"在第几页/哪一章/哪个表格哪一格"；读不懂的就当一堆文字存——能搜到，但说不清位置。**

## 一、一张表看懂

| 你传什么 | 切成什么样 | 引用能定位到 |
|---|---|---|
| PDF | 一页一条知识 | 第几页（跨页给起止页） |
| md 笔记 | 按 # 标题分章 | 哪个标题下面 |
| Word（.docx） | 按标题样式分章 | 哪个标题下面 |
| Excel | **一行数据一条知识** | 哪个 Sheet 的哪些格子（如 A5:E5） |
| 图片 | 整张图一条知识 | 原图保留可看可下载 |
| 其他（txt/html/csv/json/ppt/字幕等） | 按段落切 | 说不清位置 |

## 二、PDF 怎么准备

- 要传**文字能用鼠标选中复制**的 PDF；页数 ≤2000；别设密码。
- **扫描件（整页是照片）读不出字**——会被跳过等于白传。办法：先转成文字版，或把关键页截图按「图片」传（让 AI 看图认字）。

## 三、Word（.docx）怎么准备

- 分章必须用 Word 自带的**「标题1」「标题2」样式**（开始菜单点样式框）。只是把字加粗调大——系统不认。
- ⚠️ **第一个标题之前的文字会被扔掉**：开头别放封面引言，第一行就写标题。
- ⚠️ **Word 里的表格读不出来**：表格内容请存成 Excel 再传，或改成正文文字。
- 老的 `.doc` 先在 Word 里「另存为 .docx」再传。

## 四、Excel 怎么准备（效果最好：一行一条知识）

心法：把表当「清单」做——FAQ 问答表、设备台账、费用标准表都是好例子。

- **第 1 行必须放列名**（如 `问题 | 答案`），后面每行一条完整数据。
- 一个 sheet 只放一张规整表：**别合并单元格、别搞两级表头、别在上面加大标题行**。
- 上传时可勾选只导入部分 sheet；隐藏的、空的 sheet 自动忽略。
- 公式格只取「上次保存时的计算结果」，不会重算。
- 超限会缩水（有告警）：列超 10 列换一种存法；单格超 200 字截断；单 sheet 超 5000 行截断。

## 五、图片怎么准备（二选一）

1. **自动识图**：AI 看图，把图里的文字和图表结构写成描述（需管理员配好视觉模型）。
2. **手填描述**：自己写一段「这张图是什么」（不能为空）。

原图一直保留，可下载、引用时能回显。

## 六、不想传文件：直接粘贴文字

知识库 → 文档管理 →「**直接输入文本入库**」→ 标题可空（默认取首行），正文 ≤4000 字 → 提交。和上传走一样的流程。

## 七、传完之后（所有格式一样）

1. 自动走：解析 → 生成摘要 → 向量化 → 建索引。
2. 文档状态变「**已索引**」= 可以被检索和问答引用了。
3. 状态显示「**已隔离**」= 内容疑似提示词注入攻击被自动隔离（不进索引）；觉得误判找管理员解除。
4. 超长文档默认只解析前 10 万字——超大文档建议拆分后上传。

## 常见异常

| 现象 | 原因 | 处理 |
|---|---|---|
| 传完搜不到 | 状态还没到「已索引」 | 稍等，看文档状态 |
| PDF 传了等于没传 | 是扫描件 | 转文字版或按图片传 |
| Word 章节全乱 | 没用「标题」样式 | 用样式重新排版再传 |
| Excel 内容缺了 | 超列/超字/超行上限 | 拆分表格；找管理员调上限 |
