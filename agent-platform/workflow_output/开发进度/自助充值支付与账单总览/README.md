# README · 自助充值支付与账单总览

> B/C 类功能（用户+管理员都用，技术深度高）——用户地图 + 简要技术说明。
> 详情：[开发进度1.md](开发进度1.md)；原理：[../../docs/feature-map/积分计费系统.feature-map.md](../../docs/feature-map/积分计费系统.feature-map.md)「自助充值支付」节。

## 用户地图

| 角色 | 场景 | 入口 | 效益 |
|---|---|---|---|
| 普通用户 | 余额不足自助充值 | 我的钱包 →「充值」 | 不排队等管理员；30 分钟未付自动关单不扣钱；双击不双扣 |
| 普通用户 | 核对充值历史 | 我的钱包 →「充值记录」卡 | 六字段+累计条，对得上账 |
| 管理员 | 查全平台充值 | 账单总览 →「充值记录」tab | 筛选联动 Σ，一眼汇总 |
| 管理员 | 看全平台余额分布 | 账单总览 →「用户余额」tab | 合计卡+排序，回答「充了多少/还剩多少」 |
| 运维 | 支付异常兜底 | 账单总览 → 对账「支付渠道异常」 | 三节异常列表 = 人工补单线索 |

## 技术说明（一页版）

- **状态机**：payment_order PENDING→PAID/FAILED/CLOSED，全部条件 UPDATE 抢态（0 行=输家），回调重推/过期 job/用户取消三方互斥。
- **幂等**：渠道单号部分唯一索引 → 抢态 → uq_ledger_ref 三层；前端 idemKey=会话 UUID。
- **渠道 SPI**：PaymentChannelService 四方法 + Router；mock 通道 HMAC-SHA256 签名（密钥服务端持有），mock 收银台走真回调链路；Alipay/Wechat 骨架留位，填环境变量激活。
- **安全**：notify 匿名+IP 限流；金额复核；验签失败/终态后付款记安全事件+审计；prod+mock 同开启动即拒。
- **运维**：过期 job（60s×200）；对账三节异常只读不自动修。
- **DB**：V140（Flyway）；回滚块见迁移文件头。
