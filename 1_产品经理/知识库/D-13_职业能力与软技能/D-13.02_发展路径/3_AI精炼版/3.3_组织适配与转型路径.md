## 组织适配：不同组织的PM发展策略

### 1. 大厂PM

| 优势 | 劣势 | 策略 |
|---|---|---|
| 专业体系完善+职级透明 | 螺丝钉感强+晋升排队 | 利用体系学方法→深挖一个赛道→建立跨团队影响力 |
| 资源充足+数据丰富 | 决策链长+试错成本高 | 用数据做决策+小规模AB→大范围推广 |
| 转岗机会多 | 容易温水煮青蛙 | 每2-3年主动寻求新挑战/转岗 |

### 2. 中小厂PM

| 优势 | 劣势 | 策略 |
|---|---|---|
| 一人多岗+全栈锻炼 | 专业深度不足+缺乏导师 | 刻意补专业短板+外部学习+建立个人知识体系 |
| 决策链短+快速验证 | 资源有限+数据不足 | 用定性研究补定量不足+巧用免费工具 |
| 看到业务全局 | 职级模糊+晋升靠关系 | 用商业结果证明价值+主动定义职级标准 |

### 3. 创业公司PM

| 优势 | 劣势 | 策略 |
|---|---|---|
| 从0到1的完整经历 | 高不确定性+随时可能倒闭 | 选择有潜力的赛道+积攒从0到1的方法论 |
| 扁平+话语权大 | 什么都得干+容易杂而不精 | 核心能力深耕+AI工具补短板 |
| 股权/期权 | 变现不确定性 | 股权≠现金，评估创业公司的真实价值 |

## PM转型路径

### 路径1：PM → 产品总监 → VP → CPO

| 阶段 | 关键转变 | 核心挑战 |
|---|---|---|
| PM→总监 | 从"做产品"到"管产品+管人" | 管理能力+战略思维+向上影响力 |
| 总监→VP | 从"管产品线"到"管业务" | 商业判断+组织变革+董事会沟通 |
| VP→CPO | 从"管业务"到"定义公司产品战略" | CEO级战略思维+行业定义力 |

### 路径2：PM → 创业

| 前提条件 | 说明 |
|---|---|
| 行业认知深度 | 至少在一个垂直领域有专家级认知 |
| 商业闭环验证 | 不只是"有好想法"，还要验证"有人买单" |
| 人脉+资源 | 供应链/客户/投资人…创业不是光杆司令 |
| 风险承受 | 6-12个月无收入的准备 |

### 路径3：PM → 咨询/培训/IP

| 前提条件 | 说明 |
|---|---|
| 方法论资产 | 有可重复交付的框架/工具/模板 |
| 个人品牌 | 在行业有知名度=自带流量 |
| 内容能力 | 持续输出能力（文章/课程/直播） |
| 客户获取 | 知道去哪里获客、怎么转化 |

### 路径4：PM → 投资

| 前提条件 | 说明 |
|---|---|
| 行业洞察力 | 能判断哪些赛道/团队值得投 |
| 人脉网络 | 能触达好项目 |
| 财务素养 | 看懂商业模型+估值逻辑 |
| 心理准备 | 投资是"概率游戏"→90%项目会失败 |

## 职业发展时间线参考

| 年限 | 阶段 | 核心任务 | 关键决策 |
|---|---|---|---|
| 0-2年 | 探索期 | 多尝试、打硬技能基础 | 选赛道方向 |
| 3-5年 | 定位期 | 深耕一个赛道、建立专业标签 | B端/C端/AI？大厂/创业？ |
| 5-8年 | 加速期 | 从执行→定义、建立影响力 | 管理线vs专家线？是否创业？ |
| 8-12年 | 突破期 | 从产品→商业/战略、定义行业 | 创业/VP/IP/投资？ |
| 12年+ | 成熟期 | 复利积累、选择长期方向 | 长期在哪个领域创造价值？ |
