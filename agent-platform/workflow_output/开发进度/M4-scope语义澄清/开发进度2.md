## 关键决策
- 记忆模式用 3 态下拉(跟随全局/本会话开/本会话关),「跟随」按钮并入「跟随全局」选项 → 少一个图标的认知负担。
- n-select 的 `value` 不收 boolean(类型 `string|number`):总记忆开关用 `'on'/'off'` 字符串 + `@update:value` 回写 boolean。坑:tsc 报 `Value` 类型不匹配。
- 动作入口(项目/记忆)保留为按钮但去文字 + circle + 图标:它们是「打开抽屉/弹窗」的导航动作,塞下拉语义不通;用户已确认(方案 B)。
