## 是什么

安全合规是产品经理在处理数据出境、网络安全等级保护（等保）和AI生成内容安全时必须遵守的法律法规与技术标准体系。它从"技术防护"和"内容治理"两个维度划定了产品安全的法律底线——违反不只是罚款，更可能面临产品下架、业务暂停乃至刑事责任。

核心知识域（3层）：
- **数据出境层**：数据出境安全评估 / 标准合同（SCC）/ 个人信息出境认证三条路径 / 自贸区负面清单制度 / 关键信息基础设施数据本地化
- **等保合规层**：网络安全等级保护2.0五级体系 / GA/T 2380-2026数据安全新规 / 定级-备案-建设-测评-整改全流程 / 关键信息基础设施保护（CIIO）
- **AI内容安全层**：GB 45438-2025强制标识标准 / 《人工智能生成合成内容标识办法》 / 深度合成内容治理 / AI虚假信息专项治理
