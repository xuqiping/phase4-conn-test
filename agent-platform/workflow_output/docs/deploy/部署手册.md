> 本地开发见 [快速启动速查表](../run-guide/快速启动速查表.md)。

## 一、服务器环境要求
- **OS**：Windows Server 2019 (build 17763) x64；同内核 Win10 (19045) 可直接迁移。
- **CPU/内存**：建议 ≥4 核 / ≥8G；JVM `-Xms512m -Xmx2g`。
- **编码**：DB 必须 UTF8（`SHOW server_encoding`）。
- **网络**：LLM API 全国内（Doubao/DeepSeek/GLM/Kimi），无需代理；GitHub 代理 127.0.0.1:7890 仅构建期。

## 三、傻瓜式部署步骤

### Step 0 · 准备服务器
- [ ] 系统更新；装 VC++ 2015-2022 x64 Redistributable；防火墙放行 80/443/8080/8090/5432/6379（按需内网）。

### Step 1 · PostgreSQL + pgvector
- [ ] 装 EDB 16.x，记 superuser 密码；端口 5432、编码 UTF8。
- [ ] pgvector：停服务 postgresql-x64-16 → 解压 zip 覆盖到 `<PG>\lib` 与 `<PG>\share\extension` → 启服务 → `CREATE EXTENSION vector;` → 验证 `extversion=0.8.2`。

### Step 2 · 建库
- [ ] `createdb agent_platform`；启动 backend 让 Flyway 跑完 V1..V42（或手动按序执行迁移 SQL）。
- [ ] **先 git commit 未入库的迁移文件**，保证可追溯。

### Step 3 · Redis
- [ ] 装 WSL2 + 官方 Redis 7（首选）或 Memurai；**设密码**；`redis-cli ping` → PONG。

### Step 4 · 放码 + 构建
- [ ] `git clone` 到如 `D:\app\agent-platform`。
- [ ] backend：`mvn clean package` → `agent-platform.jar`。
- [ ] frontend：`npm install && npm run build` → `frontend\dist\index.html`。
- [ ] sidecar（若用）：`python -m pip install -r runtime-sidecar\requirements.txt`。

### Step 5 · nginx
- [ ] 托管 `frontend\dist`；反代 `/api` → `localhost:8080`、`/ws` WebSocket。

### Step 6 · 启动（注入环境变量）
- [ ] backend：`java -Dfile.encoding=UTF-8 -Xms512m -Xmx2g -jar agent-platform.jar`
- [ ] sidecar：`uvicorn app.main:app --port 8090`
- [ ] 必须注入：`DB_PASSWORD`、`JWT_SECRET`、`RUNTIME_CALLBACK_TOKEN`、`REDIS_PASSWORD`。

### Step 7 · 注册服务（NSSM 开机自启）
- [ ] 注册 `agent-platform-backend` / `-redis` / `-sidecar` / nginx；`AppEnvironmentExtra` 注入敏感变量。

## 四、配置项说明（部署必改）
文件：`backend/src/main/resources/application.yml`（占位走环境变量）。
| 配置 / 环境变量 | 生产必改 | 说明 |
|---|---|---|
| `DB_PASSWORD` | **强密码**（dev `aa64221886` 已泄露必须轮换） | spring.datasource.password，fail-closed |
| `JWT_SECRET` | **随机 64 字节 base64**（`openssl rand -base64 64`） | jwt.secret，未注入拒启动 |
| `RUNTIME_CALLBACK_TOKEN` | **随机 hex 32**（`openssl rand -hex 32`），sidecar 同值 | runtime.callback.token，fail-closed |
| `REDIS_PASSWORD` | 设密码 | spring.data.redis.password |
| `runtime.gateway.mode` | sidecar（调试用 mock） | 工作流走 sidecar |
| `-Dfile.encoding` | **UTF-8** | JVM 启动参数（Windows 默认 GBK） |
| `DINGTALK_*` | 启用时填齐 APP_KEY/APP_SECRET/AGENT_ID | dingtalk.* |

## 六、回滚方案
- **代码**：`git revert <commit>` 或 `git checkout <稳定 tag>`。
- **数据库**：Flyway 单向无回滚脚本。回滚前先 `pg_dump agent_platform` 全库备份；schema 不兼容时用备份恢复。
- **应用**：保留上一版 `agent-platform.jar` + `frontend\dist`，NSSM 指向旧路径重启（DB schema 兼容前提下）。
- **Redis**：仅缓存，重启丢失=用户重登+可见集重算，不影响主业务。
