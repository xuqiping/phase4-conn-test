## 关键技术决策（坑点对应）
- **#3 严禁 UPDATE audit_logs**：中文走 AuditLabelDictionary 显示层字典，绝不回写历史行（V90 REVOKE+V93 hash 链会断链+DB 拒绝）。
- **#4 worker 无 MDC**：媒体终态审计走 `AuditLogService.recordTask` 显式传 userId/username/clientIp（从任务行取），禁 worker 调 fromMdc。
- **#5 chat SSE AOP 坑**：不用 @AuditLog（对 SseEmitter 在 emitter 创建瞬间记，非流完成），改 ChatSessionService 单咽喉编程式。
- **#10 媒体禁 traceId 关联**：worker 是 DB 轮询异步线程零 MDC，且与 submit 不同请求不同 traceId → 用 taskId(targetId) 显式关联；chat 才用 traceId（同请求三处一致）。
- **#11 单一计算源**：chat_completed 行 token/积分复用 LlmBillingService 本帧计费值，禁二次算价；媒体 success 行积分来自 chargeMedia 返回值。
- **#12 @AuditLog firstLongArg 取不到 @RequestBody**：媒体 submit 的 taskId 在 @RequestBody 里，AOP 取不到 → 走编程式 auditSubmit。
