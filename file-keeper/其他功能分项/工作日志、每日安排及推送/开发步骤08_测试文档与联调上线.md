### 4.5 端到端联调

按以下场景逐项验证：

| 场景 | 步骤 | 预期结果 |
|---|---|---|
| 未授权访问 | 用户未被授权 work-report，打开桌面端 | Tab 置灰，点击提示未授权 |
| 授权后使用 | 管理后台授权，桌面端重新登录 | Tab 可用，可正常使用 |
| 工作记录 | 添加 3 条记录，刷新 | 记录保留，按 sort_order 排序 |
| 每日安排 | 添加待办，标记完成 | 状态更新，明日计划可切换 |
| 报告配置 | 创建日报配置，设置每天 18:00 推送 | 配置保存成功 |
| 手动生成 | 点击生成报告 | 报告内容包含工作记录和 AI 总结 |
| 飞书推送 | 配置飞书 Bot，手动推送 | 飞书群/个人收到消息 |
| 定时推送 | 等待 cron 触发 | 到点自动生成并推送 |
| 历史报告 | 查看历史列表 | 状态正确，可重新推送 |
| Git 导入 | 选择本地仓库，导入日志 | 自动生成工作记录 |
| 离线使用 | 断网，打开模块 | 本地记录可查，推送提示离线 |
