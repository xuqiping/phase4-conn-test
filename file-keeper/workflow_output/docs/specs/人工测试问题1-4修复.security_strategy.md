# 人工测试问题 1—4 修复安全策略

> 本文件补充根安全策略，仅覆盖本次桌面端本地能力。

## 1. 安全目标

- 删除收藏项绝不删除用户原文件、目录或程序。
- 快捷方式导入不执行目标，不扩大现有命令执行面。
- 收藏路径、窗口标题、分组和剪贴板内容不上传服务端。
- 悬浮球失败时始终保留可恢复应用的入口。

## 2. 快捷方式与文件安全

1. 导入 `.lnk` 仅解析元数据并复制，不自动启动。
2. 托管文件名使用随机 ID，不使用用户输入直接组成目标路径。
3. 托管目录由应用创建；删除前规范化路径并确认其直接位于托管根下。
4. 拒绝删除托管根目录、子目录、符号链接、连接点及任何越界路径。
5. 导入采用“临时文件 → 校验 → 原子重命名”，异常时清理临时文件。
6. 普通 EXE、文档和文件夹只记录路径；移除收藏只删元数据。
7. 打开收藏项复用参数化 OS API，不将路径拼入 Shell 字符串。

## 3. 快捷键安全

- 快捷键配置只表示触发哪个现有收藏项，不允许携带命令、脚本或额外参数。
- 注册前进行统一标准化，避免同义组合键绕过冲突检查。
- 快捷键触发时重新检查收藏项仍存在且路径有效。
- 日志只记录注册结果和收藏项 ID，不记录完整文件路径。

## 4. 窗口与隐私

- 窗口标题只在本机进程页展示，不上传、不写持久化日志。
- 标题按普通文本渲染，禁止使用 `v-html`，避免标题内容成为注入载体。
- 悬浮球窗口只接受应用内部事件，不加载远程 URL。
- 悬浮球右键“退出”沿用 Tauri 正常退出流程，确保监听器和快捷键释放。

## 5. 剪贴板数据安全

- 分组只保存名称和本地记录关联，不新增云同步。
- 分组名去空白、限制 40 字符、拒绝控制字符，SQL 始终使用参数绑定。
- 删除分组不级联删除剪贴板记录。
- 置顶不绕过现有敏感内容拦截和缓存配额。
- 数据库迁移前保留原文件；迁移失败不得创建半迁移状态。

## 6. 威胁与对策

| 威胁 | 对策 |
|---|---|
| 构造缓存路径删除用户文件 | 随机 ID、规范化、根目录边界和文件类型校验 |
| 恶意 `.lnk` 在导入时执行 | 导入阶段只解析和复制 |
| 窗口标题注入 HTML | 文本插值渲染，不使用 `v-html` |
| 隐藏主窗口后无入口 | 悬浮球失败降级托盘，托盘失败恢复主窗口 |
| 分组删除误删内容 | 事务内置空归属后仅删除分组元数据 |

## 7. 术语表

| 术语 | 大白话 | 简单案例 |
|---|---|---|
| 路径穿越 | 用特殊路径跳出允许目录 | `..\..\用户文件` |
| 原子重命名 | 文件要么完整出现，要么完全不出现 | 导入失败不留下半个 `.lnk` |
| 参数绑定 | 数据作为参数交给数据库而非拼 SQL | 分组名含引号也不会改写查询 |
