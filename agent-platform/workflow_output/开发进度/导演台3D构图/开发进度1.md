## 三、关键技术结论（跨会话复用）

- three r169：TransformControls 不再是 Object3D，须 `scene.add(tc.getHelper())`；Controls 有公共基类。
- scissor 遮幅必须先整帧清屏再裁剪渲染（scissor 只清框内，不清留残影）；视口 y 轴翻转（three 原点左下）。
- 截图纪律：暂存 size+pixelRatio → setPixelRatio(1) → setSize(分辨率) → render → toBlob → finally 恢复。
- VTU×naive-ui：input 值在内层 `<input>.value`（text() 拿不到）；emit 丢尾部 undefined 参数。
- happy-dom 无 WebGL：逻辑层零 three import 即可测；渲染层只走 vue-tsc+人工。
- InstancedMesh 群众用确定性 sin-hash 抖动（禁 Math.random），同数据同渲染。
