## 概述

A/B测试是从假设到结论的系统工程，不是"做个实验看看"。本SOP提供6步标准流程，确保实验结论的统计有效性和业务可落地性。

[来源:📚增长实验方法论 | 置信度:📚中]

## 6步标准流程

### Step 1：定义假设

**目标**：明确"验证什么"和"预期什么"

**模板**：
```
假设：如果我们将[变量X]从[A当前值]改为[B新值]，
那么[核心指标Y]将[提升/降低][预期幅度Z]，
因为[用户行为推理]。
```

**示例**：
- 假设：如果将注册按钮文案从"注册"改为"立即开始"，注册转化率将提升5%，因为"立即开始"降低了用户的心理门槛。

**自检**：
- [ ] 变量是否单一？（一次只改一个变量）
- [ ] 核心指标是否可量化？
- [ ] 预期幅度是否合理？（不是"提升越多越好"）

### Step 2：计算样本量

**目标**：确定需要多少用户/多长时间才能得出可靠结论

**输入参数**：
| 参数 | 说明 | 典型值 |
|---|---|---|
| 基线转化率（Baseline） | 当前版本的转化率 | 如5% |
| 最小可检测效应（MDE） | 你希望检测到的最小变化幅度 | 如1个百分点（5%→6%） |
| 显著性水平（α） | 允许的假阳性概率 | 0.05 |
| 统计功效（1-β） | 检测到真实效应的概率 | 0.80 |

**计算方法**：使用在线计算器（如Evan Miller的AB测试计算器）或统计公式。

**经验法则**：基线转化率越低、MDE越小，需要的样本量越大。5%基线、1% MDE通常需要每组约8000-10000样本。

### Step 3：设计实验

**关键决策**：
| 决策项 | 选项 | 推荐做法 |
|---|---|---|
| 分组方式 | 50/50均分 / 不等分 | 默认50/50；流量不足时可70/30（对照组/实验组） |
| 实验时长 | 固定周期 / 达到样本量即停 | 固定周期（避免周期性波动影响） |
| 实验范围 | 全量用户 / 特定用户群 | 按假设选择（如"新用户注册流程"只对新用户实验） |
| 互斥控制 | 与其他AB测试是否互斥 | 同时跑的AB测试需互斥或分层 |

### Step 4：执行实验

**操作清单**：
- [ ] 实验配置已上线，流量分配正确
- [ ] 埋点数据采集正常（实验组/对照组标识）
- [ ] 实验开始后24h内检查数据是否正常流入
- [ ] 监控异常：如果实验组指标暴跌>10%，立即检查是否有bug
- [ ] 不在实验期间中途修改实验配置
- [ ] 不在实验期间提前看结果做决策（防止"偷看偏误"）

### Step 5：分析结果

**核心分析步骤**：

1. **样本量验证**：实际样本量是否达到Step 2计算的最小样本量？
2. **统计显著性检验**：p值<0.05？（如果是→差异可信；如果否→差异可能是随机波动）
3. **效果量计算**：提升幅度是多少？（如"转化率从5.0%提升到5.8%，相对提升16%"）
4. **分群分析**：不同用户群的效果是否一致？（如新用户提升但老用户下降）
5. **副作用检查**：核心指标提升了，但其他指标是否下降？（如转化率提升但客单价下降）

**结果模板**：
```
实验名称：[名称]
实验周期：[开始日期] - [结束日期]（共X天）
样本量：对照组X人 / 实验组X人
核心指标：[指标名]
  对照组：X%（基准）
  实验组：X%（+Y%，p=0.0XX）
结论：✅实验组显著优于对照组 / ❌无显著差异 / ⚠️有显著差异但存在副作用
决策：采纳/放弃/优化后重测
```

### Step 6：决策与行动

| 实验结果 | 决策 | 后续行动 |
|---|---|---|
| 显著正向+无副作用 | ✅采纳 | 进入灰度发布流程 |
| 显著正向+有副作用 | ⚠️需评估 | 权衡核心指标提升 vs 副作用下降，做业务决策 |
| 无显著差异 | ❌放弃或优化 | 分析原因（MDE太小？样本量不足？假设错误？） |
| 显著负向 | ❌放弃 | 不要上线，分析为什么新版本更差 |

## 常见坑总结

| ⚠️常见坑 | ✅推荐做法 |
|---|---|
| 没有计算样本量就开实验 | Step 2先算样本量，算不出来就说明流量不够 |
| 实验跑了2天看到"显著"就停 | 预设实验周期，至少跑到样本量达标 |
| 只看p值不看效果量 | p值告诉你"差异是否可信"，效果量告诉你"差异有多大"——两者都要看 |
| 多次比较未做校正 | 同时测多个指标时用Bonferroni校正（α/指标数） |
| 选择性报告（只报好的指标） | 预先注册核心指标和辅助指标，所有结果都报告 |
