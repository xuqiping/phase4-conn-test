## P 系列 · 画布连线保留开关

**前置**：画布摆 A→B→C 链（A,B 相邻，C 在外）。

| # | 用例 | 步骤 | 预期 |
|---|---|---|---|
| P1 | L4 正向 | ⛓ 开（默认）框选 A,B → Ctrl+C → 鼠标移空处 Ctrl+V | 粘贴体含 A'→B' 内边 + **B'→C 跨集边**（副本接入原上下文） |
| P2 | L4 反向 | ⛓ 关 → 同样复制粘贴 | 仅 A'→B' 内边，零跨集边；无确认弹窗 |
| P3 | L4 时点判定 | ⛓ 开复制 → 切 ⛓ 关 → 粘贴 → 再切开 → 再粘贴 | 第一贴无跨集边、第二贴有（粘贴当下态生效） |
| P4 | L5 上游面板 | P1 后点 A' | 上游面板显示原 C 等外部上游，断链灰显消失 |
| P5 | L5 反向·悬挂 | 复制后删掉 C（连同其边）→ ⛓ 开粘贴 | 跨集边静默丢，无断线残留，无报错 |
| P6 | L6 批量·平行边 | ⛓ 开连按 Ctrl+V 三次 | 三份副本各带跨集边=对 C 三条平行线，可逐条点选删 |
| P7 | L6 撤回 | P6 后 Ctrl+Z 一次 | 该次粘贴的节点+全部边（含跨集）一步消失 |
| P8 | 副本门 | ⛓ 开：C 节点「创建副本」→ 数边；⛓ 关再副本 | 开=克隆全部入/出边（现状）；关=副本零边 |
| P9 | L7 占位符口径 | ⛓ 关做副本 → 看副本提示词 `@C` | 占位符仍指原 C（不重写）；上游面板可能断链灰显——重新连线恢复 |
| P10 | 组边排除 | 组员+组外节点混合框选复制粘贴 | 组边（广播/聚合）不带入粘贴体 |
| P11 | 持久化 | ⛓ 关刷新页面 | ⛓ 仍关 |
| P12 | 自动保存 | P1 后等防抖落库刷新 | 跨集边入库重现（快照就是普通边） |
