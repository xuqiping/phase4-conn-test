# 4.2 内容运营执行手册

## 一、内容矩阵规划

### Step 1：确定内容方向
- [ ] 基于产品核心价值，定义3-5个内容支柱（Content Pillar）
- [ ] 每个支柱下拆解5-10个常青话题（Evergreen Topic）
- [ ] 建立话题库（持续更新，至少储备50个话题）

### Step 2：规划内容类型与比例
| 类型 | 占比 | 更新频率 | 目标 |
|---|---|---|---|
| 引流内容（教程/盘点/热点） | 60% | 日/周 | 曝光+拉新 |
| 转化内容（案例/对比/测评） | 25% | 周 | 促活+付费 |
| 品牌内容（白皮书/纪录片） | 15% | 月/季 | 品牌建设 |

### Step 3：渠道适配
- [ ] 选择2-3个主阵地（资源有限，不做全平台）
- [ ] 每个渠道适配内容形式（公众号→深度文，抖音→短视频，小红书→图文笔记）
- [ ] 制定分发节奏（如公众号周2更、抖音周3-5更）

## 二、内容生产AIGC人机协作流程

### 流程图
```
人（选题方向+核心观点） → AI（生成初稿/多版本标题） → 人（审核+精修+注入品牌语言）
→ AI（格式适配：小红书/抖音/公众号等多平台版本） → 人（最终审核+定时发布） 
→ 数据收集 → AI（效果分析+下期选题建议） → 人（策略决策）
```

### 各环节操作清单

#### 选题阶段（人主导）
- [ ] 每月初规划当月内容日历（热点+常青+活动配合）
- [ ] 确定核心观点和品牌立场
- [ ] 输出：《月度内容日历》

#### 初稿阶段（AI辅助）
- [ ] 用AI生成3-5个标题候选
- [ ] 用AI生成文章/脚本初稿
- [ ] 用AI生成配图素材初版
- [ ] 注意：AI初稿仅作为"框架"，不可直接发布

#### 精修阶段（人主导）
- [ ] 注入品牌独特语言与观点（AI最缺的就是"独特性"）
- [ ] 核实所有事实性信息（AI"幻觉"风险）
- [ ] 调整语调/风格（确保与品牌调性一致）
- [ ] 添加个人经验/独到洞察（这是人不可替代的价值）

#### 适配阶段（AI辅助）
- [ ] 一篇长文→自动拆分为小红书笔记+抖音脚本+朋友圈短文
- [ ] 自动生成不同平台的封面尺寸
- [ ] 自动提取关键词/标签

#### 发布阶段（人审核）
- [ ] 检查格式/排版/链接/图片
- [ ] 确认发布时间（基于历史数据选最佳时段）
- [ ] 如需标注"AI辅助创作"，确认标注合规
