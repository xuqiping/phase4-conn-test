## 一、人工测试用例（P4 勾选用）

| # | 用例 | 操作步骤 | 预期结果 |
|---|---|---|---|
| H1 | 剪贴板粘贴成图节点 | 外部（截图/网页右键复制图片）→ 画布空白处 Ctrl+V | 鼠标位置出现图片节点（有产物、fileId 有值）；右上「已保存」闪现；刷新节点还在 |
| H2 | 粘贴不误伤输入框 | 选中某节点 → 提示词框内 Ctrl+V 粘文字 | 文字正常进输入框，画布不建节点 |
| H3 | 本地拖拽三分流 | 从资源管理器分别拖 1 图、1 视频、1 音频文件进画布 | 图→图片节点；视频→视频节点；音频→音频节点（来源=上传）；多文件同时拖错位排布 |
| H4 | 拖拽拒未知类型 | 拖 .txt / .zip 进画布 | toast「支持拖入图片/视频/音频」，不建节点 |
| H5 | 副本连线克隆 | 造链：图片A→视频B→视频C（B 上下游都有边）→ 选 B 创建副本 | 副本 B' 有 A→B' 与 B'→C 两条边；A→B、B→C 原边都在；B' 可独立重生成不影响 B |
| H6 | 提示词 maxlength | 视频节点提示词粘贴 9000 字文本 | 截到 8000；下方见「官方建议 ≤500 汉字/1000 英文词」浅色文案；图片节点同测（≤300 汉字/600 英文词） |
| H7 | 29MB 附件真跑 | 画布图片节点上传 29MB 图 + 填提示词 → 生成 | 上传成功（不再 8MB 报错）；任务成功；抓请求附件为签名 URL 非 base64 |
| H8 | 31MB 前端预检 | 上传 31MB 图 | 前端 toast 拒（≤30MB），不发请求 |
| H9 | 视频参数 capability 对齐 | 画布视频节点选 Cdance2.0 | 比例 7 档含 adaptive；分辨率 4 档；时长 4-15；生成音频/水印开关出现；预估联动正常 |
| H10 | 切模型收敛 | 选好 4K+21:9 后切到只支持 720p 的模型（如接入 fast 后） | 分辨率/比例自动收敛到合法档，不白屏不残值 |
| H11 | @音频引用 | 上传音频节点 → 视频节点提示词 @它 → 提交 | 提示词出现「音频N」占位；任务详情附件含 kind:'audio' |
| H12 | 回归抽测 | @图片/视频引用、上游面板、Lightbox、自动保存、独立视频页全链 | 行为与修复VI前一致 |

## 二、功能联动用例（对齐 plan 联动清单 6 条，含反向/批量）

| # | 触发→联动 | 验证点（含边界） |
|---|---|---|
| L1 | 拖/粘文件上传成功→节点+保存链 | 正向：H1/H3；失败：断网拖文件→toast 不建节点；批量：3 文件错位不重叠 |
| L2 | 焦点在输入框 Ctrl+V→输入框 | 正向：H2；反向：焦点在画布空白才建节点 |
| L3 | 创建副本→连线克隆 | 正向：H5；反向：原边一条不少；自环节点（边指向自己）副本也自环；组内节点副本不入组 |
