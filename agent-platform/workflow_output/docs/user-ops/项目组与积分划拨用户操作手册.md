# 项目组与积分划拨 · 用户操作手册

> 面向组长与成员。功能入口：侧栏「项目组」；业务入口顶栏「参与项目」下拉。

## 1. 组长：建组与划拨

**入口**：侧栏→「项目组」。

| 步骤 | 操作 | 界面变化 | 完成标志 |
|---|---|---|---|
| 1 | 点右上「新建项目组」，填组名（必填≤64字）/描述→「建组」 | 弹窗关，列表多一张卡片（标「组长」，组池 0） | 卡片出现 |
| 2 | 点卡片进详情 | 顶部组名+「组长」标签+「划拨」「回收」按钮+组池余额 | 看到余额 chip |
| 3 | 「划拨」→输积分（如 500）→确认 | 余额 chip 变 500；个人钱包 −500 | 流水 tab 多「划入 +500」行 |
| 4 | 「回收」→输积分→确认 | 组池减少、个人加回 | 流水多「回收 −N」行 |

**异常**：
- 划拨超个人余额→报错拒付，无流水。
- 回收额超「组池−在途占用」→ 被拒；在途=已提交未结算任务的估价和，等任务结算后再收。
- 组池非 0 时删组被拒——先回收清零再删。

## 2. 组长：成员管理（2026-08-21 起改为邀请制）

详情→「成员」tab→「邀请成员」：搜索用户名选人+可选限额（空=不限）→「发送邀请」。
**对方在「项目组页→我的邀请」条点「同意加入」后才真正入组**（拒绝/你撤销则邀请作废）；待处理的邀请显示在成员表上方，可随时「撤销」。

成员表每行操作：
- **调限额**：输入新值（空=改回不限）。调低不追溯已耗，只约束后续消耗。
- **重置已用**：把该成员已用归零（流水留「调整」痕），限额不变——比如按月重置额度。
- **功能开关**（2026-08-21 新增）：弹窗勾该成员可用的模块（对话/嵌入/重排/图片/视频）。默认「不限制」；取消开关后只勾部分=白名单；**一个都不勾=全禁**（界面会亮警告）。被禁后该成员在组内提交对应模块会被拦，提示「组长已限制你在本组使用该类模型（对话）」。
- **可见性**（2026-08-21 新增）：按模块给该成员单独定「跟随组默认 / 仅自己 / 全员可见」，优先级高于「设置」页的组级配置。例：组默认各自只见自己，但给某成员把「对话」设成全员可见——全组就能看到他的对话产出。全部选「跟随组默认」=清除个人配置。
- **移除**：移出项目组；历史流水与产出保留。**再次被邀请并同意时直接复活旧成员行**：已用清零、角色/开关/可见性不继承（按新成员重新开始），流水留「成员回归复活」痕。

## 2c. 组长：任免「管理」（2026-08-21 新增）

成员表「角色」列下拉（仅组长可见可操作）：成员 ↔ 管理。
- **管理能做什么**：邀请成员、审批入组申请、调限额/重置已用/移除普通成员、配置成员功能开关与可见性、查看组池流水（只读）、看全组产出。
- **管理不能做什么**：划拨/回收组池、改组设置（可见性/公共池）、任免角色、动其他管理——这些仍组长专属。
- 组长本人是唯一的「组长」角色，不可被任免；把管理降回成员随时可逆（**降职后该管理名下的成员额度统一改挂组长**，2026-08-25 起）。

## 2e. 层级额度：组长给管理定预算，管理在预算内往下分（2026-08-25 新增）

**解决的老问题**：之前把人设成管理后就无法再给他配额度。现在组长可以直接在管理行点「调额度」定预算。

**玩法**（额度=预算帽子，组池才是钱）：
1. 组长在成员表管理行点「调额度」，输入比如 **5000**——这就是该管理的预算上限。
2. 管理给成员配限额时只能从自己的预算里出：**新限额 ≤ 自己剩余可分配**。
3. **剩余可分配怎么算**（例子：管理 5000 → 分给 A 1000 → A 用了 500）：
   - 管理的总额度随下级消耗缩水：5000 − 500 = **4500**；
   - A 名下还剩 500（1000 − 500）是已分配预留；
   - 管理剩余可分配 = 4500 − 500 = **4000**。
   - 自己不用算：成员表「可分配」列、组卡片、组详情顶部、页顶「参与项目」下拉都会直接显示。
4. **管理自己消耗也占预算**（从可分配里扣，不能吃掉已预留给成员的部分）。
5. **组长调整管理预算的下限**：不能低于该管理当前已占用（子树已耗 + 下级已分配预留）——想收得更紧，先让管理下调成员限额或重置已用。
6. **注意事项**：
   - 被限额的管理给成员配额度**必须填具体数值**，不能「不限」（不限的预留无法入账）；管理自己不限额时则不受此约束。
   - 组长直接在成员行调限额 = 把该成员**改挂组长直管**（不再占原管理预算）。
   - 管理被降回普通成员后，其名下成员统一改挂组长直管。
   - 公共池审批进来的成员默认挂组长直管（不占任何管理预算）。

## 2d. 管理视角（2026-08-21 新增；2026-08-25 补可分配显示）

管理打开组详情：有「成员 / 组池流水（只读）/ 入组审批 / 产出」四个 tab，**没有「设置」tab，也没有「划拨/回收」按钮**；成员表里其他管理行只显「仅组长可任免/调额」。
- 顶部积分 chip 常显「我的额度 N · 可分配 M」；成员表「可分配」列、页顶「参与项目」下拉同样显示——随时知道自己还能往下分多少。

## 2b. 组长：产出可见性与公共池招募（2026-08-21 新增）

详情→「设置」tab：
- **成员产出可见性**：默认「各自只见自己」（成员只看自己的产出记录与图片/视频产物）；可改「成员互见全组」。下方勾选框是**例外模块**——比如只勾「对话」，则全组互见对话产出、图/视频仍各自只见自己。组长和 admin 始终全量可见。
- **公共池招募**：点「推入公共池」后，全平台用户在「项目组→公共池」看到本组并可「申请加入」（可附 200 字留言）；申请出现在详情→「入组审批」tab，你逐条「通过/拒绝」。人够了点「撤出公共池」——未审批的申请自动失效并通知申请人；同一申请人被拒后 30 天内不能重复申请。

## 3. 成员限额怎么起作用

成员在任一入口选组干活时，每次消耗先查「该成员已用+本次预估 ≤ 限额」：
- 超了→拦截提示「超出组长配置的成员积分限额」，换个人或找组长调额。
- 失败任务自动退款会把「已用」回减，余量恢复可用。

## 4. 所有角色：页顶统一选组干活（2026-08-20 更新）

入口：**每页顶部 AppHeader 右侧「参与项目」下拉**（唯一控制点，全局生效；旁边常显「组池 N」和「个人 N」两个积分徽标）。
> 旧版五个页面各有一个选择器，已收拢；原位置只留一个小标签显示当前计费去向。旧五入口各自记住的选择，打开对应页面时会自动带过来一次（全局已有选择则不动）。

| 步骤 | 操作 | 界面变化 | 完成标志 |
|---|---|---|---|
| 1 | 页顶下拉选组（个人=默认第一项） | 选项显组名+余额徽标（组长标「组长」；成员显「余 N · 限剩 M」）；多组可逐项对比余额再切换 | 页顶「组池」徽标显示该组余额 |
| 2 | 去任意页面发起对话/问答/生图/生视频/画布 | 消耗走**组池**，个人钱包不动 | 项目组页产出 tab 出现该行 |
| 3 | 切回「个人」 | 页顶「组池」徽标消失，后续请求不再带组 | 我的钱包明细行「项目组」列显「—」 |

**注意**：
- 选择全局唯一并持久化（刷新/重开浏览器仍保持）；正在编辑的画布切组后自动保存，快照记账去向跟上。
- 积分徽标随路由切换轻刷新；加载失败时徽标隐藏，不影响使用。
- 组池不足→提示「项目组积分不足」，找组长划拨。
- 被移出组后再提交→403 报错，重新选择或切回个人。

## 5. 组长：看产出与流水

详情→「产出」tab：全员消耗行（时间/成员/类型/模型/内容摘要/任务状态/积分）；筛选=成员下拉+类型+日期范围。
- **内容摘要列**（2026-08-25 修复）：对话类（CHAT）行现在显示**用户当时提问的内容**（图片/视频行仍显提示词）；无提问可关联的老数据显示「-」。不再出现清一色「对话消耗」。
- 「预览」列直接看成品：图片显缩略图（点开大图）、视频点「▶播放」弹窗播。组长全量可见；**成员能看到哪些产物由「设置」tab 的可见性决定**（默认各自只见自己）。

详情→「组池流水」tab：划入/回收/消耗/退款/调整/兜底 全记录，每行带变动后余额（链条连续可对账）。

## 6. 成员：看自己的消耗

项目组页点自己所在组卡片→直接进「产出」tab，默认只显示自己的行（可按类型/日期筛）；组长开了「互见」或勾了例外模块时可看到对应全组成员的行。普通成员看不到成员表与组流水（管理视角组长/管理专属，且管理的流水只读）。

**平台 admin 代管视角**（2026-08-25 修复）：admin 即使只是某组普通成员，点开组卡片也能进完整管理界面（成员/流水/审批/产出全 tab）——与后端「admin 恒有管理权」口径一致。此前 admin 成员只见到产出 tab，已修。

## 6b. 成员：受邀入组与申请入组（2026-08-21 新增）

- **被邀请**：项目组页顶部出现「我的邀请」条（页顶铃铛也有通知）→「同意加入」即入组，「拒绝」则作废。
- **主动加入**：项目组页→「公共池」→ 在招募中的组上点「申请加入」（可附留言）→ 等组长在「入组审批」通过；进度在页顶「我的入组申请」条可见（已通过/已拒绝/已失效），待审批时可「取消申请」。

## 7. 账单里的项目组列

- **admin 账单总览→调用明细**：新增「项目组」列+筛选下拉（个人行显「—」）。
- **我的钱包→积分消耗明细**：新增「项目组」列+「我的组」筛选（只看我在某组的消耗）。

## 常见异常与恢复

| 现象 | 原因 | 恢复 |
|---|---|---|
| 侧栏没有「项目组」 | 账号无 project-group:manage 权限码 | 找 admin 配角色权限 |
| 选择器只有「个人」 | 不在任何组/组已删/加载失败 | 找组长确认成员身份；刷新重试 |
| 提交报「超出成员限额」 | 已用+预估>限额 | 找组长调高限额或重置已用 |
| 组池够但仍被拒 | 限额是按人的，与组池独立 | 同上 |
| 流水出现「兜底」行 | 在途任务结算时组池已被回收光 | 差额记组长个人；后续留足余额再回收 |
| 提示「组长已限制你在本组使用该类模型（对话）」 | 组长给你配了功能开关白名单，该模块不在内 | 找组长在成员行「功能开关」勾选或改回不限制 |
| 管理看不到「划拨/回收/设置」 | 设计如此：管理管人不管钱 | 资金与组设置找组长 |
| 管理无法调另一管理的限额 | 管理行只能由组长任免/调整 | 找组长处理 |
| 管理配额度报「超出你的可分配额度」 | 新限额预留 > 剩余可分配（额度−子树已耗−成员预留） | 下调金额、先重置下级已用，或找组长加预算 |
| 管理配「不限」被拒 | 被限额管理不能给成员配不限额 | 填具体数值，或找组长把自己的预算改为不限 |
| 组长调管理预算报「不能低于已占用」 | 新预算 < 该管理子树已耗+下级预留 | 先让管理下调成员限额/重置已用再收 |

## 2026-08-26 增补
- **管理降为成员，限额自动收紧**（堵「200 变 300」漏洞）：组长把某管理降为成员时，其限额立刻收紧为「自己已用 + 直接下级（改挂组长）额度之和」——下级的额度不动、不用重配，但被降者不能再给自己或他人凭空放大限额。操作路径不变（成员列表 → 调整角色），降职后该成员超额即拦，与普通成员一致。
- **配额变动全程留痕**：每次给成员授予/收回/改限额，都在组流水里记一笔（类型：成员授予/成员收回/成员限额调整，对象=该成员）。组长在组流水页可按成员查历史，谁什么时候给了谁多少，一目了然。
- **成员生成任务按「项目内剩余」拦截**：被限额成员提交视频/图片任务时，预估消耗比对他的「上限−已用」，不够则不创建任务并红字提示（此前只看组池，成员可越过个人上限）。不限额成员与组长仍按组池口径。

- **邀请成员支持多选**：搜索命中用户名/姓名/备注，行显「姓名·账号·[备注]」，一次圈多人批量发邀请。

## 2026-08-27 增补（修复V：流水筛选 + 导出 CSV）

> 对应 commit `671bea37`；详见 feature-map 同日增补。仅组长/管理/平台 admin 可见可用。

**筛选**（组详情 →「流水」tab 顶部筛选行）：
1. 关键词：输入备注内容或操作人账号/姓名 → 表格即筛选（匹配备注、操作人账号、姓名、用户备注四路）。
2. 类型下拉：14 种流水单选（划入/回收/消耗/退款/调整/兜底/配额划入/配额回收/限额调整/名下划入/名下消耗/名下退款/名下还款/欠款核销）。
3. 操作人下拉：选组内某成员，只看该人相关流水。
4. 时间范围：选起止日期，只看该区间。
- 界面变化：筛选行出现在流水表格上方（与「产出」tab 筛选行同款式）；任一筛选变更 → 表格重查且跳回第 1 页；「清空」一键回全量；翻页保留筛选条件。
- 预期结果：表格行随筛选收窄；条件可叠加；无匹配显示空表。

**导出 CSV**（筛选行右侧按钮）：
1. 先按需设好筛选（不设=全量导出，上限 5 万行）。
2. 点「导出 CSV」→ 浏览器下载 `group-{组id}-ledger-日期.csv`，按钮转 loading，完成恢复。
3. 打开文件：Excel 双击直开不乱码；首行表头（时间/类型/操作人/变动积分/变动后组池余额/关联/备注）；类型列是中文标签；操作人列含「姓名（账号）·备注」；超 5 万行时文件首行注明真实总行数。
- 完成标志：CSV 落地、内容与表格同套筛选所见一致。
- 常见异常：普通成员无此按钮，直接调接口返回 403「仅组长/管理员可导出组池流水」；导出中可继续操作页面（按钮禁用防连点）。
