## 是什么

本地化适配（l10n）是产品经理在i18n架构就绪后，将产品"实际适配"到特定地区/文化的执行体系——涵盖文化适配、格式本地化（货币/时区/度量衡/日期/姓名地址）、UI/UX本地化（RTL布局/色彩禁忌/图标语义）、内容本地化（文案语气/视觉风格/社交习惯）。l10n不是"翻译"，而是让产品"像本地人做的"。Common Sense Advisory数据：56%消费者认为获取母语信息比价格更重要；本地化投入每$1回报$25。

核心知识域（3层）：
- **格式本地化层**：货币符号与精度 / 日期时间格式 / 度量衡（公制/英制/美制）/ 时区与夏令时 / 姓名顺序与地址格式 / 电话号码格式
- **文化适配层**：色彩文化差异 / 图标语义差异 / 文案语气与社交习惯 / 宗教与禁忌 / 节日与日历 / 社交礼仪与隐私预期
- **UI/UX本地化层**：RTL布局适配 / 文本膨胀率设计 / 响应式本地化 / 本地化QA与自动化检测 / AI辅助本地化审查

本叶子不含：多语言架构设计/翻译流程管理（→D-20.01 多语言i18n）、数据本地化/隐私法规（→D-20.03 地区合规）、海外商店渠道/推广（→D-20.04 海外发行运营）、落地流程与模板（→4_可落地流程）、案例详解（→5_业内顶级案例）
