
## C2 · 一键关联（按名自动插 @）

**目标**：框选多个文本类节点（文本/脚本/分镜）→「一键关联」→ 祖先节点（连线可达上游）中 label 或资产名在目标文本中出现者，自动把该词替换为 `@{{node:id}}` 占位符——效果等价手动 @，运行时插值链路零改动。

**动作（伪代码）**：
```
新 utils/autoAssociate.ts:
  buildProposals(selectedIds, getNodes, getEdges) -> Proposal[]
    for target of 选中节点 where type in [text, script, storyboard]:
      text = data.prompt || data.synopsis || data.description      // 该类型主文本字段
      anc = ancestors(target.id, edges)                            // 复用 interpolate.ts 反向BFS
      cands = anc 节点的 label(长度>=2) + 资产徽标 assetName
        按 name 长度降序排列          // 防「主角1」吞掉「主角10」的命中区间
      for cand in cands:
        在 text 中找【未占用区间】内 cand.name 首次出现位置
        跳过命中点已落在 @{{...}} 占位符内部的（防重复包装）
        记 Proposal { targetId, candNodeId, name, pos, 前后文预览 }；区间标记已占用
  applyProposals(checkedProposals, board):
    按 target 分组、组内按 pos 降序（逆序替换防位移）
      text 原位替换 name → "@{{node:<candId>}} "
      board.updateNodeData(targetId, { 主文本字段: newText })
    scheduleSave()
新 components/canvas/AutoAssociateDialog.vue:
  表格列：目标节点 | 匹配上游（类型+label）| 替换预览（高亮词）
  默认全勾选，可逐行取消；确认 → applyProposals
  0 条提案 → 不弹窗，message.info（区分：无祖先 / 名字未出现）
CanvasView.vue:
  工具条「一键关联」→ 仅当 selectedIds 含文本类节点可用
  若目标节点正在属性面板编辑中 → 先取面板最新值再算提案（防覆盖未同步输入）
```
