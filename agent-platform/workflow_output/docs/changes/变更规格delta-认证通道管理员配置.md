# 变更规格 Delta · 认证通道管理员配置

## ADDED

- 管理员可配置邮件/短信启用开关、区域、AccessKey、发信/签名/模板、链接和限流参数。
- 管理端可查看密钥是否已配置，但任何响应均不得返回密钥明文。
- 配置保存即时生效；提供受审计的测试邮件、测试短信能力。

## MODIFIED

- 密钥来源从“仅环境变量”调整为“数据库 AES 加密配置优先，环境变量兜底”。
- `EmailService`、`SmsService` 每次发送前读取当前动态配置，不再把 `@Value` 当主来源。

## REMOVED

- 移除“修改认证通道参数必须重启后端”的限制。

## 兼容与回滚

- 未写入数据库配置时，行为与旧版环境变量配置完全兼容。
- 清除数据库配置即可恢复环境变量来源。
