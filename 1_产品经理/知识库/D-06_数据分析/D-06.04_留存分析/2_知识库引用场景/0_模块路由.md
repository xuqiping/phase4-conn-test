## 决策树：什么时候做留存分析

```
用户量问题
  ├─ 新增在降？→ 渠道分析（非留存分析主场景）
  ├─ DAU在降？→ 拆解DAU=新增+留存，确认是留存问题
  │     ├─ 次日留存降？→ 新手引导/首日体验优化
  │     ├─ 7日留存降？→ 核心功能体验优化
  │     └─ 30日留存降？→ 长期价值/习惯养成优化
  └─ DAU没降但MAU在降？→ 参与度/使用频率问题
```
