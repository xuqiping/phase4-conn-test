# 知识库问答：挂库提问、看引用、提反馈

## 一、对话里引用知识库

1. 进入「智能对话」，顶栏「**知识库**」多选下拉，勾 1~N 个库（选择会记住；清空=不引用）。
2. 正常提问 → 回答前系统自动检索你选的库，带证据作答。
3. 回答下方出现「**📎 引用来源**」：编号 + 来源文档标题 + 原件下载。
4. 没权限的库会自动被排除（不报错）；不选库 = 普通对话。

## 二、引用能告诉你答案在哪

- PDF：显示「第 3 页」，跨页显示「第 3～5 页」。
- Word/md：显示标题路径（如「报销制度 > 差旅标准」）。
- Excel：显示「哪个 Sheet 的 A5:E5」。
- 引用条可以点开核对原文；**保密库**的引用没有下载按钮（设计如此，见「保密库」篇）。

## 三、问答为什么有时要等十几秒

检索本身只要 1-2 秒；慢在「提炼事实 + 合成答案」两次模型调用，且页面会等引用校验完才一次显示答案（保证你看到的每个引用都真实可点）。只想快速验证能不能搜到 → 用库里的「检索调试」。

## 四、回答不好？提反馈

1. 答案生成完成后，下方出现反馈区。
2. **单选一个知识库**（多选时反馈按钮禁用，系统无法判断归属）。
3. 选问题类型：结果不相关 / 内容已过期 / 引用错误 / 答案不完整。
4. （可选）补充说明 ≤1000 字 →「提交反馈」。
5. 提示「已进入待审核队列」= 成功。反馈不直接改排序，由管理员审核后用于改进。

## 五、提问小技巧

- 带**版本号、日期、条款编号、引号原文**的问题走精确检索，又快又准。
- 「列出全部」「比较 A 和 B」类问题会自动取更多证据（最多 20 条）。
- 回答下方的**置信状态**会告诉你答案靠谱程度：完全支持 / 部分支持 / 证据不足 / 超出范围等——「证据不足」时别硬用，换问法或补充文档。
