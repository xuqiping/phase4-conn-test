## 1. 智能体 / Agent

| 字段 | 内容 |
|---|---|
| 英文全称 | Agent / AI Agent / Intelligent Agent |
| 中文别名 | 智能体、代理 |
| 定义 | 基于AI技术构建的、具备感知环境、理解信息、自主推理决策、规划与执行动作并持续与环境/其他主体交互，以自主达成预设或动态生成目标的数字智能实体 |

## 2. Agent Loop / 智能体循环

| 字段 | 内容 |
|---|---|
| 英文全称 | Agent Loop |
| 定义 | Agent执行任务的基本循环：感知→推理→行动→观察→再推理→再行动，直到任务完成或需要人工介入 |
| PM解读 | Agent Loop是理解Agent行为的底层框架——每一次循环就是Agent"想一步、做一步、看结果"。循环次数决定Token消耗和延迟 |
| 常见误解 | 以为Agent Loop越复杂越好（过多循环=浪费Token+延迟过长；关键是让循环有意义地收敛） |
| 来源 | [来源:知乎 | 📚中 | 2026-05] |

## 3. 自主性 / Autonomy

| 字段 | 内容 |
|---|---|
| 英文全称 | Autonomy |
| 定义 | Agent在无需人类干预的情况下自主完成任务的程度。通常分为L0-L5六级（类比自动驾驶） |
| PM解读 | 自主性等级是Agent产品的核心设计决策——L1适合高安全场景（每步确认），L3+适合高吞吐场景（批量执行） |
| 自主性分级 | L0=无自主(纯规则) L1=需每步确认 L2=关键步骤确认 L3=事后审查 L4=仅异常上报 L5=完全自主 |
