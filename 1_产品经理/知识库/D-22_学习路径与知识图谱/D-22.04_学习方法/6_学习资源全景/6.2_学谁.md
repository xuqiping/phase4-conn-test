# 6.2 学谁

> 业内顶尖人士对标图谱——学习方法与学习科学的思想源头。

## 核心人物

### 1. Anders Ericsson（1947-2020）

| 字段 | 内容 |
|---|---|
| 身份 | 佛罗里达州立大学心理学教授/"刻意练习"理论创始人 |
| 核心成就 | 30年研究顶尖表现者，发现"刻意练习"vs"天真练习"的关键差异 |
| **思维模型** | "刻意练习"——在"学习区"练习+明确目标+即时反馈；"1万小时"不等于专家，必须是有质量的1万小时 |
| **行动范式** | 实证研究驱动——每个结论都有30年数据支撑；反对流行心理学的简化解读 |
| 可学习点 | **PM做100次需求评审≠刻意练习**——必须有"学习区挑战+反馈+改进"循环 |
| 代表作 | 《Peak: Secrets from the New Science of Expertise》(2016) |
| 来源 | [来源:Ericsson论文+书籍 | 置信度:🔍高] |

### 2. Barbara Oakley

| 字段 | 内容 |
|---|---|
| 身份 | 奥克兰大学工程学教授/Learning How to Learn创始人 |
| 核心成就 | Coursera 400万+学员，将学习科学普及到大众 |
| **思维模型** | "专注模式vs发散模式"——难问题用专注模式攻坚，灵感用发散模式(散步/洗澡)涌现；"组块化"——将知识压缩为可快速调用的"组块" |
| **行动范式** | 从语言学转工程学——亲身验证跨领域学习方法；用动画+故事讲硬核科学 |
| 可学习点 | **PM学复杂概念时，专注模式攻坚+发散模式沉淀**——不要一口气学完，中间散步/运动让大脑后台处理 |
| 代表作 | 《A Mind for Numbers》/Coursera "Learning How to Learn" |
| 来源 | [来源:Coursera+Oakley官网 | 置信度:🔍高] |

### 3. Scott Young

| 字段 | 内容 |
|---|---|
| 身份 | 自学实验者/Ultralearning方法论创始人 |
| 核心成就 | 1年学完MIT 4年CS课程；1年学4种语言(与Benny Lewis合作) |
| **思维模型** | "Ultralearning 9原则"——元学习/专注/直接性/演练/检索/反馈/记忆/直觉/实验；核心："直接性"——做>看 |
| **行动范式** | 用自己做实验——每个方法论都在自己身上验证；公开分享过程(博客+书) |
| 可学习点 | **PM学习要"直接性优先"——做真实产品>看课程，写PRD>读模板** |
| 代表作 | 《Ultralearning》(2019)/MIT挑战博客 |
| 来源 | [来源:scottyoung.com | 置信度:🔍高] |

### 4. Cal Newport

| 字段 | 内容 |
|---|---|
| 身份 | 乔治城大学计算机科学教授/深度工作方法论创始人 |
| 核心成就 | 提出"深度工作"(Deep Work)概念——在注意力碎片化时代保持深度专注 |
| **思维模型** | "深度工作vs浅度工作"——深度工作(无打扰专注)产出=浅度工作3倍；"注意力残留"——任务切换有认知成本 |
| **行动范式** | 极简数字生活——不用社交媒体；固定深度工作时段；邮件批处理 |
| 可学习点 | **PM学习必须保护"深度工作"时段**——每天至少1个90min无打扰时段 |
| 代表作 | 《Deep Work》(2016)/《Digital Minimalism》(2019) |
| 来源 | [来源:calnewport.com | 置信度:🔍高] |
