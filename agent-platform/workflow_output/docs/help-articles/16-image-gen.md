# 图片生成（Seedream）

> 入口：侧栏「**图片生成**」。看不到菜单 = 没有权限，找管理员开通。

## 一、文生图

1. 模型下拉选「Seedream 5.0 lite」（或 pro）。
2. 输提示词（如「赛博朋克猫咪，霓虹」）。
3. 选尺寸（如 4K；选「自定义宽x高」可自己填，如 1536x1024）。
4. 点「**生成图片**」→ 右侧网格出现图。
5. 点图片下「下载」保存 png。

## 二、组图批量（lite 模型）

1. 选 lite → 输提示词。
2. 「组图」选「自动组图」→ 张数填 4（范围 1-15）。
3. 生成 → 网格出现 4 张，按 4 张扣积分。

## 三、参考图生图

1. 「参考图」区点「**+ 从资产库选取**」。
2. 选图确认（上限：lite 14 张 / pro 10 张）→ 缩略图入槽；点「✕」可移除。
3. 生成 → 图会反映参考图风格。

> 参考图可从「公共池」选（顶部切换来源）；切回「我的/共享项目」时已选会被清空需重选。

## 四、lite 和 pro 的区别

| | lite | pro |
|---|---|---|
| 组图 | ✅ | ❌ |
| 联网搜索 | ✅ | ❌ |
| 引导尺度滑块 | ❌ | ✅（1-10） |
| 提示词优化 | standard | standard + fast |
| 参考图上限 | 14 | 10 |
| 4K | ✅ | ❌（最高 2K） |

⚠️ lite 传了 12 张参考图后切 pro → 参考图**被清空**（防超限）；4K 切 pro → 回退 2K。

## 五、一键入资产库

1. 生成后点图片下「**入库**」。
2. 选目标项目（你是 owner/editor 的项目才会列出）→ 改名/描述（可选）→「入库」。
3. 资产库对应项目里出现该图资产。**同一张图可入多个项目**，各自独立。

## 六、历史区

- 可按提示词/时间筛选，「清空」恢复。
- 点某行 → 结果区加载该任务的图 + 左侧表单**回填当时全部参数**（含参考图）→ 改改就能再生成。
- 「请求参数」按钮核对当时提交的完整参数。
- 模型已下线的历史行有警告条，可看参数但不能提交。

## 常见异常

| 现象 | 原因 | 恢复 |
|---|---|---|
| 提交报「余额不足」 | 积分不够 | 充值后再提交 |
| 参考图提示「N 张已失效」 | 原图被删/失权 | 重选参考图 |
| 入库按钮灰/403 | 目标项目你只有只读权 | 换可写项目或找 owner 升权 |
| 某张图占位失败 | 该张生成出错 | 其余正常，按实际成功张数计费 |
