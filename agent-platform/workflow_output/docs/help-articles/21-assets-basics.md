# 项目资产库：建项目、传资产、版本管理

> 入口：侧栏「**资产库**」。看不到菜单 = 没有权限，找管理员开通。
> 资产库把创作素材（提示词/剧本/图片/视频/音频）按项目管起来，画布和生成页都能复用。

## 一、建项目

1. 资产库页右上「**新建项目**」→ 填项目名 + 描述（可选）→ 确定。
2. 项目自动带 5 个叙事角色分类：人物 / 道具 / 场景 / 风格 / 通用（不用手填）。

## 二、传资产（项目详情页）

1. 点项目卡片进详情页。
2. **传文件**：点「上传」选图片/视频/音频（类型要对上，mp4 不能进图片资产）。上传后自动提取宽高/时长等信息。
3. **建文本资产**：点「新建提示词」/「新建剧本」→ 选类型 + 勾叙事角色 → 命名 → 在详情里写正文。

## 三、找资产：双轴矩阵 + 筛选

- **顶栏**按类型筛（全部/提示词/剧本/图片/视频/音频），**左栏**按叙事角色筛，两个维度交叉定位。
- 搜索框输关键词叠加过滤。
- 还可按**上传者、分数来源、分数区间**筛（筛选条后三个下拉）。

## 四、资产详情（点卡片打开抽屉）

- **预览**：图片/视频/音频直接看，文本类格式化显示。
- **状态流转**（编辑者以上）：
  - 草稿 →「**定稿**」（锁定，画布引用固定当前版）/「归档」（列表默认隐藏）。
  - 定稿 →「解锁」回草稿。
  - 归档 →「取消归档」恢复。
- **版本时间线**：每次修改产新版本，点旧版本只读回看（快照不可变）。
- **下载**：文件类资产可下载原件。
- **使用记录**：看这资产被哪些画布节点产出/引用过。

## 五、和画布打通

**画布产出 → 入库**：
1. 画布上生成满意的图/视频 → 节点右键「**存入资产库**」。
2. 选项目（owner/editor 才能入）→ 叙事角色 → 命名 → 确定。
3. 同一节点重复入库时选：存为新版本 / 另存为新资产。

**资产 → 画布引用**：
1. 选中画布节点 → 属性面板「**从库选择**」→ 选项目/公共池 → 选资产。列表里可先预览再选：图片悬浮放大/点击开大图，视频显首帧点击播放，音频行内试听，文本显正文片段；点「选择」按钮才真正选用（2026-09-01 修复X 起）。
2. 节点头部显示「来自资产·名称 v版本」徽标。
3. 资产出新版后徽标变黄「有新版」→ 点「更新到最新版」手动换（**不自动变**，防止画面突然变样）。

## 权限速查

| 操作 | 项目主 | 编辑者 | 只读者 |
|---|---|---|---|
| 看项目/资产 | ✅ | ✅ | ✅ |
| 上传/改资产/定稿 | ✅ | ✅ | ❌ |
| 画布入库 | ✅ | ✅ | ❌ |
| 从库引用到画布 | ✅ | ✅ | ✅ |
| 管成员/删项目 | ✅ | ❌ | ❌ |

## 常见异常

| 现象 | 原因 | 恢复 |
|---|---|---|
| 上传被拒「类型不匹配」 | 文件类型和资产类型不符 | 选对类型再传 |
| 入库弹窗项目下拉是空的 | 你在项目里只是只读者 | 找项目主升你为编辑者 |
| 提示版本冲突 | 两人同时改同一资产 | 重新打开（拉最新版）再提交 |
