## 2026-08-15 · Step 1 A4 refresh token 旋转（SEC-FR-004+）✅ `2ee9bd18`

- **对拍结论**：refresh 无旋转 7 天固定复用、用后不拉黑可无限重放（`AuthService.refreshToken` 只发新 access）；前端 `applyTokenPair` 已存在但 `refreshAccessToken` 只存新 access——旋转上线前端不落新票必 401 循环。
- **后端**：`refreshToken` 旋转三步——旧票拉黑（值=`rotated` 区别 logout 的 `1`，TTL=剩余有效期；Redis 故障 WARN 降级）→ 签新 refresh（**同 sid**=会话延续，沿 S2 A8 范式）→ 响应回传；开关 `security.auth.refresh-rotation.enabled`（默认开，进 EDITABLE_KEYS）。
- **重放检出**：黑名单命中且值=`rotated` → `security.auth.refresh.replayed` 计数 + `KIND_TOKEN_REUSE` 事件 + `refresh_replayed` 审计失败行；**复用既有 `TokenReuseRule`**（11x P3-C9 多 IP 检测，verdict 码同是 TOKEN_REUSE）扩直发通道——不建新规则类。logout 拉黑（值 `1`）不告警。
- **前端**：`refreshAccessToken` 落新票（`res.data.data?.refreshToken` 存在才更新，开关关=后端不回传维持旧值）+ `RefreshResponse` 类型加可选 `refreshToken` 字段。
- **指标**：`security.auth.refresh.rotated` / `security.auth.refresh.replayed`。
- **测试**：AuthServiceTest +4（旋转拉黑+新票回传+计数 / 开关关=旧行为零写入 / rotated 重放拒+告警+不进签发链 / logout 拉黑拒但不告警）= **24 绿**；SystemSettingServiceTest 34 绿（开关默认值并入既有断言集）。
- **坑**：replay 分支 `securityEventPublisher != null` 短路 → Mockito 严格模式报 `getUserIdFromToken` stub 未用——删 stub（@InjectMocks 字段注入 null 是预期直通）。

## 2026-08-15 · Step 2 A6 管理员 TOTP 两步登录（SEC-FR-006）✅ `4dc6444f`

- **核心**：`auth/totp/TotpService`（RFC6238 零依赖自实现：Base32+HmacSHA1+30s 步长 ±1 窗口+常量时间比对；**RFC 官方测试向量对拍绿**）+ `MfaService`（绑定/校验/恢复码状态机，secret 走 system_settings 加密 KV，不在 EDITABLE_KEYS=管理端不可见）。
- **两步登录流**：已绑定用户密码过 → 只回 `mfaRequired`+`mfaToken`（JWT type=mfa，5min 一次性，jti 消费即拉黑）→ `POST /auth/mfa/verify`（permitAll，mfaToken 即凭证）验 TOTP/恢复码 → issueTokens 建会话。**防爆破**：同一 mfaToken 5 次试错封顶作废；**用户状态复查**防两步间被封禁仍登录。过滤器只放行 type=access——mfaToken 打 API 无效。
- **绑定流**（认证态）：`/mfa/bind` 发 secret+otpauth URI（pending 加密暂存）→ 前端手动录入验证器 → `/mfa/bind/confirm` 验码转正+发 **8 组一次性恢复码**（SHA-256 只存哈希，明文仅一次）→ `/mfa/unbind` 需有效码（防劫会话拆因素）。
- **开关**：`security.auth.totp.required`（默认关，EDITABLE_KEYS）——只对未绑定 admin 加 `mfaBindAdvice` 建议（**不硬阻断**，防开关误开锁死）；已绑定恒走两步与开关无关。
- **前端**：PasswordLoginTab 两步屏（mfaToken 存在即切第二屏，返回=重新密码步）+ auth store login 返回 MFA 信号/verifyMfa 落双 token + SettingsView 安全设置挂 `TotpSettingsCard`（三段绑定向导+解绑）。
- **指标/审计**：`security.auth.mfa.verify{result}`；`login_mfa` 审计（mfa_pending/mfa_code_wrong/mfa_verified/mfa_attempts_exceeded）。
- **测试**：**50 绿** = TotpServiceTest 9（RFC 向量/窗口/篡改/畸形/往返）+ MfaServiceTest 13（绑定状态机/恢复码一码一次/降级）+ AuthServiceTest 28（+5：绑定分流/建议标记/验证通过消费/错码可重试/重放拒）。前端 build 过+vitest 431 绿（7 失败为 PricingConfig/VideoGen **预存**，stash 验证与本改动无关）。
- **坑**：Mockito 混用 raw+matcher 报 InvalidUseOfMatchers（全 eq()）；blacklistMfaToken 用 300 SECONDS 非 300000 MS（测试对齐）。

## 2026-08-15 · Step 4 C5/C8/F2 残点收口（SEC-FR-025/027/061）✅ `a5b7746b`

- **C5 WS Origin**：`WebSocketConfig` 弃 `setAllowedOrigins("*")` → 共读 `app.cors.allowed-origins`（与 CORS 同配置两处生效）。dev 空 → 回退 `*`+WARN；**误配纯逗号 → fail-closed 空数组**（握手全拒、错配立现，不静默回退）。封跨站 WS 劫持（CSWSH：恶意页携受害者凭证语境直连 /ws/chat）。
- **C8 枚举残点**：①KB `visibility` 服务端白名单——实证契约是 **PRIVATE/TEAM/PUBLIC**（V17 迁移+前端注释），非计划草拟的 ORG；非法值 400 + 小写归一大写。②`AgentService.updateStatus` 裸 Map.get("status") 收白名单 DRAFT/PUBLISHED/OFFLINE（对齐 UserController ALLOWED_STATUS 范式）。
- **F2 回调 HMAC 双轨**：`RuntimeCallbackSecurityFilter` 升级——签名契约 `X-Callback-Signature=hex(HMAC-SHA256(token, ts+"."+body))`+`X-Callback-Timestamp`（epoch ms，±300s 窗封重放）；带签名头必须验过（错签/过期/篡改 body 均 401），无签名头 dual 回落静态 token（旧 sidecar 发布兼容期）/enforce 拒（`security.runtime.callback.hmac-mode` 热更，进 EDITABLE_KEYS）。恒定时间比对防时序探密钥；**验签消费流后 BodyCachingRequest 重放 body 给下游**。sidecar `callback_client.py` 同步加签——**先序列化一次、签名与发送同字节**（弃 httpx json= 的内部序列化）。
- **指标**：`security.callback.auth{result=hmac/legacy/rejected}`。
- **测试**：**71 绿** = FilterTest 12（RFC4231 向量对拍/错签/过期 ts/篡改 body/非法 ts/enforce 无签拒/legacy dual 过/fail-closed/非回调路径直通/下游 body 重读）+ WS 解析 3 + KB 可见性 5（新文件）+ Agent 3（=14）+ 回归（Settings 34/SecurityHeaders/AsyncDispatch/RuntimeCallbackSecurity 真链路 legacy 过）+ **python 签名头 2 绿**（独立复算对拍）。
