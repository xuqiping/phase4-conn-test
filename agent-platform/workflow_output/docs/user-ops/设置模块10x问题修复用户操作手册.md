# 设置模块 10x 问题修复 · 用户操作手册

> 面向 admin（管理员）的操作手册。普通用户无感知（设置入口对其隐藏）。

## 谁用
- **admin**：能进设置页、管理全局供应商的管理员。
- 普通用户：本次改动后**看不到**「设置」菜单（10x-3），无需操作。

---

## 一、进入设置（仅 admin）

**入口**：登录后左侧菜单底部「设置」

**界面变化**：
- 菜单「设置」仅 admin 可见（10x-3）。
- 进入 `/settings` 后，Tab 列表**不再有**「我的模型」（10x-1），现有 Tab：
  - 全局模型供应商
  - 认证设置
  - 计费设置
  - RAG/召回
  - 联网搜索

**预期**：admin 点「设置」正常进入；普通用户点不到、手敲 `/settings` 会跳回首页。

---

## 二、全局模型供应商 · 导出（10x-2）

**场景**：备份供应商配置 / 迁移到另一环境。

**步骤**：
1. 进 `/settings` → 「全局模型供应商」Tab。
2. 点顶部「导出」按钮。
3. 弹出确认窗，提示**「导出文件将包含明文 API Key，请妥善保管」** → 点「确认导出」。
4. 浏览器自动下载文件 `llm-providers-YYYY-MM-DD.json`。

**界面变化**：下载完成后右下角提示「导出成功」。

**最终标志**：本地有一份 JSON 文件，打开可见 provider 列表，`apiKey` 字段为明文。

**注意**：
- ⚠️ 此文件含明文密钥，**不要**发到群里/提交到 git/放公共网盘。
- 导出操作会在审计日志留痕（`provider_export`）。

---

## 三、全局模型供应商 · 导入（10x-2）

**场景**：从导出文件恢复 / 从其他环境迁入配置。

**步骤**：
1. 进 `/settings` → 「全局模型供应商」Tab。
2. 点顶部「导入」按钮。
3. 系统弹出文件选择窗 → 选一个 `.json` 文件（之前导出的或按格式自建的）。
4. 弹出预览窗，显示：
   ```
   共 N 条：预计新增 X / 更新 Y / 疑似非法 Z
   ```
   点「确认导入」。
5. 提示「导入完成：新增 X / 更新 Y / 失败 Z」。

**界面变化**：列表自动刷新，显示最新供应商。

**最终标志**：提示成功且列表数据更新。

**规则（重要）**：
- **按 name 匹配**：同名的 provider 会被更新（非空字段覆盖），不同名的新增。
- **API Key 为空时保留原值**：导入项里某 provider 没填 apiKey，**不会**清空该 provider 已有的 key（防止误删）。
- **非法行跳过**：name 为空、apiEndpoint 非 http(s) 的行会计入「失败」，不影响其他行。
- **单次上限 200 条**：超过会被拒绝（提示参数错误）。

**常见异常与恢复**：
| 现象 | 原因 | 处理 |
|---|---|---|
| 提示「文件解析失败：不是合法 JSON」 | 文件不是有效 JSON | 检查文件格式，重新导出对照 |
| 提示「失败 K」且有合法行成功 | 部分行非法 | 看 console 的「供应商导入失败明细」，修正后重导 |
| 提示参数错误（400） | 超过 200 条 | 分批导入 |

## 四、模块不再可见（10x-4/10x-5，全员感知）

**变化**：
- **Agent大厅、工作流、执行监控**：对所有人（含 admin）隐藏，菜单不显示，手敲 URL 会跳回首页。后端与前端代码保留，未来恢复只需改 `config/modules.ts` 开关。
- **视频生成/图片生成/视频剪辑/无限画布/资产库**：仅持有对应权限的用户可见（admin 默认有）。

**预期**：admin 登录后菜单更精简（少了 Agent大厅/工作流/执行监控）；普通用户只看到自己有权限的模块。

---

## 五、对话模型选择（10x-1，全员感知）

**变化**：
- 「我的模型」Tab 下线，个人不再能配置自己的大模型。
- 所有对话**统一走全局供应商**配置。

**预期**：对话功能照常可用，模型下拉显示全局配置的模型；存量用户曾配过的个人 override 不再生效。
