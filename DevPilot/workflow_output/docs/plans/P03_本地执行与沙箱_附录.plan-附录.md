# P03 本地执行与沙箱 · 附录

## 技术坑点预判

1. **Windows 路径与 WSL/MSYS 混淆**：沙箱 canonicalize 在符号链接/挂载点上行为不一致。规避：统一用 `dunce::simplified` + 手动解析 `..`；符号链接一律按真实路径判。
2. **进程超时杀不干净**：子进程又开了孙子进程。规避：tokio 超时后先 `kill()`，再按 OS 遍历进程树杀（Windows `taskkill /PID /T`，Unix `killpg`）。
3. **环境画像缓存失效**：用户改了 package.json 但 lockfile 没变。规避：缓存 key 加 `package.json` 内容 hash；探测结果含「需安装项」时不缓存。
4. **自动修复死循环**：LLM 反复同一错误。规避：限制重试次数、每次把历史失败输出摘要给 LLM、超过上限人工接管。
5. **Secrets 脱敏误伤**：短 secret（如 `abc`）会把正常文本里的 abc 全替掉。规避：只脱敏长度 ≥8 的 token；按单词边界匹配。
6. **沙箱与 IDE/git 冲突**：任务改 `.gitignore`、`.vscode` 等配置文件可能触发用户其他工具。规避：初始白名单默认包含项目根全部，但改隐藏文件仍走审批。
7. **并发任务 worktree 隔离（FR-002 P1 不在本 plan，但 P03 需预留）**：runner 接口接收 `worktree_path`，未来 P05/P08 扩展。

## 安全检查清单

- [ ] 目录白名单默认只含项目根；越界操作暂停弹审批（AC-001）。
- [ ] 危险命令清单在 Auto 模式下仍强制审批；Manual 模式逐条审批（AC-010/011）。
- [ ] Secrets 本地加密存储；注入环境变量；输出流实时脱敏（AC-014）。
- [ ] 任务进程超时强制终止，避免僵尸进程。
- [ ] 自动安装命令来自受信任包管理器，禁止 `curl | sh` 除非用户明确审批。
- [ ] 存档点 commit 不包含 secrets 明文或临时日志。

## 功能联动点清单

| 触发动作 | 联动对象 | 预期变化 | 边界 |
|---|---|---|---|
| 用户在阶段 2 点「开工」 | 状态机 + runner | 进入阶段 3，runner 启动探测/安装/执行 | 余额不足：由云端 402 拦截，任务暂停（FR-041 联动，反向） |
| runner 遇到越界路径 | pending_approvals 表 + UI | 任务挂起，弹审批卡片；用户允许后继续/拒绝则失败 | 同一任务多次越界：每次都审批（Manual）或只批危险项（Auto） |
| runner 测试失败 | LLM 自动修复 + 叙事流 | 自动修复重试；达到上限后 task 标 failed，UI 显示大白话原因 | 用户中途取消：保存当前文件状态，允许断点续开（AC-008，后续） |
| 用户新增 secret | core-state secrets 表 + 后续任务 | 新任务 env 注入；旧任务不 retroactive | 删除 secret 后已落盘日志仍可能含旧值，需说明「删除仅影响未来输出」 |
| runner 成功完成 | git commit 存档点 + tasks 表 | 项目多一个 `devpilot:` commit；状态机推进阶段 4 | 若项目无 git：先 `git init`（需审批）或仅生成 diff 不 commit |
| 环境探测命中缓存 | env_profiles 表 | 跳过文件扫描，≤10s 就绪 | lockfile 变化：重新探测 |

## 运维考量清单

| 项 | 决定 |
|---|---|
| 可观测性 | **做**：runner 每次执行产结构化日志（命令/退出码/耗时/审批事件），存 `task_logs` 表；UI 叙事流基于此。P08 再接入 /metrics。 |
| 配置开关 | **做**：`dangerous_commands` 清单、审批模式、超时默认值、自动修复重试次数全走 env/设置文件。 |
| 可回滚 | **做**：每个成功任务 git commit 即存档点；失败也打 `devpilot-failed` 标签；用户可一键 `git reset --hard`（UI 提示风险）。 |
| 限流熔断 | **后续再说**：per-task 执行时长上限、单用户并发任务数归 P05/P08。 |
| 降级路径 | **做**：环境探测失败→允许用户手动指定技术栈；自动安装失败→给手动命令+大白话原因。 |
| 运维入口 | **后续再说**：管理后台 P08；P03 通过本地 SQLite + 日志文件排查。 |
| 告警阈值 | **后续再说**：本地任务失败率、平均执行时长等聚合指标 P08 再议。 |
| 容量预案 | **后续再说**：本地执行无服务端容量问题；未来 remote execution 另规划。 |

## 术语表

| 术语 | 大白话 |
|---|---|
| 沙箱 | 任务的笼子：默认只能在项目目录里读写，越界要先问用户 |
| 审批两档 | 自动档（危险命令才问）和手动档（每步都问） |
| 环境画像 | 记住项目用啥语言、啥包管理器、装过啥，下次不再重新扫描 |
| 全流程闭环 | 读代码→改代码→跑测试→失败修→成功 commit 一条龙 |
| Secrets 脱敏 | 密钥在屏幕上显示成 `***`，写不进日志和文件 |
| 存档点 | 每个任务成功后一个 git commit，方便回滚 |
