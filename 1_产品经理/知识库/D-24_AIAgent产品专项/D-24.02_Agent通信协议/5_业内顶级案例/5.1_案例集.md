# 5.1 Agent 通信协议业内顶级案例集

## 案例1·MCP 生态突破 10 万 Server+2026-07-28 史上最大修订

- **是什么**：MCP（Model Context Protocol）Anthropic 发起的 Agent 工具层协议，2024-11 推出，2025-12 捐赠 Linux 基金会 Agentic AI Foundation，2026-07 月下载 9700 万、注册 Server 突破 10 万，发布史上最大修订候选规范
- **协议定位**：工具层（Agent ↔ 工具/数据源）
- **关键数据**：
  - 月下载 9700 万；注册 Server 10 万+；SDK 覆盖 8 种语言（TS/Py/Java/Rust/Go/C#/Kotlin/Swift）；Claude Desktop/Cursor/Cline/VS Code/Windsurf/Replit/Zed 全主流 AI IDE 集成 [来源:MCP官方/Linux基金会 | 🔍高 | 2026-07]
  - 2026-07-28 修订：从工具调用协议转型生产级智能体基础设施，新增全链路可治理（Task Lifecycle/Permission/RateLimit）+调用全流程可追溯（Invocation Log/Audit Trail/Provenance Chain）+可观测性（Telemetry/Metrics/Tracing）[来源:MCP官方 | 🔍高 | 2026-07-28]
- **落地价值**：MCP 是 Agent 工具层事实标准，所有 AI IDE 集成度最高；修订后可上生产环境（治理/可审计/可观测三件套）
- **PM 启示**：MCP 已是默认选项；生产级 Agent 必须升级到 2026-07-28 修订版（不可继续用旧版无治理能力）

## 案例2·A2A v1.0 GA + 150+ 组织生态

- **是什么**：A2A（Agent-to-Agent Protocol）Google 2025-04 推出的 Agent 互操作协议，2026 年进入 v1.0 GA（General Availability），从 50 个创始伙伴扩展到 150+ 组织参与
- **协议定位**：Agent 间层（云端 Agent 互操作）
- **关键数据**：
  - v1.0 GA；150+ 组织；50+ 创始伙伴含 Salesforce/AWS/SAP/Workday/Atlassian/ServiceNow/Box/Cohere/MongoDB；与 MCP 互补不竞争声明 [来源:Google A2A | 🔍高 | 2025-04/2026]
  - 协议核心：AgentCard 公开能力自描述 + Task 生命周期管理（submitted/working/input-required/completed/cancelled/failed）+ Artifact 标准产出物 + HTTP+SSE+JSON-RPC 双向通信
- **落地价值**：A2A 是 Agent 间协作的事实标准，让跨厂商 Agent 互联（OpenAI+Anthropic+自研混用）从"定制 N×M"降为"标准 N+M"
- **PM 启示**：做多 Agent 产品不集成 A2A 等于自建孤岛；A2A 与 LangGraph/CrewAI 不冲突（协议层 vs 框架层），可并存

## 案例3·AG-UI 被 Google/Microsoft 采纳 + CopilotKit 2700 万 A 轮

- **是什么**：AG-UI（Agent User Interaction Protocol）CopilotKit 2025-05 开源（MIT 许可）的 Agent 前端标准化协议，2026-06 获 Google 与 Microsoft 同时采纳，CopilotKit 完成 2700 万美元 A 轮融资
- **协议定位**：前端层（Agent ↔ 前端）
- **关键数据**：
  - 2026-06 Google/Microsoft 双大厂采纳；CopilotKit 2700 万 A 轮融资；MIT 许可开放；16 种标准事件类型（TextMessageChunk/ToolCallStart/StateSnapshot/HumanApprovalRequest 等）；React/Vue/Svelte SDK 全覆盖 [来源:CopilotKit/AG-UI | 🔍高 | 2025-05/2026-06]
- **落地价值**：Agent 前端从"等结果黑盒"升级"过程实时可见"；解决人机协同审批前端标准化痛点
- **PM 启示**：人机协同/自主Agent 前端必须用 AG-UI（替代自研 SSE/WebSocket）；Cursor/Devin/Manus 类过程可视化用 AG-UI 标准化

## 案例4·Anthropic Skills 生态（能力封装格式）

- **是什么**：Anthropic 2025-10 推出的 Agent 能力封装格式，把领域 know-how 打包成"经验包"让 Agent 加载即用——业内类比"装进脑子里的经验包"
- **协议定位**：能力层（领域 know-how 封装）
- **关键数据**：
  - 2025-10 推出；Anthropic 主导；与 MCP 互补（MCP 是工具，Skills 是经验）；生态起步中 [来源:Anthropic Skills | 🔍高 | 2025-10]
- **落地价值**：让 Agent 获得领域专长无需重训模型；产品经理方法论/法务合规/医疗诊疗/代码 review 规范等都可封装成 Skills
- **PM 启示**：领域专家可把方法论封装成 Skills 卖（B2B Skills 市场）；Skills+MCP 是"经验包+工具箱"组合

## 案例5·IBM Bee Agent Framework 与 ACP 实践

- **是什么**：IBM 在 Bee Agent Framework 中主导推动 ACP（Agentic Context Protocol/Agent Communication Protocol），是与 MCP/A2A 并列的第三大 Agent 协议，定位边缘与本地协同
- **协议定位**：边缘 Agent 间层
- **关键数据**：
  - ACP 双层面设计：通信连接层 + 智能体上下文层；Apache 2.0 开源；IBM Bee Agent Framework 推动中 [来源:IBM Bee | 🔍高 | 2026]
  - 适用场景：IoT/工业 Agent 边缘协同、本地多 Agent 协作、离线/隐私敏感 Agent、设备集群协同
- **落地价值**：补全云-边-端全域协议层；边缘场景带宽低/断连频繁下，ACP 的本地上下文共享比 A2A 云通信更优
- **PM 启示**：做边缘/IoT Agent 产品必须懂 ACP；国内 IBM Bee 生态弱于海外，落地需自研补全

## 案例6·中国信通院智能体可信握手协议（ATH）

- **是什么**：中国信通院 2026 年发起的智能体可信握手协议（Agent Trusted Handshake），目标做国内 Agent 间可信通信标准，对标 A2A 但强调"可信"，50 家企业已试点
- **协议定位**：国内 Agent 间可信通信标准
- **关键数据**：
  - 2026 年发起；50 家企业试点；与 A2A 对标但强调可信；面向国内市场（尤其国企/政府/金融/医疗）[来源:信通院 | 🔍高 | 2026]
- **落地价值**：国内合规敏感市场必须对齐 ATH；预留 Adapter 层对接国际 A2A 与国内 ATH
- **PM 启示**：面向国内市场的 Agent 产品必须预留 ATH 适配层；ATH 强于 A2A 的"可信"维度包括身份/权限/审计/数据主权

## 案例7·全国信标委智能体互联协议（AIP）国标

- **是什么**：全国信息技术标准化技术委员会（全国信标委）2026 年推动的智能体互联协议（Agent Interconnection Protocol）国家标准，目标是国内 Agent 互联的强制/推荐国标
- **协议定位**：国内 Agent 互联国家标准
- **关键数据**：
  - 2026 年推进中；全国信标委主导；定位国标（强制或推荐）；与 MCP/A2A 国际协议形成国内国际双轨 [来源:全国信标委 | 🔍高 | 2026]
- **落地价值**：未来国内 Agent 产品可能需 AIP 合规认证；提前对齐避免后期改造
- **PM 启示**：国内合规敏感场景必须关注 AIP 国标进展；国标合规改造应预留 Adapter 层

## 案例8·Cursor MCP 集成典型（个人 Agent +MCP 实践）

- **是什么**：Cursor 是 AI IDE 领军，2025-2026 全面集成 MCP，让 Cursor Agent 能通过 MCP 调用任意工具/数据源，是 MCP 在个人 Agent 场景的标杆落地案例
- **协议定位**：MCP 工具层在 AI IDE 的落地
- **关键数据**：
  - Cursor 全面支持 MCP 1.0+；用户可在 Cursor 中配置任意 MCP Server；GitHub/Slack/PostgreSQL/文件系统等 MCP Server 直接可用 [来源:Cursor | 🔍高 | 2026]
  - Cursor Agent 通过 MCP 扩展能力：从纯编码 Agent 升级为可调任意工具的通用 Agent
- **落地价值**：MCP 让 Cursor 从"AI 编辑器"升级为"AI Agent 工作站"；用户无需写代码即可扩展 Agent 能力
- **PM 启示**：MCP 集成是 Agent 产品从"封闭"到"开放"的关键；个人 Agent + MCP = 用户可扩展的 Agent 工作站
