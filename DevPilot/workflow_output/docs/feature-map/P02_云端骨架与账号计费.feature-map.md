## 表注解（涉建表，Flyway）

云端 PG 迁移在 `PROJECT/cloud/flyway/`（V1/V3，本地经 PGlite 迁移器执行）：

| 表 | 用途 | 关键字段用处 |
|---|---|---|
| users | 账号 | phone UNIQUE 主凭证；password_hash BCrypt |
| wallets | 钱包缓存 | balance_cents/gift_cents（账本推导的缓存，可重建）；version 乐观锁；month_spent_cents 预留月度口径（月熔断未实现，台账挂账） |
| token_ledger | 账本（审计即它） | 只增不改；kind 1消费/2充值/3赠送/4人工调整；idempotency_key UNIQUE 防重放；nonce 关联请求 |
| recharge_orders | 充值订单 | status 0待付/1已到账（CAS 转换）；paid_at 防重复入账 |
| api_identities | 上游身份 | api_key AES-GCM 加密落库，客户端永不可见（铁律） |

本地 SQLite `L3__usage_mirror.sql`：usage_mirror——云端账本的只增镜像，idempotency_key UNIQUE（云端 id）保证重放零新增；reconcile 比 SUM 出 drift 告警。

## 技术坑点回顾（为什么这么写）

- **R 封装是手动 `.then(R)`**：Nest 无全局包装，忘包就漏裸 JSON（e2e 抓过 5 处）。
- **进程内按用户互斥锁**：纯乐观锁在 100 并发下重试饥饿（实测只成功 12/100），加锁后全过。
- **SSE 防缓冲**：`@Res()` 手写 + `no-transform` + `x-accel-buffering: no` + flushHeaders，否则逐字变憋一屏。
- **幂等两层**：nonce（请求级防重发）≠ task_id（任务级熔断累计），别混。
