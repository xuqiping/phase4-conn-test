# File Keeper 项目 README

> 本文档仅说明当前各功能模块的详细功能；架构、接口、用户画像和竞品分析请查看同目录其他专项文档。

## 1. 文件管理模块

### 1.1 文件与文件夹收藏
- 支持添加单个文件或文件夹到收藏列表。
- 支持把本地文件或文件夹直接拖拽到主窗口完成收录。
- 支持使用系统默认程序打开文件，或直接打开文件夹。
- 支持在资源管理器中显示目标所在位置，方便回到真实目录继续操作。

### 1.2 文件组织能力
- 提供默认分组：**全部**、**最近打开**。
- 支持创建、重命名、删除自定义分组。
- 支持把文件归类到不同分组，用于区分项目、课程、客户、任务等资料集合。
- 每条文件记录支持维护标签和备注，方便表达文件用途、状态和说明。

### 1.3 搜索与排序能力
- 支持按文件名、文件路径、标签进行搜索。
- 搜索结果支持关键字高亮，便于快速定位命中内容。
- 支持以下排序方式：
  - 自定义顺序
  - 打开次数
  - 文件名
  - 最近打开
  - 添加时间
- 最近打开分组可直接查看近期或高频使用资料。

### 1.4 视图与展示能力
- 支持**网格视图**，适合浏览与展示。
- 支持**列表视图**，适合快速扫描与定位。
- 支持**真实文件图标**与**通用图标**两种模式。
- 大量文件场景下支持虚拟滚动与图标懒加载，减少列表渲染压力。

### 1.5 批量操作能力
- 支持多选文件。
- 支持批量打开。
- 支持批量移动分组。
- 支持批量添加标签。
- 支持批量删除。

## 2. 运行中应用管理模块

### 2.1 应用总览
- 展示当前运行中的可见桌面应用窗口。
- 单条应用记录可展示：
  - 应用名称
  - 窗口标题
  - PID
  - 内存占用
  - CPU 使用率
  - 应用类别
  - 窗口句柄

### 2.2 应用分类能力
- 内置多种常见应用类别识别，当前覆盖：
  - Browser
  - Office
  - Explorer
  - Terminal
  - Archive
  - Document
  - Media
  - Image
  - Communication
  - Download
  - Game
  - System
  - Other
- 分类目标是让用户按“浏览器、终端、办公、图像、通讯”等日常概念整理窗口，而不是只看进程名。

### 2.3 筛选、排序与列配置
- 支持按应用类别筛选。
- 支持按名称、类别、PID、内存、CPU、窗口标题等字段排序。
- 支持显示/隐藏列。
- 支持拖拽调整列顺序。
- 支持保存列配置，用于长期保持个人偏好的信息密度。

### 2.4 选择与批量整理
- 支持单选、多选、全选、反选、取消选择。
- 支持对单个应用窗口发起关闭请求。
- 支持对选中应用窗口批量发起关闭请求。
- 当前关闭逻辑面向日常桌面整理，底层是向目标窗口发送正常关闭请求，而不是默认强制杀进程。
- 如果目标应用实现了托盘驻留、关闭后最小化到托盘、仅隐藏主窗口或自定义关闭逻辑，那么窗口可能消失，但进程仍继续在后台运行。

### 2.5 右键快捷操作
- 支持把目标窗口显示到前台。
- 支持复制进程信息，便于排查、记录或沟通。
- 支持直接对目标窗口发起关闭请求。

### 2.6 自动刷新与安全保护
- 支持手动刷新当前运行应用列表。
- 支持自动刷新和刷新间隔设置。
- 支持关闭确认策略：总是确认、白名单确认、从不确认。
- 支持系统关键应用白名单，降低误关重要窗口的风险。
- 当目标应用权限更高或系统拒绝操作时，会给出更明确的关闭失败提示。

### 2.7 文件相关进程处理
- 支持查找与某个文件相关的打开进程。
- 支持关闭与某个文件相关的进程。
- 这里的“关闭文件相关进程”与运行中应用管理中的“关闭窗口”不是同一语义：前者是按进程进行处理，后者是向窗口发送关闭请求。
- 适合在文件被占用、无法编辑或无法删除时快速处理相关进程。

## 3. 剪贴板管理模块

### 3.1 剪贴板内容采集
- 支持监听并记录以下剪贴板内容：
  - 文本
  - 文件
  - 图片
- 在文本与富内容基础上，系统还会识别或归类为：
  - HTML
  - URL
  - 颜色
  - 安全事件
- 剪贴板历史会写入本地数据库，用于后续检索、预览和再次复制。

### 3.2 历史浏览与搜索能力
- 支持按关键字搜索历史记录。
- 支持按内容类型筛选。
- 支持按时间范围筛选。
- 搜索会覆盖记录标题、摘要、原始内容、OCR 文本和备注等可索引信息。

### 3.3 详情预览能力
- 文本记录支持查看正文。
- HTML 记录支持查看 HTML / Markdown / 简化文本内容。
- 图片记录支持查看图片预览、尺寸、格式和 OCR 文本。
- 文件记录支持查看文件列表、原始路径、缓存路径和缓存状态。
- URL 记录支持查看链接地址、标题和描述字段。
- 颜色记录支持查看 HEX / RGB 信息。
- 安全事件记录支持查看命中的敏感原因。

### 3.4 备注与整理能力
- 支持为单条剪贴板记录添加或修改备注。
- OCR 结果会自动写入图片记录的备注字段。
- 支持批量复制所选记录。
- 支持批量删除所选记录。
- 支持清理全部历史、仅清理非文本缓存、仅清理安全事件。

### 3.5 复制与粘贴能力
- 支持按记录类型复制原始内容。
- 支持纯文本复制。
- 对富文本记录支持 HTML / Markdown 形式复制。
- 对图片记录支持图片格式复制。
- 对文件记录支持文件复制。
- 支持记住目标窗口，并在开启自动粘贴时恢复目标窗口后直接粘贴。

### 3.6 快速面板能力
- 支持通过全局快捷键打开剪贴板快速面板。
- 支持在快速面板中即时搜索历史记录。
- 支持回车直接粘贴。
- 支持 Shift + Enter 以纯文本方式粘贴。

### 3.7 存储与备份能力
- 支持 `backup` 与 `reference_only` 两种文件保存模式。
- 支持自定义备份目录。
- 支持总非文本容量限制。
- 支持单条记录大小限制。
- 支持按类型设置容量上限。
- 支持文件扩展名白名单 / 黑名单规则。
- 支持查看各类剪贴板数据的存储占用情况。

## 4. 截图模块

### 4.1 快速截图能力
- 支持通过全局快捷键打开截图遮罩层。
- 支持全屏透明遮罩下的鼠标拖拽框选截图区域。
- 支持按 `Esc` 取消截图。
- 截图成功后会生成一条新的图片剪贴板记录。

### 4.2 截图结果联动能力
- 截图完成后，应用会切换到剪贴板页面。
- 会自动定位并加载新生成的截图记录。
- 截图后的 OCR 结果完成时，会刷新同一条记录的内容展示。

## 5. OCR 模块

### 5.1 图片文字识别能力
- 支持对截图结果执行 OCR。
- 支持对普通剪贴板图片执行 OCR。
- 支持把识别出的文本回写到图片记录中。

### 5.2 OCR 提供者策略
- 优先使用本地 OCR sidecar。
- 本地 sidecar 不可用时，可回退到 Windows 系统 OCR。
- 支持查询当前 OCR 提供者状态与可用性。

### 5.3 OCR 结果使用方式
- OCR 文本会写入 `ocrText` 字段。
- OCR 文本会同步到备注字段，方便用户直接查看和编辑。
- OCR 文本会进入搜索索引，使截图中的文字也能被搜索命中。

## 6. 链接预览与安全检测模块

### 6.1 链接预览能力
- 可识别 URL 类型的剪贴板内容。
- 记录会保存链接地址、标题、描述等预览字段。
- 支持在需要时重新触发链接预览抓取。

### 6.2 敏感内容检测能力
- 支持识别多类敏感文本，例如：
  - 私钥标记
  - JWT
  - 常见 API Key / Secret 模式
  - 银行卡号
  - 高熵密钥串
- 命中后会把该内容写入安全事件，而不是作为普通文本历史记录处理。
- 支持在剪贴板模块中单独查看和清理安全事件。

## 7. 桌面集成与个性化模块

### 7.1 托盘与窗口行为
- 支持系统托盘图标。
- 支持从托盘显示主窗口、隐藏主窗口、退出应用。
- 支持最小化到托盘，减少桌面干扰。

### 7.2 全局快捷键
- 支持主窗口快捷键。
- 支持剪贴板快速面板快捷键。
- 支持截图快捷键。
- 支持在设置中修改快捷键。

### 7.3 主题与界面偏好
- 支持 `light`、`dark`、`auto` 三种主题模式。
- 支持设置默认文件视图为网格或列表。
- 支持设置图标模式为真实图标或通用图标。

### 7.4 语言能力
- 当前支持中文和英文两套界面文案。
- 支持在应用内切换当前语言。

## 8. 当前模块关系

File Keeper 当前由以下几类核心能力共同组成：

1. **文件管理**：负责高频资料的收藏、组织、搜索与批量操作。
2. **运行中应用管理**：负责窗口总览、筛选、批量整理与安全关闭。
3. **剪贴板管理**：负责历史记录、预览、再次复制、快速粘贴与缓存管理。
4. **截图与 OCR**：负责把截图内容直接纳入剪贴板历史，并让图片文字可搜索。
5. **链接预览与安全检测**：负责提升 URL 可读性并识别敏感内容。
6. **桌面集成与个性化**：负责托盘、快捷键、主题和语言等长期使用体验。
