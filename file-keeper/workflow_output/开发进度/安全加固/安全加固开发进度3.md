## 本轮目标

完成 plan.md **Chunk 2 · 客户端 Rust：公钥验签 + 强校验 + 门禁**：
- 消除 P0-1：Rust 侧改用 Ed25519 公钥验签，废弃 HMAC 对称密钥。
- 消除 P1-1：token 内 `notAfter` 强校验，移除外部 `offline_seconds` 续期路径。
- 消除 P1-2：特权 Tauri 命令在 Rust 侧强制 `require_module` 门禁。
