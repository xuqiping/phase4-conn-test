## 复验中补修（真 bug，playwright 才暴露）

**daterange 时间筛选两坑**（ImageGenView.vue，vitest 424 绿 + vue-tsc 净）：
1. **v-model 不提交**：naive-ui 2.38 daterange 默认 `actions=['clear','confirm']`——点击日期只暂存 pendingValue（输入框有显示但 `historyTimeRange` 仍 null，`清空` 钮 disabled 实锤），须点「确认」才提交；源码 `use-dual-calendar.mjs:293` 提交路径要求 `close-on-select`。修：`:actions="['clear']" + close-on-select + update-value-on-close`（选完第二日即提交并关面板）。
2. **同日区间 400**：daterange 结束日时间戳=当日 00:00，选 8/11..8/11 → from==to 被后端 `from.isBefore(to)` 校验 400。修：前端 `to = range[1] + 24h - 1ms`（含结束日整天，语义正确）。
- 教训：组件「输入框显示了值」≠「v-model 已提交」；watch 不触发时先查组件提交语义（naive-ui range picker 默认要 confirm）。
