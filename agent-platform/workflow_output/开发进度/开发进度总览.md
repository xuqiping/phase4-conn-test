## 子目录与文件拆分约定
```
workflow_output/开发进度/
├── 开发进度总览.md            ← 本文件
├── _模板.开发进度n.md          ← 每轮对话记录模板
├── _模板.总路由.md             ← 超 5000 tokens 时索引
├── _模板功能README.md          ← 功能完成 README 模板
└── <功能名>/                  ← 每功能一目录（新功能开发时建）
```

### 单文件 5000 tokens 限制规则
接近 4000 预警；超限拆 `开发进度n.md` 或建 `总路由.md`。
