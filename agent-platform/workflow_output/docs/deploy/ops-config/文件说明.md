# ops-config 文件说明（专业术语 + 大白话）

> 本目录 = 平台「可选运维系统」（部署手册 §十）的全部配置与脚本，仓库内零密钥。
> 装监控系统、自动备份、一键发布时才用得到；只跑平台本体可以不管。
> 每个文件两行：【术语】专业解释 /【白话】这玩意儿干嘛的。

---

## 一、运维\ —— 配置文件（拷到服务器 `E:\IT\ops\` 各组件目录用）

### 运维\README.md
- 【术语】运维配置包的总索引与使用约定。
- 【白话】这堆配置文件怎么用、往哪拷的说明书，先看它。

### 运维\prometheus\prometheus.yml
- 【术语】Prometheus（指标采集器，时序数据库）主配置：定义 15 秒一次的抓取任务（scrape job）——后端 `:8080/actuator/prometheus`、sidecar `:8090/metrics`、windows_exporter `:9182`，以及 15 天数据留存策略与告警规则文件引用。
- 【白话】告诉监控器「每 15 秒去这三家门口抄一次表，数据留半个月」。

### 运维\prometheus\alert-rules.yml
- 【术语】Prometheus 告警规则组（alerting rules）：8 条 PromQL 表达式，如接口 5xx 率、JVM 堆占用、服务下线（up==0）超阈值即触发告警，推送 Alertmanager。
- 【白话】8 条「出事线」——错误太多、内存爆、服务挂了，就喊人。

### 运维\grafana\custom.ini
- 【术语】Grafana（可视化看板平台）主配置覆盖文件：监听地址（仅 127.0.0.1）、端口 3000、管理员初始账号、匿名访问关闭等。
- 【白话】看板网站的站规：只能本机访问、首次登录强制改密。

### 运维\grafana\provisioning\
- 【术语】Grafana 自动供给（provisioning）配置：`datasources` 声明 Prometheus 为默认数据源，`dashboards` 声明看板 JSON 的加载目录——Grafana 启动时自动装配，无需手工导入。
- 【白话】开机自动装好：数据源连线 + 4 块看板，不用手点。

### 运维\grafana-dashboards\ai-core.json
- 【术语】「AI 核心」看板定义：LLM 调用量、token 消耗、模型延迟等业务指标面板。
- 【白话】看 AI 花了多少token、模型快不快的那块屏。

### 运维\grafana-dashboards\api-quality.json
- 【术语】「API 质量」看板定义：HTTP 请求量、响应时间分位数（p95/p99）、错误率面板。
- 【白话】看接口卡不卡、报错多不多的那块屏。

### 运维\grafana-dashboards\security.json
- 【术语】「安全」看板定义：登录失败、限流触发、审计异常等安全事件面板。
- 【白话】看有没有人撞密码、刷接口的那块屏。

### 运维\grafana-dashboards\system-overview.json
- 【术语】「系统总览」看板定义：CPU/内存/磁盘/网络（来自 windows_exporter）+ JVM 状态面板。
- 【白话】服务器身体检查屏：CPU 烧不烧、盘满不满。

### 运维\grafana-dashboards\gen_dashboards.py
- 【术语】看板 JSON 的代码生成器（Python 脚本）：4 个 JSON 均由它生成，改看板只改此脚本再重跑，禁止手改 JSON。
- 【白话】看板的「印刷机」——要改版面改它重印，别手抠印出来的纸。

### 运维\alertmanager\alertmanager.yml.example
- 【术语】Alertmanager（告警路由/分组/静默器）配置模板：告警按级别分组凑批、抑制重复，转发至钉钉适配器；`.example` 后缀表示需复制为正式名并填入密钥后生效。
- 【白话】告警「接线员」的排班表模板——把告警攒一攒再发钉钉，别一条一轰炸。

### 运维\alertmanager\dingtalk-config.yml.example
- 【术语】钉钉告警适配器的配置模板：钉钉群机器人 webhook 地址与加签密钥的填位。
- 【白话】钉钉群机器人的「电话号码本」模板，群 token 填这就通。

### 运维\winsw\agent-backend.xml
- 【术语】WinSW（Windows Service Wrapper，把普通程序包装成 Windows 服务）配置：后端 jar 的启动命令、JVM 参数、环境变量注入（密钥经 `<env>` 写入）、日志路径——实现开机自启与崩溃自拉起。
- 【白话】让后端变成「开机自动跑、挂了自动拉」的 Windows 服务的配方。

### 运维\winsw\agent-sidecar.xml
- 【术语】WinSW 配置：runtime-sidecar（Python 工作流执行引擎）的服务化定义，uvicorn 启动参数与环境变量。
- 【白话】同上，给 Python 工作流引擎用的服务配方。

### 运维\winsw\agent-prometheus.xml / agent-alertmanager.xml / agent-grafana.xml / agent-windows-exporter.xml / agent-dingtalk-webhook.xml
- 【术语】WinSW 配置：监控五组件各自的服务化定义（可执行文件路径、启动参数、日志）；WinSW 硬性要求 exe 与 xml 同名配对。
- 【白话】五个监控零件各自的「开机自启配方」。⚠️ 配方文件名必须和 winsw.exe 改名后一模一样，否则不认。

### 运维\运维手册.md
- 【术语】运维 runbook：日常巡检项、常见告警的处置流程（先查什么→怎么定位→怎么恢复）、密钥应急轮换步骤。
- 【白话】出事了翻这本：报警响了第一步干嘛、第二步干嘛。

### 运维\恢复演练规程.md
- 【术语】备份有效性验证规程：定期用备份文件实际恢复一次（restore drill）的步骤与验收标准——备份不演练等于没备份。
- 【白话】「防火演习」手册：隔段时间真把备份还原一次，证明真出事能救回来。

### 运维\部署检查清单.md
- 【术语】装机核对清单（checklist）：新服务器从装依赖到上线的逐项打勾表。
- 【白话】装机时的「出门前检查单」：钥匙手机钱包，一项项勾。

## 二、scripts\ops\ —— 可执行脚本（服务器上直接跑）

### scripts\ops\deploy\deploy.bat
- 【术语】一键发布脚本：备份当前版本（`versions\时间戳`，只保 3 版）→ 停服务 → 拷贝新包 → 起服务 → 轮询 `/actuator/health` 健康门禁 5 分钟 → 超时自动回滚旧版并钉钉汇报。
- 【白话】更新平台用的「一键换血」按钮：换不上自动换回来，还会在群里喊一声。

### scripts\ops\backup\backup-pg.bat
- 【术语】PostgreSQL 逻辑备份脚本：`pg_dump` 全库导出（含向量数据），建议注册为每日 02:00 计划任务。
- 【白话】每天半夜给数据库拍一张完整「快照」存起来。

### scripts\ops\backup\backup-files.bat
- 【术语】文件备份脚本：`robocopy /MIR` 把上传文件目录镜像同步到备份目录（/MIR 为镜像模式，源删目标也删）。
- 【白话】把用户上传的文件整个「复印」一份到备份盘。

### scripts\ops\backup\backup-env.example.bat
- 【术语】备份脚本的参数模板：数据库密码、备份目标路径等环境变量填位；复制改名为 `backup-env.bat` 填真实值后生效（含密钥，不入 git）。
- 【白话】备份脚本的「填空题」模板：密码、存哪，填好改名就能用。

### scripts\ops\backup\sync-offsite.bat
- 【术语】异地容灾同步脚本：将备份产物再推送一份到异机/异盘（offsite copy），防单机房毁损。
- 【白话】把备份再抄一份寄到「别的房子」——本地烧了还有救。

### scripts\ops\winsw\install-services.bat
- 【术语】监控服务批量注册脚本：对 5 个监控组件逐一执行 WinSW install + 启动，用 `sc query` 判存（WinSW status 对未装服务也返回 0，不可靠）；GBK 编码，勿用编辑器重存。
- 【白话】一条命令把五个监控零件全注册成 Windows 服务并启动。⚠️ 别拿记事本另存，存坏编码就废。

### scripts\ops\alertmanager\配置钉钉告警.bat
- 【术语】钉钉告警交互式配置向导：引导填入群机器人 webhook token，自动生成 Alertmanager 与钉钉适配器正式配置（含密钥，仅存服务器本地）、重启服务并发送测试消息。
- 【白话】一步步问你「群机器人号码多少」，填完自动配好并发条测试消息到群里。

### scripts\ops\security-baseline-check.ps1
- 【术语】主机安全基线巡检脚本（PowerShell）：核对 RDP/防火墙规则、中间件绑定地址、uploads 目录 ACL 等基线项，输出偏离报告，建议每月执行。
- 【白话】每月一次的「保安巡楼」：门窗关没关、权限乱没乱，出张报告。

## 术语小词典

| 术语 | 大白话 |
|---|---|
| Prometheus | 定时抄表+存表的监控数据库 |
| Grafana | 把监控数据画成图的看板网站 |
| Alertmanager | 告警接线员：分组、去重、往钉钉发 |
| windows_exporter | 采集 Windows 主机指标（CPU/内存/盘）的小探针 |
| WinSW | 把任意程序包装成 Windows 服务的壳 |
| 健康门禁（health gate） | 发布后用健康检查把门，不过就回滚 |
| 镜像同步（/MIR） | 目标目录变得和源一模一样，多删少补 |
| provisioning | 启动时自动装配配置，免手工导入 |
| runbook | 故障处置步骤手册 |
