## M 组 · 功能联动用例（对齐 plan 联动点 #1-#6）

### M1 素材上传区随模型显隐（联动点 #1）
1. 视频生成页选 `happyhorse-1.1-t2v` → 素材上传区**隐藏**；切 `minimax-h3-regeneration` → 隐藏。
2. 反向：切回 `doubao-seedance-2-0-260128` → 上传区恢复；切 `happyhorse-1.1-i2v` → 恢复但限单图。
3. 边界：画布视频节点属性面板选 t2v → 上传区同样隐藏（两处下拉逻辑必须一致）。
4. 异常：t2v 模式若仍能传图（bug）→ 提交应被后端 400（"t2v 不支持参考媒体"）。

### M2 比例下拉随模型显隐与选项集（联动点 #2）
1. 选 `happyhorse-1.1-i2v` → 比例下拉**隐藏**（官方无 ratio，宽高跟首帧）。
2. 选 `happyhorse-1.1-t2v` → 比例下拉出现，选项=官方 9 值（16:9/9:16/1:1/4:3/3:4/4:5/5:4/9:21/21:9，**无 adaptive**）；`happyhorse-1.1-r2v` 同。
3. 边界（脏值清理）：先选 t2v+比例 4:5 → 切 `minimax-h3` → 比例须回落/清空（minimax 无 4:5 有 adaptive），提交体不得携带 4:5。
4. 反向：切回 t2v → 比例控件恢复且默认 16:9。

### M3 regeneration 源任务模式切换（联动点 #3）
1. 选 `minimax-h3-regeneration` → prompt/素材/比例/时长/分辨率全隐藏，源任务下拉出现。
2. 反向：切回 `minimax-h3` → 表单还原，此前输入的 prompt **不丢**（暂存）。
3. 边界：未选源任务 → 提交按钮禁用；源任务列表只列 本人+succeeded+7 天内+minimax-h3 生成任务（过期/失败/他人任务**不出现**，而非出现后报错）。
4. 选定源任务 → 估价预览=源任务时长×2K 秒价（如 5s → ¥1.5 档位）；清空选择 → 预览归零/提交禁用。

### M4 context-ir 表单与估价（联动点 #4，并入 M3 口径）
1. 选 `minimax-h3-context-ir` → 表单=prompt+素材（图/视频/音频）+时长+比例，**无分辨率控件**。
2. 估价预览随 prompt 长度变化（输入 100 字 ≈ ¥0.09 起，含 4000 tok 输出预估）。
3. 空 prompt → 提交拒（前端禁用或后端 400"content 须含非空 text"）。

### M5 历史列表新任务类型展示（联动点 #5）
1. CONTEXT_IR 成功行 → 结果区显示增强文本预览（超长截断+展开）+下载 .md，**非视频播放器**。
2. REGENERATION 成功行 → 显示 2K 视频预览，与普通视频行一致。
3. 反向：既有 seedance 视频行渲染零变化（回归）。

### M6 价表页新行可见（联动点 #6）
1. 设置→价表：VIDEO 侧见 5 新行（分档秒价槽可编辑）；CHAT 侧见 `minimax-h3-context-ir`（5.8/23）。
2. 边界：误删某价行 → 对应模型提交即拒（fail-closed），报 PRICING_NOT_FOUND 话术。
