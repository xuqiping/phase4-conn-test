## 真跑发现：last_frame 与 reference_image 互斥

ctaigw（SeedDance 2.0）对「尾帧 + 参考图」同请求返 **400**：

```
InvalidParameter: The parameter `content` specified in the request is not valid:
last frame image content cannot be mixed with reference image or draft_task content.
```

**契约**（Phase4 确认，三轮全绿单测无法覆盖——需现网真请求）：
| 组合 | 合法性 |
|---|---|
| 首帧 + 尾帧（无参考图） | ✅ task22/23 SUCCEEDED |
| 首帧 + 参考图（无尾帧） | ✅（仅 last_frame 与参考图互斥） |
| 尾帧 + 参考图 | ❌ 网关 400 |
| 参考图（任意） | ✅ task14 |

诊断手法：`ArkSeedanceProvider.createTask` catch 捕 `WebClientResponseException.getResponseBodyAsString()` 打日志，定位到 body 后定根因。

## 附：MentionTextarea 打 @ 宽度塌缩修复（commit `61a027a4`）

playwright 冒烟复测 @ 交互时抓到：视频页提示词框打 @ 后整个组件塌缩到 31px 宽，空态文案竖排撑成 412px 高窄条盖住下方附件区。

**根因**：[MentionTextarea.vue](../../../frontend/src/components/canvas/MentionTextarea.vue) `.mention-ta` 包裹层无显式宽度，在 Naive `n-form-item` 里是 flex item → 收缩到内容宽。空态靠 `is-empty::before` 占位符长文本撑出 ~346px；一打 @ → `is-empty` 移除 → 占位符消失 → min-content 塌到「@」字宽 31px，连带 `input{width:100%}` + `popover{min-width:100%}` 全塌。

## 附3：节点头全显「未命名」— vue-flow $attrs label 透传覆盖（commit `769e72b7`）

playwright 查画布发现**所有节点**头都显「未命名」，但后端 `/api/canvas/1` 返回的 `nodes[].data.label` 全部有值（视频/图片/抽帧(LAST)/文本…）。问题纯前端渲染。

**定位手法**：playwright `browser_evaluate` 沿 `__vueParentComponent`/`subTree` 深挖 Vue 实例，读组件 `props`/`attrs`/编译后 render——

- `VideoNode.props.data.label = "测试标签XYZ"`（reactive 自有属性，✓）
- 编译 render 正确绑定 `label: $props.data.label`
- 但 `CanvasNodeBase.props.label = undefined`，而同源的 `.props.status = "success"`（同 data、同绑定模式，独独 label 丢）
- `VideoNode.$attrs` 含 `label: undefined`（键在、值 undefined）+ id/type/position/dimensions 等

**根因**：vue-flow 把 `label` 当节点一等属性（vue-flow 数据模型里 node.label 是可显示标签）塞进自定义节点组件的 `$attrs`。VideoNode 等 5 节点组件**未声明 `label` prop** → 落 `$attrs` → 默认 `inheritAttrs:true` → 透传合并到根子组件 `CanvasNodeBase` 的 vnode props。

CanvasNodeBase vnode props 实测（铁证）：`{kind, kind-label, status, selected, id, type, events, resizing, dragging, connectable, position, dimensions, zIndex}`——显式绑定 + vue-flow 垃圾 attr 全混在一起，**且 `label` 键整个缺席**（不是 undefined，是键都没了）。fallthrough 的 `label:undefined` 覆盖显式 `:label="data.label"` → Vue 剥 undefined prop → 键消失 → CNB `v-if(label)` 落空 → 显「未命名」。`status` 不受害因 vue-flow 不传 `status`。

**修**：5 节点组件（[VideoNode](../../../frontend/src/components/canvas/nodes/VideoNode.vue)/[ImageNode](../../../frontend/src/components/canvas/nodes/ImageNode.vue)/[AudioNode](../../../frontend/src/components/canvas/nodes/AudioNode.vue)/[TextNode](../../../frontend/src/components/canvas/nodes/TextNode.vue)/[ScriptNode](../../../frontend/src/components/canvas/nodes/ScriptNode.vue)）各加一行 `defineOptions({ inheritAttrs: false })`。关 vue-flow `$attrs` 透传，显式 `:label="data.label"` 得以存活；定位/变换由外层 `.vue-flow__node` 包裹层负责，自定义节点本就不需要这些 attr，顺带清掉 id/position 等对 CNB 根 DOM 的污染。

**验证**：playwright reload `/canvas/1`——全 12 节点显真名（图片/视频/抽帧(FIRST)/抽帧(LAST)/抽帧(AT 1s)/文本…），零「未命名」；vue-tsc 净；vitest 284/284 零回归。

**踩坑批注**：vue-flow 自定义节点组件，凡子组件声明了与 vue-flow 节点一等属性同名的 prop（`label`/`id`/`type`/`position`/`data` 等），必加 `inheritAttrs:false`，否则 vue-flow 注入的 `$attrs` 会覆盖显式绑定。
