# 4.3 转化率诊断清单

## 概述

本碎片提供漏斗每步转化率的逐级诊断检查清单，帮助产品经理快速排查"转化率为什么低"的常见原因，从数据侧→产品侧→体验侧→技术侧四个维度系统排查。

---

## 诊断流程

```
转化率异常
    │
    ├─→ 数据侧：数据本身是否有问题？
    │      ├─ 埋点是否正确触发？
    │      ├─ 时间窗口是否合理？
    │      └─ 分组样本是否充足？
    │
    ├─→ 产品侧：产品设计是否有缺陷？
    │      ├─ 步骤定义是否合理？
    │      ├─ 步骤是否过多？
    │      └─ 是否有非必要步骤？
    │
    ├─→ 体验侧：用户动线是否有障碍？
    │      ├─ CTA是否显眼？
    │      ├─ 信息是否过载？
    │      └─ 焦虑感是否未消除？
    │
    └─→ 技术侧：是否有性能/BUG问题？
           ├─ 页面加载是否过慢？
           ├─ 是否有崩溃/报错？
           └─ 兼容性是否有问题？
```

## 逐维度检查清单

### 一、数据侧诊断

| 检查项 | 检查方法 | 常见问题 | 处理方式 |
|---|---|---|---|
| 埋点完整性 | 核对事件是否触发 | 漏埋/重复埋点 | 补埋/去重 |
| 事件参数 | 检查关键参数是否上报 | 参数缺失导致无法分组 | 补充参数 |
| 时间窗口 | 对比不同窗口下的转化率 | 窗口过短导致有效转化被排除 | 调整窗口 |
| 步骤定义 | 验证步骤事件是否对应实际用户动作 | 事件名与实际行为不匹配 | 修正映射 |
| 去重逻辑 | 检查同一用户多次触发是否正确处理 | 重复计数虚增分母 | 统一去重规则 |
| 样本量 | 每组至少500用户 | 分组过细导致统计不显著 | 合并低流量分组 |

### 二、产品侧诊断

| 检查项 | 检查方法 | 常见问题 | 处理方式 |
|---|---|---|---|
| 步骤必要性 | 每步是否为转化必须 | 非必要步骤增加摩擦 | 合并/删减步骤 |
| 步骤顺序 | 是否存在用户想跳过但无法跳的步骤 | 强制流程与用户意愿冲突 | 允许跳过/调整顺序 |
| 信息充分性 | 用户是否有足够信息做决策 | 信息不足导致犹豫流失 | 补充关键信息 |
| 信息过载 | 步骤是否塞了太多内容 | 认知负荷过大 | 精简/分步展示 |
| 激励对齐 | 完成每步的收益是否清晰 | 用户看不到价值 | 强化利益点展示 |
| 替代路径 | 是否有未纳入漏斗的替代转化路径 | 用户通过其他路径完成目标 | 补充替代路径追踪 |

### 三、体验侧诊断

| 检查项 | 检查方法 | 常见问题 | 处理方式 |
|---|---|---|---|
| CTA可见性 | 主操作按钮是否首屏可见 | CTA被折叠/位置偏 | 调整位置/增加浮层 |
| 表单负担 | 字段数量/类型 | 非必要字段导致放弃 | 减少必填、延迟填写 |
| 信任感 | 是否有社会证明/安全保障 | 用户不敢提交信息 | 添加安全标识/用户评价 |
| 焦虑点 | 哪些环节用户可能犹豫 | 退款政策不明/试用风险 | 消除顾虑信息前置 |
| 分散注意 | 页面是否有过多干扰元素 | 弹窗/广告/推荐分散注意力 | 减少非核心元素 |
| 返回/退出 | 用户是否容易误退出 | 没有确认对话框 | 添加退出挽留 |

### 四、技术侧诊断

| 检查项 | 检查方法 | 常见问题 | 处理方式 |
|---|---|---|---|
| 页面加载速度 | 监控P50/P90加载时间 | >3秒导致大量流失 | 优化性能 |
| 接口超时 | 监控API成功率 | 支付/提交接口超时 | 优化后端/加超时提示 |
| 崩溃率 | 监控崩溃日志 | 特定机型/系统崩溃 | 修复兼容性 |
| 跳转断裂 | 跨页面/跨端跳转测试 | 跳转失败/空白页 | 修复链接/重定向 |
| 缓存问题 | 清缓存后重新走漏斗 | 缓存导致显示异常 | 修复缓存策略 |
| 第三方依赖 | 检查第三方SDK状态 | 支付/地图SDK故障 | 添加降级方案 |

## 快速排查要点（3分钟速查版）

当时间紧迫时，按以下优先级快速排查：

1. **数据对不对？** → 埋点是否触发、样本是否充足（30秒）
2. **流量稳不稳？** → 是否有断崖式下跌，是否骤降（30秒）
3. **竞品对不对？** → 同类产品该步骤转化率是否也低（60秒）
4. **技术有没有问题？** → 加载速度、崩溃率、接口成功率（60秒）
