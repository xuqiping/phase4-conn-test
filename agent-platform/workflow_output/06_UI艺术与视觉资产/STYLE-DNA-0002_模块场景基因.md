# STYLE-DNA-0002 · 模块场景基因（雾中浮岛）

## 场景公式（每模块唯一构图，参数化）

**一页一景 = 天际渐变 + 底部远山 + 雾层缓漂 + 右缘诗签 + 浮岛内容**

```
scene(module) =
  sky:     linear-gradient(180deg, rgba(moduleRGB, 0.14) → transparent 45%)   // 天际
  ridge1:  radial-ellipse 山形A at bottom, rgba(moduleRGB, 0.08)               // 近山
  ridge2:  radial-ellipse 山形B at bottom, rgba(moduleRGB, 0.05)               // 远山（错开 20%+ 横向位）
  mist:    既有晨昏雾层（复用资产，36s 缓漂）                                    // 雾
  poem:    右缘竖排文楷诗签（writing-mode: vertical-rl）                          // 题跋
  islands: 内容卡 90%+ 实底绢本卡，浮于雾上                                      // 浮岛
```

四档山形种子（ridge 椭圆参数组合）轮转，保证 12 模块构图不同源：
- 种子1 双峰对峙（30%/70%）｜ 种子2 孤峰偏左（22%）｜ 种子3 连绵三岭（15%/50%/85%）｜ 种子4 平远水岸（宽大矮丘 60%）

## 七条基因（模块场景语境下的重述）

1. **淡**：场景层是「底色」不是「图画」——天际 ≤0.14、山 ≤0.08，永远淡到险些看不见
2. **远**：山形只在页面底缘 20% 高度内，营造「远景」；禁止山形进入页面中上部
3. **空**：场景区即留白区——内容卡之间的空隙透出场景，就是「空」
4. **逸**：雾 36s 缓漂唯一动效；诗签静态；禁任何其他场景动画
5. **稳**：浮岛卡 ≥90% 实底，文字对比度与无场景时完全一致（红线）
6. **明**：宣纸主题下同一套场景换浅调（山形用墨色 5%，天际用模块色 0.10）
7. **时**：晨昏雾层已随本地时间切换，场景色不变

## Do / Don't（门禁必查）

| ✅ Do | ❌ Don't |
|---|---|
| 天际渐变 45% 高度内消隐为透明 | 整页覆盖色场（变回方向三） |
| 山形用椭圆渐变的极简剪影 | 写实山峰/复杂轮廓/AI 山水画贴图 |
| 诗签竖排、文楷、text-secondary、≤8 字 | 诗签横排大字/正文用诗/每屏多句 |
| 浮岛卡实底 ≥90% + 8px 柔影 | 半透明卡透出场景影响文字 |
| 每模块一个专属色（真值表） | 一页多色场景/高饱和霓虹渐变 |
| admin 页场景 opacity ×0.5（密度优先） | admin 页全浓度场景干扰判读 |
| reduced-motion：雾静止、场景保留（静态装饰） | reduced-motion 下场景全删（氛围损失） |
| 旧三主题零场景（全部 ink 门控） | 场景泄漏到 deep-space 等旧主题 |

## 焦点纪律

每页视觉焦点 = 场景 + 页头，二合一为一个焦点区；内容区不再新增任何装饰元素（Q: 卡片内不再加山形水印）。
