# 规格 · 知识库：模型可选、只读越权修复、库级保密

> Phase 1 修复规格。实现必须与本文一致；来源为 2026-08-17 人工测试问题 14x 未解决项 #1/#2/#3（#3 用户已拍板：库级保密开关）。
> 关联：[企业级精准知识库RAG 总览](企业级精准知识库RAG-总览.md)｜[企业级精准知识库RAG Feature Map](../feature-map/企业级精准知识库RAG.feature-map.md)。

## 1. 目标

1. 知识库可选用 embedding 模型与 RAG 问答 LLM 模型（下拉选择，不再全局唯一/手填）。
2. 修复「授权只读的成员也能编辑」越权：读写权限判定归位，前端按钮按 per-KB 权限显隐。
3. 库级保密开关：保密库的成员只能通过 RAG 问答召回相关内容，不可浏览切片原文、不可下载原件。

## 3. 只读越权修复（14x#2）

### 3.1 后端判定归位

- **谓词修复**（核心一行）：`hasGrant(kb, userId, requireWrite)` 在 `requireWrite=true` 时必须匹配 `canWrite=true`（或 canManage=true）；`requireWrite=false` 维持 canRead/canWrite/canManage 任一可读语义。修复后：
  - 只读成员（canRead=true, canWrite=false）不再通过 canWrite → 上传文档、直传文本入库被拒（403）。
  - 授权语义矩阵：

| 授权位 | 读（列表/下载/切片/问答） | 写（上传/直传/替换） | 治理（元数据/版本/删除/授权） |
|---|---|---|---|
| canRead | ✅ | ❌ | ❌ |
| canWrite | ✅ | ✅ | ❌ |
| canManage | ✅ | ✅ | ✅ |
| owner/admin | ✅ | ✅ | ✅ |

- **canManage 授予位生效**：`canManage()` 改为 admin ‖ owner ‖ hasGrant(canManage=true)，让授权弹窗的「管理」勾选产生真实语义（可管理该库授权与治理）；KB 改名/删除仍限 owner/admin（授予位不含销毁库）。
- **读路径审计**：`KnowledgeDocumentService` 中现用 canWrite 的「预览」类读路径逐个改回 canRead（写归写、读归读）；治理类维持 canManage。实现阶段输出逐接口归位清单入 PR 描述。

### 3.2 前端显隐归位

- KB 列表 VO 补 per-KB `canWrite` 字段（canManage 已有）。
- `KnowledgeView.vue` / `DocumentManager.vue`：
  - KB 行「编辑/删除」：per-KB canManage（owner/admin）；
  - 文档抽屉上传区/直传/新版本：per-KB canWrite；
  - 治理/解除隔离/删除文档：per-KB canManage；
  - 「授权」按钮：per-KB canManage（现状）。
- 后端为唯一安全边界，前端显隐仅防误操作。

## 4. 模型可选（14x#1）

### 4.1 embedding 模型

- `KbFormModal` 的 embedding 输入改 **n-select**：选项 = GET /api/llm/models/active?category=EMBEDDING；含「跟随全局默认」空选项。
- 存量值与新选择写入既有 `kb.embeddingModel`；检索/索引已按库取值（`RagRetrievalService.java:193,424`、`IndexJobWorker.java:127-130`），零后端改动。
- 混库检索既有约束（enforceSameEmbeddingModel 混模型只留首组）不变，选择器选项上提示。

### 4.2 RAG 问答 LLM 模型

- 数据模型（Flyway）：`knowledge_bases` 增列 `answer_model VARCHAR(128)`（NULL=跟随全局默认）。
- 表单新增「问答模型」下拉：选项 = /api/llm/models/active?category=CHAT + 空选项「跟随全局默认」。
- 生效点：`RagRetrievalService` 三处 LlmRequest（生成 :1081、事实提炼 :1187、答案合成 :1262）在有值时显式 set model，空值维持回退逻辑。
- 边界：索引摘要 LLM、评测 LLM 维持全局默认（本规格只放开问答链路）；每库混配不同 embedding 的既有约束不放松。

## 5. 库级保密开关（14x#3）

### 5.1 数据模型

`knowledge_bases` 增列 `confidential BOOLEAN NOT NULL DEFAULT FALSE`（存量库全部非保密，行为零变化）。

### 5.2 开关语义

- 仅 owner/admin 可切换（KB 表单「保密库」开关 + 说明文案：开启后成员只能通过 RAG 问答召回相关内容）；切换即时生效，不删数据、不动既有授权。
- 保密判定 = `kb.confidential && !(owner ‖ admin)`。

### 5.3 内容面收紧矩阵（服务端强制）

| 接口 | 非保密库（现状） | 保密库成员 |
|---|---|---|
| GET /documents?kbId（文档列表） | 全量元数据 | **保留**：标题/类型/状态/时间（可当目录索引）；**剔除 fileRef** 字段 |
| GET /{id}/asset（下载原件） | canRead 即可 | **403**（BUSINESS 错误码 KNOWLEDGE_CONFIDENTIAL_DENIED） |
| GET /{docId}/nodes（切片原文） | canRead 即可 | **403** |
| POST /retrieve（检索调试） | canRead，content 直出 | **403**（整接口对保密库成员关闭，防切片原文/证据内容旁路） |
| RAG 问答（chat kbIds / ask SSE） | 正常 | **正常**（唯一内容出口；仍走权限求交 + 引用校验） |
| chat CITATION 帧下载原件入口 | 显示 | 前端隐藏下载按钮（后端 /asset 403 兜底） |

- 「只能召回涉及到的相关内容」的保证来自：问答出口只返回与问题相关的证据段（既有 QueryPlan 预算 + 引用校验），成员无法通过列表/切片/下载/调试旁路拼出全文。
- 前端同步：保密库徽标（库卡片/列表）；DocumentManager 对保密库成员隐藏下载原件按钮；RetrievalDebugPanel 对保密库成员禁用该库选项。
- 边界：曾授写的成员在库转保密后同样只保留问答出口（其已上传文档不例外）；保密不改变授权授予/撤销链路；公开库（PUBLIC）不允许开保密（表单互斥校验）。

## 6. 测试策略

| 层 | 用例 |
|---|---|
| 后端单测 | 谓词矩阵：canRead/canWrite/canManage × 读/写/治理 9 格逐格断言（修复核心回归）；canManage 授予位生效/不越库销毁；answer_model 空回退默认/有值透传三处 LlmRequest；保密矩阵：列表剔除 fileRef、asset 403、nodes 403、retrieve 403、问答放行；owner/admin 全通行；PUBLIC 库开保密被拒 |
| 前端单测 | embedding/问答模型下拉选项装配与空选项；per-KB 按钮显隐三态；保密徽标与下载按钮隐藏 |
| 人工/playwright | 只读成员：上传/直传被拒（403 文案），问答正常；下拉换 embedding 建库→索引→检索命中；换问答模型后 /ask 生效（请求快照或响应风格可辨）；开保密后成员侧四路旁路全 403、问答引用正常 |

## 7. 边界与不做

- 不做多模型并行评测/自动选型；不放开索引摘要模型 per-KB。
- 不做水印/防截屏类内容防泄露（应用层无法根防，本规格收敛服务端可强制的旁路面）。
- 不改授权主体体系（USER/ROLE/DEPARTMENT 三类主体维持）。
- 检索调试整接口 403（而非脱敏返回）为首版选择：简单、无半泄露面；owner 调试不受影响。

## 8. 术语表

| 术语 | 大白话 | 简单案例 |
|---|---|---|
| ACL | 访问控制列表——「谁能对这个库读/写/管」的授权记录表 | 给同事授 canRead=true 一行 |
| per-KB 权限 | 按「这一个知识库」算出的权限，而非全站角色权限 | 全局有 knowledge:write 不代表能写别人的库 |
| 谓词（predicate） | 判定函数里那个真/假条件表达式 | `canRead ‖ (requireWrite && canWrite)` |
| 旁路 | 绕过主路径拿到内容的其他出口 | 问答只给相关段落，但下载按钮能拿全文=旁路 |
| CITATION 帧 | RAG 回答里标「引用了哪几段」的结构化消息 | 回答末尾 [1]《值班制度》可点下载 |
