# 账单总览与调用明细（管理员）

> 入口：侧栏「账单总览」。看全平台真实消耗：token、人民币、积分。

## 一、六个页签

| 页签 | 看什么 |
|---|---|
| 总览 | 平台累计消耗、活跃用户数、近期流水 |
| 按用户 | 每用户消耗排名，点人看明细 |
| 按模型 | 哪个模型用得多（判断价表合理性） |
| 按类型 | 对话/嵌入/视频/图片各占多少 |
| 趋势 | 按日期折线图看涨跌 |
| 调用日志 | 每次模型调用的真 token + ¥ + 积分 + 成败 |

顶部可按用户/模型/日期范围筛选。「调用明细」还有「项目组」列，可筛某组的消耗。

## 二、充值记录页签

1. 顶部筛选：用户名/渠道/状态/日期 → 查询。
2. 筛选上方一行汇总：「当前筛选：已付金额 ¥xx，已付积分 xx」（只统计已支付，随筛选联动）。
3. 未支付的单「充值后余额」显示「—」。

## 三、用户余额页签

- 顶部四张合计卡：用户数 / 余额合计 / 累计充值积分 / 累计充值金额（全平台口径）。
- 表格按用户列：当前余额、累计充值、最近充值时间；点列头排序。
- 用途：回答「全平台充了多少钱、发了多少积分、用户手里还剩多少」。

## 四、人工补单（极少见）

用户实际已付款但订单显示已关闭 → 对账区「支付渠道异常」有其线索（时间/单号）→ 核实后走「积分充值」补等额积分并备注订单号。

## 五、对账

系统每天自动核对「每个用户余额 = 流水之和」。**平时什么都不用做**；收到对账不平告警说明数据被异常改动，须人工查清——系统绝不会自动修账（故意的安全设计）。
