# AESTH-0002 · 模块级审美补强研究（为什么第一版"看不出意境"）

> 日期：2026-08-29 ｜ 触发：用户审核结论「所有模块没有体现出高山流水/缥缈/高级/现代化中国风的元素和感觉」
> 性质：AESTH-0001 的补强，不替代

## 1. 失败归因

第一版模块设计（ART-DIR-0002 旧版）把 90% 的力气花在**令牌层**（颜色/字体/圆角/阴影），只给每页留了「竖痕+文楷标题」级别的签名。问题：

| 层 | 第一版做了什么 | 用户感知 |
|---|---|---|
| 令牌层（色/字/影） | 完整 | 「换了个深色皮肤」 |
| 构图层（留白/景深层次） | 没做——内容区是一整块平板 | 「跟普通后台没区别」 |
| 场景层（山水画面感） | 只有登录页有 | 「模块里完全没有高山流水」 |
| 文化层（诗意/意象命名） | 只有空状态 | 「感觉不到中国风的魂」 |

**结论：意境要可被感知，必须上「场景层」和「文化层」——每页有看得见的山水画面与读得到的诗意签名，而不只是调色。**

## 2. 意境密度刻度（本专项的核心工具）

| 密度 | 手段 | 参考 |
|---|---|---|
| L0 皮肤 | 换色换字体 | 第一版 ≈ 此档（失败档） |
| L1 点缀 | 印章、发丝线、竖痕 | 公共层已做（保留） |
| L2 景窗 | 页头一条山水场景带（渐变山形/雾/光） | 每日故宫、新中式 App 首图 |
| L3 场景 | 整页背景即风景，内容如雾中浮岛 | 西窗烛、Apple TV+ 片头 |
| L4 沉浸 | WebGL 生成式山水 | 方向 C 二期，本轮不做 |

**B 端工具的甜区在 L2-L3 之间**：低于 L2 无感（本轮教训），高于 L3 伤可读性与性能。

## 3. 「高级感」的三个可操作来源（现代中国风）

1. **克制的大留白 + 一处精致焦点**——高级感=敢空。每页只许一个视觉焦点场景。
2. **低饱和同色系的纵深**——用 3 层明度差做出「远中近」景，而不是加新颜色。
3. **文化符号的现代转译**——山=极简渐变剪影、水=流光细线、雾=柔光层、印=朱砂小方块、诗=竖排或宽字距文楷短句。禁止直给（水墨画、祥云、龙凤=廉价感）。

## 5. 竞品/参照速查

- **每日故宫/西窗烛**：L2 景窗 + 大量留白，证明 B 端密度下意境可成立
- **Linear/Notion**：高级感来自间距节奏与微动效，不是装饰——我们的留白节奏对标之
- **Apple 官网产品页**：深色底+单一柔光焦点——「敢空+一处光」的教科书

## 6. 结论

模块级重设计必须：① 每模块上 L2-L3 场景层（景窗或全页场景）；② 用第 4 节真值表把文化层补齐（意象+色+诗签）；③ 高级感三来源（敢空/同色系纵深/现代转译）贯穿。三个竞案方向见 ART-DIR-0002R。
