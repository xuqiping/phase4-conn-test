## 本轮关键决策与变更

- **全部组件只绑 127.0.0.1**：与 /actuator 安全策略一致（不对外暴露、不经 Nginx 反代）。Grafana 默认 admin/admin，**首登须改密**（写进 Step 13 运维手册待办）。
- **windows_exporter 用官网裸 exe，不走 msi**：msi 自带服务注册与 WinSW 统一管理冲突；且 0.31.8 已提供 amd64 exe 直链。
- **alertmanager 先装后配**：占位 yml（null receiver）让服务可启动，真实钉钉 webhook/SMTP 属 Step 10 且密钥不入库。
- **sidecar target 日常 down 属预期**：sidecar 进程不在跑时该 target 必 down，非故障；验证时临时拉起 sidecar 证实 UP 即可。

## 踩坑与排雷

- **windows_exporter 0.31 移除 `cs` 采集器**：`unknown collector cs` 进程起不来，xml 已删并留红线注释。
- **WinSW v2 `status` 对未安装服务也返回 0**：不能用于判存，install-services.bat 改用 `sc query`（头注释留痕）。
- **alertmanager 占位配置 receiver 要写字符串 `"null"`**：YAML 裸 `null` 是空值，报 root route must specify a default receiver。
- **WinSW v2.12.0 资产名是 `WinSW.NET461.exe`**（无 .x64 后缀），下错名 404。
- **大文件下载须走代理**：dl.grafana.com 直连 26KB/s（274MB 包），代理 7892 后 ~2.5MB/s。已存记忆 local-proxy-port。
- **cmd 的 `echo` 不复位 errorlevel**：子例程末尾必须显式 `exit /b 0`，否则 start 失败的错误码泄漏给调用方误判整体失败（首版 install-services.bat 因此只跑了第一个服务就退出）。
