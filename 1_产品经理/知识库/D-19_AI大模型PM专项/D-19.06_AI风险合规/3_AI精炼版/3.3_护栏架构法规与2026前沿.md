# 3.3 护栏架构·AI合规法规·2026前沿

## 一、多层护栏架构（Defense in Depth）

纯靠模型对齐不够，必须四层护栏纵深防御：

```
用户输入
   │
   ▼
┌─────────────────────────┐
│ 1.输入侧护栏              │ 意图检测/PII过滤/越狱识别/敏感词
└─────────────────────────┘
   │
   ▼
┌─────────────────────────┐
│ 2.模型侧护栏              │ 对齐/宪法AI/结构约束/温度控制
└─────────────────────────┘
   │
   ▼
┌─────────────────────────┐
│ 3.输出侧护栏              │ 内容审核/引用溯源/置信度/有害检测/重生成
└─────────────────────────┘
   │
   ▼
┌─────────────────────────┐
│ 4.运营侧护栏              │ 监控/告警/审计日志/人工兜底/熔断
└─────────────────────────┘
   │
   ▼
用户输出
```

### 1.1 各层护栏设计

| 层 | 护栏组件 | 实现 |
|---|---|---|
| **输入侧** | 意图检测 | 分类器判断意图合规 |
| | PII过滤 | 命名实体识别去PII |
| | 越狱识别 | 模板匹配+模型识别 |
| | 敏感词过滤 | 关键词+语义过滤 |
| | 速率限制 | 防滥用扫描 |
| **模型侧** | 对齐训练 | RLHF/宪法AI/DPO |
| | 系统提示词约束 | 强约束系统Prompt |
| | 结构约束 | 限制输出格式/白名单行为 |
| | 温度控制 | 降低温度提稳定性 |
| | 模型路由 | 高风险转强对齐模型 |
| **输出侧** | 内容审核 | 有害/违法/涉黄检测 |
| | 引用溯源 | 关键事实带引用 |
| | 置信度标注 | 低置信度标记 |
| | 相似度过滤 | 防复制受版权内容 |
| | 重新生成 | 输出不合规自动重生 |
| **运营侧** | 实时监控 | 指标监控+异常告警 |
| | 审计日志 | 全链路可追溯 |
| | 人工兜底 | 高风险转人工 |
| | 熔断机制 | 风险事件触发熔断 |
| | 用户反馈闭环 | 举报→分析→护栏更新 |

### 1.2 Agent专项护栏（OWASP ASI 2026对齐）

| 护栏 | 防什么 |
|---|---|
| **工具白名单** | 工具滥用——只允许调用白名单工具 |
| **权限边界** | 权限越权——最小权限原则 |
| **沙箱执行** | 工具滥用/级联——代码/操作沙箱 |
| **HITL确认点** | 高风险动作——删除/转账/下单二次确认 |
| **目标锁定** | 目标劫持——关键决策不可被Prompt改 |
| **记忆隔离+审查** | 记忆污染——记忆写入前审查 |
| **步骤校验** | 级联故障——每步校验+可回退 |
| **工具签名验证** | 供应链攻击——MCP/工具来源验证 |

## 二、AI合规法规（2026全球格局）

### 2.1 欧盟AI Act（全球首部综合性AI法）

| 维度 | 内容 |
|---|---|
| **生效时间** | 2024-08-01分阶段生效，**核心条款2026-08-02全面生效** [来源:君合律所/山东外贸学院 | 🔍高 | 2026] |
| **核心原则** | 风险分级监管 |
| **风险四级** | 不可接受（禁止）/高风险/有限风险/最小风险 |
| **禁止类** | 社会评分/公共场所实时生物识别（2025-02起率先强制） |
| **高风险类** | 医疗/教育/关键基础设施——全生命周期监管 |
| **违规罚款** | 最高年营收6%或3000万欧元 |
| **数据要求** | 高风险AI需训练数据质量/偏见检测/人工监督 |

4. **全球AI监管"精细化落地"**——欧盟AI Act 2026-08-02全面生效、中国拟人化办法2026-07-15施行、美国FTC框架，从"原则指引"进"法律约束" [来源:多源 | 🔍高 | 2026]

7. **斯坦福AI指数2026核心警告**——AI能力高速发展但安全/评估框架严重滞后，"能力与治理差距"是核心挑战，PM须主动建风险体系 [来源:Stanford HAI | 🔍高 | 2026-04-13]

9. **AI红队民主化**——A.I.G等开源/免费红队平台普及，红队不再是巨头专利 [来源:腾讯云 | 🔍高 | 2026-07]

## 四、常见坑汇总

| 坑 | 表现 | 应对 |
|---|---|---|
| 合规是法务事 | PM后置审查 | PM全生命周期负责 |
| 靠模型对齐就够 | 不设多层护栏 | 四层护栏纵深 |
| 幻觉只是质量 | 高风险场景不控 | 风险分级控制，医疗/法律/金融<1% |
| 套壳无风险 | 不审查上游 | 套壳合规审查+合同保护 |
| Agent护栏=大模型护栏 | 无工具白名单/沙箱 | ASI 2026专项护栏 |
| 隐私=不上传数据 | 忽视记忆/日志隐私 | 全链路隐私设计 |
| 偏见检测一次就够 | 不持续监测 | 持续偏见监测 |
| 红队上线前做一次 | 不持续 | 持续红队+社区响应 |
| 合规=满足中国法 | 出海翻车 | 多法域合规清单 |
| 审计日志=debug日志 | 不满足法定要求 | 可追溯/不可篡改/法定留存 |
| 只看文本护栏 | 多模态对抗翻车 | 多模态专项审核 |
| 不做风险分级 | 所有场景一视同仁 | 按风险等级差异化控制 |
| 不做DPIA | 高风险AI违规 | 高风险前置DPIA |
| 无熔断机制 | 风险事件扩散 | 风险事件触发熔断 |
| 不更新护栏 | 新型越狱绕过 | 护栏随攻防持续更新 |
