## 本轮关键决策与变更

- **LLM 选型**：**【第2轮已改】** 改用智谱 **Anthropic 兼容端点** `/api/anthropic`（Claude Messages API 格式），模型 **GLM-5**；`x-api-key` 鉴权 + 顶层 `system` + `max_tokens`。配置读取改为 **环境变量优先 → application.yaml 回退 → 默认值**（yaml 已加入 .gitignore，key 不入库）。用裸 `requests` 调 `/v1/messages`，不引入 SDK。
- **参考图匹配**：按 basename 去扩展名、小写模糊匹配（文档写 `cat.jpg`、上传 `CAT.JPG` 也能对上）；**未匹配的参考图直接跳过**（按无该图继续生成），而非让整条失败——对应 plan 的「用户可强制生成（按无参考图）」边界。
- **参考图复用**：同一张图整批只上传 Coze 一次（`file_id_cache`），避免重复上传浪费。
- **并发**：默认 `CONCURRENCY=3`（Coze ≈5 QPS，3 较稳，可经 `BATCH_CONCURRENCY` 环境变量调）；遇限流指数退避重试（2/4/8s）。
- **批次状态**：内存存（`BATCHES` dict），重启即丢——本地工具可接受，因结果图已落盘 `downloads/`。
- **解析→确认→生成**三段式：解析后**先回前端让用户核对/改/删**，确认后才并行提交，避免误拆浪费额度。
