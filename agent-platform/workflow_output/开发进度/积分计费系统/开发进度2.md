## Chunk E 最高风险段如何落地（spec §4 坑点①）

**铁律**：流式 usage 不改 StreamEvent / 不改发出 Flux 数据序列，否则 13 调用方回归。

```
provider.chatStream 入口建 AtomicReference<TokenUsage>
  → .map 阶段 parseStreamChunk(data, usageRef) 解析末 chunk usage 写 ref（usage chunk content 空，会被下游 .filter 丢，故必须在过滤前写 ref）
  → .filter(非空 content)  ← usage chunk 在此被丢，但 ref 已写
  → doOnComplete 读 ref → usageSink.accept(usage)  ← gateway 在此采+扣
```

- **OpenAI**：请求体加 `stream_options:{include_usage:true}`，末 chunk `choices:[]`+`usage:{prompt/completion/total}`。
- **Claude**：usage 拆两事件——`message_start`→`message.usage.input_tokens`，`message_delta`→`usage.output_tokens`，合并成一条 TokenUsage（input+output）。
- **流异常（doOnError）不触发 doOnComplete → 不采不扣**，由 gateway 的 catch→`onFailure` 兜 FAILED。
- **gateway 侧线程策略**：`provider.chatStream(req, sink).publishOn(Schedulers.boundedElastic())`——把完成信号切到阻塞容忍调度器，扣减的同步 DB 事务（UPDATE...RETURNING，<5ms）不阻塞 netty event-loop。publishOn 只切线程不切数据，**SSE 字节不变**。

## embed 估算兜底（spec §4 决策）

- OpenAI 兼容 provider 覆写 `embedWithUsage` 解析响应 `/usage`（embed 多只回 prompt_tokens，completion=0）。
- provider 未回 usage（老端点 / 非 OpenAI）→ usage=null → gateway 用 `TokenEstimator.estimate(text)`（chars/4）估 input、output=0、status=**ESTIMATED**。
- Claude 不覆写 embedWithUsage（其 embed 抛 UnsupportedOperationException；走 interface default，但 Claude 不进 embed 路由）。

## gateway 6 出口接线清单（Step12）

| 出口 | 预检 | 采+扣 | 失败 |
|---|---|---|---|
| `chat(req)` | null 跳 | onSuccess(null,...) 仅采 | onFailure |
| `chat(req,userId)` | requireAffordable | usage 非空 SUCCESS / 空估算 ESTIMATED | onFailure 重抛 |
| `chatStream(req)` | null 跳 | sink=null 路径仅采 | — |
| `chatStream(req,userId)` | requireAffordable | doOnComplete sink→onSuccess | doOnError 不触发 |
| `embed(text,model)` | null 跳 | onSuccess(null,EMBED) 仅采 | onFailure |
| `embed(text,model,userId)` | requireAffordable | embedWithUsage 真/估算 | onFailure 重抛 |

> `chat(req)`/`embed(text,model)` 无 userId 重载 → 委托带 null 版本：系统调用仅采不扣（charge 在 userId=null 短路）。
> `LlmBillingService.onSuccess` 加 `isEnabled()` 短路：billing.enabled=false 时跳过 computeCost，避免价表未配时 PRICING_NOT_FOUND 在 disabled 态误报噪声（record 也随 collector 自短路）。

## 计费链现状（全链就绪）

```
chat/chatStream: token → PricingService.computeCost(CHAT) → ¥
                            → PointsRatioService.toPoints(阶梯) → points
                            → PointsWalletService.charge(UPDATE...RETURNING 行锁) → balance  [同步,不可丢]
                            → UsageCollector.record(llm_usage_logs)                          [异步,可丢]
embed: 同上，kind=EMBED
视频/图片: 待 Chunk F（secs/count 维度，不经 token 路径）
```
