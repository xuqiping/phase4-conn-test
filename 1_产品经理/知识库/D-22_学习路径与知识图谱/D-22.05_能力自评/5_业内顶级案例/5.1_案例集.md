## 案例1：Google PM用360评分校准自评偏差

| 要素 | 内容 |
|---|---|
| 名称 | Google PM 360评分校准实践 |
| 时间 | 2023-2025 |
| 主角 | Google L5→L6 PM |
| 背景 | 该PM自评"产品思维4分/技术理解3分"，但连续2次晋升被拒 |
| 技术手法 | 用Google 5维PM能力模型做360评分(上级+平级+下级+跨职能各2人)→发现产品思维他评3分(自评4分偏高1分)、技术理解他评2分(自评3分偏高1分)→达克效应显著 |
| 影响后果 | 校准后重做差距分析→技术理解差距最大→6个月定向提升技术理解(和工程师结对做技术方案评审)→再次晋升通过 |
| 教训启示 | 自评≠真评，360评分是达克效应的最佳校准器；晋升失败=自评偏差的信号 |
| 反例 | 另一PM不做校准，坚持"自评很准"→连续3年晋升失败→被迫离开 |
| 来源标注 | [来源:Google PM晋升实践+行业访谈 | 置信度:📚中] |
