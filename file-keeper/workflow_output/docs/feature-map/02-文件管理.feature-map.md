# 文件管理 Feature Map

> 当前真相：2026-09-03。重点覆盖收藏项独立快捷键和 Windows `.lnk` 托管。

## 功能与代码

| 功能 | 关键文件 | 作用 |
|---|---|---|
| 收藏数据 | `src/types/file.ts`、`src/stores/fileStore.ts` | 保存原路径、托管描述、失效状态和独立快捷键 |
| 快捷键标准化 | `src/utils/shortcut.ts` | 统一同义按键写法并检测应用内冲突 |
| 收藏快捷键协调 | `src/composables/useFavoriteShortcuts.ts` | 新键先注册，成功后再释放旧键；启动有界恢复 |
| 编辑入口 | `src/components/EditFileDialog.vue`、`src/components/SettingsDialog.vue` | 录入、清空快捷键并展示冲突/恢复失败 |
| 拖入和重定位 | `src/App.vue`、`src/components/AddFileButton.vue`、`src/api/files.ts` | 区分 `.lnk` 与普通文件/文件夹/EXE/Office 文档 |
| `.lnk` 托管 | `src-tauri/src/platform/windows/managed_shortcut.rs` | 解析但不执行，临时复制、校验、随机名原子发布 |
| 文件命令 | `src-tauri/src/commands/files.rs`、`src-tauri/src/main.rs` | 导入、状态检查、重新定位和安全删除 |

## 类型处理矩阵

| 拖入对象 | 保存方式 | 删除收藏时 |
|---|---|---|
| Windows `.lnk` | 复制到应用数据目录 `managed-shortcuts/`，收藏指向托管副本 | 先删收藏元数据，再只删经归属校验的托管副本 |
| 文件夹、PPT/PPTX、普通文件 | 仅记录用户原路径 | 不删除原目录或文件 |
| 非快捷方式 EXE | 仅记录用户原路径 | 不删除 EXE |

## 调用链

```text
拖入路径 → inspect/import 命令
  → Windows 普通 .lnk：复制临时文件 → 校验 → 随机名原子发布
  → 其他类型：返回 direct descriptor，不复制
  → 成功后 fileStore 才新增收藏

触发收藏快捷键 → 重新按收藏 ID 取数据 → 校验路径 → 复用现有打开与统计逻辑
```

## 技术原理（大白话）

- **原子发布**：副本完全写好后才改成正式名。像快递验货后才签收，失败不会留下半个文件。
- **规范路径归属校验**：删除前同时确认父目录、扩展名、普通文件和非重解析点。像仓库出库要核对库位、标签和封条，不能只看名字相似。
- **快捷键两阶段替换**：先占住新键，再释放旧键。像换手机号先确认新卡能用，避免换号失败后两边都联系不上。
- **有界恢复**：启动时只并发处理有限数量快捷键。像分批安检，单个失败不会堵住所有人。

> 路径不上传、不写完整日志；快捷键只关联收藏 ID，不保存脚本或命令参数。
