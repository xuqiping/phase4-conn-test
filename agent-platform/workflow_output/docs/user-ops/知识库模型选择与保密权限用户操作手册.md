# 知识库模型选择与保密权限 · 用户操作手册

> 面向：知识库 OWNER / 被授权成员 / 管理员。配套 [README](../../开发进度/知识库模型选择与保密权限/README.md)。
> 人工测试用例见[测试方案](../测试方案/知识库模型选择与保密权限测试方案.md)。

## 功能一：给知识库指定问答模型（OWNER/管理员）

**入口**：知识库页 → 「新建知识库」或库行「编辑」按钮。

| 步骤 | 操作 | 界面变化 | 完成标志 |
|---|---|---|---|
| 1 | 打开弹窗，找到「问答模型」下拉 | 下拉首项「跟随全局默认」，其余为管理员已启用的 CHAT 模型 | — |
| 2 | 选择某模型（如 glm-5.1）→ 保存 | 提示「更新成功」弹窗关闭 | 重新打开编辑弹窗回显所选模型 |
| 3 | 该库发起 RAG 问答（知识库问答/聊天挂库） | — | 回答由所选模型生成（与其他库不同模型可见风格差异） |

**边界**：
- 选「跟随全局默认」= 用系统设置里的默认聊天模型。
- 所选模型后来被管理员下线 → 问答**不报错**，自动回退全局默认（下线无感）。
- 下拉里不会出现未启用的模型；编辑旧库时若原模型已下线，显示「xxx（当前，未在启用列表）」灰选项，防止静默丢配置。

## 功能二：换向量模型的重建索引提示（OWNER/管理员）

**入口**：库行「编辑」→「Embedding 模型」下拉换一个 → 保存。

| 步骤 | 操作 | 界面变化 | 预期结果 |
|---|---|---|---|
| 1 | 库内已有文档时换 embedding 并保存 | 顶部黄色警告横幅「向量模型已变更…请到索引运维重建索引」，**弹窗不自动关闭** | 读完后手动点「取消」关闭 |
| 2 | 去「索引运维」重建该库索引 | 重建进度可见 | 重建完成后检索恢复正常召回质量 |
| 3 | 空库换 embedding | 无横幅，直接「更新成功」 | 空库无存量向量，无需重建 |

## 功能三：开启保密库（OWNER/管理员）

**入口**：库行「编辑」→「保密库」开关。

| 步骤 | 操作 | 界面变化 | 完成标志 |
|---|---|---|---|
| 1 | 打开「保密库」开关，右侧说明文字实时更新 | 说明：「开启后成员只能通过 RAG 问答获取内容…」 | — |
| 2 | 保存 | 库列表「可见性」列出现橙色「🔒 保密」徽标 | 徽标 hover 有完整语义提示 |
| 3 | 成员再访问该库 | 见功能四 | — |

**边界（必读）**：
- **公开（PUBLIC）库不能开保密**：可见性选「公开」时开关自动禁用并提示「公开库不支持保密」；想开保密先改成私有/团队。
- 开关可逆：关掉后成员立即恢复全部权限。
- OWNER 和管理员**永远不受限**，随时可看原件。
- 保密切换会记入审计日志（谁在何时开的/关的）。

## 功能四：保密库的成员视角（被授权成员）

开关打开后，成员（非 OWNER/非管理员）在该库看到：

| 功能 | 之前 | 现在 |
|---|---|---|
| 文档列表/详情 | 有「下载原件」链接 | 链接消失，**标题/状态等目录信息保留**（知道库里有什么） |
| 文档展开（切片原文） | 可见 L0 摘要/L2 原文 | 显示「🔒 保密库：原件仅可经问答召回，如需全文请联系库管理员」 |
| 图片/文件缩略图 | 可预览 | 变为上面的保密提示 |
| 检索调试面板 | 可选该库跑调试 | 该库灰显「（保密库，仅问答）」不可选 |
| 聊天引用 [n] | FILE 引用带「⬇ 下载原件」、IMAGE 带缩略图 | 引用条目还在（标题可见），**下载钮/缩略图消失** |
| **RAG 问答** | 正常 | **完全正常——这是唯一的内容出口** |

**常见异常与恢复**：

| 现象 | 原因 | 恢复 |
|---|---|---|
| 提示「保密知识库：内容仅可通过 RAG 问答召回…」(403) | 成员直调了原件/切片/调试接口 | 走问答；确需全文联系库 OWNER |
| 聊天引用没有下载钮但别的库有 | 该引用来自保密库（设计行为） | 联系 OWNER 关闭保密开关 |
| 历史消息引用突然没了下载钮 | 旧缓存回放的引用按当前保密标志渲染 | 属预期；下载本就被 403 挡住 |
| 想开保密但开关点不动 | 库可见性是 PUBLIC | 先把可见性改为私有/团队 |
