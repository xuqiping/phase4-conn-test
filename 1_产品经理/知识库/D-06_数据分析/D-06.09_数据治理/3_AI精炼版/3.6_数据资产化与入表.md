# 3.6 数据资产化与入表

## 数据资产化全景

### 从"成本中心"到"资产"的路径

```
数据资源(原始) → 数据治理(标准化/质量/安全) → 数据资产(可信任/可发现/可计量) → 数据产品(可交易) → 数据资本(可入表)
```

### 数据资产化四步法

| 步骤 | 核心动作 | 产出物 | PM角色 |
|---|---|---|---|
| 1.数据盘点 | 全面摸清企业有哪些数据、在哪、质量如何 | 数据资产清单+数据地图 | 提供业务视角的分类与优先级 |
| 2.数据目录 | 构建可搜索、可理解、可信任的资产目录 | 数据目录平台+标签体系 | 定义业务分类+指标标签+使用场景 |
| 3.价值评估 | 评估数据资产的业务价值与经济价值 | 数据价值评估报告 | 从业务收益角度量化数据价值 |
| 4.数据入表 | 将数据作为资产计入财务报表 | 数据资源会计核算+审计报告 | 配合财务定义数据使用场景与收益 |

## 数据目录建设

### 数据目录核心能力

| 能力 | 说明 |
|---|---|
| 搜索发现 | 关键词/标签/分类多维度搜索数据资产 |
| 资产详情 | 元数据+血缘+质量评分+使用统计+负责人 |
| 标签体系 | 业务标签+技术标签+安全标签+自定义标签 |
| 血缘可视化 | 端到端数据流向图+影响分析 |
| 协作评价 | 用户对数据的评价/补充/纠错 |
| 订阅通知 | 数据变更/质量异常自动推送 |
| 权限管控 | 基于分级分类的浏览/申请/审批流 |

### 数据资产盘点的PM视角

**盘点关键问题**：
1. 企业有哪些核心数据域？（客户/产品/交易/行为/财务…）
2. 每个数据域有多少数据源/表/字段？
3. 数据质量现状如何？（质量评分/缺失率/问题清单）
4. 谁在用这些数据？（使用频次/核心消费方）
5. 数据产生了哪些业务价值？（支撑哪些报表/模型/决策）

## 数据入表政策要点

### 财政部数据资源会计准则（2024年1月生效）

| 维度 | 要求 |
|---|---|
| 适用对象 | 企业合法拥有或控制的、预期带来经济利益的数据资源 |
| 确认条件 | ①企业合法拥有/控制 ②预期带来经济利益 ③成本可可靠计量 |
| 计量方式 | 初始计量=成本法（采购成本/开发成本）；后续可按公允价值重估 |
| 披露要求 | 强制披露：数据资源类别/获取方式/使用寿命/摊销方法；自愿披露：数据资源应用场景/对业务的影响 |
| 前提条件 | 数据治理体系完善（质量可信+权属清晰+安全合规）——入表倒逼治理 |

### 国家数据局《数据产权登记工作指引》

**三权分置框架**（2026年推进）：

| 权利 | 定义 | 典型场景 |
|---|---|---|
| 数据持有权 | 对数据资源的合法持有 | 企业自己采集/生产的数据 |
| 数据使用权 | 按约定使用数据的权利 | 授权第三方分析你提供的数据 |
| 数据经营权 | 运营数据并获得收益的权利 | 数据交易平台出售数据产品 |

> 本指引系统回答了"谁来登、登什么、怎么登、登了有什么用"，为数据资产确权提供操作依据。[来源:国家数据局 | 置信度:🔍高 | 2026]

### PM在入表中的角色

- **业务场景定义**：说明数据用于什么业务场景、产生了什么经济收益
- **数据质量背书**：确认入表数据的质量达标（质量评分+治理证明）
- **权属确认**：明确数据来源合法、企业拥有持有权/使用权
- **使用价值量化**：从业务角度评估数据带来的增量收入/降低成本/提升效率
