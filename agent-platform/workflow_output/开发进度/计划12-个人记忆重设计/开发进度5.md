### D-6 主流程编排 + 装配 ①⑦（✅ commit `feat 计划12迭代D-6` `a9c661f9`）
- 新 `MemoryRecallResult` / `RecallTraceStep` DTO（assembledText + selectedTags + counts + degraded + notes + traceId + steps）。
- 新 `MemoryRecallPipeline` @Service 串七步：①resolve → ②aggregate → ③select → ④⑤read → ⑥patch → ⑦assemble，每步 `System.nanoTime` 计时 + `RecallTraceStep` 打点。
- **⑦ 装配格式裁决**（设计 §3.3 line 110 落地）：行 `- {owner前缀}{subject前缀}{topic}：{content}`。
  - owner≠self 加 `user#{id}·` 占位（D-7 前端查用户名美化，D-6 不引 UserService 解耦）。
  - subject='我'/null/空 → 省主体（owner≠self 时 owner 名天然替代「我」，对齐 line 110「【张三·爱好】」）。
  - subject 非「我」（表哥/配偶…）→ 保留主体 `{subject}·`。
  - turn 无单值 subject/topic（多 tag 难归属）→ 直接 `- {owner?}[{direction}] {rawContent}`。
- **tags 空跳 select/read**：aggregate 返空时跳 selector/reader 直走 patch turns 兜底（防 unstubbed mock 返 null NPE + 语义「无标签→turns 兜底」）。
- **selector 降级启发式**：selector 不暴露降级信号，pipeline 用 `tags.size()>COARSE_TOP && selected.size()==tags.size()` 判 LLM 全失败用全集 → 标 degraded。
- **降级链**：子组件内部已消化 LLM 失败（不抛），pipeline 每步再 try-catch 兜 mapper/意外异常 → `notes` 收明细 + `degraded=true`，不中断后续步。
- **最多 2 次 LLM**：select(1) + reflect(1，仅 summary>5 触发)；embed 不计 chat LLM。
- TDD：MemoryRecallPipelineTest **15 绿**（空 scope/happy path/4 种 owner×subject 前缀/includeL2 true-false/turn 装配/aggregate+read 抛降级/select 返空/selector 降级启发式/steps 6 步/scope 透传）。
- **XML 正确性 + 全链 IT 仍留 D-7**（单测 mock 5 子组件不启 Spring）。
