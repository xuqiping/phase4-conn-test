# 4.2 卡片分类实操模板

## 开放卡片分类执行模板

### 准备阶段

| 项目 | 检查 |
|---|---|
| 内容卡片数 | 30-50张（核心内容项） |
| 用户样本 | 15-30人，含新手+老手 |
| 工具 | OptimalSort / FigJam / 实体卡片 |
| 分组指引 | "请按你的理解将这些卡片分成几组，并为每组起个名字" |

### 执行话术模板

> "这是一些[产品名]的功能/内容卡片。请按照你觉得最自然的方式把它们分组——没有标准答案，按你自己的直觉来就好。分完后给每一组起一个名字。如果你觉得某张卡片不属于任何组，也可以单独放一边。"

### 结果分析SOP

1. **导出原始数据**：每人的分组结果
2. **构建相似度矩阵**：每对卡片被分到同一组的频率
3. **层次聚类**：生成Dendrogram，可视化聚类关系
4. **识别共识簇**：高共识度（>70%用户同组）= 稳定分类
5. **标记分歧卡片**：低共识度（<40%用户同组）= 需讨论/多入口
6. **生成候选分类**：基于聚类+业务判断，输出2-3套候选

### 输出模板

| 聚类编号 | 标签候选 | 包含卡片 | 共识度 | 备注 |
|---|---|---|---|---|
| C1 | 订单/交易/购买 | 订单管理,购物车,支付,退款… | 78% | 高共识 |
| C2 | 设置/配置/账户 | 个人信息,安全设置,通知偏好… | 65% | 可拆分 |
| C3 | ? | 消息,通知,公告,活动 | 35% | 分歧大→多入口 |

## 封闭卡片分类执行模板

### 准备阶段

| 项目 | 检查 |
|---|---|
| 预设分组 | 来自开放卡分结果+业务约束 |
| 卡片数 | 同开放卡分 |
| 用户样本 | 20-50人（可与开放卡分人群不同） |
| 指引 | "请将每张卡片放入你觉得最合适的组" |

### 成功判定标准

| 指标 | 达标线 |
|---|---|
| 单卡片归组正确率 | >70% |
| 整体方案一致性 | >60% |
| 无明确归属的卡片比例 | <10% |

## AI辅助卡片分类 Prompt模板

### Prompt 1：AI生成初始分类方案

```
你是一位资深信息架构师。以下是一个[产品类型]产品的50个核心功能/内容项：
[列出全部内容项]

请基于以下原则生成2套候选分类方案：
1. 面向[目标用户]的心智模型（不是内部组织架构）
2. 层级不超过3层
3. 每组3-7个项目
4. 标签用用户易懂的语言

输出格式：
- 方案名称
- 层级结构（用缩进表示）
- 每项的标签候选（2-3组）
- 未归位项目及原因说明
```

```
以下是N位用户的开放卡片分类结果（每人分组+组名）：
[粘贴卡分数据]

请：
1. 计算每对卡片的相似度（被同组频率）
2. 识别高共识簇（>70%用户同组）
3. 标记高分歧卡片（<40%用户同组）
4. 提出2套综合分类方案
5. 对分歧卡片给出处理建议（多入口/拆分/合并）

注意：你的分析仅作参考初稿，最终方案需经人工审阅和用户验证。
```
