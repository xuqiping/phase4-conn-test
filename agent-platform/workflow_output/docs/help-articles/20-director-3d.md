# 导演台：3D 构图

> 在画布上搭 3D 场面、多机位取景，截图回流画布当生图/生视频的参考图。
> 入口：无限画布 → 左调色板点「**导演台**」节点。

## 一、建导演台节点并打开

1. 画布左调色板点「导演台」→ 画布出现节点卡片。
2. 双击节点或点「**打开导演台**」→ 全屏编辑器：左边加元素 / 中间 3D 视口 / 右边属性+机位。

## 二、摆场面

1. 左栏「人物」区点体型 → 视口出现素模人。
2. 选中人物 → 右栏改**姿势**（站/坐/走/跑/蹲/躺）、点色板换色。
3. 左栏加桌子/椅子/箱子；「群众」填行列间距 → 一键生成整片人群。
4. 拖 gizmo 移动/旋转元素；按 **V/R/S** 切移动/旋转/缩放模式（缩放按住 Shift = 等比）。
5. 右侧清单每行可：隐藏（眼睛）/ 复制 / 删除。

> 上限：元素 200 个、机位 16 个。

## 三、机位取景与截图

1. 鼠标右键/滚轮调好导演视角 → 右栏「机位」→「**从当前视角新增机位**」→ 视口出现青色视锥。
2. 机位行点「**看**」→ 主视口切到该机位视角（带黑边遮幅 + 画幅标签）；点「导演视角」返回。
3. 调 **FOV 滑杆**（15-90）和**画幅**（16:9 / 9:16 / 1:1 / 4:3 / 2.39:1），遮幅实时变化。
4. 机位视角下点顶栏「**截图回流画布**」→ 画布自动新增图片节点并连线；导演台卡片封面变成最新截图。
5. 换机位再截 → 多张图自动错开排列。

## 四、保存与撤销

- 点「完成并关闭」回画布 → **记得点画布「保存」**（不保存直接刷新会回上次保存版）。
- 编辑器内 Ctrl+Z / Ctrl+Shift+Z 撤销/重做（最多 50 步，含机位）。

## 常见异常

| 现象 | 原因 | 恢复 |
|---|---|---|
| 「无法打开导演台」 | 浏览器不支持/禁用了 WebGL | 换 Chrome/Edge 或开启 WebGL |
| 截图失败红提示 | 断网/上传超时 | 恢复网络重按截图（不会产生空节点） |
| 卡片封面是空的 | 从没截过图 | 进机位视角截一张即有封面 |
