## 实测发现（3 个测试工装坑 + 1 个库行为备注，均非 VIII 产品缺陷）

1. **vue-flow 默认 `SelectionMode.Full`**：框选矩形必须**完整包住**节点才选中（部分相交不算）——冒烟框选一开始按"相交"划框选不中。产品无感（人手划框自然划大）。
2. **`fit-view-on-init` 对小画布会 zoom 到 2×**：节点拖拽屏幕位移=流坐标位移÷zoom，固定像素拖拽失准。解法：API 预置快照摆好节点再开页（脚本走法），或反馈式多轮逼近。
3. **簇叠节点遮挡**：调色板连点的节点随机位堆叠，按 nth(i) 中心拖会拖到别的节点。
4. **多选包围盒 rect 盖住组员 handle**：Shift 框选/设组后 vue-flow 渲染多选包围盒（可拖动整组），此时去拖成员节点圆点=拖整组而非拉线。**库标准行为，点空白即消**；已在测试方案 M9 加前置说明。真实用户无感（拉线前自然先点空白或直接拉未选中节点）。
   - 附带发现：`selectionKeyCode` 传 `'Shift'` 字符串时 vue-flow 1.48 prop 校验告警（Boolean|Null）但功能正常——既有代码，不动。
