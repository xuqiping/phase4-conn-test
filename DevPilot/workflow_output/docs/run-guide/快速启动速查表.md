# DevPilot 快速启动速查表

> last_updated: 2026-08-16 ｜ 适用：P01+P02 交付后（桌面骨架 + 云端账号计费/模型网关）

## 一图流

```
克隆仓库 → 装依赖 → dev 启动 →（可选）出包
```

## 环境要求

| 项 | 要求 |
|---|---|
| Rust | stable + cargo（含 tauri-cli 依赖自动拉取） |
| Node | ≥ 20（含 npm） |
| WebView | Win 自带 WebView2；Mac 系统 WKWebView |
| 数据库 | 桌面无需安装（SQLite bundled）；云端也无需安装（PGlite 进程内 WASM PG，dev/test 零外部依赖） |

## 首次启动（3 条命令）

```bash
cd DevPilot/PROJECT/desktop
npm install                 # 前端依赖（含 playwright，仅 dev 用）
npm run tauri dev           # 编译 Rust + 起 Vite(:1420) + 开真窗口
```

- 首次 Rust 编译较慢（几分钟）；之后增量秒级
- 窗口打开后：左上「未选择项目」→ 创建项目向导（走真 IPC + 状态机）

## 常用命令

| 命令 | 用途 |
|---|---|
| `npm run tauri dev` | 开发模式（热更新） |
| `npm run tauri build` | 出包（Win 产 MSI/NSIS，Mac 产 dmg/app） |
| `npm run test` | 前端 Vitest 单测（12 个） |
| `node scripts/smoke-ui.mjs` | 界面冒烟（需 dev server 已起；用系统 Edge，零下载） |
| `bash ../../scripts/check_all.sh` | 全量质量门（桌面 UI/Rust + 云端 lint/tsc/unit/e2e + docs） |

## 云端启动（P02 起）

```bash
cd DevPilot/PROJECT/cloud
npm install
# 必带 JWT 密钥（缺了注册/登录 500「secretOrPrivateKey must have a value」）
JWT_ACCESS_SECRET=dev-only-change-me JWT_REFRESH_SECRET=dev-only-change-me-too PORT=3000 npm run start      # 监听 :3000，前缀 /api/v1
```

- 上游供应商默认全 mock（`GATEWAY_PROVIDER` 未配=mock），无需任何真实模型 key
- 验证：`curl http://127.0.0.1:3000/api/v1/healthz`
- 生产必配：`PAYMENT_HMAC_SECRET`（缺配时回调服务拒绝工作，防自签伪造充值）

## 端口速查

| 服务 | 端口 |
|---|---|
| 桌面前端 dev（Vite） | 1420 |
| 云端 API（NestJS） | 3000（env PORT 可改） |

**查/关端口（Windows）**：`netstat -ano | findstr :3000` → `taskkill /PID <PID> /F`；Linux：`lsof -i:3000` → `kill -9`

## Rust 侧

```bash
cd DevPilot/PROJECT/desktop/src-tauri
cargo test --workspace        # ⚠ 必须 --workspace，否则 crate 测试静默跳过
cargo clippy --workspace --all-targets
```

SQLite 数据位置：用户数据目录下 devpilot 数据库（WAL 模式，L 版本迁移自动执行）。

## 出包（Win 示例）

```bash
npm run tauri build   # 产物在 src-tauri/target/release/bundle/
```

签名：当前未配置证书 → 产物未签名（正式发布需用户提供证书，P02+ 处理）。

## 排错速查

| 症状 | 处置 |
|---|---|
| `npm run tauri dev` 起不来 | 确认端口 1420 未占用；删 node_modules 重装 |
| 冒烟脚本报连不上 | 先起 dev server（冒烟只测界面壳层，浏览器无 Tauri IPC 属预期） |
| cargo 下载慢 | 设代理：`export https_proxy=http://127.0.0.1:7892`（用户本地代理） |
| Playwright 下载卡死 | 本脚本用系统 Edge 免下载；若手写脚本需 `channel:"msedge"` |

## 术语

- **WAL**（Write-Ahead Logging）：SQLite 先写日志再落盘的并发友好模式
- **IPC**（进程间通信）：前端 JS ↔ Rust 内核的调用通道
- **MSI/NSIS**：Windows 两种安装包格式
