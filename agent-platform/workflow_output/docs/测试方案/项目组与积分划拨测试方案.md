# 项目组与积分划拨 · 人工测试方案

> 对应 plan：`docs/plans/项目组与积分划拨.plan.md`（Step1-8 已落地）。
> 本功能涉及真实扣费、多角色视角、跨入口联动——机器测不了体感与流程闭环，需人工介入。
> 联动用例覆盖 plan 联动点清单 L1-L7（含正向/反向/半选/批量边界）。

## 前置准备

- 三个账号：`leader`（组长）、`member1`/`member2`（成员）、`outsider`（无关人）；均需 `project-group:manage` 权限码（V134 种子给默认角色）。
- leader 个人钱包充值 ≥1000 分（admin 积分充值页）。
- 后端起服务，浏览器双开（leader / member1 各一窗）。

## 一、建组与划拨（Step 2/3）

| # | 操作 | 预期 |
|---|---|---|
| A1 | leader 项目组页→新建「测试组」 | 列表出现卡片，角色标「组长」，组池 0 |
| A2 | 点组卡片→划拨 500 | 组池 500；个人钱包 −500；流水出现「划入 +500 balance_after=500」；列表卡片余额刷新 |
| A3 | 划拨 0 / 划拨超个人余额 | 均被拒，文案明确，流水无新行 |
| A4 | 回收 200 | 组池 300；个人 +200；流水「回收 −200」；弹窗含在途封顶提示文案 |
| A5 | 加成员：搜索 member1 + 限额 100；member2 不限额 | 成员表两行，限额列 100 / 不限 |
| A6 | outsider 建组页访问 | 菜单不可见（无权限码场景）；直敲 URL /project-groups → 接口 403 |

## 二、五入口选择器与组池扣费（Step 4/5/6 · 联动 L1/L4）

| # | 操作 | 预期 |
|---|---|---|
| B1 | member1 对话页选「测试组」发消息 | 组池扣减；member1 个人余额**不变**；徽标余额刷新 |
| B2 | 切回「个人」再发 | 个人扣费；usage 行不带组（账单「项目组」列=「—」） |
| B3 | 对话页切旧会话 | 各会话记住各自的组选择（localStorage 每入口独立） |
| B4 | member1 图片/视频/知识库问答/画布 四入口各选组发起一次 | 全走组池（组流水 4 笔 CONSUME；个人零变动） |
| B5 | 画布：选组→保存→刷新 | 选择保持（快照顶层持久化）；运行节点请求带 gid |
| B6 | member2 无限额消耗到组池尽 | 40201「项目组积分不足」 |
| B7 | member1 消耗到限额（used>100−est） | 400「超出组长配置的成员积分限额」，member2 仍可用（限额按人） |
| B8 | member1 提交视频任务（异步）后组长立刻回收全部 | 回收被在途占额封顶拒绝或仅回收余量；任务成功后结算若组池不足→流水 BACKSTOP 行（组长个人补差） |
| B9 | 失败任务退款 | 组池回加 + used 回减 + REFUND 行；member1 限额余量恢复可再用 |

## 三、项目推进页（Step 7）

| # | 操作 | 预期 |
|---|---|---|
| C1 | leader 组详情→产出 tab | 全员行：成员名/类型/模型/内容摘要/任务状态/积分；筛选成员=member1 只剩其行 |
| C2 | 筛选类型=视频、日期=今天 | 仅今天的视频行；清空恢复 |
| C3 | leader 组池流水 tab | 分页翻页/改页大小生效；类型标签对（划入/消耗/退款/兜底） |
| C4 | member1 打开同组 | 只见产出 tab；行**仅自己**；成员筛选下拉不渲染；有「仅显示自己的消耗行」提示 |
| C5 | member1 直敲 overview URL | 403（管理总览组长专属） |
| C6 | outsider 直敲 outputs URL | 403「非本项目组成员」 |
| C7 | 组长调限额/重置已用/移除成员 | 见 L4/L7/L5 用例 |

|---|---|---|
| D1 | admin 账单总览→调用明细 | 有「项目组」列；组池行显组名，个人行显「—」；旧数据行全「—」 |

## 五、联动专项（L4/L5/L6/L7 边界）

| # | 联动点 | 操作 | 预期（反向/边界） |
|---|---|---|---|
| E1 | L4 调低限额 | member1 used=90 时组长限额 100→80 | 不追偿（used 仍 90）；下一次消耗 est>−10 即拒 |
| E2 | L4 调高限额 | 80→200 | 立即解禁可继续消耗 |
| E3 | L5 移除成员 | member2 在途任务未结算时被移除 | 选择器即消失；在途结算仍入组账（历史行保留）；member2 残留页面提交→403 提示回落个人 |
| E4 | L6 组池清零删组 | 回收至 0→删除组 | 成功；五入口选择器该组消失；旧画布快照 gid 提交→按个人计费+提示 |
| E5 | L6 拒删 | 组池 300 时删组 | 拒绝「组池须为 0」 |
| E6 | L7 重置已用 | member1 used=90→重置 | used=0 可再消耗；流水多一笔「调整」（delta=0 留痕）；进行中请求不受影响 |

## 六、成员复活与成员权限（17x#1/#2 · V139，2026-08-21 二轮）

| # | 操作 | 预期 |
|---|---|---|
| F1 复活 | member1 被移除 → 组长再邀请 → member1 同意 | 入组成功（不再 409）；成员行已用=0、角色=成员、开关/可见性=默认；流水多「调整·成员回归复活」行 |
| F2 复活并发 | 同一邀请两个标签页同时点「同意」 | 一个成功；另一个友好 409「该用户已在项目组中」 |
| F3 角色任免 | 组长在成员表角色列把 member2 升为管理 | member2 刷新后：组卡片标「管理」；详情有 成员/流水(只读)/审批/产出 tab，**无设置 tab、无划拨回收按钮**；可邀请/调限额/移除普通成员 |
| F4 管理边界 | member2(管理) 尝试：①划拨 ②改设置 ③把另一管理降成员 ④给自己调限额 | ①② UI 无入口；③④ 成员行操作按钮不渲染（直敲 URL 403/400「仅可管理普通成员/组内角色无权」） |
| F5 功能开关 | 组长给 member1 开关只勾「对话」 | member1 组内对话正常扣组池；组内生图/视频提交被拦，toast「组长已限制你在本组使用该类模型（图片）」；切「不限制」保存后恢复 |
| F6 全禁 | 开关弹窗一个都不勾保存 | 亮「全禁」警告；member1 组内任何消耗均被拦 |
| F7 成员可见性 | 组默认各自只见自己；给 member1 可见性弹窗把「对话」设「全员可见」 | member3 产出 tab 能看到 member1 的对话行，但图片/视频行仍不可见；member1 改回「跟随组默认」后恢复不可见 |
| F8 管理恒可见 | 组默认各自只见自己 | member2(管理) 产出 tab 看全组行，与组长一致 |

## 通过标准

- A1-A6/B1-B9/C1-C6/D1-D3/E1-E6/F1-F8 全过；
- 全程个人钱包余额变动 = 划出−回收+BACKSTOP 补差（无不明漂移）；
- 组池 `balance_after` 链条连续（每行余额=上一行±delta）。
