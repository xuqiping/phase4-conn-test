# 影响评估：人工测试问题 1—4 修复

> 日期：2026-09-03
> 状态：Phase 3 开发中
> 规格：[人工测试问题 1—4 修复 PRD](../specs/人工测试问题1-4修复.PRD.md)
> 计划：[人工测试问题 1—4 修复实施计划](../plans/人工测试问题1-4修复.plan.md)

## 1. 变更目标

修复收藏项快捷键、Windows `.lnk` 生存、进程标题默认展示、关闭后悬浮球、剪贴板置顶和剪贴板分组六项问题。全部能力保持本地可用，不依赖登录、会员或服务端。

## 2. 直接影响范围

| 模块 | 当前行为 | 目标行为 | 主要风险 |
|---|---|---|---|
| 收藏项 | 无独立快捷键；路径直接保存 | 任意收藏可绑定快捷键；统一冲突检测 | 注册替换失败导致旧快捷键失效 |
| `.lnk` | 保存桌面原路径 | 复制到应用托管目录后启动副本 | 缓存越界删除用户文件 |
| 进程列 | 已采集标题但默认隐藏 | 新旧用户按版本规则默认展示 | 迁移反复覆盖用户手动选择 |
| 关闭行为 | 托盘或直接关闭 | 悬浮球、托盘、退出三态 | 隐藏后没有可见恢复入口 |
| 剪贴板 | 有 `is_pinned` 底座但无入口 | 稳定置顶排序和右键操作 | 排序不稳定、并发回滚覆盖新状态 |
| 剪贴板分组 | 无分组 | 单归属、固定全部/未分组、自定义组 | 删组误删记录、旧库迁移失败 |

## 3. 数据与兼容影响

- `FileItem` 只增加可选字段；旧收藏缺失字段时按普通路径处理。
- `Settings.minimizeToTray` 兼容读取一次，迁移为 `closeBehavior`；新版本不再写旧字段。
- 进程设置按列 key 合并并记录版本，不能整数组覆盖。
- 剪贴板 SQLite 使用 `PRAGMA user_version` 事务迁移；旧记录默认未分组、不置顶。
- 不修改 Spring Boot、PostgreSQL、Redis、管理后台或登录链路。

## 4. 删除与隐私边界

- 删除普通文件、文件夹、Office 文档或 EXE 收藏，只删除收藏元数据。
- 仅允许删除 File Keeper 托管根目录直属的普通 `.lnk`；根目录、目录、符号链接、连接点和越界路径一律拒绝。
- 导入 `.lnk` 只解析和复制，不执行目标。
- 收藏路径、窗口标题、快捷键、剪贴板正文和分组信息不上传、不写持久化诊断日志。

## 5. 功能联动与回归

- 修改收藏快捷键：新键成功后才释放旧键；清空时注销；失败时持久化不变。
- 删除或重新定位收藏：同步处理托管副本和快捷键，保留或清理范围必须与动作一致。
- 隐藏/恢复主窗：悬浮球和托盘互斥；恢复主窗后隐藏悬浮球。
- 切换剪贴板分组：刷新查询、选择和详情；不可见选择不参与批量操作。
- 删除分组：所属记录回到未分组，不删除内容。
- 回归覆盖收藏增删改/排序/批量打开、三类现有快捷键、托盘、进程关闭、剪贴板监控/搜索/复制/删除/OCR/缓存清理。

## 6. 回滚策略

- 每个 Chunk 独立提交，按提交倒序回滚代码。
- Pinia 新字段保留旧字段兼容读取；回滚旧版本时不要求破坏性清理。
- SQLite 迁移只新增表、列和索引；应用回滚后旧查询忽略新增字段，数据库文件不降级改写。
- 托管 `.lnk` 作为可安全遗留的应用缓存；回滚时不批量删除，避免错误扩大。
- 人工测试问题文档只有 Phase 4 实测通过后才改为“已解决”。

## 7. 不在本次范围

- 云同步、跨设备同步、服务端分组、嵌套分组、多标签归属。
- macOS `.app` 或 Linux `.desktop` 托管复制。
- 快捷键序列、宏命令、额外启动参数。
- 服务端监控、远程开关或后台运维页面。

## 8. 术语表

| 术语 | 大白话 | 示例 |
|---|---|---|
| 兼容读取 | 新版本仍看得懂旧数据 | 读取旧 `minimizeToTray` 后转成三态设置 |
| 安全遗留 | 留着比自动删除更安全的无害缓存 | 回滚后不批量清空托管 `.lnk` |
| 单归属 | 一条记录最多放进一个组 | 一段文字不能同时属于两个剪贴板组 |
