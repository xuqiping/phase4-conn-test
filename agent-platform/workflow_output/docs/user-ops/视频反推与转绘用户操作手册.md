# 视频反推与转绘 · 用户操作手册

> 面向持有 `media:gen` 权限的用户。两个入口：**视频生成页「视频反推」Tab**（推荐，链路最全）与**无限画布视频节点**。
> 前置：视频时长 ≤10 分钟；勾分镜/剧本才消耗多模态 token（仅勾关键帧零 LLM 成本）。

---

## 功能一：视频生成页反推（上传/历史任务 → 三产物 → 转绘 → 再生成）

**入口**：侧边栏「视频生成」→ 顶部 Tab「视频反推」。

**操作步骤**：

| 步骤 | 用户操作 | 界面变化 | 预期结果 |
|---|---|---|---|
| 1 | 「① 选择视频来源」选「上传本地视频」传文件，或「从历史任务选」下拉挑已完成任务 | 上传显示「已选：文件名」；下拉列出本人最近 50 条成功视频任务 | 来源就绪，「开始反推」解禁 |
| 2 | 「② 反推产物」勾选：关键帧（默认）/分镜表/剧本；可展开「帧数(4-24)/阈值(0.1-0.9)」 | 提示文案随帧数联动「≤N 帧多模态 token」 | 知道大概花多少积分 |
| 3 | 点「开始反推」 | 按钮转圈；长任务可点「取消」 | 「③ 反推结果」出现：N 帧·时长·场景检测/均匀采样 + 模型标签 |
| 4 | 查看关键帧时间轴条 | 缩略横排，每帧标时间戳；**悬浮放大**，**点击全屏** | 镜头切换单元一目了然 |
| 5 | 查看分镜表/剧本 | 分镜表列：#/起止/景别/运镜/画面描述/台词；剧本为格式化 JSON，右上「复制」可带走 | 三产物齐 |
| 6 | （可选）「④ 本土化转绘」填目标地区（如「美国」）+ 保留要求（如「保留春节团圆情节」）→「开始转绘」 | 黄色警示条（若有）+ 改写剧本 + 替换清单（原元素/替换为/位置） | 筷子→刀叉逐条可核对；场景数不一致会有「请人工核对」警示但结果仍可用 |
| 7 | 点「用剧本生成（原剧本/本土化）→ 填入生成表单」（转绘后默认本土化版，radio 可切回） | 若生成表单已有提示词/参考视频 → 弹窗三选：**取消/追加/替换** | 自动切回「视频生成」Tab：提示词=剧本文本，参考视频槽=源视频（首尾帧模式下不带入只提示） |
| 8 | 检查预填内容，点「提交生成」 | 「当前任务」走 排队→生成中→已完成 | 新视频产出 |

**完成标志**：反推三产物可查 + （可选）转绘核对过 + 预填后的生成任务提交成功。

**常见异常与恢复**：
- 「已取消反推」：只断了等待，已抽的帧文件保留，可直接重试。
- 「模型未返回合法 JSON，请重试」：重试一次即过（已内置 1 次自动重试，这是第二次也失败）。
- 转绘警示条：结果仍可用，人工扫一遍 changeLog 再用。
- 历史任务下拉为空：仅列**本人 SUCCEEDED 且有产物**的视频任务，先去生成一条。

## 功能二：无限画布反推（视频节点 → 衍生节点连边）

**入口**：无限画布 → 选中视频节点 → 右侧属性面板「反推」区。

**操作步骤**：

| 步骤 | 用户操作 | 界面变化 | 预期结果 |
|---|---|---|---|
| 1 | 勾选产物（关键帧默认/分镜/剧本），可调帧数/阈值 | 计费提示随帧数联动 | 同功能一步骤 2 |
| 2 | 点「开始反推」（进行中可「取消」） | 视频节点旁自动新建：每帧一个图片节点（纵向排列、自动连边）+ 分镜节点 + 剧本节点 | 衍生节点全连通可回溯 |
| 3 | 选中 script（剧本）或 storyboard（分镜）节点 → 属性面板「本土化转绘」 | 弹窗：目标地区 + 保留要求 | — |
| 4 | 填写并确认 | 新 script 节点连自原节点，标签「本土化(地区)」；warning（若有）toast 提示「结果仍可用请人工核对」 | 原节点内容**不动** |
| 5 | 点新剧本节点查看详情 | data 内含 changeLog 与警示 | 逐条核对替换 |

**完成标志**：衍生节点链完整（帧图可悬浮放大），转绘产物连边且原稿未变。

**常见异常与恢复**：
- 反推失败：不产生任何半成品节点，源节点标红错误信息，直接重试。
- 取消：画布零节点（服务端已抽的帧保留，重跑重新抽帧）。

## 两入口差异速查

| | 视频生成页 Tab | 无限画布 |
|---|---|---|
| 来源 | 上传本地 / 历史任务 | 画布上的视频节点 |
| 产物形态 | 面板内时间轴条+表格 | 独立节点+连线（可继续@引用） |
| 转绘 | 面板④卡片 | 新 script 节点 |
| 回流生成 | 「用剧本生成」一键预填 | 剧本可 @ 进任意文本节点 prompt |
