# 3.1 定义与留存分类

## A.01 核心定义

**留存分析（Retention Analysis）** 是度量用户在首次触达产品后不同时间点仍回访/使用产品的比例，反映产品长期粘性与用户价值。核心公式：

```
N日留存率 = (第N日仍回访的用户数 / 首日新增用户数) × 100%
```

**一句话定位**：留存是产品的"体检报告"——新增告诉你有多少人来了，留存告诉你有多少人愿意留下。

## A.04 边界与不含什么

**留存分析包含**：留存率计算、留存曲线解读、群组分析、流失定位与预警、留存优化策略。

**留存分析不含**：指标体系设计（→D-06.01）、数据采集（→D-06.02）、漏斗分析（→D-06.03）、路径发现（→D-06.05）、因果推断（→D-06.06）。

## I.01 核心术语

| 术语 | 定义 |
|---|---|
| 留存率(Retention Rate) | 首次访问后第N天仍回访的用户占比 |
| 流失率(Churn Rate) | 1 - 留存率 |
| 同期群(Cohort) | 在同一时间段内首次使用产品的用户群体 |
| 次日留存(D1 Retention) | 注册/首次使用后第1天仍回访的比例 |
| 7日留存(D7 Retention) | 注册后第7天仍回访的比例 |
| 30日留存(D30 Retention) | 注册后第30天仍回访的比例 |
| N-Day留存 | 严格在第N天回访才算留存（日历对齐） |
| Unbounded留存 | 第N天及之后任意一天回访都算留存（累计） |
| Bracket留存 | 在指定时间段内回访算留存（如7±1天） |

## I.03 三种留存计算方式

### 1. N-Day留存（精确日留存）

```
D1留存 = 首日注册用户中，第2天（24h后）仍登录的占比
D7留存 = 首日注册用户中，第8天仍登录的占比
```

- **适用**：日活型产品（社交/工具/内容）
- **优点**：精确、可对比不同群组
- **缺点**：单日波动大，不适合低频产品

### 2. Unbounded留存（无限界留存）

```
D7留存 = 首日注册用户中，第7天及之后任意一天至少回访一次的占比
```

- **适用**：低频产品（SaaS/旅游/汽车）
- **优点**：包容回访时间偏移
- **缺点**：可能高估留存（因为只要之后回来就算）

### 3. Bracket留存（区间留存）

```
D7留存 = 首日注册用户中，第5~9天期间至少回访一次的占比
```

- **适用**：中频产品（电商/教育）
- **优点**：平衡精确性和波动
- **缺点**：区间选择需行业经验

### 三种方式对比

| 维度 | N-Day | Unbounded | Bracket |
|---|---|---|---|
| 精确性 | ★★★★★ | ★★★ | ★★★★ |
| 抗波动性 | ★★ | ★★★★★ | ★★★★ |
| 适用频率 | 日活型 | 低频型 | 中频型 |
| 典型行业 | 社交/工具/游戏 | SaaS/房产/汽车 | 电商/教育/金融 |

## 六类留存指标

| 留存类型 | 定义 | 典型应用 |
|---|---|---|
| 回访留存 | 回来打开App/网站 | 基础粘性评估 |
| 功能留存 | 回来使用特定功能 | 核心功能价值评估 |
| 付费留存 | 持续付费/续费 | 商业健康度评估 |
