### 绝对优势功能 1：真跨平台原生统一体验

**功能描述**
一套代码/统一逻辑，同时编译为Windows和macOS原生应用。两端共享：
- 完全一致的快捷键体系（如统一为 `Ctrl/Cmd+Shift+V` 呼出）
- 完全一致的界面布局（自适应系统主题：暗色/亮色/跟随系统）
- 完全一致的数据格式（历史条目在两端的渲染效果相同）
- 数据互通（通过跨设备同步实现"Mac复制，Windows粘贴"）

**为什么这是绝对优势**
| 维度 | 竞品现状 | 我们的方案 |
|------|---------|-----------|
| Paste | Mac独占，Win用户无法使用 | 原生双端，一套逻辑 |
| Ditto | Windows独占，Mac用户无法使用 | 原生双端，一套逻辑 |
| CopyQ | 理论跨平台，但Win/Mac版本体验割裂 | 统一UI，一致体验 |
| 1Clipboard | 跨平台但依赖Google Drive，已停更 | 统一架构，持续维护 |

**需求验证**
- 置信度：**9.9/10**（验证通过）
- 证据：16次独立提及，用户普遍使用"邮件传链接""微信文件传输"等 workaround
- 行为：用户同时使用多个工具（Paste+Ditto）或自建开源方案

**人性锚点**
- 安全需求（内容不丢失）+ 生理需求（无摩擦舒适）
- "我的数字记忆应该跟随我，而非跟随设备"

**技术实现**
- **推荐框架**：Tauri 2.0（Rust核心+Web前端）
  - 编译为原生二进制（非Electron，用户明确厌恶臃肿）
  - 内存占用 <50MB（Ditto ~80MB，CopyQ ~150MB）
  - 启动速度 <500ms
  - 支持Windows和macOS双端编译
- **数据存储**：SQLite本地数据库 + 两端统一的序列化格式 + 可选云端加密备份
- **UI框架**：React/Vue + Tailwind CSS，自适应系统主题

**传播钩子**
> "一台Mac，一台Windows，一套剪贴板历史。复制一次，到处粘贴。"

### 绝对优势功能 2：跨设备自动同步（LAN优先+云端可选+手动IP回退）

**功能描述**
设备间自动发现与同步，三层架构灵活适配不同网络环境：

**第一层：零配置局域网同步（首选）**
- 同一WiFi下自动发现（mDNS/Bonjour），无需输入IP、无需登录
- 安装后自动扫描局域网内的其他设备
- 发现后弹窗提示"发现Windows电脑'Work-PC'，是否配对？"
- 传输端到端加密（AES-256）

**第二层：手动IP配对（企业网络回退）**
- 当mDNS被企业防火墙/VLAN隔离阻断时，自动提示"切换到手动手动配对"
- 设备A显示二维码 + IP:端口，设备B扫码或手动输入
- 支持通过公司内网固定IP直连（无需公网）
- 配对后同样使用端到端加密传输

**第三层：云端加密中继（跨网络/团队版）**
- 设备不在同一网络时（如家里Mac和公司Windows），通过云端加密中继同步
- 数据在离开设备前已加密（AES-256-GCM），服务端仅存储密文
- 云端数据可配置保留策略（30/90/365天）

**同步状态可视化**："已同步到3台设备 ✅（LAN×2 + 云端×1）"

**为什么这是绝对优势**
| 维度 | 竞品现状 | 我们的方案 |
|------|---------|-----------|
| Paste | iCloud同步，仅限Apple生态，年费$30 | 跨生态+多模式+灵活选择 |
| Ditto | 支持LAN同步，但需手动输入IP和密码 | 零配置优先+手动回退 |
| 1Clipboard | 依赖Google Drive存储剪贴板 | 端到端加密，服务端不解密 |
| 微信文件传输 | 最普遍的 workaround，但需登录+手动操作 | 自动同步+剪贴板原生 |

**需求验证**
- 置信度：**8.3/10**（验证通过）
- 证据：用户对"emailed yourself a link"的 workaround 描述极其普遍
- 行为：用户因跨平台割裂而同时使用多个工具或自建方案

**人性锚点**
- 安全需求（内容不丢失）+ 生理需求（懒惰/零配置）
- "我不想中断心流去打开另一个应用传链接"

**技术实现**
- **设备发现**：mDNS/Bonjour多播（局域网），二维码/IP直连（企业网）
- **传输协议**：WebSocket over LAN / QUIC over Internet，全程TLS+AES-256端到端加密
- **云端中继**：服务端仅转发密文，不触碰明文；密钥仅设备持有
- **冲突处理**：时间戳+设备ID去重；同一内容多设备复制不重复存储
- **离线处理**：无网络时正常记录，恢复连接后批量同步
- **手动IP配对**：
  ```
  设备A（Mac）显示：
  ┌─────────────────────────┐
  │  📡 手动配对模式         │
  │  IP: 192.168.10.45:8765 │
  │  [📱 扫描二维码]         │
  │  配对码：7A3F            │
  └─────────────────────────┘
  
  设备B（Windows）操作：
  ① 扫描设备A二维码 或 手动输入IP:端口
  ② 两端显示配对码校验（防止误配）
  ③ 校验通过后建立TLS加密直连通道
  ```

**传播钩子**
> "同一WiFi自动发现，不同网络加密同步，企业内网扫码直连。"

### 绝对优势功能 3：自动敏感内容防护（"安全盾牌"）

**功能描述**
安装后自动保护敏感内容，用户完全无感知：
- **预置排除列表**：自动检测系统已安装的密码管理器（1Password、Bitwarden、KeePass、Chrome密码、iCloud Keychain等），自动加入排除列表
- **智能识别**：复制内容若符合高熵字符串（随机密码）、信用卡号格式、API Key格式，自动排除不进入历史
- **应用来源排除**：从已标记为"敏感应用"的窗口复制的内容自动跳过
- **安全可视化**：状态栏图标显示盾牌标识；首次从密码管理器复制时弹出toast："敏感内容已自动排除，无需担心"
- **用户控制**：误报时可一键"加入白名单"；用户可手动添加/移除排除应用

**为什么这是绝对优势**
| 维度 | 竞品现状 | 我们的方案 |
|------|---------|-----------|
| Paste | 无自动排除，密码进入历史 | 自动检测+智能排除 |
| Ditto | 无敏感内容保护 | 三重防护机制 |
| CopyQ | 可配置排除，但需手动设置 | 安装即保护，零配置 |
| macOS Tahoe | 明文显示1Password密码（重大漏洞） | 主动排除，安全优先 |

**需求验证**
- 置信度：**9.5/10**（验证通过）
- 证据：12次安全相关提及，情绪词"scared""vulnerability""major risk"
- 行为：用户因安全顾虑**拒绝使用**剪贴板工具；Tahoe漏洞被广泛报道

**人性锚点**
- 安全需求（生存级）—— 密码泄露=身份被盗=财务损失
- "安全感"是剪贴板工具的**底线门槛**：没有它，用户根本不考虑使用

**技术实现**
- **密码管理器检测**：扫描 `/Applications` 和 `Program Files` 中的已知应用签名
- **高熵检测**：Shannon熵计算 + 正则匹配（信用卡号Luhn校验、API Key格式）
- **应用来源追踪**：通过系统API获取前台窗口的进程ID和Bundle ID
- **排除执行层**：在数据进入SQLite存储前拦截，敏感内容仅存在于系统剪贴板（按规定时间清除）
- **云端同步层**：敏感内容在本地被拦截，绝不会进入任何同步通道

**传播钩子**
> "你的密码永远不会出现在剪贴板历史中 — 我们连看都看不到。"

### 绝对优势功能 4：智能粘贴格式清理 + 预览选择

**功能描述**
粘贴前弹出微型浮窗，智能推荐最佳粘贴格式：
- **自动检测**：根据来源应用和目标应用，自动判断最佳格式
  - 从网页复制到Word → 推荐"清理后的富文本"（保留链接、去掉怪异CSS）
  - 从PDF复制到Excel → 推荐"表格结构"（自动识别行列）
  - 从代码编辑器复制到Markdown → 推荐"纯文本代码块"
- **预览浮窗**：3-5个选项按钮（原始/纯文本/表格/代码块），鼠标悬停预览效果
- **快捷选择**：方向键切换选项，Enter确认，Esc直接粘贴原始格式
- **学习机制**：用户对某来源应用的选择会被记忆，后续自动默认

**为什么这是绝对优势**
| 维度 | 竞品现状 | 我们的方案 |
|------|---------|-----------|
| Paste | 纯历史管理，无格式处理 | 粘贴前智能处理 |
| Ditto | 支持"粘贴为纯文本"，但需手动操作 | 自动推荐，一键选择 |
| CopyQ | 有脚本可自定义格式，但门槛极高 | 零配置，开箱即用 |
| CmdOS | Windows独占，有表格识别 | 我们跨平台+更易用 |
| 系统内置 | 无任何格式清理 | 智能处理 |

**需求验证**
- 置信度：**8.5/10**（验证通过）
- 证据：11次格式相关提及，"jumbled mess""Comic Sans"等强画面感描述
- 行为：用户每周花费1-3小时手动清理格式；Excel"分列"功能是高频 workaround

**人性锚点**
- 生理需求（舒适）+ 自我实现（专业产出）
- "我不想让我的文档看起来像垃圾"

**技术实现**
- **格式检测引擎**：本地规则引擎
  - HTML内容解析：提取文本、链接、表格结构，丢弃CSS样式
  - PDF表格识别：基于布局分析的行列检测算法
  - 代码语言检测：文件扩展名+语法特征识别 → 推荐对应代码块格式
- **预览渲染**：在浮窗中实时渲染目标格式的缩略预览
- **用户偏好存储**：SQLite中存储"来源应用→目标应用→用户偏好"映射

**传播钩子**
> "从PDF复制表格到Excel，再也不会变成一团乱码。"

### 绝对优势功能 7：图片/文件复制粘贴强化（新增）

**功能描述**
不仅管理文本，更将剪贴板升级为真正的"内容中转站"，支持图片、文件、富媒体的复制、预览、搜索、同步：

**图片强化**
- **剪贴板图片管理**：截图/Snipaste/设计稿复制后自动保存为缩略图，历史面板可直接预览
- **图片搜索**：搜索图片中的文字（OCR）、按尺寸/颜色/格式过滤
- **图片格式转换**：粘贴时自动转换为PNG/JPG/WebP（按目标应用智能选择）
- **图片压缩**：粘贴到聊天工具/邮件时自动压缩到合适尺寸，避免发送10MB截图

**文件强化**
- **文件路径剪贴板**：复制文件/文件夹后，历史记录保存文件引用（而非仅路径文本），支持一键重新复制
- **跨设备文件传输**：Mac复制文件 → 自动传输到Windows → 直接粘贴为文件（而非仅路径文本失效）
- **文件预览**：历史面板中悬停文件条目，显示文件图标、大小、修改日期
- **文件集合**：支持一次性复制多个文件，按批次管理，批量重新粘贴

**富媒体强化**
- **HTML片段**：复制网页富文本后保留完整HTML结构，粘贴时可选"简化HTML"或"Markdown"
- **颜色代码识别**：复制颜色（如设计软件中的色板），自动识别为HEX/RGB/CMYK格式
- **链接预览**：复制URL后自动抓取标题/缩略图，历史面板显示卡片式预览

**为什么这是绝对优势**
| 维度 | 竞品现状 | 我们的方案 |
|------|---------|-----------|
| Paste | 支持图片但无OCR/无格式转换 | 图片OCR+智能格式转换+压缩 |
| Ditto | 支持图片但预览体验差 | 缩略图网格+悬停预览+搜索 |
| CopyQ | 支持文件但仅保存路径文本 | 文件引用+跨设备自动传输 |
| 系统内置 | 图片仅临时存储，重启丢失 | 永久保存+分类管理+跨设备 |

**需求验证**
- 置信度：**8.0/10**（基于用户行为推断）
- 证据：开发者频繁截图传代码、设计师传配色/素材、办公用户传文件
- 行为：用户通过微信/钉钉传文件给自己作为 workaround；截图后用Snipaste临时保存
- 痛点：系统剪贴板图片重启后丢失；跨设备复制文件=文件只存在于原电脑，粘贴=路径失效

**人性锚点**
- 效率动机（一站式内容管理）+ 安全需求（截图不丢失）
- "我的截图、我的文件、我的配色，都应该被记住"

**技术实现**
- **图片存储**：本地文件系统存储原图，SQLite存储元数据（尺寸、OCR文本、颜色直方图）
- **OCR引擎**：本地轻量模型（如PaddleOCR或tesseract），不上传云端
- **文件引用**：保存文件路径+文件哈希，目标设备粘贴时若文件不存在，触发自动传输
- **图片压缩**：本地算法按目标应用智能压缩（粘贴到微信→压缩到1MB以内；粘贴到Figma→保留原图）
- **跨设备文件传输**：通过功能2的同步通道传输文件内容（LAN直连或云端加密中继）

**传播钩子**
> "截图再也不会丢失。复制文件到另一台电脑，真的能粘贴出来。"

## 八、总结：为什么这7个功能构成"绝对优势"

> **普通产品做功能。绝对优势产品做"功能组合 + 信任 + 价值观"。**

| 层级 | 我们的构建 |
|------|-----------|
| **功能层** | 跨平台 + 多模式同步 + 安全防护 + 格式清理 + 键盘UI + 图片/文件强化 = 每个单项都是竞品短板 |
| **体验层** | 零配置+手动回退+云端可选 + 自动保护 + 粘贴预览 + 图片OCR + 全程键盘 = 用户从"能用"到"爱上" |
| **信任层** | 免费核心 + 终身买断 + 法律承诺 + 开源审计 + E2EE加密 = 消除用户最大的顾虑 |
| **价值观层** | "你的数据属于你"（设备本地+加密云端）+ "一次拥有，永久使用"（反订阅）= 用户认同的品牌立场 |

**最终判断**：
这7个功能不是简单的"功能堆叠"，而是围绕一个核心用户群体（"跨平台效率用户"）的**完整需求闭环**：
1. **痛点触发**：跨平台工作 → 剪贴板断点 → 寻找工具
2. **信任建立**：安全顾虑 → 自动防护 + E2EE加密 → 放心使用
3. **价值交付**：格式混乱 → 智能清理；图片丢失 → 永久保存；文件跨设备 → 自动传输 → 效率提升
4. **长期关系**：订阅恐惧 → 终身买断 → 永久忠诚

这就是**绝对优势** —— 不是某一点比竞品强10%，而是**整个用户旅程中的每一个关键节点都比竞品强**，形成无法被单点复制的系统性优势。
