# 开发环境启停脚本实施计划

## 目标

在项目根目录提供 `启动.ps1`、`关闭.ps1`、`重启.ps1`，管理 Memurai/Redis、PostgreSQL、Java 后端和 Tauri 桌面端。管理后台不纳入本轮。

## 实施步骤

- [x] 1. `启动.ps1`：先检查 `6379/5432/8088/1420` 是否已监听，只启动未运行组件；后端和 Tauri 使用可见 PowerShell 窗口。
- [x] 2. `关闭.ps1`：按 Tauri、后端、PostgreSQL、Redis 的顺序关闭；项目进程只通过启动脚本记录的 PID 树关闭。
- [x] 3. `重启.ps1`：复用关闭和启动脚本，避免重复逻辑。
- [x] 4. 同步 `.gitignore` 和 `workflow_output/docs/run-guide/0_项目启动命令.md`。
- [x] 5. 用 PowerShell Parser 检查三个脚本语法，用静态断言检查端口、启动命令和管理后台提醒。

## 安全与回滚

- 不将 JWT secret 写入文件或日志；未配置时仅在当次后端子进程内生成临时值。
- 不根据模糊进程名强杀项目进程；只结束状态文件记录的进程树。
- 临时状态文件 `.file-keeper-dev-processes.json` 不提交 Git。
- 回滚时删除三个脚本并恢复运行指南即可，不涉及数据迁移。
