# 导演台3D构图 · Feature Map

> 代码速查表（前端 14 文件，无后端改动/无建表/无迁移）。用户视角见 [User-Ops](../user-ops/导演台3D构图用户操作手册.md)。

## 一、文件清单与调用链

```
CanvasView.vue（画布页：modal 编排 + 截图回流建图节点）
 ├─ defineAsyncComponent → DirectorEditorModal.vue（懒加载，three 只进此 chunk）
 │   ├─ DirectorToolbar.vue（左栏：添加面板+元素清单）
 │   ├─ DirectorViewport.vue（three 视口）→ buildScene.ts / cameraFrustum.ts
 │   ├─ DirectorProperties.vue（右栏元素属性）
 │   └─ DirectorCameraPanel.vue（右栏机位面板）
 ├─ CanvasBoard.vue（nodeTypes 注册 director + provide 桥 + 双击打开）
 │   └─ nodes/DirectorNode.vue（卡片）→ directorBridge.ts（inject）
 └─ director/sceneModel.ts ←—— 全组件共用的数据真源（零 three）
     figurePresets.ts（体型/姿势纯数据）← buildScene.ts
```

## 二、逐文件注解

| 文件 | 作用 | 技术大白话 |
|---|---|---|
| `director/sceneModel.ts` | 场景 schema + 解析/序列化/undo 栈 | **采用技术**：手写白名单校验 + structuredClone。**原理**：任何进来的脏数据先过「字段白名单→枚举回退→数值 clamp→数组截断」四道闸，坏数据变好数据而不是报错。**大白话**：像海关查验，没申报的东西一律没收，带多了截断。**案例**：手改快照 JSON 塞 201 个元素→加载后只剩 200。undo 栈像游戏存档槽，只留 50 个，拖 gizmo 松手那一刻才存档（不是每帧都存）。 |
| `director/figurePresets.ts` | 8 体型 + 6 姿势比例表 | 纯数据表：体型=头/躯干/四肢的长度粗细，姿势=各关节转多少度。像人体木偶的出厂说明书，坐下=胯转-90°+膝转+90°。 |
| `director/buildScene.ts` | 数据→three 对象 | **原理**：素模人物=盒体图元按比例拼装的层级 Group（骨盆→躯干→头/四肢），姿势=按关节名旋转；群众=InstancedMesh。**大白话**：乐高说明书——数据是图纸，这里是拼装车间。InstancedMesh=一个印章画 144 人只花一份刻章钱。**踩坑批注**：geometry/材质走共享缓存，dispose 时只清一次，否则删元素会把别人还在用的缓存炸掉。 |
| `DirectorViewport.vue` | 渲染视口（最重文件） | **原理**：invalidate 按需渲染——画面脏了才画，静止 2s 停 rAF；场景同步走 id diff，同签名只刷变换不重建。**大白话**：省电模式，动才亮屏。机位视角=scissor 裁剪渲染（只画遮幅框内）+先整帧清屏（scissor 只清框内，不清会留残影）。**踩坑批注**：①截图改 renderer 尺寸前必须暂存旧值，finally 恢复，否则主视口被截图分辨率毁掉；②three r169 起 TransformControls 不是 Object3D，要 `scene.add(tc.getHelper())`；③像素比 setPixelRatio(min(dpr,2)) 防 4K 屏爆 GPU。 |
| `DirectorEditorModal.vue` | 编辑器壳 | WebGL 探测（getContext 探针）失败→NAlert 降级不崩；Ctrl+Z/文本 500ms 防抖推栈；截图=captureView→File→既有 upload 咽喉→emit fileId 给画布。 |
| `DirectorToolbar/Properties/CameraPanel.vue` | 三块面板 | VTU 坑：naive-ui 输入框的值在内层 `<input>.value`，`text()` 拿不到；emit 会丢尾部 undefined 参数。 |
| `cameraFrustum.ts` | 机位视锥可视化 | 4 条线到远平面 + 机身盒（可点选）。生活比喻：相机小三脚架模型，锥线=取景范围。 |
| `nodes/DirectorNode.vue` | 画布节点卡片 | 摘要走 parseScene 同一真相源（卡片显示数=打开编辑器看到的数）；封面=coverPreviewUrl（会话级 objectURL，保存剥离）。 |
| `directorBridge.ts` | 节点→画布桥 | **原理**：InjectionKey 类型化 provide/inject。**大白话**：Vue Flow 节点组件喊话画布听不见（emit 不冒泡），得递个对讲机。 |
| `CanvasBoard.vue`（改） | 注册 + 桥 + 双击 | nodeTypes 加 director（markRaw）；双击走 wrapper `data-id` 反查节点类型，只 director 拦截，其余节点维持原「不弹快速添加」语义。 |
| `CanvasView.vue`（改） | modal 编排/截图回流 | 连截偏移=已有出边数×220px 纵排；close(scene) 才回写 data（WebGL 降级 close(null) 不动数据）。 |
| `api/canvas.ts` upload / fetchCanvasPreview` | 既有复用 | 零新端点；封面/图片预览走鉴权 fetch→objectURL（`<img>` 带不了 header）。 |
