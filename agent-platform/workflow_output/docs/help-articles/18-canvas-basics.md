# 无限画布：建画布、拖节点、连线生成

> 入口：侧栏「**无限画布**」（电脑端使用，手机端不可用）。看不到菜单 = 没有权限，找管理员开通。
> 在画布上**生成视频**还需视频生成权限（media:gen）。

## 一、建画布与拖节点

1. 进入「无限画布」→ 右上「**新建画布**」→ 自动进入编辑页。
2. 左侧调色板拖节点到画布：**文本 / 图片 / 视频 / 音频 / 脚本 / 分镜** 6 类。
3. 滚轮缩放；按住空白拖动平移；点节点选中，右侧属性面板编辑内容。
4. 改动**自动保存**（停手约 1 秒后）；右上「重命名」改画布名。

## 二、六种节点怎么用

| 节点 | 干什么 | 关键操作 |
|---|---|---|
| 文本 | 提示词扩写 | 填提示词 →「运行」→ 显示扩写结果 |
| 脚本 | 剧本拆分镜 | 填剧本 →「拆分镜」→ 右侧自动扇出 N 个分镜节点并连线 |
| 分镜 | 单镜画面描述 | 可编辑描述，下游 @引用它生图/生视频 |
| 图片 | 上传图 / AI 生图 | 选图片模型 → 填参数 →「AI 生图」 |
| 视频 | 文生/图生视频 | 填提示词 →「生成」→ 1-3 分钟出预览 |
| 音频 | 上传音频 | 上传即可 |

## 三、连线（让节点互相喂料）

1. 悬停节点边缘出现圆点，**从上游节点拖到下游节点**松手即连。
2. 图片 → 视频连线后，视频生成自动拿上游图当参考图（首帧）。
3. **删连线**：单击连线（变红加粗）→ 按 Delete。
4. **快速建下一节点**：从节点右侧圆点**拉线到空白处松手** → 弹出搜索框选类型 → 回车，新节点自动建在线上。

## 四、@引用（在提示词里引用上游产出）

1. 文本/脚本/视频节点的输入框里输 **`@`** → 弹出候选列表（只列连线上游节点）。
2. 选中插入 → 生成时自动替换为上游节点的产出内容。
3. 上游被删/断连 → 显示黄色「断链引用」警告，重连或移除即可。
4. 节点重命名不影响 @引用（存的是内部编号）。

## 五、视频小工具（选中视频节点 → 属性面板）

- **抽帧**：取首帧/尾帧/第 N 秒 → 产一张新图片节点。
- **截取**：填起止秒 → 产一段新视频节点（片段 ≤600 秒）。
- **故事板**（顶部按钮）：≥2 个视频段调顺序 → 预览 →「拼接成片」产一个成片节点（要求各段同尺寸）。

## 六、一键重跑全链

顶部「重跑全链」→ 按上下游顺序串行重跑所有可生成节点。报错「画布存在环」→ 先删掉成环的一条连线。

## 常用快捷键

| 操作 | 作用 |
|---|---|
| 滚轮 | 缩放画布 |
| ✋ 模式拖空白 | 平移；Shift+拖 = 临时框选 |
| ▭ 模式拖空白 | 直接框选多节点（右下工具条切换） |
| Ctrl+Z / Ctrl+Shift+Z | 撤回 / 重做（最多 50 步，刷新后清空） |
| Delete | 删选中节点/连线 |
| Esc | 取消选中 |

## 常见异常

| 现象 | 原因 | 恢复 |
|---|---|---|
| 视频节点失败「无 media:gen 权限」 | 有画布权限但无视频生成权限 | 找管理员补授权 |
| 节点标红「上游缺失」 | 上游被删或失败 | 重跑或重连上游 |
| 刷新后图片预览没了 | 正常 | 重进画布自动重新加载 |
| 编辑内容丢了 | 自动保存有约 1 秒延迟 | 重要改动稍等再关页面；或用「版本」功能存档 |
