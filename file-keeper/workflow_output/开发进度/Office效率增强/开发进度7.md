## 2. 代码与关键 API

- `src/types/office.ts`：前端任务、输入、输出、问题、引擎、状态和输出策略类型；无密码、正文、Token 或模型 Key 字段。
- `src-tauri/src/office/types.rs`：对应 serde camelCase 领域类型、`OfficeInput::new`、`OutputSummary`、稳定 `DomainErrorCode`。
- `src-tauri/src/office/state_machine.rs`：`OfficeTaskStateMachine::transition` 与内部完成摘要入口。
- `src-tauri/src/office/tests/state_machine_tests.rs`：17 个独立行为测试。
- `src-tauri/src/office/mod.rs` / `src-tauri/src/main.rs`：只注册 Rust 模块以便编译测试，不注册 Tauri command。
- `workflow_output/项目规范约束/Office任务状态机约束.md`：沉淀后续模块必须复用的状态与输出约定。
