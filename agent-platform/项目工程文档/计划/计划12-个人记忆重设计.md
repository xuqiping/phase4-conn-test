## 各迭代目标（一句话）

- **A · 数据层**：Flyway V47 建 `memory_tags` / `memory_turns` / `memory_summaries` / `memory_summary_coverage` / `memory_project_members` / `memory_project_settings` / `memory_project_user_settings` / `memory_consolidation_scopes` / `memory_notifications` + 扩 `memory_conflicts`；实体继承 BaseEntity；Mapper 所有读方法内联 SCOPE_FILTER。**关键约束**：`memory_summary_coverage` UNIQUE 带 `NULLS NOT DISTINCT`（个人 scope project_id=NULL）；halfvec `<=>` XML 转义；BIGINT[] typeHandler。
- **B · 标签归一**：写记忆前 resolve 标签（精确 label 命中 / aliases 命中 / anchor 向量 ≤0.25 二次 LLM 判 / 全 miss 新建）；复用时 usage_count++、语义同滚进 aliases。**禁手动归并/拆分/重抽**（误并不可逆）；仅 owner 改 label/补 aliases 纠显示名（tag_id 不变，anchor 重生属预期纠错）。
- **I1 · ACL 前置**：`memory_project_members` 加 role(OWNER/ADMIN/MEMBER) + recall_admin；建 `memory_recall_acl`（reader→target）；实现 `readableAuthors(projectId, reader)`（owner 全员、admin/member 按 ACL + 自己、含 DEPARTED 曾赋权）。
- **C · 生成写入**：一轮对话一次 LLM 出 INPUT/OUTPUT 双侧 L0/L1/L2（前置过滤按侧独立跳过）；gen 开关 per-project（owner AND 会员覆写，默认开）；写入目标多选（默认勾个人、与召回解耦）；gen 关写 raw 行（`gen_done=false`）；异步 fire-and-forget。
- **D · 召回**：scope 多选过滤 → 聚合标签（(subject,topic) 跨 user 去重）→ LLM 选标签（>30 anchor RRF 粗筛）→ 优先读自己总结 → reflect 判深读 → 拼未覆盖流水账（allCovered 严格策略）；恒不召回他人总结、不召回 raw turn；最多 2 次 LLM。
- **E · 总结冲突**：统一「开始总结」入口（手动+自动都走它，独立于任何开关）；手动按「距上次总结后是否有变化」标可选/灰选；自动默认勾{个人}每天定时、定时跑前无新增空跳过、gen 关态定时仅总结已生成 turn；项目总结取数范围可配；冲突时序互斥 PENDING 四选项裁决；provenance + 防膨胀；时序日期铁律。
- **I2 · 花名册/ACL 端点**：`GET /projects/{pid}/roster`（含已退出人员）；`PUT/GET /projects/{pid}/recall-acl`（仅 owner 或 recall_admin admin）。
- **I3 · ACL 接入**：召回（D1）项目 scope 拼流水账时 `turn.user_id IN readableAuthors`；总结取数（E1）候选 = 当前可召回人员集；summary 不变（仍只读自己）。
- **F · 前端**：MemoryManagerPanel 三页签（流水账/总结/标签库）+ 冲突裁决四选项 + RagMemorySettingsTab（gen 开关+总结入口+raw 管理+顶端说明条）+ ChatView 底栏（召回 scope 多选 + 写入目标多选 + 离职开关 + 时间窗/方向）+ 已删除/已离开项目折叠板 + 波及通知 badge。
- **I4 · 前端 ACL**：项目页成员花名册 + owner/admin ACL 配置矩阵 + 总结取数选人组件。
- **H · 收尾**：旧 `/api/chat/memories/*` 端点 404；V49 DROP `user_memories` / `user_memory_projects`；速查表 09 三件套重写为新模型。

## 验收（关键项）

- 单测全绿：归一四路径 / L0L1L2 生成 / 前置过滤按侧跳过 / 总结冲突判定 / 日期铁律 / scope 隔离。
- 关键 IT 全绿：mapper scope 六路径（含 coverage UNIQUE NULLS NOT DISTINCT 拦截）/ 召回全链 / provenance round-trip / 个人总结 project_id NULL / 个人 scope 按出身召回 / 项目出身卸空转 born_personal / 写入目标默认勾个人不随召回泄漏 / 离职人员按开关纳入排除（开关优先级高于人员多选）/ 作者离职不可选原项目召回需 copy-to 恢复 / 项目删除 deleted_project_ids 标记 + 成员收通知 / raw 查看/删除仅本人无导出 + TTL 90 天 / 流水账删除级联 + 12h 规则（他人引用且>12h 拒删）+ 跨用户波及通知 / 旧表 DROP 后旧端点 404 / 项目 ACL 隔离（A 未授权读不到 B）。
- E2E 全绿：三页签 CRUD / 冲突裁决 / 补生成（仅 raw，可单条可批量）/ 流水账挂多项目 / 召回 scope 多选持久化 / 总结统一入口（手动+自动）/ 未总结>100 告警按钮 / gen 默认开 + 按侧过滤 + 敏感黑名单 / 移动端。
- 性能：召回 < 2s（含 LLM），总结 worker 不阻塞对话。
- 安全：13 向量 + ACL 向量全部越权 IT 覆盖。
