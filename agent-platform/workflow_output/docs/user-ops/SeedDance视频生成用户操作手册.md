# SeedDance 视频生成 · 用户操作手册

> 面向持有 `media:gen` 权限的用户。功能入口：侧边栏「视频生成」菜单（`/video-gen`，无权限不显示，联系 admin 授权）。
>
> **v2（2026-08-06）**：支持**选择视频模型**；参考媒体模式可混搭多张参考图、参考视频、参考音频。首/尾帧属于另一种模式，不能与参考媒体混用。

## 前置条件

- 账号已被授予 `media:gen` 权限（默认仅 admin 有；普通用户须 admin 在「角色权限」页授予）。
- 系统已配置 MEDIA 类供应商（「全局模型供应商」里 category=MEDIA、models 填视频模型 id）——由运维保证，用户无需关心。
- 使用参考视频时，运维还须配置 Ark 可访问的公网 HTTPS 地址和签名密钥；未配置时页面仍显示参考视频区，但上传与资产库按钮禁用，并给出配置提示。
- 页面顶部「视频模型」下拉为空 = 没有可用模型，联系运维配置。

## 功能一：文生视频

**操作步骤**：
1. 点侧边栏「视频生成」进入页面。
2. 「视频模型」选模型（默认第一个；不同模型的可选比例/分辨率/时长会自动跟随变化）。
3. **不上传任何参考附件**即为文生视频。
4. 「提示词」填描述（≤2000 字，越具体越好，如「一只橘猫在窗台上晒太阳，阳光柔和，慢镜头」）。
5. 「画面比例」选 16:9 横屏（默认）/9:16 竖屏/1:1/4:3/3:4/21:9/adaptive。
6. 「时长」选 4-15 秒（区间随模型）；「分辨率」选 480p/720p/1080p/4K（720p 推荐；4K 仅 2.0 全版，H.265 部分播放器不兼容；fast/mini 模型最高 1080p）。
7. 「水印」开关（默认关）；「生成音频」开关（默认关，仅支持的模型显示，2.0 特色，同步生成原生音频）。
8. 点 **提交生成**。

**界面变化**：右侧「当前任务」出现状态标签「排队中」→「生成中」（旋转加载图标）。

**完成标志**：状态变「已完成」，内联 `<video>` 播放器出现 + 「下载视频」按钮；下方历史列表新增一行（含所用模型）。

**预期耗时**：通常 1-3 分钟。平台不设置生成总时限；长任务可离开页面，之后从历史继续查看。

## 功能二：多模态参考生视频（图 + 视频 + 音频）

> 原「图生视频」的升级版。上传任意参考附件即自动进入该模式（无需手动切换）；素材上限随所选模型显示在上传区标题里。

**SeedDance 2.0 上限**：参考图 ≤9 张、参考视频 ≤3 个、参考音频 ≤3 个，**合计 ≤12 个附件**。

**操作步骤**：
1. 「视频模型」选支持多模态的模型（如 SeedDance 2.0 系列）。
2. 按需上传参考素材（可混搭）：
   - **参考图**（≤8MB/张，image/*）：产品图、人物图、风格图等。
   - **参考视频**（≤50MB/个，video/*）：运镜、动作参考。
   - **参考音频**（≤15MB/个，audio/*）：音色、背景音乐参考。
3. 填提示词，**按上传顺序引用素材**，如「以图1为产品细节参考，视频1为第一人称运镜参考，音频1作为背景音乐，生成一支简洁的水果茶广告」。
4. 画面比例可填 adaptive（沿用参考素材比例）；选时长/分辨率/水印/音频 → **提交生成**。

**完成标志**：同文生视频。

> 注：附件全部上传完成前「提交生成」不可用（按钮旁提示「附件上传中」）；超过模型上限的附件会被上传组件直接拦住。

### 首尾帧模式

- 首帧和尾帧可以单独使用，也可以一起使用。
- 一旦选择首帧或尾帧，参考图/参考视频/参考音频入口会被禁用；已有参考媒体时也不能再添加首尾帧。
- 如需切换模式，先清空当前模式中的附件。后端也会再次校验，防止旧页面或接口绕过。

## 功能三：查看历史与回看

- 每条历史记录固定显示“提示词”列；窄屏或右栏空间不足时其余列横向滚动，提示词仍固定在左侧。
- 可按提示词和时间范围筛选，点“清空筛选”恢复最近记录。
- 成功记录右侧显示小视频；进入可视区域后才加载，预览失败不影响打开详情。
- 点某行“查看”后，上方当前任务和左侧模型、提示词、比例、时长、分辨率、水印、音频、首/尾帧及附件会恢复。
- 历史模型已下线时保留只读模型名；历史附件已删或失权时保留名称占位，但不能直接重新提交。

## 功能四：查看实际发送参数

1. 提交任务或在历史中点“查看”。
2. 在“当前任务”卡片点“请求参数”。
3. “平台收到的提交参数”显示平台落库的表单参数；“实际发给模型（已脱敏）”显示发送瞬间与 POST body 同源的结构。
4. 点“复制 JSON”可复制当前页签内容。

媒体附件正文不会显示；页面只显示 `fileId/MIME/字节数/SHA-256` 摘要。改造前的旧任务会明确提示“该历史任务未记录发送快照”，系统不会事后猜测并冒充实际请求。`videoUrl/imageUrls` 只代表成功生成后的输出地址，为 `null` 不等于输入附件没有发送；输入请看 `inputAttachments` 和请求快照。

## 下载视频

- 「当前任务」已完成时点「下载视频」→ 浏览器下载 mp4（Content-Disposition 附件，不在线执行）。
- 下载需 `media:gen` 权限 + 任务归属（非自己任务，普通用户下载被拒）。

## 常见异常与恢复

| 现象 | 原因 | 恢复 |
|---|---|---|
| 看不到「视频生成」菜单 | 无 `media:gen` 权限 | 联系 admin 在「角色权限」页授权 |
| 直接访问 `/video-gen` 显示「无 media:gen 权限」 | 同上（4 层权限第②层兜底） | 同上 |
| 「视频模型」下拉为空 | 未配置 MEDIA 类供应商 | 联系运维在「全局模型供应商」配置 |
| 提交提示「模型不可用」 | 模型已下线或不在供应商 models 列表 | 重新选择下拉里的模型 |
| 提交提示「参考图/视频/音频超限」或「附件总数超限」 | 超过所选模型上限 | 删掉多余附件（上限见上传区标题） |
| 「参考视频」区域显示配置警告且按钮不可用 | 未配置 Ark 可访问的公网 HTTPS 签名通道 | 联系运维配置 `MEDIA_REFERENCE_PUBLIC_BASE_URL` 和 `MEDIA_REFERENCE_SIGNING_KEY` |
| 提示首/尾帧不能与参考媒体同时使用 | 同时选择了两种互斥模式 | 清空首尾帧或清空参考图/视频/音频后重试 |
| 提交提示「附件类型不符」 | 文件实际类型与上传区不符（如把视频传到参考图） | 传到正确的上传区 |
| 提交提示「无权使用该附件」 | 引用了他人上传的文件 | 用本人上传的附件重新提交 |
| 提交后页面提示 403 | 权限被收回 | 联系 admin |
| 状态「失败」+「Ark 429 限流」 | Ark 配额超限 | 稍后重试（重新提交） |
| 长时间保持“生成中” | 模型方仍在处理或查询暂时失败 | 可离开页面，稍后从历史回看；平台不会因总时长自动判失败 |
| 状态「失败」+ 含「参考附件读取失败/过大」 | 附件超大小上限（图 8MB/视频 50MB/音频 15MB） | 压缩后重新上传提交 |
| 状态「下载失败」 | Ark 出视频但下载落盘失败 | 历史保留 arkTaskId 可重试（MVP 暂无重试入口，重新提交） |
| 轮询中页面提示「网络异常」 | 服务暂不可达 | 连续 5 次自动跳登录；恢复后重新进入页面回看历史 |

## 移动端

- ≤768px 自动单列堆叠（表单在上、结果在下），操作流程同桌面端。

### 变更记录（2026-08-14 · 4x 第二轮）
- 历史视频加载提速：同一视频二次查看走浏览器缓存再验证（不重复下载整段）；任务结果文件不可变，重新生成是新任务新地址，不存在缓存过期问题。
- 生成成功后：「下载视频」旁新增「入库到资产库」；历史成功记录行新增「入库」。入库后弹窗可一键「前往资产库」查看。

### 变更记录（2026-08-25 · 2x + 7x）
- 长视频（15 秒等大文件）生成不再报「下载失败：Exceeded limit on max bytes to buffer」——下载改流式落盘，体积无上限；无限画布里的生视频节点同步修好。
- 生成页提交按钮下方新增「预估消耗 X 积分」实时提示：选模型/时长/分辨率/参考视频后自动刷新；余额（或组池）不够会红字提醒，不够提交不了。提交时先按预估扣住，完工按实际消耗多退少补，任务失败全额自动退回。
