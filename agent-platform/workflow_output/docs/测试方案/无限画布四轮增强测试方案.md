# 无限画布四轮增强 · 测试方案

> 覆盖 [plan](../plans/无限画布四轮增强.plan.md) Step 1-9。联动用例对齐 plan「功能联动点清单」L1-L7，每条含正向/反向/批量边界。
> 自动化可断言部分走单测（各 Step 验证清单），本方案仅人工交互部分。

## 一、前置环境

- 后端 + 前端 dev 栈已起；演示画布含：文本节点、图片节点（含 fileId）、视频节点（taskId）、A→B→C 链式依赖、菱形依赖（A→B、A→C、B/C→D）
- 浏览器可切离线模式（DevTools Network Offline）用于 L6
- 手机竖拍样图（EXIF 方向 6）一张用于 Step 6 EXIF 用例

## 二、功能联动用例（L1-L7）

### L1 依赖调度 → 下游自动提交（Step 4）
| # | 操作 | 预期 |
|---|---|---|
| L1-1 正向链 | 框选 A→B→C（B @A、C @B）→ 批量生成 | A 提交成功后 B 才提交；进度浮条 B 显示「等待上游」 |
| L1-2 失败跳过 | A 提示词非法致 FAILED | B、C 灰标 `上游失败`，不提交、不报错弹窗 |
| L1-3 上游缺失 | 只框选 B（A 不在选集） | B 标 `上游不在选集`，说明原因 |
| L1-4 并行分支 | 框选菱形 A→{B,C}→D | B/C 并发（窗口 2），全成功后 D 提交 |
| L1-5 取消 | 调度中点进度浮条关闭 | 停止释放新任务；在途任务不撤（完成后正常回填） |
| L1-6 看门狗 | 模拟上游永不终态（断网） | 60min 上限或取消令牌兜底，进度条可关不悬挂（单测+代码走查） |
| L1-7 429 退避不占槽 | 窗口 2 + 3 节点全 429 | 退避重试期间不阻塞第 3 个排队的（单测断言） |

### L2 选中 → 关联高亮/只看关联（Step 5）
| # | 操作 | 预期 |
|---|---|---|
| L2-1 正向 | 菱形图点 D | D→B/C→A 路径边高亮（accent 加粗），无关节点/边淡化 |
| L2-2 反向 | 点空白清选中 | 全部还原 |
| L2-3 只看关联 | 选中 D → 开「只看关联」 | 无关节点隐藏（非淡化）；关开关全恢复 |
| L2-4 重算 | 「只看关联」开着再点 B | 隐藏集按 B 重算 |
| L2-5 拖动不复算 | 拖动选中节点 | 高亮集合不闪烁重算（memo） |
| L2-6 多选 | 框选 B+C | 关联=两者并集 |

### L3 拖宽高 → 内容/快照联动（Step 2）
| # | 操作 | 预期 |
|---|---|---|
| L3-1 正向 | 选中图片节点拖右下手柄 | 宽高实时变；图 100% 自适应不裁切 |
| L3-2 最小值 | 缩到极限 | 卡 160×64；文本超高出滚动条不溢出 |
| L3-3 持久化 | 拖完 → 刷新页面 | 宽高还原；快照 JSON 含 width/height |
| L3-4 老快照 | 打开无宽高的存量画布 | 默认 200 宽渲染零报错 |
| L3-5 叠加 | 拖宽后连线 | 左右连线锚点跟随新宽度 |

### L4 画框标注 → 确认可用性（Step 7）
| # | 操作 | 预期 |
|---|---|---|
| L4-1 正向 | 画 2 框（不同色）各填指令 | 确认可用；预览图框色/文字即时反映 |
| L4-2 空框 | 删光所有框 | 确认禁用 |
| L4-3 改色 | 改最后一框颜色 | 预览即时变 |
| L4-4 取消 | 画 2 框后取消弹层 | 不产生任何节点/请求 |
| L4-5 AI 修改 | 2 框确认 → AI 修改 | 参考图=[原图,标注图]、prompt=逐框指令；产出下游图节点连线 |

### L5 建组 → 视觉/候选联动（Step 9）
| # | 操作 | 预期 |
|---|---|---|
| L5-1 正向 | 框选 3 节点 →「设为组」输名 | 彩色包围盒+组名；成员同色描边 |
| L5-2 拖跟随 | 拖其中一个成员 | 包围盒实时跟随（不卡顿） |
| L5-3 解组 | 菜单「解组」 | 描边/包围盒全还原 |
| L5-4 移组 | 成员 A 加入新组 | 旧组自动减员、包围盒收缩 |
| L5-5 删成员 | 删除组内一节点 | 组引用清理；全删完组自解散 |
| L5-6 @全员 | 下游节点 @ 选组 | 候选列表组分节；选组=注入组内全员；孤立组（无成员在祖先）不出现在候选 |
| L5-7 往返 | 建组 → 保存 → 刷新 | 组还原；老快照（无 groups）打开=空组零报错 |

### L6 断网恢复 → 轮询/断路豁免（Step 1）
| # | 操作 | 预期 |
|---|---|---|
| L6-1 轮询豁免 | 视频生成中切 Offline 30s | 不弹「服务不可达」红 toast（最多「后台任务网络波动」）；不清会话不跳登录 |
| L6-2 退避 | Offline 期间观察请求 | 间隔 5→10→30s 封顶；恢复后回 5s |
| L6-3 恢复 | 切回 Online | 任务续跑、状态最终回填 |
| L6-4 主动操作仍断路 | Offline 下点「保存」等主动操作连续失败 | 照常断路提示（豁免只针对后台型） |
| L6-5 标签页回切 | 生成中切走再切回 | 立即补一次轮询 |

### L7 @引用 → 参考预览区（Step 8）
| # | 操作 | 预期 |
|---|---|---|
| L7-1 正向 | 节点 prompt @两图一视频 | 属性面板「参考」区 3 张缩略：图N/视频N 徽标；序号与 @chip 一致 |
| L7-2 悬浮/点击 | hover 缩略 / 点击 | hover 放大；点击全屏（视频播首帧 poster+播放） |
| L7-3 增删 | 编辑 prompt 增删 @ | 参考区列表随动 |
| L7-4 断链 | @ 的节点已删除 | 该项显示「断链」不崩 |
| L7-5 首尾帧 | 视频节点设首尾帧 + 又 @ 同链 | 参考区与首尾帧共存渲染 |

## 三、回归红线（每步完成后必过）

1. 存量画布打开零报错（老快照缺 width/groups 字段）
2. 六类节点新建/拖动/删除/保存往返
3. 批量生成（旧滑窗路径在新调度器下等价）
4. 图片视频模块历史分页/预览缓存不回归
