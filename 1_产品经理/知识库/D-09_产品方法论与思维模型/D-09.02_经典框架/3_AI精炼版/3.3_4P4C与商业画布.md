# 4P/4C 与商业画布

## 4P → 4C：营销分析的双视角

### 4P（企业视角 · McCarthy 1960）

| P | 含义 | 内涵 |
|---|---|---|
| **Product** | 产品 | 功能/品质/品牌/包装/生命周期 |
| **Price** | 价格 | 定价策略/折扣/支付方式 |
| **Place** | 渠道 | 分销路径/覆盖区域/流通效率 |
| **Promotion** | 推广 | 广告/促销/公关/社交媒体 |

### 4C（用户视角 · Lauterborn 1990）

| C | 对应P | 视角翻转 |
|---|---|---|
| **Customer Value** | Product | 不看"我们做了什么"，看"用户得到什么价值" |
| **Cost** | Price | 不看"我们标价多少"，看"用户总成本"（含时间/认知/机会成本） |
| **Convenience** | Place | 不看"我们铺了什么渠道"，看"用户获取有多方便" |
| **Communication** | Promotion | 不看"我们推了什么广告"，看"与用户建立了什么对话" |

### 5层穷尽

**① 基础**：4P从企业出发、4C从用户出发——两者互补而非替代

**② 进阶**：
- **4P→4C 做产品时的合并用法**：每个维度同时问4P和4C——"Product是什么？→ Customer Value是什么？"
- **7P扩展**：4P + People/Process/Physical Evidence（服务营销扩展版，B端/服务型产品适用）

**③ 前沿**：
- **AI时代的4P重构**：Product→AI Agent即产品 / Place→API/Agent调用即渠道 / Promotion→AI推荐和SEO(GEO/AEO)即推广 [来源:2025全球产品经理大会 | 📚中 | 2025]
- **4C的数字化升级**：Convenience从"购买便利"升级为"即时获取"(即时满足) / Communication从"对话"升级为"AI个性化推荐"

**④ 组合**：4P+商业画布 = 4P做营销策略 + 商业画布做整体商业设计

**⑤ 反面/边界**：4P/4C不适用于纯技术导向产品（如开发者工具），也不适用于网络效应型产品（其核心在连接而非单点）

## 商业画布（Business Model Canvas · Osterwalder 2010）

### 9要素全景

| 区域 | 要素 | 回答什么 |
|---|---|---|
| **供给** | 价值主张 | 我们为谁解决什么问题？ |
| **供给** | 核心资源 | 我们需要什么才能运转？ |
| **供给** | 关键活动 | 我们必须做什么？ |
| **供给** | 重要合作 | 谁帮我们？ |
| **客户** | 客户细分 | 谁付钱？ |
| **客户** | 渠道通路 | 怎么触达客户？ |
| **客户** | 客户关系 | 什么关系？自助/专属/社区？ |
| **财务** | 成本结构 | 主要成本在哪？ |
| **财务** | 收入来源 | 怎么收钱？ |

### 5层穷尽

**① 基础**：9格填完即初步商业模型

**② 进阶**：
- **价值主张画布**（VPC）：画布左侧拆出做"价值主张-客户画像"精调
- **画布不是静态的**：每次 Pivot 都重画一版，对比前后差异

**③ 前沿**：
- **AI原生商业画布**：新增"数据资产"和"AI能力"维度——传统9格未覆盖AI时代的数据飞轮和模型壁垒 [来源:Strategyzer博客 | 📚中 | 2025]

**④ 组合**：商业画布（全局）+ 精益画布（1页验证）+ 4P（营销深挖）

**⑤ 反面/边界**：
- **表面完整 ≠ 逻辑自洽**：9格都填了但"价值主张"和"收入来源"可能矛盾
- **不适合复杂生态**：多边平台需多张画布叠加，单张可能过度简化
