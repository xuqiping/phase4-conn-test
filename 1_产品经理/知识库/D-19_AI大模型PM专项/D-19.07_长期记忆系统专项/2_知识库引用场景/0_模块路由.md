# 2 知识库引用场景 — 何时查本叶子

## 场景矩阵

| 场景 | 何时查 | 查哪个模块 |
|---|---|---|
| **设计有跨会话个性化的 AI 产品** | PM 立项"AI 助手要记得我"类需求时；要在 Chatbot/Copilot 里加记忆 | 1（定义）→3（机制）→4（设计流程） |
| **Agent 长周期任务设计** | Agent 接管企业级多步任务（财务/代码/客服/项目管理），需跨会话保持连续性 | 1+3+4+5（参考 OpenAI/Letta） |

| **记忆系统评估与回归** | 已有记忆功能要做指标化、AB、上线前评估 | 3.3（指标）+4.2（看板模板） |
| **记忆崩溃事故排查** | 线上出现 Agent"失忆"事故（财务错账/客服忘历史），需根因定位 | 1（反命题）+5（反例）+4.2 |
| **记忆商业化咨询项目** | 客户咨询"如何给 AI 产品加记忆"；做记忆系统设计/咨询/培训课 | 1+3+5+变现片段03 D-19.07 |
| **多 Agent 协作的记忆架构** | 多 Agent 共享或隔离记忆的设计；防串扰防污染 | 3.1（隔离）+3.2（污染防护） |
| **隐私合规自查（记忆维度）** | PII/被遗忘权/GDPR/国内拟人化办法的记忆侧自查 | 1（隐私要素）+ 交叉 D-19.06 |
| **记忆成本与延迟优化** | 记忆库膨胀导致延迟/成本涨，需优化检索与遗忘策略 | 3.2（遗忘）+3.3（参数） |
| **新模型上线后的记忆一致性回归** | 切换底层模型后记忆召回/合成行为漂移，需回归测试 | 3.3（一致性指标）+4.2 |
