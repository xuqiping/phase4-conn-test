# 取消商业化与开放模块 · 人工测试方案

> Phase 3 功能级预处理产出。关联规格：[取消商业化与开放模块设计](../specs/取消商业化与开放模块设计.md)。

## 1. 为什么需要人工测试

- [x] 涉及桌面端与管理后台 UI 交互。
- [x] 涉及全局快捷键、剪贴板监听、截图和进程等真实原生能力。
- [x] 涉及登录、退出、Token 失效、设备禁用等跨端流程。
- [x] 涉及旧路由和旧授权接口兼容行为。

自动化测试负责状态和接口断言；人工测试负责真实窗口、快捷键、系统权限、浏览器导航和跨端联动。

## 2. 前置条件

- Windows 11，1920×1080，100% 或 125% 缩放。
- 桌面端 dev 端口 1420；后端 8088；管理后台使用项目配置端口。
- PostgreSQL/H2 测试迁移已执行；Redis 可用。
- 准备两个普通账号、两个不同设备身份；其中一个账号和一台设备可由管理员禁用。
- 不在文档中记录真实密码、JWT、AI Key 或推送密钥。

## 3. 正常路径

| 编号 | 场景 | 操作步骤 | 预期结果 | 实际 | 通过 |
|---|---|---|---|---|---|
| TC1 | 未登录使用本地模块 | 退出账号；依次打开文件、进程、剪贴板；触发截图 | 四个本地能力可用，无“未授权/试用”提示 | | ⬜ |
| TC2 | 未登录进入工作汇报 | 点击工作汇报 Tab | 不发送业务请求；显示“请先登录”和可聚焦登录按钮 | | ⬜ |
| TC3 | 未登录进入 AI 设置 | 打开设置并进入 AI | 不加载配置；显示登录引导 | | ⬜ |
| TC4 | 注册即用 | 注册新账号并立即登录 | 注册结果为 active，不出现等待审核 | | ⬜ |
| TC5 | 登录后全功能 | 登录无权益记录账号；使用工作汇报、AI、收件箱、灵感、推送配置 | 全部可用，数据属于当前账号 | | ⬜ |
| TC6 | 多设备不限量 | 同账号在超过旧上限的设备登录 | 新设备正常登记并使用服务端功能 | | ⬜ |
| TC7 | 后台安全管理 | 管理员查看用户/设备并执行禁用/启用 | 无权益/试用/额度入口；禁用/启用有效且有提示 | | ⬜ |

## 4. 功能联动与边界

| 编号 | 触发动作 | 联动对象与预期 | 反向/异常边界 | 实际 | 通过 |
|---|---|---|---|---|---|
| LC1 | 未登录启动应用 | 本地 Tab 可用；剪贴板监听仅启动一次 | 重启、重复挂载、监听失败不崩溃 | | ⬜ |
| LC2 | 工作汇报登录引导中完成登录 | 登录弹窗关闭；工作汇报加载当前用户数据 | 取消/登录失败仍保持引导 | | ⬜ |
| LC3 | AI 登录引导中完成登录 | AI 配置列表开始加载 | 退出后配置清空并恢复引导 | | ⬜ |
| LC4 | refresh 失败 | 清理服务端会话；本地模块继续可用 | 并发请求只触发一次刷新 | | ⬜ |
| LC5 | 管理员禁用当前设备 | 工作汇报/AI 后续请求 403 | 文件/进程/剪贴板/截图继续可用；其他设备不受影响 | | ⬜ |
| LC6 | 截图完成 | 新图片进入剪贴板并切换到剪贴板 Tab | OCR 失败不影响图片保存 | | ⬜ |
| LC7 | 打开旧后台路由 | 跳转 Dashboard，不白屏 | 浏览器后退、刷新仍稳定 | | ⬜ |
| LC8 | 调用旧授权接口 | 返回兼容响应或明确废弃错误 | 不返回 500，不泄漏签名/权益数据 | | ⬜ |

## 5. 原生与弱网场景

| 编号 | 场景 | 预期 | 实际 | 通过 |
|---|---|---|---|---|
| EC1 | 后端离线 | 本地模块可用；工作汇报/AI 显示网络错误 | | ⬜ |
| EC2 | 结束普通进程 | 无授权 Token 仍执行；系统权限错误清晰 | | ⬜ |
| EC3 | 截图区域过小/溢出 | 继续被参数校验拒绝，不因移除门禁而放宽 | | ⬜ |
| EC4 | 禁用账号刷新 Token | 会话失效并提示账号禁用 | | ⬜ |
| EC5 | 禁用设备重新心跳 | 返回设备禁用，不更新最后活跃时间 | | ⬜ |
