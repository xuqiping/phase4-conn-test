## 关键决策/偏离（须延续）

1. **召回缓存 evict 省略（偏离 plan）**：plan 坑点表提「授权变更 evict mem: 缓存」，但新栈召回（MemoryRecallPipeline）无 Redis 读缓存（H'-2 已删），`MemoryQueryCache` 仅剩 legacy 清理入口——索引查询即实时，无需 evict。
2. **viaAuthorizedLink 瞬态标方案（偏离 plan 文件清单）**：plan 原写改 `MemoryRecallScopeResolver`；实际用 VO 瞬态布尔 + SQL join projectName，pipeline 方法签名零改、既有测试零改。
3. **发起权=child OWNER（非 owner/admin）**：FR-101 原文「child owner 发起」；审批/撤销=parent owner/admin（同 P1 审核权边界）。
4. **复活语义**：同 (parent,child) 活行唯一——REJECTED 超 30 天 / REVOKED 再发起走条件 UPDATE 同行复活（created_at 重置为新发起时钟），不新增行不撞唯一索引。
5. **撤销不删行**：ACTIVE→REVOKED 状态翻转留审计痕；仅 child 取消 PENDING 走软删（未生效无审计必要，且释放唯一键）。
6. **前端两栏归属判定**：`managedIds`（genMatrix role∈OWNER/ADMIN）∩ child/parent projectId——后端 listInvolving 已按「任一侧 owner/admin」过滤，前端再按侧拆栏。
