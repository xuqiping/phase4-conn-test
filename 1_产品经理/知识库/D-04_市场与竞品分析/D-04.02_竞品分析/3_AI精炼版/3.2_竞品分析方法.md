## 竞品分析方法

### 1. SWOT分析（最通用）

| 维度 | 我们 | 竞品A | 竞品B |
|---|---|---|---|
| S(优势) | 我们的独有能力/资源 | | |
| W(劣势) | 我们的短板 | | |
| O(机会) | 市场趋势/对手弱点可利用 | | |
| T(威胁) | 竞争压力/替代风险 | | |

**PM实操**：不要只列自己的SWOT——把竞品的SWOT也做一遍，找到"对手的W=我的O"

### 2. 功能矩阵对比（最实用）

| 功能/维度 | 我们 | 竞品A | 竞品B | 权重 | 差距判断 |
|---|---|---|---|---|---|
| 核心功能1 | ★★★★ | ★★★ | ★★ | 高 | 我们领先 |
| 核心功能2 | ★★ | ★★★★ | ★★★ | 高 | 我们落后 |
| 差异功能1 | ★★★★★ | - | - | 中 | 我们独有 |
| ... | | | | | |

**评分标准**：★=基本有 / ★★=有但弱 / ★★★=行业平均 / ★★★★=优秀 / ★★★★★=行业标杆

**关键技巧**：
- 按"用户视角"而非"技术实现"定义功能名——用户不关心你用的是REST还是GraphQL
- 权重来自用户调研（问用户"哪个功能最重要"），不是PM自己拍脑袋
- 最后算加权总分，但**不要被总分骗了**——1个核心功能落后可能比5个边缘功能领先更致命

### 3. 体验对标（最深入）

不只看功能有没有，还要看"用起来怎么样"：

| 体验维度 | 我们 | 竞品A | 差异根因 |
|---|---|---|---|
| 首次使用上手时间 | 30min | 5min | 我们缺少引导流程 |
| 核心任务完成步骤 | 7步 | 3步 | 我们的信息架构太深 |
| 视觉满意度（NPS） | 6.5 | 8.2 | 我们的设计系统不统一 |
| 客服响应时间 | 24h | 2h | 我们人力不足 |

### 4. 波特五力（竞品版）

将经典五力模型适配到竞品分析：

| 力量 | 竞品分析应用 | 评估方法 |
|---|---|---|
| 买方议价权 | 用户是否容易在不同产品间切换 | 切换成本分析+替代品数量 |
| 供应商议价权 | 我们是否依赖少数关键供应商/平台 | 依赖度评估+备选方案 |
| 新进入者威胁 | 易否有新竞品快速出现 | 进入壁垒高度评估 |
| 替代品威胁 | 是否有完全不同的方案满足同需求 | 需求替代分析 |
| 现有竞争强度 | 行业内竞争有多激烈 | 竞品数量+差异化程度+价格竞争 |

### 5. 方法选择指南

| 目的 | 推荐方法 | 时间 | 深度 |
|---|---|---|---|
| 快速了解竞品全貌 | SWOT+功能矩阵 | 1-2天 | 中 |
| 深入对比功能差异 | 功能矩阵+体验对标 | 3-5天 | 高 |
| 战略级竞品研判 | 波特五力+SWOT | 1-2周 | 很高 |
| 决定优先做什么功能 | 功能矩阵（加权） | 2-3天 | 中 |
