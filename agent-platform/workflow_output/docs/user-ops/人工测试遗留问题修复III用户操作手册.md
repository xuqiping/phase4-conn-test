# 人工测试遗留问题修复III · 用户操作手册

> 面向组长/成员/财务/管理员。功能→步骤→界面变化→预期结果。

## 1. 组长：成员欠款与补差（A/B）

### 1.1 看欠款
入口：项目组 → 选组 → 「成员」tab。
界面：成员行「名下余额 / 欠款（组池垫·组长垫）」列；欠款>0 红字。
预期：消耗超限额后，超的部分按「谁垫的」拆两栏。

### 1.2 成员自助划款入组（还款）
入口：成员本人 → 组卡片「自助划拨」按钮 → 填积分。
预期：先还组长垫→再还组池垫→余款进「名下余额」；弹窗实时显欠款拆分。**还清即刻解冻**（页面自动刷新，不重进）。

### 1.3 豁免（调高限额抵欠款）
入口：成员行「限额」→ 调高数值。
预期：可用额度=新限额-已用（欠款被抵扣清零，无资金流动）；流水备注含抵扣额。调低不碰欠款。

### 1.4 重置已用（清欠修脏数据）
入口：成员行「重置已用」。
预期：used+双欠款清零；名下余额不动。确认弹窗二次确认。

### 1.5 退组结算
入口：成员行「移除」。
预期：名下余额先还款各回各家→余款退成员个人钱包→还不清的残欠核销（流水留痕，不再追讨）。

## 2. 组长/财务：批量选人与充值（E3）

### 2.1 按备注「A 班」圈人批量充值
入口：管理端「钱包/充值」→ 开「批量充值」开关 → 搜索框输 `A 班`。
界面：下拉行显「姓名 · 账号 · [备注 tag]」；点选多人成 chips。
预期：填积分→「充值（N 人）」→ 逐人到账；失败者列 ID 汇总，重选仅失败者重充不双扣。

### 2.2 批量邀请入组
入口：组「成员」tab →「邀请成员」→ 搜索（支持姓名/账号/备注）→ 多选 → 「发邀请（N 人）」。
预期：对方在「项目组→我的邀请」同意后才入组。

## 3. 管理员：解锁与姓名（E1/E2）

### 3.1 提前解锁被锁账号
入口：用户管理 → 状态=锁定且有到期时间行 →「解锁」。
界面：确认弹窗显「锁定至 YYYY/MM/DD HH:mm」。
预期：确认后该用户**立即可登录**；审计落「提前解锁账号」。封禁/禁用行不显此按钮（走「启用」）。

### 3.2 被锁用户看到什么
登录报错文案：「账号已锁定，将于 MM-dd HH:mm 自动解锁，可联系管理员提前解锁」。

### 3.3 设姓名/备注
- 个人中心：设置→个人信息→昵称/姓名（≤64）。
- 管理端：用户管理行「姓名」按钮。
预期：项目组成员表显「姓名（账号）」；审计详情操作人行括注现姓名+备注 tag。**审计列表用户列保持登录账号快照**（证据链）。

## 4. 组长：产出一键入库（F）

入口：组「产出」tab → 行尾「入库」。
- 图片行：弹窗选可写项目（仅你 OWNER/EDITOR 的）→ 入库。
- 视频行/对话行：同款弹窗（对话预填该轮回复）。
预期：成功后该行显绿「已入库」（刷新仍在）；**同项目再点**提示已入过不重复建；**换项目**可再存一份。
边界：无可用项目=下拉空态；EMBED/RERANK 行无入库按钮；多图任务默认第 1 张（其余去生成页逐张）。

## 5. 画布（C/D，2x）

- **@引用**：输入框打 @ 候选弹层跟光标；**双击上游媒体卡**自动把 @引用插到末尾并聚焦（生成中禁插）。
- **上游面板**：选中媒体节点侧栏往上游溯源（参考图/上游生成链）。
- **Lightbox**：点产物缩略图放大查看/播放。
- **自动保存**：右上徽标「保存中→已保存」；失败可重试；有未存改动离开弹确认。
- 默认图片模型/比例切换/节点副本/尺寸调节/点击行为：见画布工具栏与节点属性面板。

## 6. 常见异常与恢复

| 现象 | 原因/恢复 |
|---|---|
| 提交任务被拒「有欠款」 | 还款（2.1 自助划拨）或找组长豁免（1.3）；还清即解冻 |
| 批量充值部分失败 | 失败 ID 已列；重开批量模式只选失败者重充（独立幂等键不双扣） |
| 解锁按钮没有 | 该账号是封禁/禁用（非自动锁）——用「启用」动作 |
| 入库按钮没有 | 产物未成功（无文件）或非组长/管理；EMBED/RERANK 不可入库 |
| 入库提示「已入库过」 | 同项目判重——换项目可再存，或去资产库找既有资产 |
