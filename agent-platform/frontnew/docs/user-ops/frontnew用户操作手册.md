# frontnew 用户操作手册

> 面向：要比选 4 套前端主题的人。全程无需后端。

## 0. 启动

```bash
cd agent-platform/frontnew
pnpm install   # 首次
pnpm dev       # 打开 http://localhost:5173
```

## 1. 切换主题（核心动作）

**入口**：右上角「🎨 主题」按钮。

**步骤**：
1. 点击「主题」→ 弹出 4 个主题（各带 3 个预览色点 + 一句话描述）
2. 点击任一名称 → **界面变化**：全站立即换肤，无刷新无闪烁
3. 刷新浏览器 → **预期**：仍是你选的主题（localStorage 记忆）

**快捷方式**：URL 加 `?theme=cineon`（可选值 `neon-pulse` / `calm-slate` / `hybrid-glow` / `cineon`）直达指定主题，适合发链接给人定点看。

## 2. 看画布新卡片（重点）

**入口**：左侧导航「无限画布」（默认首页）。

**界面内容**：12 节点演示工作流，主干 脚本→分镜→图像→视频，旁支出音频/文本。

| 操作 | 界面变化 | 预期结果 |
|------|---------|---------|
| 看节点头部 | 类型色条+图标+类型名+SC 序号+状态点 | 6 类一眼可辨 |
| 看节点中部 | 类型特有预览 | 文本=摘要；图像=16:9 缩略图；视频=宽银幕缩略图+时长；音频=波形；脚本=行数；分镜=镜头小图阵 |
| 看节点底部 | 状态+耗时+token | 「失败」红、「完成」绿✓、「生成中」有动效（T1 流光/T2 呼吸点/T4 播放头扫描） |
| 点某节点 | 节点高亮 + 右侧属性面板显示详情 + 相连线变类型色 | 再点空白处全部还原 |
| 框选多节点 | 右面板显示「已选 N 个节点」 | — |
| 点连线中点 × | 该连线消失（仅前端演示） | — |
| 滚轮/拖拽 | 缩放平移 | 小地图（右下）同步 |
| 右上角工具条 | 放大/缩小/适应视图/节点数 | — |

**压测**：URL 改 `/canvas?nodes=100` → 100 节点网格；缩放手感应流畅。`?nodes=9999` 自动截 500。

## 3. 对话页

1. 左侧切会话（2 个 mock 会话）
2. 底部输入任意文字按 Enter → 消息上屏，AI **逐字打出**回复；打字期间输入框禁用
3. 消息类型示例：代码块（等宽灰底）、引用卡（左侧 accent 竖条）

## 4. 智能体大厅

1. 顶部搜索框输入关键词 → 网格即时过滤（名称/描述）
2. 点标签行标签 → 再叠加过滤；多标签是「或」关系；再点一次取消
3. 搜到无结果 → 空态提示；清空搜索恢复 12 张卡片

## 7. 常见异常与恢复

| 现象 | 恢复 |
|------|------|
| 页面样式全裸 | 确认 dev 服务器在跑；硬刷新（Ctrl+F5） |
| 主题切换无效 | DevTools → Application → 清 localStorage `frontnew-theme` 再刷新 |
| 画布空白 | 看 URL 是否带了非法 `?nodes=`，去掉即回演示流 |
| 端口被占 | `pnpm dev --port 5199` 换端口 |
