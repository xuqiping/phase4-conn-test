# P07 Skills 与 MCP 用户操作手册

## 技能是什么

把你反复用的任务流程存成一条「斜杠命令」。存在 `~/.devpilot/skills/<名字>/SKILL.md`，一个文件夹一个技能，复制走就能在别的机器用。

### 存一个技能

1. 走完一个任务后，在「追加指令」区域选择把本次上下文存成技能。
2. 填：技能名（小写字母/数字/连字符，如 `release-check`）+ 一句话描述。
3. 保存成功提示「可用 /名字 调用」。同名会拒绝，请换名字或先删旧的。

### 用一个技能

1. 建造阶段「追加指令续跑」输入框里打 `/` 加前缀，如 `/re` → 弹候选。
2. ↑↓ 选，Enter 展开（输入框上方出现技能标签）；Esc 关候选。
3. 输入你这次的具体要求，点「追加并续跑」——模型收到的是「技能正文 + 你的要求」。
4. 点标签上的 × 可摘掉技能，按纯文本提交。

注意：`/usr/bin` 这类路径不会触发候选；只有匹配到技能前缀才弹。

### 导入导出

- 导出：把技能目录整个复制到你选的位置。
- 导入：选一个技能目录（或装了一堆技能目录的文件夹），逐个复制进来；装不下的（文件坏了）会逐项告诉你原因，好的照常进。

## MCP server（给模型装外挂工具）

侧边栏「MCP 管理」一个页面全搞定：上半部分是已装的 server，下半部分是市场。

### 装一个

1. 市场卡片直接点「安装」，全程不用改任何配置文件。
2. 需要填 key 的（如 GitHub）会先弹表单，必填项填完才装。
3. 装完状态变「运行中」即立即可用；装失败会给原因（常见：没装 Node.js 或 uv，按提示装完重试）。
4. 手动添加：展开「手动添加」贴一段 JSON 配置，校验通过走同一条安装链路。

### 日常管理

- 状态徽章：运行中 / 已停止 / 出错（红）/ 需人工处理（黄）。
- 出错或需人工处理时，「一键重启」按钮高亮，点它恢复；反复崩会自动停手转人工——这时看日志排查。
- 「日志」打开最近 200 条，可一键复制贴给别人求助。
- 「卸载」要二次确认；只删配置记录和进程，不动你的 npm/pip 缓存。

## 贴图（截图当需求）

- 截图直接**拖**进追加指令框，或 **Ctrl+V** 粘贴。
- 支持 png/jpg/webp，原图 ≤10MB；存盘自动压成 ≤1MB（省空间，模型也够看）。
- 图片以标签形式显示（文件名+大小），点 × 撤掉。
