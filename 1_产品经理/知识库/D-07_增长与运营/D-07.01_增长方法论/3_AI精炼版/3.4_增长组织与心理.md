# 3.4 增长组织与心理

## 增长团队组织设计

### 三种建制模式

| 模式 | 结构 | 优势 | 劣势 | 适用阶段 |
|---|---|---|---|---|
| 独立增长团队 | 专职GM+分析师+工程师+设计师 | 聚焦+速度快 | 易与产品团队冲突 | 1→10/10→100 |
| 虚线增长团队 | 成员归属各职能但虚线汇报GM | 跨职能+灵活 | 执行力受职能主管影响 | 1→10 |
| 增长嵌入产品 | 每个产品小队含增长角色 | 最贴近业务 | 可能增长被日常需求淹没 | 10→100 |

### 增长会机制

| 频率 | 内容 | 时长 |
|---|---|---|
| 每日standup | 实验进展+阻塞+数据更新 | 15min |
| 每周growth review | 实验结果回顾+新实验启动 | 60min |
| 每月战略会 | 北极星复盘+杠杆重排+下月计划 | 120min |

### OKR与增长对齐

- **O(目标)**：季度增长方向（如"提升新用户激活率"）
- **KR(关键结果)**：可量化的验收标准（如"新用户7日激活率从30%→45%"）
- **Initiatives**：达成KR的实验组合（如"新手引导3组实验+推送2组实验"）
- 铁律：每条KR至少关联1个可执行的实验

## K.01 增长心理学

### 行为经济学在增长中的应用

| 效应 | 增长应用 | 示例 |
|---|---|---|
| 锚定效应 | 先展示高价再展示低价 | 定价页先展示Enterprise再看Pro |
| 损失厌恶 | 强调不行动的损失 | "限时优惠最后3天" |
| 社会认同 | 展示他人行为 | "10万人已加入"/评价/销量 |
| 稀缺性 | 限时/限量 | "仅剩2个名额" |
| 禀赋效应 | 让用户先感受拥有 | 免费试用→不舍得放弃 |
| 诱饵效应 | 加入诱饵让目标选项更显优 | 三档定价中档最有性价比 |

### 增长触发器（Behavioral Triggers）

| 触发器类型 | 说明 | 增长应用 |
|---|---|---|
| 内在触发 | 用户内心需求驱动 | 无聊→刷抖音/焦虑→学英语 |
| 外在触发-付费 | 花钱买的触达 | 广告/SEM/KOL |
| 外在触发-赢得 | 靠口碑获得的触达 | 好友推荐/App Store好评 |
| 外在触发-自有 | 自有渠道触达 | 推送/邮件/公众号 |

**Nir Eyal的上瘾模型(Hook Model)**：

```
触发(Trigger) → 行动(Action) → 变动奖励(Variable Reward) → 投入(Investment) → 触发（循环）
```

[来源: Nir Eyal, "Hooked" | 置信度:🔍高]

### 用户激活的心理路径

1. **感知价值**：用户看到产品能解决什么问题（价值主张清晰度）
2. **感知易用**：用户觉得用起来简单（新手引导 Friction 最小化）
3. **信任建立**：用户相信产品可靠（社会认同/权威背书）
4. **首次成功**：用户完成第一个有意义的动作（Aha Moment到达）
5. **习惯形成**：用户反复使用（Hook循环建立）

## K.10 说服力在增长中的应用

增长PM需要有说服力——说服用户行动（转化）+说服团队优先（内部对齐）：

- **对用户**：行为设计（Hook模型）/文案优化（清晰>聪明）/个性化推荐（预测下一步）
- **对团队**：用数据讲故事（"这个实验能提升X%的Y指标"）/快速试错降低决策成本/小胜利建立信心
