## 一、人工测试用例（P4 勾选用）

| # | 用例 | 操作步骤 | 预期结果 |
|---|---|---|---|
| J1 | 单节点复制粘贴 | 选 1 个有产物的图片节点 → Ctrl+C → 鼠标移到空白处 Ctrl+V | toast「已复制 1 个节点」；粘贴体落在鼠标处、产物同显；与原节点重生成互不影响（脱钩）；右上「已保存」闪现、刷新还在 |
| J2 | 框选子图复制粘贴 | 造链 A→B→C（含一条通向集外的边）→ 框选 A、B、C → Ctrl+C → 别处 Ctrl+V | 3 节点+2 内边一次粘出（相对位置保持）；通向集外的边**不带**；label 撞名追加序号（A 2…） |
| J3 | 连按错开 | 同一剪贴板连按 3 次 Ctrl+V | 三组粘贴体逐次 +32 错开不重叠，label 序号递增 |
| J4 | 粘贴一步撤回 | 粘贴一子图后 Ctrl+Z，再 Ctrl+Shift+Z | 一步整体消失（节点+边）；重做一步整体回来 |
| J5 | 一键整理全图 | 乱摆 8+ 节点（含 2 个不连通孤立点、1 个自环）→ 点工具条 ✨ | 上游在左下游在右、孤立点另起一列不重叠；视口自动 fitView；Ctrl+Z 一步还原全部旧位置 |
| J6 | 整理选中子图 | 框选链中 2 节点（其一属组）→ 点 ✨ | 只重排选中+整组拉入的成员，集外节点原地不动；组包围盒跟随新位置、组色/组名不变 |
| J7 | 整理后持久化 | 整理完等「已保存」→ 刷新页面 | 布局保持（position 已落库）；撤回栈清空（预期，重进=新时间线） |
| J8 | 回归抽测 | 修复VI 图片 Ctrl+V/文件拖拽、「创建副本」连边、批量生成、@候选跟光标、只看关联 | 行为与修复VII 前一致 |

## 二、功能联动用例（对齐 plan 联动清单 10 条，含反向/半选/批量）

| # | 触发→联动 | 验证点（含边界） |
|---|---|---|
| K1 | 无选中 Ctrl+C → 清剪贴板 | 正向：复制过节点后，Esc 清选→Ctrl+C→Ctrl+V 外部图片→建**图片节点**（通道恢复，非节点副本） |
| K2 | Ctrl+V 三级优先 | 内部剪贴板非空→粘节点；清空后→外部图片→图片链；焦点在输入框→三级全让位（正常粘文本） |
| K3 | 粘贴 × 撤回/重做 | J4；撤回后剪贴板保留（可再 Ctrl+V，新 id 不撞） |
| K4 | label 去重 × @引用 | 粘贴体 @文本仍指原节点（不重写）；删原节点后→【断链】既有口径兜底 |
| K5 | 整理 × 选中态 | 有选=子图模式（J6）；Esc 清选后点 ✨=全图模式（J5）；半选：只选 1 个孤立节点点 ✨=合法 no-op 不报错 |
| K6 | 整理 × 只看关联 | 「只看关联」隐藏若干节点后点 ✨→隐藏节点也被重排（可见性会话态），整理后隐藏态不变 |
| K7 | 整理 × 组 | 整理不动组关系；组头改名/解散照常；包围盒 rAF 跟随无残影 |
| K8 | 整理 × 运行中节点 | 生成中的节点参排：位置动、任务轮询/完成回调不炸（完成定型尺寸与排版无冲突） |
| K9 | 整理 × 保存链 | 整理只触发一次防抖保存（徽标闪一次）；断网整理→「保存失败重试」链路同既有 |
| K10 | 工具条 disabled | 空画布 ✨ 禁用（aria-disabled=true）；加 1 节点即恢复 |
