# D-06.07 实验与A/B — AI精炼版

---

## 3.1 实验基本原理

**核心逻辑**：随机化分组 → 控制混杂因素 → 归因因果效应。

**因果推断中的RCT**：随机化对照实验（RCT）是因果推断的"金标准"——随机分组使处理组和对照组在所有可观测和不可观测特征上期望相等，因此组间差异可归因为处理的因果效应。

**三大底层假设**：
1. **SUTVA（稳定单位处理值假设）**：一个用户的处理状态不影响另一个用户的结果（无溢出效应）
2. **一致性**：处理分配与实际接受的处理一致
3. **可忽略性**：给定协变量，处理分配独立于潜在结果（随机化保证）

## 3.2 实验设计类型

### 3.2.1 经典A/B测试

| 要素 | 说明 |
|---|---|
| 分组 | 随机分为对照组(A)和实验组(B) |
| 比例 | 通常50:50，低风险实验可用90:10 |
| 指标 | 1个OEC(总体评估标准)+若干护栏指标 |
| 时长 | ≥1个完整周期(7天)或达到预设样本量 |
| 停止规则 | 达到预设运行时间或样本量后分析 |

### 3.2.2 A/B/n测试

- 同时测试多个变体（n>2），如3-5个推荐算法同时对比
- 需要更大的样本量（多重比较校正）
- 适用于候选方案筛选阶段

### 3.2.3 多变量测试（MVT）

- 同时测试多个因素的组合效应（如按钮颜色×文案×布局 = 2×2×2 = 8组）
- 可估计交互效应
- 样本量需求大（组数多），适合大流量场景

### 3.2.4 交错实验（Interleaving）

- **原理**：在单次展示中将两个算法的结果混合交替呈现，用户点击作为"投票"
- **优势**：所需样本量仅为A/B测试的1/10~1/100
- **适用**：排序算法/推荐算法对比
- **局限**：只能比较排序质量，不能测量业务指标变化
- **Netflix首创**：2013年论文，已成为推荐系统标准方法

### 3.2.5 网络效应实验

| 方法 | 原理 | 适用场景 | 局限 |
|---|---|---|---|
| Cluster随机化 | 按社交簇/地理区域整群随机 | 社交产品 | 精度损失（需更大样本） |
| Switchback | 按时间片交替开关处理 | 双边市场(出行/外卖) | 时间异质性 |
| Geo实验 | 按地理区域随机分配 | 营销/定价 | 区域差异混杂 |

## 3.3 统计检验方法

### 3.3.1 假设检验框架

| 要素 | 说明 |
|---|---|
| 原假设H₀ | 实验组=对照组（无差异） |
| 备择假设H₁ | 实验组≠对照组（有差异） |
| 显著性水平α | 通常0.05（5%假阳性率） |
| 统计功效1-β | 通常0.8（80%检测真实效应的概率） |
| p值 | 在H₀下观测到当前或更极端结果的概率 |
| 置信区间 | 效应大小的区间估计 |

### 3.3.2 检验方法选择

| 指标类型 | 检验方法 | 适用条件 |
|---|---|---|
| 比例型（转化率） | Z检验/卡方检验 | n≥30, np≥5 |
| 均值型（停留时长） | t检验/Welch t检验 | 检验正态性或大样本 |
| 计数型（点击次数） | 泊松回归/负二项回归 | 过离散时用负二项 |
| 排序型（Interleaving） | 符号检验/配对t检验 | 交错实验专用 |
| 非参数 | Mann-Whitney U/Bootstrap | 分布未知或极端偏态 |

### 3.3.3 样本量计算

**公式**（双比例检验）：
n = (Z_α/2 + Z_β)² × [p₁(1-p₁) + p₂(1-p₂)] / (p₁ - p₂)²

**关键参数**：
- MDE（最小可检测效应）：业务上值得关注的最小变化，如1%相对提升
- 基线转化率：p₁
- 期望转化率：p₂ = p₁ × (1 + MDE)
- α=0.05, β=0.2（80%功效）

**实际建议**：使用在线计算器（Evan Miller A/B Calculator）或statsmodels库自动计算。

## 3.4 常见陷阱与反模式

| 陷阱 | 表现 | 修正方法 |
|---|---|---|
| 偷看结果 | 多次查看p值，p<0.05就停 | 预设运行时间，或用序贯分析/始终有效置信区间 |
| p值操纵 | 不断增加指标直到某指标显著 | 预注册OEC，护栏指标仅作参考 |
| 新奇效应 | 新功能短期效果好但衰减 | 延长实验周期，观察趋势而非单点 |
| 溢出效应 | 社交功能实验影响对照组 | 用Cluster随机化/Switchback |
| 辛普森悖论 | 整体和分层结论相反 | 分层分析，检查组间不均衡 |
| 样本量不足 | 效应不显著但实际有效 | 计算MDE，确保样本量足够 |
| 护栏指标缺失 | 主指标提升但负向指标被忽略 | 必设护栏指标（如卸载率/投诉率） |
| AA测试未做 | 分流本身不均 | 先做AA测试验证分流正确性 |

## 3.5 进阶方法

### 3.5.1 序贯分析（Sequential Testing）

- **目的**：实现"边跑边看"，不用等预设时间结束
- **方法**：始终有效置信区间（Always-Valid CI）/mSPRT/群体序贯设计
- **优势**：提前检测大效应，节省时间
- **代价**：需要更严格的显著性阈值

### 3.5.2 分层实验平台

- **问题**：多实验并发时流量互斥，实验效率低
- **方案**：分层实验（Layered Experiment）——每层独立随机化，不同层的实验正交
- **经典架构**：Google Overlap Experiment Infrastructure（2010）/Microsoft ExP
- **关键**：正交分层保证不同层实验之间无干扰

### 3.5.3 方差削减（Variance Reduction）

- **CUPED**：使用实验前协变量调整方差，等价于减少所需样本量
- **效果**：可减少30-50%的样本量需求
- **实现**：Y_adj = Y_观测 - θ × (X_预实验 - E[X])

### 3.5.4 异质处理效应（HTE）

- **目的**：不再只看平均效应，而是"对谁有效、对谁无效"
- **方法**：Causal Forest / Meta-Learner (S/T/X-Learner)
- **应用**：个性化策略——对响应好的用户上线，对响应差的不上线

## 3.7 前沿趋势（2025-2026）

1. **AI时代实验范式迁移**：从静态分组→动态自适应实验，传统A/B假设（i.i.d.、恒定效应）在AI产品中失效，需新方法论 [A/B测试失效真相 | 中置信度 | 2026]
2. **自动化实验**：AI自动生成分组策略、自动检测效应、自动决策上线，减少人工干预
3. **合成控制+实验融合**：小流量场景用合成控制增强因果识别
4. **实验文化民主化**：从"只有数据团队做实验"到"PM自助式实验"，GrowthBook/Statsig等降低门槛
5. **隐私保护下的实验**：差分隐私实验分析、联邦学习下的多端实验
6. **Interleaving成为推荐系统标配**：Netflix方法被广泛采用，2025-2026年大量公司落地
