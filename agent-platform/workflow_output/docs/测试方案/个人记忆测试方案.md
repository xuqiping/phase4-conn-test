## 功能联动用例(L1-L12,每条含正向/反向/半选/批量)

> **铁律 v1.9**:每条联动须测反向/半选(取消父、子部分勾),只测正向必漏 bug。

### L1 gen 开关切換(owner AND 会员)
- **正向**:owner 开+会员开 → 新对话生成 L0/L1/L2 落库。
- **反向**:owner 关 → 会员覆写无效,项目侧不生成(会员开也只留 raw)。
- **半选**:会员关+owner 开 → 仍写 raw 不生成。
- **批量**:两侧前置过滤独立跑(双侧被过滤→不写 raw 也不调 LLM)。

### L2 召回 scope 多选
- **正向**:勾{个人+项目X} → 召回并集。
- **反向**:取消全部 → 空召回不报错。
- **半选**:勾离职人员但「同步已离开」关 → 仍不召回(开关优先级高)。
- **默认**:首次无历史默认{个人};持久化上次选择新会话沿用。

### L3 写入目标多选(与召回解耦)
- **正向**:勾{个人+项目X} → born_personal=true + project_ids=[X]。
- **反向**:卸空所有项目 → 自动转 born_personal=true。
- **半选**:显式取消{个人}仅项目X → born_personal=false(个人页不可见)。
- **默认**:不跟随召回 scope。

### L4 冲突裁决四选项
- **正向**:KEEP_BOTH → 两条按 created_at 排序都留。
- **反向**:DISCARD 被他人引用且引用方 summarized_at>12h → 拒 403。
- **半选**:KEEP_NEW/OLD → 留一条另一条软删(turns 保留)。
- **批量**:DISCARD 连带软删 source_turn_ids 全部 turns(防死循环)。

### L5 成员离职
- **正向**:置 DEPARTED+departed_at → 该项目 turns 追加 departed_project_ids。
- **反向**:本人召回 scope 锁定不可选原项目。
- **半选**:本人 born_personal=true 记忆仍经个人 scope 召回不受影响。
- **补救**:copy-to(copy 非 move,原项目零改动)。

### L6 项目删除
- **正向**:项目删 → turns 追加 deleted_project_ids(不从 project_ids 移)+ 清项目 summary/coverage/members + 曾写成员收 PROJECT_DELETED_AFFECTED 通知。
- **反向**:个人 summary(project_id=NULL)不清;个人 scope 召回不受影响。
- **半选**:restore 仅拉 turn 不拉 summary。
- **批量**:折叠板 badge 聚合多个未处理项目。

### L7 流水账删除 + summary 级联
- **正向**:删自己的 turn → source_turn_ids @> [T] 的 summary 标 STALE + 删 coverage + worker 重压缩。
- **反向**:他人引用且引用方 summarized_at>12h → 拒删 403。
- **半选**:无他人引用 → 作者随时删(含 born_personal=true 同时挂项目的)。
- **批量**:跨用户波及每命中一个他人 summary 写 SUMMARY_AFFECTED_BY_RECALL 通知;个人 scope 删不发通知。

### L8/L9 手动/自动总结勾选 scope
- **正向**:手动勾有变化 scope → 先 backfill raw 再压缩;自动勾{个人}每天定时跑。
- **反向**:无变化 scope 灰选不可点;自动定时跑前判无新增空跳过不耗 token。
- **半选**:gen 关态定时仅总结 gen_done=true 的已生成 turn,raw 不纳入。
- **默认**:自动默认勾{个人},项目主动加。

### L10「同步召回已离开项目人员」开关
- **正向**:项目 scope 开关开 → 召回+总结取数含离职人员,带「已离开人员·名·date」标注。
- **反向**:开关关 → 离职人员既不召回也不进任何总结取数。
- **半选**:勾了离职人员也召回不到(开关优先级高于人员多选)。
- **批量**:同时控召回与总结取数。

### L11 流水账挂载项目(project_ids 增减)
- **正向**:挂项目X → X 成员可读(经 ACL)。
- **反向**:卸空 → born_personal 转 true。
- **半选**:ACL 未授权的读者读不到(挂了也读不到)。
- **批量**:可多挂;首次挂载弹确认。

### L12 标签归一命中(写时)
- **正向**:精确 label / aliases / anchor≤阈值+二次 LLM 判同义 → 复用 tag_id,usage_count++。
- **反向**:误并不可逆 → 禁归并/拆分/重抽。
- **半选**:仅 owner 改 label/补 aliases(tag_id 不变,anchor 重生属预期纠错)。
- **批量**:全 miss 新建;并发 10 线程同义词 → UNIQUE 兜底只造一条。
