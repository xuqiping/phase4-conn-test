## 功能简介
每轮对话全程留痕(按侧过滤,过过滤侧落 raw)→ 开生成后一次 LLM 出 INPUT/OUTPUT 双侧三层(L0 标签 `主体:主题` / L1 一句概要 / L2 结构化详述)→ 写时标签归一进独立表 → 召回聚合 scope 内标签、优先读自己总结、reflect 判深读、拼未覆盖流水账 → 周期/手动总结把流水账压成精华条(provenance 溯源)→ 时序互斥进冲突 pending → 流水账可挂多项目按成员 ACL 只读共享。

## 活聊天入口(切流 H'-1)
[ChatSessionService](../../backend/src/main/java/com/superprogrammer/chat/service/ChatSessionService.java):
- **召回** 3 处(syn/stream)→ `MemoryRecallPipeline.recall(query, scopeReq, userId).assembledText`(null/降级→空串兜底)。
- **写入** 6 处(syn/stream/agent)→ `MemoryGenerationService.processTurnAsync(...)`(fire-and-forget,走 [memoryTaskExecutor](../../backend/src/main/java/com/superprogrammer/chat/config/MemoryTaskExecutorConfig.java))。
- 默认召回 scope = {个人 + 当前会话项目},方向 BOTH,时间窗 null,includeDeparted=false。scope 走用户持久化偏好([MemoryRecallScopePreferenceService](../../backend/src/main/java/com/superprogrammer/chat/service/internal/MemoryRecallScopePreferenceService.java))。
- **旧栈已弃**:活冲突拦截 `interceptConflict`、`recordIncident`、incident/status 轮询、HYBRID/ASYNC 分支全删(新栈冲突走面板非聊天拦截;写入恒异步)。

## 配置开关(走 `system_settings` KV upsert + 独立设置表,无 Flyway)
| key / 表 | 用途 | 默认 |
|---|---|---|
| `rag.memory.gen.personal.enabled` | 非项目会话兜底 gen | 开 |
| `memory_project_settings.gen_enabled` | owner 项目级 gen(AND) | 开 |
| `memory_project_user_settings.gen_enabled` | 会员个人覆写 gen(AND) | 开 |
| `memory.tag.anchor-threshold` | 标签归一 anchor 阈值 | 0.25 |
| `memory_consolidation_scopes.auto_enabled` | 自动总结 scope 勾选 | {个人} |
| 召回方向/时间窗/离职开关 | 用户偏好(`memory_recall_scope_prefs`) | BOTH/不限/开 |
| raw TTL | worker 软删 `gen_done=false AND age>90d` | 90 天 |
| 防膨胀阈值 | 总结链 >N 再压一次 | 用户配 |
