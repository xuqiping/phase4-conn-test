## 关键结论（一句话）

离线授权用 HMAC 对称签名 → 密钥必然外泄可伪造 token（P0-1），叠加「绝对过期时间未校验可无限续期（P1-1）」「特权命令无 Rust 侧门禁（P1-2）」，当前接近「挡君子不挡小人」。根治方向：Ed25519 非对称签名 + token 内 `notAfter` 强校验 + 特权命令 Rust 侧 `require_module`。
