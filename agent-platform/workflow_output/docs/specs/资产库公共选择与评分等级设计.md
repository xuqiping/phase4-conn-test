# 规格 · 资产库：公共池选择、成员搜索默认展示、评分等级制、复制管控

> Phase 1 修复规格。实现必须与本文一致；来源为 2026-08-17 人工测试问题 2x 未解决项 #4/#5/#7 与「待决策：别人的项目内容是否允许被复制」（用户已拍板：发布时 OWNER 自选）。
> 关联：[资产库公众池与授权修复规格](资产库公众池与授权修复.md)｜[项目资产库 Feature Map](../feature-map/项目资产库.feature-map.md)。

## 1. 目标

1. 图片生成/视频生成模块的资产选择器可选公共池资产（当前只有我的/共享项目）。
2. 分享弹窗点开用户搜索即展示用户列表，无需先输入关键词。
3. 资产评分展示由百分制数值改为 A+/A/B/C/D 等级制（存分不变，展示派生）。
4. 公共池发布时 OWNER 可设置「是否允许复制」，复制接口按标志管控。

## 3. 公共池资产选择（2x#4）

### 3.1 前端契约

- `AssetFilePicker.vue` 项目来源区新增「公共池」分组（或 Tab）：
  - 数据 = GET /api/assets/public-pool 中 `usable=true` 的项目（不可用的不展示，与资产库页公共池 Tab 口径一致）；
  - 选择公共池项目后，资产列表复用现有 `assetApi.list(projectId, ...)`（后端 ACL 已放行，无需新接口）；
  - 类型过滤沿用 `type` 参数；确认 resolve 链路不变。
- 仅限 usable 项目：APPROVAL_REQUIRED 且未获批的项目不出现在选择器（后端 usable=false 天然过滤）。
- 画布侧 `AssetPicker.vue`（canvas 专用）同缺口：同口径补「公共池」来源（组件结构不同源，分别改，行为对齐）。

### 3.2 后端契约

- 唯一缺口：公共池摘要 VO 若不含项目 `mediaTypes`（选择器需按图片/视频过滤项目），在 `AssetPublicPoolService` 摘要装配中补该字段（读 asset_projects 已有列，无新表）。
- 无新权限语义：VIEWER 读资产/resolve 均为既有放行面，不扩大。

## 4. 成员搜索默认展示（2x#5）

### 4.1 根因

前端 `ShareDialog.vue:257-268` 在关键词为空时主动不发请求并清空候选；后端本就支持空关键词（返前 20）。

### 4.2 修复契约

- 前端：弹窗打开（或下拉 focus）即以空关键词调 `searchCandidates`，初始就展示候选列表；输入仍实时远程过滤。
- 后端：`searchActiveCandidates` 空关键词 LIMIT 由 20 提至 50（有 keyword 时维持 20）；接口签名不变。
- 边界：不做下拉滚动分页；用户多于 50 时需输入关键词收窄（提示文案「输入用户名筛选，最多展示 50 人」）。
- 排除规则不变：排除 OWNER、现有成员、操作人自己；只返 id/username。

## 5. 评分等级制（2x#7）

### 5.1 映射规则（后端唯一真相源）

| 分数区间 | 等级 |
|---|---|
| ≥95 | A+ |
| 90–94 | A |
| 80–89 | B |
| 70–79 | C |
| <70（含已评 0–69） | D |
| 未评 | 不显示等级（维持现状空态） |

- 存储不变：`asset_scores` 仍存 0-100 整数，双轨算法（拥有者分/成员均分）不变。
- 派生位置：后端 Java 常量 `AssetGrade.fromScore(int)`；`AssetScoreVO` 与列表批量 VO 增加 `ownerGrade/memberAvgGrade` 字段，前端只展示不自行映射（防两处漂移）。
- 展示位：资产卡片（`AssetCard.vue:56-60`）与详情抽屉（`AssetDetailDrawer.vue:164-207`）数值旁加等级徽章（如 `★A+`、`均分 B·3人`）；打分表单滑杆旁实时显示当前分对应等级。
- 筛选：保留 scoreMin/scoreMax；前端筛选条新增等级快捷选（A+/A/B/C/D → 映射为对应分数区间下发，后端零改动）。

## 6. 复制管控（待决策项落地）

### 6.1 数据模型（Flyway 迁移）

`asset_projects` 增列：

- `allow_public_copy BOOLEAN NOT NULL DEFAULT TRUE`（存量默认允许，兼容现状与已发布项目）

### 6.2 行为契约

- 发布到公共池时（OWNER 或 admin）表单提供「允许公共用户复制资产」开关，默认开；admin 代发布同样可设。重新发布可改。
- `AssetService.copyCurrent`：源项目 `publicPool=true` 时校验 `allowPublicCopy`，false 则抛 `BusinessException(ASSET_COPY_FORBIDDEN)`（新增 ErrorCode，403 语义）。
- 前端公共 VIEWER 资产卡片「复制到我的项目」按钮按项目摘要中的 `allowPublicCopy` 显隐；关闭时该位置不渲染（不留死按钮）。
- 摘要 VO / 项目详情 VO 透出 `allowPublicCopy`。
- 复制副本仍为 PERSONAL 归复制者、与源解耦（现状不变）；项目内成员复制（非公共路径）不受此开关限制——开关只管公共池 VIEWER。
- 移出公共池后开关值保留，再次发布时可改。

## 7. 测试策略

| 层 | 用例 |
|---|---|
| 后端单测 | 等级映射边界（94/95、89/90、79/80、69、未评）；VO 派生字段；空关键词候选≤50 且排除项正确；copyCurrent：公共池 allow=false 拒绝 / =true 通过 / 非公共项目不受限；发布写入开关；摘要含 mediaTypes |
| 前端单测 | ShareDialog 打开即有候选；等级徽章渲染；等级筛选映射分数区间；复制按钮显隐 |
| 人工/playwright | 图片页选参考图 → 公共池项目可选且能 resolve 入表单；视频页首帧从公共池选取；分享弹窗开箱见用户列表；公共池关闭复制的项目无复制按钮且直调 API 403 |

## 8. 边界与不做

- 不改评分存储与双轨均分算法；不引入 A-/B+ 等半级（如需后续加映射行即可）。
- 不做成员候选下拉分页/滚动加载。
- 不改「共享给我」与公众池的既有可见边界（详见旧规格）。
- 画布 `AssetPicker` 公共池入口为顺带统一项，若结构差异大可单独排期（在 plan 中拆分）。

## 9. 术语表

| 术语 | 大白话 | 简单案例 |
|---|---|---|
| 公共池 | 项目 OWNER 发布出去、所有登录用户按权限使用的资产项目 | 团队把素材包发布成公共池，别人画布里直接引用 |
| usable | 摘要接口算出的「当前用户能不能用」标志（OPEN/已获批/admin/owner） | 需审批且未获批 → usable=false，选择器不展示 |
| ACL 咽喉 | 所有权限判断收敛经过的一个函数/服务，改一处全局生效 | AssetAclService.requireXxx |
| 双轨评分 | 拥有者打分单列、成员打分取平均，两轨互不混算 | ★88（拥有者）· 90·3人（成员均分） |
| 派生字段 | 不存库、由已有数据现场算出的字段 | 88 分 → 等级 B，B 不入库 |
