## 共享运维考量清单（7 类逐条落字）

| 类 | 决策 | 落点 |
|---|---|---|
| 可观测性 | **做**：计价新路径（闲时选价/缓存三腿/BACKSTOP 计 used）DEBUG 日志带 traceId/taskId；WS 事件推送失败 WARN+计数（仿 UsageCollector 丢弃计数）；审计写入失败已有计数不动 | 各子计划步骤内 |
| 配置开关 | **做**：闲时整体 `enabled` 开关（关=全忙时，出问题秒关）；间隔秒数可配；**不做**：缓存计价开关（NULL 列天然回退）、审计开关（哈希链不能断） | D1/D8、C2 |
| 可回滚 | **做**：价表新列全 NULL 默认（回滚=行为不变）；SECOND 合并用逻辑删除（可恢复）；**受限**：存量 BACKSTOP 补 used 无自动回滚（逆向脚本=减回同额，迁移日志记录每笔明细供逆向）；E 无 DB 变更天然可回滚（前端不连即回退轮询前的手动刷新态） | A3、D1 |
| 限流/熔断/降级 | **做**：WS 心跳 30s×3 踢除、监听器异常只 WARN；**不做**：事件队列背压（单实例量小）；C 被拒不耗配额已属限流修正 | E2/E3、C2 |
| 运维入口 | **做**：对账 tab 本身即白嫖探针（A 交付）；价表偏差提示即校准入口（D9）；**后续再说**：WS 连接数监控页（单实例无需求） | A、D |
| 告警阈值 | **后续再说**：对账 diff≠0 已在页面标红，暂无外部告警通道（无钉钉/邮件运维告警接入）；记录为待办不阻塞本期 | — |
| 容量/性能 | **想过**：审计 P2 高频编辑端点 detail 精简防表膨胀（B5）；WS 每用户 Set 索引内存 O(在线用户×端)，千级用户无压力；**不做**：审计表分区（现量级不到） | B5、E2 |
