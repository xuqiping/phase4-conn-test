# 产品经理体系 Workflow Checklist

Use this checklist after completing every step of `workflow/product_manager_workflow.md`. Every item must be answered **yes** before the step is considered complete. If any item is **no**, fix the output and re-validate.

## Step 1: 产品需求设计与优先级管理

- [ ] 用户洞察完成：JTBD任务清单（≥5个核心任务）+ 痛点热力图
- [ ] KANO分类完成：基本型/期望型/兴奋型/无差异/反向需求已分类
- [ ] RICE评分表完整：Reach/Impact/Confidence/Effort四项均有数值
- [ ] 需求优先级排序：Top 20%进入Now（当前迭代）
- [ ] Validation Pyramid四层验证计划：问题假设→解决方案假设→MVP测试→PMF验证
- [ ] 每层验证有明确通过标准（如MVP 7日留存>20%）
- [ ] North Star Metric已定义且可量化
- [ ] AARRR漏斗已绘制，关键转化节点标注
- [ ] Now-Next-Later路线图产出，战略方向明确
- [ ] 所有`[参考: ...]`标注指向的知识库文件真实存在且章节可定位

## Step 2: 原型设计与PRD撰写

- [ ] 原型三阶段覆盖：低保真（草图）→中保真（交互）→高保真（视觉）
- [ ] Double Diamond四阶段完成：发现→定义→开发→交付
- [ ] 8段式PRD结构完整：背景/用户/范围/交互/数据/非功能/依赖/指标
- [ ] 每条需求可测试且有明确验收标准
- [ ] 无歧义表述（无"友好"/"快速"等主观词）
- [ ] 状态机覆盖所有边界情况（加载/空/错误/成功/部分成功）
- [ ] 数据埋点清单：事件名/触发时机/属性字段已规划
- [ ] 无障碍设计：WCAG 2.1 AA合规已评估
- [ ] 设计系统：Atomic Design层级或Design Token变量化已定义
- [ ] PRD评审通过（PO+Tech Lead+Designer确认）

## Step 3: 技术产品商业化规划

- [ ] BMC九要素或Lean Canvas已填写完整
- [ ] ICP（理想客户画像）和Buyer Persona已定义
- [ ] 定价策略明确：订阅/用量/Outcome至少1种，定价理由充分
- [ ] GTM策略：PLG/SLG/AI驱动至少1种，路径清晰
- [ ] PLG飞轮（如适用）：Land→Expand→Convert，PQL定义明确
- [ ] SaaS关键指标：NRR目标>120%/Rule of 40达标/Magic Number>0.75
- [ ] 增长黑客工具：A/B Test/Referral/UGC至少1种已规划
- [ ] 财务预测：CAC/LTV/回本周期/3年收入模型
- [ ] 国际化合规：GDPR/多语言/多币种已评估（如适用）
