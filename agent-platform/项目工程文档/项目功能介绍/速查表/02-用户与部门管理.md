# 02 - 用户与部门管理

## 功能简介
管理员对用户列表/启停、分配角色；部门树 CRUD、部门成员管理；钉钉免登用户**自动同步部门 + 存显示名**；全站显示「部门 - 姓名」。

## 后端 (backend)
- 用户：
  - [UserController.java](../../backend/src/main/java/com/superprogrammer/auth/controller/UserController.java) — `GET /api/users` `PUT /{id}/status` `PUT /{id}/roles`
- 部门：
  - [DepartmentController.java](../../backend/src/main/java/com/superprogrammer/auth/controller/DepartmentController.java) — `GET POST /api/departments` `PUT/DELETE /{id}` 成员 `POST/DELETE /members`
- 服务：`auth/service/`
  - 用户逻辑隐于 [AuthService.java](../../backend/src/main/java/com/superprogrammer/auth/service/AuthService.java)（`getCurrentUser` 组装 UserVO，`loginByDingTalk` 建号/同步部门）
  - [DepartmentService.java](../../backend/src/main/java/com/superprogrammer/auth/service/DepartmentService.java) — CRUD/成员 + `syncUserDepartmentsFromDingtalk` + `getPrimaryDepartmentName`
- 实体：`auth/entity/` User（含 `name`）、Department（含 `dingtalkDeptId`）、UserDepartment、UserRole
- Mapper：`auth/mapper/`（含 xml）

### 钉钉部门自动同步
- 入口：`AuthService.loginByDingTalk` 建号后调 `DepartmentService.syncUserDepartmentsFromDingtalk(userId, depts, operatorId)`。
- 规则：按 `departments.dingtalk_dept_id` 建/匹配本地部门（名变原地刷新，`code=dt_{deptId}`）；`assignMember` 是 `(user_id,dept_id)` upsert，**幂等不累积**；主部门 = `dept_id_list` 首个 ≠ 1（钉钉根部门）。
- 详情见 [01-认证与登录](01-认证与登录.md) 钉钉免登节。

### 显示「部门 - 姓名」
- 字段：`UserVO` / `TokenResponse.UserInfo` 均含 `name`（显示名）+ `primaryDepartmentName`（主部门名）。
- 一致性：`/auth/login`、`/auth/login/dingtalk`、`/auth/me`、`/users` 四端点都返回这两字段（登录直落盘 vs 刷新走 /me vs 管理走 /users）。
- `name` 取值：钉钉用户 = 钉钉 nick；账密用户 = 空（前端回退 `username`）。

## 数据表
`users`、`departments`、`user_departments`、`user_roles`
- `users.name` VARCHAR(100)（V46，显示名）
- `departments.dingtalk_dept_id` BIGINT + 部分唯一索引 `uk_departments_dingtalk_dept (tenant_id, dingtalk_dept_id) WHERE dingtalk_dept_id IS NOT NULL`（V46）
- `user_departments.is_primary` BOOLEAN（V18 已有，主部门标记）

## 通用错误处理（顺带）
唯一约束冲突（重名/重复提交）由 `GlobalExceptionHandler` 兜底转 **409** 友好提示，不报 500。约束→文案映射：
- `uk_kb_tenant_name` →「同名知识库已存在，请更换名称」
- `uk_user_memories_user_key_home` →「该记忆已存在，请勿重复添加」
- `uk_users_username` →「用户名已存在，请更换」
- 其他 →「数据已存在（唯一约束：xxx），请勿重复创建」
