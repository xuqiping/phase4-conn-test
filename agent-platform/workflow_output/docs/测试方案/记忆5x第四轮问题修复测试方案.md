## 环境依赖
- 后端跑第四轮代码（V129/V130 已迁移）；前端 dev 起来。
- 测试账号 2 个（A 主测 / B 造他人数据）；至少 1 个项目 P（A 为 owner）。
- 文件素材：与某标签主题强相关文档 1 份（如「居住」标签 + 租房合同 PDF）、无关文档 1 份（如菜谱 PDF）。

## 联动用例（对齐 plan 七条）

### U-1 流式中点停止（plan 联动①）
- **正向**：发一个长回答问题 → 流式中点「⏹ 停止」→ 文本立即停住；消息尾部/气泡带「已停止」态；刷新页面已生成部分仍在（部分内容落库，拍板③）。
- **边界（不可再停）**：已停止的消息不再显停止按钮；流已完成（DONE）的消息也无按钮——按钮仅 DONE 前存在。
- **反向（不重答）**：停止后等 30s+ 刷新 → 无第二条同问回答（连接死路径封死 REST 重答，无双倍计费）。
- **反向（超时同理）**：模拟断网中断流（DevTools offline）→ 刷新后同样保留部分内容、不自动重答。

### U-2 附件随消息发送 → 定向召回（plan 联动②）
- **正向**：上传 PDF 等 READY（chip 显「就绪」）→ 下一条消息**再挂同一附件**提问「这份文件说了什么」→ 回答开头参考附件内容（top-2 块注入）+ 顶部「📎 本附件」置顶卡片。
- **半选（非 READY）**：上传后立刻（PROCESSING 中）挂附件提问 → 只显带「解析中」状态的卡片，不注入半成品内容；FAILED 附件卡片显「失败」态。
- **反向（ragOn=false 全跳过，拍板④）**：关掉记忆召回总开关 → 同样挂 READY 附件提问 → 无附件注入、无「📎 本附件」卡片（附件不豁免开关）。
- **反向（非本人 fileId 剔除）**：B 账号上传文件的 fileId 由 A 挂消息发送（抓包改 attachmentFileIds）→ 该文件不进 A 的注入链（归属双门剔除）。

### U-3 无关文件零卡片（plan 联动③，拍板②宁缺勿噪）
- **正向**：菜谱 PDF 已 READY 且其标签与「居住」类对话共存 → 问「我住哪里」→ 回答**不挂**菜谱文件卡（向量距离 > 0.5 被门控剔除）。
- **正向（相关文件出卡）**：问租房相关问题 → 租房合同卡片出现，每文件 ≤2 卡、单轮总 ≤5 卡。
- **反向（降级轮零卡片）**：管理员把 `rag.memory.attachment-recall.enabled` 关掉/模拟 embedding 不可用 → 文件卡全消失但回答正常（fail-open 不阻塞聊天）。
- **调参**：`memory.recall.file-card-max-distance` 热调到 2.0 → 原本被剔的菜谱卡出现（验证热调不重启）。

### U-4 文件「收录于」徽标（plan 联动④）
- **正向**：文件名命中 P 项目硬规则并收录 → 文件记忆页签该文件行显「收录于：P」徽标。
- **反向（无收录不显示）**：未收录的文件行**无**徽标、无「未收录」负信息。
- **边界（仅本人可见项目）**：文件被 A 非成员的项目 Q 收录（造数据）→ 徽标不透出 Q 项目名（信息最小化）。

### U-5 新建标签+重新归类（plan 联动⑤，拍板⑤）
- **正向**：先聊几条「健身」话题 → 标签库新建「健身」标签 → 点「重新归类」→ 默认范围（建标签前）→「预估条数」显 N>0 → 开始归类 → 命中 K 条 → 流水账页签这 K 条挂上「健身」标签；标签 usageCount 增。
- **反向（只增不删）**：归类命中行原本挂的其他标签**仍在**（对照归类前后快照）；未命中行不变。
- **边界（总结手动生效）**：归类后总结页签旧总结不变 → 对该标签点「重新总结」→ 新总结吃进新挂的 K 条（不自动跟变是预期）。
- **边界（失败批）**：结果提示「N 批失败」时已命中部分保留（保守跳批）；限流 3 次/分钟触发第 4 次被拒。

### U-6 面板页签可达性（plan 联动⑥，U2）
- **正向**：打开记忆抽屉 → 九页签**两行**全可见无需横向滚动；「文件记忆」在第 3 位。
- **边界（小屏退方案）**：390~640px 宽度下页签区不溢出遮挡；激活远处页签时自动滚动到可见（箭头导航可用）。

### U-7 思考/回答分别复制（plan 联动⑦）
- **正向**：带思考过程的回答完结后 → 思考块、回答块各自复制按钮，分别复制各自 content（粘贴核对）。
- **反向（流式中不出现）**：流式进行中悬停气泡 → 无复制按钮（内容还在变）；点停止后按钮出现。
- **边界**：无思考块的气泡只显回答复制按钮。
