# P04 工作流主链：想法需求计划 · 用户操作手册

> 面向使用 DevPilot 桌面端的开发者：如何从「一个想法」开始，完成需求确认与施工计划审批，让项目进入建造阶段。

## 1. 维护项目约定（FR-008）

### 入口
打开项目 → 顶部导航栏「项目约定」按钮。

### 操作步骤
1. 在弹窗中填写：项目一句话定位、目标用户、技术栈偏好、命名风格、提交规范、安全红线、文档要求、测试红线。
2. 点击「保存」。
3. 系统重写项目根目录下的 `AGENTS.md`。

### 预期结果
- 项目根目录出现或更新 `AGENTS.md`。
- 后续 AI 生成报告/卡片/plan 都会按这些约束执行。

### 边界
- 手动修改 `AGENTS.md` 会被下次保存覆盖；如需固定内容，请通过表单字段表达。

---

## 2. 想法打磨向导（FR-030/AC-033）

### 入口
侧边栏或阶段条进入「想法」视图。

### 操作步骤
1. 依次回答 5 个问题：做给谁、痛点、竞品/替代方案、怎么赚钱/持续运营、技术/平台约束。
2. 点击「生成分析报告」。
3. 若 AI 觉得信息不足，会弹出追问对话框；回答后继续生成（最多 3 轮）。
4. 报告生成后，页面显示「建议」标签和摘要。

### 预期结果
- 项目目录下生成 `workflow_output/docs/项目分析/项目分析报告.md`。
- 建议为「值得做」「建议先缩小范围」或「建议再想想」之一。

### 边界
- 报告基于你的输入生成，输入越模糊，建议越保守。
- 追问超过 3 轮仍歧义时，系统提示「信息仍不足，建议人工梳理后重试」。

---

## 3. 需求确认卡片（FR-031/AC-034）

### 入口
侧边栏进入「需求」视图。

### 操作步骤
1. 左侧显示分析报告摘要；右侧点击「从报告生成卡片」。
2. 系统把报告拆成多张需求卡，每张包含标题、细节、验收标准。
3. 对每张卡执行以下操作之一：
   - 点击「确认」表示需求明确。
   - 点击「跳过」表示本阶段不做。
   - 点击「编辑」修改标题/细节/验收标准。
4. 当所有卡都确认或跳过后，右下角「进入计划」按钮亮起。
5. 点击「进入计划」推进到计划阶段。

### 预期结果
- 未全部确认时，「进入计划」按钮置灰，无法点击。
- 全部确认/跳过后，状态机自动解锁 `requirement_confirm` 门禁，可进入计划。

### 边界
- 重新生成卡片会清空旧卡片的编辑和确认状态，请谨慎操作。
- 已生成的卡片不影响状态机；只有确认/跳过动作才会触发门禁解锁。

---

## 4. 施工计划 chunk 看板（FR-032/AC-035）

### 入口
侧边栏进入「计划」视图。

### 操作步骤
1. 点击「从需求卡生成计划」。
2. 系统根据已确认的需求卡生成若干 chunk（每个 chunk 是可独立执行的小任务）。
3. 点击 chunk 的「编辑」可调整标题、目标、预估 tokens、依赖。
4. 确认 plan 合理后，点击「审批计划」。
5. 审批后「开工」按钮亮起；点击「开工」进入建造阶段。

### 预期结果
- 审批前，`tasks` 表不创建任何任务，也不会修改项目代码文件。
- 审批后，系统按 chunk 顺序创建 pending 任务，并解锁 `kickoff` 门禁。
- 点击「开工」后阶段条从「计划」变为「建造」。

### 边界
- 如需修改 plan，先点击「撤销审批」；这会删除对应 pending tasks 并重新锁定「开工」。
- 进入建造阶段后仍可回退到计划，但不会自动删除已创建的 tasks。

---

## 5. 主动反问澄清（FR-044/AC-048）

### 触发时机
在想法、需求、计划任一视图点击生成后，若 AI 认为信息不足，会自动弹出追问对话框。

### 操作步骤
1. 阅读追问问题。
2. 在输入框填写回答。
3. 点击「确认回答」。
4. 系统把回答追加到上下文，再次生成。

### 预期结果
- AI 先问清楚再生成，避免瞎猜。
- 单阶段最多追问 3 轮；超过后提示人工梳理。

### 边界
- 若取消追问弹窗，本次生成中止；可补充信息后重新点击生成。

---

## 6. 故障排查速查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 「进入计划」按钮不亮 | 还有需求卡未确认/跳过 | 检查列表中的 pending 卡片 |
| 「开工」按钮不亮 | 施工计划尚未审批 | 点击「审批计划」 |
| 生成报告/卡片/plan 后无反应 | 模型返回追问或 JSON 解析失败 | 查看错误提示；追问则回答，错误则重试 |
| 审批后撤销，但「开工」仍亮 | 状态快照未刷新 | 稍等或重新选择项目 |
| AGENTS.md 被覆盖 | 手动修改后又在表单保存 | 把想保留的内容填进表单字段 |
