## 3.1 ChatBI与NL2SQL

### 3.1.1 定义与演进

**ChatBI**（对话式商业智能）：用户以自然语言提问，系统自动生成SQL、执行查询、返回结果+可视化，实现"人人可取数"。

**演进路径**：
- 2023年：LLM突破自然语言理解，ChatBI成为行业方向
- 2024年：RAG+Schema增强，准确率从60%提升至80%+
- 2025年：Agent架构赋予自主规划+校验+修正能力
- 2026年：Text2SQL智能体进入"生成→校验→修正"闭环

[瓴羊数据分析Agent白皮书 | 高置信度 | 2025-12]

### 3.1.2 NL2SQL技术架构

| 层级 | 功能 | 关键技术 |
|---|---|---|
| 意图理解 | 解析用户自然语言意图 | LLM+Prompt Engineering |
| Schema映射 | 将自然语言映射到表/列 | RAG+Schema Linking+Few-shot |
| SQL生成 | 生成可执行SQL | LLM+Chain-of-Thought |
| SQL校验 | 验证SQL正确性 | 语法检查+语义检查+执行预检 |
| 结果呈现 | 格式化输出+可视化 | 自动图表推荐+自然语言总结 |

### 3.1.3 准确率与局限

- **当前最佳**：Spider Benchmark上SOTA模型准确率约85-90%（简单查询），复杂多表JOIN准确率降至60-70%
- **主要挑战**：复杂嵌套查询、模糊的列名语义、隐含的业务规则、数据权限控制
- **工程解法**：RAG增强Schema理解、执行反馈修正（Self-Correction）、人工校验环节

[Text2SQL智能体 | 高置信度 | 2026-07]

## 3.2 自动洞察发现（Automated Insights）

### 3.2.1 定义

自动洞察发现是AI系统主动扫描数据，识别统计显著且业务有意义的数据模式，以自然语言输出"洞察"。

### 3.2.2 洞察类型

| 类型 | 示例 | 检测方法 |
|---|---|---|
| 趋势变化 | "7月DAU同比增长15%，为近3月最高" | 时序分解+变化点检测 |
| 异常值 | "华东区退货率突然从2%跳至5%" | IQR/Z-score/ESD |
| 分布偏移 | "新用户占比从40%升至55%" | KS检验/卡方检验 |
| 相关性发现 | "页面停留时长与转化率强相关(r=0.8)" | 相关分析+显著性检验 |
| 排名变化 | "品类A超越品类B成为Top-1" | 排名追踪+统计检验 |
| 分层差异 | "iOS用户留存显著高于Android" | 分层统计检验 |

### 3.2.3 洞察质量评估

**高质量洞察标准**：
1. **统计显著**：p<0.05或效应量>阈值
2. **业务相关**：与已知业务目标/关注点吻合
3. **可操作性**：洞察能引导具体行动
4. **新颖性**：不是"已知事实"，而是"新发现"
5. **可解释性**：洞察有因果逻辑，非纯相关性

## 3.3 AI异常检测与归因

### 3.3.1 AI异常检测

| 方法 | 原理 | 适用场景 | 局限 |
|---|---|---|---|
| 统计方法 | IQR/Z-score/Grubbs | 单指标、正态分布 | 非正态失效 |
| 时序分解 | STL/Prophet | 有季节性的时序 | 需要足够历史窗口 |
| 机器学习 | Isolation Forest/One-Class SVM | 多维异常 | 需要训练数据 |
| 深度学习 | LSTM-Autoencoder/Transformer | 复杂时序模式 | 算力要求高 |

### 3.3.2 AI自动归因

**工作流**：
1. 异常检测触发 → 2. LLM理解异常上下文 → 3. 自动维度拆解 → 4. SHAP/贡献度排序 → 5. 自然语言归因报告

**2025-2026前沿**：
- NL2Attribution：大模型自动生成归因解释，支持多轮追问
- 因果AI：将因果推断与大模型结合，从相关归因升级为因果归因

## 3.6 AI辅助数据分析质量控制（O.03维度）

### 3.6.1 准确性保障

| 环节 | 风险 | 控制措施 |
|---|---|---|
| NL2SQL | 生成SQL错误 | 执行前语法校验+沙箱试运行+结果合理性检查 |
| 洞察生成 | "假洞察" | 统计显著性+效应量+交叉验证 |
| 异常检测 | 误报/漏报 | 多方法交叉+基线校准+人工确认 |
| 归因分析 | 混淆相关与因果 | 强制标注因果置信度+反事实检验建议 |
| 报告生成 | 选择性呈现 | 固定报告模板+完整性检查 |

### 3.6.2 可信度分级

| 等级 | 描述 | 使用建议 |
|---|---|---|
| L1-AI草稿 | AI生成，未经人工审核 | 仅作探索参考，不用于决策 |
| L2-AI+人工校验 | AI生成+人工检查关键结论 | 可用于日常运营决策 |
| L3-AI+统计验证 | AI生成+统计显著+效应量检验 | 可用于重要业务决策 |
| L4-AI+因果验证 | AI+统计+因果推断验证 | 可用于战略级决策 |

## 3.8 前沿趋势（2025-2026）（O.04维度）

1. **数据分析Agent元年**：2025年从ChatBI（被动问答）→Agent（主动规划+执行+反思），实现"你只管问，AI全链路搞定" [瓴羊白皮书 | 高置信度 | 2025-12]
2. **Text2SQL进入闭环时代**：生成→校验→修正闭环，准确率从80%→95% [Text2SQL智能体 | 高置信度 | 2026-07]
3. **多模态数据分析**：从文本→图表→图像+视频，AI理解非结构化数据并联合分析
4. **AI原生BI崛起**：不是给BI加AI，而是以AI为核心重新设计数据分析流程
5. **企业级数据权限+AI安全**：AI取数场景下的行级/列级权限控制与审计
6. **AI辅助因果推断**：大模型+DoWhy/CausalML融合，自动化因果推断pipeline
7. **数据分析民主化加速**：非技术人员的"自助分析"从拖拽BI→对话式AI，门槛进一步降低
