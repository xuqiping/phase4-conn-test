## 一、钱路径门槛用例（A/B 完成后必过，不过不许进 C/D）

### T1 降职缩额防薅（A2，17x-1 复演）
1. 组长建组、邀请 A、B（或 DB 直插），组长给 A 设管理员 quota=200。
2. A 给 B 配 quota=100 → 核对 A「可分配」变 100。
3. 组长把 A 降为成员。
4. **预期**：A 限额自动变 100（组成员表/组详情可见）；组内 Σ限额不再超组池；组账本出现「管理降职缩额」流水。
5. **反向**：A 已用 150 时降职 → 限额=150（不回收已用）；A 为不限额管理时降职 → 限额仍「不限」。

### T2 聊天开局拦截（B3，9x）
1. 账号余额 1 积分，发起智能对话。
2. **预期**：不产生任何回答，明确话术「积分不足，预估 X 当前 Y」（不是「服务器内部错误」）。
3. **并行**：画布 LLM 节点 + 智能对话同时开 → 各自预扣互不影响，先到先得。

### T3 流中报数与精确结算（B2/B3，Q2=B）
1. 正常聊天一轮。
2. **预期**：回答区实时计数跳动（PROGRESS）；答完显示精确「N tokens ≈ X 积分」；钱包流水见 CHAT-HOLD 预扣 + 多退少补（补扣 CONSUME / 退差 REFUND）。
3. **半途点停止**（Q3=B）：按已产内容折算收费（流水可见折算结算，非全额退）。

### T4 DEBT 兜底全链（B5，Q10=A）
1. 构造结算缺口（余额 10 让结算需 300：可用临时关 hold 开关或直接后端触发结算腿）。
2. **预期**：余额扣到 0、欠款 290；钱包页显示「欠款 290」；所有消费入口被拒并提示先还款。
3. 充值 100 → **预期**：欠款变 190、余额仍 0（先还后进）；继续消费仍拒；还清后自动恢复。

### T5 对账恒等式（D4）
1. 走 划拨→成员消耗→退款→回收 全流程。
2. **预期**：账单「项目组对账」tab 顶卡「平」。
3. 手工 UPDATE 组池余额 −10 → **预期**：该组标红、顶卡「不平」。

## 二、功能联动用例（对齐各子计划联动清单，含反向/半选/批量边界）

### A 计划（3 条）
- L-A1 降职缩额 → 成员表「可分配」/组卡片/chip/页顶下拉四处同步变小；刷新一致（反向：重新升职不自动还原限额，需组长手调——预期留痕）。
- L-A2 quota 变化 → 生成页预估「项目内剩余」同步变（联动 C1；半选边界：不限额显示「不限」）。
- L-A3 成员配额调增/调减 → 「项目组分配」tab 毛额只增、净额随调减回减（联动 D3）。

### B 计划（5 条）
- L-B1 DONE.usage → 回答尾显示精确值；老消息显示「-」（半选边界）；ERROR 后不显示。
- L-B2 PROGRESS → 计数递增；DONE 后停；ERROR 后停。
- L-B3 hold 失败 → 前端话术（反向：充值后同参数可发起）。
- L-B4 DEBT 产生 → 钱包页欠款行 + 全入口拦截；管理员发放积分也先冲抵欠款（批量边界：发放 50 欠 290 → 欠 240 余额 0）。
- L-B5 充值到账 → 先还欠款余数进余额；部分还款=余额仍 0。

### C 计划（5 条）
- L-C1 比例选中 → WxH 预览变；切档位重算；切「自定义」清比例（反向）。
- L-C2 1K/1.5K+比例 → 提交禁用红字；切回 2K 自动恢复（反向）。
- L-C3 比例变 → 预估不变（比例不影响价），文案注明。
- L-C4 成员限额变 → 预估「项目内剩余」联动（同 L-A2）。
- L-C5 画布参数每键输入 → 预估 500ms 防抖合并；参数未变不重发（半选边界）。

### D 计划（5 条）
- L-D1 备注注册/自改/管理员改 → 管理列表备注列与 keyword 筛选即时命中（反向：清空备注后筛不到）。
- L-D2 成员配额流水 → 「项目组分配」tab 毛额/净额（同 L-A3）。
- L-D3 组资金流水 → 对账恒等式始终平（同 T5）。
- L-D4 无 token 直达 /reset-password → 显示引导页+重发入口，不露手机号表单（反向：带 token 正常重置；channel=sms 且 SMS 未启用 → 也不露 SMS）。
- L-D5 QQ 邮箱重置邮件 → 链接下方有可复制纯文本 URL，复制到浏览器可打开。
