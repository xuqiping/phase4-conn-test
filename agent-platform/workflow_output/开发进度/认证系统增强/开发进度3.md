## 运维/安全口径（刻意设计，非 bug）
- 邮件通道未开启 → **注册整体暂停**（发码 400「邮件通道未开启」）；邮件通道成关键依赖。
- 日封顶触发记 `log.error`（`MailSendQuotaService`）——可接告警。
- 注册码校验 Redis 故障 **fail-closed**（必须证明邮箱归属，不降级放行）；其余限流/滑块均降级放行。
- 激活链接流程保留给「改绑邮箱」；注册路径不再用。
