## 本轮做了什么（迭代 A 全量落地，编译全绿）

完全替换旧 `user_memories` 模型的**数据层地基**：9 新表 + 扩 memory_conflicts + 实体 + Mapper + SCOPE_FILTER + IT（编译过，待人工实跑）。

### A-1 Flyway V47 建表
- [V47__create_memory_new_tables.sql](../../../backend/src/main/resources/db/migration/V47__create_memory_new_tables.sql)
- 9 表：`memory_tags` / `memory_turns` / `memory_summaries` / `memory_summary_coverage` / `memory_project_members` / `memory_project_settings` / `memory_project_user_settings` / `memory_consolidation_scopes` / `memory_notifications`。
- 扩 `memory_conflicts` 加 `tag_id` + `summary_id`（旧列保留，H 收尾随旧表废弃）。
- 关键约束：`memory_tags UNIQUE(user_id,subject,topic) NULLS NOT DISTINCT`；`memory_summary_coverage UNIQUE(turn_id,tag_id,project_id,user_id) NULLS NOT DISTINCT`（个人 scope project_id=NULL 拦截重复）；`memory_consolidation_scopes UNIQUE(user_id,scope_kind,project_id) NULLS NOT DISTINCT`。
- 索引：`memory_turns` GIN(project_ids/tag_ids/departed_project_ids/deleted_project_ids) + (user_id,created_at) + (user_id,gen_done,created_at)；`memory_summaries` GIN(source_turn_ids) + (user_id,project_id,tag_id)；`memory_tags` HNSW(anchor_embedding)+GIN(anchor_tokens_tsv/aliases)。
- **项目删除 §3.7 清理 = `ON DELETE CASCADE` 在 memory_summaries/coverage/members/settings 的 project_id 单值列自动实现**；turns.project_ids 是数组无 FK，项目 id 保留（app 追加 deleted_project_ids）。
- **新用户钩子 = DB trigger**（偏离 plan「AOP」建议，理由：数据层纯净 + 多注册路径一致性强保证）：`trg_memory_new_user_default_scope AFTER INSERT ON users` → 自动插 `memory_consolidation_scopes(user, PERSONAL, NULL, auto_enabled=true)`。

### A-2 实体（继承判定见 plan）
- `StringArrayTypeHandler`（新，`common/typehandler`）：TEXT[] ↔ List<String>，给 aliases 用。
- 走 BaseEntity 软删：[MemoryTag](../../../backend/src/main/java/com/superprogrammer/chat/entity/MemoryTag.java) / [MemoryTurn](../../../backend/src/main/java/com/superprogrammer/chat/entity/MemoryTurn.java) / [MemorySummary](../../../backend/src/main/java/com/superprogrammer/chat/entity/MemorySummary.java)。
- 无 deleted（业务硬约束/级联清）：MemorySummaryCoverage / MemoryProjectMember / MemoryProjectSetting / MemoryProjectUserSetting / MemoryConsolidationScope / MemoryNotification（6 个 plain `@TableName`，id+created_at(+updated_at)）。
- [MemoryConflict.java](../../../backend/src/main/java/com/superprogrammer/chat/entity/MemoryConflict.java) 扩 tagId + summaryId（实体仍 plain）。
- BIGINT[] 字段挂 `@TableField(typeHandler=LongArrayTypeHandler.class)`；aliases 挂 StringArrayTypeHandler；halfvec/tsv 列不映射（走自定义 SQL，同 UserMemory embedding 模式）。

### A-3 Mapper + XML + SCOPE_FILTER
- [SqlScopeFilter.java](../../../backend/src/main/java/com/superprogrammer/chat/service/internal/SqlScopeFilter.java)：param 键常量 + 空集归一（防 `project_ids && null` 报错）。
- 4 表带 XML（`chat/mapper/xml/`）：MemoryTurnMapper / MemoryTagMapper / MemorySummaryMapper / MemorySummaryCoverageMapper。
- 2 表 plain BaseMapper：MemoryProjectMemberMapper / MemoryNotificationMapper。
- MemoryConflictMapper 扩 `findByUser`（XML），保留既有注解方法。
- **坑规避落地**：`&&` 在 XML 转义 `&amp;&amp;`；halfvec `<=>` 转义 `&lt;=&gt;`（MemoryTagMapper.findNearestByAnchor）；BIGINT[] 更新显式 `typeHandler=`（MemoryTurnMapper.updateProjectIds，绕开 LambdaUpdateWrapper 不读 typeHandler 的 V33 坑）。
- scope 策略：turns 走 SCOPE_FILTER（自己 ∪ accessible 项目集）；summaries/coverage/conflicts 恒 `user_id=self`（只读自己防污染）。
