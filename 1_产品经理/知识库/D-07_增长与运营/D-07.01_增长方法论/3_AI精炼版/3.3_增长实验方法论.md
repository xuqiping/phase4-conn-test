# 3.3 增长实验方法论

## I.06 实验方法论框架

增长实验的核心循环：

```
识别增长杠杆 → 生成假设 → 优先级排序 → 设计实验 → 执行与数据收集 → 分析结果 → 规模化或放弃
```

### 假设驱动

**好假设的三要素**："如果我们做[X]，那么[Y指标]会提升[Z%]，因为[原因]"。

| 要素 | 说明 | 示例 |
|---|---|---|
| 行动(X) | 你要改变什么 | 缩短新手引导步骤从5步→3步 |
| 预期结果(Y) | 你预期哪个指标变 | 激活率 |
| 因果逻辑 | 为什么X会导致Y | 减少摩擦→更快到达Aha Moment |

### 优先级排序

| 框架 | 公式 | 优缺点 |
|---|---|---|
| ICE | Impact×Confidence×Ease | 快速但主观 |
| RICE | (Reach×Impact×Confidence)/Effort | 更精确但工作量大 |
| 增长杠杆矩阵 | 影响×成本(2×2) | 直观但粗糙 |

**实用建议**：日常用ICE快速筛选，关键决策用RICE精排。

## I.07 实验技法

### 实验类型光谱

| 类型 | 说明 | 成本 | 置信度 | 适用阶段 |
|---|---|---|---|---|
| 顿悟型 | PM/用户洞察→直接改 | 低 | 低 | 0→1快速迭代 |
| A/B测试 | 随机分流→统计比较 | 中 | 高 | 1→10验证 |
| 多臂老虎机(MAB) | 动态分配流量给胜出方案 | 中 | 中 | 10→100持续优化 |
| 因果推断 | 准实验设计(IV/DID/RDD) | 高 | 高 | 精确归因 |

### 实验设计关键参数

| 参数 | 说明 | 经验值 |
|---|---|---|
| 最小可检测效应(MDE) | 你希望检测的最小变化幅度 | 基线转化率的10-20% |
| 统计显著性(α) | 犯第一类错误的概率 | 0.05 |
| 统计功效(1-β) | 检测到真实效应的概率 | 0.8 |
| 样本量 | 需要多少用户参与 | 按MDE+α+β计算 |
| 实验周期 | 跑多久 | ≥1个完整周期(周) |

### 护栏指标

**做增长实验必须设定护栏指标**——防止优化了主指标但损害了其他关键维度：

| 护栏类型 | 示例 | 为什么需要 |
|---|---|---|
| 用户体验护栏 | NPS/崩溃率不降 | 防止"增长劫持" |
| 商业护栏 | LTV/7日回款不降 | 防止虚假增长 |
| 合规护栏 | 投诉率/退订率不升 | 防止违规增长 |

## E.03 合规红线

| 红线 | 说明 |
|---|---|
| 诱导分享 | 微信等平台禁止"分享后解锁"等强制行为 |
| 数据造假 | 严禁刷量/刷评/虚假好评 |
| 过度推送 | 推送频率过高→用户投诉→应用商店下架风险 |
| 未授权A/B | 涉及个人信息/付费的实验需用户知情同意 |
| 暗黑模式(dark pattern) | 故意设置困难取消流程/隐藏收费→法律风险 |
