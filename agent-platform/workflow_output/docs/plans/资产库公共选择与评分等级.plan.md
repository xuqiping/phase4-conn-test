# Implementation Plan for 资产库公共选择与评分等级

> Phase 2 产出。Phase 3 逐步勾选执行。只含伪代码，不含真代码。
> 来源规格：[../specs/资产库公共选择与评分等级设计.md](../specs/资产库公共选择与评分等级设计.md)

## 背景与目标

- 2x#4：图片/视频生成模块的资产选择器可选公共池资产（前端补来源，后端仅补摘要字段）。
- 2x#5：分享弹窗打开即展示用户候选（根因=前端空关键词不发请求）。
- 2x#7：评分展示改 A+/A/B/C/D 等级（存分不变，后端派生）。
- 待决策项落地：公共池发布时 OWNER 自选「是否允许复制」，copy 接口按标志管控。

## 技术实现坑点预判与规避措施

| 技术点/功能块 | 可能的坑 | 规避措施 | 验证方式 |
|---|---|---|---|
| 选择器接公共池 | `projectApi.list()` 与 public-pool 两接口字段结构不同，选择器内部假设「我的项目」字段全量 | 选择器内做来源适配层（映射成统一 `{id,name,mediaTypes,...}`），缺省字段补默认 | 单测适配映射 + playwright 选公共池项目出资产列表 |
| 公共池资产 resolve | 公共 VIEWER resolve 走 loadAccessible 已放行，但**画布 AssetPicker**（canvas 专用）与非画布 AssetFilePicker 结构不同源 | 两组件分别改，行为对齐；resolve 失败兜底提示「无权引用」 | 两入口各测一次 resolve |
| 等级映射双份漂移 | 前端自算等级与后端不一致（如 94.5 均分四舍五入分歧） | **后端 VO 派生 grade 字段为唯一来源**；前端只渲染；等级→筛选区间的映射表也由后端常量导出（或前端硬编码同一常量并加对齐单测） | 后端边界单测 94/95/89/90/79/80/69 + 前端对齐测试 |
| 成员均分小数 | AVG 产生 90.5 这类小数 → 等级判定边界抖动 | 后端派生前四舍五入到整分再映射（与展示口径一致，展示处注明取整规则） | 单测 90.4→90→A、90.5→91→A |
| copy 校验绕过 | 只改前端按钮、后端不校验 → 直调 API 复制保密项目 | 后端 `copyCurrent` 强校验（规格 §6.2），ErrorCode 403 语义 | 单测：直调 copy 于 allow=false 项目被拒 |
| 迁移默认值 | 存量已发布项目未选过开关 | DEFAULT TRUE 兼容现状（公共池现状=允许复制），发布弹窗回显可改 | 迁移后抽查存量行全 TRUE |
| n-select remote 初始加载 | 打开即请求的时序：组件 mount 时 options 尚空触发 loading 闪烁 | onMounted 触发空关键词搜索 + loading 态占位「输入用户名筛选，最多展示50人」 | 手测打开弹窗即见列表 |

## 安全检查清单

- [ ] **鉴权/授权**：public-pool 摘要仅 usable 项目；copy 校验 allow_public_copy；candidates 仅项目 OWNER/admin 可调（既有 requireManage 不动）
- [ ] **输入校验**：keyword 长度上限（复用既有 32 字符约束）；allow_public_copy 仅接受布尔
- [ ] **审计**：copy 拒绝路径 @AuditLog 记录（action=copy, result=denied）；发布参数变更走既有发布审计
- [ ] **错误处理**：ErrorCode `ASSET_COPY_FORBIDDEN` 文案不泄漏源项目内部信息
- [x] **数据加密/CORS/依赖**：无新增面

## 性能考虑与验证计划

- [ ] 摘要补 mediaTypes 为单查询补列（无 N+1：public-pool 列表本就 JOIN projects）
- [ ] 等级派生在既有批量装配 SQL 结果上内存计算（不新增查询）
- [ ] candidates 空关键词 LIMIT 50 全表扫 ACTIVE 用户——量级小（内部平台），暂不加索引；Phase 4 观察耗时
- [ ] 筛选等级=前端映射区间，复用既有 scoreMin/scoreMax 索引路径

## 实现步骤

- [x] **Step 1：后端——公共池摘要补字段 + 候选上限提升**（完成 2026-08-18）
  - **目标**：摘要 VO 含 mediaTypes；空关键词候选 LIMIT 50
  - **动作**：①`AssetPublicPoolService` 摘要装配补 `mediaTypes`（若 VO 已有则仅补测试）；②`AssetMemberService.searchCandidates` 空关键词 limit 20→50（有 keyword 维持 20）；③前端提示文案常量（扩展为 ShareDialog 开箱即载完整修复，见备注 1）
  - **文件**：`AssetPublicPoolService.java`、`AssetPublicPoolController.java`（若 VO 定义在此）、`AssetMemberService.java`、对应 Test
  - **依赖**：无
  - **验证**：单测：摘要含 mediaTypes；空关键词 ≤50 且排除 owner/成员/自己；带关键词 ≤20

- [x] **Step 2：前端——选择器公共池来源（两个组件）**（完成 2026-08-18）
  - **目标**：AssetFilePicker 与画布 AssetPicker 可浏览/选用公共池资产
  - **动作**：①来源数据 = `GET /assets/public-pool` 过滤 usable，映射统一结构；②项目下拉分组「我的项目/共享给我/公共池」；③选中公共池项目 → `assetApi.list(projectId)` 载资产（ACL 已放行）；④类型过滤 type 参数透传；⑤resolve 链路不动，失败提示兜底
  - **文件**：`frontend/src/components/asset/AssetFilePicker.vue`、`frontend/src/components/canvas/AssetPicker.vue`、`frontend/src/api/assets.ts`（若需 publicPool api 封装）
  - **依赖**：Step 1（mediaTypes）
  - **验证**：playwright：图片页/视频页/画布三入口选公共池图片+视频并 resolve 成功；非 usable 项目不出现（playwright 移交 Phase 4，单测 6 例覆盖来源切换/usable+mediaTypes 过滤/type 透传/兜底）

- [x] **Step 3：后端——评分等级派生**（完成 2026-08-18）
  - **目标**：VO 提供 ownerGrade/memberAvgGrade；等级常量唯一真相源
  - **动作**：①新增 `AssetGrade`（fromScore：≥95 A+ / 90-94 A / 80-89 B / 70-79 C / <70 D / null 未评）；均分先取整再映射；②`AssetScoreVO`、列表批量 VO（AssetVO 装配处）加派生字段；③导出「等级→分数区间」映射供前端筛选用
  - **文件**：新增 `asset/service/AssetGrade.java`、`AssetScoreVO.java`、`AssetVO.java`（装配处）、`AssetScoreServiceTest.java`（边界用例）
  - **依赖**：无
  - **验证**：单测边界 94/95/89/90/79/80/69/未评/均分取整两例

- [ ] **Step 4：前端——等级徽章与筛选**
  - **目标**：卡片/详情/打分控件显示等级；筛选条等级快捷选
  - **动作**：①`AssetCard`/`AssetDetailDrawer` 数值旁渲染等级徽章（用 VO 字段）；②打分 slider/input 旁实时等级（前端同常量，加与后端映射对齐的单测）；③筛选条加等级下拉 → 映射 scoreMin/scoreMax（区间：A+=[95,100]、A=[90,94]、B=[80,89]、C=[70,79]、D=[0,69]）
  - **文件**：`AssetCard.vue`、`AssetDetailDrawer.vue`、`AssetProjectView.vue`（筛选条+canScore 区）、新增前端等级常量 `frontend/src/constants/assetGrade.ts`
  - **依赖**：Step 3
  - **验证**：playwright：徽章显示/打分实时变级/等级筛选结果与分数筛选一致（抽 A+ 与 D 各一档）

- [ ] **Step 5：后端——复制管控**
  - **目标**：`allow_public_copy` 列 + copy 校验 + 发布写入
  - **动作**：①迁移 `V128__asset_allow_public_copy.sql`（DEFAULT TRUE）；②`AssetProject` 实体加字段；发布请求/Service 写入（OWNER 与 admin 代发均可设，默认回显当前值）；③`copyCurrent` 源项目 publicPool=true 时校验，false 抛 `ASSET_COPY_FORBIDDEN`（ErrorCode 新增）；④摘要/详情 VO 透出
  - **文件**：新增 `V128__*.sql`、`AssetProject.java`、`AssetPublicPoolService.java`、`AssetService.java`、`ErrorCode.java`、对应 Test
  - **依赖**：无（与 Step1-4 并行可）
  - **验证**：单测：allow=false 公共池 copy 拒 / =true 过 / 非公共项目不受限 / 发布写入与回显

- [ ] **Step 6：前端——发布开关与复制按钮显隐**
  - **目标**：发布弹窗加开关；公共 VIEWER 卡片按钮按标志显隐
  - **动作**：①发布弹窗「允许公共用户复制资产」n-switch（默认 true，重新发布回显）；②公共池项目页用摘要 `allowPublicCopy` 控制「复制到我的项目」按钮渲染；③文案说明「关闭后公共用户仅可引用，不可复制副本」
  - **文件**：发布弹窗组件（`AssetListView.vue` 内或独立）、`AssetProjectView.vue`
  - **依赖**：Step 5
  - **验证**：playwright：发布关复制 → 公共账号看不到按钮 + 直调 API 403；重新发布打开 → 恢复

## 功能联动点清单（含反向/边界）

| # | 触发动作 | 联动对象 | 预期变化 | 必测边界 |
|---|---|---|---|---|
| L1 | 选择器选公共池项目 | 资产列表/类型过滤 | 载入该项目资产 | 切回「我的项目」列表正确切换；公共池项目被移出公众池后（会话中）→ 载列表报错需兜底提示 |
| L2 | 发布时关「允许复制」 | 公共 VIEWER 复制按钮 | 立即隐藏（重新拉取摘要后） | 已开着项目页的用户刷新后按钮消失；admin 代发同样受控；直调 API 兜底 403 |
| L3 | 打分拖动 slider | 等级实时标签 | 分数跨档位等级即变 | 94↔95 边界来回拖；未评→首评出现等级 |
| L4 | 等级筛选选中 | scoreMin/scoreMax 输入框 | 区间联动填入 | 等级与手动分数区间冲突时以等级覆盖（等级是快捷方式）；清除等级不清手动区间 |
| L5 | 分享弹窗打开 | 候选下拉 | 空关键词即出 ≤50 人 | 输入后清空关键词 → 恢复全量候选而非空白；已选成员不重复出现 |
| L6 | 均分变动（成员改分） | 均分等级徽章 | 重新计算 | 跨档位两成员分拉平均后等级正确取整映射 |
