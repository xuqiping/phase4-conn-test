# Office 效率增强开发进度 14

> 记录日期：2026-08-26。范围是统一安全底座 Chunk 7：Tauri API 与可访问向导。测试按用户要求留到 Phase 4。

## 1. Tauri 编排 API

- 应用启动时在 app data 目录初始化 `office_tasks.db`，执行迁移并清理超过 90 天的已结束任务。
- 新增预检、确认入队、执行边界、取消、分页历史、恢复发现、系统凭据保存和删除命令。
- 预检只接受用户选择的输入文件作为允许根；路径、文件指纹和问题只进入本地数据库，不发服务端。
- 阻断问题存在时不能确认；状态更新使用“预期旧状态”条件更新，避免并发请求重复跳转。
- 具体 Office 处理器尚未接入时，执行命令返回 `OFFICE_EXECUTION_ENGINE_NOT_READY`，不进入 running，不伪造结果。

## 2. 桌面端工作台

- `App.vue` 新增 Office 标签；`OfficeWorkspace.vue` 提供新建任务和历史切换。
- 三步向导支持任务类型、输出策略、文件多选、独立输出目录、安全预检、确认入队、取消和重新开始。
- 问题列表支持全部/警告/阻断筛选，但阻断项始终显示；旧格式、宏、签名、外链和密码高保真场景继续阻止。
- 恢复区域展示本机未结束任务并允许取消；历史页展示状态、文件数、体积和创建时间。
- 所有新增文案进入中英文 locale；交互使用原生 button/select 和 label，保留键盘顺序与焦点样式。
