## 四、关键术语速查

| 术语 | 定义 |
|---|---|
| 费曼学习法 | "教别人"倒逼深度理解——能简单讲给外行听=真正理解 |
| 刻意练习 | 在"学习区"而非"舒适区"练习，有反馈+有目标+专注[来源:Anders Ericsson | 置信度:🔍高] |
| 间隔重复(SRS) | 按遗忘曲线在即将遗忘时复习，长期记忆留存率↑80%+[来源:Ebbinghaus | 置信度:🔍高] |
| 学习金字塔 | 不同学习方式留存率排序：讲授5%→阅读10%→视听20%→演示30%→讨论50%→实践75%→教别人90%[来源:Dale 1969 | 置信度:📚中] |
| 主动学习 | 输出优先（讨论/实践/教），而非被动输入（听/读/看） |
| 项目驱动学习 | 以真实项目为载体，边做边学，知识在实战中内化 |
| 输出倒逼输入 | 先确定要产出什么→倒推需要学什么→学习有目的性和紧迫感 |
| 逆向学习 | 从"高手怎么做"反推"需要学什么"，而非从基础一步步来 |
| 学习区(Vygotsky) | 介于"舒适区"和"恐慌区"之间的最佳学习难度区间[来源:Vygotsky ZPD | 置信度:🔍高] |
