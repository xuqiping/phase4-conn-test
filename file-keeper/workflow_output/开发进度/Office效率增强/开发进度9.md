## 2. 安全与运维边界

- 数据库不定义密码、正文、模型 Key、Authorization 或 Token 字段。
- `rule_json` 带正整数 `rule_schema_version`；规则和问题 JSON 写入前递归拒绝敏感键。
- Repository 的 `Debug/Display` 不输出路径、SQL 或 JSON 正文。
- 保存任务与输入/问题使用单事务；开启外键和级联删除。
- 历史单页最大 200；恢复查询只取非终态；清理只删除有 `finished_at` 的终态任务。
- 应用启动接入、日志 traceId 和 UI 分页属于后续 Chunk，不在本轮提前实现。
