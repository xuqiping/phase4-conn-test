# Office 效率增强：统一安全底座

## 用户地图

面向需要批量处理 Excel、Word、PowerPoint 的财务、行政、HR、运营和研究用户。工作台把“先备份再运行脚本”的高风险操作改成固定流程：选择文件、扫描风险、确认、进入本地队列、独立发布结果。

当前用户可使用安全预检、风险清单、免费额度提示、任务取消、恢复提示和历史记录。旧格式、宏与未验证高保真场景会明确阻断；具体拆分、合并、替换和外链处理器将在后续功能 Chunk 接入，不会提前显示伪成功。

## 技术说明

- Rust 主进程负责状态机、SQLite、路径预检、Worker 生命周期、输出事务和系统凭据。
- Vue 工作台只通过 Tauri 命令访问本地能力；文件路径、正文和 Office 密码不上云。
- 源文件默认只读；结果必须在临时目录生成、校验并原子发布。
- Windows Credential Manager、macOS Keychain、Linux Secret Service 保存主动记住的密码，文件变化后旧密码不可自动使用。
- 超过免费额度只影响开始执行：后续接入服务端 Office Pro 实时校验；本地预检和模块入口不锁定。

## 当前边界

- 已完成安全底座与任务工作台，不等于 Excel/Word/PPT 业务处理器全部完成。
- `office_start_task` 在处理器未注册时稳定拒绝，不把排队状态当成功。
- Phase 4 仍需完成自动化测试、真实系统保险库、断电/磁盘/Worker 故障注入、键盘与屏幕阅读器验收。
