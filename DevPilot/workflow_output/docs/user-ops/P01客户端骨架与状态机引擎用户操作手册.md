# P01 客户端骨架与状态机引擎 · 用户操作手册

> 受众：使用者（零代码背景也能看懂）。last_updated: 2026-08-14

## 1. 安装与启动

1. 双击 `DevPilot_x.x.x_x64_en-US.msi` → 按向导安装（若提示装 WebView2，点是即可）。
2. 启动 DevPilot。
   - **预期**：出现深空蓝三栏窗口；首次启动自动弹出「新建项目」向导。

## 2. 新建项目

1. 向导里填**项目名**（大白话即可，如「记账小助手」）。
2. 选**规模**：拿不准就选 L2 标准应用；只是个小脚本选 L0。
3. 「放在哪个文件夹下」留空 = 默认放 `用户目录/DevPilotProjects`。
4. 点**创建项目**。
   - **预期**：向导关闭；顶栏出现项目名；管道条「想法」发光（呼吸蓝）；中栏显示想法视图。
   - **若报错**：同名目录已存在 → 换名字或换目录；提示含路径符号 → 项目名不要带 `/`、`\`、`..`。

## 3. 推进阶段（核心操作）

中栏底部的**阶段操作条**是你的方向盘：

| 你想做什么 | 操作 | 界面变化 | 预期结果 |
|---|---|---|---|
| 推进到下一阶段 | 点蓝色「推进到『XX』」 | 管道条高亮移动、中栏换视图、右栏 Tab 归位 | 成功进入新阶段 |
| 推进但门禁未过 | 同上 | 右上角弹大白话提示（如「门禁『需求确认』未通过」） | 阶段不动 |
| 过门禁 | 点操作条上的「确认『XX』」黄色按钮 | 按钮变绿 ✓ | 再点推进即可通过 |
| 回退（如验收打回） | 点灰色「回退到『XX』」 | 同上反向 | 回到之前阶段，历史留痕 |
| 越级跳（如想法→建造） | 管道条上直接点远处阶段 | toast 提示不允许 | 被拦截（这是刻意的纪律） |

## 4. 浏览与查看

- **左栏导航**：随便点，只切换"你在看哪个视图"，不改变项目真实阶段。
- **右栏五 Tab**：规格/变更/日志/预览/文件；切换视图时右栏自动归位到推荐 Tab。
- **顶栏项目名 ▾**：切换别的项目或「＋新建项目」。
- **顶栏右侧「舒适/紧凑」**：切换界面密度。

## 5. 断点续开

随时关掉软件。再打开时：项目自动停在上次的阶段，已过门禁也在。
**预期**：管道条高亮位置与关软件前一致。

## 6. 遇到问题

- 白屏/打不开：先确认系统已装 WebView2（Win10 以上一般自带）。
- 报错 toast 看不懂：截图 + 设置页「诊断信息一键导出」（后续版本提供）发给开发者。
