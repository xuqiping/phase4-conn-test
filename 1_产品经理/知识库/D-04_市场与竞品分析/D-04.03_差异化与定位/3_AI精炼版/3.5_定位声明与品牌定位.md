## 定位声明与品牌定位

### 1. 定位声明（Positioning Statement）

标准公式（已在3.1介绍），这里强化实操：

```
对于 [目标用户]，[产品名] 是 [品类] 中最能 [差异化价值] 的选择，因为我们 [信据/RTB]。
```

**5个检验问题**：
1. 目标用户是否足够具体？（"25-35岁产品经理" >> "白领"）
2. 品类名是否一听就懂？（"在线协作白板" >> "数字化协同工作空间"）
3. 差异化是否独特且可持续？（竞品做不到+在3年内可持续）
4. 信据是否可靠？（用户可验证的数据/事实）
5. 全句是否≤30个字？（越长越记不住）

### 2. 品牌金字塔

```
            ┌─────────┐
            │ 品牌精髓  │  一句话核心
            ├─────────┤
            │ 品牌价值  │  3-5个核心价值主张
            ├─────────┤
            │ 品牌个性  │  如果品牌是人，是什么样的性格？
            ├─────────┤
            │ 品牌证据  │  支撑价值的具体事实
            └─────────┘
```

**示例（Notion）**：
- 精髓：All-in-One工作空间
- 价值：灵活、整合、美观、协作
- 个性：极简主义、聪明的、不装腔作势
- 证据：block+database架构、模板市场、1亿+用户

### 3. 定位一致性检查

| 触点 | 是否与定位一致 | 不一致的修正 |
|---|---|---|
| 产品功能 | 新功能是否支撑定位？ | 不支撑定位的功能要慎重加 |
| 定价模型 | 价格是否反映定位？ | "高端"定位不能有"免费+广告"模式 |
| 营销信息 | 官网/广告语是否一致？ | 每个对外信息都要经过定位检验 |
| 用户口碑 | 用户描述你的方式是否一致？ | 如果用户说不清你是什么=定位有问题 |
| 竞品关系 | 是否清晰表明与竞品的差异？ | 不要模仿竞品——模仿=否定自己的定位 |

### 4. 定位调整的5个信号

1. **用户说不清你是什么** → 定位太模糊/太复杂
2. **增长依赖买量而非口碑** → 定位不够独特
3. **总是被拿来和错误的对手比较** → 品类定义出了问题
4. **定价只能跟竞品走** → 没有定价权=定位不够强
5. **新品类挑战者在快速成长** → 你的品类可能正在被重新定义
