# 用户操作手册 · 安全体系

> Phase 3 产物。安全加固大多是「看不见的护栏」，本手册只收**你作为用户/管理员可能真实撞到的行为变化**（2026-08 S1 上线后；S2 追加单点登录/低余额限行；8-10 追加注册密码要求；8-15 S3 追加隔离/会话封顶/打码、S4 追加上传四类新护栏）。
> 关联 Feature Map：[../feature-map/安全体系.feature-map.md](../feature-map/安全体系.feature-map.md)
> 本功能 PRD 编号：SEC-FR-001/003/008/010/040~044/120~123/126/031~034/113/124/125

## 一句话描述
平台加了一层安全护栏：登录有防爆破锁定、危险文件传不上也打不开、积分充值不怕重复点——你基本无感，撞到规则时照本手册处理即可。

## 适用场景

- **谁用**：全体用户（登录锁定、文件上传）+ 管理员（充值防重、对账）
- **什么时候用**：登录提示被锁 / 上传文件被拒 / 担心充值重复到账
- **用完得到什么**：知道发生了什么、多久恢复、找谁处理

## 一、登录提示「登录失败次数过多」（普通用户）

**发生了什么**：你的账号连续输错密码 **5 次**，系统把它锁了 **15 分钟**——这是防别人暴力猜你密码的护栏，锁定期内**连正确密码也进不去**。

**怎么办**：
1. 等 15 分钟自动解锁，再用正确密码登录。
2. 着急用：联系管理员在 Redis 里删 `login:fail:u:你的用户名` 键立即解锁（运维手册有 runbook）。
3. 如果**不是你本人试的**：解锁后立刻改密码，并告知管理员查审计日志（每次锁定都有记录）。

**另一条规则**：同一个 IP 一小时失败超 20 次会被封 1 小时（公司共用出口网络时，别人试错可能误伤你，同样等自动解或找管理员）。

---

## 二、上传文件提示「文件类型不允许上传」（普通用户）

**发生了什么**：你传的文件扩展名在危险名单里（如 `.html`、`.svg`、`.exe`、`.js`）——这类文件能被用来在平台里塞恶意脚本，上传入口统一拒收（HTTP 400，错误码 40010）。

**怎么办**：
1. 文档/图片/音视频/pdf 都能正常传；被拦的基本是可执行或网页类文件。
2. 确需传代码/网页：打包成 `.zip` 再传（zip 不在危险名单）。
3. 既有老的 html/svg 文件**还能下载**，但只会强制下载到本地、不会在浏览器里直接打开——这是故意的，不是坏了。

## 五、提示「账号已在别处登录」（普通用户，S2 新增）

**发生了什么**：你的账号在另一台设备/浏览器**新登录了一次**，系统实行单点登录——同账号只允许一处在线，新登录会把旧会话踢下线（HTTP 401，错误码 40104）。

**怎么办**：
1. 是你自己换设备登录的 → 正常现象，原设备重新登录即可（会把另一边踢掉）。
2. **不是你本人登录的** → 立刻改密码，并告知管理员查审计日志（每次踢人都留有 `session_kicked` 记录）。
3. 登出（点退出）会同时失效两侧 token，不用担心残留。

**例外**：平台 Redis 故障期间单点登录会临时失效（双端都能用），恢复后自动回到「一处在线」——这是有意的可用性设计，不是bug。

## 六、提示「余额不足，请等待当前任务完成」（普通用户，S2 新增）

**发生了什么**：你的积分余额低于平台阈值（默认 100，管理员可调），系统限制你**同时只跑一个任务**（对话/视频生成）。你前一个任务还在跑，第二个就被拦了（HTTP 429，错误码 42902）。

**怎么办**：
1. 等当前任务跑完再发下一条——余额低不影响使用，只是不能并行。
2. 充值到阈值以上立即恢复并行能力。
3. 不影响：知识库索引、文件上传、历史记录查看等不扣费功能照常。

**管理员**：阈值和在途上限在「设置 → 计费设置」页面实时可调（保存即生效，无需重启）。

## 七、注册时提示密码不符合要求（普通用户，2026-08-10 新增）

**发生了什么**：注册密码现在有强度要求，不达标会被拒（HTTP 400，话术会说明具体原因）。规则共四条：

1. 长度 6~100 字符；
2. **必须同时包含**大写字母、小写字母、数字、特殊字符（如 `Str0ng#Pass`）；
3. 不能是常见弱密码（`123456`、`password`、`admin123` 这类会被直接拒）；
4. 不能和你的用户名相同。

另外密码总长别超过约 24 个汉字 / 72 个英文字符——超出加密算法上限的部分会被静默丢弃，系统会直接拒而不是悄悄截断。

**怎么办**：按提示换密码即可。**老账号不受影响**——已注册的账号哪怕密码很简单也照常登录，本规则只管新注册；建议老账号密码过弱的在改密功能上线后主动更换。

## 八、知识库文档显示「已隔离」（管理员，S3 新增）

**功能入口**：知识库 → 文档管理。
**现象**：文档状态列红色「已隔离」，错误列显示「疑似提示词注入：命中特征 …」。
**这是什么**：文档内容命中注入攻击特征（如「忽略以上所有指令」类话术），为防污染问答已被自动隔离——不进检索索引，用户问答用不到它。
**操作步骤**：
1. 点该文档行的「解除隔离」按钮（仅 knowledge:manage 可见）。
2. 文档回到「待解析」并自动重新走解析+索引；确认内容确实无恶意再解。
**完成标志**：状态列回到正常流转（解析中→已索引）。
**常见异常**：解除后又很快再被隔离——说明文档内容确实反复命中特征，须人工核对原文（不要对同一文档无脑连解）。

## 九、提示「本会话累计用量已达上限，请开通新会话继续」（普通用户，S3 新增）

**这是什么**：单会话累计消耗 token 超上限（默认 50 万），继续聊会让上下文越来越贵——开新会话即可，历史消息仍可回看。
**操作**：左侧会话列表新建会话继续对话。
**注意**：这是会话级限额不是封号；新会话照常用。管理员可在「安全管理 → 规则配置」调 `security.llm.session-token-cap`（0=关闭该限制）。

## 十、AI 回复里身份证/手机号变成 `***`（普通用户，S3 新增）

**这是什么**：输出侧敏感信息打码（身份证/手机号/银行卡/密钥样式串整段遮蔽），防止 AI 复述出他人敏感数据。属正常安全行为，无法按需关闭单条。
**看到大段「[系统提示词内容已遮蔽]」**：模型在复述内部提示词被拦——属正常防护，重问一次通常正常作答；频繁出现可反馈管理员核查该智能体的提示词配置。

## 十一、上传提示「文件内容与声明类型不符」（普通用户，S4 新增）

**发生了什么**：你传的文件**改名了**——比如把 `.exe` 改成 `.png`、把网页脚本改成 `.txt`。系统会读文件开头的特征字节（魔数）核对真实类型，对不上直接拒收（HTTP 400，错误码 40010）。

**怎么办**：
1. 确认文件本身没损坏、扩展名与内容一致（用本机打开正常、后缀没手改过）再传。
2. 从别处下载的素材被拦 → 找原始来源重新导出；确实是你自己改名导致的，改回真实后缀即可。
3. 极少数冷门格式被误拦 → 联系管理员核查（系统对识别不出的类型默认放行并计数观察，误拦率极低）。

---

## 十二、上传提示「图片分辨率过大」/「存储空间已满」（普通用户，S4 新增）

**发生了什么**：两条不同护栏——①图片总像素超过 1 亿（如恶意超大尺寸图，防止解码拖垮服务器，HTTP 400）；②你的个人存储配额用满（默认 2GB，HTTP 40011，提示里带「已用 X.XGB / 上限 X.XGB」）。

**怎么办**：
1. 分辨率问题：用图片工具缩小后再传（正常照片/截图远低于上限，撞到的基本是异常文件）。
2. 配额问题：进文件/资产列表**删除旧文件**（删完额度立即回吐）再传；或联系管理员调大配额（`security.user.storage-quota-mb` 热更，0=不限制）。

---

## 十三、上传提示「操作过于频繁」（普通用户，S4 新增）

**发生了什么**：上传类操作限频——每分钟最多 10 次（含文件/图片/视频/知识库文档/画布素材各入口）。批量导图、连续传知识库文档时可能撞到（HTTP 429）。

**怎么办**：等 1 分钟再继续。确有批量导入需求（如一次性导入几十个文档）→ 联系管理员调高 `security.rate.upload_file.max` 或临时关 `security.rate.enabled`。

---

## 十四、知识库超长文档只解析了一部分（管理员，S4 新增）

**发生了什么**：文档解析有文本上限（默认 10 万字符，`security.upload.max-parse-chars` 热更）——高膨胀文件（如 zip bomb 型文档）解到这里就截断，防止内存被撑爆。截断后的内容**不进**向量库，检索可能不全。

**怎么办**：超大文档建议拆分成多个文档上传；确认是正常大文档且需要全量解析 → 调高热更键（注意服务器内存水位）。

## 常见问题

**Q: 我什么都没做，为什么登录被锁？**
A: 两种可能：有人（或某个存了你旧密码的客户端）在反复试你的账号；或你所在的共用出口 IP 被别人试错连累。等自动解锁或找管理员，解锁后建议改密码。

**Q: 安全响应头/CORS 白名单会影响我用平台吗？**
A: 正常用完全无感。只有自己写脚本/第三方页面跨域调平台 API 时才受白名单限制——生产环境仅放行官方前端域名，发现跨域报错联系管理员核对白名单。

**Q: 我存的积分流水能被后台改掉吗？**
A: 不能。流水表只增不改（数据库层禁止应用账号 UPDATE/DELETE），且有每日对账抓异常。

**Q: 审计日志会不会被偷偷改掉？**（S2 新增）
A: 改不了不留痕。每条审计记录都带着「链上一条」的防伪指纹（HMAC 哈希链），改或删任意一条，后面全对不上——系统每天凌晨自动全量校验并把末行指纹写入独立锚点文件，断链会告警且留 `chain_broken` 记录。只会告警不会自动改回（防篡改系统自己覆盖证据）。

**Q: 单点登录能关掉吗？**（管理员）
A: 能。「设置 → 认证设置 → 单点登录」开关关掉即恢复同账号多端同时在线，立即生效。

**Q: 我用简单密码的老账号会被强制改密吗？**（2026-08-10 新增）
A: 不会。密码强度要求只管**新注册**，存量账号照常登录不受任何影响。改密功能上线后建议主动换成强密码（届时改密也会走同样的强度校验）。

**Q: 我传的正常文件会被魔数嗅探误拦吗？**（S4 新增）
A: 概率极低。嗅探对识别不出的类型默认**放行**并计数观察（不拦）；只有「内容与扩展名明显对不上」（exe 冒充 png、脚本冒充 txt）才拒。真被误拦联系管理员看拒收指标 `security.upload.magic.denied` 的 reason 定位。

**Q: 视频抽帧/剪辑会受超时影响吗？**（S4 新增）
A: 正常短视频完全无感（超时 30s、帧预算远超常规时长）。只有损坏/恶意构造的视频会在有限时间内收到失败话术，而不是让画布节点永远转圈。

## 十二、管理员两步登录（TOTP，S5 新增）

**谁用**：绑定了 TOTP 的用户（当前主要为管理员）。绑定后每次登录需「密码+手机验证器 6 位码」两步。

**绑定步骤**（设置 → 安全设置 → TOTP 两步验证）：
1. 点「开始绑定」→ 出现 secret 密钥和 otpauth 链接。
2. 手机验证器 App（Google Authenticator / Microsoft Authenticator / 阿里云身份宝等）选「手动输入设置密钥」，粘贴 secret（或扫描 otpauth 二维码）。
3. 输入验证器当前显示的 6 位码确认 → 绑定生效，**一次性发放 8 组恢复码**。
4. **恢复码请立即抄写保存到安全地方**——只显示这一次，每张只能用一次，手机丢了靠它救场。

**登录变化**：密码输对后不直接进系统，出现第二屏要求输 6 位码或恢复码；输错可重试（同一中间票最多 5 次，超了作废重登）。

**解绑**：设置 → 安全设置 → TOTP 卡片「解绑」——需输一个当前有效的 6 位码（防止别人借你登录着的电脑直接拆掉第二道锁）。

**常见异常**：验证器一直报错 → 检查手机时间是否自动同步（TOTP 按 30 秒时间窗算码，时间偏差大会全部错位）；手机丢了 → 用恢复码登录后重新绑定。

## 十三、注销账号（S5 新增）

**入口**：设置 → 安全设置 → 最底部「注销账号」。

**操作步骤**：
1. 点「注销我的账号」→ 弹确认窗（含不可恢复警示与《隐私政策》链接）。
2. 输入**当前密码** + 在第二框输入「注销」两个字。
3. 点「确认注销」→ 提示成功，自动跳回登录页。

**界面变化**：注销成功瞬间所有设备被踢下线跳登录页；原用户名/邮箱从此无法登录。

**完成标志**：登录页用原用户名+原密码登录 → 报「账号状态不允许」类错误。

**注销前后你需要知道**（详见 `/privacy` 隐私政策页）：
- 用户名/邮箱/手机号/头像被**匿名化清除，不可恢复**——想再用平台须重新注册。
- 账号余额**不予退还**，请注销前处理完毕。
- 计费流水与审计日志按法定要求**脱敏保留**（不再关联到你这个人）。

**误操作恢复**：无法恢复。密码确认+「注销」二字双闸就是为拦手滑；真的点成功了，只能重新注册新账号。
