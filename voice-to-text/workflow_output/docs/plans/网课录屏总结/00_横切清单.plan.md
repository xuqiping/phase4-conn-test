# 子 plan · 横切关注点（联动点 + 运维）

> 父 plan：[../网课录屏总结.plan.md](../网课录屏总结.plan.md)。本文件满足 Phase2 出口条件的「功能联动点清单」「运维考量清单」两项（v1.3/v1.4 硬要求）。
> 联动点 = 某操作会触发其他 UI/数据变化，必须覆盖**正向 / 反向 / 边界**，否则 Phase 4 验收翻车。

## 功能联动点清单

| # | 触发动作 | 联动对象 | 预期变化（正向） | 边界（反向 / 异常 / 批量） |
|---|---|---|---|---|
| L1 | 点「停止录制」 | 状态机 + Processing | 状态 `Recording → Processing`，自动开始编排（抽帧→OCR→对齐→总结） | **异常**：录制中断 → 保留已录片段 + 提示，仍可进处理（部分）；**磁盘满** → 停止 + 提示，不进处理 |
| L2 | 切换「多模态精修」开关 | 总结输入 + 提示 | ON → 分段附带课件图给 VLM；弹二次确认；建议重新总结 | **反向**：OFF → 仅传文字；**取消确认** → 保持 OFF；**已有总结不自动重算**（需手动重新生成） |
| L3 | 点「重新生成」（全局/单段） | 草稿 + 版本历史 | 覆盖草稿，旧版进版本历史 | **生成中再点** → 忽略/排队；**失败** → 保留旧草稿不覆盖；**单段** → 只换该段，其余不动 |
| L4 | 选中时间轴章节 | 右侧要点 + 课件帧 + 视频 | 右侧切换该章节内容；视频跳到章节起点 | **无选中** → 空态提示；**章节无要点** → 提示「本段无总结」 |
| L5 | 点要点时间戳 / 课件帧 | 视频播放器 | 跳到该时刻 + 高亮对应帧 | **原视频已删** → 提示「原视频已删除，仅可查看帧」 |
| L6 | feature flag 关闭 | 应用入口 | 录屏总结入口隐藏，回到纯录音转文字 | **反向**：再开启 → 入口恢复；**已有会话数据保留**，可再访问 |
| L7 | 切换会话 | 学习区全量 | 时间轴/总结/课件帧重新加载 | **有未保存编辑** → 提示保存（草稿态确认） |
| L8 | 点「导出」选格式 | 文件系统 | 生成 MD（导图/Anki 占位）到 exports/ | **磁盘不足** → 提示；**同名覆盖** → 确认 |

> 实现时每条联动在对应 Step（L1→Step4/12，L2/L3→Step8/11，L4/L5/L7/L8→Step11，L6→Step12）的「动作」里体现，并在 Phase 4 按本表逐条验证边界。

## 运维考量清单（每条明确 做 / 不做 / 后续）

| # | 项 | 决定 | 说明 |
|---|---|---|---|
| O1 | 可观测性 | **做** | 关键路径日志（capture/ocr/align/summary 各阶段耗时 + 结果状态），traceId = 会话目录名；前端关键事件埋点（采纳/重写/完成/各阶段进入） |
| O2 | 配置开关 | **做** | feature flag 控制入口显隐；抽帧阈值（直方图/汉明距离）、API 并发度可配置 |
| O3 | 可回滚 | **做**（数据层天然可逆） | 会话目录可整体删；总结草稿态 + 版本历史可回滚；**无 DB schema 变更**（无回滚迁移问题） |
| O4 | 限流/熔断/降级 | **做** | 云端 API 超时/限流 → 重试 + 降级（保留文本兜底）+ 友好报错；本地阶段失败 → 阶段化重试 |
| O5 | 运维入口 | **做**（轻量） | 学习区「重新总结」= 手动重试入口；会话管理可手动清理脏目录/补处理 |
| O6 | 告警阈值 | **不做**（桌面单机） | 无服务端告警系统；异常（掉帧率、API 失败率）仅在本地日志体现 + 用户可见错误提示 |
| O7 | 容量/性能预案 | **做** | sessions/ 磁盘累积 →「导出后删原视频」+ 会话清理；2h 视频 15min 切片；OCR/抽帧结果缓存避免重算 |

## 备注

- 本清单是开发期「埋点/留开关/留入口」的依据，Phase 3 写码时按此埋，上线后补不回来。
- 桌面单机应用与 B/S 架构不同：无服务端告警/熔断基础设施，O6 判定为「不做」是合理的，但 O1/O2/O4/O5 必须做。
