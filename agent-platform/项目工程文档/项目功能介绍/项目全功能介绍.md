# 多Agent智能体平台 — 全功能介绍

## 一、项目概述

多Agent智能体平台是一个面向AI应用场景的低代码编排系统。用户可以在平台上浏览Agent（智能体）、查看其技能和能力，通过可视化画布将多个Agent技能编排成工作流，实现复杂的AI任务自动化。

**技术栈**：Vue 3 + TypeScript + Spring Boot 3 + PostgreSQL + Redis

**核心定位**：桌面端优先的Agent管理与工作流编排平台

## 二、功能模块

### 2.1 认证与权限系统

| 功能 | 说明 |
|------|------|
| 用户注册 | 用户名+密码+邮箱注册，自动分配"普通用户"角色 |
| 用户登录 | JWT认证，accessToken(15分钟) + refreshToken(7天)双Token机制 |
| Token刷新 | accessToken过期后自动用refreshToken换取新Token，无感续期 |
| 用户登出 | 登出后Token加入Redis黑名单，彻底失效 |
| RBAC权限 | 基于角色的访问控制：3种角色 × 15种权限 |
| 方法级鉴权 | `@RequirePermission("agent:read")` 注解控制API访问 |

**三种角色**：

| 角色 | 权限范围 |
|------|---------|
| 普通用户(user) | 查看Agent、工作流CRUD+发布、执行工作流、查看日志 |
| Agent管理员(agent_admin) | Agent全权限 + 技能管理 + 工作流 + 执行（共13项） |
| 系统管理员(admin) | 全部15项权限 + 用户管理 + 角色管理 |

### 2.2 主题系统

| 功能 | 说明 |
|------|------|
| 3套暗色主题 | Deep Space（冷蓝）、Dark Pro（绿色）、Cyber Glow（霓虹） |
| 实时切换 | 登录页和主界面均可切换，CSS变量驱动 |
| 持久化 | 主题选择保存到localStorage |

### 2.3 Agent展示模块

| 功能 | 说明 |
|------|------|
| Agent大厅 | 4列网格布局展示所有Agent，显示头像、名称、分组、描述、技能数、在线状态 |
| 分组筛选 | 按分组下拉筛选（通用助手/数据分析/内容创作/开发工具） |
| 关键词搜索 | 输入关键词实时搜索Agent名称和描述 |
| Agent详情页 | 左右分栏：左侧技能列表、右侧技能详情+步骤时间线 |
| 技能时间线 | 垂直时间线展示技能的执行步骤，标注动作类型 |

### 2.4 工作流编排模块

| 功能 | 说明 |
|------|------|
| 工作流列表 | 卡片列表展示所有工作流，支持搜索、新建、导入 |
| 可视化画布 | 基于Vue Flow的拖拽式画布，支持节点拖放、连线、缩放 |
| 3种节点类型 | 开始节点(绿色)、结束节点(红色)、技能节点(卡片式) |
| 组件面板 | 左侧面板展示所有Agent的技能，按Agent分组，拖入画布使用 |
| 属性面板 | 右侧面板显示选中节点的属性：类型、名称、描述、所属Agent、坐标 |
| 工具栏 | 底部浮动工具栏：撤销、重做、放大、缩小、适应画面、导出 |
| 节点连线 | 从组件面板拖技能到画布 → 用线连接节点 → 保存工作流 |
| 工作流CRUD | 创建、编辑、复制、删除、导入导出(JSON) |
| 画布保存 | 序列化节点和边数据到数据库，编辑时可恢复完整画布状态 |

### 2.5 管理后台

| 功能 | 说明 |
|------|------|
| 用户管理 | 分页用户列表、分配角色（多选）、启用/禁用用户 |
| 角色权限 | 角色卡片选择 → 按资源分组的权限checkbox编辑 → 保存 |
| 权限分组 | 按资源分类展示：Agent管理(5)、技能(1)、工作流(5)、执行(2)、用户(1)、角色(1) |

### 2.6 数据导入

| 功能 | 说明 |
|------|------|
| Markdown同步 | 从文件系统Markdown文件批量导入Agent分组、Agent、技能、技能步骤 |
| 自动更新 | 已存在的数据按名称匹配更新，不重复插入 |
| API触发 | 通过 `POST /api/agents/sync` 触发同步 |

### 2.7 Agent管理界面

| 功能 | 说明 |
|------|------|
| 创建Agent | Agent大厅顶部「新建Agent」按钮，填写名称/描述/分组/头像 |
| 编辑Agent | 卡片悬浮显示编辑按钮，或详情页顶部编辑按钮 |
| 删除Agent | 确认弹窗后逻辑删除 |
| 发布/下线 | 草稿→发布、已发布→下线，状态标签实时显示 |
| 权限控制 | 仅拥有agent:create/update/delete/publish权限的用户可见操作按钮 |

## 四、API清单

### 认证模块 `/api/auth`
| 方法 | 端点 | 说明 | 权限 |
|------|------|------|------|
| POST | `/login` | 登录 | 公开 |
| POST | `/register` | 注册 | 公开 |
| POST | `/refresh` | 刷新Token | 公开 |
| POST | `/logout` | 登出 | 登录用户 |
| GET | `/me` | 获取当前用户信息 | 登录用户 |

### Agent模块 `/api`
| 方法 | 端点 | 说明 | 权限 |
|------|------|------|------|
| GET | `/agent-groups` | 分组列表 | agent:read |
| GET | `/agents` | Agent列表（支持筛选） | agent:read |
| GET | `/agents/{id}` | Agent详情（含技能） | agent:read |
| GET | `/agents/{id}/skills` | Agent技能列表 | agent:read |
| GET | `/skills/{id}` | 技能详情（含步骤） | agent:read |
| POST | `/agents` | 创建Agent | agent:create |
| PUT | `/agents/{id}` | 更新Agent | agent:update |
| DELETE | `/agents/{id}` | 删除Agent(逻辑删除) | agent:delete |
| PUT | `/agents/{id}/status` | 发布/下线Agent | agent:publish |
| POST | `/agents/sync` | Markdown数据同步 | agent:create |

### 工作流模块 `/api/workflows`
| 方法 | 端点 | 说明 | 权限 |
|------|------|------|------|
| GET | `/` | 工作流列表 | workflow:read |
| POST | `/` | 创建工作流 | workflow:create |
| GET | `/{id}` | 工作流详情（含节点+边） | workflow:read |
| PUT | `/{id}` | 更新工作流 | workflow:update |
| DELETE | `/{id}` | 删除工作流 | workflow:delete |
| POST | `/{id}/duplicate` | 复制工作流 | workflow:create |
| GET | `/{id}/export` | 导出JSON | workflow:read |
| POST | `/import` | 导入JSON | workflow:create |

### 管理模块 `/api/users` + `/api/roles`
| 方法 | 端点 | 说明 | 权限 |
|------|------|------|------|
| GET | `/users` | 用户列表(分页) | user:manage |
| GET | `/users/{id}` | 用户详情 | user:manage |
| PUT | `/users/{id}/status` | 启用/禁用用户 | user:manage |
| PUT | `/users/{id}/roles` | 分配角色 | user:manage |
| GET | `/roles/all` | 所有角色 | role:manage |
| GET | `/roles/{id}/permissions` | 角色的权限ID列表 | role:manage |
| PUT | `/roles/{id}/permissions` | 更新角色权限 | role:manage |
| GET | `/roles/permissions/all` | 所有权限列表 | role:manage |

### 执行模块 `/api/executions`（预留）
| 方法 | 端点 | 说明 | 权限 |
|------|------|------|------|
| POST | `/` | 启动执行 | execution:run |
| GET | `/{id}` | 执行日志详情 | execution:read |
| GET | `/` | 按工作流查执行列表 | execution:read |

## 六、后端模块清单

| 包 | 说明 |
|---|------|
| `auth` | 认证模块：用户/角色/权限实体、JWT工具、Security过滤器、登录注册API |
