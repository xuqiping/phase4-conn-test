# 3.3 交互原型设计

## I.03 交互原型框架

交互原型的核心是将静态布局转化为动态行为表达。五层框架：

| 层级 | 内容 | 对应产出 |
|---|---|---|
| L1 页面流 | 页面间的跳转关系与导航路径 | 页面流程图 |
| L2 状态机 | 同一页面/组件在不同条件下的表现 | 状态转换表 |
| L3 交互响应 | 用户操作→系统反馈的映射关系 | 交互规格说明 |
| L4 数据驱动 | 内容随数据变化的动态渲染逻辑 | 数据绑定说明 |
| L5 异常处理 | 网络/权限/空值等异常的降级方案 | 异常状态矩阵 |

### 交互原型的三种表达模式

| 模式 | 实现 | 精度 | 成本 |
|---|---|---|---|
| 热区跳转(Hotspot) | 页面A热区→页面B | 仅验证流程可达 | 最低 |
| 条件连线(Conditional) | IF条件→页面A/页面B | 验证分支逻辑 | 中等 |
| 变量驱动(Variable-driven) | 变量赋值→动态渲染→条件跳转 | 验证数据逻辑 | 最高 |

## C.01 场景化交互原型设计

### 场景1：C端电商下单流程

```
首页商品→商品详情页→[加入购物车/立即购买]
  ├ 加入购物车→购物车页→结算页→地址选择→支付→成功页
  ├ 立即购买→结算页→地址选择→支付→成功页
  └ 异常分支：库存不足→推荐替代/缺货提示
```

**原型关键点**：①购物车状态需实时绑定数量变量；②地址选择需条件跳转（无地址→新增/有地址→选择）；③支付需加载态+超时态+取消态。

### 场景2：B端数据管理后台

```
登录→仪表盘→数据列表页→筛选+排序+分页
  ├ 新增→表单→校验→成功提示→刷新列表
  ├ 编辑→预填表单→校验→成功提示→刷新列表
  ├ 删除→确认弹窗→删除API→成功提示→刷新列表
  └ 批量操作→多选→批量操作栏→确认→结果反馈
```

**原型关键点**：①列表需动态数据模拟（分页+排序）；②表单需实时校验+错误状态；③批量操作需选中态+操作栏联动。

### 场景3：AI对话产品

```
首页→对话输入→AI响应(stream)
  ├ 文本输入→流式输出→追问/编辑/复制
  ├ 图片上传→识别+描述→追问
  └ 异常分支：内容审核拒答/网络超时/Token超限
```

**原型关键点**：①流式输出的打字机动效模拟；②上下文关联对话的分支连线；③审核拒答的降级提示。
