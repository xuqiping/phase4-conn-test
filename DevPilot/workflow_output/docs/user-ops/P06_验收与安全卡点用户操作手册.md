# P06 验收与安全卡点 · 用户操作手册

## 1. 进入验收阶段

**前置**：建造阶段（build）所有任务完成。

| 步骤 | 界面变化 | 预期结果 |
|---|---|---|
| 1. Build 视图点「进入验收」 | L2/L3 项目先跑安全扫描 | 扫描通过 → 自动切到验收视图；不通过 → 红色提示风险项，不切换 |
| L0/L1 项目 | 直接切换 | 安全扫描只是建议项，不拦截（可在验收视图里手动扫） |

## 2. 验收清单逐项点检

| 操作 | 位置 | 效果 |
|---|---|---|
| 标记结果 | 每个用例旁「通过 / 不通过 / 不适用」 | 状态立即保存；全部 pass/na 后底部提示「可以发布」 |
| 重新生成清单 | 清单右上「重新生成」 | 先弹确认（会清空当前清单含已通过状态）；确认后重新读测试方案文档重建清单（历史运行记录保留） |
| 跑自动验收 | 「跑自动验收」 | 对「（自动）」标记的用例跑 Playwright 冒烟，几秒后显示「通过 X 失败 Y 跳过 Z」 |

**联动**：在预览窗格圈选问题创建修复任务（见第 4 节）时，对应验收项关联该任务；修复任务完成（done）后该项自动变回「待验收」，需要重新点检。

## 3. 看安全扫描结果

| 步骤 | 注意事项 |
|---|---|
| 1. 左栏「安全检查」点「扫描安全风险」 | 几秒出结果 |
| 2. 点任意风险条目 | 展开类别 / 建议 / 代码片段（密钥已脱敏，只显示头尾几位） |
| 3. 看「安全门禁已解锁」徽章 | L2/L3 项目必须解锁才能进验收；L0/L1 仅提示 |

## 4. 在预览窗格里圈选问题

| 步骤 | 界面变化 | 预期结果 |
|---|---|---|
| 1. 右栏输入本地地址（如 `http://localhost:5173`） | iframe 内嵌预览 | 只允许 localhost / 127.0.0.1，外网地址拒绝 |
| 2. 切换「手机 / 平板 / 桌面」 | 预览区尺寸变化 | 用于检查响应式 |
| 3. 点「圈选」后在预览上点问题位置 | 弹出修复任务对话框 | 坐标已带入 |
| 4. 补充 CSS 选择器（如 `#submit-btn`）+ 问题描述 → 确认 | 提示「已创建修复任务 #N」 | 任务进入当前轮次队列，AI 下一轮会修 |

## 5. 发布

| 步骤 | 注意事项 |
|---|---|
| 1. 底部「发布」按钮 | 全部验收项 pass/na 才会亮起；有未完成项时灰色并提示 |
| 2. 点击发布 | 进入部署阶段 | 就算按钮被绕过，内核也会再校验一次并拦截 |

## 6. 常见问题

- **自动验收全是「跳过」**：本机没装 Node 或 Playwright，装上后重跑；期间可人工点检。
- **预览空白**：确认 dev server 已启动、地址是 localhost 且带 `http://`。
- **清单是空的**：先在项目里写测试方案文档（含 TC-XX 用例），再点「重新生成」。
