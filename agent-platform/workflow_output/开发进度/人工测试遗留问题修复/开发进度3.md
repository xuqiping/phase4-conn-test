## 实现期修正（记录到 spec §偏离）
1. C3 推导舍入原计划纯 round，实测 4K+16:9 恰在限内（16,776,192 ≤ 16,777,216）但一般情况可能贴破 → 加「超上限高度回落一步」保底（面积近似守恒）。
