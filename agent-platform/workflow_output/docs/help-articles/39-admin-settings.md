# 系统设置（管理员）

> 入口：侧栏底部「设置」（仅管理员和模型配置岗可见）。页签：全局模型供应商 / 认证设置 / 计费设置 / RAG·召回 / 联网搜索。

## 一、全局模型供应商

**新增供应商**：按类别建——CHAT（对话）/ IMAGE（图片）/ MEDIA（视频）/ EMBEDDING（向量）/ RERANK（重排）。填名称、类别、接口地址、API Key、模型列表。

- 图片生成需建 IMAGE 类供应商；视频生成需 MEDIA 类；知识库需 EMBEDDING + RERANK（不能登记成 CHAT）。
- 行内「测试」：Embedding 成功显示维度；Rerank 成功显示排序正确。
- ⚠️ 配完模型还要去「价表配置」定价，否则调用无法计费。

**导出/导入**（备份/迁移）：
1. 「导出」→ 确认窗提示「含明文 API Key」→ 下载 JSON。⚠️ 文件含明文密钥，别发群/别提交 git。
2. 「导入」→ 选 JSON → 预览「新增 X / 更新 Y / 疑似非法 Z」→ 确认。**按名称匹配更新**；某行没填 Key 不会清空已有 Key；单次上限 200 条。

## 二、认证设置（认证通道）

- **单点登录开关**：开 = 同账号只一处在线（新登录踢旧的）；关 = 多端同时在线。即时生效。
- **邮件通道（SMTP）**：以腾讯邮箱为例——
  1. 通道类型选 SMTP，填四要素（QQ 邮箱：`smtp.qq.com` 端口 465 SSL 开，用户名=完整邮箱，密码=SMTP 授权码）。
  2. 先点「**测试发信**」给自己收一封——收到再开「启用」。
  3. **邮箱验证总开关**（默认关）：开 = 注册强制邮箱验证码 + 充值需已验证邮箱；关 = 注册邮箱选填、充值不卡邮箱。
  4. 日封顶默认 500 封/天（防盗号轰炸）。

## 三、计费设置

- 低余额限行阈值（默认 100）与在途上限：余额低于阈值的用户同时只能跑 1 个任务。保存即生效。

## 四、RAG/召回（记忆设置）

- 「记忆检索模式」切换后，**只显示该模式相关的设置项**（不相关的自动隐藏，已填的值不丢）。
- 「entities 词袋计数」（仅 LLM_KEY/混合模式可见）：调召回关键词的数量旋钮（总数上限/同义变体/专名/上位词），改完自动保存。
- ⚠️ 改配置**只对新记忆生效**；要让老记忆按新配置重抽 → 点「老记忆关键词重抽」按钮（异步跑，可重跑）。

## 五、联网搜索

1. 「联网搜索（全局）」总开关打开 → 用户侧的 🌐 开关才生效。
2. 选默认引擎；配外部 Key（Tavily/Serper/Bing，AES 加密入库不回显）。
3. 「测试连通」：命中 >0 条 = 通道正常；0 条看各引擎可用性标签定位。
4. 自建引擎（SearXNG）由运维 Docker 部署后在配置文件指地址，不在本页改。
