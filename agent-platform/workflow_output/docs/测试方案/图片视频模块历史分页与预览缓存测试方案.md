# 图片视频模块历史分页与预览缓存 · 人工测试方案

> Phase 3 功能级预处理。来源：[计划](../plans/图片视频模块历史分页与预览缓存.plan.md) · [规格](../specs/图片视频模块历史分页与预览缓存设计.md)
> 覆盖问题：4x#2（视频历史分页）、4x#3/6x#1（参考图悬浮+灯箱）、6x#2（图片两级缓存）。
> 纯逻辑部分（分页参数校验、ETag 生成、LRU 逐出）由自动化单测覆盖，本方案只列**必须人工介入**的交互/体感项。

## 一、前置数据

- 账号 A：≥ 23 条视频任务 + ≥ 23 条图片任务（覆盖不同日期与提示词，至少 1 条含参考图、1 条含首尾帧、1 条含参考视频）。
- 账号 B（他人）：少量任务，用于确认互不可见。
- 浏览器：Chrome，开 DevTools Network 面板；「Disable cache」勾选状态分别用到（缓存用例需取消勾选）。

## 二、分页（Step 1/2）

| 用例 | 步骤 | 预期 |
|---|---|---|
| P1 默认条数 | 打开视频页历史区 | 首次加载 10 条，分页器显示总条数与总页数 |
| P2 切每页条数 | 条数下拉切 5→20→50 | 列表按新条数重载，回第 1 页 |
| P3 翻页 | 点第 2、3 页，末页，再回第 1 页 | 各页数据不重复不丢；末页条数≤每页条数 |
| P4 越界页 | 手动停留在末页后删除数据再刷新（或条数从 5 切 50） | 空页不报错，分页器正确回落/显示 |
| P5 图片页 | 图片页重复 P1-P4 | 行为与视频页一致 |
| P6 筛选+分页组合 | 提示词筛「猫」→翻第 2 页→清空筛选 | 筛后翻页数据正确；清空回第 1 页且全量 |

## 三、联动用例（对齐计划 L1-L5，含反向/边界）

| # | 触发动作 | 预期变化 | 必测反向/边界 |
|---|---|---|---|
| L1 | 改筛选（提示词/起止时间） | 分页器重置第 1 页并重载 | 清空筛选同样重置；翻页时筛选保持不丢；时间倒置被拒且有提示 |
| L2 | hover 参考图瓦片→点击 | hover 浮层出现（放大图，零新请求）；点击后浮层关闭、灯箱打开 | hover 中直接点击不出现两层叠加；灯箱 Esc/点遮罩关闭后再次 hover 正常 |
| L3 | 历史行点击回填（既有能力） | 表单回填，页码不动 | 翻页后点行回填正常；回填后再翻页表单不清空 |
| L4 | 视频参考瓦片点击 | 播放弹窗打开（可播可暂停），表单不被改动 | 弹窗开着时点提交不被弹窗阻挡；关闭后瓦片状态原样 |
| L5 | 第 5 页×5 条时切每页 50 条 | 超出范围回落第 1 页 | 回落后总页数/itemCount 正确；切回 5 条可再翻深页 |

## 四、悬浮与灯箱（Step 3/4）

| 用例 | 步骤 | 预期 |
|---|---|---|
| H1 悬浮放大 | 图片页参考图 chip、视频页首尾帧槽位/参考瓦片分别 hover ≥300ms | 受控浮层出现，图像清晰；移出即关 |
| H2 防抖 | 快速划过多个瓦片 | 不闪烁成串，停留<300ms 不弹 |
| H3 灯箱 | 点击各处缩略图 | 全屏黑底居中大图；Esc/遮罩点击/关闭钮三路均可关 |
| H4 复用加载 | 同一瓦片先 hover 再点击 | 第二次悬浮/灯箱秒出（blob 复用，Network 无新请求） |
| H5 历史回填瓦片 | 点历史行回填后检查瓦片 | 回填出的首尾帧/参考瓦片同款 hover/点击能力 |

## 五、缓存（Step 5/6）

| 用例 | 步骤 | 预期 |
|---|---|---|
| C1 会话内 LRU | 同一参考图悬浮两次（间隔操作其它图） | 第二次 Network 零 `/api/files/{id}` 请求 |
| C2 跨刷新 304 | 刷新页面后再悬浮同一图 | `/api/files/{id}` 返回 304（Network Size 列显示小体积/无 body） |
| C3 缓存上限 | 连续浏览 >80 个不同文件 | 内存平稳（DevTools Memory 抽查），最早条目被逐出后再悬浮会重新请求（200） |
| C4 数据不更新疑虑 | 上传新版本文件场景（若可构造） | fileId 变化→新 URL 不受缓存影响；fileId 不变→内容也不该变（不可变约定） |
| C5 他人文件 | B 账号的文件 URL 直接访问 | 403/404，不因缓存头放松鉴权 |

## 六、回归红线

- 图片页既有灯箱行为（本轮抽取为共享组件后）不回退：切换/关闭/滚轮缩放（若有）。
- 视频页历史筛选、回填、下载入口全部照旧。
- 画布/反推后续接入共享组件后（后续计划），本方案 H1-H3 用例在画布属性面板复测一遍。

## 术语表

| 术语 | 大白话 | 简单案例 |
|---|---|---|
| remote 分页 | 翻页才向服务器要那一页 | 第 3 页只请求 21-30 条 |
| 304 | 指纹没变，服务器只回「没变」不传正文 | 二次加载图片零流量 |
| LRU | 满了扔最久没用的 | 缓存 80 张，第 81 张挤掉最早那张 |
| 灯箱 | 点小图弹全屏大图层 | 黑底居中大图，点空白关闭 |
