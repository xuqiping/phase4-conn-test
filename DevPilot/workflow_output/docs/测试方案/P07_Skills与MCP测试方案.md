# P07_Skills与MCP 测试方案（人工部分）

自动化已覆盖的部分见文末「自动化对照」。这里只列**必须人工在真机上走**的用例。

## 一、技能：生成 → 斜杠调用（AC-028）

| # | 用例 | 步骤 | 预期 |
|---|------|------|------|
| H1 | 保存即可调用 | 建项目到建造阶段 → 追加指令框输入 `/re` | 弹技能候选（若已存 release-check） |
| H2 | Enter 展开 | 候选中按 Enter | 输入框清空、出现技能 chip（/名 + 描述） |
| H3 | 提交拼接 | 挂 chip 后输入正文点「追加并续跑」 | 任务收到「技能正文 + 空行 + 正文」（看事件日志确认） |
| H4 | 同名冲突 | 重复保存同名技能 | 报「已有同名技能」，原文件不被覆盖 |
| H5 | 导入导出往返 | 导出技能目录 → 换机器/删掉后导入 | 技能回到列表且可调用 |

**联动边界**：
- 反向：chip 上点 × → 再提交不拼技能正文（自动化已断言提交文本）。
- 半选：Esc 关候选后输入 `/rel` 按回车 → 按原文提交 `/rel`（不误展开）。
- 批量：导入文件夹含 1 好 1 坏 → 逐项报告，坏的不落盘。
- 路径不误弹：输入 `/usr/bin` 不弹候选（自动化已断言）。

## 二、MCP 市场 + 管理（AC-012 / AC-029）

| # | 用例 | 步骤 | 预期 |
|---|------|------|------|
| M1 | 点选安装免配置 | MCP 管理页 → 市场装 `fetch`（需本机有 Node） | 安装后状态「运行中」，全程没改任何配置文件 |
| M2 | 缺运行时降级 | 本机不装 uv → 装 `git`（uvx） | 大白话指路（pip install uv），不崩不半装 |
| M3 | 必填 env | 安装 `github` 不填 token | 弹表单拦住；填完才装 |
| M4 | 崩溃自动重启（AC-029 真机） | 任务管理器强杀某 running server 进程 | 管理页几秒内变「出错」→ 自动重启回「运行中」；反复杀 4 次后转「需人工处理」 |
| M5 | 一键重启 | error 态点「一键重启」 | 回运行中，重启计数清零 |
| M6 | 日志抽屉 | 点「日志」 | 最近 ≤200 条，可一键复制 |
| M7 | 卸载确认 | 点「卸载」 | 二次确认；确认后列表消失 |

**联动边界**：
- 反向：停用/停止 server → 管理页徽章变「已停止」，无残留进程（任务管理器确认）。
- 批量：同时启动 5 个 server < 5s（性能验证项，plan 运维清单）。
- 手动添加：贴非法 JSON → 行内大白话报错；合法 JSON → 与市场同链路安装。
