## 竞品分析6步SOP

### Step 1：明确分析目的

| 项 | 填写 |
|---|---|
| 分析目的 | 例：决定"协作功能"优先级 / 融资路演 / 季度Review |
| 分析范围 | L1直接竞品 / L1+L2 / 全四层 |
| 核心问题 | 例："为什么用户从我们这里流失到竞品A？" |
| 时间约束 | 例：1周内出结论 |

### Step 2：识别与选择竞品

1. 用四层模型列出所有候选竞品
2. 按优先级公式（威胁度×可学习度×信息可获得性）排序
3. 选择2-5个深入分析对象（资源有限时聚焦最核心的）

**产出**：竞品清单+优先级排序

### Step 3：信息收集

| 渠道 | 方法 | 注意 |
|---|---|---|
| 亲自体验 | 注册+深度使用核心功能≥3次 | 必须付费版（免费版≠完整体验） |
| App Store/社区 | 读最近100条评论 | 分好评/差分别归因 |
| 官方材料 | 官网/博客/帮助文档/变更日志 | 关注最近3个月的动态 |
| 公开数据 | SimilarWeb/财报/融资新闻 | 标注数据时效性 |
| AI辅助 | 用Claude/Perplexity快速汇总 | AI产出必须人工验证 |

**产出**：信息收集表（标注来源+置信度）

### Step 4：深度分析

应用3.2-3.3的方法：

1. **SWOT**：我和竞品各自的优劣势机会威胁
2. **功能矩阵**：核心功能加权对比
3. **体验对标**：关键任务路径的步骤对比
4. **功能拆解**：对核心差异化功能做L1-L4四层拆解

**产出**：分析矩阵+拆解报告

### Step 5：判断与建议

| 分析项 | 判断 |
|---|---|
| 竞品最核心的优势 | |
| 竞品最明显的短板 | |
| 我们最该学习的点 | |
| 我们最佳差异化方向 | |
| 近期优先做的3件事 | |

**关键**：每个判断必须附依据，不要只凭"感觉"

### Step 6：持续监控

→ 详见3.4情报监控体系

- 建立3-5个核心竞品的信息卡片
- 配置监控源与频率
- 设立竞品动态Feed（Slack/飞书频道）
