# Intent Routing Workflow Checklist

在完成workflow/intent_routing_workflow.md的每一步后，使用此检查清单进行交叉验证。每个项目必须回答**是**才算完成。如果有任何项目回答**否**，修复输出并重新验证。

## Step 1: 解析用户意图

- [ ] 已从用户消息中扫描并提取了所有可能的技术/领域关键词
- [ ] 已对照AGENTS.md路由表的Task Keyword列完成关键词匹配
- [ ] 候选领域列表已记录（包括零个、一个或多个的情况）

## Step 2: 匹配领域

- [ ] 当仅匹配一个领域时，直接确定了目标子Agent，无需用户澄清
- [ ] 当匹配两个领域时，已向用户展示两个候选选项并请求确认
- [ ] 当匹配零个领域时，已向用户说明情况并请其重新表述或选择
- [ ] 当匹配超过两个领域时，已提取最相关的两个选项向用户展示
- [ ] 最终目标子Agent已明确且无歧义

## Step 3: 分发至子Agent

- [ ] 已在skills-router.md中成功查找到对应的Sub-Agent Directory和Skill Name
- [ ] 已向用户明确宣布将由哪个子Agent处理请求
- [ ] 已成功加载该子Agent目录下的AGENTS.md文件
- [ ] 已识别出最相关的细粒度工作流文件路径
- [ ] 已做好子Agent工作流启动的准备

## Overall

- [ ] 工作流中的所有步骤已按顺序执行，没有跳过
- [ ] 每一步都已与其检查清单部分进行交叉验证
- [ ] 没有在任何检查清单部分通过前提前进入下一步
- [ ] 	ask/current_task.md已更新完成记录
