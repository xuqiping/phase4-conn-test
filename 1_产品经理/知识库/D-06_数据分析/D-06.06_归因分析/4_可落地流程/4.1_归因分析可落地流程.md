## 4.1 指标异动归因排查 SOP

### 流程图

```
发现异动 → 确认统计显著性 → 粗粒度维度拆解 → 贡献度排序 → 细粒度钻取 → 因果验证 → 输出归因报告
```

### 详细步骤

| 步骤 | 动作 | 输入 | 输出 | 注意事项 |
|---|---|---|---|---|
| 1.发现异常 | 监控告警/手动发现 | 指标时序数据 | 异常时间点+幅度 | 区分真异常vs季节波动 |
| 2.确认显著性 | t-test/Bootstrap/业务阈值 | 异常前后数据 | p值+业务影响量级 | 统计显著≠业务显著 |
| 3.粗粒度拆解 | 按平台/地域/用户群/渠道/版本 | 维度数据 | 各子维度变化 | 确保无遗漏维度 |
| 4.贡献度排序 | 贡献度 = (子项变化×权重)/总变化 | 拆解结果 | Top-3驱动因素 | 关注方向(正/负) |
| 5.细粒度钻取 | 对Top因素进一步下钻 | 细分数据 | 根因定位 | 最多3层，避免过拟合 |
| 6.因果验证 | 找准实验/控制变量/时序证据 | 多源数据 | 因果判断(确认/排除/待验) | 区分相关vs因果 |
| 7.输出报告 | 结构化归因报告模板 | 全流程结论 | 归因报告 | 含建议行动+置信度 |

### 归因报告模板

```markdown
## 指标异动归因报告
- 异常指标：[指标名]
- 异常时段：[起止时间]
- 异常幅度：[变化量/率]
- Top驱动因素：1. [因素1] 贡献度XX%  2. [因素2] 贡献度XX%  3. [因素3] 贡献度XX%
- 因果判断：[确认/排除/待验]
- 建议行动：1. [行动1]  2. [行动2]
- 置信度：[高/中/低]
- 待跟进：[需进一步验证的事项]
```

### 阶段规划

### 前置条件检查清单

- [ ] 用户路径数据可采集（触点时序完整）

- [ ] 归因窗口已确定（如7/14/30天）
- [ ] 自然转化基线可估计

## 4.3 特征贡献分析清单

### 流程

```
定义目标变量 → 选取特征集 → 训练模型 → 计算SHAP值 → 全局+局部解释 → 验证稳定性 → 输出结论
```

### 操作要点

| 环节 | 要点 | 常见问题 |
|---|---|---|
| 目标定义 | 明确Y是业务指标还是模型预测值 | Y定义不清导致归因方向错 |
| 特征选取 | 避免后选择偏差（不用未来特征） | 泄露(leakage)导致虚假高贡献 |
| 模型选择 | 树模型用TreeSHAP，其他用KernelSHAP | 复杂度与精度权衡 |
| SHAP计算 | 检查特征相关性对SHAP值的影响 | 高相关特征SHAP值不稳定 |
| 全局解释 | 特征重要性排序+依赖图 | 排序受采样影响，需置信区间 |
| 局部解释 | 瀑布图解释单样本 | 个体解释≠因果 |
| 稳定性验证 | Bootstrap重采样看SHAP值变化 | SHAP值波动大时降低置信度 |

## 4.4 归因分析 Agent 提示词

### 提示词：指标异动归因助手

```
# Role
你是一位资深数据分析专家，擅长指标异动归因排查，能快速定位驱动因素并区分相关与因果。

# Background
产品经理在日常工作中经常会遇到核心指标突然波动的情况（如DAU下降、转化率下降、收入异常），需要快速、系统地找到根因，以便采取正确的行动。传统的"凭感觉"排查容易遗漏关键因素或误将相关当因果。

# Objective
帮助产品经理系统化地完成指标异动归因排查，输出结构化的归因报告，包含Top驱动因素、因果判断和建议行动。

# Key Results
1. 确认异常的统计显著性和业务显著性
2. 按维度逐层拆解，找到Top-3驱动因素及其贡献度
3. 对Top因素做出因果判断（确认/排除/待验）
4. 给出可执行的建议行动

# Steps
1. 确认异常：判断指标波动的统计显著性（p<0.05）和业务显著性（影响>阈值）
2. 维度拆解：按平台/地域/用户群/渠道/版本五个维度逐层拆分
3. 贡献度计算：每个子维度的贡献度 = (子项变化 × 子项权重) / 总变化
4. Top-3识别：按贡献度绝对值排序，取Top-3
5. 细粒度钻取：对Top因素进一步下钻（最多3层）
6. 因果验证：寻找时序证据/控制变量/准实验证据，区分相关与因果
7. 输出报告：按归因报告模板输出

# 红线
- 禁止将相关性直接等同于因果性，必须标注因果判断的置信度
- 禁止在维度拆解少于3个维度时下结论
- 禁止忽略自然波动和季节性因素
- 如果数据不足以支撑结论，必须明确标注"数据不足，结论待验证"

# 输出格式
```markdown
## 指标异动归因报告
- 异常指标：[指标名]
- 异常时段：[起止时间]
- 异常幅度：[变化量/率]
- Top驱动因素：1. [因素1] 贡献度XX%  2. [因素2] 贡献度XX%  3. [因素3] 贡献度XX%
- 因果判断：[确认/排除/待验]
- 建议行动：1. [行动1]  2. [行动2]
- 置信度：[高/中/低]
- 待跟进：[需进一步验证的事项]
```

# 固定结尾
以上归因基于当前可用数据，结论可能随新数据补充而更新。建议对"待验"项安排A/B实验或准实验验证。
```

## 4.5 快速归因决策树

```
需要归因？
├─ 营销渠道归因
│   ├─ 数据充分（完整路径+转化数据）→ 数据驱动归因(Shapley/马尔可夫)
│   └─ 数据不充分 → 规则归因(选最贴近业务的规则)+标注局限
├─ 指标异动归因
│   ├─ 单维度可解释 → 贡献度排序+输出
│   ├─ 多维度交织 → 维度拆解+交互效应分析
│   └─ 无法拆解 → 因果推断(找准实验/IV/PSM)
├─ 特征贡献归因
│   ├─ 有预测模型 → SHAP值
│   └─ 无预测模型 → 先建模再SHAP / 单变量分析+交互
└─ 预算分配决策
    ├─ 有实验能力 → 增量归因(Holdout/Geo)
    └─ 无实验能力 → MMM+Shapley近似
```
