# 视频模型接入扩展II 用户操作手册

> MiniMax H3 全家（视频生成 / H3-Context-IR 提示词增强 / 2K 再生成）+ HappyHorse 1.1 三形态（文生/图生/多图参考生视频），经中转 `https://ai.ctaigw.cn` 接入。
> 计价 = 中转价（=官网非折扣列表价）。规格：`../specs/视频模型接入扩展II-H3与HappyHorse中转接入.md`。

## 0. 一次性准备：填 API Key（管理员）

V166 迁移已种好 2 个供应商行 + 6 条价表，**仅 Key 留空待填**。

1. 入口：**设置 → 全局模型供应商**
2. 找到两行：
   - `HappyHorse 1.1（ai.ctaigw.cn 中转）`（协议 dashscope，3 模型：t2v/i2v/r2v）
   - `MiniMax H3（ai.ctaigw.cn 中转）`（协议 minimax，3 模型：h3 / context-ir / regeneration）
3. 每行点编辑 → **API Key** 粘贴中转站的 key → 保存
4. （推荐）点该行「测试」按钮：零成本探测端点+Key 有效性，绿了再走真实生成
5. 完成标志：两行状态 ACTIVE，测试通过；「视频生成」页模型下拉出现 6 个新模型

异常恢复：测试红 → 检查 key 是否中转站的（不是 MiniMax/阿里官网 key）、两行端点不要手改（迁移已配好中转专用的查询端点）。

## 1. HappyHorse 三形态生成

入口：**视频生成**页，模型下拉选 HappyHorse 组。

| 模型 | 输入 | 界面变化 | 计费（1000 积分=¥1） |
|---|---|---|---|
| t2v 文生 | 仅提示词 | 参考图/视频/音频上传区**整体消失**（纯文本） | 720p ¥0.9/秒，1080p ¥1.2/秒 |
| i2v 图生 | 提示词 + 恰 1 张首帧图 | **比例下拉消失**（官方无此参数，宽高跟随首帧） | 480p ¥0.45 / 720p ¥0.9 / 1080p ¥1.2 每秒 |
| r2v 多图参考 | 提示词 + 1-9 张参考图 | 比例 9 档可选 | 720p ¥0.9/秒，1080p ¥1.2/秒 |

操作：选模型 → 表单按上表自动变形（能力驱动，无需手动开关）→ 填提示词/传图 → 提交。
完成标志：历史出现任务，成片可播放/下载/入库。
注意：三形态输出 MP4 无音轨（官方行为）；时长 3-15 秒。

## 2. MiniMax H3 视频生成

模型 `minimax-h3`：提示词 + 最多 9 图/3 视频/3 音频参考；分辨率 **768p/2K** 两档（没有 720p）；时长 4-15 秒；可开「生成音频」。
计费：768p ¥0.5/秒，2K ¥0.8/秒（输出有声同价）。

## 3. H3-Context-IR 提示词增强（输出=文本，不是视频）

1. 模型选 `minimax-h3-context-ir`
2. 界面变化：**时长/分辨率/水印/生成音频控件全部消失**——该接口只吃「提示词+可选参考图/视频/音频」，产出结构化专业提示词
3. 填原始创意（可 @ 引用参考素材）→ 提交
4. 完成标志：任务完成处显示**增强文本**（可滚动阅读、「下载 .md」保存）；历史「结果」列标绿 tag「增强文本」
5. 计费：按 token，输入 ¥5.8/百万 + 输出 ¥23/百万；预估按提示词字数估算，**结算按上游实报 token 多退少补**
6. 典型用法：增强文本复制出来 → 切回 `minimax-h3` 生成视频，提示词质量更高

注意：增强文本**不入库资产库**（是文本非视频）；不会出现视频播放器属正常。

## 4. H3 2K 再生成（旧片升 2K）

1. 先有一条**已完成的 MiniMax 生成任务**（7 天内）
2. 模型选 `minimax-h3-regeneration` → 提示词/附件/参数区消失，只剩**源任务下拉**（列出你 7 天内完成的 MiniMax 生成任务：#id·模型·时长·提示词摘要）
3. 选源任务 → 提交。时长继承源任务，分辨率锁 2K，无需任何其他输入
4. 完成标志：新任务成片为源片的 2K 版
5. 计费：¥0.3/秒 × 源任务时长（预估条随所选源任务实时变）

常见异常：
- 下拉为空 → 没有符合条件的源任务（非 MiniMax 生成 / 已失败 / 超 7 天 / 本身是增强或再生成任务都不算）
- 报「源任务已超 7 天再生成窗口」→ 官方限制，只能重新生成源片

## 5. 计费对账口径（输入侧不建模）

中转账单里的**输入侧**费用（H3 输入视频 ¥0.5-0.8/秒、输入图片 ¥0.2/张；再生成输入 ¥0.3/秒；HappyHorse 仅输出计费）中，随任务提交的**参考素材（图/视频/音频）不参与平台计费**——平台按输出秒数/token 收积分（与「输出视频」价目一致）。原因：参考素材已在资产库/上传链路，平台不重复收费；个人中转账单的输入侧费用请自行在中转站核对。详见规格 §8。

## 6. 画布注意

画布视频节点的模型下拉**不出现** context-ir / regeneration 两个附属模型（附属功能依赖源任务选择器/文本结果展示，入口只在「视频生成」独立页）。画布可选全部 6 个生成模型（含 H3 与 HappyHorse 三形态）。
