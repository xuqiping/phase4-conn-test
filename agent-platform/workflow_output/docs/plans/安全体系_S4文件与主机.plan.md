## 技术实现坑点预判与规避措施

| 技术点 | 可能的坑 | 规避措施 | 验证方式 |
|---|---|---|---|
| magic number 误伤 | docx/xlsx 本质是 zip，Tika 可能检出 `application/x-tika-ooxml`/`application/zip`；mp4/mov 检出 `video/quicktime`——白名单死板比对会拦掉正常文件 | 扩展名→可接受 MIME **前缀集合**映射（zip 容器族归并）；嗅探结果三态：**危险**（PE/ELF/HTML/SVG/JS 文本特征）→ 拒；**兼容** → 放行；**未知** → 放行+计数指标（观察期后再收紧，可用性优先） | 构造 exe 改名 .png → 拒；正常 docx/png/mp4 → 过 |
| 嗅探吞流 | Tika detect 读 InputStream 会消费流，store() 再读就空了 | 嗅探用 `file.getInputStream()`（MultipartFile 每次返回新流）或 `pushback`；只读头几十字节（Tika detect 自带最小读取） | 上传后文件字节完整（大小一致） |
| 像素炸弹 | `ImageIO.read` 全量解码 10 万×10 万 PNG 直接 OOM | `createImageReader` 只 `getWidth(0)/getHeight(0)` 读头不解码；总像素 >1e8 拒（上传侧拒收话术）；读头也异常 → 按 F-2 未知放行 | 构造超大宽高 PNG 头 → 拒且进程不 OOM |
| Tika 文本膨胀 | 60MB zip bomb 解出 GB 级文本撑爆内存 | `parseToString(in, maxStringLength)` 显式上限（2,000,000 字符），截断即止不抛 | 构造高膨胀 xlsx → 截断不 OOM |
| FFmpeg native 挂死不响应 interrupt | CompletableFuture.cancel 杀不掉 native 调用，线程仍卡 | `grabber.setOption("rw_timeout", "…µs")`（IO 层超时）+ analyzeduration 限制 + 抽帧循环帧数/时长预算（防逐帧死循环）；同步调用天然不占额外线程池 | 损坏视频文件 → 有限时间内返回失败话术而非挂死 |
| 配额 N+1 | 每次上传 SUM 一次全表？ | `stored_files` 单查询 `COALESCE(SUM(size),0) WHERE owner_user_id=? AND status='ACTIVE'`，owner 维度行数有限（用户级），暂不加索引列（owner 已有索引则用）；查询异常**放行**（检测层不自残范式） | 灌 2GB 假数据 → 下一次上传 400 |
| @InjectMocks 构造注入 | FileStorageService 走手写构造器，Mockito 构造注入不填新协作者 | 配额检查用 mapper 已有字段 `storedFileMapper`（不新增协作者）；若新增可选依赖照旧 `ReflectionTestUtils.setField` | 单测真实触发拒收路径（非静默跳过） |
| 限流误伤正常上传 | 5 入口共用 `upload_file` 动作名，批量导图场景 5/60s 可能不够 | max=10/60s 起步 + 热更键 `security.rate.upload_file.max` 进 EDITABLE_KEYS；总闸 `security.rate.enabled` 可一键关 | 11 次快速传 → 第 11 次 429 |

## 功能联动点清单

- [ ] **配额→上传体验**：超配额上传 400 固定话术（含当前用量/上限）；边界：删除文件（status 变更/清理 CLEANED）后配额即时回吐（SUM 只算 ACTIVE）；管理员不豁免（同一口径）。
- [ ] **嗅探拒收→上传体验**：伪造类型 400 话术指出「文件内容与声明类型不符」；边界：未知嗅探结果**不拦**（记录计数）——上线后按指标决定收紧。
- [ ] **上传限流→批量导入**：Excel 预览/批量导图连发 429；边界：热更键可调，总闸可关；与 chat_send 同 USER 维度滑动窗。
- [ ] **抽帧超时→画布节点**：超时节点失败走既有节点错误话术（不挂死画布会话）；边界：正常短视频不受影响（预算远超常规时长）。
- [ ] **Nginx 加固→部署**：`client_max_body_size 65m` 与后端 multipart 对齐（60MB 文件+表单开销）；reload 不中断长连接。
- [ ] **K5 脚本→运维巡检**：输出 PASS/FAIL 清单退出码非零=有 FAIL；边界：脚本只读核查不改系统（人工按手册改，脚本复查）。

## 术语表

- **magic number（魔数）**：文件头部的特征字节（如 PNG 开头 `89 50 4E 47`），改扩展名骗不了字节嗅探
- **像素炸弹**：宽高天文数字的图片文件，解码时按宽×高分配内存直接打挂进程
- **zip bomb（压缩炸弹）**：极小压缩包解压后体积膨胀千万倍的恶意文件
- **配额（quota）**：单用户可占用的存储总量上限，超了拒收新上传
- **rw_timeout**：FFmpeg 的 IO 层超时参数，读数据卡住超过该时长即报错返回，不再无限等
