## 学习路径建议

**入门（1-2周）**：
1. 读 Futurum《Agentic Memory》四层模型 + LightMem CRUD-M 论文（第1类/第5类）
2. 跑 Mem0 官方教程 + DeepLearning.AI AI Agents in LangGraph 课程（第2类+第4类）
3. 读 MemGPT 论文 + Lost in the Middle 论文（第5类）

**进阶（2-4周）**：
4. 精读 Stanford/MIT/CMU 847 部署研究 + Karpathy/Hashimoto/Cherny Context Engineering 三文（第1类/第8类）
5. 读 Claude Code 五层 Compaction 工程博客 + Anthropic Memory Tool 文档（第1类）
6. 拆解 Letta 自管理分页 + Zep 时间感知 KG 仓库（第2类）
7. 跟腾讯云 / 51CTO / 即刻 记忆工程话题（第7类）

**实战（4-8周）**：
8. 用 4.1 记忆与上下文设计 Agent 设计一个真实记忆系统
9. 跑 4.2 SOP 落地四层架构 + CRUD-M + 五层 Compaction + 投毒防御
10. 配 GDPR 遗忘权全链路删除 + 记忆可观测五类指标看板
11. 持续跟踪 OpenAI / Anthropic / Mem0 / Letta 官方工程博客（第1类+第7类）

**前沿（持续）**：
12. 跟 ICLR 2026 / NeurIPS 2026 Agent Memory Track（第5类）
13. 跟 Mem0 / Letta / Zep Discord（第6类）
14. 跟 Stanford/MIT/CMU 记忆安全研究持续产出（第8类）
15. 持续跟踪记忆工程师招聘市场（第8类，PM 转型信号）
