# 4.2 RAG工程SOP + 评估模板 + 参数调优表 + 合规自查

## 一、RAG工程7步SOP（生产级落地）

[来源:RAG完整学习笔记生产级实践+曌选科技调优经验 | 🔍高 | 2026-07]

### Step 1 需求诊断（Day 0-1）
- 业务场景 / 最高QPS / 知识更新频率 / 多模态 / 合规等级
- 输出：架构决策树 + 4段需求文档

### Step 2 数据流水线（Day 1-7，重要★70%问题在这）
- 文档解析：7大工具按需选（Unstructured通用/Marker PDF/PyMuPDF高性能/Docling版式/MinerU公式表格/PaddleOCR扫描件/DeepSeek-OCR表格）
- 清洗：去页眉页脚/去重复页/正则提取结构/ OCR校对
- 元数据标注：部门/时间/权限/语言/类型/作者
- 验收：抽样100份查解析准确率 ≥95%

### Step 3 分块策略（Day 7-10）
- 按内容类型选5种策略之一（固定/递归/语义/结构/父子）
- 调参：chunk_size = 256/512/1024对比实验，chunk_overlap = 10%/15%/20%
- 验收：抽样50个case对比命中率，差20%+则换策略

### Step 4 Embedding选型（Day 10-14）
- 5维度框架选型（领域/长度/维度/语言/延迟）
- 候选：bge-large-zh-v1.5 / bge-M3 / Qwen-Embedding / Jina v3
- 微调：领域文档≥1万条可考虑微调（zero-cost提25%准确率）
- 验收：5个候选在黄金集跑Recall@10对比

### Step 5 检索重排（Day 14-21）
- 混合检索：BM25 + 向量，RRF融合
- 查询变换：Multi-Query(3-5) / HyDE / Step-Back 取舍
- Reranker：BGE-reranker-v2-m3或Qwen3-Reranker-0.6B
- 调参：topK=20-50，re_rank_top_k=3-5，min_score=0.5-0.8
- 验收：调3个重排序参数零代码提22%准确率（张钧泽经验）

### Step 6 生成策略（Day 21-25）
- LLM选型：性价比/精度/合规综合（GPT/Claude/DeepSeek/Qwen混用）
- 引用溯源：每段答案标注source_id
- 幻觉控制：temperature 0.1-0.3，faithfulness<0.9则拒答
- 上下文压缩：可选小模型先抽关键句

### Step 7 评估优化（Day 25-30+）
- RAGAS 4指标：Faithfulness / Context Precision / Context Recall / Answer Relevancy
- 黄金集：≥200条覆盖核心场景
- 12指标看板：见下节
- 回归测试：每次架构变更必跑黄金集

## 三、12参数调优表（I.20必选）

| 参数 | 起步值 | 优化方向 | 影响维度 |

## 四、RAGAS评估模板（黄金集）

```python
from ragas import evaluate
from ragas.metrics import (faithfulness, answer_relevancy,
                            context_precision, context_recall)
from datasets import Dataset

# 黄金集至少200条，覆盖核心场景
golden_set = {
    "question": [...],         # 200+个标准问题
    "answer": [...],           # RAG系统生成的答案
    "contexts": [...],         # 检索回来的上下文chunks
    "ground_truth": [...]      # 人工标注的标准答案
}

ds = Dataset.from_dict(golden_set)
result = evaluate(ds, metrics=[faithfulness, answer_relevancy,
                                context_precision, context_recall])
# 目标：4指标均≥0.8，Faithfulness≥0.9
```

## 五、上线回归测试清单（10项）

1. 黄金集4指标回归（差异<5%）
2. 压力测试（峰值QPS下P95延迟）
3. 权限元数据校验（无越权检索）
4. 多模态文档解析准确率（抽样100份）
5. 拒答场景测试（知识库无答案时正确拒答）
6. 注入攻击测试（恶意query不输出敏感内容）
7. 引用准确率测试（引用指向正确chunk）
8. 成本回归（单次Token消耗与预算对齐）
9. 灾备演练（向量库故障切换）
10. 监控告警全链路验证

## 六、5项合规自查（必做）

1. **权限元数据**：每chunk必须有部门/角色权限标签，检索前严格过滤
2. **数据出境**：境内部署 vs 国内数据，遵循GDPR/数据出境合规
3. **版权**：知识库内容是否有版权许可？引用是否构成侵权？
4. **隐私**：知识库是否含PII（个人身份信息）？是否需要脱敏？
5. **审计日志**：每次查询/引用/输出是否记录可审计？
