## 一句话定位

对标并全覆盖 OpenAI Codex 的桌面端编程智能体（**Windows + macOS 通用桌面客户端，本地执行**），**垂直差异点 = 内置一套 Spec→Plan→Implement→Run 引导式开发工作流**，把「商业分析→规格→计划→开发→验收→上线→变更」做成非程序员可无感走完的流水线，服务一人公司/独立创造者/零基础创业者。**商业模式：Token 充值转售**（接入多家模型，按量扣费赚差价），不做订阅 SaaS。

## 核心设计决策（先看这 8 条）

1. **委派优先，而非编辑器优先**：延续 Codex「描述任务→沙箱执行→审阅 diff」的异步委派心智，但把入口从「任务」升级为「项目」——用户管的是产品，不是工单。
2. **工作流即产品骨架**：`2_编程类可迭代workflow` 的 Phase 0~6 不作为文档存在，而是做成**阶段管道（Pipeline）UI**，每个 Phase = 一个用户可见的阶段关卡，审批点全部卡片化、按钮化。
3. **大白话双层呈现**：所有技术产物（PRD/diff/日志/报错）都有「翻译层」——专业人士看原文，零代码用户看翻译，一键切换。这是与 Codex 体验上的分水岭。
4. **桌面客户端为主表面**：主产品 = Win/Mac 桌面客户端（本地执行，任务跑在用户自己机器上）；**能力开放面 = CLI 指令 + `devpilot://` 深链 + MCP Server**，别的应用可用指令传参把任务委派进来；移动端监督面后置；Web 只做账号/充值门户。
5. **可生长的能力体系**：支持对话生成 Skills（把常用流程沉淀为可复用技能）、MCP 客户端接入外部工具、工作流本身也可被封装为行业技能包。
5. **信任基建三件套**：全量会话日志 + commit 存档点时间轴 + 一键回滚（吸收 Claude Code /rewind 与 Replit checkpoint 之长）。
6. **安全默认值兜底**：针对 vibe coding 事故高发区（数据库裸奔、硬编码密钥、无鉴权上线），工作流内置安全清单强制卡点，零代码用户不可绕过。
7. **成本透明**：Token 余额 + 每次任务消耗实时可见、历史明细可查，杜绝 Replit 式计费失控口碑事故（我们是卖 Token 的，透明度就是口碑）。
8. **文档分级 → 项目规模**：L0~L3 裁剪表产品化为建项目时的「规模选择」（一次性脚本/小工具/正式产品/对外产品），自动决定工作流严格度。

## 竞品速记（详表见文档 1）

- **Codex**：功能最全（云沙箱/并行/Best-of-N/多表面），但假设用户是开发者，无方法论引导。
- **Lovable/Bolt/v0**：门槛最低，但锁定技术栈、只做前端或原型，无工程严谨性。
- **Replit Agent**：引导最好（checkpoint+主动反问），但 IDE 优先、计费失控口碑差。
- **空位** = 「Codex 的工程能力 × Replit 的引导体验 × 一套真方法论」——本产品的落点。

## 工作流版本锚定（同步纪律）

- 本套设计基于 **`2_编程类可迭代workflow` v1.20**（2026-08-13 时的最新版）。
- 设计文档中所有「对应工作流 vX.X / 继承工作流 XX 机制」的标注都是**可检索的锚点**：工作流升级后，按版本号和条目名搜索即可定位所有受影响的设计条目，逐条评审修订。
- 产品实现侧：工作流以**可配置 YAML + 状态机解释执行**的方式内置于引擎（见文档 4 §4 / 文档 5 §5），阶段增减、卡点调整、话术优化都是改配置而非改代码；项目创建时绑定工作流版本，老项目不被强制升级。
