# 公共基础设施用户操作手册

> 适用版本：人工测试问题 1—4 修复完成后的桌面端。已进入 Phase 4；自动化和桌面启动通过，M8/M9、L3、E4 等真实系统交互待用户确认。

## 选择关闭行为

1. 打开“设置”。
2. 在关闭行为中选择“悬浮球”“托盘”或“退出”。
3. 关闭主窗口。

界面变化与结果：

- 悬浮球：主窗口隐藏，桌面出现一个置顶小球；单击恢复主窗口，小球自动隐藏。
- 托盘：主窗口隐藏，只保留系统托盘入口；从托盘打开后主窗口获得焦点。
- 退出：应用结束，全局快捷键和监听被释放。

## 操作悬浮球

- 拖动：按住悬浮球移动，松开后保存位置；重启会恢复，并自动校正到可见屏幕。
- 右键：可选择打开主窗口、切换到托盘或退出。
- 键盘恢复：使用应用主窗口全局快捷键恢复；恢复后悬浮球隐藏。

## 异常恢复

- 若悬浮球创建失败，应用自动降级到托盘；托盘也不可用时恢复主窗口。
- 显示器拔插后若原位置不可见，再次显示时会被校正到当前工作区。
- 双屏、缩放和显示器拔插属于 Phase 4 M8/M9、L3、E4 验收项。
