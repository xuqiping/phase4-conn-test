# 案例：Claude Computer Use——Computer Use的标杆实现

## 术语映射

| 术语 | 在本案例中的体现 |
|---|---|
| Computer Use | Claude能直接操作电脑桌面：截图→理解界面→点击/输入/滚动 |
| Tool Use | Computer Use是Tool Use的最高形态——不是调API，而是直接操作GUI |
| 自主性 | Claude Computer Use默认为L2（关键操作需确认），可配置为L3 |
| Agent Loop | 截图→分析→操作→截图→再分析，经典的Agent Loop |
| Guardrails | 限制可操作的应用范围、禁止删除文件/发送邮件等高风险操作 |

## 产品决策启示

1. **Computer Use≠万能**：可靠性低于API调用——GUI变化可能导致操作失败，适合"最后兜底"
2. **安全是头号问题**：让AI操作你的电脑=给它最大权限——Guardrails设计是核心
3. **成本极高**：每次截图+分析+操作都是一个完整的Agent Loop，Token消耗巨大
