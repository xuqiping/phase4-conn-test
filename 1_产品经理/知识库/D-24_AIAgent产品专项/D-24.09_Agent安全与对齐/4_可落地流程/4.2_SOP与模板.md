# 4.2 SOP 与模板

## SOP 1：越狱防护与注入防御

### 步骤
1. **识别注入通道**：盘点 Agent 所有外部数据源入口（用户输入/网页/文档/数据库/MCP/邮件/API），每个入口即间接注入通道
2. **OWASP Top10 排查**：对照 OWASP Top 10 for Agentic Applications 2026 逐项排查，重点 ASI01 Goal Hijacking
3. **部署三段护栏**：输入层（注入检测+指令隔离）→ 执行层（最小权限+工具审批）→ 输出层（内容审核+脱敏+外发管控）
4. **间接注入专项**：外部数据源进入 Agent 上下文前须输入层护栏清洗
5. **红队验证**：上线前红队测试验证护栏有效性
6. **持续监控**：审计追踪 + 异常告警持续运行

### 关键交付物
- OWASP Top10 排查表（模板1）
- 三段护栏配置表（模板2）

## SOP 2：自主行为约束与目标对齐

### 步骤
1. **定义目标+方式约束**：不只定义"做什么"，还要定义"不许怎么做"（不许伤害/越权/作弊）
2. **内嵌宪法原则**：将 Constitutional AI 原则写进 Agent 目标函数
3. **自我评估闭环**：Agent 执行前自检"此操作是否违反宪法原则"
4. **终止条件设阈值**：时间/步数/成本/行为/人工 五类终止条件各设阈值
5. **记忆投毒防护**：长期记忆写入前校验，读取后验证（关联 D-24.06）
6. **自进化约束**（若适用）：进化方向可控/可回滚/可审计

### 关键交付物
- 终止条件阈值表（含在模板3）
- 红队测试用例表（模板4）

## SOP 3：权限边界与最小权限

### 步骤
1. **权限盘点**：列出 Agent 所需所有权限（数据库/API/邮件/资金/文件）
2. **最小权限设计**：禁通配符，任务级动态授权（启动授权/审批/结束回收）
3. **高危操作审批**：数据库写入/资金操作/邮件发送/文件删除须 Human-in-the-Loop
4. **权限降级与熔断**：检测越权倾向立即降权，一键熔断停服
5. **审计留痕**：全量记录（谁/何时/做什么/为什么/结果）
6. **定期复核**：权限清单季度复核，清理过期权限

### 关键交付物

## SOP 4：红队测试与形式化验证

### 步骤
1. **合法授权**：红队测试须获书面授权，明确测试范围与边界
2. **用例设计**：越狱/注入/越权/目标跑偏/记忆投毒 五类用例
3. **执行测试**：按用例逐一测试，记录结果
4. **缺陷修复**：发现漏洞→修复→复测→通过
5. **形式化验证**（L4 级）：关键路径用数学证明行为合规
6. **上线准入**：第8段合规自查通过后方可上线
