## 维度树（共 23 个一级维度）

### 一、产品工作全流程（SOP 总览）
1. 产品生命周期：0-1 新品 / 1-N 成长 / 成熟维护 / 衰退下线
2. 端到端节点：需求调研→分析定义→设计评审→研发排期→测试验收→上线发布→运营迭代
3. 评审门：立项评审 / 需求评审 / 上线准入 Go-NoGo / 复盘

### 二、需求分析与管理 ⚙️（优先级放开第 4 层）
1. 需求收集：用户反馈 / 业务方老板 / 数据洞察 / 竞品市场
2. 需求分析方法：用户故事 / JTBD / 场景化 / 5W2H
3. 真伪与价值判断：伪需求识别 / 价值评估 / 来源甄别
4. 需求优先级
   - (1) KANO 模型
     - a. 基本型需求：没有就崩，满足了无感
     - b. 期望型需求：越多越好，线性提升满意度
     - c. 兴奋型需求：超出预期，惊喜感来源
     - d. 无差异型：做不做用户都无所谓
     - e. 反向型：做了反而惹用户烦
   - (2) RICE：Reach 触达 / Impact 影响 / Confidence 信心 / Effort 工作量
   - (3) MoSCoW：Must / Should / Could / Won't
   - (4) 四象限：价值 vs 成本
   - (5) ICE：Impact / Confidence / Ease
5. 需求池管理：Backlog 结构 / 状态流转 / 版本规划

### 三、用户研究与洞察（C 端为主；B 端大客户研究见「十七」）

### 十九、AI/大模型产品经理专项（新增 · v5 补全记忆/RAG/Token/LLM 局限）
1. AI 产品形态：对话式 Chatbot / 生成式 Copilot / Agent 智能体 / 嵌入式 AI
2. 提示词工程：Prompt 设计原则 / 提示框架（CO-STAR·RISEN·Few-shot）/ 上下文与记忆（详见 7）
3. 模型选型与评估：能力维度 / 评测基准（MMLU·HumanEval；记忆类 LongMemEval·LoCoMo·BEAM）/ 自研 vs API / 微调与 RAG（详见 8）
4. AI 体验设计：生成式 UI / 不确定性管理 / 反馈纠错闭环
5. AI 产品指标：质量（准确/相关/满意）/ 成本（Token·单次·缓存命中率，详见 9）/ 性能（延迟·吞吐）
6. AI 风险合规：幻觉控制（详见 10）/ 安全对齐·越狱防护 / 数据隐私 / 伦理偏见 / 训练数据版权·套壳白牌（详见 11）
7. **长期记忆系统专项**（v5 补全——直击"记忆矛盾""记忆污染"）⚙️
   - (1) 记忆分层：工作记忆（上下文窗口=内存，易丢）/ 短期会话 / 长期记忆（外部库=硬盘）
   - (2) 写入策略：抽取规约 / 写入时机（实时 vs 异步）/ 覆盖 vs 追加 / TTL 过期淘汰
   - (3) **一致性·消矛盾**：冲突检测 / 时序覆盖（新事实压旧事实，如"1 岁女儿"被"3 岁儿子"更正）/ 去重溯源 / 状态机化（矛盾本质=状态管理问题）
   - (4) **污染治理·防误用**：一次性偏好被当长期规范 / 过期规范仍生效 / 主动遗忘·记忆清洗 / 分级置信度标注
   - (5) 检索召回：相关性排序 / 记忆条数上限 / 召回不全致"失忆"
   - (6) 记忆安全：记忆注入攻击（诱导写入伪造事实）/ 隐私泄露（记忆含 PII）/ 跨会话·跨用户隔离
   - (7) 评测基准：LongMemEval / LoCoMo / BEAM；治理框架 SSGM（稳定性+安全）
8. **RAG 检索增强专项**（v5 补全——直击"匹配度差""越问越错"）⚙️
   - (1) 分块 Chunking：定长切（碎义）/ 语义切（保义但慢）/ 递归切 / 父子块·滑动窗口
   - (2) **嵌入漂移 Embedding Drift**：换模型/数据分布变→旧向量失效（沉默杀手）→ 需全量重嵌入
   - (3) **匹配度**：语义相似≠真相关 / 关键词 vs 向量权衡 / 混合检索（向量+BM25）+ 重排 Rerank
   - (4) **Lost-in-the-Middle**：长上下文中段被忽略（位置偏置）→ 关键信息置首尾 / 重排前置
   - (5) 检索评估：召回率·精确率 / 上下文命中率 / RAGAS（faithfulness·answer-relevancy）
   - (6) 调试监控：端到端难调（"比想象难 10 倍"）/ 分阶段埋点·可观测
   - (7) 进阶架构：GraphRAG / Agentic RAG / Self-RAG / 多跳检索
9. **Token 消耗与成本优化专项**（v5 补全——直击"贵"）⚙️
   - (1) **缓存**：前缀/Prompt 缓存（复用 KV，省 41–90%）/ 语义缓存（相似问复用，省达 73%）
   - (2) 上下文工程：压缩·摘要 / 精准裁剪 / 智能装配（省 40–60%）
   - (3) 模型分级路由：简单走小模型·复杂走大模型 / 输出长度约束
   - (4) Prompt 瘦身：去冗余 / 少 few-shot / 结构化模板
   - (5) 运行时状态保持：跨轮复用 KV（状态当 runtime，勿反复重发整段历史）
10. **LLM 固有局限**（v5 补全——直击"其他大模型问题"）⚙️
   - (1) 幻觉：训练数据稀疏/矛盾致编造 / 上下文致幻（注意力衰减·位置编码漂移）
   - (2) **长上下文失效**：Context Rot（上下文腐烂）/ MECW 有效窗口远小于标称 → 越长越笨
   - (3) 推理错误：长上下文注意力衰减 / 多步推理累积误差 / 知识截止时效
   - (4) **模型漂移 Model Drift**：版本升级致输出变化 / 回归风险 / 上线前灰度对比·评测门禁
   - (5) 知识时效：训练截止日 / 时效敏感场景需 RAG 外挂补
11. **AI 灰度/擦边与合规**（⚠️ 挂合规自查——维度表灰度覆盖偏好）⚙️
   - (1) 训练数据来源：抓取·版权·授权（AIGC 侵权，⚠️ 合规自查）
   - (2) 套壳/白牌：API 套壳冒充自研（虚假宣传风险，⚠️ 合规自查）
   - (3) 换脸·克隆·Deepfake：肖像权·诈骗（⚠️ 合规自查）
   - (4) 生成内容擦边：色情·暴力·政治·意识形态红线（⚠️ 合规自查）
