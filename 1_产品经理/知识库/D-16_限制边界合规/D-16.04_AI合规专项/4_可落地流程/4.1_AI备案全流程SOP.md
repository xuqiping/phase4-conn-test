# 4.1 AI备案全流程SOP

## 适用场景

AI产品上线前的算法备案/大模型备案/API登记路径选择与执行。

## Step 1：备案路径判定决策树

```
产品是否提供生成式AI服务（含对话/生成/推荐/排序/检索/调度）？
├─ 否 → 不适用本SOP
└─ 是 → 
    是否自研大模型（非调用第三方API）？
    ├─ 是 → 【大模型备案】+【算法备案】（两者都需）
    │   └─ 模型有舆论属性或社会动员能力？
    │       ├─ 是 → 须通过安全评估后才能上线
    │       └─ 否 → 备案后上线
    ├─ 否（调用已备案模型API）→ 【API调用登记】（地方网信办）+【算法备案】（如涉及推荐/排序等）
    └─ 微调已备案模型 → ⚠️待核实（视微调深度，建议咨询网信办）
```

## Step 2：算法备案执行清单

### 材料准备

| # | 材料 | 说明 | 预计工时 |
|---|---|---|---|
| 1 | 算法备案系统账号注册 | 互联网信息服务算法备案系统 | 1天 |
| 2 | 算法基本信息表 | 名称/类型(五大场景)/用途/URL | 2天 |
| 3 | 算法安全自评估报告 | 核心文档，见下方模板要点 | 2-3周 |
| 4 | 算法机制说明 | 算法原理/数据输入输出逻辑 | 1周 |
| 5 | 算法模型说明 | 模型类型/训练数据概要 | 1周 |
| 6 | 用户权益保护方案 | 透明度/选择权/未成年人保护 | 1周 |

### 算法安全自评估报告模板要点

```
1. 算法基本概况
   - 算法名称、类型、应用场景、上线时间
   - 服务对象、日活/月活规模

2. 算法机制说明
   - 输入数据类型与来源
   - 算法处理逻辑（推荐逻辑/生成逻辑/排序逻辑）
   - 输出结果形式

3. 安全风险评估
   - 信息内容安全风险（是否可能生成违法内容）
   - 算法偏见风险（是否存在歧视性输出）
   - 用户权益侵害风险（是否侵害选择权/知情权）
   - 数据安全风险（数据泄露/滥用风险）

4. 风险应对措施
   - 内容过滤机制
   - 算法审计与纠偏
   - 用户反馈与申诉渠道
   - 应急处置预案

5. 未成年人保护
   - 年龄识别机制
   - 内容分级过滤
   - 使用时长限制
```

## Step 4：API调用登记执行清单

| # | 步骤 | 说明 |
|---|---|---|
| 1 | 确认调用的模型已备案 | 查网信办公示名单 |
| 2 | 准备登记材料 | 应用场景说明+调用模型备案号+内容安全措施+用户保护 |
| 3 | 向地方网信办提交 | 省级网信办 |
| 4 | 等待审核 | 通常2-4周 |

## Step 5：被驳回应对

| 驳回原因 | 应对措施 |
|---|---|
| 安全评估报告不充分 | 补充测试数据、增加评估维度 |
| 训练数据来源不明 | 补充数据来源证明和版权授权文件 |
| 内容过滤机制不足 | 增加多级过滤、接入第三方内容安全API |
| 用户保护措施缺失 | 补充未成年人保护、投诉举报渠道设计 |
| 算法机制描述不清 | 重写算法说明，增加流程图和数据流图 |
