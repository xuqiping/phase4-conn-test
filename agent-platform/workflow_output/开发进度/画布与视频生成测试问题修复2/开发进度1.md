### Chunk A · @ 引用体验（2.1）✅（A1 标记受限）
测绘发现 A 的核心修复**前序会话已落未提交**，本轮验证 + 收尾：
- **A2「输入一段话后 @ 弹不出」**：根因 = `detectAnchor` 邮箱启发式过激（@ 前字符 ∈ `[A-Za-z0-9]` 即判邮箱拒）。已落修复：改为「@ 前一字符须**非**字母数字」（拦 `foo@bar`，放行中文句末/标点后）。[MentionTextarea.vue:135-140](../../../frontend/src/components/canvas/MentionTextarea.vue#L135-L140) + 单测「中文句末无空格 @ 也唤起」。
- **「@文本不起效果」**：根因 = 运行期 resolver 原仅取 text 节点 `outputText`，没跑过的文本节点 @ 出来是断链。已落修复：回落 `prompt`（用户输入文本）。[CanvasView.vue:318-322](../../../frontend/src/views/CanvasView.vue#L318-L322) buildMentionResolver。
- **A1「chip 丑 / 应显节点名」⚠️ 设计受限**：C4 镜像层要求 mirror 文本 === textarea 文本（蓝底对齐）；textarea 显原始 token `@{{node:id}}`（id 非 label，重命名不断链，[MentionTextarea.vue:6](../../../frontend/src/components/canvas/MentionTextarea.vue#L6) 注释）。mirror 显 label 会让蓝底宽度 ≠ 可见 token → 部分高亮更丑。**纯 textarea 架构下不可行**，真 label-chip 需 contenteditable 重设计（独立大 chunk，本轮不做）。蓝 chip 已给视觉区分，"有点丑"为次要。
- **测试**：[MentionTextarea.test.ts](../../../frontend/src/components/canvas/MentionTextarea.test.ts) **15/15 绿**（含新增中文句末用例）；vue-tsc 净。
- **commit**：`467020af`
