## 设计要点

- **门控对齐后端**：前端 `personalMode` 排除 OWNER（owner 旁路）；抽屉 `canOperateThis` 对 NULL createdBy fail-closed（与后端 requireAssetOperate 同语义）；真实权限仍由 API 403 兜底。
- **canScore 三态**：OWNER 恒 true（独立轨）；EDITOR 随项目开关（均分轨）；VIEWER/公共 false——全部在视图层 computed 一处计算，抽屉只收布尔。
- **评分区可见性**：有任一轨评分即展示聚合行；打分表单仅 canScore；无分且不可评→整区不渲染。
- **评分拉取容错**：loadScore 内部 catch，失败不阻塞详情加载（空态展示）。
- **设置弹窗草稿隔离**：每次打开重建 draft（watch show+immediate）；取消不污染；无变更不发请求。

## 踩坑

- **watch 缺 immediate**：弹窗测试直接 show=true 挂载，`watch(()=>props.show)` 不触发→草稿未同步。凡「打开时初始化」的 watch 必带 `immediate: true`。
- **teleport 残留**：happy-dom 无 auto-unmount setup，n-drawer 内容跨测试残留 document.body→「不存在」断言用**增量计数**（挂载前后 .asset-detail__actions 数量不变），不能全文查找。
- **n-slider 类型**：value 不接受 null（TS2322）→ `:value="draft ?? 50"` + 显式 `@update:value`。
