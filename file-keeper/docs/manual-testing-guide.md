# File Keeper 手动测试指南

**测试版本**: v0.1.0  
**测试日期**: 2026-05-25  
**测试平台**: Windows 10/11 (64-bit)  
**测试分支**: file-close

---

## 📋 测试概述

本文档包含 File Keeper 应用管理功能的完整手动测试清单。请按照以下步骤逐项测试，并记录测试结果。

### 测试环境准备

1. **启动应用程序**
   - 运行 `npm run tauri dev` 启动开发服务器
   - 等待应用程序窗口打开
   - 确认应用正常启动，无错误提示

2. **打开开发者工具**
   - 按 F12 打开浏览器开发者工具
   - 切换到 Console 标签页，查看性能日志
   - 切换到 Performance 标签页，准备录制性能数据

3. **准备测试环境**
   - 打开多个不同类型的应用程序（浏览器、办公软件、媒体播放器等）
   - 确保系统中有 50+ 个运行中的进程
