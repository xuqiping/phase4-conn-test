## 本轮关键决策与变更

- **MaskingAppender 取代 %mask converter**（plan 偏离①）：事件层装饰（同 AsyncAppender 模式），一条代码路径覆盖 console 文本 + LogstashEncoder JSON + SQL 通道；converter 对 JSON encoder 不生效需双机制，易回潮。
- **MdcUserFilter 不 MDC.clear()**：finally 只 remove 自身 3 key，防抹掉 micrometer traceId 作用域；防串号靠「只清自身 + 每请求覆盖写」。
- **V77 全字段 audit_logs 超集**：覆盖安全体系 S1 计划的最小 audit_logs 表——**S1 plan 须改：迁移号 V80+、复用本表不再自建**。
- **CompositeTaskDecorator**：ThreadPoolTaskExecutor 只收一个 decorator，组合 MDC + BillingContext 两个；裸 ExecutorService 走 `MdcContextTaskDecorator.wrap()`。
- **SQL 通道免登记**：mybatis-plus `log-prefix: sql.` → 单 logback logger 覆盖全部现状/未来 mapper 包。
- **顺手修复预存坏测试**：AuthServiceTest.login_success 缺 departmentService mock 的 NPE（基线 61bac85 即红），补 mock 后转绿。
- **已知预存红（非本次引入，基线对拍确认）**：RuntimeCallbackSecurityTest 401、RagRetrievalServiceTest UnnecessaryStubbing —— 待各自 owner 修。
