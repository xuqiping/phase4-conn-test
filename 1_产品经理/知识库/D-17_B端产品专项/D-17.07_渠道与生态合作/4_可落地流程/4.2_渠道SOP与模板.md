# 4.2 渠道SOP与模板

## SOP-1：渠道选型评估流程

| 步骤 | 动作 | 负责人 | 产出 |
|---|---|---|---|
| 1 | 填写产品可渠道化评估表（标准化/可演示/可集成/可交付4维评分） | PM | 评估表 |
| 2 | 计算可渠道化总分，判定是否适合建渠道 | PM+渠道总监 | 评估结论 |
| 3 | 如适合，填写渠道选型矩阵（客单价×交付复杂度→推荐渠道类型） | 渠道总监 | 渠道选型报告 |
| 4 | 渠道Economics测算（返佣+MDF+赋能成本 vs 预期渠道收入） | PM+财务 | Economics模型 |
| 5 | 渠道总监+PM联合评审 → Go/No-Go决策 | 渠道总监+PM | 决策纪要 |

### 模板：产品可渠道化评估表

| 评估维度 | 评分项 | 0分 | 5分 | 10分 | 得分 |
|---|---|---|---|---|---|
| 标准化程度 | 配置化率 | <30% | 30-70% | >80% | |
| 标准化程度 | 交付SOP | 无 | 有但粗 | 有且细 | |
| 可演示性 | 远程Demo | 不可 | 需定制环境 | 开箱即Demo | |
| 可演示性 | 试用 | 不可 | 申请后可 | 自助试用 | |
| 可集成性 | 开放API | 无 | 部分开放 | 完整SDK+文档 | |
| 可集成性 | ISV集成认证 | 无 | 概念阶段 | 有认证体系 | |
| 可交付性 | 伙伴可独立交付 | 不可 | 需厂商协助 | 伙伴独立交付 | |
| 可交付性 | 交付文档 | 无 | 有基础文档 | 有完整实施手册 | |
| **总分** | | | | | **/80** |

> 60分以上适合建渠道；40-60分需先做标准化改造；40分以下不适合建渠道。

## SOP-2：合作伙伴招募流程

| 步骤 | 动作 | 周期 | 产出 |
|---|---|---|---|
| 1 | 目标伙伴画像（行业/规模/能力要求/区域） | 1周 | 伙伴画像文档 |
| 2 | 定向邀请（行业活动/推荐/LinkedIn/渠道门户公开招募） | 2-4周 | 意向名单 |
| 3 | 资质审核（营业执照/技术能力/客户资源/竞品冲突） | 1周 | 审核结果 |
| 4 | 签署合作协议（PSP条款/保密协议/返佣协议） | 1-2周 | 签约协议 |
| 5 | 入驻赋能（产品培训+认证+门户开通+首单陪跑） | 2-4周 | 认证证书+首个商机 |

## SOP-3：Deal Registration报备流程

| 步骤 | 动作 | 时效 | 规则 |
|---|---|---|---|
| 1 | 伙伴在门户提交报备（客户名/联系人/商机阶段/接触记录） | T+0 | 需有实质性接触证据 |
| 2 | 系统自动查重（同一客户是否已有报备/直销跟进） | T+1h | 有冲突则进入仲裁 |
| 3 | 渠道经理审核（真实性+资质匹配） | T+24h | 审核通过则锁定保护期 |
| 4 | 保护期生效（90天内厂商和其他伙伴不得竞争） | 90天 | 到期未成交自动释放 |
| 5 | 成交结算（报备伙伴获返佣）或释放（到期未成交可续报备1次） | 成交后 | 续报备需说明延期理由 |

## SOP-4：Co-sell联合打单流程

| 步骤 | 动作 | 负责方 | 产出 |
|---|---|---|---|
| 1 | Co-sell商机评估（客单价>10万？需联合方案？） | 渠道经理 | 商机评估表 |
| 2 | 确认Co-sell模式（线索共享/联合方案/联合交付/平台Co-sell） | 渠道经理+PM | 模式确认书 |
| 3 | 联合方案设计（厂商SE+伙伴SE联合产出） | 厂商SE+伙伴SE | 联合解决方案 |
| 4 | 联合述标（分工：厂商讲产品+伙伴讲行业方案） | 厂商+伙伴 | 述标分工表 |
| 5 | 商务谈判（签约主体+分佣比例确认） | 渠道总监 | 合同+分佣协议 |
| 6 | 联合交付（产品交付+实施交付） | 厂商+伙伴 | 交付验收 |
| 7 | 收益结算（按分佣比例结算） | 财务 | 结算确认书 |
