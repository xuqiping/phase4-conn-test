## 关键设计决策

- **占位符本体存 node id，非 label**（设计 §十三硬约束 + L8）：`@{{node:n1}}`，重命名只改 label 不动占位符；label 唯一性仅服务 @选择器与手输场景的人脑消歧（选择器显 label、插 id）。
- **祖先链硬约束**（设计 §十三）：@候选 = 反向 BFS 沿 edges 的祖先集（直接上游+上游的上游，传递闭包）。无连线可达不出现在选择器。资产库资产不受此限（非节点），但 MVP 选择器仅列祖先节点（asset 占位符引擎支持，运行期不预解析，Phase4 评估）。
- **不递归**（plan 踩坑预判）：`interpolate` 注入的是上游已物化产出，返回串里的 @占位符不再二次解析——防 `A@B、B 内含 @` 递归死循环。
- **环画布选择器为空**：成环时祖先集虽可构造（环内互为祖先），但画布现有重跑前 Kahn 环检测会先报错；且 `ancestors` 的 visited 集合保证 BFS 不死循环。候选为空时显「无可引用祖先节点（无连线可达/画布成环）」。
- **断链灰显三态同源**（L7/L8 + 设计关键决策 3）：`findBrokenMentions` 一套检测驱动两处呈现——属性面板黄色 warn（运行前可见）+ 运行时 message.warning（断链处降级「【断链】」注入，不级联失败）。
- **运行前插值不污染原文**：`interpolateForRun` 返 `{...node.data}` 拷贝，仅 payload 走插值；node.data.prompt/synopsis 保留 `@{{...}}` 占位符持久化（重跑/下次运行重新解析最新产出）。
- **响应式祖先集无需手动 tick**：computed 内调 `boardRef.getEdges()`，其实现 `return edges.value`——`.value` 读取被 Vue 追踪，CanvasBoard 内 `edges.value` 增删自动触发 computed 重算。
- **重命名查重契约（按 id 剔除自身，非按值）**：`onRenameBlur` 第一版按值过滤误删他节点同名导致漏判，改为父组件传 `otherLabels`（按节点 id 剔除 selectedNode），组件直接用不再过滤。
- **MentionTextarea 用原生 textarea 非 n-input**：需 `selectionStart`/`setSelectionRange` 精准定位光标做 @唤起 + 中段插入；n-input 不暴露光标 API。
- **L9 三入口分工**：新建/粘贴 → `CanvasBoard.addNode` 去重；重命名 → `PropertyPanel.onRenameBlur` 去重；旧快照载入幂等修正（L9 第三项）留 Phase4（loadSnapshot 时跑一遍 uniqueLabel 批修正历史重名）。
