## 板块 B · 学谁 — 业内顶尖人士对标图谱

### 1. Clayton Christensen（克莱顿·克里斯坦森）

| 维度 | 内容 |
|---|---|
| 身份 | 哈佛商学院教授 |
| 国籍 | 美国 |
| 核心成就 | 提出"破坏性创新"理论，著《The Innovator's Dilemma》；解释成熟期巨头为何被颠覆 |
| 思维模型 | **破坏性创新思维**：不从正面硬刚，找"低端/新兴"市场缝隙切入；成熟期公司理性决策反而导致失败 |
| 行动范式 | 学术严谨+商业实践并重；理论先行→案例验证→推广传播；用"理论→反例→修正"迭代 |
| 可学习点 | 不要只看"当前做得好"——成熟期利润是衰退期的麻醉剂；寻找被忽视的底层创新信号 |
| 代表作 | 《The Innovator's Dilemma》《The Innovator's Solution》 |
| 来源 | 🔍高 |

### 2. Geoffrey Moore（杰弗里·摩尔）

| 维度 | 内容 |
|---|---|
| 身份 | 科技战略顾问/作家 |
| 国籍 | 美国 |
| 核心成就 | 提出"技术采纳生命周期"与"跨越鸿沟"框架；将PLC导入→成长细化为"创新者→鸿沟→早期多数→晚期多数" |
| 思维模型 | **鸿沟思维**：从早期采纳者到早期多数之间存在不可忽视的鸿沟，跨越需要垂直聚焦→建立标杆→横向扩展 |
| 行动范式 | 咨询驱动写作——每个框架先在客户中验证再写书；简洁模型+丰富案例 |
| 可学习点 | 导入期通过鸿沟≠长大；"聚焦一个垂直市场先赢"是鸿沟跨越的核心策略 |
| 代表作 | 《Crossing the Chasm》《Zone to Win》 |
| 来源 | 🔍高 |

### 3. Reed Hastings

| 维度 | 内容 |
|---|---|
| 身份 | Netflix联合创始人/CEO |
| 国籍 | 美国 |
| 核心成就 | 两次跨越第二曲线（DVD→流媒体→原创），带领Netflix从创业公司到全球最大流媒体 |
| 思维模型 | **第二曲线投资思维**：在利润高点做最大胆的投资；不等待衰退信号，用前瞻布局代替被动防守 |
| 行动范式 | 极端透明管理(No Rules Rules)+数据驱动决策；快试快错，不纠结 |
| 可学习点 | 成熟期的利润不是"赚到"的，而是"用来投资第二曲线"的；管理文化决定转型速度 |
| 代表作 | 《No Rules Rules》(合著)/Netflix公开文化手册 |
| 来源 | 🔍高 |

### 4. Ben Thompson

| 维度 | 内容 |
|---|---|
| 身份 | Stratechery创始人/科技战略分析师 |
| 国籍 | 美国(居台湾) |
| 核心成就 | 创建Stratechery（全球最具影响力的独立科技分析之一），提出聚合理论(Aggregation Theory) |
| 思维模型 | **聚合理论思维**：互联网改变价值链结构，平台聚合者(如Google/Facebook)在分发层获取价值——PLC框架需叠加"平台逻辑"才能解释 |
| 行动范式 | 每日深度分析+付费订阅模式；不追逐热点，用框架解释本质；独立思考不逢迎 |
| 可学习点 | 传统PLC需要结合平台效应修正——平台型产品可能"永续成长"不衰退；理解聚合逻辑才能判断产品终局 |
| 代表作 | Stratechery博客/Dithering播客 |
| 来源 | 🔍高 |

### 5. Marty Cagan

| 维度 | 内容 |
|---|---|
| 身份 | SVPG创始人/产品管理顾问 |
| 国籍 | 美国 |
| 核心成就 | 著《Inspired》，定义了现代产品管理实践框架；指导Google/Apple/Amazon等大厂产品团队 |
| 思维模型 | **产品发现思维**：导入期核心不是"交付功能"而是"发现值得解决的问题"；PMF验证需要产品设计→原型→测试的闭环 |
| 行动范式 | 实战经验+方法论整合；每个观点都有真实公司案例支撑；强调"产品团队"而非"项目团队" |
| 可学习点 | 导入期PM的职责是"发现"不是"执行"；验证PMF需要勇气砍掉不成立的方向 |
| 代表作 | 《Inspired》《Empowered》 |
| 来源 | 🔍高 |
