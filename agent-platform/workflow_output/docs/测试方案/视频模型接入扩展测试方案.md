## 二、功能联动用例（对齐 plan 联动清单 6 条）

| # | 触发→联动 | 验证点（含边界/反向/批量） |
|---|---|---|
| L1 | llm_providers 加行+models | 正向：H2/H5/H6 后画布+独立页下拉出现新模型、价表候选出现；反向：删 models→模型不可达；批量：一渠道多模型互不影响 |

| L3 | SECOND 槽配值→完工扣费 | 正向：H5/H6 金额按档；未配档：提交未配分辨率→通用秒价；反向：清槽保存→回落通用；脏 JSON（手工 UPDATE 库）→WARN 回落不炸结算 |
| L4 | fast/mini 能力修正 | 正向：H2 面板只 480p/720p；边界：旧画布节点存了 1080p 草稿→提交后端 validate 拒（话术可读），前端切模型收敛 |
