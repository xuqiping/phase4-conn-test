# 影响评估 · 资产库公众池与价表模型选择

> Phase 6 产物。依据 2026-08-10 人工测试记录与已批准设计。

## 变更概要

- **变更类型**：修改 + 增加
- **变更目标**：修复资产授权 403；增加项目级公众池、申请审批与复制；价表改为选择未配置的全局模型。
- **变更原因**：人工测试确认现有授权入口不可用于普通 OWNER，且公众池和价表模型约束尚未实现。
- **变更规模**：大（资产权限、数据库、前后端页面及计费配置跨模块）。

## 引用点排查

| 被改对象 | 类型 | 主要引用位置 | 结论 |
|---|---|---|---|
| `AssetAclService.loadAccessible` | 权限咽喉 | 所有资产项目、资产、版本、画布桥接端点 | 可扩展公共只读判定；必须回归 OWNER/EDITOR/VIEWER/admin |
| `AssetProjectService.list/get/toVO` | 服务/DTO | 资产列表页、项目页、AssetPicker | 增加公共摘要与发布字段时需防未审批内容泄漏 |
| `asset_project_members` | 表/授权 | 成员邀请、共享给我、ACL | 保持不变；公共申请使用独立表，避免语义混淆 |
| `ShareDialog` + `/api/users` | 页面/接口 | 项目成员管理 | 停用此处管理员接口依赖，改资产域最小用户搜索 |
| `PricingConfigService` | 计费配置 | 价表 CRUD、`PricingService` 询价 | 新增候选与创建校验；历史询价逻辑不改 |
| `PricingConfigView` | 管理页面 | 新增/编辑价表 | 新增时改下拉，编辑时锁定模型身份 |

## 数据库影响

- 涉及 `asset_projects` 新增发布字段和新表 `asset_public_access_requests`。
- 只增加新的 Flyway 版本；不修改 V56-V60、V65-V66 等已执行迁移。
- 旧项目默认私有，旧数据无需回填；申请表初始为空。

## 功能联动点

- 项目转让不改变既有发布者标记；新 OWNER 接管审批权。
- 项目删除或移出公众池后公共访问失效，成员直接授权仍按原规则。
- `OPEN↔APPROVAL_REQUIRED` 切换即时改变未获批用户访问；获批记录仅在项目仍公开时有效。
- 公共引用继续遵守版本快照；公共复制生成目标项目独立资产。
- 供应商启停影响新增候选，不删除历史价表，不改变历史账单。

## 运维考量

- 保留现有资产拒绝访问日志；新增发布、申请、审批、撤销、复制审计日志。
- 不改变服务端口、健康检查和部署方式。
- 新迁移失败可阻止启动，需在上线前真 PostgreSQL 验证约束和索引。

## 回滚锚点

- 变更前 commit：`a0b67cf4157b792fea4833c018806b6e53b44a55`
- 回滚方式：对实现 commit 执行 `git revert` 并部署旧版本；新增数据库结构由旧代码忽略。不得修改已执行迁移。

## 废弃判断

- 不删除公开 API；`/api/users` 保持原管理用途和权限，只移除 ShareDialog 对它的依赖。
