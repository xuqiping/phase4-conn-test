## 反AI平庸设计Prompt模板

### 模板结构（五段式）

```
## 1. 任务定义
你是一个[产品类型]的UI设计师。设计一个[页面名称]，服务于[目标用户]实现[核心目标]。

## 2. 风格约束（关键·防同质化）
- 品牌主色: [具体色值]，不是默认蓝色
- 风格参考: [具体品牌/设计风格]，不要通用SaaS模板风格
- 排版: [具体排版风格]
- 禁止: 渐变背景 / 3D效果 / 过度圆角 / AI典型蓝紫色调

## 3. 设计系统约束
- 间距基数: 4px
- 圆角: 按钮8px / 卡片12px / 弹窗16px
- 字体: [具体字体+字号梯度]
- 品牌-icon风格: [outlined/filled/dual-tone]

## 4. 内容与交互
- 页面包含: [具体内容区块]
- 核心交互: [主要操作流程]
- 响应式: [断点要求]

## 5. 输出要求
- 格式: [Figma文件 / React代码 / 截图]
- 暗色模式: 是/否
- 可交付标准: 符合Design System + 可交互
```

### 关键反平庸策略

| 策略 | Prompt写法 | 效果 |
|---|---|---|
| 色彩锚定 | "品牌主色#E63946，不是蓝色，永远不用蓝色" | 打破AI默认蓝调 |
| 风格锚定 | "风格参考:Aesop官网的极简质感，非Vercel风" | 指定品牌参照 |
| 负向约束 | "禁止:渐变/3D/过度圆角/模板化Hero区" | 排除高频AI套路 |
| 品牌动词 | "品牌动词:激发/温暖/可靠，非冷酷/科技/未来" | 语义层面约束AI输出 |
| 差异化要求 | "与竞品[名称]的视觉差异要≥3处明显区别" | 强制差异化 |
