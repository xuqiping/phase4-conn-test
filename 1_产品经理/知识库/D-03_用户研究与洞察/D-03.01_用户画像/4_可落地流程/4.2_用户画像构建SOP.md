# 用户画像构建 SOP

## 适用场景
- 新产品启动、用户认知空白期
- 已有产品用户变化大、需重新画像
- 产品转型/新市场进入，用户群体变更

## 6步流程

### Step 1：确立画像目标（1天）

| 动作 | 说明 |
|---|---|
| 明确决策场景 | "画像要帮我们回答什么问题？"（如：要不要做社交功能？定价策略怎么定？） |
| 确定画像类型 | 定性画像（共识+设计输入）/ 定量画像（运营+推荐输入）/ 混合 |
| 划定画像范围 | 核心用户 vs 边缘用户；新用户 vs 老用户；付费 vs 免费 |

### Step 2：数据采集（1~2周）

| 数据类型 | 采集方法 | 最低要求 |
|---|---|---|
| 定性数据 | 深度访谈5~8人 + 可用性测试3~5人 | 详见 D-03.02 研究方法 |
| 定量数据 | 行为日志(≥30天) + 问卷(≥100份) | 详见 D-06.02 数据采集 |
| 竞品/行业 | 竞品用户评论 + 行业报告 | 补充视角，不作为主数据源 |

### Step 3：行为变量提炼与映射（2~3天）

1. 从定性数据中提炼8~12个行为变量（如：目标类型/信息获取方式/决策速度/社交依赖度）
2. 将每位被访者映射到变量空间（高/中/低 或 存在/不存在）
3. 识别模式聚类——2~3人行为模式高度相似 = 候选Persona

### Step 4：Persona构建（2~3天）

每个Persona填7要素+3层目标模板：

```
【Persona名称】李敏
【身份】28岁 / 杭州 / 新媒体运营 / 月薪12K
【场景与目标】
  - 场景：午休+下班后刷手机找灵感，工作中需快速找素材
  - 最终目标：3分钟内找到可用素材或好物推荐
  - 体验目标：不想被无关内容打扰，快速获得"我想要的"
  - 生活目标：成为朋友圈里"会挑好东西"的人
【行为模式】先小红书种草→淘宝比价→知乎看测评→下单
【痛点】①推荐总是推已买过的 ②搜索结果太泛 ③比价信息分散
【引用语】"我只想找适合我的，不是最火的"
【约束】手机为主 / 碎片时间 / 预算敏感但不是最低价
【关联决策】①推荐算法需"去重复" ②搜索需支持场景化意图
```

### Step 5：标签体系设计（3~5天，仅定量画像）

1. 梳理业务需要的画像维度（从Persona特征反推）
2. 按L1/L2/L3分层设计标签
3. 定义每个标签的计算逻辑、数据源、更新频率、有效期
4. 建立标签治理规则（评审/盘点/衰减/权限）

### Step 6：验证与迭代（持续）

| 验证方式 | 频率 | 方法 |
|---|---|---|
| 团队验证 | Persona完成后立即 | 拿Persona问3位未参与访谈的同事"你认识这样的人吗" |
| 用户验证 | 每季度 | 找新用户验证Persona特征是否仍成立 |
| 数据验证 | 每月（定量） | 标签覆盖率/准确率/区分度自动化监控 |
| 假设验证 | 按优先级 | 对"⚠️假设待验证"项安排专门调研 |

### 常见卡点与解法

| 卡点 | 解法 |
|---|---|
| 访谈约不到人 | 用问卷先行筛+用奖励+利用社区/私域 |
| 定性定量的Persona不一致 | 先定性→校准定量分群维度→定量反哺定性细节 |
| 画像做完没人用 | 构建时拉研发/设计参与；用"角色扮演"会议拉共鸣 |
| 标签太多管不过来 | 初始只做核心20个标签，用MVP思路迭代 |
