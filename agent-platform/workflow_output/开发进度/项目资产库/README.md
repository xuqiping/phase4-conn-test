## 这是什么

把创作中反复用的**提示词 / 剧本 / 图片 / 视频 / 音频**五类资产，按「类型 × 叙事角色（人物/道具/场景/风格/通用）」双轴归档进**项目**，配**版本快照**（引用锁某版不被新版冲掉）和**一致性包**（角色定妆档案），再打通无限画布——节点产出能**入库**，画布能**从库引用**，节点之间还能用 **@** 互引上游产出。

## 谁用 · 场景 · 效益

| 角色 | 场景 | 效益 |
|---|---|---|
| 创作者（OWNER/EDITOR） | 给角色建「人物」资产，攒主参考图+三视图+标准描述 | 一致性包注入生成保形象不变，不用每次重贴 |
| 创作者 | 在画布 A 产了一张满意的图 → 右键入库 | 画布 B 直接从库引用，v2 升版后旧引用不被冲掉 |
| 创作者 | 文本节点扩写时 `@` 引用上游节点产出 | 跨节点复用不用手动复制粘贴；改上游重跑自动带最新产出 |
| 团队成员（VIEWER） | 被 owner 邀请进项目只读参考 | 可引用资产到自己的画布，但不能改项目资产 |
| 管理员 | `asset:write` seed gated 控入口 | 无权者菜单/路由/API 三层兜底拒访 |

## 核心概念（生活化）

- **双轴矩阵**：Excel 行(类型)列(角色)交叉——「图片×人物」=所有人物图。
- **版本快照**：引用时锁定当时那一版，资产升 v3 不影响已引用 v2 的内容（画布引用存版本号）。
- **一致性包**：一个角色的「定妆档案」——主参考图 + 图集 + 标准描述 + 参数基线，生成时整套注入保形象不变（老板娘=主图+三视图+标准描述）。
- **PRODUCED/REFERENCE 绑定**：资产详情「使用记录」=这件资产产自哪个画布节点(PRODUCED)、被哪些节点引用(REFERENCE)，双向追溯台账。
- **@引用祖先链**：`@` 只能引用经连线可达的上游节点（反向 BFS）；占位符存节点 id（重命名不断链），运行前插值注入上游产出，**不递归**。

## 技术说明（简）

- **后端**：独立 `asset` 包（`com.superprogrammer.asset`），Flyway V56–V59 六表全新建。单向只读依赖 `CanvasService.loadOwned`，canvas 包不反向依赖（保画布零回归）。权限咽喉点 `AssetAclService.loadAccessible` 三判（owner/member/admin）+ 全端点 `@RequirePermission("asset:write")`。
- **前端**：`components/asset/`（资产库页面）+ 画布打通散落 `components/canvas/`（SaveToAssetDialog/AssetPicker/MentionTextarea）。`utils/interpolate.ts` 统一 @引用引擎。
- **性能**：角色筛选走 `asset_role_links` 关系表（不查 JSONB）；列表 `IN` 批查防 N+1；计数一条 `GROUP BY` 聚合；版本 content 懒加载。
- **质量**：后端 72/72 单测；前端 vue-tsc 绿 + vitest 194/194。

## 功能联动（L1–L10，详见 plan）

- **L1** 移除成员→其「共享给我」列表项目消失（其画布已引用快照不受影响）
- **L2** 资产定稿(LOCK)→画布引用锁定当前版（新版不影响）
- **L4** 删除项目→全级联软删（stored_files 保留，画布引用快照不受影响）
- **L5** 节点入库→矩阵计数+1 + 落 PRODUCED 绑定（已有 PRODUCED → 默认存新版本）
- **L6** 库→画布引用→节点显「来自资产·name vN」；升版后徽标「有新版」（手动更新）
- **L7/L8** 删连线/删节点→下游 @引用灰显「断链」（运行前提示重连或移除，不级联）
- **L9** 节点 label 唯一（新建/粘贴/重命名三入口查重自动序号）
