# 4.2 增长实验SOP

## 适用场景

产品有PMF、有核心指标、有数据基座，需要系统化做增长实验。

## 前置条件

- PMF验证通过（次留>25%）
- 北极星指标已确定
- 核心数据可追踪
- 增长团队就位

## 六步SOP

### 第1步：识别瓶颈与杠杆（1-2天）

| 动作 | 方法 | 产出 |
|---|---|---|
| 分析核心指标漏斗 | 画出AARRR各环节转化率 | 瓶颈环节定位 |
| 穷举增长杠杆 | 每个环节至少5个杠杆 | 杠杆清单 |
| ICE打分 | 影响(1-10)×信心(1-10)×难度(1-10，越高越容易) | 排序后杠杆TOP10 |

### 第2步：生成假设（1天）

**标准格式**："如果我们做[X]，那么[Y指标]会提升[Z%]，因为[原因R]"

| 假设模板 | 示例 |
|---|---|
| 如果缩短[新手引导步骤]，则[激活率]提升[X%]，因为[减少摩擦→更快Aha] | 如果把5步引导→3步，激活率提升15%，因为减少2步摩擦 |
| 如果增加[社交推荐触点]，则[推荐率]提升[X%]，因为[社会认同→行动] | 如果在成果页加"邀请好友"，推荐率提升20%，因为用户在成功时最愿分享 |
| 如果个性化[推送内容]，则[7留]提升[X%]，因为[相关度→回访] | 如果推送按兴趣标签个性化，7留提升8%，因为内容更相关 |

### 第3步：设计实验（1-2天）

| 设计要素 | 说明 |
|---|---|
| 对照组 | 当前版本（不改动） |
| 实验组 | 改动版本 |
| 分流比例 | 通常50:50；流量不足时70:30 |
| 样本量 | 按MDE+α=0.05+β=0.2计算 |
| 实验周期 | ≥1个完整周期+覆盖周末/工作日波动 |
| 主指标 | 假设中的Y指标 |
| 护栏指标 | NPS/投诉率/崩溃率/LTV至少1个 |
| 终止条件 | 护栏指标显著变差→立即终止 |

### 第4步：执行实验（1-4周）

| 动作 | 注意点 |
|---|---|
| 开发实验代码 | 最小化改动→快速上线 |
| 分流部署 | 确保分流均匀/无偏 |
| 数据埋点确认 | 确保实验数据可追踪 |
| 监控护栏指标 | 每日检查；异常立即暂停 |
| 不提前偷看 | 未到结束日期不判定结果（避免偷看偏差） |

### 第5步：分析结果（1天）

| 分析项 | 方法 |
|---|---|
| 统计显著性 | p值<0.05则显著 |
| 效应量 | 主指标提升幅度是否≥MDE |
| 护栏指标 | 护栏是否变差 |
| 分群分析 | 不同用户群(新/老/付费/免费)的效应差异 |
| 增量ROI | 实验收益/实验成本 |

### 第6步：决策（1天）

| 结果 | 决策 | 下一步 |
|---|---|---|
| 主指标显著提升+护栏正常 | 规模化上线 | 监控规模化后的效果 |
| 主指标提升但不显著 | 扩大样本量/延长周期 | 迭代实验 |
| 主指标无变化+护栏正常 | 放弃 | 下一个排名的假设 |
| 护栏指标变差 | 立即回滚 | 分析原因+调整方案 |

## 关键里程碑

| 里程碑 | 时间 | 验收标准 |
|---|---|---|
| M1 实验框架搭建 | T+1周 | 增长会机制确立+假设清单+实验模板 |
| M2 首批实验上线 | T+2周 | ≥3个实验同时运行 |
| M3 首个规模化 | T+4周 | 至少1个实验结果显著并规模化 |
| M4 增长飞轮启动 | T+8周 | 规模化实验持续贡献核心指标增长 |
