# 人工测试问题 1—4 修复架构设计

> Phase 1 专项架构；需求以 [专项 PRD](人工测试问题1-4修复.PRD.md) 为准。

## 1. 架构结论

本轮只改 Tauri 桌面端，不增加 Spring Boot、PostgreSQL、Redis 或管理后台依赖。前端负责交互与本地状态编排，Rust 负责 Windows 快捷方式、受控文件操作、窗口和 SQLite 能力。

## 2. 模块边界

### 2.1 收藏项快捷键协调器

新增前端组合式模块，统一负责：快捷键标准化、内部冲突检测、注册生命周期、启动恢复和失败汇总。它读取 `fileStore` 与 `settingsStore`，触发时调用现有 `openFile`，不自行拼接命令。

```text
FileItem.shortcut / 全局设置
  → 标准化与内部冲突检查
  → Tauri global-shortcut 试注册
  → 成功后替换旧注册并持久化
```

### 2.2 收藏项导入服务

新增 Rust 导入命令，返回标准化描述，不直接修改前端 Store。

```text
拖入路径
  → Rust 校验路径和类型
  ├─ Windows .lnk：解析目标 → 随机名复制 → 返回托管描述
  └─ 其他路径：返回直接路径描述
  → 前端确认无重复 → 写入 FileItem
```

托管目录位于 Tauri `app_data_dir/managed-shortcuts/`。删除命令只接受托管文件标识或经过根目录校验的路径。

### 2.3 进程设置迁移

保留当前 `EnumWindows + GetWindowTextW` 数据链，只调整 `processSettingsStore`：默认列定义成为唯一来源，加载时按 key 合并，并记录设置版本。`runtime/path` 若无对应数据或渲染能力，不进入可见列集合。

### 2.4 悬浮球窗口控制器

新增轻量 Vue 宿主与 Tauri 独立 Webview 窗口。窗口控制器保证同一时刻只有一个悬浮球实例。

```text
CloseRequested
  → closeBehavior
  ├─ floating_ball：prevent close → hide main → show/create ball
  ├─ tray：prevent close → hide main
  └─ exit：正常退出

ball click → show/focus main → hide ball
```

窗口配置：透明、无边框、置顶、跳过任务栏。位置校正使用显示器工作区 API，不使用固定坐标。

### 2.5 剪贴板分组与置顶服务

扩展现有 `ClipboardService → ClipboardStorage` 链路，不新建第二套数据库。新增分组 CRUD、移动记录、置顶更新命令；Store 负责乐观更新失败后的回滚。

```text
UI 操作
  → clipboardStore
  → api/clipboard.ts
  → Tauri command
  → ClipboardService
  → SQLite transaction
  → clipboard://changed
```

## 3. 关键技术决策

| 决策 | 采用方案 | 未采用方案及原因 |
|---|---|---|
| `.lnk` 生存策略 | 复制快捷方式到托管缓存 | Windows 符号链接可能需要权限，且指向原 `.lnk` 时源文件删除仍会失效 |
| 普通文件策略 | 只保存原路径 | 复制 PPT/EXE 会造成内容过期、体积膨胀或破坏程序依赖 |
| 悬浮球 | 独立 Tauri 窗口 | 在隐藏主窗口内渲染无法保持可见；原生全新 UI 增加双实现成本 |
| 分组模型 | 单条记录单分组 | 多标签、嵌套分组超出当前组织需求 |
| 窗口标题 | 修复设置迁移 | Rust 已能采集标题，无需重写进程枚举 |

## 4. 失败与降级

- 导入事务失败：删除本轮新缓存，前端不新增收藏。
- 新快捷键注册失败：保留旧注册和旧持久化值。
- 启动恢复部分失败：完成其余注册并展示失败清单。
- 悬浮球创建失败：显示托盘入口；托盘也不可用时恢复主窗口。
- 标题为空：使用 `-`，不丢弃进程行。
- 分组删除失败：SQLite 回滚，前端恢复原状态。
