# M4 scope 语义澄清 · 用户操作手册

> 记住一句话:**「落库于」= 写哪;「读取范围」= 读哪。两件事互不影响。**
> 迭代2(2026-07-18):底栏全是下拉框 + 末尾 2 个图标按钮,无杂乱开关/文字按钮。

## 底栏长这样(从左到右,全是下拉框)
| 下拉框 | 作用 | 选项 |
|---|---|---|
| 目标 / 模型 | 对话对象 + AI 模型 | 略 |
| **记忆模式** | 记忆系统开/关 | 跟随全局(默认,跟系统设置)/ 本会话开 / 本会话关 |
| **记忆落库于**(写) | 新事实存哪 | 总记忆 / 某项目 |
| **总记忆**(读范围里) | 读不读全局记忆 | 总记忆:开 / 总记忆:关 |
| **项目记忆**(读范围里,多选) | 额外读哪些项目的记忆 | 勾选项目 |

末尾两个**图标按钮**(无文字):
- 📂 文件夹图标 = 管理项目(新建/删除/共享)
- 🔖 书签图标(带红点 = 有冲突待处理)= 打开「我的记忆」抽屉

## 场景一:新说的事实存哪?
**「记忆落库于」**下拉(带浅色底纹那组)。
- 选「总记忆」→ 全局,所有项目能用。
- 选某项目 → 只挂该项目。

## 场景二:AI 回答时读哪些记忆?
读范围那组 = **「总记忆」下拉 + 「项目记忆」多选**。
- 只读某项目不掺总记忆:「总记忆」选「关」+ 只勾该项目。
- 全读:「总记忆」「开」+ 项目多选全勾。

## 场景三:记忆模式怎么切?
**「记忆模式」下拉**:
- 跟随全局 = 跟系统设置走(默认)。
- 本会话开/关 = 只对当前对话生效,覆盖全局。

## 场景四:调试「这条记忆为啥没被用上?」
点末尾 🔖 书签图标 → 「我的记忆」抽屉 → 顶部「记忆注入预览」→ 输入问题 → 预览范围选「指定项目」→ 「包含总记忆」开关(默认关)→ 预览注入。

## 常见疑问
| 现象 | 原因 / 处理 |
|---|---|
| 找不到「跟随」按钮了 | 并进「记忆模式」下拉的「跟随全局」选项 |
| 总记忆开关变成下拉了 | 迭代2 改的,选「总记忆:开/关」 |
| 没有文字只有图标的两按钮是啥 | 悬停看 tooltip:📂=项目管理,🔖=记忆抽屉(红点=有冲突) |
| 改了读范围但事实落别处 | 写目标看「记忆落库于」,不是读范围 |
