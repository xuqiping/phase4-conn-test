# 3.3 AI增长核心能力

## 能力1：预测式增长

**定义**：AI模型预测用户行为，在"事件发生之前"主动触发增长动作。

| 预测类型 | 模型输入 | 预测输出 | 触发动作 |
|---|---|---|---|
| 流失预测 | 近7天行为/登录频次/功能使用 | 7天内流失概率 | 高风险→自动挽留触达流 |
| 转化预测 | 浏览/加购/比价行为 | 7天内购买概率 | 高概率→推优惠促转化 |
| 需求预测 | 历史消费周期/库存/价格 | 下次购买时间 | 提前2天推复购券 |
| LTV预测 | 首月行为/付费/使用深度 | 预估LTV | 高LTV→优先投入资源 |
| 使用深层预测 | 功能使用路径/时间分布 | 深度使用概率 | 低概率→功能引导Push |

**落地前提**：至少3个月的行为数据+10000+用户样本+行为事件埋点完善。

> [来源:📚训练知识 | 置信度:🔍高]

## 能力2：智能触达

**定义**：AI自动选择最佳时机、渠道、内容、频次进行触达。详见D-07.04触达策略，此处聚焦AI增量。

| 传统触达 | AI智能触达 |
|---|---|
| 运营手动设发送时间 | AI预测每人最佳打开时间（STO） |
| 固定渠道策略 | AI根据历史偏好自动路由渠道 |
| 人工写3版文案A/B测试 | AI生成100版文案自动多臂老虎机测试 |
| 固定频次上限 | AI实时计算疲劳风险，动态调频 |
| 人群3-5分群 | AI实时计算千人千面触达方案 |

> [来源:2025 AI触达工具榜-搜狐 | 置信度:📚中 | 日期:2025-11]

## 能力3：AI内容生成

**定义**：AI批量生成个性化增长内容——文案/图片/视频/落地页。

| 内容类型 | AI生成方式 | 质量把控 |
|---|---|---|
| Push文案 | LLM生成多版本+多语言 | 人审+AB测试筛选 |
| 邮件正文/标题 | LLM生成+模板填充 | 品牌调性审核 |
| 落秋页/落地页 | AI生成HTML+A/B变体 | 设计规范审核 |
| 短视频素材 | 视频生成模型+自动化剪辑 | 创意审核+合规 |
| 商品图/广告素材 | 图片生成模型+批量产出 | 版权+合规审核 |

**关键洞察**：AI内容的威力不是"质量超越人类"而是"数量碾压人类"——100个中等质量变体AB测试 > 1个人精心打磨的版本。

> [来源:📚训练知识 | 置信度:📚中]

## 能力4：自动化实验

**定义**：AI自动完成"假设生成→实验设计→执行→分析→迭代"全闭环。

| 环节 | 传统 | AI自动化 |
|---|---|---|
| 假设生成 | 增长会头脑风暴 | AI分析数据自动生成假设 |
| 优先级排序 | ICE/RICE打分 | AI预测每个假设的预期收益 |
| 实验设计 | 手动配置A/B分流 | AI自动配置分流+样本量 |
| 执行监控 | 人盯数据面板 | AI实时监控+异常预警 |
| 结果分析 | 人工看p-value | AI自动分析+推荐下一步 |
| 迭代决策 | 人决策胜者 | AI按统计显著性自动选胜者 |

**效率提升**：从每周5个实验→每天50个自动实验（但需设置安全边界防止AI跑偏）。

> [来源:📚训练知识 | 置信度:📚中]

## 能力5：增长Agent

**定义**：端到端执行增长任务的AI Agent——接收增长目标→自主规划→自主执行→自主优化。

**增长Agent的能力边界**：
- ✅ 可以做：圈人群、选渠道、写文案、配实验、看数据、调策略
- ⚠️ 需人审：品牌调性、合规检查、预算审批
- ❌ 不能做：战略方向决策、组织变革、跨部门协调

**增长Agent架构**：

```
目标设定（人）→ Agent规划器 → 子Agent矩阵
                                ├── 数据分析Agent
                                ├── 触达策略Agent  
                                ├── 内容生成Agent
                                ├── 实验执行Agent
                                └── 效果归因Agent
                              → 结果汇报（人审核）→ 自动迭代
```

> [来源:2026 AI Agent Harness Engineering-CSDN | 置信度:📚中 | 日期:2026-05]
