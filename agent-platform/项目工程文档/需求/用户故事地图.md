## 四、非功能性需求

### 4.1 性能需求

| 需求ID | 需求描述 | 指标 |
|--------|---------|------|
| NFR-PERF-01 | 首屏加载时间 | ≤ 2秒（正常网络环境） |
| NFR-PERF-02 | Agent大厅列表加载 | ≤ 1秒（15个Agent卡片渲染完成） |
| NFR-PERF-03 | 工作流编辑器响应 | 节点拖拽延迟 ≤ 50ms，连线渲染 ≤ 100ms |
| NFR-PERF-04 | API平均响应时间 | ≤ 200ms（P95 ≤ 500ms） |
| NFR-PERF05 | 并发支持 | 支持100个同时在线用户，50个同时执行工作流 |

### 4.2 安全需求

| 需求ID | 需求描述 |
|--------|---------|
| NFR-SEC-01 | 所有API通信使用HTTPS (TLS 1.2+) |
| NFR-SEC-02 | 密码使用BCrypt加密存储（cost factor ≥ 10） |
| NFR-SEC-03 | JWT Token使用RS256签名，私钥服务端存储 |
| NFR-SEC-04 | 所有用户输入进行XSS/SQL注入防护 |
| NFR-SEC-05 | 敏感操作（删除工作流、权限变更）需二次确认 |
| NFR-SEC-06 | API接口实现速率限制（登录接口：5次/分钟，通用接口：60次/分钟） |

### 4.3 可用性需求

| 需求ID | 需求描述 |
|--------|---------|
| NFR-UX-01 | 操作结果反馈：所有用户操作在200ms内给出视觉反馈 |
| NFR-UX-02 | 错误提示：所有错误消息使用中文，提供具体解决建议 |
| NFR-UX-03 | 键盘快捷键：工作流编辑器支持 Ctrl+Z/Y（撤销/重做）、Delete（删除节点）、Ctrl+S（保存） |
| NFR-UX-04 | 无障碍：满足WCAG 2.1 AA级标准的基础要求（焦点管理、ARIA标签） |
| NFR-UX-05 | 浏览器兼容：Chrome 90+、Firefox 88+、Edge 90+、Safari 14+ |

### 4.4 可靠性需求

| 需求ID | 需求描述 |
|--------|---------|
| NFR-REL-01 | 系统可用性 ≥ 99.5%（月度） |
| NFR-REL-02 | 工作流执行状态持久化，服务重启后可恢复 |
| NFR-REL-03 | 数据库每日自动备份，备份保留30天 |
| NFR-REL-04 | 前端工作流编辑自动保存，浏览器崩溃后可恢复 |

## 五、约束条件

### 5.1 技术约束

| 编号 | 约束 | 说明 |
|------|------|------|
| TC-01 | 前端框架 | Vue 3 + Composition API + TypeScript |
| TC-02 | UI组件库 | Element Plus（暗色主题定制） |
| TC-03 | 工作流画布 | Vue Flow（基于React Flow的Vue3版本）或自研Canvas方案 |
| TC-04 | 后端框架 | Spring Boot 3.x + Java 17+ |
| TC-05 | 数据库 | PostgreSQL 15+ |
| TC-06 | 缓存 | Redis 7+ |
| TC-07 | 部署环境 | Docker容器化部署 |
| TC-08 | Agent数据源 | Markdown文件解析入库，文件变更时触发增量同步 |

### 5.2 业务约束

| 编号 | 约束 | 说明 |
|------|------|------|
| BC-01 | 桌面端优先 | MVP阶段仅适配桌面端（1280px+），移动端仅做响应式降级 |
| BC-02 | Agent数据来源 | 15个Agent定义从现有Markdown文件迁移，不支持用户自建Agent |
| BC-03 | 语言 | 界面语言为简体中文，暂不支持多语言 |
| BC-04 | 数据隔离 | 企业版（V2.0）考虑多租户数据隔离，MVP阶段单租户 |

### 5.3 项目约束
