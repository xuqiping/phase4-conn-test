# 舆情监控体系

## 一、舆情监控是什么

舆情监控（Social Listening / Brand Monitoring）是持续追踪品牌/产品在公开渠道上的用户讨论、情感倾向和舆论走向，目标是在"噪音中发现信号，在信号中识别危机"。

**Social Listening vs Social Monitoring**：

| 维度 | Social Monitoring | Social Listening |
|---|---|---|
| 问题 | 用户说了什么？ | 用户为什么这么说？ |
| 深度 | 计数+统计 | 情感+动机+趋势 |
| 行动 | 回复/灭火 | 优化产品/调整策略 |
| AI的价值 | 自动采集+计数 | 情感分析+主题提取+预测 |

## 二、舆情监控的4层架构

### Layer 1：数据采集层

| 数据源 | 采集方式 | 覆盖内容 |
|---|---|---|
| 社交媒体 | API/爬虫 | 微博/抖音/小红书/微信公众号 |
| 应用商店 | API | App Store/Google Play评价 |
| 新闻媒体 | RSS/API | 新闻报道+行业分析 |
| 论坛/社区 | 爬虫 | Reddit/知乎/V2EX/BBS |
| 短视频 | API | 抖音/B站/快手评论 |
| 海外渠道 | API | Twitter/YouTube/Reddit/Product Hunt |

### Layer 2：信号处理层

| 处理任务 | AI方法 | 输出 |
|---|---|---|
| 去重+去噪 | 文本相似度+NLP | 有效记录数 |
| 情感分析 | 情感分类模型 | 正面/中性/负面比例 |
| 主题提取 | LDA/BERT主题模型 | Top10讨论主题 |
| 实体识别 | NER | 品牌/产品/人物/事件 |
| 关键词提取 | TF-IDF/TextRank | 高频词+新兴词 |

### Layer 3：洞察分析层

| 分析维度 | 分析方法 | 业务价值 |
|---|---|---|
| 情感趋势 | 时序情感曲线 | 口碑变好还是变差？ |
| 主题演变 | 主题模型+时间线 | 用户关注点在怎么变化？ |
| 竞品对比 | 多品牌情感对比 | 我们vs竞品口碑差距？ |
| 影响力识别 | PageRank/传播网络 | 谁在主导舆论？ |
| 危机检测 | 异常检测+关键词规则 | 是否需要启动应急？ |

### Layer 4：预警分发层

| 输出形式 | 推送渠道 | 推送频率 |
|---|---|---|
| 实时预警 | 钉钉/飞书/Slack | 触发即推 |
| 日报摘要 | 邮件 | 每日 |
| 周报分析 | 邮件+文档 | 每周 |
| 专题报告 | 文档 | 按需/每月 |

## 三、情感分析的核心模型

### 3.1 基础情感分类

| 类别 | 定义 | 典型信号词 | AI模型 |
|---|---|---|---|
| 强正面 | 高度满意/推荐 | "太好用了！""强推" | BERT微调 |
| 弱正面 | 基本满意 | "还行""不错" | 规则+模型 |
| 中性 | 客观描述/询问 | "请问这个功能怎么用？" | 分类器 |
| 弱负面 | 轻微不满 | "有点慢""不太方便" | 规则+模型 |
| 强负面 | 强烈不满/投诉 | "垃圾""退款""投诉" | BERT微调+规则 |

### 3.2 细粒度情感（Aspect-Based）

不只判断"正面/负面"，还判断"对什么的正面/负面"：

```
"这个产品功能很好，但客服太差了"
→ 功能：正面 | 客服：负面
```

### 3.3 情感趋势看板

| 指标 | 计算方式 | 预警阈值 |
|---|---|---|
| 整体情感指数 | (正面-负面)/总数×100 | <-20 危险 |
| 负面舆情量 | 负面评论数/日 | >均值3倍=异常 |
| NPS替代指标 | 推荐者%-贬损者% | <0=严重 |
| 情感波动率 | 标准差/7日 | >2倍=不稳定 |

## 四、舆情危机的识别与分类

| 危机类型 | 特征 | 典型案例 | 黄金响应时间 |
|---|---|---|---|
| 产品质量 | 集中投诉+传播加速 | 产品缺陷大面积曝光 | 2小时 |
| 数据/隐私 | 涉及用户数据安全 | 数据泄露事件 | 1小时 |
| 高管/品牌 | 个人言行牵连品牌 | 高管不当言论 | 4小时 |
| 公关翻车 | 营销内容引发反感 | 歧视/低俗广告 | 3小时 |
| 竞品攻击 | 竞品主动制造负面 | 公关战/法律纠纷 | 6小时 |
