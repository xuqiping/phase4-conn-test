# 4.2 AI产品指标设计SOP与看板模板

## 一、AI产品指标体系搭建8步SOP

| 步骤 | 输入 | 动作 | 输出 |
|---|---|---|---|
| 1.产品定类型 | 产品形态/任务样本 | 判定对话式/Copilot/Agent/RAG/搜索 | 产品类型卡 |
| 2.北极星定位 | 产品类型/核心价值 | 选1个能反映"用户拿到价值"的北极星 | 北极星定义文档 |
| 3.四级指标构建 | 北极星 | 主指标(3-5)+辅助(5-10)+反指标(1-3/主) | 四级指标表 |
| 4.四象限看板 | 四级指标 | 质量×成本×性能×体验四象限+分层+健康度评分 | 看板原型 |
| 5.埋点设计 | 行为埋点最小集 | 设计含分母的采集点+显性反馈 | 埋点文档 |
| 6.反馈闭环 | 5步法 | 采集→脱敏→分级→回流→验证 | 闭环方案 |
| 7.基线与目标 | 第三方基准 | 用SWE-bench/Chatbot Arena/调研数据定基线 | 基线对照表 |
| 8.上线监测 | 看板+告警 | 灰度→持续度量→AB→迭代 | 监测看板 |

## 二、北极星指标选型决策表

| 产品类型 | 北极星候选 | 推荐北极星 | 反指标 |
|---|---|---|---|
| 对话式助手 | 任务完成率/CSAT | **任务完成率** | 弃用率/平均会话轮数 |
| Copilot类 | 采纳率/任务完成率 | **采纳率** | 弃用率/平均耗时 |
| Agent产品 | 端到端完成率/工具调用成功率 | **端到端完成率** | 人工介入率/平均成本 |
| 搜索/问答 | 任务完成率/引用准确率 | **任务完成率** | 重试率/放弃时延 |
| RAG知识库 | 引用准确率/任务完成率 | **引用准确率** | 拒答率/任务完成率 |
| 创作类 | 采纳率/CSAT | **采纳率** | 重写率/弃用率 |
| 推理类 | 任务完成率/思考质量 | **任务完成率** | 思考成本/思考时延 |
| 客服类 | 任务完成率/转人工率 | **任务完成率** | 转人工率/二次咨询率 |

> 红线：北极星只能1个；无法决定时问"用户拿到价值=什么指标达成"；自动指标（BLEU/ROUGE）不可作北极星。

## 三、四级指标体系模板（按产品类型）

### 3.1 Copilot类模板（如Cursor/GitHub Copilot）

| 层级 | 指标 | 定义 | 目标 |
|---|---|---|---|
| 北极星 | 采纳率 | 用户接受AI建议未修改比例 | >60% |
| 主指标 | 任务完成率 | 任务独立完成比例 | >90% |
| 主指标 | 幻觉率 | 编造事实比例 | <5% |
| 主指标 | 单位任务成本 | 单任务平均Token成本 | <客单价30% |
| 主指标 | P95时延 | 95%请求时延 | <3s |
| 辅助 | 重写率/首次成功率/缓存命中率/平均会话轮数 | - | 基线对比 |
| 反指标 | 弃用率 | 中途放弃比例 | <15% |
| 反指标 | 平均耗时 | 单任务耗时 | 行业基线 |

### 3.2 Agent类模板（如Manus/Devin）

| 层级 | 指标 | 定义 | 目标 |
|---|---|---|---|
| 北极星 | 端到端完成率 | 整任务链完整完成 | >70% |
| 主指标 | 工具调用成功率 | 选对工具且参数正确 | >85% |
| 主指标 | 规划正确率 | 任务分解合理（人评） | 人评基线 |
| 主指标 | 单位任务成本 | 单任务平均成本 | 商业可行边界 |
| 主指标 | 端到端时延 | 单任务总耗时 | 体验边界 |
| 辅助 | 平均步骤数/错误恢复率/检查点回退率/中断率 | - | 基线对比 |
| 反指标 | 人工介入率 | 需人工介入比例 | <30% |
| 反指标 | 平均成本/任务 | 单任务花费 | <客单价50% |

## 四、四象限看板模板

### 4.1 看板布局

```
┌───────────────质量象限───────────────┬───────────────成本象限───────────────┐
│ 🎯 北极星: 任务完成率 (周趋势)         │ 💰 单位任务成本 (周趋势)              │
│ 采纳率/重写率/幻觉率/引用准确率        │ Token消耗/缓存命中率/毛利率           │
│                                       │ ⚠反指标: 单位任务成本>客单价30%       │
├───────────────性能象限───────────────┼───────────────体验象限───────────────┤
│ ⚡ TTFT/TPS (实时)                     │ ⭐ CSAT/NPS                          │
│ P95/P99时延/错误率/SLA达成率           │ 放弃率/复用率/平均会话轮数            │
│ ⚠反指标: P95>3s                        │ ⚠反指标: 弃用率>15%                   │
└───────────────────────────────────────┴───────────────────────────────────────┘
```

### 4.2 健康度评分模型（加权+否决）

```yaml
health_score:
  quality_health:  # 权重40%
    metric: north_star_达成率 * 0.5 + 反指标守门率 * 0.5
    veto: 幻觉率 > 红线 -> 归零
  cost_health:     # 权重25%
    metric: (客单价 - 单位任务成本) / 客单价 + 缓存命中率
    veto: 单位任务成本 > 客单价90% -> 归零
  performance_health:  # 权重20%
    metric: P95时延达成率 + SLA可用性
    veto: SLA < 99% -> 归零
  experience_health:   # 权重15%
    metric: CSAT + 复用率 - 弃用率
    veto: 弃用率 > 30% -> 归零
  total: 加权和; 任一否决项触发 -> 总分标记⚠️异常
```

## 五、反馈数据闭环模板（5步法落地）

### 5.1 行为埋点最小集（YAML）

```yaml
events:
  - name: ai_response_shown        # 必埋·分母基线
    fields: [message_id, session_id, scenario, ts]
  - name: ai_response_adopted      # 采纳率分子
    fields: [message_id, edit_distance(0=直接采纳)]
  - name: ai_response_edited       # 重写率/纠错样本
    fields: [message_id, original_text, edited_text]
  - name: ai_response_ignored      # 弃用率分子
    fields: [message_id, ignore_after_ms]
  - name: ai_regenerate            # 不满意信号
    fields: [message_id, reason]
  - name: ai_feedback_explicit     # 显性反馈
    fields: [message_id, type(thumb/star), value, dimension]
  - name: ai_tool_call             # Agent专项
    fields: [tool_name, success, latency, args_hash]
```

### 5.2 数据回流路径

```
[采集] → [脱敏/合规审查] → [标注质量分] → [分级]
  ├→ 高质量反馈 → SFT/DPO训练集 (用户授权)
  ├→ 中质量反馈 → Prompt优化样本
  └→ 低质量反馈 → Safety训练负样本
[迭代] → 模型/Prompt更新 → 灰度 → 监测采纳率/任务完成率 → 全量
```

> 红线：反馈数据采集必须"用户授权前置"，符合数据隐私合规（详见 [D-16.01 数据隐私](../../../D-16_限制边界合规/D-16.01_数据隐私/1_知识库概览/0_模块路由.md)）

## 六、AI A/B实验设计模板（含特殊考虑）

### 6.1 AI A/B四大特殊坑

| 坑 | 说明 | 应对 |
|---|---|---|
| 指标延迟 | 采纳率/任务完成率需时间积累，不能1-2天判定 | 实验时长≥2周 |
| 样本异质性 | 不同任务类型AB结果可能相反 | 按复杂度/用户类型分群 |
| 学习曲线 | 新范式初期差（用户不熟），过早判定误判 | 观察学习曲线，剔除前3天 |
| 跨会话效应 | 个性化记忆影响跨会话体验 | 不能孤立看单次 |

### 6.2 实验设计模板

```yaml
假设: "用推理模型替代标准模型，将提升复杂任务完成率"
主指标: 任务完成率(%)
辅助指标: 采纳率/重写率/平均会话轮数/CSAT
反指标: 单位任务成本/思考时延/P95时延
分群:
  - 任务复杂度: 简单/中等/复杂
  - 用户类型: 新用户/老用户/重度
样本量: 按统计功效计算(MDE=3%, power=0.8)
实验时长: ≥2周（覆盖学习曲线+跨会话）
灰度策略: 5%→20%→50%→100%（监测反指标停损）
判定规则: 主指标显著正向 + 反指标未越红线 = 全量
```

## 七、第三方基准对照表（防自吹自擂）

| 产品类 | 基准 | 用途 | 来源 |
|---|---|---|---|

## 八、PM自检清单（指标体系是否健康）

- [ ] 是否有且只有1个北极星？
- [ ] 北极星是否真能反映"用户拿到价值"（非自动指标）？
- [ ] 是否有3-5主指标+每个主指标配1-3反指标？
- [ ] 是否有质量×成本×性能×体验四象限看板？
- [ ] 看板是否分层（战略/运营/诊断/个人）？
- [ ] 健康度评分是否有反指标否决项？
- [ ] 反馈闭环是否脱敏前置+回流训练？
- [ ] 埋点是否含`ai_response_shown`分母？
- [ ] 是否用第三方基准对照自家数据？
- [ ] AB实验是否≥2周+覆盖学习曲线+分群下钻？
- [ ] 推理模型是否补思考Token/思考时延指标？
- [ ] Agent是否补端到端完成率/工具调用成功率？
- [ ] 是否持续度量（非仅上线前）？
