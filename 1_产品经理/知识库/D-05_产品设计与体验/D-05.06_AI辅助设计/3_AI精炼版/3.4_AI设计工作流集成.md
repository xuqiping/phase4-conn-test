## AI设计工作流集成

### 人机协同设计流程（5阶段）

| 阶段 | AI做什么 | 人做什么 | 产出 |
|---|---|---|---|
| 探索 | 生成50+视觉方向/概念方案 | 策展+筛选3-5个方向 | 概念方案 |
| 细化 | 按选中方向生成高保真变体 | 判断+取舍+品牌调整 | 精修设计稿 |
| 规范化 | 自动引用Design System令牌 | 审核一致性+定制例外 | 规范化交付物 |
| 原型化 | 生成可交互原型 | 补充复杂交互逻辑 | 可测试原型 |
| 评估 | AI辅助启发式评估+a11y扫描 | 用户测试+最终决策 | 评估报告 |

### 工具链集成模式

**模式一：Figma中心式**
```
需求→ChatGPT(写Prompt)→Galileo/Figma AI(生成UI)→Figma(精修)→开发移交
```

**模式二：代码中心式**
```
需求→v0.dev(生成React UI)→Cursor(精修代码)→Storybook(文档化)→部署
```

**模式三：混合式（推荐）**
```
需求→AI探索(视觉)→Figma(设计精修+DS约束)→v0(代码生成)→人工审查→部署
```

### AI嵌入设计评审的新流程

| 传统评审 | AI时代评审 |
|---|---|
| 评审1个设计稿 | 评审5-10个AI方案+人工精修稿 |
| "这个设计好不好" | "哪个AI方案最接近品牌调性"+"需要哪些精修" |
| 评审焦点在细节 | 评审焦点在方向选择+质量控制 |

### 人机协同分工原则

| 原则 | 说明 |
|---|---|
| AI做量，人做质 | AI生成大量方案，人做判断和取舍 |
| AI做执行，人做决策 | AI填充Design System，人定义Design System |
| AI做检查，人做验证 | AI自动扫描合规性，人做可用性测试 |
| AI做重复，人做创造 | AI处理组件变体，人做创新交互设计 |
