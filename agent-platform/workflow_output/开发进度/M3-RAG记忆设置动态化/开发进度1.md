## 沉淀规范
prompt 含既有 `%s` 占位符 + 需动态注入数值时,**用命名 token `{NAME}` + helper replace,不用 `%d`**——避免 String.format 顺序耦合(数值 token 与字符串 token 顺序难维护)。已织入通用约束。
