## 2. 外部调研结论（2026-08-28）

- **LibTV/ComfyUI 式「一键整理」**业界通解=**层次布局（DAG 分层排布）**：上游→下游沿一轴等距铺开。vue-flow 官方示例与多数节点画布（含 ComfyUI 整理插件）用 **dagre**（自动分层图布局库）。
- 依赖选型：`@dagrejs/dagre`（dagre 现维护 scoped 包，gzip ≈12KB，纯前端零 IO）；elkjs 效果更好但体积/接入成本高（大画布才值得），本轮不取。
- dagre 特性对口径：多孤立子图自动分块不重叠；有环自动断环不挂死；同输入同输出（确定性，可单测断言）。

## 3. 用户决策（2026-08-28 拍板）

| # | 问题 | 决策 |
|---|---|---|
| Q1 | 节点复制范围 | **多选子图**：Ctrl+C 复制选中节点（支持框选批量），Ctrl+V 一次粘出全部节点+**选中集内部连线**（两端都在集内的边才带出；通向外部的边不带——与「创建副本」连边克隆为两种口径）；克隆脱钩语义同 C-8 |
| Q2 | 粘贴落点 | **鼠标位置**：子图按复制时相对位置整体平移、中心对齐鼠标（与修复VI 图片粘贴落点口径一致）；无鼠标记录回落视口中心；连按逐次 +32 错开 |
| Q3 | 布局方向 | **从左到右**（上游在左下游在右，dagre rankdir=LR） |
| Q4 | 布局范围 | **全图，选中时只排选中**：默认一键重排全部；有选中（≥1）则只重排选中子图（选中含组成员→整组纳入），未选节点不动；整理完 fitView、Ctrl+Z 一步撤回 |

## 5. 非功能需求

- **性能目标**：一键整理 500 节点/800 边 ≤150ms（同步一次，dagre network-simplex；超大盘后续可切 worker，本轮不做）；粘贴 ≤50 节点同步 <16ms 不掉帧（纯数组批写）；两功能零新增网络请求。
- **安全**：纯前端功能，无新端点/无新攻击面；粘贴建节点走既有保存链（认证+归属校验不变）；dagre 为本地计算库无外联。
- **依赖**：新增 `@dagrejs/dagre`（gzip ≈12KB，随 CanvasView 所在 chunk）；无 DB 迁移、无数据迁移；旧画布快照零影响（只动既有 position 字段）。
- **可回滚**：纯代码 revert 即回现状；Ctrl+Z 一步撤回布局/粘贴（快照栈既有能力，无新栈）。

## 6. 数据模型

无变更。节点 position、边、快照结构（nodes/edges/groups）已含全部所需字段；内部剪贴板为组件会话态（不入库、不进 localStorage——重进画布即清，口径与「不跨画布」决策一致）。

## 7. 测试策略

- **单测**：①canvasClipboard 纯函数（从 nodeClone 抽新）：内部边过滤（仅两端在集）、id 重映射、RESET_KEYS 脱钩与创建副本同口径、包围盒平移落点、+32 逐次错开、批内 label 去重；②autoLayout：上游 x+宽 ≤ 下游 x（LR 序不变量）、孤立节点不重叠、有环不断言不挂死+可出坐标、includeIds 只动选中且左上角锚定、同输入同输出（确定性）、16 网格对齐；③CanvasBoard 组件：Ctrl+C/V 在 input/textarea/contentEditable 放行、无选中 Ctrl+C 清剪贴板且不 preventDefault（图片粘贴通道恢复）、粘贴单历史步（undoStack 长度 +1）、一键整理后 position 变化+单 structure-changed。
- **人工测试标记**（需真实浏览器手势）：①框选 3 节点带内部连线 Ctrl+C→空白处 Ctrl+V：节点+内部边齐全、落点在鼠标处、外部连线不带；②连按 3 次 Ctrl+V 逐次错开不叠；③粘贴后 Ctrl+Z 一步整体消失；④外部复制图→Ctrl+V 建图片节点链不受影响（含复制过节点后再复制图的优先级恢复）；⑤一键整理全画布：左→右分层、fitView、Ctrl+Z 一步还原；⑥框选子图整理：只动选中、组整组跟排、组包围盒跟随；⑦生成中/运行中节点参与复制粘贴与整理不炸（脱钩副本可独立重生成）。
- **回归**：修复VI 图片粘贴/文件拖拽、「创建副本」连边克隆（与本轮子图口径互不挤占）、批量生成/一键关联、自动保存链、撤回重做 50 步、@候选与跟光标。

## 8. 边界与不做

- **不做**：Ctrl+X 剪切；跨画布/跨项目粘贴（系统剪贴板 JSON 序列化）；从上到下方向或方向切换；elkjs/worker 大图布局；锁定节点（pin 不参与排布）；边路由样式改造（保持贝塞尔）；布局参数（间距/方向）设置面板与持久化；粘贴节点入组。
- 内部剪贴板与系统图片剪贴板冲突裁决：**非空内部剪贴板优先**（Ctrl+C 无选中即清空恢复图片通道），不监听系统 copy 事件做时间戳仲裁（复杂度不值）。
- 一键整理会覆盖用户手摆位置——这正是功能语义；撤回一步可回。不提供「仅排未连接节点」等细分模式。
- dagre 对超长提示词文本节点尺寸按默认表估算，不逐节点实测 DOM（整理是重排不是精排，误差可接受）。

## 10. 术语表

| 术语 | 大白话 | 案例 |
|---|---|---|
| dagre | 把有向图自动分层摆整齐的布局库 | 上游排左、下游排右、层间等距 |
| 子图 | 大图里挑出来的一小块节点和它们之间的连线 | 框选 3 个节点+2 条内部边 |
| 诱导边 | 两端都在选中集里才算的连线 | 选 A、B，边 A→B 算，A→C 不算 |
| 包围盒 | 圈住一组元素的最小矩形 | 粘贴时整组对齐鼠标用 |
| 快照栈 | 每次大改动前存一份全图备份，供撤销 | Ctrl+Z 回到粘贴前 |
| fitView | 自动缩放平移让全部内容刚好铺满视口 | 整理完一键看全图 |
| 脱钩 | 复制体与原任务/资产记录切断关联 | 副本重生成=全新任务（C-8 口径） |
