# 录音实时转文字 - 技术选型与开发计划

## 一、项目概述

开发一款跨平台桌面录音实时转文字工具。用户对着麦克风说话，文字实时显示在屏幕上。支持录音保存、文字导出、离线运行。

**核心目标：**

- 离线运行，无需网络
- 实时流式识别，延迟 < 2秒
- 安装包体积尽可能小
- 跨 Windows / macOS / Linux

## 二、语音识别引擎选型

### 2.1 方案对比

| 特性 | sherpa-onnx | faster-whisper | whisper.cpp | Vosk |
|------|------------|----------------|-------------|------|
| 实时流式识别 | ✅ 原生支持 | ❌ 需VAD分段 | ⚠️ 实验性 | ✅ |
| 中文效果 | 优秀 | 优秀 | 优秀 | 一般 |
| 最小模型 | ~30MB | ~75MB (tiny) | ~40MB (量化) | ~50MB |
| 跨平台 | ✅ | ✅ | ✅ | ✅ |
| 说话人分离 | ✅ (pyannote) | ❌ | ❌ | ❌ |
| Python API | ✅ `pip install sherpa-onnx` | ✅ | ✅ (pywhispercpp) | ✅ |
| Rust API | ✅ (sherpa-rs) | ❌ | ✅ (whisper-rs) | ❌ |
| 授权 | Apache 2.0 | MIT | MIT | Apache 2.0 |

### 2.2 推荐：sherpa-onnx

**理由：**
1. 唯一同时满足「流式识别 + 轻量模型 + 中文优秀 + 跨平台 + 多语言API」的方案
2. 内置 VAD（语音活动检测）
3. 支持说话人分离
4. 活跃维护（最新 v1.13.0，2026-04-28）

**推荐模型：**

| 模型 | 语言 | 大小 | 说明 |
|------|------|------|------|
| paraformer-zh-streaming (int8) | 中文 | ~120MB | 流式中文，推荐首选 |
| zipformer-transducer-bilingual | 中英双语 | ~150-300MB | 流式双语，精度最高 |
| 量化小模型 | 中文 | ~30-50MB | 体积最小，精度略降 |

## 三、GUI 框架与整体方案选型

### 3.1 三种方案对比

| | 方案A：Tauri + Rust | 方案B：Python + PySide6 | 方案C：Tauri壳 + Python核心 |
|---|---|---|---|
| **安装包（不含模型）** | **~3-10MB** | ~80MB | ~35MB |
| **开发效率** | 中（需学Rust） | **高（已有经验）** | 中 |
| **学习成本** | 高 | **低** | 中 |
| **UI 美观度** | 高（Web技术） | 高（Qt6） | 高（Web技术） |
| **性能** | **最好** | 好 | 好 |
| **预计开发周期** | 6-8周 | **3-4周** | 4-5周 |

### 3.2 方案A：Tauri 2.0 + Rust + sherpa-rs（体积最小）

```
安装包预估：~3-10MB（不含模型）
```

- 前端：Vue 3 / React + TypeScript
- 后端：Rust + sherpa-rs（官方Rust绑定）
- 音频采集：cpal
- 打包：Tauri 内置（Windows exe / macOS dmg / Linux AppImage）
- 优势：体积最小，性能最好，支持自动更新和系统托盘
- 劣势：需学习 Rust

**体积明细：**

| 组件 | 体积 |
|------|------|
| Tauri Runtime | < 1MB |
| WebView（系统自带） | 0 |
| sherpa-onnx + ONNX Runtime | ~15-20MB |
| cpal + 音频处理 | ~1MB |
| 前端资源 | ~2MB |
| **安装包总计（不含模型）** | **~20-25MB** |

### 3.3 方案B：Python + PySide6 + sherpa-onnx（开发最快）

```
安装包预估：~80MB（不含模型）
```

- GUI：PySide6（Qt6 Python 绑定，与 PyQt5 几乎一致）
- 语音识别：sherpa-onnx Python
- 音频采集：sounddevice
- 打包：Nuitka（编译为C） + UPX压缩
- 优势：开发最快，沿用现有 PyQt5 经验
- 劣势：打包体积大

**体积明细：**

| 组件 | 体积 |
|------|------|
| Python Runtime（Nuitka编译） | ~15-20MB |
| PySide6 | ~40-50MB |
| sherpa-onnx | ~5MB |
| ONNX Runtime | ~15-20MB |
| sounddevice + PortAudio | ~2MB |
| **安装包总计（不含模型）** | **~80MB** |

### 3.4 方案C：Tauri 壳 + Python 核心（折中）

```
安装包预估：~35MB（不含模型）
```

- 前端：Tauri 2.0 + Vue 3（负责UI，体积小）
- 后端：Python 打包为独立 exe（负责音频+识别，通过 sidecar 或本地 HTTP 通信）
- 优势：前端体积小 + Python核心开发快
- 劣势：需要打包两个程序，通信略复杂

                                    ↓
                              文字导出(TXT/SRT)

## 七、开发计划

### Phase 1：MVP（第 1-2 周）

**目标：** 能录音，能实时出文字

| 基础 UI | 开始/停止按钮 + 文字滚动区 |

**里程碑：** 点击"开始"→ 对着麦克风说话 → 文字实时出现在屏幕上。

| 任务 | 详情 |
|------|------|

| 设置面板 | 采样率、语言、主题等 |
| 系统托盘 | 最小化到系统托盘 |

**里程碑：** 完整可用的录音转文字工具。

### Phase 3：优化与发布（第 5-6 周）

| 任务 | 详情 |

## 八、打包与分发

### 模型分发策略

- 安装包**不含**模型（控制体积）
- 首次启动时自动下载，显示进度条
- 支持离线手动放置到 `models/` 目录
- 提供多个模型选项（小/中/大）

| 平台 | 格式 | 方案A | 方案B | 方案C |
|------|------|-------|-------|-------|
| Windows | exe (NSIS) | ~25MB | ~80MB | ~40MB |

## 九、开发环境搭建

### 方案A（Tauri + Rust）

```bash
# 1. 安装 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 2. 安装 Node.js（前端构建）
# https://nodejs.org 下载安装

# 3. 创建 Tauri 项目
npm create tauri-app@latest

# 4. 添加 Rust 依赖
cd src-tauri
cargo add sherpa-rs cpal

# 5. 开发运行
npm run tauri dev

# 6. 打包发布
npm run tauri build
```

### 方案B（Python + PySide6）

```bash
# 1. 安装依赖
pip install PySide6 sherpa-onnx sounddevice numpy

# 2. 运行开发
python src/main.py

# 3. Nuitka 打包
pip install nuitka
nuitka --standalone --onefile --enable-plugin=pyside6 --windows-disable-console src/main.py
```

### 方案C（Tauri 壳 + Python）

```bash
# 1. 安装 Rust + Node.js（同方案A）

# 2. 安装 Python 依赖
pip install sherpa-onnx sounddevice numpy

# 3. 打包 Python 核心为 exe
nuitka --standalone --onefile python-core/server.py -o core.exe

# 4. 将 core.exe 放入 Tauri 的 sidecar 目录

# 5. 开发运行
npm run tauri dev

# 6. 打包（自动包含 sidecar）
npm run tauri build
```

## 十、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| sherpa-rs 绑定不完善 | 高 | 通过 C FFI 直接调用 sherpa-onnx C API；或改用方案B/C |
| Rust 学习曲线 | 中 | 选择方案B（Python）或方案C（仅前端用Tauri） |
| 模型体积过大 | 中 | 量化模型 + 首次下载策略 + 提供多档位模型 |
| 中文识别不准 | 中 | 提供多个模型选项，用户可切换 |
| macOS 麦克风权限 | 低 | 引导用户在系统设置中授权 |
| Nuitka 打包兼容性 | 中 | 充分测试多平台打包；备选 PyInstaller |
