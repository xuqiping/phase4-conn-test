# 3.3 群组分析

## I.06 方法论核心

**群组分析（Cohort Analysis）** 是留存分析的核心执行方式——将用户按某个维度分成群组，对比不同群组的留存差异，找到影响留存的关键因素。

## 群组划分维度

### 1. 时间群组（Time Cohort）

按用户首次使用的时间段划分。

| 群组 | 定义 | 用途 |
|---|---|---|
| 日群组 | 同一天注册的用户 | 短期留存趋势跟踪 |
| 周群组 | 同一周注册的用户 | 中期趋势+降噪 |
| 月群组 | 同一月注册的用户 | 长期趋势+战略级评估 |

**时间群组热力图**：

```
        D0   D1   D7   D14  D30
Jan W1  100% 45%  22%  18%  12%
Jan W2  100% 48%  24%  19%  13%  ← 改进后留存微升
Jan W3  100% 42%  20%  16%  10%  ← 这周为什么降？
Jan W4  100% 50%  26%  21%  15%  ← 新版本发布后提升
```

### 2. 行为群组（Behavioral Cohort）

按用户的初始行为划分，是最有洞察力的群组划分方式。

| 行为群组 | 定义 | 典型发现 |
|---|---|---|
| 完成新手引导 vs 未完成 | D0是否完成引导 | 完成引导的用户D7留存高2~3倍 |
| 使用核心功能 vs 未使用 | D0~D3是否使用核心功能 | 核心功能使用者留存显著更高 |
| 社交连接 vs 独立使用 | 是否邀请/连接好友 | 有社交关系的用户留存更稳 |
| 付费 vs 免费 | 是否在首周付费 | 付费用户留存更高但样本偏小 |

### 3. 属性群组（Attribute Cohort）

按用户固有属性划分。

| 属性 | 维度 | 用途 |
|---|---|---|
| 获客渠道 | 自然流量/付费广告/社交分享 | 评估渠道质量 |
| 设备 | iOS/Android/PC | 识别平台差异 |
| 地区 | 一线/二线/三线 | 区域化策略 |
| 年龄段 | Z世代/千禧/X世代 | 圈层运营 |

## 群组对比方法

### 方法1：同期群横向对比

同一时间点注册的不同群组横向对比，看留存差异。

```
D7留存对比：
  渠道A: 28%  ← 最高
  渠道B: 22%
  渠道C: 15%  ← 需优化
```

### 方法2：时间序列纵向对比

同一群组在不同时间点的留存变化，看趋势。

```
渠道A D7留存趋势：
  1月: 25% → 2月: 27% → 3月: 28% ← 持续提升
```

### 方法3：群组间差异归因

发现群组留存差异后，用行为数据归因。

```
发现：完成新手引导的群组D7留存=28%，未完成的=12%
归因：完成引导的用户中80%触达了核心功能，未完成只有20%
→ 假设：核心功能触达是留存提升的真正驱动因素
→ 验证：A/B测试强化引导→核心功能路径
```

## 群组分析注意事项

1. **样本量**：每组至少200~500用户，小群组波动大、不可靠
2. **时间对齐**：比较不同群组时，统一用D7/D30等相对时间
3. **季节效应**：工作日vs周末注册的用户行为天然不同，需控制
4. **选择性偏差**：行为群组（如付费vs免费）天然存在偏差——愿意付费的用户可能本身粘性更高
