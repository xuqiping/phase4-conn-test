# 23 - 前端布局与移动端适配

## 功能简介
平台外壳（顶栏 + 左侧栏 + 内容区）的布局约定，以及全站移动端（≤768px）/ 平板（≤1024px）响应式适配方案。断点由单一 composable 驱动，导航与多面板页在窄屏切换为抽屉模式。

## 响应式断点
- 新增 composable：[useBreakpoints.ts](../../frontend/src/composables/useBreakpoints.ts)
  - 基于 `window.matchMedia`，无 `@vueuse` 依赖。
  - 导出响应式 `isMobile`（≤768px）、`isTablet`（≤1024px），`onMounted` 注册监听、`onUnmounted` 移除，兼容旧 Safari（`addListener` 回退）。
- 约定：
  - 裸 `@media (max-width: 768px)` 写移动端 CSS；平板用 1024px。
  - `viewport` meta 已正确（`width=device-width, initial-scale=1.0`，不锁缩放）。

## 外壳布局（桌面 / 移动）
- 入口：[MainLayout.vue](../../frontend/src/layouts/MainLayout.vue)
  - 桌面：固定左侧栏（`--sidebar-width: 240px`，可折叠到 64px），内容区 `margin-left` 推开。
  - 移动：内容区 `margin-left:0` 不推开；侧栏变覆盖式抽屉 + 半透明遮罩（`.main-layout__overlay`）。`isMobile && mobileSidebarOpen` 控制显隐，路由切换 `watch(route.path)` 自动收起。
- 侧栏：[Sidebar.vue](../../frontend/src/components/Sidebar.vue)
  - props：`collapsed`（桌面折叠）、`mobileOpen`、`isMobile`。
  - 移动端 `position:fixed; transform:translateX(-100%)`，`--mobile-open` 时 `translateX(0)`；底部折叠按钮移动端隐藏。
- 顶栏：[AppHeader.vue](../../frontend/src/components/AppHeader.vue)
  - 汉堡按钮 `@toggle-sidebar` → MainLayout 按 `isMobile` 分流（移动开抽屉 / 桌面折叠）。
  - 移动端隐藏：搜索框（固定 200px）、用户名；保留头像 + 主题切换 + 汉堡。

## 多面板页（窄屏面板抽屉化）
- 智能对话 [ChatView.vue](../../frontend/src/views/ChatView.vue)：会话侧栏（260px）移动端抽屉化（`transform` 滑入 + 遮罩），聊天头加切换按钮，`handleSelectSession` 选会话后自动收起。记忆抽屉宽度移动端 100%（项目管理已改为 `ProjectManagerModal` 弹窗，非抽屉）。
- 工作流编辑器 [WorkflowEditorView.vue](../../frontend/src/views/WorkflowEditorView.vue)：**移动端（≤768px）不渲染画布**，显示「请在电脑端使用」占位页（节点画布不适合触屏，有意为之，非 bug）。桌面端三栏布局不变。

## 响应式改造模式（全站通用）
- **弹窗宽度**：固定 `style="width:Npx"` → `:style="{ maxWidth: 'Npx', width: '90vw' }"`（n-modal preset="card" 同理）。涉及 ProviderManageTab、UserProviderTab、ProjectManagerModal 等（MemoryManagerPanel 为纯 n-tabs 面板，移动适配走 640px 断点页签折行，不属此模式）。
- **表格横向滚动**：`n-data-table` 加 `:scroll-x="列宽合计"`，窄屏横向滚动条干净生效。涉及 KnowledgeView、UserManageView、ProviderManageTab、KbPermissionModal、RetrievalAuditPanel、AgentPermissionModal。
- **筛选/操作行换行**：`@media(max-width:768px){ .xxx__filters{flex-wrap:wrap / flex-direction:column} .xxx__search{width:100%} }`，网格降为 `1fr`。涉及 AgentHallView、WorkflowListView、AgentPermissionModal、RetrievalDebugPanel。
- **抽屉宽度响应式**：`n-drawer :width="N"` → `:width="isMobile ? '100%' : N"`。
- **触屏可发现性**：靠 `:hover` 显隐的操作按钮（WorkflowCard、AgentHallView 的卡片操作），加 `@media (hover: none){ opacity:1 }` 常驻，否则触屏永久不可见。
- **窄屏 padding 收窄**：MessageBubble/ChatInput/SkillDetail/AgentDetailView 等在 768 断点收窄 padding。
