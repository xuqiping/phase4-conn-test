## 常见问题排查

### 问题 1：快捷键无响应

**可能原因**：
- 快捷键被其他应用占用
- 应用未正确注册全局快捷键
- 独立截图遮罩窗口创建失败或创建事件丢失
- 应用崩溃或后台进程终止

**排查步骤**：
1. 检查任务管理器中应用进程是否运行
2. 完全退出并重启 `npm run tauri:dev`，避免旧进程仍占用快捷键
3. 尝试修改为其他快捷键
4. 在其他应用中按快捷键后等待约 1 秒：如果出现"截图遮罩窗口创建超时"，说明遮罩窗口创建失败，需要查看 Tauri 控制台日志
5. 查看应用日志是否有 `screenshot-overlay`、`create_webview_window` 或 capability 权限错误

---

### 问题 2：截图保存后无 OCR 文本

**可能原因**：
- OCR 功能被禁用
- 图片中无可识别文字
- Windows OCR 语言包未安装
- OCR 进程失败

**排查步骤**：
1. 检查设置中"启用 OCR"是否勾选
2. 使用清晰大号文字重新测试
3. Windows 设置 → 时间和语言 → 语言，确认已安装中文语言包
4. 查看应用日志中的 OCR 错误信息

---

### 问题 3：截图区域与实际内容不匹配

**可能原因**：
- 高 DPI 缩放因子计算错误
- 多显示器坐标转换问题
- 虚拟屏幕配置异常

**排查步骤**：
1. 检查系统显示缩放设置
2. 尝试在主显示器上截图
3. 检查 `scaleFactor` 是否正确传递
4. 查看后端日志中的物理坐标值

---

### 问题 4：应用崩溃或卡死

**可能原因**：
- 截图区域过大导致内存溢出
- OCR 处理超时
- 文件 I/O 错误

**排查步骤**：
1. 截取较小区域重试
2. 临时禁用 OCR 功能
3. 检查磁盘空间是否充足
4. 查看崩溃日志（Windows 事件查看器）
