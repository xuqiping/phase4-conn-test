# 样式皮肤层约定（frontnew → 合回 frontend 也适用）

> 沉淀自 frontnew C1–C8。违反这些 = 4 主题切换破功。

## 铁律

1. **组件内禁止硬编码色值/阴影/模糊**。一律 `var(--token)`。颜色进 `theme/tokens/<主题>.css`。
2. **双源同步**：改 tokens css 必同步 `theme/naive.ts` 的 CSS_MIRROR。`tests/tokens.spec.ts` 逐键比对，漂移即红。
3. **动效只动 transform/opacity**。布局属性动画 = 掉帧。
4. **blur 配额制**：`backdrop-filter: blur` 只允许出现在 ≤3 个固定面板（侧栏/弹层/顶栏），节点卡片等大数量元素禁用（用半透明代替）。
5. **新动效必须响应 `prefers-reduced-motion`**（global.scss 已全局兜底，自定义 JS 动画要自己判断，如 ChatView 流式打字）。
6. **状态视觉走状态类名**（BEM 修饰符 `--running` 等），组件不写内联样式。
7. **禁止 `:global([data-theme=...])` 裸选择器**——编译会塌成命中 `<html>` 的规则，整页白屏（真实事故，见开发进度1）。主题差异一律改 token 开关变量（如 `--stream-display`）。

## 运维/走查开关

| 开关 | 用法 |
|------|------|
| `?theme=<key>` | URL 直达主题（截图比选/分享链接） |
| `?nodes=N` | 画布压测（N≤500，超限自动截断） |
| localStorage `frontnew-theme` | 主题持久化键；非法值自动回退 neon-pulse |

## 合回 frontend 顺序（architecture.md §6）

tokens css → 节点组件样式 → 布局样式 → naive overrides。每步独立 commit。
