# PRD — frontnew 前端样式优化版

> 版本 v1.0 · 2026-08-14 · 唯一真相源。后续实现与本文件冲突时：要么改实现，要么改本文件并记录原因。

## 1. 背景与问题

现有前端 `agent-platform/frontend`（Vue 3 + Naive UI 暗色）功能完整，但视觉偏「传统管理台」：

- 无限画布中 6 类节点卡片（文本/图像/视频/音频/脚本/分镜）样式朴素，无类型区分度、无运行态视觉反馈，缺乏「智能化」气质；
- 页面层级平、无纵深感，主题是简单换色而非完整设计语言；
- 与 2026 年 AI 平台设计趋势（AI-native 摘要卡、暗色优先、玻璃拟态分层、状态辉光）存在代差。

## 2. 目标

建 `agent-platform/frontnew`：**纯前端样式验证项目**（Vue 3 + TS + Vite + mock 数据，无后端连接），用于：

1. 验证 4 套设计主题在核心页面上的实际效果，供用户比选；
2. 重点重做无限画布 6 类节点卡片的视觉与状态设计；
3. 沉淀一套可合回 `frontend` 的设计令牌（**design tokens**——颜色/圆角/阴影/动效等基础样式变量的统称）与组件皮肤层。

**非目标（Out of Scope）**：

- 不接任何后端 API，不实现真实业务逻辑；
- 不做移动端适配（桌面优先，最低宽度 1280px）；
- 不做国际化（仅中文界面）；
- 不做旧浏览器兼容（仅 Chrome/Edge 最新两版）；
- 不重做的页面：登录/注册/找回密码、钱包/计费、管理后台、知识库、图像/视频生成页、视频编辑器、执行监控（二期再议）。

## 3. 用户故事

| # | 角色 | 故事 | 验收 |
|---|------|------|------|
| US-1 | 平台用户（设计者） | 打开 frontnew，在 4 套主题间一键切换，逐页对比效果 | 主题切换不刷新页面、无闪烁，<100ms 生效 |
| US-2 | 平台用户 | 在无限画布看到 6 类节点卡片的新设计：类型一眼可辨、状态（选中/运行/完成/报错）一眼可辨 | 6 类卡片各有类型色与图标；5 种状态有差异化视觉 |
| US-3 | 平台用户 | 画布上有演示用的连线工作流（mock 数据），可缩放、平移、选中节点 | 100 节点缩放手感流畅 |
| US-4 | 平台用户 | 浏览对话页/智能体大厅/工作流列表的新样式 | 各页面在 4 主题下均完整可读、无样式崩坏 |
| US-5 | 开发者（未来的我） | 读 design_system.md 与 tokens 文件，能把主题合回 frontend | tokens 为 CSS 变量，主题文件独立可拆 |

## 4. 功能需求

### 4.1 主题系统（FR-T）

- FR-T1：提供 4 套主题，均为暗色优先：
  - **T1 霓虹 AI「Neon Pulse」**：深空底色 + 玻璃拟态面板（**glassmorphism**——半透明+背景模糊，像磨砂玻璃浮在页面上）+ 霓虹辉光描边 + 渐变流光动效；
  - **T2 冷静极简「Calm Slate」**：Linear/Vercel 式分层灰阶（页面 #0F0F0F → 侧栏 #1A1A1A → 卡片 #1F1F1F → 弹层 #2A2A2A），单一强调色，零装饰；
  - **T3 混合「Hybrid Glow」**：页面结构用 T2 的克制，仅画布卡片用 T1 的玻璃+辉光；
  - **T4 影像工坊「Cineon」**：贴合 AI 视频生成主业——放映厅级深色（偏暖黑 #12100E 系）、胶片橙金/品红双强调色、时间轴/分镜语言融入卡片与排版（详见 design_system.md §5）。
- FR-T2：主题切换器固定在主布局顶栏，带 4 主题预览色点；选择持久化到 localStorage。
- FR-T3：主题用 CSS 变量驱动 + Naive UI `themeOverrides` 同步换肤，切换无刷新。
- FR-T4：4 主题下正文对比度均满足 **WCAG 2.2**（国际无障碍标准）AA：正文 ≥4.5:1，大字/图标 ≥3:1。

### 4.2 页面范围（FR-P，核心页优先）

| 页面 | 内容 | mock 数据 |
|------|------|-----------|
| 主布局 MainLayout + 侧边栏 | 新导航结构、折叠态、顶栏（主题切换/用户头像/通知铃铛 mock） | 菜单静态 |
| 无限画布 CanvasView | 6 类节点卡片新设计、连线、小地图、工具栏、右侧面板壳 | 1 条演示工作流（≥10 节点，覆盖 6 类型 × 4 种数据状态 idle/running/success/failed；hover/选中为交互态，走查时现场演示） |
| 对话页 ChatView | 消息流、AI 流式打字效果（mock 定时器模拟）、输入区、引用卡 | 2 会话 |
| 智能体大厅 AgentHallView | 智能体卡片网格、标签筛选、搜索框 | 12 个智能体 |
| 工作流列表 WorkflowListView | 表格 + 状态徽标 + 操作列 | 10 条工作流 |

### 4.3 画布节点卡片（FR-N，本项目的重中之重）

每类节点卡片必须包含的解剖结构（详细视觉规格见 design_system.md §6）：

- **头部**：类型图标 + 类型名 + 状态指示点；类型色编码——文本=蓝、图像=紫、视频=品红、音频=青、脚本=琥珀、分镜=绿（T4 主题下映射为胶片色系，见设计文档）；
- **内容区**：类型特有预览（图像/视频显示缩略图占位、文本显示摘要 2 行、音频显示波形占位、脚本显示行数徽标、分镜显示镜头数）；
- **连接桩（handle）**：左入右出，hover 放大，类型色；
- **状态系统**：`默认 / hover / 选中 / 运行中 / 完成 / 报错` 六态。运行中=呼吸辉光/流光描边动画；报错=红描边+图标；完成=角标✓；
- **选中态**：描边 + 外发光（T2 主题下退化为纯描边加粗，保持克制）。

### 4.4 mock 层（FR-M）

- FR-M1：所有数据放 `src/mocks/`，按页面分文件，导出类型化常量；
- FR-M2：不引 axios、不写请求拦截器；如需异步感（流式打字），用 `setTimeout` 模拟；
- FR-M3：路由直达可用，无需登录守卫（顶部放「样式预览版」徽标明示）。

## 5. 非功能需求

### 5.1 性能目标

| 指标 | 目标 |
|------|------|
| 首屏可交互（本地 dev） | < 2s |
| 主题切换生效 | < 100ms，无整页闪烁 |
| 画布 100 节点缩放/平移 | ≥ 55fps（肉眼无卡顿） |
| 生产构建体积（gzip） | 首包 < 500KB（Naive UI 按需引入） |
| 动效 | 仅用 transform/opacity，不触发布局重排 |

### 5.2 可访问性

- 键盘可切换主题、可 Tab 遍历侧边栏与卡片操作；
- 动效尊重 `prefers-reduced-motion`（用户系统设了减弱动效时，辉光/流光自动关闭）。

### 5.3 安全策略（小项目并入此节）

- 纯静态 mock，无凭证、无真实用户数据；localStorage 只存主题键值；
- mock 文本渲染走 Vue 默认插值（自带 XSS 转义），禁止 `v-html`；
- 依赖安全：沿用 frontend 已验证的依赖版本区间，不新增未知来源包。

## 6. 成功标准

- 4 主题 × 5 页面全部可浏览，用户从中选定 1 套（或组合）作为合回 frontend 的目标风格；
- 画布 6 类节点卡片新设计获用户认可；
- design tokens 文件可直接被 frontend 引用（CSS 变量无构建依赖）。

## 7. 术语表

| 术语 | 大白话 | 案例 |
|------|--------|------|
| design tokens | 设计令牌：把颜色/圆角/间距等抽成变量，换肤=换一组变量值 | `--color-accent: #7C5CFF` |
| glassmorphism | 玻璃拟态：半透明+模糊背景，像磨砂玻璃 | 毛玻璃侧边栏 |
| WCAG 2.2 | 国际网页无障碍标准，规定文字与背景最小对比度 | 正文对比度 4.5:1 |
| themeOverrides | Naive UI 提供的组件级换肤配置对象 | 把 n-button 主色改成主题色 |
| handle | 节点卡片上的连接桩，拖线用的圆点 | 卡片左侧的输入圆点 |
| prefers-reduced-motion | 操作系统级「减少动画」开关，网页可读取并响应 | 关掉呼吸辉光动画 |
