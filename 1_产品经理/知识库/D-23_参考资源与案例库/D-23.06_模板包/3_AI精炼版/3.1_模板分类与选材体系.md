# 3.1 模板分类与选材体系

> 5类模板分类+5大合规选材原则+5条违规红线——什么算"模板"、怎么选、选什么。

## 一、5类模板分类

| 类型 | 定义 | 特征 | 代表模板 |
|---|---|---|---|
| 文档类 | PM日常交付物的标准化文档模板 | 结构化/可交付/版本控制 | PRD/竞品分析/用户画像/数据报告/复盘报告 |
| 流程类 | PM工作流程的标准化步骤模板 | 步骤化/可SOP化/可培训 | SOP/上线SOP/变更管理/需求评审流程/项目计划 |
| 清单类 | PM检查与决策的清单化辅助模板 | 检查项/防漏/可批处理 | 需求清单/上线检查表/合规自查表/RACI矩阵/预算清单 |
| 工具类 | PM工作辅助的填空式工具模板 | 填空式/工具化/快速产出 | 优先级矩阵/需求颗粒度拆解表/OKR模板/会议纪要模板/路线图Canvas |
| Agent提示词类 | AI Agent场景下的元提示词模板(2025-2026新兴) | 8段结构/可复用/AI工程 | 8段元提示词/Agent设计模板/Agent评测模板/Agent调试模板 |

### 分类决策树

```
你需要的模板属于哪类？
├── 写交付物(给上游/下游/老板看的文档) → 文档类
├── 描述工作流程(可SOP化培训) → 流程类
├── 检查防漏(避免遗漏) → 清单类
├── 填空快速产出(单页工具) → 工具类
└── 设计/调试/评测Agent → Agent提示词类

注：同一模板可跨多类(如"上线SOP"=流程类+清单类双属性)，按主用途归类。
```

## 二、5大合规选材原则

| # | 原则 | 定义 | 评估方法 |
|---|---|---|---|
| 1 | 简明度 | 模板是否"一页说清"——简明>臃肿 | 字段≤15个+核心字段≤5个+一页可看完 |
| 2 | 可复用度 | 模板能否跨产品/项目/团队复用——可复用>定制 | 至少3个产品验证可复用+适配成本<定制成本 |
| 3 | 标准化度 | 模板是否行业公认标准(非自创小众) | 来源有行业背书(书籍/大厂/业内公开课) |
| 4 | 工具化度 | 模板是否有现成工具支撑(Word/Excel/Notion/飞书) | 有现成工具/插件/Notion模板市场可下载 |
| 5 | 合规度 | 模板使用是否过5条违规红线(不侵权/不抄袭/不数据黑市/不实承诺/不越权) | 法务/合规过审+来源授权+脱敏 |

### 5大原则的优先级排序

```
合规度(0容忍) > 简明度(决定是否会用) > 标准化度(决定是否通用) > 可复用度(决定是否值得) > 工具化度(锦上添花)
```

> 合规是底线，不合规的一切模板不收录；简明决定是否被使用(臃肿模板=文档黑洞)；其余决定是否值得和好用。

### 模板与SOP/规范的边界判定

| 维度 | 模板(D-23.06) | SOP/规范(D-11等) |
|---|---|---|
| 性质 | 填空式/可裁剪工具 | 强制性/上下文一致 |
| 复用性 | 高复用/工具化 | 上下文绑定/不可裁剪 |
| 用法 | "拿到模板改就完事" | "按规范执行不可改" |
| 目标 | 节省时间+拉平质量方差 | 保证流程一致性+合规 |

## 三、5条违规红线（强制·不收录越线模板）

| # | 红线 | 内容 | 违反法规 |
|---|---|---|---|
| 1 | 不侵权 | 模板来源是否合规(自研/授权/开源)，不直接套用他人付费版权模板 | 《著作权法》第10条 |
| 2 | 不抄袭 | 引用他人模板需标注来源，避免伪原创与抄袭 | 《著作权法》第47条 |
| 3 | 不数据黑市 | 模板内案例/数据来源合规，无用户数据黑市 | 《个人信息保护法》《刑法》253条之一 |
| 4 | 不实承诺 | 模板不承诺效果(模板=工具，效果取决于执行) | 《广告法》第4/28条(防虚假宣传) |
| 5 | 不越权 | 模板内涉及的敏感信息(用户数据/商业秘密)使用前需脱敏+合规 | 《反不正当竞争法》第9条 |

> 任一红线涉及→该模板不收录；本叶子只收录"合规且工具化"或"自研开源可分发"的模板。

### 落选案例与原因

| 模板 | 落选原因 | 替代方案 |
|---|---|---|
| 某大厂付费版权PRD模板 | 越红线1(侵权；未授权分发) | 用自研开源版替代 |
| 复杂多层嵌套PRD模板(50+字段) | 简明度不足(臃肿；过载) | 用核心字段版(15字段以内)替代 |
| "用了必提升转化率200%"的模板 | 越红线4(不实承诺) | 用"模板+用法说明"替代 |
| 含某竞品真实用户数据的画像模板 | 越红线3(数据黑市) | 用脱敏或合成数据替代 |
| 某公司内部商业秘密SOP模板 | 越红线5(越权) | 用脱敏开源版替代 |
| 过时PRD模板(只覆盖PC无移动/多端) | 标准化度低(过时) | 用多端兼容版替代 |
| 自创小众"3色决策矩阵"模板 | 标准化度低(无行业背书) | 用行业通用优先级矩阵替代 |
| "万能模板"(声称适用所有场景) | 不存在万能模板——任何模板都有场景边界 | 用场景化模板替代 |

## 五、选材更新机制

| 规则 | 内容 |
|---|---|
| 年度复审 | 每年Q1用5原则重评10大，可替换≤2个 |
| 合规追溯 | 已收录模板若发现来源不合规→立即下架并移入失败案例 |
