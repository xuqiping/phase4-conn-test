# 常用文件管理相关
1. 鼠标拖拽多选
2. 对所有文件都增加右键关联菜单选项
3. 被动记录一段时间内打开次数多的文件，然后做推荐
4. 一键上云
5. 绑定快捷键，如Win+1打开某个应用
6. 做成新一代的操作系统（也是噱头）
   1. 深度/快速搜索
   2. 磁盘清理
   3. 复制粘贴
   4. 快速关闭已经打开的应
   5. 便签功能
7. 团队协作
   1. 快速上传协同办公
   2. 在线编辑（针对txt、xlsx等，不同人编辑保存的，会像git一样，每个人生成一个分支，并记录下与主分支的区别，由主分支确定是否同意按指定子分支修改，如果有重复，则生成冲突警告）
   3. 屏幕共享
8. 分组拖拽移动排序
9.  组合打开（已经实现，多选打开）
10. 分组复制备份
11. 右键/卡片左上角增加排序位置的设置
12. 快速排序（按打开次数等）
13. AI功能：能分析云上的内容，来快速找到对应的内容
    1. 最好有一个总路由文件，默认每次上传文件，都会在总路由文件中总结目录名/文件内容等（用户自选），以便续快速分析并找到文件
    2. 深入管理文本文件、图片文件，放弃大文件
 14. 除了快速打开文件，还需要快速打开网页、cmd命令、执行常见语言脚本
