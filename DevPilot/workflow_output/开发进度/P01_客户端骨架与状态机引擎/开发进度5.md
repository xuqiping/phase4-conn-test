## 本轮关键决策与变更

- **无状态命令**：不在 Rust 侧缓存 PersistentMachine，每次 command 从 DB load_or_init——DB 即真相，天然支持断点续开与多窗口一致性，代价是每次一次 SQL 读（可忽略）。
- **管道条语义升级**：Step 5 点击=切视图；Step 7 起点击=向内核发起转移（被拒 toast 大白话）。纯浏览走左栏导航。Step 5 的 LI1 管道条用例改为 PhaseBar 路径，导航用例保留。
- **PhaseBar**：中栏底部操作条，「确认门禁」骨架期一点即过——真实检查单交互在 P04（需求确认卡）/P06（安全清单）替换，已注明。
- **规模变体 UI 呈现**：管道条按快照 phases 渲染，L0/L1 被跳阶段不显示（联动点 2 UI 侧闭环）。
- **路径安全**：项目名拒 `..` 与分隔符；父目录 canonicalize 后 starts_with 校验；默认可空走 `~/DevPilotProjects`。
- **测试基建**：jsdom 无 Tauri 运行时，`vi.mock("./lib/ipc")` 内存假内核（语义对齐 default.yaml）——后续所有前端测试沿用此模式。
