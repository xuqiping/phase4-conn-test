## 8. 更新后的完成定义

第一版商业授权完成时，应满足：

- [ ] 服务端可启动并连接 PostgreSQL、Redis。
- [ ] 管理后台可登录超级管理员。
- [ ] 管理员可审核用户、禁用/启用用户。
- [ ] 管理员可授予、禁用、撤销模块权益。
- [ ] 管理员可设置单用户设备上限和离线缓存时长。
- [ ] 管理员可查看并禁用用户设备。
- [ ] 桌面端未登录时可获得匿名 7 天全功能试用。
- [ ] 匿名试用过期后可选择一个长期免费模块。
- [ ] 桌面端可注册、登录、退出账号。
- [ ] 登录成功后自动绑定设备并拉取授权快照。
- [ ] pending_review 用户有明确等待审核提示。
- [ ] active 用户只能使用已授权且未过期模块。
- [ ] 设备被禁用后商业授权失效。
- [ ] 设备数超限时有明确提示。
- [ ] 离线缓存行为符合管理员配置。
- [ ] 授权过期后客户端降级匿名权益。
- [ ] 文件收藏、剪贴板历史、截图内容不上传服务端。
- [ ] 后端测试、桌面端测试、桌面端构建、管理后台构建全部通过。
- [ ] 真实环境端到端联调记录完成。
