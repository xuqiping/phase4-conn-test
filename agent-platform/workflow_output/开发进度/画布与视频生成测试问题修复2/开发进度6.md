## 背景

第三轮落地后，首/尾/参考三态统一走 `attachments[]`，F1/F2/F3 UI 允许「首帧+尾帧+参考图」同请求。真 E2E 验证此组合被 ctaigw 拒绝。

## 真跑发现：last_frame 与 reference_image 互斥

ctaigw（SeedDance 2.0）对「尾帧 + 参考图」同请求返 **400**：

```
InvalidParameter: The parameter `content` specified in the request is not valid:
last frame image content cannot be mixed with reference image or draft_task content.
```

**契约**（Phase4 确认，三轮全绿单测无法覆盖——需现网真请求）：
| 组合 | 合法性 |
|---|---|
| 首帧 + 尾帧（无参考图） | ✅ task22/23 SUCCEEDED |
| 首帧 + 参考图（无尾帧） | ✅（仅 last_frame 与参考图互斥） |
| 尾帧 + 参考图 | ❌ 网关 400 |
| 参考图（任意） | ✅ task14 |

诊断手法：`ArkSeedanceProvider.createTask` catch 捕 `WebClientResponseException.getResponseBodyAsString()` 打日志，定位到 body 后定根因。

## 落地（commit `1b488ad8`）

- **后端互斥校验** [MediaGenTaskService.java](../../../backend/src/main/java/com/superprogrammer/media/service/MediaGenTaskService.java) `validateAttachments`：`referenceImages = images - firstFrame - lastFrame`；`lastFrame>0 && referenceImages>0` → 抛 `BusinessException` 中文提示「尾帧不能与参考图同时使用…互斥」，前置拦截，不透传网关英文 400。
- **网关错误体透传** [ArkSeedanceProvider.java](../../../backend/src/main/java/com/superprogrammer/media/provider/ArkSeedanceProvider.java) `createTask` catch：`WebClientResponseException` 不再 chain 作 cause（`rootMessage` 会下钻到泛化 "400 Bad Request from POST…"，丢网关真实原因），改抛无 cause 异常、message 直带响应体 → `errorMsg` 落库即用户可读；完整堆栈由 `log.error(...,wce)` 记录。
- **测试**：拆 `submit_attachmentFrameRole` 为「首尾帧（无参考）」+「首帧+参考图」两合法组合；新增 `submit_lastFramePlusReference_400` 互斥校验。provider 16 + service 21 = **37/37 绿**。

## 附：MentionTextarea 打 @ 宽度塌缩修复（commit `61a027a4`）

playwright 冒烟复测 @ 交互时抓到：视频页提示词框打 @ 后整个组件塌缩到 31px 宽，空态文案竖排撑成 412px 高窄条盖住下方附件区。

**根因**：[MentionTextarea.vue](../../../frontend/src/components/canvas/MentionTextarea.vue) `.mention-ta` 包裹层无显式宽度，在 Naive `n-form-item` 里是 flex item → 收缩到内容宽。空态靠 `is-empty::before` 占位符长文本撑出 ~346px；一打 @ → `is-empty` 移除 → 占位符消失 → min-content 塌到「@」字宽 31px，连带 `input{width:100%}` + `popover{min-width:100%}` 全塌。

**修**：`.mention-ta { width:100% }`（宽度只跟父容器，与内容/占位符解耦）+ popover `max-height:240px; overflow-y:auto`。playwright 真 DOM 复测：打 @ 后 wrap/input/popover 均 346px、popover 高 412→29px。vue-tsc 净；vitest 67/67 零回归。canvas PropertyPanel 同组件同受益。
