## 用户地图（谁用/场景/效益）

| 用户 | 场景 | 效益 |
|---|---|---|
| 创作者（canvas:write） | 画布上框选一批分镜节点，一键把文本里的角色名自动换成 @引用 | 免逐个手动输入 @，长名短名不误吞 |
| 创作者 | 选中 5 个图/视频节点批量生成，中途去喝杯茶回来刷新 | 同时最多 2 个在途不撞限流，429 自动退避，回来任务照跑 |
| 团队成员（EDITOR） | 共享项目里看到「这张图是谁传的」、给好素材打分 | 上传者一目了然；拥有者分与成员均分分开看 |
| 项目 OWNER | 成员互相乱改内容 → 项目设置切「个人」模式；成员乱打分 → 关评分开关 | 一键收紧权限，历史数据不丢，可随时切回 |
| 管理员 | 生成任务把供应商配额打爆 | 系统设置调每用户并发上限（默认 video=2 / image=3），运行时生效 |

## 一句话技术说明

- **C1 框选**：接管 vue-flow 原生 Shift 多选（`delete-key-code=null` 杜绝库默认 Backspace 静默双删），选集 ≥2 浮批量工具条。
- **C2 一键关联**：纯函数匹配（祖先节点 label/资产名 ≥2 字、长名降序、跳过 @{{}} 占位符区间）→ 预览确认 → 逆序替换写入，运行插值链路零改动复用。
- **C3 并发闸**：Redis INCR 预占 + TTL 30min 自愈 + worker 状态迁移影响行=1 才释放；上限存 system_settings 热改生效；Redis 停机 fail-open。
- **C4 批量生成**：诱导子图拓扑序 + 滑动窗口 2 + 指数退避 1s/2s/4s×3；taskId 即时持久化复用刷新恢复机制。
- **C5 迁移**：V123（media_gen_tasks 部分索引）+ V124（asset_scores 表 0-100 CHECK + 项目开关列 + created_by 存量回填，文件类溯源 stored_files 真实上传者）。
- **C6 后端**：`requireAssetOperate` 资产级写咽喉（PERSONAL 下 EDITOR 仅本人内容，NULL fail-closed）+ 双轨评分 upsert（ON CONFLICT）+ 列表筛选批装配防 N+1。
- **C7 前端**：评分区（slider+数字框）、上传者徽标、PERSONAL 按钮门控、OWNER 项目设置弹窗（局部提交+切换二确认）。
