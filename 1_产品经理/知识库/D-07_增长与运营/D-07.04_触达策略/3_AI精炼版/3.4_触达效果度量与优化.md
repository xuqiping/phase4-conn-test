# 3.4 触达效果度量与优化

## 触达指标体系

### 漏斗指标

| 指标 | 定义 | 基准参考 | 健康信号 |
|---|---|---|---|
| 授权率 | 用户开启Push授权的比例 | iOS 40-60%，Android 70-90% | 持续下降需警惕 |
| 触达率 | 消息成功送达比例 | Push 85-95%，短信95%+ | 低于80%需排查技术问题 |
| 展示率 | 送达后被用户看到的比例 | Push 50-70%，短信查看率<5% | 下降=时机或疲劳问题 |
| 打开率 | 被打开/点击的比例 | Push 2-8%，邮件15-25% | 行业差异大，纵向对比更重要 |
| 转化率 | 打开后完成目标行为的比例 | 因目标而异 | 核心北极星指标 |
| 退订率 | 收到后退订/关闭授权的比例 | Push<1%/月 | 最重要红线指标 |

## 效果归因

### 归因挑战

触达归因的难点在于**跨渠道归因**：用户先收到邮件→后来打开App→看到Push→最终下单，归谁？

### 归因模型选择

| 模型 | 逻辑 | 适用 |
|---|---|---|
| 末次触达 | 归给最后触达的渠道 | 简单，适合快速决策 |
| 首次触达 | 归给最先触达的渠道 | 评估启频效果 |
| 线性归因 | 各触达渠道平均分配 | 多渠道协同评估 |
| 时间衰减 | 越接近转化权重越高 | 短决策周期场景 |
| 数据驱动（DDD） | 基于实际数据分析各渠道贡献 | 数据充足时的最优选择 |

**推荐**：日常运营用末次触达快速决策；季度复盘用DDD做深度分析。

## A/B测试在触达中的应用

### 高频A/B测试维度

| 维度 | 测试内容 | 周期 |
|---|---|---|
| 文案 | 标题A/B、副标题A/B、CTA文案A/B | 1-3天 |
| 时机 | 上午vs下午、工作日vs周末 | 1周 |
| 频次 | 每周3次vs5次 | 2-4周 |
| 渠道 | Push vs 短信vs双渠道 | 1-2周 |
| 个性化 | 全量vs分群vs参数化 | 1-2周 |
| 画面 | 纯文本vs富媒体vs大图 | 3-5天 |

### A/B测试纪律

1. **单变量原则**：每次只测一个维度
2. **样本量足够**：每组≥1000人或统计显著性≥95%
3. **时长足够**：覆盖完整行为周期（至少7天）
4. **不追胜率**：看起来赢了但统计不显著的不算
5. **长期看退订率**：短期打开率提升可能掩盖长期退订率上升

## 消息疲劳识别与治理

### 疲劳信号

- 打开率连续3次下降
- 退订率/关闭授权率环比上升20%+
- 同一用户连续N条未打开
- App Store评论出现"推送太多"相关差评

### 治理方法

| 方法 | 说明 |
|---|---|
| 疲劳熔断 | 连续3条未打开→7天内不再发营销Push |
| 渠道轮换 | 同一消息不强推同一渠道，换低频渠道 |
| 内容升级 | 从优惠轰炸→服务提醒→个性化推荐，多样性提升 |
| 用户选择 | 提供偏好设置，让用户自选接收频次和类型 |
| 冷静期 | 大促后强制进入7天"触达冷静期" |
