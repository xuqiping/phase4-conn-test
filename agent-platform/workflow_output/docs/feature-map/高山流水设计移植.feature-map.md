## 关键调用链

```
main.ts 装样式链 → App.vue(ConfigProvider 套 naive-overrides[data-theme])
  → theme store initTheme()（启动：读 localStorage → hidden 则迁夜墨 → 写 data-theme）
  → 路由页 ModuleScene(scene="chat") → scenes.ts 查表 → import.meta.glob 懒加载 avif → 远山背景
组件样式一律 var(--color-*) → ye-mo.scss / xuan-zhi.scss 按当前 data-theme 供值
```

## 技术原理大白话

- **CSS 变量换肤**：像给整栋楼预埋灯控线路——组件只接「主色」这根线，夜墨/宣纸往线里送不同电，全屋灯一起变。切主题只改 `<html data-theme>` 一个属性，0ms 生效。
- **naive-overrides**：Naive UI 组件不吃 CSS 变量，得用它自己的 JS 主题入口喂数据——相当于组件库的「官方后门」。
- **import.meta.glob 懒加载**：Vite 把 24 幅画变成「按文件名取画」的函数，进哪个页面才下载哪幅——dist 里不用的画不会被打包。
- **字体子集化**：全量文楷几 MB，实际界面只用到几百个字；脚本只保留用到的字形，瘦到 45KB。
- **三向合并**：`git merge-file`（共同祖先、frontupdate 新版、frontend 新版三方对撞）自动融合「frontupdate 改了样式、frontend 改了逻辑」的文件，机器保证不丢行，人只核验双源都在。

## 踩坑批注

1. **CRLF**：Windows 下 diff 必带 `--strip-trailing-cr`，否则 223 假差异；merge-file 前先 `sed -i 's/\r$//'` 归一，否则整文件报冲突。
2. **pathspec 双前缀**：cwd 已在 `agent-platform/` 再写全路径 `agent-platform/frontend/x` → git 静默匹配空。用相对 cwd 的路径。
3. **E类文件直引 THEME_LIST**：LoginView 自己渲染主题按钮不走 ThemeSwitcher，C9 只改了 ThemeSwitcher 漏了它——C10 走查抓到（5 项），已修。教训：改公共状态出口，全 grep 引用方。
4. **worktree 无 node_modules**：Windows 下 `mklink /J` junction 复用主仓依赖再 build；删 junction 用 `rmdir`（只删链接不删真身）。
5. **dist 体积口径**：对比必须同源构建——基线 commit 起 worktree 实测（4.4M），不能拿记忆里数字。
