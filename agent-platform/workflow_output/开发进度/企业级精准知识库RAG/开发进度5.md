# 企业级精准知识库 RAG 开发进度 5

## P1 Step 3：结构化解析产物协议与精确定位

- 扩展 `ExtractedDocument/Section`，新增 `SectionLocator/BoundingBox`，统一保存解析器身份、源文件 Hash、标题树、节点类型、阅读顺序、页码、Sheet/Cell、跨页标记和可选 bbox。
- 新增 `StructuredDocumentExtractor`：PDFBox 逐页输出真实页码；Markdown/DOCX 保留标题层级；图片输出第 1 页 IMAGE 区域。无法可靠取得 bbox 时保持为空。
- Excel 每个数据行保存 Sheet、行号、Cell 起止范围和稳定阅读顺序；已有每行一 Section 行为不变。
- `DocumentParserService` 接入结构化解析并为 Tika/手工等旧路径补齐协议字段；复用上传阶段由后端计算的 `fileHash` 作为 `sourceHash`。
- 新增 V108 与 `ParseArtifactService`：解析 JSON 写文件存储，版本表只保存 parser version、artifact ref、SHA-256 和 parsedAt；历史无版本文档兼容跳过产物写入。
- `KnowledgeNodeWriter` 将 Section 层级/locator 合并进原有 metadata，L0/L2 均继承当前 `versionId` 和结构化 `nodeType`，不覆盖图片/文件回显字段。
- 安全限制：PDF 最多 2000 页、全文最多 2000 万字符；不执行宏、脚本或外部链接；不伪造视觉坐标。
