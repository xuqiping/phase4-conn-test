### B2. buildLlmKeyContext pipeline

`MemoryService` 新 `buildLlmKeyContext(MemoryScope readScope, String query)`，五步：

```
① QueryExpansionService.expand(query, MEMORY_EMBED_MODEL)
     → ExpandedQuery(canonicalQuery, qHalfs[])，多 qHalf 提 recall
② 粗筛：每 qHalf 跑 findTopKByAnchor（向量 top-K）+ findAnchorBm25（BM25）
     → RrfFusion.fuseWeighted（向量权重 > 词法权重）→ top-N（默认 40）
③ LLM 精排（rerank=true 时）：filterRelevantKeys 双维度筛
④ formatMemories 装 value + 注入（key-lang 感知）
⑤ MemoryQueryCache.getRerankKeys 缓存选中 key 列表（TTL 60s）
```

- [x] 异常降级：扩展挂→单 qHalf；向量挂→仅 BM25；都空→`return null`（不回退全量，同 EMBEDDING_VECTOR）。
- [x] 旋钮：`rag.memory.llm-key.rerank`（默认 true，false 跳 ③ 直接注 top-N）；`rag.memory.llm-key.coarse-top-n`（默认 40）。
