# 3.2 漏斗构建方法论

## I.06 步骤定义四原则

| 原则 | 说明 | 反例 |
|---|---|---|
| 用户视角 | 步骤定义基于用户行为而非页面/UI | "点击购买按钮"→应改为"发起购买" |
| 可归因 | 每步转化率变化可归属于某个产品改动 | 步骤定义含混无法归因→优化无依据 |
| 粒度适中 | 步骤不过粗不过细，4~7步为宜 | 15步漏斗→噪音太多看不清 |
| 埋点支撑 | 每步必须有对应埋点事件 | 步骤无埋点→无法度量→形同虚设 |

## I.07 时间窗口设计

### 常见时间窗口参考

| 漏斗类型 | 推荐时间窗口 | 理由 |
|---|---|---|
| 电商购买漏斗 | 24h~7天 | 用户可能比价后回来买 |
| 注册激活漏斗 | 1h~24h | 激活应该很快完成 |
| B端销售漏斗 | 30~90天 | B端决策周期长 |
| 内容消费漏斗 | 30min~1h | 打开→消费→互动应在短时间完成 |

### 时间窗口对转化率的影响

| 时间窗口 | 整体转化率 | 说明 |
|---|---|---|
| 1小时 | 5.2% | 严格，只算快速转化 |
| 24小时 | 8.7% | 常用 |
| 7天 | 12.1% | 宽松，包含犹豫后转化 |
| 30天 | 14.3% | 极宽松，可能混入重新进入的用户 |

**选择原则**：根据业务决策需要选择——如果关注"即时体验"用短窗口，关注"最终转化"用长窗口。[来源: Amplitude漏斗文档 | 置信度:🔍高]

## I.09 用户分组漏斗

| 分组维度 | 作用 | 示例 |
|---|---|---|
| 渠道 | 评估渠道质量 | 自然流量vs付费广告vs社交裂变 |
| 用户类型 | 区分新老用户 | 新客vs老客漏斗差异显著 |
| 平台 | 跨端对比 | App vs Web vs 小程序 |
| 版本 | 评估版本改版效果 | v3.0 vs v3.1转化率对比 |
| 地区 | 本地化差异 | 一线城市vs下沉市场 |

## 闭合vs开放漏斗选择

| 维度 | 闭合漏斗 | 开放漏斗 |
|---|---|---|
| 定义 | 同一用户同一会话按序完成 | 用户可在不同时间/会话完成 |
| 适用 | 一次性流程（注册/支付） | 长周期流程（B端销售/复购） |
| 转化率 | 偏低但精确 | 偏高但含"跳过再回来"的用户 |
| 典型错误 | 长周期流程用闭合漏斗→转化率被严重低估 | - |
