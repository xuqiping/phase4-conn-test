# 资产库公共选择与评分等级 · 用户操作手册

> 2026-08-18。四块功能：公共池选用 / 分享候选开箱即载 / 评分等级 / 复制管控。
> 技术侧见 [Feature Map](../feature-map/资产库公共选择与评分等级.feature-map.md)。

## 1. 图片/视频生成模块选公共池资产

**入口**：图片生成页 / 视频生成页 → 「从资产库选择」。

**步骤**：
1. 点开资产选择弹窗，顶部出现来源切换：「我的/共享项目 | 公共池」两枚按钮。
2. 点「公共池」→ 下拉列出公共池项目（名称含发布者、官方标记、资产数）。只显示你当前能用的项目（需审批未获批的不会出现），且只显示包含当前媒体类型（图片/视频）的项目。
3. 选项目 → 资产列表载入该项目资产（你以只读身份引用，不会改动原项目）。
4. 点选资产 → 完成选择。再切回「我的/共享项目」时选择会被清空，需重选。

**界面变化**：选择器顶部多一行来源切换；公共池项目下拉与资产列表样式与原有一致。

**常见异常与恢复**：

| 现象 | 原因 | 处理 |
|---|---|---|
| 公共池下拉是空的 | 没有对你开放且类型匹配的公共项目 | 属正常；找项目 OWNER 开放使用或申请审批 |
| 选完项目资产列表报错 | 项目刚被管理员移出公众池 | 关闭弹窗重开刷新列表；换别的项目 |
| 公共池资产点了没反应 | 你对该项目是「需审批」状态 | 联系发布者审批 |

## 2. 分享弹窗打开即显示候选用户

**入口**：资产项目页 → 「分享」。

**步骤**：
1. 点「分享」→ 弹窗打开的瞬间，候选用户下拉**直接展示最多 50 人**（已排除项目 OWNER、已有成员和你自己）。
2. 想找人：输入用户名片段 → 列表实时筛选（最多 20 条匹配）。
3. 清空输入框 → 恢复全量候选（不是空白）。
4. 选中用户 → 选角色 → 确认邀请。

**界面变化**：下拉下方提示「输入用户名筛选，最多展示 50 人」。

**常见异常与恢复**：

| 现象 | 原因 | 处理 |
|---|---|---|
| 打开后下拉还没出人 | 候选列表请求中 | 稍等片刻即出 |
| 找不到某人 | 该用户是 OWNER/已是成员/是你自己 | 属正常排除 |
| 想邀的人不在 50 人里 | 候选按上限截断 | 输入对方用户名精确筛选 |

## 3. 评分等级（A+/A/B/C/D）

**等级表**（未评分不显示等级）：

| 等级 | 分数 |
|---|---|
| A+ | 95-100 |
| A | 90-94 |
| B | 80-89 |
| C | 70-79 |
| D | 0-69 |

**在哪看**：
- **资产卡片**：拥有者分、成员均分两行，数值右侧各有一枚等级小胶囊。
- **详情抽屉**：评分摘要同样带徽章；「我的评分」旁是你已保存分数的等级。
- **打分时**：拖动分数滑杆，右侧「当前 xx 分 · x档」实时变化（94↔95 来回拖会看到 A↔A+ 跳档）；滑杆悬浮提示也带档位。已保存的徽章不会跟着拖动跳，只认你上次提交的分。
- **成员均分**：先四舍五入到整分再定档（两人评 94、95 → 均分 94.5 → 95 → A+）。

**等级快捷筛选**（资产矩阵筛选条）：
1. 筛选条第 3 个下拉「等级」，选项格式「A+（95-100 分）」等。
2. 选中某档 = 自动把分数区间填成该档范围（选 A+ 即 95-100）。
3. **等级是分数区间的快捷方式**：选中会覆盖你手填的分数上下限。
4. 清除等级选择（点 ×）→ **不会**清掉你手动填的分数区间，区间原样保留。

**常见异常与恢复**：

| 现象 | 原因 | 处理 |
|---|---|---|
| 卡片只有数字没有等级徽章 | 该资产（或该轨道）还没人评分 | 属正常，评过即出现 |
| 滑杆一打开显示 50 分 · D | 未评分时滑杆默认 50 分，50<D 档下限 70 | 属正常，拖到你想要的分即可 |
| 选等级后手动改了区间又选同档没反应 | 同档区间值相同，emit 值不变 | 先清除等级再改区间 |

## 4. 公众池复制管控（发布者视角 + 使用者视角）

### 4a. 发布时设置（项目 OWNER / 管理员）

**入口**：资产项目页 → 「发布到公众池」。

**步骤**：
1. 打开发布弹窗，在开放方式下方新增「复制权限」区。
2. 开关「允许公共用户复制资产」——默认开；重新发布时显示上次的选择。
3. 关掉 → 说明文案「关闭后公共用户仅可引用，不可复制副本；项目成员不受影响」。
4. 点「发布到公众池」→ 开关随发布生效。之后想改：先下架再重新发布，开关回显上次值可直接改。

**效果**：关闭后，公共用户（非本项目成员）只能引用你的资产到生成模块，不能把资产复制成自己项目的副本；你的项目成员和你自己不受任何影响。

### 4b. 公共池使用者视角

- 打开一个公共项目：若发布者关闭了复制，资产卡片上**不会出现**「复制到我的项目」按钮（不是置灰，是不渲染）——引用照常可用。
- 若你恰是该项目成员：复制不受限，按钮照常。

**常见异常与恢复**：

| 现象 | 原因 | 处理 |
|---|---|---|
| 公共项目看不到复制按钮 | 发布者关闭了允许复制 | 属预期；可联系发布者开启 |
| 刚发布关掉复制，按钮还在 | 页面未刷新 | 刷新或重进项目页即消失（后端也有 403 兜底） |
| 直调 API 复制返回「该项目不允许复制资产」(403) | 后端强校验拦截 | 属预期安全兜底，无绕过 |
| 老项目（功能上线前发布的）能复制吗 | 存量项目默认允许复制 | 能；发布者重新发布时可关闭 |
