# 3.4 AI增长实施路径

## 四维度准备度评估

### 维度1：数据准备度

| 等级 | 描述 | 能做什么 | 无法做什么 |
|---|---|---|---|
| D1 无数据 | 无行为埋点 | — | 任何AI增长 |
| D2 基础数据 | 核心事件埋点+用户属性 | 简单分群+规则触达 | 预测模型/智能触达 |
| D3 行为数据 | 完整行为路径+3个月+ | 预测模型+STO+智能触达 | 增长Agent/自动化实验 |
| D4 丰富数据 | 行为+交易+触达+反馈 | 全部AI增长能力 | — |

**最低起飞线**：D3级（3个月行为数据+日活10000+）。D2可做AI辅助但不适合AI驱动。

### 维度2：工具准备度

| 等级 | 描述 | 必要工具 |
|---|---|---|
| T1 手工运营 | 无自动化工具 | 至少接入MA工具 |
| T2 营销自动化 | MA平台（神策/Braze/Convertlab） | AI辅助增长 |
| T3 AI增强 | MA+LLM接入+预测模型 | AI驱动增长 |
| T4 Agent平台 | MA+LLM+Agent框架（LangChain/CrewAI） | Agentic增长 |

**最低起飞线**：T3级。T2只能AI辅助。

### 维度3：组织准备度

| 等级 | 描述 |
|---|---|
| O1 无增长团队 | 运营兼做增长，无专门团队 |
| O2 增长团队 | 有增长负责人+数据分析师+运营 |
| O3 AI增长团队 | 增长团队+AI工程师+ML模型 |
| O4 Agent增长团队 | 增长+AI+Agent运维+安全审核 |

**关键变化**：AI增长团队需新增"AI运营"角色——负责监控AI决策质量、处理AI异常、审核AI生成内容。

### 维度4：技能准备度

| 必要技能 | 说明 |
|---|---|
| 数据分析思维 | 看懂AI模型输出，不盲信 |
| 提示词工程 | 会写高效Prompt指导AI增长 Agent |
| 增长实验设计 | 理解A/B测试方法论，能审核AI实验方案 |
| AI安全意识 | 知道AI会幻觉、会偏执、会过度优化 |
| 成本意识 | 理解AI推理成本与增长ROI的平衡 |

## 落地路线图

### Phase 1 · AI辅助增长（1-3个月）

**目标**：在现有增长流程中嵌入AI辅助能力

| 行动 | 产出 | 前提 |
|---|---|---|
| 接入数据分析AI功能 | AI自动发现数据洞察/异常 | T2+D2 |

### Phase 2 · AI驱动增长（3-6个月）

**目标**：AI做决策+自动执行，人审核

| 行动 | 产出 | 前提 |
|---|---|---|
| 部署预测模型 | 流失预测/转化预测自动触发触达 | D3+T3 |

| 上线AI内容AB测试 | 100版文案自动测试 | T3+O3 |
| 建立AI审核流程 | 人审品牌/合规，AI管其余 | O3 |

### Phase 3 · Agent化增长（6-12个月）

**目标**：增长Agent端到端自主执行

| 行动 | 产出 | 前提 |
|---|---|---|
| 搭建增长Agent原型 | Agent自动执行增长任务 | T4+D4+O4 |
| 设定安全边界 | Agent行为护栏+预算上限+人审触发条件 | 全维达标 |
| 逐步扩大Agent自主权 | 从10%→50%→80%增长任务Agent化 | 持续验证 |
