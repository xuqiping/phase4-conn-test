## 本轮做了什么

### C1：数据模型 + 权限 seed + 常量（IC-14/IC-16）

- **Flyway V55** [V55__canvases.sql](../../../backend/src/main/resources/db/migration/V55__canvases.sql)：`canvases` 表（id IDENTITY / user_id / name / snapshot JSONB + BaseEntity 审计列 deleted/version）+ 索引 `(user_id,updated_at) WHERE deleted=0`（部分索引，跳过软删行）+ `canvas:write` 权限 seed（gated，仅 admin 默认有，照 V54 media:gen 范式）+ 回滚注释。
- **Canvas 实体** [Canvas.java](../../../backend/src/main/java/com/superprogrammer/canvas/entity/Canvas.java)：继承 `BaseEntity`，`snapshot` 用 `JsonbStringTypeHandler`（String↔jsonb，同 MediaGenTask.requestConfig）。
- **CanvasMapper** [CanvasMapper.java](../../../backend/src/main/java/com/superprogrammer/canvas/mapper/CanvasMapper.java)：纯 `BaseMapper`，ownership 过滤在 service 层。
- **SOURCE_CANVAS 常量** [StoredFileEntity.java](../../../backend/src/main/java/com/superprogrammer/file/entity/StoredFileEntity.java)：画布产出物（抽帧/截取/衍生/上传图）来源标记。
- **扩展（plan 隐含基建）**：snapshot CRUD 后端闭环，为 C2 前端提供端点——
  - DTO：`CanvasVO`（列表省 snapshot 重字段，仅详情带）/ `CanvasCreateRequest` / `CanvasSaveRequest`（snapshot ≤5MB 防撑爆）。
  - [CanvasService](../../../backend/src/main/java/com/superprogrammer/canvas/service/CanvasService.java)：create/list/get/save/rename/delete，**ownership 硬过滤**（普通用户只能操作自己的画布，admin 旁路看全量）；nodeCount 从 snapshot.nodes 派生；软删不级联清 stored_files（plan 联动清单）；保存/删除打日志（canvasId/userId/nodeCount）。
  - [CanvasController](../../../backend/src/main/java/com/superprogrammer/canvas/controller/CanvasController.java)：`/api/canvas` 全端点 `@RequirePermission("canvas:write")`（切面 403 兜底）。

### C2：画布底座前端（Vue Flow）+ 路由 + 导航（IC-1）

- **本地类型** [types/canvas.ts](../../../frontend/src/types/canvas.ts)：`CanvasNode/CanvasEdge/CanvasSnapshot` 扁平接口——**规避 vue-flow `Node` 默认泛型深递归 TS2589**（范式同 `types/workflow.ts` 的 WorkflowNode）。
- **CanvasBoard** [CanvasBoard.vue](../../../frontend/src/components/canvas/CanvasBoard.vue)：`@vue-flow/core` 画布 + Background 网格 + snap-to-grid + smoothstep 连线 + 拖拽增节点（调色板 dataTransfer）+ 手选删除（onNodeClick 跟踪 id，规避 Node.selected 联合类型不可达）+ 缩放/适应工具条 + `loadSnapshot/getSnapshot` 序列化（getViewport 是函数非 ref，1.41 API）。
- **CanvasView** [CanvasView.vue](../../../frontend/src/views/CanvasView.vue)：列表模式（我的画布卡片网格 + 新建/删除）↔ 编辑模式（路由 `/canvas/:id` 驱动）；节点调色板（5 类占位，C3 接属性面板）；保存/重命名接 API；**无权限兜底**（`canEdit=hasPermission('canvas:write')`，直访显示 403 卡片）。
- **路由** [router/index.ts](../../../frontend/src/router/index.ts)：`/canvas`（列表）+ `/canvas/:id`（编辑），同 video-gen 不按权限卡路由（菜单隐藏+页内 canEdit+API 403 三重兜底）。
- **Sidebar** [Sidebar.vue](../../../frontend/src/components/Sidebar.vue)：`canEditCanvas` gated 入口（AppsOutline 图标），仅 canvas:write 持有者可见。
- **API** [api/canvas.ts](../../../frontend/src/api/canvas.ts)：create/list/get/save/rename/remove 六端点类型+函数。

## 踩坑批注

| 坑 | 解 | 备注 |
|---|---|---|
| vue-flow `Node` 默认泛型 TS2589 深递归 | 本地扁平类型 `CanvasNode`（同 WorkflowNode 范式），`ref<CanvasNode[]>` | 直接 `ref<Node[]>` + spread 必爆 |
| `n.selected` 联合类型不可达 | 手选模式：onNodeClick 跟 `selectedNodeId` | 同 FlowCanvas 现有解法 |
| `getViewport` 是函数非 ref（1.41） | `getViewport()` 调用，非 `.value` | |
| vue-flow `zoomIn` 等签名与 DOM `@click` 不兼容 | 模板内联箭头 `@click="() => vfZoomIn()"` | 直接绑函数 TS 报错 |
| `npm run build \| tail` 吞退出码 | `> log; echo EXIT=$?; tail log` | tail 的退出码≠vue-tsc |
