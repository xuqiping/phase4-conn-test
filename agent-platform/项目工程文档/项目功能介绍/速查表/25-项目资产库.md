## 一句话

把提示词/剧本/图片/视频/音频当**资产**存进**项目**，用「类型 × 叙事角色」双轴归档，配**版本快照**（画布引用锁某版），画布节点能**入库**/**从库引用**，节点间还能 **@** 互引上游产出。

## 数据模型（Flyway V56–V59）

| 表 | 角色 | 关键字段 |
|---|---|---|
| `asset_projects` | 项目 | owner_id / narrative_roles(JSONB 五桶) |
| `asset_project_members` | 成员授权 | project_id/user_id/role(OWNER·EDITOR·VIEWER) UNIQUE |
| `assets` | 资产 | project_id/media_type/status(DRAFT·LOCKED·ARCHIVED)/current_version(乐观锁) |
| `asset_versions` | 版本快照 | asset_id/version/content(JSONB)/file_id/gen_meta |
| `asset_role_links` | 叙事角色挂载 | asset_id/role_key |
| `asset_bindings` | 画布↔库台账 | asset_id/node_id/canvas_id/kind(PRODUCED·REFERENCE) |

## 核心机制

- **双轴矩阵**：`GROUP BY media_type, role` 一条聚合返全图计数（不每格 count）；角色筛选走 `asset_role_links`（不查 JSONB）。
- **版本乐观锁**：`UPDATE WHERE current_version=?` 0 行=冲突→CONFLICT。画布引用存版本号，资产升版不影响已引用方。
- **咽喉点**：`AssetAclService.loadAccessible(projectId,userId)` 三判 owner/member/admin，否则 403。viewer 只读可 resolve 引用，写全拒。
- **一致性包**：主参考图+图集+标准描述+参数基线 → 局部合并入 `content.consistency` 产新版本（仅 人物/道具/场景 类额染）。
- **画布打通**：`AssetCanvasBridgeService` importFromCanvas（节点→资产+PRODUCED 绑定+重复三态 NEW_VERSION/NEW_ASSET）/ resolve（资产→版本快照，viewer 可读）/ usages（双向追溯）。
- **@引用**（S13）：`utils/interpolate.ts`——ancestors 反向 BFS+visited 防环 / interpolate 不递归替换+断链降级「【断链】」/ uniqueLabel L9 序号。占位符存 node id（重命名不断链），运行前前端插值，**后端零改动**。
- **剧本 AI 拆分场**（FR-006，模型供应商改造 Step7）：`AssetDetailDrawer`「AI 拆分场」入口（SCRIPT+canEdit）→ ModelSelector（optional 模式）选模型 → `scriptApi.breakdown(assetId, model)` 产新版本，content `breakdownModel` 回显所选；不选走后端 `asset.script-model` 默认。
