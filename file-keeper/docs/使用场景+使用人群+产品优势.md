# File Keeper 使用场景、适用人群与产品优势

File Keeper 不只是一个文件快速访问工具，它也是一个面向 Windows 桌面工作流的效率工具：一边帮助用户快速访问常用文件，一边帮助用户查看、筛选和关闭正在运行的应用程序。对于需要频繁在文档、项目资料、浏览器、终端和办公软件之间来回切换的用户来说，File Keeper 的价值不只是“找文件更快”，而是把“找文件”和“管应用”放进同一个工作台里。

---

## 产品定位

File Keeper 当前提供两条能力主线：

1. **常用文件快速访问**
   - 用卡片式界面管理高频文件
   - 支持分组、标签、搜索、排序、双视图和批量操作

2. **Windows 应用管理**
   - 查看当前运行中的应用程序
   - 按类别筛选、按列排序、批量选择和关闭
   - 提供列显示/顺序自定义、右键快捷操作和重要应用确认保护

这让 File Keeper 更适合承担“个人工作台入口”的角色，而不是单纯替代文件管理器。

## 核心使用场景

### 1. 项目文档与配置文件快速访问

**场景描述**：开发者需要频繁访问 README、接口文档、配置文件、脚本和会议记录。

**使用方式**：
- 将项目文档、配置文件和脚本加入 File Keeper
- 按项目创建分组，按用途添加标签
- 用打开次数、最近打开或自定义排序维持高频内容靠前
- 需要切换工作环境时，再配合应用管理页快速关闭不需要的浏览器、终端或测试窗口

**价值**：
- 常用资料可以一键打开
- 减少在文件夹、IDE 和多个应用窗口之间反复切换
- 同时管理“工作资料”和“当前工作窗口”

---

### 2. 学习资料与课程窗口管理

**场景描述**：学生、自学者和培训参与者需要同时处理讲义、笔记、作业、浏览器标签页、PDF 阅读器和会议软件。

**使用方式**：
- 按课程或阶段创建分组，例如“数据结构”“机器学习”“论文阅读”
- 使用标签区分“重点”“待复习”“作业”“资料”
- 切换到进程管理页查看当前打开的学习相关应用
- 一次性关闭不用的 PDF 阅读器、浏览器窗口或会议工具，保持桌面整洁

**价值**：
- 学习资料更容易集中管理
- 复习、查资料和交作业时切换成本更低
- 不需要再单独打开任务管理器清理学习环境

---

### 3. 设计素材与创作工作台整理

**场景描述**：设计师、内容创作者需要快速打开设计稿、素材库、参考图，并同时管理 Photoshop、浏览器、图片查看器、通讯工具等应用。

**使用方式**：
- 将 PSD、AI、参考图、交付文档统一收纳到 File Keeper
- 通过图标、分组和标签快速定位素材
- 在进程管理页按“图像”“媒体”“通讯”等类别筛选运行中的应用
- 关闭暂时不用的软件，减少桌面和任务栏噪音

**价值**：
- 文件与应用切换更顺手
- 找素材和整理工作区可以在一个工具里完成
- 对多应用并行工作的用户更友好

---

### 4. 办公文档中心与会议后清理

**场景描述**：办公人员经常要在报告、表格、演示文稿、浏览器、会议软件和即时通讯工具之间切换。

**使用方式**：
- 通过“最近打开”快速回到当前工作文档
- 用搜索定位特定报告、合同、模板文件
- 在进程管理页批量选择并关闭会后遗留的浏览器、会议软件或辅助工具
- 对重要应用保留确认机制，避免误操作

**价值**：
- 文档查找速度更快
- 会后清理窗口更直接
- 比“文件管理器 + 任务管理器”两头切换更高效

---

### 5. 多任务开发/测试环境收尾

**场景描述**：开发者或测试人员常常同时打开多个浏览器、终端、编辑器、接口工具和本地服务窗口。

**使用方式**：
- 用文件管理能力保留常用脚本、日志文件、接口说明和配置
- 在进程管理页按类别筛选浏览器、终端、文档工具
- 通过排序查看 CPU/内存占用较高的窗口
- 用单选、多选、全选/反选和批量关闭快速收尾
- 右键菜单可直接“显示到前台”“复制信息”“关闭进程”

**价值**：
- 更快识别当前工作会话中还开着哪些窗口
- 收尾和切换项目时更省时间
- 对频繁重建测试环境的用户很实用

---

### 6. 运维、技术支持与桌面排查

**场景描述**：运维、IT 支持或高级用户需要快速确认某个应用是否仍在运行、属于哪一类、是否能安全关闭。

**使用方式**：
- 在进程管理页查看应用名称、PID、窗口标题、内存和 CPU 信息
- 用类别筛选快速缩小范围
- 复制进程信息用于沟通、记录或工单描述
- 遇到权限不足时，界面会明确提示目标应用可能以更高权限运行

**价值**：
- 比只看任务栏或猜测窗口来源更可靠
- 常见排查信息能直接复制
- 对“知道要关哪个应用，但不想手动去任务管理器翻”的场景特别方便

## 进程管理当前已实现的能力

### 列表与信息展示
- 查看当前运行中的 Windows 应用程序
- 显示应用名称、PID、窗口标题、内存、CPU、类别等信息
- 支持空状态提示和错误提示

### 智能分类
- 支持 **13+ 应用类别**：浏览器、办公、文件管理器、终端、压缩、文档、媒体、图像、通讯、下载、游戏、系统、其他
- 内置 **400+ 进程映射**，覆盖常见 Windows 软件

### 筛选、排序与列自定义
- 支持下拉类别筛选和常用快捷筛选
- 支持按名称、类别、PID、内存、CPU、窗口标题排序
- 支持显示/隐藏列
- 支持在列设置弹窗中拖拽调整列顺序，并同步到表头和每一行

### 刷新与性能控制
- 支持手动刷新
- 支持自动刷新开关和刷新倒计时
- 页面不可见时暂停自动刷新
- 离开进程管理页时停止刷新并清空列表，减少非当前页面的性能开销

### 选择与关闭
- 支持单选、多选、全选、反选、取消选择
- 支持关闭单个应用和批量关闭多个应用
- 当前关闭方式是优先向窗口发送正常关闭信号，更适合日常桌面整理场景

### 安全与反馈
- 对重要应用提供确认机制
- 内置白名单保护逻辑，减少误关系统/关键应用的风险
- 如果目标应用权限更高，界面会给出“请尝试以管理员身份启动 File Keeper”这一类更明确的提示

### 右键快捷操作
- 显示到前台
- 复制进程信息
- 关闭进程

## 产品优势

### 1. 一个工具覆盖“文件入口 + 应用整理”
传统方式通常需要在文件管理器、资源管理器、任务管理器之间切换。File Keeper 把“打开文件”和“整理应用”放进同一个界面体系里，减少上下文切换。

### 2. 更接近真实工作流
很多用户的问题不是“文件打不开”，而是“资料和窗口都很多，切换太乱”。File Keeper 同时处理这两件事，更贴近日常工作场景。

### 3. 对 Windows 桌面多任务更友好
进程管理不是只罗列进程，而是围绕常见桌面应用做了类别识别、筛选、排序、批量关闭和右键操作，适合真实桌面工作流，而不是面向系统底层排查的专业任务管理器替代品。

### 4. 安全感更强
对于重要应用，File Keeper 会保留确认机制；遇到权限不足，也会给出更明确的原因提示，而不是只报一条难懂的错误。

### 5. 本地化、轻量、低打扰
文件数据和进程管理设置都保存在本地，不依赖联网；进程管理页也采用按需激活的方式，不打开该页时不会持续占用资源。

## 与传统工具的区别

| 维度 | File Keeper | 传统文件管理器 / 任务管理器 |
|------|-------------|------------------------------|
| 文件访问 | 常用文件一键打开 | 需要进入文件夹逐级查找 |
| 文件组织 | 分组 + 标签 + 排序 | 主要依赖文件夹层级 |
| 运行中应用查看 | 内置在同一应用中 | 需要切换到任务管理器 |
| 应用筛选 | 类别化查看，更接近日常场景 | 以进程视角为主 |
| 批量关闭应用 | 支持多选与确认保护 | 依赖任务管理器手动操作 |
| 界面风格 | 统一的工作台式体验 | 功能分散在不同系统工具 |

## 最佳实践

### 1. 文件管理和进程管理搭配使用
- 将常用资料固定在 File Keeper 中
- 开始工作前快速打开文件
- 结束工作后切到进程管理页清理窗口

### 2. 用分组和标签管理“长期资产”
- 分组适合按项目、课程、客户划分
- 标签适合表达用途、优先级和状态

### 3. 用进程分类做“工作区整理”
- 浏览器、终端、办公软件、通讯软件往往最适合类别筛选
- 批量关闭前先筛到一个类别，效率更高

### 4. 关注重要应用确认
- 对资源管理器、任务管理器等关键程序，建议保留确认思路
- 权限更高的应用如果无法关闭，优先检查是否需要管理员权限
