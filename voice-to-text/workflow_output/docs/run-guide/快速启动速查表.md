## 一、项目组成

## 二、前置依赖

1. **Node.js** >= 18
2. **Rust** >= 1.77（建议 [rustup](https://rustup.rs/) 安装）
3. **Visual Studio Build Tools**（Windows C++ 编译器）

## 三、首次启动（从零到跑起来）

> ⚠️ **所有 npm 命令都在项目根目录 `D:\AI Projects\AI-Projects\voice-to-text` 下执行**
> （即 `package.json` 所在目录；**不要**进 `src/` 或 `src-tauri/` 里跑 npm）。
> cargo 命令才需要进 `src-tauri/`。

```bash
# 0. 进入项目根目录（npm 命令的工作目录）
cd "D:\AI Projects\AI-Projects\voice-to-text"

# 1. 安装前端依赖
npm install

# 2. 下载语音模型（约 100MB，二选一）
npm run download-models                 # 方式一：自动下载脚本（需网络/代理）
# 或手动下载解压到 models/ 目录        # 方式二：见部署手册的模型下载地址

# 3. 启动开发（同时起 Vite 前端 + Tauri 桌面窗口，带热重载）
npm run tauri:dev
```

> Rust 依赖首次编译需几分钟；`sherpa-rs` 会自动下载预编译 C++ 库（约 50-100MB），需网络。

### Windows 编译环境变量（bindgen/libclang 报错时必看）

报 `Unable to find libclang` / `LoadLibraryExW failed` = 当前终端缺环境变量。
**PowerShell 当前窗口临时生效**（在 npm 命令前执行）：

```powershell
$env:LIBCLANG_PATH='D:\IT\anaconda\Library\bin'
$env:Path="D:\IT\anaconda\Library\bin;$env:Path"   # libclang 的依赖 dll 也在此目录
$env:ORT_CACHE_DIR='D:\dev-cache\ort'              # ONNX Runtime 缓存（防 C 盘撑爆）
$env:OAR_HOME='D:\dev-cache\oar'                   # PP-OCRv5 模型缓存
npm run tauri:dev
```

**永久生效**：逐条 `setx LIBCLANG_PATH "D:\IT\anaconda\Library\bin"`（其余同理）后
**关闭并重开终端**——setx 不影响已打开的窗口。

## 四、常用命令

| 命令 | 作用 |
|---|---|
| `npm run tauri:dev` | 开发模式（Vite 5173 + Tauri 窗口，热重载） |
| `npm run dev` | 仅启动前端 Vite（无桌面壳） |
| `npm run build` | 前端构建（vue-tsc 类型检查 + vite build → dist/） |
| `npm run tauri:build` | 打包安装包（详见[部署手册](../deploy/部署手册.md)） |
| `npm run download-models` | 下载语音模型到 models/ |
| `scripts/check_all.bat` | commit 前最小质量门（类型检查 + cargo check + 文档校验） |

## 五、开发端口 / 关键路径

- 前端 dev server：`http://localhost:5173`
- 前端代码：`src/stores/app.ts`（IPC 通信核心）、`src/components/*`
- 后端代码：`src-tauri/src/lib.rs`（命令注册）、`audio/`、`stt/`
- 日志：`%APPDATA%\com.ap.voicetotext\logs\`
- 打包产物：`src-tauri/target/release/bundle/`

## 六、前端 / 后端开发入口

**前端（`src/`）：**
- `stores/app.ts` — 核心状态，处理与 Rust 后端的 IPC 通信
- `components/Controls.vue` — 录音控制、设备选择
- `components/Transcription.vue` — 转写结果展示

**后端（`src-tauri/src/`）：**
- `lib.rs` — Tauri 命令注册（`start_recording` / `stop_recording` / `list_audio_devices`）
- `audio/capture.rs` — 音频采集抽象（cpal 麦克风 + WASAPI loopback）
- `audio/loopback.rs` — Windows 系统音频内录
- `stt/recognizer.rs` — sherpa-onnx 流式识别器，含重采样

## 七、常见启动问题

| 现象 | 原因 / 解决 |
|---|---|
| `Unable to find libclang` | 当前终端缺 `LIBCLANG_PATH`，见「三、Windows 编译环境变量」 |
| `libclang.dll could not be opened` | 只设了 LIBCLANG_PATH 没加 Path；把 `D:\IT\anaconda\Library\bin` 也加进 Path |
| 首次编译特别慢 | sherpa-rs 下载预编译 C++ 库，需网络；之后走缓存 |
| 识别结果显示 `[mock] 你好` | 模型加载失败回退演示模式，检查 `models/` 是否完整 |
| 点击开始录音闪退 | 检查 `models/` 目录存在且 4 个模型文件齐全 |
| 系统音频设备列表为空 | 仅 Windows 支持；需有活跃音频输出设备 |
