## 📋 项目概述

### 项目定位
**轻量级跨平台文件收藏管理器**，专注解决"常用文件快速访问"和"批量管理已打开文件"两大核心痛点。

### 核心价值主张
- **极致轻量**：8-12MB 打包体积，毫秒级启动
- **跨平台统一**：Windows/macOS/Linux 一致体验
- **独家功能**：一键关闭已打开文件（竞品未充分满足）
- **零学习成本**：开箱即用，3分钟上手

### 目标用户群体
1. **效率焦虑型职场人**（核心付费群体）：25-35岁白领，多项目并行
2. **跨平台开发者/设计师**：技术驱动，偏好轻量工具
3. **项目管理者/自由职业者**：批量管理刚需
4. **学生/研究生**：入门级但量大
5. **行政/文员/财务**：高频重复型工作
6. **极简主义者/数字洁癖**：品味驱动

## 🎯 核心需求分析

### 刚需功能（Must Have）
| 功能 | 用户痛点 | 付费意愿 | 竞品对比 |
|------|---------|---------|---------|
| **一键快速打开文件** | "桌面堆满文件，每次找东西翻半天" | ★★★★★ | Alfred/Listary 已验证 |
| **极速轻量不卡顿** | "Electron工具打开比我还慢" | ★★★★☆ | Tauri 技术优势 |
| **一键关闭已打开程序** | "任务栏乱七八糟，想关都找不到" | ★★★★☆ | **竞品空白** |

### 中刚需功能（Medium Need）
- 跨平台一致性（双平台用户核心痛点）
- 批量管理文件组（项目经理/设计师高频需求）
- 文件快速预览（高频但已有替代方案）

### 非刚需功能（Nice to Have）
- 标签/颜色标记
- 云同步配置
- 插件扩展（与产品定位冲突，明确不做）

### 反向需求（明确避开）
- ❌ 不做臃肿的插件生态（uTools教训）
- ❌ 不做复杂的脚本/自动化（Quicker劝退入门用户）
- ❌ 不做在线服务强依赖（隐私顾虑）
- ❌ 不做订阅制强制付费（用户抵触）

#### 2.1 数据层实现（Day 1）

**前端 Store**
```typescript
// stores/fileStore.ts
export const useFileStore = defineStore('file', {
  state: () => ({
    files: [] as FileItem[],
    currentGroupId: 'all',
  }),
  actions: {
    async addFile(file: Omit<FileItem, 'id' | 'createdAt'>) {
      const newFile = {
        ...file,
        id: uuid(),
        createdAt: Date.now(),
        openCount: 0,
      };
      this.files.push(newFile);
      await this.saveToStore();
    },
    async removeFile(id: string) {
      this.files = this.files.filter(f => f.id !== id);
      await this.saveToStore();
    },
    async openFile(id: string) {
      const file = this.files.find(f => f.id === id);
      if (file) {
        await invoke('open_file', { path: file.path });
        file.lastOpened = Date.now();
        file.openCount++;
        await this.saveToStore();
      }
    },
  },
});
```

**Windows实现**：

```rust
// platform/windows.rs
use windows::Win32::UI::WindowsAndMessaging::*;
use sysinfo::{System, SystemExt, ProcessExt};

#[tauri::command]
async fn get_processes_for_file(file_path: String) -> Result<Vec<ProcessInfo>, String> {
    let mut sys = System::new_all();
    sys.refresh_all();
    
    let mut result = Vec::new();
    
    for (pid, process) in sys.processes() {
        // 通过窗口标题匹配
        if let Some(title) = get_window_title(*pid) {
            if title.contains(&file_path) {
                result.push(ProcessInfo {
                    pid: pid.as_u32(),
                    name: process.name().to_string(),
                    window_title: Some(title),
                    associated_file: Some(file_path.clone()),
                });
            }
        }
    }
    
    Ok(result)
}

#[tauri::command]
async fn close_process(pid: u32) -> Result<(), String> {
    let mut sys = System::new_all();
    sys.refresh_all();
    
    if let Some(process) = sys.process(sysinfo::Pid::from_u32(pid)) {
        process.kill();
        Ok(())
    } else {
        Err("进程不存在".to_string())
    }
}
```
