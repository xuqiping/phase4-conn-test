# 知识库RAG检索能力增强 · 用户操作手册

> 面向使用者：每个功能=「入口→操作步骤→界面变化→预期结果」。异常与恢复见各节末。
> 前置：已登录且有对应权限（库成员=问答/检索；canManage=关系管理；owner/admin=连接器、重建）。

## 1. 文档关联（C1）

**入口**：知识库管理 →「文档」→ 文档行「关联」。
**步骤**：①选目标文档（可搜索）+关系类型（相关/依赖/引用等）；②保存；或打开「智能建议」逐条 采纳/忽略。
**界面变化**：文档详情出现关系列表；被关联文档反向也可见。
**预期**：之后问答命中任一文档时，答案材料自动带上关联文档内容（trace 可见「关系扩展」条目）。
**常见异常**：建边报「跨库/自环/重复」——系统拒绝同类边重复；删边后旧答案缓存自动失效，下次提问即更新。

## 2. 附件文档（C2）

**入口**：文档管理 → 上传时选择 索引模式=附件（ATTACHMENT），或直传附件类文件。
**步骤**：①上传文件；②**必填描述**（≤4000 字，说明这份附件是什么）；③保存后走正常解析。
**界面变化**：文档列表标题带 📎 徽标。
**预期**：提问命中描述或母文档时附件参与召回；答案需要原文时自动注入内容——纯文本直拼，图片附件走 AI 视觉描述（首次调用稍慢，之后有缓存）。计费记在文档上传者账上。

## 3. 多轮检索（C3）

**入口**：RAG 问答 Tab（自动生效，无需开启）。
**界面变化**：复杂问题下答案下方 trace 显示「第 1 轮/第 2 轮检索」与覆盖判定说明。
**预期**：材料够时一轮即止（与原来一样快）；不够时自动改写追问检索。合成黄金集实测：多开一轮 Recall 0.75→1.00。
**异常**：无——循环有界（轮数封顶），不会无限烧钱。

## 4. 上下文嵌入（C4）

**新文档**：自动生效——每个切片入库时自带「上文定位语」，指代类切片（「该产品……」）可被独立召回。
**存量库重建**：知识库管理 →「索引运维」Tab → 选库 →「重建上下文嵌入」→ 确认框显示 **chunk 数×单价成本预估** → 确认。
**界面变化**：运维面板出现重建 job 进度；文档详情切片预览首行出现定位语。
**预期**：重建完成该库召回质量提升；job 排队限速执行，可中途取消。
**异常**：误点——确认框就是防误触；已花的成本按实际完成 chunk 结算。

## 5. 多模态检索（C5）

**入口**：上传含图片的文档（PDF/Word 截图等）自动生效。
**界面变化**：检索调试/RAG 问答 trace 出现 IMAGE 通道命中。
**预期**：「这张截图说的是什么」类问题能召回图片本体（视觉向量参与 RRF 融合，与文本通道互补）。
**说明**：ColPali 视觉通道为实验特性（KB 级开关，默认关；启用后探活失败自动禁用，不影响主流程）。

## 6. 连接器（C6）

**入口**：知识库管理 → 自己创建的库（或 admin）行上「连接器」按钮 → 右侧抽屉。
**新建**：①「新建连接器」；②选类型并按表单填：
- URL 站点：种子地址（https://…，同域 ≤2 层爬取）；
- S3 网盘：Endpoint+Bucket+Prefix（可选）+AccessKey+SecretKey（兼容 MinIO/OSS/COS）；
- WebDAV：地址+账号+密码（公共目录密码可空）；
③选周期（每小时/每天 04:00/每周一/自定义六段 cron）；④可选开「源删同步删」；⑤创建。
**界面变化**：列表出现该连接器（运行中/已停用/错误 三态）；同步来的文档在文档列表带 🔌 徽标（悬停看源地址）。
**立即同步**：行上「立即同步」→ 提示已触发（异步），约数秒后「刷新」看结果摘要（新增/更新/复活/重试/隔离/删除/跳过/错误）。
**启停/删除**：停用保留配置与账本随时再启用；删除需二次确认——**已同步文档保留**，转为普通手工管理文档。
**凭证安全**：密钥加密存储、保存后不再回显；需要换凭证=新建或在后端更新接口替换。
**常见异常**：
- 状态「错误 ×N」：连续 N 轮同步失败已停调度。看结果摘要定位原因（如地址不通/凭证失效）→ 修好后「立即同步」自动复位重试；
- 文档被隔离（ISOLATED）：源端删除所致，默认保留本地记录但不召回；源端恢复后下轮自动复活重索引；开了「源删同步删」则直接走治理删除。

## 7. 全局问答（C7）

**入口**：RAG 问答 Tab → 检索范围选「全部知识库」（或跨多库选择）。
**界面变化**：答案顶部出现「共检索 N 个库」分解视图；引用列表标注来源库。
**预期**：各库分别检索作答再汇总（map-reduce），跨库问题一处问全；引用逐条核验过，答案不会张冠李戴。
**说明**：范围大时响应随库数增加；每库答案基于该库摘要+本地检索，互不串味。

## 功能联动速查

| 触发 | 变化 |
|---|---|
| 建边/换附件 | 答案缓存自动失效，下次提问即生效 |
| 源端文件更新 | 下轮同步自动建新版本并重索引（旧版可回溯） |
| 手工删除同步文档 | 不再被连接器复活 |
| 删除连接器 | 文档保留，🔌 徽标变普通文档 |
