- **做什么**：spawn（危险命令过 core-sandbox 审批门，非 Allow 一律拒）→ initialize 握手（超时 kill + 标 error）→ running；异常退出监听 → 标 error → 自动重启（超 3 次转 manual_required）；环形日志 ≤200 行；stop/restart/list_tools/logs。
- **文件**：`core-mcp/src/rpc.rs`（JSON-RPC 编解码）、`manager.rs`、`bin/mcp-fake-server.rs`（假 server，3 模式）、`tests/manager_process.rs`（5 个真进程集成测试）。
- **测试**：3 单测 + 5 集成全绿；workspace 全量测试通过；check_docs FAIL=0。
- **关键坑（已修）**：`supervise` 持 child 锁调 `wait().await`，`stop()` 的 `kill` 拿不到锁 → 死锁，测试挂 118s。改成 `try_wait` 轮询（100ms 间隔、每轮放锁）后 2.2s 跑完。**教训：跨 await 持 tokio Mutex 的地方，要考虑其他持有者是否需要插进来。**
