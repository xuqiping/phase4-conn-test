# 4.1 活动运营全流程SOP

## 适用场景
所有运营活动的标准化策划、执行、复盘流程。

## 8步流程

### Step 1：活动立项
- [ ] 明确活动核心目标（仅1-2个，SMART化）
- [ ] 确定活动类型（拉新/促活/转化/品牌/召回）
- [ ] 确定活动规模（S/A/B/C级）及对应资源
- [ ] 获得上级审批与跨部门对齐
- [ ] 输出：《活动立项表》（目标+类型+规模+预算+时间）

### Step 2：方案设计
- [ ] 选定活动玩法模板（限时/拼团/签到/PK/裂变/抽奖等）
- [ ] 设计活动规则（参与条件/奖励机制/时间安排/次数限制）
- [ ] 设计活动页面（主视觉/流程图/关键页面线框图）
- [ ] 设计奖励方案（奖品层级/中奖概率/预算分配）
- [ ] 输出：《活动方案文档》

### Step 3：资源盘点
- [ ] 预算确认（总预算+各模块预算分配）
- [ ] 技术资源（开发排期+测试时间）
- [ ] 设计资源（视觉设计+页面开发）
- [ ] 合作方资源（KOL/品牌方/渠道方对接）
- [ ] 输出：《资源甘特图》

### Step 4：活动搭建
- [ ] 后台配置活动（规则/奖品/时间/人群）
- [ ] 页面开发与联调
- [ ] 奖品/优惠券创建与测试
- [ ] 全链路测试（从入口→参与→中奖→到账→分享）
- [ ] 输出：《测试用例与测试报告》

### Step 5：预热推广
- [ ] 站内预热（开屏/Banner/弹窗/Push文案）
- [ ] 站外推广（社交媒体/KOL/广告投放）
- [ ] 种子用户邀请（VIP/核心用户提前体验）
- [ ] 输出：《推广排期表》

### Step 6：活动执行
- [ ] 上线前最终检查（入口/规则/奖品/监控）
- [ ] 实时监控Dashboard（参与人数/转化率/奖励消耗/GMV）
- [ ] 每日站会（15分钟同步数据+问题+调整）
- [ ] 应急响应（技术故障/奖品超发/负面舆论→启用Plan B）
- [ ] 输出：《活动日报》

### Step 7：活动下线与收尾
- [ ] 按时下线（关闭入口/停止计奖）
- [ ] 未发放奖励的补发与核查
- [ ] 活动页面归档/下线
- [ ] 用户反馈收集
- [ ] 输出：《活动收尾清单》

### Step 8：复盘
- [ ] 目标达成度（实际 vs 目标）
- [ ] 过程指标分析（参与率/转化率/分享率/各环节漏斗）
- [ ] ROI计算（产出/投入，包含隐性成本）
- [ ] 负面效应评估（活动后活跃度塌方/价格锚点/毛利侵蚀）
- [ ] 沉淀资产盘点（可复用模板/素材/用户数据）
- [ ] 输出：《活动复盘报告》
