## 三、傻瓜式部署步骤（照着勾）

### Step 0 · 准备服务器

- [ ] 系统更新；防火墙放行需要的端口（列出：__________）
- [ ] 创建运行用户 / 目录：<如 `/opt/<项目名>`>

### Step 1 · 装依赖软件（按"软件清单"逐个装）

- [ ] JDK —— 验证：`java -version`
- [ ] Node.js —— 验证：`node -v && npm -v`
- [ ] Redis —— 验证：`redis-cli ping` 返回 `PONG`
- [ ] MySQL —— 验证：`mysql -u root -p` 能进
- [ ] Nginx —— 验证：`nginx -v`

### Step 2 · 放项目代码 & 配置

- [ ] 拉代码到服务器：`git clone <仓库地址> <路径>` 或上传打包代码
- [ ] 改配置文件（数据库密码、Redis 地址、密钥等）：<具体哪个文件，如 `.env` / `application.yml` / `config.js`>

### Step 3 · 建库建表（用 Flyway）

- [ ] 执行迁移：<如 `mvn flyway:migrate`，或后端启动时自动迁移>
> 📌 表结构说明见各功能的 Feature Map「数据库表与 SQL 注解（Flyway）」。

### Step 4 · 构建

- [ ] 后端打包：<如 `mvn clean package -DskipTests`>
- [ ] 前端打包：<如 `cd frontend && npm run build`，产物在 `frontend/dist/`>

### Step 5 · 启动

- [ ] 启动依赖：Redis、MySQL
- [ ] 启动后端：<如 `nohup java -jar app.jar > app.log 2>&1 &`>
- [ ] 部署前端：把 `dist/` 拷到 Nginx 目录，`nginx -s reload`
- [ ] 验证：浏览器打开 <http://你的域名或IP>，看到首页算成功

### Step 6 · 设开机自启（推荐）

- 后端：<systemd 服务 / `pm2` / docker `restart=always`>
- Redis/MySQL：<设为系统服务>
