## 本轮目标

Step 5 媒体链路（提交/结算/退款）：图/视频任务带 gid，估价预检 + 结算组池扣费 + 失败退款 + BACKSTOP 兜底。

## 实现内容

- **提交入口**：`MediaGenController` 两提交接口 + `projectGroupId` 透传；`MediaSubmitRequest`/`ImageSubmitRequest` +字段；`MediaGenTaskService.submit/submitImage` 新重载（旧签名委托 null=个人现状，零调用方破坏）。预检分派：gid 空→`requireAffordable`，非空→`requireAffordableGroup`（非成员 403 / 组池尽 40201，在闸门 acquire 前）；组池余额直接喂 L7 在途闸门（与个人余额同语义）。
- **组任务三重预检**（`doSubmit`/`doSubmitImage`，估价值，不足即拒 task 不建）：①成员身份（入口已验）②组池余量 `poolBalance < est` → INSUFFICIENT_POINTS「项目组积分不足（预估消耗 N）」③成员限额余量 `used + est > quotaLimit` → BAD_REQUEST「超出组长配置的成员积分限额」。两道预检独立，组池够但限额超照拒。
- **估价快照**：`estimateVideoPoints/estimateImagePoints`（PricingService+PointsRatioService，**积分口径**非金额——与回收在途上限/预检同源，免两处换算漂移）；SECOND 模式按 duration，TOKEN 模式提交期无 token 维度/价表缺价记 0+WARN（保守容忍，坑表既定）；个人任务也落 `estimated_cost`（V133 列）。估价 helper catch Exception 记 0。
- **结算**：`MediaBillingService` 11 参 `chargeMedia`——gid 非空且积分>0 → `chargeGroup`（**幂等键 `media-charge-{taskId}`**，429 退避重投不双扣，同个人路径 uq_ledger_ref 语义）；残余竞态（提交预检已过、结算时组池尽/超限额抛 BusinessException）→ **BACKSTOP 兜底**：全差额扣组长个人（`backstop(groupId, ownerUserId, false, ...)`）+ 组流水 BACKSTOP 行（不动组池、不计 used，V133 对账排除口径）——媒体成本已真实发生（视频已生成），取兜底不取「FAILED 让平台亏钱」；组长个人也不足/组已删 → 兜底抛 → 外层记 FAILED usage 返回 null。usage record 14 参带 gid。
- **退款**：5 参 `refundMedia` → `refundGroup`（组池回加 + used 回减 + REFUND 流水，幂等键 `media-refund-{taskId}`）；worker `markSucceeded` 落库失败撤销链路同样传 gid。视频/图片 worker 结算均传 `task.getProjectGroupId()`。
