# Security Strategy · DevPilot 安全策略

> 上级：[PRD.md](PRD.md)。安全是前置设计不是事后补丁；Phase 2 据此出检查清单，Phase 3 逐项验证。
> last_updated: 2026-08-13

## 1. 威胁模型（三大面）

| 面 | 威胁 | 影响 |
|---|---|---|
| 本地执行面 | agent 误删/越权读写用户文件、执行危险命令 | 用户数据丢失（口碑死穴） |
| 计费面 | Token 计量被篡改/绕过、重复扣费、薅体验金 | 直接经济损失（商业模式命门） |
| 生成物面 | 产出的项目带漏洞上线（密钥硬编码/无鉴权/数据库裸奔） | 用户出事连坐平台 |

## 2. 本地执行安全（对应 FR-001/006/009/012）

1. **目录白名单**：默认仅项目目录可读写；越界操作暂停弹审批（AC-001）。白名单存 core-state，用户可见可改。
2. **命令审批两档**（AC-010/011）：「每步都问」逐条批准；「自动走」模式下危险命令清单（rm -rf / curl|sh / 改系统目录 / 杀进程等）仍强制弹批。
3. **系统级加固**：macOS 用 Seatbelt 沙箱子进程；Windows 用 Job Object + 受限令牌 + 目录 ACL。MVP 先落目录白名单+审批档，Seatbelt/Job Object 为 Phase 3 高危任务（见 plan 坑点预判）。
4. **网络白名单**：任务期出网按域名白名单，默认仅依赖源（npm/pip/crates 等）（AC-007）。
5. **密钥脱敏**：secrets 注入进程环境变量，不出现在对话/日志/代码/快照；输出流实时脱敏（AC-014）。

## 3. 计费与账号安全（对应 FR-041，ADR-003）

1. **服务端权威计量**：客户端不持有任何上游 API Key，全部 LLM 调用经自家模型网关；网关按上游返回 usage 入账，客户端本地账本只是展示镜像 + 对账。
2. **幂等与防重**：写操作必带 idempotency_key；钱包扣减走乐观锁（version 列）+ 事务。
3. **支付安全**：充值回调服务端验签；金额以分为单位整数；退款冲正走人工调整账本（kind=4）。
4. **防薅**：体验金限新设备+新手机号双因子；单任务 Token 上限可配；异常消耗速率触发熔断暂停并通知用户。
5. **账号**：JWT access 15min + refresh 7 天（沿用通用约束）；验证码限频；密码 BCrypt。

## 4. 生成物安全（对应 FR-040 安全卡点）

上线前强制扫描（L2+ 不可跳过，AC-044）：
- 密钥硬编码（gitleaks 规则集）
- 鉴权缺失（路由级探测：无鉴权可访问的敏感端点）
- 数据库/端口暴露（配置静态分析 + 端口探测）
- 依赖漏洞（OSV 数据库比对）
未过项 → 阻止发布 + 大白话修复清单。

## 5. 供应链与依赖安全

- Rust：`cargo audit` 入 CI；前端：`npm audit`；依赖锁定文件必交。
- 模型供应商：多供应商冗余 + 国产兜底；上游 Key 加密落盘（AES-GCM），仅网关服务可读。
- 合规：转售模型 API 的资质与数据出境评估列为 Phase 2 前置任务（责任人：用户本人决策）。

## 6. 隐私与数据

- 项目代码/产物全在用户本机，云端零代码存储（卖点+避险）。
- 遥测默认关闭，开启需明示同意；日志本机留存 30 天自动清理。

## 7. 漏洞管理

- 安全响应：security@ 邮箱 + 72h 响应承诺（L3 要求）。
- 客户端自动更新带签名校验；高危漏洞强制更新通道。

## 8. 术语表

| 术语 | 大白话 | 简单案例 |
|---|---|---|
| Seatbelt / Job Object | macOS / Windows 系统自带的「关程序的小黑屋」 | agent 进程碰不到你的照片文件夹 |
| 乐观锁 | 改余额时核对版本号，防止两个人同时扣出错 | 并发扣费不超扣 |
| 验签 | 验证支付回调确实是微信/支付宝发的 | 伪造「已付款」通知无效 |
| 熔断 | 消耗速度异常时自动拉闸 | 死循环任务烧钱被自动暂停 |
| gitleaks / OSV | 扫密钥泄露 / 扫依赖漏洞的公开规则库 | 提交里的密码被揪出来 |
