## 一、打包命令

```bash
npm run tauri:build
```

产物位置：

```
src-tauri/target/release/bundle/
├── msi/   voice-to-text_0.1.0_x64_en-US.msi      # Windows MSI（推荐）
└── nsis/  voice-to-text_0.1.0_x64-setup.exe       # Windows NSIS（有 DLL bug，不推荐）
```

> `target/release/` 只有执行过 `tauri:build` 后才生成（开发态只有 `target/debug/`）。

## 二、打包前检查清单

1. **改 Bundle Identifier**：`src-tauri/tauri.conf.json` 的 `identifier` 不能是默认 `com.tauri.dev`，改成唯一值（如 `com.ap.voicetotext`），否则报错：
   > `The default value com.tauri.dev is not allowed as it must be unique across applications.`
2. **模型文件就位**：`models/` 目录存在且完整，否则运行时无法加载识别器。

## 三、国内网络打包注意事项

Tauri 需从 GitHub 下载 **WiX**（MSI 工具）和 **NSIS**（安装包工具），国内不走代理会超时。设代理后打包：

```bash
# Git Bash / WSL
export HTTP_PROXY=http://127.0.0.1:7890
export HTTPS_PROXY=http://127.0.0.1:7890
npm run tauri:build
```

```powershell
# PowerShell
$env:HTTP_PROXY="http://127.0.0.1:7890"
$env:HTTPS_PROXY="http://127.0.0.1:7890"
npm run tauri:build
```

> `7890` 换成你自己代理端口。

## 四、⚠️ 关键：NSIS 安装包 DLL 缺失问题

经实际验证，Tauri v2 的 NSIS（`.exe`）**不包含**运行时 DLL，安装后无法运行；**MSI** 能正确包含所有 DLL。

| 对比项 | MSI `.msi` | NSIS `.exe` |
|--------|-----------|-------------|
| 安装包大小 | ~8.5 MB | ~2.0 MB |
| 包含 DLL | ✅ 全部 | ❌ 缺失 |
| 安装后运行 | ✅ 可用 | ❌ 缺 DLL 无法启动 |
| 推荐 | ⭐ 推荐 | 不推荐（当前有 bug） |

**结论：优先用 MSI 分发，或手动分发绿色版。**

## 五、产物体积参考（本项目实测）

`target/release/` 关键文件：

| 文件 | 大小 | 说明 |
|------|------|------|
| `app.exe` | 8.9 MB | 主程序（打包后改名 voice-to-text.exe） |
| `onnxruntime.dll` | 11 MB | ONNX Runtime 推理引擎 |
| `sherpa-onnx-c-api.dll` | 3.6 MB | sherpa-onnx C API |
| `sherpa-onnx-cxx-api.dll` | 182 KB | sherpa-onnx C++ API |
| `onnxruntime_providers_shared.dll` | 23 KB | ONNX 共享提供程序 |
| `cargs.dll` | 136 KB | 命令行参数解析 |

安装包**不含**语音模型（约 100MB），安装后仍需单独放置 `models/`。

## 六、正常打包配置（不含模型）

`src-tauri/tauri.conf.json` 的 `bundle`：

```json
{
  "bundle": {
    "active": true,
    "targets": "all",
    "icon": ["icons/32x32.png", "icons/128x128.png", "icons/128x128@2x.png", "icons/icon.icns", "icons/icon.ico"]
  }
}
```

> `targets: "all"` 同时生成 MSI + NSIS。只需 MSI 可改 `"targets": ["msi"]`。

## 七、分发方式

### 方式一：MSI + 单独发模型（推荐，网络分发）

安装包小巧，适合网络传输。

1. `npm run tauri:build` 生成安装包
2. 发 `voice-to-text_0.1.0_x64_en-US.msi` 给用户（**不要发 NSIS .exe**）
3. 单独把 `models/` 压成 zip 发给用户
4. 用户装 MSI 后，将 `models/` 解压到安装目录（如 `C:\Program Files\voice-to-text\models\`）

- 优点：安装包小，下载快，MSI 含完整 DLL
- 缺点：用户需手动放模型，多一步

### 方式二：模型打包进 MSI（一键安装）

希望用户零配置、双击即用时用。

**改 `tauri.conf.json`，加 `resources` 并指定 `targets: ["msi"]`：**

```json
{
  "bundle": {
    "active": true,
    "targets": ["msi"],
    "resources": { "../models": "models" },
    "icon": ["icons/32x32.png", "icons/128x128.png", "icons/128x128@2x.png", "icons/icon.icns", "icons/icon.ico"]
  }
}
```

> 只打 MSI 是为跳过有 bug 的 NSIS。

重新 `npm run tauri:build`：

| 对比项 | 方式一（不含模型） | 方式二（含模型） |
|--------|---|---|
| MSI 大小 | ~8.5 MB | ~115 MB |
| 用户操作 | 装后手动放 models/ | 一键即用 |
| 模型位置 | 安装目录/models/ | 安装目录/models/ |

`lib.rs` 已支持从**可执行文件目录**查找 `models/`，**不需要改代码**。

### 方式三：绿色版（免安装）

不想做安装包时，直接复制文件：

```
voice-to-text/              # 任意文件夹名
├── voice-to-text.exe       # 从 target/release/ 复制
├── models/                 # 必须
└── （同目录所有 .dll，见第五节）
```

> 手动分发建议把 `target/release/` 下所有 `.dll` 一并复制。

### 如何选

| 场景 | 推荐 |
|------|------|
| 网络分发（微信/邮件） | 方式一（MSI + 单独模型） |
| U 盘 / 局域网共享 | 方式二（MSI 一体包） |
| 给用户最简体验 | 方式二 |
| 模型常更新 | 方式一（分开更新） |

## 八、常见打包问题

| 问题 | 解决 |
|---|---|
| `com.tauri.dev is not allowed` | 改 `identifier` 为唯一值 |
| `failed to bundle timeout: global` | 设代理后重试（见第三节） |
| 用户装后缺 DLL | 改用 MSI；或绿色版带齐所有 .dll |
| 识别为 `[mock] 你好` | 模型路径/文件问题，检查 models/ |
