# 知识库模型选择与保密权限 · 测试方案（人工）

> Phase 3 预处理产出（2026-08-18）。覆盖 [plan](../plans/知识库模型选择与保密权限.plan.md) L1-L6 联动 + 旁路安全。
> 前置账号：owner（库创建者）、member-read（只读授权）、member-write（写授权）、member-manage（管理授权）、admin。
> 自动化已覆盖 9 格权限矩阵/保密五行矩阵/模型校验；本方案只测机器测不了的 UI 与链路。

## A · 只读越权修复回归（L1）

| # | 步骤 | 预期 |
|---|---|---|
| A1 | member-read 打开知识库页 → 文档抽屉 | 上传区/直传/新版本按钮**不可见**（刷新后） |
| A2 | A1 直调 `POST /api/knowledge/documents`（带文件） | 403 |
| A3 | member-write 同页 | 上传可见；「治理/解除隔离/删除文档」不可见 |
| A4 | member-manage 同页 | 治理/授权可见；KB 行「编辑/删除」**不可见**（仅 owner/admin） |
| A5 | owner 给 member-read 加写授权 → member-read 刷新 | 上传按钮出现（反向：撤销→消失） |

## B · 模型下拉全链路（L4/L5）

| # | 步骤 | 预期 |
|---|---|---|
| B1 | 新建 KB → embedding 输入 | 是**下拉**（/llm/models/active?category=EMBEDDING），含「跟随全局默认」空选项 |
| B2 | 选非默认模型建库 → 上传文档 → 索引完成 → 检索调试命中 | 检索正常（索引用所选模型） |
| B3 | 已有文档的库换 embedding 模型保存 | 顶部横幅警告「需重建索引」；重建后横幅消失、检索恢复 |
| B4 | 空库换 embedding 模型 | 无横幅（无失配面） |
| B5 | 表单选「问答模型」（category=CHAT）→ /ask 提问 | 回答生效（Trace/日志 model 字段=所选模型）；不选=全局默认 |
| B6 | 问答模型所选模型后来下线 | 回退全局默认不报错（active 列表已无该项，表单回显空） |

## C · 保密四旁路 + 唯一出口（L3/L6）

| # | 步骤 | 预期 |
|---|---|---|
| C1 | owner 开「保密库」开关（KB 表单） | 保存成功；PUBLIC 库时开关**禁用**（互斥） |
| C2 | member-read（或 member-write）看该库 | 库卡片/列表带锁图标徽标 |
| C3 | 成员开文档列表 | 标题/类型/状态/时间可见（当目录）；**无 fileRef/下载入口** |
| C4 | 成员直调 `GET /documents/{id}/asset` | 403 `KNOWLEDGE_CONFIDENTIAL_DENIED`，文案不泄漏库内文档数/标题 |
| C5 | 成员直调 `GET /documents/{docId}/nodes`、`POST /retrieve` | 均 403 |
| C6 | 成员 chat 选该库提问（kbIds） | **问答正常**，引用帧正常显示，**无下载原件按钮** |
| C7 | 多库混选（1 保密+1 普通）提问 | 普通库引用有下载钮、保密库无；全保密→全无 |
| C8 | 检索调试面板 | 保密库选项灰显+原因提示；owner 不受限可选 |
| C9 | owner 关保密开关 | 成员四旁路全部恢复（可逆）；正在浏览的成员下一步操作即通 |
| C10 | 转保密前已上传文档的 member-write | 同样只剩问答出口（已上传不例外） |

## D · 管理授予位（L2）

| # | 步骤 | 预期 |
|---|---|---|
| D1 | owner 授 member-manage「管理」位 | 该成员可见「授权」按钮，可管理该库授权/治理 |
| D2 | D1 成员尝试删库/改库名 | 403（授予位不含销毁库） |
| D3 | D1 成员再授 manage 给第三人 | 允许（保留可授）但审计日志有 kb_grant 记录 |
| D4 | owner 撤销 D1 授权 | 立即失效（下一步 403） |

## 回归红线

- 老库（升级前建）不勾保密：行为与升级前完全一致（DEFAULT FALSE）。
- PUBLIC 库问答/引用链路零变化。
- owner/admin 全程无感（所有收紧只针对成员）。
- admin 审计页可检索 kb_grant/kb_revoke/kb_confidential 切换记录。
