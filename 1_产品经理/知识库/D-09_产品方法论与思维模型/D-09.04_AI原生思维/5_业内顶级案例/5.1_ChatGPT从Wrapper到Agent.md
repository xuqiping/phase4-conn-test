# 5.1 ChatGPT：从Wrapper到Agent的AI Native进化

## 基本信息

- **时间**：2022.11–2026
- **主角**：OpenAI（Sam Altman / 产品团队）
- **产品**：ChatGPT

## 背景

ChatGPT 2022年底上线时，本质就是一个Wrapper——在GPT API外套了一层对话UI。2023-2024年间，用户留存率持续下降（"用完即走"），面临与所有AI Wrapper相同的困境：用户不知道问什么、AI幻觉频发、工作流断裂。

## AI Native进化路径

### 阶段一：Wrapper时代（2022-2023）
- 纯对话界面，空白画布综合征严重
- 用户留存靠好奇心驱动，缺乏持续使用场景
- AI角色 = 被动回答器

### 阶段二：Copilot尝试（2023-2024）
- 推出GPTs/GPT Store——试图让用户自定义AI角色
- 加入代码解释器、联网搜索——给AI安上"眼和手"
- 但核心仍是"你问我答"模式

### 阶段三：Agent化重构（2025-2026）
- 推出Operator（AI自主浏览网页完成任务）、Deep Research（AI自主多步推理检索）
- 从"用户提问→AI回答"到"用户给目标→AI规划+执行+反馈"
- AI角色 = Proactive Agent，主动规划任务步骤
- 引入Tool Use + Memory + 护栏机制——完整的驾驭工程落地

## 对AI原生思维的核心启示

1. **Wrapper终局是留存困境**：好奇心驱动的DAU不可持续，必须重构工作流
2. **Tool Use是AI Native的关键跳板**：给AI安上"眼和手"是从Wrapper到Agent的转折点
3. **Proactive Agent取代被动响应**：用户不给指令时AI也要主动工作
