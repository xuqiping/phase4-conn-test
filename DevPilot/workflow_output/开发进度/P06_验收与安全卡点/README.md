# P06 验收与安全卡点 · README

> 受众 B（用户类）。功能是什么 / 怎么用 / 出问题怎么办。

## 一句话

项目造完不能直接发布：先过安全扫描，再逐项验收，发现问题圈出来让 AI 修，修完重新验，全通过才放行发布。

## 覆盖的 FR

- **FR-033 验收清单与修复闭环**：测试方案 → 可点检的清单 → fail 自动生成修复任务 → 修完重置重验。
- **FR-040 验收/发布双门禁**：build→accept 有安全门禁（L2/L3 强制）；accept→deploy 需清单全 pass/na（内核二次校验）。
- **FR-052 安全扫描与自动冒烟**：静态扫描+依赖审计+密钥脱敏；Playwright 自动冒烟（无 Node 时降级人工）。

- 数据：SQLite L9 迁移建 `acceptance_items / acceptance_runs / security_scans`；L10 给 `tasks.source` 加 'fix'。
- 门禁在 Rust 侧命令里强制校验，前端按钮只是体验层（纵深防御）。
- 冒烟脚本生成到 `.devpilot/tmp/` 临时执行，截图留证据，跑完即删。
