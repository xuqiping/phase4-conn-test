# 部署检查清单（生产/新环境一次性动作）

> 2026-08-10 合并收尾项 13 建档。按序执行；每步带验证命令。运维手册见 [运维手册.md](运维手册.md)。

## 1. 环境变量（fail-closed，缺一 backend 拒启动）

| 变量 | 要求 | 验证 |
|---|---|---|
| `JWT_SECRET` | 随机 64 字节 base64 | 启动无 JwtUtil 报错 |
| `DB_PASSWORD` | PG 账号密码 | flyway 迁移全 success |
| `RUNTIME_CALLBACK_TOKEN` | 与 sidecar 一致 | sidecar 回调非 401 |
| `AUDIT_HMAC_KEY` | **≥32 字符强随机**（审计哈希链 HMAC；泄露=链可伪造，轮换需配套链校验窗口） | 启动无 AuditHashChainService 报错 |

## 2. PG 非超管账号 agent_app（安全基线 V90/V92 REVOKE 生效前提）

V90（audit_logs REVOKE）与 V92（points_ledger REVOKE UPDATE/DELETE/TRUNCATE + balance CHECK）对 **owner/超管无效**——必须用非超管账号跑业务才生效：

```sql
CREATE ROLE agent_app LOGIN PASSWORD '<强密码>';
GRANT CONNECT ON DATABASE agent_platform TO agent_app;
GRANT USAGE ON SCHEMA public TO agent_app;
GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO agent_app;
GRANT USAGE, SELECT ON ALL SEQUENCES IN SCHEMA public TO agent_app;
-- 之后执行的迁移 REVOKE 才会落到 agent_app
```

- 切换：`DB_USER=agent_app` + `DB_PASSWORD` 换值；**迁移用账号须保留 owner**（flyway 用 postgres 跑或授予建表权——建议：flyway 与业务同账号前，先用超管把迁移跑完再切）
- 验证：`SELECT current_user;` 为 agent_app；`DELETE FROM points_ledger LIMIT 1` 应 permission denied

## 3. ffmpeg（视频剪辑 media.edit）

- 版本 **≥4.4**（`adelay all=` 需要）；须有 libx264 + aac
- Linux：`apt install ffmpeg` 或静态包；验证 `ffmpeg -version`
- Windows 服务器：设 `MEDIA_EDIT_FFMPEG_PATH` 指到 ≥4.4 的 ffmpeg.exe（PATH 首个可能是 ImageMagick 捆绑旧版）
- 字幕字体：`MEDIA_EDIT_FONT_FILE` 可覆盖；默认按序探测常见 CJK 字体，全缺+有字幕=渲染 fail-fast
- 验证：提交单段剪辑任务 → SUCCEEDED

## 4. IMAGE provider + 生图价表（生图功能）

admin 后台：
1. 「全局模型供应商」建 **IMAGE 类** provider（ctaigw endpoint + key）
2. 模型：`Doubao-Seedream-5.0-lite` / `Doubao-Seedream-5.0-pro`（pro 尺寸 1K/1.5K/2K）
3. 「计费价表」配两模型 **price_per_image** 价目（缺价表不阻生成但不扣费）
4. 授用户 `media:gen` 权限；剪辑另需 `media:edit`
- 验证：生图一页提交 → 产物逐张下载

## 7. 上传/下载安全行为变更（合并后生效，用户可感知）

- 上传扩展名白名单：html/svg/js/exe/无扩展名拒收（40010）
- 下载危险类型强制 attachment + `X-Content-Type-Options: nosniff`
- 登录：同账号 5 次失败锁 15min；同 IP 1h>20 次封禁；**单点登录默认开**（新登录踢旧会话）
- 注册密码策略：四要素复杂度+弱密码字典（存量账号登录不受影响）
