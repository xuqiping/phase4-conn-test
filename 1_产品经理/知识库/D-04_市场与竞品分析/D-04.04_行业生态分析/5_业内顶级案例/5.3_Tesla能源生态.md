# Tesla能源生态

## 案例背景

- **公司**：Tesla Inc.
- **生态类型**：从电动车到"能源+AI+制造"纵向整合生态
- **时间线**：2008-2025
- **结局**：全球电动车销量Top1，FSD+能源业务成为新增长极

[来源:Tesla年报+Musk公开讲话 | 置信度:📚中]

---

## 生态结构：三层纵向整合

### Layer 1：能源生成层

- Solar Roof：太阳能屋顶发电
- Powerwall：家庭储能
- Megapack：电网级储能

### Layer 2：能源使用层

- Model S/3/X/Y：电动车（能源消耗端）
- Supercharger：充电网络（能源传输）
- FSD：自动驾驶AI（数据+算法层）

### Layer 3：制造层

- Gigafactory：电池自造（成本控制）
- 4680电池：下一代电池技术
- Dojo超级计算机：AI训练基建

---

## 飞轮设计

```
卖车 → 积累驾驶数据 → FSD训练 → 更好的自动驾驶 → 车更有吸引力 → 卖更多车
  ↑                                                                  │
  └──── Gigafactory降成本 → 车价下降 → 更多买得起 → 卖更多车 ←──────┘
        ↑
        └── 电池技术进步 → Powerwall更便宜 → 能源生态更强
```

**独特之处**：Tesla的飞轮不是"平台飞轮"（供给侧网络效应），而是"数据飞轮"（更多车→更多数据→更好的FSD→更有竞争力→更多车）。

---

## PM可复用的5个关键决策点

1. **纵向整合不是倒退，而是极致控制力** —— Tesla自造电池/芯片/软件，这是"成本+体验+速度"三赢
2. **数据飞轮>供给飞轮** —— 在AI时代，"数据越多产品越好"比"供给越多用户越多"更有护城河
3. **从产品到基础设施** —— Supercharger从"为Tesla服务"变成行业标准（NACS被北美广泛采用）
4. **能源是电动车生态的上游延伸** —— 当车是移动物联网终端时，"发电-储电-用电"全链路才有意义
5. **制造能力本身就是护城河** —— Gigafactory不是成本中心，而是竞争壁垒
