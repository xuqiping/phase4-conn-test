# B 学谁 — 业内顶尖人士对标图谱

## 1. Jakob Nielsen

| 维度 | 内容 |
|---|---|
| 身份/头衔 | "可用性之父"、NNGroup联合创始人 |
| 核心成就 | 提出5用户法则、十大可用性原则、可用性折扣工程(Discount Usability) |
| **思维模型** | **"折扣可用性"**——不需要昂贵的眼动仪和实验室，5个用户+1台电脑+观察就够了 |
| **行动范式** | 快速测试→快速修复→再测试——速度比精度重要 |
| 可学习点 | "研究不需要完美才有效"——PM做5人可用性测试比不做强100倍 |
| 代表作 | NNGroup文章库（免费）、《Usability Engineering》 |
| 来源 | [来源:nnngroup.com｜ 置信度:🔍高] |

## 2. Steve Portigal

| 维度 | 内容 |
|---|---|
| 身份/头衔 | 用户研究顾问 |
| 核心成就 | 《Interviewing Users》作者；访谈方法实操标杆 |
| **思维模型** | **"深度>广度"**——5人做1小时深度访谈>500人填5分钟问卷；**"笨问题>聪明问题"**——问你真不知道的，别问你想验证的 |
| **行动范式** | 充分准备大纲→到现场放下大纲→跟随用户走→回来重新看笔记 |
| 可学习点 | 访谈的核心不是问题列表，而是追问能力——"你刚才说的X，能再多讲讲吗？" |
| 代表作 | 《Interviewing Users》(2013) |
| 来源 | [来源:portigal.com｜ 置信度:📚中] |

## 3. Janice Fraser

| 维度 | 内容 |
|---|---|
| 身份/头衔 | Luxr/FuturePrime创始人、Lean UX先驱 |
| 核心成就 | 将精益创业思想融入用户研究 |
| **思维模型** | **"研究即实验"**——每次研究都是验证假设的实验，不等收集完所有数据再行动 |
| **行动范式** | 最小可行研究→最小可行产品→快速验证循环 |
| 可学习点 | 研究目的不是"全面了解用户"而是"减少下一个决策的不确定性" |
| 代表作 | Lean UX方法论实践 |
| 来源 | [来源:luxr.co｜ 置信度:📚中] |

## 4. 黎万强

| 维度 | 内容 |
|---|---|
| 身份/头衔 | 小米联合创始人 |
| 核心成就 | 小米"参与感"研究方法论——让用户参与产品开发 |
| **思维模型** | **"用户是朋友不是样本"**——不是"研究用户"，而是"和用户一起做产品" |
| **行动范式** | MIUI论坛100人种子用户→每周迭代→用户投票决定功能优先级 |
| 可学习点 | 中国式用户研究的创新路径——社区即研究场、粉丝即研究员 |
| 代表作 | 《参与感》(2014) |
| 来源 | [来源:豆瓣读书/小米官方｜ 置信度:🔍高] |

## 5. Tomer Sharon

| 维度 | 内容 |
|---|---|
| 身份/头衔 | Google前资深UX研究员 |
| 核心成就 | 《Validating Product Ideas》作者；精益研究方法实践 |
| **思维模型** | **"验证>探索"**——产品想法很多，关键是快速验证哪个值得做；**"18分钟面谈"**——够回答1个核心问题就停 |
| **行动范式** | 定义假设→选方法→快速执行→结论即行动 |
| 可学习点 | PM自己做研究不需要成为专业研究员——掌握3个核心方法(访谈+问卷+可用性测试)覆盖80%场景 |
| 代表作 | 《Validating Product Ideas》(2016) |
| 来源 | [来源:medium/@tomershoron｜ 置信度:📚中] |
