## Step1：V70 + 条目级 coverage（FR-301/305）

- `memory_summaries` 加 `scope_owner`（USER/PROJECT，默认 USER 兼容老行）+ `source_entry_ids BIGINT[]`（条目级 provenance）；`user_id` DROP NOT NULL（项目资产行 user_id=NULL）。
- 新表 `memory_entry_coverage`（entry_id + summary_id FK CASCADE + project_id/tag_id/user_id，**UNIQUE NULLS NOT DISTINCT(entry_id, project_id, tag_id, user_id)**）。
- **偏离 plan**：plan 写 UNIQUE(entry_id, project_id)——条目多标签 + 成员个人通道须按 (tag, user) 幂等，落 4 列键（V70 头部已记偏离）。

## Step2：项目共享总结生成 + 读取（FR-301/303）

- **生成**：`MemoryConsolidationService.summarizeProjectScope`——触发权限 shared→owner/admin（非→note 跳过）、personal→ACTIVE 成员；取数=`[projectId] + findActiveChildIds` 嵌套单跳实时算 → 按 tag 分组 → `compressEntries`（条目版压缩器，同 3 重试 + 日期铁律）→ `writeProjectSummaryAndCoverage`（共享：user_id=NULL + scope_owner=PROJECT；PENDING_CONFLICT 同域判定）。
- **读取**：`GET /summaries/project/{projectId}`（`listProjectSharedSummaries`，ACTIVE 成员咽喉在 service 层）。
- **裁决权随总结所有权**（FR-303）：`MemoryConflictResolutionService.resolve` 先载 trigger summary——scope_owner=PROJECT → 项目 owner/admin 才可裁（越权统一 NOT_FOUND 防探测）；个人→conflict.user_id 匹配（一期语义不变）。**项目共享 DISCARD 仅软删 summary**：条目是项目资产不动，entry_coverage 留档防重压循环。
- **targets**：`MemoryConsolidationTargetView.canWriteShared`（OWNER/ADMIN）供前端通道选择。

## Step3：成员个人压缩通道（FR-302）

- `MemoryConsolidationScopeRequest.toPersonal`：true → 产出 user_id=自己 + scope_owner=USER + project_id=该项目 + entry coverage user_id=自己（按成员个人域幂等）；对项目共享总结零写。普通成员调共享通道 → note 跳过不报错（批量触发语义）。

## Step4：废 12h + 删除级联 + 撤销授权钩子（FR-303/304）

- **废 12h 拒删**（FR-304）：DISCARD 分支 12h FORBIDDEN 删除——被引用统一 STALE + 通知 + worker 重生，无 403（HOURS_12 留 @Deprecated 注释）。
- **`MemoryTurnDeleteCascadeService`**（新，单事务）：turn 软删后 → ① `source_turn_id` 命中条目级联软删 → ② 波及总结双路收集去重（`source_turn_ids @> [T]` ∪ `source_entry_ids @> [E]`）→ ③ 标 STALE + 清双侧 coverage + 通知（个人→作者；共享→项目 ACTIVE owner/admin）；已 STALE 幂等跳过。**级联零 LLM**，重压异步给 worker（坑点预判④ 防级联风暴）。
- **worker 条目级重生** `regenEntryOne`：取数=**当前 ACTIVE 链实时算**（撤销授权后重压天然不含 child 内容，坑点预判③）；空链 → 软删 summary + 清 coverage；成员个人总结作者非 ACTIVE 成员 → 软删（离职失读权）；共享总结 user_id=NULL 不在 per-user 循环 → `pollAuto` 末尾 `regenStaleProjectShared()` 统一入口。
- **撤销授权钩子**（FR-303）：`MemoryProjectLinkService.revoke` ACTIVE→REVOKED 成功后 `markProjectSharedStaleByChildEntries(parent, child)`（`source_entry_ids && child 条目集` 单 UPDATE）。

## 关键决策 / 偏离 plan

1. **coverage 唯一键 4 列**（见 Step1）。
2. **项目共享 DISCARD 留 coverage 档**：删了会让下轮总结把同批条目重压重建同样冲突（死循环）；summary_id 指向软删行无害。
3. **重生取数一律实时算链**，不信 provenance 快照——撤销/删除后的正确性靠「当前 ACTIVE」保证，provenance 只用于 STALE 标记定位。
4. **冲突列表共享行打瞬态标而非改表**：`projectShared` 仅展示层 badge 用，不落库。
5. **普通成员触发共享通道不 403 改 note 跳过**：批量触发多 scope 时单 scope 权限不足不应整批失败（与一期 summarizeScope note 语义一致）。
