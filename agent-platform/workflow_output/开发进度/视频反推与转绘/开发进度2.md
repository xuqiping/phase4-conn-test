## 关键决策

1. **单次 LLM 双产物**：STORYBOARD+SCRIPT 共用一次多模态调用（提示词同时约束两结构），省一次调用与 token；KEYFRAMES-only 完全不调 LLM。
2. **parts 组装**：指令文本 part + 每帧（image base64 jpeg part + 「第N帧 t=X.XXs」文本 part）交替，时间序；温度 0.3/maxTokens 4000/stream false。
3. **JSON 容错解析**承 CanvasNodeRunnerService/MemoryEntryDistiller 范式：剥 ``` 围栏→截首 `{` 尾 `}`→readTree；失败真实重试 1 次（多一次计费可控），两败 UNPROCESSABLE 固定话术。
4. **结构告警不阻断**：localize 比对原稿与改写稿 scenes 数，不一致 → warning 字段（结果仍可用）；原稿非 JSON（用户手改后）静默跳过比较。
5. **model 以响应为准**：请求 model 可空（网关回退管理员默认对话模型），响应 model 回传实际值——多模态场景用户需感知用了哪个模型。
6. **源授权双路**：taskId → `loadForDownload(uid,false)` 咽喉（他人任务 FORBIDDEN 透传）；fileId → 抽帧 `loadPath` 归属校验。
