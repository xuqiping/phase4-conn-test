## 官方 SeedDance 2.0 契约（顶层平铺，无 parameters 包裹）

| 字段 | 中文 | 取值 |
|---|---|---|
| model | 模型 | `dreamina-seedance-2-0-*` / 网关 `Cdance2.0` |
| content[] | 输入内容 | text / image_url / video_url / audio_url（+ role） |
| ratio | 画面比例 | 21:9/16:9/4:3/1:1/3:4/9:16/adaptive |
| duration | 时长 | **4–15 秒**（统一，无 fps，24fps 固定） |
| resolution | 分辨率 | 480p/720p/1080p/4K（全版；Fast/Mini 仅 480p/720p） |
| watermark | 水印 | bool |
| generate_audio | 生成音频 | bool（2.0 特色，同步原生音频） |
| service_tier | 推理层级 | flex（离线，可选） |

查询响应：`status`(queued/running/succeeded/failed) + `content.video_url` + `usage.completion_tokens`(byteplus/网关) || `usage.total_tokens`(火山方舟)。

## 6 处不符 → 修复（commit 7871e37b 后端 + 11a2d310 前端）

| # | 旧 | 新 |
|---|---|---|
| 1 | path 硬编 `/api/v3/contents/generations/tasks` + strip `/api/v3\|/v1` | path 相对 `/contents/generations/tasks`；baseUrl 直接用 doubao endpoint（含版本段，官方 `/api/v3`、ctaigw `/v1` 原样） |
| 2 | body `parameters:{watermark,duration,resolution,fps}` 嵌套 | 顶层平铺 model/content/ratio/duration/resolution/watermark/generate_audio |
| 3 | 缺 `ratio` | 加 ratio（默认 16:9，白名单含 adaptive） |
| 4 | 多 `fps` | 删（官方统一 24，无此参） |
| 5 | duration 1–10 | 4–15（MediaSubmitRequest @Min4/@Max15；properties.maxDuration 默认 10→15） |
| 6 | usage 读 `total_tokens` | `completion_tokens` || `total_tokens`（双字段兼容） |

resolution 保留（官方确有）+ 加 4K 白名单/费率(555840/s)。

## 补充 2（全链路 E2E 打通，commit 8c000f63）

ctaigw 冒烟又暴露 2 个问题，修复后 **task4 全链路 SUCCEEDED+下载+真值 usage=108900**：

**3. seedance 混入 chat 路由（commit 8c000f63）**：`LlmConfig.initProviders` 把每个 active provider 都注册成 chat provider，seedance 被当 chat → 聊天发 `/chat/completions` → ctaigw 视频网关 500。修：新增 `MEDIA` category（LlmProviderService.CATEGORIES 加 MEDIA）；initProviders 跳过 MEDIA；`/models/available` 排除 MEDIA；前端 ProviderManageTab category 下拉加「视频/生图 (MEDIA)」。seedance 设为 MEDIA 后注册数 6→5、chat 模型列表无 Cdance2.0。视频代码按 name 单独取 seedance 不受影响。

**4. 视频 URL 下载 400 AccessDenied（commit 8c000f63）**：Ark/ctaigw 返的 video_url 是预签名 TOS 链接（query 含 `%2F` 已编码），`MediaStorageService` 用 `.uri(String)` 被 WebClient 当 URI 模板**二次编码**（`%`→`%25`）→ 签名破坏 → TOS 400 AccessDenied → DOWNLOAD_FAILED。修：`.uri(URI.create(videoUrl))` 跳过编码工厂原样发送。

**E2E 终态（task4，ctaigw 真任务）**：
```
submit 200 PENDING → worker 认领 → 建任务成功 cgt-xxx（ctaigw 译 model=doubao-seedance-2-0-260128）
→ query running → SUCCEEDED → URI 下载落盘 stored_files → markSucceeded
状态 SUCCEEDED，videoUrl=Y（下载端点），usageTokens=108900（Ark 真值，flag=SUCCESS）
```

**部署必做（更新）**：seedance provider 的 **category 必须设 `MEDIA`**（不是 CHAT），否则会混进 chat 路由报 500。其余 endpoint=`https://ai.ctaigw.cn/v1` + key + models=`["Cdance2.0"]`。

## 补充 3（浏览器「查看」播放报「请求失败」，commit 432518fc）

SUCCEEDED 任务点「查看」报「请求失败」：`fetchVideoBlob` 用 `responseType:'blob'` 拉下载端点，响应是 video/mp4 二进制（无 `{code,msg,data}` 包装），但 axios 响应拦截器对所有响应校验 `res.code`，blob 无 code → `undefined !== 200` → 当业务错误弹「请求失败」并 reject。

修：响应拦截器对 `responseType ∈ {blob, arraybuffer}` 跳过 code 校验原样返回（二进制下载不走业务码）。此 bug 影响全站任意 blob 下载，非视频专属。
