# 企业级精准知识库 RAG 开发进度 7

## P1 Step 5：Contextual Content 与幂等索引任务

- 新增 `Contextualizer`，按固定顺序拼装文档标题、不可变版本、titlePath、所属背景和 Chunk 原文；可选字段缺失使用明确占位，不输出 `null`。
- `contentHash` 保持原文 Hash，`contextHash` 覆盖完整上下文化文本；不把 owner、ACL、密级等治理信息加入模型文本。
- S1、C2、E3 均创建索引 Outbox；C2/E3 节点保存真实 `contextHash`，Worker 向量化 contextual content，不再只向量化裸原文。
- 新增 V109：任务锁定 `versionId/parserVersion/chunkerVersion/embeddingModel/pipelineVersion`。Embedding 模型来自 KB 显式配置，Pipeline 版本来自 `RAG_INDEX_PIPELINE_VERSION`。
- Worker 优先使用任务模型快照，调用前复核节点状态、content/context Hash 和版本背景；漂移任务直接 FAILED，由新版本任务接管。
- `IndexJobTxService` 在短事务内再次复核 Hash，按节点真实 L0/L2 level upsert 向量、完成任务并判断文档 INDEXED；旧任务保留明确兼容回退。
- 节点任务通过 `ON CONFLICT (idempotency_key) DO NOTHING` 幂等入队，指纹覆盖节点、双 Hash 与完整版本快照；重复解析不因唯一键冲突失败。
