## 四、关键术语速查

| 术语 | 定义 |
|---|---|
| 前置依赖 | A是B的前置 = 不学A就学不懂B（硬性逻辑依赖） |
| 并行可学 | A和B无前置关系，可同时学习 |
| 依赖链 | 多个前置串联形成的路径（A→C→F） |
| 反向依赖 | X是Y的前置 = Y反向依赖X |
| 知识锁 | 多个前置同时满足才能解锁的学习节点 |
| 依赖深度 | 从根节点到目标节点的最长路径长度 |
| 分轨依赖 | 不同专业方向（B端/AI/增长）的不同前置集 |
