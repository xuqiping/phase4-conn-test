# 变更记录（Changelog）· <项目名>

> Phase 6 产物。项目级变更日志，每次**改 / 增 / 删已有功能**追加一条。
> 让"这个功能什么时候、为什么被改成现在这样"有据可查。
> **新功能开发不记这里**（那走主链）；本表只记**对存量功能的变更**。
> **文档规模**：本文件不得超过 5000 tokens。记录过多时，按年份/季度拆分（如 `变更记录.2026.md`），本文件保留最近记录和索引。
