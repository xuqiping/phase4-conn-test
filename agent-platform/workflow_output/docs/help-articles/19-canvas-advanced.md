# 无限画布进阶

> 前置：已会基础操作（见「无限画布：建画布、拖节点、连线生成」）。

## 一、框选与批量操作

1. 右下工具条点 **▭** 切到框选模式 → 左键拖框框住多个节点（≥2 个时顶部浮出批量工具条）。
2. **批量生成**：按上下游顺序提交——上游成功下游才跑；上游失败下游自动跳过标灰（互不依赖的并行 2 个）。浮条可「停止调度」。
3. **一键关联**：选中多个文本类节点，自动把文本里出现的上游节点名字替换成 @引用（弹提案预览，可逐行勾选再「应用」）。
4. **批量删除**：二次确认后连节点带线删。

## 二、版本存档（跨会话的后悔药）

撤回（Ctrl+Z）只在当前会话有效；**版本**能跨会话存档：

1. 编辑页头部点「**版本**」按钮。
2. 输版本名（可空）→「存版本」= 存档点。
3. 点某版本「恢复」→ 二次确认；**恢复前系统自动把当前状态存为「恢复前自动存」**，恢复错了能再恢复回来。
4. 每画布自动保留最近 30 个版本，超出自动清最老的。

## 三、节点组（给相关节点围个圈）

1. 框选 ≥2 个节点 → 工具条「**设为组**」→ 输组名（如「角色设定组」）。
2. 画布出现彩色虚线包围盒；拖成员包围盒跟着走。
3. 点组名改名；点 ✕ 解散（节点不删）。
4. **下游 @ 组员**：组内任一成员连到你，整组成员都能被 @（按组分节显示，方便找）。

## 四、图片节点小工具

**翻转/旋转**（选中图片节点 → 属性面板）：↔ 水平翻转 / ↕ 垂直翻转 / ⟳ 旋转——产新图节点连在原图旁，**原图不变**。

**彩色标注 + AI 修改**（属性面板「彩色标注」）：
1. 在图上拖框 → 选颜色 → 写指令（如「这里加一个杯子」，≤200 字）。可画 ≤8 个框。
2. 两个出口：
   - 「**生成标注图**」→ 只产标注后的图节点。
   - 「**AI 修改**」→ 自动建下游 AI 图节点，按你的逐框指令改图（源节点需已选图片模型，否则提示选模型后手动运行）。

## 五、其他实用增强

- **拖角改大小**：选中节点拖四角柄改宽高（最小 160×64）。
- **关联高亮**：选中节点 → 上下游连线高亮；右下工具条 🔗「只看关联」隐藏无关节点。
- **参考预览**：@了上游图/视频后，属性面板「参考」区显示缩略图（悬浮放大、点击全屏/播放）。
- **断网韧性**：生成中断网不再误报「服务不可达」，网络恢复自动续跑；切走标签页再回来立即刷新进度。
- **离开不丢任务**：提交生成后关页面，任务照跑，回来自动接着显示进度/结果。

## 常见异常

| 现象 | 原因 | 恢复 |
|---|---|---|
| 批量后部分节点灰标 | 上游失败或上游不在选集 | 悬停看原因；重跑上游或把上游一起框选 |
| AI 修改没自动出图 | 源节点没选图片模型 | 选模型后点「AI 生图」 |
| 建组没反应 | 框选少于 2 个节点 | 多框几个（上限 50） |
| 拖柄拖不动 | 节点没选中/已到最小尺寸 | 先单击选中 |
