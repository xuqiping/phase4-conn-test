## 关键调用链

```
提交视频/图片: PropertyPanel 运行 → CanvasView.onRunVideo/Image
  → buildVideoAttachments/buildImageRefs → resolveCanvasVideoAttachments
    → collectCanvasRefs（@解析+序号化）→ mediaApi.submit* → pollMediaTask（退避）

批量生成: 批量工具条 → onBatchRun（资格预检+环检测）
  → runDependencyScheduled（窗口2）
    → submit 段: submitVideoOnly/submitImageOnly/onRunNode(text)
    → awaitTerminal 段: pollVideo/ImageTask 或读 text status
    → onNodeState: skipped/done/failed → 节点标灰+浮条计数

图片变换/标注: PropertyPanel 按钮 → CanvasView.onTransformImage/onAnnotate*
  → canvasApi.transformImage/annotateImage → 后端 EXIF 归正+op 变换/合成
  → 新 fileId → fetchCanvasPreview → addNode 衍生节点+addEdge

节点组: 框选≥2 → 批量工具条「设为组」→ confirmCreateGroup
  → Board.createGroup（过滤死成员/查50/移出旧组）→ 包围盒 watch rAF 重算
下游 @: MentionTextarea 候选 ← CanvasView.mentionCandidates
  ← expandGroupCandidates(selectedAncestors, nodes, groups)
```

## 踩坑批注

- vue-flow 无公开 `useViewport` 组合式——`onMove(({flowTransform}))` 事件钩子是唯一口；store 的 viewport 是 readonly。
- `/frames` 抽首帧每次产新 stored_file——预览场景会持续污染产出物列表；用 blob+`<video preload="metadata">` 浏览器原生首帧零后端副作用。
- resize 拖动中每帧 `updateStyle:true`——只在 `resizing:false` 一次 emit structure-changed，否则 800ms 防抖被搅成保存风暴。
- 标注色合成期望按**白底** 30% 混色推算（非黑底）——首版算错 34 距离返工。
- vue-tsc：CanvasBoard 内 computed 声明顺序敏感（applyVisualClasses 引 nodeGroupMap 须先声明）。
- vitest mock `useVueFlow` 时新解构字段（如 onMove）要同步补 mock，否则 `undefined is not a function` 全文件挂。
