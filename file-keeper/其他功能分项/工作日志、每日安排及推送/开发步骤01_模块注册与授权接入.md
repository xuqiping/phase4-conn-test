## 4. 详细任务

### 4.1 后端常量注册

修改 [`AuthConstants.java`](../../server/src/main/java/com/superprogrammer/security/AuthConstants.java)：

```java
public static final String MODULE_FILES = "files";
public static final String MODULE_PROCESSES = "processes";
public static final String MODULE_CLIPBOARD = "clipboard";

// 新增
public static final String MODULE_WORK_REPORT = "work-report";
```

### 4.2 授权服务白名单

修改 [`AuthorizationService.java`](../../server/src/main/java/com/superprogrammer/authorization/service/AuthorizationService.java)：

```java
private static final List<String> MODULE_CODES = List.of(
        AuthConstants.MODULE_FILES,
        AuthConstants.MODULE_PROCESSES,
        AuthConstants.MODULE_CLIPBOARD,
        AuthConstants.MODULE_WORK_REPORT   // 新增
);
```

### 4.3 数据库 CHECK 约束

新增 Flyway 脚本 `V{x}__extend_module_code_for_work_report.sql`：

```sql
ALTER TABLE user_module_entitlements
    DROP CONSTRAINT IF EXISTS ck_user_module_entitlements_module;

ALTER TABLE user_module_entitlements
    ADD CONSTRAINT ck_user_module_entitlements_module
        CHECK (module_code IN ('files', 'processes', 'clipboard', 'work-report'));
```

> 注意：如果 `anonymous_device_trials.free_module_code` 也有 CHECK 约束，本步骤不需要修改（MVP 不支持匿名免费），但需在文档中备注 Phase 2 再评估。

### 4.4 桌面端中文映射

修改 [`EntitlementStatus.vue`](../../src/components/EntitlementStatus.vue)：

```ts
const MODULES: Array<{ code: ModuleCode; label: string }> = [

```

### 4.5 管理后台授权选项

## 8. 风险与注意事项

| 风险 | 说明 |
|---|---|
| CHECK 约束命名不一致 | 如果现有约束名不是 `ck_user_module_entitlements_module`，需先确认真实约束名 |
| 前后端 moduleCode 不一致 | 必须确保前后端都是 `work-report`，不要写成 `workReport` 或 `workflow-report` |
| 离线 Token 不包含新模块 | 检查 `AuthorizationService.authenticatedSnapshot()` 是否基于 `MODULE_CODES` 循环生成 |
