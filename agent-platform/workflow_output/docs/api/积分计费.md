# 积分计费 API 契约

> 前后端内部契约速查。统一响应：`R<T>`；路径均带 `/api`；错误由全局异常处理返回固定业务消息。

## 价表模型候选

### `GET /api/billing/pricing/available-models`

- 权限：`pricing:manage`
- 入参：无
- 出参 `data`：候选数组；每项仅含：
  - `providerId: number`：全局供应商 ID
  - `providerName: string`：显示名，缺失时回退内部名称
  - `model: string`：已 trim、去重的模型名
  - `kind: CHAT | EMBED | IMAGE | VIDEO`
- 规则：只读取 `ACTIVE` 全局供应商；类别映射 `CHAT→CHAT`、`EMBEDDING→EMBED`、`IMAGE→IMAGE`、`VIDEO→VIDEO`；排除已存在相同 `(providerId, model)` 的价表。
- 容错：空/坏 JSON、未知类别供应商被跳过并记录 WARN，不返回密钥或 provider config。

示例：

```json
{
  "code": 200,
  "msg": "success",
  "data": [
    {"providerId": 7, "providerName": "豆包", "model": "doubao-seed", "kind": "CHAT"}
  ]
}
```
