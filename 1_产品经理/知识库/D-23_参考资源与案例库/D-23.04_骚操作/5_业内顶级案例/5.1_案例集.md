## 案例1：老乡鸡200元土味发布会——反差自黑+低成本逆袭(2020)

| 要素 | 内容 |
|---|---|
| 名称 | 老乡鸡200元土味战略发布会 |
| 时间 | 2020-03-18 |
| 主角 | 老乡鸡（董事长束从轩） |
| 背景 | 2020年3月疫情冲击，老乡鸡全国损失近5亿；同期获银行10亿授信+战投，需向外界传递"逆势扩张+招人5000" |
| 技术手法 | 用200元成本搭村口土味舞台(砖头/红布/搪瓷杯/老式话筒)，董事长束从轩用安徽口音+大白话讲战略级信息；前期"手撕员工免薪联名信"造热，发布会引爆后"不洗手不允许吃饭"等持续造梗 |
| 影响后果 | 微博热搜阅读量10亿+；3天获数万份应聘简历；老乡鸡从区域品牌跃迁为全国品牌；2023年营收近100亿[来源:前瞻网 2020+新浪财经 2023 | 置信度:🔍高] |
| 教训启示 | 反差自黑=品牌主动示弱→用户会心一笑→主动传播；低成本创意>"高大上"舞台；董事长亲自下场是最强人格化 |
| 反例（反面） | 不少品牌模仿"土味发布会"且模仿痕迹明显→舆情嘲讽"作秀"而非引爆 |
| 来源标注 | [来源:前瞻网 2020+Morketing 2020+新浪财经 2023 | 置信度:🔍高] |
