# 商业画布填写模板

## 填写指南

**顺序**：先左（供给）→ 右（客户）→ 底（财务）——先想"提供什么+给谁"，再想"怎么赚钱"

## 9格模板

```
┌─────────────┬─────────────┬─────────────┬─────────────────────┬──────────────┐
│ 重要合作      │ 关键活动      │ 价值主张      │ 客户关系             │ 客户细分      │
│              │              │              │                     │              │
│ 谁帮我们？    │ 必须做什么？  │ 为谁解什么？  │ 什么关系？            │ 谁付钱？      │
│ ___________ │ ___________ │ ___________ │ ___________         │ ___________ │
│              │              │              │                     │              │
│              ├─────────────┤              ├─────────────────────┤              │
│              │ 核心资源      │              │ 渠道通路             │              │
│              │              │              │                     │              │
│              │ 需要什么？    │              │ 怎么触达？            │              │
│              │ ___________ │              │ ___________         │              │
├─────────────┴─────────────┴─────────────┴─────────────────────┴──────────────┤
│ 成本结构                          │ 收入来源                              │
│ 主要花在哪？                      │ 怎么收钱？                            │
│ ___________                      │ ___________                          │
└──────────────────────────────────┴─────────────────────────────────────────┘
```

## 每格填写要点

| 格子 | 关键问题 | 高频错误 |
|---|---|---|
| **价值主张** | 用一句话说清"谁+什么痛点+我们怎么解" | 堆功能而非说价值 |
| **客户细分** | 谁付钱？≠谁用（B2B2C要拆） | "所有人"=没人 |
| **渠道通路** | 用户第一次接触我们是通过什么？ | 只写线上/线下，不写具体触点 |
| **客户关系** | 自助/社区/专属？获取/留存/增长各什么关系？ | 只写一种关系 |
| **收入来源** | 每类客户怎么收？是订阅/一次/分成？ | 只写一种收入 |
| **核心资源** | 没有_什么_我们就没法运转？ | 遗漏数据/品牌/关系等无形资源 |
| **关键活动** | 我们每天/每周必须做的最关键3件事？ | 列太多（>5=没有优先级） |
| **重要合作** | 哪些事我们不做、靠合作伙伴？ | 把供应商当合作伙伴 |
| **成本结构** | 如果营收翻10倍，什么成本也翻10倍？ | 只算固定成本不算边际成本 |

## 检查清单

- [ ] 价值主张与客户细分的对应——每个细分都有对应的价值主张吗？
- [ ] 收入来源覆盖所有客户细分——每类客户都有收入模式吗？
- [ ] 成本结构与关键活动/核心资源匹配——最大花销在最重要的活动/资源上吗？
- [ ] 逻辑自洽——如果价值主张是"低价"，那成本结构是否支撑低价盈利？
