# 3.1 格式本地化体系

## 一、货币格式本地化

### 1.1 核心差异维度

| 维度 | 典型差异 | 常见坑 |
|---|---|---|
| 符号位置 | €1,00（欧元区）/ ¥1（中日）/ 1€（法语）/ $1（美元）| 硬编码"$"符号→欧洲用户看不懂 |
| 小数精度 | 日元/韩元无小数；迪纳尔3位小数；美元2位小数 | 统一2位小数→日元显示¥100.00很荒谬 |
| 千分位分隔 | 1,000.00（美英）/ 1.000,00（德法）/ 1 000,00（瑞士）| 把德国1.000当1千而非1.0导致金额错误 |
| 货币代码 | ISO 4217（USD/EUR/CNY/JPY） | 混用CNY/CN¥/RMB，未统一标准码 |

### 1.2 PM必知决策点

- **货币选择策略**：多货币展示（列表页显示当地货币估算）vs 单货币结算（统一结算币种）→ 需明确汇率数据源与更新频率
- **舍入规则**：日元/韩元需去小数位；瑞士法郎按0.05舍入（瑞士舍入法）；印度卢比用拉克/克罗表示大数
- **汇率实时性**：展示汇率 vs 结算汇率——展示可延迟，结算必须锁汇率 `[来源:ICU4X文档 | 📚中 | 2026]`

## 二、日期与时间格式

### 2.1 日期格式三大体系

| 体系 | 格式 | 代表地区 | ISO 8601对齐 |
|---|---|---|---|
| 大端序（年月日） | YYYY-MM-DD / YYYY年M月D日 | 中国/日本/韩国/伊朗 | ✅天然对齐 |
| 中端序（月日年） | MM/DD/YYYY | 美国 | ❌最易混淆 |
| 小端序（日月年） | DD/MM/YYYY | 欧洲/拉美/非洲 | ❌与美式混淆 |

**致命坑**：01/02/2025——美国读2月1日，欧洲读1月2日。PM决策：**优先展示ISO 8601（YYYY-MM-DD）或月份拼写缩写（01 Feb 2025）消除歧义** `[来源:CLDR | 🔍高 | 2026]`

### 2.2 时间格式

| 维度 | 差异 | 常见坑 |
|---|---|---|
| 12h vs 24h | 美国12h（AM/PM），全球多数24h | 强制24h→美国用户不适 |
| 时区表示 | UTC+8 / CST / GMT / IANA时区名(Asia/Shanghai) | CST=中国标准时间=中央标准时间(美)=古巴标准时间→3义 |
| 夏令时(DST) | 美欧有，中日韩无；2026年3月美启动DST | 硬编码偏移量→DST切换时定时任务错位 |

### 2.3 PM决策：时区架构选型

- **服务器统一UTC存储 + 客户端本地渲染**（最佳实践）
- **IANA时区数据库**（tzdata）为唯一可靠数据源——各国时区政策年际变化（如墨西哥2022取消DST）需定期更新 `[来源:iana.org | 🔍高 | 2026]`

## 三、度量衡本地化

| 体系 | 适用地区 | PM注意 |
|---|---|---|
| 公制（SI） | 全球多数国家 | 温度℃/长度m/重量kg |

## 四、姓名与地址格式

### 4.1 姓名格式差异

| 地区 | 格式 | 特殊处理 |
|---|---|---|
| 中国/日/韩 | 姓+名（张三/田中太郎） | 姓名顺序与西方相反；单姓单名常见 |
| 欧美 | 名+姓（John Smith） | 中间名（middle name）可选 |
| 西班牙/拉美 | 名+父姓+母姓（Juan García López） | 双姓系统——只取父姓=信息丢失 |
| 阿拉伯 | 名+父名+祖父名+族名 | 四段式，部分段可省 |
| 冰岛 | 名+父名后缀-son/-dóttir | 无固定姓氏，每代新生 |

**PM铁律**：姓名字段**永远分"姓""名"存储**，展示层按地区拼接；禁止合并为单一"全名"字段 `[来源:W3C i18n | 🔍高]`

### 4.2 地址格式差异

| 地区 | 格式顺序 | 特殊字段 |
|---|---|---|
| 中国 | 国>省>市>区>路>号>室 | 邮编6位数字 |
| 日本 | 邮编>都道府県>市区町村>町名>番地 | 邮编7位〒开头 |
| 美国 | 街道>套房>城市>州>邮编 | 州2字母缩写+5位ZIP |
| 德国 | 街道+门牌>邮编>城市 | 门牌号在街名后面 |
| 英国 | 门牌+街道>城市>县>邮编>国家 | 邮编有空格格式(SW1A 1AA) |

**PM决策**：地址表单**按地区动态渲染字段**，不要用一套"全球通吃"的固定表单 `[来源:Google Address i18n API | 📚中]`

## 五、电话号码格式

- **E.164国际格式**：+86 138 0000 0000（国际标准）
- **各国分组差异**：中国3-4-4 / 美国(3)3-4 / 日本3-4-4 / 德国3-3-6
- **国家代码**：+1(美加) / +86(中) / +81(日) / +49(德) / +44(英)
- **PM注意**：号码输入框应支持国际格式+自动格式化显示；存E.164，展示本地格式 `[来源:ITU E.164 | 🔍高]`
