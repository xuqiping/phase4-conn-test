# OKR对齐与战略规划

## 一、OKR对齐规划

OKR（Objectives and Key Results）对齐是连接公司战略与产品执行的**核心机制**。《2025年中国企业目标管理实践调研报告》显示，超过70%的企业推行OKR一年内中断，主因是"目标与执行脱节"。[来源：搜狐《OKR管理法赋能研发团队》 | 置信度：📚中 | 2026-07]

### OKR对齐五步法

| 步骤 | 动作 | 工具/方法 | 常见坑 |
|---|---|---|---|
| 1. 战略解码 | 公司OKR→产品条线目标 | Strategy Canvas+鱼骨图 | 只拆不解——把CEO原话当OKR |
| 2. 目标推导 | 目标→产品方向→关键结果 | 用户旅程+数据诊断 | 目标无数据支撑 |
| 3. Roadmap映射 | 关键结果→Roadmap主题→Now/Next/Later | Impact Mapping | KR与Roadmap主题断层 |
| 4. Sprint关联 | Roadmap主题→Epic→Story→Sprint | 用户故事地图 | Sprint做完发现偏离OKR |
| 5. 周期检视 | 双周Review OKR进度+调整Roadmap | OKR看板+燃尽图 | 季度末才看OKR，已来不及 |

### OKR与版本规划的对齐矩阵

```
公司OKR层级       产品OKR层级        版本规划层级
O1: 行业第一     → O1: 核心NPS达50  → 战略型版本
  KR1: DAU+30%  → KR1: 留存+15%     → 演进型版本
  KR2: NPS>50   → KR2: 核心体验达标  → 日常型版本
```

> ⚠️ **关键**：OKR不是任务清单。写"完成X功能"是任务，不是KR。KR应是**可衡量成果**——"将注册转化率从25%提升至35%"才是KR。[来源：训练知识 | 置信度：📚中]

## 二、战略规划文档

战略规划文档是面向高层/投资人的**1-3年产品战略叙事**，是所有规划的顶层输入。

### 核心模块（7段式）

| 段落 | 内容 | 检验标准 |
|---|---|---|
| 1. 市场格局 | TAM/SAM/SOM+趋势+拐点信号 | 数据有出处，趋势有信号 |
| 2. 用户洞察 | 核心用户画像+未满足需求+JTBD | 有用户原话/调研证据 |
| 3. 竞争定位 | 竞品矩阵+差异化策略+护城河 | 不是"我们更好"，而是"我们不同" |
| 4. 产品愿景 | 3年愿景+北极星指标 | 一句话说清"为谁解决什么" |
| 5. 核心策略 | 3-5条策略主线+资源预估 | 每条策略有投入产出预估 |
| 6. 里程碑 | 关键节点+验证指标+决策门 | 每个里程碑有"验证/调整/砍掉"标准 |
| 7. 风险与依赖 | 技术风险/市场风险/监管风险+缓解方案 | 风险不是"无"，而是具体缓解动作 |

### 愿景-目标-策略-战术四层架构

```
VISION（愿景，3-5年）
  └── GOALS（目标，年/季度OKR）
        └── STRATEGIES（策略，方向选择）
              └── TACTICS（战术，功能/项目）
```

**核心原则**：从上往下对齐（每个战术归属某策略→归属某目标→归属愿景），从下往上验证（战术执行数据验证策略是否有效）。

## 三、常见误区

| 误区 | 后果 | 正解 |
|---|---|---|
| 战略文档=PPT美化 | 形式大于内容 | 先有逻辑，再做呈现 |
| 只看竞争不看用户 | 跟着竞品跑 | 用户洞察先行+竞品参考 |
| 写完就锁死 | 环境变化不响应 | 季度Review+动态调整 |
| 战略与执行两张皮 | 高层觉得好，一线做不了 | 每条策略对应可执行Epic |
| 忽略组织能力 | 战略写了做不到 | 评估团队/技术/资源就绪度 |
