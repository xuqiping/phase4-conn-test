## 已交付能力

- JSON Lines stdin/stdout 的 `office_ooxml_worker inspect` 技术尖峰；路径不接受命令行传入。
- `SAFE_OOXML/HIGH_FIDELITY_REQUIRED/BLOCKED` 三类稳定路由。
- SAFE 前使用 `quick-xml` 校验真实内容类型元素、根关系、扩展对应主部件及其基本一致性；忽略注释、解码字符引用并拒绝 DTD，缺失、错配和超大关系均阻止。
- XML 根/命名空间/直接子级严格校验；ZIP entry 原始名、点段、绝对/drive-like 路径和 ASCII 大小写归一后重复均阻止。
- JSONL 单行 1 MiB，超限排空后继续；ZIP 扫描具备源大小、entry 数、扫描元数据累计、压缩比和 30 秒 deadline 预算。
- 每个 `.rels` 均强制 OPC Relationships 根/命名空间；6 MiB 累计预算仅统计实际读取的 Content Types 与 `.rels`，普通 worksheet/body/slide XML 不误占预算。
- 哈希→ZIP 扫描→复核哈希均使用同一已打开文件句柄，并核对 length/modified。
- 检出旧格式、宏扩展、包内 VBA、数字签名和外部关系；损坏 ZIP 与不支持扩展阻止。
- 检查前后 SHA-256 一致；ZIP 只读扫描，不提取或重写源包。
- 运行时无敏感合成 fixture、真实样本登记规则、Windows COM Worker 安全边界和兼容矩阵。
