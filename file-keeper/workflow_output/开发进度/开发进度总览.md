## 子目录与文件拆分约定

```
workflow_output/开发进度/
├── 开发进度总览.md            ← 本文件（全局入口）
├── 改造总路由.md              ← 本次文档改造的索引（超 5000 tokens 时启用）
└── <功能名>/
    ├── 总路由.md                ← 该功能进度超 5000 tokens 时使用
    ├── <功能名>开发进度总览.md   ← 该功能全貌
    ├── <功能名>开发进度1.md       ← 第 1 轮对话
    └── ...
```

### 单文件 5000 tokens 限制规则
- 所有 Phase 3 产出文档（开发进度 / Feature Map / User-Ops / 功能 README / 测试方案等）≤5000 tokens，约 3000~4000 汉字。
- 接近 4000 预警；超限则：①新建 `<n+1>.md`，或 ②建 `总路由.md` 按主题 / 轮次索引。
