### Task 5B-2：新增桌面端认证 Store

**Files:**

- Create: `file-keeper/src/stores/authStore.ts`
- Test: `file-keeper/src/stores/__tests__/authStore.test.ts`
- Uses: `file-keeper/src/api/auth.ts`
- Uses: `file-keeper/src/stores/commercialAuthStore.ts`

**Store responsibilities:**

- 保存 `accessToken`、`refreshToken`、`user`。
- 登录成功后调用 `commercialAuthStore.initializeAuthenticated(baseUrl, accessToken)`。
- 退出登录后清空认证态，并重新初始化匿名授权。
- 启动时如果本地有 refresh token，先 refresh，再初始化登录授权。
- 如果 refresh 失败，清空登录态并使用匿名授权。

- [ ] **Step 1: Write failing store tests**

Create `file-keeper/src/stores/__tests__/authStore.test.ts` with tests for:

1. `login()` stores tokens and user.
2. `login()` calls `commercialAuthStore.initializeAuthenticated()`.
3. `logout()` calls auth API logout and clears tokens.
4. `logout()` calls `commercialAuthStore.initializeAnonymous()` after clearing login state.
5. `restoreSession()` refreshes token when refresh token exists.
6. `restoreSession()` falls back to anonymous authorization if refresh fails.

- [ ] **Step 2: Run failing store tests**

Run:

```bash
npm --prefix "file-keeper" test -- src/stores/__tests__/authStore.test.ts
```

Expected: FAIL because `authStore.ts` does not exist.
